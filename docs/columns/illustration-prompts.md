## 0. 使い方

1. 下記「共通スタイル」＋「共通禁止事項」＋「個別プロンプト」を**連結して1つのプロンプト**として投入する。
2. 出力は **16:9 の横長**。既存4点と同じ 1672×941 でも、他の16:9サイズでもよい（後段でリサイズする）。
3. 生成後、**右下隅にウォーターマーク状の記号が入っていないか**を確認する（`c9c3749` の申し送り事項）。
4. 原画を1フォルダにまとめ、ファイル名を下表の `原画ファイル名` に揃えて渡していただければ、
   こちら側で 1600×900 / WebP / 120KB以下へ変換し、マニフェストを作成する（変換コマンドは §4）。

プロンプトは日本語で記載している。GPT Image 2 の追従が弱い場合は英語版を用意できるので指示されたい。

## 1. 共通スタイル（全34点の先頭に付ける）

```
淡い水彩のエディトリアルイラスト。背景は生成り（#FAF9F6）のほぼ無地。
主役の色はくすんだ深緑（#1B4332・#2D6A4F）と藍鼠。差し色の金（#C9A227）はごく小さな面積だけ。
にじみとかすれのある水彩の筆致。輪郭線は細く控えめ。影は淡く、コントラストは強くしない。
構図は中央寄りで、上下左右に広い余白をとる。画面中央を正方形に切り抜いても主題が欠けないこと。
人物を描く場合は顔を描き込まず、後ろ姿・横向き・輪郭と姿勢だけで表す。
写実的な写真調・3DCG調にしない。雑誌の特集記事の扉絵として成立する落ち着いたトーン。
16:9の横長。
```

## 2. 共通禁止事項（全34点の末尾に付ける）

```
以下を画面内に一切入れない：
文字・数字・ロゴ・署名・透かし・判読できる書類やスクリーンの文字。
時計の文字盤の数字、グラフの目盛りや数値、看板や暖簾の文字。
実在の人物・企業・団体・物件・商標・官公署の紋章。
裁判所・法廷・裁判官の木槌・天秤（正義の秤）。これらは弁護士・裁判の記号であり、
行政書士・社会保険労務士・宅地建物取引士の業務範囲を誤認させるため使わない。
手の指が不自然にならないよう、手元は最小限にするか画面外に置く。
派手な原色、強いコントラスト、光沢、ストックフォト調。
```

> **重要（既存画像の実例）**: `public/hero/labor-joseikin-16x9.webp`（社労士・助成金）の左下には
> **天秤が描かれている**。弁護士・裁判の記号が社労士の記事に載っている状態であり、
> 上記の禁止事項に該当する。**差し替え候補として §5 に挙げる**（差し替えるかは浦松の判断）。

## 4. 納品後の変換（リポジトリ側で実施）

原画を1フォルダに置いていただければ、以下で 1600×900 / WebP / 120KB以下に統一する。
既存20点と同じ仕様・同じ品質自動調整ロジック（`c9c3749` の踏襲）。

```js
// build-illustrations.mjs  —  node build-illustrations.mjs <原画フォルダ> <出力フォルダ>
import { readdir, stat } from "node:fs/promises";
import path from "node:path";
import sharp from "sharp";

const [srcDir, outDir] = process.argv.slice(2);
const LIMIT = 120 * 1024;

for (const f of (await readdir(srcDir)).filter((f) => /\.(png|jpe?g|webp)$/i.test(f))) {
  const base = path.basename(f, path.extname(f));
  const out = path.join(outDir, `${base}-16x9.webp`);
  let quality = 82;
  for (;;) {
    await sharp(path.join(srcDir, f))
      .resize(1600, 900, { fit: "cover", position: "centre" })
      .webp({ quality })
      .toFile(out);
    const { size } = await stat(out);
    if (size <= LIMIT || quality <= 50) {
      console.log(`${base}-16x9.webp  ${(size / 1024).toFixed(1)}KB  q=${quality}`);
      break;
    }
    quality -= 4;
  }
}
```
