# 既存挿絵によるコラム詳細の先行修正

## 目的

不動産・行政書士・社労士のコラム詳細で、著者写真以外の画像が表示されない状態を、既存画像だけで解消する。記事本文やDBは更新せず、表示テンプレートで一元的に扱う。

## 診断

- 日本語公開ページ監査では、不動産102件、行政書士110件、社労士114件の長文コラムに実質的な挿絵がなかった。
- 原因は画像404ではなく、3種類の詳細テンプレートがグラデーションとタイトルだけを表示していたこと。
- `public/hero/`には、同じ水彩調の16:9画像が20テーマ分ある。桜画像の軽量版を含めると21ファイル。
- 記事固有の`Column.ogImage`は型とDB列に存在し、JSON-LDでは一部利用されていたが、画面とOpen Graphでは統一されていなかった。
- ローカルの本番DB接続情報は認証エラーとなるため、DBへの書込み・migrationは行わない。公開件数は2026-09-22のHTTP監査結果を正本にする。

## 設計

### 画像選択

サーバー側の純粋関数で、日本語正本の`business`、`slug`、`title`、`category`、`tags`、`ogImage`から画像を決める。

優先順位：

1. 記事固有の`ogImage`
2. slugの明示指定
3. テーマ一致
4. 事業別フォールバック

ローカライズ後の文言では選ばない。同一slugは4言語で同じ画像にし、altだけを4言語で変える。

**画像1枚あたりの使用件数に上限を設けない。** 同じテーマに21記事以上が該当しても、件数を理由に意味の異なる画像へ切り替えない。画像の分散は将来プールへ同じテーマの複数バリエーションを追加した後に、意味を保った候補内だけで行う。

### テーマ

- 不動産：グループホーム、海外、相続、社宅、事業用、補助金、投資、文京区。
- 行政書士：障害福祉、相続、在留・国際、補助金、法人・許認可。
- 社労士：処遇改善、障害年金、外国人雇用、外部監査、助成金、介護・福祉、採用、人事・労務。

既存画像は事業名の接頭辞だけで閉じず、意味が合う場合は事業横断で使う。例として、相続不動産には家族・住まい・書類を描いた`legal-inheritance`、事業用不動産には事業所と書類を描いた`legal-company`を使う。

### 表示

色は既存の深緑グラデーションを維持し、水彩画を主役にする。文字は画像へ重ねない。

```text
PC
┌──────────────────────────────────────────────┐
│ 日付  カテゴリ       ┌─────────────────────┐ │
│ 記事タイトル         │      16:9 挿絵      │ │
│                      └─────────────────────┘ │
└──────────────────────────────────────────────┘

スマートフォン
┌──────────────────────┐
│ 日付  カテゴリ       │
│ 記事タイトル         │
│ ┌──────────────────┐ │
│ │    16:9 挿絵     │ │
│ └──────────────────┘ │
└──────────────────────┘
```

- 390px・768pxでは縦積み、1024px以上では左右2列。
- 既存の過大な`min-h-[40vh]`と上下余白を減らす。
- 16:9を明示し、`next/image`と適切な`sizes`でCLSと転送量を抑える。
- 外部`ogImage`は許可ホストを広げず、通常の画像要素で表示する。

### SEO整合

一度解決した同じ画像URLを次へ渡す。

- 画面のヒーロー画像
- Open Graph / Twitter metadata
- BlogPosting JSON-LD `image`

記事固有画像が絶対URLの場合は、`SITE_URL`を二重に連結しない。

## 変更範囲

- 画像マニフェストと解決関数。
- 共通`ColumnArticleHero`。
- 3種類のコラム詳細ページと表示コンポーネント。
- `BlogPostingJsonLd`の画像override。
- 解決規則・使用上限なし・4言語・画像実在性のテスト。

記事本文、CTA、DB、migration、画像ファイルは変更しない。

## 検証

- テーマ優先順位、記事固有画像、フォールバック、危険なURLの除外。
- 同一テーマ25記事が同じ最適画像を選び、20件で打ち切られないこと。
- 同一slugの4言語同一srcと4言語alt。
- 20テーマ画像の実在性。
- 変更ファイルlint、TypeScript、全テスト。
- 代表ページを390px、768px、1440pxで確認。
- visible image、OG/Twitter、JSON-LDが同じURLであることをHTMLで確認。
- 社労士公開フラグON/OFFの既存挙動を維持。
