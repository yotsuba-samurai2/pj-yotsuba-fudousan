# 延滞税の割合 年次更新手順

**毎年1月に実施する。** 延滞税の割合は年ごとに見直され、サイトに数値を直接書いているため、放置すると本番が誤りになる。

実際、2026-08-09 の時点で本番は**令和7年の値（2.4% / 8.7%）のまま**だった。令和8年は 2.8% / 9.1% に上がっており、7か月間ずれていた。

---

## 1. 何を見るか

国税庁「延滞税の割合」
https://www.nta.go.jp/taxes/nozei/entaizei/keisan/entai_wariai.htm

この表の**当年の行**を見る。2つの数値がある。

| 区分 | 意味 |
|---|---|
| 左の数値 | 納期限までの期間、および納期限の翌日から2か月を経過する日までの期間 |
| 右の数値 | 納期限の翌日から2か月を経過する日の翌日以後 |

### 実績

| 期間 | 2か月まで | 2か月経過後 |
|---|---|---|
| 令和4〜7年（2022〜2025） | 2.4% | 8.7% |
| **令和8年（2026）** | **2.8%** | **9.1%** |

### なぜ変わるか

延滞税特例基準割合（前々年9月〜前年8月の銀行の新規短期貸出約定平均金利の平均に年1%を加えたもの）に連動する。**前年11月30日までに財務大臣が告示**されるため、**1月時点で当年の値は確定している。**

---

## 2. どこを直すか（2026-08-09 時点で12か所）

### A. 特集 `/leaving-japan`（リポジトリ・4ロケール）

`src/app/(realestate)/leaving-japan/page.tsx` の各ロケール定数の `faqs` 内、
「税金を払わずに出国したら、どうなりますか？」の回答。

| ロケール | 現在の文言 |
|---|---|
| ja | 延滞税（令和8年は年2.8%、納期限の翌日から2か月を経過した後は年9.1%。年により変動） |
| en | late-payment interest of 2.8% per year, rising to 9.1% after two months from the due date (Reiwa 8 / 2026 rates, revised annually) |
| zh-tw | 延滯稅（2026年度為年2.8%，超過繳納期限次日起2個月後為年9.1%，逐年調整） |
| zh | 延滞税（2026年度为年2.8%，超过缴纳期限次日起2个月后为年9.1%，逐年调整） |

**探し方**：`grep -rn "2\.8%\|9\.1%" src/`

### B. コラム C4「出国後の未納は、いつまで追いかけてくるのか」（DB・4ロケール）

slug: `shukkoku-go-minou-kasanzei-zairyu-shinsa`

正典は DB だが、投入元の
`src/lib/data/leaving-japan-columns-seed.ts` にも同じ値が入っている。
**seed を直してから `/admin/columns/seed-leaving-japan` を再実行する**のが確実
（既存 slug は既存の status を引き継ぐので、公開状態は変わらない）。

各ロケールの `excerpt` と `content` の**両方**に数値がある（4ロケール × 2 = 8か所）。
本文には表もあり、そこに令和7年と令和8年の2行が並んでいる。**この表は行を足す**。

```
| 期間 | 納期限の翌日から2か月を経過する日まで | それ以後 |
| 令和7年（2025年） | 年 2.4% | 年 8.7% |
| 令和8年（2026年） | 年 2.8% | 年 9.1% |   ← 当年の行を足す
```

---

## 3. 手順

1. 国税庁のページで当年の値を確認する
2. 前年と同じなら、**何もしない**（年号の表記だけ更新するか判断する）
3. 変わっていれば、上記12か所を直す
4. `npx tsc --noEmit` を通す
5. PR を出す。**マージは浦松**
6. マージ後、`/admin/columns/seed-leaving-japan` を再実行する（Bの反映）
7. 本番4ロケールで数値を確認する

```bash
for L in "" en/ zh-tw/ zh/; do
  curl -s "https://luck428.com/${L}leaving-japan" | grep -o '2\.8\|9\.1' | head -2
done
```

## 4. あわせて見直す数値

延滞税以外にも、年次・改正で動く数値がある。同じタイミングで確認する。

| 項目 | 現在の値 | 出典 | 備考 |
|---|---|---|---|
| 無申告加算税 | 5% / 10・15・25% / 15・20・30%、繰り返し+10% | 国税庁 No.2024 | 令和5年分以降 |
| 重加算税 | 無申告に代え40%、過少申告に代え35%、繰り返し+10% | 国税通則法68条 | 4項は令和6年1月1日施行 |
| 源泉徴収（譲渡） | 10.21% | 所法161①五・212① | **2027年1月から内訳が変わる**（下記） |
| 源泉徴収（賃貸） | 20.42% | 所法161①七・212① | 同上 |
| 概算取得費 | 売った金額の5% | 措法31の4 | |
| 住所等変更登記の経過措置 | 令和10年3月31日 | 不登法76の5 | 施行前の変更の期限 |

### 2027年1月の注意

令和8年度税制改正により、**2027年（令和9年）1月1日以後に生ずる所得**から
防衛特別所得税（所得税額の1%）が創設され、復興特別所得税は 2.1% → 1.1% に
引き下げられる。付加される税の合計は 2.1% のままなので、**10.21% / 20.42% の
合計税率そのものは変わらない**が、**内訳の呼び方が変わる**。

`/kaigai-owner` には既にこの注記がある。**2026年12月〜2027年1月に、
他ページの記述も内訳表記を見直すこと。**
