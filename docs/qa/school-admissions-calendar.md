# 文京区の新入学説明会：掲載・更新の手順

対象はトップ、学区ページ、既存URL `/gakku/calendar` および4言語版。小学校の一般行事のカレンダーではない。

- 区または当該校の公式案内で、入学年度・学校名・新入学説明会であること・開催日・開始時刻・対象者を確認する。一般の来校者や学区を検討しているだけの人に参加可能とは案内しない。2027年4月入学分の対象は入学予定児の保護者のみ。
- 公式一覧と日程PDFを照合する。受付時刻が別に記載されている学校では、開始時刻と取り違えない。予約不要・全員参加可など、案内にない条件は追加しない。
- 学校別の新しい訂正・中止案内を優先する。年度・日時・対象のいずれかが未確認または出典が矛盾した予定は、確認待ちの注意書きを付けて掲載するのではなく、掲載しない。
- 授業公開・見学会・学校祭・発表会・展覧会などは、予定が判明してもこの公開データに追加しない。過去の修正履歴の参照はGit履歴を使う。顧客画面や配信されるブラウザ用コードに補助の旧日程表を含めない。
- 掲載データ／出典・確認日：`src/lib/school-events.ts`。新年度は既存の20校や日付から推定せず、年度ごとに公式確認をやり直す。開始時刻に達した説明会は「これから」の対象外。新しく確認できた予定がなければ空の案内のままとする。
- 更新時はデータ・SSR・クライアント時計のテストを実行し、4言語のトップ、学区一覧、学校別リンク、`/gakku/calendar` の実表示を確認する。現時点で外部からの自動取込・予約受付はない。

令和9年度の出典：[文京区の新入学説明会案内](https://www.city.bunkyo.lg.jp/b048/p007702.html)、[学校別日程PDF](https://www.city.bunkyo.lg.jp/documents/13446/reiwa9nennsetumeikai.pdf)。
