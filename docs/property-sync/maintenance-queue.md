# 四葉サイト正本からの入替確認

管理画面 `/admin/bukken` の「掲載の再確認」は、既存の共通物件DBに登録済みの公開中物件を、次の順序で優先表示する。募集状況の確認期限、次回更新予定日（日本時間の日付当日から）、情報更新から7日超。同じ物件に複数の理由があっても一覧では1件であり、同じ優先度では古い期限から確認する。これは閲覧専用の選別であり、期限到来を申込・成約・募集終了とみなさない。

1. 正本を起点に同じ号室・募集回を識別する。日付更新・募集終了判定までの間、別媒体の状態を四葉サイトの状態と混同しない。
2. 元情報から最新の募集中／申込あり／終了と公開許可を確認。確認できなかった物件や公開内容に矛盾がある物件は、更新・新規掲載扱いにしない。
3. 賃貸の「取込・掲載確認」で確認のみを先に行う。既存物件は再確認、新規は同一住戸チェック、終了は確認情報付きの公開停止フローに振り分ける。ATBBの情報は媒体別に記録・照合し、ATBB掲載成功のみで両媒体の完了と扱わない。
4. 変更後は、管理画面の物件IDと状態を読み戻し、四葉サイトの詳細、関連一覧・学区・サイトマップを確認する。ATBBも別途読み戻す。保存/反映の結果が不明なら再送前に確認する。

本変更に同期ジョブ・本番データ更新・権限変更・ATBB接続・広告条件緩和は含まれない。公開中の販促期限（申込締切等）の文言は、次回の再確認時に元情報と本文を照合する。本文内の日付を抽出して自動でキャンペーン終了や募集終了と判定しない。
