# 効果測定の率計算（ローカル入力契約）

`measurement-ratio.ts` はM05の合成検証用。全結果は`executable:false`、`decisionEligible:false`。掲載入替・配賦・改善判断や実計測への接続は行わない。

## 計算条件

1. 固定されたpair版/hashに、同じsource/媒体公開先/物件/募集回/市場/端末、分子分母の指標定義版/hash、単位、母集団・計上期間・意味の根拠参照を結び付ける。確認済みで有効期間内の場合のみ次へ進む。
2. threshold版/hashはpair参照を含む。最低分母と最低観察期間は設定値であり、実業務値の既定はない。null、未確認、期限切れを保留する。期間の基準は経過ミリ秒のみ対応し、暦日数を24時間倍へ置換しない。
3. `complete`や既計算totalの自己申告は受け付けず、両側の観測契約入力を区間集計関数で再計算。全期間が確認済みで、timezoneも一致する場合のみ計算。欠測を小計で補完せず、unknown端末やCRM由来の問い合わせをPC/スマホへ推測配賦しない。
4. 分母0は計算不可。分子0は分母正・その他条件充足時に0。部分集合率は同じ単位と分子≦分母を要求し、超過を100%へ丸めない。一般のイベント比率は1超を許すが百分率を出さない。
5. bucket別割合の平均ではなく、全期間分子合計÷分母合計。整数文字列の正確分数を保存し、IEEE754の近似比率/百分率を別欄にする。表示丸めは行わない。両summary hash、pair/threshold版、scope、期間、検査時刻を結果へ固定。

## 未実装・未検証

根拠参照の存在は真正性や個々の受付・計測イベントの対応を証明しない。実データのattribution、異なるsource間の承認済み対応表、未観測の二重計上、最新版の信頼できる選択、実媒体ごとの定義、最低分母/観察期間の業務決定は別工程。この関数は単一の明示入力版だけを照合し、履歴から最新の承認版を選んだとは主張しない。

設定が成立して算出できても説明用の比率に留め、少数結果による自動入替・停止や顧客への公開に使用しない。M05の部分的ローカル証跡であり全受入合格ではない。
