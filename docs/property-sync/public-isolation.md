# 物件入替：公開境界の修正（2026-10-24）

基準は main `62c26de`。この変更は公開データの隔離と保存前検査に限定する。DB migration、媒体操作、ルールの有効化、スケジュール追加を含まない。

## 修正した境界

`toPublicProperty` はルートだけでなく、種別ごとの概要、交通、画像のURL・説明・種別、翻訳、翻訳の概要表を許可項目から新しいオブジェクトへ写す。未知のキーは公開しない。文字列等を想定した項目にオブジェクトが入っていた場合は、データを含めないエラーで停止する。入力の検証・誤データの修復を代替するものではない。

概要の許可項目は6種別の型に対して網羅性を型検査する。翻訳の概要キーは既存の概要表キーを使い、`landArea` 等とDBキーを混同しない。公開後の社内データ変更で公開オブジェクトが変わる参照共有も解消する。

既存の `publicContentHash` はこの公開変換を使い続ける。内部の追加情報では変化せず、公開値の変更は検出する。このhashはIndexNow用であり、更新日時・状態・賃貸確認期限を除外する既存仕様のまま。書込み用CASや完全な媒体反映hashの代わりにしてはいけない。

通常管理APIの `bannedTermsError` は概要・交通・所在地・画像説明・翻訳も検査する。PATCHは入力差分だけでなく既存値と合成した結果を検査し、DB更新・通知より前に停止する。下書き保存とinternalの保持は継続する。借主向け仲介手数料の表示は維持する。

## 検証範囲

- 6物件種別の既存値の保持、すべてのネストへ混入させた非公開canaryの除外。
- 返却後の元データ変更、公開hash、概要表、翻訳、JSON-LD。
- 文字列欄へのオブジェクト混入は詳細データを出さずに拒否。
- POSTの画像説明、PATCHの概要のみ変更、下書きから公開へのstatusのみ変更をDB・通知モックで検証。
- 画像のURLは広告本文の語句検査から除外。画像説明は検査する。

画像ピクセル、スキャン図面の帯、手書き、OCR結果の正しさはこの変更では検証できない。公開前の画像確認根拠とasset hashを結び付ける工程が別途必要。許可された文字列そのものに未知の機密表現がある場合も、構造のallowlistだけでは判定できない。既存公開データ全件の安全性を証明するものではない。

## 次の最小単位

1. B01のソースと評価セットを復旧し、現行mainに差分適用する。過去の実装報告と現存コードを区別する。
2. B02の募集episode・媒体掲載・観測を既存SupabaseとIDで関連付ける。観測結果を `properties.internal` へ書いて `updatedAt` のCASを不用意に変えない。先にローカル入力契約とテストを作る。
3. ルール履歴は適用scope（全体／個別顧客、居住用賃貸／売買／事業用）、版、有効期間、承認根拠を持たせる。現在有効な全体ルールが未確定なら計画を保留し、過去の金額や契約種別を既定値へ戻さない。
4. 差分計画に物件ID・episode・媒体・ルール版・変更前の完全hash・期待更新版を固定する。実行器は再読取りし、古いジョブ・手動変更・許諾失効・募集終了を拒否する。IndexNow hashは流用しない。
5. 本番writerの前に、既存CLIの未定義 `recordExpiredPropertyPublications` 呼出し、通知tableの実schemaとmigrationのRLS/権限を個別に解消する。全体tsconfigはscriptsを除外しているため、通常のtsc成功だけではCLIを検証したことにならない。

## 後続の循環と承認境界

許可済み入力 → 同一部屋照合・差分計画 → 事前検査 → 承認された媒体への反映 → PC/スマホ別の公開照合 → 受任・反響・採算の評価 → 回帰試験を伴う改善案、の順に進める。反映結果不明は再読取りまで保留し、再送・重複登録をしない。

自社サイトとアットホームの状態を別々に管理する。アットホームの「トップ」は同じ部屋を掲載する会社の中で四葉が先頭であることを指し、物件検索順位や公開成功と別の指標にする。学区は住所境界・年度・出典を保持し、記事との関連付けは募集終了時にも更新する。

媒体の公式API／正規エクスポートが利用契約上確認できるまではモック／入力口に限定する。REINSの無人取得、CAPTCHA・再認証越えを作らない。夜間処理は許可済み入力の検証・差分提案・テストまで。自己改善で権限、適格条件、評価基準を自動緩和しない。

本番掲載入替・削除・merge・deploy・DB migration・権限変更・外部連絡は今回未実施。PR公開前に、この単位の差分と検証結果を確認する。
