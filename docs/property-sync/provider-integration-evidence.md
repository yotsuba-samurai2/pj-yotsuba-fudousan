## 現在の実装への適用

- 契約プランや検索回数上限は、自動収集・無人巡回・大量取得の許諾とは扱わない。
- 既存入力受け口・注入reader・mockを維持する。未確認のURL、認証方式、CSV列、削除指示を推測して実adapterを作らない。
- 容量は既存`capacityConfigSchema`の区分・pool・確認状態・適用期間と、別取得のsnapshotを使用する。契約記載の公開枠、管理枠、残枠を混ぜない。共有poolや占有不明なら既存ゲートで停止する。
- 契約資料の具体値は非公開作業証跡だけに記録する。コードや公開出力へ直接書かない。確認期限や有効時刻も推定しない。
- 取得できることと公開できることは別。募集状況/広告承諾/素材利用権/有効期限と、最終payload・画像確認は別途必要。
- REINSは本人認証後の個別指示検索のみ。連携商品の案内があっても無人取得へ変更しない。

## 確認を依頼する際の最小項目（未送信）

担当窓口には、使用中契約に適用できる正規の自作システム連携方法と仕様書、対象データ/画像の取得・再公開条件、区分ごとの枠計数と共有/合算関係、更新受付と不明応答の確定照合方法を一括で確認する。既知の顧客層やローカルDB先を再質問しない。実際の依頼送信や契約変更は行っていない。
