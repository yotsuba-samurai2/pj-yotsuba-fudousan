# 学区根拠の厳密な照合（ローカル契約）

`school-evidence.ts` はT16のための合成データ検証。既存の `school-district.ts` / 賃貸・売買の公開学区判定は変更しない。既存parserの空文字→全域や候補一校の確定判定を、新契約の入力正規化として流用しない。

## 必要な入力

- 対象物件/募集回/source版、自治体ID、小学校/中学校、対象年度、適用日。年度を更新日や現在年から推測しない。
- 確認済み正規化住所：住居表示/地番/不明を区別し、今回は住居表示のみ。町ID・丁目・番・号、正規化方式版・元住所hash・確認参照をsource版に結び付ける。部屋番号・raw住所は受け付けず、地番を住居表示に読み替えない。
- 範囲表：自治体/町丁目/学校種別/年度のcoverage、当該範囲全行の完全性確認、出典内容hash・公表日とそのtimezone・観測/確認時刻・公式自治体参照、適用開始日/終了日、表id/version/hash。適用期間は半開区間。
- 行ごとの学校IDと番/号の構造化selector。`all`/列挙/除外/有限範囲/未解釈を分け、空・逆転範囲・重複値・危険整数を拒否。範囲を巨大配列へ展開しない。

## 判定

対象住所と重なる可能性がある「一部」「例外」「旧住所」「未解釈範囲」が残れば保留。確定行だけを抽出して一校へ絞らない。有限範囲や列挙等で必要な番/号が欠ければ、候補一校でも保留する。公式入力が`all`と明示された粒度だけはその番号を不要とする。

二校に重なる場合・対象なし・不明年度・適用日外・不完全表も保留。matchedの返却は学校ID、参照行、表版/hash、対象/source版、住所全体のhashだけ。詳細住所を返さない。

## 未確認境界

入力の「公式」「確認済み」「完全性」は契約上の申告。原本の取得許可/真正性、住所正規化の妥当性、部屋番号を号へ誤入力していないこと、全行収録、最新表の選択、信頼できるexpected参照の保管はこの関数だけでは証明できない。住所文字列の解析・地理推測・学校までの距離による代用・実表取得・実DB接続なし。

`matched`でも`executable:false`・`publicClaimAllowed:false`・`assignmentGuaranteed:false`を維持。指定校/入学可否や公開表示を確定したとは扱わない。文京区20学区および周辺自治体を実データで検証済みとは主張しない。

## unit44：公式表と既存静的データの再照合

2026-10-26 JSTに[文京区の小学校通学区域表](https://www.city.bunkyo.lg.jp/b048/p002107.html)を1回取得し、rowspanを展開し、学校名の読み・空白を整理したTSVを既存TSVと比較した（HTML原本同士のバイト比較ではない）。公式表の表示更新日は2026-01-09、326行・20校・12,986バイトで一致し、SHA-256は`7999dea050d90b9b9d16a7145466a9a16f6214160763742999b524b65627507b`。原文で省略された末尾備考セルのみ空欄として扱い、町丁目/番/号は推測補完していない。証跡と比較スクリプトは作業領域`evidence/unit44-school`に保存。

この照合は現在の公式掲載表との一致確認であり、2027年度等の入学時点の適用、個別住所の正規化、旧町名による分岐、周辺自治体の範囲を確認したものではない。区の更新日を年度/有効期限へ変換しない。公開中の学区データ・判定処理・物件・入学保証は変更していない。T16の全体受入は引き続き未完。
