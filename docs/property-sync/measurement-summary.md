# 効果測定の区間集計（ローカル入力契約）

`measurement-summary.ts` は合成入力を扱う純粋関数。DB・GA4・ATBB・ブラウザへの接続や公開画面への出力はしない。媒体実データの定義・取得許可を確認済みとは扱わない。

## 集計の境界

- source/media/一般向け・業者間・提携/市場/物件/募集回/端末が完全一致する入力のみ扱う。`all` と各端末、`unknown` とPC等を相互補完しない。
- 指標のid/version/hashを必須にし、一覧表示・詳細閲覧・PV・訪問・利用者・クリック・試行・受付保存・CRM受信を区別する。区間countと確認された加算性の組合せだけを合計する。ユニーク人数、残数、累計、平均は合算しない。
- 区間は `[start,end)`。合計は要求期間の全区間が欠けず重複せず、確定・根拠参照あり・scope確認済みの場合だけ返す。欠測理由と未取得区間を残し、欠測を0へ変換しない。部分取得の`knownTotal`は既知部分の小計であり、期間全体の推定ではない。
- 同一観測ID/内容の再送は一度だけ数える。ID再利用による内容変更、別IDで重なる区間は保留。訂正の最新版を推測して採用しない。
- 暫定・推定・標本・秘匿値、mock/不明な取得方法、区間終了前の観測は既知小計から除外する。実0もこれらの確認条件が必要。
- 暦日型は指定timezoneの午前0時から翌日午前0時を検査。夏時間の23/25時間を一律24時間へ補正しない。件数4,000・期間370日・安全整数は技術上限であり、業務の最低観察期間や最低分母ではない。

## 残る検証

定義確認・evidenceRefは入力契約であり、真正性をこの関数だけで証明しない。保存元の信頼、計測adapter、定義変更の移行、受付/CRMイベントの同一性、GA4送信内容、公開日数、掲載変更版、観測による自己閲覧、最小分母・観察期間、改善判断は未実装。返却値は常に`executable:false`、`decisionEligible:false`。

M01/M02/M07/RF23の部分的ローカル証跡を追加する。実媒体での受入合格を意味しない。
