## 修正を要する不整合

**150 / major：報酬の表の「時間や成果でなく労務」は報告本文と整合しない。** [1985年報告](https://www.mhlw.go.jp/content/001477330.pdf)の第2の1(2)、PDF4頁/印字3頁は、時間給を基礎とする計算など、一定時間の労務提供への対価という性格が使用従属性を補強すると説明している。日本語、英語の “not time or output”、繁体字・簡体字の時間を除外するセルを、時間給も判断材料になり得る限定表現へ揃える。これは単一要素による自動認定ではなく、他の要素との総合判断である。

推奨する日本語：**「時間給を基礎とする計算など、一定時間の労務提供への対価という性格（他の要素と総合判断）」**。4言語の対応文は親へ先行送信済み。

**150 / major：コマ給・支給額を一律に総労働時間で割る説明は限定が必要。** [対象賃金の公式説明](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/chingin/newpage_43898.html)は6分類の除外項目を示す。[公式換算説明](https://saiteichingin.mhlw.go.jp/point/page_point_check.html)は時間給、日給、月給、出来高等、併給で異なる式を示し、ケースC/Dは割増分の区分と固定・歩合部分の別々の換算を説明する。コマ給の分類を推測せず、対象/除外と分母を実際の契約・賃金規程に基づいて資格者へ確認する旨に、本文・手順2・FAQ4・翻訳を揃える。

推奨する日本語：**「最低賃金との比較では、割増賃金などの除外対象を除き、時間給・日給・月給・出来高払制や併給の別に応じて時間額へ換算します。コマ給の賃金形態、対象賃金と除外項目、授業外労働を含む記録と計算の分母は、実際の契約・賃金規程をもとに資格者へ確認します。単に支給総額を総労働時間で割ればよいとは扱いません。」** 4言語の対応文も親へ先行送信済み。

**149 / minor：規則の追加制限と短縮した42時間表示。** 規則12条の4第3項ただし書には、旧協定比較により280日より少ない上限となる場合がある。280日までなら常に適合するという読みを避け、旧協定比較を資格者・所管確認事項に含める。労基法36条4・5項の42/320は対象期間3か月超が条件なので、一部の短縮した表・FAQにもこの条件を維持すると明確になる。記事最初の表の条件自体は確認できた。

## 判決と固定残業代の確認範囲

[最高裁公式詳細ページ](https://www.courts.go.jp/hanrei/52572/detail2/index.html)で平成7(オ)2029、賃金請求事件、平成12年3月9日、最高裁第一小法廷、民集54巻3号801頁と確認した。そこからリンクされた [判決全文](https://www.courts.go.jp/assets/hanrei/hanrei-pdf-52572.pdf) の全3頁を読み、原本の抽出文字を CP932 補正して本文とも照合した。指揮命令下かどうかの客観的判断と、事業所内で義務づけられた準備等に必要な時間という一般枠組みを確認した。参照条文は昭和62年改正前の32条で、造船所の個別事実である。塾の在宅準備、採点、自由な自己学習をこの判決だけで一律認定しない。

先に取得した18843版は同様の一般理由を含むが、匿名化と改頁が異なる2頁版である。事件の同一性を推測で認定せず、公式詳細ページが直接結びつく52572版を主根拠とした。

[固定残業代リーフレット](https://www.mhlw.go.jp/file/06-Seisakujouhou-11600000-Shokugyouanteikyoku/0000184068.pdf)では募集・求人の基本給、時間数/金額等、超過した時間外・休日・深夜の追加支払の表示を確認した。2頁の判例は抜粋であり各事件の裁判全文を取得した意味ではない。表示が揃えば個別契約が必ず有効、という判断には用いない。
