# 独立レビュー：225　過半数代表者（社労士）
対象原稿は final 配下の4言語の本文・要旨・表・見出し・FAQ・タイトル。ファイル全体を読み、実際のシードが生成した final/payload-225.json の本文・タイトルを各原稿と照合した。記事本文は編集していない。独立レビューであり、資格者本人による個別案件の判断・署名又は本番公開処理ではない。

## 判定
- 公開を妨げる重大な内容の誤り：4言語ともなし（下記ハッシュに限る）。
- 当初版で見つけた修正必須事項：36協定と就業規則を一括で無効と読める記述、選出・届出と法定時間外/休日労働ができる時点、署名押印と行政への届出の区別、36協定には使えない全員管理監督者時の例外、リンク切れの計画年休ページ。この版では解消した。法令上の労使手続を一般論として案内し、資格者が個別判断する旨・特定社労士ADRの範囲を明示。
- 法的な区別を4言語で確認した箇所：事業場単位の過半数組合の有無／選出目的の明示／労働者側の意思と事業場の全労働者の過半数の支持／会社指名・親睦会代表の自動充当は不可／職名単独で管理監督者扱いしない／パート等も母数に含める／選出の経過の記録と周知／36協定は適正選出・締結・事前届出・有効期間開始を区別し過去には遡らない／就業規則の意見聴取は同意でなく、手続違反のみで個々の条項が当然に無効にはならない／計画年休の協定自体は届出不要。各言語で読者が日本の制度の説明であると分かる。
- 本文の内部リンクは同じ言語の10本ずつで、旧版で404を確認した計画年休記事へのリンクは4言語すべてから除去された。新リンクは厚生労働省サイトの該当手続本文まで独立に確認。全40内部URLのHTTP実査について、独立環境では一部の接続がタイムアウトし、個々の到達確認に加え、別環境（親側Mac）から全40件をGETしてすべて200かつリダイレクトなしと確認した結果を突合。各言語の独立環境で取得できた画面のH1と言語も照合した。

## 軽微な指摘／推奨（上記ハッシュ時、公開停止事項ではない）
1. JA 原稿104行：ADRの発行主体は厚生労働省でなく**全国社会保険労務士会連合会**。署名・計画年休の後で独立した発行主体として記載。JA 3行末の外部代理の説明も、1・67・70行で明示したADR範囲と同じ文言にそろえると読みやすい。
2. EN 32・39・99・112行：第41条**第2号**の正確な英訳として `Article 41, item (ii)` を使用する。現在の `Article 41(2)` は英語の段落番号にも読めるが、条文の内容自体は正しい。
3. 全言語の電子選出のFAQ（JA 97～98行、EN 104～105行）：投票に参加できるだけでなく「事業場の全労働者の過半数の支持を確認し、無回答を賛成に数えない」と1文を加えると、FAQ単独の引用でも分母を取り違えない。本文には既に過半数支持の要件あり。管理職のFAQ（JA 91～92行）も、就業規則に限らない規則6条の2第2項の限定例外があるので、冒頭を「36協定では」とするとFAQだけでも例外の読み落としを防げる。
