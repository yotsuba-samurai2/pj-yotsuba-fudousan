## 3. H2「こんな物件を探しています」

| 種別 | 向く理由（一般論） | 契約前に確認すること |
|---|---|---|
| 戸建て（部屋数の多い住宅） | 居間・食堂・浴室など共用部を確保しやすい | 用途変更の要否（延べ面積）、居室面積、消防設備、貸主承諾の範囲 |
| 空き家・相続した実家 | 住宅地の立地が共同生活援助の住まいと親和性がある | 登記名義、境界、残置物、耐震・劣化の状況 |
| アパート・一棟 | 居室の独立性を保ちやすい。本体住居やサテライト型の候補になる | 各戸の居室面積、消防設備、既存入居者との関係 |
| 事業利用について相談できる物件 | 用途を住宅に限らない前提で契約できる | 転貸・用途の承諾を契約書に残す |

条件に合わないように見えても、まずご相談ください。表の「確認すること」は、当社が契約前に一つずつ整理します。

## 4. H2「グループホームに貸すと、一般の賃貸と何が違いますか」

| | 一般の賃貸（住居） | グループホームに貸す場合 |
|---|---|---|
| 借主 | 入居する個人 | 運営する事業者（法人が多い）。住むのは障害のある方で、世話人などの職員が出入りする |
| 使い方 | 借主とその家族の住まい | 共同生活援助の住まいとして運営する。用途の承諾を契約で明示する |
| 改修と原状回復 | 原則そのまま使う。原状回復は通常損耗を除く | 手すり・設備など事業者側の改修が入ることがある。範囲と復旧を契約で定める |
| 近隣 | 特段の説明はないことが多い | 事業者が説明を行うのが一般的（自治体の運用による）。開設後は地域の関係者を含む「地域連携推進会議」をおおむね年1回開く仕組みがある |
| 賃料の決まり方 | 周辺の相場 | 事業者の事業計画と物件の条件。当社は相場と事業者目線の両方を整理する |
| 契約期間の考え方 | 更新型の契約が多い | 事業者は継続して運営する前提で考えることが多い。期間・更新・中途解約を契約で定める |

金額や期間の目安は、物件と事業者で変わるためここには書きません。貸す仕組み、大家さんが不安に思う点、契約書で決めておくことの詳しい解説は、貸し手向けのコラムにまとめています。

## 5. H2「四葉が行うこと（相談の流れ）」

1. **物件情報の送信**：下のフォーム、LINE、電話のいずれかで。図面だけ、住所と種別だけでも構いません
2. **概要確認**：所在地・種別・面積・利用状況から、グループホームとしての利用可能性の論点を洗い出します
3. **現地確認**（必要に応じて）：建物の状態、共用部、避難経路、周辺環境を見ます
4. **利用可能性の整理**：用途変更の要否、消防設備、貸主承諾の範囲、転貸の扱いを論点として整理します。可否の判断は建築士・特定行政庁・消防署が行い、その確認の段取り（[契約前の事前協議](/legal/column/group-home-keiyakumae-jizen-kyogi)）をご案内します
5. **借主候補の事業者との調整**：事業者の計画と物件条件を突き合わせ、条件・改修・原状回復・近隣説明の考え方を整理します
6. **条件が合えば賃貸借契約**：契約書に用途の承諾、改修と原状回復の範囲、転貸の扱い、期間・更新・中途解約を落とし込みます

**当社の立場**：貸主様側の媒介です。取引態様は媒介であることを明示します（宅地建物取引業法第34条）。報酬は賃貸借契約が成立したときのみで、同法第46条に基づく告示の範囲内です。借主側（事業者）の媒介を当社が兼ねる場合は、その旨を事前にお伝えします。

（指示書 5-1 の「第34条の2」は、e-Gov で確認した現行条文では売買・交換の媒介契約書面の規定で貸借の媒介を含まないため、本ページでは引用しない＝`01_konkyo.md`）

## 8. FAQ（10 問・FAQPage と同一配列）

1. **グループホームに貸す場合、通常の賃貸と何が違いますか。**
   借主が個人ではなく事業者（法人）で、建物を障害のある方の住まいとして運営する点が違います。改修と原状回復の範囲、近隣への説明、契約期間の考え方を、契約前に取り決めておくことが要点です。
   → [貸す仕組みと契約書で決める5点](/column/kodate-akiya-group-home-ni-kasu)
2. **どんな物件が向いていますか。**
   居室を複数確保でき、居間・食堂・浴室などの共用部をとれる戸建てや、アパート一棟が候補になります。相続した実家や長く空室の物件も対象です。向き不向きは物件ごとに現地で確認します。
   → [戸建て型・アパート型・サテライト型の違い](/legal/column/group-home-kodate-apart-satellite-chigai)
3. **古い戸建てでも相談できますか。**
   相談できます。築年数だけで判断せず、耐震・劣化の状況、検査済証の有無、用途変更の要否などを整理したうえで、事業者側の計画と合うかを検討します。検査済証が無い建物の考え方は下の記事にまとめています。
   → [検査済証が無い建物を福祉用途に使うには](/column/kensazumisho-nashi-bukken-fukushi-youto-henko)
4. **消防設備は必要ですか。費用は誰が負担しますか。**
   必要な設備は物件の規模・構造と入居者像で変わり、要否は管轄の消防署が判断します。費用の負担は契約で決めます。一般に借主（事業者）の負担とする例が多いものの、契約によります。当社は要否の判断をしません。
   → [消防設備の要否（スプリンクラー・(6)項ロ／ハ）](/legal/column/group-home-shobo-setsubi-sprinkler)
5. **用途変更の手続は必要ですか。**
   建物の延べ面積や現在の用途によって、建築基準法の用途変更の確認申請が要る場合と要らない場合があります。要否は建築士と特定行政庁（文京区など）が判断します。当社は論点の整理までを行います。
   → [建築基準法と用途変更の要否](/legal/column/group-home-kenchikukijunho-youto-henko)
6. **近隣への説明はどうなりますか。**
   開設にあたって近隣の同意は法令上の指定要件ではありませんが、事業者が近隣へ説明を行うのが一般的で、自治体の運用によります。説明は事業者が行うものとして、その手順と貸主の関わり方を契約前に整理します。
   → [近隣説明の進め方](/legal/column/group-home-kinrin-setsumei)
7. **原状回復や契約条件は、どう考えればよいですか。**
   手すりや設備の設置など事業者が行う改修の範囲と、退去時に元に戻す範囲を、契約書に具体的に書いておくことが基本です。用途（共同生活援助）の承諾、転貸の可否、中途解約の条件もあわせて取り決めます。
   → [契約書で決めておくこと](/column/kodate-akiya-group-home-ni-kasu)
8. **家賃はどう決まりますか。**
   事業者の事業計画と物件の条件（広さ・部屋数・改修の要否・立地）で決まります。当社は近隣の賃料事例と事業者側の目線の両方を整理してお示しし、貸主様が判断できる材料をそろえます。将来の賃料や収益の約束はしません。
   → [家賃の考え方（貸し手向けコラム）](/column/kodate-akiya-group-home-ni-kasu)
9. **まだ貸すか決めていなくても相談できますか。**
   相談できます。貸すか売るか、そのまま持つかを含めて、選択肢と論点を整理するところから始められます。図面や募集図面だけでも、物件の概要を伺うところからお受けします。
   → [相続した空き家の管理・活用・売却](/souzoku/akiya)
10. **相談や物件の登録に費用はかかりますか。**
    相談・物件の登録は無料です。報酬は賃貸借契約が成立したときのみ、宅地建物取引業法第46条に基づく告示の範囲内でいただきます。契約に至らなければ費用は発生しません。
    → [不動産の料金](/ryokin)
