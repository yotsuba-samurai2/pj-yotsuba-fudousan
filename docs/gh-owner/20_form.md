# 専用フォーム（`#form`）の仕様（Step 3・第6章 6-1）

コンポーネント：`src/components/group-home/GhOwnerForm.tsx`（`'use client'`）。送信先は既存の `POST /api/contact`。

## 項目

| 項目 | 必須 | 形式 | 送信先の項目 |
|---|---|---|---|
| お名前 | 必須 | text | `name` |
| メールアドレス | メールか電話のどちらか必須 | email | `email` |
| 電話番号 | 同上 | tel | `phone` |
| 物件の所在地 | 必須 | text。プレースホルダ「区市町村と町名まで（番地は任意）。例：文京区小日向」 | `message`（整形） |
| 物件の種別 | 必須 | select：戸建て／アパート・一棟／マンションの一室／空き家／土地／その他 | `message`（整形）。GA には値のキーのみ |
| 間取り・部屋数 | 任意 | text。例：4LDK（居室4） | `message` |
| 延床面積（㎡） | 任意 | text | `message` |
| 現在の利用状況 | 任意 | select：空室・空き家／自己使用中／賃貸中（入居者あり）／その他 | `message` |
| 希望賃料 | 任意 | text。プレースホルダ「例：月額21万円（未定で構いません）」（2026-09-24 本番の実送信で「２１０」と単位なしで届いたため、単位付きの例を示す） | `message` |
| 図面・資料 | 任意 | checkbox「図面・写真があります（送信後に LINE またはメールでお送りください）」 | `message` |
| 備考 | 任意 | textarea | `message` |
| どちらで四葉グループをお知りになりましたか | 任意 | select（既存フォームと同じ `SOURCE_OPTIONS`） | `source` |

- `category` は固定で `gh-owner`、`business` は `realestate`。
- 個人情報の同意チェックは置かない（既存フォームに同意欄が無いため同じ形にする）。フォーム末尾に「送信いただいた情報は、お問い合わせへの回答・対応のために利用します」とプライバシーポリシーへのリンクを 1 行置く。
- フォーム内に「LINE で図面を送る」ボタン（`LineLink`・`/line`）を置く。

## バリデーション（クライアント）

| 条件 | メッセージ |
|---|---|
| お名前が空 | お名前を入力してください |
| メールと電話の両方が空 | メールアドレスまたは電話番号を入力してください |
| メールが入力されていて形式が不正 | 有効なメールアドレスを入力してください（サーバー側の zod と同文） |
| 所在地が空 | 物件の所在地を入力してください |
| 種別が未選択 | 物件の種別を選択してください |

サーバー側（`route.ts`）は `category === "gh-owner"` のときだけ「電話があればメール任意」を許す。両方空なら 400（`email`：メールアドレスまたは電話番号を入力してください）。メールが無い送信は自動返信を送らず、通知メールの返信先も省く。

## 送信本文（`message`）の整形

`buildGhOwnerMessage()`（純関数・`src/lib/shared/gh-owner-intake.ts`）。任意項目が空のときは「未入力」と書く（通知メールで項目の欠落と入力漏れを区別できる）。

期待出力（種別＝戸建て・利用状況＝空室・空き家・図面あり・備考あり）：

```
【グループホーム向け物件のご相談】
所在地：文京区小日向
種別：戸建て
間取り・部屋数：4LDK（居室4）
延床面積：110㎡
利用状況：空室・空き家
希望賃料：未定
図面・資料：あり（LINE またはメールで送付）
備考：相続した実家です。
```

期待出力（任意項目がすべて空・図面なし）：

```
【グループホーム向け物件のご相談】
所在地：文京区小日向
種別：戸建て
間取り・部屋数：未入力
延床面積：未入力
利用状況：未入力
希望賃料：未入力
図面・資料：なし
備考：未入力
```

## 送信後

- 成功：`gaEvent("contact_submit", …)` を送ってから `router.push(addLocalePrefix("/thanks", locale))`（既存フォームと同じ）。`/thanks` は種別を受けられない（`?from=` は Phase 2）。
- 失敗：既存フォームと同じく画面上にエラーを表示し、`contact_submit_error`（kind＝validation／server／network）を送る。

## スパム対策

既存の送信経路と同じ（＝現状は honeypot・Turnstile・レート制限のいずれも無い）。本 PR で新しい仕組みは足さない。**未検証事項として PR に記載**（公開フォームが 1 つ増えるため、Phase 2 でレート制限の要否を検討）。
