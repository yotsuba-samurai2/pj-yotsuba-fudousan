**结论（先讲重点）**：以技术・人文知识・国际业务（技人国）聘用中国・台湾人才时，首先要确认的是「本人的学历・实务经验与所交付的职务是否相关」。此处一偏，在留资格的该当性就会崩掉。聘用后的劳务，2024年（令和6年）4月1日起应明示的劳动条件增加，社会保险・雇用保险不问国籍，满足要件即加入。而加班与工资的纠纷，会在在留期间更新时，作为劳务管理的妥适性而反映。

在留资格的认定・变更・更新的申请取次属行政书士的业务，社会保险劳务士不能办理在留申请的取次。与本事务所各自独立的事业体，请另行签约。本事务所承接的是劳务・社会保险的设计，个别判断由资格者在面谈后进行。

## 以技人国聘用中国・台湾人才时，首先要确认什么？

技术・人文知识・国际业务，是规定于出入国管理及难民认定法别表第一之二的就劳在留资格，统合理学・工学等技术领域、法律・经济・社会等人文知识领域，以及口译・笔译・语言指导・海外交易业务等国际业务。是否核准，首先取决于本人的学历或实务经验，与所交付职务的关联性。

| 要确认的事 | 劳务侧的看点 |
|---|---|
| 职务内容 | 是否为专门・技术性业务而非单纯作业。在雇用契约书具体写明职务内容 |
| 学历・实务经验 | 技术・人文领域需相关学历或一定年数实务经验；国际业务原则3年以上实务经验（语言指导等有例外） |
| 与职务的关联性 | 大学等的主修或实务经验，与所交付职务是否连结 |
| 报酬 | 是否为日本人从事同工作时的同等额以上 |

技人国「是否该当」的最终判断由出入国在留管理厅作出，认定・变更的申请属行政书士的业务。本事务所设计其前提的职务内容・报酬・劳动条件是否符合劳动关系法令。聘用1名外国人时所动的手续全貌，整理于[聘用1名外国人时，需要几个窗口](/zh/labor/column/gaikokujin-koyo-madoguchi-wakekata)；偏向高度专门职・IT技术者的论点，整理于[聘用高度专门职（外国人IT・技术者）时的劳务与社会保险](/zh/labor/column/koudo-senmonshoku-gaikokujin-it-koyo-roumu)。

## 劳动条件的明示，母语对应需到什么程度？

劳动条件的明示是劳动基准法第15条第1项的义务，应明示的事项规定于同法施行规则第5条。2024年（令和6年）4月1日起明示事项增加。以外语（母语）明示本身虽非法律上的义务，但以本人能理解的语言呈示较为安全，厚生劳动省也公开了多语言的示范劳动条件通知书。

| 2024年4月增加的明示事项 | 内容 |
|---|---|
| 就业场所・业务的变更范围 | 明示将来因配置转换等可能变动的就业场所・业务范围 |
| 更新上限 | 有期契约若有更新次数・通算契约期间的上限，其内容 |
| 无期转换申请机会 | 于无期转换申请权发生的每次更新时点，该旨 |
| 无期转换后的劳动条件 | 无期转换后的劳动条件 |

技人国常以有期契约聘用，此时更新上限与无期转换的明示直接相关。母语明示虽非义务，但若以纯日文的通知书未能传达内容，会连动到后续纠纷与在留更新时的说明负担。对外国人的劳动条件明示、含母语对应的论点，整理于[对外国人的劳动条件明示，母语对应需到什么程度](/zh/labor/column/gaikokujin-roudou-joken-meiji-bogoko-2024)；2024年改正的明示事项本身，整理于[劳动条件明示的2024年改正——变更范围是什么](/zh/labor/column/roudou-joken-meiji-2024-henko-han-i)。

## 社会保险・雇用保险，从何时开始加入？

社会保险（健康保险・厚生年金保险）与雇用保险，不问国籍与在留资格，适用规则与日本人相同。在适用事业所常时使用者，满足要件即自入社时点成为被保险人。不能以「因为是外国人而延后」处理。

| 保险 | 加入的想法 |
|---|---|
| 健康保险・厚生年金保险 | 在适用事业所常时使用者，不问国籍即被保险人。兼职等以4分之3基准，特定适用事业所则为每周20小时以上・月额8.8万日圆以上・预计使用超过2个月・非学生的要件 |
| 雇用保险 | 每周所定劳动时间20小时以上・预计使用31日以上即被保险人（2028年10月起拟扩大至每周10小时以上） |
| 劳灾保险 | 只要是劳工，不问国籍・在留资格皆适用 |
| 外国人雇用状况的申报 | 每次雇入・离职向公共职业安定所申报（劳动施策总合推进法第28条第1项） |

与母国制度的双重加入，只能与缔结社会保障协定的相手国，以适用证明书调整。与中国有协定，但无年金加入期间通算的规定；与台湾则无协定本身。此差别整理于[中国驻在的社会保障协定与双重加入](/zh/labor/column/chugoku-chuzai-shakaihosho-kyotei-nijukanyu)、[从台湾聘用・以出向受入时的社会保险](/zh/labor/column/taiwan-koyo-shukko-shakaihoken-kyotei-nashi)。所得税与日中・日台间的租税取扱，属税理士的领域。

## 影响在留更新的劳务纠纷，如何避免？

在留期间更新时，审查也会看雇用的继续性与公司劳务管理的妥适性。加班费未付、契约与实态不符，可能在更新场面不利。把劳务整备好，就直接降低更新的风险。

| 易发生的事 | 劳务侧的对策 |
|---|---|
| 加班费未付 | 客观掌握劳动时间，正确计算时间外・深夜・休日的加给（劳动基准法第37条） |
| 契约书与实态的落差 | 使明示的职务内容・就业场所，与实际业务一致 |
| 在留期限与契约期间不一致 | 有期契约的期间・更新上限，与在留期限一并设计 |
| 职务内容的变更 | 影响技人国该当性的配置转换，事前确认在留资格的观点 |

在留期限与雇用契约期间各自独立运行。此设计整理于[在留期限与雇用契约期间，哪个先到期](/zh/labor/column/zairyu-kigen-koyo-keiyaku-kikan)。惟更新是否核准的见込，以及个别雇止的可否等判断，本文不下结论。核准的判断由出入国在留管理厅作出，具纠纷性的案件由律师处理。

## 从聘用到在留更新，谁负责什么？

以技人国聘用中国・台湾人才时，负责的资格分工如下。

| 论点 | 负责 |
|---|---|
| 雇用契约・劳动条件明示、就业规则・薪资规程、社会・劳动保险手续、劳动时间・工资管理 | 社会保险劳务士（本事务所） |
| 在留资格的认定・变更・更新的申请取次、职务与学历关联的整理 | 行政书士（申请取次） |
| 所得税・日中／日台间的租税取扱 | 税理士 |
| 对不许可的不服申立等具纠纷性的对应 | 律师 |
| 住居（社宅・租赁）的确保 | 不动产 |

社会保险劳务士不能办理在留申请的取次，故在留资格的申请必定交由行政书士。四葉行政書士事務所与本事务所各自独立的事业体，必要时我们会请客户另行签约，本事务所不收取介绍费。住居的确保由四葉不動産株式会社承接，这也是另一事业体。

## 四葉社会保険労務士事務所能做什么？

本事务所承接的是聘用技人国人才时的劳务・社会保险设计。

- 劳动条件明示（含2024改正的变更范围・更新上限・无期转换）与雇用契约书的作成
- 就业规则・薪资规程的整备
- 社会保险・雇用保险的加入判定与手续、外国人雇用状况的申报
- 劳动时间・时间外・加给工资管理的设计
- 为不影响在留更新的劳务管理点检

以下不由本事务所处理。

- 在留资格的认定・变更・更新的申请取次、职务与学历关联的整理 → 由四葉行政書士事務所作为另一事业体承接
- 住居（社宅・租赁）的确保 → 由四葉不動産株式会社作为另一事业体承接
- 所得税・租税的取扱 → 转介税理士
- 具纠纷性的对应 → 转介律师

四葉不動産株式会社、四葉行政書士事務所、四葉社会保険労務士事務所，各自独立的事业体受任业务。转介其他专家时，也请客户直接签约，本事务所不收取介绍费。

## 常见问题

**Q. 以技人国聘用中国・台湾人才时，首先要确认什么？**
A. 本人的学历或实务经验，与所交付职务的关联性。技术・人文领域需相关学历或一定年数实务经验，国际业务原则3年以上实务经验（语言指导等有例外）为目安，且须为专门・技术性业务而非单纯作业。该当性的最终判断由出入国在留管理厅作出，认定・变更的申请属行政书士的业务。本事务所依劳动关系法令设计其前提的职务内容・报酬・劳动条件。

**Q. 对外国人必须以母语明示劳动条件吗？**
A. 以外语（母语）明示本身非法律上的义务。惟以本人能理解的语言呈示较为安全，厚生劳动省公开了英语・中文等多语言示范劳动条件通知书。2024年4月起，就业场所・业务的变更范围、更新上限、无期转换相关事项的明示增加（劳动基准法第15条第1项・同法施行规则第5条）。若以纯日文的通知书未能传达内容，会连动到后续纠纷与在留更新时的说明负担。

**Q. 外国人员工的社会保险・雇用保险从何时加入？**
A. 不问国籍与在留资格，适用规则与日本人相同。在适用事业所常时使用者，满足要件即自入社时点成为健康保险・厚生年金保险的被保险人，劳灾保险只要是劳工全员适用，雇用保险以每周20小时以上・预计使用31日以上加入。与母国制度的双重加入，只能与协定相手国以适用证明书调整，中国无年金期间通算，与台湾则无协定本身。

**Q. 加班或工资纠纷会影响在留更新吗？**
A. 在留期间更新时，审查也会看雇用的继续性与公司劳务管理的妥适性。加班费未付、契约与实态不符，可能在更新场面不利。客观掌握劳动时间、正确计算时间外・深夜・休日的加给工资、使明示的职务内容与实际业务一致，即为对策。惟更新是否核准的见込，本文不下结论。核准的判断由出入国在留管理厅作出。

- 健康保险法（大正11年法律第70号）・厚生年金保险法（昭和29年法律第115号） ── 适用事业所与被保险人资格（不问国籍・在留资格，常时使用者满足要件即被保险人。兼职等以4分之3基准，特定适用事业所则为每周20小时以上・月额8.8万日圆以上・预计使用超过2个月・非学生的要件）

- 学历・实务经验的年数要件与职务关联性的具体套用，因职种・经历而判断不同。个别可否本文未处理（**未验证**）
