**结论（先讲重点）**：开设诊所（Clinic）后，最先需要的劳务是**员工的社会保险（健康保险・厚生年金保险）参保手续**、**劳动条件的明示与雇用契约**，以及若使用10人以上时的**就业规则制作・申报**。此外，若让医师或员工值夜班・日班，还要向所辖的劳动基准监督署取得可作为劳动时间例外处理的**宿日直许可**。医疗法人（法人）只要雇用员工即为社会保险强制适用，个人经营的诊所则在常时5人以上时强制适用。本文整理该从何处着手、社会保险的适用判断、宿日直许可的意义、就业规则・36协定的时机，以及该委托谁做什么。

「院长只看诊、劳务往后放」的方式开业，容易在到职日前后产生社会保险的空窗或未付。本页面是为新开业的医师・事务长而写，以社会保险劳务士的劳务管理视角，整理开业时最先需要的劳务手续。

## 开设诊所最先需要的劳务手续是什么？

除了诊所的开设申报（保健所）与保险医疗机关的指定申请之外，还有**因雇用而产生的手续**。依开业前后的顺序排列如下。

| 时期 | 该做的事 | 提出对象 |
|---|---|---|
| 开业前～到职前 | 劳动条件的明示・雇用契约书的制作（劳动基准法第15条） | 公司内（交付本人） |
| 到职日 | 健康保险・厚生年金保险的资格取得申报（5日内） | 年金事务所（协会健保等） |
| 到职日～10日内 | 雇用保险的资格取得申报 | Hello Work |
| 开始使用劳工之日～ | 劳动保险（劳灾・雇用）的成立申报・概算保险费申报 | 劳动基准监督署・Hello Work |
| 常时使用10人以上时 | 就业规则的制作・申报（劳动基准法第89条） | 所辖劳动基准监督署长 |
| 让员工值宿直・日直时 | 断续性宿直或日直勤务的许可（劳动基准法施行规则第23条） | 所辖劳动基准监督署长 |

社会保险（健保・厚年）的资格取得申报以**到职起5日内**、雇用保险的资格取得申报以**到职次月10日前**为基准。首先确定「让谁、从何时、加入哪种保险」是出发点。劳动时间・加班费的一般想法，请一并参阅[36协定与加班的上限](/zh/labor/column/36-kyotei-zangyo-sharoushi-doko-made)。

## 护士・前台的社会保险会强制适用吗？如何判断？

事业所是否作为单位加入社会保险（健康保险・厚生年金保险），取决于**事业所的形态**与**行业・人数**。

| 事业所形态 | 社会保险（健保・厚年） |
|---|---|
| 医疗法人等法人 | 只要常时使用员工即**强制适用**（不问人数） |
| 个人经营的诊所（适用业种） | 常时使用**5人以上**即**强制适用**；未满5人为任意适用 |

医疗事业（疾病的治疗等）属于健康保险法・厚生年金保险法的**适用业种**（健康保险法第3条第3项、厚生年金保险法第6条）。因此，个人经营的诊所只要常时雇用5人以上，健保・厚年即为强制适用；医疗法人则不问人数皆为强制适用。

在此之上，兼职的护士・前台等**是否个别成为被保险人**，以劳动时间・日数判断。若1周的所定劳动时间与1个月的所定劳动日数达一般劳工的**4分之3以上**即为被保险人；即使未满4分之3，只要满足一定要件（每周20小时以上・月薪88,000日元以上等）也成为被保险人。这项对短时间劳工的适用正逐步扩大。详细的界线请参阅[兼职・打工的社会保险以4分之3为基准](/zh/labor/column/tanjikan-koyo-shakaihoken-4bunno3)与[社会保险的适用扩大](/zh/labor/column/shakaihoken-tekiyo-kakudai-2027)。

## 医师・员工的宿日直许可为何需要？向谁提出？

宿直・日直（夜间或假日的待机性勤务），依原则会被当作劳动时间，牵动时间外・深夜的加班费与劳动时间的上限。但对于**通常几乎没有劳动必要**的待机性勤务，使用者若取得**所辖劳动基准监督署长的许可**（样式第10号），则可不受劳动时间规制（劳动基准法第32条）而使其从事（劳动基准法第41条第3号、劳动基准法施行规则第23条）。这就是宿日直许可。

关于医师，自2024年（令和6年）4月起，从事医业的医师也适用时间外劳动的上限规制，取得宿日直许可的时间原则上不算入劳动时间，因此在与上限规制的关系上，有无许可在实务上也很重要。不过，即使在取得许可的宿日直中，从事与通常勤务相同劳动的时间仍作为劳动时间处理，并为加班费的对象。

| 项目 | 内容 |
|---|---|
| 根据 | 劳动基准法第41条第3号、劳动基准法施行规则第23条 |
| 许可对象 | 通常几乎没有劳动必要的待机性宿直・日直 |
| 申请对象 | 所辖劳动基准监督署长（样式第10号） |
| 效果 | 不受劳动时间规制（劳动基准法第32条）；但从事通常劳动的时间为劳动时间 |

许可的判断由劳动基准监督署进行。本事务所协助依许可基准整理勤务实态并制作申请书类。

## 就业规则与36协定在什么时机需要？

依人数与使其劳动的方式，需要以下书面。

| 书面 | 何时需要 | 根据 |
|---|---|---|
| 就业规则 | 常时使用10人以上劳工时（制作・申报义务） | 劳动基准法第89条 |
| 36协定 | 使其进行超过法定劳动时间的时间外・假日劳动时 | 劳动基准法第36条 |

常时使用10人以上劳工的使用者，有义务制作就业规则并**向所辖劳动基准监督署长申报**（劳动基准法第89条）。未满10人时，为统一劳动条件与工资规则而先行制作，也能让实务稳定。就业规则从几人开始有义务，请参阅[就业规则从几人开始有义务](/zh/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)。

要使其超过法定劳动时间（原则1天8小时・1周40小时）进行时间外・假日劳动，必须先与过半数代表者缔结36协定并**申报后**才可（劳动基准法第36条）。医疗现场容易产生夜间・假日勤务，因此在开业初期把就业规则・36协定・加班费计算整套备妥较为安全。

## 如何把劳务手续纳入开业时程？

劳务手续在时期上会与诊所开设申报、物件准备重叠。为防漏，依下列顺序排列较清楚。

| 阶段 | 劳务要做的事 |
|---|---|
| 物件・装修的规划 | 由预估人数与班表，设计社会保险的适用与劳动时间的架构 |
| 员工招募 | 劳动条件的明示・雇用契约书的制作、就业规则的草稿 |
| 开业前夕 | 劳动保险的成立申报、社会保险的新规适用申报的准备 |
| 到职日 | 健保・厚年的资格取得申报（5日内）、雇用保险的资格取得申报 |
| 开业后尽速 | 10人以上者申报就业规则、有宿日直者取得宿日直许可、缔结・申报36协定 |

物件本身的选定与租赁是不动产的领域，诊所开设申报是行政书士或院长本人（保健所）的手续，与劳务的承担者分开。下一节整理。

## 该委托谁做什么？

诊所开业不会仅以劳务完结。各业务的承担者不同。

| 该做的事 | 属于谁的业务 |
|---|---|
| 社会・劳动保险的适用手续、就业规则・36协定的制作、劳动时间・宿日直许可的书类、薪资计算 | **社会保险劳务士**（本事务所） |
| 诊所开设申报等行政手续的书类制作 | **行政书士**（或院长本人向保健所） |
| 宿日直许可・36协定的许可・受理判断 | **所辖劳动基准监督署长** |
| 保险医疗机关的指定 | **地方厚生局** |
| 诊所物件的选定・租赁・装修 | **不动产（宅地建物取引业者）** |
| 未付工资的请求或劳资纠纷 | **律师** |
| 源泉征收・年终调整・法人的税务 | **税理士** |

本事务所仅限于劳务管理的资讯提供与手续。诊所开设申报等行政手续可为您转介四葉行政書士事務所，物件可转介四葉不動産；但前提是**社会保险劳务士业务、行政书士业务与宅地建物取引业，各自独立、须另行签约**。本事务所不做一括受任。

## 四葉社会保険労務士事務所能为您做什么？

位于文京区小日向的四葉社会保険労務士事務所，就诊所开业提供**社会・劳动保险的适用手续、劳动条件的明示・雇用契约书的制作、就业规则・36协定的制作与申报、宿日直许可申请书类的整理、薪资计算**。**咨询免费。** 依内容与人数估价，收费的思考方式请参阅[报酬额表](/zh/labor/ryokin)，常被询问的问题整理于[常见问答](/zh/labor/faq)。

若已进入未付工资的请求或纠纷，将为您安排直接委托律师的方式。本事务所不收取转介费。

## 常见问题

**Q. 员工只有2～3人也必须加入社会保险吗？**
A. 若是医疗法人等法人，即使员工只有2～3人，健康保险・厚生年金保险也是强制适用。个人经营的诊所则在常时5人以上时强制适用，未满5人为任意适用。不过行业与人数的计算方式有需要判断的场面，建议依实态确认。

**Q. 只要取得宿日直许可，夜间的加班费就完全不用付吗？**
A. 不是。宿日直许可是把通常几乎没有劳动必要的待机性勤务，置于劳动时间规制之外。即使在取得许可的宿日直中，从事急患对应等通常劳动的时间，仍作为劳动时间处理，并为加班费的对象。

**Q. 就业规则在开业同时一定需要吗？**
A. 制作・申报成为义务的，是常时使用10人以上劳工时（劳动基准法第89条）。未满10人时，为统一劳动条件与工资・服务规则而先行制作，较易防止日后纠纷。

**Q. 找物件与诊所开设申报也可以一起委托吗？**
A. 劳务管理是社会保险劳务士、诊所开设申报等行政手续的书类是行政书士（或院长本人向保健所）、物件是宅地建物取引业者的业务。在各自独立、须分别承接（另行签约）的前提下，可为您转介四葉行政書士事務所・四葉不動産。本事务所不采一括受任的形式。
