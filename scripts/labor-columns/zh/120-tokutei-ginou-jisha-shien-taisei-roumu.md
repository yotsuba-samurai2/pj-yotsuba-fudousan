**先讲结论**：特定技能1号的外国人，接收企业须制作支援计划并实施义务性支援10项目。不委托登录支援机关、由自家公司实施即为「自家支援」。自家支援有支援体制的基准：须自过去2年内适当接收或管理中长期在留者（就劳资格）或处理其生活咨询的职员中，选任支援责任者与支援担当者（每个事业所各1名以上），并具备能以外国人充分理解的语言中立地实施支援的体制（出入国管理及难民认定法第2条之5、平成31年法务省令第5号）。无法继续自家支援时，可切换为委托登录支援机关。运作支援的勤怠・工资・就业规则・社会保险等劳务由社会保险劳务士办理；在留诸申请的取次与支援计划的申报由行政书士（申请取次）或登录支援机关办理；许否的判断由出入国在留管理厅作成（各自为独立的事业体、另行签约）。

「每月付给登录支援机关的委托费是负担，想自家公司做支援」「切换为自家支援的要件是什么」——这是接收特定技能1号外国人的企业常有的咨询。本页面是为了不委托登录支援机关、想自家支援的接收企业劳务负责人，整理运作义务性支援10项目的体制与其劳务的整备方式。在留资格的该当性与许否的展望，不在本文范围内（判断由出入国在留管理厅作成）。

## 自家支援与委托登录支援机关，该选哪一个？

特定技能1号的接收机关（特定技能所属机关），负有制作支援计划并依计划实施支援的义务。可选择自家公司实施，或委托登录支援机关。若将支援全部委托登录支援机关，接收机关即视为满足支援体制的基准。要自家实施（自家支援），须自行满足下表的支援体制基准。

| | 自家支援 | 全部委托登录支援机关 |
|---|---|---|
| 支援体制的基准 | 接收机关自行满足 | 因委托而视为满足 |
| 委托费 | 不需要（须有社内人事费） | 每名支援对象者须有每月委托费 |
| 实施主体 | 自家的支援责任者・支援担当者 | 登录支援机关 |
| 适合的场面 | 有中长期在留者的接收实绩・多语言对应人才 | 实绩或语言体制尚未整备 |

接收1名外国人，在留资格的申请、劳动・社会保险的申报、住居的确保会同时启动。其整体面貌整理于[雇用1名外国人需要几个窗口](/zh/labor/column/gaikokujin-koyo-madoguchi-wakekata)。分野别的劳务，护理请见[护理的特定技能外国人劳务与社会保险](/zh/labor/column/kaigo-tokutei-ginou-gaikokujin-roumu-shakaihoken)，外食・自技能实习移行请见[自技能实习移行至特定技能](/zh/labor/column/ginou-jisshu-tokutei-ginou-ikou-gaishoku-shakaihoken)。

## 要自家运作义务性支援10项目，需要什么体制？

义务性支援，是必须纳入支援计划、必须实施的10项目。与任意性支援不同，不可省略。要自家运作，须将各项目由谁・何时・以何种语言实施，作为社内角色事先决定。

| 义务性支援10项目（概要） | |
|---|---|
| ①事前指导（说明劳动条件・活动内容・入国手续・有无收取保证金等） | ⑥提供日语学习机会 |
| ②出入国时的接送 | ⑦咨询・申诉的对应（以能充分理解的语言） |
| ③住居确保・生活必要契约（银行账户・手机・水电煤气等）的支援 | ⑧促进与日本人的交流 |
| ④生活导览 | ⑨（因接收方缘故解除雇用契约时的）转职支援 |
| ⑤公家手续等的同行 | ⑩定期面谈（3个月1次以上）・向行政机关通报 |

- ③的住居确保，若准备宿舍则租赁由不动产公司办理，该宿舍若属劳动基准法的事业附属宿舍，宿舍规则的申报亦必要（[宿舍规则的申报](/zh/labor/column/gaikokujin-kishukusha-kisoku-todokede-roumu)）
- ⑦的咨询・申诉对应与⑩的定期面谈，以能以外国人充分理解的语言实施的体制为前提
- 支援的实施状况须记录于文书，自雇用契约终了日起备置1年以上

义务性支援虽为入管制度上的义务，但日日运作它的基础，是勤怠管理・工资支付・就业规则・社会保险等劳务。报酬须为与日本人从事同一工作时同等以上，劳动・社会保险的适当加入亦为接收的前提。

## 支援责任者・支援担当者由谁担任？中立性的要件是什么？

自家支援中，须选任支援责任者与支援担当者（可同一人・每个事业所各1名以上）。并非谁都能选，须显示能适当实施支援的体制。基准是自符合下列任一的职员中选任。

- ①过去2年内适当接收或管理中长期在留者（限就劳资格）有实绩，并自职员中选任
- ②自职员中、过去2年内具有从事中长期在留者生活咨询等经验者中选任
- ③自职员中、能与①②同程度适当实施支援业务者中选任

此外，支援责任者・支援担当者须为能中立地实施支援计划的立场。运用要领说明：对支援对象外国人具指挥命令・监督立场者，不能谓为中立立场（2026年9月参照）。因其负有于定期面谈中拾取不满与法令违反的角色，其宗旨在于安置能以独立于当事人之眼审视的人。这些基准的细部可能修订，须以出入国在留管理厅的特定技能运用要领确认最新版。接收华语圈人才时的采用・在留劳务，亦整理于[中国・台湾人才的采用与在留](/zh/labor/column/gijinkoku-chuka-taiwan-jinzai-saiyo-roumu-zairyu)。

## 无法继续自家支援时，会怎样？

因支援担当者离职或体制变化，可能无法满足自家支援的基准。若放任支援体制基准未满足，即成为未能适当实施支援计划的状态，也影响此后的在留诸申请。无法继续时，可切换为将支援全部委托登录支援机关。

- 切换为全部委托后，接收机关即视为满足支援体制的基准
- 伴随委托或支援计划变更等而向出入国在留管理厅的申报・申请取次，由行政书士（申请取次）或登录支援机关办理
- 社会保险劳务士负责伴随体制变更的勤怠・工资・就业规则・社会保险侧的整备。各自为独立的事业体、另行签约

是否选择自家支援，须比较有无实绩与人才、以及委托费与社内负担来决定。开始后也须定期检视能否维持体制，若变得困难，尽早检讨切换为委托。

## 常见问题

**Q. 想不委托登录支援机关而切换为自家支援，需要资格吗？**
A. 不需要特别资格，但须满足支援体制的基准。须自过去2年内适当接收・管理中长期在留者（就劳资格）或处理其生活咨询的职员中，选任支援责任者与支援担当者，并须有能以外国人充分理解的语言中立地实施支援的体制（平成31年法务省令第5号）。实绩或语言体制尚未整备时，委托登录支援机关较为实际。

**Q. 义务性支援的10项目，可以只自家做一部分、其余委托吗？**
A. 支援原则上整体一并实施。若将支援全部委托登录支援机关，接收机关即视为满足支援体制的基准，惟一部委托的可否与范围依运用要领的规定。若出现无法实施的项目，即欠缺支援计划的适当实施，故体制有不安时，应检讨全部委托。最新处理以出入国在留管理厅的运用要领确认。

**Q. 支援担当者可以是该外国人的直属上司吗？**
A. 运用要领说明：对支援对象外国人具指挥命令・监督立场者，不能谓为中立立场。因其负有于定期面谈中拾取不满与法令违反的角色，其宗旨在于安置能以独立于当事人之眼审视的人。在仅有直属上司的小规模体制，须确认能否保持中立性后选任。

**Q. 支援担当者离职，无法继续自家支援。该怎么办？**
A. 可切换为将支援全部委托登录支援机关。切换后接收机关即视为满足支援体制的基准。伴随委托或支援计划变更而向出入国在留管理厅的申报・申请取次由行政书士（申请取次）或登录支援机关办理，勤怠・工资・社会保险等劳务侧的整备由社会保险劳务士负责（各自为独立的事业体、另行签约）。
