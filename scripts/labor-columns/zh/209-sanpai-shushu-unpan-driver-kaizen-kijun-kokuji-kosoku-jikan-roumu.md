**结论（先讲重点）：** 改善基准告示（自动车运转者的劳动时间等改善基准）的适用，**与是否持有运输业许可无关，而是对主要从事四轮以上汽车驾驶业务的劳动者适用**（告示第1条）。因此，即使只用自家卡车运送自家产业废弃物、既不需要收集运搬业许可也不需要运输业许可，该名驾驶仍受改善基准告示规范。自2024年（令和6年）4月1日起，卡车驾驶的拘束时间在**1年3,300小时・1个月284小时・1天13小时（最多15小时）**的界线内管理，休息期间**以连续11小时为基本、不低于9小时**。本文整理许可与劳务管理的切分、拘束时间上限、36协定与就业规则的修改处，以及该委托谁做什么。

「我们没取得运输业许可，所以驾驶的劳动时间规制与我们无关」——这种理解很危险。本页面面向以产业废弃物收集运搬业许可雇用卡车驾驶的业者，以及用自家车运送自家废弃物的业者的劳务负责人，从社会保险劳务士的劳务管理视角，整理改善基准告示的适用范围、拘束时间与休息期间、36协定与就业规则的修改处。

## 没有运输业许可，也适用改善基准告示吗？

适用。改善基准告示是否适用，**取决于「是否为主要从事汽车驾驶业务的劳动者」，而非「持有什么许可」。**

改善基准告示第1条将本基准适用的「自动车运转者」定义为：劳动基准法第9条规定的劳动者（排除仅使用同居亲属的事业之劳动者及家事使用人），且**主要从事四轮以上汽车驾驶业务**（厚生劳动省劳动基准局长所定者除外）的人。此处并没有「受雇于持有货物自动车运送事业许可之业者」这样的限定。

至于是否需要许可，则由其他法律决定。

| 运送方式 | 所需许可 | 依据 |
|---|---|---|
| 以业务形式运送他人的产业废弃物 | 产业废弃物收集运搬业许可（都道府县知事） | 废弃物处理法第14条第1项 |
| 运送自家（业者自身）的产业废弃物 | **不需许可** | 废弃物处理法第14条第1项但书（业者自行运送其产业废弃物的情形） |
| 应他人需求、有偿运送货物 | 一般货物自动车运送事业许可 | 货物自动车运送事业法第2条 |
| 用自家车运送自家货物（废弃物） | 不需运输业许可（非「应他人需求」） | 货物自动车运送事业法第2条 |

也就是说，只用自家卡车运送自家废弃物，既不需要产废收集运搬业许可，也不需要运输业许可。**但「不需许可」与「驾驶的劳动时间规制不适用」是两回事。** 一旦雇用主要从事驾驶业务的人，无论有无许可，都必须进行改善基准告示的管理。驾驶以外一般劳动时间规则，请一并参阅[36协定与加班上限](/zh/labor/column/36-kyotei-zangyo-sharoushi-doko-made)。

## 2024年4月起，拘束时间（1年・1个月・1天）如何改变？

改善基准告示于2022年（令和4年）12月23日以厚生劳动省告示第367号修正，自2024年（令和6年）4月1日起适用。卡车驾驶的主要基准如下。

| 项目 | 原则 | 例外・上限 |
|---|---|---|
| 1年的拘束时间 | 3,300小时 | 依劳资协定，1年内最多6个月可达3,400小时 |
| 1个月的拘束时间 | 284小时 | 依劳资协定，1年内最多6个月可达310小时（超过284小时最多连续3个月；须努力使当月时间外・休日劳动低于100小时） |
| 1天的拘束时间 | 13小时 | 最多15小时（长距离货物运送：1周2次可达16小时） |
| 休息期间 | 勤务结束后，以连续11小时以上为基本 | 不低于连续9小时 |
| 连续驾驶时间 | 4小时以内 | 不得已时最多可延长30分钟 |

拘束时间是指从上班到下班、劳动时间加上休息时间（含手待时间）的时间。改善基准告示并非劳动基准法本身，而是厚生劳动大臣的告示；但若违反，将成为劳动基准监督署纠正指导的对象。它与时间外劳动的上限规制（汽车驾驶业务即使特别条款也在1年960小时以内。劳动基准法附则第140条第1项）是不同的尺度，**必须同时满足两者**。

## 产废驾驶的「装载・收集地点待机」算进拘束时间吗？

算进去。拘束时间涵盖的**不只是劳动时间，还包括休息与手待时间——即从上班到下班的整段时间。**

产业废弃物的收集运搬，包含在排出事业场的装载、在处分场或中间处理设施的卸货、依受入顺序的等待等，「未在驾驶的时间」容易拉长。只要这些时间处于雇主的指挥命令下、无法自由使用，就算进手待时间、计入拘束时间。若只计算驾驶时间、判断「还有余裕」，就可能发生实际拘束时间已超过15小时的情况。

| 时间种类 | 是否算进拘束时间 |
|---|---|
| 驾驶中的时间 | 算（劳动时间） |
| 装载・卸货的作业时间 | 算（劳动时间） |
| 处分场的受入等待・排队等待 | 在指挥命令下则算（手待时间） |
| 休息时间 | 算（计入拘束时间；非劳动时间） |
| 勤务与勤务之间的休息期间 | 不算（在拘束时间之外；以连续11小时为基本） |

管理的起点，是用数位行车记录器或日报**记录实际拘束时间，并区分驾驶、作业、待机**。待机越长的现场，确认记录与实态是否一致就越重要。

## 36协定与就业规则该怎么整备？

要同时满足拘束时间管理与时间外劳动的上限规制，需要仔细制作书面文件。修改处如下。

| 要做的事 | 检视重点 |
|---|---|
| 36协定（特别条款） | 将汽车驾驶业务的时间外劳动设计在1年960小时以内，并载明特别条款的次数（1年6次以内）・理由・程序（劳动基准法第36条・附则第140条第1项） |
| 就业规则・工资规程 | 反映拘束时间・休息期间的思路，并与加给工资的计算（时间外25%以上・休日35%以上・深夜25%以上）保持一致（劳动基准法第37条） |
| 拘束时间・劳动时间的记录 | 将1天15小时・1个月284小时・休息9小时的界线纳入每日管理的运作，并明确手待时间的处理 |
| 过半数代表者的选出 | 以适当程序选出非管理监督者的人，并留下记录（劳动基准法施行规则第6条之2） |

常时雇用10人以上劳动者的事业场，就业规则的作成・申报为义务。详情请参阅[就业规则从几人起成为义务](/zh/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)。此外，持有运输业许可的一般货物自动车运送事业者的「2024年问题」全貌，在[运输业的2024年问题与改善基准告示](/zh/labor/column/unso-2024-mondai-kaizen-kijun-kokuji)也有讨论。

## 许可找行政书士、劳务找社劳士——界线划在哪里？

产废驾驶的对应，无法仅靠劳务管理完成。承担者依业务而分。

| 要做的事 | 属于谁的业务 |
|---|---|
| 36协定・就业规则・工资规程的作成、拘束时间・劳动时间管理体制的整备、加给工资的计算 | **社会保险劳务士**（本事务所） |
| 产业废弃物收集运搬业的许可申请・变更申报、是否需要许可的程序判断 | **行政书士** |
| 一般货物自动车运送事业许可（运送他人货物时）、事业计划变更的认可・申报 | **行政书士**（运输行政的最终判断由地方运输局做出） |
| 未付加班费的请求、职灾争议、劳资纠纷・劳动审判・诉讼 | **律师** |
| 加给工资的源泉征收・年末调整的税务判断 | **税理士** |

本事务所仅限于劳务管理的资讯提供与手续。关于产业废弃物收集运搬业或运输业的许可，我们虽可为您转介四葉行政書士事務所，但前提是**社会保险劳务士业务与行政书士业务各由独立的事业体承担、须另行签约**。不做一括受任。

## 常见问题

**Q. 只是用自家卡车运送自家废弃物，也必须遵守改善基准告示吗？**
A. 必须遵守。改善基准告示的适用，取决于是否为主要从事四轮以上汽车驾驶业务的劳动者，而非是否持有运输业或产废收集运搬业许可（告示第1条）。即使运送自家废弃物不需许可，只要该驾驶主要从事驾驶业务，就必须管理拘束时间与休息期间。

**Q. 产废收集运搬需要许可，那除了改善基准告示，是否也需要运输业许可？**
A. 视运送方式而定。以业务形式运送他人的产业废弃物需要产业废弃物收集运搬业许可（废弃物处理法第14条第1项），但自行运送自家废弃物则不需许可（同项但书）。运输业（一般货物自动车运送事业）许可是在「应他人需求、有偿」运送货物时才需要，仅用自家车运送自家货物则不需要。是否需要许可，与劳动时间规制是不同的论点。

**Q. 在处分场等待受入的时间，算进拘束时间吗？**
A. 只要处于雇主的指挥命令下、无法自由使用，就算进手待时间、计入拘束时间。拘束时间是劳动时间加上休息与手待时间、从上班到下班的时间，也包含未在驾驶的待机时间。待机长的现场，以记录掌握实态是管理的起点。

**Q. 驾驶的许可与劳务，可以一起委托吗？**
A. 劳务管理是社会保险劳务士的业务，产废收集运搬业或运输业许可的文件是行政书士的业务。在各为独立事业体、另行签约的前提下，我们可为您转介四葉行政書士事務所。我们不采取一括受任的形式。
