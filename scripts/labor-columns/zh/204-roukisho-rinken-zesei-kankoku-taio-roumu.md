**结论（先讲重点）**：劳动基准监督署的调查（临检监督）来时，基本流程是出示被要求的帐簿・书类，收到改正劝告书或指导票后，在期限内完成改正并提出改正报告书。临检与帐簿提出是劳动基准法第101条所定监督官的权限，拒绝或虚伪记载属第120条罚则的对象。平时整备好法定三帐簿・36协定・工作规则，是在调查中不陷入困境的最佳准备。

## 劳动基准监督署的调查（临检）有哪些种类，为何会来？

劳动基准监督署的调查称为“临检监督”，由劳动基准监督官进入事业场，确认帐簿与劳动实况。依据为劳动基准法第101条：监督官得对事业场、宿舍及其他附属建设物临检，要求提出帐簿及书类，并对使用者或劳工进行询问（且须携带证明其身分的证票）。依厚生劳动省・都道府县劳动局的运用，调查大致分为下列各类。

| 种类 | 契机 |
|---|---|
| 定期监督 | 依年度计划选定对象进行的通常监督 |
| 申告监督 | 因劳工的申告（第104条）而进行的监督 |
| 灾害时监督 | 发生劳动灾害时，为究明原因・防止再发而进行的监督 |
| 再监督 | 为确认对过去改正劝告的因应而进行的监督 |

劳工于事业场有违反法令的事实时，得向行政官厅或劳动基准监督官申告其事实，使用者不得以申告为由对劳工解雇或其他不利对待（第104条）。亦即“为何会来”，可能是计划性的定期监督，也可能以员工的申告或劳灾的发生为契机（调查的分类属厚生劳动省・劳动局的运用，2026年11月12日参照）。

## 当天会被看什么、被要求哪些帐簿・书类？

临检中，劳动时间・工资・安全卫生的实况会与帐簿对照确认。核心是法令所定须制作・保存的书类。

| 书类 | 依据 |
|---|---|
| 劳工名簿 | 劳动基准法第107条 |
| 工资台帐 | 第108条 |
| 出勤簿・打卡等劳动时间的记录 | 劳动时间的记录（第108条工资计算的基础） |
| 时间外・休日劳动的协定书（36协定） | 第36条 |
| 工作规则（经常雇用10人以上的事业场） | 第89条 |
| 健康检查记录・安全卫生相关书类 | 劳动安全卫生法等 |

劳工名簿・工资台帐・出勤簿即所谓法定三帐簿，须制作并保存一定期间（详见[法定三帐簿的整备与保存](/zh/labor/column/hotei-san-choubo-seibi-hozon)）。劳动安全卫生法第91条亦有监督官立入检查・询问・物件检查的权限，安全卫生面也可能一并确认。若拒绝提出被要求的帐簿书类，或提出有虚伪记载的帐簿书类，依劳动基准法第120条第4项，属30万日元以下罚金的对象。当天，基本做法是迅速出示被要求的书类，不清楚之处则确认后再答覆。

## “改正劝告”与“指导票”有何不同，置之不理会如何？

作为调查结果交付的书面，主要有改正劝告书与指导票。两者都不是有法律明文的“处分”，而是作为行政指导交付的文书。

| 书面 | 交付场合 | 定位 |
|---|---|---|
| 改正劝告书 | 认定有法令违反时 | 载明违反事项・改正内容・改正期限的行政指导 |
| 指导票 | 虽未达法令违反，但认定改善为宜时 | 载明改善事项的行政指导 |

改正劝告书与指导票都是行政指导，本身并非得提起不服申立的行政处分。惟若置之不理，可能进行再监督，在恶质・重大情形下，可能导致后述的送检或企业名称的公布。依劳动安全卫生法，于劳动灾害危险迫切等情形，可能发出使机械・设备停止使用等的处分（使用停止命令），此为行政处分。收到后，确认指摘的依据条文与改正期限、整理何者须于何时改正，是出发点。

## 改正报告书要在何时・如何撰写？若查出未付加班费？

收到改正劝告书或指导票后，在指定期限内完成改正，并提出改正（改善）报告书。报告书中，就被指摘的各事项，具体写明如何改正（或改正的计划与时期）。

| 步骤 | 内容 |
|---|---|
| 整理指摘 | 将指摘事项・依据条文・改正期限列表 |
| 确认事实 | 将劳动时间・工资的实况与帐簿对照确认 |
| 实施改正 | 修订规程、检讨运用、补付不足分等 |
| 制作报告书 | 就各事项记载改正内容・时期，于期限内提出 |

典型的指摘是未付的加成工资（加班费）。若劳动时间的记录与工资台帐不一致，可能被要求追溯补付不足分。采用固定加班费（视为加班费）时，会确认其是否符合要件、是否另付超过部分（见[固定加班费合法的要件与差额结算](/zh/labor/column/kotei-zangyodai-tekiho-youken-sagaku-seisan)）。若难以于期限内改正，切勿置之不理，应提示改正的计划与预定时期并洽商。改正报告书的制作支援与劳动时间・工资实况的整理，属社会保险劳务士的领域。咨询费用请见[报酬额表](/zh/labor/ryokin)。

## 在何种情形会走到送检・公布企业名称？

多数案件以改正报告结束，但恶质・重大案件可能进入刑事程序。劳动基准监督官就违反劳动基准法之罪，执行刑事诉讼法所定司法警察官的职务（第102条）。亦即监督官于一定情形下，具侦查并将案件移送检察官（送检）的权限。

| 阶段 | 概要 |
|---|---|
| 改正劝告・指导 | 行政指导；通常于期限内改正即结束 |
| 再监督 | 确认改正状况；未改正则反覆进行 |
| 送检 | 就恶质・重大违反，依第102条移送检察官 |
| 公布企业名称 | 就违法长时间劳动或送检案件等，可能依厚生劳动省的运用公布企业名称 |

走到送检或公布的，多为恶质・重大案件——反覆无视改正劝告、隐匿重大劳动灾害、出示虚伪帐簿等（企业名称公布系依厚生劳动省的运用，2026年11月12日参照）。送检后的刑事程序、就行政指导・处分的因应所生法律争议、就未付工资的诉讼，属律师的领域。从何处为社会保险劳务士、从何处为律师，亦可参考[解雇因应是社劳士还是律师](/zh/labor/column/kaiko-sharoushi-bengoshi-dochira)的切分。这些与社会保险劳务士事务所各自独立为事业体，前提是分别签约而切分。没有介绍费。

## 平时整备好什么，调查时就不会困扰？

对调查最好的准备，是平时的劳务管理。平时就把临检核心的书类整备好，调查来时也能从容因应。

| 要整备的事项 | 重点 |
|---|---|
| 法定三帐簿 | 制作劳工名簿・工资台帐・出勤簿，并遵守保存期间 |
| 劳动时间的记录 | 以打卡等客观掌握，并与工资计算一致 |
| 36协定 | 于时间外・休日劳动前缔结・申报；在上限规制范围内运用 |
| 工作规则 | 经常10人以上则制作・申报；与实况一致 |
| 加成工资 | 检视加班费计算方法；固定加班费须确认要件与差额结算 |

36协定的缔结・申报与上限规制的运用，整理于[36协定能委托社劳士到什么程度](/zh/labor/column/36-kyotei-zangyo-sharoushi-doko-made)；工作规则的制作义务与内容，整理于[工作规则的制作义务与内容](/zh/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)。平时把这些整备好并留下记录，是对调查最好的准备。帐簿・协定・工作规则的整备，以及调查来时的改正报告书制作支援，属社会保险劳务士的领域。常见问题整理于[常见问答](/zh/labor/faq)。

## 常见问题

**Q. 劳动基准监督署的调查可以拒绝吗？**
A. 无正当理由不得拒绝。劳动基准法第101条规定，劳动基准监督官得对事业场临检、要求提出帐簿及书类、对使用者・劳工询问。拒绝・妨碍・忌避临检，对询问不陈述，不提出帐簿书类，或提出有虚伪记载的帐簿书类，依第120条第4项属30万日元以下罚金的对象。日程的调整可洽商，但拒绝调查本身并不适切。

**Q. 改正劝告书是行政处分吗？有不服可以争讼吗？**
A. 改正劝告书与指导票都不是有法律明文的行政处分，而是作为行政指导交付的文书。因此其本身并非得作为处分撤销争讼的对象。惟若对指摘的依据或事实认定有疑问，应确认依据条文与事实后，向监督署说明・协议。送检、行政处分、就未付工资的诉讼等法律争议的阶段，属律师的领域。

**Q. 调查中查出未付加班费，要追溯到何时补付？**
A. 一般会被要求结算加成工资的不足分。追溯的范围与计算方法，依劳动时间的记录与工资台帐确认。采用固定加班费时，会确认是否符合要件、是否另付超过部分。因金额与时效的个别判断依案件而异，宜将劳动时间・工资的实况与帐簿对照整理，必要时向社会保险劳务士咨询。若就未付工资发展为诉讼等法律纷争，属律师的领域。

**Q. 税务署的调查与劳动基准监督署的调查是同一回事吗？**
A. 是不同的。劳动基准监督署的调查（临检监督）确认劳动基准法・劳动安全卫生法等劳动相关法令的履行，对象为劳动时间・工资・安全卫生。确认税捐申报・缴纳的税务调查由税务署进行，属税理士的领域。两者依据法令与主管机关皆不同，故应就各自独立的事业体・机关分别咨询。
