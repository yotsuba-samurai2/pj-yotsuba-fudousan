**先讲结论**：中国・台湾企业在日本雇用员工，公司须负担**健康保险・厚生年金保险・介护保险・雇用保险・劳灾保险**的保险料，以及全额由公司负担的**儿童・育儿拠出金**。健康保险・厚生年金・介护・雇用保险原则为**劳资折半**（劳灾与拠出金全额由公司负担），公司负担多半约为报酬额的**15〜16%左右**（料率随年度・都道府县・业种而变）。本文从社会保险劳务士的观点，整理加入义务的界线与入社手续。

进出日本雇用当地员工时，除了薪资本身，还须预估公司额外上乘负担的社会・劳动保险成本。本文为中国・台湾企业的人事・经营层，以及其当地的会计・人事顾问，说明在日本雇人对公司而言要花多少。具体料率每年度改定，金额请以最新一次资讯确认。

## 在日本雇人，公司要负担哪些社会保险料？

日本公司（法人）雇用员工时，公司须负担下列保险料。健康保险・介护保险・厚生年金・雇用保险由劳工与公司分担，劳灾保险与儿童・育儿拠出金由公司全额负担。

| 保险・拠出金 | 主要对象 | 负担 |
|---|---|---|
| 健康保险 | 疾病・受伤・生产等医疗 | 劳资折半 |
| 介护保险 | 40岁以上未满65岁的被保险人 | 劳资折半 |
| 厚生年金保险 | 老龄・障碍・遗属年金 | 劳资折半 |
| 雇用保险 | 失业给付・育儿休业给付等 | 劳资分担（公司较多） |
| 劳灾保险 | 业务・通勤灾害 | 公司全额负担 |
| 儿童・育儿拠出金 | 儿童手当等财源 | 公司全额负担 |

健康保险・介护・厚生年金向日本年金机构（或健康保险组合），雇用・劳灾保险作为劳动保险合并向国家缴纳。设立公司后何时该申报什么，整理于[设立公司后，何时该申报什么](/zh/labor/column/kaisha-setsuritsu-shakaihoken-roudouhoken-kigen)。

## 劳资折半的料率与公司负担有多少？

主要料率如下（令和8年度＝2026年度。健康保险与劳灾保险的率随都道府县・业种而变，正确值请向协会健保・厚生劳动省确认）。

| 保险・拠出金 | 料率（合计） | 公司负担的目安 |
|---|---|---|
| 厚生年金保险 | 18.3%（平成29年9月以后固定） | 劳资折半，公司9.15% |
| 健康保险 | 都道府县别（协会健保・全国约10%前后） | 劳资折半 |
| 介护保险（40〜64岁） | 1.62%（协会健保・令和8年度） | 劳资折半，公司0.81% |
| 雇用保险（一般事业） | 1.35%（令和8年度） | 公司0.85%（本人0.5%） |
| 劳灾保险 | 业种别 | 公司全额负担 |
| 儿童・育儿拠出金 | 0.36%（令和8年度） | 公司全额负担（乘以厚生年金的标准报酬） |

合计而言，**公司负担多半约为报酬额的15〜16%左右**，于支付薪资之外上乘发生（40岁以上再加介护保险之分）。保险料不仅对每月薪资，对奖金亦课征。料率逐年度改定，人事费试算请采用最新料率表。厚生年金料率固定为18.3%及劳资折半的思路，于[以短时间雇用，社会保险会如何](/zh/labor/column/tanjikan-koyo-shakaihoken-4bunno3)亦为前提。

## 社会保险的加入义务，自哪一条界线发生？

**法人即使仅社长1人，亦为社会保险（健康保险・厚生年金保险）的强制适用事业所**。在日本设立子公司或分公司（已登记的法人），该时点即为适用事业所。员工个别的加入义务，以下列界线判断。

- **社会保险（健康保险・厚生年金）**：除正职外，1周约定工作时间与1月约定工作日数皆为一般劳工**4分之3以上**的兼职等为被保险人。被保险人51人以上的特定适用事业所，周20小时以上・月薪8.8万圆以上等短时间劳工亦扩大适用。
- **雇用保险**：1周约定工作时间**20小时以上**（2028年10月起10小时以上）、且预期雇用31日以上者。日间学生原则除外。
- **劳灾保险**：对雇用**即使1名**劳工的事业强制适用，不问国籍・在留资格・工作时间皆适用于劳工。

即为外国人，此判定与日本人完全相同，不会因国籍而改变加入与否。4分之3基准的具体数法请参阅[以短时间雇用，社会保险会如何](/zh/labor/column/tanjikan-koyo-shakaihoken-4bunno3)；雇用1名外国人时所动手续的全貌，请参阅[雇用1名外国人，需要几个窗口](/zh/labor/column/gaikokujin-koyo-madoguchi-wakekata)。

## 外国员工入社需要哪些资格取得手续？

雇入外国人时，除与日本人相同的社会保险・雇用保险手续外，另增1项**外国人特有的申报**。

| 手续 | 提出处 | 期限 |
|---|---|---|
| 健康保险・厚生年金保险 被保险人资格取得届 | 日本年金机构（年金事务所） | 自事实发生5日内 |
| 雇用保险 被保险人资格取得届 | Hello Work | 资格取得之翌月10日前 |
| 外国人雇用状况的申报 | Hello Work | 雇用保险被保险人以资格取得届兼用；其余至翌月末日 |

**外国人雇用状况的申报**于雇入・离职时皆须办理（劳动施策综合推进法第28条第1项），未申报者可处30万圆以下罚金，须申报在留资格・在留期间・国籍等。详见[雇用外国人后，向Hello Work申报](/zh/labor/column/gaikokujin-koyo-jokyo-todokede)。自中国以出向接受时的社会保障协定（双重加入的调整）整理于[中国驻在・中国员工的社会保险](/zh/labor/column/chugoku-chuzai-shakaihosho-kyotei-nijukanyu)；如台湾般无协定时，则见[从台湾雇用・以出向接受人员时的社会保险](/zh/labor/column/taiwan-koyo-shukko-shakaihoken-kyotei-nashi)。

## 公司设立・在留资格・税务，该如何分工委托？

进出日本至雇人为止，依负责的资格分工。各自为不同的契约。

| 要做的事 | 主要负责 |
|---|---|
| 劳动・社会保险的适用、资格取得・丧失的申报、雇用契约・就业规则的整备、薪资计算 | 社会保险劳务士（本事务所） |
| 公司设立的登记申请 | 司法书士 |
| 设立后的法人设立届・源泉征收・薪资的税务 | 税理士 |
| 在留资格（经营・管理、技术・人文知识・国际业务等）的申请・取次 | 行政书士 |
| 事业所・社宅之物件寻找 | 宅地建物取引业者 |

在留资格的申请・取次可转介至四葉行政書士事務所，事业所或社宅的物件可转介至四葉不動産，惟四葉行政書士事務所・四葉不動産与本事务所为**各自独立**的事业体，社会保险劳务士业务・行政书士业务・宅地建物取引业务须**另行签约**（不进行一括受任）。本事务所不收取介绍费。备置社宅时现物给与的处理，请参阅[提供社宅，社会保险料可能上升](/zh/labor/column/shataku-genbutsu-kyuyo-hyojun-hoshu)。

四葉社会保険労務士事務所可协助日本社会・劳动保险适用的整理、资格取得・丧失的申报、薪资计算、雇用契约・就业规则的整备。咨询免费，费用汇整于[报酬额表](/zh/labor/ryokin)。

## 常见问题

**Q. 在日本设立子公司、仅社长1人时，须加入社会保险吗？**
A. 须加入。法人即使仅代表者1人，亦为健康保险・厚生年金保险的强制适用事业所，领取报酬的代表者为被保险人。雇用员工则亦须劳动保险（劳灾・雇用保险）。劳灾保险对雇用即使1名劳工的事业强制适用。

**Q. 公司负担的保险料，约为薪资的多少？**
A. 将健康保险・介护・厚生年金・雇用保险的公司负担分，加上公司全额负担的劳灾保险・儿童・育儿拠出金，合计多半约为报酬额的15〜16%左右。健康保险料率为都道府县别、劳灾保险料率为业种别，40岁以上再加介护保险之分。正确率每年度改定，请以最新料率表确认。

**Q. 雇用外国人，手续会比日本人多吗？**
A. 社会保险・雇用保险的加入判定与手续与日本人相同。惟雇入・离职时皆须向Hello Work办「外国人雇用状况的申报」（劳动施策综合推进法第28条第1项），未申报者可处30万圆以下罚金。雇用保险的被保险人以资格取得届兼用之。

**Q. 自中国以出向派遣的员工，也要加入日本的社会保险吗？**
A. 只要在日本的适用事业所常时使用，原则不问国籍成为日本被保险人。惟依日中社会保障协定，5年以内的一时派遣可以适用证明书免于加入日本年金（对象仅年金）。台湾无协定，故无法使用此机制。详见各记事。
