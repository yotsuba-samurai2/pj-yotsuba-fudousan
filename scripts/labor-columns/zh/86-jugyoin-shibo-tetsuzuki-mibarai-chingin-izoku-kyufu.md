**结论（先讲重点）**：员工过世时，公司要在期限内办理**社会保险・雇用保险的资格丧失手续**，把**未付工资与退职金支付给继承人**，并协助**遗属可领取的给付**（劳灾的遗属补偿给付・遗属年金等）。健康保险・厚生年金保险的资格丧失日为死亡日的次日，申报以5日内、雇用保险的资格丧失申报以10日内为基准。未付工资属于继承对象，权利者（继承人）提出请求时须于7日内支付（劳动基准法第23条）。本文以社会保险劳务士的劳务管理视角，整理何时做什么、支付给谁、资格丧失手续、遗属给付，以及公司内部该备妥什么。

员工的过世来得突然，遗属对应与各项手续同时进行。本页面是为员工过世的中小企业经营者・人事负责人而写，整理公司该做的事与期限。

## 员工过世后公司要在何时做什么？

接到死亡通知后，在对应遗属的同时，推进有期限的手续。主要如下。

| 该做的事 | 期限基准 | 提出对象 |
|---|---|---|
| 健康保险・厚生年金保险的资格丧失申报 | 死亡日次日（资格丧失日）起5日内 | 年金事务所（协会健保等） |
| 健康保险证（被保险者证）的返还 | 与资格丧失申报一并 | 年金事务所・健康保险组合 |
| 雇用保险的资格丧失申报 | 不再是被保险人之日的次日起10日内 | Hello Work |
| 未付工资・金品的支付・返还 | 权利者（继承人）请求起7日内 | 向继承人 |
| 劳灾遗属（补偿）给付的说明・请求协助 | 遗属请求（注意时效） | 劳动基准监督署 |

社会保险（健保・厚年）的资格丧失日为**死亡日的次日**，并非死亡「当天」，须留意。退职相关金品的一般处理，请一并参阅[退职伴随的金品・年休实务](/zh/labor/column/taishoku-daiko-kaisha-taio-nenkyu-kashiyohin)。

## 未付工资或退职金该支付给谁（确认继承人）？

劳工过世时，尚未支付的工资（未付工资）与退职金无法支付给本人。**工资债权为继承对象**，由继承人承继（民法）。劳动基准法第23条规定，劳工死亡时，**权利者（继承人）提出请求时，须于7日内支付工资，并返还积立金・保证金・储蓄金及其他属于劳工权利的金品**。违反有罚则（30万日元以下罚金）。

| 项目 | 处理 |
|---|---|
| 未付工资 | 继承对象。支付给继承人（劳动基准法第23条・民法） |
| 退职金 | 依就业规则・退职金规程的受领权者规定；无规定时作为继承问题整理 |
| 支付期限 | 权利者（继承人）请求起7日内（劳动基准法第23条） |
| 继承人为复数时 | 需确定由谁・以何比例受领（遗产分割・法定继承分） |

容易出问题的是**继承人有复数／联络不上**时。支付对象或金额有误，会有双重支付的风险。继承人范围・顺位的确定（户籍的收集等）属于继承手续的领域，承担者分开。下一节整理。

## 社会保险・雇用保险的资格丧失手续怎么办？

死亡与退职相同，是被保险人资格的丧失事由。由公司作为事业主申报。

| 保险 | 手续 | 期限 | 提出对象 |
|---|---|---|---|
| 健康保险・厚生年金保险 | 被保险者资格丧失申报（资格丧失日＝死亡日次日） | 5日内 | 年金事务所（协会健保）・健康保险组合 |
| 雇用保险 | 被保险者资格丧失申报 | 不再是被保险人之日的次日起10日内 | Hello Work |
| 健康保险的被扶养者 | 原被扶养的遗属需转入国民健康保险等时 | 尽速 | 市区町村等 |

健康保险证于资格丧失后不可使用。除被保险人本人外，若过世员工有**受其扶养的家属**，该家属的医疗保险也需切换（加入国民健康保险，或转入其他家属的扶养等）。公司应确实办理资格丧失申报与保险证返还，并向遗属说明切换的窗口。

## 遗属可领取的给付（劳灾的遗属补偿・遗属年金）有哪些？

依死亡原因，遗属可领取的给付不同。公司向遗属说明可请求的给付，并协助证明与填写。

| 给付 | 对象 | 根据・窗口 |
|---|---|---|
| 遗属补偿给付（遗属补偿年金・一时金） | 因业务事由死亡（业务灾害） | 劳动者灾害补偿保险法第16条等／劳动基准监督署 |
| 遗属给付 | 因通勤死亡（通勤灾害） | 劳动者灾害补偿保险法／劳动基准监督署 |
| 遗属厚生年金 | 厚生年金的被保险人等死亡时 | 厚生年金保险法第58条／年金事务所 |
| 遗属基础年金 | 满足一定要件的有子女之配偶・子女等 | 国民年金法／年金事务所・市区町村 |
| 埋葬料・葬祭料 等 | 健康保险・劳灾各自的制度 | 协会健保・劳动基准监督署 |

是否为业务上・通勤的死亡，由**劳动基准监督署**认定；遗属年金的受领资格・顺位，由**年金事务所（日本年金机构）**判断。劳灾给付的请求有时效，因此向遗属的说明宜早。公司并非最终判断「请求权人是谁」「是否业务上」，而是协助必要的证明与填写的立场。

## 为避免纠纷，公司内部该如何备妥？

为了临事不乱，平时先备妥以下事项较为安全。

| 该做的事 | 目的 |
|---|---|
| 在退职金规程中订定受领权者 | 明确支付对象，避免继承相关争议 |
| 掌握紧急联络人・家庭组成 | 尽速联络遗属并切换扶养家属的保险 |
| 资格丧失・给付说明的手顺书 | 不漏掉5日・10日等期限 |
| 未付工资支付对象的确认手顺 | 继承人确定前不轻率支付（防止双重支付） |

在继承人有复数、有遗嘱、继承人间有争执等场面，公司不宜独自判断，应将承担者分开推进。下一节整理。

## 该委托谁做什么？

员工过世伴随的手续不会仅以劳务完结。各业务的承担者不同。

| 该做的事 | 属于谁的业务 |
|---|---|
| 社会・雇用保险的资格丧失、劳灾遗属给付・遗属年金的手续、就业规则・退职金规程的整备 | **社会保险劳务士**（本事务所） |
| 继承人范围・顺位的确定、户籍收集、遗产分割协议书的制作等继承手续 | **行政书士**（或依司法书士・律师的业务范围） |
| 继承人间的纠纷、未付工资・退职金支付的争议 | **律师** |
| 继承登记（不动产的名义变更） | **司法书士** |
| 遗产税・准确定申报的税务 | **税理士** |
| 业务上・通勤灾害的认定 | **劳动基准监督署** |

本事务所仅限于劳务管理的资讯提供与手续。与继承人确定或遗产分割相关的书类，可为您转介四葉行政書士事務所；但前提是**社会保险劳务士业务与行政书士业务各自独立、须另行签约**。本事务所不做一括受任。若继承人间有争执，或就支付有对立，将为您安排直接委托律师的方式。

## 常见问题

**Q. 未付的薪水该支付给遗属中的谁？**
A. 未付工资为继承对象，由继承人承继。继承人为1人时支付本人，复数时依法定继承分或遗产分割支付。权利者（继承人）提出请求时，须于7日内支付（劳动基准法第23条）。在未确定继承人的情况下支付会有双重支付的风险，建议先确认继承人。

**Q. 社会保险的资格丧失日，是过世当天还是次日？**
A. 健康保险・厚生年金保险的资格丧失日为死亡日的**次日**。申报（被保险者资格丧失申报）以5日内为基准。雇用保险的资格丧失申报，以不再是被保险人之日的次日起10日内为基准。

**Q. 遗属可以领取哪些给付？**
A. 依死亡原因而定。业务上的死亡为劳灾的遗属补偿给付，通勤造成的死亡为劳灾的遗属给付，另外满足要件时有遗属厚生年金・遗属基础年金等。是否业务上・通勤由劳动基准监督署认定，年金的受领资格由年金事务所判断。请求有时效，因此宜早说明。

**Q. 继承人的确定与遗产分割也可以一起委托吗？**
A. 劳务手续是社会保险劳务士、继承人确定与遗产分割相关书类是行政书士（或依司法书士・律师的业务范围）、继承人间的纠纷是律师的业务。在各自独立的事业体、须分别承接（另行签约）的前提下，可为您转介四葉行政書士事務所。本事务所不采一括受任的形式。
