**结论（先讲重点）**：自立训练（生活训练・机能训练）的人员配置，先从把指定基准（依身心障碍者综合支援法所定指定身心障碍福祉服务事业等之人员、设备及运营基准＝平成18年厚生劳动省令第171号）第156条（机能训练）、第166条（生活训练）所定员数，读成“以常勤换算须满足多少人份的勤务时间”开始设计。机能训练须将护理人员、理学疗法士等与生活支援员的**合计**，以常勤换算达**利用者数除以6以上**（同令第156条第1项第1号）；生活训练须将生活支援员以常勤换算达“通所利用者除以6”与“宿泊型自立训练利用者除以10”之**合计以上**（同令第166条第1项第1号），且各附带服务管理责任者与各职种至少1人常勤的要件。本文整理社会保险劳务士负责的常勤换算计算、社会保险与雇用保险的加入门槛、含夜间与访问的劳动时间管理、工作规则与雇用契约的范围，并将基准本身的解释与指定申请文件交由行政书士处理。

“指定基准的人数虽已满足，但在年假或研修抽离时不致低于基准的排班该怎么组”“宿泊型配置夜间支援后，劳动时间与加给工资如何计”——这是开设、运营自立训练事业所的法人、个人劳务负责人常提出的咨询。本页以自立训练的人员配置为前提，整理常勤换算、社会保险、劳动时间管理与工作规则这一劳务设计。基准本身的适合与指定申请的许否，属指定权者（都道府县、市町村、指定都市等）与申请实务的范畴，本文聚焦于劳务的思考。

## 以劳务的视角，如何解读自立训练的人员基准？

自立训练是身心障碍者综合支援法训练等给付中的生活训练与机能训练两类型。从业者的员数，依类型分别规定于指定身心障碍福祉服务之人员、设备及运营基准（平成18年厚生劳动省令第171号）的不同条文。骨架如下（细目与处理因制度改正与自治体运营而异，最终适合以指定权者的手引确认）。

| 类型 | 主要职种与配置的考量 |
|---|---|
| 机能训练（第156条第1项第1号） | 护理人员、理学疗法士、作业疗法士、言语听觉士与生活支援员的**合计**，以常勤换算达**利用者数除以6以上**。护理人员、疗法士、生活支援员各须1以上 |
| 机能训练（同条同项第2号） | 服务管理责任者：利用者60人以下为1以上；61人以上每超过40人（或其端数）加1 |
| 生活训练（第166条第1项第1号） | 生活支援员以常勤换算达“**通所利用者除以6**”与“**宿泊型自立训练利用者除以10**”之合计以上 |
| 生活训练（同条同项第2号、第3号） | 办理宿泊型时须配置地域移行支援员1以上。服务管理责任者与机能训练同 |
| 管理者 | 原则常勤、专任（于不生妨碍之范围内得兼任） |

须掌握的是，**人员基准多以“常勤换算＝勤务时间总量”而非“人头”订定**。正因如此，谁于何时入班几小时的排班方式，直接左右对基准的适合。此外，**机能训练须护理人员、生活支援员、服务管理责任者各至少1人常勤**（第156条第6项至第8项），**生活训练须生活支援员与服务管理责任者各至少1人常勤**（第166条第6项、第7项），此与雇用契约、勤务表的设计直接相关。社会保险劳务士负责的不是“配置人数”，而是“满足该人数的勤务做法”——排班设计、雇用契约、工作规则与薪资规程的整备、劳动时间管理、社会保险的资格得丧手续。基准本身的解释与指定申请文件属行政书士业务，所依法律不同。

## 常勤换算如何计算，兼职可用到什么程度？

常勤换算数是**将该事业所从业者的勤务延时数，除以常勤者应勤务的时数所得之数**。机能训练、生活训练的必要数，均以此概念作为“勤务时间总量”满足。身心障碍福祉与照护共通的常勤换算算法，整理于[身心障碍福祉、照护的常勤换算如何计算](/zh/labor/column/shogai-fukushi-kaigo-jokin-kansan-keisan-jinin)。

| 项目 | 内容 |
|---|---|
| 计算式 | 常勤换算数＝（全体职员的勤务延时数）÷（常勤者应勤务的时数） |
| 常勤应勤务时间 | 工作规则所定的所定劳动时间（例：每周40小时）。劳动基准法第32条上限为1日8小时、1周40小时 |
| 兼职（部分工时）职员 | 以实际勤务时间计入延时数；以时间、而非人头计 |
| 常勤要件 | 即使满足常勤换算，仍另有“各职种至少1人为常勤”的要件，仅凭兼职无法满足 |
| 端数、余裕 | 为使年假、缺勤、研修致延时下降时不致低于基准，宜留余裕编组 |

须注意的是，**常勤换算以勤务时间总量、而非人头来看**。每周40小时的常勤1人，与每周20小时的兼职2人，于常勤换算上同为“1”。另一方面，**常勤要件（各职种至少1人）无法以时间替代**。即使增厚兼职以满足常勤换算，未配置常勤者仍可能构成低于基准。兼职可用到何种程度，取决于“常勤换算的总量”与“常勤要件”两面，这是劳务设计的起点。

## 社会保险、雇用保险从哪些职员开始加入？

职员的社会保险（健康保险、厚生年金保险）与劳动保险（雇用保险、劳灾保险），其加入门槛由与人员基准不同的法律决定。法人事业所原则为健康保险、厚生年金保险的强制适用事业所。劳灾保险原则上涵盖所雇用的全体劳工（含兼职、工读）。

| 保险 | 主要加入门槛 |
|---|---|
| 健康保险、厚生年金保险（一般） | 每周所定劳动时间与每月所定劳动日数，达一般劳工**大致4分之3以上**者（[4分之3基准的细节](/zh/labor/column/tanjikan-koyo-shakaihoken-4bunno3)） |
| 健康保险、厚生年金保险（短时间劳工） | 在特定适用事业所（如参保人数达到51人以上的企业）等工作，每周约定工时达到20小时、预计受雇超过2个月，且原则上不具学生身份的人员。工资方面的例外见下文。 |
| 雇用保险 | 每周所定劳动时间20小时以上且有31日以上雇用见込者（雇用保险法第6条） |
| 劳灾保险 | 所雇用的劳工原则全员（手续由事业主统一办理） |

此处须注意，**短时间劳工的社会保险适用正分阶段扩大**。依厚生劳动省资料，企业规模（被保险者数）要件将由51人以上下修为36人以上（2027年10月）、21人以上（2029年10月）、11人以上（2032年10月），并于2035年10月撤废。每月约定工资须达到8.8万日元的门槛已于2026年10月1日取消。经批准适用最低工资减额特例，且每月约定工资低于8.8万日元的人员，原则上不纳入参保范围，但本人可申请加入。自立训练事业所常大量使用兼职生活支援员，故**纵使现为对象外，亦宜于开设时审视是否为日后因规模要件下修而将加入之职员**的设计。分阶段扩大的全貌，整理于[社会保险的适用扩大（2027年起）](/zh/labor/column/shakaihoken-tekiyo-kakudai-2027)。

## 含夜间支援或访问时，劳动时间管理如何设计？

宿泊型自立训练有时于夜间配置地域移行支援员等，通所的机能训练、生活训练亦有访问利用者住处进行训练的运用。劳动时间管理易生疑义之处如下。

| 论点 | 劳务上的处理 |
|---|---|
| 夜间勤务 | 午后10时至午前5时的劳动有深夜加给（劳动基准法第37条、25%以上）。只要是实际劳动即为工资对象 |
| 宿直、日直 | 若属常态几无劳动的态势，得经劳动基准监督署长许可，以宿直、日直处理（劳动基准法第41条第3号、同施行规则第23条）。未经许可而于深夜如常勤务者，为加给对象 |
| 访问的移动时间 | 处于事业所指挥命令下的移动可能构成劳动时间。于勤务表记录访问、移动、训练的区别 |
| 变形劳动时间制 | 若日、周有繁闲，以1个月单位（第32条之2）、1年单位（第32条之4）变形劳动时间制收于法定劳动时间内。选法见[变形劳动时间制与弹性工时如何选择](/zh/labor/column/henkei-roudoujikan-flextime-erabikata) |
| 休憩 | 逾6小时45分、逾8小时1小时以上（劳动基准法第34条）。休憩中若有应对义务则为手待时间，可能构成劳动时间 |

把夜勤称为“宿直”便可免加给，此种误解甚危。**宿直的许可以实态几无劳动的态势为前提**，夜间若有常态的支援业务，则作为通常劳动时间而为加给对象。团体家屋等的夜勤、宿直之区分，亦整理于[夜勤与宿直有何不同](/zh/labor/column/group-home-yakin-shukuchoku-roudou-chigai)。欲使职员从事时间外、休日劳动，须缔结并申报36协定（劳动基准法第36条），上限原则为每月45小时、每年360小时。

## 工作规则与雇用契约，开设前须先决定什么？

欲持续满足人员基准，先以工作规则、雇用契约固定勤务框架是关键。开设前宜先决定者如下。

- **工作规则的制作、申报**。经常雇用10人以上劳工的事业场有制作、申报义务（劳动基准法第89条）。未满10人亦宜就劳动时间、休日、薪资订定规则以稳定运营。从几人起，见[工作规则从几人开始须制作与申报](/zh/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)
- **劳动条件的明示**。于缔约时以书面等明示所定劳动时间、休日、薪资、有无更新等（劳动基准法第15条）。兼职生活支援员宜于契约明确计入常勤换算的实勤务时间
- **常勤、兼职的区别与常勤要件的分配**。预先决定以谁的雇用契约满足各职种至少1人常勤的要件
- **变形劳动时间制、夜间支援的规则**。宿泊型者将夜间勤务体制、有无宿直、加给工资的计算方式落实于薪资规程
- **客观记录勤务实绩的体制**。将始业、终业时刻、休憩、职务之别（兼任时）留于勤务表与打卡记录，俾日后可查核常勤换算是否满足

未付工资的消灭时效目前为3年（劳动基准法第115条、附则），加给工资计算有误时，恐遭一并请求3年份。夜间、变形劳动愈多的事业所，愈应将加给工资的设计做正确，以为防备。

## 人员的劳务与指定申请，该分别委托给谁？

自立训练的开设、运营，判断的主体各有分别。将角色切分、各自委由其专业者，较为安全。

| 要做的事 | 属谁的范畴 |
|---|---|
| 排班设计与常勤换算管理、工作规则、薪资规程、36协定、变形劳动时间制的整备、劳动时间管理、社会保险与雇用保险手续 | **社会保险劳务士**（四葉社会保険労務士事務所） |
| 人员基准的解释、自立训练的指定申请与变更申报文件、法人章程事业目的的整理 | **行政书士**（四葉行政書士事務所） |
| 物件的用途地域、构造、采光、避难、消防之适否 | 宅地建物交易业者、建筑士 |
| 所有权移转等登记、法人设立登记 | 司法书士 |
| 报酬请求相关税务 | **税理士** |
| 未付工资的请求、纷争、劳动审判、诉讼 | **律师** |

四葉社会保険労務士事務所与四葉行政書士事務所为**独立的事业体**。劳务交由社会保险劳务士、指定申请交由行政书士，须**分别承接、另行签约**（分离受任）。彼此不收授介绍费。对应人员基准的劳务见[对应人员基准的劳务](/zh/labor/services/jinin-kijun-roumu)，照护、身心障碍福祉的劳务见[照护、身心障碍福祉的劳务管理](/zh/labor/services/kaigo-roumu)。**咨询免费。** 费用请见[报酬额表](/zh/labor/ryokin)，常见问题请见[常见问答](/zh/labor/faq)。

## 常见问题

**Q. 自立训练的人员，可仅以兼职（部分工时）凑齐吗？**
A. 常勤换算的总量虽可以兼职的实勤务时间满足，但另有“各职种至少1人为常勤”的常勤要件（机能训练＝平成18年厚生劳动省令第171号第156条第6至8项、生活训练＝同令第166条第6、7项）。未配置常勤者而仅凭兼职无法满足，故须先决定以谁的雇用契约满足常勤要件。此为雇用契约与排班的设计问题，属社会保险劳务士涉及的范围。

**Q. 常勤换算以“人头”满足即可吗？**
A. 否。常勤换算以勤务时间总量来看，为全体职员的勤务延时数除以常勤者应勤务时数之数。因年假、缺勤、研修致延时下降时有低于基准之虞，故以留有余裕的排班为前提。

**Q. 宿泊型的夜间支援，以宿直处理即可免加给工资吗？**
A. 得以宿直处理者，限于实态几无劳动的态势并经劳动基准监督署长许可之情形（劳动基准法第41条第3号、同施行规则第23条）。夜间若有常态支援业务，即为通常劳动时间，午后10时至午前5时为深夜加给（同法第37条、25%以上）对象。须按实态设计。

**Q. 人员基准的适合与劳务，可委托同一人吗？**
A. 因所依法律不同，宜分开考量。人员基准的解释与指定申请文件为行政书士；排班设计、工作规则、劳动时间管理、社会保险的劳务为社会保险劳务士。于四葉，四葉行政書士事務所与四葉社会保険労務士事務所为独立的事业体，以另行签约的方式分担。
