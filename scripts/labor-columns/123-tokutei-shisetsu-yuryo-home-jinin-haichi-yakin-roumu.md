**結論（先に要点）**：介護付き有料老人ホーム（特定施設入居者生活介護）の労務は、**指定の人員基準を「常勤換算」で満たしながら、夜勤の労働時間と割増賃金を法どおりに設計する**ことが軸になります。人員基準は「指定居宅サービス等の事業の人員、設備及び運営に関する基準」（平成11年厚生省令第37号）に定められ、看護職員と介護職員の合計は要介護の利用者3人に1人以上（常勤換算）などとされています。夜間・深夜に置く職員は、実際に介助・見守りを行う**実働の夜勤**であることが通常で、このとき深夜割増（22時〜5時、25%以上）と、法定労働時間を超える分の時間外割増（労働基準法第37条）が発生します。名称を「宿直」にしても、常態としてほとんど労働の必要がないという許可基準（労働基準法第41条第3号、昭和22年9月13日発基第17号）を満たさなければ、労働時間として扱われます。この記事では、人員基準のうち社会保険労務士が関わる範囲、常勤換算の数え方、夜勤と宿直の違い、16時間夜勤の労働時間管理を整理します。

「指定の人員基準は満たしているが、夜勤の割増賃金の計算が合っているか不安」「夜勤専従を入れたいが労働時間の管理をどうするか」——介護付き有料老人ホームを開設・運営する事業者の労務担当から、よく受ける相談です。このページは、特定施設入居者生活介護の人員配置を前提に、労働時間・割増賃金・就業規則という労務の設計を整理します。指定基準そのものへの適合や指定申請の可否は指定権者（都道府県・市）と申請実務の領分で、この記事は労務の考え方に絞ります。

## 特定施設の人員基準は、どこまで社会保険労務士が関わりますか？

特定施設入居者生活介護の人員基準は、指定を受けるための要件であると同時に、**その人数を「常勤換算で満たし続ける」ための労働時間・雇用契約の設計**という労務の問題でもあります。基準の骨格は次のとおりです（一般型。数値は制度・自治体の取扱いで細目が変わるため、最終的な適合は指定権者の案内で確認します）。

| 職種 | 配置の目安（常勤換算） |
|---|---|
| 生活相談員 | 利用者100人に1人以上 |
| 看護職員・介護職員の合計 | 要介護者3人に1人以上／要支援者10人に1人以上 |
| うち看護職員 | 利用者30人まで1人、30人を超える場合は50人ごとに1人を加えた数 |
| 介護職員 | 常時1人以上（うち1人以上は常勤） |
| 機能訓練指導員 | 1人以上（兼務可） |
| 計画作成担当者 | 介護支援専門員1人以上（利用者100人に1人を標準） |
| 管理者 | 専らその職務に従事する常勤の者1人 |

このうち、社会保険労務士が担うのは**「置く人数」ではなく「その人数を満たす勤務の作り方」**です。具体的には、常勤換算を満たすシフトの設計、雇用契約・就業規則・賃金規程の整備、夜勤・時間外の労働時間管理と割増賃金の計算、社会保険の資格取得・喪失の手続です。人員基準そのものの解釈や、指定申請・変更届の書類作成は行政書士の業務で、社会保険労務士業務とは扱う法律が異なります。障害福祉の常勤換算の数え方は[障害福祉・介護の常勤換算はどう計算しますか](/labor/column/shogai-fukushi-kaigo-jokin-kansan-keisan-jinin)にも整理しています。

## 常勤換算は、どう数えてシフトに落とし込みますか？

常勤換算数は、**その事業所の従業者の勤務延べ時間数を、常勤の従業者が勤務すべき時間数で割った数**です。式にすると次のようになります。

| 項目 | 内容 |
|---|---|
| 計算式 | 常勤換算数＝（職員全員の週の勤務延べ時間数）÷（常勤が勤務すべき週の時間数） |
| 常勤の勤務時間 | 就業規則で定める所定労働時間（例：週40時間）。ただし労働基準法第32条の上限は1日8時間・1週40時間 |
| パート職員 | 実際の勤務時間で延べ時間に算入する |
| 端数の扱い | 各職種の必要数に満たない状態を作らないよう、余裕を持って組む |

注意したいのは、**常勤換算は「人数」ではなく「勤務時間の総量」で見る**という点です。週40時間の常勤1人と、週20時間のパート2人は、常勤換算では同じ「1」になります。だからこそ、有給休暇の取得・欠勤・研修参加で延べ時間が落ちると、基準割れの恐れが出ます。シフトは、法定労働時間（1日8時間・1週40時間）と時間外・休日労働の協定（労働基準法第36条＝36協定）の枠内で、余裕を持たせて組むのが安全です。就業規則は常時10人以上の事業場で作成・届出の義務があります（労働基準法第89条）。詳しくは[就業規則は何人から作成・届出が必要ですか](/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)をご覧ください。

## 夜勤と宿直は何が違い、割増賃金はどう変わりますか？

介護付き有料老人ホームの夜間配置は、実際に介助・排泄対応・見守り・記録を行う**実働の夜勤**であるのが通常です。これは労働基準法上の「労働時間」で、宿直（許可を受ければ労働時間規制の適用除外になる勤務）とは実態が違います。

| 観点 | 夜勤（実働） | 宿直（許可を受けた場合） |
|---|---|---|
| 業務の実態 | 通常の介護・見守り・記録 | 定時的巡視・緊急対応の待機など断続的業務 |
| 労働時間 | 労働時間に該当する | 労働時間・休憩・休日の規定が適用除外 |
| 深夜割増（22時〜5時） | 25%以上が必要 | 原則不要（労働時間でないため） |
| 時間外割増 | 法定超過分は25%以上が必要 | 原則不要 |
| 許可 | 不要（労働時間として管理） | 所轄労働基準監督署長の許可が必要 |

宿直として労働時間規制の適用を外すには、**常態としてほとんど労働する必要がない**という許可基準を満たし、所轄労働基準監督署長の許可を受ける必要があります（労働基準法第41条第3号、同法施行規則第23条、昭和22年9月13日発基第17号）。頻繁に介助や見守りが発生する介護施設の夜間帯は、この要件を満たしにくく、通常は宿直の許可対象になりません。したがって、夜間帯に労働させた分は深夜割増（労働基準法第37条第3項）の対象で、法定労働時間を超える分にはさらに時間外割増（同条第1項）が必要です。宿日直許可の基準は[医療・介護の宿日直許可はどんな勤務なら取れますか](/labor/column/iryo-kaigo-shukujitchoku-kyoka-kijun)に、障害グループホームの夜勤・宿直の違いは[グループホームの夜勤と宿直は労務でどう違いますか](/labor/column/group-home-yakin-shukuchoku-roudou-chigai)に整理しています。

## 夜勤専従・16時間夜勤の労働時間管理で注意する点は何ですか？

介護現場では、夕方から翌朝までの「16時間夜勤」や、夜勤だけを担う「夜勤専従」を組むことがあります。ここで押さえるべき論点は次のとおりです。

- **1日8時間・1週40時間を超える設計は、変形労働時間制で吸収する**。1か月単位（労働基準法第32条の2）や1年単位（同第32条の4）の変形労働時間制を使えば、特定の日を8時間超に設定しても、期間を平均して週40時間以内に収める形にできます。ただし1年単位を採ると、常時10人未満でも週44時間の特例は使えず週40時間で計算します
- **深夜割増は変形労働時間制でも別に必要**。変形制で法定内に収めても、22時〜5時の労働には深夜割増（25%以上）が別途かかります
- **休憩の確保**。16時間の拘束なら、労働基準法第34条により少なくとも1時間以上の休憩を、労働から解放された形で与える必要があります。「仮眠中も呼び出しに応じる義務がある」時間は手待時間として労働時間になり得ます
- **時間外・休日労働は36協定の範囲内で**。協定の上限を超える労働はさせられません（労働基準法第36条）

未払い賃金の請求権の消滅時効は、当分の間3年とされています（労働基準法第115条・附則）。夜勤の割増計算を誤ると、3年分がまとめて請求される恐れがあるため、始業・終業時刻と休憩・仮眠の実態を客観的に記録することが前提です。個別の未払い請求への対応は弁護士の業務で、この記事の範囲外です。変形労働時間制の選び方は[変形労働時間制とフレックスはどう選びますか](/labor/column/henkei-roudoujikan-flextime-erabikata)、36協定の範囲は[36協定と残業は社会保険労務士にどこまで頼めますか](/labor/column/36-kyotei-zangyo-sharoushi-doko-made)をご覧ください。

## 指定の人員基準と労務は、誰に分けて頼めばいいですか？

特定施設の開設・運営では、判断する主体が分かれます。役割を切り分けて、それぞれの専門家に頼むのが安全です。

| すること | 誰の領分か |
|---|---|
| 就業規則・賃金規程・36協定・変形労働時間制の整備、夜勤の割増賃金の計算、社会保険の手続 | **社会保険労務士**（四葉社会保険労務士事務所） |
| 人員基準の解釈・特定施設の指定申請・変更届の書類作成 | **行政書士**（四葉行政書士事務所） |
| 介護報酬の請求・税務 | 事業者・**税理士** |
| 未払い賃金の請求・紛争、労働審判・訴訟 | **弁護士** |

四葉社会保険労務士事務所と四葉行政書士事務所は、**独立した事業体**です。労務は社会保険労務士、指定申請は行政書士というように、**別々にご契約**いただく分離受任の形になります。紹介料の受け渡しはありません。人員基準の労務は[人員基準に対応する労務](/labor/services/jinin-kijun-roumu)、介護・障害福祉の労務は[介護・障害福祉の労務管理](/labor/services/kaigo-roumu)にまとめています。**ご相談は無料です。** 費用は[報酬額表](/labor/ryokin)を、よくいただくご質問は[よくあるご質問](/labor/faq)をご覧ください。

## よくある質問

**Q. 介護付き有料老人ホームの夜勤は「宿直」にして割増賃金を払わなくてよいですか？**
A. 通常はできません。宿直として労働時間規制の適用を外すには、常態としてほとんど労働の必要がない断続的業務であることについて、所轄労働基準監督署長の許可が要ります（労働基準法第41条第3号、発基第17号）。頻繁に介助・見守りが発生する介護施設の夜間帯は要件を満たしにくく、実働の夜勤として深夜割増・時間外割増の対象になるのが通常です。

**Q. 常勤換算は「頭数」で満たせばよいのですか？**
A. いいえ。常勤換算は勤務時間の総量で見ます。職員全員の勤務延べ時間数を、常勤が勤務すべき時間数で割った数です。有給休暇・欠勤・研修で延べ時間が落ちると基準割れの恐れがあるため、余裕を持ったシフト設計が前提です。

**Q. 16時間夜勤は労働基準法違反になりませんか？**
A. 直ちに違反にはなりませんが、1日8時間・1週40時間の法定労働時間を超える設計は、1か月単位や1年単位の変形労働時間制で期間を平均して週40時間以内に収める必要があります（労働基準法第32条の2・第32条の4）。深夜割増と休憩の確保、36協定の範囲内であることは別に満たします。

**Q. 人員基準の適合と労務は同じ人に頼めますか？**
A. 根拠となる法律が違うため、分けて考えます。人員基準の解釈や指定申請の書類作成は行政書士、就業規則・割増賃金・社会保険の労務は社会保険労務士です。四葉では、四葉行政書士事務所と四葉社会保険労務士事務所が独立した事業体として、別々にご契約いただく形で分担します。
