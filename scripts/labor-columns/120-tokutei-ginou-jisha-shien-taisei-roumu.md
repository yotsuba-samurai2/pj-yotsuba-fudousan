**結論（先に要点）**：特定技能1号の外国人には、受入れ企業が1号特定技能外国人支援計画を作り、義務的支援10項目を実施する義務があります。これを登録支援機関に委託せず自社で行うのが「自社支援」です。自社支援には支援体制の基準があり、過去2年間に中長期在留者（就労資格）の受入れ・生活相談などを適正に行った実績のある役職員などから、支援責任者と支援担当者（事業所ごとに1名以上）を選任し、外国人が十分理解できる言語で中立的に支援を実施できる体制が要ります（出入国管理及び難民認定法第2条の5、平成31年法務省令第5号）。支援を自社で続けられなくなったときは、登録支援機関への委託に切り替えられます。支援を回すための勤怠・賃金・就業規則・社会保険などの労務は社会保険労務士、在留諸申請の取次や支援計画の届出は行政書士（申請取次）または登録支援機関、許否の判断は出入国在留管理庁が行います（いずれも独立した事業体・別々にご契約）。

「登録支援機関に毎月払う委託料が負担なので、支援を自社でやりたい」「自社支援に切り替える要件は何か」——特定技能1号の外国人を受け入れる企業からいただく相談です。このページは、登録支援機関に委託せず自社で支援したい受入企業の労務担当に向けて、義務的支援10項目を回す体制と、その労務の整え方を整理します。在留資格の該当性や許否の見込みは、この記事の範囲外です（判断は出入国在留管理庁が行います）。

## 自社支援と登録支援機関への委託は、どちらを選びますか？

特定技能1号の受入れ機関（特定技能所属機関）には、1号特定技能外国人支援計画を作成し、そのとおりに支援を実施する義務があります。この支援を自社で行うか、登録支援機関に委託するかを選べます。支援の全部を登録支援機関に委託すれば、受入れ機関は支援体制の基準を満たすものとして扱われます。自社で行う（自社支援）には、下の表の支援体制の基準を自ら満たす必要があります。

| | 自社支援 | 登録支援機関へ全部委託 |
|---|---|---|
| 支援体制の基準 | 受入れ機関が自ら満たす | 委託により満たすものとされる |
| 委託料 | 不要（社内の人件費は要る） | 支援対象者1人あたり月額の委託料が要る |
| 実施主体 | 自社の支援責任者・支援担当者 | 登録支援機関 |
| 向く場面 | 中長期在留者の受入れ実績・多言語対応の人材がある | 実績や言語体制がまだ整っていない |

外国人を1人受け入れると、在留資格の申請、労働・社会保険の届出、住まいの確保が同時に動きます。その全体像は[外国人を1人雇うと窓口はいくつ必要か](/labor/column/gaikokujin-koyo-madoguchi-wakekata)で整理しています。分野別の労務は、介護なら[介護の特定技能外国人の労務と社会保険](/labor/column/kaigo-tokutei-ginou-gaikokujin-roumu-shakaihoken)、外食・技能実習からの移行なら[技能実習から特定技能への移行](/labor/column/ginou-jisshu-tokutei-ginou-ikou-gaishoku-shakaihoken)を参照してください。

## 義務的支援10項目を自社で回すには、どんな体制が要りますか？

義務的支援は、支援計画に必ず盛り込み、必ず実施する10項目です。任意的支援と違い、省くことはできません。自社で回すには、各項目を誰が・いつ・どの言語で行うかを社内の役割として決めておく必要があります。

| 義務的支援10項目（概要） | |
|---|---|
| ①事前ガイダンス（労働条件・活動内容・入国手続・保証金徴収の有無等の説明） | ⑥日本語学習の機会の提供 |
| ②出入国する際の送迎 | ⑦相談・苦情への対応（十分に理解できる言語で） |
| ③住居の確保・生活に必要な契約（銀行口座・携帯電話・ライフライン等）の支援 | ⑧日本人との交流促進 |
| ④生活オリエンテーション | ⑨（受入れ側の都合で雇用契約を解除する場合の）転職支援 |
| ⑤公的手続等への同行 | ⑩定期的な面談（3か月に1回以上）・行政機関への通報 |

- ③の住居の確保では、寮を用意するなら賃貸借は不動産会社が担い、その寮が労働基準法の事業附属寄宿舎に当たれば寄宿舎規則の届出も要ります（[寄宿舎規則の届出](/labor/column/gaikokujin-kishukusha-kisoku-todokede-roumu)）
- ⑦の相談・苦情対応と⑩の定期面談は、外国人が十分に理解できる言語で行える体制が前提です
- 支援の実施状況は文書に記録し、雇用契約の終了日から1年以上備え置きます

義務的支援は入管制度上の義務ですが、これを日々回す土台は、勤怠管理・賃金支払・就業規則・社会保険といった労務です。報酬は日本人が従事する場合と同等以上でなければならず、労働・社会保険の適正な加入も受入れの前提になります。

## 支援責任者・支援担当者は誰が担えますか？中立性の要件は？

自社支援では、支援責任者と支援担当者（同一人でも可・事業所ごとに1名以上）を選任します。誰でも選べるわけではなく、支援を適正に実施できる体制を示す必要があります。基準は、次のいずれかに当たる役職員から選任することです。

- イ 過去2年間に中長期在留者（就労資格に限る）の受入れ又は管理を適正に行った実績があり、役職員の中から選任していること
- ロ 役職員で、過去2年間に中長期在留者の生活相談等に従事した経験を有する者の中から選任していること
- ハ イ・ロと同程度に支援業務を適正に実施できる者を、役職員の中から選任していること

あわせて、支援責任者・支援担当者は支援計画を中立的に実施できる立場であることが求められます。運用要領は、支援対象の外国人を指揮命令・監督する立場にある者は中立的な立場にあるとはいえない、と説明しています（2026年9月参照）。定期面談で不満や法令違反を拾い上げる役割がある以上、当事者から独立した目で見られる人を置くのが趣旨です。これらの基準の細部は改定され得るため、出入国在留管理庁の特定技能運用要領で最新版を確認します。中国語圏の人材を受け入れる場合の採用・在留の労務は[中国・台湾人材の採用と在留](/labor/column/gijinkoku-chuka-taiwan-jinzai-saiyo-roumu-zairyu)でも整理しています。

## 自社支援が続けられなくなったら、どうなりますか？

支援担当者の退職や体制の変化で、自社支援の基準を満たせなくなることがあります。支援体制の基準を欠いたまま放置すると、支援計画を適正に実施できていない状態になり、次回以降の在留諸申請にも影響します。続けられなくなったら、支援の全部を登録支援機関に委託する形に切り替えられます。

- 全部委託に切り替えると、受入れ機関は支援体制の基準を満たすものとして扱われます
- 委託や支援計画の変更などに伴う出入国在留管理庁への届出・申請の取次は、行政書士（申請取次）または登録支援機関が担います
- 社会保険労務士は、体制変更に伴う勤怠・賃金・就業規則・社会保険の側の整備を担当します。いずれも独立した事業体として、別々にご契約いただきます

自社支援を選ぶかどうかは、実績と人材の有無、委託料と社内の負担を比べて決めます。始めたあとも、体制を維持できるかを定期的に見直し、難しくなったら早めに委託への切替えを検討します。

## 四葉社会保険労務士事務所は、何ができますか？

文京区小日向の四葉社会保険労務士事務所は、**特定技能1号の受入れに伴う勤怠管理・賃金（日本人と同等以上の報酬）の設計、就業規則の整備、労働・社会保険の適用手続、定期面談を含む労務記録の整え方、体制変更時の労務対応**をお受けします。1号特定技能外国人支援計画の作成・届出や在留諸申請の取次は行政書士（申請取次）または登録支援機関、在留の許否の判断は出入国在留管理庁が担い、いずれも当事務所とは独立した事業体として、別々にご契約いただきます。当事務所は労務管理の面を担当します。**ご相談は無料です。** 費用は[報酬額表](/labor/ryokin)を、よくいただくご質問は[よくあるご質問](/labor/faq)をご覧ください。

## よくある質問

**Q. 登録支援機関に委託せず、自社支援に切り替えたいのですが、資格は要りますか？**
A. 特別な資格は要りませんが、支援体制の基準を満たす必要があります。過去2年間に中長期在留者（就労資格）の受入れ・管理や生活相談を適正に行った実績のある役職員などから、支援責任者と支援担当者を選任し、外国人が十分理解できる言語で中立的に支援を実施できる体制が求められます（平成31年法務省令第5号）。実績や言語体制が整っていない場合は、登録支援機関への委託が現実的です。

**Q. 義務的支援の10項目は、一部だけ自社でやって残りを委託できますか？**
A. 支援は原則として全体を一体で実施します。支援の全部を登録支援機関に委託すれば受入れ機関は支援体制の基準を満たすものとして扱われますが、一部委託の可否や範囲は運用要領の定めによります。実施できない項目が出ると支援計画の適正実施を欠くため、体制に不安があるなら全部委託を検討します。最新の取扱いは出入国在留管理庁の運用要領で確認します。

**Q. 支援担当者は、その外国人の直属の上司でもよいですか？**
A. 運用要領は、支援対象の外国人を指揮命令・監督する立場にある者は中立的な立場にあるとはいえないと説明しています。定期面談で不満や法令違反を拾う役割がある以上、当事者から独立した目で見られる人を置くのが趣旨です。直属の上司しかいない小規模な体制では、中立性を保てるかを確認したうえで選任します。

**Q. 支援担当者が辞めて自社支援を続けられません。どうすればよいですか？**
A. 支援の全部を登録支援機関に委託する形に切り替えられます。切り替えると受入れ機関は支援体制の基準を満たすものとして扱われます。委託や支援計画の変更に伴う出入国在留管理庁への届出・申請の取次は行政書士（申請取次）または登録支援機関が担い、勤怠・賃金・社会保険など労務の側の整備は社会保険労務士が担当します（いずれも独立した事業体・別々にご契約）。
