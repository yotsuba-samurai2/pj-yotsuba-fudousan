**結論（先に要点）**：労働基準監督署の調査（臨検監督）が入ったら、求められた帳簿・書類を示し、是正勧告書や指導票を受けたら期限までに是正して是正報告書を出すのが基本の流れです。臨検や帳簿提出は労働基準法第101条に基づく監督官の権限で、拒否や虚偽記載は第120条の罰則の対象です。ふだんから法定三帳簿・36協定・就業規則を整えておくことが、調査で困らない最大の備えになります。

## 労働基準監督署の調査（臨検）にはどんな種類があり、なぜ来るのか？

労働基準監督署の調査は「臨検監督」と呼ばれ、労働基準監督官が事業場に立ち入って帳簿や労働実態を確認するものです。根拠は労働基準法第101条で、監督官は事業場・寄宿舎その他の附属建設物に臨検し、帳簿及び書類の提出を求め、使用者または労働者に尋問を行うことができます（その際、身分を証明する証票を携帯します）。調査は、厚生労働省・都道府県労働局の運用上、おおむね次のように分けられています。

| 種類 | きっかけ |
|---|---|
| 定期監督 | 年間計画に基づき対象を選んで行う通常の監督 |
| 申告監督 | 労働者からの申告（第104条）を受けて行う監督 |
| 災害時監督 | 労働災害が発生したときに原因究明・再発防止のために行う監督 |
| 再監督 | 過去の是正勧告への対応を確認するために行う監督 |

労働者は、事業場に法令違反の事実があるとき、その事実を行政官庁または労働基準監督官に申告でき、使用者は申告したことを理由に解雇その他不利益な取扱いをしてはなりません（第104条）。つまり「なぜ来たのか」は、計画的な定期監督のこともあれば、従業員の申告や労災の発生がきっかけのこともあります（調査の分類は厚生労働省・労働局の運用で、2026年11月12日参照）。

## 当日、何を見られ、どんな帳簿・書類を求められるのか？

臨検では、労働時間・賃金・安全衛生の実態が、帳簿と突き合わせて確認されます。中心になるのは、法令で作成・保存が義務づけられた書類です。

| 書類 | 根拠 |
|---|---|
| 労働者名簿 | 労働基準法第107条 |
| 賃金台帳 | 第108条 |
| 出勤簿・タイムカード等の労働時間の記録 | 労働時間把握の資料（第108条の賃金計算の基礎） |
| 時間外・休日労働に関する協定届（36協定） | 第36条 |
| 就業規則（常時10人以上の事業場） | 第89条 |
| 健康診断の記録・安全衛生関係の書類 | 労働安全衛生法ほか |

労働者名簿・賃金台帳・出勤簿はいわゆる法定三帳簿で、整備と一定期間の保存が義務です（詳しくは[法定三帳簿の整備と保存](/labor/column/hotei-san-choubo-seibi-hozon)）。労働安全衛生法第91条にも監督官の立入検査・質問・物件検査の権限があり、安全衛生面もあわせて確認されることがあります。求められた帳簿書類の提出を拒んだり、虚偽の記載をした帳簿書類を提出したりすると、労働基準法第120条第4号により30万円以下の罰金の対象になります。当日は、求められた書類を速やかに示し、分からない点は確認して後日回答するのが基本です。

## 「是正勧告」と「指導票」は何が違い、放置するとどうなるのか？

調査の結果として交付される書面には、主に是正勧告書と指導票があります。いずれも法律上の明文がある「処分」ではなく、行政指導として交付される文書です。

| 書面 | 交付される場面 | 位置づけ |
|---|---|---|
| 是正勧告書 | 法令違反が認められたとき | 違反事項・是正の内容・是正期限が示される行政指導 |
| 指導票 | 法令違反とまではいえないが改善が望ましいとき | 改善事項を示す行政指導 |

是正勧告書も指導票も行政指導であり、それ自体は不服申立ての対象となる行政処分ではありません。ただし放置すれば、再監督が行われ、悪質・重大なケースでは後述の送検や企業名の公表に至ることがあります。労働安全衛生法に基づき、労働災害の危険が切迫している場合などに機械・設備の使用停止等を命じる処分（使用停止命令）が出ることもあり、これは行政処分です。交付を受けたら、指摘の根拠条文と是正期限を確認し、何をいつまでに直すかを整理することが出発点になります。

## 是正報告書はいつまでに・どう書くのか？未払残業が見つかったら？

是正勧告書や指導票を受けたら、指定された期限までに是正し、是正（改善）報告書を提出します。報告書には、指摘された事項ごとに、何をどう是正したか（または是正の計画と時期）を具体的に書きます。

| 進め方 | 内容 |
|---|---|
| 指摘の整理 | 指摘事項・根拠条文・是正期限を一覧化 |
| 事実確認 | 労働時間・賃金の実態を帳簿と突き合わせて確認 |
| 是正の実施 | 規程の改定、運用の見直し、不足分の支払い等 |
| 報告書の作成 | 事項ごとに是正内容・時期を記載して期限内に提出 |

典型的な指摘が、未払いの割増賃金（残業代）です。労働時間の記録と賃金台帳が食い違っていれば、不足分をさかのぼって支払うよう求められることがあります。固定残業代（みなし残業代）を採用している場合は、その要件を満たしているか、超過分を別途支払っているかが確認されます（[固定残業代が適法になる要件と差額精算](/labor/column/kotei-zangyodai-tekiho-youken-sagaku-seisan)）。期限内の是正が難しいときは、放置せず、是正の計画と見込み時期を示して相談するのが筋です。是正報告書の作成支援や労働時間・賃金の実態整理は社会保険労務士の領域です。ご相談いただく場合の費用は[報酬額表](/labor/ryokin)にまとめています。

## 送検・企業名公表に至るのはどんな場合か？

多くの事案は是正報告で終わりますが、悪質・重大なケースは刑事手続に進むことがあります。労働基準監督官は、労働基準法違反の罪について、刑事訴訟法に規定する司法警察官の職務を行います（第102条）。つまり監督官は、一定の場合に捜査を行い、検察官へ送致（送検）する権限を持ちます。

| 段階 | 概要 |
|---|---|
| 是正勧告・指導 | 行政指導。期限内の是正で終了するのが通常 |
| 再監督 | 是正状況の確認。未是正なら繰り返される |
| 送検 | 悪質・重大な違反で、第102条に基づき検察官へ送致 |
| 企業名公表 | 違法な長時間労働や送検事案などについて、厚生労働省の運用で企業名が公表されることがある |

送検や企業名公表に至るのは、是正勧告を繰り返し無視した、重大な労働災害を隠した、虚偽の帳簿を示したといった悪質・重大なケースが中心です（企業名公表は厚生労働省の運用に基づくもので、2026年11月12日参照）。送検後の刑事手続や、行政指導・処分への対応をめぐる法的な争い、未払賃金をめぐる訴訟は、弁護士の領域です。どこからが社会保険労務士でどこからが弁護士かは[解雇対応は社労士か弁護士か](/labor/column/kaiko-sharoushi-bengoshi-dochira)の切り分けも参考になります。これらは社会保険労務士事務所とは独立した事業体として、別々にご契約いただく前提で分けます。紹介料はありません。

## ふだんから何を整えておけば調査で困らないのか？

調査で困らない最大の備えは、ふだんの労務管理です。臨検で中心になる書類を平時から整えておけば、調査が入っても慌てずに対応できます。

| 整えるもの | ポイント |
|---|---|
| 法定三帳簿 | 労働者名簿・賃金台帳・出勤簿を作成し、保存期間を守る |
| 労働時間の記録 | タイムカード等で客観的に把握し、賃金計算と一致させる |
| 36協定 | 時間外・休日労働の前に締結・届出。上限規制の範囲内で運用 |
| 就業規則 | 常時10人以上なら作成・届出。実態と一致させる |
| 割増賃金 | 残業代の計算方法を点検。固定残業代は要件と差額精算を確認 |

36協定の締結・届出と上限規制の運用は[36協定はどこまで社労士に頼めるか](/labor/column/36-kyotei-zangyo-sharoushi-doko-made)、就業規則の作成義務と中身は[就業規則の作成義務と中身](/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)に整理しています。これらを平時に整え、記録を残しておくことが、調査への最良の備えになります。帳簿・協定・就業規則の整備や、調査が入ったときの是正報告書の作成支援は社会保険労務士の領域です。よくいただくご質問は[よくあるご質問](/labor/faq)にまとめています。

## よくある質問

**Q. 労働基準監督署の調査は、断ることができますか？**
A. 正当な理由なく拒むことはできません。労働基準法第101条は、労働基準監督官が事業場に臨検し、帳簿及び書類の提出を求め、使用者・労働者に尋問できると定めています。臨検を拒み・妨げ・忌避したり、尋問に陳述しなかったり、帳簿書類を提出しなかったり、虚偽の記載をした帳簿書類を提出したりすると、第120条第4号により30万円以下の罰金の対象になります。日程の調整などは相談できますが、調査自体を拒否するのは適切ではありません。

**Q. 是正勧告書は行政処分ですか？不服があれば争えますか？**
A. 是正勧告書も指導票も、法律上の明文がある行政処分ではなく、行政指導として交付される文書です。そのため、それ自体を処分の取消しとして争う対象にはなりません。ただし指摘の根拠や事実認定に疑問がある場合は、根拠条文と事実を確認したうえで、監督署に説明・協議することになります。送検や行政処分、未払賃金をめぐる訴訟といった法的な争いの段階は、弁護士の領域です。

**Q. 調査で未払残業が見つかったら、どこまでさかのぼって払うのですか？**
A. 不足している割増賃金の清算を求められることが一般的です。さかのぼる範囲や計算方法は、労働時間の記録と賃金台帳に基づいて確認します。固定残業代を採用している場合は、その要件を満たしているか、超過分を別途支払っているかが確認されます。金額や時効の個別判断は事案によって異なるため、労働時間・賃金の実態を帳簿と突き合わせて整理し、必要に応じて社会保険労務士に相談するとよいでしょう。未払賃金をめぐって訴訟など法的紛争に発展する場合は弁護士の領域です。

**Q. 税務署の調査と労働基準監督署の調査は同じものですか？**
A. 別のものです。労働基準監督署の調査（臨検監督）は、労働基準法・労働安全衛生法などの労働関係法令の履行を確認するもので、労働時間・賃金・安全衛生が対象です。税金の申告・納付を確認する税務調査は税務署が行い、税理士の領域です。両者は根拠法令も担当機関も異なるため、それぞれ独立した事業体・機関として別々にご相談ください。
