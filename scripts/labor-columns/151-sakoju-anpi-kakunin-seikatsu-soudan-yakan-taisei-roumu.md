**結論（先に要点）**：サービス付き高齢者向け住宅（サ高住）の労務は、**「状況把握（安否確認）・生活相談サービスを担う職員を日中どう常駐させるか」と「夜間に職員を置くなら宿直か夜勤か」を、労働時間と賃金の設計として組む**ことが軸になります。一般型のサ高住は、介護付き有料老人ホーム（特定施設）のような介護保険の人員配置基準（要介護者3人に1人以上を常勤換算）を持ちません。登録基準で求められるのは、状況把握・生活相談を担う職員が原則として日中（おおむね9時〜17時が想定）常駐することで、夜間に職員を常駐させるかは登録基準では必須とされず、常駐しない時間帯は各居住部分の緊急通報装置で対応する扱いが一般的です（高齢者の居住の安定確保に関する法律＝平成13年法律第26号 第5条・第7条、同法施行規則ほか）。夜間に職員を置く場合、その勤務が実働の夜勤か、常態としてほとんど労働の必要がない宿直かで、深夜割増・時間外割増の要否が変わります。この記事では、特定施設との職員配置の違い、安否確認・生活相談の担い手、夜間の宿直と夜勤の区別、社会保険の加入、外部の訪問介護との労務の切り分けを、社会保険労務士の業務範囲で整理します。

「サ高住を開業したいが、職員は何人、どんな資格の人を置けばいいのか」「夜間は1人でよいと聞いたが、その人の勤務は宿直にできるのか」——サ高住を開業・運営する事業者からよく受ける相談です。このページは、一般型のサ高住を前提に、状況把握・生活相談の人員と夜間体制を、労働時間・割増賃金・社会保険という労務の設計として整理します。サ高住の登録そのものの可否や登録基準への適合は、登録権者（都道府県・政令市・中核市）と登録申請実務の領分で、この記事は労務の考え方に絞ります。

## サ高住と有料老人ホーム（特定施設）で、職員の置き方はどう違うのですか？

まず押さえるのは、サ高住（一般型）と介護付き有料老人ホーム（特定施設入居者生活介護）では、**そもそも適用される人員基準の法律が違う**という点です。

| | サ高住（一般型） | 介護付き有料老人ホーム（特定施設） |
|---|---|---|
| 根拠 | 高齢者の居住の安定確保に関する法律の登録基準 | 介護保険法に基づく指定基準（平成11年厚生省令第37号） |
| 置く職員 | 状況把握・生活相談を担う職員 | 看護職員・介護職員・生活相談員・機能訓練指導員ほか |
| 介護の人員基準 | なし（介護は外部サービスを利用） | 要介護者3人に1人以上（常勤換算） |
| 介護の提供主体 | 入居者が契約する外部の介護事業者 | 施設（特定施設の指定を受けた事業者） |
| 夜間の職員常駐 | 登録基準では必須でない（緊急通報装置で対応可） | 指定基準で夜勤職員の配置が求められる |

特定施設は、施設自身が介護保険の給付対象サービスを提供するため、常勤換算での人員配置が指定の要件になります。一方、一般型のサ高住は「住まい＋見守り（状況把握・生活相談）」が本体で、介護は入居者が外部の訪問介護などと別に契約して受けます。したがって、サ高住の運営者が登録基準として置くのは介護職員ではなく、状況把握・生活相談を担う職員です。特定施設の夜勤・人員の労務は[介護付き有料老人ホームの人員基準と夜勤の労務はどう設計しますか](/labor/column/tokutei-shisetsu-yuryo-home-jinin-haichi-yakin-roumu)に整理しています。**自社がどちらの類型かで、置く職員も労働時間の設計も変わります。**

## 安否確認・生活相談サービスは誰が担うのですか？（資格・常駐）

サ高住の登録基準では、状況把握（安否確認）サービスと生活相談サービスを提供することが求められます。これを担うのは、いわゆる「ケアの専門家」で、具体的には次のような有資格者（または所定の研修を修了した者）が想定されています。

| 項目 | 内容 |
|---|---|
| 担い手 | 医師・看護師・准看護師・介護福祉士・社会福祉士・介護支援専門員・一定の研修修了者など（登録権者の運用で範囲が示される） |
| 常駐の時間帯 | 原則として日中。おおむね9時〜17時が想定 |
| 常駐の場所 | 住宅の敷地内または隣接する敷地内の建物 |
| 状況把握の方法 | 毎日1回以上、居室への訪問その他適切な方法（訪問・電話・安否確認装置など） |
| 夜間など職員がいない時間帯 | 各居住部分に設置した緊急通報装置で対応 |

労務の観点で大事なのは、**この常駐職員を「どんな雇用契約・勤務シフトで日中確実に置くか」**です。常駐は人がいて初めて成り立つため、有給休暇・欠勤・研修で日中の常駐が空かないよう、シフトに余裕を持たせて組む必要があります。常駐要件は2022年9月以降、一定の条件を満たせば緩和される場合があるとされますが、緩和の具体的な条件は登録権者（自治体）の運用で異なるため、本記事では細目を未検証として断定を避けます。就業規則は常時10人以上の労働者を使用する事業場で作成・届出の義務があります（労働基準法第89条）。詳しくは[就業規則は何人から作成・届出が必要ですか](/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)をご覧ください。

## 夜間はどんな体制が要るのですか？宿直と夜勤はどう違うのですか？

一般型のサ高住では、夜間に職員を常駐させることは登録基準上の必須ではなく、常駐しない時間帯は緊急通報装置で対応する扱いが一般的です。ただし、入居者の安心のために夜間も職員を置く事業者は多く、**そのときに「宿直」と「夜勤」のどちらで組むかが労務の分かれ目**になります。

| 観点 | 夜勤（実働） | 宿直（許可を受けた場合） |
|---|---|---|
| 業務の実態 | 通常の見守り・緊急対応・記録など継続的業務 | 定時的巡視・緊急時の待機など断続的業務 |
| 労働時間 | 労働時間に該当する | 労働時間・休憩・休日の規定が適用除外 |
| 深夜割増（22時〜5時） | 25%以上が必要 | 原則不要（労働時間でないため） |
| 時間外割増 | 法定超過分は25%以上が必要 | 原則不要 |
| 許可 | 不要（労働時間として管理） | 所轄労働基準監督署長の許可が必要 |

宿直として労働時間規制の適用を外すには、**常態としてほとんど労働する必要がない**断続的業務であることについて、所轄労働基準監督署長の許可を受ける必要があります（労働基準法第41条第3号、同法施行規則第23条、昭和22年9月13日発基第17号）。緊急通報への対応が時折あるだけで、職員が夜間に十分な睡眠時間を確保できる体制なら宿直の許可対象になり得ますが、頻繁に見守りや介助が発生する実態なら夜勤として扱われ、深夜割増（労働基準法第37条第3項）、法定労働時間を超える分には時間外割増（同条第1項）が必要です。呼び名を「宿直」にしても、実態で判断される点は介護施設と同じです。宿日直許可の基準は[医療・介護の宿日直許可はどんな勤務なら取れますか](/labor/column/iryo-kaigo-shukujitchoku-kyoka-kijun)に、障害グループホームの夜勤・宿直の違いは[グループホームの夜勤と宿直は労務でどう違いますか](/labor/column/group-home-yakin-shukuchoku-roudou-chigai)に整理しています。**仮眠中でも緊急通報に応じる義務がある時間は、手待時間として労働時間になり得ます。**

## 社会保険・労働保険はどう加入するのですか？

サ高住の運営者が従業員を雇えば、社会保険（健康保険・厚生年金保険）と労働保険（労災保険・雇用保険）の加入が問題になります。

- **労災保険**：労働者を1人でも雇えば、業種・規模を問わず適用されます。パート・アルバイトも区別なく対象です
- **雇用保険**：1週間の所定労働時間が20時間以上で、31日以上の雇用見込みがある労働者が被保険者になります（適用範囲は段階的に拡大予定のため、最新の施行時期を確認します）
- **健康保険・厚生年金保険**：法人の事業所は強制適用、個人事業は常時5人以上を使用する一定業種で強制適用です。パート・短時間労働者も、週の所定労働時間・所定労働日数が通常の労働者の4分の3以上なら加入し、4分の3未満でも企業規模などの要件を満たせば加入します

夜勤や変形労働時間制で勤務時間が月ごとに変動する場合、標準報酬月額の算定や随時改定（月額変更届）の判断を誤りやすいので、賃金規程と勤怠記録を整えておくことが前提です。短時間労働者の社会保険の線引きは[短時間労働者の社会保険は4分の3でどう決まりますか](/labor/column/tanjikan-koyo-shakaihoken-4bunno3)に整理しています。保険料の計算や資格取得・喪失の手続は社会保険労務士の業務です。

## 外部の訪問介護を使うとき、労務はどう切り分けるのですか？

一般型のサ高住では、入居者への介護は外部の訪問介護などが担います。ここで労務上わかれるのは、**「サ高住の運営者が雇う職員」と「訪問介護事業所が雇うヘルパー」は、別の事業体の労務として扱う**という点です。

| すること | 誰の労務か |
|---|---|
| サ高住の状況把握・生活相談の職員、夜間体制の設計 | サ高住の運営者（＝本記事の主体） |
| 入居者に介護を提供するヘルパーの労働時間・移動時間・賃金 | 訪問介護事業所（運営者と同一法人が併設する場合も、事業所単位で別に設計） |

同一法人が併設の訪問介護事業所を運営することは多く、その場合は訪問介護の人員基準（常勤換算）とヘルパーの移動時間・待機時間の労働時間管理が、サ高住本体とは別に発生します。訪問介護特有の移動時間の労働時間性は[訪問介護の移動時間は労働時間に入りますか](/labor/column/homon-kaigo-idou-jikan-roudou-jikan)に整理しています。**「同じ建物で働く人」でも、どの事業所に雇われているかで労働時間と賃金の設計は別になります。**

## 誰に何を分けて頼めばいいのですか？

サ高住の開業・運営では、判断する主体が分かれます。役割を切り分けて、それぞれの専門家に頼むのが安全です。

| すること | 誰の領分か |
|---|---|
| 就業規則・賃金規程・36協定・変形労働時間制の整備、夜間体制の宿直・夜勤の設計、割増賃金の計算、社会保険・労働保険の手続 | **社会保険労務士**（四葉社会保険労務士事務所） |
| サ高住の登録申請・変更の届出、外部介護サービスの指定申請などの官公署へ提出する書類 | **行政書士**（四葉行政書士事務所） |
| 建物のバリアフリー・用途・面積の設計 | **建築士** |
| 介護報酬の請求・税務 | 事業者・**税理士** |
| 未払い賃金の請求・紛争、労働審判・訴訟 | **弁護士** |

四葉社会保険労務士事務所と四葉行政書士事務所は、**独立した事業体**です。労務は社会保険労務士、登録申請・指定申請は行政書士というように、**別々にご契約**いただく分離受任の形になります。紹介料の受け渡しはありません。人員基準に対応する労務は[人員基準に対応する労務](/labor/services/jinin-kijun-roumu)、介護・障害福祉の労務管理は[介護・障害福祉の労務管理](/labor/services/kaigo-roumu)にまとめています。**ご相談は無料です。** 費用は[報酬額表](/labor/ryokin)を、よくいただくご質問は[よくあるご質問](/labor/faq)をご覧ください。

## よくある質問

**Q. サ高住は、介護付き有料老人ホームと同じ人員基準（3対1）で職員を置く必要がありますか？**
A. 一般型のサ高住には、介護保険の人員配置基準（要介護者3人に1人以上を常勤換算）は適用されません。サ高住で置くのは状況把握・生活相談を担う職員で、原則として日中（おおむね9時〜17時）常駐します。要介護者3人に1人という基準は、施設が自ら介護を提供する特定施設（介護付き有料老人ホーム）の指定基準です。

**Q. 夜間は職員1人でよいと聞きました。その人は「宿直」にできますか？**
A. 実態によります。常態としてほとんど労働の必要がなく、夜間に十分な睡眠時間を確保できる断続的業務なら、所轄労働基準監督署長の許可を受けて宿直にできる場合があります（労働基準法第41条第3号）。一方、頻繁に見守りや緊急対応が発生するなら夜勤として扱われ、深夜割増・時間外割増の対象です。呼び名ではなく実態で判断されます。

**Q. 状況把握・生活相談の職員は、無資格でもよいですか？**
A. 登録基準では、医師・看護師・介護福祉士・社会福祉士・介護支援専門員などの有資格者、または所定の研修を修了した者が担うことが想定されています。具体的にどの資格・研修が認められるかは登録権者（自治体）の運用で示されるため、登録申請の前に確認します。

**Q. サ高住に併設する訪問介護のヘルパーの労務も、同じ契約でまとめて頼めますか？**
A. 事業所の単位が違うため、分けて考えます。サ高住の状況把握・生活相談の職員と、訪問介護事業所のヘルパーは、同一法人でも別の事業所の労務として、人員基準・移動時間・賃金を別に設計します。就業規則や賃金規程も事業所の実態に合わせて整えます。
