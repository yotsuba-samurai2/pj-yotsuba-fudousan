**結論（先に要点）**：自立訓練（生活訓練・機能訓練）の人員配置は、指定基準（障害者総合支援法に基づく指定障害福祉サービスの事業等の人員、設備及び運営に関する基準＝平成18年厚生労働省令第171号）第156条（機能訓練）・第166条（生活訓練）が定める員数を、「常勤換算で何人分の勤務時間を満たすか」で読み替えるところから設計します。機能訓練は看護職員・理学療法士等・生活支援員の総数を常勤換算で利用者数を6で除した数以上（同令第156条第1項第1号）、生活訓練は生活支援員を常勤換算で通所利用者数を6で除した数と宿泊型利用者数を10で除した数の合計以上（同令第166条第1項第1号）とされ、いずれもサービス管理責任者と常勤要件が付きます。この記事では、この人員基準を労務＝常勤換算の数え方、社会保険・雇用保険の加入ライン、夜間・訪問を含む労働時間管理、就業規則・雇用契約に落とす範囲を整理し、指定基準そのものの解釈や指定申請の書類作成は行政書士に分ける切り分けまで示します。

「指定基準の人数は満たしているが、有給や研修で抜けたときに割れないシフトをどう組むか」「宿泊型で夜間支援を置くと、労働時間と割増賃金はどうなるのか」——自立訓練の事業所を開設・運営する法人・個人の労務担当から、よく受ける相談です。このページは、自立訓練の人員配置を前提に、常勤換算・社会保険・労働時間管理・就業規則という労務の設計を整理します。指定基準そのものへの適合や指定申請の可否は指定権者（都道府県・市町村・指定都市等）と申請実務の領分で、この記事は労務の考え方に絞ります。

## 自立訓練の人員基準を、労務の視点ではどう読み替えますか？

自立訓練は、障害者総合支援法の訓練等給付のうち、生活訓練と機能訓練の2類型です。従業者の員数は、指定障害福祉サービスの人員・設備・運営基準（平成18年厚生労働省令第171号）に、類型ごとに別の条文で定められています。骨格は次のとおりです（細目・取扱いは制度改正と自治体の運用で変わるため、最終的な適合は指定権者の手引きで確認します）。

| 類型 | 主な職種と配置の考え方 |
|---|---|
| 機能訓練（第156条第1項第1号） | 看護職員・理学療法士・作業療法士・言語聴覚士・生活支援員の**総数**を、常勤換算方法で**利用者の数を6で除した数以上**。看護職員、理学療法士等、生活支援員はそれぞれ事業所ごとに1以上 |
| 機能訓練（同条同項第2号） | サービス管理責任者を、利用者60人以下は1以上、61人以上は60人を超えて40人ごとに1を加えた数以上 |
| 生活訓練（第166条第1項第1号） | 生活支援員を、常勤換算で**通所の利用者数を6で除した数**と**宿泊型自立訓練の利用者数を10で除した数**の合計数以上 |
| 生活訓練（同条同項第2号・第3号） | 宿泊型を行う場合は地域移行支援員を1以上。サービス管理責任者は機能訓練と同じ考え方 |
| 管理者 | 原則として常勤・専従（支障がない範囲で兼務できる場合がある） |

ここで押さえたいのは、**人員基準の多くが「頭数」ではなく「常勤換算＝勤務時間の総量」で定められている**という点です。だからこそ、誰がいつ何時間入るかというシフトの作り方が、そのまま基準への適合を左右します。あわせて、**機能訓練では看護職員・生活支援員・サービス管理責任者のうち各1人以上が常勤**（第156条第6項〜第8項）、**生活訓練では生活支援員とサービス管理責任者のうち各1人以上が常勤**（第166条第6項・第7項）という常勤要件があり、これは雇用契約と勤務表の設計に直結します。社会保険労務士が担うのは「置く人数」ではなく「その人数を満たす勤務の作り方」——シフト設計、雇用契約・就業規則・賃金規程の整備、労働時間管理、社会保険の資格得喪の手続です。基準そのものの解釈や指定申請の書類作成は行政書士の業務で、扱う法律が異なります。

## 常勤換算はどう数え、非常勤はどこまで使えますか？

常勤換算数は、**その事業所の従業者の勤務延べ時間数を、常勤の従業者が勤務すべき時間数で割った数**です。機能訓練・生活訓練の必要数は、この考え方で「勤務時間の総量」として満たします。障害福祉・介護に共通する常勤換算の数え方は[障害福祉・介護の常勤換算はどう計算しますか](/labor/column/shogai-fukushi-kaigo-jokin-kansan-keisan-jinin)に整理しています。

| 項目 | 内容 |
|---|---|
| 計算式 | 常勤換算数＝（職員全員の勤務延べ時間数）÷（常勤が勤務すべき時間数） |
| 常勤が勤務すべき時間 | 就業規則で定める所定労働時間（例：週40時間）。労働基準法第32条の上限は1日8時間・1週40時間 |
| 非常勤（パート）職員 | 実際の勤務時間で延べ時間に算入する。頭数ではなく時間で効く |
| 常勤要件 | 常勤換算を満たしても、別途「各職種1人以上は常勤」の要件があり、非常勤だけでは満たせない |
| 端数・余裕 | 有給・欠勤・研修で延べ時間が落ちても割れないよう、余裕を持って組む |

注意したいのは、**常勤換算は人数ではなく勤務時間の総量で見る**という点です。週40時間の常勤1人と、週20時間の非常勤2人は常勤換算では同じ「1」です。一方で、**常勤要件（各職種1人以上）は時間で代替できません**。非常勤を厚くして常勤換算を満たしても、常勤者を置いていなければ基準割れになり得ます。非常勤をどこまで使えるかは「常勤換算の総量」と「常勤要件」の両面で決まる、というのが労務設計の出発点です。

## 社会保険・雇用保険は、どの職員から加入になりますか？

職員の社会保険（健康保険・厚生年金保険）と労働保険（雇用保険・労災保険）は、人員基準とは別の法律で加入ラインが決まります。法人の事業所は原則として健康保険・厚生年金保険の強制適用事業所です。労災保険は、雇用する労働者であれば原則として全員が対象になります（パート・アルバイトを含む）。

| 保険 | 加入になる主なライン |
|---|---|
| 健康保険・厚生年金保険（一般） | 週の所定労働時間・月の所定労働日数が、通常の労働者の**おおむね4分の3以上**の者（[4分の3基準の詳細](/labor/column/tanjikan-koyo-shakaihoken-4bunno3)） |
| 健康保険・厚生年金保険（短時間労働者） | 特定適用事業所（被保険者数51人以上の企業等）などで、週の所定労働時間が20時間以上、2か月を超える雇用の見込みがあり、原則として学生でない人。賃金に関する例外は本文参照 |
| 雇用保険 | 週の所定労働時間20時間以上かつ31日以上の雇用見込みがある者（雇用保険法第6条） |
| 労災保険 | 雇用する労働者は原則として全員（手続は事業主がまとめて行う） |

ここで、**短時間労働者の社会保険適用は段階的に広がっていく**点に注意します。厚生労働省の資料によると、企業規模（被保険者数）要件は51人以上から36人以上（2027年10月）・21人以上（2029年10月）・11人以上（2032年10月）へ下がり、2035年10月に撤廃される予定です。所定内賃金が月8.8万円以上という要件は、2026年10月1日に撤廃されました。ただし、最低賃金の減額に関する特例許可を受け、所定内賃金が月8.8万円未満の人は原則対象外です。本人の申出により加入できます。自立訓練の事業所は非常勤の生活支援員を多く使うことがあり、**今は対象外でも、規模要件の引下げで将来加入になる職員が出る**設計かどうかを、開設時に見ておくのが安全です。段階引上げの全体像は[社会保険の適用拡大（2027年〜）](/labor/column/shakaihoken-tekiyo-kakudai-2027)に整理しています。

## 夜間支援や訪問を含むとき、労働時間管理はどう設計しますか？

宿泊型自立訓練では夜間に地域移行支援員等を置くことがあり、通所の機能訓練・生活訓練でも利用者宅を訪問して訓練を行う運用があります。労働時間管理でつまずきやすいのは次の点です。

| 論点 | 労務での扱い |
|---|---|
| 夜間の勤務 | 午後10時〜午前5時の労働には深夜割増（労働基準法第37条・25%以上）。実労働である限り賃金の対象 |
| 宿直・日直 | 常態的にほとんど労働がない態勢なら、労働基準監督署長の許可を受けて宿直・日直として扱える場合がある（労働基準法第41条第3号・同施行規則第23条）。許可なく通常勤務として深夜に働かせれば割増の対象 |
| 訪問の移動時間 | 事業所の指揮命令下にある移動は労働時間になり得る。勤務表で訪問・移動・訓練の別を記録する |
| 変形労働時間制 | 日や週で繁閑があるなら、1か月単位（第32条の2）・1年単位（第32条の4）の変形労働時間制で、法定労働時間の枠内に収める。選び方は[変形労働時間制とフレックスはどう選びますか](/labor/column/henkei-roudoujikan-flextime-erabikata) |
| 休憩 | 6時間超で45分、8時間超で1時間以上（労働基準法第34条）。休憩中に対応義務があれば手待時間として労働時間になり得る |

夜勤を「宿直」と呼べば割増が要らなくなる、という誤解は危険です。**宿直の許可は、実態がほとんど労働のない態勢であることが前提**で、夜間に支援業務が常態的にあれば通常の労働時間として割増の対象になります。グループホーム等の夜勤・宿直の切り分けは[夜勤と宿直はどう違いますか](/labor/column/group-home-yakin-shukuchoku-roudou-chigai)にも整理しています。時間外・休日労働をさせるには36協定の締結・届出が必要で（労働基準法第36条）、上限は原則月45時間・年360時間です。

## 就業規則と雇用契約で、開設前に決めておくことは何ですか？

人員基準を満たし続けるには、勤務の枠組みを就業規則・雇用契約で先に固めておくことが要です。開設前に決めておきたいのは次の点です。

- **就業規則の作成・届出**。常時10人以上の労働者を使用する事業場では作成・届出の義務があります（労働基準法第89条）。10人未満でも、労働時間・休日・賃金のルールを定めておくと運用が安定します。何人からかは[就業規則は何人から作成・届出が必要ですか](/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)をご覧ください
- **労働条件の明示**。雇用契約時に、所定労働時間・休日・賃金・更新の有無などを書面等で明示します（労働基準法第15条）。非常勤の生活支援員は、常勤換算に算入する実勤務時間を契約で明確にする
- **常勤・非常勤の別と常勤要件の割り当て**。各職種1人以上の常勤要件を、誰の雇用契約で満たすかを決めておく
- **変形労働時間制・夜間支援のルール**。宿泊型なら夜間の勤務体系、宿直の有無、割増賃金の計算方法を賃金規程に落とす
- **勤務実績を客観的に記録する体制**。始業・終業時刻、休憩、職務の別（兼務時）を勤務表とタイムカード等で残し、常勤換算が満たされていることを後から検証できるようにする

未払い賃金の消滅時効は当分の間3年（労働基準法第115条・附則）で、割増賃金の計算を誤ると3年分をまとめて請求される恐れがあります。夜間・変形労働の多い事業所ほど、割増賃金の設計を正確にしておくことが備えになります。

## 人員の労務と指定申請は、誰に分けて頼めばよいですか？

自立訓練の開設・運営では、判断する主体が分かれます。役割を切り分けて、それぞれの専門家に頼むのが安全です。

| すること | 誰の領分か |
|---|---|
| シフト設計・常勤換算の管理、就業規則・賃金規程・36協定・変形労働時間制の整備、労働時間管理、社会保険・雇用保険の手続 | **社会保険労務士**（四葉社会保険労務士事務所） |
| 人員基準の解釈・自立訓練の指定申請・変更届の書類作成、法人の定款の事業目的の整理 | **行政書士**（四葉行政書士事務所） |
| 物件の用途地域・構造・採光・避難・消防の適否 | 宅地建物取引業者・建築士 |
| 所有権移転など登記、法人設立登記 | 司法書士 |
| 報酬請求に関わる税務 | **税理士** |
| 未払い賃金の請求・紛争、労働審判・訴訟 | **弁護士** |

四葉社会保険労務士事務所と四葉行政書士事務所は、**独立した事業体**です。労務は社会保険労務士、指定申請は行政書士というように、**別々にご契約**いただく分離受任の形になります。紹介料の受け渡しはありません。人員基準に対応する労務は[人員基準に対応する労務](/labor/services/jinin-kijun-roumu)、介護・障害福祉の労務は[介護・障害福祉の労務管理](/labor/services/kaigo-roumu)にまとめています。**ご相談は無料です。** 費用は[報酬額表](/labor/ryokin)を、よくいただくご質問は[よくあるご質問](/labor/faq)をご覧ください。

## よくある質問

**Q. 自立訓練の人員は、非常勤（パート）だけでそろえられますか？**
A. 常勤換算の総量は非常勤の実勤務時間でも満たせますが、別途「各職種1人以上は常勤」という常勤要件があります（機能訓練＝平成18年厚生労働省令第171号第156条第6〜8項、生活訓練＝同令第166条第6・7項）。常勤者を置かずに非常勤だけで満たすことはできないため、常勤要件を誰の雇用契約で満たすかを先に決めます。これは雇用契約とシフトの設計の問題で、社会保険労務士が関わる範囲です。

**Q. 常勤換算は「頭数」で満たせばよいのですか？**
A. いいえ。常勤換算は勤務時間の総量で見ます。職員全員の勤務延べ時間数を、常勤が勤務すべき時間数で割った数です。有給休暇・欠勤・研修で延べ時間が落ちると基準割れの恐れがあるため、余裕を持ったシフト設計が前提です。

**Q. 宿泊型の夜間支援は、宿直として扱えば割増賃金は要りませんか？**
A. 宿直として扱えるのは、実態がほとんど労働のない態勢で、労働基準監督署長の許可を受けた場合に限られます（労働基準法第41条第3号・同施行規則第23条）。夜間に支援業務が常態的にあれば通常の労働時間として、午後10時〜午前5時は深夜割増（同法第37条・25%以上）の対象です。実態に合わせた設計が必要です。

**Q. 人員基準の適合と労務は、同じ人に頼めますか？**
A. 根拠となる法律が違うため、分けて考えます。人員基準の解釈や指定申請の書類作成は行政書士、シフト設計・就業規則・労働時間管理・社会保険の労務は社会保険労務士です。四葉では、四葉行政書士事務所と四葉社会保険労務士事務所が独立した事業体として、別々にご契約いただく形で分担します。
