**先講結論**：附照護的收費型老人之家（特定設施入居者生活介護）的勞務，核心是**一邊以「常勤換算」滿足指定的人員基準，一邊依法設計夜班的勞動時間與加成薪資**。人員基準規定於「指定居宅服務等事業之人員、設備及營運相關基準」（平成11年厚生省令第37號），看護職員與照護職員合計，須為要照護利用者3人配置1人以上（常勤換算）。夜間、深夜配置的職員，通常是實際進行協助、看守的**實際工作的夜班**，此時會產生深夜加成（22點～5點、25%以上），以及超過法定勞動時間部分的延長工時加成（勞動基準法第37條）。即使名稱是「宿直」，只要不符合常態上幾乎不需要勞動的許可基準（第41條第3項、發基第17號），就當作**勞動時間**。本文整理社會保險勞務士參與的範圍、常勤換算的算法、夜班與宿直的差異，以及16小時夜班的勞動時間管理。

「指定的人員基準有滿足，但不確定夜班加成薪資的計算是否正確」「想安排夜班專任，但勞動時間該怎麼管理」——這是開設、營運附照護收費型老人之家的事業者勞務負責人常問的問題。本頁面以特定設施的人員配置為前提，整理勞動時間、加成薪資、就業規則等勞務設計。是否符合指定基準、指定申請能否通過，是指定權者（都道府縣、市）與申請實務的領域，本文聚焦在勞務的想法。

## 特定設施的人員基準，社會保險勞務士參與到什麼程度？

人員基準既是取得指定的要件，同時也是**以常勤換算「持續滿足」該人數的勞動時間、雇用契約設計**這一勞務問題。基準的骨架如下（一般型。數值細目會因制度、自治體處理而變，最終適合以指定權者的說明確認）。

| 職種 | 配置目安（常勤換算） |
|---|---|
| 生活相談員 | 利用者100人配置1人以上 |
| 看護職員與照護職員合計 | 要照護者3人配置1人以上／要支援者10人配置1人以上 |
| 其中看護職員 | 利用者30人以下1人，超過30人時每50人加1人 |
| 照護職員 | 隨時1人以上（其中1人以上為常勤） |
| 機能訓練指導員 | 1人以上（可兼任） |
| 計畫作成擔當者 | 照護支援專門員1人以上（利用者100人配置1人為標準） |
| 管理者 | 專職從事該職務的常勤者1人 |

其中，社會保險勞務士負責的是**「不是配置幾人，而是滿足該人數的勤務作法」**：滿足常勤換算的排班設計、雇用契約與就業規則與薪資規程的整備、夜班與延長工時的勞動時間管理與加成薪資計算、社會保險的資格取得與喪失手續。人員基準本身的解釋、指定申請與變更申報的書類作成，是行政書士的業務，適用的法律不同。身心障礙福祉的常勤換算算法，也整理於[身心障礙福祉、照護的常勤換算如何計算](/zh-tw/labor/column/shogai-fukushi-kaigo-jokin-kansan-keisan-jinin)。

## 常勤換算怎麼數，如何落實到排班？

常勤換算數，是**該事業所職員的勤務累計時間數，除以常勤職員應勤務的時間數**。

| 項目 | 內容 |
|---|---|
| 計算式 | 常勤換算數＝（全體職員每週勤務累計時間數）÷（常勤每週應勤務時間數） |
| 常勤勤務時間 | 就業規則所定的所定勞動時間（例：每週40小時）。第32條上限為1日8小時、1週40小時 |
| 兼職職員 | 以實際勤務時間計入累計時間 |
| 端數處理 | 為避免低於各職種必要數，須有餘裕地編排 |

要注意的是，**常勤換算是以「勤務時間的總量」而非「人頭數」來看**。每週40小時的常勤1人，與每週20小時的兼職2人，在常勤換算上都是「1」。正因如此，當有薪假、缺勤、研習使累計時間下降時，就有低於基準的風險。排班應在法定勞動時間（1日8小時、1週40小時）與延長工時、假日勞動協定（第36條＝36協定）的範圍內有餘裕地編排。就業規則在隨時10人以上的事業場有作成、申報義務（第89條）。詳情請見[就業規則從幾人開始需要作成、申報](/zh-tw/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)。

## 夜班與宿直有何不同，加成薪資如何變化？

附照護收費型老人之家的夜間配置，通常是實際進行協助、如廁對應、看守、記錄的**實際工作的夜班**。這是勞動基準法上的「勞動時間」，與宿直（取得許可即可免除勞動時間規定的勤務）實態不同。

| 觀點 | 夜班（實際工作） | 宿直（取得許可時） |
|---|---|---|
| 業務實態 | 一般的照護、看守、記錄 | 定時巡視、緊急待命等斷續性業務 |
| 勞動時間 | 屬於勞動時間 | 免除勞動時間、休息、休日規定 |
| 深夜加成（22點～5點） | 需要25%以上 | 原則不需要 |
| 延長工時加成 | 超過法定部分需25%以上 | 原則不需要 |
| 許可 | 不需要（當作勞動時間管理） | 需要所轄勞動基準監督署長的許可 |

要以宿直免除勞動時間規定，須符合**常態上幾乎不需要勞動**的許可基準，並取得所轄勞動基準監督署長的許可（第41條第3項、施行規則第23條、昭和22年9月13日發基第17號）。頻繁發生協助與看守的照護設施夜間時段，難以符合此要件，通常不屬於宿直許可對象。因此，夜間時段勞動的部分屬深夜加成（第37條第3項）對象，超過法定勞動時間部分還需延長工時加成（同條第1項）。宿日直許可的基準整理於[醫療、照護的宿日直許可什麼樣的勤務才能取得](/zh-tw/labor/column/iryo-kaigo-shukujitchoku-kyoka-kijun)，身心障礙團體家屋的夜班、宿直差異整理於[團體家屋的夜班與宿直在勞務上如何不同](/zh-tw/labor/column/group-home-yakin-shukuchoku-roudou-chigai)。

## 夜班專任、16小時夜班的勞動時間管理要注意什麼？

照護現場有時會編排從傍晚到隔天早上的「16小時夜班」，或只負責夜班的「夜班專任」。要掌握的論點如下。

- **超過1日8小時、1週40小時的設計，以變形勞動時間制吸收**。使用1個月單位（第32條之2）或1年單位（第32條之4）的變形勞動時間制，即使特定日設定超過8小時，也能平均整個期間至每週40小時以內。惟採1年單位時，即使隨時未滿10人，也不能用每週44小時特例，須以每週40小時計算
- **深夜加成在變形制下仍需另計**。即使在變形制下收在法定內，22點～5點的勞動仍另需深夜加成（25%以上）
- **確保休息**。16小時拘束時，須依第34條給予至少1小時以上、脫離勞動的休息。「仮眠中仍有義務回應呼叫」的時間，可能成為待機時間而屬勞動時間
- **延長工時、假日勞動在36協定範圍內**。不得使其超過協定上限勞動（第36條）

未付薪資請求權的消滅時效，目前暫定為3年（第115條、附則）。夜班加成計算若有誤，有被合併請求3年份的風險，因此以客觀記錄起訖時刻與休息、仮眠的實態為前提。個別未付請求的處理是律師的業務，本文範圍之外。變形勞動時間制的選擇整理於[變形勞動時間制與彈性工時如何選](/zh-tw/labor/column/henkei-roudoujikan-flextime-erabikata)，36協定的範圍整理於[36協定與加班能請社會保險勞務士做到哪裡](/zh-tw/labor/column/36-kyotei-zangyo-sharoushi-doko-made)。

## 指定的人員基準與勞務，該分別委託給誰？

特定設施的開設、營運中，做判斷的主體是分開的。將角色切分、分別委託給各自的專家較為安全。

| 要做的事 | 屬於誰的領域 |
|---|---|
| 就業規則、薪資規程、36協定、變形制的整備，夜班加成薪資計算，社會保險 | **社會保險勞務士**（四葉社会保険労務士事務所） |
| 人員基準的解釋、特定設施的指定申請與變更申報書類作成 | **行政書士**（四葉行政書士事務所） |
| 照護報酬的請求、稅務 | 事業者、**稅理士** |
| 未付薪資請求與紛爭、勞動審判、訴訟 | **律師** |

四葉社会保険労務士事務所與四葉行政書士事務所是**獨立事業體**。勞務由社會保險勞務士、指定申請由行政書士，也就是各自**另行簽約**的分離受任形式，彼此各自獨立，沒有介紹費的收受。人員基準的勞務整理於[對應人員基準的勞務](/zh-tw/labor/services/jinin-kijun-roumu)，照護、身心障礙福祉的勞務整理於[照護、身心障礙福祉的勞務管理](/zh-tw/labor/services/kaigo-roumu)。**諮詢免費。** 費用請見[報酬額表](/zh-tw/labor/ryokin)，常見問題請見[常見問答](/zh-tw/labor/faq)。

## 常見問題

**Q. 附照護收費型老人之家的夜班，可以算「宿直」而不付加成薪資嗎？**
A. 通常不行。要以宿直免除勞動時間規定，須就常態上幾乎不需要勞動的斷續性業務，取得所轄勞動基準監督署長的許可（第41條第3項、發基第17號）。頻繁發生協助、看守的照護設施夜間時段難以符合要件，通常屬實際工作的夜班，是深夜加成、延長工時加成的對象。

**Q. 常勤換算用「人頭數」滿足即可嗎？**
A. 不是。常勤換算是以勤務時間的總量來看，也就是全體職員的勤務累計時間數，除以常勤應勤務的時間數。有薪假、缺勤、研習使累計時間下降時，有低於基準的風險，因此以有餘裕的排班設計為前提。

**Q. 16小時夜班會違反勞動基準法嗎？**
A. 不會立即違反，但超過1日8小時、1週40小時的設計，須以1個月單位或1年單位的變形勞動時間制，將期間平均收在每週40小時以內（第32條之2、第32條之4）。深夜加成、確保休息、在36協定範圍內，須另行滿足。

**Q. 人員基準的適合與勞務可以委託同一人嗎？**
A. 因為依據的法律不同，須分開考量。人員基準的解釋與指定申請書類作成是行政書士，就業規則、加成薪資、社會保險的勞務是社會保險勞務士。在四葉，四葉行政書士事務所與四葉社会保険労務士事務所各自獨立為事業體，以另行簽約的形式分工。
