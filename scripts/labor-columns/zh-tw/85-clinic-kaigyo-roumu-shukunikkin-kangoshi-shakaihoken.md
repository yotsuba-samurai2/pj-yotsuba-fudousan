**結論（先講重點）**：開設診所（Clinic）後，最先需要的勞務是**員工的社會保險（健康保險・厚生年金保險）加保手續**、**勞動條件的明示與雇用契約**，以及若使用10人以上時的**就業規則製作・申報**。此外，若讓醫師或員工值夜班・日班，還要向所轄的勞動基準監督署取得可作為勞動時間例外處理的**宿日直許可**。醫療法人（法人）只要雇用員工即為社會保險強制適用，個人經營的診所則在常時5人以上時強制適用。本文整理該從何處著手、社會保險的適用判斷、宿日直許可的意義、就業規則・36協定的時機，以及該委託誰做什麼。

「院長只看診、勞務往後放」的方式開業，容易在到職日前後產生社會保險的空窗或未付。本頁面是為新開業的醫師・事務長而寫，以社會保險勞務士的勞務管理視角，整理開業時最先需要的勞務手續。

## 開設診所最先需要的勞務手續是什麼？

除了診所的開設申報（保健所）與保險醫療機關的指定申請之外，還有**因雇用而產生的手續**。依開業前後的順序排列如下。

| 時期 | 該做的事 | 提出對象 |
|---|---|---|
| 開業前～到職前 | 勞動條件的明示・雇用契約書的製作（勞動基準法第15條） | 公司內（交付本人） |
| 到職日 | 健康保險・厚生年金保險的資格取得申報（5日內） | 年金事務所（協會健保等） |
| 到職日～10日內 | 雇用保險的資格取得申報 | Hello Work |
| 開始使用勞工之日～ | 勞動保險（勞災・雇用）的成立申報・概算保險費申報 | 勞動基準監督署・Hello Work |
| 常時使用10人以上時 | 就業規則的製作・申報（勞動基準法第89條） | 所轄勞動基準監督署長 |
| 讓員工值宿直・日直時 | 斷續性宿直或日直勤務的許可（勞動基準法施行規則第23條） | 所轄勞動基準監督署長 |

社會保險（健保・厚年）的資格取得申報以**到職起5日內**、雇用保險的資格取得申報以**到職次月10日前**為基準。首先確定「讓誰、從何時、加入哪種保險」是出發點。勞動時間・加班費的一般想法，請一併參閱[36協定與加班的上限](/zh-tw/labor/column/36-kyotei-zangyo-sharoushi-doko-made)。

## 護理師・櫃檯的社會保險會強制適用嗎？如何判斷？

事業所是否作為單位加入社會保險（健康保險・厚生年金保險），取決於**事業所的形態**與**行業・人數**。

| 事業所形態 | 社會保險（健保・厚年） |
|---|---|
| 醫療法人等法人 | 只要常時使用員工即**強制適用**（不問人數） |
| 個人經營的診所（適用業種） | 常時使用**5人以上**即**強制適用**；未滿5人為任意適用 |

醫療事業（疾病的治療等）屬於健康保險法・厚生年金保險法的**適用業種**（健康保險法第3條第3項、厚生年金保險法第6條）。因此，個人經營的診所只要常時雇用5人以上，健保・厚年即為強制適用；醫療法人則不問人數皆為強制適用。

在此之上，兼職的護理師・櫃檯等**是否個別成為被保險人**，以勞動時間・日數判斷。若1週的所定勞動時間與1個月的所定勞動日數達一般勞工的**4分之3以上**即為被保險人；即使未滿4分之3，只要滿足一定要件（每週20小時以上・月薪88,000日圓以上等）也成為被保險人。這項對短時間勞工的適用正逐步擴大。詳細的界線請參閱[兼職・打工的社會保險以4分之3為基準](/zh-tw/labor/column/tanjikan-koyo-shakaihoken-4bunno3)與[社會保險的適用擴大](/zh-tw/labor/column/shakaihoken-tekiyo-kakudai-2027)。

## 醫師・員工的宿日直許可為何需要？向誰提出？

宿直・日直（夜間或假日的待機性勤務），依原則會被當作勞動時間，牽動時間外・深夜的加班費與勞動時間的上限。但對於**通常幾乎沒有勞動必要**的待機性勤務，使用者若取得**所轄勞動基準監督署長的許可**（樣式第10號），則可不受勞動時間規制（勞動基準法第32條）而使其從事（勞動基準法第41條第3號、勞動基準法施行規則第23條）。這就是宿日直許可。

關於醫師，自2024年（令和6年）4月起，從事醫業的醫師也適用時間外勞動的上限規制，取得宿日直許可的時間原則上不算入勞動時間，因此在與上限規制的關係上，有無許可在實務上也很重要。不過，即使在取得許可的宿日直中，從事與通常勤務相同勞動的時間仍作為勞動時間處理，並為加班費的對象。

| 項目 | 內容 |
|---|---|
| 根據 | 勞動基準法第41條第3號、勞動基準法施行規則第23條 |
| 許可對象 | 通常幾乎沒有勞動必要的待機性宿直・日直 |
| 申請對象 | 所轄勞動基準監督署長（樣式第10號） |
| 效果 | 不受勞動時間規制（勞動基準法第32條）；但從事通常勞動的時間為勞動時間 |

許可的判斷由勞動基準監督署進行。本事務所協助依許可基準整理勤務實態並製作申請書類。

## 就業規則與36協定在什麼時機需要？

依人數與使其勞動的方式，需要以下書面。

| 書面 | 何時需要 | 根據 |
|---|---|---|
| 就業規則 | 常時使用10人以上勞工時（製作・申報義務） | 勞動基準法第89條 |
| 36協定 | 使其進行超過法定勞動時間的時間外・假日勞動時 | 勞動基準法第36條 |

常時使用10人以上勞工的使用者，有義務製作就業規則並**向所轄勞動基準監督署長申報**（勞動基準法第89條）。未滿10人時，為統一勞動條件與工資規則而先行製作，也能讓實務穩定。就業規則從幾人開始有義務，請參閱[就業規則從幾人開始有義務](/zh-tw/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)。

要使其超過法定勞動時間（原則1天8小時・1週40小時）進行時間外・假日勞動，必須先與過半數代表者締結36協定並**申報後**才可（勞動基準法第36條）。醫療現場容易產生夜間・假日勤務，因此在開業初期把就業規則・36協定・加班費計算整套備妥較為安全。

## 如何把勞務手續納入開業時程？

勞務手續在時期上會與診所開設申報、物件準備重疊。為防漏，依下列順序排列較清楚。

| 階段 | 勞務要做的事 |
|---|---|
| 物件・裝修的規劃 | 由預估人數與班表，設計社會保險的適用與勞動時間的架構 |
| 員工招募 | 勞動條件的明示・雇用契約書的製作、就業規則的草稿 |
| 開業前夕 | 勞動保險的成立申報、社會保險的新規適用申報的準備 |
| 到職日 | 健保・厚年的資格取得申報（5日內）、雇用保險的資格取得申報 |
| 開業後儘速 | 10人以上者申報就業規則、有宿日直者取得宿日直許可、締結・申報36協定 |

物件本身的選定與租賃是不動產的領域，診所開設申報是行政書士或院長本人（保健所）的手續，與勞務的承擔者分開。下一節整理。

## 該委託誰做什麼？

診所開業不會僅以勞務完結。各業務的承擔者不同。

| 該做的事 | 屬於誰的業務 |
|---|---|
| 社會・勞動保險的適用手續、就業規則・36協定的製作、勞動時間・宿日直許可的書類、薪資計算 | **社會保險勞務士**（本事務所） |
| 診所開設申報等行政手續的書類製作 | **行政書士**（或院長本人向保健所） |
| 宿日直許可・36協定的許可・受理判斷 | **所轄勞動基準監督署長** |
| 保險醫療機關的指定 | **地方厚生局** |
| 診所物件的選定・租賃・裝修 | **不動產（宅地建物取引業者）** |
| 未付工資的請求或勞資糾紛 | **律師** |
| 源泉徵收・年終調整・法人的稅務 | **稅理士** |

本事務所僅限於勞務管理的資訊提供與手續。診所開設申報等行政手續可為您轉介四葉行政書士事務所，物件可轉介四葉不動産；但前提是**社會保險勞務士業務、行政書士業務與宅地建物取引業，各自由獨立的事業體承擔，須另行簽約**。本事務所不做一括受任。

## 常見問題

**Q. 員工只有2～3人也必須加入社會保險嗎？**
A. 若是醫療法人等法人，即使員工只有2～3人，健康保險・厚生年金保險也是強制適用。個人經營的診所則在常時5人以上時強制適用，未滿5人為任意適用。不過行業與人數的計算方式有需要判斷的場面，建議依實態確認。

**Q. 只要取得宿日直許可，夜間的加班費就完全不用付嗎？**
A. 不是。宿日直許可是把通常幾乎沒有勞動必要的待機性勤務，置於勞動時間規制之外。即使在取得許可的宿日直中，從事急患對應等通常勞動的時間，仍作為勞動時間處理，並為加班費的對象。

**Q. 就業規則在開業同時一定需要嗎？**
A. 製作・申報成為義務的，是常時使用10人以上勞工時（勞動基準法第89條）。未滿10人時，為統一勞動條件與工資・服務規則而先行製作，較易防止日後糾紛。

**Q. 找物件與診所開設申報也可以一起委託嗎？**
A. 勞務管理是社會保險勞務士、診所開設申報等行政手續的書類是行政書士（或院長本人向保健所）、物件是宅地建物取引業者的業務。在各自獨立的事業體、須分別承接（另行簽約）的前提下，可為您轉介四葉行政書士事務所・四葉不動産。本事務所不採一括受任的形式。
