**結論（先講重點）：** 改善基準告示（自動車運転者的勞動時間等改善基準）的適用，**與是否持有運輸業許可無關，而是對主要從事四輪以上汽車駕駛業務的勞動者適用**（告示第1條）。因此，即使只用自家卡車運送自家產業廢棄物、既不需要收集運搬業許可也不需要運輸業許可，該名駕駛仍受改善基準告示規範。自2024年（令和6年）4月1日起，卡車駕駛的拘束時間在**1年3,300小時・1個月284小時・1天13小時（最多15小時）**的界線內管理，休息期間**以連續11小時為基本、不低於9小時**。本文整理許可與勞務管理的切分、拘束時間上限、36協定與就業規則的修改處，以及該委託誰做什麼。

「我們沒取得運輸業許可，所以駕駛的勞動時間規制與我們無關」——這種理解很危險。本頁面面向以產業廢棄物收集運搬業許可雇用卡車駕駛的業者，以及用自家車運送自家廢棄物的業者的勞務負責人，從社會保險勞務士的勞務管理視角，整理改善基準告示的適用範圍、拘束時間與休息期間、36協定與就業規則的修改處。

## 沒有運輸業許可，也適用改善基準告示嗎？

適用。改善基準告示是否適用，**取決於「是否為主要從事汽車駕駛業務的勞動者」，而非「持有什麼許可」。**

改善基準告示第1條將本基準適用的「自動車運転者」定義為：勞動基準法第9條規定的勞動者（排除僅使用同居親屬的事業之勞動者及家事使用人），且**主要從事四輪以上汽車駕駛業務**（厚生勞動省勞動基準局長所定者除外）的人。此處並沒有「受雇於持有貨物自動車運送事業許可之業者」這樣的限定。

至於是否需要許可，則由其他法律決定。

| 運送方式 | 所需許可 | 依據 |
|---|---|---|
| 以業務形式運送他人的產業廢棄物 | 產業廢棄物收集運搬業許可（都道府縣知事） | 廢棄物處理法第14條第1項 |
| 運送自家（業者自身）的產業廢棄物 | **不需許可** | 廢棄物處理法第14條第1項但書（業者自行運送其產業廢棄物的情形） |
| 應他人需求、有償運送貨物 | 一般貨物自動車運送事業許可 | 貨物自動車運送事業法第2條 |
| 用自家車運送自家貨物（廢棄物） | 不需運輸業許可（非「應他人需求」） | 貨物自動車運送事業法第2條 |

也就是說，只用自家卡車運送自家廢棄物，既不需要產廢收集運搬業許可，也不需要運輸業許可。**但「不需許可」與「駕駛的勞動時間規制不適用」是兩回事。** 一旦雇用主要從事駕駛業務的人，無論有無許可，都必須進行改善基準告示的管理。駕駛以外一般勞動時間規則，請一併參閱[36協定與加班上限](/zh-tw/labor/column/36-kyotei-zangyo-sharoushi-doko-made)。

## 2024年4月起，拘束時間（1年・1個月・1天）如何改變？

改善基準告示於2022年（令和4年）12月23日以厚生勞動省告示第367號修正，自2024年（令和6年）4月1日起適用。卡車駕駛的主要基準如下。

| 項目 | 原則 | 例外・上限 |
|---|---|---|
| 1年的拘束時間 | 3,300小時 | 依勞資協定，1年內最多6個月可達3,400小時 |
| 1個月的拘束時間 | 284小時 | 依勞資協定，1年內最多6個月可達310小時（超過284小時最多連續3個月；須努力使當月時間外・休日勞動低於100小時） |
| 1天的拘束時間 | 13小時 | 最多15小時（長距離貨物運送：1週2次可達16小時） |
| 休息期間 | 勤務結束後，以連續11小時以上為基本 | 不低於連續9小時 |
| 連續駕駛時間 | 4小時以內 | 不得已時最多可延長30分鐘 |

拘束時間是指從上班到下班、勞動時間加上休息時間（含手待時間）的時間。改善基準告示並非勞動基準法本身，而是厚生勞動大臣的告示；但若違反，將成為勞動基準監督署糾正指導的對象。它與時間外勞動的上限規制（汽車駕駛業務即使特別條款也在1年960小時以內。勞動基準法附則第140條第1項）是不同的尺度，**必須同時滿足兩者**。

## 產廢駕駛的「裝載・收集地點待機」算進拘束時間嗎？

算進去。拘束時間涵蓋的**不只是勞動時間，還包括休息與手待時間——即從上班到下班的整段時間。**

產業廢棄物的收集運搬，包含在排出事業場的裝載、在處分場或中間處理設施的卸貨、依受入順序的等待等，「未在駕駛的時間」容易拉長。只要這些時間處於雇主的指揮命令下、無法自由使用，就算進手待時間、計入拘束時間。若只計算駕駛時間、判斷「還有餘裕」，就可能發生實際拘束時間已超過15小時的情況。

| 時間種類 | 是否算進拘束時間 |
|---|---|
| 駕駛中的時間 | 算（勞動時間） |
| 裝載・卸貨的作業時間 | 算（勞動時間） |
| 處分場的受入等待・排隊等待 | 在指揮命令下則算（手待時間） |
| 休息時間 | 算（計入拘束時間；非勞動時間） |
| 勤務與勤務之間的休息期間 | 不算（在拘束時間之外；以連續11小時為基本） |

管理的起點，是用數位行車紀錄器或日報**記錄實際拘束時間，並區分駕駛、作業、待機**。待機越長的現場，確認記錄與實態是否一致就越重要。

## 36協定與就業規則該怎麼整備？

要同時滿足拘束時間管理與時間外勞動的上限規制，需要仔細製作書面文件。修改處如下。

| 要做的事 | 檢視重點 |
|---|---|
| 36協定（特別條款） | 將汽車駕駛業務的時間外勞動設計在1年960小時以內，並載明特別條款的次數（1年6次以內）・理由・程序（勞動基準法第36條・附則第140條第1項） |
| 就業規則・工資規程 | 反映拘束時間・休息期間的思路，並與加給工資的計算（時間外25%以上・休日35%以上・深夜25%以上）保持一致（勞動基準法第37條） |
| 拘束時間・勞動時間的記錄 | 將1天15小時・1個月284小時・休息9小時的界線納入每日管理的運作，並明確手待時間的處理 |
| 過半數代表者的選出 | 以適當程序選出非管理監督者的人，並留下記錄（勞動基準法施行規則第6條之2） |

常時雇用10人以上勞動者的事業場，就業規則的作成・申報為義務。詳情請參閱[就業規則從幾人起成為義務](/zh-tw/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)。此外，持有運輸業許可的一般貨物自動車運送事業者的「2024年問題」全貌，在[運輸業的2024年問題與改善基準告示](/zh-tw/labor/column/unso-2024-mondai-kaizen-kijun-kokuji)也有討論。

## 許可找行政書士、勞務找社勞士——界線劃在哪裡？

產廢駕駛的對應，無法僅靠勞務管理完成。承擔者依業務而分。

| 要做的事 | 屬於誰的業務 |
|---|---|
| 36協定・就業規則・工資規程的作成、拘束時間・勞動時間管理體制的整備、加給工資的計算 | **社會保險勞務士**（本事務所） |
| 產業廢棄物收集運搬業的許可申請・變更申報、是否需要許可的程序判斷 | **行政書士** |
| 一般貨物自動車運送事業許可（運送他人貨物時）、事業計畫變更的認可・申報 | **行政書士**（運輸行政的最終判斷由地方運輸局做出） |
| 未付加班費的請求、職災爭議、勞資糾紛・勞動審判・訴訟 | **律師** |
| 加給工資的源泉徵收・年末調整的稅務判斷 | **稅理士** |

本事務所僅限於勞務管理的資訊提供與手續。關於產業廢棄物收集運搬業或運輸業的許可，我們雖可為您轉介四葉行政書士事務所，但前提是**社會保險勞務士業務與行政書士業務各由獨立的事業體承擔、須另行簽約**。不做一括受任。

## 常見問題

**Q. 只是用自家卡車運送自家廢棄物，也必須遵守改善基準告示嗎？**
A. 必須遵守。改善基準告示的適用，取決於是否為主要從事四輪以上汽車駕駛業務的勞動者，而非是否持有運輸業或產廢收集運搬業許可（告示第1條）。即使運送自家廢棄物不需許可，只要該駕駛主要從事駕駛業務，就必須管理拘束時間與休息期間。

**Q. 產廢收集運搬需要許可，那除了改善基準告示，是否也需要運輸業許可？**
A. 視運送方式而定。以業務形式運送他人的產業廢棄物需要產業廢棄物收集運搬業許可（廢棄物處理法第14條第1項），但自行運送自家廢棄物則不需許可（同項但書）。運輸業（一般貨物自動車運送事業）許可是在「應他人需求、有償」運送貨物時才需要，僅用自家車運送自家貨物則不需要。是否需要許可，與勞動時間規制是不同的論點。

**Q. 在處分場等待受入的時間，算進拘束時間嗎？**
A. 只要處於雇主的指揮命令下、無法自由使用，就算進手待時間、計入拘束時間。拘束時間是勞動時間加上休息與手待時間、從上班到下班的時間，也包含未在駕駛的待機時間。待機長的現場，以記錄掌握實態是管理的起點。

**Q. 駕駛的許可與勞務，可以一起委託嗎？**
A. 勞務管理是社會保險勞務士的業務，產廢收集運搬業或運輸業許可的文件是行政書士的業務。在各為獨立事業體、另行簽約的前提下，我們可為您轉介四葉行政書士事務所。我們不採取一括受任的形式。
