**結論（先講重點）**：施行是2027年4月，但**手續已經開始了**。監理支援機關許可的施行日前申請**受理中**，**育成就勞計畫認定的施行日前申請自2026年9月1日開始**。技能實習側也有期限：監理團體的新規許可至**2026年9月30日**、1號技能實習計畫的認定申請至**2027年2月**。

本頁面寫給正在接收技能實習生、或準備以育成就勞接收外國人材的公司經營者與總務人員。不是制度解說，只從外國人技能實習機構（OTIT）的公開資料（2026年8月14日確認）整理**「何時之前・做什麼」**。

## 施行是明年4月，為什麼是現在？

**因為施行日前申請的機制已經在運轉。** 等施行才動，施行日就來不及。而且技能實習側，**新規受理關閉的期限**已經公示。「育成就勞開始之前先用技能實習」——這樣想的公司，恰恰需要同時看這兩份行事曆。

## 何時之前，提出什麼？

以下全部是OTIT公開頁面（2026年8月14日確認）明記的事項。**頁面更新頻繁，行動前務必以最新頁面再確認。**

| 時期 | 發生什麼 |
|---|---|
| **受理中** | **監理支援機關許可**的施行日前申請（申請書類一式・樣式已公開） |
| **2026年9月1日起** | **育成就勞計畫認定**的施行日前申請開始（「請於9月1日以後送達」） |
| **2026年9月30日前** | **技能實習**制度的**監理團體新規許可**申請 |
| **2027年2月前** | **技能實習**制度的**1號技能實習計畫**認定申請 |
| **2027年4月1日** | 育成就勞制度施行（預定） |

兩點注意。第一，**「9月30日」是技能實習的監理團體新規許可的期限**，不是育成就勞的申請期限。混淆兩者的資訊不少，公司內部共享時也請區分。第二，**提出地點因申請而異**：監理支援機關許可寄往本部審查課**分室**（與本部地址不同），育成就勞計畫認定寄往**地方事務所・支所**（不是本部）。OTIT自己在兩處都加了注意標記。施行日前申請的一般諮詢，設有專用客服電話（0570-011-300・平日9:00〜17:00）。

## 接收的公司，要準備什麼？

從育成就勞計畫認定的申請樣式一覽，**可以反推會被要求什麼**。

| 樣式 | 要準備的東西 |
|---|---|
| 第1-2號 | **雇用契約書及雇用條件書**——契約書式的重建 |
| 第1-13號 | 期間中的**待遇重要事項說明書** |
| 第1-15號・第1-39號 | **報酬・宿泊設施・徵收費用**（第1-39號含移動・轉居費用等）的說明書——[待遇欄寫什麼](/zh-tw/labor/column/ikusei-shuro-keikaku-taigu-kakikata) |
| 第1-11號 | **育成就勞責任者・指導員・生活相談員**的就任承諾書——3個職務的人選 |
| 第1-35號 | **目標日本語能力**講習等履修狀況申告書——日語學習體制 |
| 第1-16號〜第1-22號 | **轉籍（實施者變更希望）相關7樣式**——[轉籍時的保險與申報](/zh-tw/labor/column/ikusei-shuro-tenseki-shakaihoken-koyohoken) |
| 第1-36號 | 優良要件適合申告書——是否爭取優良要件的判斷 |

光轉籍就有7個樣式——**樣式的數量本身，顯示轉籍位於這個制度的中心**。整體圖像見[技能實習與育成就勞，勞務會有什麼不同](/zh-tw/labor/column/ginou-jisshu-ikusei-shuro-roumu-chigai)，就業規則側的準備見[接收之前，就業規則怎麼修](/zh-tw/labor/column/ikusei-shuro-shugyokisoku-minaoshi)。

## 找誰，辦什麼？

| 要做的事 | 誰的業務 |

| **外部稽核人員的確保** | 申請書類一覽含**外部稽核人員・稽核人員（外部監査人・監査人）的就任承諾書**（監理支援機關許可＝參考樣式第2-5號、計畫認定＝第1-26號）。**也就是說，申請時點稽核人員必須已經確定。** 委託對象的選法・要件見[育成就勞的外部稽核人員](/zh-tw/legal/services/ikuseishuro-gaibu-kansa)（四葉行政書士事務所・不同事業體）；稽核會看什麼・如何準備見[外部稽核人員（備妥側）](/zh-tw/labor/services/gaibu-kansanin) |
| 雇用契約書式・待遇書面・就業規則・社會保險——**勞務的重建** | **社會保險勞務士**（本事務所） |

## 四葉社会保険労務士事務所能做什麼？

位於文京區小日向的四葉社会保険労務士事務所，承接面向育成就勞接收的**勞務側準備**——雇用契約書式（對應第1-2號的內容）、待遇說明書面的整理、就業規則的修訂、社會保險・勞動保險手續。**諮詢免費。** 費用載於[報酬額表](/zh-tw/labor/ryokin)。從「我們公司的話，何時之前做什麼」的盤點開始，與您一起進行。

### 該向誰諮詢

監理支援機關的許可申請・育成就勞計畫認定的申請・在留資格由**四葉行政書士事務所**承接（與本事務所是不同的事業體，另行簽約）。外部稽核人員由律師・社會保險勞務士・行政書士任一資格皆可就任，四葉的行政書士事務所・社會保險勞務士事務所都可以承接，但**各自作為獨立的事業體、以各自的契約受任**。住居・宿舍由**四葉不動産株式会社**（同）、薪資課稅是**稅理士**、爭議案件是**律師**的業務。以上均不收取介紹費。

## 常見問題

**Q. 還沒施行，為什麼申請已經開始？**
A. 因為設有施行日前申請的機制。監理支援機關許可受理中，育成就勞計畫認定自2026年9月1日開始（OTIT公開資料・2026年8月14日確認）。要在施行日（2027年4月1日預定）開始使用制度，就必須在施行前推進許可・認定的手續。

**Q. 聽說「9月30日前要申請」，是育成就勞的期限嗎？**
A. 不是。2026年9月30日是OTIT就技能實習制度的監理團體新規許可申請所示的期限，不是育成就勞申請的推薦期限。混淆兩者的資訊在流傳，請以一次資料（OTIT的頁面）確認。

**Q. 目前還在用技能實習接收。有關係嗎？**
A. 有。1號技能實習計畫的認定申請至2027年2月，之後的新規將移往育成就勞側。正在用技能實習接收的公司，更需要及早畫出移行的行事曆。整體差異見[比較文章](/zh-tw/labor/column/ginou-jisshu-ikusei-shuro-roumu-chigai)。

**Q. 外部稽核人員要在什麼時候之前決定？**
A. 申請書類一覽含就任承諾書（監理支援機關許可＝參考樣式第2-5號），因此提出申請書的時點就必須已經確定。「許可下來再找」的順序不可行。委託對象的選法見[育成就勞的外部稽核人員](/zh-tw/legal/services/ikuseishuro-gaibu-kansa)（四葉行政書士事務所・不同事業體）。
