**結論（先講重點）**：就勞繼續支援A型・B型的人員基準，判斷的不是「配置幾名職員」，而是「以常勤換算對利用者人數是否足夠」。所以非常勤・兼職職員的所定勞動時間設計與勤務實績的記錄，直接連動指定的維持。職業指導員與生活支援員，以常勤換算需在利用者人數除以10以上、各1人以上、其中1人以上為常勤，服務管理責任者則在利用者60人以下配置1人以上。

最大的差別在雇用契約。A型與利用者締結雇用契約，因此該利用者被當作最低工資・社會保險・勞動時間對象的勞工。B型不締結雇用契約，而支付工資（此處指日文「工賃」，即作業報酬）。

指定申請本身屬行政書士，報酬（國保連請求）的制度設計屬行政書士與事業者，法人的會計・稅務屬稅理士的領域。本事務所承接的是勞務・社會保險的支援，個別判斷由資格者在面談後進行。

## A型與B型，職員的人員基準與雇用的想法如何不同？

人員基準的骨架（職業指導員・生活支援員・服務管理責任者・管理者）在A型與B型是共通的，但利用者的定位不同。A型由事業所與利用者締結雇用契約，B型不締結。指定基準規定於平成18年厚生勞動省令第171號，A型為第186條以下，B型為第199條以下。

| 論點 | 就勞繼續支援A型 | 就勞繼續支援B型 |
|---|---|---|
| 與利用者的關係 | 締結雇用契約（基準第190條） | 不締結雇用契約，支付工資 |
| 職業指導員・生活支援員 | 常勤換算為利用者數÷10以上，各1人以上、其中1人以上常勤（第186條） | 常勤換算為利用者數÷10以上，相同（第199條） |
| 服務管理責任者 | 利用者60人以下1人以上，超過60人每40人（或其端數）加1人，其中1人以上常勤 | 與A型相同的想法 |
| 管理者 | 每一事業所1人，無妨礙時可兼任 | 同左 |
| 支付給利用者的 | 工資（最低工資法對象） | 工賃（作業報酬） |

A型締結雇用契約的利用者，屬於受勞動基準法等勞動相關法規適用的勞工。這帶來A型特有的負擔：除了職員的勞務管理，同時發生「利用者＝勞工」的勞務管理。報酬上雖有選擇更厚配置（例如利用者7.5人配置職員1人）的區分，但那是報酬的問題，與指定基準的最低線不同。滿足指定的最低線是「除以10以上」。

## 常勤換算如何計算非常勤或兼職來滿足？

配置數以「常勤換算方法」計算。所謂常勤換算，是把從業者的工作時數總和，除以該事業所常勤職員應工作的時數，換算成相當於幾名常勤。也就是說，是否滿足基準，取決的不是雇了幾名兼職，而是工作時數總和相當於幾名常勤。

| 設計要點 | 勞務側要決定的事 |
|---|---|
| 常勤的所定勞動時間 | 在就業規則明確「常勤職員應工作的時數」 |
| 非常勤・兼職的所定勞動時間 | 在雇用契約書明示所定勞動時間・所定勞動日數（勞動基準法第15條第1項・同法施行規則第5條） |
| 常勤換算的計算 | 各人的工作時數總和 ÷ 常勤應工作的時數 |
| 記錄 | 勤務預定表與勤務實績（打卡等）都要保留 |

勞動條件的明示是勞動基準法第15條第1項的義務，應明示的事項規定於同法施行規則第5條。因有應以書面（含勞工希望時的電子交付）明示的事項，請勿只以口頭交代。勞動時間管理鬆散時，常勤換算的數字會低於基準，使事業所處於不符指定基準的狀態。勤務實績的記錄，既是勞務管理，也是維持指定的書類。以短時數雇用時的社會保險想法，整理於[以短時數雇用時，社會保險會如何](/zh-tw/labor/column/tanjikan-koyo-shakaihoken-4bunno3)。

## 服務管理責任者或職業指導員的兼任，容許到什麼程度？

兼任是否容許，前提是不破壞常勤換算的數字，並能確保各職務所需的時間。管理者在對管理業務無妨礙時，於某些場合容許與其他職務兼任，但作為職業指導員・生活支援員計數的時間與管理者的時間，不能重複計算。

| 兼任型態 | 想法 |
|---|---|
| 管理者與服務管理責任者 | 無妨礙時某些場合容許兼任，但常勤換算不可重複計上 |
| 職業指導員與生活支援員 | 各需另配置1人以上，1人不能同時填滿兩個名額 |
| 常勤重複 | 同一勤務時間不跨多職種計數 |

具體哪種兼任被容許，取決於自治體的運用與該事業所的勤務體制。本文僅止於一般想法，個別兼任的可否不下結論。作為思考勤務形態與勞動時間・工資關係的線索，以障害者團體家屋為例的[障害者團體家屋的夜勤與宿直，勞動時間的處理不同](/zh-tw/labor/column/group-home-yakin-shukuchoku-roudou-chigai)也請一併參閱。就業規則的作成義務本身，整理於[就業規則從幾人開始是義務，非義務的是什麼](/zh-tw/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)。

## A型的利用者作為勞工，最低工資與社會保險如何處理？

A型與利用者締結雇用契約，因此該利用者屬受最低工資法適用的勞工。有支付最低工資額以上工資的義務（最低工資法第4條）；若有因障害而勞動能力顯著偏低等情事，經都道府縣勞動局長許可，可將最低工資以一定比率減額適用（最低工資法第7條）。未經許可不得低於最低工資。

| 論點 | A型（有雇用契約） | B型（無雇用契約） |
|---|---|---|
| 支付的 | 工資（最低工資法第4條對象） | 工賃 |
| 最低工資的減額 | 需都道府縣勞動局長許可（同法第7條） | 非工資，不在最低工資法框架內 |
| 社會保險 | 作為勞工，滿足要件時為健康保險・厚生年金保險・雇用保險對象 | 無雇用關係，利用者非勞動保險・社會保險被保險人 |
| 勞動時間・休息 | 勞動基準法對象 | 非勞動基準法的勞工 |

A型利用者是否加入健康保險・厚生年金保險，以與職員相同的判斷軸（4分之3基準與短時數勞工的適用擴大）觀察。雇用保險以每週20小時為分界。因是否取得減額特例許可會改變工資設計，要點在於使就業規則・薪資規程與雇用契約書和實際勤務時間一致。惟個別利用者是否核准減額特例、比率為何，本文不下結論。

## 人員配置的勞務與指定申請，該找誰？

開業與營運的準備，依負責的事業體而分。

| 論點 | 負責 |
|---|---|
| 職員・A型利用者的雇用契約、就業規則・薪資規程、留意常勤換算的勤務體制、社會・勞動保險手續 | 社會保險勞務士（本事務所） |
| 指定申請・變更申報等自治體手續、報酬（國保連請求）的制度設計 | 行政書士・事業者 |
| 事業所物件的選定・租賃 | 不動產 |
| 法人的會計・稅務 | 稅理士 |
| 事業所的登記 | 司法書士 |

指定申請屬行政書士的業務，四葉行政書士事務所與本事務所各自獨立的事業體。物件由四葉不動產株式会社承接，這也是另一事業體。必要時，我們會請客戶另行簽約，本事務所不收取介紹費。

## 四葉社会保険労務士事務所能做什麼？

本事務所承接的是滿足人員基準的勞務設計與其維持。

- 反映常勤・非常勤所定勞動時間的雇用契約書作成（含與A型利用者的雇用契約）
- 留意常勤換算的勤務體制・排班設計，以及勤務實績記錄的整備
- 就業規則・薪資規程的整備
- 職員・A型利用者的社會保險・雇用保險加入判定與手續
- 勞動時間・休息・加班時間管理的設計

以下不由本事務所處理。

- 指定申請・變更申報等自治體手續，以及報酬（國保連請求）的制度設計 → 由四葉行政書士事務所作為另一事業體承接
- 事業所物件的選定・租賃 → 由四葉不動産株式会社作為另一事業體承接
- 法人的會計・稅務 → 轉介稅理士
- 事業所的登記 → 轉介司法書士

四葉不動産株式会社、四葉行政書士事務所、四葉社会保険労務士事務所，各自獨立的事業體受任業務。轉介其他專家時，也請客戶直接簽約，本事務所不收取介紹費。

## 常見問題

**Q. A型與B型，職員的人員基準不同嗎？**
A. 職員人員基準的骨架（職業指導員・生活支援員以常勤換算為利用者數÷10以上、各1人以上・其中1人以上常勤，服務管理責任者於利用者60人以下1人以上）在A型與B型是共通的想法。不同的是利用者的定位：A型與利用者締結雇用契約（基準第190條），B型不締結。即使職員側基準相同，A型另加上利用者作為勞工的勞務管理。

**Q. 只用兼職職員能滿足人員基準嗎？**
A. 只要滿足常勤換算的數字，以非常勤・兼職的組合滿足基準本身是可能的。惟職業指導員・生活支援員需各1人以上，其中1人以上為常勤。若不置常勤、只靠兼職運作，會卡在此常勤要件而無法滿足基準。在就業規則明確「常勤應工作的時數」，是常勤換算計算的前提。

**Q. A型的利用者也必須支付最低工資嗎？**
A. A型與利用者締結雇用契約，該利用者屬勞工，有支付最低工資額以上工資的義務（最低工資法第4條）。若有因障害而勞動能力顯著偏低等情事，經都道府縣勞動局長許可，可將最低工資以一定比率減額（同法第7條）。未經許可不得低於最低工資。個別是否核准、比率為何，本文不下結論。

**Q. 職員未滿10人也需要就業規則嗎？**
A. 勞動基準法第89條的作成・申報義務，發生於經常使用10人以上勞工的事業場。未滿10人則此義務本身不發生。惟將常勤換算前提的「常勤應工作的時數」，以及含A型利用者在內的工資想法整理為規程，不論人數，在實務上多屬必要。請將作為義務的就業規則，與為營運而整備的規程，視為目的不同。
