**先講結論**：特定技能1號的外國人，接收企業須製作支援計畫並實施義務性支援10項目。不委託登錄支援機關、由自家公司實施即為「自家支援」。自家支援有支援體制的基準：須自過去2年內適當接收或管理中長期在留者（就勞資格）或處理其生活諮詢的職員中，選任支援責任者與支援擔當者（每個事業所各1名以上），並具備能以外國人充分理解的語言中立地實施支援的體制（出入國管理及難民認定法第2條之5、平成31年法務省令第5號）。無法繼續自家支援時，可切換為委託登錄支援機關。運作支援的勤怠・工資・就業規則・社會保險等勞務由社會保險勞務士辦理；在留諸申請的取次與支援計畫的申報由行政書士（申請取次）或登錄支援機關辦理；許否的判斷由出入國在留管理廳作成（各自為獨立的事業體、另行簽約）。

「每月付給登錄支援機關的委託費是負擔，想自家公司做支援」「切換為自家支援的要件是什麼」——這是接收特定技能1號外國人的企業常有的諮詢。本頁面是為了不委託登錄支援機關、想自家支援的接收企業勞務負責人，整理運作義務性支援10項目的體制與其勞務的整備方式。在留資格的該當性與許否的展望，不在本文範圍內（判斷由出入國在留管理廳作成）。

## 自家支援與委託登錄支援機關，該選哪一個？

特定技能1號的接收機關（特定技能所屬機關），負有製作支援計畫並依計畫實施支援的義務。可選擇自家公司實施，或委託登錄支援機關。若將支援全部委託登錄支援機關，接收機關即視為滿足支援體制的基準。要自家實施（自家支援），須自行滿足下表的支援體制基準。

| | 自家支援 | 全部委託登錄支援機關 |
|---|---|---|
| 支援體制的基準 | 接收機關自行滿足 | 因委託而視為滿足 |
| 委託費 | 不需要（須有社內人事費） | 每名支援對象者須有每月委託費 |
| 實施主體 | 自家的支援責任者・支援擔當者 | 登錄支援機關 |
| 適合的場面 | 有中長期在留者的接收實績・多語言對應人才 | 實績或語言體制尚未整備 |

接收1名外國人，在留資格的申請、勞動・社會保險的申報、住居的確保會同時啟動。其整體面貌整理於[僱用1名外國人需要幾個窗口](/zh-tw/labor/column/gaikokujin-koyo-madoguchi-wakekata)。分野別的勞務，照護請見[照護的特定技能外國人勞務與社會保險](/zh-tw/labor/column/kaigo-tokutei-ginou-gaikokujin-roumu-shakaihoken)，外食・自技能實習移行請見[自技能實習移行至特定技能](/zh-tw/labor/column/ginou-jisshu-tokutei-ginou-ikou-gaishoku-shakaihoken)。

## 要自家運作義務性支援10項目，需要什麼體制？

義務性支援，是必須納入支援計畫、必須實施的10項目。與任意性支援不同，不可省略。要自家運作，須將各項目由誰・何時・以何種語言實施，作為社內角色事先決定。

| 義務性支援10項目（概要） | |
|---|---|
| ①事前指導（說明勞動條件・活動內容・入國手續・有無收取保證金等） | ⑥提供日語學習機會 |
| ②出入國時的接送 | ⑦諮詢・申訴的對應（以能充分理解的語言） |
| ③住居確保・生活必要契約（銀行帳戶・手機・水電瓦斯等）的支援 | ⑧促進與日本人的交流 |
| ④生活導覽 | ⑨（因接收方緣故解除雇用契約時的）轉職支援 |
| ⑤公家手續等的同行 | ⑩定期面談（3個月1次以上）・向行政機關通報 |

- ③的住居確保，若準備宿舍則租賃由不動產公司辦理，該宿舍若屬勞動基準法的事業附屬宿舍，宿舍規則的申報亦必要（[宿舍規則的申報](/zh-tw/labor/column/gaikokujin-kishukusha-kisoku-todokede-roumu)）
- ⑦的諮詢・申訴對應與⑩的定期面談，以能以外國人充分理解的語言實施的體制為前提
- 支援的實施狀況須記錄於文書，自雇用契約終了日起備置1年以上

義務性支援雖為入管制度上的義務，但日日運作它的基礎，是勤怠管理・工資支付・就業規則・社會保險等勞務。報酬須為與日本人從事同一工作時同等以上，勞動・社會保險的適當加入亦為接收的前提。

## 支援責任者・支援擔當者由誰擔任？中立性的要件是什麼？

自家支援中，須選任支援責任者與支援擔當者（可同一人・每個事業所各1名以上）。並非誰都能選，須顯示能適當實施支援的體制。基準是自符合下列任一的職員中選任。

- イ 過去2年內適當接收或管理中長期在留者（限就勞資格）有實績，並自職員中選任
- ロ 自職員中、過去2年內具有從事中長期在留者生活諮詢等經驗者中選任
- ハ 自職員中、能與イ・ロ同程度適當實施支援業務者中選任

此外，支援責任者・支援擔當者須為能中立地實施支援計畫的立場。運用要領說明：對支援對象外國人具指揮命令・監督立場者，不能謂為中立立場（2026年9月參照）。因其負有於定期面談中拾取不滿與法令違反的角色，其宗旨在於安置能以獨立於當事人之眼審視的人。這些基準的細部可能修訂，須以出入國在留管理廳的特定技能運用要領確認最新版。接收華語圈人才時的採用・在留勞務，亦整理於[中國・台灣人才的採用與在留](/zh-tw/labor/column/gijinkoku-chuka-taiwan-jinzai-saiyo-roumu-zairyu)。

## 無法繼續自家支援時，會怎樣？

因支援擔當者離職或體制變化，可能無法滿足自家支援的基準。若放任支援體制基準未滿足，即成為未能適當實施支援計畫的狀態，也影響此後的在留諸申請。無法繼續時，可切換為將支援全部委託登錄支援機關。

- 切換為全部委託後，接收機關即視為滿足支援體制的基準
- 伴隨委託或支援計畫變更等而向出入國在留管理廳的申報・申請取次，由行政書士（申請取次）或登錄支援機關辦理
- 社會保險勞務士負責伴隨體制變更的勤怠・工資・就業規則・社會保險側的整備。各自為獨立的事業體、另行簽約

是否選擇自家支援，須比較有無實績與人才、以及委託費與社內負擔來決定。開始後也須定期檢視能否維持體制，若變得困難，儘早檢討切換為委託。

## 常見問題

**Q. 想不委託登錄支援機關而切換為自家支援，需要資格嗎？**
A. 不需要特別資格，但須滿足支援體制的基準。須自過去2年內適當接收・管理中長期在留者（就勞資格）或處理其生活諮詢的職員中，選任支援責任者與支援擔當者，並須有能以外國人充分理解的語言中立地實施支援的體制（平成31年法務省令第5號）。實績或語言體制尚未整備時，委託登錄支援機關較為實際。

**Q. 義務性支援的10項目，可以只自家做一部分、其餘委託嗎？**
A. 支援原則上整體一併實施。若將支援全部委託登錄支援機關，接收機關即視為滿足支援體制的基準，惟一部委託的可否與範圍依運用要領的規定。若出現無法實施的項目，即欠缺支援計畫的適當實施，故體制有不安時，應檢討全部委託。最新取扱以出入國在留管理廳的運用要領確認。

**Q. 支援擔當者可以是該外國人的直屬上司嗎？**
A. 運用要領說明：對支援對象外國人具指揮命令・監督立場者，不能謂為中立立場。因其負有於定期面談中拾取不滿與法令違反的角色，其宗旨在於安置能以獨立於當事人之眼審視的人。在僅有直屬上司的小規模體制，須確認能否保持中立性後選任。

**Q. 支援擔當者離職，無法繼續自家支援。該怎麼辦？**
A. 可切換為將支援全部委託登錄支援機關。切換後接收機關即視為滿足支援體制的基準。伴隨委託或支援計畫變更而向出入國在留管理廳的申報・申請取次由行政書士（申請取次）或登錄支援機關辦理，勤怠・工資・社會保險等勞務側的整備由社會保險勞務士負責（各自為獨立的事業體、另行簽約）。
