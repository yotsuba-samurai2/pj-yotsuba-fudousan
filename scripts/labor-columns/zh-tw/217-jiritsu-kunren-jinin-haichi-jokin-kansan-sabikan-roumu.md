**結論（先講重點）**：自立訓練（生活訓練・機能訓練）的人員配置，先從把指定基準（依身心障礙者綜合支援法所定指定身心障礙福祉服務事業等之人員、設備及營運基準＝平成18年厚生勞動省令第171號）第156條（機能訓練）、第166條（生活訓練）所定員數，讀成「以常勤換算須滿足多少人份的勤務時間」開始設計。機能訓練須將護理人員、理學療法士等與生活支援員的**合計**，以常勤換算達**利用者數除以6以上**（同令第156條第1項第1號）；生活訓練須將生活支援員以常勤換算達「通所利用者除以6」與「宿泊型自立訓練利用者除以10」之**合計以上**（同令第166條第1項第1號），且各附帶服務管理責任者與各職種至少1人常勤的要件。本文整理社會保險勞務士負責的常勤換算計算、社會保險與雇用保險的加入門檻、含夜間與訪問的勞動時間管理、工作規則與雇用契約的範圍，並將基準本身的解釋與指定申請文件交由行政書士處理。

「指定基準的人數雖已滿足，但在特休或研修抽離時不致低於基準的排班該怎麼組」「宿泊型配置夜間支援後，勞動時間與加給工資如何計」——這是開設、營運自立訓練事業所的法人、個人勞務負責人常提出的諮詢。本頁以自立訓練的人員配置為前提，整理常勤換算、社會保險、勞動時間管理與工作規則這一勞務設計。基準本身的適合與指定申請的許否，屬指定權者（都道府縣、市町村、指定都市等）與申請實務的範疇，本文聚焦於勞務的思考。

## 以勞務的視角，如何解讀自立訓練的人員基準？

自立訓練是身心障礙者綜合支援法訓練等給付中的生活訓練與機能訓練兩類型。從業者的員數，依類型分別規定於指定身心障礙福祉服務之人員、設備及營運基準（平成18年厚生勞動省令第171號）的不同條文。骨架如下（細目與取扱因制度改正與自治體營運而異，最終適合以指定權者的手引確認）。

| 類型 | 主要職種與配置的考量 |
|---|---|
| 機能訓練（第156條第1項第1號） | 護理人員、理學療法士、作業療法士、言語聽覺士與生活支援員的**合計**，以常勤換算達**利用者數除以6以上**。護理人員、療法士、生活支援員各須1以上 |
| 機能訓練（同條同項第2號） | 服務管理責任者：利用者60人以下為1以上；61人以上每超過40人（或其端數）加1 |
| 生活訓練（第166條第1項第1號） | 生活支援員以常勤換算達「**通所利用者除以6**」與「**宿泊型自立訓練利用者除以10**」之合計以上 |
| 生活訓練（同條同項第2號、第3號） | 辦理宿泊型時須配置地域移行支援員1以上。服務管理責任者與機能訓練同 |
| 管理者 | 原則常勤、專任（於不生妨礙之範圍內得兼任） |

須掌握的是，**人員基準多以「常勤換算＝勤務時間總量」而非「人頭」訂定**。正因如此，誰於何時入班幾小時的排班方式，直接左右對基準的適合。此外，**機能訓練須護理人員、生活支援員、服務管理責任者各至少1人常勤**（第156條第6項至第8項），**生活訓練須生活支援員與服務管理責任者各至少1人常勤**（第166條第6項、第7項），此與雇用契約、勤務表的設計直接相關。社會保險勞務士負責的不是「配置人數」，而是「滿足該人數的勤務作法」——排班設計、雇用契約、工作規則與薪資規程的整備、勞動時間管理、社會保險的資格得喪手續。基準本身的解釋與指定申請文件屬行政書士業務，所依法律不同。

## 常勤換算如何計算，兼職可用到什麼程度？

常勤換算數是**將該事業所從業者的勤務延時數，除以常勤者應勤務的時數所得之數**。機能訓練、生活訓練的必要數，均以此概念作為「勤務時間總量」滿足。身心障礙福祉與照顧共通的常勤換算算法，整理於[身心障礙福祉、照顧的常勤換算如何計算](/zh-tw/labor/column/shogai-fukushi-kaigo-jokin-kansan-keisan-jinin)。

| 項目 | 內容 |
|---|---|
| 計算式 | 常勤換算數＝（全體職員的勤務延時數）÷（常勤者應勤務的時數） |
| 常勤應勤務時間 | 工作規則所定的所定勞動時間（例：每週40小時）。勞動基準法第32條上限為1日8小時、1週40小時 |
| 兼職（部分工時）職員 | 以實際勤務時間計入延時數；以時間、而非人頭計 |
| 常勤要件 | 即使滿足常勤換算，仍另有「各職種至少1人為常勤」的要件，僅憑兼職無法滿足 |
| 端數、餘裕 | 為使特休、缺勤、研修致延時下降時不致低於基準，宜留餘裕編組 |

須注意的是，**常勤換算以勤務時間總量、而非人頭來看**。每週40小時的常勤1人，與每週20小時的兼職2人，於常勤換算上同為「1」。另一方面，**常勤要件（各職種至少1人）無法以時間替代**。即使增厚兼職以滿足常勤換算，未配置常勤者仍可能構成低於基準。兼職可用到何種程度，取決於「常勤換算的總量」與「常勤要件」兩面，這是勞務設計的起點。

## 社會保險、雇用保險從哪些職員開始加入？

職員的社會保險（健康保險、厚生年金保險）與勞動保險（雇用保險、勞災保險），其加入門檻由與人員基準不同的法律決定。法人事業所原則為健康保險、厚生年金保險的強制適用事業所。勞災保險原則上涵蓋所雇用的全體勞工（含兼職、工讀）。

| 保險 | 主要加入門檻 |
|---|---|
| 健康保險、厚生年金保險（一般） | 每週所定勞動時間與每月所定勞動日數，達一般勞工**大致4分之3以上**者（[4分之3基準的細節](/zh-tw/labor/column/tanjikan-koyo-shakaihoken-4bunno3)） |
| 健康保險、厚生年金保險（短時間勞工） | 於特定適用事業所（現為**被保險者51人以上**），每週20小時以上、所定內薪資每月8.8萬日圓以上、非學生等要件者 |
| 雇用保險 | 每週所定勞動時間20小時以上且有31日以上雇用見込者（雇用保險法第6條） |
| 勞災保險 | 所雇用的勞工原則全員（手續由事業主統一辦理） |

此處須注意，**短時間勞工的社會保險適用正分階段擴大**。依厚生勞動省資料，企業規模（被保險者數）要件將由51人以上下修為36人以上（2027年10月）、21人以上（2029年10月）、11人以上（2032年10月），並於2035年10月撤廢。每月8.8萬日圓的薪資要件之撤廢，預定於確認全國最低工資達到1,016日圓後，於年金制度改正法公布起3年內以政令所定之日施行，具體施行日尚未確定（2026年10月起施行者，為對新加入的短時間勞工減輕保險料負擔、合計3年的特例＝保險料調整制度，與薪資要件撤廢日屬不同施策。最終施行日與要件以厚生勞動省官方資料確認）。自立訓練事業所常大量使用兼職生活支援員，故**縱使現為對象外，亦宜於開設時審視是否為日後因規模要件下修而將加入之職員**的設計。分階段擴大的全貌，整理於[社會保險的適用擴大（2027年起）](/zh-tw/labor/column/shakaihoken-tekiyo-kakudai-2027)。

## 含夜間支援或訪問時，勞動時間管理如何設計？

宿泊型自立訓練有時於夜間配置地域移行支援員等，通所的機能訓練、生活訓練亦有訪問利用者住處進行訓練的運用。勞動時間管理易生疑義之處如下。

| 論點 | 勞務上的處理 |
|---|---|
| 夜間勤務 | 午後10時至午前5時的勞動有深夜加給（勞動基準法第37條、25%以上）。只要是實際勞動即為工資對象 |
| 宿直、日直 | 若屬常態幾無勞動的態勢，得經勞動基準監督署長許可，以宿直、日直處理（勞動基準法第41條第3號、同施行規則第23條）。未經許可而於深夜如常勤務者，為加給對象 |
| 訪問的移動時間 | 處於事業所指揮命令下的移動可能構成勞動時間。於勤務表記錄訪問、移動、訓練的區別 |
| 變形勞動時間制 | 若日、週有繁閑，以1個月單位（第32條之2）、1年單位（第32條之4）變形勞動時間制收於法定勞動時間內。選法見[變形勞動時間制與彈性工時如何選擇](/zh-tw/labor/column/henkei-roudoujikan-flextime-erabikata) |
| 休憩 | 逾6小時45分、逾8小時1小時以上（勞動基準法第34條）。休憩中若有應對義務則為手待時間，可能構成勞動時間 |

把夜勤稱為「宿直」便可免加給，此種誤解甚危。**宿直的許可以實態幾無勞動的態勢為前提**，夜間若有常態的支援業務，則作為通常勞動時間而為加給對象。團體家屋等的夜勤、宿直之區分，亦整理於[夜勤與宿直有何不同](/zh-tw/labor/column/group-home-yakin-shukuchoku-roudou-chigai)。欲使職員從事時間外、休日勞動，須締結並申報36協定（勞動基準法第36條），上限原則為每月45小時、每年360小時。

## 工作規則與雇用契約，開設前須先決定什麼？

欲持續滿足人員基準，先以工作規則、雇用契約固定勤務框架是關鍵。開設前宜先決定者如下。

- **工作規則的製作、申報**。經常僱用10人以上勞工的事業場有製作、申報義務（勞動基準法第89條）。未滿10人亦宜就勞動時間、休日、薪資訂定規則以穩定營運。從幾人起，見[工作規則從幾人開始須製作與申報](/zh-tw/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)
- **勞動條件的明示**。於締約時以書面等明示所定勞動時間、休日、薪資、有無更新等（勞動基準法第15條）。兼職生活支援員宜於契約明確計入常勤換算的實勤務時間
- **常勤、兼職的區別與常勤要件的分配**。預先決定以誰的雇用契約滿足各職種至少1人常勤的要件
- **變形勞動時間制、夜間支援的規則**。宿泊型者將夜間勤務體制、有無宿直、加給工資的計算方式落實於薪資規程
- **客觀記錄勤務實績的體制**。將始業、終業時刻、休憩、職務之別（兼任時）留於勤務表與打卡紀錄，俾日後可查核常勤換算是否滿足

未付工資的消滅時效目前為3年（勞動基準法第115條、附則），加給工資計算有誤時，恐遭一併請求3年份。夜間、變形勞動愈多的事業所，愈應將加給工資的設計做正確，以為防備。

## 人員的勞務與指定申請，該分別委託給誰？

自立訓練的開設、營運，判斷的主體各有分別。將角色切分、各自委由其專業者，較為安全。

| 要做的事 | 屬誰的範疇 |
|---|---|
| 排班設計與常勤換算管理、工作規則、薪資規程、36協定、變形勞動時間制的整備、勞動時間管理、社會保險與雇用保險手續 | **社會保險勞務士**（四葉社会保険労務士事務所） |
| 人員基準的解釋、自立訓練的指定申請與變更申報文件、法人章程事業目的的整理 | **行政書士**（四葉行政書士事務所） |
| 物件的用途地域、構造、採光、避難、消防之適否 | 宅地建物交易業者、建築士 |
| 所有權移轉等登記、法人設立登記 | 司法書士 |
| 報酬請求相關稅務 | **稅理士** |
| 未付工資的請求、紛爭、勞動審判、訴訟 | **律師** |

四葉社会保険労務士事務所與四葉行政書士事務所為**獨立的事業體**。勞務交由社會保險勞務士、指定申請交由行政書士，須**分別承接、另行簽約**（分離受任）。彼此不收授介紹費。對應人員基準的勞務見[對應人員基準的勞務](/zh-tw/labor/services/jinin-kijun-roumu)，照顧、身心障礙福祉的勞務見[照顧、身心障礙福祉的勞務管理](/zh-tw/labor/services/kaigo-roumu)。**諮詢免費。** 費用請見[報酬額表](/zh-tw/labor/ryokin)，常見問題請見[常見問答](/zh-tw/labor/faq)。

## 常見問題

**Q. 自立訓練的人員，可僅以兼職（部分工時）湊齊嗎？**
A. 常勤換算的總量雖可以兼職的實勤務時間滿足，但另有「各職種至少1人為常勤」的常勤要件（機能訓練＝平成18年厚生勞動省令第171號第156條第6至8項、生活訓練＝同令第166條第6、7項）。未配置常勤者而僅憑兼職無法滿足，故須先決定以誰的雇用契約滿足常勤要件。此為雇用契約與排班的設計問題，屬社會保險勞務士涉及的範圍。

**Q. 常勤換算以「人頭」滿足即可嗎？**
A. 否。常勤換算以勤務時間總量來看，為全體職員的勤務延時數除以常勤者應勤務時數之數。因特休、缺勤、研修致延時下降時有低於基準之虞，故以留有餘裕的排班為前提。

**Q. 宿泊型的夜間支援，以宿直處理即可免加給工資嗎？**
A. 得以宿直處理者，限於實態幾無勞動的態勢並經勞動基準監督署長許可之情形（勞動基準法第41條第3號、同施行規則第23條）。夜間若有常態支援業務，即為通常勞動時間，午後10時至午前5時為深夜加給（同法第37條、25%以上）對象。須按實態設計。

**Q. 人員基準的適合與勞務，可委託同一人嗎？**
A. 因所依法律不同，宜分開考量。人員基準的解釋與指定申請文件為行政書士；排班設計、工作規則、勞動時間管理、社會保險的勞務為社會保險勞務士。於四葉，四葉行政書士事務所與四葉社会保険労務士事務所為獨立的事業體，以另行簽約的方式分擔。
