**結論（先講重點）**：勞動基準監督署的調查（臨檢監督）來時，基本流程是出示被要求的帳簿・書類，收到改正勸告書或指導票後，在期限內完成改正並提出改正報告書。臨檢與帳簿提出是勞動基準法第101條所定監督官的權限，拒絕或虛偽記載屬第120條罰則的對象。平時整備好法定三帳簿・36協定・工作規則，是在調查中不陷入困境的最佳準備。

## 勞動基準監督署的調查（臨檢）有哪些種類，為何會來？

勞動基準監督署的調查稱為「臨檢監督」，由勞動基準監督官進入事業場，確認帳簿與勞動實況。依據為勞動基準法第101條：監督官得對事業場、宿舍及其他附屬建設物臨檢，要求提出帳簿及書類，並對使用者或勞工進行詢問（且須攜帶證明其身分的證票）。依厚生勞動省・都道府縣勞動局的運用，調查大致分為下列各類。

| 種類 | 契機 |
|---|---|
| 定期監督 | 依年度計畫選定對象進行的通常監督 |
| 申告監督 | 因勞工的申告（第104條）而進行的監督 |
| 災害時監督 | 發生勞動災害時，為究明原因・防止再發而進行的監督 |
| 再監督 | 為確認對過去改正勸告的因應而進行的監督 |

勞工於事業場有違反法令的事實時，得向行政官廳或勞動基準監督官申告其事實，使用者不得以申告為由對勞工解僱或其他不利對待（第104條）。亦即「為何會來」，可能是計畫性的定期監督，也可能以員工的申告或勞災的發生為契機（調查的分類屬厚生勞動省・勞動局的運用，2026年11月12日參照）。

## 當天會被看什麼、被要求哪些帳簿・書類？

臨檢中，勞動時間・工資・安全衛生的實況會與帳簿對照確認。核心是法令所定須製作・保存的書類。

| 書類 | 依據 |
|---|---|
| 勞工名簿 | 勞動基準法第107條 |
| 工資台帳 | 第108條 |
| 出勤簿・打卡等勞動時間的紀錄 | 勞動時間的紀錄（第108條工資計算的基礎） |
| 時間外・休日勞動的協定書（36協定） | 第36條 |
| 工作規則（經常僱用10人以上的事業場） | 第89條 |
| 健康檢查紀錄・安全衛生相關書類 | 勞動安全衛生法等 |

勞工名簿・工資台帳・出勤簿即所謂法定三帳簿，須製作並保存一定期間（詳見[法定三帳簿的整備與保存](/zh-tw/labor/column/hotei-san-choubo-seibi-hozon)）。勞動安全衛生法第91條亦有監督官立入檢查・詢問・物件檢查的權限，安全衛生面也可能一併確認。若拒絕提出被要求的帳簿書類，或提出有虛偽記載的帳簿書類，依勞動基準法第120條第4項，屬30萬日圓以下罰金的對象。當天，基本做法是迅速出示被要求的書類，不清楚之處則確認後再答覆。

## 「改正勸告」與「指導票」有何不同，置之不理會如何？

作為調查結果交付的書面，主要有改正勸告書與指導票。兩者都不是有法律明文的「處分」，而是作為行政指導交付的文書。

| 書面 | 交付場合 | 定位 |
|---|---|---|
| 改正勸告書 | 認定有法令違反時 | 載明違反事項・改正內容・改正期限的行政指導 |
| 指導票 | 雖未達法令違反，但認定改善為宜時 | 載明改善事項的行政指導 |

改正勸告書與指導票都是行政指導，本身並非得提起不服申立的行政處分。惟若置之不理，可能進行再監督，在惡質・重大情形下，可能導致後述的送檢或企業名稱的公布。依勞動安全衛生法，於勞動災害危險迫切等情形，可能發出使機械・設備停止使用等的處分（使用停止命令），此為行政處分。收到後，確認指摘的依據條文與改正期限、整理何者須於何時改正，是出發點。

## 改正報告書要在何時・如何撰寫？若查出未付加班費？

收到改正勸告書或指導票後，在指定期限內完成改正，並提出改正（改善）報告書。報告書中，就被指摘的各事項，具體寫明如何改正（或改正的計畫與時期）。

| 步驟 | 內容 |
|---|---|
| 整理指摘 | 將指摘事項・依據條文・改正期限列表 |
| 確認事實 | 將勞動時間・工資的實況與帳簿對照確認 |
| 實施改正 | 修訂規程、檢討運用、補付不足分等 |
| 製作報告書 | 就各事項記載改正內容・時期，於期限內提出 |

典型的指摘是未付的加成工資（加班費）。若勞動時間的紀錄與工資台帳不一致，可能被要求追溯補付不足分。採用固定加班費（視為加班費）時，會確認其是否符合要件、是否另付超過部分（見[固定加班費合法的要件與差額結算](/zh-tw/labor/column/kotei-zangyodai-tekiho-youken-sagaku-seisan)）。若難以於期限內改正，切勿置之不理，應提示改正的計畫與預定時期並洽商。改正報告書的製作支援與勞動時間・工資實況的整理，屬社會保險勞務士的領域。諮詢費用請見[報酬額表](/zh-tw/labor/ryokin)。

## 在何種情形會走到送檢・公布企業名稱？

多數案件以改正報告結束，但惡質・重大案件可能進入刑事程序。勞動基準監督官就違反勞動基準法之罪，執行刑事訴訟法所定司法警察官的職務（第102條）。亦即監督官於一定情形下，具偵查並將案件移送檢察官（送檢）的權限。

| 階段 | 概要 |
|---|---|
| 改正勸告・指導 | 行政指導；通常於期限內改正即結束 |
| 再監督 | 確認改正狀況；未改正則反覆進行 |
| 送檢 | 就惡質・重大違反，依第102條移送檢察官 |
| 公布企業名稱 | 就違法長時間勞動或送檢案件等，可能依厚生勞動省的運用公布企業名稱 |

走到送檢或公布的，多為惡質・重大案件——反覆無視改正勸告、隱匿重大勞動災害、出示虛偽帳簿等（企業名稱公布係依厚生勞動省的運用，2026年11月12日參照）。送檢後的刑事程序、就行政指導・處分的因應所生法律爭議、就未付工資的訴訟，屬律師的領域。從何處為社會保險勞務士、從何處為律師，亦可參考[解僱因應是社勞士還是律師](/zh-tw/labor/column/kaiko-sharoushi-bengoshi-dochira)的切分。這些與社會保險勞務士事務所各自獨立為事業體，前提是分別簽約而切分。沒有介紹費。

## 平時整備好什麼，調查時就不會困擾？

對調查最好的準備，是平時的勞務管理。平時就把臨檢核心的書類整備好，調查來時也能從容因應。

| 要整備的事項 | 重點 |
|---|---|
| 法定三帳簿 | 製作勞工名簿・工資台帳・出勤簿，並遵守保存期間 |
| 勞動時間的紀錄 | 以打卡等客觀掌握，並與工資計算一致 |
| 36協定 | 於時間外・休日勞動前締結・申報；在上限規制範圍內運用 |
| 工作規則 | 經常10人以上則製作・申報；與實況一致 |
| 加成工資 | 檢視加班費計算方法；固定加班費須確認要件與差額結算 |

36協定的締結・申報與上限規制的運用，整理於[36協定能委託社勞士到什麼程度](/zh-tw/labor/column/36-kyotei-zangyo-sharoushi-doko-made)；工作規則的製作義務與內容，整理於[工作規則的製作義務與內容](/zh-tw/labor/column/shugyokisoku-10nin-gimu-nani-ga-hitsuyo)。平時把這些整備好並留下紀錄，是對調查最好的準備。帳簿・協定・工作規則的整備，以及調查來時的改正報告書製作支援，屬社會保險勞務士的領域。常見問題整理於[常見問答](/zh-tw/labor/faq)。

## 常見問題

**Q. 勞動基準監督署的調查可以拒絕嗎？**
A. 無正當理由不得拒絕。勞動基準法第101條規定，勞動基準監督官得對事業場臨檢、要求提出帳簿及書類、對使用者・勞工詢問。拒絕・妨礙・忌避臨檢，對詢問不陳述，不提出帳簿書類，或提出有虛偽記載的帳簿書類，依第120條第4項屬30萬日圓以下罰金的對象。日程的調整可洽商，但拒絕調查本身並不適切。

**Q. 改正勸告書是行政處分嗎？有不服可以爭訟嗎？**
A. 改正勸告書與指導票都不是有法律明文的行政處分，而是作為行政指導交付的文書。因此其本身並非得作為處分撤銷爭訟的對象。惟若對指摘的依據或事實認定有疑問，應確認依據條文與事實後，向監督署說明・協議。送檢、行政處分、就未付工資的訴訟等法律爭議的階段，屬律師的領域。

**Q. 調查中查出未付加班費，要追溯到何時補付？**
A. 一般會被要求結算加成工資的不足分。追溯的範圍與計算方法，依勞動時間的紀錄與工資台帳確認。採用固定加班費時，會確認是否符合要件、是否另付超過部分。因金額與時效的個別判斷依案件而異，宜將勞動時間・工資的實況與帳簿對照整理，必要時向社會保險勞務士諮詢。若就未付工資發展為訴訟等法律紛爭，屬律師的領域。

**Q. 稅務署的調查與勞動基準監督署的調查是同一回事嗎？**
A. 是不同的。勞動基準監督署的調查（臨檢監督）確認勞動基準法・勞動安全衛生法等勞動相關法令的履行，對象為勞動時間・工資・安全衛生。確認稅捐申報・繳納的稅務調查由稅務署進行，屬稅理士的領域。兩者依據法令與主管機關皆不同，故應就各自獨立的事業體・機關分別諮詢。
