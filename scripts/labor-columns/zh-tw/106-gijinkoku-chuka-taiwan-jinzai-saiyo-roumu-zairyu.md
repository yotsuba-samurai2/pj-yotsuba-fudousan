**結論（先講重點）**：以技術・人文知識・國際業務（技人國）聘用中國・台灣人才時，首先要確認的是「本人的學歷・實務經驗與所交付的職務是否相關」。此處一偏，在留資格的該當性就會崩掉。聘用後的勞務，2024年（令和6年）4月1日起應明示的勞動條件增加，社會保險・雇用保險不問國籍，滿足要件即加入。而加班與工資的糾紛，會在在留期間更新時，作為勞務管理的妥適性而反映。

在留資格的認定・變更・更新的申請取次屬行政書士的業務，社會保險勞務士不能辦理在留申請的取次。與本事務所各自獨立的事業體，請另行簽約。本事務所承接的是勞務・社會保險的設計，個別判斷由資格者在面談後進行。

## 以技人國聘用中國・台灣人才時，首先要確認什麼？

技術・人文知識・國際業務，是規定於出入國管理及難民認定法別表第一之二的就勞在留資格，統合理學・工學等技術領域、法律・經濟・社會等人文知識領域，以及口譯・筆譯・語言指導・海外交易業務等國際業務。是否核准，首先取決於本人的學歷或實務經驗，與所交付職務的關聯性。

| 要確認的事 | 勞務側的看點 |
|---|---|
| 職務內容 | 是否為專門・技術性業務而非單純作業。在雇用契約書具體寫明職務內容 |
| 學歷・實務經驗 | 技術・人文領域需相關學歷或一定年數實務經驗；國際業務原則3年以上實務經驗（語言指導等有例外） |
| 與職務的關聯性 | 大學等的主修或實務經驗，與所交付職務是否連結 |
| 報酬 | 是否為日本人從事同工作時的同等額以上 |

技人國「是否該當」的最終判斷由出入國在留管理廳作出，認定・變更的申請屬行政書士的業務。本事務所設計其前提的職務內容・報酬・勞動條件是否符合勞動關係法令。聘用1名外國人時所動的手續全貌，整理於[聘用1名外國人時，需要幾個窗口](/zh-tw/labor/column/gaikokujin-koyo-madoguchi-wakekata)；偏向高度專門職・IT技術者的論點，整理於[聘用高度專門職（外國人IT・技術者）時的勞務與社會保險](/zh-tw/labor/column/koudo-senmonshoku-gaikokujin-it-koyo-roumu)。

## 勞動條件的明示，母語對應需到什麼程度？

勞動條件的明示是勞動基準法第15條第1項的義務，應明示的事項規定於同法施行規則第5條。2024年（令和6年）4月1日起明示事項增加。以外語（母語）明示本身雖非法律上的義務，但以本人能理解的語言呈示較為安全，厚生勞動省也公開了多語言的示範勞動條件通知書。

| 2024年4月增加的明示事項 | 內容 |
|---|---|
| 就業場所・業務的變更範圍 | 明示將來因配置轉換等可能變動的就業場所・業務範圍 |
| 更新上限 | 有期契約若有更新次數・通算契約期間的上限，其內容 |
| 無期轉換申請機會 | 於無期轉換申請權發生的每次更新時點，該旨 |
| 無期轉換後的勞動條件 | 無期轉換後的勞動條件 |

技人國常以有期契約聘用，此時更新上限與無期轉換的明示直接相關。母語明示雖非義務，但若以純日文的通知書未能傳達內容，會連動到後續糾紛與在留更新時的說明負擔。對外國人的勞動條件明示、含母語對應的論點，整理於[對外國人的勞動條件明示，母語對應需到什麼程度](/zh-tw/labor/column/gaikokujin-roudou-joken-meiji-bogoko-2024)；2024年改正的明示事項本身，整理於[勞動條件明示的2024年改正——變更範圍是什麼](/zh-tw/labor/column/roudou-joken-meiji-2024-henko-han-i)。

## 社會保險・雇用保險，從何時開始加入？

社會保險（健康保險・厚生年金保險）與雇用保險，不問國籍與在留資格，適用規則與日本人相同。在適用事業所常時使用者，滿足要件即自入社時點成為被保險人。不能以「因為是外國人而延後」處理。

| 保險 | 加入的想法 |
|---|---|
| 健康保險・厚生年金保險 | 在適用事業所常時使用者，不問國籍即被保險人。兼職等以4分之3基準，特定適用事業所則為每週20小時以上・月額8.8萬日圓以上・預計使用超過2個月・非學生的要件 |
| 雇用保險 | 每週所定勞動時間20小時以上・預計使用31日以上即被保險人（2028年10月起擬擴大至每週10小時以上） |
| 勞災保險 | 只要是勞工，不問國籍・在留資格皆適用 |
| 外國人雇用狀況的申報 | 每次雇入・離職向公共職業安定所申報（勞動施策總合推進法第28條第1項） |

與母國制度的雙重加入，只能與締結社會保障協定的相手國，以適用證明書調整。與中國有協定，但無年金加入期間通算的規定；與台灣則無協定本身。此差別整理於[中國駐在的社會保障協定與雙重加入](/zh-tw/labor/column/chugoku-chuzai-shakaihosho-kyotei-nijukanyu)、[從台灣聘用・以出向受入時的社會保險](/zh-tw/labor/column/taiwan-koyo-shukko-shakaihoken-kyotei-nashi)。所得稅與日中・日台間的租稅取扱，屬稅理士的領域。

## 影響在留更新的勞務糾紛，如何避免？

在留期間更新時，審查也會看雇用的繼續性與公司勞務管理的妥適性。加班費未付、契約與實態不符，可能在更新場面不利。把勞務整備好，就直接降低更新的風險。

| 易發生的事 | 勞務側的對策 |
|---|---|
| 加班費未付 | 客觀掌握勞動時間，正確計算時間外・深夜・休日的加給（勞動基準法第37條） |
| 契約書與實態的落差 | 使明示的職務內容・就業場所，與實際業務一致 |
| 在留期限與契約期間不一致 | 有期契約的期間・更新上限，與在留期限一併設計 |
| 職務內容的變更 | 影響技人國該當性的配置轉換，事前確認在留資格的觀點 |

在留期限與雇用契約期間各自獨立運行。此設計整理於[在留期限與雇用契約期間，哪個先到期](/zh-tw/labor/column/zairyu-kigen-koyo-keiyaku-kikan)。惟更新是否核准的見込，以及個別雇止的可否等判斷，本文不下結論。核准的判斷由出入國在留管理廳作出，具糾紛性的案件由律師處理。

## 從聘用到在留更新，誰負責什麼？

以技人國聘用中國・台灣人才時，負責的資格分工如下。

| 論點 | 負責 |
|---|---|
| 雇用契約・勞動條件明示、就業規則・薪資規程、社會・勞動保險手續、勞動時間・工資管理 | 社會保險勞務士（本事務所） |
| 在留資格的認定・變更・更新的申請取次、職務與學歷關聯的整理 | 行政書士（申請取次） |
| 所得稅・日中／日台間的租稅取扱 | 稅理士 |
| 對不許可的不服申立等具糾紛性的對應 | 律師 |
| 住居（社宅・租賃）的確保 | 不動產 |

社會保險勞務士不能辦理在留申請的取次，故在留資格的申請必定交由行政書士。四葉行政書士事務所與本事務所各自獨立的事業體，必要時我們會請客戶另行簽約，本事務所不收取介紹費。住居的確保由四葉不動産株式会社承接，這也是另一事業體。

## 四葉社会保険労務士事務所能做什麼？

本事務所承接的是聘用技人國人才時的勞務・社會保險設計。

- 勞動條件明示（含2024改正的變更範圍・更新上限・無期轉換）與雇用契約書的作成
- 就業規則・薪資規程的整備
- 社會保險・雇用保險的加入判定與手續、外國人雇用狀況的申報
- 勞動時間・時間外・加給工資管理的設計
- 為不影響在留更新的勞務管理點檢

以下不由本事務所處理。

- 在留資格的認定・變更・更新的申請取次、職務與學歷關聯的整理 → 由四葉行政書士事務所作為另一事業體承接
- 住居（社宅・租賃）的確保 → 由四葉不動産株式会社作為另一事業體承接
- 所得稅・租稅的取扱 → 轉介稅理士
- 具糾紛性的對應 → 轉介律師

四葉不動産株式会社、四葉行政書士事務所、四葉社会保険労務士事務所，各自獨立的事業體受任業務。轉介其他專家時，也請客戶直接簽約，本事務所不收取介紹費。

## 常見問題

**Q. 以技人國聘用中國・台灣人才時，首先要確認什麼？**
A. 本人的學歷或實務經驗，與所交付職務的關聯性。技術・人文領域需相關學歷或一定年數實務經驗，國際業務原則3年以上實務經驗（語言指導等有例外）為目安，且須為專門・技術性業務而非單純作業。該當性的最終判斷由出入國在留管理廳作出，認定・變更的申請屬行政書士的業務。本事務所依勞動關係法令設計其前提的職務內容・報酬・勞動條件。

**Q. 對外國人必須以母語明示勞動條件嗎？**
A. 以外語（母語）明示本身非法律上的義務。惟以本人能理解的語言呈示較為安全，厚生勞動省公開了英語・中文等多語言示範勞動條件通知書。2024年4月起，就業場所・業務的變更範圍、更新上限、無期轉換相關事項的明示增加（勞動基準法第15條第1項・同法施行規則第5條）。若以純日文的通知書未能傳達內容，會連動到後續糾紛與在留更新時的說明負擔。

**Q. 外國人員工的社會保險・雇用保險從何時加入？**
A. 不問國籍與在留資格，適用規則與日本人相同。在適用事業所常時使用者，滿足要件即自入社時點成為健康保險・厚生年金保險的被保險人，勞災保險只要是勞工全員適用，雇用保險以每週20小時以上・預計使用31日以上加入。與母國制度的雙重加入，只能與協定相手國以適用證明書調整，中國無年金期間通算，與台灣則無協定本身。

**Q. 加班或工資糾紛會影響在留更新嗎？**
A. 在留期間更新時，審查也會看雇用的繼續性與公司勞務管理的妥適性。加班費未付、契約與實態不符，可能在更新場面不利。客觀掌握勞動時間、正確計算時間外・深夜・休日的加給工資、使明示的職務內容與實際業務一致，即為對策。惟更新是否核准的見込，本文不下結論。核准的判斷由出入國在留管理廳作出。
