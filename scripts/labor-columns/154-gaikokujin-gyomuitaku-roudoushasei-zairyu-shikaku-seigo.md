**結論（先に要点）**：外国人を「業務委託（フリーランス）」で起用するときは、**「契約書の名称ではなく働き方の実態で雇用か委託かが判断される（労働者性）」「業務委託という働き方が本人の在留資格と整合するか（技術・人文知識・国際業務などは本邦の機関との契約が前提）」「労働者と判断されれば社会保険・労災・最低賃金が実態の雇用開始時にさかのぼって適用される」**の3点を最初に確かめます。労働基準法上の「労働者」（第9条）に当たるかは、契約の名称ではなく、仕事の依頼を断れるか、指揮監督を受けるか、時間・場所に拘束されるか、報酬が労働の対償かといった実態で判断されます（昭和60年＝1985年の労働基準法研究会報告）。在留資格「技術・人文知識・国際業務」は本邦の公私の機関との契約に基づく活動を前提とするため、業務委託の形が在留資格と整合するかは個別の該当性判断になります。この記事では、労働者性の判断、在留資格との整合、労働者と認定された場合の保険・最低賃金の遡及、契約書の名称だけでは足りない理由を、社会保険労務士の業務範囲で整理します。在留資格の該当性の判断・申請取次は行政書士（申請取次）と出入国在留管理庁、契約・報酬の紛争は弁護士の領分として振り分けます。

「中国・台湾の人材を雇用ではなく業務委託で起用したい」「すでに外国人に業務委託で仕事を出しているが、これで在留資格や保険は大丈夫か」——外国人材を起用する事業者と本人（専門職）からよく受ける相談です。このページは、外国人を業務委託で起用するときの労務（労働者性の判断、在留資格との整合、保険・最低賃金の遡及）を労務の設計として整理します。在留資格の該当性そのものの判断や申請取次、契約紛争の解決は、この記事の範囲外（行政書士・弁護士・出入国在留管理庁の領分）として触れるにとどめます。

## 外国人を業務委託で使うとき、まず何が『雇用』と判断されますか？

労働基準法や最低賃金法が適用される「労働者」かどうかは、契約書の名称（業務委託・請負）ではなく、働き方の実態で判断されます。労働基準法第9条は、労働者を「事業に使用される者で、賃金を支払われる者」と定め、その判断基準は昭和60年（1985年）の労働基準法研究会報告に整理されています。

| 判断の視点 | 労働者と判断されやすい実態 |
|---|---|
| 仕事の諾否の自由 | 個々の依頼を断れない（事実上断れない） |
| 指揮監督 | 業務の遂行方法について具体的な指示を受ける |
| 時間的・場所的拘束 | 勤務時間・勤務場所が指定され拘束される |
| 代替性 | 本人以外の者が代わって業務を行えない |
| 報酬の性格 | 報酬が時間を単位に計算されるなど労働の対償といえる |

これらに加え、機械・器具を自分で負担するか、報酬の額、他社の仕事も受けられる専属性の有無などが補強的に考慮されます。これらを総合して判断するため、名称が「業務委託」でも、実態が指揮監督下の労働なら労働者と判断されます。日本人も含む一般の外注と労働者性の線引きは[外注と雇用の境目はどこで分かれますか](/labor/column/gaichu-koyo-sakaime-roudoushasei)に整理しています。なお、最終的な労働者性の認定は、個別の事実に基づき労働基準監督署または裁判所が行います。

## 技術・人文知識・国際業務などの在留資格は、業務委託と整合しますか？

在留資格「技術・人文知識・国際業務」（技人国）は、出入国管理及び難民認定法の別表第一の二の表で、**本邦の公私の機関との契約に基づいて行う**自然科学・人文科学の分野の技術・知識を要する業務などと定められています。ここが外国人の業務委託で最初につまずく点です。

| 論点 | 内容 |
|---|---|
| 契約の相手 | 本邦の公私の機関（会社・団体・個人も含まれうる）との契約が前提 |
| 契約の形態 | 雇用に限られないが、特定の機関との継続的・安定的な契約が求められる |
| 業務の内容 | 単純作業・反復訓練で足りる業務は該当しないと判断される |
| 不特定多数との単発委託 | 相手が定まらない単発の委託は在留資格の該当性が崩れやすい |

業務委託（フリーランス）の形が在留資格と整合するかは、契約の継続性・安定性や業務の内容を踏まえた個別の該当性判断になります。この該当性の判断と在留諸申請の取次は行政書士（申請取次）と出入国在留管理庁の領分で、社会保険労務士は在留申請の取次ができません。技人国で中国・台湾の人材を採用するときの労務と在留の整合は[技術・人文知識・国際業務で中国・台湾の人材を採るとき何を確かめますか](/labor/column/gijinkoku-chuka-taiwan-jinzai-saiyo-roumu-zairyu)をご覧ください。在留資格の該当性の最終判断は出入国在留管理庁が行います。

## 労働者と判断された場合、社会保険・労災・最低賃金はどう遡りますか？

実態が労働者と判断されると、業務委託として扱ってきた期間にさかのぼって、労働関係の法令が適用されます。遡及の範囲は保険ごとに異なります。

| 項目 | 遡及の考え方 |
|---|---|
| 労災保険 | 労働者であれば当然に適用。事業主が手続していなくても、被災した労働者は給付を受けられる（事業主から費用徴収されることがある） |
| 健康保険・厚生年金保険 | 被保険者資格の確認で、原則として保険料の徴収権の時効（2年）の範囲でさかのぼって加入・保険料負担が生じうる |
| 雇用保険 | 被保険者資格の遡及確認。原則2年、賃金から保険料控除が確認できる場合はそれ以前にさかのぼることがある |
| 最低賃金 | 労働者には最低賃金法が適用され、地域別最低賃金を下回る報酬は差額の支払義務が生じうる |

遡及は、追加の保険料負担や未払賃金の清算につながり、金額が大きくなりがちです。労災は、事業主が未手続でも労働者への給付が行われ、事業主に費用徴収（さかのぼっての保険料と、場合により給付費用の一部）が及ぶことがあります。フリーランスに業務を発注する側の義務（取引条件の明示・報酬支払期日など）は[フリーランスに発注する企業が確認することは何ですか](/labor/column/freelancelaw-hatchu-kigyo-kakunin)に整理しています。遡及の具体的な範囲・金額は、所轄の年金事務所・労働基準監督署・ハローワークで確認します。

## 契約書で『業務委託』と書けば足りますか？（実態優先の落とし穴）

結論として、契約書の文言だけでは足りません。労働者性は実態で判断されるため、「業務委託契約書」という名称や「指揮命令を受けない」との条項があっても、実際に指揮監督下で時間・場所を拘束して働かせていれば、労働者と判断されます。

| よくある誤解 | 実際 |
|---|---|
| 「業務委託契約書」にすれば労働法は適用されない | 名称は決め手にならない。実態で判断される |
| 「委託料」と書けば賃金ではない | 労働の対償なら賃金として扱われうる |
| 本人が同意していれば委託で問題ない | 同意があっても実態が労働者なら法令が適用される |

外国人の場合、この「実態優先」の落とし穴が在留資格の問題と重なります。業務委託のつもりが実態は雇用だった場合、労務面の遡及に加え、在留資格の該当性（技人国は本邦の機関との契約が前提）の見直しが必要になることもあります。さらに、2024年（令和6年）11月1日に施行された特定受託事業者に係る取引の適正化等に関する法律（フリーランス新法）は、業務委託として適正に発注する場合でも、発注者に取引条件の明示・報酬支払期日（給付を受けた日から原則60日以内）などの義務を課しています。労務（労働者性の判断と社会保険・労働保険の手続）は社会保険労務士、在留資格の該当性の判断と申請取次は行政書士（申請取次）、契約・報酬をめぐる紛争は弁護士の業務で、それぞれ独立した事業体として別々にご契約いただきます。

## 労働者性は誰に、在留資格は誰に、契約紛争は誰に相談しますか？

外国人の業務委託では、確かめる主体が3つに分かれます。役割を切り分けて、それぞれの専門家に頼むのが安全です。

| すること | 誰の領分か |
|---|---|
| 労働者性を踏まえた労働条件の設計、社会保険・労働保険の適用判定と手続、最低賃金の確認 | **社会保険労務士**（四葉社会保険労務士事務所） |
| 在留資格の該当性の判断、在留諸申請の取次（業務委託と在留の整合） | **行政書士（申請取次）** |
| 在留資格の許否の判断 | **出入国在留管理庁** |
| 業務委託契約・報酬・労働者性をめぐる紛争 | **弁護士** |

四葉社会保険労務士事務所は、**独立した事業体**として労務を担います。在留資格の該当性の判断・申請取次は行政書士（申請取次）、紛争は弁護士へ、それぞれ**別々にご契約**いただく分離受任の形になります。社会保険労務士は在留申請の取次ができないため、在留資格に関わる部分は必ず行政書士（申請取次）に振ります。紹介料の受け渡しはありません。**ご相談は無料です。** 費用は[報酬額表](/labor/ryokin)を、よくいただくご質問は[よくあるご質問](/labor/faq)をご覧ください。

## よくある質問

**Q. 業務委託契約書を結べば、労働基準法は適用されませんか？**
A. 契約書の名称だけでは決まりません。労働者かどうかは、仕事を断れるか、指揮監督を受けるか、時間・場所を拘束されるか、報酬が労働の対償かといった実態で判断されます（労働基準法第9条・昭和60年の労働基準法研究会報告）。実態が労働者なら、名称が業務委託でも労働基準法・最低賃金法が適用されます。

**Q. 技術・人文知識・国際業務の在留資格で、業務委託として働けますか？**
A. 在留資格は本邦の公私の機関との契約に基づく活動を前提とします。雇用に限られませんが、特定の機関との継続的・安定的な契約が求められ、相手が定まらない単発の委託は該当性が崩れやすいとされます。整合するかは個別の該当性判断で、行政書士（申請取次）と出入国在留管理庁の領分です。

**Q. 業務委託としてきた人が労働者と判断されたら、何がさかのぼりますか？**
A. 労災保険は当然に適用され（未手続でも給付、事業主に費用徴収がありうる）、健康保険・厚生年金・雇用保険は保険料徴収権の時効（原則2年）の範囲で遡及して加入・保険料負担が生じうるほか、最低賃金を下回っていた場合は差額の支払義務が生じうります。範囲・金額は所轄の年金事務所・労働基準監督署・ハローワークで確認します。

**Q. 本人が業務委託に同意していれば問題ありませんか？**
A. 本人の同意があっても、実態が指揮監督下の労働なら労働者と判断されます。労働者性は当事者の合意ではなく実態で判断されるためです。加えて、適正な業務委託であっても、フリーランス新法（2024年11月1日施行）により発注者には取引条件の明示や報酬支払期日などの義務があります。
