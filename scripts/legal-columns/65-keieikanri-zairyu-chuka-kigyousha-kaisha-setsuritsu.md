**結論（先に要点）**：中国・台湾などの起業家が日本で会社を作り、その経営を行うために取得を目指すのが在留資格「経営・管理」です（出入国管理及び難民認定法 別表第一の二）。上陸許可の基準は「出入国管理及び難民認定法第7条第1項第2号の基準を定める省令」に定められ、2025年（令和7年）10月16日施行の改正で、資本金又は出資の総額が3,000万円以上へ引き上げられたほか、常勤職員1人以上の雇用、申請者本人又は常勤職員の一定の日本語能力、経営経験3年以上又は修士等の学位、事業計画の専門家確認、独立した事業所の確保が求められるようになりました。本記事は、要件の全体像と、申請取次を行う行政書士の役割を整理する一般的な情報提供です。個別の許否は出入国在留管理庁の審査によります。

## 「経営・管理」在留資格の主な要件は何？

「経営・管理」は、日本で事業の経営を行い、又は管理に従事する外国人のための在留資格です（出入国管理及び難民認定法 別表第一の二）。上陸許可の基準は同法第7条第1項第2号の基準を定める省令に置かれ、2025年（令和7年）10月16日の改正で内容が大きく変わりました。改正後の主な基準は次のとおりです。

| 事項 | 改正後の基準（2025年10月16日施行） |
| --- | --- |
| 資本金又は出資の総額 | **3,000万円以上**（改正前は500万円以上） |
| 常勤職員 | **1人以上**を雇用。日本人・特別永住者・別表第二の在留資格をもって在留する外国人が対象 |
| 日本語能力 | 申請者本人又は常勤職員が「日本語教育の参照枠」の**B2相当以上**（日本語能力試験N2以上、BJTビジネス日本語能力テスト400点以上などで立証） |
| 経営経験・学歴 | 事業の経営・管理について**3年以上の経験**、又は博士・修士・専門職の学位 |
| 事業計画 | 中小企業診断士・公認会計士・税理士など**専門家による確認**を受けたもの |
| 事業所 | 独立した事業所の確保。**自宅と兼ねることは原則として認められない** |

既に「経営・管理」で在留している方には、施行日から3年（令和10年＝2028年10月16日）までの経過措置が設けられ、その間の更新では改正後の基準に段階的に適合していくことが想定されています。改正の趣旨は、実体を伴わない会社の設立を防ぎ、実質的な事業運営を担保することにあるとされています。四葉行政書士事務所は、行政書士業務の範囲で、要件の確認・立証資料の整理・申請書類の作成・申請の取次を支援します。個別の許否は出入国在留管理庁の審査によります。

## 事業所（オフィス）と資本金はどこまで必要？

改正で特に重くなったのが、資本金と事業所です。

| 事項 | 内容（要旨） |
| --- | --- |
| 資本金・出資の総額 | 法人なら払込済みの資本金の額（合名・合資・合同会社は出資の総額）、個人事業なら事業に投下されている総額で、**3,000万円以上**が求められる |
| 事業所 | 事業を継続的に営むための独立した施設。**自宅兼用は原則不可**とされ、いわゆる住所貸しのみの形態は認められにくい |
| 使用権原 | 賃貸借契約などで事業所を使える権原があること。用途地域・建物用途が事業に適合すること |

事業所は「借りられる物件があるか」だけでなく、用途地域や建物の使い方が事業に合うかの確認が先に必要です。物件を先に契約してから使えないと分かると探し直しになるため、物件選定の段階で確認しておくと安全です。事業所となる物件探しと賃貸借は、別事業体の四葉不動産株式会社（宅地建物取引業者）が独立した事業体として別途ご契約のうえ対応します。当事務所は紹介料を受け取りません。

## 会社設立と在留資格申請はどちらが先？

海外に居住したまま起業する場合、実務上は「会社を設立してから、在留資格を申請する」流れが一般的です。会社（法人）が存在し、資本金・事業所・事業計画が整っていることを前提に、在留資格の審査が行われるためです。

| 段階 | 内容 |
| --- | --- |
| ① 事業計画・資金の準備 | 3,000万円以上の資本金の手当て、事業計画の作成と専門家確認、事業所の確保 |
| ② 会社設立 | 定款作成・認証、出資の払込み、設立登記（登記申請は司法書士） |
| ③ 在留資格の申請 | 在留資格認定証明書交付申請（海外から呼び寄せる場合）等を出入国在留管理庁へ。行政書士が申請を取り次ぐ |
| ④ 入国・事業開始 | 証明書をもとに査証（ビザ）を取得し入国、事業を開始 |

会社設立の登記は司法書士、法人設立届・税務は税理士、事業所の物件は宅地建物取引業者、従業員を雇う際の社会保険・労働保険は社会保険労務士と、担当が分かれます。各事業体は独立した事業体として別々にご契約いただく前提で、当事務所は紹介料を受け取りません。

## 設立登記・税務・社会保険は誰にどう分けて頼む？

「経営・管理」の取得には、行政書士以外の専門家の関与が欠かせません。独占業務の切り分けは次のとおりです。

- 在留資格の要件確認・立証資料の整理・申請書類の作成・申請の取次 → 四葉行政書士事務所（申請取次行政書士）
- 会社の設立登記・役員変更などの登記 → 司法書士
- 法人設立届・税務・記帳・税務相談 → 税理士
- 事業所となる物件探し・賃貸借契約 → 四葉不動産株式会社（宅地建物取引業者）
- 従業員を雇うときの社会保険・労働保険の手続き → 社会保険労務士

四葉行政書士事務所と四葉不動産株式会社は別事業体です。各分野は、それぞれの資格者と独立した事業体として別々にご契約いただく前提で、当事務所は紹介料を受け取りません。登記を行政書士が代理することはできず、税務相談は税理士、登記は司法書士が担います。グループホームなど特定の業種で「経営・管理」を検討する場合の指定申請との関係は、[外国人がグループホーム事業を始めるには（経営・管理在留資格）](/legal/column/group-home-gaikokujin-keieikanri-zairyushikaku)でも扱っています。

## 申請取次の行政書士は何をどこまでできる？

出入国在留管理庁への在留資格の申請は、原則として本人が出頭して行いますが、一定の研修を修了し届け出た行政書士（申請取次行政書士）は、本人に代わって申請書類を提出（取次）できます。これにより、本人が入管の窓口へ出頭する負担を減らせます。

| できること | できないこと |
| --- | --- |
| 要件の確認、立証資料の整理、申請書・理由書の作成、申請の取次 | 許否の保証・断定。審査は出入国在留管理庁が行う |
| 事業計画書の作成支援（数値の妥当性は専門家確認が前提） | 会社の設立登記（司法書士の業務）、税務相談・申告（税理士の業務） |
| 中国語（繁体字・簡体字）・英語での書類説明の窓口 | 個別事案の法的評価の断定。最終判断は資格者・入管による |

申請取次はあくまで手続の代行であり、在留資格が下りることを保証するものではありません。資本金・事業所・日本語能力・事業計画の専門家確認など、改正後の基準を一つずつ満たしていく必要があります。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務の全体像は[許認可・各種申請サービス](/legal/services)をご覧ください。

## よくある質問

**Q. 資本金は本当に3,000万円必要ですか？**
A. 2025年（令和7年）10月16日施行の改正で、資本金又は出資の総額の下限が500万円以上から3,000万円以上へ引き上げられました。既に「経営・管理」で在留している方には施行日から3年（2028年10月16日）までの経過措置がありますが、これから新規に取得する場合は改正後の基準で審査されます。個別の扱いは出入国在留管理庁で確認してください。

**Q. 日本語が話せなくても取得できますか？**
A. 改正後は、申請者本人又は常勤職員に「日本語教育の参照枠」のB2相当以上（日本語能力試験N2以上など）の日本語能力が求められます。申請者本人が満たさない場合、その水準を満たす常勤職員を確保する方法もあります。立証方法や具体的な水準は最新の基準で確認が必要です。

**Q. 会社を作る前に在留資格を申請できますか？**
A. 実務上は、会社を設立し、資本金・事業所・事業計画が整った状態で在留資格を申請するのが一般的です。会社の存在と事業の実体が審査の前提になるためです。設立登記は司法書士、在留資格の申請取次は行政書士と担当が分かれ、それぞれ独立した事業体として別々にご契約いただきます。

**Q. 行政書士に頼めば必ず許可されますか？**
A. いいえ。申請取次行政書士ができるのは、要件確認・資料整理・書類作成・申請の取次までで、許否は出入国在留管理庁が審査して判断します。可否を保証・断定することはできません。本記事は一般的な情報提供であり、個別の許否を保証するものではありません。
