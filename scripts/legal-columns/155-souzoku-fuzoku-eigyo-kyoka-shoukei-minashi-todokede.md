**結論（先に要点）**：風俗営業の許可は、営業者が亡くなっても相続人に当然には引き継がれません。相続人が営業を続けるには、被相続人の死亡後60日以内に都道府県公安委員会の承認（相続による地位の承継の承認）を受ける必要があります（風俗営業等の規制及び業務の適正化等に関する法律第7条第1項）。申請をしておけば、死亡の日から承認または不承認の通知を受けるまでの間は、被相続人への許可が相続人に対してされたものとみなされ、営業を続けられます（第7条第2項＝みなし営業）。ただし承認は第4条第1項の欠格事由に当たらないことが条件で（第7条第3項の準用）、相続人が暴力的不法行為のおそれや一定の前科に当たると承認されません。本記事は承継の手続と期限を整理する一般的な情報提供であり、個別の承認の可否は判断しません。

## 風俗営業の許可は相続人にそのまま引き継がれるのか？

いいえ。風俗営業の許可は、営業者に与えられた許可で、営業者が亡くなっても預貯金や不動産のように当然に相続人へ移るわけではありません。相続人が同じ場所で営業を続けたいときは、改めて都道府県公安委員会の承認を受けて、被相続人が持っていた「風俗営業者の地位」を承継する必要があります。根拠は風俗営業等の規制及び業務の適正化等に関する法律（風営法）第7条です。第7条第4項は、承認を受けた相続人が被相続人に係る風俗営業者の地位を承継すると定めています。

同じ「引き継ぎ」でも、生前に事業を譲る場合と、死亡による相続とでは手続が違います。生前に法人の合併・分割で引き継ぐ場合は第7条の2（合併）・第7条の3（分割）で事前の承認が必要で、生前に別の人へ事業を譲るときは原則として新規の許可を取り直します。生前の事業承継で許認可をどう扱うかの総論は[生前の事業承継で許認可は再取得が要るのか](/legal/column/souzoku-jigyo-shokei-kyoninka-shoukei-saishutoku)で整理しています。この記事は、営業者が亡くなった「相続」の場面に絞ります。

## 相続による承継の承認申請はいつまでに出すのか？

第7条第1項は、相続人が被相続人の死亡後60日以内に公安委員会に申請して、その承認を受けなければならないと定めています。この60日は、相続人が営業を続ける意思がある場合の期限です。

| 項目 | 内容 | 根拠 |
| --- | --- | --- |
| 申請期限 | 被相続人の死亡後60日以内 | 風営法第7条第1項 |
| 申請先 | 営業所の所在地を管轄する都道府県公安委員会（窓口は所轄警察署の生活安全課） | 風営法第7条第1項 |
| 承認基準 | 第4条第1項の欠格事由に当たらないこと | 風営法第7条第3項（第4条第1項の準用） |
| 標準処理期間 | 都道府県により異なる（各公安委員会の審査基準・標準処理期間を確認） | 各都道府県の審査基準 |

標準処理期間や必要書類の様式は都道府県ごとに異なるため、必ず営業所所在地の公安委員会・所轄警察署の案内で確認してください。

## 承認が下りるまで営業を続けられるのか？（みなし営業）

続けられます。第7条第2項は、承認の申請をした場合、被相続人の死亡の日から承認を受ける日（または承認をしない旨の通知を受ける日）までの間は、被相続人に対してされていた許可を相続人に対してしたものとみなす、と定めています。これが「みなし営業」です。期限内に申請さえしておけば、審査期間中に無許可営業になることはありません。

逆に、60日以内に申請しないまま営業を続けると、みなし営業の根拠がなく、無許可営業（第3条第1項違反）と評価されるおそれがあります。承認を受けたら遅滞なく許可証の書換えを受け（第7条第5項）、不承認の通知を受けたら許可証を返納します（第7条第6項）。

## 相続人が複数いるときは誰が承継するのか？

相続人が2人以上いるときは、その協議で当該風俗営業を承継すべき相続人を定めたときは、その者が申請の主体になります（第7条第1項）。つまり、全員が営業者になるのではなく、誰が営業を継ぐかを相続人間の協議で決め、その1人が承認を申請します。

| 相続人の状況 | 承継承認を申請する人 |
| --- | --- |
| 相続人が1人 | その相続人 |
| 相続人が複数・協議で承継者を定めた | 協議で定められた相続人 |
| 協議が調わない | 承継者が定まらず申請が難しくなる（※） |

（※）協議が調わない間は申請の主体が定まらず、60日の期限との関係で営業の継続が不安定になります。遺産分割や相続人間の争いそのものの調整は弁護士の分野で、当事務所とは独立した事業体として別々にご契約いただきます。

## 承継できないのはどんな場合か？（欠格事由）

承認は、承継する相続人が第4条第1項の欠格事由に当たらないことが条件です（第7条第3項で第4条第1項を準用）。代表的な欠格事由は次のとおりです。

| 号 | 欠格事由（要旨） |
| --- | --- |
| 第4条第1項第1号 | 破産手続開始の決定を受けて復権を得ない者 |
| 第4条第1項第2号 | 1年以上の拘禁刑、または風営法違反など列挙された罪で刑に処され、執行終了等から5年を経過しない者 |
| 第4条第1項第3号 | 集団的・常習的に暴力的不法行為を行うおそれがあると認めるに足りる相当な理由がある者（暴力団員に関わる類型） |
| 第4条第1項第5号 | 心身の故障により風俗営業の業務を適正に行えない者（国家公安委員会規則で定めるもの） |
| 第4条第1項第11号 | 営業に関し成年者と同一の行為能力を有しない未成年者（一定の場合を除く） |

「拘禁刑」は、刑法改正により令和7年6月1日に施行され、従来の懲役・禁錮を一本化した刑です。承継する相続人がこれらに当たると承認されず、営業を続けられません。該当性の最終的な確認は本人の申告と警察の調査によります。なお、未成年の相続人については、法定代理人が欠格事由に当たらない場合に承継できる扱いがあります（第4条第1項第11号のただし書）。

## 承認申請・相続手続・登記・税はそれぞれ誰に頼むのか？

風俗営業の相続は、複数の専門分野にまたがります。担当は次のとおりです。

- 相続による地位の承継の承認申請・各種届出の作成と公安委員会への申請の代理、相続人の確定・遺産分割協議書の作成 → 四葉行政書士事務所（行政書士）
- 事業用不動産（店舗）の相続後の賃貸・売買や名義の確認 → 四葉不動産株式会社（宅地建物取引業者）
- 不動産や会社の登記（相続登記・役員変更登記など） → 司法書士
- 相続税の申告・事業の税務 → 税理士
- 相続人間の遺産分割の争い、不承認など不利益処分への不服申立て → 弁護士

四葉行政書士事務所とは別事業体の四葉不動産株式会社が、独立した事業体として別契約で、店舗物件の賃貸・売買や名義の確認を担当します。登記は司法書士、税務は税理士、紛争や不服申立ては弁護士が、いずれも独立した事業体として別々にご契約いただきます。各分野は、それぞれの窓口・資格者と別々にご契約いただく前提で、当事務所は紹介料を受け取りません。相続した不動産の活用のご相談は[相続した不動産のこと](/souzoku)、受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務の全体像は[許認可・各種申請サービス](/legal/services)をご覧ください。風俗営業そのものの許可要件は、接待をともなう場合は[接待をともなう飲食店（風営法1号）の許可](/legal/column/fuzoku-eigyo-1go-settai-inshoku-kyoka-bukken-kyori)、低照度・区画席の場合は[低照度・区画席の飲食店（風営法2号・3号）の許可](/legal/column/fuzoku-eigyo-2go-3go-teishoudo-kukakuseki-kyoka)もあわせてご覧ください。

## よくある質問

**Q. 親が亡くなったあと、何もしなくても店を続けられますか？**
A. いいえ。風俗営業の許可は相続人に当然には移りません。続けるには被相続人の死亡後60日以内に都道府県公安委員会へ相続による承継の承認を申請する必要があります（風営法第7条第1項）。申請をしておけば、死亡の日から承認・不承認の通知までの間はみなし営業として続けられます（同条第2項）。申請しないまま営業すると無許可営業と評価されるおそれがあります。

**Q. 承認の審査中は休業しなければなりませんか？**
A. 休業する必要はありません。第7条第2項のみなし営業により、期限内に申請していれば審査期間中も営業を続けられます。ただし、これは60日以内に申請していることが前提です。承認後は許可証の書換え、不承認なら許可証の返納が必要です（同条第5項・第6項）。

**Q. 相続人が兄弟3人いるとき、全員で営業者になるのですか？**
A. いいえ。相続人が2人以上のときは、協議で営業を承継する相続人を1人定め、その人が承認を申請します（第7条第1項）。全員が営業者になるわけではありません。誰が継ぐかで争いがあるときは、遺産分割の調整が弁護士の分野になり、当事務所とは独立した事業体として別々にご契約いただきます。

**Q. 相続人に前科や自己破産があると承継できませんか？**
A. 承継には第4条第1項の欠格事由に当たらないことが条件です（第7条第3項の準用）。破産して復権を得ていない、1年以上の拘禁刑や風営法違反の刑から5年を経過していない、暴力的不法行為のおそれがあるなどに当たると承認されません。該当するかは本人の申告と警察の調査で確認され、最終的な判断は都道府県公安委員会が行います。
