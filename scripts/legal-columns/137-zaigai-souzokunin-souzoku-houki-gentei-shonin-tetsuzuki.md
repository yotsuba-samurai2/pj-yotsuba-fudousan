**結論（先に要点）**：海外に住む相続人も、日本の家庭裁判所に相続放棄・限定承認を申述できます（郵送でもできます）。熟慮期間は「自己のために相続の開始があったことを知った時から3か月」（民法第915条第1項）で、申述先は被相続人の最後の住所地を管轄する家庭裁判所です。

**情報確認日：2026年10月27日**。本記事は、台湾・中国本土などに住む相続人や、在外の相続人がいる日本側のご家族、現地の専門職に向けて、在外から日本の相続を放棄・限定承認する段取りと3か月の熟慮期間の起算に絞って整理します。放棄・限定承認の基本は[相続放棄・限定承認の基礎](/legal/column/souzoku-hoki-gentei-shonin)、海外・外国籍がからむ相続の全体像は[海外・外国籍がからむ相続](/legal/column/souzoku-kaigai-gaikokuseki)、期間の起算と伸長は[熟慮期間の起算点と伸長](/legal/column/souzoku-hoki-jukuryo-kikan-shincho-kisanten)もあわせてご覧ください。条文は[e-Gov法令検索](https://laws.e-gov.go.jp/)で照合しました。

## 海外に住んでいても日本の相続を放棄できますか？

放棄できます。相続の放棄は、相続人が住む場所ではなく、被相続人（亡くなった方）の相続について家庭裁判所に申し立てる手続です。民法第938条は「相続の放棄をしようとする者は、その旨を家庭裁判所に申述しなければならない」と定めます。相続を放棄した人は、その相続については初めから相続人とならなかったものとみなされます（民法第939条）。したがって放棄すると、次順位の相続人（たとえば子が全員放棄すれば父母、父母もいなければ兄弟姉妹）に相続の権利が移ります。

相続財産の一部を受け取りつつ債務超過のリスクに備えたい場合は、限定承認という選択もあります。民法第922条は、相続によって得た財産の限度でのみ被相続人の債務・遺贈を弁済することを留保して承認できると定め、相続人が数人あるときは共同相続人全員が共同してのみ限定承認ができます（民法第923条）。限定承認をするには、熟慮期間内に相続財産の目録を作成して家庭裁判所に提出し、その旨を申述します（民法第924条）。

申述先は、相続が開始した地を管轄する家庭裁判所です。家事事件手続法第201条第1項は、相続の承認及び放棄に関する審判事件を「相続が開始した地を管轄する家庭裁判所」の管轄に属すると定め、相続は被相続人の住所において開始します（民法第882条・第883条）。つまり被相続人の最後の住所地を管轄する家庭裁判所に申述します。在外の相続人は、申述書と添付書類を郵送して申し立てることができます（連絡は郵便のやり取りになるため、国際郵便の期間も見込んで早めに動くのが安全です）。

| 選択肢 | 内容 | 主な根拠 |
| --- | --- | --- |
| 単純承認 | 権利も義務（債務）もすべて承継する | 民法第920条 |
| 限定承認 | 得た財産の限度でのみ債務を弁済。相続人全員で共同申述・財産目録を提出 | 民法第922条・第923条・第924条 |
| 相続放棄 | 初めから相続人でなかったとみなされ、次順位へ移る | 民法第938条・第939条 |

## 3か月の熟慮期間はいつから数えますか？伸長できますか？

起算日は「自己のために相続の開始があったことを知った時」です。民法第915条第1項は、相続人は自己のために相続の開始があったことを知った時から3か月以内に、単純承認・限定承認・放棄のいずれかをしなければならないと定めます。死亡の日からではなく、「自分が相続人になったことを知った時」から数える点が重要です。海外に住んでいて訃報が遅れて届いた場合や、先順位の相続人が放棄したことで自分が相続人になった次順位の方は、その事実を知った時が起算点になります。

熟慮期間内に判断がつかないときは、期間の伸長を申し立てられます。民法第915条第1項ただし書は、この期間を「利害関係人又は検察官の請求によって、家庭裁判所において伸長することができる」と定めます。国外の財産・債務の調査や戸籍・公証書の取り寄せに時間がかかる在外相続のケースでは、熟慮期間内に家庭裁判所へ期間伸長を申し立てることを検討します。また相続人は、承認・放棄をする前に相続財産の調査をすることができます（民法第915条第2項）。

| 項目 | 内容 |
| --- | --- |
| 熟慮期間 | 自己のために相続の開始があったことを知った時から3か月（民法第915条第1項） |
| 起算の考え方 | 死亡日ではなく「自分が相続人になったことを知った時」 |
| 伸長 | 期間内に家庭裁判所へ伸長を申立て（同項ただし書） |
| 財産調査 | 承認・放棄の前に調査できる（同条第2項） |

期間の起算点をめぐっては見解が分かれ得るため、個別の起算日や伸長の可否は、申立て前に管轄の家庭裁判所と有資格者に確認してください。

## 申述に必要な書類（台湾戸籍・在外公館の証明）は誰が集めますか？

共通して必要になるのは、被相続人の死亡の記載がある戸籍（除籍・改製原戸籍）謄本、被相続人の住民票の除票または戸籍の附票、申述人（放棄する人）の戸籍謄本です。続柄（配偶者・子・父母・兄弟姉妹）によって求められる戸籍の範囲が変わり、第二順位以降では被相続人の出生から死亡までの戸籍が必要になることがあります。費用は申述人1人につき収入印紙800円と連絡用の郵便切手で、切手の額は裁判所ごとに異なります（参照日2026-10-27、裁判所「相続の放棄の申述」）。

在外相続に特有なのは、国外で作る本人確認書類です。日本に住所・印鑑登録がない相続人は、印鑑証明書に代えて在外公館（日本国大使館・総領事館）の署名（サイン）証明を用いる場面があります。相続人が外国籍・外国戸籍の場合は、台湾の戸籍（除戸籍）や中国本土の公証書・領事認証など、国ごとの身分証明書類をそろえる必要があります。台湾には日本の大使館・領事館がないため、証明は公益財団法人日本台湾交流協会（台北・高雄）が担う実務です。中国本土の相続人の親族関係公証書・領事認証の流れは[中国本土の相続人の親族関係公証書と領事認証](/legal/column/chugoku-tairiku-souzokunin-shinzoku-koshosho-ryoji-ninsho)で扱っています。どの書類がどの手続で求められるか、署名証明で足りるかは裁判所・事案で異なり、具体の要否は本記事では未検証です。

行政書士（当方）がお手伝いできるのは、相続人の確定（戸籍の収集・相続関係の整理）、台湾戸籍・中国公証書など国外書類の収集、限定承認で家庭裁判所に提出する財産目録の作成です。申述書そのものの作成・提出は、次の見出しのとおり役割が分かれます。

| 書類・作業 | 主な担い手 |
| --- | --- |
| 被相続人・相続人の戸籍収集、相続人の確定 | 行政書士（当方） |
| 台湾戸籍・中国公証書など国外書類の収集 | 行政書士（当方） |
| 限定承認の財産目録の作成 | 行政書士（当方） |
| 在外公館の署名証明・各国の身分証明 | 本人が在外公館・現地当局で取得 |
| 家庭裁判所への申述書の作成・提出 | 本人、または裁判所提出書類として司法書士 |

## 家裁への申述・争い・税務・登記はそれぞれ誰が担いますか？

相続放棄・限定承認は、作業ごとに担い手が分かれます。家庭裁判所への申述は相続人本人が行うか、裁判所提出書類の作成を司法書士に依頼します。遺産分割や相続放棄の有効性をめぐって争いがある場合の交渉・調停・代理は弁護士、相続税の評価・申告は税理士、不動産の相続登記は司法書士の分野です。行政書士（当方）は、相続人の確定・国外書類の収集・財産目録の作成を担います。

| 依頼先 | 担当する範囲 |
| --- | --- |
| 四葉行政書士事務所 | 相続人の確定、戸籍・国外書類の収集、限定承認の財産目録の作成 |
| 本人／司法書士 | 家庭裁判所への相続放棄・限定承認の申述（裁判所提出書類の作成） |
| 弁護士 | 遺産分割・放棄の有効性などで争いがある場合の交渉・調停・代理 |
| 税理士 | 相続税の評価・申告 |
| 司法書士 | 相続不動産の名義変更（相続登記） |

四葉行政書士事務所、四葉社会保険労務士事務所、四葉不動産株式会社はそれぞれ別事業体で、独立した事業体として受任します。各分野の担当者と別々にご契約いただき、各受任者が直接請求・入金を受けます。当事務所は紹介料を受け取りません。

## よくある質問

**Q. 海外に住んでいても日本の相続を放棄できますか？**
A. できます。相続放棄は被相続人の最後の住所地を管轄する家庭裁判所への申述で行い（民法第938条、家事事件手続法第201条第1項）、在外の相続人は申述書・添付書類を郵送して申し立てられます。放棄すると初めから相続人でなかったものとみなされ、次順位の相続人に権利が移ります（民法第939条）。

**Q. 熟慮期間の3か月はいつから数えますか？**
A. 「自己のために相続の開始があったことを知った時」から3か月です（民法第915条第1項）。死亡日ではなく、自分が相続人になったことを知った時が起算点です。海外で訃報が遅れて届いた場合や、先順位の放棄で相続人になった次順位の方は、その事実を知った時から数えます。期間内に家庭裁判所へ伸長を申し立てられます（同項ただし書）。

**Q. 必要な台湾戸籍や中国の公証書は誰が集めますか？**
A. 相続人の確定に必要な戸籍の収集、台湾戸籍・中国公証書など国外書類の収集、限定承認で提出する財産目録の作成は行政書士（当方）が担えます。在外公館の署名証明や各国の身分証明は、相続人ご本人が在外公館・現地当局で取得します。どの書類が必要かは裁判所・事案で異なり、具体は未検証のため管轄の家庭裁判所に確認してください。

**Q. 相続人が全員海外にいると限定承認はできますか？**
A. 限定承認は相続人全員が共同してのみ申述でき（民法第923条）、熟慮期間内に財産目録を家庭裁判所に提出します（民法第924条）。全員が在外でも、国外書類と署名証明をそろえ、郵送で共同申述することは可能です。全員の足並みと3か月の期限管理が要になるため、早めに相続人を確定し、必要なら期間伸長を検討してください。
