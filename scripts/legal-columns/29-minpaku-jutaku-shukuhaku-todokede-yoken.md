**結論（先に要点）**：自宅や所有する住宅を使って民泊（住宅宿泊事業）を始めるには、住宅宿泊事業法（平成29年法律第65号）第3条第1項にもとづき、都道府県知事等（保健所設置市・特別区では市長・区長）へ届出をします。旅館業法の営業許可とは根拠法も窓口も別で、住宅宿泊事業は「人を宿泊させる日数が1年間で180日を超えない」ことが定義上の前提です（同法第2条第3項）。届出には消防法令適合通知書などの添付が求められ、家主不在型では住宅宿泊管理業者への委託が必要です（同法第11条）。分譲マンションでは管理規約、賃貸物件では賃貸借契約の許諾も確認します。本記事は、届出と旅館業許可の違い・180日規制・添付書類・管理規約の確認点・役割分担を整理する一般的な情報提供であり、個別の届出の可否や物件が民泊に使えるかは判断しません。

## 住宅宿泊事業の届出と旅館業許可は、どこで分かれますか？

宿泊料を受けて人を宿泊させる事業は、大きく「旅館業法の許可」と「住宅宿泊事業法の届出」に分かれます。旅館業法（昭和23年法律第138号）は許可制で、フロント設備や客室の基準など施設面の要件が重くなります。これに対し住宅宿泊事業法は届出制で、住宅を活用して人を宿泊させる事業を対象にします。

分かれ目は「営業日数」と「施設が住宅か」です。住宅宿泊事業は、旅館業を営む者以外の者が宿泊料を受けて住宅に人を宿泊させる事業で、人を宿泊させる日数が1年間で180日を超えないもの、と定義されています（住宅宿泊事業法第2条第3項）。180日を超えて営業したい場合は住宅宿泊事業の枠に収まらず、旅館業法の許可（簡易宿所営業など）を検討することになります。

| | 旅館業法の許可 | 住宅宿泊事業法の届出 |
| --- | --- | --- |
| 手続 | 許可制 | 届出制 |
| 窓口 | 都道府県知事等（保健所） | 都道府県知事等（保健所設置市・特別区は市長・区長） |
| 年間営業日数 | 上限なし | 180日以下（第2条第3項の定義） |
| 対象施設 | 旅館・ホテル・簡易宿所等 | 住宅 |

どちらの枠組みが適するかは、営業したい日数・施設の性格・立地によって変わります。四葉行政書士事務所では、行政書士業務の範囲で、住宅宿泊事業の届出書・添付書類の作成と提出の代理を支援します。旅館業許可が必要となる場合の建築確認は建築士の領域です。個別の可否は所轄の審査によります。

## 届出に必要な書類と、消防法令適合通知書はどう揃えますか？

住宅宿泊事業の届出は、住宅宿泊事業法第3条第1項にもとづき、電子システム（民泊制度運営システム）または書面で行います。届出書のほか、住宅の図面、登記事項証明書、消防法令適合通知書などの添付が求められます。書類の種類は自治体の手引きにより細部が異なるため、届出前に所在地の窓口の案内を確認します。

消防法令適合通知書は、住宅が消防法令に適合していることを消防署（消防長・消防署長）が確認して交付する書面です。住宅宿泊事業では、住宅の規模や家主の居住形態に応じて、自動火災報知設備・誘導灯・消火器などの設置が必要になる場合があります。設備の要否と設計は消防署・消防設備士の領域で、届出の前提として早めに相談しておくと安全です。

| 主な添付・確認事項 | 担当・窓口 |
| --- | --- |
| 届出書・住宅の図面・登記事項証明書の整理と提出代理 | 四葉行政書士事務所（行政書士） |
| 消防法令適合通知書の取得・消防用設備の設計 | 消防署（消防長・消防署長）・消防設備士 |
| 宿泊者名簿の備付け（第8条）、標識の掲示（第13条） | 住宅宿泊事業者（届出者） |
| 家主不在型での住宅宿泊管理業務の委託（第11条） | 住宅宿泊管理業者 |

住宅宿泊事業者は、宿泊者名簿を備え付けなければならず（第8条）、届出住宅ごとに標識を掲示しなければなりません（第13条）。書類の作成・提出は行政書士、消防設備は消防署・消防設備士と、担当が分かれます。

## 年間180日の上限と、自治体の上乗せ条例はどう効きますか？

住宅宿泊事業で人を宿泊させることができるのは、1年間で180日が上限です。この「1年間」は、毎年4月1日正午から翌年4月1日正午までの期間で算定するのが国の運用です（民泊制度ポータルサイト・参照日2026年8月27日）。宿泊させた日数は定期報告で自治体へ報告します。

さらに、都道府県（保健所設置市・特別区を含む）は、生活環境の悪化を防止するため必要があるときは、条例で区域を定めて住宅宿泊事業を行う期間を制限することができます（住宅宿泊事業法第18条）。この「上乗せ条例」により、住居専用地域では平日の営業を認めない、学校周辺では期間を限るなど、180日よりさらに狭い制限がかかることがあります。

| 制限の種類 | 根拠 |
| --- | --- |
| 全国一律の営業日数上限 | 住宅宿泊事業法第2条第3項（180日以下） |
| 区域を定めた期間制限（上乗せ条例） | 住宅宿泊事業法第18条 |
| 集合住宅での可否 | 管理規約・賃貸借契約 |

物件が良くても、上乗せ条例の対象区域では想定した日数を営業できないことがあります。用途地域や条例の区域は物件を決める前に確認しておくことが大切で、立地の可否や上乗せ条例の該当は、物件選びの重要な確認事項です。物件が民泊に使えるかの見立ては、四葉行政書士事務所とは別事業体の四葉不動産株式会社（宅地建物取引業者）が、宅建業務の範囲で担当します。

## 分譲マンションで民泊する場合、管理規約と賃貸借の何を確認しますか？

分譲マンション（区分所有建物）で民泊を行うには、法令の届出とは別に、管理規約の確認が欠かせません。マンション標準管理規約には、住宅宿泊事業を「行うことができる／行ってはならない」を明記する規定例が示されており、規約で民泊が禁止されていれば、届出ができても実施できません。

賃貸物件で民泊を行う場合は、賃貸借契約で転貸や民泊利用が許諾されているかを確認します。所有者・貸主の承諾がないまま民泊を行うと、契約違反となるおそれがあります。これらの適合判断（用途地域・管理規約・賃貸借の許諾）は不動産の領域で、行政書士が行う届出書類の作成とは担当が分かれます。

- 管理規約で住宅宿泊事業が禁止されていないかの確認 → 管理組合・区分所有者、確認は四葉不動産株式会社（宅地建物取引業者）
- 賃貸借契約での転貸・民泊利用の許諾の確認 → 貸主、確認は四葉不動産株式会社（宅地建物取引業者）
- 届出書・添付書類の作成と提出代理 → 四葉行政書士事務所（行政書士）

管理規約や賃貸借の確認は、物件が民泊に使えるかどうかの前提です。届出の代理は行政書士が担当しますが、物件そのものが民泊に適合するかの見立ては不動産が担当します。

## 物件確認・届出・消防は、それぞれ誰に頼めばよいですか？

民泊の開始は、複数の手続と専門分野にまたがります。担当は次のとおりです。

- 住宅宿泊事業の届出書・添付書類の作成、届出の代理 → 四葉行政書士事務所（行政書士）
- 物件が民泊に使えるかの判断（用途地域・管理規約・賃貸借の許諾）・物件の売買や賃貸の仲介 → 四葉不動産株式会社（宅地建物取引業者）
- 消防法令適合通知書の取得・消防用設備の設計 → 消防署（消防長・消防署長）・消防設備士
- 旅館業許可が必要となる場合の建築確認 → 建築士

四葉行政書士事務所とは別事業体の四葉不動産株式会社が、独立した事業体として別契約で、物件の適合の見立て・売買や賃貸の仲介・管理規約や賃貸借の確認を担当します。消防法令適合通知書は消防署の所管で、消防用設備の設計は消防設備士、旅館業許可が要る場合の建築確認は建築士の領域です。各分野は、それぞれの窓口・資格者と独立した事業体として別々にご契約いただく前提で、当事務所は紹介料を受け取りません。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務の全体像は[許認可・各種申請サービス](/legal/services)をご覧ください。開業に伴う他の許認可は[深夜0時以降にお酒を出す店、届出は何がいる？](/legal/column/shinya-shurui-teikyo-todokede-yoken)、[古物商許可、営業所には何が必要？](/legal/column/kobutsusho-kyoka-eigyosho-yoken)も参考になります。

## よくある質問

**Q. 年間90日しか営業しなくても、届出は必要ですか？**
A. はい。住宅宿泊事業の180日は「上限」であって、営業日数が少なくても、宿泊料を受けて反復継続して人を宿泊させるなら住宅宿泊事業に当たり、住宅宿泊事業法第3条第1項の届出が必要です。届出をせずに営業すると法の対象となります。日数の多寡にかかわらず、営業前の届出が前提です。

**Q. 旅館業許可と住宅宿泊事業の届出は、どちらを選べばよいですか？**
A. 年間180日以内で住宅を活用するなら住宅宿泊事業の届出、180日を超えて営業したい・施設の性格が住宅とはいえないなどの場合は旅館業法の許可（簡易宿所営業など）が検討対象になります。どちらの枠組みが適するかは日数・施設・立地によって変わり、個別の可否は所轄の審査によります。物件の性格の見立ては不動産、建築確認は建築士の領域です。

**Q. 分譲マンションの一室でも民泊できますか？**
A. 法令上の届出とは別に、管理規約の確認が必要です。マンション標準管理規約には住宅宿泊事業の可否を明記する規定例が示されており、規約で禁止されていれば届出ができても実施できません。賃貸なら貸主の許諾も要ります。管理規約・賃貸借の確認は不動産の領域です。

**Q. 消防法令適合通知書は、行政書士が取ってくれますか？**
A. 消防法令適合通知書は、住宅が消防法令に適合していることを消防署（消防長・消防署長）が確認して交付する書面で、届出の添付書類になります。設備の要否の判断や設計は消防署・消防設備士の領域で、当事務所が代行するものではありません。届出書・添付書類の作成と提出の代理は当事務所が、消防設備は消防署・消防設備士が、それぞれ担当します。
