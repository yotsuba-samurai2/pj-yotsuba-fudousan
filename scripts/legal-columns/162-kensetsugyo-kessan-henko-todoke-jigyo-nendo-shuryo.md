**結論（先に要点）**：建設業許可を受けた業者は、毎事業年度が終わるたびに「決算変更届（事業年度終了届）」を提出する義務があります。根拠は建設業法第11条第2項で、提出期限は毎事業年度経過後4月以内です。これは申請者の都合で省略できる手続きではなく、工事実績がない年度や休業中でも提出が必要です。出し忘れると、5年ごとの許可の更新や業種追加（般・特新規など）の際に未提出分をまとめて出さなければ受理されず、虚偽や長期の未提出は監督処分・罰則の対象になり得ます。商号・営業所・資本金・役員等の変更は変更があった日から30日以内（建設業法第11条第1項）、経営業務の管理責任者や専任技術者が交代したときの変更届は2週間以内（同条第4項・第5項）と、期限が手続きごとに違う点にも注意が必要です。本記事は一般的な情報提供で、個別の提出要否や処分の有無を判断・保証するものではありません。決算変更届の書類作成・提出代行は四葉グループの行政書士が独立した事業体として担い、添付する財務諸表のもとになる税務申告・決算書の作成は税理士、役員変更・商号変更・本店移転などの登記は司法書士が、それぞれ別々にご契約いただく分離受任で対応します。

## 決算変更届（事業年度終了届）は何を・いつまでに出す？

決算変更届は、建設業法第11条第2項に基づき、許可業者が毎事業年度の経過後4月以内に提出する届出です。「事業年度終了届」「決算報告」とも呼ばれますが、同じものを指します。たとえば3月決算の法人なら7月末まで、12月決算の個人なら翌年4月末までが目安で、末日が行政庁の閉庁日に当たるときの扱いは提出先の運用で確認してください。

提出する主な書類は、その事業年度の工事の実績と、決算の内容を示すものです。内容は許可行政庁（国土交通大臣許可か都道府県知事許可か）や法人・個人の別で変わるため、提出先の手引きで最新の様式を確認するのが前提になります。

| 主な書類 | 内容 |
| --- | --- |
| 工事経歴書 | その事業年度に請け負った工事の実績（請負金額・工期など） |
| 直前3年の各事業年度における工事施工金額 | 業種別・元請／下請別の施工金額 |
| 財務諸表（建設業用） | 貸借対照表・損益計算書など。建設業法施行規則で定める様式に従ったもの |
| 事業報告書 | 株式会社の場合に必要 |
| 納税証明書等 | 事業税など、行政庁が定めるもの |

工事の実績がない年度でも「実績なし」として提出する必要があり、休業中でも許可を維持する限り届出義務は残ります。当事務所の[取扱業務](/legal/services)・[受任の流れ](/legal/nagare)・[報酬額表](/legal/ryokin)もあわせてご覧ください。

## 提出しないと更新や業種追加にどう響く？

決算変更届は、単独で完結する手続きというより、5年ごとの許可の更新や、業種追加・般特新規といった次の申請の土台になる書類です。更新や追加の申請を受け付ける行政庁は、過去の事業年度の決算変更届が出そろっていることを前提にします。未提出の年度があると、まずその分を提出するよう求められ、たまっていると更新のタイミングで一気に作成することになって、期限に間に合わないおそれが生まれます。

| 場面 | 決算変更届が未提出だとどうなるか |
| --- | --- |
| 5年ごとの許可更新 | 未提出の事業年度分を提出しないと更新申請が受理されない |
| 業種追加・般特新規 | 同じく、直前の決算変更届がそろっていることが前提 |
| 経営事項審査（公共工事の入札） | 決算変更届の提出が前提。未提出だと経審に進めない |
| 虚偽記載・長期の未提出 | 建設業法上の監督処分（指示・営業停止等）や罰則の対象になり得る |

公共工事の入札に参加する事業者は、毎年の決算変更届を土台に経営事項審査（経審）へ進みます。この流れは[公共工事の入札参加に向けた経営事項審査（経審）の見方](/legal/column/keiei-jiko-shinsa-keishin-nyusatsu-sankaku-shikaku)で整理しています。更新や業種追加で問われる経営業務の管理責任者・専任技術者・財産的基礎といった取得時の要件は[建設業許可の要件（経管・専技・財産的基礎）の全体像](/legal/column/kensetsugyo-kyoka-yoken-keikan-sengi-zaisan)で扱っています。

## 建設業法上の財務諸表は税務の決算書とどう違う？

決算変更届に添付する財務諸表は、税務署に出す確定申告の決算書とは様式も勘定科目も異なります。税務の決算書は会計・税法のルールで作られますが、建設業法の財務諸表は建設業法施行規則が定める様式に沿い、「完成工事高」「完成工事原価」「未成工事支出金」「工事未払金」といった建設業特有の勘定科目に組み替える必要があります。

| 区分 | 税務の決算書 | 建設業法の財務諸表 |
| --- | --- | --- |
| 根拠 | 法人税法・所得税法など | 建設業法・同施行規則の様式 |
| 作成する専門家 | 税理士（税務申告の一環） | 行政書士が様式に組み替えて作成（当事務所） |
| 勘定科目 | 一般の売上・仕入など | 完成工事高・完成工事原価・未成工事支出金など |
| 提出先 | 税務署 | 建設業の許可行政庁 |

ここが分離受任の線引きです。もとになる決算書の作成や税務申告は税理士の独占領域で、四葉グループの税理士は独立した事業体として担います。その決算書を建設業用の様式に組み替え、工事経歴書などとあわせて決算変更届として作成・提出する部分を、行政書士が担います。税額や会計処理そのものの判断は税理士が行い、行政書士が税務の判断に踏み込むことはありません。各専門家とは別々にご契約いただき、相互に紹介料を受け取りません。

## 役員・商号・営業所を変えたときの変更届の期限は？

決算変更届とは別に、許可申請書に記載した事項が変わったときは「変更届」が必要です。期限は変更の種類で分かれます。建設業法第11条第1項は、商号・名称、営業所の名称・所在地、資本金額、役員等の氏名など（建設業法第5条第1号〜第4号に対応する事項）に変更があったときは、変更があった日から30日以内の届出を求めています。

一方、経営業務の管理責任者や、営業所ごとの専任技術者が交代・退任したときは、2週間以内の届出が必要です（建設業法第11条第4項・第5項）。経営業務の管理責任者や専任技術者は許可の要件そのものなので、空白が生じないよう、より短い期限が設けられています。

| 変更の内容 | 届出の期限 | 根拠 |
| --- | --- | --- |
| 商号・名称、営業所の名称・所在地、資本金額、役員等 | 変更の日から30日以内 | 建設業法第11条第1項 |
| 経営業務の管理責任者・専任技術者の交代・退任等 | 変更の日から2週間以内 | 建設業法第11条第4項・第5項 |
| 事業年度ごとの決算（決算変更届） | 毎事業年度経過後4月以内 | 建設業法第11条第2項 |

注意したいのは、会社の登記上の変更（役員変更・商号変更・本店移転など）と、建設業許可の変更届は別々の手続きだという点です。登記は司法書士が独立した事業体として担い、その登記を踏まえた建設業許可の変更届を行政書士が担います。どちらか一方だけでは足りません。

## 毎年の届出を回すために誰に何を頼む？

建設業の許可維持は、年に一度の決算変更届と、随時発生する変更届を取りこぼさないことが要になります。関わる専門家が分かれるため、それぞれ独立した事業体として別々にご契約いただくのが基本です。四葉グループの行政書士は、決算変更届・各種変更届・更新・業種追加といった許可行政庁への手続きを独立した事業体として担います。

| 依頼先 | 主な役割 |
| --- | --- |
| 行政書士（当事務所） | 決算変更届・変更届・許可更新・業種追加・経審の申請書類作成と提出 |
| 税理士 | 決算書の作成・法人税／所得税・消費税の申告（財務諸表のもと） |
| 司法書士 | 役員変更・商号変更・本店移転などの登記 |
| 不動産業者（別事業体の当社） | 本店・営業所となる物件の選定・賃貸借の媒介・重要事項説明 |

営業所の移転や新設に伴って物件を探す場面では、別事業体である四葉不動産株式会社が、独立した事業体として物件の選定や賃貸借の媒介を担います。税務・登記・不動産はそれぞれ独立した事業体で、相互に紹介料を受け取りません。一つの窓口でご相談を受け、必要な手続きを整理したうえで、それぞれの資格者に別々にご契約のうえ対応していただきます。

## よくある質問

**Q. 工事の実績がない年度でも決算変更届は必要ですか？**
A. 必要です。決算変更届（事業年度終了届）は、許可を維持する限り毎事業年度経過後4月以内に提出する義務があり（建設業法第11条第2項）、工事実績がない年度は「実績なし」として、休業中でも許可を持ち続ける限り提出します。出し忘れると更新や業種追加の際にまとめて作成することになり、期限に間に合わないおそれがあります。個別の要否は許可行政庁の手引きで確認してください。

**Q. 決算変更届を数年ぶんためてしまいました。許可は取り消されますか？**
A. 未提出がただちに取消しに直結するとは限りませんが、虚偽記載や長期の未提出は建設業法上の監督処分や罰則の対象になり得ます。実務上は、更新や業種追加の前に未提出分をまとめて提出するよう求められます。何年ぶんをどう整えるかは状況によるため、提出先の行政庁と、書類作成を担う行政書士に早めにご相談ください。

**Q. 税理士に決算をお願いしていれば、決算変更届も出してもらえますか？**
A. 別の手続きです。税理士は税務申告のための決算書を作成しますが、決算変更届に添付する財務諸表は建設業法施行規則の様式に沿って完成工事高などの勘定科目に組み替える必要があり、工事経歴書などとあわせて許可行政庁へ提出します。この部分は行政書士が独立した事業体として担い、税務の判断は税理士が行います。両者は別々にご契約いただきます。

**Q. 役員が変わったときは、いつまでに何を届け出ますか？**
A. 役員等の変更は、変更があった日から30日以内に変更届を提出します（建設業法第11条第1項）。あわせて、その役員が経営業務の管理責任者だった場合などは、後任に関する届出を2週間以内に行う必要があります（同条第4項・第5項）。会社の役員変更登記は司法書士、建設業許可の変更届は行政書士と、別々にご契約のうえ進めます。
