**結論（先に要点）**：技能実習から育成就労への移行により、現在の「監理団体」は自動的に「監理支援機関」へ横滑りするわけではなく、新たに監理支援機関の許可を受ける必要があります（出入国在留管理庁「育成就労制度Q&A」Q33）。制度の施行日は2027年（令和9年）4月1日で、根拠は育成就労関係の改正法（令和6年法律第60号）です。施行を待たずに手続を進められるよう、監理支援機関の許可の施行日前申請は令和8年4月15日から、育成就労（監理型）計画の認定の施行日前申請は令和8年9月1日から受け付けられています（申請先は外国人技能実習機構の本部審査課分室）。許可を受けると、技能実習制度の一般監理事業の許可を受けているものとみなされる扱いが案内されています（同Q&A Q39）。許可申請・計画認定の書類作成の支援は申請取次行政書士の業務範囲、労働条件・就業規則・社会保険・賃金の設計は社会保険労務士、労使紛争は弁護士が、それぞれ独立した事業体として別々にご契約いただく前提で分けて振ります。四葉社会保険労務士事務所は当事務所とは別事業体です。施行日・経過措置には変更や追加の運用情報があり得るため、本記事は裏取りできた範囲に限定し、最新の確認先を示します。本記事は一般的な情報提供であり、個別の許可の可否を判定・保証するものではありません。当事務所は紹介料を受け取りません。

## 育成就労制度への移行で、技能実習の監理団体の立場はどう変わりますか？

育成就労は、人材の確保と育成を目的に、技能実習に代わって創設される受入れの枠組みです。根拠は育成就労関係の改正法（令和6年法律第60号。令和6年6月21日公布）で、技能実習の適正な実施及び技能実習生の保護に関する法律などが改正されます。受入れの在留資格は、出入国管理及び難民認定法の別表第一に位置づけられる仕組みです。

技能実習で受入れ団体を監理してきた「監理団体」に相当する役割は、育成就労では「監理支援機関」が担います。名称が変わるだけでなく、許可の枠組みそのものが新制度のものに切り替わります。出入国在留管理庁の案内では、制度の運用開始（施行日）は2027年（令和9年）4月1日とされています。したがって、技能実習の監理団体が、施行日後もそのまま監理支援機関として業務を続けられるわけではない、という点が出発点になります。登録支援機関（特定技能の支援委託先）の役割との違いは[登録支援機関の登録と支援計画](/legal/column/toroku-shien-kikan-touroku-shien-keikaku)で整理しています。

## 監理支援機関の許可を新たに取り直す必要がありますか、経過措置はありますか？

はい、新たに許可を受ける必要があります。出入国在留管理庁「育成就労制度Q&A」Q33は、監理団体が育成就労に関する業務を行うには、新たに監理支援機関の許可を受ける必要があると案内しています。自動的に資格が引き継がれるわけではありません。

一方で、施行をまたぐ空白を避けるための扱いも示されています。同Q&A Q39では、監理支援機関の許可を受けた者は、技能実習制度の一般監理事業の許可を受けているものとみなされ、監理団体の許可の有効期間について別途の更新を要しないと案内されています。

| 項目 | 内容（出入国在留管理庁の案内） |
| --- | --- |
| 施行日 | 2027年（令和9年）4月1日 |
| 監理支援機関の許可の施行日前申請 | 令和8年4月15日から受付（申請先＝外国人技能実習機構 本部審査課分室） |
| 育成就労（監理型）計画の認定の施行日前申請 | 令和8年9月1日から受付 |
| 既存の監理団体の扱い | 自動移行せず、新たに監理支援機関の許可が必要（Q33） |
| 許可を受けた場合 | 技能実習の一般監理事業の許可を受けているものとみなす（Q39） |

施行日前申請の受付期間や、申請から業務開始までに要する期間の目安は、運用の更新で変わり得ます。申請を検討する際は、後述の公式ページで必ず最新の受付状況を確認してください。

## 受入れ（育成就労）計画の認定とは何を審査しますか？

育成就労では、受入れ機関（企業など）が作成する育成就労計画について、認定を受ける仕組みが設けられます。技能実習でいう技能実習計画の認定に相当する位置づけです。計画の認定では、育成の対象となる分野・業務や育成の期間・目標、受入れ体制、報酬など、受入れが適正に行われる前提が審査されることが想定されます。監理型の計画の認定を受けるには、監理支援機関の許可（施行日前申請を含む）が前提になるという関係も案内されています。

もっとも、認定の審査項目や基準の細目、様式は、施行に向けた運用要領で具体化される部分があり、確定・公表された範囲で確認する必要があります。本記事では、審査の大枠（計画の認定という制度が設けられ、監理支援機関の許可と連動すること）までを一次情報で確認できた範囲として示し、個別の基準値や様式の細目は最新の公表資料に委ねます。外国人を雇用する企業の体制づくりという観点は、在留資格による会社運営の論点を整理した[経営・管理の在留資格と会社設立](/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)も参考になります。

## 許認可（行政書士）と労務・社会保険（社労士）の役割はどう分かれますか？

育成就労の受入れ準備は、許認可（入管関係）と労務（労働・社会保険関係）という性質の異なる手続が重なります。四葉では、次のように独立した事業体として別々にご契約いただく前提で分けて振ります。

| 分野 | 担当（独立した事業体として別々にご契約） |
| --- | --- |
| 監理支援機関の許可申請・育成就労計画の認定申請の書類作成の支援、在留資格に関する申請取次 | 申請取次行政書士 |
| 労働条件の明示・就業規則・賃金規程・36協定などの整備 | 社会保険労務士（四葉社会保険労務士事務所は別事業体） |
| 社会保険・労働保険の適用・手続 | 社会保険労務士 |
| 労使間の紛争・個別労働関係紛争の交渉・訴訟 | 弁護士 |

行政書士が担当するのは、入管関係の申請取次と、許可・認定の申請書類の作成の支援です。入管法令に基づく申請取次は、申請取次の届出をした行政書士が行える範囲です。これに対し、労働条件や社会保険の設計・手続は社会保険労務士、労使紛争の代理は弁護士の業務であり、行政書士は行いません。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、対応業務の全体像は[取扱業務](/legal/services)をご覧ください。四葉社会保険労務士事務所は当事務所とは別事業体であり、各専門家はそれぞれ独立してご契約いただきます。当事務所は紹介料を受け取りません。

## よくある質問

**Q. 今の監理団体は、そのまま監理支援機関になれますか？**
A. そのままでは移行できません。出入国在留管理庁「育成就労制度Q&A」Q33は、育成就労に関する業務を行うには新たに監理支援機関の許可を受ける必要があると案内しています。ただし、許可を受けると技能実習の一般監理事業の許可を受けているものとみなされ、監理団体の許可について別途の更新は要しないと案内されています（Q39）。

**Q. 施行日はいつですか、施行前に申請できますか？**

**Q. 許可申請や計画認定は行政書士に頼めますか？**

**Q. 個別の受入れで許可・認定が通るかどうかを判定してもらえますか？**
