**結論（先に要点）**：相続欠格と廃除は、どちらも特定の人が相続権を失う制度ですが、しくみが違います。相続欠格は、一定の重大な行為をした相続人が、手続を経ることなく法律上当然に相続権を失う制度です（民法第891条）。廃除は、遺留分を有する推定相続人による虐待・重大な侮辱・著しい非行があったときに、被相続人の請求で家庭裁判所が審判して相続権を失わせる制度です（民法第892条〜第895条）。いずれも代襲相続の原因になります（民法第887条第2項）。本記事は制度の一般的な情報提供にとどまり、具体的な事案でどちらに当たるか、廃除が認められるかは、資格者への相談と家庭裁判所の判断によります。

## 相続欠格と廃除は何がどう違うのか？

どちらも「ある人を相続から外す」効果は同じですが、外れる理由と手続が根本的に異なります。相続欠格は法律上当然に生じ、手続はいりません。廃除は被相続人の意思に基づき、家庭裁判所の審判によって生じます。整理すると次のとおりです。

| | 相続欠格 | 廃除 |
| --- | --- | --- |
| 根拠 | 民法第891条 | 民法第892条〜第895条 |
| 対象 | すべての相続人 | 遺留分を有する推定相続人 |
| 原因 | 法定の欠格事由（重大な非行・遺言への干渉等） | 虐待・重大な侮辱・その他の著しい非行 |
| 効果の発生 | 法律上当然（手続不要） | 家庭裁判所の審判の確定 |
| 被相続人の意思 | 関係なく生じる | 被相続人の請求が必要 |
| 取消し・撤回 | できない | できる（民法第894条） |
| 遺贈を受けられるか | 受けられない（民法第965条で第891条を準用） | 受けられる（廃除は準用されない） |
| 戸籍への記載 | されない | 審判確定後に届け出て記載される |
| 代襲相続 | 生じる（民法第887条第2項） | 生じる（民法第887条第2項） |

遺留分を有する推定相続人が対象という点も重要です。兄弟姉妹はもともと遺留分がないため廃除の対象外で、被相続人は遺言で「兄弟姉妹に相続させない」と定めれば足りるため、廃除の必要がありません。

## 相続欠格になるのはどんな行為をしたときか？

民法第891条は、次の5つのいずれかに当たる者を相続人になれない（相続権を失う）と定めています。

1. 故意に被相続人又は先順位・同順位の相続人を死亡させ、又は死亡させようとしたために、刑に処せられた者
2. 被相続人が殺害されたことを知りながら、告発・告訴しなかった者（是非の弁別がないとき、又は殺害者が自己の配偶者・直系血族であったときを除く）
3. 詐欺又は強迫によって、被相続人が相続に関する遺言をし、撤回し、取り消し、又は変更することを妨げた者
4. 詐欺又は強迫によって、被相続人に相続に関する遺言をさせ、撤回させ、取り消させ、又は変更させた者
5. 相続に関する被相続人の遺言書を偽造し、変造し、破棄し、又は隠匿した者

ポイントは、欠格は手続を経ずに法律上当然に生じることです。家庭裁判所の審判も、被相続人の意思表示も必要ありません。相続開始後に、ある相続人が欠格に当たるかどうかは、遺産分割や登記の場面で問題となり、争いになれば最終的には訴訟で確定します。なお、欠格者は相続だけでなく遺贈も受けられません。民法第965条が受遺者について民法第891条を準用しているためで、これは廃除には準用されていません。どの行為が欠格事由に当たるか（特に第5号の遺言書の隠匿・破棄の故意や目的）の評価は個別判断であり、紛争性がある場合の主張・立証は弁護士の領域です。

## 廃除はどこに申し立て、遺言でもできるのか？

廃除は家庭裁判所に請求します。方法は2つあります。第一に、被相続人が生前に自ら家庭裁判所へ請求する方法です（民法第892条）。遺留分を有する推定相続人が、被相続人に対して虐待をし、若しくは重大な侮辱を加えたとき、又はその他の著しい非行があったときに請求できます。第二に、遺言による廃除です（民法第893条）。被相続人が遺言で廃除の意思を表示したときは、遺言執行者が、遺言の効力が生じた後、遅滞なく家庭裁判所に廃除を請求します。この場合、廃除の効力は被相続人の死亡の時にさかのぼって生じます。遺言による廃除を検討するなら遺言執行者の定めが要になるため、遺言書の型は[自筆証書遺言と公正証書遺言](/legal/column/jihitsu-kosei-yuigon)もあわせてご確認ください。

廃除はいつでも取り消せます（民法第894条）。取消しも生前の請求と遺言のどちらでもできます。また、廃除又はその取消しの請求後、審判が確定する前に相続が開始したときは、家庭裁判所は、親族・利害関係人・検察官の請求により、遺産の管理について必要な処分を命ずることができます（民法第895条）。手続の面では、推定相続人の廃除の審判事件は家事事件手続法の別表第一の86の項、廃除の審判の取消しは同表の87の項に定める審判事件で、調停にはなじまない審判事項として扱われます（家事事件手続法）。

| 手続 | 請求できる人 | 根拠 |
| --- | --- | --- |
| 生前の廃除 | 被相続人 | 民法第892条 |
| 遺言による廃除 | 遺言執行者（遺言に基づく） | 民法第893条 |
| 廃除の取消し | 被相続人（生前・遺言） | 民法第894条 |
| 審判確定前の遺産管理 | 親族・利害関係人・検察官 | 民法第895条 |

## 欠格・廃除があると法定相続分と代襲相続はどうなるのか？

欠格・廃除により相続権を失った人は、初めから相続人でなかったものとして扱われ、その分は他の相続人の法定相続分に反映されます。ここで大切なのが代襲相続です。被相続人の子が、相続開始以前に死亡したとき、又は相続欠格に該当し、若しくは廃除によって相続権を失ったときは、その者の子（孫）が代襲して相続人になります（民法第887条第2項）。つまり、親が欠格・廃除で外れても、その子は代襲相続人として相続できます。相続を外れた本人が得をしないための調整である一方、その直系卑属の権利は守られるしくみです。

混同しやすいのが相続放棄との違いです。相続放棄をした人は初めから相続人でなかったものとみなされますが、放棄は代襲相続の原因にはなりません。したがって、放棄した人の子は代襲しません。欠格・廃除では代襲が生じ、放棄では生じない、という違いを押さえてください。法定相続分そのものの考え方は[法定相続分と代襲相続の基礎](/legal/column/houtei-souzoku-bun)にまとめています。最終的な相続分の確定と分け方は、相続人全員の遺産分割協議で決めます。

## 協議書作成・家裁申立て・登記は誰に頼むのか？

欠格・廃除がからむ相続は、段階ごとに担当が分かれます。

- 相続人・相続分を確定するための戸籍収集、相続関係説明図、合意が成立した場合の遺産分割協議書の作成支援 → 四葉行政書士事務所（行政書士）

- 相続財産に不動産があるときの相続登記 → 司法書士
- 相続税の申告・計算 → 税理士

## よくある質問

**Q. 相続欠格と廃除はどちらが重い制度ですか？**
A. 軽重ではなく、しくみが違います。相続欠格は、一定の重大な行為をした相続人が手続を経ずに法律上当然に相続権を失う制度です（民法第891条）。廃除は、遺留分を有する推定相続人の虐待・重大な侮辱・著しい非行があったときに、被相続人の請求で家庭裁判所が審判して相続権を失わせる制度です（民法第892条）。欠格は行為の重大性で当然に生じ、廃除は被相続人の意思と家庭裁判所の判断が必要という点が異なります。

**Q. 遺言で相続人を廃除できますか？**
A. できます。被相続人が遺言で廃除の意思を表示したときは、遺言執行者が、遺言の効力が生じた後、遅滞なく家庭裁判所に廃除を請求します（民法第893条）。効力は被相続人の死亡の時にさかのぼって生じます。遺言執行者を定めておくことが要になるため、遺言書の作成段階から検討するのが実務的です。廃除はいつでも取り消せます（民法第894条）。

**Q. 親が欠格・廃除で相続できないと、その子も相続できませんか？**
A. その子は代襲相続人として相続できます。被相続人の子が相続欠格に該当し、又は廃除によって相続権を失ったときは、その者の子が代襲して相続人になります（民法第887条第2項）。相続を外れるのは行為をした本人だけで、その直系卑属の相続権は代襲によって守られます。なお、相続放棄は代襲相続の原因にならないため、放棄した人の子は代襲しません。

**Q. 廃除された人は遺贈も受けられませんか？**
A. 廃除は相続権を失わせる制度で、遺贈まで妨げるものではありません。民法第965条は受遺者について民法第891条（欠格）を準用していますが、廃除は準用していないため、廃除された人でも遺贈を受けることは妨げられません。一方、欠格に当たる人は相続も遺贈も受けられません。個別の事案でどう扱うかは資格者にご相談ください。
