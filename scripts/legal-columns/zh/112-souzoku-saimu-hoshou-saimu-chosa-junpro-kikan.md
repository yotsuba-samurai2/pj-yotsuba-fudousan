**结论（先讲重点）**：继承的借款与保证债务，可通过合同、催缴通知、存折与信用信息调查。单纯承认、限定承认、放弃继承的选择有民法第915条的3个月熟虑期间；若来不及，可向家事法院申请延长。向家事法院提出的申述・申请书制作，属行政书士的业务范围外。

**信息确认日：2026年10月12日**。本文整理在正资产可能少于负资产（借款・连带保证）的继承中，要调查什么、哪项手续委托给谁。制度全貌请见[放弃继承・限定承认的基础](https://luck428.com/legal/column/souzoku-hoki-gentei-shonin)，财产盘点请见[继承财产目录的制作](https://luck428.com/legal/column/souzoku-zaisan-mokuroku)。

## 继承的借款或保证债务，要如何调查？

被继承人的债务并非集中于一处。请比对下列资料加以查明。

| 调查对象 | 可得知的事项 |
| --- | --- |
| 合同・金钱消费借贷证书・保证合同书 | 借款・保证的对象与金额 |
| 邮件（请款单・催缴通知・催告书） | 持续中的债务或欠缴 |
| 存折・账户扣款记录 | 还款・租赁・保证费的支付 |
| 向信用信息机构的开示请求 | 贷金・信用卡・银行交易的登录信息 |

信用信息登录于CIC・JICC・全国银行个人信用信息中心。法定继承人在部分情形可请求开示已故者的信息，惟所需文件（如户籍）与可否、方式因机构而异。请求前请以各机构最新说明确认。依民法第915条第2项，继承人于承认・放弃前可调查继承财产。

## 连带保证人的地位会被继承吗？

一般保证债务・连带保证债务为金钱债务，原则上由继承人承继并依法定应继分分担。至于未定上限或期间的持续性保证，另有不同处理。

| 保证种类 | 继承的处理（原则） |
| --- | --- |
| 特定债务的保证・连带保证 | 会被承继 |
| 个人根保证合同 | 因主债务人或保证人死亡而本金确定（民法第465条之4第1项第3款）；承继至死亡时确定的部分 |
| 身元保证 | 视为一身专属，原则上不被承继（已确定的具体赔偿另计） |

受主债务人委托而为保证的保证人，可向债权人请求余额等信息提供（民法第458条之2，2020年〔令和2年〕4月1日施行）。这可作为确认被继承人生前所保证债务余额的线索。保证的具体效力与范围之判断请咨询律师。

## 单纯承认、限定承认、放弃继承该如何选择？

| 选择 | 内容 | 依据 |
| --- | --- | --- |
| 单纯承认 | 无限承继权利义务；在一定情形构成法定单纯承认 | 民法第920条・第921条 |
| 限定承认 | 仅于所得财产限度内清偿债务与遗赠 | 民法第922条〜第924条 |
| 放弃继承 | 视为自始即非继承人 | 民法第938条・第939条 |

限定承认须由共同继承人全体共同为之（第923条）。须于第915条第1项的期间内制作继承财产目录并提交家事法院，申述限定承认之意旨（第924条）。放弃继承须向家事法院申述（第938条）。若处分财产，或未于期间内办理，可能构成法定单纯承认（第921条）。放弃继承者于放弃时现实占有财产的，负有于交付前的保存义务（第940条，令和3年修正・2023年〔令和5年〕4月1日施行）。

## 3个月的熟虑期间自何时起算？来不及时怎么办？

熟虑期间自知悉继承对自己开始之时起算3个月（第915条第1项）。若期间内无法判断，可向家事法院申请延长期间。

起算点有例外。最高法院昭和59年4月27日判决认为，继承人相信完全无继承财产、且此一相信有相当理由时，期间自继承人认知、或通常可认知继承财产全部或一部存在之时起算。惟是否适用须就个案评价，无法一概断定。日后才发现高额借款的情形，请咨询司法书士・律师。

## 要向谁委托什么？（家事法院的申述・债务整理的转介）

| 委任对象 | 负责范围 |
| --- | --- |
| 四叶行政书士事务所 | 继承财产・债务的调查、继承财产目录制作支援 |
| 司法书士・律师 | 放弃继承・限定承认・熟虑期间延长之家事法院申述・申请书制作 |
| 律师 | 债务整理・诉讼、保证债务效力与范围之判断 |
| 税理士 | 继承税・视同转让所得之试算 |
| 司法书士 | 继承登记 |

**向家事法院提交的申述书・申请书制作，属行政书士的业务范围外。** 四叶行政书士事务所、四叶社会保险劳务士事务所、四叶不动产株式会社各为不同事业体，皆以独立的事业体受任。请与各领域负责人分别签约，由各受任者直接请款与收款。本事务所不收取介绍费。

请参阅[继承手续支援](https://luck428.com/legal/services/inheritance)、[受任流程](https://luck428.com/legal/nagare)与[报酬金额表](https://luck428.com/legal/ryokin)。继承不动产的出售由另签合同的[继承不动产咨询](https://luck428.com/souzoku)处理。

## 常见问题

**Q. 借款的有无要如何调查？**
A. 确认合同、催缴通知与存折扣款，并可考虑向信用信息机构（CIC・JICC・全国银行个人信用信息中心）开示。法定继承人在部分情形可请求已故者信息，惟所需文件与方式请以各机构最新说明确认。

**Q. 连带保证也会被继承吗？**
A. 一般保证・连带保证原则上会被承继。个人根保证合同因保证人等死亡而本金确定，身元保证原则上不被承继。具体效力与范围请咨询律师。

**Q. 超过3个月就必定是单纯承认吗？**
A. 逾期为法定单纯承认的一项事由，但起算点有最高法院昭和59年4月27日判决的例外，来不及时亦可向家事法院申请延长期间。是否适用须就个案判断。

**Q. 放弃继承的文件可以委托行政书士吗？**
A. 向家事法院提交的申述书・申请书制作属行政书士业务范围外，由司法书士・律师负责。行政书士进行继承财产・债务的调查与财产目录制作支援。
