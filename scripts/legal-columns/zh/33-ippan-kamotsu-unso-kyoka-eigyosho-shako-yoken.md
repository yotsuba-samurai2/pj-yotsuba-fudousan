**结论（先说要点）**：欲经营卡车运送业（一般货物汽车运送事业），须依货物汽车运送事业法第3条取得国土交通大臣（实务为地方运输局长）之许可。许可于符合同法第6条之基准时核发――事业计画适于确保运输安全、事业用汽车之数量（最低5辆）与车库规模符合国土交通省令基准、具备自行妥适遂行事业之经济基础与能力。本文为一般资讯提供，整理营业所・车库・休憩睡眠设施之位置与大小、前面道路与用途地域易落之点、申请至许可之标准处理期间，以及物件・车辆・劳务应交由何人处理。个别许可之可否，由运输支局・地方运输局审查。

## 一般货物汽车运送事业许可须符合什么始能核发？

一般货物汽车运送事业，系应他人需求、有偿以汽车（除三轮以上之轻型车及二轮车）运送货物之事业。欲开始经营，货物汽车运送事业法第3条规定须取得许可。

许可基准规定于同法第6条，要旨如下。

| 区分 | 内容（要旨） |
| --- | --- |
| 运输安全（第6条第1号） | 事业计画就防止过劳驾驶、事业用汽车之安全等，适于确保运输安全 |
| 事业计画之妥适（第6条第2号） | 事业用汽车之数量、车库规模及其他计画符合省令所定基准 |
| 遂行能力（第6条第3号） | 具备自行妥适且持续遂行事业之经济基础及其他能力 |
| 特别併装（第6条第4号） | 为特别併装货物运送时，妥适保有・管理装卸设施并采事故防止措施 |

此外，须不该当同法第5条之欠格事由（如自许可撤销起未逾一定期间者），常勤役员中1名须通过法令试验，须能选任运行管理者・整备管理者，并须估算所需资金并确保自有资金。事业用汽车须备妥最低5辆。四叶行政书士事务所于行政书士业务范围内，支援要件确认、事业计画与申请文件之制作、申请之代理。个别许可之可否，由运输支局・地方运输局审查。

## 营业所・休憩睡眠设施・车库之位置与大小要件为何？

营业所・休憩睡眠设施・车库，各有位置、大小与使用权原之要件。

| 设施 | 主要要件 |
| --- | --- |
| 营业所 | 具使用权原（自有，或租赁；租赁以契约期间1年以上或自动更新为目安）。建物符合建筑基准法・消防法。原则不得设于市街化调整区域。地目为农地（田・畑）者原则不可 |
| 休憩・睡眠设施 | 併设于营业所或车库。须使驾驶人睡眠时，每人须2.5㎡以上之睡眠设施。依运行形态能确保驾驶人8小时以上休息者，睡眠设施亦有不需之情形 |
| 车库 | 原则併设于营业所。无法併设时，须距营业所一定距离内（详后）。能收容所有计画之事业用汽车，且车辆与车库境界及车辆相互间有50公分以上之间隔 |

营业所与车库须位于不牴触都市计画法・建筑基准法・农地法等相关法令之处。若先签约物件，事后才发现因用途地域或地目而不能使用，即须重新寻找。宜于物件选定阶段依要件确认。

## 前面道路或用途地域于何种情形会落选？

许可申请中易被忽略者，为车库前面道路之宽度与营业所・车库之立地。

| 事项 | 目安 |
| --- | --- |
| 营业所与车库之距离 | 併设为原则。分开时，原则以直线距离距营业所10km以内（首都圈・近畿圈之一部等地区为5km・20km等，因地方运输局而异） |
| 前面道路之宽度 | 使用车辆能符合车辆限制令通行。以道路管理者之宽度证明书等证明（国道等亦有不需证明之情形） |
| 车库之使用权原 | 自有或租赁（租赁以契约期间2年以上且有自动更新记载为目安） |
| 立地（地目・区域） | 市街化调整区域原则不可。地目为农地者原则不可。即使于市街化区域，仍须确认用途地域之限制 |

若前面道路狭窄，欲使用之大型车不符合车辆限制令，该车库即无法取得许可。宽度证明书向道路管理者（国道・都道府县道・市町村道之窗口不同）取得。于决定物件前确认用途地域・地目・前面道路三点，可避免重做。

## 自申请至许可需多久？（标准处理期间）

自申请至许可之标准处理期间，于无文件不备・补正时，概略为3〜5个月。因地方运输局而有幅度：关东运输局约3〜4个月，近畿运输局约4〜5个月。此以法令试验合格与补正事项于期间内完成为前提。

| 阶段 | 内容・目安 |
| --- | --- |
| 提出申请书 | 经管辖之运输支局向地方运输局提出 |
| 标准处理期间 | 概略3〜5个月（因局而为3〜4・4〜5个月）。为无文件不备・补正时之目安 |
| 法令试验 | 常勤役员中1名受验。合格为许可之前提 |
| 许可・登录免许税 | 许可后缴纳登录免许税（12万日圆） |
| 运输开始 | 事业用汽车之登录（绿牌）、运行管理者・整备管理者之选任申报、运输开始申报 |

即使核发许可，仍须经事业用汽车之登录（取得绿牌）与运输开始前之确认，始能实际开始运送。以轻型卡车进行之货物轻型汽车运送事业（黑牌）为申报制，与此一般货物之许可系不同制度。

## 物件・车辆・劳务应交由何人处理？

一般货物汽车运送事业，涉及许认可・不动产・车辆・劳务。分工如下。

- 许可申请之要件确认・事业计画与文件制作・申请代理 → 四叶行政书士事务所（行政书士）
- 营业所・车库物件之寻找、用途地域・地目・前面道路之适合确认、租赁契约 → 四叶不动产株式会社（宅地建物交易业者）

## 常见问题

**Q. 事业用汽车不足5辆，仍能取得许可吗？**
A. 一般货物汽车运送事业以备妥事业用汽车最低5辆为要件。不足5辆即不得取得许可。以轻型卡车运送之货物轻型汽车运送事业（黑牌）为申报制，系无5辆要件之另一制度。属何者，视事业计画而定。

**Q. 可将自宅作为营业所吗？**
A. 若符合使用权原・建筑基准法・消防法・用途地域，或属可能。惟市街化调整区域或地目为农地之处，原则不得作为营业所。租赁时尚有契约期间与自动更新之要件。建议于决定物件前依要件确认。

**Q. 车库可远离营业所吗？**
A. 原则须併设于营业所。无法併设时，须置于距营业所直线距离原则10km以内（因地区为5km・20km等，因地方运输局而异）。并须车库前面道路符合车辆限制令，且车辆与境界・车辆相互间有50公分以上之间隔。

**Q. 申请后多久核发许可？**
A. 标准处理期间概略为3〜5个月（因局而为3〜4・4〜5个月）。此为无文件不备・补正时之目安，并以常勤役员之法令试验合格与补正事项于期间内完成为前提。个别审查期间由运输支局・地方运输局判断。
