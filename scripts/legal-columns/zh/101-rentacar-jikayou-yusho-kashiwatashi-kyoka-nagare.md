**先讲要点：** 在日本经营租车或共享汽车，须取得自家用自動車有償貸渡業许可。备齐申请文件与保险，规划取得许可后的车辆登记、租赁记录和整备管理，再向主要事务所所在地的运输支局申请。

更新日期：2026-10-10

## 租车业许可要向哪里申请？

道路运送法第80条第1项的许可，由主要事务所所在地的运输支局受理，按时计费的共享汽车也包含在内。出租人为车辆使用者的租车业，依国土交通省通达接受审查。

租车是出租车辆的业务，不得随租赁提供驾驶人。代驾客户自己的车辆，或由经营者运送乘客，分别适用其他制度。请参阅[驾驶代行的认定](/zh/legal/column/unten-daiko-nintei-eigyosho-zuihan-jidosha-yoken)及[介护出租车许可](/zh/legal/column/kaigo-taxi-fukushi-yuso-kyoka-shako-yoken)。

货物运输业务的条件，请参阅[一般货物汽车运输许可与营业所、车库要求](/zh/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)。

## 申请文件和保险要准备什么？

本次确认的国土交通省通达，最后记载的修订为国自旅第55号、2022年5月31日，附则规定适用于2022年6月1日以后的许可。请使用申请机关目前的表格。

| 文件 | 主要内容 |
|---|---|
| 申请书和申请人资料 | 法人的登记事项证明书、个人的住民票等 |
| 租金和租赁条款 | 费用和使用条件 |
| 不属于消极资格的确认书 | 确认申请人、法人董事等相关人员 |
| 各事务所、各车种的配置车辆数表 | 各事务所的车种和数量 |
| 运营计划 | 负责人、员工培训、整备管理和保险等 |

2022年通达列有刑罚记录、许可被撤销等消极资格，但不能直接视为2026年现行表格的内容。懲役和禁錮均自2025年6月1日起改为拘禁刑；本许可消极资格的过渡规定如何适用，尚未验证。申请人、董事等的具体情况，须由运输支局和具有相应资格的专业人员依据最新确认书核对。

| 通达的保险类别 | 最低保障额 |
|---|---|
| 对人保险 | 每人8,000万日元以上 |
| 对物保险 | 每起事故200万日元以上 |
| 搭乘者保险 | 每人500万日元以上 |

搭乘者保险可包含人身伤害保险。产品保障范围和投保条件须向保险公司确认，并准备证明符合标准的文件。

## 取得许可后如何公开条款和保存租赁记录？

通达的许可条件禁止出借营业名义，以及随租赁提供、介绍或安排驾驶人。驾驶人信息的提供也有禁止和例外规定，不能认为只提供联系方式就一定可以；请向运输支局确认通达引用通知的适用范围。

| 项目 | 许可条件 |
|---|---|
| 不提供驾驶人的告知 | 依通达认可的方法，在事务所公示、网站公开，或以书面、电子方式提示等 |
| 租金和租赁条款 | 在事务所公众易见处公示，或在网站公开 |
| 貸渡簿 | 记录承租人、驾驶人、驾照、车辆、租赁日期、费用、事故等，自租赁结束日起保存2年 |
| 貸渡証 | 以书面或电子方式交付，由驾驶人随身携带；租车型共享汽车有例外 |
| 年度报告 | 每年5月31日前提交上一年度的貸渡実績报告等 |

以上是通达的许可条件。共享汽车的运营方式能否适用貸渡証交付、携带的例外，须向申请机关确认。

## 车辆登记和整备管理者的门槛如何确认？

租车仍按自家用车登记，使用出租用途的平假名「わ」（部分为「れ」）。平假名用途标示和数字分类号码不同，营业许可和车辆登记也是不同程序。

中部运输局2022年6月的说明，对一个事务所使用的自家用车列出以下整备管理者门槛。

| 车种 | 须选任的数量 |
|---|---|
| 核定乘车人数11人以上的汽车 | 1辆以上 |
| 车辆总重8t以上的货车 | 5辆以上 |
| 核定乘车人数10人以下的乘用车、总重未满8t的货车 | 10辆以上 |

请依据道路運送車両法第50条和施行规则第31条之3，向运输支局确认现行规定，包括车种、车辆使用者以及持有、使用的分类。

通达不允许出租核定乘车人数30人以上或车长超过7m的自家用巴士，以及灵柩车。自家用小型巴士另有经营实绩等条件，新经营者未必能按普通乘用车的条件开业。具体车种在申请机关的条件尚未验证。

## 开业准备分别由谁协助？

| 专业人员、经营主体 | 主要职责 |
|---|---|
| 四葉行政書士事務所 | 许可、申报文件制作和代理；资格业务范围内的公司章程等文件支持 |
| 司法书士等 | 公司设立、董事变更的登记 |
| 税理士 | 税务咨询、申报 |
| 申请人、汽车销售店等 | 车辆登记 |
| 保险公司、整备经营者 | 保险产品、车辆整备 |
| 四葉社会保険労務士事務所 | 雇用后的劳动事务、劳动保险和社会保险 |
| 四葉不動産株式会社 | 营业所房源寻找、租赁中介 |
| 律师 | 赔偿纠纷、刑事案件等 |

四葉行政書士事務所、四葉社会保険労務士事務所、四葉不動産株式会社分别为独立的经营主体。客户与各专业人员、经营主体分别签约，由其直接收费、直接收款。本事务所不收取介绍费。许可的审查和决定由行政机关作出。请参阅[受任流程](/zh/legal/nagare)、[报酬额表](/zh/legal/ryokin)及[许认可服务](/zh/legal/services)。

## 常见问题

**Q. 租车业需要许可还是申报？**
A. 以经营方式有偿出租自家用车，须取得道路运送法第80条第1项的许可，共享汽车也包含在内。请向主要事务所所在地的运输支局申请。

**Q. 租车会使用营业用绿色车牌吗？**
A. 租车仍按自家用车登记，使用出租用途的平假名「わ」（部分为「れ」）。平假名和分类号码不同，车辆登记和营业许可也是不同程序。

**Q. 可以连同驾驶人出租车辆吗？**
A. 随租赁提供、介绍或安排驾驶人属于禁止事项，须依通达认可的事务所公示、网站公开等方法告知。提供驾驶人信息的例外，也请先向申请机关确认，不自行判断。

**Q. 一定要选任整备管理者吗？**
A. 取决于车种和数量。本次确认的运输局说明中，每个事务所的门槛为11人以上车辆1辆、8t以上货车5辆、10人以下乘用车或未满8t货车10辆以上。请连同使用者、使用分类向运输支局确认现行规定。
