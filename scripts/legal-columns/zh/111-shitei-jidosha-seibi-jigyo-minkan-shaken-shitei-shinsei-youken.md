**结论（先讲重点）**：认证是“可进行特定整备”的资格，指定（民间车检场）是由自家汽车检查员检查并核发保安基准适合证的资格。指定以取得认证为前提，另外加上完成检查场等设备与汽车检查员的选任。

**信息确认日：2026年10月12日**。本文写给运营特定整备认证工厂、想升级为指定汽车整备事业（民间车检场）并自行检查的业者，整理与认证的差异及设备、人员要件。认证本身的流程请见[汽车特定整备的认证申请](https://luck428.com/legal/column/jidosha-tokutei-seibi-ninsho-shinsei-nagare-youken)。

## 认证工厂与指定工厂（民间车检场）有何不同？

依据为道路运送车辆法（昭和26年法律第185号）。认证与指定是不同处分，取得顺序与角色皆不同。

| | 认证（认证工厂） | 指定（指定工厂・民间车检场） |
| --- | --- | --- |
| 依据 | 第78条第1项 | 第94条之2第1项 |
| 取得内容 | 地方运输局长的认证 | 地方运输局长的指定（须先有认证） |
| 可做事项 | 特定整备（点检・整备） | 另可自行检查并核发保安基准适合证 |
| 车检时的现车 | 须将车辆送至运输支局等检查场 | 提交保安基准适合证可省略现车提示 |

特定整备在2020年（令和2年）4月1日由原本的分解整备扩大范围，加入与自动驾驶相关的电子控制装置整备。认证是进行此特定整备的资格，指定则由认证工厂中符合一定基准者申请取得。

## 取得指定后，自家可做到什么程度？

指定工厂对于由汽车检查员检查、确认符合保安基准的车辆，可核发保安基准适合证与保安基准适合标章（第94条之5）。将该证提交运输支局・汽车检查登录事务所等，即可在续检等时省略向国家检查场提示现车。

但这并非“国家把检查权限移转给民间”。指定是将部分检查委由民间办理的制度，须在国家稽核、对应受临时检查车辆的核发限制等框架内运作。保安基准适合证与标章附有有效期间（第94条之5第6项），天数请以最新的运输局说明确认。

## 设备、工员、汽车检查员的要件为何？

依国土交通省说明，指定除取得认证外，另需下列事项。具体尺寸与机器清单请以告示、规则及主管运输局最新说明确认。

| 区分 | 主要内容 |
| --- | --- |
| 设备・技术・管理组织 | 符合优良汽车整备事业者认定规则所定水准 |
| 检查设备 | 具备指定汽车整备事业规则所定检查设备 |
| 设施 | 室内作业场外，另需车辆置场与完成检查场 |
| 工员 | 4人以上（处理大型车时依条件需5人以上）；其中3分之1以上须持汽车整备士资格 |
| 汽车检查员 | 依第94条之4于各事业场选任；须有整备主任者1年以上实务经验并修毕教习（1级汽车整备士为6个月以上） |

大型车指车辆总重量8公吨以上、最大载重量5公吨以上，或乘车定员30人以上的车辆。汽车检查员的选任・变更须于15日内向地方运输局长申报（第94条之4第3项）。资格要件细节请以最新的国家考试与教习说明确认。

## 指定申请向谁提出、需要哪些文件？

| 项目 | 内容 |
| --- | --- |
| 提出对象 | 事业场所在都道府县的运输支局 |
| 审查流程 | 运输支局形式审查 → 地方运输局内容审查 → 地方运输局长决定指定 |
| 标准处理期间 | 依国土交通省说明，自申请至决定约45日 |

申请书须附设备明细、检查机器、汽车检查员选任、管理组织等文件。表格、附件与规费以主管运输局最新说明为准。上表并非适用于所有事业场的固定文件清单。

## 取得指定后须遵守哪些义务？（适正化・账簿・保安基准适合证）

取得指定后，须持续适正地执行检查、整备记录与账簿、适正核发保安基准适合证。汽车检查员若有不正行为，地方运输局长可命令解任（第94条之4第4项），自解任起2年内不得担任检查员（同条第5项）。指定本身在不再符合基准时亦可能被撤销等。

| 委任对象 | 负责范围 |
| --- | --- |
| 四叶行政书士事务所 | 指定申请文件制作与手续说明 |
| 地方运输局・运输支局 | 汽车检查员选任要件之确认、指定审查 |
| 设备业者 | 检查用机器・完成检查场・建物之设置 |
| 司法书士 | 法人之设立・变更登记 |
| 四叶社会保险劳务士事务所 | 检查员之加班・排班等劳务 |

四叶行政书士事务所、四叶社会保险劳务士事务所、四叶不动产株式会社各为不同事业体，皆以独立的事业体受任。请与各领域负责人分别签约，由各受任者直接请款与收款。本事务所不收取介绍费。运输局・运输支局为行政手续窗口，并非受任契约的对象。

## 常见问题

**Q. 已有认证，是否就不需要指定？**
A. 认证是进行特定整备的资格，指定是自行检查并核发适合证的资格。若要自行检查并省略现车提示即需指定，认证则为其前提。

**Q. 取得指定后是否就不必前往国家检查场？**
A. 提交保安基准适合证即可在续检等时省略现车提示。但须在国家稽核、临时检查及核发限制等框架内运作，并非所有检查权限皆移转。

**Q. 任何人都能担任汽车检查员吗？**
A. 须有整备主任者1年以上实务经验并修毕教习（1级汽车整备士为6个月以上）等要件，于各事业场选任并向地方运输局长申报。细节请以最新国家考试与教习说明确认。

**Q. 指定申请向哪里提出、需时多久？**
A. 向事业场所在的运输支局提出，经运输支局形式审查与地方运输局内容审查后，由地方运输局长决定。依国土交通省说明，自申请至决定约45日。
