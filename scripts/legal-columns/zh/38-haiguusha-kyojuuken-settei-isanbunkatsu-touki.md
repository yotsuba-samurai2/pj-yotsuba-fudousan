**结论（先说要点）**：配偶者居住权使被继承人之配偶，得于其于继承开始时所居住、被继承人所有之建物，终身或一定期间无偿继续居住（民法第1028条，令和2年4月1日施行）。取得原因为遗产分割或遗赠，亦有由家庭裁判所审判取得者（民法第1029条）。存续期间原则为配偶之终身，得以协议・遗言・审判为别段之定（民法第1030条）。于遗产分割协议书载明配偶取得配偶者居住权之旨与居住建物・存续期间，并就建物备妥设定登记（民法第1031条、不动产登记法第81条之2），则对其后取得建物之第三人亦得对抗。设定登记之申请由司法书士，配偶者居住权与敷地利用权之评价・继承税由税理士，争议由律师处理，行政书士则负责遗产分割协议书等之制作。本文为一般资讯提供，整理成立要件・存续期间・协议书记载・登记与评价之分工・与配偶者短期居住权之差异。个别设定之可否与评价额，由资格者之判断而定。

## 配偶者居住权由谁、于何种情形得以取得？

配偶者居住权系民法第1028条第1项所定之权利，符合下列要件之配偶得以取得。其一，须为被继承人之配偶。此所称配偶系经法律婚姻之配偶，不含事实上（内缘）之配偶。其二，该配偶于继承开始时，居住于被继承人所有之建物。建物为被继承人与配偶共有者得以取得，惟与被继承人以外之第三人共有之建物则非属对象。

取得原因为同项所定之遗产分割取得（第一号）与遗赠取得（第二号）。此外，受遗产分割请求之家庭裁判所，于一定情形亦得以审判使配偶取得配偶者居住权（民法第1029条）。配偶者居住权即使仅居住于建物之一部，亦及于建物全部。

| 事项 | 内容 |
| --- | --- |
| 依据 | 民法第1028条（配偶者居住权）・第1029条（审判取得） |
| 施行 | 适用于令和2年4月1日以后开始之继承 |
| 得取得者 | 于继承开始时居住于被继承人所有建物之法律上配偶（不含内缘） |
| 取得原因 | 遗产分割・遗赠・家庭裁判所之审判 |
| 及于范围 | 居住建物之全部（即使仅居住一部亦及于全体） |

配偶者居住权系即使自宅所有权由其他继承人取得，仍能确保配偶居住权之机制。用于自宅评价偏高、配偶若取得所有权则无法取得存款等其他财产之情形。

## 得以遗产分割或遗赠设定，存续期间如何决定？

配偶者居住权除以遗产分割之协议・调停・审判设定外，亦得以遗言之遗赠设定。以遗赠定明者，配偶得不待遗产分割协商即确实取得。又，虽有被继承人书明「使配偶继承配偶者居住权」之例，惟为确实设定，一般案内以遗赠之方式为之。

存续期间依民法第1030条原则为配偶之终身。惟遗产分割之协议・遗言有别段之定，或家庭裁判所于遗产分割审判为别段之定时，即依其期间。亦得设定10年・20年之有期。

| 事项 | 内容 |
| --- | --- |
| 设定方法 | 遗产分割（协议・调停・审判）／遗赠 |
| 存续期间 | 原则为配偶之终身（民法第1030条）。得以协议・遗言・审判设为有期 |
| 得否让与 | 配偶者居住权不得让与（民法第1032条第2项）。无法变卖现金化 |
| 费用负担 | 居住建物之通常必要费由配偶负担（民法第1034条） |

配偶者居住权系为配偶本人之权利，不得让与他人（民法第1032条第2项）。欲使第三人使用・收益居住建物者，须经建物所有者之承诺。配偶应以善良管理人之注意使用建物，并负担固定资产税等通常必要费。

## 遗产分割协议书应如何记载配偶者居住权？

以遗产分割设定时，于遗产分割协议书载明由何继承人取得居住建物之所有权，及配偶取得配偶者居住权。居住建物以登记事项（所在・地番・家屋番号・种类・构造・床面积）特定，并记载存续期间。设为终身者载明其旨，设为有期者记载期间。

为设定登记，将不动产登记法第81条之2所定之登记事项反映于协议书内容，可使手续顺畅。具体而言，存续期间，及有许第三人使用・收益居住建物之定者其定，均为登记事项。居住建物之所有者，对配偶负使其备妥配偶者居住权设定登记之义务（民法第1031条第1项），故于协议书载明所有者协力登记手续之旨，可使其后之登记申请易于进行。

| 记载事项 | 内容 |
| --- | --- |
| 权利者・义务者 | 取得配偶者居住权之配偶，与取得居住建物所有权之继承人 |
| 居住建物之特定 | 以所在・地番・家屋番号・种类・构造・床面积特定 |
| 存续期间 | 终身或期间（民法第1030条） |
| 对登记之协力 | 基于所有者备妥设定登记之义务（民法第1031条第1项）之协力 |

遗产分割协议书之制作，行政书士得于业务范围内支援。四叶行政书士事务所支援基于已合意内容之遗产分割协议书等之制作。个别条项有效性之判断，及有争议事案之代理，属律师之领域。

## 配偶者居住权之登记与评价（继承税）由谁负责？

配偶者居住权之设定登记，仅就居住建物为之，敷地（土地）不予登记。登记以配偶为权利者、建物所有者为义务者之共同申请为之。受他人委托而为之登记申请代理及登记申请书之制作，属司法书士或律师之业务。本事务所不为登记申请之代理及登记申请书之制作。

登记之意义在于对抗要件。民法第1031条第2项准用租赁之规定（民法第605条），未备妥设定登记者，不得对其后取得居住建物之第三人对抗配偶者居住权。备妥登记可确保继续居住之权利。

| 事项 | 负责・依据 |
| --- | --- |
| 设定登记之申请 | 司法书士（仅就建物・共同申请）。依据为不动产登记法第81条之2 |
| 对抗要件 | 备妥登记则得对第三人对抗（民法第1031条第2项准用民法第605条） |
| 继承税之评价 | 税理士。配偶者居住权・居住建物・基于配偶者居住权之敷地利用权・居住建物之敷地之评价（相续税法第23条之2） |

继承税上，将配偶者居住权与利用该土地之权利即敷地利用权评价为配偶侧之财产，其他继承人则评价为取得附负担之所有权（相续税法第23条之2）。配偶死亡致配偶者居住权消灭时之课税关系等，评价与税务之判断属税理士之领域。本事务所不进行税务咨询。

## 与配偶者短期居住权有何不同，发生争议时应向何人咨询？

配偶者短期居住权系民法第1037条所定之另一权利。配偶于继承开始时无偿居住于被继承人所有之建物者，因继承开始而当然发生，至遗产分割确定居住建物归属之日，或自继承开始起经过6个月之日，以较迟者为止，得无偿继续居住。无须设定合意或登记，惟因无法登记，故对第三人无对抗力。其目的为遗产分割终了前之短期保护。

| 事项 | 配偶者居住权（第1028条） | 配偶者短期居住权（第1037条） |
| --- | --- | --- |
| 发生 | 以遗产分割・遗赠・审判设定 | 因继承开始而当然发生 |
| 存续期间 | 原则终身（亦得有期） | 至遗产分割确定日或继承开始起6个月经过日之较迟者为止 |
| 登记・对抗 | 以设定登记得对第三人对抗 | 无法登记（无对抗力） |
| 让与 | 不得让与 | 不得让与 |

就是否设定配偶者居住权、如何评价，继承人间生对立而协商无法达成时，则进入家庭裁判所之遗产分割调停・审判。与对造之交涉及调停・审判之代理属律师之领域。设定登记由司法书士，评价・继承税由税理士，遗产分割协议书等之制作由行政书士，分工各异。

## 常见问题

**Q. 配偶者居住权可变卖为现金吗？**
A. 配偶者居住权系为配偶本人之权利，不得让与他人（民法第1032条第2项），故无法变卖现金化。欲使第三人使用・收益居住建物者，须经建物所有者之承诺。得予抛弃，惟其对价与税务之处理视个别情事而定，评价・税务请向税理士确认。

**Q. 内缘之妻亦得取得配偶者居住权吗？**
A. 得取得配偶者居住权者为经法律婚姻之配偶（民法第1028条第1项），不含内缘之配偶。就住居确保之考量，或须检讨以遗言之遗赠，或其他权利（租赁权・使用借贷等），个别设计由资格者之判断而定。

**Q. 不登记会如何？**
A. 配偶者居住权未备妥设定登记者，不得对其后取得居住建物之第三人对抗（民法第1031条第2项准用民法第605条）。备妥登记则得对第三人主张继续居住之权利。设定登记仅就建物为之，该申请之代理属司法书士或律师之业务。

**Q. 遗产分割协议书之制作可委托何人？**
A. 基于已合意内容之遗产分割协议书等之制作，行政书士得于业务范围内支援。配偶者居住权之设定登记由司法书士，评价・继承税由税理士，有争议之事案由律师，均为独立的事业体个别处理。本事务所不收取介绍费。
