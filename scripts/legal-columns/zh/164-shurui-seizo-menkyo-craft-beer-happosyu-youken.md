**结论（先讲要点）**：制造酒类，须按所制造酒类的品目、并按各制造场，向其所在地的所辖税务署长取得「酒类制造免许」（酒税法第7条第1项）。啤酒须达年60千升，发泡酒与其他酿造酒类须达年6千升的最低制造数量基准（酒税法第7条第2项），须有达成该基准的预估才符合要件。本文以行政书士视角整理免许区分、要件与申请流程，属一般性信息提供，免许可否的最终判断由所辖税务署作出。酒税的申报・缴纳与税务交由税理士，制造设备的建筑确认・用途交由建筑士，附设餐饮时的食品卫生交由保健所，物件要件交由宅地建物交易业者（另一事业体的四叶不动产股份有限公司），各以独立的事业体分别签约为前提分开委任。本事务所不收取介绍费。

## 酒类制造免许与「酒类零售免许」有何不同，免许又如何按酒类区分？

与酒相关的免许大致分为「制造」与「销售」。酿造方取得酒类制造免许（酒税法第7条），销售已完成酒类的一方取得酒类销售业免许（第9条）。开设酿造所（brewery）自酿啤酒的行为须有制造免许，而将其以瓶装或罐装零售的行为，可能另须「酒类零售业免许」。若酿造并自售，须将销售免许与制造免许分开检讨。零售免许的要件与店铺・物件思路，整理于[酒类零售业免许与店铺・物件要件](https://luck428.com/legal/column/shurui-kouri-menkyo-tenpo-bukken-yoken)。

制造免许按「品目别・按各制造场」取得。即酿啤酒取啤酒的免许，酿发泡酒取发泡酒的免许，按所酿酒类的品目区分，并按各制造场（工厂・酿造所）取得。酒类的品目于酒税法第3条区分为清酒・啤酒・果实酒・发泡酒・其他酿造酒・利口酒・烈酒等，同样的「精酿啤酒」也会因麦芽使用比例与副原料而被归为啤酒、发泡酒或其他酿造酒。要申请哪一品目的免许，须以原料与配方为前提向所辖税务署确认，品目的最终归类为税务署的判断。

## 啤酒・发泡酒・其他酿造酒类的「最低制造数量基准」是多少？

酒类制造免许规定，于一制造场取得制造免许后一年内预计制造的数量，若未达各品目所定数量，即不得取得（酒税法第7条第2项），称为最低制造数量基准。主要品目如下。

| 品目 | 最低制造数量基准（每年・每一制造场） |
|---|---|
| 清酒・合成清酒・连续式蒸馏烧酎・啤酒 | 60千升 |
| 单式蒸馏烧酎・味淋 | 10千升 |
| 果实酒・甜味果实酒・威士忌・白兰地 | 6千升 |
| 发泡酒・其他酿造酒・原料用酒精 | 6千升 |
| 烈酒・利口酒・粉末酒・杂酒 | 6千升 |

精酿啤酒开业常见的争点，是啤酒（60千升）与发泡酒・其他酿造酒类（各6千升）之间的差距。依麦芽比例与啤酒花以外副原料的用法，有时在酒税法上并非「啤酒」而被归为「发泡酒」或「其他酿造酒」，即使小规模也可能以6千升的基准检讨免许。但品目归类由原料・制法决定，并非为压低基准而决定配方的顺序。属哪一品目须经税务署确认。啤酒基准虽于1994年由2,000千升下调至60千升，但现行数量如上表所示，撰稿前已对照国税厅最新手引确认。

## 制造场所・设备有何要件？（申请单位・制造设备）

因免许按各制造场取得，制造场所与设备即为审查对象。酒税法第10条规定，于申请免许时若有各款之一情形，税务署长得不给予免许，主要观点如下。

| 观点 | 酒税法第10条之相关（概要） |
|---|---|
| 人的要件 | 自免许撤销起一定年数内之人、国税・地方税之滞纳处分、酒税法等罚金刑之经过年数等（第1款至第8款） |
| 场所的要件 | 无正当理由于取缔上不适当之场所设置制造场（第9款） |
| 经营基础要件 | 认定经营基础薄弱之情形（第10款） |
| 需给调整要件 | 为保全酒税维持酒类供需均衡之必要而认不适当之情形（第11款） |
| 技术・设备要件 | 不具备制造技术能力，或制造场设备认定不充分之情形（第12款） |

制造设备（投料・发酵・贮酒・过滤・灌装・计量等）与能确实管理制造数量的体制，被作为「技术・设备要件」审视。给排水・排水处理・建物用途也牵涉其他法令（建筑基准法・水质相关规制・食品卫生），故于施工或签订租赁契约前，应向建筑士・施工公司或所辖窗口确认。制造设备的建筑确认・用途判断属建筑士领域，行政书士不保证设计或合法性。

## 构造改革特区（浊酒特区・葡萄酒特区等）在何种情形放宽基准？

构造改革特别区域法设有在经认定特区内放宽最低制造数量基准的酒税法特例，代表者为所谓「浊酒特区」与「葡萄酒特区」。

- 浊酒特区（构造改革特别区域法第25条「酒税法之特例」）：经营农家民宿等的特定农业者，以自行生产的米或果实为原料，于自己营业场供饮用而制造浊酒（不过滤的其他酿造酒）或果实酒时，不适用酒税法第7条第2项（最低制造数量基准）之特例。
- 葡萄酒特区・特产酒类之特例（第26条）：依认定计划的事业者以特产果实为原料制造果实酒等时，将果实酒的基准由「6千升」读替为「2千升」、利口酒读替为「1千升」等放宽（单式蒸馏烧酎・原料用酒精为适用除外）。

二者均以该地区已取得构造改革特别区域计划之内阁总理大臣认定，且符合对象者・对象品目・原料要件为前提。于特区外制造同一品目者，适用原则的最低制造数量基准。自己的计划是否属特区对象，须对照特区计划内容及所辖税务署・自治体的指引确认。

## 申请向何处・以何种文件提出，审查约需多久？

申请对象为制造场所在地所辖的税务署（所辖税务署长）。除申请书外，另须提出显示事业计划・制造方法・制造设备・资金计划・场所状况等的附件。具体样式・附件须对照国税厅「酒类制造免许申请手引」与所辖税务署指引确认。

| 确认点 | 内容（申请前向税务署・手引确认） |
|---|---|
| 申请对象 | 制造场所在地之所辖税务署长 |
| 免许单位 | 品目别・按各制造场 |
| 主要附件 | 事业・制造计划、制造方法书、制造设备概要、场所图纸・契约关系、收支预估、申请人经历等 |
| 审查观点 | 人的・场所的・经营基础・需给调整・技术/设备各要件（酒税法第10条）、达成最低制造数量基准之预估（第7条第2项） |
| 标准处理期间 | 以税务署公布之标准处理期间为参考确认（依申请内容增减） |

审查所需期间因申请内容与有无补正而异。标准处理期间并非法定确定期限，故日程须向所辖税务署确认。是否给予免许的最终判断由所辖税务署作出。行政书士负责申请文件的制作・整理与手续进行支援，不保证可否或品目归类。委任流程见[委任流程](https://luck428.com/legal/nagare)、费用见[报酬额表](https://luck428.com/legal/ryokin)、承办业务见[许认可服务](https://luck428.com/legal/services)。

## 酒税申报・物件・食品卫生该委任给谁？（税理士・不动产・保健所的切分）

酿造所开业除免许外，横跨税务・物件・食品卫生等多领域，各以独立的事业体分别签约为前提分开委任。

| 委任对象 | 主要角色 |
|---|---|
| 四叶行政书士事务所 | 酒类制造免许申请文件之制作・提出、手续进行支援 |
| 税理士 | 酒税之申报・缴纳、法人税・消费税等税务 |
| 建筑士・施工公司 | 制造设备之设计・施工、建筑确认・用途判断（依资格・业务范围） |
| 保健所 | 附设餐饮时之餐饮店营业许可・食品卫生咨询 |
| 四叶不动产股份有限公司（另一事业体） | 制造用物件之介绍・租赁之中介 |

酒税之申报・缴纳与税务属税理士，制造设备之建筑确认・用途属建筑士，附设餐饮时之食品卫生许可属保健所，物件要件属宅地建物交易业者的领域。若附设餐饮店，请并参[餐饮店营业许可与保健所设备基准](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)；若涉及食品制造，请参[食品制造业许可与物件・设备基准](https://luck428.com/legal/column/shokuhin-seizogyo-kyoka-bukken-setsubi-kijun)。四叶行政书士事务所・税理士・建筑士・四叶不动产股份有限公司为另一事业体，各以独立的事业体，与各专家・业者分别签约，以直接请款・直接入账的形式受任。本事务所不收取介绍费。制造用物件之咨询由另一事业体的四叶不动产股份有限公司负责。

## 常见问题

**Q. 想小规模酿精酿啤酒，是否一定要年产60千升才能取得免许？**
A. 若以啤酒品目取得免许，须有于一制造场每年达60千升最低制造数量基准（第7条第2项）之预估。但若麦芽比例或副原料使其在酒税法上被归为「发泡酒」或「其他酿造酒」，则有时可以6千升基准检讨免许。属哪一品目由原料・制法决定，最终归类由所辖税务署判断。

**Q. 是否同时需要制造免许与酒类零售业免许？**
A. 酿造行为可能须制造免许（第7条），将完成酒类零售的行为可能另须酒类零售业免许（第9条）。若自酿并自售，须分开检讨二者之要否，细节请向所辖税务署确认。

**Q. 在浊酒特区或葡萄酒特区，小规模是否也能制造？**
A. 仅于经认定特区内，符合对象者・对象品目・原料要件时，才有不适用或下调最低制造数量基准的特例（构造改革特别区域法第25条・第26条）。特区外适用原则基准。自己的计划是否为对象，须对照特区计划及所辖税务署・自治体确认。

**Q. 审查约需多久？**
A. 因申请内容与有无补正而异。请以所辖税务署公布之标准处理期间为参考确认。标准处理期间并非法定确定期限，是否给予免许的最终判断由所辖税务署作出。
