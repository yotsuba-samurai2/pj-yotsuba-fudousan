**结论（先讲重点）**：开办护理出租车（有偿运送需护理者就医、外出），须依道路运送法第4条取得国土交通大臣（实务为地方运输局长）的许可。多数属一般乘用旅客自动车运送事业中的“福祉运送事业限定”许可；若使用附轮椅、担架设备的福祉自动车，车辆一台即可申请。驾驶人须持有为有偿运送旅客的第二种驾驶执照（道路交通法第86条）；若以轿车型的一般车辆进行护理运送，驾驶人还须具备护理福祉士、访问护理员（居家照护员）等资格。本文以行政书士观点，整理许可种类、营业所与车库（物件）要件、二种驾照与护理资格、费用与期间概估，以及物件、驾照、劳务该交给谁，属一般资讯提供。个别许可之可否由运输支局・地方运输局审查决定。

## 开办护理出租车（福祉运送）需要哪种许可？

护理出租车是回应他人需求、有偿以包租乘用车运送需护理者的事业。开办须依道路运送法第4条取得一般旅客自动车运送事业许可。

道路运送法第3条将旅客自动车运送事业分类，护理出租车属“一般乘用旅客自动车运送事业”（以一个契约包租乘车定员未满11人之车辆运送旅客之事业）。实务上，多以将运送对象限于需护理者的“福祉运送事业限定”许可为主。

许可基准规定于道路运送法第6条，要旨如下。

| 区分 | 内容（要旨） |
| --- | --- |
| 运送安全（第6条） | 事业计划为确保运送安全而适当 |
| 事业计划适当（第6条） | 营业所・车库・车辆等计划不妨害运送安全及公共福祉 |
| 遂行能力（第6条） | 具备自行适切且持续遂行事业之能力（资金等） |

此外，须不该当道路运送法第7条之欠格事由（如许可被撤销后未经一定期间者）。四叶行政书士事务所于行政书士业务范围内，协助确认要件、制作事业计划与申请文件、代理申请。个别许可之可否由运输支局・地方运输局审查决定。

## 一般乘用旅客与“福祉运送事业限定”有何不同？

同为一般乘用旅客自动车运送事业，一般法人出租车与福祉运送事业限定，在运送对象与最低车辆数上不同。

| 事项 | 一般乘用旅客（法人出租车） | 福祉运送事业限定（护理出租车） |
| --- | --- | --- |
| 运送对象 | 不特定之一般旅客 | 限经认定为需护理・需支援者、领有身心障碍者手册者，及因肢体不便・内部障碍等而单独移动或利用公共交通困难者等 |
| 最低车辆数 | 依营业区域订定之最低车辆数（多数区域为5台以上） | 车辆1台即可申请 |
| 主要使用车辆 | 一般乘用车 | 福祉自动车（附轮椅・担架用升降机或斜坡等之车）或一般车辆（轿车型等） |

福祉运送事业限定可自1台起步，适合个人或小规模开业。惟可运送对象限于需护理者，是与一般出租车的重大差异。因运送对象不同会改变应取得的许可种类，宜在事业计划阶段整理清楚对象。

## 营业所・车库（物件）与车辆有哪些要件？

营业所・车库・休息小睡设施与车辆各有要件。

| 设施・车辆 | 主要要件 |
| --- | --- |
| 营业所 | 具使用权原（自有或租赁）。位于不抵触建筑基准法・都市计划法・农地法等相关法令之场所。市街化调整区域原则不得设置 |
| 车库 | 原则与营业所并设。无法并设时，须距营业所一定距离内（部分地区为2km，依地方运输局而异）。可容纳所有使用车辆，前面道路符合车辆限制令 |
| 休息・小睡设施 | 与营业所或车库并设，供驾驶人休息 |
| 车辆 | 福祉自动车（附轮椅・担架用升降机或斜坡、旋转座椅等之车），或一般车辆（轿车型）。须具使用权原 |

若先签物件、事后才发现因用途地域或地目不能用，就得重新寻找。宜在物件选定阶段对照要件确认。营业所・车库物件之寻找与租赁，由别事业体四叶不动产株式会社（宅地建物交易业者）承办。

## 驾驶人的二种驾照与护理资格、劳务如何处理？

有偿运送旅客之驾驶，除道路运送法外，另须道路交通法第86条之第二种驾驶执照。驾照区分规定于道路交通法第84条；为旅客运送而驾驶旅客自动车，须持有第二种驾照。

此外，若非福祉自动车而以轿车型等一般车辆进行护理运送，驾驶人须具备下列之一资格。

| 使用车辆 | 驾驶人须具备 |
| --- | --- |
| 福祉自动车（附升降机・斜坡等） | 对应使用车辆之第二种驾驶执照 |
| 一般车辆（轿车型等） | 第二种驾照，另加护理福祉士・访问护理员（居家照护员）・居宅护理从业者・护理运送服务从事者研修结业者等之一资格 |

驾驶人之工时・社会保险・工作规则等劳务，属社会保险劳务士领域。若雇用驾驶人开业，须另行整备劳务设计。

## 至许可为止的流程与费用・期间概估？

自申请至开始运送之流程与费用概估如下。

| 阶段 | 内容・概估 |
| --- | --- |
| 提出申请书 | 经管辖运输支局向地方运输局提出 |
| 所需资金 | 须依人事费・车辆费・燃料费・保险费等估算，确保自有资金 |
| 标准处理期间 | 审查约2个月（依地方运输局而异）。无文件缺漏・补正时之概估 |
| 许可・登录免许税 | 许可后缴纳登录免许税（3万日元） |
| 开始运送 | 事业用自动车登录（绿牌）、整备营运与整备管理体制、提出开始运送之申报 |

以法人申请出租车事业时，役员须经法令考试；福祉运送事业限定则处理方式可能不同。要件细部因地方运输局・运输支局而异，请于申请地之最新手引确认。即使取得许可，仍须经事业用自动车登录（福祉限定绿牌）与开始运送前之确认，方能实际开始运送。

## 常见问题

**Q. 只有1台车也能开办护理出租车吗？**
A. 福祉运送事业限定之一般乘用旅客自动车运送事业，车辆1台即可申请。一般法人出租车须具依营业区域订定之最低车辆数（多数区域5台以上），但福祉运送事业限定放宽此要件。属何者取决于运送对象与事业计划。

**Q. 用轿车型的一般轿车也能做护理出租车吗？**
A. 可能可行，但以轿车型等一般车辆进行护理运送，驾驶人除第二种驾驶执照外，还须具备护理福祉士・访问护理员（居家照护员）等资格。若使用附轮椅・担架设备之福祉自动车，具对应车辆之第二种驾照即可。

**Q. 可以把自宅当营业所或车库吗？**
A. 若具使用权原且不抵触建筑基准法・都市计划法・农地法等，可能可行。惟市街化调整区域原则不得设置。车库原则与营业所并设，无法并设时须距营业所一定距离内（部分地区2km，依地方运输局而异）。建议于决定物件前对照要件确认。

**Q. 申请后多久会核准？**
A. 审查之标准处理期间约2个月（依地方运输局而异）。此为无文件缺漏・补正时之概估，并以所需资金之确保与补正事项之解消于期间内完成为前提。个别审查期间由运输支局・地方运输局判断。
