**结论（先说要点）**：以事业经营汽车特定整备（原分解整备加上电子控制装置整备）者，须依道路运送车辆法第78条，就各事业场取得地方运输局长之认证。认证基准见第80条：须符合作业场・车辆置场之规模（道路运送车辆法施行规则别表第四）、整备主任者等人员（同施行规则第62条之2之2），以及作业机械・器具・扫描工具（scan tool）等设备。申请经由事业场所在地管辖之运输支局（向地方运输局长提出）。2020年（令和2年）4月1日施行之改正，将原「分解整备」扩大为「特定整备」，新增与自动运行装置及驾驶辅助相关之电子控制装置整备。本文为一般资讯提供，整理须认证之整备范围、人员与设备要件、2020年改正内容、申请流程，以及物件・登记・税务应交由何人处理。个别认证之可否与必要文件，由管辖之运输支局之处理而定。

## 特定整备之认证于何种整备时始需要？

特定整备定义于道路运送车辆法施行规则第3条。同条第1号至第7号属原「分解整备」，对象为拆卸原动机、动力传达装置、行走装置、操纵装置、制动装置、缓冲装置、连结装置所为之整备・改造。第8号・第9号为2020年新增之「电子控制装置整备」，对象为自动运行装置，以及碰撞被害减轻刹车、车道偏离警报等驾驶辅助所用之摄影机・雷达等感测器之拆卸・调整（即所谓aiming定位）。

应他人需求、有偿且反复地以事业经营此等特定整备者，依道路运送车辆法第78条第1项须取得地方运输局长之认证。认证就各事业场、定明特定整备事业之种类（分解整备・电子控制装置整备）与对象自动车之种类（普通・小型・轻型・大型等）而取得。未取得认证而以事业经营特定整备者，属违法并为罚则对象。

| 事项 | 内容 |
| --- | --- |
| 依据 | 道路运送车辆法第78条第1项（自动车特定整备事业之认证） |
| 对象 | 分解整备（施行规则第3条第1号〜第7号）／电子控制装置整备（同第8号〜第9号） |
| 单位 | 就各事业场・定明事业种类与对象自动车种类而取得 |
| 申请地 | 事业场所在地管辖之运输支局（向地方运输局长提出） |

自家工场所为之整备是否属分解整备・电子控制装置整备，视作业内容而定。判断有疑义时，依事业计画向管辖之运输支局事前咨询较为确实。

## 认证所需之人（整备主任者・工员）与设备要件为何？

道路运送车辆法第80条定明地方运输局长审查申请之基准，规定事业场之设备・从业员・作业管理状况不符合省令所定基准时，不得认证。实务上之要件大致分为人员要件与设备・作业场要件。

| 区分 | 主要要件 |
| --- | --- |
| 整备主任者 | 依施行规则第62条之2之2选任。须具一级或二级自动车整备士等资格。电子控制装置整备原则须修毕运输支局长等所行电子控制装置整备之整备主任者等资格取得讲习（一级大型・一级小型整备士免讲习） |
| 工员 | 依对象自动车种类・作业确保人数 |
| 设备 | 作业所需之作业机械・器具。电子控制装置整备须具符合性能・机能要件之扫描工具及水准器等 |
| 作业场・车辆置场 | 施行规则别表第四所列规模之屋内作业场・车辆置场（数值因对象自动车种类而异） |

又，电子控制装置整备向来必备之扫描工具，于2025年7月8日之省令改正中，朝向原动机等分解整备事业场亦须配置之方向扩大。作业场・车辆置场之具体间口・奥行・面积依施行规则别表第四，惟因对象车种而异，故于决定物件前依运输支局之基准确认，可避免文件退回。作业场・车辆置场之物件侧要件，亦请参阅别事业体四叶不动产株式会社整理之[汽车整备工场（认证工场）可用物件之要件](https://luck428.com/column/jidosha-tokutei-seibi-ninsho-koujou-bukken-youken)。

## 2020年由分解整备改为特定整备之改正，电子控制装置整备有何变化？

随自动驾驶・驾驶辅助技术普及，道路运送车辆法施行规则经修正，自2020年（令和2年）4月1日起将原「分解整备」扩大为「特定整备」。此改正于拆卸机械部分之分解整备外，新增电子控制装置整备为认证对象。

| 事项 | 内容 |
| --- | --- |
| 施行日 | 2020年（令和2年）4月1日 |
| 变更点 | 将「分解整备」扩大为「特定整备」，新增电子控制装置整备 |
| 电子控制装置整备对象 | 自动运行装置、与驾驶辅助相关之摄影机・雷达等感测器之拆卸・调整（aiming）等 |
| 经过措施 | 2020年（令和2年）3月31日前已行电子控制装置整备之事业者，得于2024年（令和6年）3月31日前未认证继续，惟此经过措施已终了 |

因经过措施于令和6年3月31日终了，现行aiming等电子控制装置整备无法于未认证下进行。即使已取得分解整备认证之工场，欲进行电子控制装置整备，仍须另行取得追加该种类之认证（变更・追加申请）。

## 认证申请之文件与运输支局之手续流程为何？

认证依道路运送车辆法第79条，经由事业场所在地管辖之运输支局向地方运输局长申请。主要流程与文件如下。

| 阶段 | 内容 |
| --- | --- |
| 事前咨询 | 整理作业场图面・设备・人员，向管辖之运输支局事前咨询 |
| 文件准备 | 认证申请书、整备主任者选任申报书、工员名簿与证明整备士资格之文件、作业场・车辆置场之配置图・照片、土地建物之登记事项证明书或租赁契约书、法人须具登记事项证明书等 |
| 申请・审查 | 向运输支局申请。书面审查，并视需要就作业场・设备进行实地调查 |
| 认证・揭示 | 认证后揭示认证标识，并备特定整备记录簿记录 |

认证申请书及其附件之制作，属向官公署提出之文件制作，行政书士得于业务范围内支援。四叶行政书士事务所于行政书士业务范围内，支援认证申请书与整备主任者选任申报书等之制作。个别必要文件与实地调查之要否，由管辖之运输支局之处理而定。

又，认证工场（第78条）与依指定自动车整备事业（第94条之2）之指定工场（即所谓民间车检场）为不同制度。指定工场于工场内进行完成检查并得交付保安基准适合证，认证工场则于运输支局受检。指定工场之指定申请，行政书士亦得以官公署提出文件之制作支援。

## 物件之要件确认・公司设立与税务，应各交由何人处理？

取得特定整备认证，非仅文件制作，尚涉及物件・登记・劳务・税务。分工如下。

- 特定整备事业（分解整备・电子控制装置整备）之认证申请文件、指定工场之指定申请文件、整备主任者选任申报书之制作 → 四叶行政书士事务所（行政书士）
- 作业场・车辆置场物件之寻找、用途地域与使用权原之确认、租赁契约 → 四叶不动产株式会社（宅地建物交易业者）
- 公司设立・役员变更等之登记、土地建物所有权之登记 → 司法书士（建物表题・分笔等表示之登记由土地家屋调查士）
- 从业员之劳动保险・社会保险加保、就业规则・36协定 → 社会保险劳务士
- 法人税・所得税・消费税等税务之咨询・申报 → 税理士

## 常见问题

**Q. 认证工场与指定工场（民间车检场）有何不同？**
A. 认证工场系依道路运送车辆法第78条得进行特定整备之工场，车检（继续检查）之完成检查于运输支局受检。指定工场系依同法第94条之2之指定自动车整备事业，即得于工场内进行完成检查并交付保安基准适合证之所谓民间车检场。取得指定须以认证为前提，并符合更严之设备・人员・检查体制基准。两者之申请文件，行政书士均得以官公署提出文件之制作支援。

**Q. 仅进行aiming（摄影机・雷达之调整）亦须认证吗？**
A. 自动运行装置及与驾驶辅助相关之摄影机・雷达等感测器之拆卸・调整（aiming），属道路运送车辆法施行规则第3条之电子控制装置整备，以事业经营者须依第78条取得认证。给予2020年3月31日前已行者之经过措施已于令和6年3月31日终了，现行无法于未认证下进行。

**Q. 租赁物件亦能取得认证吗？**
A. 就作业场・车辆置场具使用权原者，租赁物件亦得为认证对象。申请时以土地建物之租赁契约书等证明使用权原。惟作业场・车辆置场之规模（施行规则别表第四）与用途须符合，故于签约前确认物件侧要件较为确实。物件侧之要件向宅地建物交易业者确认较为安全。

**Q. 认证申请之文件制作可委托何人？**
A. 认证申请书及其附件属向官公署提出之文件，其制作行政书士得于业务范围内支援。作业场・车辆置场物件之租赁属宅地建物交易业者，公司设立等之登记属司法书士，劳务属社会保险劳务士，税务属税理士，均为独立的事业体个别处理。本事务所不收取介绍费。
