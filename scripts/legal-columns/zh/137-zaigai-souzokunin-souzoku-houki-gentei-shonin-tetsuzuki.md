**结论（先讲重点）**：住在海外的继承人，也能向日本的家庭裁判所申述继承抛弃、限定承认（亦可邮寄）。熟虑期间为「自知悉自己已有继承开始之时起3个月」（民法第915条第1项），申述先为管辖被继承人最后住所地的家庭裁判所。

**资料确认日：2026年10月27日**。本文面向住在台湾、中国本土等地的继承人、在日本一方而有在外继承人的家属，以及现地的专门职，聚焦于自海外办理日本继承抛弃、限定承认的步骤，以及3个月熟虑期间的起算。抛弃、限定承认的基础请见[继承抛弃、限定承认的基础](https://luck428.com/zh/legal/column/souzoku-hoki-gentei-shonin)；涉及海外、外国籍之继承的全貌请见[涉及海外、外国籍的继承](https://luck428.com/zh/legal/column/souzoku-kaigai-gaikokuseki)；期间的起算与伸长请见[熟虑期间的起算点与伸长](https://luck428.com/zh/legal/column/souzoku-hoki-jukuryo-kikan-shincho-kisanten)。条文以[e-Gov法令检索](https://laws.e-gov.go.jp/)核对。

## 住在海外也能抛弃日本的继承吗？

能抛弃。继承抛弃系就被继承人（亡者）之继承向家庭裁判所提出之手续，与继承人住在何处无关。民法第938条规定「欲抛弃继承之人，须将其意旨向家庭裁判所申述」。抛弃继承之人，就该继承而言，视为自始未为继承人（民法第939条）。因此一经抛弃，继承权即移转予次顺位继承人（例如子女全部抛弃则移至父母，父母亦无则移至兄弟姊妹）。

若欲受领部分遗产、同时防范债务超过的风险，尚有限定承认之选择。民法第922条规定，继承人得保留仅于因继承所得财产之限度内清偿被继承人之债务及遗赠而为承认；继承人有数人时，限定承认须由共同继承人全体共同为之（民法第923条）。欲为限定承认，须于熟虑期间内制作遗产目录向家庭裁判所提出，并申述限定承认之意旨（民法第924条）。

申述先为管辖继承开始地的家庭裁判所。家事事件手续法第201条第1项规定，关于继承之承认及抛弃的审判事件，属「管辖继承开始地之家庭裁判所」之管辖，而继承于被继承人之住所开始（民法第882条、第883条）。亦即，向管辖被继承人最后住所地之家庭裁判所申述。在外继承人得以邮寄申述书及附件之方式提出（因往来联络系以邮件为之，宜预估国际邮件之时间而及早行动）。

| 选项 | 内容 | 主要依据 |
| --- | --- | --- |
| 单纯承认 | 承继全部权利与义务（债务） | 民法第920条 |
| 限定承认 | 仅于所得财产之限度内清偿债务；全体继承人共同申述并提出遗产目录 | 民法第922条、第923条、第924条 |
| 继承抛弃 | 视为自始未为继承人，移转予次顺位 | 民法第938条、第939条 |

## 3个月的熟虑期间从何时起算？可以伸长吗？

起算日为「自知悉自己已有继承开始之时」。民法第915条第1项规定，继承人须自知悉自己已有继承开始之时起3个月以内，为单纯承认、限定承认或抛弃之一。重点在于非自死亡之日起算，而是自「知悉自己已成为继承人之时」起算。住在海外而讣闻迟到者，或因先顺位继承人抛弃而成为继承人之次顺位者，其起算点为知悉该事实之时。

于期间内无法判断时，得声请伸长期间。民法第915条第1项但书规定，此期间「得因利害关系人或检察官之请求，由家庭裁判所伸长之」。在外继承，调查国外财产、债务，或取得户籍、公证书等需时之情形，可考虑于熟虑期间内向家庭裁判所声请伸长。又继承人于承认或抛弃前，得调查遗产（民法第915条第2项）。

| 项目 | 内容 |
| --- | --- |
| 熟虑期间 | 自知悉自己已有继承开始之时起3个月（民法第915条第1项） |
| 起算的观念 | 非死亡日，而系「知悉自己已成为继承人之时」 |
| 伸长 | 于期间内向家庭裁判所声请伸长（同项但书） |
| 遗产调查 | 于承认、抛弃前得调查（同条第2项） |

关于起算点，可能见解分歧，个别的起算日与伸长之可否，请于声请前向管辖之家庭裁判所与有资格者确认。

## 申述所需书件（台湾户籍、在外公馆之证明）由谁搜集？

共通须备者为：记载被继承人死亡之户籍（除籍、改制原户籍）誊本、被继承人之住民票除票或户籍附票、申述人（抛弃之人）之户籍誊本。依续亲（配偶、子女、父母、兄弟姊妹）而所需户籍之范围不同，第二顺位以后可能须备被继承人自出生至死亡之户籍。费用为每一申述人收入印纸800日圆及联络用邮票，邮票金额依裁判所而异（参照日2026-10-27，裁判所「继承抛弃之申述」）。

在外继承特有者为于国外制作之本人确认文件。于日本无住所、无印鉴登录之继承人，有以在外公馆（日本国大使馆、总领事馆）之签名（签署）证明代替印鉴证明之情形。继承人为外国籍、外国户籍时，须备各国之身分证明文件，如台湾之户籍（除户籍）、中国本土之公证书与领事认证等。因台湾无日本之大使馆、领事馆，证明实务由公益财团法人日本台湾交流协会（台北、高雄）担当。中国本土继承人之亲属关系公证书、领事认证之流程，于[中国本土继承人之亲属关系公证书与领事认证](https://luck428.com/zh/legal/column/chugoku-tairiku-souzokunin-shinzoku-koshosho-ryoji-ninsho)说明。何种文件于何种手续中被要求、签名证明是否足够，依裁判所、个案而异，本文未查证。

行政书士（当方）可协助者为继承人之确定（户籍之搜集、继承关系之整理）、台湾户籍、中国公证书等国外书件之搜集，以及限定承认时向家庭裁判所提出之遗产目录之制作。申述书本身之制作、提出，如次一节所述，角色有所分工。

| 书件、作业 | 主要担当 |
| --- | --- |
| 被继承人、继承人之户籍搜集、继承人之确定 | 行政书士（当方） |
| 台湾户籍、中国公证书等国外书件之搜集 | 行政书士（当方） |
| 限定承认之遗产目录制作 | 行政书士（当方） |
| 在外公馆之签名证明、各国身分证明 | 由本人于在外公馆、现地当局取得 |
| 向家庭裁判所申述书之制作、提出 | 由本人，或作为裁判所提出书件由司法书士 |

## 向家裁之申述、争执、税务、登记各由谁担当？

继承抛弃、限定承认依作业而担当者有别。向家庭裁判所之申述由继承人本人为之，或将裁判所提出书件之制作委托司法书士。就遗产分割或抛弃之效力有争执时之交涉、调解、代理由律师担当，继承税之评价、申报由税理士担当，不动产之继承登记为司法书士之领域。行政书士（当方）担当继承人之确定、国外书件之搜集、遗产目录之制作。

| 委托对象 | 负责范围 |
| --- | --- |
| 四叶行政书士事务所 | 继承人之确定、户籍、国外书件之搜集、限定承认之遗产目录制作 |
| 本人／司法书士 | 向家庭裁判所申述继承抛弃、限定承认（裁判所提出书件之制作） |
| 律师 | 就遗产分割、抛弃之效力等有争执时之交涉、调解、代理 |
| 税理士 | 继承税之评价、申报 |
| 司法书士 | 继承不动产之名义变更（继承登记） |

四叶行政书士事务所、四叶社会保险劳务士事务所、四叶不动产株式会社各为不同事业体，均作为独立的事业体受任。请与各领域的承办人分别签约，由各受任者直接请款、收款。本事务所不收取介绍费。

## 常见问题

**Q. 住在海外也能抛弃日本的继承吗？**
A. 能。继承抛弃系向管辖被继承人最后住所地之家庭裁判所申述（民法第938条、家事事件手续法第201条第1项），在外继承人得以邮寄申述书及附件提出。一经抛弃，视为自始未为继承人，继承权移转予次顺位继承人（民法第939条）。

**Q. 熟虑期间的3个月从何时起算？**
A. 自「知悉自己已有继承开始之时」起3个月（民法第915条第1项）。非死亡日，而系知悉自己已成为继承人之时为起算点。住在海外而讣闻迟到者，或因先顺位抛弃而成为继承人之次顺位者，自知悉该事实之时起算。得于期间内向家庭裁判所声请伸长（同项但书）。

**Q. 所需之台湾户籍、中国公证书由谁搜集？**
A. 继承人确定所需户籍之搜集、台湾户籍、中国公证书等国外书件之搜集，以及限定承认提出之遗产目录制作，可由行政书士（当方）担当。在外公馆之签名证明、各国身分证明由继承人本人于在外公馆、现地当局取得。何种文件被要求依裁判所、个案而异，本文未查证，请向管辖之家庭裁判所确认。

**Q. 若继承人全部在海外，可以限定承认吗？**
A. 限定承认须由全体继承人共同申述（民法第923条），于熟虑期间内向家庭裁判所提出遗产目录（民法第924条）。纵全员在外，备齐国外书件与签名证明，以邮寄共同申述亦属可能。全员之步调一致与3个月期限之管理为关键，宜及早确定继承人，必要时考虑伸长期间。
