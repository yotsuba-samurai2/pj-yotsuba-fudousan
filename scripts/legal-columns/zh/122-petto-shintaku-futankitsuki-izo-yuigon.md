**结论（先讲要点）：**宠物（犬、猫等）在日本法律上被视为“物”、无权利能力，故不能将财产留给宠物本身，也不能让宠物成为遗赠的受遗人或信托的受益人。为被留下的宠物托付照顾，主要有两种方式。其一为负担付遗赠：将财产遗赠给照顾宠物的人，并将饲养课为其负担（民法第1002条）。义务未被履行时，继承人得为催告，若仍未履行，得向家庭裁判所请求撤销遗嘱（民法第1027条）。其二为宠物信托：将财产托付受托人，为受领照顾费用的受益人（照顾者等）管理与给付（信托法第2条、第3条）。无受益人指定的信托（目的信托），仅得以契约或遗嘱设定，存续期间不得逾20年（信托法第258条、第259条）。本文为一般性信息，不就个别遗嘱或契约是否有效作最终判断。四叶集团的行政书士，以独立的事业体承办负担付遗赠的遗嘱与信托契约的文案拟订支援。遗嘱、信托契约的公正证书化属公证人，遗留分侵害或受遗人、继承人间的纠纷属律师，将不动产纳入信托时及死亡后名义变更的登记属司法书士，继承税、受赠益的课税属税理士，继承不动产的出售、活用属不同事业体的不动产业者（本公司）领域，各自分别签约。本所不向任何专业人士收取介绍费。

## 不能把财产直接留给宠物吗？有哪些机制可托付照顾？

在日本法律上，宠物被视为“物”、无权利能力。因此，不能将金钱直接留给宠物，也不能让宠物成为遗嘱中受领财产的受遗人，或信托中受领利益的受益人。能为被留下的宠物做的，是将财产交给“照顾它的人”，同时将饲养的义务或目的与之结合的设计。

| 机制 | 财产交给谁 | 根据 |
| --- | --- | --- |
| 负担付遗赠 | 遗赠给照顾的人（受遗人），以饲养为负担 | 民法第1002条 |
| 宠物信托 | 托付受托人，为受益人（照顾者等）给付 | 信托法第2条、第3条 |
| 目的信托（无受益人指定） | 托付受托人，为饲养之目的而管理 | 信托法第258条（存续期间20年、第259条） |

遗嘱自遗嘱人死亡之时起生效（民法第985条）。亦即遗嘱的安排在身故后方才运作，故对于住院、入住机构等生前的局面，须与其他机制组合以为准备。托付生前事务的选项，与单身者的[死后事务委任契约的基本](https://luck428.com/legal/column/shigojimu-inin-keiyaku-ohitorisama)及任意后见一并考量，较易整理。遗嘱、契约的文案拟订支援，亦见于本所的[继承、遗嘱介绍](https://luck428.com/legal/services/inheritance)。

## 负担付遗赠与“宠物信托”有何不同？

两者将“受到照顾”与财产结合这一点相同，但金钱被管理的方式，以及使约定被遵守的机制不同。

| 观点 | 负担付遗赠 | 宠物信托 |
| --- | --- | --- |
| 机制 | 将财产遗赠给受遗人，以饲养为负担 | 将财产托付受托人，给付饲养费 |
| 财产管理 | 受遗人作为自己的财产管理 | 作为信托财产由受托人分别管理 |
| 开始时期 | 遗嘱人死亡后（遗嘱） | 契约则自生前起，遗嘱则死亡后 |
| 使之遵守的手段 | 未履行时向家裁请求撤销遗嘱（民法第1027条） | 以信托之约定、信托监督人、受益人代理人等监督 |
| 根据 | 民法第1002条 | 信托法第2条、第3条 |

受负担付遗赠之人，仅于不超过遗赠目的价额之限度内负饲养义务（民法第1002条第1项）。受遗人抛弃遗赠时，应受负担利益之人得自为受遗人（同条第2项）。信托则将财产切分为信托财产交由受托人管理，具有饲养费较不致被卷入受托人个人债务或继承的优点。以家人为受托人的设计全貌，亦请见[家族信托的行政书士角色与组成](https://luck428.com/legal/column/kazoku-shintaku-gyosei-yakuwari-kumisei)。

## 要如何书写，才能使照顾者（受遗人、受托人）遵守饲养？

要点在于具体书明“由谁、照顾哪只宠物、如何照顾”，并将未被遵守时的手当也一并订明。负担付遗赠中，将饲养的内容明记为负担，并设想未履行时的对应。

| 应书写之事项 | 具体例 |
| --- | --- |
| 对象宠物 | 特定个体（名字、种类、特征、登记号码等） |
| 饲养的内容 | 居住环境、就诊、疫苗、食饵、送终的方针 |
| 受遗人、受托人 | 承接之人，及不承接时的次顺位 |
| 监督的机制 | 指定遗嘱执行人、信托监督人、受益人代理人 |
| 不履行时 | 负担付遗赠为履行的催告与撤销遗嘱之请求（民法第1027条） |

负担付遗赠的受遗人未尽饲养义务时，继承人得定相当期间催告履行，届期仍未履行者，得向家庭裁判所请求撤销该负担付遗赠所涉之遗嘱（民法第1027条）。信托中，为使受益人年迈、不在时监督仍能运作，实务上会设置信托监督人或受益人代理人。此等文案拟订由行政书士支援，惟个别有效性的最终判断由资格者进行。进行方式请见[受任流程](https://luck428.com/legal/nagare)。

## 饲养费多少、如何交付较实际，余下的财产如何处理？

饲养费以宠物的平均余命、医疗费、照顾的对价估算而定。交付方式上，负担付遗赠可一次遗赠，信托则可设计为于必要时分次给付。

| 项目 | 考量方式 |
| --- | --- |
| 金额之估算 | 平均余命×年间食饵、医疗、照顾费用，再加预备 |
| 交付（遗赠） | 一次遗赠给受遗人，以饲养为负担 |
| 交付（信托） | 受托人管理，于必要时期作为饲养费给付 |
| 余剩之处理 | 预先订明宠物死亡后残余财产的归属 |
| 对价 | 亦可就照顾的劳费另订谢礼 |

为因应宠物身故后信托财产或遗赠财产尚有余剩，须预先订明残余的归属（其他人或团体等）。使用目的信托（无受益人指定的信托）时，须留意存续期间不得逾20年的限制（信托法第259条）。金额与交付方式亦影响继承人的遗留分与课税，故须与税理士、律师分担角色而检讨。本所费用的概估另定于[报酬额表](https://luck428.com/legal/ryokin)。

## 作成公正证书的意义，以及遗嘱执行人、信托监督人的角色为何？

将遗嘱或信托契约作成公正证书，较不致因方式瑕疵而无效，原本由公证役场保管，遗失、篡改之虞甚小。将负担付遗赠作成公正证书遗嘱，则死亡后家庭裁判所的检认亦不要。公正证书遗嘱的作成方式与公证人手续费，整理于[公正证书遗嘱的作成方式、证人、手续费](https://luck428.com/legal/column/kosei-shosho-yuigon-koshonin-shonin-hiyo)。

| 角色 | 内容 |
| --- | --- |
| 公证人 | 遗嘱、信托契约的公正证书化（作成、原本保管） |
| 遗嘱执行人 | 实现遗嘱内容（向受遗人交付、看顾饲养等） |
| 信托监督人 | 为受益人监督受托人（信托法） |
| 受益人代理人 | 代受益人行使权利（信托法） |

作为见证饲养是否被持续的机制，遗嘱可置遗嘱执行人，信托可置信托监督人或受益人代理人，较为安心。此等指定与文案拟订由行政书士支援，公正证书化由公证人进行。要选信托契约或遗嘱，或两者并用，须与生前的准备（任意后见、死后事务委任）一并设计。

## 遗留分、继承税、登记方面，该向律师、司法书士、税理士委请什么？

为宠物所做的手当，易形成将较多财产交给特定人的设计，故涉及其他继承人的遗留分、课税，若有不动产则涉及登记。相关专业人士以各自独立的事业体分别签约为基本。

| 委托对象 | 主要角色 |
| --- | --- |
| 行政书士（本所） | 负担付遗赠的遗嘱、信托契约的文案拟订支援 |
| 公证人 | 遗嘱、信托契约的公正证书化 |
| 律师 | 遗留分侵害额的请求（民法第1046条）、受遗人、继承人间的纠纷、法律效果的最终判断 |
| 司法书士 | 将不动产纳入信托时的信托登记、死亡后名义变更的登记 |
| 税理士 | 继承税、受赠益课税的试算 |
| 不动产业者（不同事业体的本公司） | 继承不动产的出售、活用咨询 |

财产的交付方式若侵害其他继承人的遗留分，则发生遗留分侵害额相当之金钱支付请求（民法第1046条），此属律师领域。将不动产纳入信托财产时须为信托登记，由司法书士承办。涉及继承不动产出售时，亦可利用不同事业体的不动产业者所设[继承不动产咨询窗口](https://luck428.com/souzoku)。本所与各专业人士以独立的事业体签约，相互不收取介绍费。个别有效性或课税的最终判断，由资格者于面谈后进行。

## 常见问题

**Q. 可以把金钱直接留给宠物吗？**
A. 不可以。宠物在法律上为“物”、无权利能力，故不能将财产留给宠物本身，也不能使其成为遗赠或信托的受益人。被留下宠物的照顾，透过将财产交给照顾者并课以饲养的负担付遗赠（民法第1002条），或将财产托付受托人的宠物信托（信托法第2条、第3条）来托付。

**Q. 负担付遗赠与宠物信托，哪个较安心？**
A. 无法一概而论。负担付遗赠以遗嘱完结、较简便，但金钱作为受遗人的财产管理，使之遵守的手段为履行的催告与撤销遗嘱之请求（民法第1027条）。信托可将财产作为信托财产分别管理、以信托监督人等持续监督，惟组成较费工夫。须依家庭构成与财产而选择。

**Q. 宠物身故后余下的钱会如何？**
A. 须预先订明残余财产的归属。无约定时，依继承或信托清算的规律处理。使用无受益人指定的目的信托时，亦须留意存续期间不得逾20年的限制（信托法第259条）而设计。

**Q. 遗留分与继承税该如何考量？**
A. 将较多财产交给特定人，可能发生其他继承人的遗留分侵害额请求（民法第1046条），此属律师领域。继承税、受赠益的课税属税理士，将不动产纳入信托时的登记属司法书士。行政书士支援文案拟订，与各专业人士以独立的事业体分别签约。
