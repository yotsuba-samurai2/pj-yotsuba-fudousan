**结论（先讲要点）**：要为观光或接送，向不特定对象收取运费并将巴士整车出租载客，须取得道路运送法第4条第1项的一般贷切旅客自动车运送事业许可。这是同法第3条第1号ロ所定「以一个契约将国土交通省令所定乘车定员以上的汽车整车出租以运送旅客」的事业，乘车定员由国土交通省令定为11人以上。仅将自家董监事・员工或自家客人无偿接送时原则上不需许可，但一旦收取运费载客即须许可。许可的核心是「人・物・金・安全」，须备齐运行管理者（同法第23条；由领有运行管理者资格者证者中选任）・整备管理者（道路运送车辆法第50条）・营业所・车库・损害赔偿能力（任意保险）・所需资金，车辆数等具体基准由运输局公示的审查基准定之（基准可能修订，请以申请运输局的最新公示确认）。许可依同法第8条采每5年更新制。四叶行政书士事务所在行政书士法第1条之2・第1条之3的范围内，以另行签约承接许可申请书・事业计划・运行管理者等选任申报的制作与手续。驾驶的拘束时间・休息期间等劳务设计由社会保险劳务士、营业所・车库的物件由不动产、车辆与保险由本人与保险公司负责，均为独立的事业体并分别签约。本文为一般性信息提供，不保证个别许可。本所不收取介绍费。

## 包车巴士事业在什么范围需要许可？与白牌接送有何不同？

需要一般贷切旅客自动车运送事业许可的，依道路运送法第4条第1项，是以一个契约将巴士整车出租、向不特定对象收取运费而运送旅客的情形。对象汽车为同法第3条第1号ロ所称「国土交通省令所定乘车定员以上的汽车」，乘车定员为11人以上。将10人以下的汽车整车出租载客，属一般乘用旅客自动车运送事业（含大型出租车等的「乘用」）的区分，是另一种许可的对象。

| 区分 | 典型例 | 是否需许可 |
| --- | --- | --- |
| 一般贷切旅客自动车运送事业 | 观光・接送中，将乘车定员11人以上的巴士整车出租并收费载客 | 需道路运送法第4条第1项的许可 |
| 自家运送（白牌） | 将自家董监事・员工或自家客人不收费接送 | 不需许可（惟以运送为业并有偿行之，即为许可对象） |
| 自家用汽车的有偿运送 | 以自家用车进行有偿运送 | 原则禁止（同法第78条；例外有限） |

差异的核心在于「是否收取运费的有偿运送」「是否载运不特定对象」。无偿的自家接送不需许可，但一旦收取超过实费的对价、或载运外部客人，即可能构成无许可的有偿运送而生问题。属于何者，依契约与对价的实态判断，故请在接送的设计阶段整理。需要许可之事业的受任流程请见[受任流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)，承办业务请见[承办业务一览](https://luck428.com/legal/services)。

## 许可的人・物・金要件（运行管理者・整备管理者・营业所・车库・资金）要满足什么？

许可要件可分为「人・物・金・安全」。车辆数与金额等具体基准，由申请运输局公示的审查基准定之，且可能修订。代表性项目如下（数值可能因运输局的公示而异，请于申请前以最新公示确认）。

| 区分 | 主要要件 |
| --- | --- |
| 车辆数 | 每一营业区域原则3辆以上。使用大型车时，多数公示要求5辆以上（3辆以上未满5辆，一般会附限定中型・小型车的条件） |
| 运行管理者 | 每一营业所，由领有运行管理者资格者证者中选任（道路运送法第23条）。所需人数随车辆数增加 |
| 整备管理者 | 每一营业所选任（道路运送车辆法第50条）。以整备士资格，或一定实务经验＋选任前研修满足要件 |
| 营业所・车库 | 车库原则附设于营业所。无法附设时，距营业所直线约2公里以内。营业所・车库・休息仮眠设施，多数公示要求3年以上的使用权原 |
| 损害赔偿能力 | 全部车辆加入对人赔偿每一被害人无限、对物赔偿每一事故200万日元以上之任意保险（共济）的计划 |
| 所需资金 | 估算开业所需资金并能以自有资金确保；以存款余额疏明 |

运行管理者依道路运送法第23条之2，由通过运行管理者考试者等领取资格者证。这些是取得许可后仍须维持的基准，车辆数・保险・管理者的选任，于运输开始后亦须持续满足。是否符合要件的最终审查・判断，由运输局（地方运输局・运输支局）为之。驾驶的拘束时间・休息期间等劳务设计，梳理于社会保险劳务士的[包车巴士驾驶的改善基准告示（2024年拘束・休息）与劳务](https://luck428.com/labor/column/bus-untensha-kaizen-kijun-2024-kousoku-kyusoku-roumu)（社会保险劳务士为另一事业体）。

## 从申请到许可、运输开始、监查的流程如何进行？

手续依「确定事业计划并申请→经法令考试・审查→取得许可→运输开始」的顺序进行。取得许可后，亦有每5年的更新（道路运送法第8条）。大致流程如下。标准处理期间与运用因运输局而异，请以申请运输局的指引确认。

| 阶段 | 内容 |
| --- | --- |
| 制作事业计划 | 决定营业区域・营业所・车库・车辆・运行管理者等，并拟定所需资金与任意保险的计划 |
| 申请 | 向管辖营业所的运输支局提出许可申请书与事业计划等（道路运送法第5条） |
| 法令考试 | 申请人（法人为常勤董监事）应试道路运送法等法令考试 |
| 审查・补正 | 审查是否符合要件；确认并补正设施・人员・资金 |
| 许可 | 许可下达后缴纳登录免许税 |
| 许可后手续 | 运费・料金的设定（申报）、运行管理者・整备管理者的选任申报、安全管理相关申报、车辆登录（绿牌）等 |
| 运输开始 | 开始运输并提出运输开始申报（申报期限请以运输局指引确认） |
| 更新・监查 | 许可每5年更新（道路运送法第8条）。为运输局・适正化机关之监查・巡回指导的对象 |

许可并非取得即了结，每5年的更新与运行管理・整备・劳务的持续遵守为前提。具体样式・份数・标准处理期间，请以申请运输支局的最新指引确认。本所所做的是制作申请文件・办理手续，并整理交付各专家的资料，不对审查结论或法律见通作断定。

包车巴士的开业，在许可・劳务・物件・车辆上，负责的专家各不相同。四叶集团中，行政书士・社会保险劳务士・不动产各为独立的事业体，以分别签约为前提。负责如下。

- 许可申请书・事业计划・运行管理者等选任申报的制作与手续 → 行政书士（行政书士法第1条之2・第1条之3；本所）
- 拘束时间・休息期间・工资・社会保险・就业规则等驾驶劳务设计 → 社会保险劳务士（另一事业体）

## 常见问题

**Q. 仅以巴士接送自家员工或住宿客，也需要许可吗？**
A. 仅将自家董监事・员工或自家客人不收费接送，原则上不需一般贷切旅客自动车运送事业许可。另一方面，若收取运费（超过实费的对价）载客，或载运外部不特定对象，即可能成为道路运送法第4条第1项许可的对象。无许可而以自家用汽车进行有偿运送原则禁止（同法第78条）。接送是否仍属无偿的自家运送，依契约与对价的实态判断，请于设计阶段整理。

**Q. 包车巴士许可需要几辆车？**
A. 车辆数由申请运输局公示的审查基准定之，多数公示为每一营业区域原则3辆以上，使用大型车时5辆以上（3辆以上未满5辆一般会附限定中型・小型车的条件）。此数值因运输局而异且可能修订，请于申请前以申请运输支局的最新公示确认。除车辆外，亦须一并满足运行管理者・整备管理者・营业所・车库・任意保险・所需资金的要件。

**Q. 取得许可后，是否不必更新即可持续经营？**
A. 一般贷切旅客自动车运送事业许可，依道路运送法第8条，未每5年更新即因期间经过而失效。除更新外，运行管理者・整备管理者的选任、任意保险的加入、驾驶劳动时间的管理等，于运输开始后亦须持续满足，并为运输局・适正化机关之监查・巡回指导的对象。更新时期与应维持的基准，请以申请运输局的指引确认。

**Q. 从许可申请到驾驶劳务、车库物件，能否委托同一事务所一并处理？**
A. 许可申请书・事业计划・选任申报的制作由行政书士、拘束时间・休息期间・工资・社会保险由社会保险劳务士、营业所・车库物件由另一事业体的四叶不动产株式会社、车辆与保险由本人与保险公司、许可的最终判断由运输局、处分的争讼由律师负责，均为独立的事业体并分别签约。虽可于一个窗口受理咨询并整理交付各专家，但受任系分开。本所不收取介绍费。
