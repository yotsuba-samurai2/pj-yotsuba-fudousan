**结论（先讲要点）**：经营业务用冷冻・空调设备的事业，会按"做什么"而叠加各自不同的许可。若销售冷媒等高压气体，须依高压气体保安法第20条之4办理销售事业申报（每个销售所于事业开始日的20日前向都道府县知事提出）；若对业务用空调或业务用冷冻冷藏机器充填、回收冷媒氟利昂，则须依"氟利昂类之使用合理化及管理适正化相关法律"（氟利昂排放抑制法）第27条第1项取得第一种氟利昂充填回收业者登录（由管辖业务区域的都道府县知事办理，有效期间5年＝第30条）。冷冻设备本身的设置（高压气体的"制造"）则按冷冻能力分为高压气体保安法第5条的许可或申报，并适用冷冻保安规则。四叶行政书士事务所在行政书士法第1条之2的范围内，以另行签约承接向官署提出之文件的制作与提出，仅提供资料与信息。设备施工与保安由有资格的工程业者与保安责任者、物件由另一事业体的不动产、登记由司法书士、税务由税理士负责，均为独立的事业体并分别签约。本文为一般性信息提供，不就个别登录・申报的可否作出具体法律判断。本所不收取介绍费。

## 经营业务用冷冻・空调设备，首先需要哪些许可？

冷冻・空调设备事业会因"做什么"而改变所需手续。一项事业常叠加多项手续，因此先按行为类别区分。

| 所为行为 | 主要依据 | 手续性质 |
| --- | --- | --- |
| 销售冷媒等高压气体 | 高压气体保安法第20条之4 | 销售事业申报（都道府县知事） |
| 对业务用空调・业务用冷冻冷藏机器充填・回收冷媒氟利昂 | 氟利昂排放抑制法第27条第1项 | 第一种氟利昂充填回收业者登录（都道府县知事） |
| 以冷冻设备"制造"高压气体（冷冻能力在一定以上） | 高压气体保安法第5条 | 按冷冻能力分为许可（第一种制造者）或申报（第二种制造者） |

"销售""充填・回收""制造（冷冻）"是不同制度，符合哪一项就各自需要手续。例如自行开设冷冻仓库并做到补充冷媒与更新机器，销售、充填回收、冷冻设备设置就可能各自分别被要求。符合哪个行为会随事业形态而变，因此在设备与交易内容确定后，一边向主管都道府县（高压气体・氟利昂业务课）咨询一边梳理。相关登录制度中，汽车（车用空调＝第二种特定产品）侧的氟利昂回收，另在[收取业・氟利昂回收业登录](https://luck428.com/legal/column/jidosha-recycle-hikitori-furon-kaishu-gyo-touroku)处理。

## 高压气体保安法的销售事业申报，向何处・何时提出？

欲经营销售高压气体事业者，须就每个销售所，于事业开始日的20日前，附上记载所销售高压气体种类等的书面，向都道府县知事申报（高压气体保安法第20条之4）。提出者称为"销售业者"。

| 项目 | 条文梳理 |
| --- | --- |
| 提出对象 | 都道府县知事（每个销售所） |
| 时期 | 事业开始日的20日前（第20条之4） |
| 承继 | 事业全部转让・继承・合并・分割时，应遲滞地申报（第20条之4之2） |
| 废止 | 废止事业时，应遲滞地申报（第21条） |

但有例外。第一种制造者于其事业所销售自行制造之高压气体等政令所定情形，无须申报。又，向一般消费者等销售液化石油气（LP气）时，属液石法的销售事业登录对象，而非高压气体保安法，制度分歧。在市的区域，市长或消防长可能为受理窗口，提出处・样式・附件依市町村而异，故在销售所所在地确定后，向主管都道府县（或市的消防保安业务课）确认（经济产业省及各都道府县之说明・参照日 2026-11-03）。

## 第一种氟利昂充填回收业者登录的要件与有效期间为何？

欲以营业方式对业务用空调或业务用冷冻冷藏机器（含具冷冻冷藏功能之自动贩卖机。此等称第一种特定产品＝氟利昂排放抑制法第2条第3项）中作为冷媒充填之氟利昂进行充填・回收者，须取得管辖欲经营业务区域之都道府县知事的登录（第27条第1项）。家用空调不属第一种特定产品，车用空调（第二种特定产品＝第2条第4项）的氟利昂回收，则属汽车回收法框架的另一制度。

| 项目 | 条文梳理 |
| --- | --- |
| 登录对象 | 管辖业务区域的都道府县知事（第27条第1项） |
| 申请书记载 | 姓名・住所、供业务使用之设备等（第27条第2项） |
| 登录之拒绝 | 欠格事由，或回收设备不符基准等（第29条） |
| 有效期间 | 5年；未更新即失效（第30条第1项・第2项） |
| 变更申报 | 登录事项变更时，30日内申报（第31条） |

登录簿供一般阅览（第32条）。回收设备的技术基准、欠格事由的具体内容、更新受理时期（依市町村有自有效期限前2〜3个月起等）与手续费，依都道府县运用不同且会修正，故于申请前以主管都道府县的最新说明确认。若在多个都道府县经营业务，须向窗口确认是否各区域皆需登录。符合哪个要件的最终适用，由办理登录的都道府县审查后判断。

## 开设冷冻仓库时，许可会以什么顺序排列？

设置冷冻仓库并经营低温物流时，设备・保安・登录・劳务・物件会并行推进。大致顺序如下，责任按领域分工。

- 物件选定与适合确认（用途地域・楼板荷重・电力容量等） → 另一事业体的四叶不动产股份有限公司（宅地建物交易业者），以独立的事业体另行签约对应
- 冷冻设备的设计・施工，及按冷冻能力办理高压气体保安法第5条的许可（第一种制造者）或申报（第二种制造者） → 有资格的设备・电气工程业者与高压气体制造保安责任者。文件制作由行政书士协助
- 若处理冷媒氟利昂，须办理第一种氟利昂充填回收业者登录（第27条第1项）
- 若销售冷媒等高压气体，须办理销售事业申报（第20条之4）
- 若以仓库业经营，须办理仓库业法的登录（符合设施设备基准；物件要件于不动产侧确认）
- 员工的工作规则・低温作业安全卫生・轮班 → 社会保险劳务士（另一事业体）

仓库业法的登录与所保管食品・药品的营业许可主管各异，均为独立的事业体并分别签约・办理。低温物流设施的物件适合梳理于[冷藏・冷冻仓库的物件要件](https://luck428.com/column/reizo-reito-souko-butsuryu-bukken-youken)（不动产侧专栏，为另一事业体），低温作业的劳务则于社会保险劳务士侧梳理。因前后顺序会随设备规模与事业形态而变，宜先描绘全貌再决定着手顺序。

## 行政书士能制作的文件，与施工・保安须委由有资格者的部分，如何区分？

行政书士以制作向官署提出之文件及代理提出手续为独占业务（行政书士法第1条之2）。设备施工与保安监督则属其他资格者的领域。责任如下分工，均为独立的事业体并分别签约・办理。

- 销售事业申报、第一种氟利昂充填回收业者登录申请、冷冻设备相关许可・申报之文件制作与提出代理 → 四叶行政书士事务所（行政书士）。仅提供资料与信息，不作具体法律判断
- 冷冻设备・配管・电气设备的施工 → 高压气体制造保安责任者、电气工程士，视规模由取得建筑业许可之施工业者
- 高压气体之制造・保安监督 → 高压气体制造保安责任者等有资格者
- 开业物件・仓库用地的选定・租赁媒介 → 另一事业体的四叶不动产股份有限公司（宅地建物交易业者）
- 设立法人经营时的设立登记 → 司法书士
- 开业后的记账・税务申报 → 税理士
- 工作规则・安全卫生・轮班等劳务 → 社会保险劳务士
- 交易・契约纠纷的代理・法律判断 → 律师

各领域以与各窗口・资格者分别签约为前提，本所不收取介绍费。即使在不确定是否需要登录或申报、窗口在哪的阶段，也请在决定设备与交易内容前先咨询。受任流程请见[受任流程](https://luck428.com/legal/nagare)、费用请见[报酬额表](https://luck428.com/legal/ryokin)、承办业务请见[承办业务一览](https://luck428.com/legal/services)。相关许可另请参阅[毒物剧物销售业登录](https://luck428.com/legal/column/dokugekibutsu-hanbaigyo-touroku-kozo-setsubi-kijun)与[电气工程业登录](https://luck428.com/legal/column/denki-koji-gyo-touroku-eigyosho-shunin)。

## 常见问题

**Q. 只是销售冷媒，也需要高压气体的手续吗？**
A. 若以营业方式销售冷媒等高压气体，须就每个销售所于事业开始日的20日前向都道府县知事办理销售事业申报（高压气体保安法第20条之4）。但第一种制造者于其事业所销售自行制造之气体等政令所定情形，无须申报。向一般消费者等销售LP气时，另须依液石法登录，制度分歧，故请就所处理的气体与销售形态向主管都道府县确认。

**Q. 第一种氟利昂充填回收业者登录向何处提出，有效几年？**
A. 向管辖欲经营业务区域之都道府县知事取得登录（氟利昂排放抑制法第27条第1项）。有效期间5年，未更新即失效（第30条）。登录事项变更时须30日内申报（第31条）。回收设备基准、更新受理时期与手续费依都道府县运用不同，故请于申请前以主管都道府县的最新说明确认。

**Q. 业务用空调、家用空调、车用空调的处理不同吗？**
A. 不同。业务用空调与业务用冷冻冷藏机器为第一种特定产品（氟利昂排放抑制法第2条第3项），其充填・回收属第一种氟利昂充填回收业者登录对象。家用空调不属第一种特定产品。车用空调为第二种特定产品（第2条第4项），其氟利昂回收属汽车回收法框架的另一制度。

**Q. 从设备施工到文件制作，能委由一家事务所全部处理吗？**
A. 文件制作・提出代理由行政书士、冷冻设备・电气设备施工由有资格工程业者、高压气体保安监督由高压气体制造保安责任者、物件由另一事业体的四叶不动产股份有限公司、登记由司法书士、税务由税理士、劳务由社会保险劳务士负责，均为独立的事业体并分别签约。可于同一窗口受理咨询并整理交付各负责者，但受任分开。本所不收取介绍费。
