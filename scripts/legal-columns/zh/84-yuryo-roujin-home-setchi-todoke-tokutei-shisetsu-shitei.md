**结论（先讲重点）**：开办附照护之收费型高龄者住宅，须叠合两项手续。其一为老人福祉法（昭和38年法律第133号）第29条第1项之收费型高龄者住宅设置届，向拟设置设施所在地之都道府县知事（指定都市・中核市为市长）事前届出。其二为介护保险法（平成9年法律第123号）第8条第11项所定之特定设施入居者生活介护指定，依同法第70条第1项，由都道府县知事（指定都市・中核市为市长）就各事业所指定。人员・设备・运营基准定于指定居宅服务等之事业人员、设备及运营相关基准（平成11年厚生省令第37号）第174条以下，核心为护理・照护职员须达要照护利用者每3人1人以上（常勤换算＝所谓3对1）。本文整理设置届与指定之流程、要件、时程，以及各部分应委托何人。是否符合基准与指定可否由指定权者审查决定，本事务所不保证指定。物件・建筑・消防・劳务・税务均以独立的事业体各自个别签约。

## 收费型高龄者住宅之设置届何时向谁提出？

收费型高龄者住宅，指使高龄者入居，并提供入浴・排泄・饮食之照护、饮食供应、洗衣扫除等家事、健康管理之任一服务之设施（老人福祉法第29条第1项）。拟设置者须事前向拟设置设施所在地之都道府县知事（指定都市・中核市为市长，以下同）届出。重点在于此为事前届出，而非开设后之事后届出。

收费型高龄者住宅依所提供之服务，运用上分为下列类型（厚生劳动省「收费型高龄者住宅设置运营标准指导指针」之区分）。「附照护」指已取得介护保险特定设施入居者生活介护指定者。

| 类型 | 概要 | 照护之定位 |
| --- | --- | --- |
| 附照护收费型高龄者住宅 | 已取得特定设施入居者生活介护指定 | 由设施职员以介护保险服务提供 |
| 住宅型收费型高龄者住宅 | 未取得特定设施指定 | 由入居者个别签约外部居宅服务 |
| 健康型收费型高龄者住宅 | 需照护时以退居为前提 | 不提供照护 |

设置届应于事业开始前预留余裕提出。须于事业开始预定日之几个月前届出，因自治体运用而异，部分都道府县要求事前相谈・协议。届出时期・样式・附件请于该自治体公式页面确认。未届出而运营，可能成为老人福祉法上指导・改善命令等对象。

## 取得特定设施入居者生活介护指定之要件为何？

欲名为「附照护」，须就各事业所取得介护保险法第8条第11项所定之特定设施入居者生活介护指定。指定依同法第70条第1项由都道府县知事为之，申请者原则须为法人。人员・设备・运营基准定于指定居宅服务等之事业人员、设备及运营相关基准（平成11年厚生省令第37号）第174条以下（人员为第175条），并由各自治体条例具体化。人员配置之基本如下。

| 职种 | 配置思考（常勤换算） |
| --- | --- |
| 护理・照护职员 | 要照护利用者数除以3以上（3对1）。护理职员：利用者30人以下1人以上，31人以上每50人1人以上 |
| 生活相谈员 | 利用者每100人1人以上。其中1人以上为常勤 |
| 机能训练指导员 | 1人以上（部分情形可兼务） |
| 计画作成担当者（介护支援专门员） | 以利用者每100人1人为标准，配置1人以上。部分情形可兼务 |
| 管理者 | 专职常勤1人（无妨碍时部分情形可兼务） |

护理・照护职员之「3对1」以常勤换算方法计算。夜勤・宿直如何编排、常勤换算如何落实于排班、工作规则与时间外・休日劳动协定如何整备，属劳务设计问题，为社会保险劳务士领域。与本公司・本事务所为独立的事业体，各自个别签约（设施劳务之详细亦见姊妹网站社会保险劳务士之专栏）。介护报酬之计算・请求由事业者或请求代行担当，会计・税务属税理士领域。

## 居室面积・共用部・无障碍等建筑侧基准看何处？

设备基准定于平成11年厚生省令第37号（第176条等），并由标准指导指针具体化。介护居室原则为个室，每入居者床面积原则13平方米以上（不含走廊・共用部之专用部分面积）。共用部依所提供服务，设置食堂、机能训练室、浴室、便所、医务室或健康管理室、护理・照护职员室、谈话室等。并要求走廊宽度・消除高低差・扶手等无障碍，及确保避难路线。

| 确认处 | 主要要求 |
| --- | --- |
| 介护居室 | 原则个室，每人床面积原则13平方米以上 |
| 共用设备 | 食堂・机能训练室・浴室・便所・医务室或健康管理室等 |
| 无障碍 | 走廊宽度・消除高低差・扶手・轮椅可用之便所浴室 |
| 用途・防火 | 是否符合建筑基准法上用途（老人住宅）、用途变更确认申请之要否 |
| 消防用设备 | 属消防法施行令别表第一(6)项ロ，自动火灾报知设备・洒水设备等 |

转用既有建物时，可能须建筑基准法上用途变更确认申请，其要否・设计由建筑士（设计者）判断。消防用设备（自动火灾报知设备・洒水设备・向消防机关通报之火灾报知设备等）之要否与消防同意由消防署判断。物件之用途地域・面积一次确认由不动产公司担当，本公司仅提供物件资讯，不判断建筑确认或消防可否。

## 自设置届至指定・开设之时程如何编排？

设置届（老人福祉法）与特定设施指定（介护保险法）为不同手续，惟实务上并行准备。因顺序前后易遭退件，宜及早开始事前协议。一般流程如下。

1. 确定事业计画・资金计画，设立法人（于章程事业目的加入收费型高龄者住宅之设置运营・特定设施入居者生活介护）
2. 选定物件，确认居室面积・共用部・建筑基准法・消防法之符合
3. 与都道府县（指定权者）进行事前协议（设置届・指定两者）
4. 确保护理・照护职员、生活相谈员、机能训练指导员、计画作成担当者、管理者
5. 提出收费型高龄者住宅设置届
6. 提出特定设施入居者生活介护指定申请书与附件
7. 经书面审查・现地确认，取得指定（多数自治体为每月1日付）并开设

多数自治体以每月1日付指定，指定申请之提出期限一般设于指定希望日之前月或前前月。因截止日・样式・必要文件依指定权者而异，请务必于该自治体公式页面确认。代表性必要文件为设置届样式全套、指定申请书与附表、法人登记事项证明书・章程、事业所平面图・照片・租赁契约书等、运营规程、从业者勤务形态一览表与资格证、管理者・计画作成担当者之经历、收支预算书、各种誓约书等。四叶行政书士事务所于行政书士业务范围内，支援设置届・指定申请书・附表・附件之作成、事前协议资料整理、运营规程等文案。是否符合基准之最终判断与指定可否由指定权者审查。

## 设置届・指定・建筑・消防・劳务・税务应各委托何人？

附照护收费型高龄者住宅之开设，涉及多个专业领域。分担如下。

- 设置届・指定申请书・附表・附件之作成、事前协议之支援 → 四叶行政书士事务所（行政书士）
- 事业用物件之选定・租赁・重要事项说明、用途地域・面积之一次确认 → 四叶不动产株式会社
- 用途变更确认申请・设计、居室面积・无障碍之符合、检查済证之确认 → 建筑士（设计者）
- 自动火灾报知设备・洒水设备等之要否判定・消防同意 → 消防署・消防设备士

## 常见问题

**Q. 设置届与特定设施指定，只做其一即可吗？**
A. 欲名为「附照护」，由设施职员以介护保险服务提供照护，须同时具备老人福祉法第29条第1项之设置届与介护保险法之特定设施入居者生活介护指定。未取得指定则为住宅型，由入居者个别签约外部居宅服务。因类型不同而人员・设备・手续有异，请于事前协议确认。

**Q. 服务型高龄者住宅（サ高住）也能取得特定设施指定吗？**
A. 符合一定要件之服务型高龄者住宅可能被纳入特定设施，惟登录处・所管与届出可能与收费型高龄者住宅不同。以何种架构进行，因事业计画与物件而异，请以该自治体手引与事前协议确认。制度架构之整理于行政书士业务范围内支援，惟指定可否由指定权者审查。

**Q. 夜勤体制与职员工时可向行政书士咨询吗？**
A. 符合人员基准，与该职员之雇用契约・工作规则・含夜勤宿直之工时管理・社会保险适用，为不同问题。后者属社会保险劳务士领域，与本公司为独立的事业体，各自个别签约。本事务所支援指定申请之书面面。

**Q. 可使用既有建物吗？**
A. 除居室面积・共用部・无障碍外，可能须建筑基准法上用途变更确认申请，或追加消防用设备。用途变更判断向建筑士（设计者）、消防用设备要否向消防署确认。物件属不动产公司、建筑确认属建筑士，各为别事业体，各自个别签约。
