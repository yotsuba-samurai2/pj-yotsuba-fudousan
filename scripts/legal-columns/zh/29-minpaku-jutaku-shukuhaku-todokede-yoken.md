**结论（先说要点）**：以自宅或所有之住宅经营民泊（住宅宿泊事业），须依住宅宿泊事业法（平成29年法律第65号）第3条第1项，向都道府县知事等（于设有保健所之市为市长、特别区为区长）提出申报。此与旅馆业法之营业许可，根据法律与窗口均不同；住宅宿泊事业以「使人住宿之日数1年不逾180日」为定义上前提（同法第2条第3项）。申报须附消防法令适合通知书等，于家主不在型并须委托住宅宿泊管理业者（同法第11条）。分让公寓须确认管理规约，租赁物件须确认租赁契约之许诺。本文为一般资讯提供，整理申报与旅馆业许可之别、180日规制、添付书类、管理规约之确认点与角色分工，不判断个别申报之可否或物件能否用于民泊。

## 住宅宿泊事业之申报与旅馆业许可，于何处分界？

以收取住宿费使人住宿之事业，大致分为「旅馆业法之许可」与「住宅宿泊事业法之申报」。旅馆业法（昭和23年法律第138号）为许可制，于柜台设备、客室基准等设施面之要件较重。住宅宿泊事业法则为申报制，对象为活用住宅使人住宿之事业。

分界在于「营业日数」与「设施是否为住宅」。住宅宿泊事业，定义为旅馆业者以外之人收取住宿费使人于住宅住宿之事业，且使人住宿之日数1年不逾180日（住宅宿泊事业法第2条第3项）。若欲逾180日营业，即不在住宅宿泊事业范围内，须考量旅馆业法之许可（如简易住所营业）。

| | 旅馆业法之许可 | 住宅宿泊事业法之申报 |
| --- | --- | --- |
| 手续 | 许可制 | 申报制 |
| 窗口 | 都道府县知事等（保健所） | 都道府县知事等（设保健所之市、特别区为市长・区长） |
| 年营业日数 | 无上限 | 180日以下（第2条第3项定义） |
| 对象设施 | 旅馆・饭店・简易住所等 | 住宅 |

何种架构适合，因欲营业之日数、设施性质与立地而异。四叶行政书士事务所于行政书士业务范围内，支援住宅宿泊事业申报书与添付书类之制作及申报之代理。须旅馆业许可时之建筑确认，属建筑士领域。个别可否由所辖审查。

## 申报所需书类与消防法令适合通知书如何备齐？

住宅宿泊事业之申报，依住宅宿泊事业法第3条第1项，以电子系统（民泊制度运营系统）或书面为之。除申报书外，须附住宅之图面、登记事项证明书、消防法令适合通知书等。书类种类因自治体手引而异，宜于申报前确认所在地窗口之案内。

消防法令适合通知书，为消防署（消防长・消防署长）确认住宅符合消防法令后所交付之书面。于住宅宿泊事业，依住宅规模与家主居住形态，可能须设置自动火灾报知设备・诱导灯・灭火器等。设备要否与设计属消防署・消防设备士领域，作为申报前提宜及早咨询为妥。

| 主要添付・确认事项 | 担当・窗口 |
| --- | --- |
| 申报书・住宅图面・登记事项证明书之整理与提出代理 | 四叶行政书士事务所（行政书士） |
| 消防法令适合通知书之取得・消防用设备之设计 | 消防署（消防长・消防署长）・消防设备士 |
| 宿泊者名簿之备付（第8条）、标识之揭示（第13条） | 住宅宿泊事业者（申报者） |
| 家主不在型之住宅宿泊管理业务委托（第11条） | 住宅宿泊管理业者 |

住宅宿泊事业者须备付宿泊者名簿（第8条），并就各申报住宅揭示标识（第13条）。书类之制作・提出由行政书士，消防设备由消防署・消防设备士，担当分工。

## 年180日之上限与自治体之上乗せ条例如何生效？

住宅宿泊事业使人住宿之日数，1年上限为180日。此「1年」依国之运用，以每年4月1日正午至翌年4月1日正午之期间计算（民泊制度门户网站・参照日2026年8月27日）。使人住宿之日数以定期报告向自治体报告。

再者，都道府县（含设保健所之市・特别区）为防止生活环境恶化而有必要时，得以条例定区域，限制住宅宿泊事业之营业期间（住宅宿泊事业法第18条）。经此「上乗せ条例」，可能施以较180日更狭之限制，如于住居专用地域不许平日营业、于学校周边限制期间等。

| 限制种类 | 依据 |
| --- | --- |
| 全国一律之营业日数上限 | 住宅宿泊事业法第2条第3项（180日以下） |
| 定区域之期间限制（上乗せ条例） | 住宅宿泊事业法第18条 |
| 集合住宅之可否 | 管理规约・租赁契约 |

即使物件良好，于上乗せ条例对象区域，亦可能无法营业所设想之日数。决定物件前宜确认用途地域与条例区域；立地之可否与上乗せ条例之该当，为选物件之重要确认事项。物件能否用于民泊之见立，由与四叶行政书士事务所别事业体之四叶不动产株式会社（宅地建物交易业者），于宅建业务范围内担当。

## 于分让公寓经营民泊时，须确认管理规约与租赁之何处？

于分让公寓（区分所有建物）经营民泊，除法令之申报外，管理规约之确认不可或缺。公寓标准管理规约示有明记住宅宿泊事业「得为／不得为」之规定例；若规约禁止民泊，纵能申报亦不得实施。

于租赁物件经营民泊，须确认租赁契约是否许诺转租或民泊利用。未经所有人・出租人承诺即经营民泊，恐构成违约。此等符合判断（用途地域・管理规约・租赁之许诺）属不动产领域，与行政书士所为之申报书类制作，担当分开。

- 确认管理规约未禁止住宅宿泊事业 → 管理组合・区分所有人，确认由四叶不动产株式会社（宅地建物交易业者）
- 确认租赁契约对转租・民泊利用之许诺 → 出租人，确认由四叶不动产株式会社（宅地建物交易业者）
- 申报书・添付书类之制作与提出代理 → 四叶行政书士事务所（行政书士）

管理规约与租赁之确认，为物件能否用于民泊之前提。申报之代理由行政书士担当，惟物件本身能否符合民泊之见立，由不动产担当。

## 物件确认・申报・消防，各应委托何人？

民泊之开始横跨多项手续与专业领域。分工如下。

- 住宅宿泊事业申报书・添付书类之制作、申报之代理 → 四叶行政书士事务所（行政书士）
- 物件能否用于民泊之判断（用途地域・管理规约・租赁之许诺）・物件买卖或租赁之仲介 → 四叶不动产株式会社（宅地建物交易业者）
- 消防法令适合通知书之取得・消防用设备之设计 → 消防署（消防长・消防署长）・消防设备士
- 须旅馆业许可时之建筑确认 → 建筑士

与四叶行政书士事务所别事业体之四叶不动产株式会社，以独立的事业体、个别契约担任物件符合之见立・买卖或租赁之仲介・管理规约与租赁之确认。消防法令适合通知书属消防署所管，消防用设备之设计属消防设备士，须旅馆业许可时之建筑确认属建筑士领域。各领域均以与各窗口・资格者作为独立的事业体个别签约为前提，本事务所不收取介绍费。受任流程见[受任流程](https://luck428.com/legal/nagare)；费用见[报酬额表](https://luck428.com/legal/ryokin)；取扱业务之全貌见[许认可・各种申请服务](https://luck428.com/legal/services)。其他开业许认可，亦可参考[深夜0时后供酒的店，需要什么申报？](https://luck428.com/legal/column/shinya-shurui-teikyo-todokede-yoken)、[古物商许可，营业所需要什么？](https://luck428.com/legal/column/kobutsusho-kyoka-eigyosho-yoken)。

## 常见问题

**Q. 纵使一年仅营业90日，仍须申报吗？**
A. 是。住宅宿泊事业之180日为「上限」，纵营业日数较少，若收取住宿费反复持续使人住宿，即该当住宅宿泊事业，须住宅宿泊事业法第3条第1项之申报。未申报而营业即为法之对象。不问日数多寡，营业前之申报为前提。

**Q. 旅馆业许可与住宅宿泊事业之申报，应选何者？**
A. 于年180日以内活用住宅者为住宅宿泊事业之申报；欲逾180日营业、或设施难谓为住宅等情形，则以旅馆业法之许可（如简易住所营业）为考量对象。何种架构适合，因日数・设施・立地而异，个别可否由所辖审查。物件性质之见立属不动产，建筑确认属建筑士领域。

**Q. 分让公寓之一室亦能经营民泊吗？**
A. 除法令上之申报外，须确认管理规约。公寓标准管理规约示有明记住宅宿泊事业可否之规定例；若规约禁止，纵能申报亦不得实施。若为租赁并须出租人之许诺。管理规约与租赁之确认属不动产领域。

**Q. 消防法令适合通知书，行政书士会代取吗？**
A. 消防法令适合通知书，为消防署（消防长・消防署长）确认住宅符合消防法令后所交付之书面，为申报之添付书类。设备要否之判断与设计属消防署・消防设备士领域，非本事务所代行事项。申报书・添付书类之制作与提出代理由本事务所，消防设备由消防署・消防设备士，各有其担当。
