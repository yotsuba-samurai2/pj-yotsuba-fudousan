**结论（先讲重点）**：就劳继续支援是残障者综合支援法（平成17年法律第123号）第5条第15项所定之残障福祉服务，对于难以在一般事业所受雇之残障者，提供就劳机会与生产活动机会，支援其提升工作所需之知识与能力。最大差异在于：A型提供基于雇用契约之就劳机会，B型提供不基于雇用契约之生产活动机会。开办事业须就各事业所，向都道府县知事（指定都市・中核市为市长）取得指定残障福祉服务事业者之指定（同法第36条）。人员・设备・运营基准依同法第43条，由国家基准即平成18年厚生劳动省令第171号与各自治体条例具体定之。指定可否与是否符合基准由指定权者审查决定，本事务所不保证指定。

## 就劳继续支援A型与B型，指定要件有何不同？

就劳继续支援于残障者综合支援法第5条第15项定义，提供就劳机会，并透过生产活动等机会之提供，供与提升工作所需知识・能力之训练等便宜。A型・B型之区分并非法律定义本身，而是由平成18年厚生劳动省令第171号（指定残障福祉服务之事业等人员、设备及运营相关基准）所定。两者最大差异为「是否与利用者签订雇用契约」。

| 区分 | 就劳继续支援A型 | 就劳继续支援B型 |
| --- | --- | --- |
| 与利用者之关系 | 签订雇用契约 | 不签雇用契约 |
| 支付 | 工资（适用最低工资法） | 工酬（依成果支付） |
| 主要对象 | 有一定支援即可持续就劳者 | 难以基于雇用契约就劳者 |
| 生产活动收支 | 生产活动收入扣除必要经费后之额，须达工资总额以上 | 工酬之平均额原则不低于月额3,000日元 |

A型因与利用者签订雇用契约，适用劳动基准法与最低工资法。就劳实态是否属劳工、工时・工资・工作规则如何设计，属社会保险劳务士领域，与本公司・本事务所为独立的事业体，各自个别签约。B型不基于雇用契约，依生产活动成果支付工酬，其平均额由运营基准定为原则不低于月额3,000日元（平成18年厚生劳动省令第171号）。

又，2025年（令和7年）10月1日新设「就劳选择支援」（残障者综合支援法第5条第13项），新利用B型者原则须于申请前先利用就劳选择支援，正分阶段移行。对象与施行时期请以自治体之运用确认。

## 指定所需人员基准（服务管理责任者・职业指导员・生活支援员）须几人？

人员基准由平成18年厚生劳动省令第171号所定，并由自治体条例具体化。A型・B型共通之基本配置如下。

| 职种 | 配置思考方式 |
| --- | --- |
| 职业指导员・生活支援员 | 总数以常勤换算方法为利用者数除以十以上（10比1）；职业指导员1人以上、生活支援员1人以上，其中1人以上为常勤 |
| 服务管理责任者 | 利用者60人以下1人以上；61人以上每40人（含端数）加1人；其中1人以上为常勤 |
| 管理者 | 原则专从常勤1人（无妨碍时得兼任） |

职业指导员・生活支援员之总数，A型于同省令第186条、B型于同省令第199条定为「以常勤换算方法为利用者数除以十以上」。B型于一定要件下有更手厚之配置（7.5比1）而使报酬评价改变之区分，惟此属报酬告示之区分，指定所需最低基准为10比1。符合人员基准之雇用契约・工时设计・工作规则・社会保险适用属社会保险劳务士领域，与本公司为独立的事业体，各自个别签约。

## 设备・运营基准上，须整备哪些文件与体制？

设备基准（平成18年厚生劳动省令第171号）要求训练・作业室、咨询室、洗面所、厕所、多目的室及其他运营上必要之设备。指定原则须利用定员20人以上（多机能型因组合多种服务，处理不同）。物件易不足之处如下。

| 设备・体制 | 主要要求 |
| --- | --- |
| 训练・作业室 | 不妨碍训练・作业之宽度；备必要机械器具 |
| 咨询室 | 得以隔间等顾及隐私 |
| 洗面所・厕所 | 依利用者特性之数量・规格 |
| 运营规程 | 定事业目的・方针、从业者职种・员数、营业日・时间、利用定员等 |
| 个别支援计划 | 由服务管理责任者作成并定期检讨 |

将事务所・店铺等既有建物改为事业所时，可能构成建筑基准法上之用途变更，或依消防法须追加消防用设备。用途变更确认申请之要否・设计属建筑士（设计者），消防用设备之要否与消防同意属消防署之判断。用途地域・面积之一次确认由不动产公司担任，本公司仅提供物件资讯，不判断建筑确认或消防可否。相关类型之指定，另请参见[生活介护之指定申请与物件要件](https://luck428.com/legal/column/seikatsu-kaigo-shitei-bukken-yoken)与[课后等日间服务・儿童发展支援之指定申请流程](https://luck428.com/legal/column/houkago-day-jido-hattatsu-shitei-shinsei-nagare)。

## 指定申请向何处、依何顺序提出？

指定由都道府县知事（指定都市・中核市为市长）就各事业所为之（残障者综合支援法第36条第1项）。一般流程如下，顺序前后易遭退回，故宜及早开始事前协议。

1. 确立事业计划・资金计划，设立法人（于章程事业目的加入残障福祉服务）
2. 选定物件，确认符合设备基准・建筑基准法・消防法
3. 与指定权者进行事前协议
4. 确保服务管理责任者・职业指导员・生活支援员
5. 作成申请书与附件并于截止前提出
6. 书面审查，必要时现地确认
7. 指定（多数自治体为每月1日付）

多数自治体以每月1日付指定，申请书提出期限一般设于指定希望日之前月或前前月。截止依指定权者而异，年度更替时亦可能提前，故务必于该自治体公式页面确认。代表性文件为指定申请书与附表、法人登记事项证明书・章程、事业所平面图・照片・租赁契约书等、运营规程、从业者勤务形态一览表与资格证・实务经验证明、服务管理责任者研修等修了证、收支预算书、各种誓约书等。

四叶行政书士事务所于行政书士业务范围内，支援指定申请书・附表・附件之作成、事前协议资料整理、运营规程等文案。是否符合基准之最终判断与指定可否由指定权者审查。

## 指定后之运营指导与报酬请求，最先须掌握什么？

取得指定后，须维持符合运营基准之纪录与体制，并成为自治体运营指导之对象。日常备妥服务提供纪录、个别支援计划、勤务实绩、工酬・工资管理，是减少指导指摘之近路。

报酬（训练等给付费）由「残障福祉服务等报酬告示」定之，原则向国民健康保险团体联合会请求。A型采将各事业所之取组点数化评价之计分方式，B型设有依平均工酬月额等之基本报酬区分（均依参照日2026-09-23之告示。区分・加算随改定变动，请以最新告示确认）。尤其A型，生产活动收入扣除必要经费后之额须达工资总额以上，未达时将被要求提出经营改善计划。报酬之计算・请求事务与税务非本事务所业务，会计・税务请洽税理士，报酬请求实务请洽事业者或专门之请求代行。

## 物件・建筑・劳务・登记・税务，各应委托何人？

指定申请涉及多个专业领域。分工如下。

- 指定申请书・附表・附件之作成、事前协议支援 → 四叶行政书士事务所（行政书士）
- 事业用物件之选定・租赁・重要事项说明、用途地域・面积一次确认 → 四叶不动产株式会社
- 用途变更确认申请・设计、既存不适格与检查济证之确认 → 建筑士（设计者）
- 消防用设备要否判断・消防同意 → 消防署
- 符合人员基准之雇用契约・工作规则・工时管理・社会保险适用，A型利用者之劳工性・最低工资 → 社会保险劳务士
- 法人设立・变更登记 → 司法书士
- 法人会计・税务・税额计算、报酬请求所伴随之经理 → 税理士
- 涉及权利义务・纠纷之个别法律判断 → 律师

四叶行政书士事务所与四叶不动产株式会社为别事业体。本公司仅以独立的事业体承担指定申请之支援，物件・建筑・消防・劳务・登记・税务与各资格者・窗口个别签约。本事务所不收取介绍费。全貌见[残障福祉服务之许认可](https://luck428.com/legal/services/shogai-fukushi)；受任流程见[受任流程](https://luck428.com/legal/nagare)；费用见[报酬额表](https://luck428.com/legal/ryokin)。

## 常见问题

**Q. 同一事业所可同时取得A型与B型指定吗？**
A. 有以一事业所组合A型与B型之多机能型取得指定之方法。因人员・设备・定员之思考方式与单独型不同，请以该自治体条例与手引确认。符合人员基准之雇用契约与劳务管理属社会保险劳务士领域，与本公司为独立的事业体，各自个别签约。

**Q. A型支付利用者的是薪水还是工酬？**
A. A型因签订雇用契约，支付者为工资，适用最低工资法。工酬为不基于雇用契约之B型所支付。A型利用者之劳工性与最低工资之个别判断属社会保险劳务士领域，为别事业体，各自个别签约。

**Q. 可直接以事务所或店铺作为事业所吗？**
A. 除面积・设备外，既有建物可能须用途变更确认申请或追加消防用设备。用途变更判断向建筑士（设计者）、消防用设备要否向消防署确认。物件属不动产公司、建筑确认属建筑士，各为别事业体，各自个别签约。

**Q. 行政书士做到哪里？**
A. 于行政书士业务范围内，支援指定申请书・附表・附件之作成、事前协议资料整理、运营规程等文案。是否符合基准之最终判断与指定可否由指定权者审查。劳务・登记・税务・报酬请求请各洽资格者・窗口，以独立的事业体个别签约。
