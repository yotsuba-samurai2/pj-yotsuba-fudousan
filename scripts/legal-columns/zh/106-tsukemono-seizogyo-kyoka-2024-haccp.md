**结论（先讲要点）：**于直卖所、道之驿或网络贩售酱菜（浅渍、泡菜、梅干、泽庵等）而制造者，原则上须取得「酱菜制造业」的营业许可。此系2018年（平成30年）修正食品卫生法等部分条文的法律（平成30年法律第46号）重新检讨许可业种时新设的业种，定于食品卫生法施行令第35条第29号，许可依食品卫生法第55条由保健所（都道府县知事等）核发。施行令施行日（2021年〔令和3年〕6月1日）前即已营业者，设有3年的经过措施，惟已于2024年（令和6年）5月31日届满，自2024年6月1日起，无许可即不得制造贩售用酱菜。许可须符合都道府县以条例所定的设施基准（食品卫生法第54条）、沿HACCP的卫生管理（食品卫生法第51条），并须设置食品卫生责任者，家庭厨房原样则不予许可。本文为一般性信息，不就个别设施是否符合基准作最终判断。四叶集团的行政书士，以独立的事业体承办营业许可申请文件与卫生管理计划整备的支援。设施的适合审查与许可属保健所，制造室的施工属建筑士与设备业者，营业税务属税理士，员工的劳务属社会保险劳务士，物件寻找属不同事业体的不动产业者，各自分别签约。

## 卖酱菜何以需要营业许可？

酱菜长期仅属都道府县条例下的「申报」对象，多数地区不需食品卫生法上的营业许可。惟因浅渍等所致的食物中毒曾经发生等背景，2018年（平成30年）修正食品卫生法（平成30年法律第46号）整体重新检讨许可业种，将酱菜制造业新定为许可业种。其依据为食品卫生法施行令第35条第29号，于此列为须许可的业种。

| 项目 | 内容（依据） |
| --- | --- |
| 业种的新设 | 依修正食品卫生法等部分条文的法律（平成30年法律第46号）重新检讨许可业种 |
| 定位 | 食品卫生法施行令第35条第29号「酱菜制造业」 |
| 许可的依据 | 食品卫生法第55条（都道府县知事等的营业许可） |
| 施行令的施行日 | 2021年（令和3年）6月1日 |

酱菜制造业，除梅干、泽庵、浅渍、泡菜、酸黄瓜等的制造外，亦有不少自治体说明包含以酱菜为主要原料的食品的制造，范围细节因保健所而异。与其他食品相关许认可的关系，另于[食品制造业的许可与物件、设备基准](https://luck428.com/legal/column/shokuhin-seizogyo-kyoka-bukken-setsubi-kijun)整理。亦请参阅本事务所的[许认可服务案内](https://luck428.com/legal/services)。

## 2024年6月以后，无许可贩售酱菜会如何？

施行令施行日（2021年〔令和3年〕6月1日）前即已制造酱菜者，设有3年的经过措施。该期限已于2024年（令和6年）5月31日届满，自2024年6月1日起，无许可即不得制造贩售用酱菜。

| 时期 | 处理 |
| --- | --- |
| 2021年6月1日前即已营业 | 须于2024年5月31日前取得许可（经过措施） |
| 2024年6月1日以后 | 无许可即不得制造贩售用酱菜。新设者须于营业前取得许可 |

未取得许可而营业者（违反食品卫生法第55条第1项），依同法第82条为2年以下拘禁刑或200万日元以下罚金的对象，法人亦得依第88条的两罚规定科以同额罚金。自制自用，或无偿往来，通常不属「以营业为之」的制造、贩售，惟既反覆继续贩售，即须许可。是否该当有疑义时，请勿迳为前提，而直接向保健所确认为妥。

## 可获许可的制造室设施基准（洗手、区划、给排水）须至何种程度？

许可须于设施符合都道府县以条例所定的设施基准（食品卫生法第54条；参酌厚生劳动省令的基准而定）后，始予核发。家庭厨房与住居一体的空间原样，原则上不予许可。代表性的确认点如下，惟具体数值、规格，务必依所管保健所的条例、要纲确认。

| 区分 | 主要确认点（因条例而异） |
| --- | --- |
| 区划 | 制造室以墙壁等与住居、居室区划，并区分作业区域 |
| 洗手 | 于制造室、厕所设置可洗净消毒的洗手设备 |
| 给排水 | 使用水的确保（适于饮用）与适当的排水、洗净设备 |
| 构造、材质 | 地板、墙壁、天花板易于清扫，器具为不浸透性且易洗净的材质 |
| 区域、换气 | 更衣场所、保管设备、换气、照明、防虫防鼠对策 |

制造室的施工、内装属建筑士、设备业者的领域，租赁物件阶段的用途与设备可否，为不动产的确认事项。嗣后修改格局、给排水将使费用增加，故于押定物件前，由保健所事前咨询并审阅图面为实务作法。食品物件设备的思考方式，亦于[食品制造业的许可与物件、设备基准](https://luck428.com/legal/column/shokuhin-seizogyo-kyoka-bukken-setsubi-kijun)触及。

## 作为沿HACCP的卫生管理，小规模业者应记录何事？

自2020年（令和2年）6月1日起（经经过措施后，于2021年6月1日完全施行），原则上对所有食品等业者均要求「沿HACCP的卫生管理」（食品卫生法第51条）。酱菜制造业亦无例外。惟就小规模营业者等，认可因所取扱食品特性而异的「导入HACCP思考的卫生管理」，依厚生劳动省公布的业种别手引书推进。

| 区分 | 所要求的取组（食品卫生法第51条） |
| --- | --- |
| 一般卫生管理 | 设施内外的清洁保持、鼠虫的驱除、使用水与器具的管理等 |
| 重要工程的管理 | 为防危害发生而管理特别重要工程的取组（洗净、盐分或温度的管理等） |
| 小规模营业者等 | 因食品特性而异的取组（依手引书作成卫生管理计划并记录） |

小规模业者「写什么」的核心，在于依手引书的范本作成卫生管理计划，并就原材料的受入、使用水、洗手、温度管理等的实施每日查核并留存记录。记录宜作成嗣后能说明卫生管理的形式。卫生管理计划的整备与样式的准备，行政书士得予支援，惟计划是否符合基准的最终审查由保健所为之。手引书的最新版，请勿迳为前提，而于厚生劳动省的官方网页确认。

## 申请向何处、委托何人较为确实？

申请对象为管辖制造所所在地的保健所（都道府县知事、保健所设置市长等的许可）。因相关专业人员分属不同领域，原则上请与各专业以独立的事业体分别签约。四叶集团的行政书士，以独立的事业体承办营业许可申请文件的作成、提交代办，卫生管理计划整备的支援，以及食品卫生责任者的确认。

| 委托对象 | 主要角色 |
| --- | --- |
| 行政书士（本事务所） | 营业许可申请文件的作成、提交，卫生管理计划整备的支援 |
| 保健所 | 设施基准的适合审查、现地确认，许可的决定 |
| 建筑士、设备业者 | 制造室的施工、给排水、内装等的施作 |
| 税理士 | 营业额、进货的记帐，税务申报 |
| 社会保险劳务士 | 雇用员工时的劳动保险、社会保险，就业规则 |
| 不动产业者（属不同事业体的本公司） | 可供制造的物件的介绍、签约 |

个别设施是否符合基准、应以何业种区分申请等判断，最终属保健所的审查领域，行政书士不得代为保证许可。寻找可供制造的物件阶段，由不同事业体的不动产业者得予协助。亦请参阅本事务所的[受任流程](https://luck428.com/legal/nagare)与[报酬表](https://luck428.com/legal/ryokin)。与各专业人员均以独立的事业体签约，彼此不收取介绍费。

## 常见问题

**Q. 可将于自宅厨房所制的梅干于道之驿贩售吗？**
A. 若反覆继续以贩售为目的而制造，原则上须取得酱菜制造业的许可。与住居一体的家庭厨房原样不符设施基准，通常不予许可，须有与住居区划的制造室等设备。是否该当，请向所管保健所确认。

**Q. 以往即贩售酱菜，现在仍须许可吗？**
A. 须要。施行令施行前即已营业者的3年经过措施，已于2024年（令和6年）5月31日届满。自2024年6月1日起，无许可即不得制造贩售用酱菜。若无许可而持续者，请速向保健所洽询。

**Q. 纵为小规模，亦须对应HACCP吗？**
A. 须要。惟就小规模营业者等，认可因所取扱食品特性而异的「导入HACCP思考的卫生管理」，依厚生劳动省的业种别手引书作成卫生管理计划，并就每日实施加以记录即足（食品卫生法第51条）。

**Q. 未取得许可而贩售会如何？**
A. 未取得许可而营业的行为，违反食品卫生法第55条第1项，依同法第82条为2年以下拘禁刑或200万日元以下罚金的对象。法人亦得依两罚规定（第88条）科以罚金。个别该当性的判断，属保健所、侦查机关的领域。
