**结论（先讲要点）：**在留资格「经营・管理」的更新，所问的不是新规时「能否开始事业」，而是「事业是否确实持续、经营是否具实体」。判断的资料为最近的决算、法人税与消费税及住民税等公租公课的缴纳状况、社会保险的加入、独立事业所的实在，以及今后的事业计划。尤其决算，会依出入国在留管理厅就事业继续性的看法，以最近2期的损益与有无债务超过来审视。依据为《出入国管理及难民认定法》别表第一之二「经营・管理」，以及同法第七条第一项第二号基准省令。此外，令和7年（2025年）10月16日施行的修法新增资本金・出资总额3,000万日元以上等新基准，但对已在留者的更新设有至令和10年10月16日的过渡措施。本文为一般性信息，不就个别更新能否获准作出判断或保证。向入管的申请取次由四叶集团的行政书士以独立的事业体承办；法人税与决算的申报由税理士负责；董事变更等登记由司法书士办理；社会保险与雇用保险手续由社会保险劳务士负责；事务所物件由属不同事业体的不动产负责。各自分别签约。

## 经营・管理签证的更新，与新规设立时有何不同？

在留资格「经营・管理」对应《出入国管理及难民认定法》别表第一之二所列「在本邦经营贸易或其他事业，或从事该事业之管理的活动」。新规（认定・变更）时的重心在于「能否开始」：是否设立公司、确保事业所、事业计划是否成立。更新时则移至「是否持续」：是否有营收、是否履行纳税与社会保险、经营者本人是否日常从事经营。所看资料的重心，由计划书移向决算书、纳税证明。

此外，令和7年（2025年）10月16日施行的修法提高了基准本身。新规设立要件的全貌整理于[中国、台湾的创业者如何取得「经营・管理」在留资格](https://luck428.com/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)，而与更新相关者，以下各点重要。

| 局面 | 主要所问之事 |
| --- | --- |
| 新规（认定・变更） | 事业所的确保、事业计划的实现可能性、资本金・出资总额等形式要件 |
| 更新 | 事业的继续性・实体、最近的决算、公租公课・社会保险的履行、经营者本人的参与 |
| 2025年10月16日修法 | 资本金・出资总额3,000万日元以上、常勤职员1人以上、申请者本人或常勤职员的日语能力（B2相当以上）、经营经验3年以上或学位、事业计划的专家确认 |
| 过渡措施 | 对已在留者的更新，至令和10年10月16日止，不以仅未达新基准为由不许可 |

## 「事业的继续性・实体」要以什么资料立证？

更新所审视的是实质重于形式。出入国在留管理厅的资料指出，若业务大半外包、经营者本人未日常经营，即不属「经营・管理」；事业所原则上不得与自宅兼用。公租公课的履行亦受重视，会确认雇用保险・劳灾保险、健康保险・厚生年金保险的加入与保费缴纳，以及国税、地方税（法人税、消费税、法人住民税、法人事业税等）的缴纳状况。

| 欲立证之事 | 代表性资料 |
| --- | --- |
| 事业确有运作 | 最近的决算书（资产负债表・损益表）、确定申报书副本 |
| 已履行纳税 | 法人税、消费税、住民税等的纳税证明 |
| 已履行社会保险 | 健康保险・厚生年金、雇用保险・劳灾的加入与缴纳记录 |
| 事业所确实存在 | 租赁契约书、所在地照片、招牌・门牌、可见独立性的资料 |
| 今后仍将持续 | 今后的事业计划书、预估收益的佐证资料 |

此等不仅看单一年度的数字，而以2期的推移审视。若为需要许认可的事业，亦会要求提出其取得状况的资料。无正当理由长期出国，将使经营者的参与受质疑，可能成为消极要素。

## 赤字决算或事务所实态不足，对更新有何影响？

赤字并不会立即导致不许可。出入国在留管理厅《外国经营者在留资格基准的明确化》（平成17年8月制定・令和2年8月修订）依最近2期的决算，整理了事业继续性的看法。要点以表呈现如下：

| 最近2期的决算状况 | 事业继续性的处理 |
| --- | --- |
| 有营业毛利，且最近期末无累积亏损（有盈余，或既无盈余亦无亏损） | 认定有继续性。纵有本期净损，若未产生累积亏损仍可 |
| 有营业毛利，但有累积亏损且非债务超过 | 原则上认定。提出今后1年的事业计划书・预估收益资料；必要时第三方评价书 |
| 仅最近期末为债务超过（其前期末非债务超过） | 须有中小企业诊断士、公认会计师等第三方，含于1年内解消债务超过之展望的评价书面 |
| 最近期末与前期末均为债务超过 | 原则上不认定继续性 |
| 最近2期均无营业毛利（营业毛损） | 原则上不认定继续性 |

重点在于：纵为赤字，是否尚未达债务超过；纵已达到，能否以第三方评价显示1年内解消的展望。至于事务所，与自宅兼用或仅具名义的地址，易被视为欠缺实体，确保独立事业所为前提。将业务整包外包、经营者本人未参与经营的型态，在更新时亦属不利。

## 更新・变更的提出文件与申请取次，由谁承办？

在留期间的更新，原则上由本人于现行在留期间届满前，向居住地管辖的地方出入国在留管理局申请。行政书士作为已向出入国在留管理厅申报的申请取次行政书士，可依《行政书士法》第1条之3，代本人提出申请书与资料，承办申请取次。此为省去本人部分出头的制度，并不保证许可本身。

| 文件示例 | 内容 |
| --- | --- |
| 在留期间更新许可申请书・照片 | 所定样式；依活动内容分类 |
| 决算文件・确定申报书副本 | 最近期（必要时含前期） |
| 纳税证明・社会保险资料 | 公租公课・社会保险的履行状况 |
| 登记事项证明书・事业所资料 | 公司的存在、事业所的实在 |
| 事业计划书・预估收益资料 | 补强继续性时 |

即使在过渡措施期间，亦可能被要求提出由经营专家所作的评价文件。若将永住纳入视野，持续履行纳税与社会保险的记录将有助益。永住的思路另请参阅[中国、台湾的专业人士如何在日本申请永住许可](https://luck428.com/legal/column/eiju-kyoka-shinsei-chuka-taiwan-senmonshoku)。

## 入管申请（行政书士）与税务、登记、劳务在何处划线？

由于相关专业人员分属不同领域，原则上请与各方以独立的事业体分别签约。四叶集团的行政书士，以独立的事业体承办在留期间更新・变更的申请文件制作辅助与申请取次。

| 委托对象 | 主要角色 |
| --- | --- |
| 行政书士（本事务所） | 在留期间更新・变更的申请文件制作・申请取次（行政书士法第1条之3） |
| 税理士 | 法人税・消费税・决算的申报；纳税证明的前提税务 |
| 司法书士 | 董事变更・总店迁移等商业登记 |
| 社会保险劳务士 | 健康保险・厚生年金、雇用保险・劳灾的手续 |
| 不动产业者（属不同事业体的本公司） | 作为独立事业所的物件选定・租赁中介・重要事项说明 |
| 中小企业诊断士・公认会计师等 | 事业计划・继续性的第三方评价 |

亦请参阅本事务所的[承办业务](https://luck428.com/legal/services)、[受任流程](https://luck428.com/legal/nagare)与[报酬额表](https://luck428.com/legal/ryokin)。与各专业人员均以独立的事业体签约，彼此不收取介绍费。决算的内容与税额的确定由税理士负责，许否的最终判断由入管审查为之。

## 常见问题

**Q. 最近的决算是赤字。更新已经没希望了吗？**
A. 仅赤字并不会立即导致不许可。出入国在留管理厅以最近2期的决算判断事业继续性，纵为赤字，若尚未达债务超过，有时可以今后1年的事业计划书等补强。纵已达债务超过，若有中小企业诊断士、公认会计师等评价1年内解消之展望的书面，亦会纳入考量。2期连续债务超过或营业毛损，原则上较难认定。

**Q. 事务所与自宅兼用也能更新吗？**
A. 事业所原则上不得与自宅兼用。经营・管理以独立事业所的实在为前提，更新时亦会以租赁契约书、所在地照片等确认实体。若仅借用地址而欠缺实体，将属不利。物件的确保由属不同事业体的不动产承办，契约内容由宅地建物取引士进行重要事项说明。

**Q. 2025年10月修法后需资本金3,000万日元。现仍在留中，更新也必须满足吗？**
A. 对已以「经营・管理」在留者的更新，设有至令和10年（2028年）10月16日的过渡措施。此期间不以仅未达新基准（资本金・出资总额3,000万日元以上等）为由不许可，而依经营状况与今后满足的展望综合判断。惟经营的实态、纳税与社会保险的履行、独立事业所的确保，与过渡措施无关，仍依从来确认。

**Q. 更新申请一定要本人亲赴入管才能办吗？**
A. 已向出入国在留管理厅申报的申请取次行政书士，可依《行政书士法》第1条之3，代本人提出申请书与资料，承办申请取次。可省去本人部分出头，惟此为程序上的取次，并不保证许可本身。许否由入管审查为之。
