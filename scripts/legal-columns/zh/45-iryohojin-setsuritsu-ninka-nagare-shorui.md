**结论（先讲重点）**：要将个人经营的诊所法人化，首先须取得医疗法人的设立认可。医疗法人非经其主要事务所所在地的都道府县知事认可，不得设立（医疗法第44条第1项），并且在主要事务所所在地办理设立登记后始告成立（医疗法第46条）。认可申请的受理往往一年仅数次，且须经都道府县医疗审议会的咨询，因此自正式申请至认可大致需2至3个月。认可申请书、章程或捐助章程、事业计划、财产目录等文件的制作与提出协助，由本事务所（四叶行政书士事务所）承办；设立登记由司法书士，法人的税务、会计由税理士，社会保险的转换由社会保险劳务士，各自作为独立的事业体分别签约对应。本文为整理制度流程的一般性资讯提供，个别的能否认可与格式，取决于诊所所在地都道府县的审查。

## 法人化后，与个人开业有什么不同？

医疗法人，是将拟开设医院、有医师或牙医师常时勤务的诊所、介护老人保健设施或介护医疗院的社团或财团予以法人化者，称为“医疗法人”（医疗法第39条）。个人开业时，院长个人是诊所的开设者；法人化后开设者变成法人，院长以理事长的身分经营法人。开设分院、拓展至介护事业、以及事业承继的便利，是考虑法人化的主要动机。

另一方面，医疗法人受到非营利性的框架限制。医疗法人不得为剩余金的分配（医疗法第54条），无法将利益分配给出资者。依2007年（平成19年）4月1日施行的改正医疗法，新设者原则上限于没有出资持分规定的医疗法人。无法像股份有限公司那样设计持分退还或分配的机制，是与个人事业或一般公司的重大差异。

| 项目 | 个人开业 | 医疗法人 |
| --- | --- | --- |
| 开设者 | 医师个人 | 医疗法人 |
| 设立手续 | 开设申报（医疗法第8条第1项） | 设立认可（医疗法第44条第1项）＋设立登记（医疗法第46条） |
| 剩余金分配 | ― | 禁止（医疗法第54条） |
| 持分 | ― | 新设原则上为无持分规定的医疗法人 |
| 分院、介护事业 | 以个人为单位受限 | 在章程范围内较易拓展 |

是否法人化本身，是综合税务、资金周转与承继计划的经营判断。税额与社会保险费的试算属税理士的领域，本事务所不进行税务咨询。

## 设立认可的申请何时提出？至认可需要多久？

医疗法人非经其主要事务所所在地的都道府县知事认可，不得设立（医疗法第44条第1项）。知事在认可设立时，须事先听取都道府县医疗审议会的意见，此一咨询与答复的时程决定了整体排程。

在许多都道府县，认可申请的受理或事前说明会一年仅数次（如春、秋）。实务上，一般是先以临时申请（事前审查）整备文件内容，再进入正式申请，经医疗审议会审议后核发认可书。自正式申请至认可大致需2至3个月，含事前准备则须以数个月为单位往前逆算。

| 阶段 | 主要内容 | 概估 |
| --- | --- | --- |
| 事前咨询、临时申请 | 章程草案、事业计划、财产目录的检查 | 配合受理时程 |
| 正式申请 | 提出认可申请书全套 | 受理梯次（一年数次） |
| 都道府县医疗审议会 | 咨询、答复 | 正式申请后数周起 |
| 认可书核发 | 设立的认可 | 正式申请后大致2至3个月 |

受理梯次、截止与格式因都道府县而异。请务必在申请前确认开业预定地都道府县的指引（本文不对特定都道府县的时程作断定）。

## 认可申请的必要文件与出资财产如何备齐？

设立认可的核心是章程或捐助章程（医疗法第44条）。社团医疗法人制作章程，财团医疗法人制作捐助章程，订定名称、目的、拟开设的医疗机构、事务所所在地、资产、社员（或评议员）与役员等事项。役员原则上须置理事3人以上、监事1人以上（医疗法第46条之5第1项）。

出资的财产，是用于诊所营运的设备、周转资金等，以财产目录、出资申请书等佐证。周转资金要估列多少，各都道府县的运用指引有所不同，可见以一定期间的周转资金为概估的指导，但金额基准须向都道府县确认（本文不对具体金额作断定）。

| 文件 | 内容 |
| --- | --- |
| 设立认可申请书 | 都道府县所定格式 |
| 章程或捐助章程 | 社团为章程、财团为捐助章程（医疗法第44条） |
| 设立总会议事录 | 设立意思决定的记录 |
| 事业计划书、预算书 | 开业后2年左右的收支预估 |
| 财产目录、出资申请书 | 出资财产与周转资金的佐证 |
| 役员名册、就任承诺书 | 理事3人以上、监事1人以上（医疗法第46条之5第1项） |

这些认可申请文件的制作与提出协助，可由本事务所（四叶行政书士事务所）作为向官公署提出之文件的制作而承办。计划数值的合理性与税务属税理士的领域。

## 认可之后，登记与税务、劳务由谁接手？

即使核发了认可书，该时点法人尚未成立。医疗法人于主要事务所所在地办理设立登记后始告成立（医疗法第46条）。设立登记须在认可等设立所需手续完成之日起2周内办理。登记完成后，才能以法人身分进入诊所的开设许可（医疗法第7条）、保险医疗机构的指定等手续。

角色分工如下。

- 医疗法人设立认可申请书、章程或捐助章程、事业计划、财产目录等文件的制作与提出协助，以及认可后各项申报的协助 → 四叶行政书士事务所（行政书士）
- 分院、迁移地等事业用物件的选定、租赁、重要事项说明 → 四叶不动产股份有限公司
- 医疗法人的设立登记、不动产登记 → 司法书士
- 法人的税务、会计，社会保险费的试算，出资财产与事业计划的数值 → 税理士
- 役职员的雇用契约、工作规则、社会保险的新规适用或转换 → 社会保险劳务士
- 涉及权利义务、纠纷的个别法律判断 → 律师

四叶行政书士事务所与四叶不动产股份有限公司为不同事业体。本事务所仅以独立的事业体承办医疗法人设立认可申请的协助，物件、登记、税务、劳务则与各该有资格者、事务所分别签约、咨询。设立登记交由司法书士、税务交由税理士，本事务所不代理登记申请、不制作登记申请书、不进行税务咨询。本事务所不收取介绍费。个人开业入口的诊所开设申报，整理于[诊所的开设是申报还是许可（医疗法第8条）](https://luck428.com/legal/column/shinryojo-kaisetsu-todokede-iryoho-8jo)。承办业务的整体样貌请见[许认可、各种申请服务](https://luck428.com/legal/services)，受任流程请见[受任流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)。能否认可本身由都道府县判断。

## 常见问题

**Q. 可以随时把个人诊所改为医疗法人吗？**
A. 认可申请的受理与说明会，各都道府县往往一年仅数次，未必想到就能立刻申请。因为要从临时申请（事前审查）进到正式申请，再经都道府县医疗审议会的咨询与答复，自正式申请至认可大致需2至3个月。受理梯次与截止请以开业预定地都道府县的指引确认。

**Q. 医疗法人可以分配利益吗？**
A. 不可以。医疗法人不得为剩余金的分配（医疗法第54条）。对役员的贷款、为特定个人保有资产等实质上与分配同视的行为，亦须避免。依2007年（平成19年）4月1日施行的改正医疗法，新设原则上为没有出资持分规定的医疗法人。

**Q. 认可下来后，可以立刻以法人身分开始诊疗吗？**
A. 仅核发认可书并不使法人成立。法人于主要事务所所在地办理设立登记后始告成立（医疗法第46条），登记须在认可等手续完成之日起2周内办理。之后尚须以法人身分取得诊所开设许可（医疗法第7条）与保险医疗机构的指定。宜逆算安排，使开业与保险诊疗开始的时点不致错开。

**Q. 设立认可的申请书可以委托行政书士吗？**
A. 向官公署提出的认可申请书、章程或捐助章程、事业计划、财产目录等文件的制作与提出协助，可由行政书士承办。惟设立登记为司法书士的业务、法人的税务与会计为税理士的业务。本事务所不进行这些登记代理或税务咨询，并以各自作为独立的事业体分别签约为前提提供说明。
