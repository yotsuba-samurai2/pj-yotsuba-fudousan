**先讲重点：** 新开美容室时，开始营业前须向保健所（都道府县知事；设有保健所的市、特别区为市长、区长）提出美容所的开设申报，并在保健所检查时取得构造设备的确认。开设申报依美容师法第11条，须事先申报美容所的位置、构造设备、管理美容师及其他从业者的姓名等。就已申报的构造设备接受都道府县知事检查，取得「适于采取所需卫生措施」的确认后，方可使用美容所（美容师法第12条）。本文整理申报的要件与流程，申报的受理与确认由保健所进行，本事务所不保证取得确认。

## 开设美容所时开设申报何时、向何处提出？

美容师法（昭和32年6月3日法律第163号）第2条将美容定义为「以烫发、结发、化妆等方法使容姿变美」，将美容师定义为「取得厚生劳动大臣的免许而以美容为业者」，将美容所定义为「为进行美容之业而设置的设施」。此处重要的是，美容师的免许是个人资格，而开设美容所则须与免许分开、就各美容所提出申报。仅持有免许并不能开店。

开设申报的提出处，为管辖美容所所在地的都道府县知事。但在设有保健所的市（政令市、中核市等）及特别区，窗口为市长、区长。申报须「事先」＝在开始营业之前进行（美容师法第11条）。申报的主要事项为美容所的位置、构造设备，以及管理美容师及其他从业者的姓名等。已申报事项有变更，或美容所废止时，亦须迅速申报（同条）。

| 项目 | 内容 |
| --- | --- |
| 依据 | 美容师法第11条（开设的申报） |
| 提出处 | 都道府县知事（设有保健所的市、特别区为市长、区长） |
| 时机 | 于开始营业之前「事先」 |
| 申报者 | 美容所的开设者（非美容师的个人、法人亦可） |
| 变更、废止 | 事项有变更、废止时迅速申报 |

## 构造设备基准（面积、区划、采光、消毒设备）须满足什么？

美容所的开设者，须就该美容所采取所需的卫生措施（美容师法第13条）。具体内容规定于厚生劳动省令（美容师法施行规则）与各都道府县的条例。国家施行规则所定的代表性措施如下。

| 项目 | 主要内容 | 依据 |
| --- | --- | --- |
| 消毒设备 | 消毒剃刀、剪刀、梳子等接触皮肤器具的设备。附着或可能附着血液的器具，以煮沸（2分钟以上）、乙醇水溶液、次氯酸钠水溶液等消毒 | 施行规则第25条 |
| 保持清洁 | 地板、腰板使用不透水材料。洗场设流水装置。备有附盖的污物箱、毛发箱 | 施行规则第26条 |
| 采光、照明、换气 | 作业面的照度为100勒克斯以上。作业室内的二氧化碳浓度保持在1000分之5以下 | 施行规则第27条 |
| 区划 | 将作业场以隔壁等，与居室、休息室等和作业无直接关系的场所完全区分 | 卫生管理要领 |

作业室的面积、美容椅的台数等具体数值，委任给各都道府县的条例与保健所的手册。因未能确认国家有定全国一律面积基准的规定，此处不断定面积的具体值；请以开业地的条例与保健所的手册确认。关于区划与消毒场所的思路，由厚生劳动省的「理容所及美容所卫生管理要领」（昭和56年6月1日环指第95号；平成22年9月15日健发0915第5号修正）所示。

## 理容所与美容所能否在同一店铺兼营？

可以兼营，但有条件。平成28年4月1日以后，若满足一定要件，即可在同一场所重复开设理容所与美容所。要件主要有2项：①理容所、美容所各自的构造设备与卫生上的要件均须满足；②于该设施施术的从业者全员，皆须持有理容师与美容师两种资格。此项处理，系依规制改革实施计画（平成27年6月30日内阁会议决定），于「理容师法施行规则及美容师法施行规则之部分修正省令的施行等」（平成27年12月9日生食发1209002号）等所示。

即使是重复开设，开设申报仍须就理容所与美容所各自提出。因为理容所的开设依理容师法、美容所的开设依美容师法，依据的法律不同。是同时开设，或在既有设施上追加，会使申报书应记载的事项（对方设施的名称、开设预定年月日）有所不同，故格式请向开业地的保健所确认。

## 开设申报需要哪些文件？保健所检查的流程为何？

开设申报除申报书外，还须设施的图面与关于资格、卫生的文件。格式、份数因地方政府而异，代表性者如下。

| 文件 | 内容概要 |
| --- | --- |
| 美容所开设申报书 | 位置、构造设备、管理美容师及其他从业者的姓名等 |
| 设施的平面图 | 作业室、等候区、消毒设备、洗场、厕所的配置与尺寸 |
| 美容师免许证的复印件 | 于该美容所从事美容之业的美容师者 |
| 管理美容师讲习会修了证复印件 | 常时有2名以上美容师从业时 |
| 医师的诊断书等 | 关于结核、皮肤疾病等（依地方政府） |
| 使用水的水质检查结果 | 使用井水等时 |
| 登记事项证明书 | 开设者为法人时 |

流程为：事前咨询 → 提出开设申报（开始营业前）→ 保健所的现地检查（确认构造设备）→ 确认 → 开始使用美容所（营业），依此顺序。可使用美容所者，须在检查确认其「适于采取第13条的措施」之后（美容师法第12条）。标准处理期间与检查日程因地方政府而异，故请从开业预定日回推，向开业地的保健所咨询。

此外，常时有2名以上美容师从业的美容所，须置管理美容师1名。可担任管理美容师者，须为取得美容师免许后从事美容业务3年以上，且修毕都道府县知事指定讲习会课程者（美容师法第12条之3）。

## 可以在申报前先进行工程吗？避免返工的顺序是什么？

若先完成所有内装工程再申报，构造设备可能不符基准而须修改。区划、洗场、消毒设备、换气，最好依基准自设计阶段起即纳入为宜。建议的顺序为：①物件现勘与用途确认 → ②向保健所事前咨询（携带图面）→ ③工程 → ④提出开设申报 → ⑤保健所现地检查、确认 → ⑥开始营业。特别是将作业场以隔壁与居室等完全区分、洗场的流水装置、消毒设备，若日后才加设，往往须重做墙壁与配管。在签订物件契约之前，先看间隔能否符合基准、能否确保给排水与换气。

美容室的开业横跨多个领域，分工如下。

- 美容所开设申报的制作，以及与保健所事前咨询的支援 → 四叶行政书士事务所（行政书士）
- 事业用物件的选定、租赁、重要事项说明 → 四叶不动产株式会社
- 开业后从业员的劳动条件、社会保险、工作规则 → 四叶社会保险劳务士事务所（社会保险劳务士）
- 内装达大规模用途变更时的确认申请 → 建筑士、特定行政厅
- 建物与事业的会计、税务 → 税理士
- 涉及权利义务与纷争的个别法律判断 → 律师

四叶行政书士事务所与四叶不动产株式会社为不同的事业体。本事务所仅以独立的事业体承办美容所开设申报的申请支援，物件、劳务、税务请与各专业人士、事业体分别签约、咨询。本事务所不收取介绍费。许可的整体样貌请见[行政许可手续](https://luck428.com/legal/services)，受任流程请见[受任流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)。若并设餐饮，另请确认[餐饮店营业许可与保健所的设备标准](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)。申报的受理与确认本身由保健所判断。

## 常见问题

**Q. 有美容师免许，就能直接开自己的店吗？**
A. 免许与开设是两回事。美容师免许是个人资格，但要开店（美容所），须与免许分开，向保健所提出美容所开设申报，并接受构造设备的检查、确认（美容师法第11条、第12条）。须在检查确认其适于采取所需卫生措施之后，方可使用美容所。

**Q. 开设申报应在何时提出？**
A. 于开始营业之前「事先」提出（美容师法第11条）。申报之后有保健所的现地检查，取得该确认后方可开始营业。因排定检查需要时日，从开业预定日回推、先从事前咨询开始较为安全。标准处理期间因地方政府而异，请于开业地保健所的官方网页确认。

**Q. 想在同一店铺同时经营理容室与美容室，可行吗？**
A. 平成28年4月1日以后，在①满足理容所、美容所各自的构造设备与卫生上要件，且②施术者全员持有理容师与美容师两种资格时，可于同一场所重复开设。惟开设申报须就理容所、美容所各自提出。要件细节与格式，请向开业地的保健所确认。

**Q. 一定要置管理美容师吗？**
A. 在常时有2名以上美容师从业的美容所为必要。可担任管理美容师者，须为取得美容师免许后从事美容业务3年以上，且修毕都道府县知事指定讲习会课程者（美容师法第12条之3）。常时仅1名美容师的美容所，无置管理美容师的义务。
