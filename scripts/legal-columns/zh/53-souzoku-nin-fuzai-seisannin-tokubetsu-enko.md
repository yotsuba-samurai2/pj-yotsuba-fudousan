**结论（先讲要点）**：没有法定继承人（不明有无继承人）时，遗产成为法人（民法第951条），家庭裁判所依利害关系人或检察官的请求，选任遗产清算人（民法第952条第1项）。清算人向债权人、受遗赠人清偿，仍有剩余者，可分与给与被继承人维持共同生计者、致力于疗养看护者等特别缘故者（民法第958条之2），最终剩余者归属国库（民法第959条）。2023年（令和5年）4月1日施行的修正，将“遗产管理人”改为“遗产清算人”，并使公告并行。本文从行政书士的角度，将手续全貌整理为一般性信息。选任的申请与审判为家庭裁判所的手续，属律师、司法书士的领域；不动产登记由司法书士；继承税由税理士，各以独立的事业体分别签约为前提分别承接。

## 没有法定继承人时，遗产会如何？

没有配偶、子女、直系尊亲属、兄弟姐妹，或全体皆抛弃继承——此种“不明有无继承人”的情形，遗产原本会处于悬空状态。民法将此财产视为一个法人（遗产法人，民法第951条），并备有由家庭裁判所选任的遗产清算人加以管理、清算的机制。清算人向被继承人的债权人与受遗赠人清偿，若有剩余财产，经对特别缘故者的分与，最后剩余者归属国库。

| 阶段 | 内容 | 依据 |
| --- | --- | --- |
| 遗产法人的成立 | 不明有无继承人时，遗产成为法人 | 民法第951条 |
| 清算人的选任与寻找继承人的公告 | 家庭裁判所选任清算人，并定6个月以上的期间为寻找继承人的公告 | 民法第952条 |
| 对债权人、受遗赠人的公告 | 清算人定2个月以上的期间为请求申报的公告（于上述6个月期间内届满） | 民法第957条第1项 |
| 无人主张权利时 | 期间内无继承人主张权利者，未知的债权人、受遗赠人不得行使权利 | 民法第958条 |
| 对特别缘故者的分与 | 家庭裁判所依请求，将清算后剩余财产的全部或一部给与 | 民法第958条之2 |
| 归属国库 | 未经处分的财产归属国库 | 民法第959条 |

“没有继承人”的情形，不仅包含自始即无任何亲属的情形，也包含继承人全体抛弃继承而结果无人承继的情形。抛弃继承的基本，于[抛弃继承与限定承认](https://luck428.com/legal/column/souzoku-hoki-gentei-shonin)中整理。

## 遗产清算人由谁、如何选任？

遗产清算人，由家庭裁判所依利害关系人或检察官的请求选任（民法第952条第1项）。利害关系人包含曾借款给被继承人的债权人、受遗赠的受遗赠人、可能成为特别缘故者立场的人，以及对被继承人有债权、债务的人等。申请对象为管辖被继承人最后住所地的家庭裁判所。手续依家事事件手续法别表第一所列的审判事件进行。

| 项目 | 内容 |
| --- | --- |
| 得申请之人 | 利害关系人（债权人、受遗赠人、可能成为特别缘故者之人等）或检察官 |
| 申请对象 | 管辖被继承人最后住所地的家庭裁判所 |
| 手续性质 | 家事事件手续法（别表第一的审判事件） |
| 预纳金 | 可能被要求预纳官报公告费用与清算人报酬的预纳金 |

清算人多由律师或司法书士担任。选任后，清算人进行寻找继承人的公告与对债权人、受遗赠人的请求申报公告，将财产变现以供清偿。选任的申请与审判为向家庭裁判所的手续；代理及具争议性的对应属律师，审判申请书类的制作与登记属司法书士的领域。行政书士于行政书士业务范围内，就财产与关系人的整理等前提部分，以信息方式协助。

## 何种人可作为特别缘故者受财产分与？

经清算后仍有剩余财产，且无人主张继承人权利时，家庭裁判所若认为适当，可将清算后剩余财产的全部或一部给与特别缘故者（民法第958条之2第1项）。条文所列的特别缘故者，为下列三种类型。

| 类型 | 例 |
| --- | --- |
| 与被继承人维持共同生计者 | 内缘、事实婚配偶，事实上的养子女等 |
| 致力于被继承人疗养看护者 | 长年持续照顾起居或看护之人 |
| 其他与被继承人有特别缘故者 | 被认定具有相当于上述之密切关系之人 |

请求分与，须于清算人选任公告（民法第952条第2项）所定期间届满后3个月内为之（民法第958条之2第2项）。逾此期限即无法受分与，故时期的管理甚为重要。是否分与、范围为何，由家庭裁判所依与被继承人关系的深浅与财产状况判断。何人属特别缘故者，最终由家庭裁判所判断，本文并不断定其可能性。独居者于生前预作准备的方法，于[死后事务委任契约](https://luck428.com/legal/column/shigojimu-inin-keiyaku-ohitorisama)与[任意监护契约](https://luck428.com/legal/column/nini-koken-keiyaku-ikogata)中整理。

## 2023年的民法修正，使清算的手续与期间有何改变？

2023年（令和5年）4月1日施行的民法等一部修正之法律（令和3年法律第24号），大幅整理了此一领域。重点在于名称与公告二者。

| 修正点 | 修正前 | 修正后 |
| --- | --- | --- |
| 名称 | 遗产管理人 | 遗产清算人 |
| 公告的进行方式 | 依序进行选任公告、债权申报公告、寻找继承人公告 | 寻找继承人公告（6个月以上）与债权申报公告（2个月以上）并行进行 |
| 手续所需期间的概略 | 因公告依序叠加，合计10个月以上 | 因公告并行，最短约6个月左右 |

修正前须依序叠加三种公告，至清算完成至少需10个月以上。修正后，使对债权人、受遗赠人的请求申报公告（民法第957条第1项）于寻找继承人的公告（民法第952条第2项）期间内届满，并行进行，故期间得以缩短。又，此次修正另设有以继承开始后遗产的保存为目的之遗产管理人（民法第897条之2）此一不同制度，因名称相似，须注意勿混淆。

## 选任申请、登记、继承税该分别向谁咨询？

继承人不存在的手续，牵涉家庭裁判所、登记与税务，横跨多位有资格者的领域。角色分工如下，各以独立的事业体分别签约为前提。

- 手续全貌的整理、财产与关系人信息的整理 → 四叶行政书士事务所（行政书士业务范围内）
- 遗产清算人选任的申请与审判等家庭裁判所的手续、具争议性的事案 → 律师（代理、协商）、司法书士（申请书类的制作）
- 变更为遗产清算人名义的登记、伴随归属国库或对特别缘故者分与的不动产登记 → 司法书士
- 继承税、让渡所得等税务的申报 → 税理士

行政书士不得代理家庭裁判所的审判申请，被选任为清算人者通常亦为律师、司法书士。本事务所的角色，仅止于手续的蓝图绘制，以及行政书士业务范围内的信息整理。继承业务的全貌请见[继承业务的服务](https://luck428.com/legal/services/inheritance)、受任流程请见[受任的流程](https://luck428.com/legal/nagare)、费用请见[报酬额表](https://luck428.com/legal/ryokin)。作为放手土地之选项的国库归属，亦于[继承土地国库归属制度](https://luck428.com/legal/column/souzoku-tochi-kokko-kizoku)中处理。继承的不动产出售等不动产咨询，由另一事业体四叶不动产股份有限公司于[继承不动产的窗口](https://luck428.com/souzoku)对应。四叶行政书士事务所与四叶不动产股份有限公司为不同的事业体，各领域皆以独立的事业体分别签约为前提。本事务所不收取介绍费。

## 常见问题

**Q. 继承人全体抛弃继承时也需要遗产清算人吗？**
A. 继承人全体抛弃而无人承继时，属于“不明有无继承人”，遗产成为法人（民法第951条）。有向债权人清偿或处分财产之必要时，由利害关系人或检察官向家庭裁判所申请选任遗产清算人（民法第952条第1项）。

**Q. 内缘配偶能取得财产吗？**
A. 内缘、事实婚配偶并非法定继承人，惟可作为与被继承人维持共同生计者等特别缘故者，向家庭裁判所请求财产分与（民法第958条之2第1项）。请求须于清算人选任公告期间届满后3个月内为之（同条第2项）。是否准许由家庭裁判所判断。

**Q. 手续需要多久？**
A. 2023年（令和5年）4月1日施行的修正使公告得并行进行，最短约6个月左右为概略基准。修正前因公告依序叠加需10个月以上。实际期间视财产内容与变现状况而异。

**Q. 剩余的财产最终会如何？**
A. 清算后，纵经对特别缘故者的分与仍未处分的财产，归属国库（民法第959条）。有不动产剩余时的名义变更（变更为遗产清算人名义的登记或归属国库的登记）由司法书士、继承税由税理士，各以独立的事业体分别签约后对应。
