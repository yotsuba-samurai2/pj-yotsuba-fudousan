**先说结论：** 来自中国、台湾等地的创业者，在日本设立公司并经营其事业时，目标多为在留资格「经营、管理」（《出入国管理及难民认定法》别表第一之二）。上陆许可基准规定于同法第7条第1项第2款之基准省令，2025年（令和7年）10月16日施行的修法，将资本额或出资总额提高至3,000万日元以上，并新增常勤职员1人以上的雇用、申请人本人或常勤职员的一定日语能力、3年以上经营经验或硕士等学位、事业计划的专家确认、独立事业所的确保。本文为一般性信息，整理要件全貌与代办申请的行政书士角色。个别能否核准，取决于出入国在留管理厅的审查。

## 「经营、管理」在留资格的主要要件为何？

「经营、管理」是供在日本经营事业、或从事管理的外国人使用的在留资格（《出入国管理及难民认定法》别表第一之二）。上陆许可基准置于同法第7条第1项第2款之基准省令，并于2025年（令和7年）10月16日的修法大幅变更。修法后主要基准如下。

| 事项 | 修法后基准（2025年10月16日施行） |
| --- | --- |
| 资本额或出资总额 | **3,000万日元以上**（修法前为500万日元以上） |
| 常勤职员 | 雇用**1人以上**。对象为日本人、特别永住者、以别表第二在留资格在留的外国人 |
| 日语能力 | 申请人本人或常勤职员达「日语教育参照框架」的**B2相当以上**（以日语能力试验N2以上、BJT商务日语能力测验400分以上等举证） |
| 经营经验、学历 | 就事业的经营、管理有**3年以上经验**，或博士、硕士、专门职学位 |
| 事业计划 | 经中小企业诊断士、公认会计士、税理士等**专家确认** |
| 事业所 | 确保独立事业所。**与自宅兼用原则上不予认可** |

已以「经营、管理」在留者，设有自施行日起3年（令和10年＝2028年10月16日）的过渡措施，其间更新时预期须逐步符合修法后基准。修法宗旨据称在于防止无实体的公司设立、确保实质的事业运营。本所在行政书士业务范围内，协助确认要件、整理举证资料、制作申请文件与代办申请。个别能否核准取决于出入国在留管理厅的审查。

## 事业所（办公室）与资本额需要到什么程度？

修法后特别加重的是资本额与事业所。

| 事项 | 内容（要旨） |
| --- | --- |
| 资本额、出资总额 | 法人为已缴纳的资本额（合名、合资、合同公司为出资总额），个人事业为投入事业的总额，须达**3,000万日元以上** |
| 事业所 | 供持续经营事业的独立设施。**与自宅兼用原则上不予认可**，仅借用地址的形态难以获准 |
| 使用权原 | 须有租赁契约等使用权原，且用途地区、建物用途须适合事业 |

事业所不仅是「有无可租物件」，还须先确认用途地区与建物使用方式是否适合事业。若先签约后才发现不能使用便得重找，于物件选定阶段先确认较为安全。事业所物件的寻找与租赁，由属别事业体的四叶不动产（持照不动产企业）以独立的事业体另行签约办理。本所不收取介绍费。

## 公司设立与在留资格申请，哪个先？

居于海外而创业时，实务上一般为「先设立公司，再申请在留资格」。因为审查以公司（法人）存在，且资本、事业所、事业计划齐备为前提。

| 阶段 | 内容 |
| --- | --- |
| ① 事业计划、资金 | 准备3,000万日元以上资本、制作经专家确认的事业计划、确保事业所 |
| ② 公司设立 | 章程制作、认证，缴纳出资，设立登记（登记申请由司法书士办理） |
| ③ 在留资格申请 | 向出入国在留管理厅提出在留资格认定证明书交付申请等（自海外招聘时）；由行政书士代办申请 |
| ④ 入境、开业 | 依证明书取得签证入境，开始事业 |

公司设立登记由司法书士，法人设立申报、税务由税理士，事业所物件由不动产企业，雇用员工时的社会保险、劳动保险由社会保险劳务士，各有分工。各事业体以独立的事业体分别签约，本所不收取介绍费。

## 设立登记、税务、社会保险该如何分工委托？

取得「经营、管理」离不开行政书士以外的专家参与。独占业务的切分如下。

- 在留资格的要件确认、举证资料整理、申请文件制作与代办申请 → 四叶行政书士事务所（可代办申请的行政书士）
- 公司的设立登记、董事变更等登记 → 司法书士
- 法人设立申报、税务、记账、税务咨询 → 税理士
- 事业所物件的寻找、租赁契约 → 四叶不动产（持照不动产企业）
- 雇用员工时的社会保险、劳动保险手续 → 社会保险劳务士

四叶行政书士事务所与四叶不动产股份有限公司为不同事业体。各领域以各自有资格者、以独立的事业体分别签约为前提，本所不收取介绍费。行政书士不能代理登记，税务咨询由税理士、登记由司法书士承担。以团体家屋（group home）等特定行业考量「经营、管理」时与指定申请的关系，另见[外国人如何开展团体家屋事业（经营、管理在留资格）](https://luck428.com/legal/column/group-home-gaikokujin-keieikanri-zairyushikaku)。

## 代办申请的行政书士能做到什么程度？

向出入国在留管理厅的在留资格申请，原则上由本人亲自到场办理，但完成一定研修并提出申报的行政书士（代办申请行政书士），可代本人提交（代办）申请文件，借此减轻本人到入管窗口的负担。

| 可以做的事 | 不能做的事 |
| --- | --- |
| 要件确认、举证资料整理、申请书与理由书制作、代办申请 | 保证或断定结果；审查由出入国在留管理厅进行 |
| 事业计划书的制作协助（数值妥当性以专家确认为前提） | 公司设立登记（司法书士业务）、税务咨询、申报（税理士业务） |
| 以中文（繁体、简体）、英文说明文件的窗口 | 断定个案的法律评价；最终判断由有资格者、入管进行 |

代办申请仅为手续代办，并不保证在留资格获准。须逐一符合资本、事业所、日语能力、事业计划的专家确认等修法后基准。委任流程请见[委任流程](https://luck428.com/legal/nagare)、费用请见[报酬额表](https://luck428.com/legal/ryokin)、业务全貌请见[许可、各项申请服务](https://luck428.com/legal/services)。

## 常见问题

**Q. 资本额真的需要3,000万日元吗？**
A. 2025年（令和7年）10月16日施行的修法，将资本额或出资总额的下限由500万日元以上提高至3,000万日元以上。已以「经营、管理」在留者，设有自施行日起3年（2028年10月16日）的过渡措施，但新申请者依修法后基准审查。个别处理请向出入国在留管理厅确认。

**Q. 不会说日语也能取得吗？**
A. 修法后，申请人本人或常勤职员须具备「日语教育参照框架」B2相当以上（如日语能力试验N2以上）的日语能力。若申请人本人未达，亦可透过确保达该水准的常勤职员因应。举证方式与具体水准须依最新基准确认。

**Q. 可以在设立公司前先申请在留资格吗？**
A. 实务上一般为设立公司、资本、事业所、事业计划齐备后再申请，因公司存在与事业实体为审查前提。设立登记由司法书士、在留资格代办申请由行政书士分工，各以独立的事业体分别签约。

**Q. 委托行政书士就一定会核准吗？**
A. 不会。可代办申请的行政书士能做到的，是要件确认、资料整理、文件制作与代办申请，能否核准由出入国在留管理厅审查判断，无法保证或断定核准。本文为一般性信息，不保证个别结果。
