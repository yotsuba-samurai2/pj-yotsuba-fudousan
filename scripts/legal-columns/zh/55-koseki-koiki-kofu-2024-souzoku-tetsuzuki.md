**先讲重点：** 2024年（令和6年）3月1日起施行的户籍广域交付（户籍法第120条之2），让即使本籍地遥远，也能在住处或工作地点邻近的市区町村（本籍地以外）窗口，一次请求多个本籍地的户籍谨本（全部事项证明书）等。但能请求者仅限本人、配偶者、直系尊属、直系卑属，不能以邮寄或代理人请求，窗口须出示附照片的身份证明文件。未电脑化的部分户籍、除籍，以及一部事项证明书、个人事项证明书，无法以广域交付取得。本文为梳理制度适用范围的一般性信息提供，能否取得由市区町村窗口判断。

## 户籍的广域交付，是新增了什么的制度？

户籍的广域交付，是依户籍法之一部修正的法律（令和元年法律第17号），于2024年（令和6年）3月1日施行的制度（户籍法第120条之2）。过去，户籍谨本只能在本籍地的市区町村取得，本籍散在各地时，必须依其数量分别请求。

| | 过去 | 广域交付（2024年3月1日起） |
| --- | --- | --- |
| 请求对象 | 各本籍地的市区町村 | 可在本籍地以外的邻近窗口一次请求 |
| 可取得者 | 各种户籍、除籍的证明书 | 户籍谨本（全部事项证明书）、除籍谨本等（部分不在对象内） |
| 请求方式 | 窗口、邮寄 | 仅窗口（本人亲自前往） |

在继承中，需要被继承人自出生到死亡连续的户籍。若曾多次迁移本籍，就须跨多个市区町村收集户籍，这正是继承手续最初的负担。广域交付减轻了这个「收集」阶段的负担。收集户籍与继承人调查的整体样貌，梳理于[收集户籍与继承人调查](https://luck428.com/legal/column/souzoku-hajime-koseki-chosa-bunkyo)。

## 谁能请求、反过来谁不能用？

能以广域交付请求者，由法律限定。

| 能请求者 | 广域交付 |
| --- | --- |
| 本人 | 可 |
| 配偶者 | 可 |
| 直系尊属（父母、祖父母等） | 可 |
| 直系卑属（子、孙等） | 可 |
| 兄弟姐妹、侄甥等 | 广域交付不可（须向本籍地请求等） |
| 受委任状的代理人、第三人 | 广域交付不可 |

能以广域交付请求户籍者，为本人、配偶者、直系尊属、直系卑属。兄弟姐妹并非直系，故无法以广域交付取得兄弟姐妹的户籍。当继承中由兄弟姐妹成为继承人等情形，这一点就是实务上的分水岭。谁会成为继承人的基本，请连同[法定继承信息一览图](https://luck428.com/legal/column/houtei-souzoku-jouhou-ichiran-zu)与继承顺位的梳理一起确认。

## 哪些户籍无法以广域交付取得？

广域交付并非能取得所有户籍。先知道取不到的，可避免返工。

| 取不到者 | 内容 |
| --- | --- |
| 未电脑化的部分户籍、除籍 | 电算化前仍以纸本保管的改制原户籍、除籍等 |
| 一部事项证明书 | 仅记载户籍一部分的证明书 |
| 个人事项证明书 | 仅记载户籍中特定个人事项的证明书（即所谓抄本） |

广域交付所交付者，原则上为户籍谨本（全部事项证明书）或除籍谨本等。一部事项证明书、个人事项证明书不在广域交付对象内。此外，未电脑化的部分户籍、除籍，因系统上无法一次取出，可能无法以广域交付取得。至于户籍附票的谨本是否属对象，请以您所在市区町村的说明确认。取不到的部分，另向本籍地的市区町村请求。

## 能以邮寄或代理人请求吗？如何与传统手续并用？

广域交付在方式上也有限制。

- 不能以邮寄请求。须由本人亲自前往窗口。
- 不能以代理人（受委任状者）请求。
- 窗口须出示驾照、My Number卡、护照等附照片的身份证明文件。

因此，若住得远而无法到窗口、需要兄弟姐妹的户籍、需要电算化前的改制原户籍等，就须并用向本籍地市区町村的传统请求（含邮寄）。可取得者于邻近窗口取得、取不到者向本籍地请求，是实务的基本分工。收集到的户籍，接着用于制作继承关系说明图与法定继承信息一览图。若想从头掌握继承手续，也请参见[受任流程](https://luck428.com/legal/nagare)。

## 收集到的户籍，要交给登记、税务的谁？

收集户籍是继承手续的入口，其后分为多个专业领域。分工如下。

- 收集户籍、制作继承关系说明图、申办法定继承信息一览图、遗产分割协议书的制作支援 → 四叶行政书士事务所（行政书士）
- 不动产继承登记的申请代理、登记申请书等的制作 → 司法书士或律师
- 继承税的申报、税额计算 → 税理士
- 遗产纠纷、个别法律判断 → 律师
- 继承不动产的出售、活用咨询 → 四叶不动产株式会社

收集到的户籍，若为继承登记，依[继承登记流程](https://luck428.com/legal/column/souzoku-touki-nagare)交给司法书士或律师；若为继承税，则交给税理士。四叶行政书士事务所与四叶不动产株式会社为不同的事业体，继承不动产的出售、活用由[继承不动产窗口](https://luck428.com/souzoku)（四叶不动产株式会社）承办。本事务所以独立的事业体提供收集户籍、制作文件的支援，登记、税务、纠纷请与各专业人士分别签约、咨询。本事务所不收取介绍费。继承中行政书士可承办的范围请见[继承手续支援](https://luck428.com/legal/services/inheritance)，费用请见[报酬额表](https://luck428.com/legal/ryokin)。

## 常见问题

**Q. 兄弟姐妹的户籍也能以广域交付取得吗？**
A. 不能。能以广域交付请求者为本人、配偶者、直系尊属、直系卑属，兄弟姐妹并非直系。当兄弟姐妹成为继承人等情形，须以向本籍地市区町村的请求（含邮寄）对应。依谁会成为继承人，于最初确认所需户籍的范围很重要。

**Q. 我住得远、无法到窗口。可以用邮寄办广域交付吗？**
A. 不行。广域交付是由本人于窗口请求的制度，不能以邮寄或代理人请求。窗口须出示附照片的身份证明文件。若无法到窗口，须并用向本籍地市区町村的传统邮寄请求。

**Q. 以前的改制原户籍也能以广域交付一次取得吗？**
A. 未电脑化的部分户籍、除籍（电算化前仍以纸本保管的改制原户籍等），可能无法以广域交付取得。取不到的部分，另向本籍地市区町村请求。哪些户籍属对象，请于窗口确认。

**Q. 以广域交付取得的户籍，能自行办到继承登记吗？**
A. 取得户籍是继承的入口。继承登记的申请代理与登记申请书等的制作，是司法书士或律师的业务，继承税的申报属税理士领域。本事务所承办收集户籍、继承关系说明图与法定继承信息一览图的申办支援，登记、税务请与各专业人士分别签约。
