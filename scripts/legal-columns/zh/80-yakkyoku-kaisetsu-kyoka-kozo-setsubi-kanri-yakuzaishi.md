**先讲重点：** 开设药局（进行调剂的药局），须就各店铺取得所在地都道府县知事（设有保健所的市、特别区为市长、区长）的药局开设许可（医药品医疗机器等法第4条第1项）。许可的主要要件有3项：①构造设备符合药局等构造设备规则的基准；②调剂与医药品贩卖的业务体制符合基准；③申请人未落入欠格事由（同法第5条）。药局须置管理药剂师实地管理，管理药剂师原则上不得在该药局以外的场所以业务身分兼任药事实务（同法第7条第3项）。本文以一般性信息提供整理要件与流程，许可与否由药务主管窗口判断，本事务所不保证取得许可。

## 药局开设许可的构造设备基准有哪些要求？

医药品医疗机器等法（昭和35年8月10日法律第145号。旧药事法。以下称「医药品医疗机器等法」）第4条第1项规定，药局非经所在地都道府县知事（所在地位于设有保健所的市或特别区时为市长、区长）的许可，不得开设。该许可若未每6年更新一次，即因期间经过而失效（同条第4项）。

能否取得许可的基准规定于同法第5条，落入下列任一情形时可能不予许可：①构造设备不符厚生劳动省令所定基准（第1号）；②进行调剂及医药品贩卖、授与的业务体制不符省令所定基准（第2号）；③申请人落入许可撤销、刑罚等欠格事由（第3号）。其中制定构造设备基准的厚生劳动省令，即药局等构造设备规则（昭和36年2月1日厚生省令第2号）。同规则第1条所定药局构造设备的主要项目如下。

| 项目 | 主要内容 | 依据 |
| --- | --- | --- |
| 面积 | 约19.8平方米以上，并能适切进行药局业务 | 药局等构造设备规则第1条第1项 |
| 换气、清洁 | 换气充分且清洁 | 同上 |
| 天花板、地板、内壁 | 易于清扫、可防尘埃堆积的构造 | 同上 |
| 贮藏设备 | 阴凉贮藏设备，及可上锁的贮藏设备（毒药、精神药品等） | 同上 |
| 调剂室 | 面积6.6平方米以上，天花板、地板为板材、混凝土等，并采取使领取调剂药剂者无法进入的必要措施 | 同上 |
| 调剂设备、器具 | 具备调剂所需的设备、器具 | 同上 |
| 信息提供设备 | 具备提供药品信息、基于药学知识指导的设备 | 同上 |

面积的具体数值、配置，以及等候区与陈列架的处理，在各都道府县、设有保健所的市的审查基准与手册中细节有所不同。作为全国一律的数值，上述「约19.8平方米以上」「调剂室6.6平方米以上」已定于规则，但实际的符合判断取决于开业地药务主管窗口的审查。物件本身用途、构造的适法性（建筑基准法上的用途，以及涉及用途变更时的建筑确认），非本事务所的判断范围，由建筑士、特定行政厅确认。事业用物件的选定、租赁由四叶不动产株式会社承办，本事务所承办许可申请的文件制作。

## 管理药剂师须为常勤、专任吗？可以兼职吗？

药局须置实地管理该药局的药剂师（管理药剂师）。医药品医疗机器等法第7条第1项规定，药局开设者为药剂师时，须自行实地管理该药局（自该药局从事实务的其他药剂师中指定管理者管理时，不在此限）；第2项规定，开设者非药剂师时，须自该药局从事实务的药剂师中指定管理者实地管理。也就是说，即使开设者为法人，药局的实地管理仍由药剂师管理者进行。

可否兼职，由第7条第3项规定。药局的管理者，不得为在该药局以外的场所「以业务身分」从事药局管理及其他药事实务者。但取得该药局所在地都道府县知事许可时，不在此限。因此管理药剂师原则上须专任于一家药局，与他店的兼职仅限于取得都道府县知事许可的例外情形。关于此兼职许可的思路，整理于厚生劳动省通知「关于医药品、医疗机器等法第7条第3项所定药局管理者兼职许可的思路」（平成31年3月20日药生总发第320003号）。另「常勤」并非法令用语，而是实务上的运用，工作时数、工作日数的具体处理，请向开业地窗口确认。

管理者为避免产生有害公共卫生之虞，须监督该药局勤务的药剂师及其他从业者、管理构造设备与医药品等物品、尽必要注意，并以书面向药局开设者陈述必要意见（同法第8条）。又，药剂师个人免许的取得，以及个别调剂内容的适否，非本文对象。药剂师与从业员的劳动条件、社会保险、工作规则，由四叶社会保险劳务士事务所（社会保险劳务士）承办。

## 药局开设许可的申请流程与必要文件为何？

申请应自开业预定日回推推进。标准流程为：①向药务主管窗口（都道府县的药务课、保健所）事前咨询 → ②确认物件、设计是否符合构造设备基准 → ③提出药局开设许可申请书 → ④文件审查 → ⑤现地检查（确认构造设备）→ ⑥许可 → ⑦开设，依此顺序。开业预定日的几日前提出、现地检查的日程，因地方政府而异，故从事前咨询开始较为安全。

申请时所要求的代表性文件如下。因格式、份数、附件因地方政府而异，请以开业地的官方手册确认。

| 文件 | 内容概要 |
| --- | --- |
| 药局开设许可申请书 | 名称、所在地、构造设备概要、管理者姓名等 |
| 构造设备概要、平面图 | 调剂室、等候区、贮藏设备、信息提供设备等的配置与尺寸 |
| 周边位置图 | 显示药局位置关系的图 |
| 管理药剂师的药剂师免许证影本、显示雇用关系的文件 | 担任管理者的药剂师者 |
| 登记事项证明书、章程等 | 开设者为法人时 |
| 诊断书等 | 关于申请人（法人为执行业务的役员）欠格事由者（依地方政府） |

此处须注意，以公共医疗保险进行调剂的「保险药局」指定，是与药局开设许可不同的手续。保险药局的指定依健康保险法，另向管辖所在地的地方厚生局长申请。即使取得开设许可，未取得保险药局指定即无法进行保险调剂。开设许可申请书等的制作由行政书士承办，本事务所不保证许可或保险药局指定与否。

## 药局与店铺贩卖业（药妆店等）在许可上有何不同？

「贩卖药品的店铺」大致分为药局与店铺贩卖业，作为依据的许可不同。药局是取得医药品医疗机器等法第4条药局开设许可的设施，可进行调剂，并可处理含医疗用医药品的药局医药品、要指导医药品与一般用医药品。相对地，店铺贩卖业是取得同法第26条许可的业态，不能调剂，也不能处理药局医药品（医疗用医药品等）。可处理者为要指导医药品与一般用医药品。所谓药妆店，若不进行调剂，可作为店铺贩卖业经营；若设置调剂室并进行调剂，则须药局开设许可。

管理者的资格亦有不同。店铺贩卖业中，贩卖要指导医药品或第一类医药品的店铺，由药剂师担任店铺管理者；仅贩卖第二类、第三类医药品的店铺，可由药剂师或登录贩卖者担任管理者（同法第28条）。药局须有药剂师管理者。又，非药局者，不得于其名称使用「药局」文字（同法第6条）。

| | 药局 | 店铺贩卖业 |
| --- | --- | --- |
| 依据 | 医药品医疗机器等法第4条（开设许可） | 同法第26条（许可） |
| 调剂 | 可 | 不可 |
| 可处理的医药品 | 药局医药品（含医疗用）、要指导、一般用 | 要指导、一般用（药局医药品不可） |
| 管理者 | 药剂师 | 药剂师（贩卖要指导、第一类时）／登录贩卖者（仅第二类、第三类时） |
| 「药局」名称 | 可使用 | 不得使用（第6条） |

药局的开业横跨多个领域，分工如下。

- 药局开设许可申请书等的制作，以及与药务主管窗口事前咨询的支援 → 四叶行政书士事务所（行政书士）
- 事业用物件的选定、租赁、重要事项说明 → 四叶不动产株式会社
- 药剂师、从业员的劳动条件、社会保险、工作规则 → 四叶社会保险劳务士事务所（社会保险劳务士）
- 建物用途、构造的适法性，以及涉及用途变更时的建筑确认 → 建筑士、特定行政厅
- 医药品贩卖业的会计、税务 → 税理士
- 涉及权利义务与纷争的个别法律判断 → 律师

四叶行政书士事务所与四叶不动产株式会社为不同的事业体。本事务所仅以独立的事业体承办药局开设许可的申请支援，物件、劳务、税务请与各专业人士、事业体分别签约、咨询。本事务所不收取介绍费。许可的整体样貌请见[行政许可手续](https://luck428.com/legal/services)，受任流程请见[受任流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)。关于医疗法的诊疗所开设申报，请见[诊疗所的开设申报（医疗法第8条）](https://luck428.com/legal/column/shinryojo-kaisetsu-todokede-iryoho-8jo)；关于医疗法人的设立认可，请见[医疗法人设立认可的流程](https://luck428.com/legal/column/iryohojin-setsuritsu-ninka-nagare-shorui)。许可与否本身由药务主管窗口判断。

## 常见问题

**Q. 有药剂师免许，就能马上开自己的药局吗？**
A. 免许与开设许可是两回事。药剂师免许是个人资格，但要开药局，须与免许分开，就各店铺向都道府县知事（设有保健所的市、特别区为市长、区长）取得药局开设许可（医药品医疗机器等法第4条第1项）。许可要求构造设备、业务体制符合基准，且未落入欠格事由（同法第5条）。

**Q. 管理药剂师可以在其他药局或店铺兼职吗？**
A. 原则上不可。药局的管理者不得为在该药局以外的场所以业务身分从事药事实务者（医药品医疗机器等法第7条第3项）。但取得该药局所在地都道府县知事许可时，可例外兼职。许可的思路载于厚生劳动省通知（平成31年3月20日药生总发第320003号）。

**Q. 药妆店与调剂药局是同一种许可吗？**
A. 是不同的许可。进行调剂的药局为药局开设许可（第4条）；不调剂而贩卖要指导、一般用医药品的店铺为店铺贩卖业许可（第26条）。两者在可否调剂、可处理医药品的范围、管理者资格（药剂师或登录贩卖者）上均不同。若设置调剂室并进行调剂，须药局开设许可。

**Q. 取得药局开设许可后，就能马上进行保险调剂吗？**
A. 不能。以公共医疗保险进行调剂的保险药局指定，是与开设许可不同的手续，依健康保险法向地方厚生局长申请。取得开设许可后，再取得保险药局指定，方能进行保险调剂。手续顺序与必要文件，请向地方厚生局与药务主管窗口确认。
