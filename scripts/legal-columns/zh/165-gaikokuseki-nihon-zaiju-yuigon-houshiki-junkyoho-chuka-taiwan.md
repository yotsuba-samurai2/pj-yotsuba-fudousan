**结论（先讲要点）**：住在日本的中国籍・台湾籍人士，也能在日本立遗嘱。遗嘱的「方式（如何书写形式上才有效）」只要符合行为地法・本国法・住所地法・惯常居所地法・不动产所在地法之一即方式有效（遗嘱方式准据法之法律第2条），以日本方式所立的遗嘱也可能方式有效。另一方面，遗嘱的「成立・效力」依遗嘱人的本国法（法之适用通则法第37条）。本文以行政书士视角整理立遗嘱支援・必要文件・与公证役场的协调，属一般性信息提供。公正证书遗嘱的作成交由公证人，继承开始后的登记交由司法书士，继承税・国际课税交由税理士，本国（中国・台湾）的效力与当地手续交由当地的律师，继承相关的纠纷交由律师，各以独立的事业体分别签约为前提分开委任。继承所得不动产的出售・管理由另一事业体的四叶不动产股份有限公司负责，本事务所不收取介绍费。

## 外国籍人士能在日本立遗嘱吗？遗嘱的「方式」由哪国法律决定？

外国籍并非不能在日本立遗嘱的理由。此处应分开思考的是遗嘱的「方式（如何书写形式上才有效）」与遗嘱的「成立・效力（是否作为意思表示成立、具何种效力）」。

遗嘱的方式，依「遗嘱方式准据法之法律」（昭和39年法律第100号）第2条，采只要符合下列之一即方式有效的选择性连结。

| 款 | 符合即方式有效之法（遗嘱方式准据法之法律第2条） |
| --- | --- |
| 1 | 行为地法（作成遗嘱之地的法。于日本作成即日本法） |
| 2 | 遗嘱人于立遗嘱时或死亡时具有国籍之国的法（本国法） |
| 3 | 遗嘱人于立遗嘱时或死亡时有住所之地的法 |
| 4 | 遗嘱人于立遗嘱时或死亡时有惯常居所之地的法 |
| 5 | 关于不动产之遗嘱，该不动产所在地法 |

本法律以尽可能使遗嘱方式有效为旨，使可选择多种法。住在日本的中国籍・台湾籍人士于日本立遗嘱，因符合第1款（行为地法＝日本法），以日本方式（公正证书遗嘱・自笔证书遗嘱等）所立遗嘱可能方式有效。另一方面，遗嘱的成立・效力依本国法（通则法第37条第1项）。即使方式依日本法有效，「可将什么留给谁、留多少」等实质，仍须作为本国法或继承准据法之问题另行检讨。继承本身的准据法架构，整理于[外国籍人士的继承系依日本法或本国法（通则法第36条）](https://luck428.com/legal/column/gaikokuseki-hisouzokunin-junkyoho-tsusokuho-36jo)。

## 母语非日语者立公正证书遗嘱时，通译与证人如何处理？

公正证书遗嘱，系在二名以上证人在场下由公证人作成的方式（民法第969条）。公证人以日语作成公正证书（公证人法第27条）。而当嘱托人不通晓日语时，公证人应使通译人通译（公证人法第29条）。有通译人参与时，公证人使通译人将所作公正证书之旨趣通译后取得承认（公证人法第40条）。

| 确认点 | 内容（事先向公证役场确认） |
| --- | --- |
| 证人 | 须二名以上在场。推定继承人・受遗赠人及其配偶・直系血亲等不得为证人（民法第974条之欠格） |
| 语言・通译 | 公正证书以日语作成（第27条）。不通晓日语之嘱托人以通译人之通译（第29条・第40条） |
| 本人确认・文件 | 本人确认资料与显示财产・继承人关系之资料。外国籍者之身分关系资料请事先向公证役场确认 |

通译人之安排与要否、由谁任证人、当日进行方式，可能因公证役场而异。于作成日前，向公证役场确认必要文件与通译・证人之安排。公正证书遗嘱之证人・费用的一般整理，见[公正证书遗嘱的证人・费用与公证人的关与](https://luck428.com/legal/column/kosei-shosho-yuigon-koshonin-shonin-hiyo)。行政书士负责原案制作之支援、必要文件之收集・整理，以及与公证役场的日程・文件协调，不判断遗嘱内容的法律当否。

## 自笔证书遗嘱可用外语书写吗？能使用法务局的保管制度吗？

自笔证书遗嘱，系遗嘱人亲自书写本文・日期・姓名并盖章作成的方式（民法第968条第1项）。财产目录不以亲自书写为必要，可以电脑制作或附上存折复印件等，惟各页须签名・盖章（同条第2项）。民法就自笔证书遗嘱所用语言并无明文限制，故以外语书写本身并不当然无效。惟是否符合方式（全文・日期・姓名之亲自书写、盖章），以及日后解释・手续可能须日语译本，须另行思考。

使用法务局的自笔证书遗嘱书保管制度（法务局保管遗嘱等之法律），可将遗嘱书寄存于法务局（遗嘱书保管所），并免除家庭裁判所之检认。惟此制度样式严格，有A4尺寸・所定留白・单面书写・页码等要件，逾越样式即不受理。以外语书写之自笔证书遗嘱能否以此保管制度寄存（受理可否或运用），因未能官方确认，属未验证。若以外语作成并考虑利用保管制度，请事先向法务局（遗嘱书保管所）直接确认。保管制度的手续流程见[自笔证书遗嘱书保管制度与继承开始后手续](https://luck428.com/legal/column/jihitsu-yuigon-hokan-seido-souzoku-tetsuzuki)，自笔与公正证书之差异见[自笔证书遗嘱与公正证书遗嘱的差异](https://luck428.com/legal/column/jihitsu-kosei-yuigon)。

## 该遗嘱在本国（中国・台湾）也有效吗？本国财产如何处理？

于日本以符合方式所立遗嘱，能否于本国（中国・台湾）原样通用，系本国法律与手续之问题。日本的「遗嘱方式准据法之法律」系于日本法院・手续中判断方式有效性之架构，本国之承认・执行则依本国之国际私法与程序法。

| 对象 | 思路（一般论） |
| --- | --- |
| 日本所在财产 | 于日本所立遗嘱之方式有效性，可能依遗嘱方式准据法之法律第2条各款之符合而判断 |
| 本国（中国・台湾）所在财产 | 本国之效力・承认依本国之国际私法与程序法；当地可能须另行手续・翻译・认证 |
| 本国之承认 | 日本之公正证书或自笔证书能否原样使用，或须认证（公证・领事认证・海牙认证等），依本国实务而定 |

本国有不动产或存款等财产时，仅凭日本之遗嘱可能无法完结，是否于本国须另立遗嘱或手续，向当地律师确认较为安全。何种财产须何国手续，因财产所在・种类与本国法律而异，不能断言「必定」「总是」。本国之效力・当地手续之个别判断，保留予本国之具资格者（律师）。本文仅整理日本侧之作成实务，属一般性信息提供。

## 遗嘱内容（谁得什么）的最终判断，以及起争议时的咨询对象？

「将什么・留给谁・留多少」之遗嘱内容本身，与特留分及继承准据法密切相关。外国籍人士之继承，因牵涉继承准据法（通则法第36条）与本国法之适用，遗嘱内容日后如何评价不能一概而论。遗嘱之成立・效力依本国法（第37条），即使方式有效，内容之实质效力仍须另行检讨。

## 常见问题

**Q. 我是中国籍・台湾籍，能在日本立日语的公正证书遗嘱吗？**
A. 可以。遗嘱之方式只要符合行为地法（日本法）即可能方式有效（遗嘱方式准据法之法律第2条第1款）。公正证书以日语作成（公证人法第27条），不通晓日语者以通译人之通译（公证人法第29条）。惟遗嘱之成立・效力依本国法（第37条）之点，须另行检讨。

**Q. 自笔证书遗嘱以母语书写有效吗？能寄存于法务局吗？**
A. 因民法就自笔证书遗嘱之语言无明文限制，以外语书写本身不当然无效。惟须符合全文・日期・姓名之亲自书写与盖章等方式。外语遗嘱能否以法务局保管制度寄存（受理）尚未官方确认，请事先向法务局（遗嘱书保管所）确认。

**Q. 于日本所立遗嘱，能在中国・台湾原样使用吗？**
A. 因本国之效力・承认依本国之国际私法与程序法，日本之遗嘱未必能原样使用。本国有财产时，是否须另行手续・翻译・认证，向当地律师确认较为安全。个别判断保留予本国之具资格者。

**Q. 能委任行政书士做什么？**
A. 遗嘱原案制作之支援、必要文件之收集・整理、与公证役场之日程・文件协调，以及交付各专家之资料整理。公正证书遗嘱之作成属公证人，继承登记属司法书士，税务属税理士，本国手续属当地律师，纠纷属律师之领域，行政书士不作具体法律判断或纠纷代理。
