**结论（先说要点）**：登录支援机关，系受接收特定技能1号外国人之事业者（特定技能所属机关）委托，实施「一号特定技能外国人支援计划」全部，并受出入国在留管理厅长官登录之机关（出入国管理及难民认定法第19条之23）。登录之有效期间为5年，并有不属欠格事由等要件（同法第19条之26）。支援计划须符合法务省令（订定特定技能雇用契约及一号特定技能外国人支援计划基准等之省令・平成31年法务省令第5号）之基准，并纳入事前指引等义务性支援。本文为一般资讯提供，整理登录要件・欠格事由・支援计划必要项目・自社支援之可否・申报此等入管手续，不作个别许认可之可否或法律判断。

## 登录支援机关系从事何种业务之机关？

以特定技能1号在留资格接收外国人之事业者，称为「特定技能所属机关（接收机关）」。接收机关须就所接收之每一名外国人制作「一号特定技能外国人支援计划」，并依计划就职业生活・日常生活・社会生活提供支援（出入国管理及难民认定法第2条之5）。将此支援之全部实施委托外部时，受该委托之机关即为登录支援机关。

登录支援机关系受出入国在留管理厅长官登录之法人或个人，依与接收机关之委托契约实施支援计划。未受登录之事业者不得有偿受托支援业务。行政书士受接收机关或支援机关委任，于行政书士业务范围内代为制作・提出登录申请文件与支援计划书。受任流程见[受任流程](https://luck428.com/legal/nagare)；费用见[报酬额表](https://luck428.com/legal/ryokin)；取扱业务见[取扱业务](https://luck428.com/legal/services)。

| 区分 | 角色 |
| --- | --- |
| 特定技能所属机关（接收机关） | 与外国人缔结特定技能雇用契约、制作支援计划之当事人 |
| 登录支援机关 | 受支援计划全部实施之委托而实施支援之机关 |
| 行政书士 | 登录申请・支援计划书等入管提出文件之制作・提出代理 |

## 登录之要件与欠格事由为何？

登录系向出入国在留管理厅长官申请（第19条之24），符合要件者即登录于登录支援机关登录簿（第19条之25）。登录手数料为收入印纸28,400日元，登录之有效期间为5年（第19条之23）。未更新者于期间届满时失其效力。

主要之登录基准与欠格事由如下（第19条之26第1项各款）。

| 项目 | 内容 |
| --- | --- |
| 支援体制 | 已选任支援责任者・支援担当者，并具备以外国人所能理解语言提供支援之体制 |
| 过去实绩等 | 2年内有接收中长期在留者・生活咨询之实绩等（符合省令基准） |
| 欠格事由 | 不属如受拘禁刑以上之刑、因违反出入国或劳动法令受罚金刑而未满5年、与黑社会有关、有一定申报违反等情形 |

欠格事由之有无，以及自社体制是否符合基准，最终由出入国在留管理厅审查。本事务所不保证登录之可否。

## 支援计划之必要项目为何？

一号特定技能外国人支援计划，须符合法务省令（订定特定技能雇用契约及一号特定技能外国人支援计划基准等之省令・平成31年法务省令第5号）之基准。计划须纳入下列义务性支援之全部。

| 义务性支援 | 内容例 |
| --- | --- |
| 事前指引 | 于雇用契约缔结后说明劳动条件・活动内容・入国手续等 |
| 出入国时之接送 | 机场与事业所・住居间之接送 |
| 住居确保・生活所需契约之支援 | 住居之确保，银行账户・手机・水电等手续之协助 |
| 生活导览 | 生活规则・交通・紧急时应对等之说明 |
| 公务手续等之陪同 | 住民登记・社会保障・税等手续之协助・陪同 |
| 日语学习机会之提供 | 日语教室之介绍等 |
| 咨询・申诉之对应 | 以母语之咨询对应・建议 |
| 与日本人交流之促进 | 地方活动之介绍等 |
| 转职支援 | 因接收方事由解除雇用契约时之转职支援 |
| 定期面谈・对行政机关之通报 | 支援责任者等之定期面谈，违反法令时之通报 |

其中，劳动条件之明示本身、雇用契约之内容、社会保险・劳动保险之加入手续系雇主（接收机关）之义务；代办该等手续及劳务管理属社会保险劳务士，与外国人有关之课税属税理士之领域。四叶社会保险劳务士事务所及税理士与四叶行政书士事务所为独立的事业体，须个别签约。本事务所不收取介绍费。

## 不委托而由自社支援之条件为何？

接收机关亦得不委托登录支援机关，而由自社实施支援计划。惟于此情形，接收机关本身须符合支援体制之基准（省令）。具体而言，须满足如过去2年内有接收中长期在留者之实绩，或役员・职员于过去2年内曾从事中长期在留者生活咨询业务之经验等要件后，选任支援责任者・支援担当者。

另一方面，将支援计划全部之实施委托登录支援机关时，接收机关即被视为符合支援体制之基准（出入国管理及难民认定法第2条之5）。选择自社支援抑或委托，系衡酌社内体制・语言对应・成本之经营判断；基准符合之最终判断由出入国在留管理厅为之。

## 怠于申报・更新将如何？

登录支援机关负有如登录事项变更时之变更申报（第19条之27）、休废止支援业务时之申报（第19条之29）等义务。怠于申报支援实施状况、为不实申报、未适正实施支援等情形，将成为出入国在留管理厅长官指导・建议之对象，有一定事由时其登录得被撤销（第19条之32）。登录一经撤销即无法续行支援业务，受委托之接收机关须另行整备支援体制。

四叶行政书士事务所与四叶不动产株式会社为别事业体。登录申请・支援计划书之制作由行政书士，劳动条件之明示及社会保险・劳动保险手续由社会保险劳务士，课税由税理士，在留资格相关争讼由律师，各以独立的事业体个别签约处理。本事务所不收取介绍费。受任流程见[受任流程](https://luck428.com/legal/nagare)；费用见[报酬额表](https://luck428.com/legal/ryokin)；取扱业务见[取扱业务](https://luck428.com/legal/services)。

## 常见问题

**Q. 登录支援机关之登录有效期间为何？**
A. 登录之有效期间为5年（出入国管理及难民认定法第19条之23）。期间届满后欲续行支援业务须更新，未更新即失其效力。新规登录手数料为收入印纸28,400日元。

**Q. 接收机关是否必须委托登录支援机关？**
A. 否。接收机关若符合支援体制之基准（省令），即可由自社实施支援计划。不符合或自社无法因应时，有将支援计划全部之实施委托登录支援机关之选项。全部委托时，接收机关即被视为符合支援体制之基准。

**Q. 支援计划应记载何事项？**
A. 须纳入事前指引、出入国时之接送、住居确保・生活所需契约之支援、生活导览、公务手续等之陪同、日语学习机会之提供、咨询・申诉之对应、与日本人交流之促进、转职支援、定期面谈・对行政机关之通报此等义务性支援之全部，并符合法务省令（平成31年法务省令第5号）之基准。

**Q. 劳动条件与社会保险手续亦可委由行政书士办理吗？**
A. 在留资格之申请、支援机关之登录、支援计划书之制作属行政书士业务。另一方面，劳动条件之明示、雇用契约之内容、社会保险・劳动保险之加入手续及劳务管理属社会保险劳务士，课税属税理士之领域，各以独立的事业体个别签约。本事务所不收取介绍费。
