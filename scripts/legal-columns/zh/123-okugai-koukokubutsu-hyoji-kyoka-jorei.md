**结论（先讲要点）：**店铺招牌是否需要户外广告物的表示许可，视其地点与大小而定。户外广告物的规制以户外广告物法（昭和24年法律第189号）为框架，而实际的禁止地区、许可地区、大小与高度的基准、许可的有效期间，则由各都道府县、政令市等所订的户外广告物条例决定。该法第3条使都道府县得以条例，为维持良好景观、风致或防止公众危害，指定地区或场所禁止表示、设置；第4条得以条例订定须受都道府县知事许可等限制；第5条得以条例订定广告物的形状、面积、色彩、意匠及其他表示方法的基准。设置招牌的广告业者一方，依第9条、第10条所设条例，须办理户外广告业的登录（含各营业所业务主任者的选任）。本文为一般性信息，不就个别招牌是否为许可对象、是否符合基准作最终判断。四叶集团的行政书士，以独立的事业体承办户外广告物表示许可申请与户外广告业登录申请的支援。作为一定规模工作物的建筑确认与结构安全属建筑士，招牌的制作、施工属广告施工业者，店铺物件、租赁的寻找属不同事业体的本公司（不动产业者）领域，各自分别签约。本所不向任何专业人士收取介绍费。

## 需要户外广告物许可的，是哪种招牌？

户外广告物，指常时或于一定期间继续在户外向公众表示之物，例如看板、立看板、张贴纸与张贴札，以及广告塔、广告板、挂于建物或其他工作物等上所表示者（户外广告物法第2条第1项）。店铺的墙面招牌、侧招牌（突出招牌）、自立招牌、旗帜、店头的立看板，均可能属此户外广告物。是否需要许可，取决于地点（位于何种地区）与大小、高度，其具体依管辖的条例而定。

| 招牌例 | 是否属户外广告物 | 许可要否的参考 |
| --- | --- | --- |
| 墙面招牌、侧招牌 | 属之 | 多视设置地点与大小而需许可 |
| 自立招牌、广告塔 | 属之 | 高度、面积愈大愈易成为许可对象 |
| 旗帜、店头立看板 | 属之 | 条例可能作为简易广告物而有其规制 |
| 朝向店内的室内表示 | 多因非在户外向公众表示而不属之 | 以条例确认 |

即便是标示自店名称、营业内容的“自家用广告物”，亦非当然排除于规制之外。有地区以条例设有一定面积以下免许可的处理，惟基准因地区而异。此与开业时其他店铺系的申报（如餐饮店的[餐饮店营业许可与设施基准](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)）为不同制度，故招牌须以招牌另行确认。受任的进行方式，请见[受任流程](https://luck428.com/legal/nagare)。

## 禁止地区、许可地区，与大小、高度的基准为何？

户外广告物法以条例订定将地区、场所分为“禁止”与“许可（限制）”的框架。第3条使都道府县得以条例，为维持良好景观、风致而于认有必要时禁止表示、设置的地区或场所（第1项）、对桥梁、行道树、铜像及纪念碑等物件的表示之禁止（第2项）、为防止公众危害而于认有必要时的禁止（第3项）。第4条就禁止地区以外，得订定须受知事许可等限制；第5条就广告物的形状、面积、色彩、意匠及其他表示方法的基准，或挂出物件的形状及其他设置方法的基准，均得以条例订定。

| 法的条文 | 条例得订定之事项 |
| --- | --- |
| 第3条 | 禁止地区、禁止场所、禁止物件（桥梁、行道树等）、为防止危害的禁止 |
| 第4条 | 须许可的地区、场所，知事等的许可及其他限制 |
| 第5条 | 大小（面积）、高度、形状、色彩、意匠等表示方法的基准 |
| 第7条 | 对违反广告物的表示、设置停止命令，除却及其他必要措施 |

因此，“至几平方米”“离地至几米”等具体数值基准，以及何种用途地区属禁止或许可，并非全国一律，须直接确认管辖设置地点的户外广告物条例。于景观法的景观地区，以及文化财、自然公园周边，处理可能更为严格。是否符合基准的判断涉及条例的解读，故于申请支援的范围内由行政书士协助。费用的参考，于[报酬额表](https://luck428.com/legal/ryokin)另行订定。

## 许可的申请对象、有效期间、更新为何？

申请对象为管辖设置地点的都道府县、政令指定都市、中核市、景观行政团体等，申请的窗口、样式、附件（位置图、设计图、意匠图、关于结构或强度的书类等）及有效期间、更新的处理，由条例订定。许可设有有效期间，期间届满后欲继续表示者，一般须更新许可，惟期间长短因条例而异。

| 确认项目 | 思路 |
| --- | --- |
| 申请对象 | 管辖设置地点的都道府县、政令市、中核市、景观行政团体等 |
| 附件 | 位置图、附近简图、意匠图、尺寸、关于结构或强度的书类等（以条例指定） |
| 有效期间 | 条例所订期间（因地区而异）。届满后继续多须更新许可 |
| 变更、除却 | 变更内容时、撤除时的申报与手续亦以条例订定 |

具体有效期间的年数与手续费的金额因条例而异，故本文不示一律数值。于设置预定地的条例、最新运用于书写前直接确认，较为确实（未确认的数值不予书写）。户外广告物表示许可的申请书类的制作、提出代行，作为向官公署提出书类的制作与手续，由行政书士支援，惟个别许可可否的最终判断由许可权者（行政厅）为之。亦请参见本所的[业务项目介绍](https://luck428.com/legal/services)。

## 设置招牌的业者所需的“户外广告业登录”是什么？

户外广告业，指进行户外广告物的表示或挂出广告物之物件的设置的营业（户外广告物法第2条第2项）。都道府县得以条例，设置要求欲营户外广告业者须受都道府县知事登录的登录制度（第9条）。该条例应订定登录的有效期间、登录的要件、业务主任者的选任、登录的撤销或营业停止等事项（第10条第1项），并以有效期间5年、各营业所选任业务主任者等为基准（第10条第2项）。以制作、设置招牌为业而承揽的广告施工业者，即为此登录的对象。

| 立场 | 可能需要的手续 |
| --- | --- |
| 挂招牌的店铺、事业者 | 户外广告物的表示许可（第4条所据条例） |
| 制作、设置招牌的广告业者 | 户外广告业的登录（第9条、第10条所据条例） |
| 登录业者的各营业所 | 业务主任者的选任（讲习会修了者、试验合格者等） |

挂招牌一方的“表示许可”与设置业者一方的“户外广告业登录”为不同手续。即便外包招牌，表示许可原则上与表示广告物者（店铺方）相关，故于进行前整理何种手续由谁承办，较不易生落差。登录申请、业务主任者相关的支援亦由行政书士承办。相关事业者各自以独立的事业体分别签约为基本，本所不向任何专业人士收取介绍费。

## 常见问题

**Q. 只标示自店名称的招牌，也需要许可吗？**
A. 视地点与大小而定。即便是标示自店名称、营业内容的自家用广告物，若位于依户外广告物法第4条所据条例的许可地区，且逾条例所订大小，即需许可。有地区以一定面积以下免许可，惟基准因地区而异，故请确认管辖设置地点的户外广告物条例。

**Q. 旗帜与店头的立看板也有规制吗？**
A. 旗帜与立看板亦可能属户外广告物（户外广告物法第2条第1项）。张贴纸、张贴札、立看板等，条例可能作为简易广告物而就表示方法与场所加以限制，违反物可能成为除却对象（第7条）。置于人行道或道路上时，尚涉及道路占用可否等另一规律，故请确认设置地点的条例与管理者的处理。

**Q. 招牌的设置委由业者，许可的手续也由业者办理吗？**
A. 未必如此。店铺方所负的“表示许可”（第4条的条例）与设置业者所负的“户外广告业登录”（第9条、第10条的条例）为不同手续。表示许可与表示广告物者相关，故于签约前整理何种手续由谁承办，较为安全。申请书类的制作、提出的支援，由行政书士以独立的事业体为之。

**Q. 未受许可而挂招牌，会如何？**
A. 就违反条例的广告物，都道府县知事等得命停止表示、设置，或定相当期限命除却及其他必要措施（户外广告物法第7条）。简易的违反物有时设有即时除却的处理。条例亦可能订有过料等罚则，故建议于设置前确认许可要否。
