**结论（先讲重点）**：持续销售酒类，须依酒税法第9条，就每一销售场，向该销售场所在地之所辖税务署长取得酒类销售业免许。于店头或传单向一般消费者・餐饮店销售者为“一般酒类小卖业免许”；以网络或型录向2个以上都道府县之消费者销售者为“通信销售酒类小卖业免许”，可经手之酒类范围不同。免许于符合酒税法第10条之人的・场所的・经营基础・供需调整要件时核发。本文以行政书士观点，整理免许种类、逐一销售场（物件）之要件、申请人与经营基础要件、费用与期间概估，以及物件、税务、通关该交给谁，属一般资讯提供。个别免许之可否由所辖税务署审查决定。

## 卖酒需要哪种免许（小卖与批发之别）？

欲经营酒类销售业者，须依酒税法第9条，就每一销售场，向所在地之所辖税务署长取得免许。未取得免许而销售酒类，将受罚则。

酒类销售业免许依销售对象大致分为下列。

| 区分 | 内容 |
| --- | --- |
| 酒类小卖业免许 | 向消费者、餐饮店（酒场・料理店等）、糕点制造业者等小卖酒类之免许 |
| 酒类批发业免许 | 向酒类制造者或销售业者批发酒类之免许 |

若仅于餐饮店向客人提供酒类饮用，原则上不需销售业免许；但若进行相当于“销售”之行为，如将未开封之酒直接外带销售，则需小卖业免许。整理“卖给谁”，是判断所需免许的起点。

## 一般酒类小卖业免许与通信销售酒类小卖业免许有何不同？

小卖之中，以店头销售为主者与通信销售者，免许有别。

| 事项 | 一般酒类小卖业免许 | 通信销售酒类小卖业免许 |
| --- | --- | --- |
| 销售方法 | 销售场之店头销售，及未满2都道府县范围（如同一都道府县内）之配送等 | 以网络・型录等，向横跨2个以上都道府县之广域消费者销售 |
| 可经手酒类 | 原则所有品目 | 国产者限课税移出数量（依品目）未满3,000千升之制造者所制造・销售之酒类，及进口酒类 |
| 主要用途 | 街边酒贩店、餐饮附设物贩等 | 地酒・进口酒之电商（网络商店） |

若欲向2个以上都道府县之消费者网络销售，仅一般酒类小卖业免许并不足够，须通信销售酒类小卖业免许。反之，以通信销售免许无法将大厂一般国产酒广域销售。依销售方式不同，应取得之免许与可经手商品亦随之改变。

## 销售场（物件）有哪些要件（逐一销售场之免许）？

免许系“就每一销售场”核发（酒税法第9条）。若有多家店铺或仓库，须就各销售场分别取得免许。作为销售场之物件，有场所的要件。

| 事项 | 主要要件 |
| --- | --- |
| 使用权原 | 就销售场物件，具自有或租赁等使用权原 |
| 场所的要件（第10条第9号） | 不与酒类制造场、其他酒类销售场、酒场・料理店等同一场所。销售场经区划为独立营业处所，可资区别 |
| 区划・设备 | 具备作为酒类销售场之实态，如代金结算设备等 |

用途地域本身对酒贩并无特有限制，惟须具建物之使用权原，及与其他营业区别之销售场区划。租赁物件宜于租赁契约中确认得用于酒类销售，以免日后重做区划。销售场・仓库物件之寻找与租赁，由别事业体四叶不动产株式会社（宅地建物交易业者）承办。

## 申请人与经营基础要件（欠税・欠格事由）为何？

酒税法第10条规定不予核发免许（拒绝要件）之情形。主要如下。

| 要件 | 内容（要旨） |
| --- | --- |
| 人的要件 | 不该当如：酒类免许曾遭撤销未经一定期间、受国税・地方税滞纳处分而在一定期间内、受罚金・禁锢以上之刑未经一定期间等 |
| 场所的要件 | 如前述，销售场不与制造场・其他销售场・酒场等同一场所 |
| 经营基础要件 | 经营基础非薄弱（申请人之资金・经验・知识、经营状态等） |
| 供需调整要件 | 不显著妨害酒类供需之均衡（进货方・销售方、销售方法之具体性等） |

因欠税将卡在人的要件，宜于申请前整备纳税状况。此外，酒类销售业者须依二十歳未満ノ者ノ飲酒ノ禁止ニ関スル法律（大正11年法律第20号）进行年龄确认，并于酒类之陈列・广告中标示（如“无法确认为20岁以上者，不销售酒类”等）。

## 至免许为止的流程与期间概估？

自申请至开始销售之流程与费用概估如下。

| 阶段 | 内容・概估 |
| --- | --- |
| 事前咨询・提出申请书 | 向销售场所在地所辖之税务署（酒类指导官）提出 |
| 标准处理期间 | 约2个月（文件提出后，税务署审查。无缺漏・补正时之概估） |
| 免许核发・登录免许税 | 核发时缴纳登录免许税（酒类小卖业免许每件3万日元；批发业免许每件9万日元） |
| 开始销售 | 领取免许通知书后，遵守记账义务・标示义务开始销售 |

免许核发后，仍有酒类销售数量等之记账，及次年度以后之报告义务。酒税・记账・决算属税理士领域。经手进口酒类时之通关手续，属通关业者・海关领域。

## 物件・税务・通关该交给谁？

酒类销售业横跨许认可・不动产・税务・通关。分工如下。

- 免许申请之要件确认・申请文件制作・代理申请 → 四叶行政书士事务所（行政书士）
- 销售场・仓库物件之寻找、使用权原・区划确认、租赁契约 → 四叶不动产株式会社（宅地建物交易业者）

## 常见问题

**Q. 我要开餐饮店，只是提供酒也需要免许吗？**
A. 若仅于店内向客人提供酒类供其饮用，原则上不需酒类销售业免许。惟若进行相当于“销售”之行为，如将未开封之酒直接外带销售，则需一般酒类小卖业免许。深夜0时以后仍提供酒类之餐饮店，另需深夜酒类提供饮食店营业之申报。

**Q. 想在网络商店向全国卖酒，是哪种免许？**
A. 欲以网络向2个以上都道府县之消费者销售，须通信销售酒类小卖业免许。惟可销售之国产酒限课税移出数量（依品目）未满3,000千升之制造者之酒类，无法将大厂一般国产酒广域销售。进口酒类则可经手。

**Q. 有欠税就不能取得免许吗？**
A. 依酒税法第10条之人的要件，如受国税・地方税滞纳处分而在一定期间内等情形，可能无法取得免许。宜于申请前整备纳税状况。个别判断由所辖税务署审查决定。

**Q. 申请后多久会核发免许？**
A. 标准处理期间约2个月。此为文件提出后、无缺漏・补正时之概估，并以补正事项之解消于期间内完成为前提。个别审查期间由所辖税务署判断。
