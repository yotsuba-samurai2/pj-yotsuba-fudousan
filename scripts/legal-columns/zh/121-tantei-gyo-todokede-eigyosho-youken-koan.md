**结论（先讲要点）：**侦探业并非许可制，而是申报制。依侦探业务适正化法（侦探业法）第4条，于开始营业的前一日前，须就各营业所向管辖该营业所所在地的公安委员会（实务上经由管辖警察署的防犯係）提出侦探业开始申报书，不收申报手续费。过去交付的侦探业申报证明书，已于2024年（令和6年）4月1日施行的修正中废止，改为在营业所揭示表明已申报的标识（第12条）。妨碍申报的欠格事由定于第3条：受破产程序开始裁定而未复权者、受拘禁刑以上之刑执行完毕等未满5年者、暴力团成员，以及法人中役员该当者等。以自己名义使他人经营侦探业的借名行为，依第5条禁止；无申报营业与借名均处6个月以下拘禁刑或30万日元以下罚金。本文为一般性信息，不就个别申报是否受理作最终判断。四叶集团的行政书士，以独立的事业体承办侦探业开始申报书的作成与向公安委员会提出的支援。调查伴随的名誉毁损、隐私侵害、违反跟踪骚扰规制法等违法与纠纷领域属律师，作为营业所的物件寻找与租赁属不同事业体的不动产业者（本公司）领域，各自分别签约。本所不向任何专业人士收取介绍费。

## 侦探业是许可制还是申报制，开始前须提出什么？

侦探业并非取得许可后才开始的“许可制”，而是在开始营业前申报的“申报制”。侦探业务适正化法（侦探业法；平成18年法律第60号，2007年〔平成19年〕6月1日施行）第4条规定，欲经营侦探业者，须于开始营业的前一日前，就各营业所向管辖该营业所所在地的公安委员会提出申报书。实务上经由管辖该营业所的警察署防犯係提出。

| 项目 | 内容（侦探业法） |
| --- | --- |
| 制度 | 申报制（非许可制） |
| 申报对象 | 管辖营业所所在地的公安委员会（经由管辖警察署防犯係） |
| 时期 | 开始营业的前一日前（第4条第1项） |
| 单位 | 各营业所 |
| 手续费 | 无 |
| 借名 | 禁止（第5条） |

此处所称“侦探业务”，指受他人委托，以收集特定人所在或行动之相关信息为目的，以面谈探询、尾行、埋伏及其他类似方法进行实地调查，并将结果向委托人报告的业务（第2条第1项）。专供报道机关报道之用而受委托者，自侦探业中排除（第2条第2项）。申报书的作成与提出支援，亦见于本所的[许认可业务介绍](https://luck428.com/zh/legal/services)。

## 侦探业申报不被受理的“欠格事由”有哪些？

侦探业法第3条规定，该当下列各款之一者，不得经营侦探业，列举欠格事由。申报前，须确认自己（法人则役员）是否该当。

| 款 | 欠格事由（第3条） |
| --- | --- |
| 第1款 | 受破产程序开始裁定而未复权者 |
| 第2款 | 受拘禁刑以上之刑，或因违反本法受罚金刑，自执行完毕等未满5年者 |
| 第3款 | 最近5年间违反第15条处分（营业停止、废止命令）者 |
| 第4款 | 暴力团成员，或脱离暴力团未满5年者 |
| 第5款 | 因身心故障无法适正执行侦探业务，经内阁府令所定者 |
| 第6款 | 就营业不具与成年人同等能力的未成年人，其法定代理人该当第1至5款或第7款者 |
| 第7款 | 役员中有该当第1至5款之任一者的法人 |

2022年（令和4年）刑法等修正将惩役、禁锢统合为“拘禁刑”，并自2025年（令和7年）6月1日施行，故条文亦表述为“拘禁刑以上之刑”。是否该当欠格事由的最终评价属公安委员会领域，行政书士不代为保证受理。

## 营业所或自宅开业有哪些要件与揭示义务？

侦探业法并无如餐饮店营业般的建物构造、设备基准，但课予各营业所申报义务，以及揭示表明已申报之标识的义务。过去的侦探业申报证明书，已于2024年（令和6年）4月1日施行的修正（申报手续的检讨）中废止，改为由事业者自行作成标识并揭示于营业所明显处的方式（第12条）。

| 区分 | 内容 |
| --- | --- |
| 营业所 | 须就各营业所申报；亦可以自宅为营业所（管辖依营业所所在地） |
| 标识 | 于明显处揭示表明已申报的标识（旧证明书已废止） |
| 从业者名簿 | 就各营业所备置（第12条） |
| 教育 | 使从业者适正执行侦探业务的教育（第11条） |

标识须记载受理申报的公安委员会名称、申报书的受理编号、申报年月日、商号、名称、姓名、营业所的名称与所在地等。样式与记载要领由各都道府县警察公布，作成前须于管辖的官方页面确认最新内容。租用物件开业时，物件寻找与租赁契约属不同事业体的不动产业者（本公司）领域，亦可利用本公司的[不动产咨询窗口](https://luck428.com/zh/souzoku)。承办的进行方式请见[受任流程](https://luck428.com/zh/legal/nagare)。

## 重要事项说明书、契约书面对侦探业者课予哪些义务？

侦探业者与委托人缔约时，被课予缔约前书面交付与缔约后书面交付两者的义务（第8条）。此外，须自委托人取得表明不将调查结果用于犯罪、歧视等违法目的之书面（第7条）。

| 场面 | 根据 | 主要记载事项 |
| --- | --- | --- |
| 缔约前（重要事项说明） | 第8条第1项 | 商号、住所、受理申报的公安委员会名称、守密事项、业务内容、有无委托、对价概算额与支付时期、契约解除、资料处分 |
| 缔约后（明示契约内容） | 第8条第2项 | 承办人姓名与缔约年月日、调查之内容、期间、方法、报告之方法、期限、对价之额、支付时期、方法、解除与资料处分之约定 |
| 委托人之书面 | 第7条 | 确认不将结果用于违法目的 |

执行侦探业务时，不得有害人之生活平稳等侵害个人权利利益之情形，且其他法令禁止、限制之行为，不因本法而获解除（第6条）。又，将侦探业务之全部、一部委托予非侦探业者，系遭禁止；且于知悉结果将用于违法行为时，不得执行该业务（第9条）。费用概估另定于本所的[报酬额表](https://luck428.com/zh/legal/ryokin)。

## 怠于申报、借名会有哪些罚则与风险？

未申报即经营侦探业（无申报营业），以及以自己名义使他人经营侦探业（借名），均设有罚则。借名于第5条明文禁止，无申报营业与借名均处6个月以下拘禁刑或30万日元以下罚金（第18条）。

| 行为 | 根据 | 罚则 |
| --- | --- | --- |
| 无申报经营侦探业 | 违反第4条第1项 | 6个月以下拘禁刑或30万日元以下罚金（第18条） |
| 借名 | 违反第5条 | 6个月以下拘禁刑或30万日元以下罚金（第18条） |
| 违反业务执行规制、虚伪申报等 | 各规定 | 得成为营业停止、废止命令（第15条）或罚则对象 |

怠于确认欠格事由即申报，日后可能成为处分对象。与古物商许可等其他营业并行时，因根据法与监督官厅不同，须分别确认。古物商整理于[古物商许可的营业所要件](https://luck428.com/zh/legal/column/kobutsusho-kyoka-eigyosho-yoken)，警备业整理于[警备业认定的要件、欠格、教育](https://luck428.com/zh/legal/column/keibigyo-nintei-yoken-kekkaku-kenshu)。警备业为“认定”、侦探业为“申报”，是制度上的一大差异。

## 调查将逾越合法范围时，应转介给谁？

即使已完成侦探业申报，尾行、埋伏、探询若过度，仍可能触及跟踪骚扰规制法、名誉毁损、隐私侵害等。此属违法、纠纷领域，非行政书士承办范围。相关专业人士以各自独立的事业体分别签约为基本。

| 委托对象 | 主要角色 |
| --- | --- |
| 行政书士（本所） | 侦探业开始申报书的作成与向公安委员会提出的支援、欠格事由确认的整理 |
| 律师 | 违反跟踪骚扰规制法、名誉毁损、隐私侵害等违法、纠纷的对应，法律效果的最终判断 |
| 不动产业者（不同事业体的本公司） | 作为营业所的物件寻找与租赁契约 |
| 公安委员会、警察署 | 申报的受理，标识、名簿等的指导 |

尾行、埋伏等可能逾越合法范围的业务，以及委托本身疑为违法目的的调查，本所不予承办。本所与各专业人士以独立的事业体签约，相互不收取介绍费。个别受理可否或合法性的最终判断，由资格者、公安委员会于面谈后进行。

## 常见问题

**Q. 侦探业是取得许可后才开始吗？**
A. 不是。侦探业并非许可制，而是申报制。依侦探业法第4条，于开始营业的前一日前，须就各营业所向管辖其所在地的公安委员会（经由管辖警察署防犯係）提出申报书，不收申报手续费。这并非等待许可审查的制度，但不该当欠格事由、履行书面交付等义务仍为前提。

**Q. 可以用自宅作为营业所开业吗？**
A. 须就各营业所申报，惟以自宅为营业所本身是可行的。管辖依营业所所在地而定。须在营业所明显处揭示表明已申报的标识，并备置从业者名簿（第12条）。过去的侦探业申报证明书已于2024年（令和6年）4月1日施行的修正中废止，改为揭示标识。

**Q. 未申报即开始侦探业会如何？**
A. 未申报即经营侦探业者，处6个月以下拘禁刑或30万日元以下罚金（第18条）。以自己名义使他人经营的借名，亦依第5条禁止，处相同罚则。申报须于开始营业的前一日前完成。

**Q. 行政书士能承办到什么程度？**
A. 行政书士以独立的事业体承办侦探业开始申报书的作成、向公安委员会提出的支援，以及欠格事由确认的整理。尾行、埋伏过度时的违反跟踪骚扰规制法、名誉毁损、隐私侵害等违法、纠纷的对应属律师，营业所的物件与租赁属不同事业体的不动产业者领域，各自分别签约。
