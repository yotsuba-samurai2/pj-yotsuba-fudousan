**先讲重点：** 要以事业经营宠物店、宠物美容、宠物旅馆、训练教室等，开始营业前须向管辖事业所所在地的都道府县知事（设有保健所的政令指定都市、中核市等为市长）取得「第一种动物取扱业」的登录。依据为动物之爱护及管理相关法律（昭和48年10月1日法律第105号）第10条第1项。登录须就各事业所、各业种选任动物取扱责任者（同法第22条），并使饲养设施符合基准。本文为整理登录要件与流程的一般性资讯提供，登录与否由具登录权的地方政府判断，本事务所不予保证。

## 第一种动物取扱业是什么？哪些业种是登录的对象？

动物之爱护及管理相关法律（下称「动物爱护管理法」）第10条第1项规定，凡以营利为目的、反复并持续地经营动物（哺乳类、鸟类、爬虫类，但不含畜产农业用、试验研究用、生物制剂制造用者）之取扱者，须取得都道府县知事等的登录。这即是第一种动物取扱业。它与无偿经营多数动物的「第二种动物取扱业」（申报制）为不同制度，以是否具有反复持续的营利性作切分。

登录的对象业种有下列7种。即使同一店铺，也须就各项行为特定业种登录。例如兼营销售与美容（保管），则两业种都须登录。

| 业种 | 主要例子 |
| --- | --- |
| 销售 | 宠物店、繁殖业者（含以销售为目的的繁殖、输入） |
| 保管 | 宠物旅馆、宠物美容（保管顾客动物者）、宠物保姆 |
| 出借 | 为摄影、活动或出租而出借动物之业 |
| 训练 | 训练教室、到府训练、寄养训练 |
| 展示 | 动物咖啡厅、互动设施、移动动物园 |
| 竞卖仲介 | 动物拍卖（竞卖）的仲介 |
| 受让饲养 | 有偿受让动物并饲养，如高龄犬猫之家等 |

美容因在施术期间保管顾客的动物，多半属于「保管」。仅处理自己饲养的动物，或无偿赠与友人，通常不属反复持续的营利；但是否该当的最终判断，须向开业地的地方政府出示欲经营之内容后确认。

## 要成为动物取扱责任者，需要什么资格或实务经验？

动物爱护管理法第22条要求第一种动物取扱业者，就各事业所选任为适正实施业务的「动物取扱责任者」。责任者须自专属该事业所的常勤职员中选任。若开设者本人符合要件，本人亦可兼任责任者。

可担任责任者的要件，于令和2年（2020年）6月1日施行的修正中趋于严格。动物爱护管理法施行规则所定的现行要件，须满足下列其一。仅有资格，或仅有经验，皆不足够；系将「实务经验」与「资格或学历」组合要求的形式。

| 途径 | 应满足的要件 |
| --- | --- |
| 依资格 | 持有兽医师免许者 |
| 依资格 | 持有爱玩动物看护师免许者 |
| 经验＋资格、学历 | 具欲经营业种相关半年以上的实务经验（限以常勤职员在职）等，且已通过所定资格考试，或毕业于教学1年以上的学校等教育机关 |

代替实务经验，就欲处理的动物种类，「认定为同等的1年以上饲养从事经验」亦被接受；惟不含个人兴趣的饲育，何谓「同等」为地方政府的裁量判断，须事前个别协议。此外，责任者不得该当动物爱护管理法第12条第1项各款的欠格事由（如受拘禁刑以上之刑或违反动物相关法令之罚金刑未经一定期间等）。选任后，负有使责任者每年至少1次接受动物取扱责任者研修的义务（同法第22条）。

## 设施基准（笼子、照明、隔音等）要求到什么程度？

关于饲养设施的构造、规模，于令和3年（2021年）6月1日施行的修正中，分阶段导入了所谓的数值规制。动物爱护管理法施行规则的修正，就笼子等的大小、寝床与运动空间的确保、地板墙壁的材质、采光、换气、隔音，以及污物污水的处理等，订定了具体基准。

| 项目 | 主要内容 |
| --- | --- |
| 笼子等的大小 | 就犬、猫，以体长、体高为基准的最小面积、高度的数值基准 |
| 运动空间 | 寝床、休息场所与运动空间分开设置或一体设置，基准不同 |
| 每名员工的饲养头数上限 | 犬每人20头（其中繁殖犬15头）、猫每人30头（其中繁殖猫25头）为上限 |
| 繁殖的限制 | 用于犬、猫繁殖的年龄与一生分娩次数的上限 |
| 环境的管理 | 温湿度管理、亮度确保、臭气与害虫的防止等 |

每名员工饲养头数上限等，就修正时已在营业的既有业者设有经过措施，第一种动物取扱业于令和6年（2024年）6月1日完全施行。笼子的具体尺寸与适用细节，依施行规则、告示与地方政府的运用而定，故数值当否请以开业地地方政府的手册确认。此处不断定全国一律的尺寸值。

## 从申请到开始营业，依什么顺序进行？

登录的流程为：备妥申请书与附件向地方政府窗口提出，经饲养设施的现地检查后，取得登录证。可开始营业者为取得登录之后，店头须揭示标识、从业者须佩戴名牌。登录的有效期间为5年，须每5年更新（动物爱护管理法第13条）。

| 阶段 | 主要内容 |
| --- | --- |
| 事前咨询 | 携带业种、设施图面，向地方政府咨询能否符合基准 |
| 提出申请书 | 第一种动物取扱业登录申请书（各业种、各事业所） |
| 主要附件 | 证明责任者资格、实务经验的文件、饲养设施平面图与附近见取图、事业计划、法人的登记事项证明书等 |
| 现地检查 | 确认饲养设施是否符合基准 |
| 登录、交付 | 录入登录簿、交付登录证、揭示标识与名牌 |
| 更新 | 有效期间5年；期间届满前申请更新 |

申请手续费、格式与必要文件的细部，因地方政府而异。标准处理期间亦不同，故从开业预定日回推、先从事前咨询开始较为安全。

## 物件选择与登录，由谁、依什么顺序处理？

若先签订物件契约，可能日后才发现饲养设施无法符合基准，或用途地域、建物管理规约不允许动物取扱业。安全的顺序为：①物件现勘与用途确认 → ②确认设施能否符合基准、向地方政府事前咨询 → ③签约 → ④内装与设备工程 → ⑤登录申请 → ⑥现地检查 → ⑦登录、开始营业。物件方需要哪些条件，于[可供动物取扱业使用的物件条件](https://luck428.com/column/doubutsu-toriatsukai-bukken-youken)（不动产）整理。

- 第一种动物取扱业登录申请的制作，以及与地方政府事前咨询的支援 → 四叶行政书士事务所（行政书士）
- 事业用物件的选定、租赁、重要事项说明，及用途地域、管理规约的确认 → 四叶不动产株式会社
- 内装达大规模用途变更时的确认申请 → 建筑士、特定行政厅
- 开业后从业员的劳动条件、社会保险、工作规则 → 四叶社会保险劳务士事务所（社会保险劳务士）
- 会计、税务 → 税理士
- 涉及权利义务与纷争的个别法律判断 → 律师

四叶行政书士事务所与四叶不动产株式会社为不同的事业体。本事务所仅以独立的事业体承办第一种动物取扱业登录申请的支援，物件、劳务、税务请与各专业人士、事业体分别签约、咨询。本事务所不收取介绍费。许可的整体样貌请见[行政许可手续](https://luck428.com/legal/services)，受任流程请见[受任流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)。登录与否本身由地方政府判断。

## 常见问题

**Q. 我要自己开宠物美容店。需要动物取扱业的登录吗？**
A. 施术期间通常会保管顾客的动物，该情形属于「保管」业种，须取得第一种动物取扱业的登录（动物爱护管理法第10条第1项）。若兼营销售，另加「销售」业种登录。是否该当的最终判断，请向开业地的地方政府出示欲经营之内容后确认。

**Q. 只要在宠物店经验够久，就能当动物取扱责任者吗？**
A. 仅有经验并不足够。令和2年6月1日施行的修正后，须持有兽医师、爱玩动物看护师的资格，或将半年以上实务经验与通过所定资格考试或毕业于1年以上教育机关组合（动物爱护管理法施行规则）。要件如何适用请向地方政府确认。

**Q. 登录一旦取得，就永久有效吗？**
A. 不是。登录的有效期间为5年，须每5年更新（动物爱护管理法第13条）。若未更新而过期，登录即失效。更新受理的开始时期因地方政府而异，请于有效期间届满前及早办理。

**Q. 先租物件，之后再开始准备登录可以吗？**
A. 不建议。若租到饲养设施无法符合基准，或用途地域、管理规约不允许动物取扱业的物件，往往须重做内装或契约。先进行物件现勘与用途确认、以及设施能否符合基准的确认，于签约前建立见通，较为安全。
