**结论（先讲要点）：**应他人请求并收取报酬、以建筑物的设计或工程监理为业者，原则上须依《建筑士法》第23条，就建筑士事务所向都道府县知事办理登记。这与承揽建设工程所需的建设业许可（建设业法）是不同制度。登记有效期间自登记之日起算5年，期满后欲继续者须办理更新登记（同条第2项、第3项）。各建筑士事务所须配置专任的管理建筑士（第24条第1项）；可担任管理建筑士者，须为以建筑士身分从事设计或国土交通省令所定其他业务3年以上后、修毕登录讲习机关举办的管理建筑士讲习者（同条第2项）。事务所所属建筑士另须受定期讲习（第22条之2）。本文为一般性信息，不就个别事务所是否符合登记或管理建筑士要件作出判断或保证。登记、变更申报文件的制作与提出支援，由四叶集团的行政书士以独立的事业体承办；设计、工程监理、建筑确认申请的业务本身属建筑士的独占业务；事务所物件的租赁与重要事项说明由属不同事业体的不动产业者负责；公司设立、董事变更的登记由司法书士办理；社会保险与劳务由社会保险劳务士负责；税务由税理士负责。各自分别签约。

## 建筑士事务所的「登记」与建设业许可有何不同？

出发点在于「以什么为业」。《建筑士法》第23条第1项规定，一级建筑士、二级建筑士或木造建筑士，或雇用此等人员者，欲应他人请求并收取报酬、以设计或工程监理等为业时，须定明建筑士事务所并取得都道府县知事的登记。亦即，这是着眼于「反复持续、收取报酬从事设计与监理」的登记。另一方面，建设业许可（建设业法第3条）则着眼于「承揽建设工程」，属不同制度，于承揽单件请负金额达一定金额（建筑一式工程为1,500万日元，其他工程为500万日元，均含税）以上的工程时才需要。

| 项目 | 建筑士事务所登记 | 建设业许可 |
| --- | --- | --- |
| 依据法律 | 建筑士法第23条 | 建设业法第3条 |
| 着眼点 | 收取报酬、以设计与工程监理等为业 | 以承揽建设工程为业 |
| 需要的场合 | 应他人请求、收取报酬反复持续从事设计等时 | 承揽单件请负金额达一定金额（建筑一式1,500万／其他500万・均含税）以上的工程时 |
| 登记、许可对象 | 都道府县知事 | 国土交通大臣或都道府县知事 |
| 有效期间 | 5年（须办更新登记） | 5年（须更新） |

仅开设设计事务所并不需要建设业许可，但若自行承揽工程，则两者可能同时相关。建设业许可本身的要件论点不同，另请参阅[建设业许可的要件（经营业务管理责任者、专任技术者、财产基础）](https://luck428.com/legal/column/kensetsugyo-kyoka-yoken-keikan-sengi-zaisan)。若涉及电气工程，[电气工程业的登记、拟制登记与通知](https://luck428.com/legal/column/denki-koji-gyo-touroku-eigyosho-shunin)又是另一套手续。究属哪一制度须依事业内容而定，故在计划早期即向主管的都道府县（指定事务所登记机关）确认，不可或缺。

## 管理建筑士需要哪些要件（专任、修毕讲习）？

《建筑士法》第24条第1项要求建筑士事务所的开设者，就各一级、二级、木造建筑士事务所，配置管理该事务所的专任一级、二级或木造建筑士（管理建筑士）。管理建筑士是登记的前提，欠缺者即无法取得登记（第23条之4的登记拒否事由）。

可担任管理建筑士者的要件规定于第24条第2项：须为以建筑士身分从事设计或国土交通省令所定其他业务3年以上后，修毕登录讲习机关举办的管理建筑士讲习课程的建筑士。

| 项目 | 内容（依据） |
| --- | --- |
| 配置义务 | 各事务所须配置专任的管理建筑士（第24条第1项） |
| 资格 | 以建筑士身分从事设计或省令所定其他业务3年以上（第24条第2项） |
| 讲习 | 于上述之后修毕登录讲习机关的管理建筑士讲习（第24条第2项） |
| 专任的意涵 | 常驻于该事务所并专责其管理；原则上不允许兼任他事务所或非常勤 |

须留意的是，管理建筑士讲习是「成为管理建筑士的讲习」，与后述的定期讲习（第22条之2）为不同事物。实务年数与业务内容是否符合要件，属《建筑士法》上的判断，行政书士不得以独占业务代为判定。仅出借名义而未实际常驻的「借牌」管理建筑士，将成为登记拒否或登记撤销的对象。

## 登记的有效期间、更新、变更申报，何时提出什么？

登记的有效期间自登记之日起算为5年（建筑士法第23条第2项）。有效期间届满后仍欲继续经营建筑士事务所者，须办理更新登记（同条第3项）。若疏忽更新致有效期间届满，登记即失效，不得在无登记状态下继续从事设计等业务。

| 手续 | 内容（依据・运用） |
| --- | --- |
| 登记有效期间 | 5年（第23条第2项） |
| 更新登记 | 期满后欲继续者须办理（第23条第3项）；多数都道府县要求于届满约30日前申请 |
| 登记事项变更申报 | 名称、所在地、管理建筑士、所属建筑士等有变更时 |
| 废业等申报 | 废止或停业建筑士事务所时 |

登记的申请手续规定于第23条之2（申请书记载事项）、第23条之3（登记的实施）。更新的申请时期与变更申报的期限、样式，因都道府县（指定事务所登记机关）而运用各异，故管理届满日、一旦发生变更即迅速申报，是实务的要点。「在别县是这种格式」未必能直接适用，也是申请实务常见的问题。

## 事务所的实态（专用性、设备）要求到什么程度？

登记并非「备齐文件即足」，而以具备事务所的实态为前提。尤其会审视专任的管理建筑士是否实际常驻并管理该事务所。未配置管理建筑士，或仅具名义而欠缺实态，构成违反《建筑士法》第24条第1项，成为登记拒否（第23条之4）或登记撤销（第26条）的理由。实务上亦有都道府县以未配置管理建筑士为由撤销登记的处分案例。

| 受审视之点 | 具体例 |
| --- | --- |
| 管理建筑士的常驻、专任 | 常驻于该事务所、未兼任他事务所 |
| 事务所的实态 | 从事业务的独立空间；设计图书的保存与业务记录 |
| 非借牌 | 管理建筑士与所属建筑士确实存在并实际参与业务 |

关于设备与图书保存的具体运用（应备文件、保存年限、报告书提出等），由《建筑士法》、国土交通省令与各都道府县手册所定，品项与样式的细部由主管窗口判断。开业前先向管辖的都道府县（指定事务所登记机关）事前咨询，较易避免提出前夕的退件。

## 登记（行政书士）与设计监理（建筑士）、登记（司法书士）如何划分？

由于相关专业人员分属不同领域，原则上请与各方以独立的事业体分别签约。四叶集团的行政书士，以独立的事业体承办建筑士事务所登记、更新、变更申报的申请文件制作辅助，以及向主管都道府县（指定事务所登记机关）事前咨询的引导。

| 委托对象 | 主要角色 |
| --- | --- |
| 行政书士（本事务所） | 建筑士事务所登记、更新、变更申报的申请支援；建设业许可申请支援（别论点） |
| 建筑士 | 设计、工程监理、建筑确认申请等建筑士独占业务本身 |
| 司法书士 | 公司设立、董事变更等商业登记 |
| 不动产业者（属不同事业体的本公司） | 事务所物件的选定、租赁中介、重要事项说明 |
| 社会保险劳务士 | 员工的社会保险与劳务手续 |
| 税理士 | 开业后税务 |

亦请参阅本事务所的[承办业务](https://luck428.com/legal/services)、[受任流程](https://luck428.com/legal/nagare)与[报酬额表](https://luck428.com/legal/ryokin)。与各专业人员均以独立的事业体签约，彼此不收取介绍费。登记终究只是以设计与监理为业的入口，设计与监理内容本身的判断由建筑士为之。

## 常见问题

**Q. 即使我独自在家做设计，也需要建筑士事务所登记吗？**
A. 若应他人请求、收取报酬、以设计与工程监理等为业（反复持续）者，不论规模均须办理建筑士事务所登记（建筑士法第23条）。即使仅一人，该人也须符合专任管理建筑士的要件（以建筑士身分具3年以上实务＋修毕管理建筑士讲习）。是否具备事务所的实态亦会受审视。

**Q. 只要持有建设业许可，就不需要建筑士事务所登记吗？**
A. 两者为不同制度，即使持有建设业许可，若以设计与监理为业，仍须另行办理建筑士事务所登记。建设业许可是承揽建设工程（如建筑一式1,500万、其他500万，均含税以上等）所需，并不涵盖以设计与监理为业。应依所从事业务的内容判断。

**Q. 管理建筑士的定期讲习与管理建筑士讲习是同一件事吗？**
A. 是不同的。管理建筑士讲习是为成为管理建筑士、于实务之后修毕的讲习（第24条第2项）。定期讲习则是所属建筑士事务所的一级、二级、木造建筑士持续受讲的讲习；依建筑士法第22条之2，须每隔国土交通省令所定期间（法律上为3年以上5年以内的范围，施行规则定为每3年度）受讲。

**Q. 忘记更新、有效期间届满会怎样？**
A. 登记有效期间为5年，欲继续者须办理更新登记（建筑士法第23条第2项、第3项）。若疏忽更新，登记即失效，不得在无登记状态下继续从事设计等业务。多数都道府县要求于届满约30日前申请。管理届满日并预留时间办理，至为重要。
