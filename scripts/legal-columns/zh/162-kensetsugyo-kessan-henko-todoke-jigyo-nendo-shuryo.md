**结论（先讲重点）**：取得建筑业许可的业者，每一事业年度结束时，都有提交「决算变更申报（事业年度终了申报）」的义务。依据是建设业法第11条第2项，期限为每一事业年度经过后四个月内。这不是可按申请人方便而省略的手续，即使是没有工程实绩的年度或停业中也必须提交。若漏报，在五年一次的许可更新或业种追加（一般・特定新规等）时，必须将未提交的部分一并补交，否则不予受理；而虚伪记载或长期未提交，可能成为监督处分或罚则的对象。此外，商号、营业所、资本额、董事等的变更须于变更日起30日内申报（建设业法第11条第1项），经营业务的管理负责人或专任技术者更替时则须于两周内（同条第4项、第5项），期限因手续而异，须留意。本文为一般性信息提供，并不判断或保证个别的提交必要性或处分有无。决算变更申报的文件制作与提交由四叶集团的行政书士以独立的事业主体承担，所附财务报表底稿的税务申报与决算书制作由税理士、董事变更・商号变更・本店迁移等登记由司法书士，各自作为**独立的事业体**、以独立合同分别签约的分离受任方式对应。

## 决算变更申报（事业年度终了申报）要提交什么、何时提交？

决算变更申报是许可业者依建设业法第11条第2项，于每一事业年度经过后四个月内提交的申报。也称为「事业年度终了申报」「决算报告」，指的都是同一件事。例如3月结算的法人目标为7月底、12月结算的个人为次年4月底，末日遇到行政厅休息日时的处理方式，请向提交对象确认。

主要提交的文件，是显示该事业年度的工程实绩与决算内容者。内容会因许可行政厅（国土交通大臣许可或都道府县知事许可）及法人・个人之别而不同，因此以提交对象的手引确认最新样式为前提。

| 主要文件 | 内容 |
| --- | --- |
| 工程经历书 | 该事业年度承揽的工程实绩（承揽金额・工期等） |
| 前三年各事业年度的工程施工金额 | 按业种别・元请／下请别的施工金额 |
| 财务报表（建筑业用） | 资产负债表・损益表等，依建设业法施行规则所定样式 |
| 事业报告书 | 股份有限公司时需要 |
| 纳税证明书等 | 事业税等，由行政厅所定 |

即使是没有工程实绩的年度，也须以「无实绩」提交；停业中只要维持许可，申报义务仍存续。另请参阅本所的[承办业务](https://luck428.com/legal/services)・[受任流程](https://luck428.com/legal/nagare)・[报酬额表](https://luck428.com/legal/ryokin)。

## 不提交会对更新与业种追加造成什么影响？

决算变更申报与其说是独立完结的手续，不如说是五年一次许可更新，以及业种追加・一般特定新规等下一次申请的基础文件。受理更新或追加的行政厅，以过去各事业年度的决算变更申报皆已齐备为前提。若有未提交的年度，会先被要求补交该部分；累积起来后，便须在更新时机一口气制作，产生赶不上期限的风险。

| 场面 | 决算变更申报未提交时会如何 |
| --- | --- |
| 五年一次许可更新 | 不补交未提交的事业年度分，更新申请不予受理 |
| 业种追加・一般特定新规 | 同样以前一次决算变更申报齐备为前提 |
| 经营事项审查（公共工程投标） | 以提交决算变更申报为前提，未提交则无法进入经审 |
| 虚伪记载・长期未提交 | 可能成为建设业法上的监督处分（指示・营业停止等）或罚则的对象 |

参与公共工程投标的业者，以每年的决算变更申报为基础，进入经营事项审查（经审）。此流程于[公共工程投标的经营事项审查（经审）要点](https://luck428.com/legal/column/keiei-jiko-shinsa-keishin-nyusatsu-sankaku-shikaku)整理。更新与业种追加所问的经营业务管理负责人・专任技术者・财产基础等取得时要件，于[建设业许可的要件（经管・专技・财产基础）全貌](https://luck428.com/legal/column/kensetsugyo-kyoka-yoken-keikan-sengi-zaisan)说明。

## 建设业法上的财务报表与税务决算书有何不同？

决算变更申报所附的财务报表，与向税务署提交的确定申报决算书，在样式与会计科目上都不同。税务决算书依会计・税法规则制作，而建设业法的财务报表须依建设业法施行规则所定样式，改组为「完成工程高」「完成工程原价」「未成工程支出金」「工程应付款」等建筑业特有的会计科目。

| 区分 | 税务决算书 | 建设业法的财务报表 |
| --- | --- | --- |
| 依据 | 法人税法・所得税法等 | 建设业法・同施行规则的样式 |
| 制作的专业人士 | 税理士（税务申报的一环） | 行政书士改组为样式制作（本所） |
| 会计科目 | 一般的销售・进货等 | 完成工程高・完成工程原价・未成工程支出金等 |
| 提交对象 | 税务署 | 建筑业的许可行政厅 |

这里就是分离受任的界线。底稿决算书的制作与税务申报是税理士的独占领域，四叶集团的税理士以独立的事业主体承担。将该决算书改组为建筑业用样式，连同工程经历书等一并作为决算变更申报制作・提交的部分，则由行政书士承担。税额与会计处理本身的判断由税理士进行，行政书士不涉入税务判断。与各专业人士分别签约，相互间不收取介绍费。

## 董事・商号・营业所变更时，变更申报的期限为何？

与决算变更申报不同，当许可申请书上记载的事项有变更时，须提交「变更申报」。期限按变更种类而分。建设业法第11条第1项规定，商号・名称、营业所的名称・所在地、资本额、董事等姓名等（对应建设业法第5条第1号至第4号的事项）有变更时，须于变更日起30日内申报。

另一方面，经营业务的管理负责人，或各营业所的专任技术者更替・退任时，须于两周内申报（建设业法第11条第4项・第5项）。由于经营业务的管理负责人与专任技术者正是许可要件本身，为避免产生空窗，设有更短的期限。

| 变更内容 | 申报期限 | 依据 |
| --- | --- | --- |
| 商号・名称、营业所名称・所在地、资本额、董事等 | 变更日起30日内 | 建设业法第11条第1项 |
| 经营业务管理负责人・专任技术者的更替・退任等 | 变更日起两周内 | 建设业法第11条第4项・第5项 |
| 各事业年度的决算（决算变更申报） | 每一事业年度经过后四个月内 | 建设业法第11条第2项 |

须留意的是，公司登记上的变更（董事变更・商号变更・本店迁移等）与建筑业许可的变更申报是分别的手续。登记由司法书士以独立的事业主体承担，行政书士再依据该登记承担建筑业许可的变更申报。只做其中一边并不足够。

## 为了跑好每年的申报，该请谁做什么？

建筑业许可的维持，关键在于不漏掉一年一次的决算变更申报与随时发生的变更申报。由于涉及的专业人士各异，以各自作为独立的事业主体分别签约为基本。四叶集团的行政书士，以独立的事业主体承担向许可行政厅提交决算变更申报・各种变更申报・更新・业种追加等手续。

| 委托对象 | 主要角色 |
| --- | --- |
| 行政书士（本所） | 决算变更申报・变更申报・许可更新・业种追加・经审的申请文件制作与提交 |
| 税理士 | 决算书制作・法人税／所得税・消费税申报（财务报表的底稿） |
| 司法书士 | 董事变更・商号变更・本店迁移等登记 |
| 不动产业者（别事业体的本公司） | 本店・营业所用物件的选定・租赁媒介・重要事项说明 |

在营业所迁移或新设而须寻找物件的场面，由别事业体的四叶不动产股份有限公司以独立的事业主体承担物件选定与租赁媒介。税务・登记・不动产各为独立的事业体，相互间不收取介绍费。以一个窗口受理咨询，整理必要手续后，由各有资格者分别签约对应。

## 常见问题

**Q. 没有工程实绩的年度也需要决算变更申报吗？**
A. 需要。决算变更申报（事业年度终了申报）只要维持许可，就有在每一事业年度经过后四个月内提交的义务（建设业法第11条第2项）；没有工程实绩的年度以「无实绩」提交，停业中只要持有许可也须提交。若漏报，便须在更新或业种追加时一并制作，有赶不上期限之虞。个别必要性请向许可行政厅的手引确认。

**Q. 我累积了好几年的决算变更申报没交。许可会被撤销吗？**
A. 未提交未必立即导致撤销，但虚伪记载或长期未提交，可能成为建设业法上监督处分或罚则的对象。实务上，会被要求在更新或业种追加前，将未提交部分一并补交。要整理几年份、如何整理因情况而异，请尽早向许可行政厅与承担文件制作的行政书士咨询。

**Q. 只要委托税理士做决算，决算变更申报也会帮我交吗？**
A. 是不同的手续。税理士制作的是税务申报用的决算书，但决算变更申报所附的财务报表，须依建设业法施行规则的样式改组为完成工程高等会计科目，连同工程经历书等一并向许可行政厅提交。此部分由行政书士以独立的事业主体承担，税务判断由税理士进行。两者分别签约。

**Q. 董事变更时，须于何时申报什么？**
A. 董事等的变更须于变更日起30日内提交变更申报（建设业法第11条第1项）。此外，若该董事原为经营业务的管理负责人等，须于两周内办理后任的相关申报（同条第4项・第5项）。公司的董事变更登记由司法书士、建筑业许可的变更申报由行政书士，分别签约推进。
