**结论（先讲要点）：**在留资格「经营・管理」因令和7年（2025年）10月16日施行的上陆基准省令修正而将基准提高。主要变更为资本金・出资总额3,000万日元以上、雇用常勤职员1人以上、申请者或常勤职员任一方的日语能力（能高度自立地理解与使用日语的水准＝CEFR的B2相当以上）、3年以上经营经验或相关领域的学位，以及事业计划书经中小企业诊断士、公认会计师、税理士等专家确认。对已以「经营・管理」在留者，设有自施行日起满3年、即至令和10年（2028年）10月16日的过渡措施，不以仅未达新基准为由不许可更新。依据为《出入国管理及难民认定法》别表第一之二「经营・管理」，以及同法第七条第一项第二号基准省令。本文为一般性信息，不就个别申请能否获准作出判断或保证。申请文件的制作与申请取次由四叶集团的行政书士（申请取次行政书士・行政书士法第1条之3）以独立的事业体承办；公司设立・董事变更等登记由司法书士办理；资本金・税务由税理士负责；员工的社会保险・雇用保险由社会保险劳务士负责；作为事业所的物件由属不同事业体的不动产负责。各自分别签约。

## 经营・管理签证在2025年10月有何变更？

在留资格「经营・管理」对应《出入国管理及难民认定法》别表第一之二所列「在本邦经营贸易或其他事业，或从事该事业之管理的活动」。此在留资格所要求的基准，置于同法第七条第一项第二号基准省令（上陆基准省令），而令和7年（2025年）10月16日施行的修正省令提高了其内容。出入国在留管理厅亦于同日发布含在线申请输入方式与所属机关类别处理在内的指引。

从前的水准为资本金・出资总额500万日元以上（或常勤职员2人以上），修法后金额大幅提高，并加入日语能力、经营经验、事业计划书专家确认等定性要件。新设创业而申请者，直接适用修法后的基准。含公司设立・事业所确保的新规申请全貌，整理于[中国、台湾的创业者如何取得「经营・管理」在留资格](https://luck428.com/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)；更新时所问的事业继续性，整理于[经营・管理签证更新所问的「事业继续性・实体」之立证](https://luck428.com/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)。本文聚焦于2025年10月修法的新基准与过渡措施此一时点依存的论点。

| 项目 | 修法前的目安 | 修法后（令和7年10月16日施行） |
| --- | --- | --- |
| 资本金・出资总额 | 500万日元以上（或常勤职员2人以上） | 3,000万日元以上 |
| 常勤职员 | 作为替代要件有2人以上的选项 | 要件化雇用1人以上 |
| 日语能力 | 无明文基准 | 申请者或常勤职员任一方达CEFR的B2相当以上 |
| 经营经验・学位 | 无明文基准 | 3年以上经营经验或相关领域的学位 |
| 事业计划书 | 提出 | 经中小企业诊断士・公认会计师・税理士等确认 |

## 资本金3,000万日元要件与常勤职员要件如何判断？

资本金・出资总额以公司登记与出资的实体确认。前提为能说明其为供事业之用的财产，而非虚充资金，有时会被要求提出显示资金来源的资料。仅整备票面而欠缺实体的型态，从修法宗旨亦属消极。资本金的缴纳・增资登记为司法书士的领域，税务上的处理为税理士的领域。

常勤职员在修法中被定位为「雇用1人以上」的要件。可雇用者的范围、「常勤」的判断、所定劳动时间与社会保险的适用等，须自出入国在留管理厅的指引与劳动、社会保险的实务两面确认。常勤职员的社会保险・雇用保险适用手续由社会保险劳务士承办。人数的计算方式、可将何种在留资格者计入常勤职员等细部，请务必以指引本文确认。本文不就无法裏取的个别计入与否深入论断。

| 要件 | 主要确认要点 | 主要相关专业 |
| --- | --- | --- |
| 资本金・出资总额3,000万日元以上 | 出资・缴纳的实体、资金来源、对事业的充当 | 司法书士（登记）・税理士（税务） |
| 常勤职员1人以上 | 雇用的实在、常勤性、社会保险的适用 | 社会保险劳务士（适用手续） |
| 事业所的确保 | 独立事业所的实在、不得与自宅兼用 | 不动产（属不同事业体） |

## 日语能力・事业计划书的专家确认，要求谁满足？

日语能力，要求申请者本人或常勤职员任一方满足「能高度自立地理解与使用日语的水准」（CEFR的B2相当）以上。出入国在留管理厅的在线申请样式，亦增设记入是否有达此水准的经营者或常勤从业员的栏位。采本人满足或常勤职员满足任一即可的设计，惟具体以何种考试・分数证明（日语能力试验等的处理）由指引示明，请于提出前以最新指引确认。

事业计划书不仅须提出，还须接受专家的确认。据称可承办确认者为中小企业诊断士・公认会计师・税理士等。此为由第三方专家审视事业计划实现可能性的机制，计划的数值与前提的妥当性受审。行政书士承办在留资格的申请文件制作与申请取次，惟事业计划书的专家确认、决算与税额的确定，各为属独立事业体的专家的领域。四叶集团与各专家以独立的事业体分别签约，彼此不收取介绍费。

## 对已在留者的过渡措施（至2028年10月）如何？

对已以「经营・管理」在留者，设有过渡措施。依出入国在留管理厅的指引，自施行日令和7年10月16日起满3年之日，即至令和10年（2028年）10月16日止，不以仅未达修法后新基准（资本金・出资总额3,000万日元以上、经营经验・学位、常勤职员的雇用等）为由，不许可在留期间的更新。此为使修法影响不致骤然到来的缓冲措施。

惟「至2028年前无须作为」的理解并不正确。过渡措施乃猶予新基准的适用，而从来更新所确认之点——有经营的实体、已履行公租公课（法人税・消费税・住民税等）与社会保险、已确保独立事业所——仍与过渡措施无关而受审视。更新时事业继续性的思路，于前揭[经营・管理签证更新所问的「事业继续性・实体」之立证](https://luck428.com/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)详述。

| 区分 | 过渡期间中（至令和10年10月16日）的处理 |
| --- | --- |
| 新规申请（认定・变更） | 适用修法后的新基准 |
| 在留者的更新（新基准的形式要件） | 不以仅未达新基准为由不许可 |
| 经营实体・公租公课・社会保险・事业所 | 与过渡措施无关，仍依从来确认 |

## 修法后的申请应准备哪些文件？

修法后的申请，除形式要件（资本金・常勤职员）外，显示日语能力与事业计划书专家确认的资料分量增加。具体提出文件因活动内容与所属机关类别而异，请务必以出入国在留管理厅的最新指引确认。在留资格的申请文件制作与申请取次，可由已向出入国在留管理厅申报的申请取次行政书士，依《行政书士法》第1条之3，代本人提出申请书与资料的方式承办。此为省去本人部分出头的制度，并不保证许可本身。

由于相关专业人员分属不同领域，原则上请与各方以独立的事业体分别签约。四叶集团的行政书士，以独立的事业体承办在留资格的申请文件制作辅助与申请取次。亦请参阅本事务所的[承办业务](https://luck428.com/legal/services)、[受任流程](https://luck428.com/legal/nagare)与[报酬额表](https://luck428.com/legal/ryokin)。与各专业人员均以独立的事业体签约，彼此不收取介绍费。

| 委托对象 | 主要角色 |
| --- | --- |
| 行政书士（本事务所） | 在留资格（认定・变更・更新）的申请文件制作・申请取次（行政书士法第1条之3） |
| 司法书士 | 公司设立・董事变更・本店迁移等商业登记 |
| 税理士 | 资本金确认的前提税务、法人税・消费税・决算的申报 |
| 社会保险劳务士 | 常勤职员的健康保险・厚生年金・雇用保险・劳灾的适用手续 |
| 不动产业者（属不同事业体的本公司） | 作为独立事业所的物件选定・租赁中介・重要事项说明 |
| 中小企业诊断士・公认会计师・税理士等 | 事业计划书的专家确认 |

## 常见问题

**Q. 我现以500万日元资本金的「经营・管理」在留中。是否须立即增至3,000万日元，否则无法更新？**
A. 对已以「经营・管理」在留者的更新，设有至令和10年（2028年）10月16日的过渡措施。此期间不以仅未达资本金・出资总额3,000万日元以上等新基准为由不许可更新。惟经营的实体、公租公课与社会保险的履行、独立事业所的确保，与过渡措施无关，仍依从来确认。过渡措施的对象与细部请以指引确认。

**Q. 日语能力要件，一定要社长本人满足吗？**
A. 采申请者本人或常勤职员任一方满足CEFR的B2相当以上（能高度自立地理解与使用日语的水准）即可的设计。纵社长本人对日语有不安，若有满足要件的常勤职员，亦有对应的余地。以何种考试・分数证明的具体，由指引示明，请于提出前以最新指引确认。

**Q. 事业计划书可以自己做吗？**
A. 修法后，事业计划书须接受中小企业诊断士・公认会计师・税理士等专家的确认。此为计划的数值与前提由第三方之目审视的机制。行政书士承办在留资格的申请文件制作・申请取次，惟事业计划书的专家确认，由属独立事业体的专家分别签约后进行。彼此不收取介绍费。

**Q. 常勤职员可以是外国人吗？**
A. 修法将雇用常勤职员1人以上要件化，惟可雇用者的范围、「常勤」的计算方式、可计入的在留资格种类等细部，由出入国在留管理厅的指引定之。本文不就无法裏取的个别计入与否断定。常勤职员的社会保险・雇用保险适用手续由社会保险劳务士承办，最终该当性由入管审查为之。
