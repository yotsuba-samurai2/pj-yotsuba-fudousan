**结论（先讲要点）：**原依修正前基准持「经营・管理」在留者，即使在至2028年10月16日的过渡期间，也非自动获准更新。应将目前的经营实绩证据与未来达成新基准的计划分开准备。

本文限于既有在留经营者，如何将2025年10月修法的应对反映于更新资料。公司设立及新申请请见[经营・管理取得总说](/zh/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)；一般更新的经营实体与持续性请见[更新立证解说](/zh/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)。本文不判断或保证个别许可、过渡措施适用。

## 既有在留者至2028年10月16日的过渡措施，代表什么？

对已以「经营・管理」在留者，设有过渡措施。依出入国在留管理厅的指引，自施行日令和7年10月16日起满3年之日，即至令和10年（2028年）10月16日止，即使尚未达修法后新基准，也须依经营状况及达成新基准的预期等判断在留期间更新的许否。此为使修法影响不致骤然到来的缓冲措施。

惟「至2028年前无须作为」的理解并不正确。过渡措施不保证更新，亦须审查达成新基准的预期。此外，从来更新所确认之点——有经营的实体、已履行公租公课（法人税・消费税・住民税等）与社会保险、已确保独立事业所——仍与过渡措施无关而受审视。更新时事业继续性的思路，于前揭[经营・管理签证更新所问的「事业继续性・实体」之立证](/zh/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)详述。

| 区分 | 过渡期间中（至令和10年10月16日）的处理 |
| --- | --- |
| 新规申请（认定・变更） | 原则适用新基准；须确认施行前受理及创业签证例外 |
| 在留者的更新（新基准的形式要件） | 依经营状况及达成新基准的预期等判断许否 |
| 经营实体・公租公课・社会保险・事业所 | 与过渡措施无关，仍依从来确认 |

## 过渡期间的更新，如何区分目前实绩与新基准达成计划？

先核对在留期限、上次申请副本及所属机关类别，再对照入管的更新文件清单。下表是整理范例，不是所有案件一律必备的清单。上次申请后的变更，应对应日期、理由及证据。

| 核对项目 | 目前证据范例 | 新基准的准备事项 |
| --- | --- | --- |
| 经营状况 | 最近年度决算文件、目前在留期间的经营管理活动说明 | 核对上次申请后变更与计划数字 |
| 资本金等 | 登记事项证明书、缴资及出资记录 | 资金缺口、来源、时间与进度；未完成增资不得写成已完成 |
| 常勤职员与日语能力 | 雇用及出勤记录、在留资格等证据、日语能力证明 | 分别核对雇用与语言要件，区分预定招聘与已雇用 |
| 税务、保险、许可 | 纳税、保险加入与缴纳、事业许可的证据 | 如实整理缺少资料、未履行事项及处理情况 |
| 学位、经验、计划 | 相关学位或经历证据、事业计划及专家确认资料 | 区分适用基准、仍在准备的事项与时间 |

提交时间表不等于会获准。应确认说明与决算、登记、雇用、纳税资料一致；各类别省略或追加资料依入管最新指引处理。

## 准备更新时，如何与新申请基准区分？

新申请原则依修正后基准审查。不可把既有在留者的更新过渡措施，误作新申请的资金或人员缓期。以下比较只供更新计划核对差距，不另作新申请总说。

| 项目 | 修法前的目安 | 修法后（令和7年10月16日施行） |
| --- | --- | --- |
| 资本金・出资总额 | 500万日元以上（或常勤职员2人以上） | 3,000万日元以上 |
| 常勤职员 | 作为替代要件有2人以上的选项 | 要件化雇用1人以上 |
| 日语能力 | 无明文基准 | 申请者或常勤职员任一方达「日本語教育の参照枠」的B2相当以上 |
| 经营经验・学位 | 从事管理业务时原已有3年以上经验等要件 | 3年以上经营经验或经营管理或事业相关领域的博士、硕士或专业职学位 |
| 事业计划书 | 提出 | 经具日本资格的中小企业诊断士・公认会计师・税理士确认 |

3,000万日元不是年营业额基准。法人指株式会社的已缴资本金或持分公司的出资总额，不能直接把运营费用加到资本金计算。个人事业则指确保事业所、职员1年薪资及设备投资等所投入的总额。资金与至少1名符合范围的常勤职员两项要件均须满足。

雇用要件的常勤职员，须为经营或管理者以外、居住于日本的日本人、特别永住者，或持别表第二在留资格（永住者、日本人の配偶者等、永住者の配偶者等、定住者）者。仅雇用别表第一就业等在留资格者，不能满足至少1人的雇用要件。常勤性及雇用实态须个别确认，社会保险与雇用保险手续由社会保险劳务士承办。

日语能力要件所指的常勤职员，与雇用人数要件不同，也包含持别表第一在留资格者。申请者本人或常勤职员任一方符合即可，并非要求所有人均达B2。

确认者须持有日本的中小企业诊断士、公认会计师或税理士资格，确认计划的具体性、合理性与可实现性。申请公司的董事或职员不得担任评价者，但外部顾问公认会计师或税理士可以。

## 更新文件、登记、税务与劳务应分别委托谁？

由于相关专业人员分属不同领域，原则上请与各方以独立的事业体分别签约。四叶集团的行政书士，以独立的事业体承办在留资格的申请文件制作辅助与申请取次。亦请参阅本事务所的[承办业务](/zh/legal/services)、[受任流程](/zh/legal/nagare)与[报酬额表](/zh/legal/ryokin)。与各专业人员均以独立的事业体签约，彼此不收取介绍费。

| 委托对象 | 主要角色 |
| --- | --- |
| 行政书士（本事务所） | 在留资格（认定・变更・更新）的申请文件制作・申请取次（文件制作依行政书士法第1条之3；申请取次依入管申请等取次制度） |
| 司法书士 | 公司设立・董事变更・本店迁移等商业登记 |
| 税理士 | 资本金确认的前提税务、法人税・消费税・决算的申报 |
| 社会保险劳务士 | 常勤职员的健康保险・厚生年金・雇用保险・劳灾的适用手续 |
| 不动产业者（属不同事业体的本公司） | 作为独立事业所的物件选定・租赁中介・重要事项说明 |
| 具日本资格的中小企业诊断士・公认会计师・税理士 | 事业计划书的专家确认 |

租房时如何出示在留资格、担保公司承担什么职责，可参阅独立经营的四葉不動産株式会社提供的[外国人在日本租房指南](/zh/global)。房屋中介和在留手续分别签约。

## 常见问题

**Q. 可以等到2028年10月才准备资料吗？**
A. 不可以如此理解。过渡措施不保证更新，也不免除申请。每次更新仍应能说明目前经营状况与达成新基准的预期。

**Q. 尚未增资或招聘应如何说明？**
A. 将已完成事项与计划分开，附上时间、资金来源及进度依据；不可把未来计划写成已满足的要件。

**Q. 过渡期间仍须注意纳税及保险吗？**
A. 过渡措施不免除公法义务。税务、保险、劳动法令及必要许可仍属核对事项，具体资料须依类别与最新指引确认。

**Q. 交齐表中资料就能获准更新吗？**
A. 不能保证。表中仅为整理例，必备与追加文件依申请及机关类别而异，许可由入管审查判断。
