**结论（先说要点）**：生活介护，是残障者综合支援法第5条第7项所定之残障福祉服务，开业须向都道府县知事（指定都市・中核市为市长）取得指定残障福祉服务事业者的指定（同法第36条）。人员・设备・运营之基准，依同法第43条，并由国之基准——平成18年厚生劳动省令第171号与各自治体之条例具体定之。物件须于面积・设备・避难齐备后，方成为指定之对象，故须一面制作申请书，一面并行确保物件、招募人员、确认建筑与消防。本文整理指定申请之流程与物件应满足之点，并说明何部分应委托何人。指定可否与是否符合基准，由指定权者审查决定，本事务所不保证取得指定。

## 生活介护之指定基准，由何法令决定？

生活介护，是综合支援残障者日常生活及社会生活之法律（残障者综合支援法。平成17年法律第123号）第5条第7项所定之服务。定义为：就需要经常介护之残障者，主要于白天，于残障者支援设施或其他设施，供与入浴・排泄・饮食等介护、创作活动或生产活动之机会，及其他便宜。

欲经营，须取得同法第36条之指定残障福祉服务事业者之指定。指定之人员・设备・运营基准，依同法第43条，并以国之基准（平成18年厚生劳动省令第171号，关于指定残障福祉服务事业等之人员、设备及运营之基准）为据，由都道府县・指定都市・中核市之条例定之。应确认之法令，遂成「法律→省令→自治体条例」之三层。

| 区分 | 依据 |
| --- | --- |
| 服务之定义 | 残障者综合支援法第5条第7项 |
| 事业者之指定 | 残障者综合支援法第36条 |
| 人员・设备・运营基准之委任 | 残障者综合支援法第43条 |
| 国之基准 | 平成18年厚生劳动省令第171号 |
| 具体基准 | 都道府县・指定都市・中核市之条例 |

利用者受支援，以障碍支援区分之认定为前提；生活介护之对象原则为区分3以上（伴随设施入所者为区分4以上），年龄50岁以上者基准放宽。区分之范围由厚生劳动省令定之，故个别是否该当，以认定与自治体之运用确认。

## 生活介护之人员基准，须几人？

人员基准规定于平成18年厚生劳动省令第171号，并由自治体条例具体化。基本配置如下。

| 职种 | 配置思考方式 |
| --- | --- |
| 医师 | 为利用者健康管理・疗养指导所需之数（嘱托医即可） |
| 看护职员・理学疗法士或作业疗法士・生活支援员 | 此3职种之总数，依平均障碍支援区分配置。看护职员1人以上、生活支援员1人以上，其中1人以上常勤 |
| 服务管理责任者 | 利用者60人以下1人以上。61人以上，每40人（含端数）加1人 |
| 管理者 | 原则专任常勤1人（无妨碍时得兼任） |

看护职员・理学疗法士或作业疗法士・生活支援员之总数，依平均障碍支援区分，下限如下变动。

| 平均障碍支援区分 | 总数之下限 |
| --- | --- |
| 未满4 | 利用者人数除以6以上 |
| 4以上未满5 | 利用者人数除以5以上 |
| 5以上 | 利用者人数除以3以上 |

生活介护之指定原则须利用定员20人以上（多机能型等类型思考方式会改变）。符合人员基准之雇用契约・工时设计・工作规则・社会保险适用，属社会保险劳务士领域，与本公司为独立的事业体，各自个别签约。

## 物件之面积・设备，于何处会不合格？

设备基准（平成18年厚生劳动省令第171号）要求训练・作业室、咨询室、洗面所、厕所、多目的室及其他运营上必要之设备。物件易不足之点如下。

| 设备 | 主要要求 |
| --- | --- |
| 训练・作业室 | 不妨碍训练・作业之宽度；备必要之机械器具。部分自治体以条例订定每人面积，有以3.3㎡以上为例者 |
| 咨询室 | 得以隔间等顾及隐私 |
| 洗面所・厕所 | 依利用者特性之数量・规格 |
| 多目的室 | 于不妨碍支援提供时，部分自治体允许与咨询室兼用 |

轮椅移动、厕所与出入口宽度、消除高低差等无障碍，亦关乎建筑基准法及各自治体之福祉城乡营造条例。设备不仅看「有无」，更看「宽度・规格・动线是否符合基准」，故于看房阶段将图面与现况对照确认，是减少返工之捷径。面积或设备未达基准之物件，不成为指定之对象。

## 用途变更之确认申请，自何规模起需要？

将事务所或店铺等既有建物改为生活介护事业所时，可能构成建筑基准法上之用途变更。残障福祉服务事业所，被视为建筑基准法施行令第19条所称之「儿童福祉设施等」，并定位为同法之特殊建筑物。

向特殊建筑物用途变更，且供该用途使用部分之楼地板面积超过200㎡时，依建筑基准法第87条第1项，准用同法第6条第1项第一号，须向建筑主事或指定确认检查机关提出确认申请。此楼地板面积基准，自原本之逾100㎡提高为逾200㎡，于2019年（令和元年）6月25日施行。惟即使在200㎡以下，建筑基准法・消防法之实体基准（防火・避难・采光等）仍适用，故「无须确认申请」与「符合基准」系属二事。

是否构成用途变更、是否需要确认申请，系基于图面与现况之建筑专业判断。设计・确认申请宜委托建筑士（设计者），并一并确认既存不合格与有无检查济证。本公司仅承担物件资讯与用途地域・面积之一次确认，不作建筑确认之判断。

## 消防设备于何处产生追加成本？

生活介护事业所，区分于消防法施行令别表第一之(6)项（社会福祉设施等）。即使同为(6)项，主要收容自力避难困难者之设施(6)项ロ，与以通所为主之其他(6)项ハ，所需消防用设备亦异。通所之生活介护一般区分于(6)项ハ，惟依利用者状态与设施形态，用途判定会不同。

灭火器・自动火灾报知设备・引导灯・洒水设备等之要否，由用途区分・总楼地板面积・楼层数・收容人员决定。于既有建物，此追加设置最易造成费用与工期之估算落差。防火对象物之用途判定与消防同意，由消防署判断，故决定物件前，宜先向管辖消防署咨询。本公司・本事务所不判断消防设备之要否。

## 指定申请之文件与事前协议，依何顺序进行？

一般流程如下。顺序前后颠倒容易被退件，故宜及早开始事前协议。

1. 确定事业计画与资金计画，设立法人（于章程事业目的加入残障福祉服务）
2. 选定物件，确认是否符合设备基准・建筑基准法・消防法
3. 与指定权者进行事前协议
4. 确保服务管理责任者・生活支援员・看护职员等
5. 制作申请书与附件，于截止日前提出
6. 书面审查・必要时现地确认
7. 指定（多数自治体为每月1日生效）

多数自治体以每月1日生效核发指定，申请书提出期限一般设于希望指定日之前一月或前二月。截止日因指定权者而异，年度更替时亦可能提前，故务必于该自治体公式页面确认。代表性必要文件如下。

- 指定申请书、指定相关记载事项（附表）
- 法人登记事项证明书、章程
- 事业所平面图、照片、租赁契约书等
- 运营规程、重要事项说明书
- 从业者勤务体制・勤务形态一览表、资格证・实务经验证明、服务管理责任者研修等修了证
- 管理者・服务管理责任者之经历书
- 收支预算书、处理利用者申诉所采措施之概要、各种誓约书 等

四叶行政书士事务所于行政书士业务范围内，支援指定申请书・附表・附件之制作、事前协议资料整理、运营规程等文案制作。是否最终符合基准与指定可否，由指定权者审查。

## 物件・建筑・劳务・登记・税务，各应委托何人？

指定申请涉及多个专业领域。分工如下。

- 指定申请书・附表・附件之制作、事前协议支援 → 四叶行政书士事务所（行政书士）
- 事业用物件之选定・租赁・重要事项说明，及用途地域・面积之一次确认 → 四叶不动产株式会社
- 用途变更之确认申请・设计，及既存不合格与检查济证之确认 → 建筑士（设计者）
- 消防用设备之要否判定・消防同意 → 消防署
- 符合人员基准之雇用契约・工作规则・工时管理・社会保险适用 → 社会保险劳务士
- 法人设立・变更登记 → 司法书士
- 法人会计・税务・税额计算 → 税理士
- 涉及权利义务・纠纷之个别法律判断 → 律师

## 常见问题

**Q. 生活介护事业所，任何物件都能开吗？**
A. 除面积・设备・避难外，既有建物尚可能需要用途变更之确认申请或追加消防用设备。用途变更之判断向建筑士（设计者）确认，消防用设备之要否向消防署确认。物件与不动产、建筑确认与建筑士，各作为别事业体个别签约。

**Q. 用途变更之确认申请必然需要吗？**
A. 向特殊建筑物用途变更，且供该用途使用部分之楼地板面积超过200㎡时，依建筑基准法第87条第1项须提出确认申请。即使在200㎡以下无须确认申请，防火・避难・采光等实体基准仍适用。是否需要，系建筑士基于图面与现况之专业判断。

**Q. 人员须于开所前全部备齐吗？**
A. 服务管理责任者及常勤要件等直接关乎指定要件之人员，须于申请时点示明确保状况。招募、劳动条件设计、社会保险适用属社会保险劳务士领域，与本公司为独立的事业体，各自个别签约。

**Q. 定员自几人起？**
A. 生活介护之指定原则须利用定员20人以上。因多机能型等类型思考方式会改变，个别定员以该自治体之条例与手引确认。
