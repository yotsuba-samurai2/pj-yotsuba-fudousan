**结论（先说要点）**：以营业方式（反复继续）收集运搬因建设・拆除・运送等事业所生之「他人之产业废弃物」，须依废弃物之处理及清扫相关法律（废弃物处理法）第14条第1项取得都道府县知事之许可。取得许可须具备：车辆・容器等设施与申请人之能力符合环境省令基准（第14条第5项第1号）、不该当欠格要件（同项第2号准用第7条第5项第4号）、且经营事业之本人或役员已修毕公益财团法人日本产业废弃物处理振兴中心（JW中心）之讲习。本文为一般资讯提供，整理产业废弃物收集运搬业许可之要件・欠格要件・讲习・车库与积替保管场所之处理・逐都道府县之许可与更新，不判断个别许可之可否。

## 产业废弃物收集运搬业许可，何种事业需要？

产业废弃物，系指因事业活动所生之废弃物中，燃烧残渣・污泥・废油・废塑胶类・瓦砾类等法令所定种类者。受他人委托，以营业方式（有偿且反复继续）收集运搬此类废弃物时，即须此许可。

判断之分界在于「运搬何人之废弃物」。

| 情形 | 许可之要否 |
| --- | --- |
| 受委托运搬他公司所排出之产业废弃物 | 须收集运搬业之许可 |
| 将自家事业所生之产业废弃物，自行运至处分处（自家运搬） | 原则无须许可（惟须遵守运搬基准・委托基准） |
| 运搬一般家庭所生之垃圾（一般废弃物） | 产业废弃物之许可不足，另须市町村之一般废弃物收集运搬业许可 |

由建设・拆除・运送扩展事业时，若运搬元包或他公司工地所生之废弃物，即属「他人之产业废弃物」，须有许可。四叶行政书士事务所于行政书士业务范围内，支援许可要否之确认、要件之整理、申请文件之制作、申请之代理。个别许可之可否，由都道府县审查。

## 不予许可之「欠格要件」具体为何？

欠格要件，系只要该当其一即不得取得许可之事由。就产业废弃物收集运搬业，第14条第5项第2号准用第7条第5项第4号，主要定有下列各项。

| 区分 | 内容（要旨） |
| --- | --- |
| 身心故障 | 因身心故障而不能适切执行业务者，以环境省令所定者为限 |
| 破产 | 受破产程序开始决定而未复权者 |
| 刑罚（拘禁刑） | 受拘禁刑以上之刑，自执行完毕或不再受执行之日起未逾5年者 |
| 刑罚（罚金） | 因违反废弃物处理法等环境相关之特定法令而受罚金刑，未逾5年者 |
| 暴力团关系 | 暴力团员，或不再为暴力团员之日起未逾5年者；其事业活动受暴力团员等支配者 |
| 不正・不诚实 | 有相当理由足认其于业务上有为不正或不诚实行为之虞者 |

2022年刑法修正将惩役・禁锢一元化为「拘禁刑」，条文亦记为拘禁刑以上之刑。欠格要件不仅及于申请人本人，亦及于法人之役员及一定之使用人。取得许可后若该当欠格要件，许可即被撤销，且于该当时亦有申报义务。曾有刑罚纪录者，宜及早确认是否该当。

## 讲习之修毕，何时、由何人为之？

许可申请须附公益财团法人日本产业废弃物处理振兴中心（JW中心）所办讲习之修了证。须于申请前修毕。

| 项目 | 新规许可 | 更新许可 |
| --- | --- | --- |
| 课程 | 产业废弃物之收集・运搬课程（新规） | 产业废弃物之收集・运搬课程（更新） |
| 天数概略 | 2日讲义＋修了试验 | 约1日讲义＋修了试验 |
| 修了证有效期间 | 原则5年 | 原则2年（亦有自治体定为5年之例） |
| 受讲之人 | 个人为事业主本人，法人为代表者或执行业务之役员（含政令所定使用人） | 同左 |

若处理特别管理产业废弃物（废酸・废碱・感染性废弃物等），须另修毕特别管理产业废弃物之收集・运搬课程。修了证之有效期间及更新讲习之处理，因自治体审查基准而有差异，请确认申请地都道府县之最新手引。

## 进行积替・保管时，场所要件如何改变？

收集运搬分为「无积替保管」与「有积替保管」。

- **无积替保管**：自排出场所至处分・再生设施，途中不卸下而直行运搬。多数新规许可由此区分开始。
- **有积替保管**：途中换装至他车辆，或一时保管。此时就保管场所，须具备围篱・告示牌之设置、依种类分别、保管上限（数量）、防止飞散・流出・恶臭等基准之土地，审查亦较严格。

又，置放运搬车辆之车库（停车场），须与积替保管场所分别，能以书面示明使用权原（自有或租赁契约）。车库用地及供积替保管之土地之手配・租赁，属宅地建物交易业者之角色。与四叶行政书士事务所别事业体之四叶不动产株式会社，以独立的事业体、个别契约担任物件寻找与签约。本事务所不收取介绍费。

## 许可于何都道府县取得？更新何时到来？

第14条第1项规定，仅以运搬为业时，许可权者为管辖「产业废弃物积卸区域」之都道府县知事。亦即，无积替保管之收集运搬，于积载地与卸货地双方之都道府县均须许可，仅通过之都道府县则无须许可。亦有政令所定市自行核发许可之区域。

有效期间为每5年（第14条第2项），因期间经过而失效，故须于期限前修毕更新讲习后申请更新。若经认定符合优良产业废弃物处理业者认定制度之基准，有效期间为7年。

依事业扩展方式，涉及之专业领域有别。分工如下。

- 产业废弃物收集运搬业许可之要件确认・文件制作・申请代理 → 四叶行政书士事务所（行政书士）
- 车库用地・积替保管场所之土地或物件之手配・租赁 → 四叶不动产株式会社（宅地建物交易业者）
- 法人设立・役员变更等之登记 → 司法书士
- 取得许可后之劳动保险・驾驶人劳务・就业规则 → 社会保险劳务士

四叶行政书士事务所与四叶不动产株式会社为别事业体。各领域均以与各资格者作为独立的事业体个别签约为前提，本事务所不收取介绍费。受任流程见[受任流程](https://luck428.com/legal/nagare)；费用见[报酬额表](https://luck428.com/legal/ryokin)；取扱业务之全貌见[许认可・各种申请服务](https://luck428.com/legal/services)。

## 常见问题

**Q. 运搬自家公司所生之废弃物，用自家卡车也须许可吗？**
A. 将自家事业所生之产业废弃物自行运至处分处之「自家运搬」，原则无须收集运搬业许可。惟仍须遵守运搬中防止飞散・流出等法令上之运搬基准。受委托运搬他人（他公司）之产业废弃物时，属营业行为，须有许可。

**Q. 有许可即可于全国任何地方运搬吗？**
A. 否。无积替保管之收集运搬，须于管辖产业废弃物积卸区域之各都道府县取得许可。积载之都道府县与卸货之都道府县双方均须许可，仅通过之都道府县则无须。将依运搬路线确认所需许可。

**Q. 讲习应由何人受讲？**
A. 个人为事业主本人，法人为代表者或执行业务之役员（含政令所定使用人），修毕JW中心之收集・运搬课程。新规有2日讲义与修了试验，修了证有有效期间。须于申请前修毕。

**Q. 过去曾受罚金刑，仍能取得许可吗？**
A. 视是否该当欠格要件而定。因违反废弃物处理法等环境相关特定法令之罚金，及拘禁刑以上之刑，若未逾一定期间（多为5年），可能该当欠格要件。是否该当及个别判断由都道府县为之，建议于申请前确认。
