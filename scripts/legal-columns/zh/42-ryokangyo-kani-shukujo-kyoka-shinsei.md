**先讲重点：** 要在独栋住宅或空置大楼经营纯住宿的旅宿（青年旅馆等），须取得旅馆业法的营业许可。作为简易宿所营业，向都道府县知事（设有保健所的市、特别区为市长、区长）取得许可（旅馆业法第3条第1项）。客室的延面积、厕所、洗面等构造设备，于旅馆业法施行令第1条第2项有标准，并以符合用途地域、用途变更（建筑基准法）与消防法令为前提。年营业日数没有上限，是与住宅宿泊事业法的民宿（申报制、年180日上限）最大的不同。本文整理许可的条件与流程，是否核准由保健所审查决定。本事务所不保证取得许可。

## 简易宿所的许可与民宿的申报，有何不同？

同样是"让人住宿的生意"，依据的法律不同。简易宿所是旅馆业法的"许可"，所谓民宿则是住宅宿泊事业法的"申报"，要件与日数的处理都是两回事。

| | 简易宿所营业 | 住宅宿泊事业（民宿） |
| --- | --- | --- |
| 依据法律 | 旅馆业法第3条第1项 | 住宅宿泊事业法（平成30年6月15日施行） |
| 手续 | 许可 | 申报 |
| 营业日数 | 无上限 | 每年180日以内 |
| 构造设备 | 有施行令第1条第2项的标准 | 以住宅设备为基本 |

依住宅宿泊事业法的民宿为申报制，年提供住宿的日数限制在180日以内。相对地，简易宿所营业为许可制，日数没有上限，但须符合构造设备标准以及用途地域、消防的要件。若想全年持续经营住宿业，选简易宿所的许可；若利用住宅在日数范围内经营，选民宿的申报，这是基本的取舍。民宿申报的要件整理于[住宅宿泊事业的申报](https://luck428.com/legal/column/minpaku-jutaku-shukuhaku-todokede-yoken)。

## 简易宿所的构造设备标准（客室、厕所、洗面）要求到什么程度？

简易宿所营业的构造设备标准订于旅馆业法施行令第1条第2项。代表性项目如下。都道府县等的条例可能订有加码标准。

| 项目 | 标准概要 |
| --- | --- |
| 客室的延面积 | 33㎡以上。但将住宿者数设为10人以下时，为3.3㎡乘以住宿者数所得面积以上 |
| 层架式寝台（双层床等） | 上段与下段的间隔大致1m以上 |
| 换气、采光、照明、防潮、排水 | 须有适当设备 |
| 入浴设备 | 满足住宿者需求的规模。邻近有公众浴场等者除外 |
| 洗面设备 | 满足住宿者需求的适当规模 |
| 厕所 | 须有适当数量 |

由于简易宿所是预设合住（多人房）的营业类型，与旅馆、酒店营业不同，标准是以客室整体的延面积、而非各客室的面积来订定。简易宿所并不一律要求设置玄关帐场（前台），但在运营上仍须有住宿者名簿的备置与本人确认的体制。具体的数值与区划，请于保健所的手册与事前咨询中确认。

## 用途地域或既有建物的用途变更，会成为问题吗？

旅馆业（酒店、旅馆）依建筑基准法别表第2受用途地域的限制。在第一种、第二种低层住居专用地域、田园住居地域、工业专用地域等，原则上不能兴建，是否可行因地域而异。首先向特定行政厅（主管建筑的窗口）确认要开设的地点属于哪种用途地域。

将既有建物改为住宿设施时，须留意用途变更。旅馆、酒店属建筑基准法上的特殊建筑物，若进行用途变更使供该用途的部分楼地板面积合计超过200㎡时，须办理确认申请（建筑基准法第87条第1项；将须确认的规模由超过100㎡放宽至超过200㎡的修正于令和元年6月25日施行）。用途地域是否可行、是否须用途变更、既有不合格建筑物的处理，属建筑士、特定行政厅的领域。在签订物件合同之前，先确认用途地域与用途变更的可行性，在实务上很重要。

## 为何需要消防法令适合通知书？

旅馆业的营业许可申请，一般会要求附上证明符合消防法令的"消防法令适合通知书"。此通知书由管辖该设施的消防署进行现地检查、认定符合消防法令时交付。住宿设施是不特定人就寝的用途，消防用设备等的设置标准（消防法）比住宅严格，可能要求自动火灾报知设备、诱导灯、灭火器等。

所需的消防用设备，会因建物的规模、构造、收容人数而不同。保健所的许可审查与消防署的适合确认在不同窗口进行，仅其中一方备妥并无法开始营业。在决定物件的内装与格局之前，先向消防署事前咨询、估算所需的设备与工程，对防止返工很重要。

## 建筑、消防、物件，应各自委托给谁？

简易宿所的许可横跨多个专业领域。分工如下。

- 旅馆业许可（简易宿所）申请书、附件文件的制作，以及与保健所事前咨询的支援 → 四叶行政书士事务所（行政书士）
- 事业用物件的选定、租赁、重要事项说明 → 四叶不动产株式会社
- 建筑物的用途、确认申请、用途变更、检查完成证的确认 → 建筑士、特定行政厅
- 消防用设备等的设计、工程，消防法令适合通知书的交付申请 → 消防设备士、消防机关
- 建物与事业的会计、税务 → 税理士
- 涉及权利义务与纠纷的个别法律判断 → 律师

四叶行政书士事务所与四叶不动产株式会社为不同的事业体。本事务所仅以独立的事业体承办旅馆业许可的申请支援，物件、建筑、消防、税务请与各专业人士、行政窗口分别签约、咨询。本事务所不收取介绍费。许可的整体样貌请见[行政许可手续](https://luck428.com/legal/services)，受任流程请见[受任流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)。是否核准许可本身由保健所判断。

## 常见问题

**Q. 简易宿所与民宿，哪个较有利？**
A. 无法一概而论。简易宿所（旅馆业法第3条第1项）为许可制、营业日数无上限，但须符合构造设备、用途地域、消防的要件。民宿（住宅宿泊事业法）为申报制、较易起步，但有每年180日以内的日数限制。依想持续经营、或在日数范围内经营来取舍。

**Q. 客室一定要33㎡以上吗？**
A. 将住宿者数设为10人以下时，为3.3㎡乘以住宿者数所得面积以上即可（旅馆业法施行令第1条第2项）。例如将住宿者上限设为4人的设施，客室延面积的参考值为3.3㎡×4＝13.2㎡以上。条例可能有加码标准，请向保健所确认。

**Q. 住宅区的独栋住宅也能开简易宿所吗？**
A. 视用途地域而定。旅馆、酒店依建筑基准法别表第2受用途限制，在第一种、第二种低层住居专用地域等原则上不能经营。首先向特定行政厅确认该地点的用途地域。签订物件合同之前的确认很重要。

**Q. 消防法令适合通知书何时取得？**
A. 因一般作为旅馆业许可申请的附件文件，故应在许可申请之前向消防署申请交付，经现地检查后领取。可能伴随所需消防用设备的工程，故在内装工程之前先向消防署事前咨询，可防止返工。
