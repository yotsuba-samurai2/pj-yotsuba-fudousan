**结论（先说要点）**：以一辆轻型厢型车起步之配送・宅配（货物轻型汽车运送事业，即所谓黑牌），非如一般货物汽车运送事业之「许可」，而以「申报」即可开始。依据为货物汽车运送事业法第2条第4项（货物轻型汽车运送事业之定义）与第36条第1项（经营申报）。向管辖之运输支局提出货物轻型汽车运送事业经营申报书与事业用汽车等联络书，并持该联络书于轻型汽车检查协会办理黑牌之车辆登录。自2025年4月1日起，新增于各营业所选任货物轻型汽车安全管理者之义务（同法第36条之2，令和6年法律第23号）。本文为一般资讯提供，整理申报制与许可制之差异、必要文件与车库・营业所条件、2025年施行之安全管理义务，以及物件・劳务应交由何人处理。个别申报之受理与必要文件，由管辖之运输支局・轻型汽车检查协会之处理而定。

## 轻货物（黑牌）非许可而以申报即可开始？

货物轻型汽车运送事业，于货物汽车运送事业法第2条第4项定义为「应他人需求、有偿以汽车（限于三轮以上之轻型车及二轮车）运送货物之事业，且为一般货物汽车运送事业及特定货物汽车运送事业以外者」。轻型厢型车、轻型卡车及机车快递属之。

一般货物汽车运送事业须依第3条取得「许可」，货物轻型汽车运送事业则依第36条第1项以「申报」即可开始。该项规定「欲经营货物轻型汽车运送事业者，须依省令所定手续，将营业所之名称及位置、事业用汽车之概要及其他事项向国土交通大臣申报」。实务上向管辖之运输支局申报。

| 项目 | 货物轻型汽车运送事业（黑牌） |
| --- | --- |
| 手续种类 | 申报（货物汽车运送事业法第36条第1项） |
| 使用车辆 | 三轮以上之轻型车・二轮车（轻型厢型车、轻型卡车、机车等） |
| 事业用汽车数量 | 1辆起可 |
| 车牌 | 黑底黄字之事业用车牌（即所谓黑牌） |

申报一经受理即足，非如许可般以审查判断可否之制度。惟提出文件之格式与附件因运输支局而异，事前于窗口确认可避免文件退回。

## 与一般货物运送之差异何在？（辆数・运行管理者・车库）

虽同为「运送货物之事业」，一般货物汽车运送事业与货物轻型汽车运送事业系手续与要件均不同之制度。主要差异如下。

| 事项 | 一般货物汽车运送事业（绿牌） | 货物轻型汽车运送事业（黑牌） |
| --- | --- | --- |
| 手续 | 许可（第3条） | 申报（第36条第1项） |
| 事业用汽车数量 | 最低5辆 | 1辆起可 |
| 运行管理者 | 须选任 | 无须选任（另选任安全管理者） |
| 整备管理者 | 达一定辆数时须设 | 原则不需 |
| 车库 | 位置・大小之基准（车辆相互间50公分以上等） | 具使用权原之停车空间（并设或一定距离内为目安） |
| 开始前期间 | 标准处理期间概略3〜5个月 | 申报一经受理即可进入车辆登录 |

一般货物之许可要件（5辆・运行管理者・车库大小・法令试验等），于另文[一般货物汽车运送事业之营业所・车库要件](https://luck428.com/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)整理。以一辆轻型厢型车起步时，先依事业计画确认是否属货物轻型汽车运送事业。

## 申报所需文件与车库・营业所之条件为何？

申报之核心文件为货物轻型汽车运送事业经营申报书与事业用汽车等联络书。将经营申报书向运输支局提出，并持盖有确认印之事业用汽车等联络书至轻型汽车检查协会，办理黑牌车辆之登录（事业用之变更登录）。

| 文件 | 内容 |
| --- | --- |
| 货物轻型汽车运送事业经营申报书 | 记载营业所之名称・位置、事业用汽车数量等，向运输支局提出 |
| 运价料金设定申报书 | 申报所适用之运价・料金 |
| 运送约款 | 使用标准货物轻型汽车运送约款时，于申报书载明其旨 |
| 事业用汽车等联络书 | 受运输支局确认，用于轻型汽车检查协会之车辆登录 |

营业所・车库之条件虽无如一般货物般细之面积基准，惟下列各点为目安。

- 营业所具使用权原（自有或租赁）。亦有可将自宅作为营业所之情形
- 车库能收容计画之事业用汽车且具使用权原。原则并设于营业所，分开时以一定距离内（因地区而异）为目安
- 以租赁物件作为车库・营业所时，须确认契约上是否认可该用途

车库或营业所之距离・大小之处理因运输支局而异。于签约物件前，依用途与使用权原之要件确认，可避免签约后重做。物件侧之要件，向不动产之承办确认较为确实。

## 2025年施行之货物轻型汽车安全管理者做什么？

以货物轻型汽车运送事业相关事故增加为背景，货物汽车运送事业法经修正（令和6年法律第23号，2024年5月15日公布），自2025年4月1日起施行货物轻型汽车安全管理者制度。依据为同法第36条之2。

| 事项 | 内容 |
| --- | --- |
| 选任义务 | 于各营业所选任货物轻型汽车安全管理者（第36条之2） |
| 施行日 | 2025年4月1日 |
| 对象 | 货物轻型汽车运送事业者 |
| 讲习 | 选任前修毕货物轻型汽车安全管理者讲习。其后每2年须受定期讲习 |
| 主要业务 | 点呼、对驾驶人之指导・监督、业务之记录等确保运行安全之业务 |
| 选任・申报 | 选任时向运输支局等申报 |
| 经过措施 | 2025年3月31日前已提出经营申报之既有事业者，于2027年3月31日前选任即可 |

违反选任义务或申报义务者，定有罚则（100万日圆以下罚金）。讲习之受讲手续费与日程，由受登录之讲习机关之案内而定。新开始之事业者，于修毕讲习后选任安全管理者并申报。四叶行政书士事务所于行政书士业务范围内，支援申报文件与安全管理者选任申报书之制作。个别申报之受理与文件之要否，由管辖之运输支局之处理而定。

## 雇用人员・租借物件时应向何人咨询？

货物轻型汽车运送事业，非仅以申报即告完结，尚涉及物件・劳务・登记・税务。分工如下。

- 货物轻型汽车运送事业之经营申报、事业用汽车等联络书、安全管理者选任申报书之制作 → 四叶行政书士事务所（行政书士）

## 常见问题

**Q. 仅一辆轻型厢型车亦能申报吗？**
A. 货物轻型汽车运送事业以1辆事业用汽车起即可开始，无如一般货物汽车运送事业之最低5辆要件。是否属申报（货物汽车运送事业法第36条第1项）之事业计画，视使用车辆与运送内容而定。个别受理之可否由管辖之运输支局之处理而定。

**Q. 黑牌于何处申办？**
A. 先向运输支局提出货物轻型汽车运送事业经营申报书，再持盖有确认印之事业用汽车等联络书至轻型汽车检查协会，办理事业用（黑牌）车辆之登录。申报与车辆登录之窗口不同，须确认顺序后进行。

**Q. 2025年起之安全管理者必须选任吗？**
A. 自2025年4月1日起，货物轻型汽车运送事业者须于各营业所选任货物轻型汽车安全管理者（货物汽车运送事业法第36条之2）。新开始之事业者于修毕讲习后选任・申报。2025年3月31日前已申报之既有事业者，设有2027年3月31日前选任即可之经过措施。

**Q. 与一般货物（绿牌）如何区分使用？**
A. 以三轮以上之轻型车或二轮车运送者为货物轻型汽车运送事业（申报・黑牌）；以普通车或小型卡车等运送者为一般货物汽车运送事业（许可・绿牌，最低5辆・运行管理者）。属何者视使用车辆与事业计画而定。许可制之详情见[一般货物汽车运送事业之营业所・车库要件](https://luck428.com/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)。
