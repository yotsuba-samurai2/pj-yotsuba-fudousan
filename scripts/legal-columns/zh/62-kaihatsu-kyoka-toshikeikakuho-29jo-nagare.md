**结论（先说要点）**：为建筑一定规模以上之建筑物等而变更土地区划形质之「开发行为」，原则上须经都道府县知事等之开发许可（都市计划法第29条第1项）。取得许可，须符合适用于所有区域之技术基准（同法第33条）；于市街化调整区域，尚须符合立地基准（同法第34条）之各号之一。工程完成后受检查，经工程完成公告后始得建筑建筑物（同法第36条・第37条）。本文为一般资讯提供，整理开发许可之要件与流程，不作个别许可可否或许可基准之适用等具体法律判断。

## 开发许可（都市计划法第29条）于何种情形须申请？

开发许可之对象为「开发行为」。开发行为，指主要为建筑建筑物或建设特定工作物之目的，而变更土地区划形质者（都市计划法第4条第12项）。特定工作物包含混凝土厂等可能致周边环境恶化之第一种特定工作物，及高尔夫球场、一定规模以上之运动・休闲设施等第二种特定工作物（同条第11项）。单纯之建物改建，或不伴随区划形质变更之土地利用，非属开发行为。

是否须许可，依土地所在区域及开发行为之规模而定。各区域之规模目安如下（都市计划法施行令第19条）。

| 区域 | 须申请开发许可之规模目安 |
| --- | --- |
| 市街化区域 | 1,000平方米以上（得以条例下修至最小300平方米） |
| 三大都市圈既成市街地・近郊整备地带等之一定区域 | 500平方米以上 |
| 未定区域区分之都市计划区域（非线引）・准都市计划区域 | 3,000平方米以上 |
| 都市计划区域・准都市计划区域外 | 1公顷（10,000平方米）以上 |
| 市街化调整区域 | 原则上不论规模均须申请 |

许可权者为都道府县知事，惟于指定都市・中核市等，由该市之首长掌权。又，供农业・林业・渔业使用之一定建筑物、车站・图书馆・变电所等公益上必要建筑物之一部、以都市计划事业・土地区划整理事业所为之开发行为等，得作为除外事由而不须许可（都市计划法第29条第1项各号）。属何规模・区域・除外事由，因自治体运用而异，请于着手前向预定建筑之自治体窗口确认。

## 于市街化调整区域可建何种开发（第34条）？

市街化调整区域系应抑制市街化之区域。于此取得开发许可，除技术基准（第33条）外，尚须符合立地基准（都市计划法第34条）各号之一。主要之号如下。

| 号 | 所涵盖开发行为之例 |
| --- | --- |
| 第1号 | 供开发区域周边居住者日常生活所必要物品之贩售・加工・修理等店铺等 |
| 第9号 | 为确保道路顺畅交通而设于适当位置之休憩所・加油站等 |
| 第10号 | 于地区计划或集落地区计划区域内、符合计划之开发行为 |
| 第11号 | 于以条例指定为邻接・近接市街化区域且大致连栋50以上建筑物之地域内之开发行为 |
| 第12号 | 作为无促进市街化之虞且于市街化区域内施行困难・不适当者，以条例限定区域・目的・用途所定者 |
| 第14号 | 经开发审查会之议，认无促进市街化之虞且于市街化区域内施行困难・不适当者 |

可能符合何号，因条例指定区域之范围及审查基准而各自治体差异甚大。第11号・第12号因以条例定区域及用途，须事先于自治体之开发许可基准・审查要领确认对象地是否入该区域、预定建物之用途是否获准。若无可能符合之号，于市街化调整区域亦有无法建筑之情形。

## 开发许可之技术基准（第33条）系应符合何事？

技术基准（都市计划法第33条）不问市街化区域・市街化调整区域，共通适用于所有开发行为。主要项目如下。

- 预定建筑物等之用途，符合用途地域・地区计划等
- 依开发区域之规模・形状，适当配置道路・公园・广场等公共空地
- 排水设施以能适当处理污水・雨水等之构造・能力设置
- 自来水等给水设施以无碍需求之构造・能力设置
- 已采防止崩崖・出水等灾害之措施
- 已取得开发区域内公共设施管理者之同意，并与将管理新设公共设施者协议（同法第32条）
- 申请者具完成开发行为所需之资力・信用

此等为技术性・定量性之基准，道路宽度或排水计划等于自治体审查要领有细部规定。设计与图面之制作，通常有建筑士・测量士・土木设计等专家参与。

## 自申请至许可・工程完成公告之流程与期间为何？

开发许可之一般流程如下。

| 阶段 | 内容 | 根据・留意点 |
| --- | --- | --- |
| ① 事前相谈・事前协议 | 于自治体窗口确认区域区分・规模・立地基准之该当性 | 依自治体运用 |
| ② 公共设施管理者之同意・协议 | 道路・水路等管理者之同意；与新设公共设施管理者协议 | 都市计划法第32条 |
| ③ 申请 | 附设计图书及相当数关系权利人之同意等申请 | 都市计划法第30条 |
| ④ 审查・处分 | 审查技术基准与（调整区域者）立地基准；许可或不许可 | 都市计划法第35条（迟滞无延处分・通知） |
| ⑤ 工程 | 依许可内容施行造成等工程 | 变更须变更许可等 |
| ⑥ 工程完成届・检查 | 届报工程完成，经检查交付检查济证 | 都市计划法第36条第1项・第2项 |
| ⑦ 工程完成公告 | 由知事等公告工程完成 | 都市计划法第36条第3项 |
| ⑧ 建筑 | 公告后得建筑预定建筑物 | 都市计划法第37条（公告前原则不得建筑） |

审查所需之标准期间由各自治体订定，含事前协议可能达数月，惟此处不示一律日数（请以对象地自治体之标准处理期间确认）。于工程完成公告前，原则上不得建筑・改筑建筑物（都市计划法第37条）。又，工程完成公告后，建筑获许可之预定建筑物等以外之建筑物受限制（同法第42条）。

## 登记・测量・税务・争讼应委由何人？

开发许可之申请书・附件图书中，对行政机关之许认可申请书类之制作・提出代理，得于行政书士业务范围内支援。另方面，伴随开发之各手续，有由行政书士以外之资格者担当者。

- 将农地变更为宅地等时之农地转用许可・届报，系与开发许可有别之手续（见[农地转用（农地法第4条・第5条）许可之流程](https://luck428.com/legal/column/nochi-tenyo-4jo-5jo-kyoka-nagare)）。
- 土地之测量・分笔・地目变更等表示相关登记，属土地家屋调查士业务。
- 所有权移转、抵押权设定等权利相关登记，属司法书士业务（涉及相续者，另见[相续登记之流程](https://luck428.com/legal/column/souzoku-touki-nagare)）。
- 事业计划之收支・税务判断，属税理士业务。
- 对开发许可之不许可等所为之审查请求・撤销诉讼等争讼代理，属律师业务。

## 常见问题

**Q. 于市街化调整区域是否无法建筑建物？**
A. 虽系应抑制市街化之区域，惟并非完全不得建筑。除技术基准（都市计划法第33条）外，若符合立地基准（同法第34条）之一，得经开发许可而建筑。惟是否有可能符合之号，依对象地・预定用途及自治体之条例・审查基准，个别可否请洽自治体窗口与资格者确认。

**Q. 改建是否不须开发许可？**
A. 不伴随区划形质变更之单纯改建，本即非属开发行为（都市计划法第4条第12项），多属不须开发许可。惟依是否伴随造成或区划变更、是否位于市街化调整区域内等而异。判断自是否构成开发行为起始，请洽自治体确认。

**Q. 开发许可之申请书类可否委由行政书士？**
A. 对行政机关之许认可申请书类之制作・提出代理，得于行政书士业务范围内支援。惟设计图书由建筑士等，测量・分笔・地目变更由土地家屋调查士，权利登记由司法书士担当，各以独立的事业体个别签约。

**Q. 工程完成后是否即可建筑建物？**
A. 否。工程完成届报后受检查，经检查济证之交付后为工程完成公告（都市计划法第36条）。预定建筑物之建筑，原则上于此工程完成公告后为之（同法第37条）。公告前之建筑原则上不获准。
