**先讲结论**：要经营贷金业（包含对企业的融资），必须办理登录。在两个以上都道府县的区域内设置营业所等者，须受内阁总理大臣的登录（权限委任给财务局长）；仅在一个都道府县的区域内设置者，须受该都道府县知事的登录（贷金业法第3条第1项）。登录有效期间为3年，未更新即失效（同条第2项）。主要门槛有三。第一，作为财产基础，净资产须达政令所定金额（5000万日元）以上（贷金业法第6条第1项第14号及第3项；贷金业法施行令第3条之2。净资产额的计算方法由同法第6条第4项及施行规则定之）。第二，于各营业所或事务所，依从事贷金业务之人数，以50分之1以上的比例常驻贷金业务处理主任者（贷金业法第12条之3）。第三，不该当登录拒绝事由（同法第6条第1项各款）。本文为一般性资讯提供，个别登录可否与净资产评价的最终判断，由登录行政机关与有资格者为之。登录申请文件（向财务局・都道府县知事）的制作由四葉行政書士事務所（行政书士）负责，决算书・净资产额的计算与税务由税理士，登录后债权回收・催收的受托或代理・诉讼由律师（有非律师执业的界线），法人设立登记由司法书士，各以独立的事业体分别签约对应。四葉行政書士事務所与四葉不動産株式会社为不同事业体。本所不收取介绍费。

## 贷金业的「登录」要向何处申请、审查什么？

意欲经营贷金业者，必须办理登录。申请对象依营业所或事务所的所在而不同。在两个以上都道府县的区域内设置营业所等者，由内阁总理大臣登录（实务上权限委任给有管辖权的财务局长）；仅在一个都道府县的区域内设置者，由管辖该所在地的都道府县知事登录（贷金业法第3条第1项）。登录有有效期间，每3年未更新即因期间经过而失效（同条第2项）。

所谓「贷金业」，指以业务方式进行金钱的贷与或金钱借贷的媒介（包含票据贴现、让渡担保及其他类似方法）。不仅对个人，对企业的融资亦可能属规制对象。仅提供保证与金钱贷与或媒介，须分别确认。无登录经营贷金业将受处罚。审查除下述的财产基础・人员体制・欠格事由外，还会检视是否具备适正遂行贷金业的体制。

| 项目 | 内容 | 根据 |
|---|---|---|
| 申请对象（两个以上都道府县） | 内阁总理大臣（委任财务局长） | 贷金业法第3条第1项 |
| 申请对象（仅一个都道府县） | 所在地之都道府县知事 | 贷金业法第3条第1项 |
| 有效期间 | 3年，须更新 | 贷金业法第3条第2项 |
| 审查支柱 | 财产基础・主任者・欠格事由・遂行体制 | 贷金业法第6条等 |

登录申请文件（向公家机关提出的文件）的制作是行政书士的业务。惟税务代理、税务文件制作与税务咨询属税理士等的资格业务，登录后催收或债权回收的受托・代理则属律师领域。何处为文件制作的支援、何处起为他士业的业务，于本文后半整理。其他审查财产基础的登录型许可，可参考[建设业许可的财产基础・经营业务管理](/zh/legal/column/kensetsugyo-kyoka-yoken-keikan-sengi-zaisan)。

## 净资产5000万日元这项财产基础，要如何证明？

贷金业登录要求具备足以适正遂行业务的财产基础。具体而言，净资产额未达政令所定金额者，登录将被拒绝（贷金业法第6条第1项第14号）。法律就此政令金额规定「不得低于五千万日元」（同条第3项），据此贷金业法施行令第3条之2将金额定为5000万日元。亦即，净资产5000万日元以上为财产基础要件（参照日2026-11-17）。

重要的是，这并非仅于登录时点的要件。净资产额须在经营贷金业的整个期间内维持，登录后若低于此额，将成为监督上的问题。净资产额的计算方法，依第6条第4项授权的施行规则定之：法人以最新事业年度的资产负债表（或代替书面）之净资产部合计额判断，个人以财产调书的资产合计额减去负债合计额判断（净资产额的具体区分与计算依施行规则之规定。参照日2026-11-17）。

| 区分 | 净资产额之基础 |
|---|---|
| 法人 | 最新事业年度资产负债表等之净资产部合计额 |
| 个人 | 财产调书之资产合计减去负债合计之额 |
| 必要额 | 5000万日元以上（施行令第3条之2） |
| 维持 | 不仅登录时，经营期间内均不得低于 |

净资产额的计算伴随会计・税务判断。税务代理、税务文件制作与税务咨询，应委任具资格的税务专业人员。此不表示所有记账或决算书制作均为税理士的独占业务。办理登录申请时，分工为：以税理士制作・确认的计算书类为基础，由行政书士整备申请文件。个别净资产额是否符合要件的最终评价，由登录行政机关依提出文件为之。

## 贷金业务处理主任者在各营业所需要几人？

贷金业者须于各营业所或事务所配置贷金业务处理主任者（贷金业法第12条之3）。所需人数并非定额，而是使该营业所从事贷金业务之人数与主任者人数之比例达50分之1以上的人数。从业人员增加，所需主任者人数也随之增加。此外，主任者须为常驻，各营业所至少须配置1人。

贷金业务处理主任者为国家资格，系通过资格考试并受登录者（考试・登录相关事务由受内阁总理大臣指定的日本贷金业协会办理）。主任者的职务，是对从事贷金业务的使用人及其他从业人员，就遵守法令并适正实施业务所需，提供必要的建议或指导。并不预设仅挂名而不参与实务的「借名」。

| 项目 | 内容 |
|---|---|
| 配置单位 | 各营业所或事务所 |
| 必要数 | 达业务从事人数50分之1以上比例之数（最少1人） |
| 勤务形态 | 常驻 |
| 资格 | 贷金业务处理主任者（国家资格；考试合格＋登录） |
| 职务 | 对从业人员就法令遵守之建议・指导 |

取得资格本身是应考本人的事，行政书士无法代为取得。行政书士能支援的，是以主任者的配置状况为前提的登录申请文件制作。其他审查各营业所责任者・主任者配置的登录例，可参考[电气工事业的登录・营业所・主任电气工事士](/zh/legal/column/denki-koji-gyo-touroku-eigyosho-shunin)。

## 被拒绝登录的事由（欠格）有哪些？

即使符合财产基础与主任者的配置，若该当登录拒绝事由（欠格事由），仍不予登录。贷金业法第6条第1项逐款列举应拒绝登录的情形。代表性者如：因身心故障而无法适正进行贷金业者；受破产程序开始决定而未复权者；被撤销登录未满5年者；受拘禁刑以上之刑执行完毕未满5年者；以及黑道成员等（含脱离黑道未满5年者）。

此外，申请人为法人时，若其董监事或一定使用人中有该当这些欠格事由者，登录将被拒绝。净资产额未达基准者（同项第14号）、欠缺营业所・事务所要件者、未被认定具备适正遂行贷金业所需必要体制者，亦为拒绝对象。受黑道成员等支配其事业活动者亦包含在内。

| 类型 | 内容（例） |
|---|---|
| 身分・状态 | 身心故障；未复权之破产者 |
| 过去处分・前科 | 撤销登录未满5年；拘禁刑以上执行完毕未满5年 |
| 反社会势力 | 黑道成员等；受其支配者 |
| 财产・体制 | 净资产不足；欠缺营业所要件；遂行体制不备 |
| 法人・个人关系人 | 董监事・一定使用人有欠格事由时 |

是否该当欠格事由，须确认前科或过去处分之有无等事实关系，该当与否的最终判断由登录行政机关为之。于申请前确认自身状况是否触及各款，对避免退件或拒绝甚为重要。此确认与申请文件的整备，行政书士可提供支援，但过去处分之当否或法律评价受争执的场面属律师领域。

## 登录后的催收・债权回收，从何处起成为律师的领域？

取得登录并开始放款后，规制仍持续。尤其催收行为受规制，不得威吓债务人等，或以损害其私生活或业务平稳的言行为之（贷金业法第21条的催收行为规制）。回收自家债权本身属贷金业者业务范围，但方法若违反规制，即成为监督上・刑事上的问题。

另一方面，受托代办他人债权之回收，或取得报酬而进行债权回收之代理・交涉或诉讼，则涉及另外的规制。以取得报酬为目的、以业务方式处理他人之法律事务（交涉、诉讼代理等），依律师法第72条禁止非律师为之（非律师执业）；以服务业者（Servicer）方式，以业务方式进行他人特定金钱债权之管理回收，则另须依债权管理回收业特别措置法（Servicer法）取得法务大臣之许可。贷金业登录并不当然许可这些业务。

| 行为 | 承担者・根据 |
|---|---|
| 回收自家债权（适正方法） | 贷金业者；惟服从贷金业法第21条规制 |
| 受托代办他人债权回收 | 须确认律师等的法定业务范围，或已许可Servicer可处理的特定金钱债权范围 |
| 取得报酬之交涉・诉讼代理 | 律师（律师法第72条；禁止非律师执业） |
| 登录申请文件之制作 | 行政书士 |
| 决算书・净资产额・税务 | 税理士 |

因此，角色如下分工。登录要件的确认，与向财务局・都道府县知事登录申请文件的制作支援，由四葉行政書士事務所（行政书士）承担。决算书制作・净资产额计算・税务由税理士，登录后债权回收中属交涉・诉讼，或属代办他人债权回收的部分属律师・Servicer领域，法人设立登记由司法书士，各以独立的事业体分别签约对应。四葉行政書士事務所与四葉不動産株式会社为不同事业体。本所不收取介绍费。业务内容请见[业务内容](/zh/legal/services)，受任流程请见[受任流程](/zh/legal/nagare)，费用请见[报酬额表](/zh/legal/ryokin)。个别登录可否与体制是否充分，由登录行政机关与有资格者衡酌情形判断。

## 常见问题

**Q. 即使只对企业放款，也需要贷金业登录吗？**
A. 若以业务方式进行金钱贷与或其媒介，即使对象是企业，也可能该当贷金业而需登录（贷金业法第3条第1项）。在两个以上都道府县设营业所者向内阁总理大臣（财务局长），仅一个都道府县者向都道府县知事。无登录经营受处罚。是否该当的个别判断，须依交易实态为之。

**Q. 净资产5000万日元只要登录时符合即可吗？**
A. 否。净资产额未达政令金额（5000万日元）者登录将被拒绝（贷金业法第6条第1项第14号、第3项；施行令第3条之2），且此财产基础须在经营期间内维持。登录后若低于，将成为监督上问题。净资产额的计算伴随会计・税务判断，决算书制作与评价请咨询税理士。

**Q. 公司有1名贷金业务处理主任者就够了吗？**
A. 可能不够。主任者须于各营业所或事务所配置，且须以该营业所从事贷金业务人数之50分之1以上比例之数，常驻配置（贷金业法第12条之3）。从业人员众多的营业所，或有多个营业所时，所需主任者人数也增加。

**Q. 登录后，放出去的钱的催收与回收都可自由进行吗？**
A. 否。即使回收自家债权也服从贷金业法第21条规制，禁止威吓或损害平稳之行为。此外，取得报酬而就他人债权回收进行交涉・诉讼须由律师（律师法第72条），以Servicer身份经营特定金钱债权的管理回收，则另须同法之许可。贷金业登录并不当然包含这些。
