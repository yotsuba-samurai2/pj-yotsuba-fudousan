**结论（先讲要点）**：特定技能1号移往2号，是在出入国管理及难民认定法别表第一之二之表的特定技能在留资格中，由1号切换为2号的手续，以同法第20条的在留资格变更许可申请进行。2号是从事须熟练技能业务的在留资格，与1号不同，在留期间无通算上限（可反复3年・1年・6月的更新），满足要件即可带同配偶・子女，亦无受入机关的支援义务。2号的对象为出入国在留管理厅所示的11分野（大楼清洁、工业制品制造业、建设、造船・舶用工业、汽车维修、航空、住宿、农业、渔业、饮食料品制造业、外食业），不含看护。移转的核心要件为通过各分野的2号评价试验，与各分野所定的实务经验。四叶行政书士事务所（申请取次行政书士）在行政书士法第1条之2・第1条之3的范围内，以另行签约承接在留资格变更许可申请的文件制作与取次。移转后的雇用契约・社会保险・劳动条件由社会保险劳务士、各分野的技能试验・实务经验由本人、课税由税理士、在留资格该当性的最终判断由出入国在留管理厅、不许可时的争讼由律师负责，均为独立的事业体并分别签约。本文为一般性信息提供，不保证个别许可。本所不收取介绍费。

## 特定技能2号与1号有何不同？在留期间的更新与家族带同如何改变？

特定技能1号・2号均为出入国管理及难民认定法别表第一之二之表所定的在留资格，但在在留期间・家族带同・支援・所需技能水准上性格分歧。2号是从事「熟练技能」业务的上位架构。

| | 特定技能1号 | 特定技能2号 |
| --- | --- | --- |
| 技能水准 | 须相当程度知识・经验的技能（1号评价试验等） | 熟练技能（各分野的2号评价试验与实务经验） |
| 在留期间 | 1年・6月・4月的更新，通算上限5年 | 3年・1年・6月的更新，无通算上限 |
| 家族带同 | 原则不许可 | 满足要件即可带同配偶・子女 |
| 日本语试验 | 入国时须通过日本语试验 | 移转时原则不课日本语试验（因分野而异） |
| 受入机关的支援 | 制作・实施支援计划（可委托登录支援机关） | 无支援义务 |

最大差异在于在留期间与家族带同。1号在通算5年结束在留，2号只要持续更新即可长期在留，满足要件亦可呼唤家族。惟2号以「熟练技能」为前提，实务上在1号届满5年前，先行推进移转的准备（通过各分野的2号试验与累积实务经验）甚为重要。移转后的雇用契约・社会保险的整备，梳理于社会保险劳务士的[特定技能2号的家族带同与劳务](https://luck428.com/labor/column/tokutei-ginou-2go-kazoku-taido-roumu)（社会保险劳务士为另一事业体）。

## 可移往2号的分野，与所需的技能试验・实务经验要件为何？

可移往2号的分野，为出入国在留管理厅所示的下列11分野。看护非特定技能2号的对象（因看护可以在留资格「看护」等别的架构在留）。汽车运送业・铁道・林业・木材产业等，即使在1号受入，亦有未成为2号对象的分野，故请先确认自己的分野能否进入2号。

| 区分 | 内容 |
| --- | --- |
| 对象分野（11分野） | 大楼清洁、工业制品制造业、建设、造船・舶用工业、汽车维修、航空、住宿、农业、渔业、饮食料品制造业、外食业 |
| 技能试验 | 通过各分野的特定技能2号评价试验（或分野所定的试验，如技能检定1级等） |
| 实务经验 | 各分野所定的实务经验（多数分野要求指导复数作业员而从事的经验，或班长・现场监督等的实务经验） |

分野的区分与2号的试验・实务经验要件，由主管该分野的省厅于各分野运用方针・运用要领中个别订定，且可能修订。例如建设分野，要求班长的实务经验与通过建设分野特定技能2号评价试验等，内容因分野而异。自己的分野能否进入2号、需要哪些试验・经验，请于进入申请准备前，以主管省厅与出入国在留管理厅的最新公表资料确认。移转常自[由技能实习移往育成就劳・特定技能与管理・支援机关](https://luck428.com/legal/column/ginou-jisshu-ikusei-shuro-ikou-kanri-shien-kikan-kyoka)的路径接续，1号期间的支援梳理于[登录支援机关的登录与支援计划](https://luck428.com/legal/column/toroku-shien-kikan-touroku-shien-keikaku)。

## 在留资格变更许可申请要哪些文件？何时・何人取次？

1号移往2号，以出入国管理及难民认定法第20条的在留资格变更许可申请进行。此为将现有在留资格（特定技能1号）变更为2号的申请，须于在留期间届满前，满足分野的要件（通过2号试验・实务经验）后申请。于中国・台湾等发行的文件，有时须日文翻译与必要之认证。主要文件如下，样式・份数因分野而异。

- 在留资格变更许可申请书、照片、在留卡・护照的提示
- 各分野2号评价试验的合格证明、显示技能检定等合格的书面
- 显示实务经验的书面（在职证明、显示职务内容・从事期间的书面）
- 雇用契约书・特定技能雇用契约相关书面、报酬的说明资料
- 受入机关（所属机关）的登记事项证明书・决算书类等显示事业实在・规模的资料
- 住民税的课税・纳税证明书、显示社会保险加入的资料等

申请的取次，由已提出申请取次申报的行政书士（或律师）代本人向地方出入国在留管理官署提出申请文件（行政书士法第1条之2・第1条之3）。在留资格该当性或是否符合要件的最终审查・判断由出入国在留管理厅为之，本所不对结论或法律见通作断定。具体样式・份数・标准处理期间，请于申请前以出入国在留管理厅的最新指引确认。受任流程请见[受任流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)，承办业务请见[承办业务一览](https://luck428.com/legal/services)。

## 在留手续・移转后劳务・技能试验，分别委托给谁？

移往特定技能2号，在在留手续・劳务・试验・物件上，负责的专家各不相同。四叶集团中，行政书士・社会保险劳务士・不动产各为独立的事业体，以分别签约为前提。负责如下。

- 在留资格变更许可申请的文件制作・取次 → 申请取次行政书士（行政书士法第1条之2・第1条之3；本所）
- 移转后的雇用契约・劳动条件通知・社会保险・就业规则的整备 → 社会保险劳务士（另一事业体）
- 各分野2号评价试验的应试・实务经验的累积 → 本人・受入机关
- 所得税・住民税、租税条约的处理 → 税理士
- 在留资格该当性的最终判断 → 出入国在留管理厅
- 遭不许可时的争讼、个别法律见通 → 律师
- 住居的租赁・购买、社宅的安排 → 另一事业体的四叶不动产株式会社（宅地建物交易业者）

各领域均以与各窗口・有资格者分别签约为前提，本所不收取介绍费。转职或所属机关变更所伴随的社会保险・雇用保险手续，梳理于社会保险劳务士的[特定技能的转职・转籍与社会保险・雇用保险的交接](https://luck428.com/labor/column/tokutei-ginou-tenshoku-tenseki-shakaihoken-koyohoken-hikitsugi)（社会保险劳务士为另一事业体）。欲追求更上位在留者，[高度专门职1号移往2号的要件（中国・台湾的专门职向）](https://luck428.com/legal/column/kodo-senmonshoku-2go-ikou-youken-chuka-taiwan)亦可参考。

## 常见问题

**Q. 在特定技能1号的5年结束前移往2号，即可一直在留吗？**
A. 特定技能2号无在留期间的通算上限，可以3年・1年・6月的循环持续更新，故只要持续满足要件即可长期在留。惟2号以「熟练技能」为前提，须通过各分野的2号评价试验与实务经验。因1号有通算5年的上限，实务上于届满前满足试验合格与实务经验要件，并完成第20条的在留资格变更许可申请甚为重要。是否符合的最终判断由出入国在留管理厅为之。

**Q. 我的分野能进入特定技能2号吗？看护如何？**
A. 2号的对象为出入国在留管理厅所示的11分野（大楼清洁、工业制品制造业、建设、造船・舶用工业、汽车维修、航空、住宿、农业、渔业、饮食料品制造业、外食业），不含看护（因看护可以在留资格「看护」等别的架构在留）。汽车运送业・铁道・林业・木材产业等，即使在1号受入，亦非2号对象。对象分野与试验要件可能修订，请以主管省厅与出入国在留管理厅的最新公表资料确认。

**Q. 成为特定技能2号后，能将家族接来日本吗？**
A. 特定技能2号满足要件，即可将配偶与子女以「家族滞在」带同（1号原则不许可家族带同）。带同有可扶养的收入等个别要件，由出入国在留管理厅审查后判断。移转后的收入・社会保险的整备由社会保险劳务士、住居的安排由另一事业体的四叶不动产株式会社负责，均为独立的事业体并分别签约。带同的可否与要件可能修订，请于申请前以最新指引确认。

**Q. 从在留资格变更到入职后的雇用契约・社会保险，能否委托同一事务所一并处理？**
A. 在留资格变更许可申请的文件制作・取次由申请取次行政书士、移转后的雇用契约・劳动条件・社会保险由社会保险劳务士、所得税・租税条约由税理士、在留资格该当性的最终判断由出入国在留管理厅、不许可时的争讼由律师、住居由另一事业体的四叶不动产株式会社负责，均为独立的事业体并分别签约。虽可于一个窗口受理咨询并整理交付各专家，但受任系分开。本所不收取介绍费。
