**先讲重点：** 要以营业方式经营桑拿、钱汤或水疗，须取得公众浴场法的营业许可。凡以营业方式经营公众浴场者，须向都道府县知事（设有保健所的市、特别区为市长、区长）取得许可（公众浴场法第2条第1项）。当设置场所、构造设备被认定在公众卫生上不适当等情形时，可能不予许可（同条第2项），而构造设备与卫生措施的具体标准委任给各都道府县的条例（第2条第3项、第3条第2项）。并以符合用途地域、用途变更（建筑基准法）与消防法令为前提。本文整理许可的条件与流程，是否核准由保健所审查决定。本事务所不保证取得许可。

## 桑拿、钱汤的营业许可依据什么法律？

以营业方式经营公众浴场，须取得公众浴场法（昭和23年7月12日法律第139号）所定都道府县知事的许可。同法第1条将「公众浴场」定义为，使用温汤、潮汤或温泉等使公众入浴的设施。钱汤、桑拿（附冷水池等浴槽者）、超级钱汤，只要符合此定义即为公众浴场。

许可权者为都道府县知事。但在设有保健所的市（政令市、中核市等）及特别区，权者为市长、区长（公众浴场法第2条第1项）。知事等在认定设置场所、构造设备于公众卫生上不适当，或设置场所欠缺配置的适正时，可不予许可（同条第2项）。由于构造设备的标准（换气、采光、照明、保温、清洁等入浴者卫生与风纪所需的措施）委任给都道府县的条例（同法第3条第1项、第2项），数值与区划须以开业地的条例与保健所的手册确认。

此外，仅以蒸气、热气而不设浴槽（含冷水池）的一部分桑拿设施是否须取得公众浴场法的许可，会因设施形态而由各地方政府作不同判断。此点在撰文之前先向开业地的保健所事前咨询确认最为确实。因本社无法确认，此处仅止于「设有浴槽的桑拿、钱汤、水疗属公众浴场」的一般性处理。

## 一般公众浴场与「其他公众浴场」的许可有何不同？

公众浴场在运用上分为「一般公众浴场」与「其他公众浴场」两类处理。前者即所谓钱汤，作为地域日常生活所需的设施，入浴料金受知事统制（依物价统制令＝昭和21年勅令第118号）。后者为桑拿、超级钱汤、健康乐园、个室附浴场等，可自由设定料金的类型。

| | 一般公众浴场（钱汤） | 其他公众浴场（桑拿等） |
| --- | --- | --- |
| 依据法律 | 公众浴场法第2条第1项 | 公众浴场法第2条第1项 |
| 入浴料金 | 由知事统制（物价统制令） | 可自由设定 |
| 配置基准（距离限制） | 为条例距离限制的对象 | 原则上非对象 |
| 构造设备、卫生措施 | 须符合条例标准 | 须符合条例标准 |

最大的不同在于配置基准（距离限制）与料金。公众浴场法第2条第3项将设置场所的配置基准委任给都道府县的条例。此距离限制以一般公众浴场（钱汤）为对象，桑拿等「其他公众浴场」原则上非此距离限制的对象。惟构造设备、卫生措施的标准两者皆须遵守，此点桑拿亦不获免除。自己的设施以哪一类型受审查，取决于营业形态与条例的规定，故向保健所确认。

## 申请需要哪些图面、文件？

营业许可申请除申请书外，还须设施的图面与载明设备内容的文件。格式、份数因地方政府而异，代表性者如下。

| 文件 | 内容概要 |
| --- | --- |
| 营业许可申请书 | 营业者、设施所在地、营业种别等 |
| 设施的平面图、配置图 | 浴室、脱衣室、厕所、洗面的位置与尺寸 |
| 给排水、循环过滤设备的系统图 | 给汤、排水、循环过滤、氯消毒的路径 |
| 换气设备的图 | 浴室、脱衣室的换气路径 |
| 使用水的水质相关资料 | 使用井水等时的水质检查结果等 |
| 登记事项证明书等 | 法人时证明资格的文件 |

设置循环式浴槽时，退伍军人杆菌（Legionella）的对策为审查重点。厚生劳动省的「公众浴场卫生等管理要领」（平成12年12月15日 生卫发第1811号；令和2年12月10日 生食发第1210001号修正）载明循环过滤装置的清洗、配管内生物膜的去除、贮汤槽的适温管理等。须依此要领与各都道府县的条例，自设备设计阶段起即纳入卫生措施。

## 保健所检查与消防、建筑的确认如何并行？

公众浴场的开业，保健所（许可）、消防署（消防法令）、建筑（用途地域、用途变更）三个窗口分别运作。仅其中一项备妥并无法开始营业。

在消防方面，公众浴场（含蒸气浴场、热气浴场）属消防法施行令别表第1所列的防火对象物，须依规模、收容人数设置消防用设备等（自动火灾报知设备、诱导灯、灭火器等）。在建筑确认、许可的场面，涉及消防长、消防署长的同意（消防法第7条）。

在建筑方面，公众浴场为建筑基准法上的特殊建筑物（建筑基准法第2条第2号）。将既有建物改为公众浴场时，若进行用途变更使供该用途的部分楼地板面积合计超过200㎡，须办理确认申请（建筑基准法第87条第1项；将须确认的规模由超过100㎡放宽至超过200㎡的修正于令和元年6月25日施行）。与旅馆、酒店相同，亦有依用途地域的立地限制。在签订物件合同之前，先确认用途地域与用途变更的可行性、消防用设备的要否，对防止返工很重要。相近论点也整理于[旅馆业（简易宿所）的营业许可](https://luck428.com/legal/column/ryokangyo-kani-shukujo-kyoka-shinsei)。

## 许可申请、建筑、物件，应各自委托给谁？

公众浴场的开业横跨多个专业领域。分工如下。

- 公众浴场营业许可申请书、附件文件的制作，以及与保健所事前咨询的支援 → 四叶行政书士事务所（行政书士）
- 事业用物件的选定、租赁、重要事项说明 → 四叶不动产株式会社
- 建筑物的用途、确认申请、用途变更、检查完成证的确认 → 建筑士、特定行政厅
- 消防用设备等的设计、工程，消防同意、检查 → 消防设备士、消防机关
- 建物与事业的会计、税务 → 税理士
- 涉及权利义务与纠纷的个别法律判断 → 律师

四叶行政书士事务所与四叶不动产株式会社为不同的事业体。本事务所仅以独立的事业体承办公众浴场营业许可的申请支援，物件、建筑、消防、税务请与各专业人士、行政窗口分别签约、咨询。本事务所不收取介绍费。许可的整体样貌请见[行政许可手续](https://luck428.com/legal/services)，受任流程请见[受任流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)。若并设餐饮，请见[餐饮店营业许可与保健所的设备标准](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)；若涉及住宿，另请确认[民宿（住宅宿泊事业）的申报](https://luck428.com/legal/column/minpaku-jutaku-shukuhaku-todokede-yoken)。是否核准许可本身由保健所判断。

## 常见问题

**Q. 桑拿与钱汤是同一种许可吗？**
A. 依据同为公众浴场法第2条第1项的许可，但运用上的类型不同。钱汤为「一般公众浴场」，入浴料金受知事统制（物价统制令），并为条例距离限制的对象。桑拿、超级钱汤等为「其他公众浴场」，料金可自由设定，距离限制原则上非对象。惟构造设备、卫生措施的条例标准两者皆须遵守。

**Q. 设置循环式浴槽会使审查变严吗？**
A. 退伍军人杆菌对策会成为重点。厚生劳动省的「公众浴场卫生等管理要领」（平成12年12月15日 生卫发第1811号；令和2年12月10日修正）载明循环过滤装置的清洗、配管内生物膜的去除、贮汤槽的管理等。因须有符合此要领与各都道府县条例的设备与运用，故自设计阶段起即纳入卫生措施。

**Q. 将办公大楼的一室改为桑拿也能营业吗？**
A. 须确认用途地域与用途变更。公众浴场为建筑基准法上的特殊建筑物，供该用途的部分超过200㎡的用途变更须办理确认申请（建筑基准法第87条第1项）。亦有依用途地域的立地限制。可否由特定行政厅、建筑士判断，故在签订物件合同之前先确认可行性。

**Q. 到取得许可需要多久？**
A. 因设施规模、所需工程，以及与保健所、消防、建筑各窗口的协调状况而异，无法一概而论。多数地方政府的流程为：动工前的事前咨询→图面等的确认→工程→完成后的现地检查→许可。标准处理期间与必要文件，请于开业地保健所的官方网页确认。
