**先说结论：** 要出售继承的老家（空房）并使用「空房转让所得的3,000万日元特别扣除」（租税特别措置法第35条第3项），须在确定申告书中附上「被继承人居住用家屋等确认书」。该确认书由所出售房屋、土地所在地的市区町村长核发（国税厅、国土交通省的指引，参照日2026-10-31）。申请核发时，须附上被继承人的除票住民票、可确认电气、燃气、自来水停用（闭栓）日的书类、买卖合同的复印件等。本文为向官公署提出书类作成范围内的一般信息提供，不就特例可否作税务判断，也不办理税额计算、申告。

## 「被继承人居住用家屋等确认书」为何必要？要向何处申请？

空房转让所得的3,000万日元特别扣除，是在一定要件下出售所继承被继承人的居住用房屋（或其基地）时，可从转让所得扣除最高3,000万日元的特例（租税特别措置法第35条第3项、同法施行令第20条之3、同法施行规则第18条之2）。欲适用该特例，须在确定申告书附上「被继承人居住用家屋等确认书」（国税厅「No.3306」，参照日2026-10-31）。

确认书并非由税务署，而是由所出售房屋、土地所在地的市区町村长核发。也就是说，税的申告向税务署，证明特例前提事实的确认书向市区町村，窗口有所区分。确认书是市区町村以书类确认该房屋属于「被继承人的居住用房屋」，且自继承时起至转让时止为空房等事实的证明。

| 项目 | 内容 |
| --- | --- |
| 依据 | 租税特别措置法第35条第3项（施行令第20条之3、施行规则第18条之2） |
| 确认书的核发者 | 所出售资产所在地的市区町村长 |
| 提出对象与用途 | 附于确定申告书向税务署提出（特例适用要件之一） |
| 扣除额 | 最高3,000万日元（令和6年1月1日以后的转让，取得的继承人为3人以上时为2,000万日元） |

特例实际可否适用的判断与税额计算、申告属于税理士领域。本事务所（行政书士）就确认书的核发申请书类的作成、提出范围协助。

## 可核发确认书的房屋要件（建筑年份、非区分所有、空房）如何整理？

确认书是以所出售房屋符合特例对象的「被继承人居住用家屋」事实为前提而核发。国税厅所示主要要件如下（No.3306，参照日2026-10-31）。

| 要件 | 内容 |
| --- | --- |
| 建筑时期 | 昭和56年5月31日以前建筑 |
| 非区分所有 | 非属已办理区分所有建物登记的建物 |
| 继承前的居住 | 继承开始的直前，除被继承人外无人居住（限主要由被继承人居住的一栋建筑物） |
| 空房的持续 | 自继承时起至转让时止，未供事业、出租、居住之用 |
| 适用期间 | 平成28年4月1日至令和9年12月31日之间的转让 |
| 转让对价 | 转让对价额为1亿日元以下（与其他继承人的转让分等合计判断） |

被继承人于继承开始直前入住养老院等设施时，若符合曾受要介护认定等一定要件，仍可能成为对象。此时须另附显示入住事实与要介护认定的书类。符合何种要件的最终认定与税务判断，请向税理士确认。

## 申请时须附上哪些书类？

向市区町村申请核发确认书时，须在申请书附上如下书类（各市区町村的核发要纲，参照日2026-10-31。名称、份数因自治体而异）。

| 区分 | 主要书类 |
| --- | --- |
| 确认继承与居住 | 被继承人的除票住民票、继承人的住民票 |
| 确认曾为空房 | 可确认电气、燃气、自来水停用（闭栓）日的书类，如闭栓证明或停用联络票等。停用日须为继承开始日以后者 |
| 确认转让 | 买卖合同的复印件 |
| 入住养老院的情形 | 显示要介护认定、设施入住事实的书类 |

若电气、燃气、自来水的停用日早于继承开始日，将无法显示继承时为空房，可能无法受理确认。宜及早在手边确认闭栓日的记录。所需书类因自治体而异，也可能被要求补充，申请前请以物件所在地市区町村的最新指引确认。

## 拆除后出售与抗震改修后出售，书类有何不同？

本特例大致分为(1)将房屋抗震改修后（以具抗震性的房屋）出售的类型，与(2)将房屋拆除后仅出售土地的类型，确认书的格式也依转让态样而分。

- 抗震改修后出售：须于转让时符合一定抗震基准。令和6年1月1日以后的转让，于转让之日所属年度的次年2月15日前符合基准者也为对象。须附抗震基准适合证明书及工程相关书类。
- 拆除后出售土地：须自继承时起至拆除等时止、自拆除等时起至转让时止，均符合要件。须附显示建物拆除的书类（闭锁事项证明书等）。令和6年1月1日以后的转让，于转让之日所属年度的次年2月15日前完成拆除等者也为对象。

| 转让态样 | 要件要点 | 主要补充书类 |
| --- | --- | --- |
| 抗震改修后出售 | 转让时符合抗震基准（令和6年以后的转让，次年2月15日前符合亦可） | 抗震基准适合证明书、工程相关书类 |
| 拆除后出售土地 | 继承时至拆除时、拆除时至转让时的要件（令和6年以后的转让，次年2月15日前拆除等亦可） | 显示建物拆除的书类（闭锁事项证明书等） |

属于何种格式及书类的过与不足，与市区町村及税理士确认。本文仅就制度框架提供信息，不就个别情形认定。

## 扣除可否的判断、申告该找谁，灭失登记与买卖又该找谁？

空房的出售，与确认书的取得并行推进税务、登记、买卖。角色区分如下，各以独立的事业体分别签约、分别办理。

- 被继承人居住用家屋等确认书的核发申请书类的作成、提出 → 四叶行政书士事务所（行政书士）。仅提供资料与信息，不作具体法律判断、税务判断
- 特例可否的判断、税额计算、确定申告 → 税理士。本事务所不作税务判断、不办理申告
- 建物拆除后的建物灭失登记（表示相关登记） → 土地家屋调查士
- 继承登记（所有权转移登记） → 司法书士
- 空房出售的中介 → 另一事业体的四叶不动产股份有限公司（宅地建物交易业者），以独立的事业体依另行合同对应
- 遗产分割的争议显在化时 → 律师

出售的咨询，由与四叶行政书士事务所分属不同事业体的四叶不动产股份有限公司，以独立的事业体依另行合同对应。特例适用可否、税额计算、申告由税理士，建物灭失登记由土地家屋调查士，继承登记由司法书士，争议由律师，均以独立的事业体分别签约、分别办理。各领域均以与各窗口、资格者分别签约为前提，本事务所不收取介绍费。即使在不确定闭栓日或建筑年份要件的阶段，也请于决定出售方式之前咨询。受任流程请见[受任流程](https://luck428.com/legal/nagare)，费用请见[报酬额表](https://luck428.com/legal/ryokin)，继承承办业务请见[继承业务介绍](https://luck428.com/legal/services/inheritance)，继承综合介绍请见[继承咨询](https://luck428.com/souzoku)。相关文章另请参见[继承登记的流程](https://luck428.com/legal/column/souzoku-touki-nagare)、[遗产分割协议书的作成方式](https://luck428.com/legal/column/isan-bunkatsu-kyougisho)、[继承手续的起步与户籍调查](https://luck428.com/legal/column/souzoku-hajime-koseki-chosa-bunkyo)。

## 常见问题

**Q. 被继承人居住用家屋等确认书在哪里取得？**
A. 由所出售房屋、土地所在地的市区町村长核发（国税厅「No.3306」，参照日2026-10-31），而非税务署。将取得的确认书附于确定申告书，以适用特例（租税特别措置法第35条第3项）。申请窗口与格式因自治体而异，请以物件所在地市区町村的最新指引确认。

**Q. 电气、燃气的闭栓日为何重要？**
A. 因特例以自继承时起至转让时止为空房为前提，市区町村以可确认电气、燃气、自来水停用（闭栓）日的书类确认空房事实。停用日须为继承开始日以后者，若停用早于继承开始日，可能无法受理确认。宜及早在手边确认闭栓日的记录。

**Q. 拆除后出售与不拆除出售，书类不同吗？**
A. 不同。拆除后出售土地须附显示建物拆除的书类（闭锁事项证明书等），抗震改修后出售须附抗震基准适合证明书，确认书的格式也分。令和6年1月1日以后的转让，于转让之日所属年度的次年2月15日前完成拆除等或符合抗震基准者也为对象。属于何者请向市区町村与税理士确认。

**Q. 行政书士也会计算税金吗？**
A. 不会。特例可否的税务判断与税额计算、确定申告属于税理士领域。本事务所（行政书士）就被继承人居住用家屋等确认书的核发申请书类的作成、提出范围协助。税务由独立的事业体的税理士分别签约。本事务所不收取介绍费。
