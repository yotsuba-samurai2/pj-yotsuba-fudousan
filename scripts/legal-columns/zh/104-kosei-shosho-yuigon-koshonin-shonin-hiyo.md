**结论（先讲要点）：**公正证书遗嘱，是在2名以上证人在场下，由遗嘱人将遗嘱要旨口授公证人、由公证人笔记而作成的遗嘱（民法第969条）。因有公证人参与、原本由公证役场保管，较不致因方式瑕疵而无效，且遗嘱人死亡后无须家庭裁判所的检认。公证人手续费依公证人手续费令定之，就以继承、遗赠受领财产之人分别将其受领的目的价额套入表格计算后合计，目的价额合计1亿日元以下时另加遗嘱加算。证人有欠格事由：推定继承人、受遗人及其配偶、直系血亲不得担任（民法第974条）。本文为一般性信息，不就应将何财产遗予何人等遗嘱的法律效果作最终判断。四叶集团的行政书士，以独立的事业体承办遗嘱原案的拟订支援、必要文件的收集、与公证役场的日程协调，以及证人的安排。继承人间有争执时的对应与法律效果的最终判断属律师，遗嘱执行后的继承登记、遗赠登记属司法书士，继承税与纳税资金的试算属税理士，继承不动产的出售属不同事业体的不动产业者，各自分别签约。

## 公正证书遗嘱与自书遗嘱相比，何以较为确实？

公正证书遗嘱的特色，在于由法律专家公证人参与作成。民法第969条定其方式：2名以上证人在场、遗嘱人向公证人口授遗嘱要旨、公证人笔记并向遗嘱人与证人宣读（或阅览）、遗嘱人与证人签名盖章、公证人附记并签名盖章。因原本由公证役场保管，无遗失、篡改之虞，因方式瑕疵而无效的风险甚小。

| 项目 | 公正证书遗嘱 | 自书遗嘱 |
| --- | --- | --- |
| 作成 | 公证人参与（民法第969条） | 遗嘱人亲笔书写全文、日期、姓名并盖章 |
| 证人 | 须2名以上 | 不须 |
| 保管 | 公证役场保管原本 | 自宅保管，或法务局的保管制度 |
| 检认 | 不须 | 原则须（以法务局保管者免） |
| 费用 | 须公证人手续费 | 作成本身不生费用 |

自书遗嘱虽简便，惟仍有方式瑕疵与保管的疑虑。两者的差异与法务局的保管制度，已于[自书遗嘱与公正证书遗嘱的差异](https://luck428.com/legal/column/jihitsu-kosei-yuigon)整理。何者适合，依财产内容、继承人状况与对费用的考量而异。亦请参阅本事务所的[继承、遗嘱案内](https://luck428.com/legal/services/inheritance)。

## 公证人手续费依财产额如何决定？

公证人手续费为依公证人手续费令（第9条别表）所定的公定费用，就以继承、遗赠受领财产之人分别将其受领的价额（目的价额）套入表格计算后合计。2025年（令和7年）10月1日改定后的金额如下。

| 目的价额 | 手续费 |
| --- | --- |
| 100万日元以下 | 5,000日元（其中50万日元以下为3,000日元） |
| 逾100万至200万日元以下 | 7,000日元 |
| 逾200万至500万日元以下 | 13,000日元 |
| 逾500万至1,000万日元以下 | 20,000日元 |
| 逾1,000万至3,000万日元以下 | 26,000日元 |
| 逾3,000万至5,000万日元以下 | 33,000日元 |
| 逾5,000万至1亿日元以下 | 49,000日元 |
| 逾1亿至3亿日元以下 | 49,000日元，每超过5,000万日元加15,000日元 |
| 逾3亿至10亿日元以下 | 109,000日元，每超过5,000万日元加13,000日元 |

此外，目的价额合计1亿日元以下时，另加遗嘱加算13,000日元。正本、誊本的交付，电子资料每1通2,500日元、书面每1张300日元（原本逾3张者，每超过1张加300日元）。于遗嘱人病床作成者加计手续费的50%，公证人赴自宅、设施等出张者，须日当（每日2万日元、4小时以内1万日元）与交通费。例如将6,000万日元遗予配偶、4,000万日元遗予长男的遗嘱，约为配偶分49,000日元＋长男分33,000日元＝82,000日元，再加遗嘱加算13,000日元＝95,000日元为概估。因实际金额随财产评价而变动，作成前于公证役场确认。继承不动产的评价属税理士、不动产领域，本事务所的[报酬表](https://luck428.com/legal/ryokin)另行定之。

## 2名证人可委托何人？何人不得担任证人？

公正证书遗嘱须2名以上证人在场（民法第969条），惟非人人均得担任证人。民法第974条将下列之人定为证人、在场人的欠格事由。

| 款 | 不得担任证人之人 |
| --- | --- |
| 第1款 | 未成年人 |
| 第2款 | 推定继承人、受遗人，及其配偶与直系血亲 |
| 第3款 | 公证人的配偶、四亲等内亲属、书记及受雇人 |

易言之，处于受领财产立场的家属，及其配偶、子女等，均不得担任证人。身边无适任者时，公证役场亦有介绍证人的作法。四叶集团的行政书士，身负保密义务，得受托安排证人或以证人身分在场。因得否担任证人，与推定继承人、受遗人范围的确认相关联，故与继承关系的整理一并进行为实务作法。

## 至当日须收集的文件，及公证役场的流程为何？

公正证书遗嘱，系于确定原案后与公证人事前协商，并于当日在2名证人在场下作成。预先备妥如下文件（因公证役场而异）。

| 区分 | 主要文件 |
| --- | --- |
| 遗嘱人本人 | 印鉴登记证明书等本人确认资料 |
| 遗予继承人时 | 显示遗嘱人与继承人关系的户籍（户籍誊本等） |
| 遗赠予继承人以外者时 | 受遗人的住民票等 |
| 财产资料 | 不动产的登记事项证明书、固定资产评价证明书，存款等资料 |

当日，遗嘱人向公证人口授遗嘱要旨，公证人将笔记内容向遗嘱人与证人宣读或令其阅览，若无误则全体签名盖章。自2025年（令和7年）10月1日起，依公证人法的改正（令和5年法律第53号），公正证书的作成手续已数位化，于指定公证役场得循序利用网络会议（远程方式）及以电子资料作成、交付。得否利用，须向公证役场确认。四叶集团的行政书士，承办原案拟订支援、必要文件收集与公证役场的日程协调。

## 作成后若改变心意，遗嘱可否改写？

遗嘱于作成后仍得随时改写。民法第1022条规定，遗嘱人得随时依遗嘱方式撤回其遗嘱的全部或一部。前遗嘱与后遗嘱抵触的部分，视为以后遗嘱撤回（民法第1023条）。

| 情形 | 处理（依据） |
| --- | --- |
| 欲变更内容 | 得随时以新遗嘱撤回、变更（民法第1022条） |
| 前后遗嘱抵触 | 抵触部分视为以后遗嘱撤回（民法第1023条） |
| 撤回公正证书遗嘱 | 得以新遗嘱（公正证书或自书均可）撤回 |

撤回公正证书遗嘱，毋须将前公正证书实体销毁，而以新遗嘱表示其意思。撤回或数遗嘱并存时的优劣，已于[遗嘱的撤回、抵触与数遗嘱的优劣](https://luck428.com/legal/column/yuigon-tekkai-teishoku-fukusu-yuigon-yuretsu)整理。是否须改写，宜参酌家庭结构与财产的变动定期检视为妥。

## 原案、登记、税务、争执各该委托何人（分工）？

因相关专业人员分属不同领域，原则上请与各专业以独立的事业体分别签约。四叶集团的行政书士，以独立的事业体承办遗嘱原案的拟订支援、必要文件的收集、与公证役场的日程协调，以及证人的安排。

| 委托对象 | 主要角色 |
| --- | --- |
| 行政书士（本事务所） | 原案拟订支援、文件收集、日程协调、证人安排 |
| 公证人 | 公正证书遗嘱的作成、原本的保管 |
| 律师 | 继承人间有争执时的对应、法律效果的最终判断 |
| 司法书士 | 遗嘱执行后的继承登记、遗赠登记 |
| 税理士 | 继承税、纳税资金的试算 |
| 不动产业者（属不同事业体的本公司） | 继承不动产的出售、活用咨询 |

遗嘱“何财产遗予何人”的法律效果最终判断，属具资格者的领域，行政书士不得代为判断或保证。涉及继承不动产出售时，亦得利用由不同事业体的不动产业者所设的[继承不动产咨询窗口](https://luck428.com/souzoku)。亦请参阅本事务所的[受任流程](https://luck428.com/legal/nagare)。与各专业人员均以独立的事业体签约，彼此不收取介绍费。

## 常见问题

**Q. 订立公正证书遗嘱后，死亡后的检认即可免除吗？**
A. 是。公正证书遗嘱由公证人作成、原本由公证役场保管，故无须家庭裁判所的检认。自书遗嘱原则上须检认，惟利用法务局的自书遗嘱保管制度者则免检认。检认的要否，依遗嘱方式与保管方法而异。

**Q. 手续费是以财产总额乘以单一费率而定吗？**
A. 否。依公证人手续费令，就以继承、遗赠受领财产之人分别将其受领价额套入别表计算后合计。目的价额合计1亿日元以下时另加遗嘱加算13,000日元，正本、誊本的交付与出张另计费用。正确金额以财产评价为据于公证役场确认。

**Q. 可否委托家属担任证人？**
A. 受领财产的推定继承人、受遗人，及其配偶、直系血亲，均不得担任证人（民法第974条）。未成年人及公证人的近亲等亦不得。无适任者时，公证役场有介绍证人之例，身负保密义务的行政书士亦得受托安排证人或在场。

**Q. 已订立的公正证书遗嘱可否日后变更？**
A. 可。遗嘱人得随时依遗嘱方式撤回全部或一部（民法第1022条）。若作成与前遗嘱抵触的新遗嘱，抵触部分视为以后遗嘱撤回（第1023条）。毋须销毁前公正证书，而以新遗嘱表示其意思。
