**先说结论：** 若您不拥有自己的卡车，而是安排其他企业的运送来承揽货物（利用运送），需要办理日本《货物利用运送事业法》上的手续。以卡车进行的利用运送，以及不含集配的海运、空运、铁路利用运送，办理向国土交通大臣的"第一种货物利用运送事业"登录（第3条第1项）即可。相对地，若将海运、空运、铁路运送与其前后的集配（卡车取货、送货）一贯承揽，则需"第二种货物利用运送事业"许可（第20条）。本文为一般性信息，梳理第一种与第二种的分界、财产基础（净资产300万日元以上），以及与一般货物运送的差异。个别登录、许可能否核准，取决于运输局的审查。

## 第一种登录与第二种许可有何不同？

货物利用运送事业，是指自己不拥有运送工具（船舶、飞机、铁路车辆、卡车），而是利用实际运送企业（实运送企业）的运送，对货主承揽运送的事业。《货物利用运送事业法》（平成元年法律第82号）将其分为"第一种"与"第二种"。

| 类别 | 手续 | 对象事业（要旨） |
| --- | --- | --- |
| 第一种 | 国土交通大臣的**登录**（第3条第1项） | 第二种以外的利用运送。卡车利用运送，以及不含集配的海运、空运、铁路利用运送 |
| 第二种 | 国土交通大臣的**许可**（第20条） | 利用海运、空运、铁路企业的运送，并将其前后的集配（卡车收送）一贯承揽 |

分界在于"是否连同集配，将海运、空运、铁路运送一贯承揽"（第2条第7项、第8项的定义）。仅安排港到港的集装箱运送属第一种；自货主仓库取货、以船运送、于到达地以卡车配送一贯承揽则属第二种。本所在行政书士业务范围内，协助确认属何种类、制作与提交申请文件。个别能否核准取决于运输局的审查。

## 第一种登录需要的财产基础与营业所要件为何？

第一种登录，以不落入第6条的登录拒绝事由为条件。实务上最常出问题的是财产基础（同条第7款）与设施（同条第6款）。

| 事项 | 内容（要旨） |
| --- | --- |
| 财产基础 | 依施行规则第8条，以**净资产300万日元以上**为基准。刚成立、尚未结算的法人，资本金300万日元以上即视为符合 |
| 营业所 | 须有使用权原，且符合《城市规划法》《建筑基准法》等相关法令 |
| 保管设施 | 若进行保管，须确保适合保管货物的设施；不进行保管则不需要 |
| 消极资格 | 不得落入第6条第1项各款 |

登录后，须缴纳登录免许税（《登录免许税法》别表第一；金额请于撰写时点确认）。营业所与保管设施须先确认用途地区与使用权原，建议在签约前先对照要件。物件方面的要件，另请参考属别事业体的四叶不动产所整理的[运送业营业所、车库的物件要件](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

## 第二种许可要做国际运送或集配需要什么？

第二种许可（第20条）适用于将海运、空运、铁路运送与卡车集配一贯组合的事业。许多国际海运、国际空运的承揽企业（forwarder）会取得此许可。

| 事项 | 内容（要旨） |
| --- | --- |
| 财产基础 | 与第一种相同，以**净资产300万日元以上**为基准 |
| 集配体制 | 就集配区域，以及承担集配的运送（自行的货物汽车运送，或委托其他运送企业），规划出可确保运送安全的体制 |
| 营业所、保管设施 | 确保遂行事业所需的设施 |
| 许可、登录免许税 | 许可后缴纳登录免许税（别表第一；金额请于撰写时点确认） |

国际运送另有利用外国实运送企业时的处理、国际约款的申报等，与纯国内案件不同的论点。第二种与第一种的差别在于"一贯承揽集配"，若以自家卡车进行集配，还须一并设计是否需要一般货物汽车运送事业许可。

## 一般货物（绿牌）与利用运送如何区分使用？

依"以自家卡车运送"或"安排其他企业运送"，所需手续根本不同。

| 事业形态 | 所需手续 | 依据 |
| --- | --- | --- |
| 以自家卡车（绿牌）有偿运送 | 一般货物汽车运送事业的**许可** | 《货物汽车运送事业法》第3条 |
| 以轻型卡车（黑牌）有偿运送 | 货物轻汽车运送事业的**申报** | 《货物汽车运送事业法》 |
| 不拥有车辆而安排其他企业运送（卡车、国内） | 第一种货物利用运送事业的**登录** | 《货物利用运送事业法》第3条第1项 |
| 将海运、空运、铁路加集配一贯承揽 | 第二种货物利用运送事业的**许可** | 《货物利用运送事业法》第20条 |

以自家车辆运送的一般货物要件（营业所、车库、最低车辆数等），请见[一般货物汽车运送事业的许可｜营业所、车库要件](https://luck428.com/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)；轻货物（黑牌）的申报请见[货物轻汽车运送事业的申报](https://luck428.com/legal/column/keikamotsu-kei-jidosha-unso-todokede)。是否仅需利用运送，抑或还需运送业许可，取决于是否自行运送货物。

## 从申请到开业的流程为何？

第一种（登录）与第二种（许可）流程相似，但审查轻重不同。

| 阶段 | 内容、基准 |
| --- | --- |
| 事前确认 | 确认属第一种或第二种、是否符合财产基础（净资产300万日元以上）、能否确保营业所与保管设施 |
| 提交申请 | 向管辖的地方运输局提交（涉及外国船舶等的部分于本省办理） |
| 标准处理期间 | 由运输局公告。基准上第一种约2～3个月、第二种约3～4个月（无文件缺漏时；请向受理机关确认最新信息） |
| 登录、许可 | 缴纳登录免许税 |
| 开业 | 完成运费、费用的设定与申报等开业手续后开始运营 |

本所在行政书士业务范围内，协助确认种类、制作与提交申请文件。新设公司的设立登记由司法书士办理，营业所、保管设施的物件寻找与租赁由持照的不动产企业办理，各以独立的事业体分别签约。本所不收取介绍费。委任流程请见[委任流程](https://luck428.com/legal/nagare)、费用请见[报酬额表](https://luck428.com/legal/ryokin)、业务全貌请见[许可、各项申请服务](https://luck428.com/legal/services)。

## 常见问题

**Q. 一辆卡车都没有也能开业吗？**
A. 可以。货物利用运送事业是不拥有运送工具、利用实运送企业的运送对货主承揽运送的事业。不含集配的卡车利用运送，可办第一种登录（《货物利用运送事业法》第3条第1项）开业。若以自家车辆运送，另需一般货物汽车运送事业等许可。

**Q. 该选第一种还是第二种？**
A. 若连同集配（取货、送货）将海运、空运、铁路运送一贯承揽，以第二种许可为基本；否则为第一种登录。仅以卡车在国内安排的利用运送属第一种。因取决于事业形态，建议对照事业计划确认。

**Q. 需要多少资本金？**
A. 第一种、第二种皆以财产基础净资产300万日元以上为基准（施行规则第8条）。尚未结算的公司，以资本金300万日元以上视为符合。净资产的计算方式与附件请向受理机关确认。

**Q. 想从事国际承揽（forwarder）该怎么办？**
A. 若将国际海运、空运与集配（卡车收送）一贯组合，典型上需第二种许可；若仅安排港到港、机场到机场而不含集配，可能属第一种。因有国际约款申报等与纯国内不同的论点，需个别确认。
