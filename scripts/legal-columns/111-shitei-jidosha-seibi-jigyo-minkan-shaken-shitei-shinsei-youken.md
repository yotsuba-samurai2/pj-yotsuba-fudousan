**結論（先に要点）**：認証は「特定整備ができる」資格、指定（民間車検場）は「自社の自動車検査員が検査して保安基準適合証を交付できる」資格です。指定には認証の取得を前提に、完成検査場などの設備と自動車検査員の選任が加わります。

**情報確認日：2026年10月12日**。本記事は、自動車特定整備の認証工場を運営し、指定自動車整備事業（民間車検場）へ格上げして自社で検査まで行いたい事業者に向けて、認証との違いと設備・人員の要件を整理します。認証そのものの流れは[自動車特定整備の認証申請](/legal/column/jidosha-tokutei-seibi-ninsho-shinsei-nagare-youken)をご覧ください。

## 認証工場と指定工場（民間車検場）は何が違うのか？

根拠は道路運送車両法（昭和26年法律第185号）です。認証と指定は別の処分で、受ける順序も役割も違います。

| | 認証（認証工場） | 指定（指定工場・民間車検場） |
| --- | --- | --- |
| 根拠 | 第78条第1項 | 第94条の2第1項 |
| 受けるもの | 地方運輸局長の認証 | 地方運輸局長の指定（認証が前提） |
| できること | 特定整備（点検・整備） | 点検・整備に加え、自社で検査し保安基準適合証を交付 |
| 車検時の現車 | 運輸支局等の検査場へ車両を持ち込む | 保安基準適合証の提出で現車提示を省略できる |

特定整備は、2020年（令和2年）4月1日に従来の分解整備から範囲が広がり、自動運転等に関わる電子制御装置整備が加わった区分です。認証はこの特定整備を行うための資格で、指定は認証工場のうち一定の基準を満たすものが申請により受けます。

## 指定を受けると、どこまで自社でできるのか？

指定工場は、自動車検査員が検査して保安基準への適合を確認した自動車について、保安基準適合証と保安基準適合標章を交付できます（第94条の5）。この証明書を運輸支局・自動車検査登録事務所等に提出すると、継続検査等で国の検査場への現車提示を省略できます。

ただし「検査の権限を国から移された」わけではありません。指定は民間に検査の一部を委ねる制度で、国による監査や、臨時検査を受けるべき車両への交付制限などの枠内で運用します。保安基準適合証・保安基準適合標章には有効期間が付されます（第94条の5第6項）。有効期間の日数は最新の運輸局案内で確認してください。

## 設備・工員・自動車検査員の要件は？

国土交通省の案内によると、指定には認証の取得に加えて次が求められます。具体的な寸法・機器一覧は告示・規則と管轄運輸局の最新案内で確認してください。

| 区分 | 主な内容 |
| --- | --- |
| 設備・技術・管理組織 | 優良自動車整備事業者認定規則で定める水準を満たすこと |
| 検査の設備 | 指定自動車整備事業規則で定める検査設備を有すること |
| 施設 | 屋内作業場のほか、車両置場と完成検査場 |
| 工員 | 4人以上（大型車を扱う場合は条件により5人以上）。うち3分の1以上が自動車整備士の資格を持つこと |
| 自動車検査員 | 第94条の4により事業場ごとに選任。整備主任者として1年以上の実務経験と教習修了（1級自動車整備士は6か月以上） |

大型車は、車両総重量8トン以上・最大積載量5トン以上・乗車定員30人以上の自動車を指します。自動車検査員の選任・変更は15日以内に地方運輸局長へ届け出ます（第94条の4第3項）。資格要件の細目は国家試験・教習の最新案内で確認してください。

## 指定申請はどこに、どんな書類で出すのか？

| 項目 | 内容 |
| --- | --- |
| 申請先 | 事業場を管轄する都道府県の運輸支局 |
| 審査の流れ | 運輸支局で形式審査 → 地方運輸局で内容審査 → 地方運輸局長が指定を決定 |
| 標準処理期間 | 国土交通省の案内では指定の決定まで申請後おおむね45日 |

申請書には、設備の明細、検査機器、自動車検査員の選任、管理組織などを示す書類を添えます。様式・添付書類・手数料は管轄運輸局の最新案内が正本です。上の表は全事業場共通の確定した書類一覧ではありません。

## 指定後に守る義務は？（適正化・帳簿・保安基準適合証）

指定後は、検査の適正な実施、記録・帳簿の整備、保安基準適合証の適正な交付が継続して求められます。自動車検査員が不正をした場合、地方運輸局長は解任を命じることができ（第94条の4第4項）、解任から2年は検査員になれません（同第5項）。指定自体も、基準を満たさなくなれば取消し等の対象となります。

| 依頼先 | 担当する範囲 |
| --- | --- |
| 四葉行政書士事務所 | 指定申請の書類作成・手続案内 |
| 地方運輸局・運輸支局 | 自動車検査員の選任要件の確認、指定審査 |
| 設備業者 | 検査用機械・完成検査場・建屋の設置 |
| 司法書士 | 法人の設立・変更の登記 |
| 四葉社会保険労務士事務所 | 検査員の時間外・シフト等の労務 |

四葉行政書士事務所、四葉社会保険労務士事務所、四葉不動産株式会社はそれぞれ別事業体で、独立した事業体として受任します。各分野の担当者と別々にご契約いただき、各受任者が直接請求・入金を受けます。当事務所は紹介料を受け取りません。運輸局・運輸支局は行政手続の窓口で、受任契約の相手ではありません。

[許認可サポート](/legal/services)、[受任の流れ](/legal/nagare)、[報酬額表](/legal/ryokin)をご確認ください。

## よくある質問

**Q. 認証を受けていれば指定は不要ですか？**
A. 認証は特定整備を行うための資格、指定は自社で検査して保安基準適合証を交付するための資格です。自社で検査まで行い現車提示を省略したい場合に指定が必要で、認証はその前提になります。

**Q. 指定を受けると国の車検場へ行かなくてよくなりますか？**
A. 保安基準適合証を提出すれば継続検査等で現車提示を省略できます。ただし国の監査や臨時検査の対象、交付制限などの枠内での運用で、検査の権限がすべて移るわけではありません。

**Q. 自動車検査員は誰でもなれますか？**
A. 整備主任者として1年以上の実務経験と教習修了（1級自動車整備士は6か月以上）などの要件があり、事業場ごとに選任して地方運輸局長へ届け出ます。細目は最新の国家試験・教習案内で確認してください。

**Q. 指定申請はどこに出し、どのくらいかかりますか？**
A. 事業場を管轄する運輸支局へ提出し、運輸支局の形式審査と地方運輸局の内容審査を経て地方運輸局長が決定します。国土交通省の案内では決定まで申請後おおむね45日です。
