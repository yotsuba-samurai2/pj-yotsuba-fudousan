**結論（先に要点）**：登録支援機関とは、特定技能1号外国人を受け入れる事業者（特定技能所属機関）から「一号特定技能外国人支援計画」の全部の実施の委託を受けて支援を行う機関で、出入国在留管理庁長官の登録を受けた者をいいます（出入国管理及び難民認定法第19条の23）。登録の有効期間は5年で、欠格事由に当たらないことなどの要件があります（同法第19条の26）。支援計画は法務省令（特定技能雇用契約及び一号特定技能外国人支援計画の基準等を定める省令・平成31年法務省令第5号）の基準に適合しなければならず、事前ガイダンスなどの義務的支援を盛り込みます。本記事は、登録の要件・欠格事由・支援計画の必須項目・自社支援の可否・届出という入管手続を整理する一般的な情報提供であり、個別の許認可の可否や法的判断は行いません。

## 登録支援機関は何をする機関なのか？

特定技能1号の在留資格で外国人を受け入れる事業者を「特定技能所属機関（受入れ機関）」といい、受入れ機関は受け入れる外国人ごとに「一号特定技能外国人支援計画」を作成し、計画に沿って職業生活・日常生活・社会生活上の支援を行う義務があります（出入国管理及び難民認定法第2条の5）。この支援の全部の実施を外部に委託するとき、その委託を受ける機関が登録支援機関です。

登録支援機関は、出入国在留管理庁長官の登録を受けた法人または個人で、受入れ機関との委託契約に基づいて支援計画を実施します。登録を受けていない事業者が支援業務を有償で受託することはできません。行政書士は、受入れ機関や支援機関の依頼を受けて、登録申請書類や支援計画書の作成・提出の代理を行政書士業務の範囲で行います。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務は[取扱業務](/legal/services)をご覧ください。

| 区分 | 役割 |
| --- | --- |
| 特定技能所属機関（受入れ機関） | 外国人と特定技能雇用契約を結び、支援計画を作成する当事者 |
| 登録支援機関 | 支援計画の全部の実施の委託を受け、支援を実施する機関 |
| 行政書士 | 登録申請・支援計画書など入管提出書類の作成・提出代理 |

## 登録の要件と欠格事由は何か？

登録は出入国在留管理庁長官に申請し（第19条の24）、要件を満たせば登録支援機関登録簿に登録されます（第19条の25）。登録手数料は収入印紙28,400円で、登録の有効期間は5年です（第19条の23）。更新しなければ期間満了で効力を失います。

主な登録の基準と欠格事由は次のとおりです（第19条の26第1項各号）。

| 項目 | 内容 |
| --- | --- |
| 支援体制 | 支援責任者・支援担当者を選任し、外国人が理解できる言語で支援できる体制があること |
| 過去の実績等 | 2年以内に中長期在留者の受入れ・生活相談の実績があること等（省令の基準に適合） |
| 欠格事由 | 拘禁刑以上の刑や出入国・労働法令違反による罰金刑から5年を経過しない、暴力団関係、一定の届出違反があった等に当たらないこと |

欠格事由の有無や、自社の体制が基準に適合するかどうかの最終的な判断は、出入国在留管理庁が審査します。当事務所は登録の可否を保証しません。

## 支援計画に必須の項目は何か？

一号特定技能外国人支援計画は、法務省令の基準（特定技能雇用契約及び一号特定技能外国人支援計画の基準等を定める省令・平成31年法務省令第5号）に適合しなければなりません。計画には、次の義務的支援をすべて盛り込みます。

| 義務的支援 | 内容の例 |
| --- | --- |
| 事前ガイダンス | 労働条件・活動内容・入国手続等を雇用契約締結後に説明 |
| 出入国する際の送迎 | 空港と事業所・住居間の送迎 |
| 住居確保・生活に必要な契約支援 | 住居の確保、銀行口座・携帯電話・ライフラインの手続補助 |
| 生活オリエンテーション | 生活ルール・交通・緊急時対応等の説明 |
| 公的手続等への同行 | 住民登録・社会保障・税などの手続の補助・同行 |
| 日本語学習の機会の提供 | 日本語教室の案内等 |
| 相談・苦情への対応 | 母国語での相談対応・助言 |
| 日本人との交流促進 | 地域行事の案内等 |
| 転職支援 | 受入れ側の都合による雇用契約解除時の転職支援 |
| 定期的な面談・行政機関への通報 | 支援責任者等による定期面談、法令違反時の通報 |

このうち、労働条件の明示そのものや雇用契約の内容、社会保険・労働保険の加入手続は使用者（受入れ機関）の義務であり、その手続の代行や労務管理は社会保険労務士、外国人に関する課税は税理士の領域です。四葉社会保険労務士事務所や税理士は四葉行政書士事務所とは独立した事業体で、別々にご契約いただきます。当事務所は紹介料を受け取りません。

## 支援を委託せず自社支援できる条件は？

受入れ機関が登録支援機関に委託せず、自社で支援計画を実施することもできます。ただしその場合、受入れ機関自身が支援体制の基準（省令）に適合する必要があります。具体的には、過去2年間に中長期在留者の受入れ実績があること、または役員・職員が過去2年間に中長期在留者の生活相談業務に従事した経験があること等を満たしたうえで、支援責任者・支援担当者を選任します。

一方、支援計画の全部の実施を登録支援機関に委託する場合は、受入れ機関が支援体制の基準に適合するものとして扱われます（出入国管理及び難民認定法第2条の5）。自社支援と委託のどちらを選ぶかは、社内の体制・言語対応・コストを踏まえた経営判断であり、基準適合の最終判断は出入国在留管理庁が行います。

## 届出・更新を怠るとどうなるのか？

登録支援機関には、登録事項に変更があったときの変更の届出（第19条の27）や、支援業務を休廃止するときの届出（第19条の29）などの義務があります。支援の実施状況の届出を怠る、虚偽の届出をする、支援を適正に行わないなどの場合、出入国在留管理庁長官の指導・助言の対象になり、一定の事由があると登録を取り消されることがあります（第19条の32）。登録が取り消されると支援業務を続けられず、委託していた受入れ機関は別の支援体制を整える必要が生じます。

四葉行政書士事務所と四葉不動産株式会社は別事業体です。登録申請・支援計画書の作成は行政書士、労働条件の明示や社会保険・労働保険の手続は社会保険労務士、課税は税理士、在留資格をめぐる争訟は弁護士が、それぞれ独立した事業体として別々にご契約のうえ対応します。当事務所は紹介料を受け取りません。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務は[取扱業務](/legal/services)をご覧ください。

## よくある質問

**Q. 登録支援機関の登録には、どれくらいの有効期間がありますか？**
A. 登録の有効期間は5年です（出入国管理及び難民認定法第19条の23）。期間満了後も支援業務を続けるには更新が必要で、更新しないと効力を失います。登録手数料は新規で収入印紙28,400円です。

**Q. 受入れ機関は、必ず登録支援機関に委託しなければなりませんか？**
A. いいえ。受入れ機関が支援体制の基準（省令）に適合すれば、自社で支援計画を実施できます。適合しない場合や自社で対応しきれない場合に、支援計画の全部の実施を登録支援機関に委託する選択肢があります。全部を委託すると、受入れ機関は支援体制の基準に適合するものとして扱われます。

**Q. 支援計画には何を書けばよいですか？**
A. 事前ガイダンス、出入国する際の送迎、住居確保・生活に必要な契約支援、生活オリエンテーション、公的手続等への同行、日本語学習の機会の提供、相談・苦情への対応、日本人との交流促進、転職支援、定期的な面談・行政機関への通報という義務的支援をすべて盛り込み、法務省令の基準（平成31年法務省令第5号）に適合させる必要があります。

**Q. 労働条件や社会保険の手続も行政書士に頼めますか？**
A. 在留資格の申請や登録支援機関の登録、支援計画書の作成は行政書士の業務です。一方、労働条件の明示、雇用契約の内容、社会保険・労働保険の加入手続や労務管理は社会保険労務士、課税は税理士の領域で、それぞれ独立した事業体として別々にご契約いただきます。当事務所は紹介料を受け取りません。
