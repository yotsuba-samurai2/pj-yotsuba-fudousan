**結論（先に要点）**：就労継続支援は、障害者総合支援法（平成17年法律第123号）第5条第15項に定める障害福祉サービスで、通常の事業所に雇用されることが困難な障害者に、就労の機会と生産活動の機会を提供して働くための知識・能力の向上を支援するものです。A型は雇用契約に基づく就労の機会を、B型は雇用契約によらない生産活動の機会を提供する点が最大の違いです。事業を始めるには、事業所ごとに都道府県知事（指定都市・中核市では市長）から指定障害福祉サービス事業者の指定（同法第36条）を受けます。人員・設備・運営の基準は同法第43条にもとづき、国の基準である平成18年厚生労働省令第171号と各自治体の条例で具体的に定められます。本記事は、A型・B型の違いと指定申請の要件・流れ、どの部分を誰に頼むかを整理するためのものです。指定の可否や基準への適合は指定権者の審査によるものであり、当事務所が指定を保証するものではありません。

## 就労継続支援A型とB型は、指定の要件がどう違いますか？

就労継続支援は、障害者総合支援法第5条第15項に定義される障害福祉サービスで、就労の機会を提供するとともに、生産活動その他の活動の機会の提供を通じて、就労に必要な知識・能力の向上のために必要な訓練その他の便宜を供与するものです。A型・B型の区分は法律の定義そのものではなく、平成18年厚生労働省令第171号（指定障害福祉サービスの事業等の人員、設備及び運営に関する基準）で定められています。両者の最大の違いは「利用者と雇用契約を結ぶかどうか」です。

| 区分 | 就労継続支援A型 | 就労継続支援B型 |
| --- | --- | --- |
| 利用者との関係 | 雇用契約を締結する | 雇用契約は結ばない |
| 支払い | 賃金（最低賃金法の適用を受ける） | 工賃（成果に応じて支払う） |
| 主な対象 | 一定の支援があれば継続的に就労できる人 | 雇用契約に基づく就労が難しい人 |
| 生産活動の収支 | 生産活動の収入から必要経費を差し引いた額が、賃金の総額以上となるようにする | 工賃の平均額が原則として月額3,000円を下回らないようにする |

A型は利用者と雇用契約を結ぶため、労働基準法や最低賃金法が適用されます。就労の実態が労働者にあたるかどうか、労働時間・賃金・就業規則をどう設計するかは社会保険労務士の領域で、当社・当事務所とは独立した事業体として別々にご契約いただきます。B型は雇用契約によらず、生産活動の成果に応じた工賃を支払い、その平均額は原則として月額3,000円を下回らないよう運営基準で定められています（平成18年厚生労働省令第171号）。

なお、2025年（令和7年）10月1日に「就労選択支援」（障害者総合支援法第5条第13項）が新設され、B型を新たに利用しようとする人は、原則として申請前に就労選択支援を利用する取扱いへ段階的に移行しています。対象や施行時期は自治体の運用で確認します。

## 指定に必要な人員基準（サービス管理責任者・職業指導員・生活支援員）は何人ですか？

人員基準は平成18年厚生労働省令第171号に定められ、自治体の条例で具体化されています。A型・B型に共通する基本的な配置は次のとおりです。

| 職種 | 配置の考え方 |
| --- | --- |
| 職業指導員・生活支援員 | 総数を常勤換算方法で利用者の数を十で除した数以上（10対1）とし、職業指導員1人以上、生活支援員1人以上、うち1人以上は常勤 |
| サービス管理責任者 | 利用者60人以下で1人以上。61人以上は40人（端数を含む）ごとに1人追加。うち1人以上は常勤 |
| 管理者 | 原則として専従の常勤1人（支障がなければ兼務できる場合がある） |

職業指導員・生活支援員の総数は、A型は同省令第186条、B型は同省令第199条で「常勤換算方法で、利用者の数を十で除した数以上」と定められています。B型では、一定の要件のもとで手厚い配置（7.5対1）とすることで報酬上の評価が変わる区分がありますが、これは報酬告示の区分の話で、指定に必要な最低基準は10対1です。人員基準を満たす雇用契約・労働時間の設計・就業規則・社会保険の適用は社会保険労務士の領域で、当社とは独立した事業体として別々にご契約いただきます。

## 設備・運営基準では、どんな書類と体制を整えますか？

設備基準（平成18年厚生労働省令第171号）では、訓練・作業室、相談室、洗面所、便所、多目的室その他運営上必要な設備が求められます。指定には原則として利用定員20人以上が必要です（多機能型は複数のサービスを組み合わせるため取扱いが異なります）。物件で不足しやすいのは次の点です。

| 設備・体制 | 主な求められ方 |
| --- | --- |
| 訓練・作業室 | 訓練・作業に支障がない広さ。必要な機械器具等を備える |
| 相談室 | 間仕切り等でプライバシーに配慮できること |
| 洗面所・便所 | 利用者の特性に応じた数・仕様 |
| 運営規程 | 事業の目的・運営方針、従業者の職種・員数、営業日・時間、利用定員などを定める |
| 個別支援計画 | サービス管理責任者が作成し、定期的に見直す |

事務所や店舗などの既存建物を事業所にする場合、建築基準法上の用途変更や、消防法にもとづく消防用設備の追加が必要になることがあります。用途変更の確認申請の要否・設計は建築士（設計者）、消防用設備の要否と消防同意は消防署の判断によります。物件の用途地域・面積の一次確認は不動産会社が担い、当社は物件情報の提供までを行い、建築確認や消防の可否は判断しません。関連する類型の指定については、[生活介護の指定申請と物件の要件](/legal/column/seikatsu-kaigo-shitei-bukken-yoken)や[放課後等デイサービス・児童発達支援の指定申請の流れ](/legal/column/houkago-day-jido-hattatsu-shitei-shinsei-nagare)もあわせてご覧ください。

## 指定申請はどこへ、どんな順番で出しますか？

指定は事業所ごとに都道府県知事（指定都市・中核市では市長）が行います（障害者総合支援法第36条第1項）。一般的な流れは次のとおりで、順番が前後すると差し戻しになりやすいため、事前協議を早めに始めます。

1. 事業計画・資金計画を固め、法人を設立する（定款の事業目的に障害福祉サービスを加える）
2. 物件を選び、設備基準・建築基準法・消防法への適合を確認する
3. 指定権者と事前協議を行う
4. サービス管理責任者・職業指導員・生活支援員を確保する
5. 申請書と添付書類を作成し、締切までに提出する
6. 書類審査・必要に応じて現地確認
7. 指定（多くの自治体で毎月1日付）

指定は毎月1日付で行う自治体が多く、申請書の提出期限は指定希望日の前月または前々月に設定されているのが一般的です。締切は指定権者ごとに異なり、年度替わりは前倒しになることもあるため、必ず当該自治体の公式ページで確認します。代表的な必要書類は、指定申請書と付表、法人の登記事項証明書・定款、事業所の平面図・写真・賃貸借契約書等、運営規程、従業者の勤務形態一覧表と資格証・実務経験の証明、サービス管理責任者研修等の修了証、収支予算書、各種誓約書などです。

四葉行政書士事務所では、行政書士業務の範囲で、指定申請書・付表・添付書類の作成、事前協議の資料整理、運営規程等の文案づくりを支援します。基準への最終的な適合判断や指定の可否は指定権者の審査によります。

## 指定後の実地指導や報酬請求で、最初に押さえることは何ですか？

指定を受けた後は、運営基準に沿った記録と体制の維持が求められ、自治体による実地指導（運営指導）の対象になります。サービス提供の記録、個別支援計画、勤務実績、工賃・賃金の管理などを日々そろえておくことが、指導での指摘を減らす近道です。

報酬（訓練等給付費）は「障害福祉サービス等報酬告示」で定まり、原則として国民健康保険団体連合会（国保連）へ請求します。A型は事業所ごとの取組を点数化して評価するスコア方式、B型は平均工賃月額などに応じた基本報酬の区分が設けられています（いずれも参照日 2026-09-23の告示による。区分・加算は改定で変わるため最新の告示で確認）。とくにA型は、生産活動に係る事業の収入から必要経費を差し引いた額が賃金の総額以上となるようにしなければならず、これを満たせない場合は経営改善計画の提出を求められます。報酬の算定・請求事務や税務は当事務所の業務ではなく、会計・税務は税理士に、報酬請求の実務は事業者または専門の請求代行にご相談ください。

## 物件・建築・労務・登記・税務は、それぞれ誰に頼みますか？

指定申請は複数の専門分野が交わります。担当は次のように分かれます。

- 指定申請書・付表・添付書類の作成、事前協議の支援 → 四葉行政書士事務所（行政書士）
- 事業用物件の選定・賃貸借・重要事項説明、用途地域・面積の一次確認 → 四葉不動産株式会社
- 用途変更の確認申請・設計、既存不適格や検査済証の確認 → 建築士（設計者）
- 消防用設備の要否判定・消防同意 → 消防署
- 人員基準に対応した雇用契約・就業規則・労働時間管理・社会保険の適用、A型利用者の労働者性・最低賃金 → 社会保険労務士
- 法人設立・変更登記 → 司法書士
- 法人の会計・税務・税額計算、報酬請求に伴う経理 → 税理士
- 権利義務・紛争にわたる個別の法的判断 → 弁護士

四葉行政書士事務所と四葉不動産株式会社は別事業体です。当社は指定申請の支援のみを独立した事業体として担い、物件・建築・消防・労務・登記・税務は、それぞれの資格者・窓口と別々にご契約いただきます。当事務所は紹介料を受け取りません。障害福祉サービスの許認可の全体像は[障害福祉サービスの許認可](/legal/services/shogai-fukushi)、受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)をご覧ください。

## よくある質問

**Q. A型とB型は同時に指定を受けられますか？**
A. 一つの事業所でA型とB型を組み合わせる多機能型として指定を受ける方法があります。人員・設備・定員の考え方が単独型と変わるため、当該自治体の条例と手引きで確認します。人員基準に対応した雇用契約や労務管理は社会保険労務士の領域で、当社とは独立した事業体として別々にご契約いただきます。

**Q. A型で利用者に払うのは給料ですか、工賃ですか？**
A. A型は雇用契約を結ぶため、支払うのは賃金で、最低賃金法の適用を受けます。工賃は雇用契約によらないB型で支払うものです。A型利用者の労働者性や最低賃金の個別判断は社会保険労務士の領域で、別事業体として別々にご契約いただきます。

**Q. 事務所や店舗をそのまま事業所に使えますか？**
A. 面積・設備のほか、既存建物では用途変更の確認申請や消防用設備の追加が必要になることがあります。用途変更の判断は建築士（設計者）、消防用設備の要否は消防署に確認します。物件は不動産会社、建築確認は建築士と、それぞれ別事業体として別々にご契約いただきます。

**Q. 行政書士はどこまでやってくれますか？**
A. 行政書士業務の範囲で、指定申請書・付表・添付書類の作成、事前協議の資料整理、運営規程等の文案づくりを支援します。基準への最終的な適合判断や指定の可否は指定権者の審査によります。労務・登記・税務・報酬請求はそれぞれの資格者・窓口へ、独立した事業体として別々にご契約ください。
