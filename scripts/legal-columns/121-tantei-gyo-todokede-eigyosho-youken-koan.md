**結論（先に要点）**：探偵業は許可制ではなく届出制です。探偵業の業務の適正化に関する法律（探偵業法）第4条により、営業を開始する前日までに、営業所ごとに、その営業所の所在地を管轄する公安委員会へ（管轄警察署の防犯係を経由して）探偵業開始届出書を提出します。届出手数料はかかりません。かつて交付されていた探偵業届出証明書は2024年（令和6年）4月1日施行の改正で廃止され、代わりに届出をしたことを示す標識を営業所に掲示します（第12条）。届出ができない欠格事由は第3条に定められ、破産手続開始の決定を受けて復権を得ない者、拘禁刑以上の刑などを受けて執行終了等から5年を経過しない者、暴力団員等、法人では役員に該当者がいる場合などが該当します。自己の名義で他人に探偵業を営ませる名義貸しは第5条で禁止され、無届営業・名義貸しには6月以下の拘禁刑又は30万円以下の罰金が定められています。本記事は一般的な情報提供で、個別の届出が受理されるかの最終判断をするものではありません。四葉グループの行政書士は、探偵業開始届出書の作成・公安委員会への提出の支援を、独立した事業体として担います。調査に伴う名誉毀損・プライバシー侵害やストーカー規制法違反など違法・紛争の領域は弁護士、営業所にする物件探し・賃貸借は別事業体である不動産業者（当社）の領域で、それぞれ別々にご契約いただきます。当事務所は各専門家から紹介料を受け取りません。

## 探偵業は許可制か届出制か、始める前に何を出す必要があるのか？

探偵業は、許可を受けてから始める「許可制」ではなく、営業を始める前に届け出る「届出制」です。探偵業の業務の適正化に関する法律（探偵業法。平成18年法律第60号、2007年〔平成19年〕6月1日施行）第4条は、探偵業を営もうとする者は、営業を開始する前日までに、営業所ごとに、その営業所の所在地を管轄する公安委員会に届出書を提出しなければならないと定めています。実務上は、営業所を管轄する警察署の防犯係を経由して提出します。

| 項目 | 内容（探偵業法） |
| --- | --- |
| 制度 | 届出制（許可制ではない） |
| 届出先 | 営業所の所在地を管轄する公安委員会（管轄警察署の防犯係を経由） |
| 時期 | 営業を開始する前日まで（第4条第1項） |
| 単位 | 営業所ごと |
| 手数料 | なし |
| 名義貸し | 禁止（第5条） |

ここでいう「探偵業務」とは、他人の依頼を受けて、特定人の所在又は行動についての情報を収集することを目的に、面接による聞込み・尾行・張込みその他これらに類する方法により実地の調査を行い、その結果を依頼者に報告する業務をいいます（第2条第1項）。もっぱら報道機関の報道の用に供する目的の依頼を受けて行うものは、探偵業から除かれます（第2条第2項）。届出書の作成・提出の支援は、当事務所の[許認可業務のご案内](/legal/services)でも扱っています。

## 探偵業の届出ができない『欠格事由』にはどんなものがあるのか？

探偵業法第3条は、次のいずれかに該当する者は探偵業を営んではならないとして、欠格事由を定めています。届出の前に、自分（法人では役員）が該当しないかを確認します。

| 号 | 欠格事由（第3条） |
| --- | --- |
| 第1号 | 破産手続開始の決定を受けて復権を得ない者 |
| 第2号 | 拘禁刑以上の刑、又はこの法律の規定に違反して罰金の刑に処せられ、執行を終わり等から5年を経過しない者 |
| 第3号 | 最近5年間に第15条の処分（営業停止・廃止命令）に違反した者 |
| 第4号 | 暴力団員、又は暴力団員でなくなった日から5年を経過しない者 |
| 第5号 | 心身の故障により探偵業務を適正に行うことができない者として内閣府令で定めるもの |
| 第6号 | 営業に関し成年者と同一の能力を有しない未成年者で、法定代理人が第1号〜第5号又は第7号に該当するもの |
| 第7号 | 法人で、役員のうちに第1号〜第5号のいずれかに該当する者があるもの |

2022年（令和4年）の刑法等の改正で懲役・禁錮が「拘禁刑」に一本化され、2025年（令和7年）6月1日から施行されたため、条文の表現も「拘禁刑以上の刑」となっています。欠格事由に該当するかどうかの最終的な評価は公安委員会が行う領域で、行政書士が代わって受理を保証するものではありません。

## 営業所や自宅開業でどんな要件・表示義務があるのか？

探偵業法には、飲食店営業のような建物の構造・設備の基準はありませんが、営業所ごとの届出と、届出をしたことを示す標識の掲示が義務づけられています。従来の探偵業届出証明書は、2024年（令和6年）4月1日施行の改正（届出手続の見直し）で廃止され、事業者自身が作成した標識を営業所の見やすい場所に掲示する方式に変わりました（第12条）。

| 区分 | 内容 |
| --- | --- |
| 営業所 | 営業所ごとに届出が必要。自宅を営業所とすることも可能（管轄は営業所所在地） |
| 標識 | 届出をしたことを示す標識を営業所の見やすい場所に掲示（旧・届出証明書は廃止） |
| 従業者名簿 | 営業所ごとに備付け（第12条） |
| 教育 | 従業者に探偵業務を適正に行わせるための教育（第11条） |

標識には、届出をした公安委員会の名称、届出書の受理番号、届出年月日、商号・名称・氏名、営業所の名称・所在地などを記載します。様式や記載要領は各都道府県警察が示しているため、作成前に管轄の公式ページで最新の内容を確認します。営業所を借りて開業する場合、物件探しや賃貸借契約は別事業体である不動産業者（当社）の領域で、当社の[不動産の相談窓口](/souzoku)もご利用いただけます。受任の進め方は[受任の流れ](/legal/nagare)をご覧ください。

## 重要事項説明書・契約書面で探偵業者に義務づけられていることは？

探偵業者は、依頼者と契約するにあたって、契約前の書面交付と契約後の書面交付の両方が義務づけられています（第8条）。あわせて、調査結果を犯罪や差別などの違法な目的に使用しない旨を依頼者から書面で受け取る必要があります（第7条）。

| 場面 | 根拠 | 主な記載事項 |
| --- | --- | --- |
| 契約前（重要事項の説明） | 第8条第1項 | 商号・住所、届出先の公安委員会の名称、守秘に関する事項、業務の内容、委託の有無、対価の概算額と支払時期、契約の解除、資料の処分 |
| 契約後（契約内容の明示） | 第8条第2項 | 担当者氏名・契約年月日、調査の内容・期間・方法、報告の方法・期限、対価の額・支払時期・方法、解除・資料処分の定め |
| 依頼者からの書面 | 第7条 | 調査結果を違法な目的に用いない旨の確認 |

探偵業務を行うに当たっては、人の生活の平穏を害するなど個人の権利利益を侵害することがないようにしなければならず、他の法令で禁止・制限される行為がこの法律によって許されるわけではありません（第6条）。また、探偵業務の全部・一部を探偵業者以外の者へ委託することは禁止され、調査結果が違法行為に用いられると知ったときは業務を行ってはなりません（第9条）。費用の目安は当事務所の[報酬額表](/legal/ryokin)で別に定めています。

## 届出を怠る・名義を貸すとどんな罰則やリスクがあるのか？

届出をしないまま探偵業を営むこと（無届営業）と、自己の名義で他人に探偵業を営ませること（名義貸し）には、罰則が定められています。名義貸しは第5条で明文で禁止されており、無届営業・名義貸しのいずれも、6月以下の拘禁刑又は30万円以下の罰金の対象です（第18条）。

| 行為 | 根拠 | 罰則 |
| --- | --- | --- |
| 無届で探偵業を営む | 第4条第1項違反 | 6月以下の拘禁刑又は30万円以下の罰金（第18条） |
| 名義貸し | 第5条違反 | 6月以下の拘禁刑又は30万円以下の罰金（第18条） |
| 業務実施上の規制違反・虚偽届出等 | 各規定 | 営業停止・廃止命令（第15条）や罰則の対象となりうる |

欠格事由の確認を怠って届け出ると、後に処分の対象となるおそれがあります。古物商許可など他の営業と並行する場合は、根拠法と監督官庁が異なるため分けて確認します。古物商は[古物商許可の営業所の要件](/legal/column/kobutsusho-kyoka-eigyosho-yoken)、警備業は[警備業の認定の要件・欠格・教育](/legal/column/keibigyo-nintei-yoken-kekkaku-kenshu)で整理しています。警備業が「認定」であるのに対し、探偵業は「届出」である点が制度の大きな違いです。

## よくある質問

**Q. 探偵業は許可を取ってから始めるのですか？**
A. いいえ。探偵業は許可制ではなく届出制です。探偵業法第4条により、営業を開始する前日までに、営業所ごとに、その所在地を管轄する公安委員会へ（管轄警察署の防犯係を経由して）届出書を提出します。届出手数料はかかりません。許可の審査を待つ仕組みではありませんが、欠格事由に該当しないことや書面交付などの義務の履行は前提です。

**Q. 自宅を営業所にして開業できますか？**
A. 営業所ごとに届け出る必要がありますが、自宅を営業所とすること自体は可能です。管轄は営業所の所在地で決まります。届出をしたことを示す標識を営業所の見やすい場所に掲示し、従業者名簿を備える義務があります（第12条）。従来の探偵業届出証明書は2024年（令和6年）4月1日施行の改正で廃止され、標識の掲示に変わりました。

**Q. 届出をしないで探偵業を始めると、どうなりますか？**
A. 無届で探偵業を営んだ者は、6月以下の拘禁刑又は30万円以下の罰金の対象となります（第18条）。自己の名義で他人に探偵業を営ませる名義貸しも第5条で禁止され、同じ罰則の対象です。届出は営業開始の前日までに済ませる必要があります。

**Q. 行政書士はどこまで対応できますか？**
A. 行政書士は、探偵業開始届出書の作成と公安委員会への提出の支援、欠格事由の確認の整理などを独立した事業体として担います。尾行・張込みが行き過ぎた場合のストーカー規制法違反や名誉毀損、プライバシー侵害など違法・紛争への対応は弁護士、営業所の物件・賃貸借は別事業体の不動産業者の領域で、それぞれ別々にご契約いただきます。
