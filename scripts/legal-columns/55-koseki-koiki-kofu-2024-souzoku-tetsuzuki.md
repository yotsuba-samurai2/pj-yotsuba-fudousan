**結論（先に要点）**：2024年（令和6年）3月1日に始まった戸籍の広域交付（戸籍法第120条の2）により、本籍地が遠くても、お住まいや勤務先の最寄りの市区町村（本籍地以外）の窓口で、複数の本籍地の戸籍謄本（全部事項証明書）等をまとめて請求できるようになりました。ただし、請求できるのは本人・配偶者・直系尊属・直系卑属に限られ、郵送や代理人による請求はできず、窓口では顔写真付きの本人確認書類が必要です。コンピュータ化されていない一部の戸籍・除籍や、一部事項証明書・個人事項証明書は広域交付では取れません。本記事は制度の適用範囲を整理する一般的な情報提供で、取得できるかどうかは市区町村の窓口が判断します。

## 戸籍の広域交付とは何が新しくなった制度なのか？

戸籍の広域交付は、戸籍法の一部を改正する法律（令和元年法律第17号）に基づき、2024年（令和6年）3月1日に施行された制度です（戸籍法第120条の2）。従来、戸籍謄本は本籍地の市区町村でしか取れず、本籍が各地に散らばっている場合は、その数だけ別々に請求する必要がありました。

| | 従来 | 広域交付（2024年3月1日〜） |
| --- | --- | --- |
| 請求先 | 本籍地の市区町村ごと | 本籍地以外の最寄りの市区町村の窓口でまとめて請求可 |
| 取得できるもの | 各種の戸籍・除籍の証明書 | 戸籍謄本（全部事項証明書）・除籍謄本等（一部に対象外あり） |
| 請求方法 | 窓口・郵送 | 窓口のみ（本人が出向く） |

相続では、被相続人の出生から死亡までの連続した戸籍が必要になります。本籍を何度も移していると、複数の市区町村にまたがって戸籍を集めることになり、これが相続手続の最初の負担でした。広域交付は、この「集める」段階の負担を軽くする制度です。戸籍収集と相続人調査の全体像は[戸籍収集・相続人調査](/legal/column/souzoku-hajime-koseki-chosa-bunkyo)にまとめています。

## 誰が請求でき、逆に誰は使えないのか？

広域交付を使って請求できる人は、法律で限られています。

| 請求できる人 | 広域交付の可否 |
| --- | --- |
| 本人 | 可 |
| 配偶者 | 可 |
| 直系尊属（父母・祖父母など） | 可 |
| 直系卑属（子・孫など） | 可 |
| 兄弟姉妹・おい・めいなど | 広域交付は不可（本籍地への請求等による） |
| 委任状を受けた代理人・第三者 | 広域交付は不可 |

広域交付で戸籍を請求できるのは、本人・配偶者・直系尊属・直系卑属です。兄弟姉妹は直系ではないため、兄弟姉妹の戸籍を広域交付で取ることはできません。相続で兄弟姉妹が相続人になる場合などは、この点が実務上の分かれ目になります。誰が相続人になるかの基本は[法定相続情報一覧図](/legal/column/houtei-souzoku-jouhou-ichiran-zu)や相続順位の整理とあわせて確認します。

## 広域交付で取れない戸籍にはどんなものがあるのか？

広域交付は、すべての戸籍を取れるわけではありません。取れないものを先に知っておくと、二度手間を防げます。

| 取れないもの | 内容 |
| --- | --- |
| コンピュータ化されていない一部の戸籍・除籍 | 電算化前の紙のまま保管されている改製原戸籍・除籍など |
| 一部事項証明書 | 戸籍の一部だけを記載した証明書 |
| 個人事項証明書 | 戸籍のうち特定の個人の事項だけを記載した証明書（いわゆる抄本） |

広域交付で交付されるのは、原則として戸籍謄本（全部事項証明書）や除籍謄本などです。一部事項証明書・個人事項証明書は広域交付の対象外です。また、コンピュータ化されていない一部の戸籍・除籍は、システム上まとめて取り出せないため広域交付では取得できないことがあります。戸籍の附票の写しについては、対象になるかどうかを含め、お住まいの市区町村の案内でご確認ください。取れなかった分は、本籍地の市区町村へ別途請求します。

## 郵送や代理人請求はできるのか、従来手続とどう併用するのか？

広域交付には、方法の面でも制約があります。

- 郵送による請求はできません。窓口に本人が出向く必要があります。
- 代理人（委任状を受けた者）による請求はできません。
- 窓口では、運転免許証・マイナンバーカード・パスポートなど顔写真付きの本人確認書類が必要です。

そのため、遠方に住んでいて窓口へ行けない、兄弟姉妹の戸籍が必要、電算化前の改製原戸籍が必要、といった場合は、従来どおり本籍地の市区町村への請求（郵送を含む）を併用します。広域交付で取れるものは最寄りの窓口で、取れないものは本籍地へ、と使い分けるのが実務の基本です。集めた戸籍は、相続関係説明図や法定相続情報一覧図の作成につないでいきます。相続手続を初めから見通したい場合は[受任の流れ](/legal/nagare)もご覧ください。

## 集めた戸籍は、登記・税務の誰に渡していくのか？

戸籍収集は相続手続の入口で、その先は複数の専門分野に分かれます。担当は次のように分かれます。

- 戸籍収集、相続関係説明図の作成、法定相続情報一覧図の申出、遺産分割協議書の作成支援 → 四葉行政書士事務所（行政書士）
- 不動産の相続登記の申請代理・登記申請書等の作成 → 司法書士又は弁護士
- 相続税の申告・税額計算 → 税理士
- 遺産をめぐる争い・個別の法的判断 → 弁護士
- 相続した不動産の売却・活用の相談 → 四葉不動産株式会社

集めた戸籍は、相続登記であれば[相続登記の流れ](/legal/column/souzoku-touki-nagare)のとおり司法書士又は弁護士へ、相続税であれば税理士へ渡していきます。四葉行政書士事務所と四葉不動産株式会社は別事業体で、相続不動産の売却・活用は[相続不動産の窓口](/souzoku)（四葉不動産株式会社）が担います。当事務所は戸籍収集・書類作成の支援を独立した事業体として行い、登記・税務・紛争は、それぞれの資格者と別々にご契約・ご相談いただきます。当事務所は紹介料を受け取りません。相続で行政書士に頼める範囲は[相続手続の支援](/legal/services/inheritance)、料金は[報酬額表](/legal/ryokin)をご覧ください。

## よくある質問

**Q. 兄弟姉妹の戸籍も広域交付で取れますか？**
A. 取れません。広域交付で請求できるのは本人・配偶者・直系尊属・直系卑属で、兄弟姉妹は直系ではないためです。兄弟姉妹が相続人になる場合などは、本籍地の市区町村への請求（郵送を含む）で対応します。誰が相続人になるかを踏まえて、必要な戸籍の範囲を最初に確認することが大切です。

**Q. 遠方に住んでいて窓口に行けません。郵送で広域交付を頼めますか？**
A. できません。広域交付は窓口で本人が請求する制度で、郵送や代理人による請求はできません。窓口では顔写真付きの本人確認書類が必要です。窓口へ行けない場合は、従来どおり本籍地の市区町村への郵送請求などを併用します。

**Q. 昔の改製原戸籍も広域交付でまとめて取れますか？**
A. コンピュータ化されていない一部の戸籍・除籍（電算化前の紙のまま保管されている改製原戸籍など）は、広域交付では取得できないことがあります。取れなかった分は本籍地の市区町村へ別途請求します。どの戸籍が対象になるかは窓口で確認します。

**Q. 広域交付で取った戸籍で、相続登記まで自分で進められますか？**
A. 戸籍の取得は相続の入口です。相続登記の申請代理や登記申請書等の作成は司法書士又は弁護士の業務で、相続税の申告は税理士の領域です。当事務所は戸籍収集・相続関係説明図・法定相続情報一覧図の申出支援を担い、登記・税務はそれぞれの資格者と別々にご契約いただきます。
