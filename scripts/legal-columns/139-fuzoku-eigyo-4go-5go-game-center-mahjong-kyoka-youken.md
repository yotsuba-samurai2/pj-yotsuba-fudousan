**結論（先に要点）**：ぱちんこ屋・まあじゃん屋（風俗営業等の規制及び業務の適正化等に関する法律＝風営法の第2条第1項第4号）や、ゲームセンター・アミューズメント施設（同法同項第5号）を営むには、第3条第1項により、営業の種別に応じて営業所ごとに、その所在地を管轄する都道府県公安委員会の許可を受ける必要があります。客の接待をして飲食をさせる1号営業とは別の許可で、①人的要件（第4条第1項の欠格事由）、②場所的要件（第4条第2項第2号と政令で定める保全対象施設からの距離）、③構造設備の技術上の基準（第4条第2項第1号・施行規則第7条の照度や区画など）のすべてを満たす必要があります。本記事は4号・5号許可の要件と申請の流れを整理する一般的な情報提供であり、個別の許可の可否は判断しません。

## 風適法の4号・5号はどの営業を指すのか？

風営法は、風俗営業を第2条第1項各号で種別ごとに定めています。遊技にかかわるのが4号と5号です。条文は次のとおりです。

- 第2条第1項第4号：「まあじやん屋、ぱちんこ屋その他設備を設けて客に射幸心をそそるおそれのある遊技をさせる営業」
- 第2条第1項第5号：「スロットマシン、テレビゲーム機その他の遊技設備で本来の用途以外の用途として射幸心をそそるおそれのある遊技に用いることができるもの（国家公安委員会規則で定めるものに限る。）を備える店舗その他これに類する区画された施設において、当該遊技設備により客に遊技をさせる営業」（第4号に該当する営業を除く）

4号は、まあじゃん店・ぱちんこ店のように「射幸心をそそるおそれのある遊技」をさせる営業です。5号は、ゲームセンターやアミューズメント施設のように遊技設備を置いて客に遊技をさせる営業で、4号に当たるものは除かれます。いずれも、接待をして遊興・飲食をさせる1号営業（スナック・クラブなど）とは種別が異なります。

| 種別 | 代表例 | 根拠 |
| --- | --- | --- |
| 1号 | スナック・クラブ（接待飲食） | 風営法第2条第1項第1号 |
| 4号 | ぱちんこ屋・まあじゃん屋 | 風営法第2条第1項第4号 |
| 5号 | ゲームセンター・アミューズメント施設 | 風営法第2条第1項第5号 |

どの種別も、第3条第1項により営業所ごとに都道府県公安委員会の許可が必要です。許可は審査を経て下りるもので、標準処理期間（都道府県により概ね55日前後とされます。土日祝を除く日数で定める公安委員会もあります）を要し、下りるまで営業できません。期間と様式は都道府県で異なるため、必ず所轄警察署・公安委員会の案内で確認してください。物件の用途・面積の視点は不動産側の[ゲームセンター・アミューズメント施設の物件はどこまで選べる？（風営法5号）](/column/game-center-fuei-5go-bukken-youto-menseki)も参考になります。

## 許可が下りない人的欠格事由とは何か？

風営法第4条第1項は、申請者（法人ならその役員を含む）が一定の事由にあたるときは許可をしないと定めています。代表的な欠格事由は次のとおりです。

- 破産手続開始の決定を受けて復権を得ない者（第1号）
- 一定の罪により1年以上の拘禁刑に処せられ、又は所定の罪で刑に処せられ、執行を終わった日等から起算して5年を経過しない者（第2号）
- 集団的に、又は常習的に暴力的不法行為その他の違法な行為を行うおそれがあると認めるに足りる相当な理由がある者（第3号）
- アルコール、麻薬、大麻、あへん又は覚醒剤の中毒者（第4号）
- 心身の故障により業務を適正に実施できない者として国家公安委員会規則で定めるもの（第5号）
- 営業に関し成年者と同一の行為能力を有しない未成年者（第11号）、役員に欠格事由のある法人（第12号）、暴力的不法行為を行うおそれがある者が支配的影響力を有する者（第13号）など

（拘禁刑は刑法改正により令和7年6月1日に施行され、従来の懲役・禁錮を一本化した刑です。）人的欠格の確認は、本人の申告と警察による調査で行われます。前科・前歴に関する事実の確認は本人と警察の管轄で、当事務所が本人に代わって前科の有無を証明することはできません。

## 場所的要件（保全対象施設からの距離）はどう調べるのか？

4号・5号でも、物件選びに直結するのが「場所的要件」です。風営法第4条第2項第2号は、良好な風俗環境を保全するため特にその設置を制限する必要があるものとして政令で定める基準に従い、都道府県の条例で定める地域内にあるときは許可をしないと定めています。その政令が風営法施行令第6条で、①住居が多数集合する地域、②学校・図書館・児童福祉施設・病院・診療所などの「保全対象施設」の周囲一定距離の区域を、条例で営業制限地域として定められる枠組みを置いています。保全対象施設の周囲については、施行令が敷地の周囲おおむね100メートルの区域を限度としています。

実際の距離は都道府県の条例で異なります。物件が商業地域にあっても、近くに学校や病院があると距離制限で許可が取れないことがあります。用途地域は建築基準法にもとづく都市計画で定まり、同じ通り沿いでも区画によって変わります。物件を決める前に、用途地域と保全対象施設からの距離の両方を、物件所在地の条例で確認することが欠かせません。

| 確認項目 | 調べ方 |
| --- | --- |
| 営業制限地域か | 物件所在地の都道府県の風営法施行条例 |
| 保全対象施設からの距離 | 周囲の学校・図書館・児童福祉施設・病院・診療所の位置と条例の距離 |
| 用途地域 | 市区町村の都市計画情報（建築基準法） |

## 構造設備基準（照度・区画・遊技機）は何を満たすのか？

構造設備の基準は風営法第4条第2項第1号にもとづく技術上の基準で、国家公安委員会規則（施行規則第7条）と都道府県条例で具体化されています。4号・5号営業で代表的に問われる基準は次のとおりです。

| 項目 | 基準の目安（4号・5号） |
| --- | --- |
| 照度 | 営業所内の照度を10ルクス以下としないための構造・設備（営業中の維持は法第14条） |
| 見通し | 客室の内部に見通しを妨げる設備を設けない |
| 風俗環境 | 善良の風俗や清浄な風俗環境を害するおそれのある写真・装飾等を設けない（5号は少年の健全な育成に障害を及ぼすおそれのあるものも） |
| 出入口 | 客室の出入口に施錠の設備を設けない（営業所外へ直接通ずる出入口を除く） |
| 遊技設備 | 4号は営業に用いる遊技機以外の遊技設備を設けない。5号は紙幣を挿入できる遊技料金装置や現金・有価証券を提供する装置を有する遊技設備を設けない |

加えて、ぱちんこ・スロットなどの4号営業では、著しく客の射幸心をそそるおそれのある遊技機の設置が禁止され、遊技機には型式の規制があります（風営法第20条）。また4号営業（ぱちんこ屋その他政令で定めるもの）には、現金又は有価証券を賞品として提供すること、客に提供した賞品を買い取ることなどを禁じる規定があります（第23条第1項）。5号営業のゲームセンターでは、18歳未満の者を午後10時から翌日の午前6時までの時間に客として立ち入らせてはならないとされています（第22条第1項第5号）。図面（求積図・平面図）と現況が食い違うと実地調査で指摘を受けるため、構造設備の基準は内装設計の段階で織り込むのが安全です。

## 物件・設計・労務・不服申立ては誰に振り分けるのか？

遊技設備による営業の開業は、複数の専門分野にまたがります。担当は次のとおりです。

- 風俗営業（4号・5号）許可の要件確認・申請書類の作成・許可申請の代理 → 四葉行政書士事務所（行政書士）
- 店舗物件の賃貸借・立地（用途地域・保全対象施設からの距離）の事前確認・使用条件の調整 → 四葉不動産株式会社（宅地建物取引業者）
- 内装・構造設備図面（求積図・平面図）の設計・工事 → 建築士・内装業者
- 従業員のシフト・深夜労働など労務管理と社会保険 → 社会保険労務士
- 不許可処分・営業停止処分への不服申立て・訴訟 → 弁護士

四葉行政書士事務所とは別事業体の四葉不動産株式会社が、独立した事業体として別契約で、物件探し・賃貸借契約・用途地域や保全対象施設からの距離の事前確認を担当します。構造設備図面は建築士、労務と社会保険は社会保険労務士、処分への不服申立て・訴訟は弁護士が、いずれも独立した事業体として別々にご契約・お手続きいただきます。各分野は、それぞれの窓口・資格者と別々にご契約いただく前提で、当事務所は紹介料を受け取りません。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務の全体像は[許認可・各種申請サービス](/legal/services)をご覧ください。接待飲食の1号許可については[ゲームセンターやまあじゃん店とは別業態の、接待飲食（風営法1号）の距離制限](/legal/column/fuzoku-eigyo-1go-settai-inshoku-kyoka-bukken-kyori)、深夜の酒類提供については[深夜0時以降にお酒を出す店、届出は何がいる？](/legal/column/shinya-shurui-teikyo-todokede-yoken)も参考になります。

## よくある質問

**Q. 4号と5号は何が違うのですか？**
A. 4号は、まあじゃん屋・ぱちんこ屋その他、設備を設けて客に射幸心をそそるおそれのある遊技をさせる営業です（風営法第2条第1項第4号）。5号は、スロットマシン・テレビゲーム機その他の遊技設備を備えて客に遊技をさせる営業で、4号に当たるものは除かれます（同項第5号）。ゲームセンターやアミューズメント施設は5号です。いずれも第3条第1項により営業所ごとに公安委員会の許可が必要です。

**Q. 届出で足りる営業ではないのですか？**
A. いいえ。4号・5号は「許可」が必要です。深夜に酒類を提供する飲食店営業（接待なし）は第33条第1項の「届出」で足りますが、遊技設備で客に遊技をさせる4号・5号は人的・場所的・構造設備の各要件を審査する「許可」の対象です。許可が下りるまで営業を始められません。

**Q. 物件が商業地域なら距離制限は関係ないですか？**
A. いいえ。商業地域でも、近くに学校・図書館・児童福祉施設・病院・診療所などの保全対象施設があると、都道府県条例の距離制限で許可が取れないことがあります。距離は条例で異なり、風営法施行令第6条は保全対象施設の周囲おおむね100メートルを限度としています。物件契約の前に、所在地の条例で確認してください。

**Q. ゲームセンターに未成年を入れてはいけない時間はありますか？**
A. 5号営業の営業所には、18歳未満の者を午後10時から翌日の午前6時までの時間に客として立ち入らせてはならないとされています（風営法第22条第1項第5号）。年齢・時間の運用は所轄警察署の案内で確認してください。なお、営業時間そのものの制限は都道府県条例でも定められます。
