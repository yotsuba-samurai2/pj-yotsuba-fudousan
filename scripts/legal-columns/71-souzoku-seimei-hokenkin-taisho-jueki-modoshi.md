**結論（先に要点）**：受取人が指定された生命保険金（死亡保険金）は、原則として受取人が自分の固有の権利として受け取る財産で、遺産分割で分ける相続財産には含まれません。ただし、受取人である相続人と他の相続人との間の不公平が著しく、民法第903条の趣旨に照らして到底是認できないと評価すべき特段の事情がある場合には、例外として特別受益に準じて持ち戻しの対象になり得る、というのが最高裁の考え方です（最高裁平成16年10月29日決定）。本記事は原則と例外を整理する一般的な情報提供で、金額の当てはめや税務・紛争にわたる判断は有資格者が行います。

## 生命保険金は、そもそも遺産分割で分ける財産に入るのか

原則として入りません。相続財産（遺産）とは、亡くなった方（被相続人）がその死亡の時に持っていた財産です。これに対し、受取人が指定された死亡保険金は、被相続人の死亡を条件に、保険契約に基づいて受取人が保険会社から直接受け取るお金です。被相続人から受け継ぐのではなく、受取人が自分の権利として取得するため、原則として遺産分割協議で分ける対象にはなりません。

そのため、たとえば「長男を受取人とする2,000万円の死亡保険金」があっても、その2,000万円は長男の固有の財産で、原則として遺産分割の話し合いのテーブルには乗りません。遺産分割は、預貯金・不動産・有価証券など被相続人自身の財産について、誰が何を取得するかを相続人全員で決める手続きです。遺産分割協議書の作り方は[遺産分割協議書は自分で作れる？](/legal/column/isan-bunkatsu-kyougisho)で整理しています。

| 区分 | 遺産分割の対象になるか |
| --- | --- |
| 被相続人名義の預貯金・不動産・有価証券 | なる（相続財産） |
| 受取人が指定された死亡保険金 | 原則ならない（受取人の固有財産） |
| 受取人が「相続人」とだけ指定された死亡保険金 | 原則ならない（各相続人が固有の権利として取得） |
| 受取人が被相続人自身（＝相続財産に入る契約） | なる（相続財産に含まれる） |

受取人を誰にするかは保険契約者が定めます。保険契約者は保険事故の発生（被相続人の死亡）まで受取人を変更でき（保険法第43条）、遺言によって変更することもできます（保険法第44条）。受取人が被相続人より先に死亡していた場合は、その受取人の相続人の全員が受取人になります（保険法第46条）。

## 受取人が指定されている保険金は、なぜ受取人固有の財産なのか

最高裁は、養老保険契約に基づく死亡保険金請求権について、「保険金受取人が自らの固有の権利として取得するのであって、保険契約者又は被保険者から承継取得するものではなく、これらの者の相続財産に属するものではない」と判断しています（最高裁平成16年10月29日決定、最高裁判所民事判例集58巻7号1979頁）。受取人が指定されている以上、保険金は契約の効果として受取人にわたるお金であって、いったん被相続人の財産になってから相続で移るものではない、という整理です。

ここが、遺産分割でしばしば誤解される点です。「保険金も遺産だから均等に分けるべきだ」と考える相続人がいても、原則としてその主張は通りません。反対に、受取人になっている相続人からすれば、保険金は自分の固有財産なので、原則として他の相続人と分け合う義務はありません。まずこの原則を押さえたうえで、次の例外を確認します。

## どんなとき、特別受益に準じて持ち戻しの対象になるのか

民法第903条第1項は、共同相続人の中に、被相続人から遺贈を受け、または婚姻・養子縁組のためもしくは生計の資本として贈与を受けた者があるときは、その分を相続分の前渡し（特別受益）として計算に持ち戻す、と定めています。死亡保険金は形式的にはこの「贈与・遺贈」に当たらないため、原則として持ち戻しの対象外です。

しかし前掲の最高裁決定は、例外を認めました。「保険金受取人である相続人とその他の共同相続人との間に生ずる不公平が民法第903条の趣旨に照らし到底是認することができないほどに著しいものであると評価すべき特段の事情が存する場合には、同条の類推適用により、当該死亡保険金請求権は特別受益に準じて持戻しの対象となる」としています。そのうえで、特段の事情の有無は、次のような事情を総合考慮して判断すべきだとしました。

| 考慮される主な事情 |
| --- |
| 保険金の額 |
| その額の遺産総額に対する比率 |
| 保険金受取人である相続人と被相続人の同居の有無 |
| 被相続人の介護等に対する貢献の度合い |
| 各相続人と被相続人との関係、各相続人の生活実態 |

重要なのは、金額が大きいというだけで自動的に持ち戻しになるわけではなく、また「遺産総額に対して何割を超えたら持ち戻し」といった一律の基準があるわけでもない、という点です。実際の裁判例でも、結論は事案ごとに分かれています。ある事案で持ち戻しが認められ、別の事案で否定されるのは、上記の事情を総合してみるからです。ご自身のケースが「著しい不公平」に当たるかどうかの当てはめは、紛争性のある個別判断になるため、弁護士が行います。特別受益の一般論は[特別受益と寄与分の基本](/legal/column/souzoku-tokubetsu-jueki-kiyobun)、遺留分との関係は[遺留分の基礎](/legal/column/souzoku-iryubun-kiso)もあわせてご覧ください。

## 相続税の非課税枠と、遺産分割での扱いはどう違うのか

「遺産分割で分ける対象か」という民法の問題と、「相続税がかかるか」という税法の問題は、別の話です。死亡保険金は、遺産分割では原則として受取人の固有財産ですが、相続税の世界では「みなし相続財産」として課税対象に含まれます。ただし、受取人が相続人である場合には、相続税法第12条第1項第5号により「500万円×法定相続人の数」までが非課税です。

| 論点 | 民法（遺産分割） | 相続税法（課税） |
| --- | --- | --- |
| 死亡保険金の位置づけ | 原則、受取人の固有財産（対象外） | みなし相続財産（課税対象） |
| 非課税の枠 | ― | 500万円×法定相続人の数 |
| 相続放棄した人が受け取った場合 | 固有財産（対象外） | 受け取れるが、非課税枠は使えない |

非課税枠の計算に使う「法定相続人の数」は、相続の放棄をした人がいても、その放棄がなかったものとした場合の相続人の数で数えます。法定相続人に養子がいるときは、この数に含める養子の数に上限があり、実子がいる場合は1人まで、実子がいない場合は2人までです。相続人以外の人（たとえば孫やいとこ）が受取人の場合は、非課税枠の適用はありません。相続税の要否そのものは基礎控除との関係で決まります（[相続税の申告は必要？](/legal/column/souzoku-zei-shinkoku-hitsuyo)）。税額の計算や申告の要否の最終判断は、税務の専門家である税理士が行います。当事務所は税務相談を行いません。

## 保険金の扱いで揉めたら、誰に相談するのか（振り先の整理）

生命保険金をめぐる相続の問題は、民法・税法・保険実務が交わるため、担当が分かれます。相続財産そのものの分け方を決める遺産分割協議書の作成や、相続人を確定する戸籍の収集は行政書士が支援できます。一方、保険金が特別受益に準じて持ち戻されるかどうかといった、相続人間で争いのある個別判断は弁護士の領域です。

- 遺産分割協議書の作成、戸籍収集・相続人調査 → 四葉行政書士事務所（行政書士）

## よくある質問

**Q. 兄だけが受取人の生命保険金があります。私も分けてもらえますか？**
A. 原則として分ける対象にはなりません。受取人が指定された死亡保険金は受取人（お兄様）の固有の財産で、遺産分割の対象外です（最高裁平成16年10月29日決定）。ただし、その保険金による不公平が著しく、民法第903条の趣旨に照らして到底是認できない特段の事情がある場合には、例外的に特別受益に準じて持ち戻される可能性があります。当てはまるかどうかは争いのある個別判断のため、弁護士にご相談ください。

**Q. 保険金が遺産の大部分を占めていれば、必ず持ち戻しになりますか？**
A. 金額や比率が大きいというだけで自動的に持ち戻しになるわけではありません。最高裁は、保険金の額、遺産総額に対する比率のほか、同居の有無や被相続人の介護等への貢献の度合いなど、諸般の事情を総合考慮して判断すべきだとしています。一律の基準はなく、結論は事案ごとに分かれます。

**Q. 遺産分割の対象でないなら、相続税もかかりませんか？**
A. 別の問題です。死亡保険金は遺産分割では原則対象外ですが、相続税では「みなし相続財産」として課税対象になります。受取人が相続人なら「500万円×法定相続人の数」までが非課税です（相続税法第12条第1項第5号）。税額や申告の要否の判断は税理士が行います。

**Q. 相続放棄をしても、保険金は受け取れますか？**
A. 受取人に指定されていれば、相続放棄をしても保険金は固有の財産として受け取れます。ただし相続税の非課税枠（500万円×法定相続人の数）は、放棄した人には適用されません。放棄がなかったものとして数える「法定相続人の数」に放棄者は含めますが、放棄者自身が受け取る保険金は非課税枠の対象外になります。
