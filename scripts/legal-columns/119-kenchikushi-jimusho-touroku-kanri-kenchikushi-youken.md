**結論（先に要点）**：他人の求めに応じ報酬を得て建築物の設計や工事監理を業として行うには、建築士法第23条に基づき、建築士事務所として都道府県知事の登録を受けなければなりません。これは建設工事の請負に必要な建設業許可（建設業法）とは別の制度です。登録の有効期間は登録の日から5年で、満了後も続けるには更新の登録が要ります（同条第2項・第3項）。建築士事務所ごとに専任の管理建築士を置く義務があり（第24条第1項）、管理建築士になれるのは、建築士として3年以上の設計その他国土交通省令で定める業務に従事した後、登録講習機関が行う管理建築士講習を修了した建築士です（同条第2項）。事務所に所属する建築士には、これとは別に定期講習（第22条の2）の受講義務もあります。本記事は一般的な情報提供であり、個別の事務所が登録要件や管理建築士の要件を満たすかを判断・保証するものではありません。登録申請・変更届の書類作成と提出の支援は四葉グループの行政書士が独立した事業体として担い、設計・工事監理・建築確認申請の業務そのものは建築士の独占業務、事務所物件の賃貸借・重要事項説明は別事業体である不動産業者、会社設立・役員変更の登記は司法書士、社会保険・労務は社会保険労務士、税務は税理士の領域です。それぞれ別々にご契約いただきます。

## 建築士事務所の「登録」は、建設業許可と何が違うのか？

出発点は「何を業として行うか」です。建築士法第23条第1項は、一級建築士、二級建築士もしくは木造建築士、またはこれらの者を使用する者が、他人の求めに応じ報酬を得て設計・工事監理などを業として行おうとするときは、建築士事務所を定めて都道府県知事の登録を受けなければならない、と定めています。つまり「設計・工事監理を反復継続して報酬を得て行う」ことに着目した登録です。一方、建設業許可（建設業法第3条）は「建設工事の請負」に着目した別制度で、1件の請負代金が一定額（建築一式工事は1,500万円、それ以外の工事は500万円。いずれも税込）以上になる工事を請け負うときに必要になります。

| 項目 | 建築士事務所の登録 | 建設業許可 |
| --- | --- | --- |
| 根拠法 | 建築士法第23条 | 建設業法第3条 |
| 着目点 | 報酬を得て設計・工事監理等を業として行う | 建設工事の請負を業として行う |
| 必要になる場面 | 他人の求めに応じ報酬を得て設計等を反復継続して行うとき | 1件の請負代金が一定額（建築一式1,500万円／他500万円・税込）以上の工事を請け負うとき |
| 登録・許可先 | 都道府県知事 | 国土交通大臣または都道府県知事 |
| 有効期間 | 5年（更新の登録が必要） | 5年（更新が必要） |

設計事務所を構えるだけなら建設業許可は要りませんが、自社で工事まで請け負うなら双方が関係することもあります。建設業許可そのものの要件は論点が異なるため、[建設業許可の要件（経営業務の管理責任者・専任技術者・財産的基礎）](/legal/column/kensetsugyo-kyoka-yoken-keikan-sengi-zaisan)もあわせてご確認ください。電気工事を扱うなら[電気工事業の登録・みなし登録・通知](/legal/column/denki-koji-gyo-touroku-eigyosho-shunin)もまた別の手続です。どの制度に当たるかは事業の中身で分かれるため、計画の早い段階で所管の都道府県（指定事務所登録機関）に確認することが欠かせません。

## 管理建築士には、どんな要件（専任・講習修了）が要るのか？

建築士法第24条第1項は、建築士事務所の開設者に対し、一級建築士事務所・二級建築士事務所・木造建築士事務所ごとに、当該事務所を管理する専任の一級建築士・二級建築士・木造建築士（管理建築士）を置くことを義務づけています。管理建築士は登録の前提であり、これを欠くと登録を受けられません（第23条の4の登録拒否事由）。

管理建築士になれる人の要件は第24条第2項に定められています。建築士として3年以上の設計その他の国土交通省令で定める業務に従事した後、登録講習機関が行う管理建築士講習の課程を修了した建築士でなければなりません。

| 項目 | 内容（根拠） |
| --- | --- |
| 設置義務 | 事務所ごとに専任の管理建築士を置く（第24条第1項） |
| 資格 | 建築士として3年以上の設計その他省令で定める業務に従事（第24条第2項） |
| 講習 | 上記の後に登録講習機関の管理建築士講習を修了（第24条第2項） |
| 専任の意味 | その事務所に常勤し、管理に専念していること。他の事務所との兼任や非常勤は原則として認められない |

ここで注意したいのは、管理建築士講習は「管理建築士になるための講習」であり、後述の定期講習（第22条の2）とは別物だという点です。実務経験の年数や業務の内容が要件を満たすかどうかは建築士法に基づく判断で、行政書士が独占業務として代わりに判定するものではありません。名義だけを借りて実際には常勤していない「名義貸し」の管理建築士は、登録拒否や登録取消の対象になります。

## 登録の有効期間・更新・変更届は、いつ何を出すのか？

登録の有効期間は、登録の日から起算して5年です（建築士法第23条第2項）。有効期間の満了後も引き続き建築士事務所の業務を行おうとするときは、更新の登録を受けなければなりません（同条第3項）。更新を失念して有効期間が切れると登録は失効し、無登録のまま設計等の業務を続けることはできません。

| 手続 | 内容（根拠・運用） |
| --- | --- |
| 登録の有効期間 | 5年（第23条第2項） |
| 更新の登録 | 満了後も続けるなら必要（第23条第3項）。多くの都道府県では満了のおおむね30日前までの申請を求める |
| 登録事項の変更の届出 | 名称・所在地・管理建築士・所属建築士などに変更があったとき |
| 廃業等の届出 | 建築士事務所を廃止・休止したとき |

登録申請の手続は第23条の2（申請書の記載事項）・第23条の3（登録の実施）に定められています。更新の申請時期や変更届の期限・様式は都道府県（指定事務所登録機関）ごとに運用が異なるため、満了日を管理し、変更が生じたら速やかに届け出ることが実務の要になります。「他県ではこの書式だった」がそのまま通用しないことがある点も、申請実務でよく問題になります。

## 事務所の実態（専用性・設備）はどこまで求められるのか？

登録は「書類がそろっていれば足りる」ものではなく、事務所としての実態が伴っていることが前提です。とくに専任の管理建築士が実際に常勤し、その事務所を管理していることが問われます。管理建築士を置かない、あるいは名義だけで実態を欠くことは、建築士法第24条第1項違反として、登録拒否（第23条の4）や登録取消（第26条）の理由になります。実際に、管理建築士を置かなかったことを理由に都道府県が登録を取り消した処分事例もあります。

| 確認される点 | 具体例 |
| --- | --- |
| 管理建築士の常勤・専任 | その事務所に常勤し、他事務所と兼任していないこと |
| 事務所としての実態 | 業務を行う独立したスペース、設計図書の保存・業務記録 |
| 名義貸しでないこと | 管理建築士・所属建築士が実在し、実際に業務に関与していること |

設備や図書の保存に関する具体的な運用（備える書類、保存年限、報告書の提出など）は建築士法と国土交通省令・各都道府県の手引で定められており、品目や様式の細部は所管の窓口が判断します。開業前に、管轄の都道府県（指定事務所登録機関）へ事前相談しておくと、提出直前の差し戻しを避けやすくなります。

## 登録（行政書士）と、設計・監理（建築士）・登記（司法書士）はどう分けるのか？

関係する専門家が分かれるため、それぞれ独立した事業体として別々にご契約いただくのが基本です。四葉グループの行政書士は、建築士事務所の登録・更新・変更届の申請書類の作成補助と、所管の都道府県（指定事務所登録機関）への事前相談の案内を、独立した事業体として担います。

| 依頼先 | 主な役割 |
| --- | --- |
| 行政書士（当事務所） | 建築士事務所の登録・更新・変更届の申請支援、建設業許可の申請支援（別論点） |
| 建築士 | 設計・工事監理・建築確認申請など、建築士の独占業務そのもの |
| 司法書士 | 会社設立・役員変更などの商業登記 |
| 不動産業者（別事業体の当社） | 事務所物件の選定・賃貸借の媒介・重要事項説明 |
| 社会保険労務士 | 従業員の社会保険・労務の手続 |
| 税理士 | 開業後の税務 |

当事務所の[取扱業務](/legal/services)・[受任の流れ](/legal/nagare)・[報酬額表](/legal/ryokin)もご覧ください。各専門家とは独立した事業体として契約し、相互に紹介料を受け取りません。登録はあくまで設計・工事監理を業として行うための入口であり、設計・監理の内容そのものの判断は建築士が行います。

## よくある質問

**Q. 自宅で一人で設計の仕事をする場合も、建築士事務所の登録は必要ですか？**
A. 他人の求めに応じ報酬を得て設計・工事監理などを業として（反復継続して）行うなら、規模にかかわらず建築士事務所の登録が必要です（建築士法第23条）。一人であっても、その人が専任の管理建築士の要件（建築士として3年以上の実務＋管理建築士講習の修了）を満たす必要があります。事務所としての実態が伴うかも確認されます。

**Q. 建設業許可を持っていれば、建築士事務所の登録は要りませんか？**
A. 別の制度なので、建設業許可があっても設計・工事監理を業として行うなら建築士事務所の登録が別途必要です。建設業許可は建設工事の請負（建築一式1,500万円、他500万円・いずれも税込以上など）に必要なもので、設計・工事監理を業とすることをカバーしません。扱う業務の内容で判断します。

**Q. 管理建築士の定期講習と、管理建築士講習は同じものですか？**
A. 別のものです。管理建築士講習は、管理建築士になるために実務経験の後に修了する講習です（第24条第2項）。定期講習は、建築士事務所に所属する一級・二級・木造建築士が受け続ける講習で、建築士法第22条の2に基づき、国土交通省令で定める期間ごと（法律上は3年以上5年以内の範囲で、施行規則により3年度ごと）に受講する義務があります。

**Q. 登録の更新を忘れて有効期間が切れたらどうなりますか？**
A. 登録の有効期間は5年で、満了後も続けるには更新の登録が必要です（建築士法第23条第2項・第3項）。更新を失念すると登録は失効し、無登録のまま設計等の業務を続けることはできません。多くの都道府県では満了のおおむね30日前までの申請を求めています。満了日を管理し、余裕をもって手続を行うことが大切です。
