**結論（先に要点）**：相続放棄の熟慮期間3か月は、自己のために相続の開始があったことを知った時から数えます（民法第915条第1項）。間に合わなければ家庭裁判所に伸長を申し立てられ、過ぎた後でも起算点が例外的にずれる場合があります。家裁への申述・申立書類の作成は行政書士の業務範囲外です。

**情報確認日：2026年10月23日**。本記事は、3か月前後の相続人や、後から借金が判明した相続人に向けて、熟慮期間の起算点と伸長申立てに絞って整理します。制度の全体像は[相続放棄・限定承認の基本](/legal/column/souzoku-hoki-gentei-shonin)、借金・保証債務の調べ方は[相続する借金・保証債務の調査](/legal/column/souzoku-saimu-hoshou-saimu-chosa-junpro-kikan)をご覧ください。条文は[e-Gov法令検索](https://laws.e-gov.go.jp/law/129AC0000000089)で照合しました。

## 相続放棄の「熟慮期間」3か月はいつから数えるのか

民法第915条第1項は、相続人は自己のために相続の開始があったことを知った時から3か月以内に、単純承認・限定承認・相続放棄のいずれかをしなければならないと定めます。この3か月を熟慮期間と呼びます。起算点は「死亡の日」ではなく「自己のために相続の開始があったことを知った時」である点が、実務では重要です。

| 相続人の状況 | 起算点 | 根拠 |
| --- | --- | --- |
| 通常の相続人 | 自己のために相続の開始があったことを知った時 | 民法第915条第1項 |
| 相続人が承認・放棄せずに死亡（再転相続） | その者の相続人が、自己のために相続の開始があったことを知った時 | 民法第916条 |
| 相続人が未成年者・成年被後見人 | 法定代理人が相続の開始を知った時 | 民法第917条 |

熟慮期間が過ぎ、期間内に限定承認も放棄もしなかったときは、単純承認をしたものとみなされます（法定単純承認。民法第921条第2号）。単純承認をすると、被相続人の権利義務を無限に承継します（民法第920条）。なお、民法第915条第2項により、相続人は承認・放棄をする前に相続財産を調査できます。

## 3か月では決めきれないとき、期間は延ばせるのか

延ばせる場合があります。民法第915条第1項ただし書は、利害関係人または検察官の請求によって、家庭裁判所が熟慮期間を伸長できると定めます。相続財産が多数にわたり調査に時間がかかる、債務の全体像がつかめない、といった事情があるときに使われます。

| 項目 | 内容 |
| --- | --- |
| 申立てができる人 | 利害関係人（相続人を含む）・検察官 |
| 申立先 | 被相続人の最後の住所地の家庭裁判所 |
| 申立ての時期 | 原則として3か月の熟慮期間内 |
| 根拠 | 民法第915条第1項ただし書、家事事件手続法第201条 |

伸長の申立ては、熟慮期間が満了する前に行うのが原則です。伸長が認められるかどうか、どれだけ延ばせるかは家庭裁判所の判断です。伸長を却下する審判には即時抗告ができます（家事事件手続法第201条第9項）。手続の詳細は裁判所の案内で確認してください。

## 期間を過ぎた後に借金が判明したら、もう放棄できないのか

必ずしも諦める必要はありません。最高裁昭和59年4月27日判決は、熟慮期間の起算点について例外を示しました。相続人が、被相続人に相続財産が全く存在しないと信じ、かつそう信じたことに相当な理由があると認められるときは、熟慮期間は相続財産の全部または一部の存在を認識した時、または通常これを認識することができる時から起算するとしたものです。

この考え方によれば、死亡から3か月を過ぎた後に借金の存在を知った場合でも、起算点が後ろにずれていて放棄の余地が残ることがあります。ただし、これは事案ごとの評価であり、「3か月を過ぎれば必ず放棄できる」「必ずできない」と一律に断定できるものではありません。適用の可否は、知った時期や調査の経緯などの事実関係によって変わります。後から多額の債務が判明したケースの見通しは、司法書士・弁護士に相談してください。

なお、いったんした相続放棄は、熟慮期間内であっても撤回できません（民法第919条第1項）。錯誤・詐欺などによる取消しは別に認められますが、取消権は追認できる時から6か月、放棄の時から10年で時効消滅します（民法第919条第3項）。

## 放棄の申述や伸長の申立ては誰が書類を作れるのか

相続放棄は、家庭裁判所に申述して行います（民法第938条）。申述が受理されると、その相続に関して初めから相続人とならなかったものとみなされます（民法第939条）。熟慮期間の伸長も、家庭裁判所への申立てによります。

ここで注意が必要なのは、担い手の違いです。家庭裁判所に提出する申述書・申立書といった裁判所提出書類の作成は、行政書士の業務範囲外です。これらは司法書士または弁護士が担います。行政書士は、相続財産・債務の調査や財産目録の作成支援、遺産分割協議書の作成といった範囲を担います。

| 書類・手続 | 作成・代理の担い手 |
| --- | --- |
| 相続放棄の申述書 | 司法書士・弁護士 |
| 熟慮期間の伸長の申立書 | 司法書士・弁護士 |
| 債権者との交渉・相続をめぐる紛争 | 弁護士 |
| 相続財産・債務の調査、財産目録の作成支援 | 行政書士 |

## 財産調査・申述・紛争は誰に頼むのか（分離受任の整理）

熟慮期間は短く、調べることと手続することが同時に進みます。役割を分けて、期限を意識して頼むのが基本です。

| 依頼先 | 担当する範囲 |
| --- | --- |
| 四葉行政書士事務所 | 相続財産・債務の調査、財産目録・遺産分割協議書の作成支援 |
| 司法書士・弁護士 | 相続放棄・熟慮期間伸長の家裁への申述・申立書類の作成 |
| 弁護士 | 債権者との交渉、相続をめぐる紛争 |
| 司法書士 | 相続登記 |
| 税理士 | 相続税の試算・申告 |

**家庭裁判所に提出する申述書・申立書の作成は、行政書士の業務範囲外です。** 四葉行政書士事務所、四葉社会保険労務士事務所、四葉不動産株式会社はそれぞれ別事業体で、独立した事業体として受任します。各分野の担当者と別々にご契約いただき、各受任者が直接請求・入金を受けます。当事務所は紹介料を受け取りません。

## よくある質問

**Q. 熟慮期間の3か月は死亡の日から数えるのですか？**
A. いいえ。自己のために相続の開始があったことを知った時から数えます（民法第915条第1項）。死亡を知った時期や、自分が相続人になったことを知った時期によって起算点が変わる場合があります。再転相続（民法第916条）や未成年者等（民法第917条）には別の起算の定めがあります。

**Q. 3か月で決められないときはどうすればよいですか？**
A. 被相続人の最後の住所地の家庭裁判所に、熟慮期間の伸長を申し立てられます（民法第915条第1項ただし書、家事事件手続法第201条）。原則として3か月の期間内に申し立てます。認められるか、どれだけ延ばせるかは家庭裁判所の判断です。

**Q. 3か月を過ぎたら相続放棄はできませんか？**
A. 一律にはできないとは限りません。最高裁昭和59年4月27日判決は、相続財産が全く存在しないと信じ、そう信じたことに相当な理由がある場合に起算点がずれるとしました。適用の可否は事案ごとで、見通しは司法書士・弁護士に相談してください。

**Q. 相続放棄の書類は行政書士に頼めますか？**
A. 家庭裁判所に提出する申述書・申立書の作成は行政書士の業務範囲外で、司法書士・弁護士が担います。行政書士は相続財産・債務の調査や財産目録・遺産分割協議書の作成支援を行います。
