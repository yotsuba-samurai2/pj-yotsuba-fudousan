**結論（先に要点）**：業務用の冷凍・空調設備を扱う事業では、取り扱う内容ごとに別々の許認可が重なります。冷媒などの高圧ガスを販売するなら高圧ガス保安法第20条の4の販売事業の届出（販売所ごとに事業開始の日の20日前までに都道府県知事へ）、業務用エアコンや業務用冷凍冷蔵機器の冷媒フロン類を充塡・回収するなら「フロン類の使用の合理化及び管理の適正化に関する法律」（フロン排出抑制法）第27条第1項の第一種フロン類充塡回収業者の登録（業務を行う区域を管轄する都道府県知事、有効期間5年＝同法第30条）が必要です。冷凍設備そのものの設置（高圧ガスの「製造」）は冷凍能力に応じて高圧ガス保安法第5条の許可または届出に分かれ、冷凍保安規則が適用されます。四葉行政書士事務所は官公署への提出書類の作成・提出を行政書士法第1条の2の範囲で別契約で受任し、資料と情報の提供までを行います。設備の施工・保安は有資格の工事業者と保安責任者、物件は別事業体の不動産、登記は司法書士、税務は税理士が、いずれも独立した事業体として別々にご契約いただきます。本記事は一般的な情報提供であり、個別の登録・届出の可否という具体的な法的判断は行いません。当事務所は紹介料を受け取りません。

## 業務用の冷凍・空調設備を扱うと、まずどんな許認可が必要になりますか？

冷凍・空調設備の事業は「何をするか」で必要な手続が変わります。一つの事業に複数の手続が重なることが多く、まずは行為ごとに切り分けます。

| 行う行為 | 主な根拠 | 手続の性格 |
| --- | --- | --- |
| 冷媒などの高圧ガスを販売する | 高圧ガス保安法第20条の4 | 販売事業の届出（都道府県知事） |
| 業務用エアコン・業務用冷凍冷蔵機器の冷媒フロン類を充塡・回収する | フロン排出抑制法第27条第1項 | 第一種フロン類充塡回収業者の登録（都道府県知事） |
| 冷凍設備で高圧ガスを「製造」する（冷凍能力が一定以上） | 高圧ガス保安法第5条 | 冷凍能力に応じ許可（第一種製造者）または届出（第二種製造者） |

「販売」と「充塡・回収」と「製造（冷凍）」は別の制度で、該当すればそれぞれ手続が要ります。たとえば冷凍倉庫を自社で開設して冷媒の補充や機器更新まで行うなら、販売・充塡回収・冷凍設備の設置がそれぞれ別に問われ得ます。どの行為に当てはまるかは事業の形で変わるため、設備と取引の内容が固まった段階で、所管の都道府県（高圧ガス・フロン担当課）に照会しながら整理します。関連する登録制度として、自動車（カーエアコン＝第二種特定製品）側のフロン類回収は[引取業・フロン類回収業の登録](/legal/column/jidosha-recycle-hikitori-furon-kaishu-gyo-touroku)で別に扱っています。

## 高圧ガス保安法の販売事業の届出は、どこに・いつ出しますか？

高圧ガスの販売の事業を営もうとする者は、販売所ごとに、事業開始の日の20日前までに、販売する高圧ガスの種類などを記載した書面を添えて、その旨を都道府県知事に届け出なければなりません（高圧ガス保安法第20条の4）。届け出た者は「販売業者」と呼ばれます。

| 項目 | 条文上の整理 |
| --- | --- |
| 届出先 | 都道府県知事（販売所ごと） |
| 時期 | 事業開始の日の20日前まで（高圧ガス保安法第20条の4） |
| 承継 | 事業の全部の譲渡・相続・合併・分割があれば遅滞なく届出（同法第20条の4の2） |
| 廃止 | 事業を廃止したときは遅滞なく届出（同法第21条） |

ただし例外があります。第一種製造者が自ら製造した高圧ガスをその事業所で販売するときなど、政令で定める場合は届出が不要とされます。また、液化石油ガス（LPガス）を一般消費者等に販売する場合は高圧ガス保安法ではなく液石法の販売事業の登録の対象で、制度が分かれます。市の区域では市長や消防長が受付窓口になることもあり、提出先・様式・添付書類は自治体で異なるため、販売所の所在地が決まった段階で所管の都道府県（または市の消防保安担当）に確認します（経済産業省・各都道府県の案内・参照日 2026-11-03）。

## 第一種フロン類充塡回収業者の登録の要件と有効期間は？

業務用エアコンや業務用冷凍冷蔵機器（冷凍冷蔵機能付き自動販売機を含む。これらを第一種特定製品といいます＝フロン排出抑制法第2条第3項）に冷媒として充塡されているフロン類の充塡・回収を業として行おうとする者は、その業務を行おうとする区域を管轄する都道府県知事の登録を受けなければなりません（フロン排出抑制法第27条第1項）。家庭用エアコンは第一種特定製品に含まれず、カーエアコン（第二種特定製品＝同法第2条第4項）のフロン類回収は自動車リサイクル法の枠組みで、別の制度です。

| 項目 | 条文上の整理 |
| --- | --- |
| 登録先 | 業務を行う区域を管轄する都道府県知事（フロン排出抑制法第27条第1項） |
| 申請書の記載 | 氏名・住所、業務の用に供する設備など（同法第27条第2項） |
| 登録の拒否 | 欠格事由や回収設備が基準に適合しない場合など（同法第29条） |
| 有効期間 | 5年。更新を受けなければ効力を失う（同法第30条第1項・第2項） |
| 変更の届出 | 登録事項に変更があったときは30日以内に届出（同法第31条） |

登録簿は一般の閲覧に供されます（同法第32条）。回収設備の技術上の基準や欠格事由の具体的な中身、更新の受付時期（自治体により有効期限の2〜3か月前からなど）や手数料は都道府県で運用が分かれ、改正もあるため、申請の直前に所管の都道府県の最新の案内で確認します。複数の都道府県で業務を行うなら、区域ごとに登録が要るかを含めて窓口に確かめます。どの要件に当てはまるかという最終的な当てはめは、登録を行う都道府県が審査のうえ判断します。

## 冷凍倉庫の開設で、許認可はどんな順番で並びますか？

冷凍倉庫を構えて低温物流を行う場合、設備・保安・登録・労務・物件が並行して動きます。順番の目安は次のとおりで、担当は分野ごとに分かれます。

- 物件の選定と適合確認（用途地域・床荷重・電力容量など） → 別事業体の四葉不動産株式会社（宅地建物取引業者）が、独立した事業体として別契約で対応
- 冷凍設備の設計・施工と、冷凍能力に応じた高圧ガス保安法第5条の許可（第一種製造者）または届出（第二種製造者） → 有資格の設備・電気工事業者と高圧ガス製造保安責任者。書類の作成は行政書士が支援
- 冷媒フロン類を扱うなら第一種フロン類充塡回収業者の登録（フロン排出抑制法第27条第1項）
- 冷媒などの高圧ガスを販売するなら販売事業の届出（高圧ガス保安法第20条の4）
- 倉庫業として営むなら倉庫業法の登録（施設設備基準の適合。物件要件は不動産側で確認）
- 従業員の就業規則・低温作業の安全衛生・シフト → 社会保険労務士（別事業体）

倉庫業法の登録や保管する食品・医薬品の営業許可は所管が別で、それぞれ独立した事業体として別々にご契約・お手続きいただきます。低温物流施設の物件適合は[冷蔵・冷凍倉庫の物件要件](/column/reizo-reito-souko-butsuryu-bukken-youken)（別事業体の不動産側コラム）で、低温作業の労務は社会保険労務士側で整理しています。手続の前後関係は設備の規模や事業形態で変わるため、全体像を描いたうえで着手の順を決めます。

## 行政書士が作れる書類と、工事・保安で有資格者に頼む部分はどう分かれますか？

行政書士は、官公署に提出する書類の作成と提出手続の代理を独占業務として受任します（行政書士法第1条の2）。一方、設備の施工や保安の監督は、別の資格者の領域です。担当は次のとおり分かれ、それぞれ独立した事業体として別々にご契約・お手続きいただきます。

- 販売事業の届出、第一種フロン類充塡回収業者の登録申請、冷凍設備に係る許可・届出の書類作成と提出の代理 → 四葉行政書士事務所（行政書士）。資料と情報の提供までを行い、具体的な法的判断はしません
- 冷凍設備・配管・電気設備の施工 → 高圧ガス製造保安責任者、電気工事士、規模により建設業の許可を受けた施工業者
- 高圧ガスの製造・保安の監督 → 高圧ガス製造保安責任者などの有資格者
- 出店物件・倉庫用地の選定・賃貸借の媒介 → 別事業体の四葉不動産株式会社（宅地建物取引業者）
- 法人を設立して営業する場合の設立登記 → 司法書士
- 開業後の記帳・税務申告 → 税理士
- 就業規則・安全衛生・シフトなどの労務 → 社会保険労務士
- 取引・契約をめぐる紛争の代理・法律判断 → 弁護士

各分野は、それぞれの窓口・資格者と別々にご契約いただく前提で、当事務所は紹介料を受け取りません。登録や届出の要否・窓口が不安な段階でも、設備と取引の内容を決める前にご相談ください。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務は[取扱業務一覧](/legal/services)をご覧ください。関連する許認可として、[毒物劇物販売業の登録](/legal/column/dokugekibutsu-hanbaigyo-touroku-kozo-setsubi-kijun)、[電気工事業の登録](/legal/column/denki-koji-gyo-touroku-eigyosho-shunin)もあわせてご確認ください。

## よくある質問

**Q. 冷媒を売るだけでも高圧ガスの手続は要りますか？**
A. 冷媒などの高圧ガスの販売を業として行うなら、販売所ごとに事業開始の日の20日前までに都道府県知事へ販売事業の届出が必要です（高圧ガス保安法第20条の4）。ただし第一種製造者が自ら製造したガスを事業所で販売する場合など、政令で定める場合は届出が不要です。LPガスを一般消費者等に売る場合は液石法の登録が別に要るなど制度が分かれるため、取り扱うガスと販売形態を所管の都道府県に確認してください。

**Q. 第一種フロン類充塡回収業者の登録はどこに出し、何年有効ですか？**
A. 業務を行おうとする区域を管轄する都道府県知事に登録を受けます（フロン排出抑制法第27条第1項）。有効期間は5年で、更新を受けなければ効力を失います（同法第30条）。登録事項に変更があれば30日以内の届出が必要です（同法第31条）。回収設備の基準や更新の受付時期・手数料は都道府県で運用が分かれるため、申請直前に所管の都道府県の最新の案内で確認してください。

**Q. 業務用エアコンと家庭用エアコン、カーエアコンで扱いは違いますか？**
A. 違います。業務用エアコンや業務用冷凍冷蔵機器は第一種特定製品（フロン排出抑制法第2条第3項）で、充塡・回収は第一種フロン類充塡回収業者の登録の対象です。家庭用エアコンは第一種特定製品に含まれません。カーエアコンは第二種特定製品（同法第2条第4項）で、フロン類回収は自動車リサイクル法の枠組みの別制度です。

**Q. 設備の工事から書類づくりまで、一つの事務所にまとめて頼めますか？**
A. 書類の作成・提出の代理は行政書士、冷凍設備・電気設備の施工は有資格の工事業者、高圧ガスの保安の監督は高圧ガス製造保安責任者、物件は別事業体の四葉不動産株式会社、登記は司法書士、税務は税理士、労務は社会保険労務士が担当し、それぞれ独立した事業体として別々にご契約いただきます。一つの窓口でご相談を受けて各担当に整理してお渡しすることはできますが、受任は分かれます。当事務所は紹介料を受け取りません。
