**結論（先に要点）**：「日本人の配偶者等」は、日本人の配偶者・特別養子・日本人の子として出生した者が対象の在留資格です（出入国管理及び難民認定法 別表第二）。認定・変更・更新では婚姻の実体と継続性が見られ、配偶者としての活動を継続して6か月以上行わないで在留すると、正当な理由がある場合を除き在留資格の取消し対象になります（入管法第22条の4）。

**情報確認日：2026年10月24日**。本記事は、中国・台湾出身の配偶者を持つ家族と、在留手続を支える現地の専門家向けに、「日本人の配偶者等」の認定・変更・更新で確認される点と取消しの枠組みを情報提供として整理します。条文は[e-Gov法令検索](https://laws.e-gov.go.jp/law/326CO0000000319)の法律名（出入国管理及び難民認定法）で照合し、運用は出入国在留管理庁の案内（参照日2026-10-24）で確認しました。審査基準の内部運用、個別事案での許否は未検証です。個別の在留の可否は地方出入国在留管理官署が判断し、紛争や法的判断は弁護士が扱います。

## 『日本人の配偶者等』はどんな人が対象になるのか？

出入国在留管理庁の案内（参照日2026-10-24）によると、この在留資格の該当者は「日本人の配偶者若しくは特別養子又は日本人の子として出生した者」です。日本人の夫または妻、日本人の実子、特別養子が当てはまります。在留期間は5年・3年・1年・6月のいずれかです。

| 区分 | 該当する人 |
| --- | --- |
| 日本人の配偶者 | 日本人と法律上の婚姻関係にある者 |
| 日本人の特別養子 | 民法上の特別養子縁組による子 |
| 日本人の子として出生した者 | 出生時に父または母が日本人であった実子 |

在留資格には三つの手続があります。海外にいる配偶者を招くときは在留資格認定証明書の交付申請、別の在留資格から切り替えるときは在留資格変更許可申請、同じ資格を延ばすときは在留期間更新許可申請です。申請は本人または地方出入国在留管理官署に認められた代理人等が行います。

## 在留資格認定・更新で婚姻の実体はどう確認されるのか？

「配偶者」として在留する以上、婚姻が形式だけでなく実体を伴い、継続していることが確認されます。出入国在留管理庁の提出資料一覧（参照日2026-10-24）では、婚姻の実体や生活の状況を示す資料が求められます。具体的な様式・部数は申請の種類や官署で異なるため、最新の一覧で確認してください。

| 確認される観点 | 示す資料の例（庁の案内による） |
| --- | --- |
| 婚姻の成立 | 戸籍謄本、本国の婚姻証明書など |
| 同居・生活の実体 | 世帯全員が載った住民票の写し |
| 婚姻の実体・交流 | 質問書、夫婦の写真、連絡の記録など |
| 生計・安定性 | 身元保証書、住民税の課税・納税証明書、在職証明など |

これらは「婚姻が実体を伴って継続しているか」を総合的に見るための資料です。資料が形式的にそろっていても、実体が確認できなければ慎重に審査されます。どの資料をどう整えるかは個別事情で変わり、最終的な許否は官署が判断します（本記事では個別の可否判断は行いません）。

## 収入や同居が不安定なとき更新は不許可になるのか？

収入や同居の状況は、更新の審査で考慮される要素の一つです。ただし一つの数字で機械的に決まるわけではなく、婚姻の実体と継続性、生活の安定性が総合的に見られます。収入が低い、転職直後、単身赴任や入院で一時的に別居している、といった事情があるときは、事情を説明する理由書や裏づけ資料を添えて、実体が続いていることを示すのが実務上の一般的な対応です。

不許可の見込みや、どの資料で何を補えばよいかといった個別の見通しは、事案ごとに異なります。本記事は一般的な情報提供にとどめ、個別の判断は地方出入国在留管理官署への確認と有資格の専門家への相談によります。

## 別居・離婚・死別で在留資格はどうなるのか（22条の4）？

「日本人の配偶者等」で在留する人が、配偶者としての活動を継続して6か月以上行わないで在留していると、正当な理由がある場合を除き、在留資格の取消しの対象になります（入管法第22条の4）。出入国在留管理庁の案内（参照日2026-10-24）は、この取消事由の対象を「日本人の配偶者等」「永住者の配偶者等」で在留する配偶者とし、日本人の子・特別養子は対象外としています。

| 場面 | 在留資格との関係（一般的な整理） |
| --- | --- |
| 単身赴任・入院など一時的な別居 | 婚姻が継続していれば直ちに取消しに至らない。事情の説明が有効 |
| 離婚・死別 | 配偶者としての活動ができなくなる。6か月を一つの目安に在留資格の変更等を検討 |
| DV等からの避難による別居 | 「正当な理由」に当たり得る（法務省が2012年7月に具体例を公表） |

取消しの前には、入国審査官による意見聴取が行われ、本人は意見を述べ、証拠を提出し、資料の閲覧を求めることができます。この第7号は取消しの後に出国のための期間（30日を上限）が指定される類型で、直ちに退去強制となるものではありません（庁の案内・参照日2026-10-24）。離婚・死別の後も日本での在留を続けたい場合は、就労資格や定住者などへの在留資格変更を早めに検討するのが実務の基本です。何がその人にとって「正当な理由」や変更の可能性に当たるかは個別事情で異なり、最終判断は官署が行います。

## 紛争や戸籍の手続は誰に相談するのか（分離受任の整理）

国際結婚と在留をめぐる手続は、在留・紛争・戸籍という性質の違う作業に分かれます。それぞれの担当に分けて相談するのが基本です。

| 相談先 | 担当する範囲 |
| --- | --- |
| 四葉行政書士事務所 | 在留資格認定・変更・更新の申請書類の作成支援、資料の整理 |
| 弁護士 | 離婚・DV・親権・財産分与など紛争の代理・法的判断 |
| 市区町村の窓口 | 婚姻届・戸籍・住民票の手続 |
| 本国の公的機関・現地専門家 | 本国の婚姻証明・出生証明などの取得と認証 |

四葉行政書士事務所、四葉社会保険労務士事務所、四葉不動産株式会社はそれぞれ別事業体で、独立した事業体として受任します。弁護士も当事務所とは別の独立した事業体です。各分野の担当者と別々にご契約いただき、各受任者が直接請求・入金を受けます。当事務所は紹介料を受け取りません。離婚・DV・親権など紛争の代理や法的判断は弁護士の領域で、行政書士は扱えません。戸籍・婚姻届は市区町村の、在留の許否は出入国在留管理官署の手続で、いずれも受任契約の相手ではありません。

[国際業務サポート](/legal/services)、[受任の流れ](/legal/nagare)、[報酬額表](/legal/ryokin)をご確認ください。永住や帰化は別の在留・国籍の手続として、[永住許可（中国・台湾の専門職）](/legal/column/eiju-kyoka-shinsei-chuka-taiwan-senmonshoku)、[帰化許可の要件（中国・台湾）](/legal/column/kika-shinsei-yoken-kokusekiho-chuka-taiwan)に整理しています。本国の親族関係を示す公証書・領事認証は[中国大陸の相続人・親族関係の公証書と領事認証](/legal/column/chugoku-tairiku-souzokunin-shinzoku-koshosho-ryoji-ninsho)を参照してください。

## よくある質問

**Q. 婚姻届を出せばすぐ「日本人の配偶者等」で在留できますか？**
A. 婚姻の成立だけでは足りず、婚姻が実体を伴って継続していることが確認されます。海外にいる配偶者は在留資格認定証明書の交付申請、国内で別の資格から切り替える場合は在留資格変更許可申請を行い、質問書・住民票・交流を示す資料などで実体を示します（出入国在留管理庁・参照日2026-10-24）。許否は官署が判断します。

**Q. 離婚したら在留資格はすぐ無くなりますか？**
A. 離婚で直ちに資格が消えるわけではありませんが、配偶者としての活動ができなくなるため、その状態が継続して6か月以上続き正当な理由がなければ取消しの対象になり得ます（入管法第22条の4）。6か月を一つの目安に、就労資格や定住者などへの在留資格変更を早めに検討するのが実務の一般的な対応です。

**Q. DVから逃げて別居している場合はどうなりますか？**
A. DV等からの避難による別居は「正当な理由」に当たり得るとされ、法務省は2012年7月に取消しを行わない具体例を公表しています。相談記録・保護命令・診断書などが事情を示す資料になります。該当するかは個別事情で判断されるため、弁護士や地方出入国在留管理官署に早めに相談してください。

**Q. 収入が少ないと更新は必ず不許可ですか？**
A. 必ず不許可になるわけではありません。収入は考慮要素の一つで、婚姻の実体・継続性と生活の安定性が総合的に見られます。転職直後や一時的な収入減などの事情は、理由書と裏づけ資料で説明するのが一般的です。見通しは事案ごとに異なるため、官署への確認と専門家への相談によります。
