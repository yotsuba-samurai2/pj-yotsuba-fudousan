**結論（先に要点）**：酒類を製造するには、製造しようとする酒類の品目別に、かつ製造場ごとに、その所在地の所轄税務署長の「酒類製造免許」が必要です（酒税法第7条第1項）。ビールは年60キロリットル、発泡酒・その他の醸造酒類は年6キロリットルという最低製造数量基準（酒税法第7条第2項）を満たす見込みが要件になります。本記事は免許の区分・要件・申請の流れを行政書士の視点で整理する一般的な情報提供であり、免許可否の最終判断は所轄税務署が行います。酒税の申告・納税や税務は税理士、製造設備の建築確認・用途は建築士、飲食を併設する場合の食品衛生は保健所、物件の要件は宅地建物取引業者（別事業体の四葉不動産株式会社）に、それぞれ独立した事業体として別々にご契約いただく前提で分けて振ります。当事務所は紹介料を受け取りません。

## 酒類製造免許は「酒類小売免許」と何が違い、酒類ごとにどう免許が分かれるのか？

酒類に関する免許は、大きく「製造」と「販売」で分かれます。酒類を造る側が受けるのが酒類製造免許（酒税法第7条）で、できあがった酒類を売る側が受けるのが酒類販売業免許（酒税法第9条）です。醸造所（ブルワリー）を開いて自分で造ったビールを造る行為には製造免許が、それを瓶や缶で小売する行為には別途「酒類小売業免許」が必要になり得ます。造って売る場合は、製造免許とは別に販売の免許を検討することになります。酒類小売業免許の要件や店舗・物件の考え方は[酒類小売業免許と店舗・物件の要件](/legal/column/shurui-kouri-menkyo-tenpo-bukken-yoken)で整理しています。

製造免許は「品目別・製造場ごと」に受けます。つまり、ビールを造るならビールの免許、発泡酒を造るなら発泡酒の免許、というように、造る酒類の品目ごとに免許が分かれ、製造場（工場・醸造所）ごとに取得します。酒類の品目は酒税法第3条で清酒・ビール・果実酒・発泡酒・その他の醸造酒・リキュール・スピリッツなどに区分されており、同じ「クラフトビール」でも、麦芽の使用割合や副原料によってビールに当たるのか発泡酒・その他の醸造酒に当たるのかが変わります。どの品目の免許を申請するかは、原料とレシピを前提に所轄税務署へ確認します。品目区分の最終的な当てはめは税務署の判断です。

## ビール・発泡酒・その他の醸造酒類で求められる「最低製造数量基準」はいくらか？

酒類製造免許は、一の製造場で製造免許を受けた後1年間に製造しようとする見込数量が、品目ごとに定められた数量に達しない場合には受けることができません（酒税法第7条第2項）。これを最低製造数量基準といいます。主な品目は次のとおりです。

| 品目 | 最低製造数量基準（年・1製造場） |
|---|---|
| 清酒・合成清酒・連続式蒸留焼酎・ビール | 60キロリットル |
| 単式蒸留焼酎・みりん | 10キロリットル |
| 果実酒・甘味果実酒・ウイスキー・ブランデー | 6キロリットル |
| 発泡酒・その他の醸造酒・原料用アルコール | 6キロリットル |
| スピリッツ・リキュール・粉末酒・雑酒 | 6キロリットル |

クラフトビール開業でよく論点になるのが、ビール（60キロリットル）と発泡酒・その他の醸造酒類（いずれも6キロリットル）の差です。麦芽比率やホップ以外の副原料の使い方によっては、酒税法上「ビール」ではなく「発泡酒」や「その他の醸造酒」に区分され、小規模でも6キロリットルの基準で免許を検討できる場合があります。ただし品目区分は原料・製法で決まるもので、基準を下げる目的でレシピを決めるという順序ではありません。どの品目になるかは税務署の確認を要します。1994年にビールの基準が2000キロリットルから60キロリットルへ引き下げられた経緯はありますが、現行の数量は上表のとおりで、書く直前に国税庁の最新の手引で確認しています。

## 製造場所・設備にはどんな要件があるのか？（申請単位・製造設備）

免許は製造場ごとに受けるため、製造場所と設備が審査の対象になります。酒税法第10条は、免許の申請があった場合に各号のいずれかに該当すれば税務署長が免許を与えないことができる拒否要件を定めており、主な観点は次のとおりです。

| 観点 | 酒税法第10条の該当（概要） |
|---|---|
| 人的要件 | 免許取消しから一定年数内の者、国税・地方税の滞納処分、酒税法等の罰金刑からの経過年数など（第1号〜第8号） |
| 場所的要件 | 正当な理由なく、取締り上不適当な場所に製造場を設けようとする場合（第9号） |
| 経営基礎要件 | 経営の基礎が薄弱であると認められる場合（第10号） |
| 需給調整要件 | 酒税の保全上、酒類の需給の均衡を維持する必要があるため適当でないと認められる場合（第11号） |
| 技術・設備要件 | 製造技術の能力を備えていない、または製造場の設備が不十分であると認められる場合（第12号） |

製造設備（仕込・発酵・貯酒・ろ過・充填・計量など）や、製造数量を的確に管理できる体制が「技術・設備要件」として見られます。給排水・排水処理・建物の用途などは別の法令（建築基準法・水質関連の規制・食品衛生など）にもかかわるため、工事や賃貸借契約の前に、建築士・施工会社や所轄の窓口へ確認します。製造設備の建築確認・用途の判断は建築士の領域で、行政書士が設計や適法性を保証するものではありません。

## 構造改革特区（どぶろく特区・ワイン特区等）で基準が緩和されるのはどんな場合か？

構造改革特別区域法には、認定を受けた特区の中で最低製造数量基準を緩める酒税法の特例があります。代表的なのが、いわゆる「どぶろく特区」と「ワイン特区」です。

- どぶろく特区（構造改革特別区域法第25条「酒税法の特例」）：農家民宿などを営む特定農業者が、自ら生産した米や果実を原料に、濁酒（こさないその他の醸造酒）や果実酒を自己の営業場で提供するために製造する場合に、酒税法第7条第2項（最低製造数量基準）を適用しないとする特例です。
- ワイン特区・特産酒類の特例（構造改革特別区域法第26条）：認定計画に基づく事業者が特産の果実を原料に果実酒を造る場合などに、果実酒の基準を「6キロリットル」から「2キロリットル」に、リキュールを「1キロリットル」に読み替えるなどの緩和がされます（単式蒸留焼酎・原料用アルコールは適用除外）。

いずれも、その地域が構造改革特別区域計画の内閣総理大臣認定を受けていること、対象者・対象品目・原料の要件を満たすことが前提です。特区の外で同じ品目を造る場合は、原則どおりの最低製造数量基準が適用されます。自分の計画が特区の対象に当たるかどうかは、特区計画の内容と所轄税務署・自治体の案内で確認します。

## 申請はどこに・どんな書類で出し、審査にどれくらいかかるのか？

申請先は、製造場の所在地を管轄する税務署（所轄税務署長）です。申請書に加えて、事業の計画・製造方法・製造設備・資金計画・場所の状況などを示す添付書類を求められます。具体的な様式・添付書類は国税庁の「酒類製造免許の申請の手引」と所轄税務署の案内で確認します。

| 確認点 | 内容（申請前に税務署・手引で確認） |
|---|---|
| 申請先 | 製造場の所在地の所轄税務署長 |
| 免許の単位 | 品目別・製造場ごと |
| 主な添付書類 | 事業・製造計画、製造方法書、製造設備の概要、場所の図面・契約関係、収支見込み、申請者の経歴など |
| 審査の観点 | 人的・場所的・経営基礎・需給調整・技術/設備の各要件（酒税法第10条）、最低製造数量基準（第7条第2項）に達する見込み |
| 標準処理期間 | 税務署が公表する標準処理期間を目安に確認（申請内容により前後） |

審査にかかる期間は申請内容や補正の有無で変わります。標準処理期間は法定の確定した期限ではないため、スケジュールは所轄税務署に確認してください。免許を与えるかどうかの最終判断は所轄税務署が行います。行政書士は申請書類の作成・整理と手続の進行支援を担当し、可否や品目区分を保証するものではありません。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務は[許認可サービス](/legal/services)をご覧ください。

## 酒税の申告・物件・食品衛生は誰に頼むのか？（税理士・不動産・保健所の切り分け）

醸造所の開業は、免許だけでなく税務・物件・食品衛生など複数の分野にまたがります。それぞれ独立した事業体として別々にご契約いただく前提で分けて振ります。

| 依頼先 | 主な役割 |
|---|---|
| 四葉行政書士事務所 | 酒類製造免許の申請書類の作成・提出、手続の進行支援 |
| 税理士 | 酒税の申告・納税、法人税・消費税などの税務 |
| 建築士・施工会社 | 製造設備の設計・工事、建築確認・用途の判断（資格・業務範囲に応じて） |
| 保健所 | 飲食を併設する場合の飲食店営業許可・食品衛生の相談 |
| 四葉不動産株式会社（別事業体） | 製造用物件の紹介・賃貸借の仲介 |

酒税の申告・納税や税務は税理士、製造設備の建築確認・用途は建築士、飲食併設時の食品衛生許可は保健所、物件の要件は宅地建物取引業者の領域です。飲食店を併設するなら[飲食店営業許可と保健所の設備基準](/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)、食品の製造を伴うなら[食品製造業の許可と物件・設備基準](/legal/column/shokuhin-seizogyo-kyoka-bukken-setsubi-kijun)もあわせてご確認ください。四葉行政書士事務所・税理士・建築士・四葉不動産株式会社は別事業体であり、それぞれ独立した事業体として、各専門家・事業者と別々にご契約いただき、直接請求・直接入金の形で受任します。当事務所は紹介料を受け取りません。製造用物件の相談は別事業体の四葉不動産株式会社が担当します。

## よくある質問

**Q. クラフトビールを小さく造りたいのですが、必ず年60キロリットル造らないと免許は取れませんか？**
A. ビールの品目で免許を受ける場合は、1製造場で年60キロリットルの最低製造数量基準（酒税法第7条第2項）に達する見込みが必要です。ただし、麦芽比率や副原料によって酒税法上「発泡酒」や「その他の醸造酒」に区分される場合は、いずれも年6キロリットルの基準で免許を検討できることがあります。どの品目になるかは原料・製法で決まり、最終的な当てはめは所轄税務署が判断します。

**Q. 酒類製造免許と酒類小売業免許の両方が要りますか？**
A. 造る行為には製造免許（酒税法第7条）が、できた酒類を小売する行為には別に酒類小売業免許（酒税法第9条）が必要になり得ます。造って自ら売る場合は、両方の要否を分けて検討します。詳細は所轄税務署に確認してください。

**Q. どぶろく特区やワイン特区なら小規模でも造れますか？**
A. 認定を受けた特区の中で、対象者・対象品目・原料の要件を満たす場合に限り、最低製造数量基準が適用されない、または引き下げられる特例があります（構造改革特別区域法第25条・第26条）。特区の外では原則どおりの基準が適用されます。自分の計画が対象に当たるかは特区計画と所轄税務署・自治体で確認します。

**Q. 審査にはどれくらいかかりますか？**
A. 申請内容や補正の有無で変わります。所轄税務署が公表する標準処理期間を目安に確認してください。標準処理期間は法定の確定した期限ではなく、免許を与えるかどうかの最終判断は所轄税務署が行います。
