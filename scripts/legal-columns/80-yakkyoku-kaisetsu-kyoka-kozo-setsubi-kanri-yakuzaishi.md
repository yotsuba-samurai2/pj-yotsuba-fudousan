**結論（先に要点）**：薬局（調剤を行う薬局）を開くには、店舗ごとに、その所在地の都道府県知事（保健所を設置する市・特別区では市長・区長）の薬局開設許可を受けなければなりません（医薬品医療機器等法第4条第1項）。許可の主な要件は、①構造設備が薬局等構造設備規則の基準に適合すること、②調剤・医薬品の販売の業務体制が基準に適合すること、③申請者が欠格事由に当たらないこと、の3つです（同法第5条）。薬局には管理薬剤師を置いて実地に管理させる必要があり、管理薬剤師は原則としてその薬局以外の場所で業として薬事の実務を兼ねることができません（同法第7条第3項）。本記事は要件と流れを一般的な情報提供として整理するもので、許可の可否は薬務担当窓口が判断し、当事務所が可否を保証するものではありません。

## 薬局開設許可の構造設備基準は何が求められる？

医薬品医療機器等法（昭和35年8月10日法律第145号。旧薬事法。以下「医薬品医療機器等法」）第4条第1項は、薬局は、その所在地の都道府県知事（所在地が保健所を設置する市又は特別区にある場合は市長・区長）の許可を受けなければ開設してはならないと定めています。この許可は6年ごとに更新を受けなければ、期間の経過によって効力を失います（同条第4項）。

許可を受けられるかどうかの基準は同法第5条に定められており、次の3つのいずれかに当たると許可されないことがあります。①その構造設備が、厚生労働省令で定める基準に適合しないとき（第1号）、②調剤及び医薬品の販売・授与の業務を行う体制が、厚生労働省令で定める基準に適合しないとき（第2号）、③申請者が許可の取消しや刑罰などの欠格事由に該当するとき（第3号）です。このうち構造設備の基準を定める厚生労働省令が、薬局等構造設備規則（昭和36年2月1日厚生省令第2号）です。同規則第1条が定める薬局の構造設備の主なものは次のとおりです。

| 項目 | 主な内容 | 根拠 |
| --- | --- | --- |
| 面積 | おおむね19.8平方メートル以上で、薬局の業務を適切に行うことができること | 薬局等構造設備規則第1条第1項 |
| 換気・清潔 | 換気が十分で、かつ、清潔であること | 同上 |
| 天井・床・内壁 | 掃除がしやすく、じんあいやそのたい積を防げる構造であること | 同上 |
| 貯蔵設備 | 冷暗貯蔵のための設備、及び鍵のかかる貯蔵設備（毒薬・向精神薬等） | 同上 |
| 調剤室 | 6.6平方メートル以上の面積を有し、天井・床は板張り・コンクリート等で、調剤された薬剤等を受け取る者が進入できないよう必要な措置が採られていること | 同上 |
| 調剤の設備・器具 | 調剤に必要な設備・器具を備えていること | 同上 |
| 情報提供の設備 | 医薬品の情報提供・薬学的知見に基づく指導を行うための設備を有すること | 同上 |

面積の具体的な数値やレイアウト、待合や陳列棚の扱いは、各都道府県・保健所設置市の審査基準や手引きで細部が異なります。全国一律の数値としては上記の「おおむね19.8平方メートル以上」「調剤室6.6平方メートル以上」が規則に定められていますが、実際の適合判断は開業地の薬務担当窓口の審査によります。物件そのものの用途・構造の適法性（建築基準法上の用途や、用途変更に及ぶ場合の建築確認）は、当事務所の判断範囲ではなく、建築士・特定行政庁が確認します。事業用物件の選定・賃貸借は四葉不動産株式会社が担い、当事務所は許可申請の書類作成を担います。

## 管理薬剤師は常勤・専任でなければならない？兼務は認められる？

薬局には、その薬局を実地に管理する薬剤師（管理薬剤師）を置きます。医薬品医療機器等法第7条第1項は、薬局開設者が薬剤師であるときは自らその薬局を実地に管理しなければならない（その薬局で実務に従事する他の薬剤師のうちから管理者を指定して管理させるときは、この限りでない）と定め、第2項は、薬局開設者が薬剤師でないときは、その薬局で実務に従事する薬剤師のうちから管理者を指定して実地に管理させなければならないと定めています。つまり、法人が開設者であっても、薬局の実地の管理は薬剤師である管理者が行います。

兼務の可否は同法第7条第3項が定めています。薬局の管理者は、その薬局以外の場所で「業として」薬局の管理その他薬事に関する実務に従事する者であってはなりません。ただし、その薬局の所在地の都道府県知事の許可を受けたときは、この限りでないとされています。したがって管理薬剤師は原則として1つの薬局に専任で従事することが求められ、他店との兼務は例外的に都道府県知事の許可を受けた場合に限られます。この兼務許可の考え方は、厚生労働省の通知「医薬品、医療機器等の品質、有効性及び安全性の確保等に関する法律第7条第3項に規定する薬局の管理者の兼務許可の考え方について」（平成31年3月20日薬生総発第320003号）に整理されています。なお「常勤」という語は法令の文言ではなく、実務上の運用として用いられるもので、勤務時間や勤務日数の具体的な扱いは開業地の窓口で確認してください。

管理者は、保健衛生上支障を生ずるおそれがないよう、その薬局に勤務する薬剤師その他の従業者を監督し、構造設備や医薬品その他の物品を管理し、必要な注意をしたうえで、薬局開設者に対して必要な意見を書面により述べなければなりません（同法第8条）。なお、薬剤師個人の免許の取得や、個々の調剤内容の適否は本記事の対象ではありません。薬剤師や従業員の労働条件・社会保険・就業規則は四葉社会保険労務士事務所（社会保険労務士）が担います。

## 薬局開設許可の申請の流れと必要書類は？

申請は、開業予定日から逆算して進めます。標準的な流れは、①薬務担当窓口（都道府県の薬務課・保健所）への事前相談 → ②物件・設計が構造設備基準に適合するかの確認 → ③薬局開設許可申請書の提出 → ④書類審査 → ⑤立入検査（構造設備の確認）→ ⑥許可 → ⑦開設、という順です。開設予定日の何日前までに申請するか、立入検査の日程は自治体で異なるため、まず事前相談から始めるのが安全です。

申請の際に求められる代表的な書類は次のとおりです。自治体によって様式・部数・添付書類が異なるため、開業地の公式の手引きで確認してください。

| 書類 | 内容の概要 |
| --- | --- |
| 薬局開設許可申請書 | 名称・所在地・構造設備の概要・管理者の氏名など |
| 構造設備の概要・平面図 | 調剤室・待合・貯蔵設備・情報提供の設備などの配置と寸法 |
| 周辺の見取図 | 薬局の位置関係を示す図 |
| 管理薬剤師の薬剤師免許証の写し・雇用関係を示す書類 | 管理者となる薬剤師のもの |
| 登記事項証明書・定款等 | 開設者が法人の場合 |
| 診断書等 | 申請者（法人は業務を行う役員）の欠格事由に関するもの（自治体による） |

ここで注意したいのは、公的医療保険で調剤を行うための「保険薬局」の指定は、薬局開設許可とは別の手続だという点です。保険薬局の指定は、健康保険法に基づき、所在地を管轄する地方厚生局長へ別途申請します。開設許可を受けても、保険薬局の指定を受けなければ保険調剤はできません。開設許可申請書等の作成は行政書士が担い、当事務所は許可の可否や保険薬局指定の可否を保証するものではありません。

## 薬局と店舗販売業（ドラッグストア等）は許可がどう違う？

「薬を売る店」には、大きく分けて薬局と店舗販売業があり、根拠となる許可が異なります。薬局は医薬品医療機器等法第4条の薬局開設許可を受けた施設で、調剤を行うことができ、医療用医薬品を含む薬局医薬品・要指導医薬品・一般用医薬品を扱えます。これに対し店舗販売業は同法第26条の許可を受けた業態で、調剤はできず、薬局医薬品（医療用医薬品等）は扱えません。扱えるのは要指導医薬品と一般用医薬品です。いわゆるドラッグストアは、調剤を行わなければ店舗販売業として営むことができ、調剤室を設けて調剤も行う場合は薬局の開設許可が必要になります。

管理者の資格にも違いがあります。店舗販売業では、要指導医薬品又は第一類医薬品を販売する店舗は薬剤師が店舗管理者となり、第二類・第三類医薬品のみを販売する店舗は薬剤師又は登録販売者が管理者となれます（同法第28条）。薬局は薬剤師である管理者が必要です。また、薬局でなければ、その名称に「薬局」の文字を用いてはなりません（同法第6条）。

| | 薬局 | 店舗販売業 |
| --- | --- | --- |
| 根拠 | 医薬品医療機器等法第4条（開設許可） | 同法第26条（許可） |
| 調剤 | できる | できない |
| 扱える医薬品 | 薬局医薬品（医療用含む）・要指導・一般用 | 要指導・一般用（薬局医薬品は不可） |
| 管理者 | 薬剤師 | 薬剤師（要指導・第一類を扱う場合）／登録販売者（第二類・第三類のみ） |
| 「薬局」の名称 | 用いてよい | 用いてはならない（第6条） |

薬局の開業は複数の分野が交わるため、担当は次のように分かれます。

- 薬局開設許可申請書等の作成、薬務担当窓口との事前相談の支援 → 四葉行政書士事務所（行政書士）
- 事業用物件の選定・賃貸借・重要事項説明 → 四葉不動産株式会社
- 薬剤師・従業員の労働条件・社会保険・就業規則 → 四葉社会保険労務士事務所（社会保険労務士）
- 建物の用途・構造の適法性、用途変更に及ぶ場合の建築確認 → 建築士・特定行政庁
- 医薬品販売業の会計・税務 → 税理士
- 権利義務・紛争にわたる個別の法的判断 → 弁護士

四葉行政書士事務所と四葉不動産株式会社は別事業体です。当事務所は薬局開設許可の申請支援のみを独立した事業体として担い、物件・労務・税務は、それぞれの資格者・事業体と別々にご契約・ご相談いただきます。当事務所は紹介料を受け取りません。許認可の全体像は[許認可の手続き](/legal/services)、受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)をご覧ください。医療法に基づく診療所の開設届については[診療所の開設届（医療法第8条）](/legal/column/shinryojo-kaisetsu-todokede-iryoho-8jo)、医療法人の設立認可については[医療法人の設立認可の流れ](/legal/column/iryohojin-setsuritsu-ninka-nagare-shorui)もあわせてご確認ください。許可の可否そのものは薬務担当窓口が判断します。

## よくある質問

**Q. 薬剤師の免許があれば、すぐに自分の薬局を開けますか？**
A. 免許と開設許可は別です。薬剤師免許は個人の資格ですが、薬局を開くには、免許とは別に、店舗ごとに都道府県知事（保健所設置市・特別区は市長・区長）の薬局開設許可を受ける必要があります（医薬品医療機器等法第4条第1項）。許可には、構造設備・業務体制の基準への適合と、欠格事由に当たらないことが求められます（同法第5条）。

**Q. 管理薬剤師は他の薬局や店舗と兼務できますか？**
A. 原則としてできません。薬局の管理者は、その薬局以外の場所で業として薬事に関する実務に従事する者であってはならないとされています（医薬品医療機器等法第7条第3項）。ただし、その薬局の所在地の都道府県知事の許可を受けたときは例外的に兼務できます。許可の考え方は厚生労働省の通知（平成31年3月20日薬生総発第320003号）に示されています。

**Q. ドラッグストアと調剤薬局は同じ許可ですか？**
A. 別の許可です。調剤を行う薬局は薬局開設許可（第4条）、調剤を行わず要指導・一般用医薬品を販売する店舗は店舗販売業の許可（第26条）です。調剤の可否、扱える医薬品の範囲、管理者の資格（薬剤師か登録販売者か）が異なります。調剤室を設けて調剤も行うなら、薬局の開設許可が必要です。

**Q. 薬局開設許可を受ければ、すぐ保険調剤ができますか？**
A. できません。公的医療保険で調剤を行うための保険薬局の指定は、薬局開設許可とは別の手続で、健康保険法に基づき地方厚生局長へ申請します。開設許可を受けたうえで、保険薬局の指定を受けて初めて保険調剤ができます。手続の順序や必要書類は、地方厚生局と薬務担当窓口で確認してください。
