**結論（先に要点）**：観光や送迎で不特定の相手から運賃をもらってバスを貸し切って走らせるには、道路運送法第4条第1項の一般貸切旅客自動車運送事業の許可が要ります。これは、同法第3条第1号ロが定める「一個の契約により国土交通省令で定める乗車定員以上の自動車を貸し切って旅客を運送する」事業で、乗車定員は国土交通省令で11人以上とされています。自社の役員・従業員や自社の客を無償で送るだけなら許可は要りませんが、運賃をとって運送すれば許可が必要です。許可の中心は「人・物・金・安全」で、運行管理者（同法第23条。運行管理者資格者証の交付を受けた者から選任）・整備管理者（道路運送車両法第50条）・営業所・車庫・損害賠償能力（任意保険）・所要資金をそろえ、車両数など具体的な基準は運輸局が公示する審査基準で定まります（基準は改定され得るため申請先の最新公示で確認）。許可は同法第8条により5年ごとの更新制です。四葉行政書士事務所は許可申請書・事業計画・運行管理者等の選任届の作成と手続を、行政書士法第1条の2・第1条の3の範囲で別契約で受任します。拘束時間・休息期間など運転者の労務設計は社会保険労務士、営業所・車庫の物件は不動産、車両・保険は本人と保険会社が、いずれも独立した事業体として別々にご契約いただきます。本記事は一般的な情報提供であり、個別の許可を保証するものではありません。当事務所は紹介料を受け取りません。

## 貸切バス事業に許可が要るのはどの範囲で、白ナンバー送迎とは何が違うのですか？

一般貸切旅客自動車運送事業の許可が要るのは、道路運送法第4条第1項により、一個の契約でバスを貸し切り、不特定の相手から運賃をとって旅客を運送する場合です。対象となる自動車は、同法第3条第1号ロの「国土交通省令で定める乗車定員以上の自動車」で、乗車定員は11人以上とされています。10人以下の自動車を貸し切って運送するものは、一般乗用旅客自動車運送事業（いわゆるジャンボタクシー等を含む乗用）の区分で、別の許可の対象です。

| 区分 | 典型例 | 許可の要否 |
| --- | --- | --- |
| 一般貸切旅客自動車運送事業 | 観光・送迎で乗車定員11人以上のバスを貸し切り、運賃をとって運送 | 道路運送法第4条第1項の許可が必要 |
| 自家輸送（白ナンバー） | 自社の役員・従業員や自社の客を、運賃をとらずに送迎 | 許可不要（ただし運送を業として有償で行うと許可の対象） |
| 自家用自動車の有償運送 | 自家用車で有償の運送を行う | 原則禁止（同法第78条。例外は限定） |

違いの中心は「運賃をとる有償の運送か」「不特定の相手を運ぶか」です。無償の自社送迎なら許可は要りませんが、実費を超える対価をとる、外部の客を運ぶといった形になると、許可のない有償運送として問題になり得ます。どちらに当たるかは契約と対価の実態で判断されるため、送迎の設計段階で整理します。許可が必要な事業の受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務は[取扱業務一覧](/legal/services)をご覧ください。

## 許可の人・物・金の要件（運行管理者・整備管理者・営業所・車庫・資金）は何を満たすのですか？

許可の要件は「人・物・金・安全」に分けて整理できます。車両数や金額などの具体的な基準は、申請先の運輸局が公示する審査基準で定まり、改定され得ます。代表的な項目は次のとおりです（数値は運輸局の公示により異なることがあるため、申請直前に最新の公示で確認します）。

| 区分 | 主な要件 |
| --- | --- |
| 車両数 | 営業区域ごとに原則3両以上。大型車を使う場合は5両以上とされる公示が多い（3両以上5両未満は中型・小型車に限定する条件が付くのが一般的） |
| 運行管理者 | 営業所ごとに、運行管理者資格者証の交付を受けた者から選任（道路運送法第23条）。車両数に応じて必要人数が増える |
| 整備管理者 | 営業所ごとに選任（道路運送車両法第50条）。整備士資格または一定の実務経験＋選任前研修で要件を満たす |
| 営業所・車庫 | 車庫は営業所に併設が原則。併設できない場合は営業所から直線でおおむね2km以内。営業所・車庫・休憩仮眠施設は3年以上の使用権原が必要とされる公示が多い |
| 損害賠償能力 | 対人賠償は被害者1人あたり無制限、対物賠償は1事故あたり200万円以上の任意保険（共済）に全車加入する計画 |
| 所要資金 | 事業開始に必要な資金を見積もり、自己資金で確保できること。預金残高で疎明する |

運行管理者は、道路運送法第23条の2により、運行管理者試験に合格した者などに資格者証が交付されます。これらは許可後も維持すべき基準で、車両数・保険・管理者の選任は運輸開始後も継続して満たす必要があります。要件に当てはまるかの最終的な審査・判断は運輸局（地方運輸局・運輸支局）が行います。運転者の拘束時間・休息期間など労務面の設計は、社会保険労務士の[貸切バス運転者の改善基準告示（2024年の拘束・休息）と労務](/labor/column/bus-untensha-kaizen-kijun-2024-kousoku-kyusoku-roumu)で整理しています（社会保険労務士は別事業体）。

## 申請から許可、運輸開始、監査までの流れはどう進むのですか？

手続は、事業計画を固めて申請し、法令試験・審査を経て許可を受け、運輸を開始するという順で進みます。許可後も5年ごとの更新があります（道路運送法第8条）。おおまかな流れは次のとおりです。標準処理期間や運用は運輸局で異なるため、申請先の案内で確認します。

| 段階 | 内容 |
| --- | --- |
| 事業計画の作成 | 営業区域・営業所・車庫・車両・運行管理者等を決め、所要資金と任意保険の計画を立てる |
| 申請 | 営業所を管轄する運輸支局へ許可申請書と事業計画等を提出（道路運送法第5条） |
| 法令試験 | 申請者（法人は常勤役員）が道路運送法等の法令試験を受験 |
| 審査・補正 | 要件適合の審査。施設・人員・資金の確認と補正 |
| 許可 | 許可が出たら登録免許税を納付 |
| 許可後の手続 | 運賃・料金の設定（届出）、運行管理者・整備管理者の選任届、安全管理に関する届出、車両の登録（緑ナンバー）など |
| 運輸開始 | 運輸を開始し、運輸開始届を提出（開始後の届出期限は運輸局の案内で確認） |
| 更新・監査 | 許可は5年ごとに更新（道路運送法第8条）。運輸局・適正化機関の監査・巡回指導の対象 |

許可は取れば終わりではなく、5年ごとの更新と、運行管理・整備・労務の継続的な遵守が前提になります。具体的な書式・部数・標準処理期間は、申請先の運輸支局の最新の案内で確認します。当事務所が行うのは申請書類の作成・手続と各専門家へ渡す資料の整理で、審査の結論や法的な見通しの断定はしません。

## よくある質問

**Q. 自社の従業員や宿泊客をバスで送迎するだけでも許可は要りますか？**
A. 自社の役員・従業員や自社の客を、運賃をとらずに送迎するだけなら、一般貸切旅客自動車運送事業の許可は原則として要りません。一方、運賃（実費を超える対価）をとって運送する、外部の不特定の相手を運ぶといった形になると、道路運送法第4条第1項の許可の対象になり得ます。許可のない自家用自動車での有償運送は原則禁止です（同法第78条）。送迎が無償の自家輸送に収まるかは契約と対価の実態で判断されるため、設計段階で整理してください。

**Q. 貸切バスの許可に必要な車両は何両ですか？**
A. 車両数は申請先の運輸局が公示する審査基準で定まり、営業区域ごとに原則3両以上、大型車を使う場合は5両以上とする公示が多く見られます（3両以上5両未満では中型・小型車に限定する条件が付くのが一般的）。この数値は運輸局により異なり、改定され得るため、申請直前に申請先の運輸支局の最新の公示で確認してください。車両のほか、運行管理者・整備管理者・営業所・車庫・任意保険・所要資金の要件も併せて満たす必要があります。

**Q. 許可を取れば、あとは更新せずに続けられますか？**
A. 一般貸切旅客自動車運送事業の許可は、道路運送法第8条により5年ごとに更新を受けなければ、その期間の経過で効力を失います。更新のほか、運行管理者・整備管理者の選任、任意保険の加入、運転者の労働時間管理などは運輸開始後も継続して満たす必要があり、運輸局や適正化機関の監査・巡回指導の対象になります。更新時期や維持すべき基準は申請先の運輸局の案内で確認してください。

**Q. 許可申請から運転者の労務、車庫の物件まで、一つの事務所にまとめて頼めますか？**
A. 許可申請書・事業計画・選任届の作成は行政書士、拘束時間・休息期間・賃金・社会保険は社会保険労務士、営業所・車庫の物件は別事業体の四葉不動産株式会社、車両・保険は本人と保険会社、許可の最終判断は運輸局、処分の争いは弁護士が担当し、それぞれ独立した事業体として別々にご契約いただきます。一つの窓口でご相談を受けて各専門家へ整理してお渡しすることはできますが、受任は分かれます。当事務所は紹介料を受け取りません。
