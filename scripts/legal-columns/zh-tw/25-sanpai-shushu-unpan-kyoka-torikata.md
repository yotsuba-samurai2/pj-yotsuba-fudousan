**結論（先說要點）**：以營業方式（反覆繼續）收集運搬因建設・拆除・運送等事業所生之「他人之產業廢棄物」，須依廢棄物之處理及清掃相關法律（廢棄物處理法）第14條第1項取得都道府縣知事之許可。取得許可須具備：車輛・容器等設施與申請人之能力符合環境省令基準（第14條第5項第1號）、不該當欠格要件（同項第2號準用第7條第5項第4號）、且經營事業之本人或役員已修畢公益財團法人日本產業廢棄物處理振興中心（JW中心）之講習。本文為一般資訊提供，整理產業廢棄物收集運搬業許可之要件・欠格要件・講習・車庫與積替保管場所之處理・逐都道府縣之許可與更新，不判斷個別許可之可否。

## 產業廢棄物收集運搬業許可，何種事業需要？

產業廢棄物，係指因事業活動所生之廢棄物中，燃燒殘渣・污泥・廢油・廢塑膠類・瓦礫類等法令所定種類者。受他人委託，以營業方式（有償且反覆繼續）收集運搬此類廢棄物時，即須此許可。

判斷之分界在於「運搬何人之廢棄物」。

| 情形 | 許可之要否 |
| --- | --- |
| 受委託運搬他公司所排出之產業廢棄物 | 須收集運搬業之許可 |
| 將自家事業所生之產業廢棄物，自行運至處分處（自家運搬） | 原則無須許可（惟須遵守運搬基準・委託基準） |
| 運搬一般家庭所生之垃圾（一般廢棄物） | 產業廢棄物之許可不足，另須市町村之一般廢棄物收集運搬業許可 |

由建設・拆除・運送擴展事業時，若運搬元包或他公司工地所生之廢棄物，即屬「他人之產業廢棄物」，須有許可。四葉行政書士事務所於行政書士業務範圍內，支援許可要否之確認、要件之整理、申請文件之製作、申請之代理。個別許可之可否，由都道府縣審查。

## 不予許可之「欠格要件」具體為何？

欠格要件，係只要該當其一即不得取得許可之事由。就產業廢棄物收集運搬業，第14條第5項第2號準用第7條第5項第4號，主要定有下列各項。

| 區分 | 內容（要旨） |
| --- | --- |
| 身心故障 | 因身心故障而不能適切執行業務者，以環境省令所定者為限 |
| 破產 | 受破產程序開始決定而未復權者 |
| 刑罰（拘禁刑） | 受拘禁刑以上之刑，自執行完畢或不再受執行之日起未逾5年者 |
| 刑罰（罰金） | 因違反廢棄物處理法等環境相關之特定法令而受罰金刑，未逾5年者 |
| 暴力團關係 | 暴力團員，或不再為暴力團員之日起未逾5年者；其事業活動受暴力團員等支配者 |
| 不正・不誠實 | 有相當理由足認其於業務上有為不正或不誠實行為之虞者 |

2022年刑法修正將懲役・禁錮一元化為「拘禁刑」，條文亦記為拘禁刑以上之刑。欠格要件不僅及於申請人本人，亦及於法人之役員及一定之使用人。取得許可後若該當欠格要件，許可即被撤銷，且於該當時亦有申報義務。曾有刑罰紀錄者，宜及早確認是否該當。

## 講習之修畢，何時、由何人為之？

許可申請須附公益財團法人日本產業廢棄物處理振興中心（JW中心）所辦講習之修了證。須於申請前修畢。

| 項目 | 新規許可 | 更新許可 |
| --- | --- | --- |
| 課程 | 產業廢棄物之收集・運搬課程（新規） | 產業廢棄物之收集・運搬課程（更新） |
| 天數概略 | 2日講義＋修了試驗 | 約1日講義＋修了試驗 |
| 修了證有效期間 | 原則5年 | 原則2年（亦有自治體定為5年之例） |
| 受講之人 | 個人為事業主本人，法人為代表者或執行業務之役員（含政令所定使用人） | 同左 |

若處理特別管理產業廢棄物（廢酸・廢鹼・感染性廢棄物等），須另修畢特別管理產業廢棄物之收集・運搬課程。修了證之有效期間及更新講習之處理，因自治體審查基準而有差異，請確認申請地都道府縣之最新手引。

## 進行積替・保管時，場所要件如何改變？

收集運搬分為「無積替保管」與「有積替保管」。

- **無積替保管**：自排出場所至處分・再生設施，途中不卸下而直行運搬。多數新規許可由此區分開始。
- **有積替保管**：途中換裝至他車輛，或一時保管。此時就保管場所，須具備圍籬・告示牌之設置、依種類分別、保管上限（數量）、防止飛散・流出・惡臭等基準之土地，審查亦較嚴格。

又，置放運搬車輛之車庫（停車場），須與積替保管場所分別，能以書面示明使用權原（自有或租賃契約）。車庫用地及供積替保管之土地之手配・租賃，屬宅地建物交易業者之角色。與四葉行政書士事務所別事業體之四葉不動產株式會社，以獨立的事業體、個別契約擔任物件尋找與簽約。本事務所不收取介紹費。

## 許可於何都道府縣取得？更新何時到來？

第14條第1項規定，僅以運搬為業時，許可權者為管轄「產業廢棄物積卸區域」之都道府縣知事。亦即，無積替保管之收集運搬，於積載地與卸貨地雙方之都道府縣均須許可，僅通過之都道府縣則無須許可。亦有政令所定市自行核發許可之區域。

有效期間為每5年（第14條第2項），因期間經過而失效，故須於期限前修畢更新講習後申請更新。若經認定符合優良產業廢棄物處理業者認定制度之基準，有效期間為7年。

依事業擴展方式，涉及之專業領域有別。分工如下。

- 產業廢棄物收集運搬業許可之要件確認・文件製作・申請代理 → 四葉行政書士事務所（行政書士）
- 車庫用地・積替保管場所之土地或物件之手配・租賃 → 四葉不動產株式會社（宅地建物交易業者）
- 法人設立・役員變更等之登記 → 司法書士
- 取得許可後之勞動保險・駕駛人勞務・就業規則 → 社會保險勞務士

## 常見問題

**Q. 運搬自家公司所生之廢棄物，用自家卡車也須許可嗎？**
A. 將自家事業所生之產業廢棄物自行運至處分處之「自家運搬」，原則無須收集運搬業許可。惟仍須遵守運搬中防止飛散・流出等法令上之運搬基準。受委託運搬他人（他公司）之產業廢棄物時，屬營業行為，須有許可。

**Q. 有許可即可於全國任何地方運搬嗎？**
A. 否。無積替保管之收集運搬，須於管轄產業廢棄物積卸區域之各都道府縣取得許可。積載之都道府縣與卸貨之都道府縣雙方均須許可，僅通過之都道府縣則無須。將依運搬路線確認所需許可。

**Q. 講習應由何人受講？**
A. 個人為事業主本人，法人為代表者或執行業務之役員（含政令所定使用人），修畢JW中心之收集・運搬課程。新規有2日講義與修了試驗，修了證有有效期間。須於申請前修畢。

**Q. 過去曾受罰金刑，仍能取得許可嗎？**
A. 視是否該當欠格要件而定。因違反廢棄物處理法等環境相關特定法令之罰金，及拘禁刑以上之刑，若未逾一定期間（多為5年），可能該當欠格要件。是否該當及個別判斷由都道府縣為之，建議於申請前確認。
