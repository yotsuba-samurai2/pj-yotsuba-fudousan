**先講結論：** 要出售繼承的老家（空屋）並使用「空屋讓與所得的3,000萬日圓特別扣除」（租稅特別措置法第35條第3項），須在確定申告書中檢附「被繼承人居住用家屋等確認書」。該確認書由所出售房屋、土地所在地的市區町村長核發（國稅廳、國土交通省之指引，參照日2026-10-31）。申請核發時，須附上被繼承人之除票住民票、可確認電氣、瓦斯、自來水停用（閉栓）日之書類、買賣契約書之影本等。本文為向官公署提出書類作成範圍內之一般資訊提供，不就特例可否作稅務判斷，亦不辦理稅額計算、申告。

## 「被繼承人居住用家屋等確認書」為何必要？要向何處申請？

空屋讓與所得的3,000萬日圓特別扣除，係於一定要件下出售所繼承被繼承人之居住用房屋（或其基地）時，可自讓與所得扣除最高3,000萬日圓之特例（租稅特別措置法第35條第3項、同法施行令第20條之3、同法施行規則第18條之2）。欲適用該特例，須於確定申告書檢附「被繼承人居住用家屋等確認書」（國稅廳「No.3306」，參照日2026-10-31）。

確認書並非由稅務署，而是由所出售房屋、土地所在地之市區町村長核發。亦即，稅之申告向稅務署，證明特例前提事實之確認書向市區町村，窗口有所區分。確認書係市區町村以書類確認該房屋屬於「被繼承人之居住用房屋」，且自繼承時起至讓與時止為空屋等事實之證明。

| 項目 | 內容 |
| --- | --- |
| 依據 | 租稅特別措置法第35條第3項（施行令第20條之3、施行規則第18條之2） |
| 確認書之核發者 | 所出售資產所在地之市區町村長 |
| 提出對象與用途 | 檢附於確定申告書向稅務署提出（特例適用要件之一） |
| 扣除額 | 最高3,000萬日圓（令和6年1月1日以後之讓與，取得之繼承人為3人以上時為2,000萬日圓） |

特例實際可否適用之判斷與稅額計算、申告屬於稅理士領域。本事務所（行政書士）就確認書之核發申請書類之作成、提出範圍協助。

## 可核發確認書的房屋要件（建築年份、非區分所有、空屋）如何整理？

確認書係以所出售房屋符合特例對象之「被繼承人居住用家屋」事實為前提而核發。國稅廳所示主要要件如下（No.3306，參照日2026-10-31）。

| 要件 | 內容 |
| --- | --- |
| 建築時期 | 昭和56年5月31日以前建築 |
| 非區分所有 | 非屬已辦理區分所有建物登記之建物 |
| 繼承前之居住 | 繼承開始之直前，除被繼承人外無人居住（限主要由被繼承人居住之一棟建築物） |
| 空屋之持續 | 自繼承時起至讓與時止，未供事業、出租、居住之用 |
| 適用期間 | 平成28年4月1日至令和9年12月31日之間的讓與 |
| 讓與對價 | 讓與對價額為1億日圓以下（與其他繼承人之讓與分等合計判斷） |

被繼承人於繼承開始直前入住老人院等設施時，若符合曾受要介護認定等一定要件，仍可能成為對象。此時須另附顯示入住事實與要介護認定之書類。符合何種要件之最終認定與稅務判斷，請向稅理士確認。

## 申請時須檢附哪些書類？

向市區町村申請核發確認書時，須於申請書檢附如下書類（各市區町村之核發要綱，參照日2026-10-31。名稱、份數因自治體而異）。

| 區分 | 主要書類 |
| --- | --- |
| 確認繼承與居住 | 被繼承人之除票住民票、繼承人之住民票 |
| 確認曾為空屋 | 可確認電氣、瓦斯、自來水停用（閉栓）日之書類，如閉栓證明或停用聯絡票等。停用日須為繼承開始日以後者 |
| 確認讓與 | 買賣契約書之影本 |
| 入住老人院之情形 | 顯示要介護認定、設施入住事實之書類 |

若電氣、瓦斯、自來水之停用日早於繼承開始日，將無法顯示繼承時為空屋，可能無法受理確認。宜及早在手邊確認閉栓日之紀錄。所需書類因自治體而異，亦可能被要求補充，申請前請以物件所在地市區町村之最新指引確認。

## 拆除後出售與耐震改修後出售，書類有何不同？

本特例大致分為(1)將房屋耐震改修後（以具耐震性之房屋）出售之類型，與(2)將房屋拆除後僅出售土地之類型，確認書之格式亦依讓與態樣而分。

- 耐震改修後出售：須於讓與時符合一定耐震基準。令和6年1月1日以後之讓與，於讓與之日所屬年度之翌年2月15日前符合基準者亦為對象。須附耐震基準適合證明書及工程相關書類。
- 拆除後出售土地：須自繼承時起至拆除等時止、自拆除等時起至讓與時止，均符合要件。須附顯示建物拆除之書類（閉鎖事項證明書等）。令和6年1月1日以後之讓與，於讓與之日所屬年度之翌年2月15日前完成拆除等者亦為對象。

| 讓與態樣 | 要件要點 | 主要補充書類 |
| --- | --- | --- |
| 耐震改修後出售 | 讓與時符合耐震基準（令和6年以後之讓與，翌年2月15日前符合亦可） | 耐震基準適合證明書、工程相關書類 |
| 拆除後出售土地 | 繼承時至拆除時、拆除時至讓與時之要件（令和6年以後之讓與，翌年2月15日前拆除等亦可） | 顯示建物拆除之書類（閉鎖事項證明書等） |

屬於何種格式及書類之過與不足，與市區町村及稅理士確認。本文僅就制度框架提供資訊，不就個別情形認定。

## 扣除可否之判斷、申告該找誰，滅失登記與買賣又該找誰？

空屋之出售，與確認書之取得並行推進稅務、登記、買賣。角色區分如下，各以獨立的事業體分別簽約、分別辦理。

- 被繼承人居住用家屋等確認書之核發申請書類之作成、提出 → 四葉行政書士事務所（行政書士）。僅提供資料與資訊，不作具體法律判斷、稅務判斷
- 特例可否之判斷、稅額計算、確定申告 → 稅理士。本事務所不作稅務判斷、不辦理申告
- 建物拆除後之建物滅失登記（表示相關登記） → 土地家屋調查士
- 繼承登記（所有權移轉登記） → 司法書士
- 空屋出售之仲介 → 另一事業體的四葉不動產股份有限公司（宅地建物交易業者），以獨立的事業體依另行契約對應
- 遺產分割之爭議顯在化時 → 律師

出售之洽詢，由與四葉行政書士事務所分屬不同事業體的四葉不動產股份有限公司，以獨立的事業體依另行契約對應。特例適用可否、稅額計算、申告由稅理士，建物滅失登記由土地家屋調查士，繼承登記由司法書士，爭議由律師，均以獨立的事業體分別簽約、分別辦理。各領域均以與各窗口、資格者分別簽約為前提，本事務所不收取介紹費。即使在不確定閉栓日或建築年份要件的階段，也請於決定出售方式之前洽詢。受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)，繼承承辦業務請見[繼承業務介紹](https://luck428.com/legal/services/inheritance)，繼承綜合介紹請見[繼承諮詢](https://luck428.com/souzoku)。相關文章另請參見[繼承登記的流程](https://luck428.com/legal/column/souzoku-touki-nagare)、[遺產分割協議書的作成方式](https://luck428.com/legal/column/isan-bunkatsu-kyougisho)、[繼承手續的起步與戶籍調查](https://luck428.com/legal/column/souzoku-hajime-koseki-chosa-bunkyo)。

## 常見問題

**Q. 被繼承人居住用家屋等確認書在哪裡取得？**
A. 由所出售房屋、土地所在地之市區町村長核發（國稅廳「No.3306」，參照日2026-10-31），而非稅務署。將取得之確認書檢附於確定申告書，以適用特例（租稅特別措置法第35條第3項）。申請窗口與格式因自治體而異，請以物件所在地市區町村之最新指引確認。

**Q. 電氣、瓦斯之閉栓日為何重要？**
A. 因特例以自繼承時起至讓與時止為空屋為前提，市區町村以可確認電氣、瓦斯、自來水停用（閉栓）日之書類確認空屋事實。停用日須為繼承開始日以後者，若停用早於繼承開始日，可能無法受理確認。宜及早在手邊確認閉栓日之紀錄。

**Q. 拆除後出售與不拆除出售，書類不同嗎？**
A. 不同。拆除後出售土地須附顯示建物拆除之書類（閉鎖事項證明書等），耐震改修後出售須附耐震基準適合證明書，確認書之格式亦分。令和6年1月1日以後之讓與，於讓與之日所屬年度之翌年2月15日前完成拆除等或符合耐震基準者亦為對象。屬於何者請向市區町村與稅理士確認。

**Q. 行政書士也會計算稅金嗎？**
A. 不會。特例可否之稅務判斷與稅額計算、確定申告屬於稅理士領域。本事務所（行政書士）就被繼承人居住用家屋等確認書之核發申請書類之作成、提出範圍協助。稅務由獨立的事業體之稅理士分別簽約。本事務所不收取介紹費。
