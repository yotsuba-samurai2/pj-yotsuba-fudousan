**結論（先講重點）**：要販售試劑、農藥等毒物或劇物，須就各店舖向都道府縣知事取得販售業登記（毒物及劇物取締法第3條第3項、第4條）。登記以店舖符合設備基準（施行規則第4條之4）、並設置毒物劇物處理負責人（第7條、第8條）為前提。

**資料確認日：2026年10月23日**。本文從選物件的階段起，整理毒物劇物販售業登記所需的店舖、設備與人員配置。條文以[e-Gov法令檢索](https://laws.e-gov.go.jp/law/325AC0000000303)核對，惟各法令的最後修正日與全部施行沿革、各自治體的手續費與標準處理期間尚未查證。個別登記可否由主管的都道府縣（保健所）與有資格者判斷。

## 毒物劇物販售業登記是什麼？有哪些區分？

毒物及劇物取締法第3條第3項規定，未取得販售業登記者，不得販售、授與毒物或劇物，也不得以販售、授與為目的而貯藏、搬運或陳列。依第4條，登記就各店舖由店舖所在地的都道府縣知事為之；在設有保健所的市與特別區，則由市長、區長受理。

依第4條之2，販售業登記按可處理的品目分為三種。可處理的品目愈廣，對負責人要求的考試區分也愈廣，因此在決定業態時先確認區分。

| 登記區分 | 可處理的毒物、劇物 | 依據 |
| --- | --- | --- |
| 一般販售業 | 無品目限制 | 第4條之2 |
| 農業用品目販售業 | 僅限厚生勞動省令所定農業上必要的品目 | 第4條之2、第4條之3第1項 |
| 特定品目販售業 | 僅限厚生勞動省令所定品目 | 第4條之2、第4條之3第2項 |

農業用品目販售業者不得處理農業用品目以外之物，特定品目販售業者不得處理所定品目以外之物（第4條之3）。何種品目屬何區分由厚生勞動省令定之，請以主管的最新手冊確認。

## 店舖的構造、設備基準由哪裡規定？

登記要件之一是設備。第5條規定，店舖設備不符厚生勞動省令所定基準時，不予登記。該基準即施行規則第4條之4。同條第2項規定，販售業店舖準用第1項第2款至第4款（貯藏、陳列、搬運）。製造所所需的第1項第1款（製造作業的構造與處理設備）不準用於販售業店舖。

| 應確認事項 | 依據（施行規則第4條之4） |
| --- | --- |
| 能與其他物品區分貯藏毒物、劇物的設備 | 第1項第2款イ（準用於販售業） |
| 容器或貯藏設備無洩漏、滲出之虞 | 第1項第2款ロ、ハ |
| 貯藏場所設有上鎖設備（性質上無法上鎖時，周圍設堅固圍籬） | 第1項第2款ニ、ホ |
| 陳列場所設有上鎖設備 | 第1項第3款 |
| 搬運用具無洩漏之虞 | 第1項第4款 |

面積數值與分區方式，在各自治體審查基準的細節上有所不同。租賃物件的關鍵在於能否確保分區的貯藏空間與可上鎖的保管、陳列設備，以及能否備妥附件所需的店舖設備概要圖。本文不列出具體尺寸與格式（因自治體有差異且尚未查證，列為未查證）。物件適否的最終判斷由受理機關為之。

## 誰能擔任毒物劇物處理負責人？

第7條規定，販售業者須就各店舖設置專任的毒物劇物處理負責人，以防止毒物、劇物造成保健衛生上的危害。販售業者本人亦可兼任負責人。設置或變更負責人時，須於30日內向都道府縣知事申報（第7條第3項）。

可擔任負責人者由第8條定之。

| 資格區分 | 內容 |
| --- | --- |
| 藥劑師 | 第8條第1項第1款 |
| 修畢應用化學學科者 | 厚生勞動省令所定學校之畢業者等（第8條第1項第2款） |
| 毒物劇物處理者考試合格者 | 第8條第1項第3款 |

惟未滿18歲者、因身心障礙而無法適當執行業務者、麻藥等中毒者，以及因與毒物劇物有關之罪等受刑之執行完畢未滿3年者，不得擔任負責人（第8條第2項）。毒物劇物處理者考試分一般、農業用品目、特定品目三區分；農業用品目、特定品目的合格者，僅能在處理該品目的店舖擔任負責人（第8條第3項、第4項）。所處理的區分與負責人資格須相互對應。

## 登記向何處、以何種書件提出？

提出對象為店舖所在地的都道府縣知事（設有保健所的市與特別區為市長、區長）。申請書記載第6條的登記事項（申請人姓名、住所、店舖所在地等），並附店舖設備概要圖及證明負責人資格的文件。附件格式因自治體而異，請以主管的手冊確認。

登記並非一經取得即永久有效。第4條第3項規定，販售業登記未每6年更新即失其效力（製造業、輸入業為每5年）。店舖遷移、設備變更、負責人變更等，可能構成變更申報或新的登記。何者屬申報、變更手續，請以受理機關的最新指引確認。

## 設備、負責人、勞務該委託給誰？（分別受任的整理）

毒物劇物販售業的開業，匯集了申請、設備、人員、物件等性質各異的工作。基本做法是分別委託各自的專業者。

| 委託對象 | 負責範圍 |
| --- | --- |
| 四葉行政書士事務所 | 製作登記申請書件（協助本人申請） |
| 四葉不動產株式會社 | 店舖物件的選定、用途地域與管理規約的事前調查、看屋仲介 |
| 建築師、施工業者 | 貯藏設備、分區、上鎖設備的設計與改裝 |
| 藥劑師等有資格者 | 擔任毒物劇物處理負責人及處理上的判斷 |
| 社會保險勞務士 | 員工僱用、工作規則、社會保險的設計 |

四葉行政書士事務所、四葉社會保險勞務士事務所、四葉不動產株式會社各為不同事業體，均作為獨立的事業體受任。請與各領域的承辦人分別簽約，由各受任者直接請款、收款。本事務所不收取介紹費。毒物劇物處理負責人由有資格者本人就任，無法代理。都道府縣、保健所的藥務單位為登記的行政窗口，並非受任契約的對象。

請參閱[許認可支援](https://luck428.com/zh-tw/legal/services)、[受任流程](https://luck428.com/zh-tw/legal/nagare)、[報酬金額表](https://luck428.com/zh-tw/legal/ryokin)。販售藥品的藥妝店屬另一制度，請見[店舖販售業許可](https://luck428.com/zh-tw/legal/column/iyakuhin-tenpo-hanbaigyo-drugstore-kozo-setsubi-touroku-hanbaisha)；進行調劑的藥局則整理於[藥局開設許可的構造設備與管理藥劑師](https://luck428.com/zh-tw/legal/column/yakkyoku-kaisetsu-kyoka-kozo-setsubi-kanri-yakuzaishi)。毒物劇物販售業登記與上述者的依據法與區分皆不同。

## 常見問題

**Q. 只販售少量毒物劇物也需要登記嗎？**
A. 只要以營業方式販售、授與，不論數量多寡，皆以取得販售業登記為前提（第3條第3項）。未經登記不得販售、陳列。區分與手續會因品目與交易形態而變，請向藥務單位確認。

**Q. 不是藥劑師也能擔任毒物劇物處理負責人嗎？**
A. 有可能。除藥劑師外，於厚生勞動省令所定學校修畢應用化學學科者，以及毒物劇物處理者考試合格者，皆具負責人資格（第8條第1項）。惟農業用品目、特定品目考試的合格者，僅限於處理該品目的店舖（第8條第4項）。

**Q. 登記需要多久、費用多少？**
A. 登記手續費由都道府縣條例等定之，金額因自治體而異。標準處理期間亦載於各自治體的審查基準。實際情形取決於設備與書件是否齊備。本文不列出確定的金額與天數（自治體差異大且尚未查證，列為未查證）。

**Q. 一經登記就不必更新嗎？**
A. 並非如此。販售業登記未每6年更新即失其效力（第4條第3項）。更新的申請時期與方法載於各自治體的指引，請於期限前預留餘裕確認。
