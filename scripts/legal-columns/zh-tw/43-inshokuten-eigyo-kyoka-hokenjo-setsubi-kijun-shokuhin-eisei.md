**結論（先講重點）**：要開設烹調並提供餐點的咖啡店、居酒屋或餐廳，需要依食品衛生法取得餐飲店營業許可。餐飲店營業依食品衛生法施行令第35條屬於須取得許可的業種，向都道府縣知事（設有保健所的市與特別區則為市長、區長）申請許可（食品衛生法第55條第1項）。設施應符合的基準，依同法第54條由各地方自治體的食品衛生法施行條例訂定，並且每個設施須配置1名食品衛生責任者（同法第51條第1項）。2021年（令和3年）6月1日起，符合HACCP的衛生管理全面施行，同時進行了許可業種的重整與營業申報制度的新設。本文整理許可的條件與流程，能否取得許可由保健所審查決定，本事務所並不保證取得許可。

## 哪些業態需要餐飲店營業許可？

在店內烹調並提供餐點或飲料的營業，原則上需要餐飲店營業許可。除了餐廳、咖啡店、居酒屋、小酒館之外，以外帶或外送為主但有烹調的店，一般也屬於餐飲店營業。2021年的改正將原本的「喫茶店營業」併入餐飲店營業。

另一方面，依所處理的食品與加工內容，也可能屬於其他業種。製作並販售麵包或蛋糕屬於糕點製造業，販售肉類或魚貝類則屬各自的販售業，是否需要許可依業種而異。也有以申報即可、不需許可的業態（同法第57條），究竟適用哪一種手續，取決於營業內容。若判斷有疑義，請向開業預定地的管轄保健所確認。

| 手續種類 | 依據 | 主要例子 |
| --- | --- | --- |
| 營業許可 | 食品衛生法第55條第1項、施行令第35條 | 餐飲店營業、糕點製造業等 |
| 營業申報 | 食品衛生法第57條第1項 | 常溫可保存的包裝食品販售等 |

此外，若要在深夜0時以後以酒類為主提供，除了餐飲店營業許可外，還需要依風營法辦理申報。手續的差異整理於[深夜酒類提供飲食店營業的申報](https://luck428.com/legal/column/shinya-shurui-teikyo-todokede-yoken)。

## 保健所審查的設施基準（洗手、水槽、區劃）要滿足到什麼程度？

設施應符合的基準，依食品衛生法第54條，由各地方自治體的食品衛生法施行條例訂定。國家在施行規則中揭示應參酌的基準框架，但具體的數值與規格因自治體與業態而異，請以開業預定地的條例與保健所的指引確認。具代表性的檢查項目如下。

| 項目 | 檢查重點 |
| --- | --- |
| 洗手設備 | 設置從業人員用的洗手處；水龍頭常要求採可防止交叉污染的構造（撥桿式、自動式等） |
| 水槽（清洗設備） | 依食品與器具清洗需要的槽數；許多自治體要求2槽以上 |
| 區劃 | 能將調理場與客席、污染作業與非污染作業區分的配置 |
| 地板、牆壁、天花板 | 易清潔、具耐水性的材質 |
| 換氣、照明 | 充分的換氣與作業所需的亮度 |
| 冷藏、冷凍設備 | 設有可確認溫度的溫度計 |
| 更衣室、防蟲防鼠、供熱水 | 從業人員更衣處、防止鼠與昆蟲入侵、必要的熱水 |

數值與是否需要區劃，會因業態而變。在決定裝潢工程與格局之前先向保健所事前諮詢，並依條例的基準製作圖面，可避免工程重做。

## 誰能擔任食品衛生責任者？如何選任？

餐飲店營業等設施須配置1名食品衛生責任者（依食品衛生法第51條第1項的一般衛生管理基準；施行規則別表第17）。可由營業者本人擔任，也可選任員工。

能擔任食品衛生責任者的，是符合下列之一的人。

- 具有廚師、營養師、糕點衛生師，或可成為食品衛生管理者、食品衛生監視員等所定資格的人
- 醫師、牙醫師、藥劑師、獸醫師
- 修畢由都道府縣知事等（或知事指定之團體）辦理的食品衛生責任者養成講習會的人

若無資格，通常以參加養成講習會為途徑。責任者的角色是確認衛生管理的執行狀況，並就必要的改善向營業者進言。慣例上會在營業許可申請時之前完成選任。

## 2021年食品衛生法改正（HACCP、許可業種重整）改變了什麼？

依2018年公布的改正食品衛生法，自2021年（令和3年）6月1日起，原則上要求所有食品等事業者實施符合HACCP的衛生管理（食品衛生法第51條第1項第2號）。餐飲店在一般衛生管理之外，還須作為「導入HACCP思維的衛生管理」，參考手冊製作衛生管理計畫並加以記錄、確認。

同時，營業許可制度經檢討並重整業種。喫茶店營業併入餐飲店營業，須取得許可的業種整理於施行令第35條。此外，對於不在許可對象內但對公眾衛生有影響的營業，新設了營業申報制度（同法第57條）。自己的營業究竟屬於須許可、須申報或兩者皆不需，請向保健所確認。

## 從申請到取得許可、開始營業，要依什麼順序進行？

開設餐飲店會使物件、工程與行政手續並行。為避免重工，基本上依下列順序進行。

1. 在簽訂物件契約之前，向保健所事前諮詢，確認設施基準與必要文件
2. 依條例的基準設計並施作設施
3. 選任食品衛生責任者（若無資格則參加養成講習會）
4. 申請營業許可（提出設施圖面、申請書等）
5. 接受保健所的設施檢查
6. 領取許可證，開始營業

角色分工如下。

- 餐飲店營業許可的申請書、圖面等的製作，以及協助與保健所的事前諮詢 → 四葉行政書士事務所（行政書士）
- 事業用物件的選定、租賃、重要事項說明，以及原狀回復與排氣的確認 → 四葉不動產股份有限公司
- 深夜0時以後提供酒類的申報 → 依風營法的手續（行政書士）
- 裝潢、排氣、防火相關的工程與消防手續 → 建築師、消防設備士、消防機關
- 法人設立的登記 → 司法書士
- 開業後的會計、稅務 → 稅理士
- 涉及權利義務、糾紛的個別法律判斷 → 律師

四葉行政書士事務所與四葉不動產股份有限公司為不同事業體。本事務所僅以獨立的事業體承辦餐飲店營業許可的申請協助，物件、工程、消防、登記、稅務則與各該有資格者、行政窗口分別簽約、諮詢。本事務所不收取介紹費。許認可的整體樣貌請見[許認可手續](https://luck428.com/legal/services)，受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)。能否取得許可本身由保健所判斷。

## 常見問題

**Q. 只做外帶或餐車，也需要餐飲店營業許可嗎？**
A. 只要有烹調並提供，原則上就需要餐飲店營業許可。餐車（移動營業）的設施基準與店舖不同，可營業的品項與區域也可能受限。因所處理的食品與烹調內容不同，所需手續也會改變，請向開業預定地的管轄保健所確認。

**Q. 食品衛生責任者一定要參加講習才能擔任嗎？**
A. 不是。具有廚師、營養師、糕點衛生師等資格，或具有醫師、牙醫師、藥劑師、獸醫師資格的人，不需講習即可擔任食品衛生責任者。若無這些資格，可透過修畢由都道府縣知事等辦理（或指定）的養成講習會取得資格。

**Q. 小型的個人店也需要因應HACCP嗎？**
A. 是。自2021年6月1日起，原則上要求所有事業者因應。不過小型餐飲店等可採「導入HACCP思維的衛生管理」，基本上是參考業界團體製作的手冊，製作衛生管理計畫並加以記錄、確認。具體的格式請向保健所或手冊確認。

**Q. 許可取得一次後就不需更新嗎？**
A. 餐飲店營業許可有有效期間，須在期滿前更新。有效期間由自治體訂定，各設施大致設定在約5至8年的範圍。請確認許可證上記載的期限，以免錯過更新時機。
