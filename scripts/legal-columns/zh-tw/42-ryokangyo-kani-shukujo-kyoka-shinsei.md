**先講重點：** 要在獨棟住宅或空置大樓經營純住宿的旅宿（青年旅館等），須取得旅館業法的營業許可。作為簡易宿所營業，向都道府縣知事（設有保健所的市、特別區為市長、區長）取得許可（旅館業法第3條第1項）。客室的延面積、廁所、洗面等構造設備，於旅館業法施行令第1條第2項有標準，並以符合用途地域、用途變更（建築基準法）與消防法令為前提。年營業日數沒有上限，是與住宅宿泊事業法的民宿（申報制、年180日上限）最大的不同。本文整理許可的條件與流程，是否核准由保健所審查決定。本事務所不保證取得許可。

## 簡易宿所的許可與民宿的申報，有何不同？

同樣是「讓人住宿的生意」，依據的法律不同。簡易宿所是旅館業法的「許可」，所謂民宿則是住宅宿泊事業法的「申報」，要件與日數的處理都是兩回事。

| | 簡易宿所營業 | 住宅宿泊事業（民宿） |
| --- | --- | --- |
| 依據法律 | 旅館業法第3條第1項 | 住宅宿泊事業法（平成30年6月15日施行） |
| 手續 | 許可 | 申報 |
| 營業日數 | 無上限 | 每年180日以內 |
| 構造設備 | 有施行令第1條第2項的標準 | 以住宅設備為基本 |

依住宅宿泊事業法的民宿為申報制，年提供住宿的日數限制在180日以內。相對地，簡易宿所營業為許可制，日數沒有上限，但須符合構造設備標準以及用途地域、消防的要件。若想全年持續經營住宿業，選簡易宿所的許可；若利用住宅在日數範圍內經營，選民宿的申報，這是基本的取捨。民宿申報的要件整理於[住宅宿泊事業的申報](https://luck428.com/legal/column/minpaku-jutaku-shukuhaku-todokede-yoken)。

## 簡易宿所的構造設備標準（客室、廁所、洗面）要求到什麼程度？

簡易宿所營業的構造設備標準訂於旅館業法施行令第1條第2項。代表性項目如下。都道府縣等的條例可能訂有加碼標準。

| 項目 | 標準概要 |
| --- | --- |
| 客室的延面積 | 33㎡以上。但將住宿者數設為10人以下時，為3.3㎡乘以住宿者數所得面積以上 |
| 層架式寢台（雙層床等） | 上段與下段的間隔大致1m以上 |
| 換氣、採光、照明、防潮、排水 | 須有適當設備 |
| 入浴設備 | 滿足住宿者需求的規模。鄰近有公眾浴場等者除外 |
| 洗面設備 | 滿足住宿者需求的適當規模 |
| 廁所 | 須有適當數量 |

由於簡易宿所是預設合住（多人房）的營業類型，與旅館、飯店營業不同，標準是以客室整體的延面積、而非各客室的面積來訂定。簡易宿所並不一律要求設置玄關帳場（櫃台），但在營運上仍須有住宿者名簿的備置與本人確認的體制。具體的數值與區劃，請於保健所的手冊與事前諮詢中確認。

## 用途地域或既有建物的用途變更，會成為問題嗎？

旅館業（飯店、旅館）依建築基準法別表第2受用途地域的限制。在第一種、第二種低層住居專用地域、田園住居地域、工業專用地域等，原則上不能興建，是否可行因地域而異。首先向特定行政廳（主管建築的窗口）確認要開設的地點屬於哪種用途地域。

將既有建物改為住宿設施時，須留意用途變更。旅館、飯店屬建築基準法上的特殊建築物，若進行用途變更使供該用途的部分樓地板面積合計超過200㎡時，須辦理確認申請（建築基準法第87條第1項；將須確認的規模由超過100㎡放寬至超過200㎡的修正於令和元年6月25日施行）。用途地域是否可行、是否須用途變更、既有不合格建築物的處理，屬建築士、特定行政廳的領域。在簽訂物件契約之前，先確認用途地域與用途變更的可行性，在實務上很重要。

## 為何需要消防法令適合通知書？

旅館業的營業許可申請，一般會要求附上證明符合消防法令的「消防法令適合通知書」。此通知書由管轄該設施的消防署進行現地檢查、認定符合消防法令時交付。住宿設施是不特定人就寢的用途，消防用設備等的設置標準（消防法）比住宅嚴格，可能要求自動火災報知設備、誘導燈、滅火器等。

所需的消防用設備，會因建物的規模、構造、收容人數而不同。保健所的許可審查與消防署的適合確認在不同窗口進行，僅其中一方備妥並無法開始營業。在決定物件的內裝與格局之前，先向消防署事前諮詢、估算所需的設備與工程，對防止重工很重要。

## 建築、消防、物件，應各自委託給誰？

簡易宿所的許可橫跨多個專業領域。分工如下。

- 旅館業許可（簡易宿所）申請書、附件文件的製作，以及與保健所事前諮詢的支援 → 四葉行政書士事務所（行政書士）
- 事業用物件的選定、租賃、重要事項說明 → 四葉不動產株式會社
- 建築物的用途、確認申請、用途變更、檢查完成證的確認 → 建築士、特定行政廳
- 消防用設備等的設計、工程，消防法令適合通知書的交付申請 → 消防設備士、消防機關
- 建物與事業的會計、稅務 → 稅理士
- 涉及權利義務與紛爭的個別法律判斷 → 律師

四葉行政書士事務所與四葉不動產株式會社為不同的事業體。本事務所僅以獨立的事業體承辦旅館業許可的申請支援，物件、建築、消防、稅務請與各專業人士、行政窗口分別簽約、諮詢。本事務所不收取介紹費。許可的整體樣貌請見[行政許可手續](https://luck428.com/legal/services)，受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)。是否核准許可本身由保健所判斷。

## 常見問題

**Q. 簡易宿所與民宿，哪個較有利？**
A. 無法一概而論。簡易宿所（旅館業法第3條第1項）為許可制、營業日數無上限，但須符合構造設備、用途地域、消防的要件。民宿（住宅宿泊事業法）為申報制、較易起步，但有每年180日以內的日數限制。依想持續經營、或在日數範圍內經營來取捨。

**Q. 客室一定要33㎡以上嗎？**
A. 將住宿者數設為10人以下時，為3.3㎡乘以住宿者數所得面積以上即可（旅館業法施行令第1條第2項）。例如將住宿者上限設為4人的設施，客室延面積的參考值為3.3㎡×4＝13.2㎡以上。條例可能有加碼標準，請向保健所確認。

**Q. 住宅區的獨棟住宅也能開簡易宿所嗎？**
A. 視用途地域而定。旅館、飯店依建築基準法別表第2受用途限制，在第一種、第二種低層住居專用地域等原則上不能經營。首先向特定行政廳確認該地點的用途地域。簽訂物件契約之前的確認很重要。

**Q. 消防法令適合通知書何時取得？**
A. 因一般作為旅館業許可申請的附件文件，故應在許可申請之前向消防署申請交付，經現地檢查後領取。可能伴隨所需消防用設備的工程，故在內裝工程之前先向消防署事前諮詢，可防止重工。
