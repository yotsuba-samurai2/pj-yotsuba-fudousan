**結論（先講重點）：**在留資格「經營・管理」的更新，所問的不是新規時「能否開始事業」，而是「事業是否確實持續、經營是否具實體」。判斷的資料為最近的決算、法人稅與消費稅及住民稅等公租公課的繳納狀況、社會保險的加入、獨立事業所的實在，以及今後的事業計畫。尤其決算，會依出入國在留管理廳就事業繼續性的看法，以最近2期的損益與有無債務超過來審視。依據為《出入國管理及難民認定法》別表第一之二「經營・管理」，以及同法第七條第一項第二號基準省令。此外，令和7年（2025年）10月16日施行的修法新增資本金・出資總額3,000萬日圓以上等新基準，但對已在留者的更新設有至令和10年10月16日的過渡措施。本文為一般性資訊，不就個別更新能否獲准作出判斷或保證。向入管的申請取次由四葉集團的行政書士以獨立的事業體承辦；法人稅與決算的申報由稅理士負責；董監事變更等登記由司法書士辦理；社會保險與僱用保險手續由社會保險勞務士負責；事務所物件由屬不同事業體的不動產負責。各自分別簽約。

## 經營・管理簽證的更新，與新規設立時有何不同？

在留資格「經營・管理」對應《出入國管理及難民認定法》別表第一之二所列「在本邦經營貿易或其他事業，或從事該事業之管理的活動」。新規（認定・變更）時的重心在於「能否開始」：是否設立公司、確保事業所、事業計畫是否成立。更新時則移至「是否持續」：是否有營收、是否履行納稅與社會保險、經營者本人是否日常從事經營。所看資料的重心，由計畫書移向決算書、納稅證明。

此外，令和7年（2025年）10月16日施行的修法提高了基準本身。新規設立要件的全貌整理於[中國、台灣的創業者如何取得「經營・管理」在留資格](https://luck428.com/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)，而與更新相關者，以下各點重要。

| 局面 | 主要所問之事 |
| --- | --- |
| 新規（認定・變更） | 事業所的確保、事業計畫的實現可能性、資本金・出資總額等形式要件 |
| 更新 | 事業的繼續性・實體、最近的決算、公租公課・社會保險的履行、經營者本人的參與 |
| 2025年10月16日修法 | 資本金・出資總額3,000萬日圓以上、常勤職員1人以上、申請者本人或常勤職員的日語能力（B2相當以上）、經營經驗3年以上或學位、事業計畫的專家確認 |
| 過渡措施 | 對已在留者的更新，至令和10年10月16日止，不以僅未達新基準為由不許可 |

## 「事業的繼續性・實體」要以什麼資料立證？

更新所審視的是實質重於形式。出入國在留管理廳的資料指出，若業務大半外包、經營者本人未日常經營，即不屬「經營・管理」；事業所原則上不得與自宅兼用。公租公課的履行亦受重視，會確認僱用保險・勞災保險、健康保險・厚生年金保險的加入與保費繳納，以及國稅、地方稅（法人稅、消費稅、法人住民稅、法人事業稅等）的繳納狀況。

| 欲立證之事 | 代表性資料 |
| --- | --- |
| 事業確有運作 | 最近的決算書（資產負債表・損益表）、確定申報書副本 |
| 已履行納稅 | 法人稅、消費稅、住民稅等的納稅證明 |
| 已履行社會保險 | 健康保險・厚生年金、僱用保險・勞災的加入與繳納記錄 |
| 事業所確實存在 | 租賃契約書、所在地照片、招牌・門牌、可見獨立性的資料 |
| 今後仍將持續 | 今後的事業計畫書、預估收益的佐證資料 |

此等不僅看單一年度的數字，而以2期的推移審視。若為需要許認可的事業，亦會要求提出其取得狀況的資料。無正當理由長期出國，將使經營者的參與受質疑，可能成為消極要素。

## 赤字決算或事務所實態不足，對更新有何影響？

赤字並不會立即導致不許可。出入國在留管理廳《外國經營者在留資格基準的明確化》（平成17年8月制定・令和2年8月修訂）依最近2期的決算，整理了事業繼續性的看法。要點以表呈現如下：

| 最近2期的決算狀況 | 事業繼續性的處理 |
| --- | --- |
| 有營業毛利，且最近期末無累積虧損（有盈餘，或既無盈餘亦無虧損） | 認定有繼續性。縱有本期淨損，若未產生累積虧損仍可 |
| 有營業毛利，但有累積虧損且非債務超過 | 原則上認定。提出今後1年的事業計畫書・預估收益資料；必要時第三方評價書 |
| 僅最近期末為債務超過（其前期末非債務超過） | 須有中小企業診斷士、公認會計師等第三方，含於1年內解消債務超過之展望的評價書面 |
| 最近期末與前期末均為債務超過 | 原則上不認定繼續性 |
| 最近2期均無營業毛利（營業毛損） | 原則上不認定繼續性 |

重點在於：縱為赤字，是否尚未達債務超過；縱已達到，能否以第三方評價顯示1年內解消的展望。至於事務所，與自宅兼用或僅具名義的地址，易被視為欠缺實體，確保獨立事業所為前提。將業務整包外包、經營者本人未參與經營的型態，在更新時亦屬不利。

## 更新・變更的提出文件與申請取次，由誰承辦？

在留期間的更新，原則上由本人於現行在留期間屆滿前，向居住地管轄的地方出入國在留管理局申請。行政書士作為已向出入國在留管理廳申報的申請取次行政書士，可依《行政書士法》第1條之3，代本人提出申請書與資料，承辦申請取次。此為省去本人部分出頭的制度，並不保證許可本身。

| 文件示例 | 內容 |
| --- | --- |
| 在留期間更新許可申請書・照片 | 所定樣式；依活動內容分類 |
| 決算文件・確定申報書副本 | 最近期（必要時含前期） |
| 納稅證明・社會保險資料 | 公租公課・社會保險的履行狀況 |
| 登記事項證明書・事業所資料 | 公司的存在、事業所的實在 |
| 事業計畫書・預估收益資料 | 補強繼續性時 |

即使在過渡措施期間，亦可能被要求提出由經營專家所作的評價文件。若將永住納入視野，持續履行納稅與社會保險的記錄將有助益。永住的思路另請參閱[中國、台灣的專業人士如何在日本申請永住許可](https://luck428.com/legal/column/eiju-kyoka-shinsei-chuka-taiwan-senmonshoku)。

## 入管申請（行政書士）與稅務、登記、勞務在何處劃線？

由於相關專業人員分屬不同領域，原則上請與各方以獨立的事業體分別簽約。四葉集團的行政書士，以獨立的事業體承辦在留期間更新・變更的申請文件製作輔助與申請取次。

| 委託對象 | 主要角色 |
| --- | --- |
| 行政書士（本事務所） | 在留期間更新・變更的申請文件製作・申請取次（行政書士法第1條之3） |
| 稅理士 | 法人稅・消費稅・決算的申報；納稅證明的前提稅務 |
| 司法書士 | 董監事變更・本店遷移等商業登記 |
| 社會保險勞務士 | 健康保險・厚生年金、僱用保險・勞災的手續 |
| 不動產業者（屬不同事業體的本公司） | 作為獨立事業所的物件選定・租賃仲介・重要事項說明 |
| 中小企業診斷士・公認會計師等 | 事業計畫・繼續性的第三方評價 |

亦請參閱本事務所的[承辦業務](https://luck428.com/legal/services)、[受任流程](https://luck428.com/legal/nagare)與[報酬額表](https://luck428.com/legal/ryokin)。與各專業人員均以獨立的事業體簽約，彼此不收取介紹費。決算的內容與稅額的確定由稅理士負責，許否的最終判斷由入管審查為之。

## 常見問題

**Q. 最近的決算是赤字。更新已經沒希望了嗎？**
A. 僅赤字並不會立即導致不許可。出入國在留管理廳以最近2期的決算判斷事業繼續性，縱為赤字，若尚未達債務超過，有時可以今後1年的事業計畫書等補強。縱已達債務超過，若有中小企業診斷士、公認會計師等評價1年內解消之展望的書面，亦會納入考量。2期連續債務超過或營業毛損，原則上較難認定。

**Q. 事務所與自宅兼用也能更新嗎？**
A. 事業所原則上不得與自宅兼用。經營・管理以獨立事業所的實在為前提，更新時亦會以租賃契約書、所在地照片等確認實體。若僅借用地址而欠缺實體，將屬不利。物件的確保由屬不同事業體的不動產承辦，契約內容由宅地建物取引士進行重要事項說明。

**Q. 2025年10月修法後需資本金3,000萬日圓。現仍在留中，更新也必須滿足嗎？**
A. 對已以「經營・管理」在留者的更新，設有至令和10年（2028年）10月16日的過渡措施。此期間不以僅未達新基準（資本金・出資總額3,000萬日圓以上等）為由不許可，而依經營狀況與今後滿足的展望綜合判斷。惟經營的實態、納稅與社會保險的履行、獨立事業所的確保，與過渡措施無關，仍依從來確認。

**Q. 更新申請一定要本人親赴入管才能辦嗎？**
A. 已向出入國在留管理廳申報的申請取次行政書士，可依《行政書士法》第1條之3，代本人提出申請書與資料，承辦申請取次。可省去本人部分出頭，惟此為程序上的取次，並不保證許可本身。許否由入管審查為之。
