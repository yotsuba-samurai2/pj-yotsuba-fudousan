**先講重點：** 新開美容室時，開始營業前須向保健所（都道府縣知事；設有保健所的市、特別區為市長、區長）提出美容所的開設申報，並在保健所檢查時取得構造設備的確認。開設申報依美容師法第11條，須事先申報美容所的位置、構造設備、管理美容師及其他從業者的姓名等。就已申報的構造設備接受都道府縣知事檢查，取得「適於採取所需衛生措施」的確認後，方可使用美容所（美容師法第12條）。本文整理申報的要件與流程，申報的受理與確認由保健所進行，本事務所不保證取得確認。

## 開設美容所時開設申報何時、向何處提出？

美容師法（昭和32年6月3日法律第163號）第2條將美容定義為「以燙髮、結髮、化妝等方法使容姿變美」，將美容師定義為「取得厚生勞動大臣的免許而以美容為業者」，將美容所定義為「為進行美容之業而設置的設施」。此處重要的是，美容師的免許是個人資格，而開設美容所則須與免許分開、就各美容所提出申報。僅持有免許並不能開店。

開設申報的提出處，為管轄美容所所在地的都道府縣知事。但在設有保健所的市（政令市、中核市等）及特別區，窗口為市長、區長。申報須「事先」＝在開始營業之前進行（美容師法第11條）。申報的主要事項為美容所的位置、構造設備，以及管理美容師及其他從業者的姓名等。已申報事項有變更，或美容所廢止時，亦須迅速申報（同條）。

| 項目 | 內容 |
| --- | --- |
| 依據 | 美容師法第11條（開設的申報） |
| 提出處 | 都道府縣知事（設有保健所的市、特別區為市長、區長） |
| 時機 | 於開始營業之前「事先」 |
| 申報者 | 美容所的開設者（非美容師的個人、法人亦可） |
| 變更、廢止 | 事項有變更、廢止時迅速申報 |

## 構造設備基準（面積、區劃、採光、消毒設備）須滿足什麼？

美容所的開設者，須就該美容所採取所需的衛生措施（美容師法第13條）。具體內容規定於厚生勞動省令（美容師法施行規則）與各都道府縣的條例。國家施行規則所定的代表性措施如下。

| 項目 | 主要內容 | 依據 |
| --- | --- | --- |
| 消毒設備 | 消毒剃刀、剪刀、梳子等接觸皮膚器具的設備。附著或可能附著血液的器具，以煮沸（2分鐘以上）、乙醇水溶液、次氯酸鈉水溶液等消毒 | 施行規則第25條 |
| 保持清潔 | 地板、腰板使用不透水材料。洗場設流水裝置。備有附蓋的汙物箱、毛髮箱 | 施行規則第26條 |
| 採光、照明、換氣 | 作業面的照度為100勒克斯以上。作業室內的二氧化碳濃度保持在1000分之5以下 | 施行規則第27條 |
| 區劃 | 將作業場以隔壁等，與居室、休息室等和作業無直接關係的場所完全區分 | 衛生管理要領 |

作業室的面積、美容椅的台數等具體數值，委任給各都道府縣的條例與保健所的手冊。因未能確認國家有定全國一律面積基準的規定，此處不斷定面積的具體值；請以開業地的條例與保健所的手冊確認。關於區劃與消毒場所的思路，由厚生勞動省的「理容所及美容所衛生管理要領」（昭和56年6月1日環指第95號；平成22年9月15日健發0915第5號修正）所示。

## 理容所與美容所能否在同一店舖兼營？

可以兼營，但有條件。平成28年4月1日以後，若滿足一定要件，即可在同一場所重複開設理容所與美容所。要件主要有2項：①理容所、美容所各自的構造設備與衛生上的要件均須滿足；②於該設施施術的從業者全員，皆須持有理容師與美容師兩種資格。此項處理，係依規制改革實施計畫（平成27年6月30日內閣會議決定），於「理容師法施行規則及美容師法施行規則之部分修正省令的施行等」（平成27年12月9日生食發1209002號）等所示。

即使是重複開設，開設申報仍須就理容所與美容所各自提出。因為理容所的開設依理容師法、美容所的開設依美容師法，依據的法律不同。是同時開設，或在既有設施上追加，會使申報書應記載的事項（對方設施的名稱、開設預定年月日）有所不同，故格式請向開業地的保健所確認。

## 開設申報需要哪些文件？保健所檢查的流程為何？

開設申報除申報書外，還須設施的圖面與關於資格、衛生的文件。格式、份數因地方政府而異，代表性者如下。

| 文件 | 內容概要 |
| --- | --- |
| 美容所開設申報書 | 位置、構造設備、管理美容師及其他從業者的姓名等 |
| 設施的平面圖 | 作業室、等候區、消毒設備、洗場、廁所的配置與尺寸 |
| 美容師免許證的影本 | 於該美容所從事美容之業的美容師者 |
| 管理美容師講習會修了證影本 | 常時有2名以上美容師從業時 |
| 醫師的診斷書等 | 關於結核、皮膚疾病等（依地方政府） |
| 使用水的水質檢查結果 | 使用井水等時 |
| 登記事項證明書 | 開設者為法人時 |

流程為：事前諮詢 → 提出開設申報（開始營業前）→ 保健所的現地檢查（確認構造設備）→ 確認 → 開始使用美容所（營業），依此順序。可使用美容所者，須在檢查確認其「適於採取第13條的措施」之後（美容師法第12條）。標準處理期間與檢查日程因地方政府而異，故請從開業預定日回推，向開業地的保健所諮詢。

此外，常時有2名以上美容師從業的美容所，須置管理美容師1名。可擔任管理美容師者，須為取得美容師免許後從事美容業務3年以上，且修畢都道府縣知事指定講習會課程者（美容師法第12條之3）。

## 可以在申報前先進行工程嗎？避免重工的順序是什麼？

若先完成所有內裝工程再申報，構造設備可能不符基準而須修改。區劃、洗場、消毒設備、換氣，最好依基準自設計階段起即納入為宜。建議的順序為：①物件現勘與用途確認 → ②向保健所事前諮詢（攜帶圖面）→ ③工程 → ④提出開設申報 → ⑤保健所現地檢查、確認 → ⑥開始營業。特別是將作業場以隔壁與居室等完全區分、洗場的流水裝置、消毒設備，若日後才加設，往往須重做牆壁與配管。在簽訂物件契約之前，先看間隔能否符合基準、能否確保給排水與換氣。

美容室的開業橫跨多個領域，分工如下。

- 美容所開設申報的製作，以及與保健所事前諮詢的支援 → 四葉行政書士事務所（行政書士）
- 事業用物件的選定、租賃、重要事項說明 → 四葉不動產株式會社
- 開業後從業員的勞動條件、社會保險、工作規則 → 四葉社會保險勞務士事務所（社會保險勞務士）
- 內裝達大規模用途變更時的確認申請 → 建築士、特定行政廳
- 建物與事業的會計、稅務 → 稅理士
- 涉及權利義務與紛爭的個別法律判斷 → 律師

四葉行政書士事務所與四葉不動產株式會社為不同的事業體。本事務所僅以獨立的事業體承辦美容所開設申報的申請支援，物件、勞務、稅務請與各專業人士、事業體分別簽約、諮詢。本事務所不收取介紹費。許可的整體樣貌請見[行政許可手續](https://luck428.com/legal/services)，受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)。若併設餐飲，另請確認[餐飲店營業許可與保健所的設備標準](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)。申報的受理與確認本身由保健所判斷。

## 常見問題

**Q. 有美容師免許，就能直接開自己的店嗎？**
A. 免許與開設是兩回事。美容師免許是個人資格，但要開店（美容所），須與免許分開，向保健所提出美容所開設申報，並接受構造設備的檢查、確認（美容師法第11條、第12條）。須在檢查確認其適於採取所需衛生措施之後，方可使用美容所。

**Q. 開設申報應在何時提出？**
A. 於開始營業之前「事先」提出（美容師法第11條）。申報之後有保健所的現地檢查，取得該確認後方可開始營業。因排定檢查需要時日，從開業預定日回推、先從事前諮詢開始較為安全。標準處理期間因地方政府而異，請於開業地保健所的官方網頁確認。

**Q. 想在同一店舖同時經營理容室與美容室，可行嗎？**
A. 平成28年4月1日以後，在①滿足理容所、美容所各自的構造設備與衛生上要件，且②施術者全員持有理容師與美容師兩種資格時，可於同一場所重複開設。惟開設申報須就理容所、美容所各自提出。要件細節與格式，請向開業地的保健所確認。

**Q. 一定要置管理美容師嗎？**
A. 在常時有2名以上美容師從業的美容所為必要。可擔任管理美容師者，須為取得美容師免許後從事美容業務3年以上，且修畢都道府縣知事指定講習會課程者（美容師法第12條之3）。常時僅1名美容師的美容所，無置管理美容師的義務。
