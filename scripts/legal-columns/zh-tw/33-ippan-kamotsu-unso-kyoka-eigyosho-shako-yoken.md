**結論（先說要點）**：欲經營卡車運送業（一般貨物汽車運送事業），須依貨物汽車運送事業法第3條取得國土交通大臣（實務為地方運輸局長）之許可。許可於符合同法第6條之基準時核發――事業計畫適於確保運輸安全、事業用汽車之數量（最低5輛）與車庫規模符合國土交通省令基準、具備自行妥適遂行事業之經濟基礎與能力。本文為一般資訊提供，整理營業所・車庫・休憩睡眠設施之位置與大小、前面道路與用途地域易落之點、申請至許可之標準處理期間，以及物件・車輛・勞務應交由何人處理。個別許可之可否，由運輸支局・地方運輸局審查。

## 一般貨物汽車運送事業許可須符合什麼始能核發？

一般貨物汽車運送事業，係應他人需求、有償以汽車（除三輪以上之輕型車及二輪車）運送貨物之事業。欲開始經營，貨物汽車運送事業法第3條規定須取得許可。

許可基準規定於同法第6條，要旨如下。

| 區分 | 內容（要旨） |
| --- | --- |
| 運輸安全（第6條第1號） | 事業計畫就防止過勞駕駛、事業用汽車之安全等，適於確保運輸安全 |
| 事業計畫之妥適（第6條第2號） | 事業用汽車之數量、車庫規模及其他計畫符合省令所定基準 |
| 遂行能力（第6條第3號） | 具備自行妥適且持續遂行事業之經濟基礎及其他能力 |
| 特別併裝（第6條第4號） | 為特別併裝貨物運送時，妥適保有・管理裝卸設施並採事故防止措施 |

此外，須不該當同法第5條之欠格事由（如自許可撤銷起未逾一定期間者），常勤役員中1名須通過法令試驗，須能選任運行管理者・整備管理者，並須估算所需資金並確保自有資金。事業用汽車須備妥最低5輛。四葉行政書士事務所於行政書士業務範圍內，支援要件確認、事業計畫與申請文件之製作、申請之代理。個別許可之可否，由運輸支局・地方運輸局審查。

## 營業所・休憩睡眠設施・車庫之位置與大小要件為何？

營業所・休憩睡眠設施・車庫，各有位置、大小與使用權原之要件。

| 設施 | 主要要件 |
| --- | --- |
| 營業所 | 具使用權原（自有，或租賃；租賃以契約期間1年以上或自動更新為目安）。建物符合建築基準法・消防法。原則不得設於市街化調整區域。地目為農地（田・畑）者原則不可 |
| 休憩・睡眠設施 | 併設於營業所或車庫。須使駕駛人睡眠時，每人須2.5㎡以上之睡眠設施。依運行形態能確保駕駛人8小時以上休息者，睡眠設施亦有不需之情形 |
| 車庫 | 原則併設於營業所。無法併設時，須距營業所一定距離內（詳後）。能收容所有計畫之事業用汽車，且車輛與車庫境界及車輛相互間有50公分以上之間隔 |

營業所與車庫須位於不牴觸都市計畫法・建築基準法・農地法等相關法令之處。若先簽約物件，事後才發現因用途地域或地目而不能使用，即須重新尋找。宜於物件選定階段依要件確認。

## 前面道路或用途地域於何種情形會落選？

許可申請中易被忽略者，為車庫前面道路之寬度與營業所・車庫之立地。

| 事項 | 目安 |
| --- | --- |
| 營業所與車庫之距離 | 併設為原則。分開時，原則以直線距離距營業所10km以內（首都圈・近畿圈之一部等地區為5km・20km等，因地方運輸局而異） |
| 前面道路之寬度 | 使用車輛能符合車輛限制令通行。以道路管理者之寬度證明書等證明（國道等亦有不需證明之情形） |
| 車庫之使用權原 | 自有或租賃（租賃以契約期間2年以上且有自動更新記載為目安） |
| 立地（地目・區域） | 市街化調整區域原則不可。地目為農地者原則不可。即使於市街化區域，仍須確認用途地域之限制 |

若前面道路狹窄，欲使用之大型車不符合車輛限制令，該車庫即無法取得許可。寬度證明書向道路管理者（國道・都道府縣道・市町村道之窗口不同）取得。於決定物件前確認用途地域・地目・前面道路三點，可避免重做。

## 自申請至許可需多久？（標準處理期間）

自申請至許可之標準處理期間，於無文件不備・補正時，概略為3〜5個月。因地方運輸局而有幅度：關東運輸局約3〜4個月，近畿運輸局約4〜5個月。此以法令試驗合格與補正事項於期間內完成為前提。

| 階段 | 內容・目安 |
| --- | --- |
| 提出申請書 | 經管轄之運輸支局向地方運輸局提出 |
| 標準處理期間 | 概略3〜5個月（因局而為3〜4・4〜5個月）。為無文件不備・補正時之目安 |
| 法令試驗 | 常勤役員中1名受驗。合格為許可之前提 |
| 許可・登錄免許稅 | 許可後繳納登錄免許稅（12萬日圓） |
| 運輸開始 | 事業用汽車之登錄（綠牌）、運行管理者・整備管理者之選任申報、運輸開始申報 |

即使核發許可，仍須經事業用汽車之登錄（取得綠牌）與運輸開始前之確認，始能實際開始運送。以輕型卡車進行之貨物輕型汽車運送事業（黑牌）為申報制，與此一般貨物之許可係不同制度。

## 物件・車輛・勞務應交由何人處理？

一般貨物汽車運送事業，涉及許認可・不動產・車輛・勞務。分工如下。

- 許可申請之要件確認・事業計畫與文件製作・申請代理 → 四葉行政書士事務所（行政書士）
- 營業所・車庫物件之尋找、用途地域・地目・前面道路之適合確認、租賃契約 → 四葉不動產株式會社（宅地建物交易業者）
- 駕駛人之工時（改善基準告示）・社會保險・就業規則 → 社會保險勞務士
- 事業用汽車之登錄（綠牌） → 運輸支局
- 法人設立・役員變更等之登記 → 司法書士

四葉行政書士事務所與四葉不動產株式會社為別事業體。各領域均以與各資格者作為獨立的事業體個別簽約為前提，本事務所不收取介紹費。受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)；全貌見[許認可・各種申請服務](https://luck428.com/legal/services)。營業所・車庫物件側之要件，亦請參閱別事業體四葉不動產株式會社整理之[運送業營業所・車庫物件要件](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

## 常見問題

**Q. 事業用汽車不足5輛，仍能取得許可嗎？**
A. 一般貨物汽車運送事業以備妥事業用汽車最低5輛為要件。不足5輛即不得取得許可。以輕型卡車運送之貨物輕型汽車運送事業（黑牌）為申報制，係無5輛要件之另一制度。屬何者，視事業計畫而定。

**Q. 可將自宅作為營業所嗎？**
A. 若符合使用權原・建築基準法・消防法・用途地域，或屬可能。惟市街化調整區域或地目為農地之處，原則不得作為營業所。租賃時尚有契約期間與自動更新之要件。建議於決定物件前依要件確認。

**Q. 車庫可遠離營業所嗎？**
A. 原則須併設於營業所。無法併設時，須置於距營業所直線距離原則10km以內（因地區為5km・20km等，因地方運輸局而異）。並須車庫前面道路符合車輛限制令，且車輛與境界・車輛相互間有50公分以上之間隔。

**Q. 申請後多久核發許可？**
A. 標準處理期間概略為3〜5個月（因局而為3〜4・4〜5個月）。此為無文件不備・補正時之目安，並以常勤役員之法令試驗合格與補正事項於期間內完成為前提。個別審查期間由運輸支局・地方運輸局判斷。
