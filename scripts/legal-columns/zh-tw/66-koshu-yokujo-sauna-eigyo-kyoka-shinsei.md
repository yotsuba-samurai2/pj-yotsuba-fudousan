**先講重點：** 要以營業方式經營三溫暖、錢湯或水療，須取得公眾浴場法的營業許可。凡以營業方式經營公眾浴場者，須向都道府縣知事（設有保健所的市、特別區為市長、區長）取得許可（公眾浴場法第2條第1項）。當設置場所、構造設備被認定在公眾衛生上不適當等情形時，可能不予許可（同條第2項），而構造設備與衛生措施的具體標準委任給各都道府縣的條例（第2條第3項、第3條第2項）。並以符合用途地域、用途變更（建築基準法）與消防法令為前提。本文整理許可的條件與流程，是否核准由保健所審查決定。本事務所不保證取得許可。

## 三溫暖、錢湯的營業許可依據什麼法律？

以營業方式經營公眾浴場，須取得公眾浴場法（昭和23年7月12日法律第139號）所定都道府縣知事的許可。同法第1條將「公眾浴場」定義為，使用溫湯、潮湯或溫泉等使公眾入浴的設施。錢湯、三溫暖（附冷水池等浴槽者）、超級錢湯，只要符合此定義即為公眾浴場。

許可權者為都道府縣知事。但在設有保健所的市（政令市、中核市等）及特別區，權者為市長、區長（公眾浴場法第2條第1項）。知事等在認定設置場所、構造設備於公眾衛生上不適當，或設置場所欠缺配置的適正時，可不予許可（同條第2項）。由於構造設備的標準（換氣、採光、照明、保溫、清潔等入浴者衛生與風紀所需的措施）委任給都道府縣的條例（同法第3條第1項、第2項），數值與區劃須以開業地的條例與保健所的手冊確認。

此外，僅以蒸氣、熱氣而不設浴槽（含冷水池）的一部分三溫暖設施是否須取得公眾浴場法的許可，會因設施形態而由各地方政府作不同判斷。此點在撰文之前先向開業地的保健所事前諮詢確認最為確實。因本社無法確認，此處僅止於「設有浴槽的三溫暖、錢湯、水療屬公眾浴場」的一般性處理。

## 一般公眾浴場與「其他公眾浴場」的許可有何不同？

公眾浴場在運用上分為「一般公眾浴場」與「其他公眾浴場」兩類處理。前者即所謂錢湯，作為地域日常生活所需的設施，入浴料金受知事統制（依物價統制令＝昭和21年勅令第118號）。後者為三溫暖、超級錢湯、健康樂園、個室附浴場等，可自由設定料金的類型。

| | 一般公眾浴場（錢湯） | 其他公眾浴場（三溫暖等） |
| --- | --- | --- |
| 依據法律 | 公眾浴場法第2條第1項 | 公眾浴場法第2條第1項 |
| 入浴料金 | 由知事統制（物價統制令） | 可自由設定 |
| 配置基準（距離限制） | 為條例距離限制的對象 | 原則上非對象 |
| 構造設備、衛生措施 | 須符合條例標準 | 須符合條例標準 |

最大的不同在於配置基準（距離限制）與料金。公眾浴場法第2條第3項將設置場所的配置基準委任給都道府縣的條例。此距離限制以一般公眾浴場（錢湯）為對象，三溫暖等「其他公眾浴場」原則上非此距離限制的對象。惟構造設備、衛生措施的標準兩者皆須遵守，此點三溫暖亦不獲免除。自己的設施以哪一類型受審查，取決於營業形態與條例的規定，故向保健所確認。

## 申請需要哪些圖面、文件？

營業許可申請除申請書外，還須設施的圖面與載明設備內容的文件。格式、份數因地方政府而異，代表性者如下。

| 文件 | 內容概要 |
| --- | --- |
| 營業許可申請書 | 營業者、設施所在地、營業種別等 |
| 設施的平面圖、配置圖 | 浴室、脫衣室、廁所、洗面的位置與尺寸 |
| 給排水、循環過濾設備的系統圖 | 給湯、排水、循環過濾、氯消毒的路徑 |
| 換氣設備的圖 | 浴室、脫衣室的換氣路徑 |
| 使用水的水質相關資料 | 使用井水等時的水質檢查結果等 |
| 登記事項證明書等 | 法人時證明資格的文件 |

設置循環式浴槽時，退伍軍人桿菌（Legionella）的對策為審查重點。厚生勞動省的「公眾浴場衛生等管理要領」（平成12年12月15日 生衛發第1811號；令和2年12月10日 生食發第1210001號修正）載明循環過濾裝置的清洗、配管內生物膜的去除、貯湯槽的適溫管理等。須依此要領與各都道府縣的條例，自設備設計階段起即納入衛生措施。

## 保健所檢查與消防、建築的確認如何並行？

公眾浴場的開業，保健所（許可）、消防署（消防法令）、建築（用途地域、用途變更）三個窗口分別運作。僅其中一項備妥並無法開始營業。

在消防方面，公眾浴場（含蒸氣浴場、熱氣浴場）屬消防法施行令別表第1所列的防火對象物，須依規模、收容人數設置消防用設備等（自動火災報知設備、誘導燈、滅火器等）。在建築確認、許可的場面，涉及消防長、消防署長的同意（消防法第7條）。

在建築方面，公眾浴場為建築基準法上的特殊建築物（建築基準法第2條第2號）。將既有建物改為公眾浴場時，若進行用途變更使供該用途的部分樓地板面積合計超過200㎡，須辦理確認申請（建築基準法第87條第1項；將須確認的規模由超過100㎡放寬至超過200㎡的修正於令和元年6月25日施行）。與旅館、飯店相同，亦有依用途地域的立地限制。在簽訂物件契約之前，先確認用途地域與用途變更的可行性、消防用設備的要否，對防止重工很重要。相近論點也整理於[旅館業（簡易宿所）的營業許可](https://luck428.com/legal/column/ryokangyo-kani-shukujo-kyoka-shinsei)。

## 許可申請、建築、物件，應各自委託給誰？

公眾浴場的開業橫跨多個專業領域。分工如下。

- 公眾浴場營業許可申請書、附件文件的製作，以及與保健所事前諮詢的支援 → 四葉行政書士事務所（行政書士）
- 事業用物件的選定、租賃、重要事項說明 → 四葉不動產株式會社
- 建築物的用途、確認申請、用途變更、檢查完成證的確認 → 建築士、特定行政廳
- 消防用設備等的設計、工程，消防同意、檢查 → 消防設備士、消防機關
- 建物與事業的會計、稅務 → 稅理士
- 涉及權利義務與紛爭的個別法律判斷 → 律師

四葉行政書士事務所與四葉不動產株式會社為不同的事業體。本事務所僅以獨立的事業體承辦公眾浴場營業許可的申請支援，物件、建築、消防、稅務請與各專業人士、行政窗口分別簽約、諮詢。本事務所不收取介紹費。許可的整體樣貌請見[行政許可手續](https://luck428.com/legal/services)，受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)。若併設餐飲，請見[餐飲店營業許可與保健所的設備標準](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)；若涉及住宿，另請確認[民宿（住宅宿泊事業）的申報](https://luck428.com/legal/column/minpaku-jutaku-shukuhaku-todokede-yoken)。是否核准許可本身由保健所判斷。

## 常見問題

**Q. 三溫暖與錢湯是同一種許可嗎？**
A. 依據同為公眾浴場法第2條第1項的許可，但運用上的類型不同。錢湯為「一般公眾浴場」，入浴料金受知事統制（物價統制令），並為條例距離限制的對象。三溫暖、超級錢湯等為「其他公眾浴場」，料金可自由設定，距離限制原則上非對象。惟構造設備、衛生措施的條例標準兩者皆須遵守。

**Q. 設置循環式浴槽會使審查變嚴嗎？**
A. 退伍軍人桿菌對策會成為重點。厚生勞動省的「公眾浴場衛生等管理要領」（平成12年12月15日 生衛發第1811號；令和2年12月10日修正）載明循環過濾裝置的清洗、配管內生物膜的去除、貯湯槽的管理等。因須有符合此要領與各都道府縣條例的設備與運用，故自設計階段起即納入衛生措施。

**Q. 將辦公大樓的一室改為三溫暖也能營業嗎？**
A. 須確認用途地域與用途變更。公眾浴場為建築基準法上的特殊建築物，供該用途的部分超過200㎡的用途變更須辦理確認申請（建築基準法第87條第1項）。亦有依用途地域的立地限制。可否由特定行政廳、建築士判斷，故在簽訂物件契約之前先確認可行性。

**Q. 到取得許可需要多久？**
A. 因設施規模、所需工程，以及與保健所、消防、建築各窗口的協調狀況而異，無法一概而論。多數地方政府的流程為：動工前的事前諮詢→圖面等的確認→工程→完成後的現地檢查→許可。標準處理期間與必要文件，請於開業地保健所的官方網頁確認。
