**結論（先說要點）**：登錄支援機關，係受接收特定技能1號外國人之事業者（特定技能所屬機關）委託，實施「一號特定技能外國人支援計畫」全部，並受出入國在留管理廳長官登錄之機關（出入國管理及難民認定法第19條之23）。登錄之有效期間為5年，並有不屬欠格事由等要件（同法第19條之26）。支援計畫須符合法務省令（訂定特定技能雇用契約及一號特定技能外國人支援計畫基準等之省令・平成31年法務省令第5號）之基準，並納入事前指引等義務性支援。本文為一般資訊提供，整理登錄要件・欠格事由・支援計畫必要項目・自社支援之可否・申報此等入管手續，不作個別許認可之可否或法律判斷。

## 登錄支援機關係從事何種業務之機關？

以特定技能1號在留資格接收外國人之事業者，稱為「特定技能所屬機關（接收機關）」。接收機關須就所接收之每一名外國人製作「一號特定技能外國人支援計畫」，並依計畫就職業生活・日常生活・社會生活提供支援（出入國管理及難民認定法第2條之5）。將此支援之全部實施委託外部時，受該委託之機關即為登錄支援機關。

登錄支援機關係受出入國在留管理廳長官登錄之法人或個人，依與接收機關之委託契約實施支援計畫。未受登錄之事業者不得有償受託支援業務。行政書士受接收機關或支援機關委任，於行政書士業務範圍內代為製作・提出登錄申請文件與支援計畫書。受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)；取扱業務見[取扱業務](https://luck428.com/legal/services)。

| 區分 | 角色 |
| --- | --- |
| 特定技能所屬機關（接收機關） | 與外國人締結特定技能雇用契約、製作支援計畫之當事人 |
| 登錄支援機關 | 受支援計畫全部實施之委託而實施支援之機關 |
| 行政書士 | 登錄申請・支援計畫書等入管提出文件之製作・提出代理 |

## 登錄之要件與欠格事由為何？

登錄係向出入國在留管理廳長官申請（第19條之24），符合要件者即登錄於登錄支援機關登錄簿（第19條之25）。登錄手數料為收入印紙28,400日圓，登錄之有效期間為5年（第19條之23）。未更新者於期間屆滿時失其效力。

主要之登錄基準與欠格事由如下（第19條之26第1項各款）。

| 項目 | 內容 |
| --- | --- |
| 支援體制 | 已選任支援責任者・支援擔當者，並具備以外國人所能理解語言提供支援之體制 |
| 過去實績等 | 2年內有接收中長期在留者・生活諮詢之實績等（符合省令基準） |
| 欠格事由 | 不屬如受拘禁刑以上之刑、因違反出入國或勞動法令受罰金刑而未滿5年、與黑道有關、有一定申報違反等情形 |

欠格事由之有無，以及自社體制是否符合基準，最終由出入國在留管理廳審查。本事務所不保證登錄之可否。

## 支援計畫之必要項目為何？

一號特定技能外國人支援計畫，須符合法務省令（訂定特定技能雇用契約及一號特定技能外國人支援計畫基準等之省令・平成31年法務省令第5號）之基準。計畫須納入下列義務性支援之全部。

| 義務性支援 | 內容例 |
| --- | --- |
| 事前指引 | 於雇用契約締結後說明勞動條件・活動內容・入國手續等 |
| 出入國時之接送 | 機場與事業所・住居間之接送 |
| 住居確保・生活所需契約之支援 | 住居之確保，銀行帳戶・手機・水電等手續之協助 |
| 生活導覽 | 生活規則・交通・緊急時應對等之說明 |
| 公務手續等之陪同 | 住民登記・社會保障・稅等手續之協助・陪同 |
| 日語學習機會之提供 | 日語教室之介紹等 |
| 諮詢・申訴之對應 | 以母語之諮詢對應・建議 |
| 與日本人交流之促進 | 地方活動之介紹等 |
| 轉職支援 | 因接收方事由解除雇用契約時之轉職支援 |
| 定期面談・對行政機關之通報 | 支援責任者等之定期面談，違反法令時之通報 |

其中，勞動條件之明示本身、雇用契約之內容、社會保險・勞動保險之加入手續係雇主（接收機關）之義務；代辦該等手續及勞務管理屬社會保險勞務士，與外國人有關之課稅屬稅理士之領域。四葉社會保險勞務士事務所及稅理士與四葉行政書士事務所為獨立的事業體，須個別簽約。本事務所不收取介紹費。

## 不委託而由自社支援之條件為何？

接收機關亦得不委託登錄支援機關，而由自社實施支援計畫。惟於此情形，接收機關本身須符合支援體制之基準（省令）。具體而言，須滿足如過去2年內有接收中長期在留者之實績，或役員・職員於過去2年內曾從事中長期在留者生活諮詢業務之經驗等要件後，選任支援責任者・支援擔當者。

另一方面，將支援計畫全部之實施委託登錄支援機關時，接收機關即被視為符合支援體制之基準（出入國管理及難民認定法第2條之5）。選擇自社支援抑或委託，係衡酌社內體制・語言對應・成本之經營判斷；基準符合之最終判斷由出入國在留管理廳為之。

## 怠於申報・更新將如何？

登錄支援機關負有如登錄事項變更時之變更申報（第19條之27）、休廢止支援業務時之申報（第19條之29）等義務。怠於申報支援實施狀況、為不實申報、未適正實施支援等情形，將成為出入國在留管理廳長官指導・建議之對象，有一定事由時其登錄得被撤銷（第19條之32）。登錄一經撤銷即無法續行支援業務，受委託之接收機關須另行整備支援體制。

四葉行政書士事務所與四葉不動產株式會社為別事業體。登錄申請・支援計畫書之製作由行政書士，勞動條件之明示及社會保險・勞動保險手續由社會保險勞務士，課稅由稅理士，在留資格相關爭訟由律師，各以獨立的事業體個別簽約處理。本事務所不收取介紹費。受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)；取扱業務見[取扱業務](https://luck428.com/legal/services)。

## 常見問題

**Q. 登錄支援機關之登錄有效期間為何？**
A. 登錄之有效期間為5年（出入國管理及難民認定法第19條之23）。期間屆滿後欲續行支援業務須更新，未更新即失其效力。新規登錄手數料為收入印紙28,400日圓。

**Q. 接收機關是否必須委託登錄支援機關？**
A. 否。接收機關若符合支援體制之基準（省令），即可由自社實施支援計畫。不符合或自社無法因應時，有將支援計畫全部之實施委託登錄支援機關之選項。全部委託時，接收機關即被視為符合支援體制之基準。

**Q. 支援計畫應記載何事項？**
A. 須納入事前指引、出入國時之接送、住居確保・生活所需契約之支援、生活導覽、公務手續等之陪同、日語學習機會之提供、諮詢・申訴之對應、與日本人交流之促進、轉職支援、定期面談・對行政機關之通報此等義務性支援之全部，並符合法務省令（平成31年法務省令第5號）之基準。

**Q. 勞動條件與社會保險手續亦可委由行政書士辦理嗎？**
A. 在留資格之申請、支援機關之登錄、支援計畫書之製作屬行政書士業務。另一方面，勞動條件之明示、雇用契約之內容、社會保險・勞動保險之加入手續及勞務管理屬社會保險勞務士，課稅屬稅理士之領域，各以獨立的事業體個別簽約。本事務所不收取介紹費。
