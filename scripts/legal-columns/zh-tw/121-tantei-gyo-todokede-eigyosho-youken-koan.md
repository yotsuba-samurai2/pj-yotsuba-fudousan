**結論（先講重點）：**偵探業並非許可制，而是申報制。依偵探業務適正化法（偵探業法）第4條，於開始營業的前一日前，須就各營業所向管轄該營業所所在地的公安委員會（實務上經由管轄警察署的防犯係）提出偵探業開始申報書，不收申報手續費。過去交付的偵探業申報證明書，已於2024年（令和6年）4月1日施行的修正中廢止，改為在營業所揭示表明已申報的標識（第12條）。妨礙申報的欠格事由定於第3條：受破產程序開始裁定而未復權者、受拘禁刑以上之刑執行完畢等未滿5年者、暴力團成員，以及法人中役員該當者等。以自己名義使他人經營偵探業的借名行為，依第5條禁止；無申報營業與借名均處6個月以下拘禁刑或30萬日圓以下罰金。本文為一般性資訊，不就個別申報是否受理作最終判斷。四葉集團的行政書士，以獨立的事業體承辦偵探業開始申報書的作成與向公安委員會提出的支援。調查伴隨的名譽毀損、隱私侵害、違反跟蹤騷擾規制法等違法與紛爭領域屬律師，作為營業所的物件尋找與租賃屬不同事業體的不動產業者（本公司）領域，各自分別簽約。本所不向任何專業人士收取介紹費。

## 偵探業是許可制還是申報制，開始前須提出什麼？

偵探業並非取得許可後才開始的「許可制」，而是在開始營業前申報的「申報制」。偵探業務適正化法（偵探業法；平成18年法律第60號，2007年〔平成19年〕6月1日施行）第4條規定，欲經營偵探業者，須於開始營業的前一日前，就各營業所向管轄該營業所所在地的公安委員會提出申報書。實務上經由管轄該營業所的警察署防犯係提出。

| 項目 | 內容（偵探業法） |
| --- | --- |
| 制度 | 申報制（非許可制） |
| 申報對象 | 管轄營業所所在地的公安委員會（經由管轄警察署防犯係） |
| 時期 | 開始營業的前一日前（第4條第1項） |
| 單位 | 各營業所 |
| 手續費 | 無 |
| 借名 | 禁止（第5條） |

此處所稱「偵探業務」，指受他人委託，以收集特定人所在或行動之相關資訊為目的，以面談探詢、尾行、埋伏及其他類似方法進行實地調查，並將結果向委託人報告的業務（第2條第1項）。專供報導機關報導之用而受委託者，自偵探業中排除（第2條第2項）。申報書的作成與提出支援，亦見於本所的[許認可業務介紹](https://luck428.com/zh-tw/legal/services)。

## 偵探業申報不被受理的「欠格事由」有哪些？

偵探業法第3條規定，該當下列各款之一者，不得經營偵探業，列舉欠格事由。申報前，須確認自己（法人則役員）是否該當。

| 款 | 欠格事由（第3條） |
| --- | --- |
| 第1款 | 受破產程序開始裁定而未復權者 |
| 第2款 | 受拘禁刑以上之刑，或因違反本法受罰金刑，自執行完畢等未滿5年者 |
| 第3款 | 最近5年間違反第15條處分（營業停止、廢止命令）者 |
| 第4款 | 暴力團成員，或脫離暴力團未滿5年者 |
| 第5款 | 因身心故障無法適正執行偵探業務，經內閣府令所定者 |
| 第6款 | 就營業不具與成年人同等能力的未成年人，其法定代理人該當第1至5款或第7款者 |
| 第7款 | 役員中有該當第1至5款之任一者的法人 |

2022年（令和4年）刑法等修正將懲役、禁錮統合為「拘禁刑」，並自2025年（令和7年）6月1日施行，故條文亦表述為「拘禁刑以上之刑」。是否該當欠格事由的最終評價屬公安委員會領域，行政書士不代為保證受理。

## 營業所或自宅開業有哪些要件與揭示義務？

偵探業法並無如餐飲店營業般的建物構造、設備基準，但課予各營業所申報義務，以及揭示表明已申報之標識的義務。過去的偵探業申報證明書，已於2024年（令和6年）4月1日施行的修正（申報手續的檢討）中廢止，改為由事業者自行作成標識並揭示於營業所明顯處的方式（第12條）。

| 區分 | 內容 |
| --- | --- |
| 營業所 | 須就各營業所申報；亦可以自宅為營業所（管轄依營業所所在地） |
| 標識 | 於明顯處揭示表明已申報的標識（舊證明書已廢止） |
| 從業者名簿 | 就各營業所備置（第12條） |
| 教育 | 使從業者適正執行偵探業務的教育（第11條） |

標識須記載受理申報的公安委員會名稱、申報書的受理編號、申報年月日、商號、名稱、姓名、營業所的名稱與所在地等。樣式與記載要領由各都道府縣警察公布，作成前須於管轄的官方頁面確認最新內容。租用物件開業時，物件尋找與租賃契約屬不同事業體的不動產業者（本公司）領域，亦可利用本公司的[不動產諮詢窗口](https://luck428.com/zh-tw/souzoku)。承辦的進行方式請見[受任流程](https://luck428.com/zh-tw/legal/nagare)。

## 重要事項說明書、契約書面對偵探業者課予哪些義務？

偵探業者與委託人締約時，被課予締約前書面交付與締約後書面交付兩者的義務（第8條）。此外，須自委託人取得表明不將調查結果用於犯罪、歧視等違法目的之書面（第7條）。

| 場面 | 根據 | 主要記載事項 |
| --- | --- | --- |
| 締約前（重要事項說明） | 第8條第1項 | 商號、住所、受理申報的公安委員會名稱、守密事項、業務內容、有無委託、對價概算額與支付時期、契約解除、資料處分 |
| 締約後（明示契約內容） | 第8條第2項 | 承辦人姓名與締約年月日、調查之內容、期間、方法、報告之方法、期限、對價之額、支付時期、方法、解除與資料處分之約定 |
| 委託人之書面 | 第7條 | 確認不將結果用於違法目的 |

執行偵探業務時，不得有害人之生活平穩等侵害個人權利利益之情形，且其他法令禁止、限制之行為，不因本法而獲解除（第6條）。又，將偵探業務之全部、一部委託予非偵探業者，係遭禁止；且於知悉結果將用於違法行為時，不得執行該業務（第9條）。費用概估另定於本所的[報酬額表](https://luck428.com/zh-tw/legal/ryokin)。

## 怠於申報、借名會有哪些罰則與風險？

未申報即經營偵探業（無申報營業），以及以自己名義使他人經營偵探業（借名），均設有罰則。借名於第5條明文禁止，無申報營業與借名均處6個月以下拘禁刑或30萬日圓以下罰金（第18條）。

| 行為 | 根據 | 罰則 |
| --- | --- | --- |
| 無申報經營偵探業 | 違反第4條第1項 | 6個月以下拘禁刑或30萬日圓以下罰金（第18條） |
| 借名 | 違反第5條 | 6個月以下拘禁刑或30萬日圓以下罰金（第18條） |
| 違反業務執行規制、虛偽申報等 | 各規定 | 得成為營業停止、廢止命令（第15條）或罰則對象 |

怠於確認欠格事由即申報，日後可能成為處分對象。與古物商許可等其他營業並行時，因根據法與監督官廳不同，須分別確認。古物商整理於[古物商許可的營業所要件](https://luck428.com/zh-tw/legal/column/kobutsusho-kyoka-eigyosho-yoken)，警備業整理於[警備業認定的要件、欠格、教育](https://luck428.com/zh-tw/legal/column/keibigyo-nintei-yoken-kekkaku-kenshu)。警備業為「認定」、偵探業為「申報」，是制度上的一大差異。

## 調查將逾越合法範圍時，應轉介給誰？

即使已完成偵探業申報，尾行、埋伏、探詢若過度，仍可能觸及跟蹤騷擾規制法、名譽毀損、隱私侵害等。此屬違法、紛爭領域，非行政書士承辦範圍。相關專業人士以各自獨立的事業體分別簽約為基本。

| 委託對象 | 主要角色 |
| --- | --- |
| 行政書士（本所） | 偵探業開始申報書的作成與向公安委員會提出的支援、欠格事由確認的整理 |
| 律師 | 違反跟蹤騷擾規制法、名譽毀損、隱私侵害等違法、紛爭的對應，法律效果的最終判斷 |
| 不動產業者（不同事業體的本公司） | 作為營業所的物件尋找與租賃契約 |
| 公安委員會、警察署 | 申報的受理，標識、名簿等的指導 |

尾行、埋伏等可能逾越合法範圍的業務，以及委託本身疑為違法目的的調查，本所不予承辦。本所與各專業人士以獨立的事業體簽約，相互不收取介紹費。個別受理可否或合法性的最終判斷，由資格者、公安委員會於面談後進行。

## 常見問題

**Q. 偵探業是取得許可後才開始嗎？**
A. 不是。偵探業並非許可制，而是申報制。依偵探業法第4條，於開始營業的前一日前，須就各營業所向管轄其所在地的公安委員會（經由管轄警察署防犯係）提出申報書，不收申報手續費。這並非等待許可審查的制度，但不該當欠格事由、履行書面交付等義務仍為前提。

**Q. 可以用自宅作為營業所開業嗎？**
A. 須就各營業所申報，惟以自宅為營業所本身是可行的。管轄依營業所所在地而定。須在營業所明顯處揭示表明已申報的標識，並備置從業者名簿（第12條）。過去的偵探業申報證明書已於2024年（令和6年）4月1日施行的修正中廢止，改為揭示標識。

**Q. 未申報即開始偵探業會如何？**
A. 未申報即經營偵探業者，處6個月以下拘禁刑或30萬日圓以下罰金（第18條）。以自己名義使他人經營的借名，亦依第5條禁止，處相同罰則。申報須於開始營業的前一日前完成。

**Q. 行政書士能承辦到什麼程度？**
A. 行政書士以獨立的事業體承辦偵探業開始申報書的作成、向公安委員會提出的支援，以及欠格事由確認的整理。尾行、埋伏過度時的違反跟蹤騷擾規制法、名譽毀損、隱私侵害等違法、紛爭的對應屬律師，營業所的物件與租賃屬不同事業體的不動產業者領域，各自分別簽約。
