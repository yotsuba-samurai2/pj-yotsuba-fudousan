**結論（先講重點）**：隨著技能實習轉為育成就勞，現行的「監理團體」不會自動滑移為「監理支援機關」，必須重新取得監理支援機關的許可（出入國在留管理廳「育成就勞制度Q&A」Q33）。制度施行日為2027年（令和9年）4月1日，依據為育成就勞相關的修正法（令和6年法律第60號）。為了不必等到施行即可推進，監理支援機關許可的施行日前申請自令和8年4月15日起、育成就勞（監理型）計畫認定的施行日前申請自令和8年9月1日起受理（申請處為外國人技能實習機構本部審查課分室）。取得許可者，被視為已取得技能實習制度的一般監理事業許可（同Q&A Q39）。許可申請與計畫認定的文件製作支援，屬申請取次行政書士的業務範圍；勞動條件、就業規則、社會保險、薪資的設計屬社會保險勞務士；勞資糾紛屬律師，各自作為獨立的事業體、分別簽約。四葉社會保險勞務士事務所與本所為別事業體。由於施行日與過渡措施可能有變更或追加的運用資訊，本文僅限於可查證的範圍，並指出最新的確認處。本文為一般性資訊提供，不判定或保證個別許可的可否。本所不收取介紹費。

## 轉為育成就勞後，技能實習的監理團體立場會怎麼變？

育成就勞是以確保與培育人才為目的，取代技能實習而新設的受入框架。依據為育成就勞相關的修正法（令和6年法律第60號，令和6年6月21日公布），修正了技能實習的適正實施及技能實習生保護相關法律等。受入的在留資格，置於出入國管理及難民認定法的別表第一之中。

在技能實習中監理受入團體的「監理團體」所相當的角色，於育成就勞由「監理支援機關」承擔。這不只是改名，而是許可的框架本身切換為新制度。出入國在留管理廳的說明中，制度的運用開始（施行日）為2027年（令和9年）4月1日。因此，出發點在於：技能實習的監理團體，無法在施行日後直接以監理支援機關的身分繼續業務。與登錄支援機關（特定技能的支援委託對象）角色的差異，整理於[登錄支援機關的登錄與支援計畫](https://luck428.com/legal/column/toroku-shien-kikan-touroku-shien-keikaku)。

## 需要重新取得監理支援機關的許可嗎？有過渡措施嗎？

是的，必須重新取得許可。出入國在留管理廳「育成就勞制度Q&A」Q33說明，監理團體若要進行育成就勞相關業務，必須重新取得監理支援機關的許可。資格並不會自動承接。

另一方面，也示有避免跨施行空窗的處理。同Q&A Q39說明，取得監理支援機關許可者，被視為已取得技能實習制度的一般監理事業許可，就監理團體許可的有效期間，不需另行更新。

| 項目 | 內容（出入國在留管理廳的說明） |
| --- | --- |
| 施行日 | 2027年（令和9年）4月1日 |
| 監理支援機關許可的施行日前申請 | 自令和8年4月15日起受理（申請處＝外國人技能實習機構本部審查課分室） |
| 育成就勞（監理型）計畫認定的施行日前申請 | 自令和8年9月1日起受理 |
| 現行監理團體的處理 | 不自動移行，須重新取得監理支援機關許可（Q33） |
| 取得許可者 | 視為已取得技能實習的一般監理事業許可（Q39） |

施行日前申請的受理期間，以及自申請至業務開始所需期間的概估，可能隨運用更新而變動。考慮申請時，請務必於下述官方頁面確認最新的受理狀況。

## 育成就勞（受入）計畫的認定要審查什麼？

在育成就勞中，就受入機關（企業等）作成的育成就勞計畫，設有認定的機制，相當於技能實習中的技能實習計畫認定的定位。計畫認定預期會審查受入適正進行的前提，例如育成對象的分野、業務、育成期間與目標、受入體制、報酬等。又，要取得監理型計畫的認定，以監理支援機關的許可（含施行日前申請）為前提的關係，亦有說明。

不過，認定的審查項目、基準細目與樣式，部分有待施行相關的運用要領具體化，須在已確定、公表的範圍內確認。本文以一手資訊可確認的範圍，示出審查的大框架（設有計畫認定制度、並與監理支援機關許可連動），個別的基準數值與樣式細目則委由最新的公表資料。就建立雇用外國人的企業體制此一觀點，整理在留資格與公司運作論點的[經營、管理在留資格與公司設立](https://luck428.com/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)亦可參考。

## 入管許可（行政書士）與勞務、社會保險（勞務士）的角色如何劃分？

育成就勞的受入準備，重疊了性質不同的手續：許可、執照（入管相關）與勞務（勞動、社會保險相關）。在四葉，依下列方式作為獨立的事業體、分別簽約後分開委託。

| 分野 | 負責者（各自作為獨立的事業體、分別簽約） |
| --- | --- |
| 監理支援機關許可申請、育成就勞計畫認定申請的文件製作支援，以及在留資格的申請取次 | 申請取次行政書士 |
| 勞動條件明示、就業規則、薪資規程、36協定等的整備 | 社會保險勞務士（四葉社會保險勞務士事務所為別事業體） |
| 社會保險、勞動保險的適用、手續 | 社會保險勞務士 |
| 勞資之間、個別勞動關係糾紛的協商、訴訟 | 律師 |

行政書士負責的是入管相關的申請取次，以及許可、認定申請文件製作的支援。基於入管法令的申請取次，是在已提出申請取次申報的行政書士可為的範圍。相對地，勞動條件與社會保險的設計、手續屬社會保險勞務士，勞資糾紛的代理屬律師業務，行政書士不辦理。受任流程見[受任流程](https://luck428.com/legal/nagare)，費用見[報酬額表](https://luck428.com/legal/ryokin)，對應業務全貌見[取扱業務](https://luck428.com/legal/services)。四葉社會保險勞務士事務所與本所為別事業體，各專業人員各自獨立簽約。本所不收取介紹費。

## 常見問題

**Q. 現在的監理團體可以直接成為監理支援機關嗎？**
A. 無法直接移行。出入國在留管理廳「育成就勞制度Q&A」Q33說明，要進行育成就勞相關業務，須重新取得監理支援機關的許可。不過，取得許可後，被視為已取得技能實習的一般監理事業許可，就監理團體的許可不需另行更新（Q39）。

**Q. 施行日是何時？施行前可以申請嗎？**
A. 制度施行日為2027年（令和9年）4月1日。為不必等到施行即可推進，監理支援機關許可的施行日前申請自令和8年4月15日起、育成就勞（監理型）計畫認定的施行日前申請自令和8年9月1日起受理（申請處為外國人技能實習機構本部審查課分室）。受理期間可能變動，申請前請於機構的說明確認最新狀況。

**Q. 許可申請或計畫認定可以委託行政書士嗎？**
A. 申請文件製作的支援，以及在留資格的申請取次，屬已提出申請取次申報的行政書士業務範圍。另一方面，就業規則、薪資、社會保險等勞務設計屬社會保險勞務士，勞資糾紛的代理屬律師業務。各自作為獨立的事業體、分別簽約。

**Q. 可以請你們判斷個別受入的許可、認定是否會通過嗎？**
A. 本文為一般性資訊提供，不判定或保證個別許可、認定的可否。審查基準與樣式部分有待運用要領具體化，請以已確定、公表的最新資料，並視需要以有資格者的確認為前提判斷。
