**結論（先講重點）**：認證是「可進行特定整備」的資格，指定（民間車檢場）是由自家汽車檢查員檢查並核發保安基準適合證的資格。指定以取得認證為前提，另外加上完成檢查場等設備與汽車檢查員的選任。

**資訊確認日：2026年10月12日**。本文寫給營運特定整備認證工廠、想升級為指定汽車整備事業（民間車檢場）並自行檢查的業者，整理與認證的差異及設備、人員要件。認證本身的流程請見[汽車特定整備的認證申請](https://luck428.com/legal/column/jidosha-tokutei-seibi-ninsho-shinsei-nagare-youken)。

## 認證工廠與指定工廠（民間車檢場）有何不同？

依據為道路運送車輛法（昭和26年法律第185號）。認證與指定是不同處分，取得順序與角色皆不同。

| | 認證（認證工廠） | 指定（指定工廠・民間車檢場） |
| --- | --- | --- |
| 依據 | 第78條第1項 | 第94條之2第1項 |
| 取得內容 | 地方運輸局長的認證 | 地方運輸局長的指定（須先有認證） |
| 可做事項 | 特定整備（點檢・整備） | 另可自行檢查並核發保安基準適合證 |
| 車檢時的現車 | 須將車輛送至運輸支局等檢查場 | 提交保安基準適合證可省略現車提示 |

特定整備在2020年（令和2年）4月1日由原本的分解整備擴大範圍，加入與自動駕駛相關的電子控制裝置整備。認證是進行此特定整備的資格，指定則由認證工廠中符合一定基準者申請取得。

## 取得指定後，自家可做到什麼程度？

指定工廠對於由汽車檢查員檢查、確認符合保安基準的車輛，可核發保安基準適合證與保安基準適合標章（第94條之5）。將該證提交運輸支局・汽車檢查登錄事務所等，即可在續檢等時省略向國家檢查場提示現車。

但這並非「國家把檢查權限移轉給民間」。指定是將部分檢查委由民間辦理的制度，須在國家稽核、對應受臨時檢查車輛的核發限制等框架內運作。保安基準適合證與標章附有有效期間（第94條之5第6項），天數請以最新的運輸局說明確認。

## 設備、工員、汽車檢查員的要件為何？

依國土交通省說明，指定除取得認證外，另需下列事項。具體尺寸與機器清單請以告示、規則及主管運輸局最新說明確認。

| 區分 | 主要內容 |
| --- | --- |
| 設備・技術・管理組織 | 符合優良汽車整備事業者認定規則所定水準 |
| 檢查設備 | 具備指定汽車整備事業規則所定檢查設備 |
| 設施 | 室內作業場外，另需車輛置場與完成檢查場 |
| 工員 | 4人以上（處理大型車時依條件需5人以上）；其中3分之1以上須持汽車整備士資格 |
| 汽車檢查員 | 依第94條之4於各事業場選任；須有整備主任者1年以上實務經驗並修畢教習（1級汽車整備士為6個月以上） |

大型車指車輛總重量8公噸以上、最大載重量5公噸以上，或乘車定員30人以上的車輛。汽車檢查員的選任・變更須於15日內向地方運輸局長申報（第94條之4第3項）。資格要件細節請以最新的國家考試與教習說明確認。

## 指定申請向誰提出、需要哪些文件？

| 項目 | 內容 |
| --- | --- |
| 提出對象 | 事業場所在都道府縣的運輸支局 |
| 審查流程 | 運輸支局形式審查 → 地方運輸局內容審查 → 地方運輸局長決定指定 |
| 標準處理期間 | 依國土交通省說明，自申請至決定約45日 |

申請書須附設備明細、檢查機器、汽車檢查員選任、管理組織等文件。表格、附件與規費以主管運輸局最新說明為準。上表並非適用於所有事業場的固定文件清單。

## 取得指定後須遵守哪些義務？（適正化・帳簿・保安基準適合證）

取得指定後，須持續適正地執行檢查、整備記錄與帳簿、適正核發保安基準適合證。汽車檢查員若有不正行為，地方運輸局長可命令解任（第94條之4第4項），自解任起2年內不得擔任檢查員（同條第5項）。指定本身在不再符合基準時亦可能被撤銷等。

| 委任對象 | 負責範圍 |
| --- | --- |
| 四葉行政書士事務所 | 指定申請文件製作與手續說明 |
| 地方運輸局・運輸支局 | 汽車檢查員選任要件之確認、指定審查 |
| 設備業者 | 檢查用機器・完成檢查場・建物之設置 |
| 司法書士 | 法人之設立・變更登記 |
| 四葉社會保險勞務士事務所 | 檢查員之加班・班表等勞務 |

四葉行政書士事務所、四葉社會保險勞務士事務所、四葉不動産株式会社各為不同事業體，皆以獨立的事業體受任。請與各領域負責人分別簽約，由各受任者直接請款與收款。本事務所不收取介紹費。運輸局・運輸支局為行政手續窗口，並非受任契約的對象。

## 常見問題

**Q. 已有認證，是否就不需要指定？**
A. 認證是進行特定整備的資格，指定是自行檢查並核發適合證的資格。若要自行檢查並省略現車提示即需指定，認證則為其前提。

**Q. 取得指定後是否就不必前往國家檢查場？**
A. 提交保安基準適合證即可在續檢等時省略現車提示。但須在國家稽核、臨時檢查及核發限制等框架內運作，並非所有檢查權限皆移轉。

**Q. 任何人都能擔任汽車檢查員嗎？**
A. 須有整備主任者1年以上實務經驗並修畢教習（1級汽車整備士為6個月以上）等要件，於各事業場選任並向地方運輸局長申報。細節請以最新國家考試與教習說明確認。

**Q. 指定申請向哪裡提出、需時多久？**
A. 向事業場所在的運輸支局提出，經運輸支局形式審查與地方運輸局內容審查後，由地方運輸局長決定。依國土交通省說明，自申請至決定約45日。
