**結論（先講重點）**：就勞繼續支援是身心障礙者總合支援法（平成17年法律第123號）第5條第15項所定之身心障礙福祉服務，對於難以在一般事業所受僱之身心障礙者，提供就勞機會與生產活動機會，支援其提升工作所需之知識與能力。最大差異在於：A型提供基於僱用契約之就勞機會，B型提供不基於僱用契約之生產活動機會。開辦事業須就各事業所，向都道府縣知事（指定都市・中核市為市長）取得指定身心障礙福祉服務事業者之指定（同法第36條）。人員・設備・營運基準依同法第43條，由國家基準即平成18年厚生勞働省令第171號與各自治體條例具體定之。指定可否與是否符合基準由指定權者審查決定，本事務所不保證指定。

## 就勞繼續支援A型與B型，指定要件有何不同？

就勞繼續支援於身心障礙者總合支援法第5條第15項定義，提供就勞機會，並透過生產活動等機會之提供，供與提升工作所需知識・能力之訓練等便宜。A型・B型之區分並非法律定義本身，而是由平成18年厚生勞働省令第171號（指定身心障礙福祉服務之事業等人員、設備及營運相關基準）所定。兩者最大差異為「是否與利用者簽訂僱用契約」。

| 區分 | 就勞繼續支援A型 | 就勞繼續支援B型 |
| --- | --- | --- |
| 與利用者之關係 | 簽訂僱用契約 | 不簽僱用契約 |
| 支付 | 工資（適用最低工資法） | 工酬（依成果支付） |
| 主要對象 | 有一定支援即可持續就勞者 | 難以基於僱用契約就勞者 |
| 生產活動收支 | 生產活動收入扣除必要經費後之額，須達工資總額以上 | 工酬之平均額原則不低於月額3,000日圓 |

A型因與利用者簽訂僱用契約，適用勞動基準法與最低工資法。就勞實態是否屬勞工、工時・工資・工作規則如何設計，屬社會保險勞務士領域，與本公司・本事務所為獨立的事業體，各自個別簽約。B型不基於僱用契約，依生產活動成果支付工酬，其平均額由營運基準定為原則不低於月額3,000日圓（平成18年厚生勞働省令第171號）。

又，2025年（令和7年）10月1日新設「就勞選擇支援」（身心障礙者總合支援法第5條第13項），新利用B型者原則須於申請前先利用就勞選擇支援，正分階段移行。對象與施行時期請以自治體之運用確認。

## 指定所需人員基準（服務管理責任者・職業指導員・生活支援員）須幾人？

人員基準由平成18年厚生勞働省令第171號所定，並由自治體條例具體化。A型・B型共通之基本配置如下。

| 職種 | 配置思考方式 |
| --- | --- |
| 職業指導員・生活支援員 | 總數以常勤換算方法為利用者數除以十以上（10比1）；職業指導員1人以上、生活支援員1人以上，其中1人以上為常勤 |
| 服務管理責任者 | 利用者60人以下1人以上；61人以上每40人（含端數）加1人；其中1人以上為常勤 |
| 管理者 | 原則專從常勤1人（無妨礙時得兼任） |

職業指導員・生活支援員之總數，A型於同省令第186條、B型於同省令第199條定為「以常勤換算方法為利用者數除以十以上」。B型於一定要件下有更手厚之配置（7.5比1）而使報酬評價改變之區分，惟此屬報酬告示之區分，指定所需最低基準為10比1。符合人員基準之僱用契約・工時設計・工作規則・社會保險適用屬社會保險勞務士領域，與本公司為獨立的事業體，各自個別簽約。

## 設備・營運基準上，須整備哪些文件與體制？

設備基準（平成18年厚生勞働省令第171號）要求訓練・作業室、諮詢室、洗面所、廁所、多目的室及其他營運上必要之設備。指定原則須利用定員20人以上（多機能型因組合多種服務，處理不同）。物件易不足之處如下。

| 設備・體制 | 主要要求 |
| --- | --- |
| 訓練・作業室 | 不妨礙訓練・作業之寬度；備必要機械器具 |
| 諮詢室 | 得以隔間等顧及隱私 |
| 洗面所・廁所 | 依利用者特性之數量・規格 |
| 營運規程 | 定事業目的・方針、從業者職種・員數、營業日・時間、利用定員等 |
| 個別支援計畫 | 由服務管理責任者作成並定期檢討 |

將事務所・店鋪等既有建物改為事業所時，可能構成建築基準法上之用途變更，或依消防法須追加消防用設備。用途變更確認申請之要否・設計屬建築士（設計者），消防用設備之要否與消防同意屬消防署之判斷。用途地域・面積之一次確認由不動產公司擔任，本公司僅提供物件資訊，不判斷建築確認或消防可否。相關類型之指定，另請參見[生活介護之指定申請與物件要件](https://luck428.com/legal/column/seikatsu-kaigo-shitei-bukken-yoken)與[放課後等日間服務・兒童發展支援之指定申請流程](https://luck428.com/legal/column/houkago-day-jido-hattatsu-shitei-shinsei-nagare)。

## 指定申請向何處、依何順序提出？

指定由都道府縣知事（指定都市・中核市為市長）就各事業所為之（身心障礙者總合支援法第36條第1項）。一般流程如下，順序前後易遭退回，故宜及早開始事前協議。

1. 確立事業計畫・資金計畫，設立法人（於章程事業目的加入身心障礙福祉服務）
2. 選定物件，確認符合設備基準・建築基準法・消防法
3. 與指定權者進行事前協議
4. 確保服務管理責任者・職業指導員・生活支援員
5. 作成申請書與附件並於截止前提出
6. 書面審查，必要時現地確認
7. 指定（多數自治體為每月1日付）

多數自治體以每月1日付指定，申請書提出期限一般設於指定希望日之前月或前前月。截止依指定權者而異，年度更替時亦可能提前，故務必於該自治體公式頁面確認。代表性文件為指定申請書與附表、法人登記事項證明書・章程、事業所平面圖・照片・租賃契約書等、營運規程、從業者勤務形態一覽表與資格證・實務經驗證明、服務管理責任者研修等修了證、收支預算書、各種誓約書等。

四葉行政書士事務所於行政書士業務範圍內，支援指定申請書・附表・附件之作成、事前協議資料整理、營運規程等文案。是否符合基準之最終判斷與指定可否由指定權者審查。

## 指定後之營運指導與報酬請求，最先須掌握什麼？

取得指定後，須維持符合營運基準之紀錄與體制，並成為自治體營運指導之對象。日常備妥服務提供紀錄、個別支援計畫、勤務實績、工酬・工資管理，是減少指導指摘之近路。

報酬（訓練等給付費）由「身心障礙福祉服務等報酬告示」定之，原則向國民健康保險團體聯合會請求。A型採將各事業所之取組點數化評價之計分方式，B型設有依平均工酬月額等之基本報酬區分（均依參照日2026-09-23之告示。區分・加算隨改定變動，請以最新告示確認）。尤其A型，生產活動收入扣除必要經費後之額須達工資總額以上，未達時將被要求提出經營改善計畫。報酬之計算・請求事務與稅務非本事務所業務，會計・稅務請洽稅理士，報酬請求實務請洽事業者或專門之請求代行。

## 物件・建築・勞務・登記・稅務，各應委託何人？

指定申請涉及多個專業領域。分工如下。

- 指定申請書・附表・附件之作成、事前協議支援 → 四葉行政書士事務所（行政書士）
- 事業用物件之選定・租賃・重要事項說明、用途地域・面積一次確認 → 四葉不動產株式會社
- 用途變更確認申請・設計、既存不適格與檢查濟證之確認 → 建築士（設計者）
- 消防用設備要否判斷・消防同意 → 消防署
- 符合人員基準之僱用契約・工作規則・工時管理・社會保險適用，A型利用者之勞工性・最低工資 → 社會保險勞務士
- 法人設立・變更登記 → 司法書士
- 法人會計・稅務・稅額計算、報酬請求所伴隨之經理 → 稅理士
- 涉及權利義務・紛爭之個別法律判斷 → 律師

四葉行政書士事務所與四葉不動產株式會社為別事業體。本公司僅以獨立的事業體承擔指定申請之支援，物件・建築・消防・勞務・登記・稅務與各資格者・窗口個別簽約。本事務所不收取介紹費。全貌見[身心障礙福祉服務之許認可](https://luck428.com/legal/services/shogai-fukushi)；受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)。

## 常見問題

**Q. 同一事業所可同時取得A型與B型指定嗎？**
A. 有以一事業所組合A型與B型之多機能型取得指定之方法。因人員・設備・定員之思考方式與單獨型不同，請以該自治體條例與手引確認。符合人員基準之僱用契約與勞務管理屬社會保險勞務士領域，與本公司為獨立的事業體，各自個別簽約。

**Q. A型支付利用者的是薪水還是工酬？**
A. A型因簽訂僱用契約，支付者為工資，適用最低工資法。工酬為不基於僱用契約之B型所支付。A型利用者之勞工性與最低工資之個別判斷屬社會保險勞務士領域，為別事業體，各自個別簽約。

**Q. 可直接以事務所或店鋪作為事業所嗎？**
A. 除面積・設備外，既有建物可能須用途變更確認申請或追加消防用設備。用途變更判斷向建築士（設計者）、消防用設備要否向消防署確認。物件屬不動產公司、建築確認屬建築士，各為別事業體，各自個別簽約。

**Q. 行政書士做到哪裡？**
A. 於行政書士業務範圍內，支援指定申請書・附表・附件之作成、事前協議資料整理、營運規程等文案。是否符合基準之最終判斷與指定可否由指定權者審查。勞務・登記・稅務・報酬請求請各洽資格者・窗口，以獨立的事業體個別簽約。
