**結論（先講重點）：**寵物（犬、貓等）在日本法律上被視為「物」、無權利能力，故不能將財產留給寵物本身，也不能讓寵物成為遺贈的受遺人或信託的受益人。為被留下的寵物託付照顧，主要有兩種方式。其一為負擔付遺贈：將財產遺贈給照顧寵物的人，並將飼養課為其負擔（民法第1002條）。義務未被履行時，繼承人得為催告，若仍未履行，得向家庭裁判所請求撤銷遺言（民法第1027條）。其二為寵物信託：將財產託付受託人，為受領照顧費用的受益人（照顧者等）管理與給付（信託法第2條、第3條）。無受益人指定的信託（目的信託），僅得以契約或遺言設定，存續期間不得逾20年（信託法第258條、第259條）。本文為一般性資訊，不就個別遺言或契約是否有效作最終判斷。四葉集團的行政書士，以獨立的事業體承辦負擔付遺贈的遺言與信託契約的文案擬訂支援。遺言、信託契約的公正證書化屬公證人，遺留分侵害或受遺人、繼承人間的紛爭屬律師，將不動產納入信託時及死亡後名義變更的登記屬司法書士，繼承稅、受贈益的課稅屬稅理士，繼承不動產的出售、活用屬不同事業體的不動產業者（本公司）領域，各自分別簽約。本所不向任何專業人士收取介紹費。

## 不能把財產直接留給寵物嗎？有哪些機制可託付照顧？

在日本法律上，寵物被視為「物」、無權利能力。因此，不能將金錢直接留給寵物，也不能讓寵物成為遺言中受領財產的受遺人，或信託中受領利益的受益人。能為被留下的寵物做的，是將財產交給「照顧牠的人」，同時將飼養的義務或目的與之結合的設計。

| 機制 | 財產交給誰 | 根據 |
| --- | --- | --- |
| 負擔付遺贈 | 遺贈給照顧的人（受遺人），以飼養為負擔 | 民法第1002條 |
| 寵物信託 | 託付受託人，為受益人（照顧者等）給付 | 信託法第2條、第3條 |
| 目的信託（無受益人指定） | 託付受託人，為飼養之目的而管理 | 信託法第258條（存續期間20年、第259條） |

遺言自遺言人死亡之時起生效（民法第985條）。亦即遺言的安排在身故後方才運作，故對於住院、入住機構等生前的局面，須與其他機制組合以為準備。託付生前事務的選項，與單身者的[死後事務委任契約的基本](https://luck428.com/zh-tw/legal/column/shigojimu-inin-keiyaku-ohitorisama)及任意後見一併考量，較易整理。遺言、契約的文案擬訂支援，亦見於本所的[繼承、遺言介紹](https://luck428.com/zh-tw/legal/services/inheritance)。

## 負擔付遺贈與「寵物信託」有何不同？

兩者將「受到照顧」與財產結合這一點相同，但金錢被管理的方式，以及使約定被遵守的機制不同。

| 觀點 | 負擔付遺贈 | 寵物信託 |
| --- | --- | --- |
| 機制 | 將財產遺贈給受遺人，以飼養為負擔 | 將財產託付受託人，給付飼養費 |
| 財產管理 | 受遺人作為自己的財產管理 | 作為信託財產由受託人分別管理 |
| 開始時期 | 遺言人死亡後（遺言） | 契約則自生前起，遺言則死亡後 |
| 使之遵守的手段 | 未履行時向家裁請求撤銷遺言（民法第1027條） | 以信託之約定、信託監督人、受益人代理人等監督 |
| 根據 | 民法第1002條 | 信託法第2條、第3條 |

受負擔付遺贈之人，僅於不超過遺贈目的價額之限度內負飼養義務（民法第1002條第1項）。受遺人拋棄遺贈時，應受負擔利益之人得自為受遺人（同條第2項）。信託則將財產切分為信託財產交由受託人管理，具有飼養費較不致被捲入受託人個人債務或繼承的優點。以家人為受託人的設計全貌，亦請見[家族信託的行政書士角色與組成](https://luck428.com/zh-tw/legal/column/kazoku-shintaku-gyosei-yakuwari-kumisei)。

## 要如何書寫，才能使照顧者（受遺人、受託人）遵守飼養？

要點在於具體書明「由誰、照顧哪隻寵物、如何照顧」，並將未被遵守時的手當也一併訂明。負擔付遺贈中，將飼養的內容明記為負擔，並設想未履行時的對應。

| 應書寫之事項 | 具體例 |
| --- | --- |
| 對象寵物 | 特定個體（名字、種類、特徵、登記號碼等） |
| 飼養的內容 | 居住環境、就診、疫苗、食餌、送終的方針 |
| 受遺人、受託人 | 承接之人，及不承接時的次順位 |
| 監督的機制 | 指定遺言執行人、信託監督人、受益人代理人 |
| 不履行時 | 負擔付遺贈為履行的催告與撤銷遺言之請求（民法第1027條） |

負擔付遺贈的受遺人未盡飼養義務時，繼承人得定相當期間催告履行，屆期仍未履行者，得向家庭裁判所請求撤銷該負擔付遺贈所涉之遺言（民法第1027條）。信託中，為使受益人年邁、不在時監督仍能運作，實務上會設置信託監督人或受益人代理人。此等文案擬訂由行政書士支援，惟個別有效性的最終判斷由資格者進行。進行方式請見[受任流程](https://luck428.com/zh-tw/legal/nagare)。

## 飼養費多少、如何交付較實際，餘下的財產如何處理？

飼養費以寵物的平均餘命、醫療費、照顧的對價估算而定。交付方式上，負擔付遺贈可一次遺贈，信託則可設計為於必要時分次給付。

| 項目 | 考量方式 |
| --- | --- |
| 金額之估算 | 平均餘命×年間食餌、醫療、照顧費用，再加預備 |
| 交付（遺贈） | 一次遺贈給受遺人，以飼養為負擔 |
| 交付（信託） | 受託人管理，於必要時期作為飼養費給付 |
| 餘剩之處理 | 預先訂明寵物死亡後殘餘財產的歸屬 |
| 對價 | 亦可就照顧的勞費另訂謝禮 |

為因應寵物身故後信託財產或遺贈財產尚有餘剩，須預先訂明殘餘的歸屬（其他人或團體等）。使用目的信託（無受益人指定的信託）時，須留意存續期間不得逾20年的限制（信託法第259條）。金額與交付方式亦影響繼承人的遺留分與課稅，故須與稅理士、律師分擔角色而檢討。本所費用的概估另定於[報酬額表](https://luck428.com/zh-tw/legal/ryokin)。

## 作成公正證書的意義，以及遺言執行人、信託監督人的角色為何？

將遺言或信託契約作成公正證書，較不致因方式瑕疵而無效，原本由公證役場保管，遺失、竄改之虞甚小。將負擔付遺贈作成公正證書遺言，則死亡後家庭裁判所的檢認亦不要。公正證書遺言的作成方式與公證人手續費，整理於[公正證書遺言的作成方式、證人、手續費](https://luck428.com/zh-tw/legal/column/kosei-shosho-yuigon-koshonin-shonin-hiyo)。

| 角色 | 內容 |
| --- | --- |
| 公證人 | 遺言、信託契約的公正證書化（作成、原本保管） |
| 遺言執行人 | 實現遺言內容（向受遺人交付、看顧飼養等） |
| 信託監督人 | 為受益人監督受託人（信託法） |
| 受益人代理人 | 代受益人行使權利（信託法） |

作為見證飼養是否被持續的機制，遺言可置遺言執行人，信託可置信託監督人或受益人代理人，較為安心。此等指定與文案擬訂由行政書士支援，公正證書化由公證人進行。要選信託契約或遺言，或兩者併用，須與生前的準備（任意後見、死後事務委任）一併設計。

## 遺留分、繼承稅、登記方面，該向律師、司法書士、稅理士委請什麼？

為寵物所做的手當，易形成將較多財產交給特定人的設計，故涉及其他繼承人的遺留分、課稅，若有不動產則涉及登記。相關專業人士以各自獨立的事業體分別簽約為基本。

| 委託對象 | 主要角色 |
| --- | --- |
| 行政書士（本所） | 負擔付遺贈的遺言、信託契約的文案擬訂支援 |
| 公證人 | 遺言、信託契約的公正證書化 |
| 律師 | 遺留分侵害額的請求（民法第1046條）、受遺人、繼承人間的紛爭、法律效果的最終判斷 |
| 司法書士 | 將不動產納入信託時的信託登記、死亡後名義變更的登記 |
| 稅理士 | 繼承稅、受贈益課稅的試算 |
| 不動產業者（不同事業體的本公司） | 繼承不動產的出售、活用諮詢 |

財產的交付方式若侵害其他繼承人的遺留分，則發生遺留分侵害額相當之金錢支付請求（民法第1046條），此屬律師領域。將不動產納入信託財產時須為信託登記，由司法書士承辦。涉及繼承不動產出售時，亦可利用不同事業體的不動產業者所設[繼承不動產諮詢窗口](https://luck428.com/zh-tw/souzoku)。本所與各專業人士以獨立的事業體簽約，相互不收取介紹費。個別有效性或課稅的最終判斷，由資格者於面談後進行。

## 常見問題

**Q. 可以把金錢直接留給寵物嗎？**
A. 不可以。寵物在法律上為「物」、無權利能力，故不能將財產留給寵物本身，也不能使其成為遺贈或信託的受益人。被留下寵物的照顧，透過將財產交給照顧者並課以飼養的負擔付遺贈（民法第1002條），或將財產託付受託人的寵物信託（信託法第2條、第3條）來託付。

**Q. 負擔付遺贈與寵物信託，哪個較安心？**
A. 無法一概而論。負擔付遺贈以遺言完結、較簡便，但金錢作為受遺人的財產管理，使之遵守的手段為履行的催告與撤銷遺言之請求（民法第1027條）。信託可將財產作為信託財產分別管理、以信託監督人等持續監督，惟組成較費工夫。須依家庭構成與財產而選擇。

**Q. 寵物身故後餘下的錢會如何？**
A. 須預先訂明殘餘財產的歸屬。無約定時，依繼承或信託清算的規律處理。使用無受益人指定的目的信託時，亦須留意存續期間不得逾20年的限制（信託法第259條）而設計。

**Q. 遺留分與繼承稅該如何考量？**
A. 將較多財產交給特定人，可能發生其他繼承人的遺留分侵害額請求（民法第1046條），此屬律師領域。繼承稅、受贈益的課稅屬稅理士，將不動產納入信託時的登記屬司法書士。行政書士支援文案擬訂，與各專業人士以獨立的事業體分別簽約。
