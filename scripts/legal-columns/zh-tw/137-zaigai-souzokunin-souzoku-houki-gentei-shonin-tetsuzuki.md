**結論（先講重點）**：住在海外的繼承人，也能向日本的家庭裁判所申述繼承拋棄、限定承認（亦可郵寄）。熟慮期間為「自知悉自己已有繼承開始之時起3個月」（民法第915條第1項），申述先為管轄被繼承人最後住所地的家庭裁判所。

**資料確認日：2026年10月27日**。本文面向住在台灣、中國本土等地的繼承人、在日本一方而有在外繼承人的家屬，以及現地的專門職，聚焦於自海外辦理日本繼承拋棄、限定承認的步驟，以及3個月熟慮期間的起算。拋棄、限定承認的基礎請見[繼承拋棄、限定承認的基礎](https://luck428.com/zh-tw/legal/column/souzoku-hoki-gentei-shonin)；涉及海外、外國籍之繼承的全貌請見[涉及海外、外國籍的繼承](https://luck428.com/zh-tw/legal/column/souzoku-kaigai-gaikokuseki)；期間的起算與伸長請見[熟慮期間的起算點與伸長](https://luck428.com/zh-tw/legal/column/souzoku-hoki-jukuryo-kikan-shincho-kisanten)。條文以[e-Gov法令檢索](https://laws.e-gov.go.jp/)核對。

## 住在海外也能拋棄日本的繼承嗎？

能拋棄。繼承拋棄係就被繼承人（亡者）之繼承向家庭裁判所提出之手續，與繼承人住在何處無關。民法第938條規定「欲拋棄繼承之人，須將其意旨向家庭裁判所申述」。拋棄繼承之人，就該繼承而言，視為自始未為繼承人（民法第939條）。因此一經拋棄，繼承權即移轉予次順位繼承人（例如子女全部拋棄則移至父母，父母亦無則移至兄弟姊妹）。

若欲受領部分遺產、同時防範債務超過的風險，尚有限定承認之選擇。民法第922條規定，繼承人得保留僅於因繼承所得財產之限度內清償被繼承人之債務及遺贈而為承認；繼承人有數人時，限定承認須由共同繼承人全體共同為之（民法第923條）。欲為限定承認，須於熟慮期間內製作遺產目錄向家庭裁判所提出，並申述限定承認之意旨（民法第924條）。

申述先為管轄繼承開始地的家庭裁判所。家事事件手續法第201條第1項規定，關於繼承之承認及拋棄的審判事件，屬「管轄繼承開始地之家庭裁判所」之管轄，而繼承於被繼承人之住所開始（民法第882條、第883條）。亦即，向管轄被繼承人最後住所地之家庭裁判所申述。在外繼承人得以郵寄申述書及附件之方式提出（因往來聯絡係以郵件為之，宜預估國際郵件之時間而及早行動）。

| 選項 | 內容 | 主要依據 |
| --- | --- | --- |
| 單純承認 | 承繼全部權利與義務（債務） | 民法第920條 |
| 限定承認 | 僅於所得財產之限度內清償債務；全體繼承人共同申述並提出遺產目錄 | 民法第922條、第923條、第924條 |
| 繼承拋棄 | 視為自始未為繼承人，移轉予次順位 | 民法第938條、第939條 |

## 3個月的熟慮期間從何時起算？可以伸長嗎？

起算日為「自知悉自己已有繼承開始之時」。民法第915條第1項規定，繼承人須自知悉自己已有繼承開始之時起3個月以內，為單純承認、限定承認或拋棄之一。重點在於非自死亡之日起算，而是自「知悉自己已成為繼承人之時」起算。住在海外而訃聞遲到者，或因先順位繼承人拋棄而成為繼承人之次順位者，其起算點為知悉該事實之時。

於期間內無法判斷時，得聲請伸長期間。民法第915條第1項但書規定，此期間「得因利害關係人或檢察官之請求，由家庭裁判所伸長之」。在外繼承，調查國外財產、債務，或取得戶籍、公證書等需時之情形，可考慮於熟慮期間內向家庭裁判所聲請伸長。又繼承人於承認或拋棄前，得調查遺產（民法第915條第2項）。

| 項目 | 內容 |
| --- | --- |
| 熟慮期間 | 自知悉自己已有繼承開始之時起3個月（民法第915條第1項） |
| 起算的觀念 | 非死亡日，而係「知悉自己已成為繼承人之時」 |
| 伸長 | 於期間內向家庭裁判所聲請伸長（同項但書） |
| 遺產調查 | 於承認、拋棄前得調查（同條第2項） |

關於起算點，可能見解分歧，個別的起算日與伸長之可否，請於聲請前向管轄之家庭裁判所與有資格者確認。

## 申述所需書件（台灣戶籍、在外公館之證明）由誰蒐集？

共通須備者為：記載被繼承人死亡之戶籍（除籍、改製原戶籍）謄本、被繼承人之住民票除票或戶籍附票、申述人（拋棄之人）之戶籍謄本。依續親（配偶、子女、父母、兄弟姊妹）而所需戶籍之範圍不同，第二順位以後可能須備被繼承人自出生至死亡之戶籍。費用為每一申述人收入印紙800日圓及聯絡用郵票，郵票金額依裁判所而異（參照日2026-10-27，裁判所「繼承拋棄之申述」）。

在外繼承特有者為於國外製作之本人確認文件。於日本無住所、無印鑑登錄之繼承人，有以在外公館（日本國大使館、總領事館）之簽名（簽署）證明代替印鑑證明之情形。繼承人為外國籍、外國戶籍時，須備各國之身分證明文件，如台灣之戶籍（除戶籍）、中國本土之公證書與領事認證等。因台灣無日本之大使館、領事館，證明實務由公益財團法人日本台灣交流協會（台北、高雄）擔當。中國本土繼承人之親屬關係公證書、領事認證之流程，於[中國本土繼承人之親屬關係公證書與領事認證](https://luck428.com/zh-tw/legal/column/chugoku-tairiku-souzokunin-shinzoku-koshosho-ryoji-ninsho)說明。何種文件於何種手續中被要求、簽名證明是否足夠，依裁判所、個案而異，本文未查證。

行政書士（當方）可協助者為繼承人之確定（戶籍之蒐集、繼承關係之整理）、台灣戶籍、中國公證書等國外書件之蒐集，以及限定承認時向家庭裁判所提出之遺產目錄之製作。申述書本身之製作、提出，如次一節所述，角色有所分工。

| 書件、作業 | 主要擔當 |
| --- | --- |
| 被繼承人、繼承人之戶籍蒐集、繼承人之確定 | 行政書士（當方） |
| 台灣戶籍、中國公證書等國外書件之蒐集 | 行政書士（當方） |
| 限定承認之遺產目錄製作 | 行政書士（當方） |
| 在外公館之簽名證明、各國身分證明 | 由本人於在外公館、現地當局取得 |
| 向家庭裁判所申述書之製作、提出 | 由本人，或作為裁判所提出書件由司法書士 |

## 向家裁之申述、爭執、稅務、登記各由誰擔當？

繼承拋棄、限定承認依作業而擔當者有別。向家庭裁判所之申述由繼承人本人為之，或將裁判所提出書件之製作委託司法書士。就遺產分割或拋棄之效力有爭執時之交涉、調解、代理由律師擔當，繼承稅之評價、申報由稅理士擔當，不動產之繼承登記為司法書士之領域。行政書士（當方）擔當繼承人之確定、國外書件之蒐集、遺產目錄之製作。

| 委託對象 | 負責範圍 |
| --- | --- |
| 四葉行政書士事務所 | 繼承人之確定、戶籍、國外書件之蒐集、限定承認之遺產目錄製作 |
| 本人／司法書士 | 向家庭裁判所申述繼承拋棄、限定承認（裁判所提出書件之製作） |
| 律師 | 就遺產分割、拋棄之效力等有爭執時之交涉、調解、代理 |
| 稅理士 | 繼承稅之評價、申報 |
| 司法書士 | 繼承不動產之名義變更（繼承登記） |

四葉行政書士事務所、四葉社會保險勞務士事務所、四葉不動產株式會社各為不同事業體，均作為獨立的事業體受任。請與各領域的承辦人分別簽約，由各受任者直接請款、收款。本事務所不收取介紹費。

請參閱[繼承手續支援](https://luck428.com/zh-tw/legal/services/inheritance)、[受任流程](https://luck428.com/zh-tw/legal/nagare)、[報酬金額表](https://luck428.com/zh-tw/legal/ryokin)。繼承不動產的出售由另一事業體的[繼承不動產諮詢](https://luck428.com/zh-tw/souzoku)處理，同樣須分別簽約。

## 常見問題

**Q. 住在海外也能拋棄日本的繼承嗎？**
A. 能。繼承拋棄係向管轄被繼承人最後住所地之家庭裁判所申述（民法第938條、家事事件手續法第201條第1項），在外繼承人得以郵寄申述書及附件提出。一經拋棄，視為自始未為繼承人，繼承權移轉予次順位繼承人（民法第939條）。

**Q. 熟慮期間的3個月從何時起算？**
A. 自「知悉自己已有繼承開始之時」起3個月（民法第915條第1項）。非死亡日，而係知悉自己已成為繼承人之時為起算點。住在海外而訃聞遲到者，或因先順位拋棄而成為繼承人之次順位者，自知悉該事實之時起算。得於期間內向家庭裁判所聲請伸長（同項但書）。

**Q. 所需之台灣戶籍、中國公證書由誰蒐集？**
A. 繼承人確定所需戶籍之蒐集、台灣戶籍、中國公證書等國外書件之蒐集，以及限定承認提出之遺產目錄製作，可由行政書士（當方）擔當。在外公館之簽名證明、各國身分證明由繼承人本人於在外公館、現地當局取得。何種文件被要求依裁判所、個案而異，本文未查證，請向管轄之家庭裁判所確認。

**Q. 若繼承人全部在海外，可以限定承認嗎？**
A. 限定承認須由全體繼承人共同申述（民法第923條），於熟慮期間內向家庭裁判所提出遺產目錄（民法第924條）。縱全員在外，備齊國外書件與簽名證明，以郵寄共同申述亦屬可能。全員之步調一致與3個月期限之管理為關鍵，宜及早確定繼承人，必要時考慮伸長期間。
