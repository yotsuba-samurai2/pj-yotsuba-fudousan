**結論（先講重點）**：取得建設業許可的業者，每一個事業年度結束時，都有提交「決算變更申報（事業年度終了申報）」的義務。依據是建設業法第11條第2項，期限為每一事業年度經過後四個月內。這不是可以依申請人方便而省略的手續，即使是沒有工程實績的年度或停業中也必須提交。若漏報，在五年一次的許可更新或業種追加（一般・特定新規等）時，必須將未提交的部分一併補交，否則不予受理；而虛偽記載或長期未提交，可能成為監督處分或罰則的對象。此外，商號、營業所、資本額、董事等的變更須於變更日起30日內申報（建設業法第11條第1項），經營業務的管理負責人或專任技術者更替時則須於兩週內（同條第4項、第5項），期限因手續而異，須留意。本文為一般性資訊提供，並不判斷或保證個別的提交必要性或處分有無。決算變更申報的文件製作與提交由四葉集團的行政書士以獨立的事業體承擔，所附財務報表底稿的稅務申報與決算書製作由稅理士、董事變更・商號變更・本店遷移等登記由司法書士，各自以**獨立的事業體**分別簽約的分離受任方式對應。

## 決算變更申報（事業年度終了申報）要提交什麼、何時提交？

決算變更申報是許可業者依建設業法第11條第2項，於每一事業年度經過後四個月內提交的申報。也稱為「事業年度終了申報」「決算報告」，指的都是同一件事。例如3月結算的法人目標為7月底、12月結算的個人為次年4月底，末日遇到行政廳休息日時的處理方式，請向提交對象確認。

主要提交的文件，是顯示該事業年度的工程實績與決算內容者。內容會因許可行政廳（國土交通大臣許可或都道府縣知事許可）及法人・個人之別而不同，因此以提交對象的手引確認最新樣式為前提。

| 主要文件 | 內容 |
| --- | --- |
| 工程經歷書 | 該事業年度承攬的工程實績（承攬金額・工期等） |
| 前三年各事業年度的工程施工金額 | 依業種別・元請／下請別的施工金額 |
| 財務報表（建設業用） | 資產負債表・損益表等，依建設業法施行規則所定樣式 |
| 事業報告書 | 股份有限公司時需要 |
| 納稅證明書等 | 事業稅等，由行政廳所定 |

即使是沒有工程實績的年度，也須以「無實績」提交；停業中只要維持許可，申報義務仍存續。另請參閱本所的[承辦業務](https://luck428.com/legal/services)・[受任流程](https://luck428.com/legal/nagare)・[報酬額表](https://luck428.com/legal/ryokin)。

## 不提交會對更新與業種追加造成什麼影響？

決算變更申報與其說是獨立完結的手續，不如說是五年一次許可更新，以及業種追加・一般特定新規等下一次申請的基礎文件。受理更新或追加的行政廳，以過去各事業年度的決算變更申報皆已齊備為前提。若有未提交的年度，會先被要求補交該部分；累積起來後，便須在更新時機一口氣製作，產生趕不上期限的風險。

| 場面 | 決算變更申報未提交時會如何 |
| --- | --- |
| 五年一次許可更新 | 不補交未提交的事業年度分，更新申請不予受理 |
| 業種追加・一般特定新規 | 同樣以前一次決算變更申報齊備為前提 |
| 經營事項審查（公共工程投標） | 以提交決算變更申報為前提，未提交則無法進入經審 |
| 虛偽記載・長期未提交 | 可能成為建設業法上的監督處分（指示・營業停止等）或罰則的對象 |

參與公共工程投標的業者，以每年的決算變更申報為基礎，進入經營事項審查（經審）。此流程於[公共工程投標的經營事項審查（經審）要點](https://luck428.com/legal/column/keiei-jiko-shinsa-keishin-nyusatsu-sankaku-shikaku)整理。更新與業種追加所問的經營業務管理負責人・專任技術者・財產基礎等取得時要件，於[建設業許可的要件（經管・專技・財產基礎）全貌](https://luck428.com/legal/column/kensetsugyo-kyoka-yoken-keikan-sengi-zaisan)說明。

## 建設業法上的財務報表與稅務決算書有何不同？

決算變更申報所附的財務報表，與向稅務署提交的確定申報決算書，在樣式與會計科目上都不同。稅務決算書依會計・稅法規則製作，而建設業法的財務報表須依建設業法施行規則所定樣式，改組為「完成工程高」「完成工程原價」「未成工程支出金」「工程未付款」等建設業特有的會計科目。

| 區分 | 稅務決算書 | 建設業法的財務報表 |
| --- | --- | --- |
| 依據 | 法人稅法・所得稅法等 | 建設業法・同施行規則的樣式 |
| 製作的專業人士 | 稅理士（稅務申報的一環） | 行政書士改組為樣式製作（本所） |
| 會計科目 | 一般的銷售・進貨等 | 完成工程高・完成工程原價・未成工程支出金等 |
| 提交對象 | 稅務署 | 建設業的許可行政廳 |

這裡就是分離受任的界線。底稿決算書的製作與稅務申報是稅理士的獨占領域，四葉集團的稅理士以獨立的事業體承擔。將該決算書改組為建設業用樣式，連同工程經歷書等一併作為決算變更申報製作・提交的部分，則由行政書士承擔。稅額與會計處理本身的判斷由稅理士進行，行政書士不涉入稅務判斷。與各專業人士分別簽約，相互間不收取介紹費。

## 董事・商號・營業所變更時，變更申報的期限為何？

與決算變更申報不同，當許可申請書上記載的事項有變更時，須提交「變更申報」。期限依變更種類而分。建設業法第11條第1項規定，商號・名稱、營業所的名稱・所在地、資本額、董事等姓名等（對應建設業法第5條第1號至第4號的事項）有變更時，須於變更日起30日內申報。

另一方面，經營業務的管理負責人，或各營業所的專任技術者更替・退任時，須於兩週內申報（建設業法第11條第4項・第5項）。由於經營業務的管理負責人與專任技術者正是許可要件本身，為避免產生空窗，設有更短的期限。

| 變更內容 | 申報期限 | 依據 |
| --- | --- | --- |
| 商號・名稱、營業所名稱・所在地、資本額、董事等 | 變更日起30日內 | 建設業法第11條第1項 |
| 經營業務管理負責人・專任技術者的更替・退任等 | 變更日起兩週內 | 建設業法第11條第4項・第5項 |
| 各事業年度的決算（決算變更申報） | 每一事業年度經過後四個月內 | 建設業法第11條第2項 |

須留意的是，公司登記上的變更（董事變更・商號變更・本店遷移等）與建設業許可的變更申報是分別的手續。登記由司法書士以獨立的事業體承擔，行政書士再依據該登記承擔建設業許可的變更申報。只做其中一邊並不足夠。

## 為了跑好每年的申報，該請誰做什麼？

建設業許可的維持，關鍵在於不漏掉一年一次的決算變更申報與隨時發生的變更申報。由於涉及的專業人士各異，以各自作為獨立的事業體分別簽約為基本。四葉集團的行政書士，以獨立的事業體承擔向許可行政廳提交決算變更申報・各種變更申報・更新・業種追加等手續。

| 委託對象 | 主要角色 |
| --- | --- |
| 行政書士（本所） | 決算變更申報・變更申報・許可更新・業種追加・經審的申請文件製作與提交 |
| 稅理士 | 決算書製作・法人稅／所得稅・消費稅申報（財務報表的底稿） |
| 司法書士 | 董事變更・商號變更・本店遷移等登記 |
| 不動產業者（別事業體的本公司） | 本店・營業所用物件的選定・租賃媒介・重要事項說明 |

在營業所遷移或新設而須尋找物件的場面，由別事業體的四葉不動產股份有限公司以獨立的事業體承擔物件選定與租賃媒介。稅務・登記・不動產各為獨立的事業體，相互間不收取介紹費。以一個窗口受理諮詢，整理必要手續後，由各有資格者分別簽約對應。

## 常見問題

**Q. 沒有工程實績的年度也需要決算變更申報嗎？**
A. 需要。決算變更申報（事業年度終了申報）只要維持許可，就有在每一事業年度經過後四個月內提交的義務（建設業法第11條第2項）；沒有工程實績的年度以「無實績」提交，停業中只要持有許可也須提交。若漏報，便須在更新或業種追加時一併製作，有趕不上期限之虞。個別必要性請向許可行政廳的手引確認。

**Q. 我累積了好幾年的決算變更申報沒交。許可會被撤銷嗎？**
A. 未提交未必立即導致撤銷，但虛偽記載或長期未提交，可能成為建設業法上監督處分或罰則的對象。實務上，會被要求在更新或業種追加前，將未提交部分一併補交。要整理幾年份、如何整理因情況而異，請儘早向許可行政廳與承擔文件製作的行政書士諮詢。

**Q. 只要委託稅理士做決算，決算變更申報也會幫我交嗎？**
A. 是不同的手續。稅理士製作的是稅務申報用的決算書，但決算變更申報所附的財務報表，須依建設業法施行規則的樣式改組為完成工程高等會計科目，連同工程經歷書等一併向許可行政廳提交。此部分由行政書士以獨立的事業體承擔，稅務判斷由稅理士進行。兩者分別簽約。

**Q. 董事變更時，須於何時申報什麼？**
A. 董事等的變更須於變更日起30日內提交變更申報（建設業法第11條第1項）。此外，若該董事原為經營業務的管理負責人等，須於兩週內辦理後任的相關申報（同條第4項・第5項）。公司的董事變更登記由司法書士、建設業許可的變更申報由行政書士，分別簽約推進。
