**結論（先說要點）**：以自宅或所有之住宅經營民泊（住宅宿泊事業），須依住宅宿泊事業法（平成29年法律第65號）第3條第1項，向都道府縣知事等（於設有保健所之市為市長、特別區為區長）提出申報。此與旅館業法之營業許可，根據法律與窗口均不同；住宅宿泊事業以「使人住宿之日數1年不逾180日」為定義上前提（同法第2條第3項）。申報須附消防法令適合通知書等，於家主不在型並須委託住宅宿泊管理業者（同法第11條）。分讓公寓須確認管理規約，租賃物件須確認租賃契約之許諾。本文為一般資訊提供，整理申報與旅館業許可之別、180日規制、添付書類、管理規約之確認點與角色分工，不判斷個別申報之可否或物件能否用於民泊。

## 住宅宿泊事業之申報與旅館業許可，於何處分界？

以收取住宿費使人住宿之事業，大致分為「旅館業法之許可」與「住宅宿泊事業法之申報」。旅館業法（昭和23年法律第138號）為許可制，於櫃檯設備、客室基準等設施面之要件較重。住宅宿泊事業法則為申報制，對象為活用住宅使人住宿之事業。

分界在於「營業日數」與「設施是否為住宅」。住宅宿泊事業，定義為旅館業者以外之人收取住宿費使人於住宅住宿之事業，且使人住宿之日數1年不逾180日（住宅宿泊事業法第2條第3項）。若欲逾180日營業，即不在住宅宿泊事業範圍內，須考量旅館業法之許可（如簡易住所營業）。

| | 旅館業法之許可 | 住宅宿泊事業法之申報 |
| --- | --- | --- |
| 手續 | 許可制 | 申報制 |
| 窗口 | 都道府縣知事等（保健所） | 都道府縣知事等（設保健所之市、特別區為市長・區長） |
| 年營業日數 | 無上限 | 180日以下（第2條第3項定義） |
| 對象設施 | 旅館・飯店・簡易住所等 | 住宅 |

何種架構適合，因欲營業之日數、設施性質與立地而異。四葉行政書士事務所於行政書士業務範圍內，支援住宅宿泊事業申報書與添付書類之製作及申報之代理。須旅館業許可時之建築確認，屬建築士領域。個別可否由所轄審查。

## 申報所需書類與消防法令適合通知書如何備齊？

住宅宿泊事業之申報，依住宅宿泊事業法第3條第1項，以電子系統（民泊制度運營系統）或書面為之。除申報書外，須附住宅之圖面、登記事項證明書、消防法令適合通知書等。書類種類因自治體手引而異，宜於申報前確認所在地窗口之案內。

消防法令適合通知書，為消防署（消防長・消防署長）確認住宅符合消防法令後所交付之書面。於住宅宿泊事業，依住宅規模與家主居住形態，可能須設置自動火災報知設備・誘導燈・滅火器等。設備要否與設計屬消防署・消防設備士領域，作為申報前提宜及早諮詢為妥。

| 主要添付・確認事項 | 擔當・窗口 |
| --- | --- |
| 申報書・住宅圖面・登記事項證明書之整理與提出代理 | 四葉行政書士事務所（行政書士） |
| 消防法令適合通知書之取得・消防用設備之設計 | 消防署（消防長・消防署長）・消防設備士 |
| 宿泊者名簿之備付（第8條）、標識之掲示（第13條） | 住宅宿泊事業者（申報者） |
| 家主不在型之住宅宿泊管理業務委託（第11條） | 住宅宿泊管理業者 |

住宅宿泊事業者須備付宿泊者名簿（第8條），並就各申報住宅掲示標識（第13條）。書類之製作・提出由行政書士，消防設備由消防署・消防設備士，擔當分工。

## 年180日之上限與自治體之上乗せ條例如何生效？

住宅宿泊事業使人住宿之日數，1年上限為180日。此「1年」依國之運用，以每年4月1日正午至翌年4月1日正午之期間計算（民泊制度入口網站・參照日2026年8月27日）。使人住宿之日數以定期報告向自治體報告。

再者，都道府縣（含設保健所之市・特別區）為防止生活環境惡化而有必要時，得以條例定區域，限制住宅宿泊事業之營業期間（住宅宿泊事業法第18條）。經此「上乗せ條例」，可能施以較180日更狹之限制，如於住居專用地域不許平日營業、於學校周邊限制期間等。

| 限制種類 | 依據 |
| --- | --- |
| 全國一律之營業日數上限 | 住宅宿泊事業法第2條第3項（180日以下） |
| 定區域之期間限制（上乗せ條例） | 住宅宿泊事業法第18條 |
| 集合住宅之可否 | 管理規約・租賃契約 |

即使物件良好，於上乗せ條例對象區域，亦可能無法營業所設想之日數。決定物件前宜確認用途地域與條例區域；立地之可否與上乗せ條例之該當，為選物件之重要確認事項。物件能否用於民泊之見立，由與四葉行政書士事務所別事業體之四葉不動產株式會社（宅地建物交易業者），於宅建業務範圍內擔當。

## 於分讓公寓經營民泊時，須確認管理規約與租賃之何處？

於分讓公寓（區分所有建物）經營民泊，除法令之申報外，管理規約之確認不可或缺。公寓標準管理規約示有明記住宅宿泊事業「得為／不得為」之規定例；若規約禁止民泊，縱能申報亦不得實施。

於租賃物件經營民泊，須確認租賃契約是否許諾轉租或民泊利用。未經所有人・出租人承諾即經營民泊，恐構成違約。此等符合判斷（用途地域・管理規約・租賃之許諾）屬不動產領域，與行政書士所為之申報書類製作，擔當分開。

- 確認管理規約未禁止住宅宿泊事業 → 管理組合・區分所有人，確認由四葉不動產株式會社（宅地建物交易業者）
- 確認租賃契約對轉租・民泊利用之許諾 → 出租人，確認由四葉不動產株式會社（宅地建物交易業者）
- 申報書・添付書類之製作與提出代理 → 四葉行政書士事務所（行政書士）

管理規約與租賃之確認，為物件能否用於民泊之前提。申報之代理由行政書士擔當，惟物件本身能否符合民泊之見立，由不動產擔當。

## 物件確認・申報・消防，各應委託何人？

民泊之開始橫跨多項手續與專業領域。分工如下。

- 住宅宿泊事業申報書・添付書類之製作、申報之代理 → 四葉行政書士事務所（行政書士）
- 物件能否用於民泊之判斷（用途地域・管理規約・租賃之許諾）・物件買賣或租賃之仲介 → 四葉不動產株式會社（宅地建物交易業者）
- 消防法令適合通知書之取得・消防用設備之設計 → 消防署（消防長・消防署長）・消防設備士
- 須旅館業許可時之建築確認 → 建築士

與四葉行政書士事務所別事業體之四葉不動產株式會社，以獨立的事業體、個別契約擔任物件符合之見立・買賣或租賃之仲介・管理規約與租賃之確認。消防法令適合通知書屬消防署所管，消防用設備之設計屬消防設備士，須旅館業許可時之建築確認屬建築士領域。各領域均以與各窗口・資格者作為獨立的事業體個別簽約為前提，本事務所不收取介紹費。受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)；取扱業務之全貌見[許認可・各種申請服務](https://luck428.com/legal/services)。其他開業許認可，亦可參考[深夜0時後供酒的店，需要什麼申報？](https://luck428.com/legal/column/shinya-shurui-teikyo-todokede-yoken)、[古物商許可，營業所需要什麼？](https://luck428.com/legal/column/kobutsusho-kyoka-eigyosho-yoken)。

## 常見問題

**Q. 縱使一年僅營業90日，仍須申報嗎？**
A. 是。住宅宿泊事業之180日為「上限」，縱營業日數較少，若收取住宿費反覆持續使人住宿，即該當住宅宿泊事業，須住宅宿泊事業法第3條第1項之申報。未申報而營業即為法之對象。不問日數多寡，營業前之申報為前提。

**Q. 旅館業許可與住宅宿泊事業之申報，應選何者？**
A. 於年180日以內活用住宅者為住宅宿泊事業之申報；欲逾180日營業、或設施難謂為住宅等情形，則以旅館業法之許可（如簡易住所營業）為考量對象。何種架構適合，因日數・設施・立地而異，個別可否由所轄審查。物件性質之見立屬不動產，建築確認屬建築士領域。

**Q. 分讓公寓之一室亦能經營民泊嗎？**
A. 除法令上之申報外，須確認管理規約。公寓標準管理規約示有明記住宅宿泊事業可否之規定例；若規約禁止，縱能申報亦不得實施。若為租賃並須出租人之許諾。管理規約與租賃之確認屬不動產領域。

**Q. 消防法令適合通知書，行政書士會代取嗎？**
A. 消防法令適合通知書，為消防署（消防長・消防署長）確認住宅符合消防法令後所交付之書面，為申報之添付書類。設備要否之判斷與設計屬消防署・消防設備士領域，非本事務所代行事項。申報書・添付書類之製作與提出代理由本事務所，消防設備由消防署・消防設備士，各有其擔當。
