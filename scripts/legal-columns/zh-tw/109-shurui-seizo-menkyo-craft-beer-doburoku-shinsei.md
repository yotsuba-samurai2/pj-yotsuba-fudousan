**結論（先說要點）**：酒類製造須依品目分別取得製造執照，且須有達到各品目最低製造數量基準的見込數量（啤酒、清酒為年60公秉，發泡酒、其他釀造酒為年6公秉）。濁酒特區（構造改革特別區域法第25條）即排除此基準的特例。申請於製造場所轄稅務署，要件請依國稅廳手冊確認。

## 酒類製造執照依品目有何不同？

依酒稅法第7條第1項，製造酒類須就欲製造的品目，分別取得製造場所轄稅務署署長的執照。品目分為清酒、合成清酒、連續式蒸餾燒酒、單式蒸餾燒酒、味醂、啤酒、果實酒、甘味果實酒、威士忌、白蘭地、發泡酒、其他釀造酒、蒸餾酒、利口酒、原料用酒精、粉末酒、雜酒，取得執照的品目以外不得製造。精釀啤酒一般歸為「啤酒」，濁酒則歸為以米為原料且「不過濾」的其他釀造酒。

能否取得執照，依酒稅法第10條（製造執照等之要件）所列拒絕事由判斷。主要事由如下，各款之該當性由稅務署個別審查。

| 酒稅法第10條主要拒絕事由 | 內容（依手冊） |
|---|---|
| 第6款 | 申請前2年內受過國稅、地方稅的滯納處分 |
| 第8款 | 受拘禁刑以上之刑，執行終了等後未滿3年 |
| 第10款 | 受破產程序開始裁定尚未復權等，經營基礎薄弱 |
| 第11款 | 為維持酒類供需均衡、保全酒稅，給予執照不適當 |
| 第12款 | 欠缺製造所需技術能力，或製造場設備不足 |

以何品目申請，須就原料、製法與預估數量，事先向稅務署諮詢確認。

## 最低製造數量基準在精釀啤酒與特區濁酒有何不同？

酒稅法第7條第2項規定，取得執照後1年內於1個製造場欲製造的見込數量，未達該品目所定數量者，不得取得執照。此即最低製造數量基準。主要品目如下。

| 品目 | 最低製造數量基準（每年、每製造場） |
|---|---|
| 清酒、合成清酒、連續式蒸餾燒酒、啤酒 | 60公秉 |
| 單式蒸餾燒酒、味醂 | 10公秉 |
| 果實酒、甘味果實酒、威士忌、白蘭地、發泡酒、其他釀造酒、蒸餾酒、利口酒、原料用酒精、雜酒 | 6公秉 |

精釀啤酒的釀造所以「啤酒」申請，故年60公秉的製造見込為要件目安。又2018年（平成30年）4月1日施行的修正擴大了啤酒的定義，原以發泡酒製造者之一部分改歸啤酒，最低製造數量的目安由6公秉變為60公秉。因商品歸屬品目不同而基準不同，請將原料與配方向稅務署提示確認。另一方面，特區濁酒的處理有所不同（見次節）。

## 製造場的物件須符合哪些構造、設備要件？

製造場的設備須不致該當酒稅法第10條第12款「製造場設備不足」，並具備與品目相應的製造、貯藏設備。具體基準依國稅廳手冊與所轄稅務署審查。於承租、施工前，連同用途與租賃條件向稅務署諮詢較為安全。

| 確認點 | 內容（因品目、規模而異） |
|---|---|
| 製造設備 | 與品目相應的仕込、發酵、貯藏設備與容量 |
| 計量與記帳 | 可掌握製造數量的計量設備與帳簿體制 |
| 區劃與衛生 | 製造區域的區劃、用水與排水、易清掃構造 |
| 物件使用權原 | 租賃契約是否允許作為製造場使用 |

酒類製造本身以酒稅法的執照處理，但於製造場併製清涼飲料、無酒精飲料等其他產品，或依販售形態，有時須另依食品衛生法取得營業許可或提出營業申報，要否請向所在地保健所確認。建築基準法上的用途變更或確認由建築士、消防設備與消防署協議。物件的用途、租賃條件確認由四葉不動產株式會社協助。

## 使用濁酒特區可將要件放寬到什麼程度？

構造改革特別區域法第25條（特定農業者による特定酒類の製造事業）規定，於經認定的特區內，併營「於自己營業場供飲用酒類之業」（如農家民宿、農園餐廳）的農業者，於自己製造場以自產米等為原料製造濁酒等時，不適用酒稅法第7條第2項（最低製造數量基準）及第12條第4款。此即所謂濁酒特區。

| 比較 | 一般製造執照 | 濁酒特區（構造改革特別區域法第25條） |
|---|---|---|
| 最低製造數量基準 | 其他釀造酒為年6公秉 | 不適用 |
| 對象者 | 符合要件之申請者一般 | 特區內併營供飲用之業的農業者 |
| 可製造酒類 | 執照品目 | 濁酒等（特區計畫所認範圍） |
| 製造執照 | 必要 | 必要（不免除） |
| 記帳義務、酒稅申報繳納 | 必要 | 必要（不免除） |

放寬者為最低製造數量基準等部分要件，製造執照本身仍屬必要。無照製造即違反酒稅法。記帳義務與酒稅繳納亦不免除。特區認定狀況與運用因自治體、稅務署而異，申請前請確認是否屬特區計畫對象及最新處理。

## 取得執照後的酒稅申報與記帳由誰負責？

酒類製造者負有酒稅之申報繳納與帳簿記帳。稅務申報屬稅理士領域，行政書士則負責執照申請文件之製作、提出。基於業際分工，須與各專業人士分別簽約。所轄稅務署為執照審查與酒稅之行政窗口，與對民間專業人士之委任有別。

| 委託對象 | 主要角色 |
|---|---|
| 四葉行政書士事務所 | 酒類製造執照申請文件之製作、提出，事前諮詢準備支援 |
| 稅理士 | 酒稅、法人稅等申報，記帳指導 |
| 建築士、設備業者 | 製造場設計、施工、用途變更（依資格與業務範圍） |
| 四葉社會保險勞務士事務所 | 員工之勞動保險、社會保險、工作規則等 |
| 四葉不動產株式會社 | 製造用物件介紹、租賃仲介 |

四葉行政書士事務所、四葉社會保險勞務士事務所、四葉不動產株式會社為不同事業體，各自均為獨立的事業體受任。請與各專業人士、業者分別簽約，以直接請款、直接入帳方式受任。本事務所不收取介紹性報酬。若併營酒類零售，請見[酒類零售業執照與店面物件要件](https://luck428.com/zh-tw/legal/column/shurui-kouri-menkyo-tenpo-bukken-yoken)；深夜提供請見[深夜酒類提供飲食店營業之提出](https://luck428.com/zh-tw/legal/column/shinya-shurui-teikyo-todokede-yoken)。並請參見[受任流程](https://luck428.com/zh-tw/legal/nagare)、[報酬額表](https://luck428.com/zh-tw/legal/ryokin)、[許認可服務](https://luck428.com/zh-tw/legal/services)。

## 常見問題

**Q. 開設精釀啤酒釀造所須有多少製造見込？**
A. 以「啤酒」申請時，酒稅法第7條第2項的最低製造數量基準為年60公秉。取得執照後1年內於1個製造場的製造見込數量未達此數者，不得取得執照。因商品屬啤酒或發泡酒而基準不同，請將原料與配方向稅務署提示確認。

**Q. 濁酒特區即使少量也能製造嗎？**
A. 依構造改革特別區域法第25條之特例，特區內併營供飲用之業的農業者於自己製造場製造濁酒時，不適用第7條第2項之最低製造數量基準。惟製造執照仍屬必要，記帳義務與酒稅繳納亦不免除。請向自治體、稅務署確認是否屬特區計畫對象。

**Q. 取得製造執照即可販售嗎？**
A. 製造執照係就製造之執照。販售酒類有時另須酒類販賣業執照。因自產品之販售或批發、零售形態而要否不同，請併見[酒類零售業執照與店面物件要件](https://luck428.com/zh-tw/legal/column/shurui-kouri-menkyo-tenpo-bukken-yoken)並向稅務署確認。

**Q. 取得執照後的稅務可委託行政書士嗎？**
A. 酒稅、法人稅等之申報、記帳屬稅理士業務。行政書士負責執照申請文件之製作、提出。請與各專業人士分別簽約，本事務所不收取介紹性報酬。
