**結論（先講重點）**：製造酒類，須依所製造酒類的品目、並按各製造場，向其所在地的所轄稅務署長取得「酒類製造免許」（酒稅法第7條第1項）。啤酒須達年60公秉，發泡酒與其他釀造酒類須達年6公秉的最低製造數量基準（酒稅法第7條第2項），須有達成該基準的見込（預估）才符合要件。本文以行政書士觀點整理免許區分、要件與申請流程，屬一般性資訊提供，免許可否的最終判斷由所轄稅務署作成。酒稅的申報・繳納與稅務交由稅理士，製造設備的建築確認・用途交由建築士，附設餐飲時的食品衛生交由保健所，物件要件交由宅地建物交易業者（別事業體的四葉不動產股份有限公司），各以獨立的事業體分別簽約為前提分開委任。本事務所不收取介紹費。

## 酒類製造免許與「酒類零售免許」有何不同，免許又如何依酒類區分？

與酒相關的免許大致分為「製造」與「銷售」。釀造方取得酒類製造免許（酒稅法第7條），銷售已完成酒類的一方取得酒類銷售業免許（第9條）。開設釀造所（brewery）自釀啤酒的行為須有製造免許，而將其以瓶裝或罐裝零售的行為，可能另須「酒類零售業免許」。若釀造並自售，須將銷售免許與製造免許分開檢討。零售免許的要件與店鋪・物件思路，整理於[酒類零售業免許與店鋪・物件要件](https://luck428.com/legal/column/shurui-kouri-menkyo-tenpo-bukken-yoken)。

製造免許依「品目別・按各製造場」取得。亦即釀啤酒取啤酒的免許，釀發泡酒取發泡酒的免許，依所釀酒類的品目區分，並按各製造場（工廠・釀造所）取得。酒類的品目於酒稅法第3條區分為清酒・啤酒・果實酒・發泡酒・其他釀造酒・利口酒・烈酒等，同樣的「精釀啤酒」也會因麥芽使用比例與副原料而被歸為啤酒、發泡酒或其他釀造酒。要申請哪一品目的免許，須以原料與配方為前提向所轄稅務署確認，品目的最終歸類為稅務署的判斷。

## 啤酒・發泡酒・其他釀造酒類的「最低製造數量基準」是多少？

酒類製造免許規定，於一製造場取得製造免許後一年內預計製造的見込數量，若未達各品目所定數量，即不得取得（酒稅法第7條第2項），稱為最低製造數量基準。主要品目如下。

| 品目 | 最低製造數量基準（每年・每一製造場） |
|---|---|
| 清酒・合成清酒・連續式蒸餾燒酎・啤酒 | 60公秉 |
| 單式蒸餾燒酎・味醂 | 10公秉 |
| 果實酒・甜味果實酒・威士忌・白蘭地 | 6公秉 |
| 發泡酒・其他釀造酒・原料用酒精 | 6公秉 |
| 烈酒・利口酒・粉末酒・雜酒 | 6公秉 |

精釀啤酒開業常見的爭點，是啤酒（60公秉）與發泡酒・其他釀造酒類（各6公秉）之間的差距。依麥芽比例與啤酒花以外副原料的用法，有時在酒稅法上並非「啤酒」而被歸為「發泡酒」或「其他釀造酒」，即使小規模也可能以6公秉的基準檢討免許。惟品目歸類由原料・製法決定，並非為壓低基準而決定配方的順序。屬哪一品目須經稅務署確認。啤酒基準雖於1994年由2,000公秉下調至60公秉，但現行數量如上表所示，撰稿前已對照國稅廳最新手引確認。

## 製造場所・設備有何要件？（申請單位・製造設備）

因免許按各製造場取得，製造場所與設備即為審查對象。酒稅法第10條規定，於申請免許時若有各款之一情形，稅務署長得不給予免許，主要觀點如下。

| 觀點 | 酒稅法第10條之相關（概要） |
|---|---|
| 人的要件 | 自免許撤銷起一定年數內之人、國稅・地方稅之滯納處分、酒稅法等罰金刑之經過年數等（第1款至第8款） |
| 場所的要件 | 無正當理由於取締上不適當之場所設置製造場（第9款） |
| 經營基礎要件 | 認定經營基礎薄弱之情形（第10款） |
| 需給調整要件 | 為保全酒稅維持酒類供需均衡之必要而認不適當之情形（第11款） |
| 技術・設備要件 | 不具備製造技術能力，或製造場設備認定不充分之情形（第12款） |

製造設備（下料・發酵・貯酒・過濾・充填・計量等）與能確實管理製造數量的體制，被作為「技術・設備要件」檢視。給排水・排水處理・建物用途也牽涉其他法令（建築基準法・水質相關規制・食品衛生），故於施工或簽訂租賃契約前，應向建築士・施工公司或所轄窗口確認。製造設備的建築確認・用途判斷屬建築士領域，行政書士不保證設計或合法性。

## 構造改革特區（濁酒特區・葡萄酒特區等）在何種情形放寬基準？

構造改革特別區域法設有在經認定特區內放寬最低製造數量基準的酒稅法特例，代表者為所謂「濁酒特區」與「葡萄酒特區」。

- 濁酒特區（構造改革特別區域法第25條「酒稅法之特例」）：經營農家民宿等的特定農業者，以自行生產的米或果實為原料，於自己營業場供飲用而製造濁酒（不過濾的其他釀造酒）或果實酒時，不適用酒稅法第7條第2項（最低製造數量基準）之特例。
- 葡萄酒特區・特產酒類之特例（第26條）：依認定計畫的事業者以特產果實為原料製造果實酒等時，將果實酒的基準由「6公秉」讀替為「2公秉」、利口酒讀替為「1公秉」等放寬（單式蒸餾燒酎・原料用酒精為適用除外）。

二者均以該地區已取得構造改革特別區域計畫之內閣總理大臣認定，且符合對象者・對象品目・原料要件為前提。於特區外製造同一品目者，適用原則的最低製造數量基準。自己的計畫是否屬特區對象，須對照特區計畫內容及所轄稅務署・自治體的指引確認。

## 申請向何處・以何種文件提出，審查約需多久？

申請對象為製造場所在地所轄的稅務署（所轄稅務署長）。除申請書外，另須提出顯示事業計畫・製造方法・製造設備・資金計畫・場所狀況等的附件。具體樣式・附件須對照國稅廳「酒類製造免許申請手引」與所轄稅務署指引確認。

| 確認點 | 內容（申請前向稅務署・手引確認） |
|---|---|
| 申請對象 | 製造場所在地之所轄稅務署長 |
| 免許單位 | 品目別・按各製造場 |
| 主要附件 | 事業・製造計畫、製造方法書、製造設備概要、場所圖面・契約關係、收支見込、申請人經歷等 |
| 審查觀點 | 人的・場所的・經營基礎・需給調整・技術/設備各要件（酒稅法第10條）、達成最低製造數量基準之見込（第7條第2項） |
| 標準處理期間 | 以稅務署公布之標準處理期間為目安確認（依申請內容增減） |

審查所需期間因申請內容與有無補正而異。標準處理期間並非法定確定期限，故日程須向所轄稅務署確認。是否給予免許的最終判斷由所轄稅務署作成。行政書士負責申請文件的製作・整理與手續進行支援，不保證可否或品目歸類。委任流程見[委任流程](https://luck428.com/legal/nagare)、費用見[報酬額表](https://luck428.com/legal/ryokin)、承辦業務見[許認可服務](https://luck428.com/legal/services)。

## 酒稅申報・物件・食品衛生該委任給誰？（稅理士・不動產・保健所的切分）

釀造所開業除免許外，橫跨稅務・物件・食品衛生等多領域，各以獨立的事業體分別簽約為前提分開委任。

| 委任對象 | 主要角色 |
|---|---|
| 四葉行政書士事務所 | 酒類製造免許申請文件之製作・提出、手續進行支援 |
| 稅理士 | 酒稅之申報・繳納、法人稅・消費稅等稅務 |
| 建築士・施工公司 | 製造設備之設計・施工、建築確認・用途判斷（依資格・業務範圍） |
| 保健所 | 附設餐飲時之餐飲店營業許可・食品衛生諮詢 |
| 四葉不動產股份有限公司（別事業體） | 製造用物件之介紹・租賃之仲介 |

酒稅之申報・繳納與稅務屬稅理士，製造設備之建築確認・用途屬建築士，附設餐飲時之食品衛生許可屬保健所，物件要件屬宅地建物交易業者的領域。若附設餐飲店，請併參[餐飲店營業許可與保健所設備基準](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)；若涉及食品製造，請參[食品製造業許可與物件・設備基準](https://luck428.com/legal/column/shokuhin-seizogyo-kyoka-bukken-setsubi-kijun)。四葉行政書士事務所・稅理士・建築士・四葉不動產股份有限公司為別事業體，各以獨立的事業體，與各專家・業者分別簽約，以直接請款・直接入帳的形式受任。本事務所不收取介紹費。製造用物件之諮詢由別事業體的四葉不動產股份有限公司負責。

## 常見問題

**Q. 想小規模釀精釀啤酒，是否一定要年產60公秉才能取得免許？**
A. 若以啤酒品目取得免許，須有於一製造場每年達60公秉最低製造數量基準（第7條第2項）之見込。但若麥芽比例或副原料使其在酒稅法上被歸為「發泡酒」或「其他釀造酒」，則有時可以6公秉基準檢討免許。屬哪一品目由原料・製法決定，最終歸類由所轄稅務署判斷。

**Q. 是否同時需要製造免許與酒類零售業免許？**
A. 釀造行為可能須製造免許（第7條），將完成酒類零售的行為可能另須酒類零售業免許（第9條）。若自釀並自售，須分開檢討二者之要否，細節請向所轄稅務署確認。

**Q. 在濁酒特區或葡萄酒特區，小規模是否也能製造？**
A. 僅於經認定特區內，符合對象者・對象品目・原料要件時，才有不適用或下調最低製造數量基準的特例（構造改革特別區域法第25條・第26條）。特區外適用原則基準。自己的計畫是否為對象，須對照特區計畫及所轄稅務署・自治體確認。

**Q. 審查約需多久？**
A. 因申請內容與有無補正而異。請以所轄稅務署公布之標準處理期間為目安確認。標準處理期間並非法定確定期限，是否給予免許的最終判斷由所轄稅務署作成。
