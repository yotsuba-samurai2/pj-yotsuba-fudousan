**結論（先講重點）**：要為觀光或接送，向不特定對象收取運費並將巴士整車出租載客，須取得道路運送法第4條第1項的一般貸切旅客自動車運送事業許可。這是同法第3條第1號ロ所定「以一個契約將國土交通省令所定乘車定員以上的汽車整車出租以運送旅客」的事業，乘車定員由國土交通省令定為11人以上。僅將自家董監事・員工或自家客人無償接送時原則上不需許可，但一旦收取運費載客即須許可。許可的核心是「人・物・金・安全」，須備齊運行管理者（同法第23條；由領有運行管理者資格者證者中選任）・整備管理者（道路運送車輛法第50條）・營業所・車庫・損害賠償能力（任意保險）・所需資金，車輛數等具體基準由運輸局公示的審查基準定之（基準可能修訂，請以申請運輸局的最新公示確認）。許可依同法第8條採每5年更新制。四葉行政書士事務所在行政書士法第1條之2・第1條之3的範圍內，以另行簽約承接許可申請書・事業計畫・運行管理者等選任申報的製作與手續。駕駛的拘束時間・休息期間等勞務設計由社會保險勞務士、營業所・車庫的物件由不動產、車輛與保險由本人與保險公司負責，均為獨立的事業體並分別簽約。本文為一般性資訊提供，不保證個別許可。本所不收取介紹費。

## 包車巴士事業在什麼範圍需要許可？與白牌接送有何不同？

需要一般貸切旅客自動車運送事業許可的，依道路運送法第4條第1項，是以一個契約將巴士整車出租、向不特定對象收取運費而運送旅客的情形。對象汽車為同法第3條第1號ロ所稱「國土交通省令所定乘車定員以上的汽車」，乘車定員為11人以上。將10人以下的汽車整車出租載客，屬一般乘用旅客自動車運送事業（含大型計程車等的「乘用」）的區分，是另一種許可的對象。

| 區分 | 典型例 | 是否需許可 |
| --- | --- | --- |
| 一般貸切旅客自動車運送事業 | 觀光・接送中，將乘車定員11人以上的巴士整車出租並收費載客 | 需道路運送法第4條第1項的許可 |
| 自家運送（白牌） | 將自家董監事・員工或自家客人不收費接送 | 不需許可（惟以運送為業並有償行之，即為許可對象） |
| 自家用汽車的有償運送 | 以自家用車進行有償運送 | 原則禁止（同法第78條；例外有限） |

差異的核心在於「是否收取運費的有償運送」「是否載運不特定對象」。無償的自家接送不需許可，但一旦收取超過實費的對價、或載運外部客人，即可能構成無許可的有償運送而生問題。屬於何者，依契約與對價的實態判斷，故請在接送的設計階段整理。需要許可之事業的受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)，承辦業務請見[承辦業務一覽](https://luck428.com/legal/services)。

## 許可的人・物・金要件（運行管理者・整備管理者・營業所・車庫・資金）要滿足什麼？

許可要件可分為「人・物・金・安全」。車輛數與金額等具體基準，由申請運輸局公示的審查基準定之，且可能修訂。代表性項目如下（數值可能因運輸局的公示而異，請於申請前以最新公示確認）。

| 區分 | 主要要件 |
| --- | --- |
| 車輛數 | 每一營業區域原則3輛以上。使用大型車時，多數公示要求5輛以上（3輛以上未滿5輛，一般會附限定中型・小型車的條件） |
| 運行管理者 | 每一營業所，由領有運行管理者資格者證者中選任（道路運送法第23條）。所需人數隨車輛數增加 |
| 整備管理者 | 每一營業所選任（道路運送車輛法第50條）。以整備士資格，或一定實務經驗＋選任前研修滿足要件 |
| 營業所・車庫 | 車庫原則附設於營業所。無法附設時，距營業所直線約2公里以內。營業所・車庫・休息仮眠設施，多數公示要求3年以上的使用權原 |
| 損害賠償能力 | 全部車輛加入對人賠償每一被害人無限、對物賠償每一事故200萬日圓以上之任意保險（共濟）的計畫 |
| 所需資金 | 估算開業所需資金並能以自有資金確保；以存款餘額疏明 |

運行管理者依道路運送法第23條之2，由通過運行管理者考試者等領取資格者證。這些是取得許可後仍須維持的基準，車輛數・保險・管理者的選任，於運輸開始後亦須持續滿足。是否符合要件的最終審查・判斷，由運輸局（地方運輸局・運輸支局）為之。駕駛的拘束時間・休息期間等勞務設計，整理於社會保險勞務士的[包車巴士駕駛的改善基準告示（2024年拘束・休息）與勞務](https://luck428.com/labor/column/bus-untensha-kaizen-kijun-2024-kousoku-kyusoku-roumu)（社會保險勞務士為另一事業體）。

## 從申請到許可、運輸開始、監查的流程如何進行？

手續依「確定事業計畫並申請→經法令考試・審查→取得許可→運輸開始」的順序進行。取得許可後，亦有每5年的更新（道路運送法第8條）。大致流程如下。標準處理期間與運用因運輸局而異，請以申請運輸局的指引確認。

| 階段 | 內容 |
| --- | --- |
| 製作事業計畫 | 決定營業區域・營業所・車庫・車輛・運行管理者等，並擬定所需資金與任意保險的計畫 |
| 申請 | 向管轄營業所的運輸支局提出許可申請書與事業計畫等（道路運送法第5條） |
| 法令考試 | 申請人（法人為常勤董監事）應試道路運送法等法令考試 |
| 審查・補正 | 審查是否符合要件；確認並補正設施・人員・資金 |
| 許可 | 許可下達後繳納登錄免許稅 |
| 許可後手續 | 運費・料金的設定（申報）、運行管理者・整備管理者的選任申報、安全管理相關申報、車輛登錄（綠牌）等 |
| 運輸開始 | 開始運輸並提出運輸開始申報（申報期限請以運輸局指引確認） |
| 更新・監查 | 許可每5年更新（道路運送法第8條）。為運輸局・適正化機關之監查・巡迴指導的對象 |

許可並非取得即了結，每5年的更新與運行管理・整備・勞務的持續遵守為前提。具體樣式・份數・標準處理期間，請以申請運輸支局的最新指引確認。本所所做的是製作申請文件・辦理手續，並整理交付各專家的資料，不對審查結論或法律見通作斷定。

## 許可申請・勞務・車庫物件，分別委託給誰？

包車巴士的開業，在許可・勞務・物件・車輛上，負責的專家各不相同。四葉集團中，行政書士・社會保險勞務士・不動產各為獨立的事業體，以分別簽約為前提。負責如下。

- 許可申請書・事業計畫・運行管理者等選任申報的製作與手續 → 行政書士（行政書士法第1條之2・第1條之3；本所）
- 拘束時間・休息期間・工資・社會保險・就業規則等駕駛勞務設計 → 社會保險勞務士（另一事業體）
- 營業所・車庫・休息仮眠設施的物件尋找・租賃 → 另一事業體的四葉不動產株式會社（宅地建物交易業者）
- 車輛的調度・登錄、任意保險的設計 → 本人・經銷商・保險公司
- 是否符合要件的審查・許可的最終判斷 → 地方運輸局・運輸支局
- 遭不許可・處分時的爭訟、個別法律見通 → 律師

各領域均以與各窗口・有資格者分別簽約為前提，本所不收取介紹費。雖可於一個窗口受理諮詢並整理交付各專家，但受任係分開。受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)，承辦業務請見[承辦業務一覽](https://luck428.com/legal/services)。相關的運送類許可，貨物方面整理於[一般貨物自動車運送事業的許可（營業所・車庫要件）](https://luck428.com/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)、[貨物利用運送事業的登錄・許可（第一種・第二種）](https://luck428.com/legal/column/kamotsu-riyo-unso-1shu-2shu-touroku-kyoka)，旅客方面整理於[看護計程車（福祉運送）的許可與車庫要件](https://luck428.com/legal/column/kaigo-taxi-fukushi-yuso-kyoka-shako-yoken)。

## 常見問題

**Q. 僅以巴士接送自家員工或住宿客，也需要許可嗎？**
A. 僅將自家董監事・員工或自家客人不收費接送，原則上不需一般貸切旅客自動車運送事業許可。另一方面，若收取運費（超過實費的對價）載客，或載運外部不特定對象，即可能成為道路運送法第4條第1項許可的對象。無許可而以自家用汽車進行有償運送原則禁止（同法第78條）。接送是否仍屬無償的自家運送，依契約與對價的實態判斷，請於設計階段整理。

**Q. 包車巴士許可需要幾輛車？**
A. 車輛數由申請運輸局公示的審查基準定之，多數公示為每一營業區域原則3輛以上，使用大型車時5輛以上（3輛以上未滿5輛一般會附限定中型・小型車的條件）。此數值因運輸局而異且可能修訂，請於申請前以申請運輸支局的最新公示確認。除車輛外，亦須一併滿足運行管理者・整備管理者・營業所・車庫・任意保險・所需資金的要件。

**Q. 取得許可後，是否不必更新即可持續經營？**
A. 一般貸切旅客自動車運送事業許可，依道路運送法第8條，未每5年更新即因期間經過而失效。除更新外，運行管理者・整備管理者的選任、任意保險的加入、駕駛勞動時間的管理等，於運輸開始後亦須持續滿足，並為運輸局・適正化機關之監查・巡迴指導的對象。更新時期與應維持的基準，請以申請運輸局的指引確認。

**Q. 從許可申請到駕駛勞務、車庫物件，能否委託同一事務所一併處理？**
A. 許可申請書・事業計畫・選任申報的製作由行政書士、拘束時間・休息期間・工資・社會保險由社會保險勞務士、營業所・車庫物件由另一事業體的四葉不動產株式會社、車輛與保險由本人與保險公司、許可的最終判斷由運輸局、處分的爭訟由律師負責，均為獨立的事業體並分別簽約。雖可於一個窗口受理諮詢並整理交付各專家，但受任係分開。本所不收取介紹費。
