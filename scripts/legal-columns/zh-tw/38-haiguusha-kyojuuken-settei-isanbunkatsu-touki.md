**結論（先說要點）**：配偶者居住權使被繼承人之配偶，得於其於繼承開始時所居住、被繼承人所有之建物，終身或一定期間無償繼續居住（民法第1028條，令和2年4月1日施行）。取得原因為遺產分割或遺贈，亦有由家庭裁判所審判取得者（民法第1029條）。存續期間原則為配偶之終身，得以協議・遺言・審判為別段之定（民法第1030條）。於遺產分割協議書載明配偶取得配偶者居住權之旨與居住建物・存續期間，並就建物備妥設定登記（民法第1031條、不動產登記法第81條之2），則對其後取得建物之第三人亦得對抗。設定登記之申請由司法書士，配偶者居住權與敷地利用權之評價・繼承稅由稅理士，爭議由律師處理，行政書士則負責遺產分割協議書等之製作。本文為一般資訊提供，整理成立要件・存續期間・協議書記載・登記與評價之分工・與配偶者短期居住權之差異。個別設定之可否與評價額，由資格者之判斷而定。

## 配偶者居住權由誰、於何種情形得以取得？

配偶者居住權係民法第1028條第1項所定之權利，符合下列要件之配偶得以取得。其一，須為被繼承人之配偶。此所稱配偶係經法律婚姻之配偶，不含事實上（內緣）之配偶。其二，該配偶於繼承開始時，居住於被繼承人所有之建物。建物為被繼承人與配偶共有者得以取得，惟與被繼承人以外之第三人共有之建物則非屬對象。

取得原因為同項所定之遺產分割取得（第一號）與遺贈取得（第二號）。此外，受遺產分割請求之家庭裁判所，於一定情形亦得以審判使配偶取得配偶者居住權（民法第1029條）。配偶者居住權即使僅居住於建物之一部，亦及於建物全部。

| 事項 | 內容 |
| --- | --- |
| 依據 | 民法第1028條（配偶者居住權）・第1029條（審判取得） |
| 施行 | 適用於令和2年4月1日以後開始之繼承 |
| 得取得者 | 於繼承開始時居住於被繼承人所有建物之法律上配偶（不含內緣） |
| 取得原因 | 遺產分割・遺贈・家庭裁判所之審判 |
| 及於範圍 | 居住建物之全部（即使僅居住一部亦及於全體） |

配偶者居住權係即使自宅所有權由其他繼承人取得，仍能確保配偶居住權之機制。用於自宅評價偏高、配偶若取得所有權則無法取得存款等其他財產之情形。

## 得以遺產分割或遺贈設定，存續期間如何決定？

配偶者居住權除以遺產分割之協議・調停・審判設定外，亦得以遺言之遺贈設定。以遺贈定明者，配偶得不待遺產分割協商即確實取得。又，雖有被繼承人書明「使配偶繼承配偶者居住權」之例，惟為確實設定，一般案內以遺贈之方式為之。

存續期間依民法第1030條原則為配偶之終身。惟遺產分割之協議・遺言有別段之定，或家庭裁判所於遺產分割審判為別段之定時，即依其期間。亦得設定10年・20年之有期。

| 事項 | 內容 |
| --- | --- |
| 設定方法 | 遺產分割（協議・調停・審判）／遺贈 |
| 存續期間 | 原則為配偶之終身（民法第1030條）。得以協議・遺言・審判設為有期 |
| 得否讓與 | 配偶者居住權不得讓與（民法第1032條第2項）。無法變賣現金化 |
| 費用負擔 | 居住建物之通常必要費由配偶負擔（民法第1034條） |

配偶者居住權係為配偶本人之權利，不得讓與他人（民法第1032條第2項）。欲使第三人使用・收益居住建物者，須經建物所有者之承諾。配偶應以善良管理人之注意使用建物，並負擔固定資產稅等通常必要費。

## 遺產分割協議書應如何記載配偶者居住權？

以遺產分割設定時，於遺產分割協議書載明由何繼承人取得居住建物之所有權，及配偶取得配偶者居住權。居住建物以登記事項（所在・地番・家屋番號・種類・構造・床面積）特定，並記載存續期間。設為終身者載明其旨，設為有期者記載期間。

為設定登記，將不動產登記法第81條之2所定之登記事項反映於協議書內容，可使手續順暢。具體而言，存續期間，及有許第三人使用・收益居住建物之定者其定，均為登記事項。居住建物之所有者，對配偶負使其備妥配偶者居住權設定登記之義務（民法第1031條第1項），故於協議書載明所有者協力登記手續之旨，可使其後之登記申請易於進行。

| 記載事項 | 內容 |
| --- | --- |
| 權利者・義務者 | 取得配偶者居住權之配偶，與取得居住建物所有權之繼承人 |
| 居住建物之特定 | 以所在・地番・家屋番號・種類・構造・床面積特定 |
| 存續期間 | 終身或期間（民法第1030條） |
| 對登記之協力 | 基於所有者備妥設定登記之義務（民法第1031條第1項）之協力 |

遺產分割協議書之製作，行政書士得於業務範圍內支援。四葉行政書士事務所支援基於已合意內容之遺產分割協議書等之製作。個別條項有效性之判斷，及有爭議事案之代理，屬律師之領域。

## 配偶者居住權之登記與評價（繼承稅）由誰負責？

配偶者居住權之設定登記，僅就居住建物為之，敷地（土地）不予登記。登記以配偶為權利者、建物所有者為義務者之共同申請為之。受他人委託而為之登記申請代理及登記申請書之製作，屬司法書士或律師之業務。本事務所不為登記申請之代理及登記申請書之製作。

登記之意義在於對抗要件。民法第1031條第2項準用租賃之規定（民法第605條），未備妥設定登記者，不得對其後取得居住建物之第三人對抗配偶者居住權。備妥登記可確保繼續居住之權利。

| 事項 | 負責・依據 |
| --- | --- |
| 設定登記之申請 | 司法書士（僅就建物・共同申請）。依據為不動產登記法第81條之2 |
| 對抗要件 | 備妥登記則得對第三人對抗（民法第1031條第2項準用民法第605條） |
| 繼承稅之評價 | 稅理士。配偶者居住權・居住建物・基於配偶者居住權之敷地利用權・居住建物之敷地之評價（相續稅法第23條之2） |

繼承稅上，將配偶者居住權與利用該土地之權利即敷地利用權評價為配偶側之財產，其他繼承人則評價為取得附負擔之所有權（相續稅法第23條之2）。配偶死亡致配偶者居住權消滅時之課稅關係等，評價與稅務之判斷屬稅理士之領域。本事務所不進行稅務諮詢。

## 與配偶者短期居住權有何不同，發生爭議時應向何人諮詢？

配偶者短期居住權係民法第1037條所定之另一權利。配偶於繼承開始時無償居住於被繼承人所有之建物者，因繼承開始而當然發生，至遺產分割確定居住建物歸屬之日，或自繼承開始起經過6個月之日，以較遲者為止，得無償繼續居住。無須設定合意或登記，惟因無法登記，故對第三人無對抗力。其目的為遺產分割終了前之短期保護。

| 事項 | 配偶者居住權（第1028條） | 配偶者短期居住權（第1037條） |
| --- | --- | --- |
| 發生 | 以遺產分割・遺贈・審判設定 | 因繼承開始而當然發生 |
| 存續期間 | 原則終身（亦得有期） | 至遺產分割確定日或繼承開始起6個月經過日之較遲者為止 |
| 登記・對抗 | 以設定登記得對第三人對抗 | 無法登記（無對抗力） |
| 讓與 | 不得讓與 | 不得讓與 |

就是否設定配偶者居住權、如何評價，繼承人間生對立而協商無法達成時，則進入家庭裁判所之遺產分割調停・審判。與對造之交涉及調停・審判之代理屬律師之領域。設定登記由司法書士，評價・繼承稅由稅理士，遺產分割協議書等之製作由行政書士，分工各異。

## 常見問題

**Q. 配偶者居住權可變賣為現金嗎？**
A. 配偶者居住權係為配偶本人之權利，不得讓與他人（民法第1032條第2項），故無法變賣現金化。欲使第三人使用・收益居住建物者，須經建物所有者之承諾。得予拋棄，惟其對價與稅務之處理視個別情事而定，評價・稅務請向稅理士確認。

**Q. 內緣之妻亦得取得配偶者居住權嗎？**
A. 得取得配偶者居住權者為經法律婚姻之配偶（民法第1028條第1項），不含內緣之配偶。就住居確保之考量，或須檢討以遺言之遺贈，或其他權利（租賃權・使用借貸等），個別設計由資格者之判斷而定。

**Q. 不登記會如何？**
A. 配偶者居住權未備妥設定登記者，不得對其後取得居住建物之第三人對抗（民法第1031條第2項準用民法第605條）。備妥登記則得對第三人主張繼續居住之權利。設定登記僅就建物為之，該申請之代理屬司法書士或律師之業務。

**Q. 遺產分割協議書之製作可委託何人？**
A. 基於已合意內容之遺產分割協議書等之製作，行政書士得於業務範圍內支援。配偶者居住權之設定登記由司法書士，評價・繼承稅由稅理士，有爭議之事案由律師，均為獨立的事業體個別處理。本事務所不收取介紹費。
