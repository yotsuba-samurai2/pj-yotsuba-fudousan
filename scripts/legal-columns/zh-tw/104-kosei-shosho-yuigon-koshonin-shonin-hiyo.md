**結論（先講重點）：**公正證書遺言，是在2名以上證人在場下，由遺言人將遺言要旨口授公證人、由公證人筆記而作成的遺言（民法第969條）。因有公證人參與、原本由公證役場保管，較不致因方式瑕疵而無效，且遺言人死亡後無須家庭裁判所的檢認。公證人手續費依公證人手續費令定之，就以繼承、遺贈受領財產之人分別將其受領的目的價額套入表格計算後合計，目的價額合計1億日圓以下時另加遺言加算。證人有欠格事由：推定繼承人、受遺人及其配偶、直系血親不得擔任（民法第974條）。本文為一般性資訊，不就應將何財產遺予何人等遺言的法律效果作最終判斷。四葉集團的行政書士，以獨立的事業體承辦遺言原案的擬訂支援、必要文件的收集、與公證役場的日程協調，以及證人的安排。繼承人間有爭執時的對應與法律效果的最終判斷屬律師，遺言執行後的繼承登記、遺贈登記屬司法書士，繼承稅與納稅資金的試算屬稅理士，繼承不動產的出售屬不同事業體的不動產業者，各自分別簽約。

## 公正證書遺言與自書遺言相比，何以較為確實？

公正證書遺言的特色，在於由法律專家公證人參與作成。民法第969條定其方式：2名以上證人在場、遺言人向公證人口授遺言要旨、公證人筆記並向遺言人與證人宣讀（或閱覽）、遺言人與證人簽名蓋章、公證人附記並簽名蓋章。因原本由公證役場保管，無遺失、竄改之虞，因方式瑕疵而無效的風險甚小。

| 項目 | 公正證書遺言 | 自書遺言 |
| --- | --- | --- |
| 作成 | 公證人參與（民法第969條） | 遺言人親筆書寫全文、日期、姓名並蓋章 |
| 證人 | 須2名以上 | 不須 |
| 保管 | 公證役場保管原本 | 自宅保管，或法務局的保管制度 |
| 檢認 | 不須 | 原則須（以法務局保管者免） |
| 費用 | 須公證人手續費 | 作成本身不生費用 |

自書遺言雖簡便，惟仍有方式瑕疵與保管的疑慮。兩者的差異與法務局的保管制度，已於[自書遺言與公正證書遺言的差異](https://luck428.com/legal/column/jihitsu-kosei-yuigon)整理。何者適合，依財產內容、繼承人狀況與對費用的考量而異。亦請參閱本事務所的[繼承、遺言案內](https://luck428.com/legal/services/inheritance)。

## 公證人手續費依財產額如何決定？

公證人手續費為依公證人手續費令（第9條別表）所定的公定費用，就以繼承、遺贈受領財產之人分別將其受領的價額（目的價額）套入表格計算後合計。2025年（令和7年）10月1日改定後的金額如下。

| 目的價額 | 手續費 |
| --- | --- |
| 100萬日圓以下 | 5,000日圓（其中50萬日圓以下為3,000日圓） |
| 逾100萬至200萬日圓以下 | 7,000日圓 |
| 逾200萬至500萬日圓以下 | 13,000日圓 |
| 逾500萬至1,000萬日圓以下 | 20,000日圓 |
| 逾1,000萬至3,000萬日圓以下 | 26,000日圓 |
| 逾3,000萬至5,000萬日圓以下 | 33,000日圓 |
| 逾5,000萬至1億日圓以下 | 49,000日圓 |
| 逾1億至3億日圓以下 | 49,000日圓，每超過5,000萬日圓加15,000日圓 |
| 逾3億至10億日圓以下 | 109,000日圓，每超過5,000萬日圓加13,000日圓 |

此外，目的價額合計1億日圓以下時，另加遺言加算13,000日圓。正本、謄本的交付，電子資料每1通2,500日圓、書面每1張300日圓（原本逾3張者，每超過1張加300日圓）。於遺言人病床作成者加計手續費的50%，公證人赴自宅、設施等出張者，須日當（每日2萬日圓、4小時以內1萬日圓）與交通費。例如將6,000萬日圓遺予配偶、4,000萬日圓遺予長男的遺言，約為配偶分49,000日圓＋長男分33,000日圓＝82,000日圓，再加遺言加算13,000日圓＝95,000日圓為概估。因實際金額隨財產評價而變動，作成前於公證役場確認。繼承不動產的評價屬稅理士、不動產領域，本事務所的[報酬表](https://luck428.com/legal/ryokin)另行定之。

## 2名證人可委託何人？何人不得擔任證人？

公正證書遺言須2名以上證人在場（民法第969條），惟非人人均得擔任證人。民法第974條將下列之人定為證人、在場人的欠格事由。

| 款 | 不得擔任證人之人 |
| --- | --- |
| 第1款 | 未成年人 |
| 第2款 | 推定繼承人、受遺人，及其配偶與直系血親 |
| 第3款 | 公證人的配偶、四親等內親屬、書記及受僱人 |

易言之，處於受領財產立場的家屬，及其配偶、子女等，均不得擔任證人。身邊無適任者時，公證役場亦有介紹證人的作法。四葉集團的行政書士，身負保密義務，得受託安排證人或以證人身分在場。因得否擔任證人，與推定繼承人、受遺人範圍的確認相關聯，故與繼承關係的整理一併進行為實務作法。

## 至當日須收集的文件，及公證役場的流程為何？

公正證書遺言，係於確定原案後與公證人事前協商，並於當日在2名證人在場下作成。預先備妥如下文件（因公證役場而異）。

| 區分 | 主要文件 |
| --- | --- |
| 遺言人本人 | 印鑑登記證明書等本人確認資料 |
| 遺予繼承人時 | 顯示遺言人與繼承人關係的戶籍（戶籍謄本等） |
| 遺贈予繼承人以外者時 | 受遺人的住民票等 |
| 財產資料 | 不動產的登記事項證明書、固定資產評價證明書，存款等資料 |

當日，遺言人向公證人口授遺言要旨，公證人將筆記內容向遺言人與證人宣讀或令其閱覽，若無誤則全體簽名蓋章。自2025年（令和7年）10月1日起，依公證人法的改正（令和5年法律第53號），公正證書的作成手續已數位化，於指定公證役場得循序利用網路會議（遠端方式）及以電子資料作成、交付。得否利用，須向公證役場確認。四葉集團的行政書士，承辦原案擬訂支援、必要文件收集與公證役場的日程協調。

## 作成後若改變心意，遺言可否改寫？

遺言於作成後仍得隨時改寫。民法第1022條規定，遺言人得隨時依遺言方式撤回其遺言的全部或一部。前遺言與後遺言抵觸的部分，視為以後遺言撤回（民法第1023條）。

| 情形 | 處理（依據） |
| --- | --- |
| 欲變更內容 | 得隨時以新遺言撤回、變更（民法第1022條） |
| 前後遺言抵觸 | 抵觸部分視為以後遺言撤回（民法第1023條） |
| 撤回公正證書遺言 | 得以新遺言（公正證書或自書均可）撤回 |

撤回公正證書遺言，毋須將前公正證書實體銷毀，而以新遺言表示其意思。撤回或數遺言並存時的優劣，已於[遺言的撤回、抵觸與數遺言的優劣](https://luck428.com/legal/column/yuigon-tekkai-teishoku-fukusu-yuigon-yuretsu)整理。是否須改寫，宜參酌家庭結構與財產的變動定期檢視為妥。

## 原案、登記、稅務、爭執各該委託何人（分工）？

因相關專業人員分屬不同領域，原則上請與各專業以獨立的事業體分別簽約。四葉集團的行政書士，以獨立的事業體承辦遺言原案的擬訂支援、必要文件的收集、與公證役場的日程協調，以及證人的安排。

| 委託對象 | 主要角色 |
| --- | --- |
| 行政書士（本事務所） | 原案擬訂支援、文件收集、日程協調、證人安排 |
| 公證人 | 公正證書遺言的作成、原本的保管 |
| 律師 | 繼承人間有爭執時的對應、法律效果的最終判斷 |
| 司法書士 | 遺言執行後的繼承登記、遺贈登記 |
| 稅理士 | 繼承稅、納稅資金的試算 |

遺言「何財產遺予何人」的法律效果最終判斷，屬具資格者的領域，行政書士不得代為判斷或保證。涉及繼承不動產出售時，亦得利用由不同事業體的不動產業者所設的[繼承不動產諮詢窗口](https://luck428.com/souzoku)。亦請參閱本事務所的[受任流程](https://luck428.com/legal/nagare)。與各專業人員均以獨立的事業體簽約，彼此不收取介紹費。

## 常見問題

**Q. 訂立公正證書遺言後，死亡後的檢認即可免除嗎？**
A. 是。公正證書遺言由公證人作成、原本由公證役場保管，故無須家庭裁判所的檢認。自書遺言原則上須檢認，惟利用法務局的自書遺言保管制度者則免檢認。檢認的要否，依遺言方式與保管方法而異。

**Q. 手續費是以財產總額乘以單一費率而定嗎？**
A. 否。依公證人手續費令，就以繼承、遺贈受領財產之人分別將其受領價額套入別表計算後合計。目的價額合計1億日圓以下時另加遺言加算13,000日圓，正本、謄本的交付與出張另計費用。正確金額以財產評價為據於公證役場確認。

**Q. 可否委託家屬擔任證人？**
A. 受領財產的推定繼承人、受遺人，及其配偶、直系血親，均不得擔任證人（民法第974條）。未成年人及公證人的近親等亦不得。無適任者時，公證役場有介紹證人之例，身負保密義務的行政書士亦得受託安排證人或在場。

**Q. 已訂立的公正證書遺言可否日後變更？**
A. 可。遺言人得隨時依遺言方式撤回全部或一部（民法第1022條）。若作成與前遺言抵觸的新遺言，抵觸部分視為以後遺言撤回（第1023條）。毋須銷毀前公正證書，而以新遺言表示其意思。
