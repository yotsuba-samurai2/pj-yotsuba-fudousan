**結論（先說要點）**：中國・台灣企業結束日本子公司時，依序進行股東會解散決議、清算人之清算、對債權人之官報公告與個別催告、剩餘財產之確定・分配，至清算了結（公司法第471條・第475條・第499條・第507條）。以經營・管理在留資格來日之經營者，因公司清算而喪失該在留資格之基礎，故由入管審查變更為其他在留資格或切換至出國準備。剩餘財產匯回本國涉及稅務與外匯法之報告。本文為一般資訊提供，整理撤退流程與各專業人員之分工，不為具體法律判斷。

## 中國・台灣企業結束日本子公司時，應自何處著手？

結束日本法人（股份有限公司）時，先自判斷如何使公司消滅（通常清算，或若債務超過則特別清算・破產）著手。若資產超過負債、有全額清償債務之可能，即依公司法之通常清算程序。著手前應整理之主要項目如下。

| 著手前應確認之事 | 內容 |
| --- | --- |
| 清算方式 | 通常清算，或債務超過時之特別清算・破產（能否清償之判斷） |
| 董監・員工 | 代表人・董事之退任、員工之解僱預告・社會保險之資格喪失 |
| 許可 | 事業若有許可，是否須廢止届・返還 |
| 在留資格 | 以經營・管理等在留資格停留之董監之扱 |
| 財產 | 不動產・存款・應收款等資產，應付款・借款等負債 |

解散・清算因登記・稅務・勞務・在留資格・對外匯款同時並行，於著手前先定全體順序即為關鍵。究應依何方式之最終判斷，依債務狀況由律師・司法書士等有資格者為之。

## 解散・清算之登記與官報公告以何順序進行？

股份有限公司之解散事由由公司法第471條所定，實務上以股東會決議（公司法第309條第2項之特別決議）解散為一般。解散後公司須清算（公司法第475條），清算人進行現務之了結・債權之收取・債務之清償・剩餘財產之分配。順序之骨架如下。

1. 於股東會決議解散，並選任清算人（公司法第471條）
2. 辦理解散之登記・清算人之登記（司法書士）
3. 對債權人以官報公告應於一定期間內申報債權之旨，並對已知債權人個別催告。此期間不得短於2個月（公司法第499條）
4. 債權申報期間經過後清償債務，並將剩餘財產分配予股東
5. 清算事務終了後作成決算報告，受股東會承認（公司法第507條）。經承認清算即了結，辦理清算了結之登記（司法書士）

公司法第499條之官報公告，係保護債權人之程序，申報期間須取2個月以上。因有此期間，自決定解散至清算了結，縱順利亦須數月。登記（解散・清算人・清算了結）由司法書士擔當。

## 以經營・管理在留資格來日之經營者，撤退後在留資格如何？

經營・管理在留資格以於日本進行事業之經營或管理活動為前提。結束公司停止事業後，該活動之基礎喪失，故原則上無法維持原在留資格。撤退後之選項，依入管（出入國在留管理廳）之個別審查分為下列。

- 若於日本繼續其他事業或就勞，申請變更為對應之在留資格
- 若離開日本，於清算手續或歸國準備尚存期間，切換為出國準備之在留資格（特定活動）後出國

出國準備之特定活動之在留期間，及是否准予變更，由入管依清算進度・有無餘務・個別情事判斷。於在留期限將屆而清算未了、董監多人而扱不同等情形，須及早確認。在留資格變更・切換至特定活動之申請書類製作由行政書士處理，許可事業則廢止届之提出亦屬行政書士擔當。最終之准否由入管審查判斷。

## 將剩餘財產匯回本國時，稅務・外匯之注意點為何？

清算時，就至解散日之事業年度、其後清算中之各事業年度、剩餘財產確定之事業年度，須為法人稅等之確定申報（法人稅法）。將剩餘財產分配・匯款予股東（本國母公司等）時，含源泉徵收（視同股利之課稅等）之要否在內，稅務上之整理不可或缺。稅額之計算與申報由稅理士擔當。

對外匯款，依外國為替及外國貿易法第55條（支付等之報告），居住者等向外國為一定支付等時，除政令所定之情形外，須為報告。實務上，經銀行等之支付等之報告經由日本銀行為之，一定金額（超過3,000萬日圓相當額之支付等）為報告對象（參照日 2026-10-30）。金額基準與提出期限由政令・告示所定且運用亦變動，具體要否請於匯款時以金融機構與日本銀行之最新案內確認。

| 項目 | 擔當・確認處 |
| --- | --- |
| 清算中各事業年度・剩餘財產確定事業年度之確定申報、源泉徵收之要否 | 稅理士 |
| 剩餘財產之對外匯款之執行 | 金融機構 |
| 支付等之報告（外國為替及外國貿易法第55條） | 以金融機構・日本銀行之最新案內確認要否 |

稅務與匯款，因金額或源泉徵收之適用而結論有異，本文止於制度框架之資訊提供，不就具體稅額・匯款可否判斷。

## 清算登記・在留資格・稅務・匯款應分派予何人？

日本法人之撤退，因多項手續同時進行，分工推進。

- 在留資格之變更・切換至出國準備（特定活動）之申請、許可之廢止届 → 四葉行政書士事務所（行政書士）。止於資料與資訊之提供，不為具體法律判斷
- 解散之登記・清算人之登記・清算了結之登記 → 司法書士
- 清算事業年度・剩餘財產確定事業年度之確定申報、源泉徵收・視同股利之稅務 → 稅理士
- 員工之解僱預告、社會保險・勞動保險之資格喪失手續 → 社會保險勞務士
- 剩餘財產之對外匯款・外匯法報告之執行 → 金融機構
- 債務超過之特別清算・破產、與債權人之紛爭 → 律師
- 總公司大樓等公司所有不動產之出售 → 別事業體之四葉不動產股份有限公司（宅地建物交易業者）

解散之登記・清算人之登記・清算了結之登記屬司法書士，清算之確定申報與源泉徵收之稅務屬稅理士，員工之解僱預告與社會保險之資格喪失屬社會保險勞務士，債務超過之特別清算・破產及與債權人之紛爭屬律師，均為獨立的事業體，個別簽約・辦理。公司所有不動產之出售，由與四葉行政書士事務所為別事業體之四葉不動產股份有限公司，以獨立的事業體個別契約對應。各領域以與各窗口・資格者個別簽約為前提，本事務所不收取介紹費。撤退與在留期限、申報期限有關聯，請自決定順序之階段起諮詢。受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)，業務範圍請見[業務範圍一覽](https://luck428.com/legal/services)。進出・設立側之手續請見[台灣企業之日本分公司・外國公司之登記](https://luck428.com/legal/column/taiwan-kigyo-nihon-shiten-gaikoku-kaisha-touki)、[經營・管理在留資格與公司設立](https://luck428.com/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)，更新時之事業繼續性請見[經營・管理之更新與事業繼續性之舉證](https://luck428.com/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)。

## 常見問題

**Q. 結束日本子公司應自何處著手？**
A. 先判斷能否全額清償債務（通常清算，或債務超過時之特別清算・破產）。通常清算者，自股東會解散決議與清算人選任（公司法第471條）起，進至解散之登記、對債權人之官報公告與個別催告（公司法第499條）、債務清償與剩餘財產分配、決算報告之承認・清算了結（公司法第507條）。因登記・稅務・勞務・在留資格・匯款同時進行，於著手前先定順序甚為重要。

**Q. 官報公告之期間須多久？**
A. 清算股份有限公司須對債權人以官報公告應於一定期間內申報債權之旨，並對已知債權人個別催告。此期間不得短於2個月（公司法第499條）。因有此期間，自解散至清算了結縱順利亦須數月。公告應附記未於期間內申報之債權人自清算除斥之旨。

**Q. 經營・管理在留資格於結束公司後失效嗎？**
A. 經營・管理在留資格以事業之經營・管理活動為前提，結束公司後其基礎喪失，原則上無法維持原狀。若於日本繼續其他活動，入管審查變更為對應之在留資格；若歸國，則切換為出國準備之特定活動。因在留期間與准否依清算進度及個別情事而定，請及早向行政書士・入管確認。

**Q. 將剩餘財產匯回本國時應注意何事？**
A. 清算中各事業年度與剩餘財產確定之事業年度須為法人稅等之確定申報，分配含源泉徵收（視同股利之課稅等）之要否（法人稅法）。稅額之計算・申報由稅理士擔當。對外匯款可能為外國為替及外國貿易法第55條之支付等之報告對象，超過一定金額之支付等為對象。具體要否請於匯款時以金融機構與日本銀行之最新案內確認。
