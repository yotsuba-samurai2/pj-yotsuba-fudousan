**結論（先講重點）**：經營業務用冷凍・空調設備的事業，會依「做什麼」而重疊各自不同的許可。若販售冷媒等高壓氣體，須依高壓氣體保安法第20條之4辦理販售事業申報（每個販售所於事業開始日的20日前向都道府縣知事提出）；若對業務用空調或業務用冷凍冷藏機器充填、回收冷媒氟氯碳化物，則須依「氟氯碳化物類之使用合理化及管理適正化相關法律」（氟氯碳化物排出抑制法）第27條第1項取得第一種氟氯碳化物充填回收業者登錄（由管轄業務區域的都道府縣知事辦理，有效期間5年＝第30條）。冷凍設備本身的設置（高壓氣體的「製造」）則依冷凍能力分為高壓氣體保安法第5條的許可或申報，並適用冷凍保安規則。四葉行政書士事務所在行政書士法第1條之2的範圍內，以另行簽約承接向官署提出之文件的製作與提出，僅提供資料與資訊。設備施工與保安由有資格的工程業者與保安責任者、物件由另一事業體的不動產、登記由司法書士、稅務由稅理士負責，均為獨立的事業體並分別簽約。本文為一般性資訊提供，不就個別登錄・申報的可否作出具體法律判斷。本所不收取介紹費。

## 經營業務用冷凍・空調設備，首先需要哪些許可？

冷凍・空調設備事業會因「做什麼」而改變所需手續。一項事業常重疊多項手續，因此先依行為別區分。

| 所為行為 | 主要依據 | 手續性質 |
| --- | --- | --- |
| 販售冷媒等高壓氣體 | 高壓氣體保安法第20條之4 | 販售事業申報（都道府縣知事） |
| 對業務用空調・業務用冷凍冷藏機器充填・回收冷媒氟氯碳化物 | 氟氯碳化物排出抑制法第27條第1項 | 第一種氟氯碳化物充填回收業者登錄（都道府縣知事） |
| 以冷凍設備「製造」高壓氣體（冷凍能力在一定以上） | 高壓氣體保安法第5條 | 依冷凍能力分為許可（第一種製造者）或申報（第二種製造者） |

「販售」「充填・回收」「製造（冷凍）」是不同制度，符合哪一項就各自需要手續。例如自行開設冷凍倉庫並做到補充冷媒與更新機器，販售、充填回收、冷凍設備設置就可能各自分別被要求。符合哪個行為會隨事業形態而變，因此在設備與交易內容確定後，一邊向主管都道府縣（高壓氣體・氟氯碳化物業務課）洽詢一邊整理。相關登錄制度中，汽車（車用空調＝第二種特定產品）側的氟氯碳化物回收，另於[收取業・氟氯碳化物回收業登錄](https://luck428.com/legal/column/jidosha-recycle-hikitori-furon-kaishu-gyo-touroku)處理。

## 高壓氣體保安法的販售事業申報，向何處・何時提出？

欲經營販售高壓氣體事業者，須就每個販售所，於事業開始日的20日前，附上記載所販售高壓氣體種類等的書面，向都道府縣知事申報（高壓氣體保安法第20條之4）。提出者稱為「販售業者」。

| 項目 | 條文整理 |
| --- | --- |
| 提出對象 | 都道府縣知事（每個販售所） |
| 時期 | 事業開始日的20日前（第20條之4） |
| 承繼 | 事業全部讓與・繼承・合併・分割時，應遲滯地申報（第20條之4之2） |
| 廢止 | 廢止事業時，應遲滯地申報（第21條） |

但有例外。第一種製造者於其事業所販售自行製造之高壓氣體等政令所定情形，無須申報。又，向一般消費者等販售液化石油氣（LP氣）時，屬液石法的販售事業登錄對象，而非高壓氣體保安法，制度分歧。在市的區域，市長或消防長可能為受理窗口，提出處・樣式・附件依市町村而異，故在販售所所在地確定後，向主管都道府縣（或市的消防保安業務課）確認（經濟產業省及各都道府縣之說明・參照日 2026-11-03）。

## 第一種氟氯碳化物充填回收業者登錄的要件與有效期間為何？

欲以營業方式對業務用空調或業務用冷凍冷藏機器（含具冷凍冷藏功能之自動販賣機。此等稱第一種特定產品＝氟氯碳化物排出抑制法第2條第3項）中作為冷媒充填之氟氯碳化物進行充填・回收者，須取得管轄欲經營業務區域之都道府縣知事的登錄（第27條第1項）。家用空調不屬第一種特定產品，車用空調（第二種特定產品＝第2條第4項）的氟氯碳化物回收，則屬汽車回收法架構的另一制度。

| 項目 | 條文整理 |
| --- | --- |
| 登錄對象 | 管轄業務區域的都道府縣知事（第27條第1項） |
| 申請書記載 | 姓名・住所、供業務使用之設備等（第27條第2項） |
| 登錄之拒絕 | 欠格事由，或回收設備不符基準等（第29條） |
| 有效期間 | 5年；未更新即失效（第30條第1項・第2項） |
| 變更申報 | 登錄事項變更時，30日內申報（第31條） |

登錄簿供一般閱覽（第32條）。回收設備的技術基準、欠格事由的具體內容、更新受理時期（依市町村有自有效期限前2〜3個月起等）與手續費，依都道府縣運用不同且會修正，故於申請前以主管都道府縣的最新說明確認。若在多個都道府縣經營業務，須向窗口確認是否各區域皆需登錄。符合哪個要件的最終適用，由辦理登錄的都道府縣審查後判斷。

## 開設冷凍倉庫時，許可會以什麼順序排列？

設置冷凍倉庫並經營低溫物流時，設備・保安・登錄・勞務・物件會並行推進。大致順序如下，責任依領域分工。

- 物件選定與適合確認（用途地域・樓板荷重・電力容量等） → 另一事業體的四葉不動產股份有限公司（宅地建物交易業者），以獨立的事業體另行簽約對應
- 冷凍設備的設計・施工，及依冷凍能力辦理高壓氣體保安法第5條的許可（第一種製造者）或申報（第二種製造者） → 有資格的設備・電氣工程業者與高壓氣體製造保安責任者。文件製作由行政書士協助
- 若處理冷媒氟氯碳化物，須辦理第一種氟氯碳化物充填回收業者登錄（第27條第1項）
- 若販售冷媒等高壓氣體，須辦理販售事業申報（第20條之4）
- 若以倉庫業經營，須辦理倉庫業法的登錄（符合設施設備基準；物件要件於不動產側確認）
- 員工的工作規則・低溫作業安全衛生・輪班 → 社會保險勞務士（另一事業體）

倉庫業法的登錄與所保管食品・醫藥品的營業許可主管各異，均為獨立的事業體並分別簽約・辦理。低溫物流設施的物件適合整理於[冷藏・冷凍倉庫的物件要件](https://luck428.com/column/reizo-reito-souko-butsuryu-bukken-youken)（不動產側專欄，為另一事業體），低溫作業的勞務則於社會保險勞務士側整理。因前後順序會隨設備規模與事業形態而變，宜先描繪全貌再決定著手順序。

## 行政書士能製作的文件，與施工・保安須委由有資格者的部分，如何區分？

行政書士以製作向官署提出之文件及代理提出手續為獨占業務（行政書士法第1條之2）。設備施工與保安監督則屬其他資格者的領域。責任如下分工，均為獨立的事業體並分別簽約・辦理。

- 販售事業申報、第一種氟氯碳化物充填回收業者登錄申請、冷凍設備相關許可・申報之文件製作與提出代理 → 四葉行政書士事務所（行政書士）。僅提供資料與資訊，不作具體法律判斷
- 冷凍設備・配管・電氣設備的施工 → 高壓氣體製造保安責任者、電氣工程士，視規模由取得營造業許可之施工業者
- 高壓氣體之製造・保安監督 → 高壓氣體製造保安責任者等有資格者
- 開業物件・倉庫用地的選定・租賃媒介 → 另一事業體的四葉不動產股份有限公司（宅地建物交易業者）
- 設立法人經營時的設立登記 → 司法書士
- 開業後的記帳・稅務申報 → 稅理士
- 工作規則・安全衛生・輪班等勞務 → 社會保險勞務士
- 交易・契約糾紛的代理・法律判斷 → 律師

各領域以與各窗口・資格者分別簽約為前提，本所不收取介紹費。即使在不確定是否需要登錄或申報、窗口在哪的階段，也請在決定設備與交易內容前先諮詢。受任流程請見[受任流程](https://luck428.com/legal/nagare)、費用請見[報酬額表](https://luck428.com/legal/ryokin)、承辦業務請見[承辦業務一覽](https://luck428.com/legal/services)。相關許可另請參閱[毒物劇物販售業登錄](https://luck428.com/legal/column/dokugekibutsu-hanbaigyo-touroku-kozo-setsubi-kijun)與[電氣工程業登錄](https://luck428.com/legal/column/denki-koji-gyo-touroku-eigyosho-shunin)。

## 常見問題

**Q. 只是販售冷媒，也需要高壓氣體的手續嗎？**
A. 若以營業方式販售冷媒等高壓氣體，須就每個販售所於事業開始日的20日前向都道府縣知事辦理販售事業申報（高壓氣體保安法第20條之4）。但第一種製造者於其事業所販售自行製造之氣體等政令所定情形，無須申報。向一般消費者等販售LP氣時，另須依液石法登錄，制度分歧，故請就所處理的氣體與販售形態向主管都道府縣確認。

**Q. 第一種氟氯碳化物充填回收業者登錄向何處提出，有效幾年？**
A. 向管轄欲經營業務區域之都道府縣知事取得登錄（氟氯碳化物排出抑制法第27條第1項）。有效期間5年，未更新即失效（第30條）。登錄事項變更時須30日內申報（第31條）。回收設備基準、更新受理時期與手續費依都道府縣運用不同，故請於申請前以主管都道府縣的最新說明確認。

**Q. 業務用空調、家用空調、車用空調的處理不同嗎？**
A. 不同。業務用空調與業務用冷凍冷藏機器為第一種特定產品（氟氯碳化物排出抑制法第2條第3項），其充填・回收屬第一種氟氯碳化物充填回收業者登錄對象。家用空調不屬第一種特定產品。車用空調為第二種特定產品（第2條第4項），其氟氯碳化物回收屬汽車回收法架構的另一制度。

**Q. 從設備施工到文件製作，能委由一家事務所全部處理嗎？**
A. 文件製作・提出代理由行政書士、冷凍設備・電氣設備施工由有資格工程業者、高壓氣體保安監督由高壓氣體製造保安責任者、物件由另一事業體的四葉不動產股份有限公司、登記由司法書士、稅務由稅理士、勞務由社會保險勞務士負責，均為獨立的事業體並分別簽約。可於同一窗口受理諮詢並整理交付各負責者，但受任分開。本所不收取介紹費。
