**先講重點：**在日本經營租車或共享汽車，須取得自家用自動車有償貸渡業許可。備妥申請文件與保險，規劃取得許可後的車輛登錄、租賃紀錄及整備管理，再向主要事務所所在地的運輸支局申請。

更新日期：2026-10-10

## 租車業許可要向哪裡申請？

道路運送法第80條第1項的許可，由主要事務所所在地的運輸支局受理，按時計費的共享汽車也包含在內。以出租人為車輛使用者的租車業，依國土交通省通達進行審查。

租車是出租車輛的事業，不得隨租賃提供駕駛人。代客駕駛客人自己的車輛，或由業者運送乘客，分屬不同制度。請參閱[駕駛代行的認定](/zh-tw/legal/column/unten-daiko-nintei-eigyosho-zuihan-jidosha-yoken)及[介護計程車許可](/zh-tw/legal/column/kaigo-taxi-fukushi-yuso-kyoka-shako-yoken)。

貨物運送業的條件，請參閱[一般貨物自動車運送許可與營業所、車庫要件](/zh-tw/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)。

## 申請文件與保險要準備什麼？

本次確認的國土交通省通達，最後記載的修正為國自旅第55號、2022年5月31日，附則規定適用於2022年6月1日以後的許可。請使用申請機關目前的表格。

| 文件 | 主要內容 |
|---|---|
| 申請書與申請人資料 | 法人的登記事項證明書、個人的住民票等 |
| 租金與租賃條款 | 費用及使用條件 |
| 不符合消極資格的確認書 | 確認申請人、法人董事等相關人員 |
| 各事務所、各車種的配置車輛數表 | 各事務所的車種與台數 |
| 營運計畫 | 負責人、員工培訓、整備管理與保險等 |

2022年通達列有刑罰紀錄、許可遭撤銷等消極資格，但不能直接視為2026年現行表格的內容。懲役與禁錮均自2025年6月1日起改為拘禁刑；本許可消極資格的過渡規定如何適用，尚未驗證。申請人、董事等的個別情形，須由運輸支局及具資格者依最新確認書核對。

| 通達的保險類別 | 最低保障額 |
|---|---|
| 對人保險 | 每人8,000萬日圓以上 |
| 對物保險 | 每件事故200萬日圓以上 |
| 搭乘者保險 | 每人500萬日圓以上 |

搭乘者保險可包含人身傷害保險。商品保障範圍與投保條件須向保險公司確認，並準備證明符合基準的文件。

## 許可後如何揭示條款及保存租賃紀錄？

通達的許可條件禁止出借營業名義，以及隨租賃提供、介紹或安排駕駛人。駕駛人資訊的提供也有禁止及例外規定，不能認為只提供聯絡方式就一定可以；請向運輸支局確認通達所引用通知的適用範圍。

| 項目 | 許可條件 |
|---|---|
| 不提供駕駛人的告知 | 依通達認可的方法，於事務所揭示、網站公開，或以書面、電子方式提示等 |
| 租金與租賃條款 | 於事務所公眾易見處揭示，或於網站公開 |
| 貸渡簿 | 記錄承租人、駕駛人、駕照、車輛、租賃日期、費用、事故等，自租賃結束日起保存2年 |
| 貸渡證 | 以書面或電子方式交付，由駕駛人攜帶；租車型共享汽車有例外 |
| 年度報告 | 每年5月31日前提交前一年度的貸渡實績報告等 |

以上是通達的許可條件。共享汽車的營運方式能否適用貸渡證交付、攜帶的例外，須向申請機關確認。

## 車輛登錄與整備管理者的門檻如何確認？

租車仍以自家用車登錄，使用出租用途的平假名「わ」（部分為「れ」）。平假名用途標示與數字分類號碼不同，營業許可與車輛登錄也屬不同程序。

中部運輸局2022年6月的說明，對一個事務所使用的自家用車列出以下整備管理者門檻。

| 車種 | 須選任的台數 |
|---|---|
| 核定乘車人數11人以上的汽車 | 1輛以上 |
| 車輛總重8t以上的貨車 | 5輛以上 |
| 核定乘車人數10人以下的乘用車、總重未滿8t的貨車 | 10輛以上 |

請依道路運送車両法第50條及施行規則第31條之3，向運輸支局確認現行規定，包括車種、車輛使用者及持有、使用的分類。

通達不允許出租核定乘車人數30人以上或車長超過7m的自家用巴士，以及靈柩車。自家用小型巴士另有經營實績等條件，新業者未必能依一般乘用車的條件開業。個別車種的申請機關條件尚未驗證。

## 開業準備分別由誰協助？

| 專業人員、業者 | 主要角色 |
|---|---|
| 四葉行政書士事務所 | 許可、申報文件製作與代理；資格業務範圍內的公司章程等文件支援 |
| 司法書士等 | 公司設立、董事變更的登記 |
| 稅理士 | 稅務諮詢、申報 |
| 申請人、汽車銷售店等 | 車輛登錄 |
| 保險公司、整備業者 | 保險商品、車輛整備 |
| 四葉社会保険労務士事務所 | 僱用後的勞務、勞動保險與社會保險 |
| 四葉不動産株式会社 | 營業所物件尋找、租賃仲介 |
| 律師 | 賠償紛爭、刑事案件等 |

四葉行政書士事務所、四葉社会保険労務士事務所、四葉不動産株式会社各自為獨立的事業體。客戶與各專業人員、業者分別簽約，由其直接請款、直接收款。本事務所不收取介紹費。許可的審查與決定由行政機關進行。請參閱[受任流程](/zh-tw/legal/nagare)、[報酬額表](/zh-tw/legal/ryokin)及[許認可服務](/zh-tw/legal/services)。

## 常見問題

**Q. 租車業需要許可還是申報？**
A. 以事業方式有償出租自家用車，須取得道路運送法第80條第1項的許可，共享汽車也包含在內。請向主要事務所所在地的運輸支局申請。

**Q. 租車會使用營業用綠色車牌嗎？**
A. 租車仍以自家用車登錄，使用出租用途的平假名「わ」（部分為「れ」）。平假名與分類號碼不同，車輛登錄與營業許可也是不同程序。

**Q. 可以連同駕駛人出租車輛嗎？**
A. 隨租賃提供、介紹或安排駕駛人屬禁止事項，須依通達認可的事務所揭示、網站公開等方法告知。提供駕駛人資訊的例外，也請先向申請機關確認，不自行判斷。

**Q. 一定要選任整備管理者嗎？**
A. 依車種與台數而定。本次確認的運輸局說明中，每個事務所的門檻為11人以上車輛1輛、8t以上貨車5輛、10人以下乘用車或未滿8t貨車10輛以上。請連同使用者、使用分類向運輸支局確認現行規定。
