**結論（先講重點）**：「日本人的配偶等」是以日本人的配偶・特別養子・或以日本人之子出生者為對象的居留資格（出入國管理及難民認定法 別表第二）。認定・變更・更新會審視婚姻的實體與持續性；若未從事作為配偶的活動而持續6個月以上居留，除有正當理由外，即屬居留資格取消的對象（入管法第22條之4）。

**資訊確認日：2026年10月24日**。本文為有中國・台灣出身配偶的家庭，以及支援居留手續的當地專業人士，將「日本人的配偶等」在認定・變更・更新時所確認的要點與取消的架構整理為資訊提供。條文以[e-Gov法令檢索](https://laws.e-gov.go.jp/law/326CO0000000319)的法律名稱（出入國管理及難民認定法）核對，運用以出入國在留管理廳的說明（參照日2026-10-24）確認。審查的內部運用與個別案件的許否皆未經查證。個別居留的可否由地方出入國在留管理官署判斷，紛爭與法律判斷由律師處理。

## 「日本人的配偶等」以哪些人為對象？

依出入國在留管理廳的說明（參照日2026-10-24），本居留資格的對象為「日本人的配偶或特別養子，或以日本人之子出生者」。日本人的夫或妻、日本人的親生子女、特別養子皆屬之。在留期間為5年・3年・1年・6個月其中之一。

| 區分 | 對象 |
| --- | --- |
| 日本人的配偶 | 與日本人具法律上婚姻關係者 |
| 日本人的特別養子 | 依民法特別收養之子 |
| 以日本人之子出生者 | 出生時父或母為日本人的親生子女 |

居留資格有三種手續。要迎接在海外的配偶時，申請在留資格認定證明書；要自其他居留資格轉換時，申請在留資格變更許可；要延長同一資格時，申請在留期間更新許可。申請由本人或地方出入國在留管理官署所認可的代理人等為之。

## 認定・更新時如何確認婚姻的實體？

既以「配偶」身分居留，便會確認婚姻並非僅具形式、而具實體且持續。出入國在留管理廳的提出資料一覽（參照日2026-10-24）會要求能顯示婚姻實體與生活狀況的資料。具體樣式與份數因申請種類與官署而異，請以最新一覽確認。

| 確認的觀點 | 資料示例（依廳的說明） |
| --- | --- |
| 婚姻的成立 | 戶籍謄本、本國的婚姻證明等 |
| 同居・生活的實體 | 載有全戶成員的住民票謄本 |
| 婚姻的實體・交流 | 質問書、夫妻的照片、聯絡紀錄等 |
| 生計・安定性 | 身元保證書、住民稅的課稅・納稅證明、在職證明等 |

這些資料用以綜合審視「婚姻是否具實體且持續」。即使資料在形式上齊備，若無法確認實體，仍會審慎審查。要如何整備哪些資料因個別情事而異，最終許否由官署判斷（本文不作個別可否判斷）。

## 收入或同居不安定時更新會被不許可嗎？

收入與同居狀況是更新審查時會考量的要素之一。惟不會以單一數字機械式決定，而會綜合審視婚姻的實體與持續性、生活的安定性。於收入偏低、轉職不久、因外派或住院而暫時分居等情形時，實務上一般的因應是附上理由書與佐證資料，以顯示實體仍持續。

是否可能被不許可、以及可用哪份資料補充何者，因個案而異。本文僅止於一般資訊提供，個別判斷有賴向地方出入國在留管理官署確認及向有資格的專業人士諮詢。

## 分居・離婚・喪偶時居留資格會如何（22條之4）？

以「日本人的配偶等」居留者，若未從事作為配偶的活動而持續6個月以上居留，除有正當理由外，即屬居留資格取消的對象（入管法第22條之4）。出入國在留管理廳的說明（參照日2026-10-24）將此取消事由的對象定為以「日本人的配偶等」「永住者的配偶等」居留的配偶，日本人之子・特別養子不在此列。

| 情形 | 與居留資格的關係（一般整理） |
| --- | --- |
| 外派・住院等暫時分居 | 若婚姻持續，不致立即取消；說明情事有效 |
| 離婚・喪偶 | 無法再從事配偶活動；以6個月為一參考點考慮變更居留資格等 |
| 為逃離DV等的分居 | 可能該當「正當理由」（法務省於2012年7月公布具體例） |

取消前會由入國審查官進行意見聽取，本人可陳述意見、提出證據、請求閱覽資料。此第7號為取消後指定出國期間（以30日為上限）的類型，並非立即遣送出境（廳的說明・參照日2026-10-24）。離婚・喪偶後仍想在日本繼續居留者，實務上的基本做法是及早考慮轉換為工作資格或定住者等。對該人而言何者該當「正當理由」或變更的可能性，因個別情事而異，最終判斷由官署為之。

## 紛爭或戶籍手續該向誰諮詢？（分別受任的整理）

圍繞國際結婚與居留的手續，分為居留・紛爭・戶籍等性質各異的工作。基本做法是分別向各自的承辦人諮詢。

| 諮詢對象 | 負責範圍 |
| --- | --- |
| 四葉行政書士事務所 | 在留資格認定・變更・更新的申請書件製作支援、資料整理 |
| 律師 | 離婚・DV・親權・財產分配等紛爭的代理與法律判斷 |
| 市區町村窗口 | 婚姻登記・戶籍・住民票的手續 |
| 本國公家機關・當地專業人士 | 本國婚姻證明・出生證明等的取得與認證 |

四葉行政書士事務所、四葉社會保險勞務士事務所、四葉不動產株式會社各為不同事業體，均作為獨立的事業體受任。律師也是與本事務所各自獨立的事業體。請與各領域承辦人分別簽約，由各受任者直接請款、收款。本事務所不收取介紹費。離婚・DV・親權等紛爭的代理與法律判斷屬律師領域，行政書士不得處理。戶籍・婚姻登記為市區町村的手續，居留的許否為出入國在留管理官署的手續，兩者皆非受任契約的對象。

## 常見問題

**Q. 辦了婚姻登記就能立即以「日本人的配偶等」居留嗎？**
A. 僅婚姻成立並不足夠，還會確認婚姻具實體且持續。在海外的配偶申請在留資格認定證明書；在日本自其他資格轉換者申請在留資格變更許可，並以質問書・住民票・交流資料等顯示實體（出入國在留管理廳・參照日2026-10-24）。許否由官署判斷。

**Q. 離婚後居留資格會立刻消失嗎？**
A. 離婚不會立即使資格消滅，但因無法再從事配偶活動，若該狀態持續6個月以上且無正當理由，即可能該當取消事由（入管法第22條之4）。實務上一般的因應是以6個月為一參考點，及早考慮轉換為工作資格或定住者等。

**Q. 為逃離DV而分居的情形會如何？**
A. 為逃離DV等的分居可能該當「正當理由」，法務省於2012年7月公布了不予取消的具體例。諮詢紀錄・保護命令・診斷書等可作為顯示情事的資料。是否該當因個別情事判斷，請及早向律師或地方出入國在留管理官署諮詢。

**Q. 收入少就一定會被不許可更新嗎？**
A. 並非一定不許可。收入是考量要素之一，會綜合審視婚姻的實體・持續性與生活的安定性。轉職不久或暫時性收入減少等情事，一般以理由書與佐證資料說明。展望因個案而異，有賴向官署確認及向專業人士諮詢。
