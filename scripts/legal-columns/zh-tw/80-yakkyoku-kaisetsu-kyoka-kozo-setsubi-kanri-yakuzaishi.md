**先講重點：** 開設藥局（進行調劑的藥局），須就各店舖取得所在地都道府縣知事（設有保健所的市、特別區為市長、區長）的藥局開設許可（醫藥品醫療機器等法第4條第1項）。許可的主要要件有3項：①構造設備符合藥局等構造設備規則的基準；②調劑與醫藥品販賣的業務體制符合基準；③申請人未落入欠格事由（同法第5條）。藥局須置管理藥劑師實地管理，管理藥劑師原則上不得在該藥局以外的場所以業務身分兼任藥事實務（同法第7條第3項）。本文以一般性資訊提供整理要件與流程，許可與否由藥務主管窗口判斷，本事務所不保證取得許可。

## 藥局開設許可的構造設備基準有哪些要求？

醫藥品醫療機器等法（昭和35年8月10日法律第145號。舊藥事法。以下稱「醫藥品醫療機器等法」）第4條第1項規定，藥局非經所在地都道府縣知事（所在地位於設有保健所的市或特別區時為市長、區長）的許可，不得開設。該許可若未每6年更新一次，即因期間經過而失效（同條第4項）。

能否取得許可的基準規定於同法第5條，落入下列任一情形時可能不予許可：①構造設備不符厚生勞動省令所定基準（第1號）；②進行調劑及醫藥品販賣、授與的業務體制不符省令所定基準（第2號）；③申請人落入許可撤銷、刑罰等欠格事由（第3號）。其中訂定構造設備基準的厚生勞動省令，即藥局等構造設備規則（昭和36年2月1日厚生省令第2號）。同規則第1條所定藥局構造設備的主要項目如下。

| 項目 | 主要內容 | 依據 |
| --- | --- | --- |
| 面積 | 約19.8平方公尺以上，並能適切進行藥局業務 | 藥局等構造設備規則第1條第1項 |
| 換氣、清潔 | 換氣充分且清潔 | 同上 |
| 天花板、地板、內壁 | 易於清掃、可防塵埃堆積的構造 | 同上 |
| 貯藏設備 | 陰涼貯藏設備，及可上鎖的貯藏設備（毒藥、精神藥品等） | 同上 |
| 調劑室 | 面積6.6平方公尺以上，天花板、地板為板材、混凝土等，並採取使領取調劑藥劑者無法進入的必要措施 | 同上 |
| 調劑設備、器具 | 具備調劑所需的設備、器具 | 同上 |
| 資訊提供設備 | 具備提供藥品資訊、基於藥學知識指導的設備 | 同上 |

面積的具體數值、配置，以及等候區與陳列架的處理，在各都道府縣、設有保健所的市的審查基準與手冊中細節有所不同。作為全國一律的數值，上述「約19.8平方公尺以上」「調劑室6.6平方公尺以上」已定於規則，但實際的符合判斷取決於開業地藥務主管窗口的審查。物件本身用途、構造的適法性（建築基準法上的用途，以及涉及用途變更時的建築確認），非本事務所的判斷範圍，由建築士、特定行政廳確認。事業用物件的選定、租賃由四葉不動產株式會社承辦，本事務所承辦許可申請的文件製作。

## 管理藥劑師須為常勤、專任嗎？可以兼職嗎？

藥局須置實地管理該藥局的藥劑師（管理藥劑師）。醫藥品醫療機器等法第7條第1項規定，藥局開設者為藥劑師時，須自行實地管理該藥局（自該藥局從事實務的其他藥劑師中指定管理者管理時，不在此限）；第2項規定，開設者非藥劑師時，須自該藥局從事實務的藥劑師中指定管理者實地管理。也就是說，即使開設者為法人，藥局的實地管理仍由藥劑師管理者進行。

可否兼職，由第7條第3項規定。藥局的管理者，不得為在該藥局以外的場所「以業務身分」從事藥局管理及其他藥事實務者。但取得該藥局所在地都道府縣知事許可時，不在此限。因此管理藥劑師原則上須專任於一家藥局，與他店的兼職僅限於取得都道府縣知事許可的例外情形。關於此兼職許可的思路，整理於厚生勞動省通知「關於醫藥品、醫療機器等法第7條第3項所定藥局管理者兼職許可的思路」（平成31年3月20日藥生總發第320003號）。另「常勤」並非法令用語，而是實務上的運用，工作時數、工作日數的具體處理，請向開業地窗口確認。

管理者為避免產生有害公共衛生之虞，須監督該藥局勤務的藥劑師及其他從業者、管理構造設備與醫藥品等物品、盡必要注意，並以書面向藥局開設者陳述必要意見（同法第8條）。又，藥劑師個人免許的取得，以及個別調劑內容的適否，非本文對象。藥劑師與從業員的勞動條件、社會保險、工作規則，由四葉社會保險勞務士事務所（社會保險勞務士）承辦。

## 藥局開設許可的申請流程與必要文件為何？

申請應自開業預定日回推推進。標準流程為：①向藥務主管窗口（都道府縣的藥務課、保健所）事前諮詢 → ②確認物件、設計是否符合構造設備基準 → ③提出藥局開設許可申請書 → ④文件審查 → ⑤現地檢查（確認構造設備）→ ⑥許可 → ⑦開設，依此順序。開業預定日的幾日前提出、現地檢查的日程，因地方政府而異，故從事前諮詢開始較為安全。

申請時所要求的代表性文件如下。因格式、份數、附件因地方政府而異，請以開業地的官方手冊確認。

| 文件 | 內容概要 |
| --- | --- |
| 藥局開設許可申請書 | 名稱、所在地、構造設備概要、管理者姓名等 |
| 構造設備概要、平面圖 | 調劑室、等候區、貯藏設備、資訊提供設備等的配置與尺寸 |
| 周邊位置圖 | 顯示藥局位置關係的圖 |
| 管理藥劑師的藥劑師免許證影本、顯示僱用關係的文件 | 擔任管理者的藥劑師者 |
| 登記事項證明書、章程等 | 開設者為法人時 |
| 診斷書等 | 關於申請人（法人為執行業務的役員）欠格事由者（依地方政府） |

此處須注意，以公共醫療保險進行調劑的「保險藥局」指定，是與藥局開設許可不同的手續。保險藥局的指定依健康保險法，另向管轄所在地的地方厚生局長申請。即使取得開設許可，未取得保險藥局指定即無法進行保險調劑。開設許可申請書等的製作由行政書士承辦，本事務所不保證許可或保險藥局指定與否。

## 藥局與店舖販賣業（藥妝店等）在許可上有何不同？

「販賣藥品的店舖」大致分為藥局與店舖販賣業，作為依據的許可不同。藥局是取得醫藥品醫療機器等法第4條藥局開設許可的設施，可進行調劑，並可處理含醫療用醫藥品的藥局醫藥品、要指導醫藥品與一般用醫藥品。相對地，店舖販賣業是取得同法第26條許可的業態，不能調劑，也不能處理藥局醫藥品（醫療用醫藥品等）。可處理者為要指導醫藥品與一般用醫藥品。所謂藥妝店，若不進行調劑，可作為店舖販賣業經營；若設置調劑室並進行調劑，則須藥局開設許可。

管理者的資格亦有不同。店舖販賣業中，販賣要指導醫藥品或第一類醫藥品的店舖，由藥劑師擔任店舖管理者；僅販賣第二類、第三類醫藥品的店舖，可由藥劑師或登錄販賣者擔任管理者（同法第28條）。藥局須有藥劑師管理者。又，非藥局者，不得於其名稱使用「藥局」文字（同法第6條）。

| | 藥局 | 店舖販賣業 |
| --- | --- | --- |
| 依據 | 醫藥品醫療機器等法第4條（開設許可） | 同法第26條（許可） |
| 調劑 | 可 | 不可 |
| 可處理的醫藥品 | 藥局醫藥品（含醫療用）、要指導、一般用 | 要指導、一般用（藥局醫藥品不可） |
| 管理者 | 藥劑師 | 藥劑師（販賣要指導、第一類時）／登錄販賣者（僅第二類、第三類時） |
| 「藥局」名稱 | 可使用 | 不得使用（第6條） |

藥局的開業橫跨多個領域，分工如下。

- 藥局開設許可申請書等的製作，以及與藥務主管窗口事前諮詢的支援 → 四葉行政書士事務所（行政書士）
- 事業用物件的選定、租賃、重要事項說明 → 四葉不動產株式會社
- 藥劑師、從業員的勞動條件、社會保險、工作規則 → 四葉社會保險勞務士事務所（社會保險勞務士）
- 建物用途、構造的適法性，以及涉及用途變更時的建築確認 → 建築士、特定行政廳
- 醫藥品販賣業的會計、稅務 → 稅理士
- 涉及權利義務與紛爭的個別法律判斷 → 律師

四葉行政書士事務所與四葉不動產株式會社為不同的事業體。本事務所僅以獨立的事業體承辦藥局開設許可的申請支援，物件、勞務、稅務請與各專業人士、事業體分別簽約、諮詢。本事務所不收取介紹費。許可的整體樣貌請見[行政許可手續](https://luck428.com/legal/services)，受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)。關於醫療法的診療所開設申報，請見[診療所的開設申報（醫療法第8條）](https://luck428.com/legal/column/shinryojo-kaisetsu-todokede-iryoho-8jo)；關於醫療法人的設立認可，請見[醫療法人設立認可的流程](https://luck428.com/legal/column/iryohojin-setsuritsu-ninka-nagare-shorui)。許可與否本身由藥務主管窗口判斷。

## 常見問題

**Q. 有藥劑師免許，就能馬上開自己的藥局嗎？**
A. 免許與開設許可是兩回事。藥劑師免許是個人資格，但要開藥局，須與免許分開，就各店舖向都道府縣知事（設有保健所的市、特別區為市長、區長）取得藥局開設許可（醫藥品醫療機器等法第4條第1項）。許可要求構造設備、業務體制符合基準，且未落入欠格事由（同法第5條）。

**Q. 管理藥劑師可以在其他藥局或店舖兼職嗎？**
A. 原則上不可。藥局的管理者不得為在該藥局以外的場所以業務身分從事藥事實務者（醫藥品醫療機器等法第7條第3項）。但取得該藥局所在地都道府縣知事許可時，可例外兼職。許可的思路載於厚生勞動省通知（平成31年3月20日藥生總發第320003號）。

**Q. 藥妝店與調劑藥局是同一種許可嗎？**
A. 是不同的許可。進行調劑的藥局為藥局開設許可（第4條）；不調劑而販賣要指導、一般用醫藥品的店舖為店舖販賣業許可（第26條）。兩者在可否調劑、可處理醫藥品的範圍、管理者資格（藥劑師或登錄販賣者）上均不同。若設置調劑室並進行調劑，須藥局開設許可。

**Q. 取得藥局開設許可後，就能馬上進行保險調劑嗎？**
A. 不能。以公共醫療保險進行調劑的保險藥局指定，是與開設許可不同的手續，依健康保險法向地方厚生局長申請。取得開設許可後，再取得保險藥局指定，方能進行保險調劑。手續順序與必要文件，請向地方厚生局與藥務主管窗口確認。
