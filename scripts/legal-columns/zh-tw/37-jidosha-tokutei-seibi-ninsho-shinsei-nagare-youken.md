**結論（先說要點）**：以事業經營汽車特定整備（原分解整備加上電子控制裝置整備）者，須依道路運送車輛法第78條，就各事業場取得地方運輸局長之認證。認證基準見第80條：須符合作業場・車輛置場之規模（道路運送車輛法施行規則別表第四）、整備主任者等人員（同施行規則第62條之2之2），以及作業機械・器具・掃描工具（scan tool）等設備。申請經由事業場所在地管轄之運輸支局（向地方運輸局長提出）。2020年（令和2年）4月1日施行之改正，將原「分解整備」擴大為「特定整備」，新增與自動運行裝置及駕駛輔助相關之電子控制裝置整備。本文為一般資訊提供，整理須認證之整備範圍、人員與設備要件、2020年改正內容、申請流程，以及物件・登記・稅務應交由何人處理。個別認證之可否與必要文件，由管轄之運輸支局之處理而定。

## 特定整備之認證於何種整備時始需要？

特定整備定義於道路運送車輛法施行規則第3條。同條第1號至第7號屬原「分解整備」，對象為拆卸原動機、動力傳達裝置、行走裝置、操縱裝置、制動裝置、緩衝裝置、連結裝置所為之整備・改造。第8號・第9號為2020年新增之「電子控制裝置整備」，對象為自動運行裝置，以及碰撞被害減輕煞車、車道偏離警報等駕駛輔助所用之攝影機・雷達等感測器之拆卸・調整（即所謂aiming定位）。

應他人需求、有償且反覆地以事業經營此等特定整備者，依道路運送車輛法第78條第1項須取得地方運輸局長之認證。認證就各事業場、定明特定整備事業之種類（分解整備・電子控制裝置整備）與對象自動車之種類（普通・小型・輕型・大型等）而取得。未取得認證而以事業經營特定整備者，屬違法並為罰則對象。

| 事項 | 內容 |
| --- | --- |
| 依據 | 道路運送車輛法第78條第1項（自動車特定整備事業之認證） |
| 對象 | 分解整備（施行規則第3條第1號〜第7號）／電子控制裝置整備（同第8號〜第9號） |
| 單位 | 就各事業場・定明事業種類與對象自動車種類而取得 |
| 申請地 | 事業場所在地管轄之運輸支局（向地方運輸局長提出） |

自家工場所為之整備是否屬分解整備・電子控制裝置整備，視作業內容而定。判斷有疑義時，依事業計畫向管轄之運輸支局事前諮詢較為確實。

## 認證所需之人（整備主任者・工員）與設備要件為何？

道路運送車輛法第80條定明地方運輸局長審查申請之基準，規定事業場之設備・從業員・作業管理狀況不符合省令所定基準時，不得認證。實務上之要件大致分為人員要件與設備・作業場要件。

| 區分 | 主要要件 |
| --- | --- |
| 整備主任者 | 依施行規則第62條之2之2選任。須具一級或二級自動車整備士等資格。電子控制裝置整備原則須修畢運輸支局長等所行電子控制裝置整備之整備主任者等資格取得講習（一級大型・一級小型整備士免講習） |
| 工員 | 依對象自動車種類・作業確保人數 |
| 設備 | 作業所需之作業機械・器具。電子控制裝置整備須具符合性能・機能要件之掃描工具及水準器等 |
| 作業場・車輛置場 | 施行規則別表第四所列規模之屋內作業場・車輛置場（數值因對象自動車種類而異） |

又，電子控制裝置整備向來必備之掃描工具，於2025年7月8日之省令改正中，朝向原動機等分解整備事業場亦須配置之方向擴大。作業場・車輛置場之具體間口・奥行・面積依施行規則別表第四，惟因對象車種而異，故於決定物件前依運輸支局之基準確認，可避免文件退回。作業場・車輛置場之物件側要件，亦請參閱別事業體四葉不動產株式會社整理之[汽車整備工場（認證工場）可用物件之要件](https://luck428.com/column/jidosha-tokutei-seibi-ninsho-koujou-bukken-youken)。

## 2020年由分解整備改為特定整備之改正，電子控制裝置整備有何變化？

隨自動駕駛・駕駛輔助技術普及，道路運送車輛法施行規則經修正，自2020年（令和2年）4月1日起將原「分解整備」擴大為「特定整備」。此改正於拆卸機械部分之分解整備外，新增電子控制裝置整備為認證對象。

| 事項 | 內容 |
| --- | --- |
| 施行日 | 2020年（令和2年）4月1日 |
| 變更點 | 將「分解整備」擴大為「特定整備」，新增電子控制裝置整備 |
| 電子控制裝置整備對象 | 自動運行裝置、與駕駛輔助相關之攝影機・雷達等感測器之拆卸・調整（aiming）等 |
| 經過措施 | 2020年（令和2年）3月31日前已行電子控制裝置整備之事業者，得於2024年（令和6年）3月31日前未認證繼續，惟此經過措施已終了 |

因經過措施於令和6年3月31日終了，現行aiming等電子控制裝置整備無法於未認證下進行。即使已取得分解整備認證之工場，欲進行電子控制裝置整備，仍須另行取得追加該種類之認證（變更・追加申請）。

## 認證申請之文件與運輸支局之手續流程為何？

認證依道路運送車輛法第79條，經由事業場所在地管轄之運輸支局向地方運輸局長申請。主要流程與文件如下。

| 階段 | 內容 |
| --- | --- |
| 事前諮詢 | 整理作業場圖面・設備・人員，向管轄之運輸支局事前諮詢 |
| 文件準備 | 認證申請書、整備主任者選任申報書、工員名簿與證明整備士資格之文件、作業場・車輛置場之配置圖・照片、土地建物之登記事項證明書或租賃契約書、法人須具登記事項證明書等 |
| 申請・審查 | 向運輸支局申請。書面審查，並視需要就作業場・設備進行實地調查 |
| 認證・揭示 | 認證後揭示認證標識，並備特定整備記錄簿記錄 |

認證申請書及其附件之製作，屬向官公署提出之文件製作，行政書士得於業務範圍內支援。四葉行政書士事務所於行政書士業務範圍內，支援認證申請書與整備主任者選任申報書等之製作。個別必要文件與實地調查之要否，由管轄之運輸支局之處理而定。

又，認證工場（第78條）與依指定自動車整備事業（第94條之2）之指定工場（即所謂民間車檢場）為不同制度。指定工場於工場內進行完成檢查並得交付保安基準適合證，認證工場則於運輸支局受檢。指定工場之指定申請，行政書士亦得以官公署提出文件之製作支援。

## 物件之要件確認・公司設立與稅務，應各交由何人處理？

取得特定整備認證，非僅文件製作，尚涉及物件・登記・勞務・稅務。分工如下。

- 特定整備事業（分解整備・電子控制裝置整備）之認證申請文件、指定工場之指定申請文件、整備主任者選任申報書之製作 → 四葉行政書士事務所（行政書士）
- 作業場・車輛置場物件之尋找、用途地域與使用權原之確認、租賃契約 → 四葉不動產株式會社（宅地建物交易業者）
- 公司設立・役員變更等之登記、土地建物所有權之登記 → 司法書士（建物表題・分筆等表示之登記由土地家屋調查士）
- 從業員之勞動保險・社會保險加保、就業規則・36協定 → 社會保險勞務士
- 法人稅・所得稅・消費稅等稅務之諮詢・申報 → 稅理士

四葉行政書士事務所與四葉不動產株式會社為別事業體。各領域均以與各資格者作為獨立的事業體個別簽約為前提，本事務所不收取介紹費。受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)；全貌見[許認可・各種申請服務](https://luck428.com/legal/services)。兼營運送業時之營業所・車庫要件，亦請參閱[一般貨物汽車運送事業之營業所・車庫要件](https://luck428.com/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)與[貨物輕型汽車運送事業（黑牌）之申報](https://luck428.com/legal/column/keikamotsu-kei-jidosha-unso-todokede)。

## 常見問題

**Q. 認證工場與指定工場（民間車檢場）有何不同？**
A. 認證工場係依道路運送車輛法第78條得進行特定整備之工場，車檢（繼續檢查）之完成檢查於運輸支局受檢。指定工場係依同法第94條之2之指定自動車整備事業，即得於工場內進行完成檢查並交付保安基準適合證之所謂民間車檢場。取得指定須以認證為前提，並符合更嚴之設備・人員・檢查體制基準。兩者之申請文件，行政書士均得以官公署提出文件之製作支援。

**Q. 僅進行aiming（攝影機・雷達之調整）亦須認證嗎？**
A. 自動運行裝置及與駕駛輔助相關之攝影機・雷達等感測器之拆卸・調整（aiming），屬道路運送車輛法施行規則第3條之電子控制裝置整備，以事業經營者須依第78條取得認證。給予2020年3月31日前已行者之經過措施已於令和6年3月31日終了，現行無法於未認證下進行。

**Q. 租賃物件亦能取得認證嗎？**
A. 就作業場・車輛置場具使用權原者，租賃物件亦得為認證對象。申請時以土地建物之租賃契約書等證明使用權原。惟作業場・車輛置場之規模（施行規則別表第四）與用途須符合，故於簽約前確認物件側要件較為確實。物件側之要件向宅地建物交易業者確認較為安全。

**Q. 認證申請之文件製作可委託何人？**
A. 認證申請書及其附件屬向官公署提出之文件，其製作行政書士得於業務範圍內支援。作業場・車輛置場物件之租賃屬宅地建物交易業者，公司設立等之登記屬司法書士，勞務屬社會保險勞務士，稅務屬稅理士，均為獨立的事業體個別處理。本事務所不收取介紹費。
