**先講重點：** 2024年（令和6年）3月1日起施行的戶籍廣域交付（戶籍法第120條之2），讓即使本籍地遙遠，也能在住處或工作地點鄰近的市區町村（本籍地以外）窗口，一次請求多個本籍地的戶籍謄本（全部事項證明書）等。但能請求者僅限本人、配偶者、直系尊屬、直系卑屬，不能以郵寄或代理人請求，窗口須出示附照片的身分證明文件。未電腦化的部分戶籍、除籍，以及一部事項證明書、個人事項證明書，無法以廣域交付取得。本文為整理制度適用範圍的一般性資訊提供，能否取得由市區町村窗口判斷。

## 戶籍的廣域交付，是新增了什麼的制度？

戶籍的廣域交付，是依戶籍法之一部修正的法律（令和元年法律第17號），於2024年（令和6年）3月1日施行的制度（戶籍法第120條之2）。過去，戶籍謄本只能在本籍地的市區町村取得，本籍散在各地時，必須依其數量分別請求。

| | 過去 | 廣域交付（2024年3月1日起） |
| --- | --- | --- |
| 請求對象 | 各本籍地的市區町村 | 可在本籍地以外的鄰近窗口一次請求 |
| 可取得者 | 各種戶籍、除籍的證明書 | 戶籍謄本（全部事項證明書）、除籍謄本等（部分不在對象內） |
| 請求方式 | 窗口、郵寄 | 僅窗口（本人親自前往） |

在相續中，需要被繼承人自出生到死亡連續的戶籍。若曾多次遷移本籍，就須跨多個市區町村蒐集戶籍，這正是相續手續最初的負擔。廣域交付減輕了這個「蒐集」階段的負擔。蒐集戶籍與相續人調查的整體樣貌，整理於[蒐集戶籍與相續人調查](https://luck428.com/legal/column/souzoku-hajime-koseki-chosa-bunkyo)。

## 誰能請求、反過來誰不能用？

能以廣域交付請求者，由法律限定。

| 能請求者 | 廣域交付 |
| --- | --- |
| 本人 | 可 |
| 配偶者 | 可 |
| 直系尊屬（父母、祖父母等） | 可 |
| 直系卑屬（子、孫等） | 可 |
| 兄弟姊妹、姪甥等 | 廣域交付不可（須向本籍地請求等） |
| 受委任狀的代理人、第三人 | 廣域交付不可 |

能以廣域交付請求戶籍者，為本人、配偶者、直系尊屬、直系卑屬。兄弟姊妹並非直系，故無法以廣域交付取得兄弟姊妹的戶籍。當相續中由兄弟姊妹成為繼承人等情形，這一點就是實務上的分水嶺。誰會成為繼承人的基本，請連同[法定相續資訊一覽圖](https://luck428.com/legal/column/houtei-souzoku-jouhou-ichiran-zu)與繼承順位的整理一起確認。

## 哪些戶籍無法以廣域交付取得？

廣域交付並非能取得所有戶籍。先知道取不到的，可避免重工。

| 取不到者 | 內容 |
| --- | --- |
| 未電腦化的部分戶籍、除籍 | 電算化前仍以紙本保管的改製原戶籍、除籍等 |
| 一部事項證明書 | 僅記載戶籍一部分的證明書 |
| 個人事項證明書 | 僅記載戶籍中特定個人事項的證明書（即所謂抄本） |

廣域交付所交付者，原則上為戶籍謄本（全部事項證明書）或除籍謄本等。一部事項證明書、個人事項證明書不在廣域交付對象內。此外，未電腦化的部分戶籍、除籍，因系統上無法一次取出，可能無法以廣域交付取得。至於戶籍附票的謄本是否屬對象，請以您所在市區町村的說明確認。取不到的部分，另向本籍地的市區町村請求。

## 能以郵寄或代理人請求嗎？如何與傳統手續併用？

廣域交付在方式上也有限制。

- 不能以郵寄請求。須由本人親自前往窗口。
- 不能以代理人（受委任狀者）請求。
- 窗口須出示駕照、My Number卡、護照等附照片的身分證明文件。

因此，若住得遠而無法到窗口、需要兄弟姊妹的戶籍、需要電算化前的改製原戶籍等，就須併用向本籍地市區町村的傳統請求（含郵寄）。可取得者於鄰近窗口取得、取不到者向本籍地請求，是實務的基本分工。蒐集到的戶籍，接著用於製作相續關係說明圖與法定相續資訊一覽圖。若想從頭掌握相續手續，也請參見[受任流程](https://luck428.com/legal/nagare)。

## 蒐集到的戶籍，要交給登記、稅務的誰？

蒐集戶籍是相續手續的入口，其後分為多個專業領域。分工如下。

- 蒐集戶籍、製作相續關係說明圖、申辦法定相續資訊一覽圖、遺產分割協議書的製作支援 → 四葉行政書士事務所（行政書士）
- 不動產相續登記的申請代理、登記申請書等的製作 → 司法書士或律師
- 相續稅的申報、稅額計算 → 稅理士
- 遺產紛爭、個別法律判斷 → 律師
- 相續不動產的出售、活用諮詢 → 四葉不動產株式會社

蒐集到的戶籍，若為相續登記，依[相續登記流程](https://luck428.com/legal/column/souzoku-touki-nagare)交給司法書士或律師；若為相續稅，則交給稅理士。四葉行政書士事務所與四葉不動產株式會社為不同的事業體，相續不動產的出售、活用由[相續不動產窗口](https://luck428.com/souzoku)（四葉不動產株式會社）承辦。本事務所以獨立的事業體提供蒐集戶籍、製作文件的支援，登記、稅務、紛爭請與各專業人士分別簽約、諮詢。本事務所不收取介紹費。相續中行政書士可承辦的範圍請見[相續手續支援](https://luck428.com/legal/services/inheritance)，費用請見[報酬額表](https://luck428.com/legal/ryokin)。

## 常見問題

**Q. 兄弟姊妹的戶籍也能以廣域交付取得嗎？**
A. 不能。能以廣域交付請求者為本人、配偶者、直系尊屬、直系卑屬，兄弟姊妹並非直系。當兄弟姊妹成為繼承人等情形，須以向本籍地市區町村的請求（含郵寄）對應。依誰會成為繼承人，於最初確認所需戶籍的範圍很重要。

**Q. 我住得遠、無法到窗口。可以用郵寄辦廣域交付嗎？**
A. 不行。廣域交付是由本人於窗口請求的制度，不能以郵寄或代理人請求。窗口須出示附照片的身分證明文件。若無法到窗口，須併用向本籍地市區町村的傳統郵寄請求。

**Q. 以前的改製原戶籍也能以廣域交付一次取得嗎？**
A. 未電腦化的部分戶籍、除籍（電算化前仍以紙本保管的改製原戶籍等），可能無法以廣域交付取得。取不到的部分，另向本籍地市區町村請求。哪些戶籍屬對象，請於窗口確認。

**Q. 以廣域交付取得的戶籍，能自行辦到相續登記嗎？**
A. 取得戶籍是相續的入口。相續登記的申請代理與登記申請書等的製作，是司法書士或律師的業務，相續稅的申報屬稅理士領域。本事務所承辦蒐集戶籍、相續關係說明圖與法定相續資訊一覽圖的申辦支援，登記、稅務請與各專業人士分別簽約。
