**結論（先講重點）**：墓じまい（改葬）須先取得行政許可後始得進行。改葬指將已埋葬之遺體移至他墳墓，或將已埋藏・收藏之焼骨移至他墳墓・納骨堂（墓地、埋葬等相關法律（昭和23年法律第48號）第2條第3項）；擬改葬者，須取得焼骨等現所在地之市町村長（含特別區區長，以下同）許可（同法第5條第1項・第2項）。實務上，向現墓地之管理者取得證明埋藏・收藏事實之書面（埋葬證明・收藏證明），向遷入處取得表明受入之書面（受入證明），再向現墓地所在之市區町村提出改葬許可申請書，取得改葬許可證（同法施行規則＝昭和23年厚生省令第24號 別記樣式第三號）。祭祀財產（系譜・祭具・墳墓）由何人承繼，屬民法第897條之問題；離檀料與撤除墓所之費用則為與寺院・墓地之協商。本文整理改葬許可之流程與必要文件，及各應委託何人。改葬之許可由市町村長為之，本事務所不保證許可。書類作成與協商・紛爭，均以獨立的事業體各自個別簽約。

## 改葬許可向何處提出何物？

改葬之許可權者，與埋葬・火葬不同，為遺體或焼骨現所在地之市町村長（墓地、埋葬等相關法律第5條第2項）。即向現有墳墓之市區町村申請，而非遷入處之市區町村。申請書之記載事項定於同法施行規則第2條第1項。

| 改葬許可申請書之記載事項（施行規則第2條第1項） | 內容 |
| --- | --- |
| 第一號 | 死亡者之本籍、住所、姓名及性別 |
| 第二號 | 死亡年月日 |
| 第三號 | 埋葬或火葬之場所 |
| 第四號 | 埋葬或火葬之年月日 |
| 第五號 | 改葬之理由 |
| 第六號 | 改葬之場所（遷入處） |
| 第七號 | 申請者之住所・姓名、與死亡者之續柄等 |

年代久遠之埋葬，可能不知死亡年月日或埋葬年月日。此時多數自治體允許記載「不詳」，樣式・記載方法因市區町村而異。欲改葬之焼骨等有數具時，原則逐一申請（部分自治體有可於一份申請書記載多具之樣式）。獲准後交付改葬許可證（施行規則別記樣式第三號），將其提出於遷入處墓地・納骨堂之管理者以納骨。

## 埋葬證明・受入證明於何處取得？

改葬許可申請書須附證明埋藏・收藏事實之書面。施行規則第2條第2項要求附上墓地或納骨堂管理者所作成之「證明埋葬或埋藏或收藏事實之書面」。實務上文件之收集如下。

| 文件 | 於何處取得 | 定位 |
| --- | --- | --- |
| 埋葬證明・埋藏證明・收藏證明 | 現墓地・納骨堂之管理者（寺院・靈園・自治體） | 施行規則第2條第2項所要求之附件 |
| 受入證明（永代使用許可證・墓所使用許可證等） | 遷入處之墓地・納骨堂 | 多數自治體於申請時要求（依運用） |
| 改葬許可申請書 | 現墓地所在之市區町村 | 同規則第2條第1項之記載事項 |

墓地使用者以外之人申請時，須附墓地使用者之承諾書，或證明申請者具改葬請求權之裁判謄本・確定證明書等（施行規則第2條第2項）。因受入證明之要否與樣式因自治體・寺院而異，申請前向現墓地管理者・遷入處・市區町村三方確認必要文件，可防退件。行政書士於行政書士業務範圍內支援改葬許可申請書及其他書類之作成，惟證明書之發行由各管理者・市區町村為之。

## 祭祀承繼者未定即無法墓じまい嗎？

墳墓與存款、不動產等一般繼承財產分別處理。系譜・祭具・墳墓之所有權，依習慣由應主宰祖先祭祀者承繼；被繼承人（亡故者）有指定時由該人承繼（民法第897條第1項）。習慣不明時由家庭裁判所定之（同條第2項）。因此，整理「何人承繼祭祀並為墓所使用者」為墓じまい之起點。

現墓所使用者即為申請者時手續較易進行；否則須使用者之承諾書等（前述施行規則第2條第2項）。就何人為祭祀承繼者親族意見分歧、與寺院就承繼或離檀條件無法折衷等涉權利義務之爭議場面，屬律師領域。本事務所以獨立的事業體，支援在無爭議前提下之書類作成與手續整理。祭祀財產承繼與遺產分割之關係，整理於[祭祀之承繼・墳墓・佛壇與遺產分割之關係](https://luck428.com/legal/column/saishi-shokei-haka-butsudan-isanbunkatsu)。繼承手續整體之入口，亦請參閱別事業體之繼承專門網站[繼承窗口](https://luck428.com/souzoku)。

## 離檀料與撤除墓所之費用與何人協商？

墓じまい除行政手續費用外，尚有當事人間協商之費用。此等並非行政許可之要件，而是與寺院・墓地・石材店之契約・協商問題。

| 費用・手續 | 相對人 | 定位 |
| --- | --- | --- |
| 改葬許可申請之手續費 | 市區町村 | 多數自治體免費或數百日圓（因自治體而異） |
| 離檀料 | 寺院（欲退出檀家時） | 法律無定之任意性質。金額由當事人間協商 |
| 墓石之撤除・整地費用 | 石材店 | 民間之承攬契約 |
| 閉眼供養（撤靈）等布施 | 寺院 | 習慣・宗教上之事 |

離檀料無法律上之定，金額與有無支付義務由與寺院之協商決定。金額或條件無法折衷而生紛爭時之協商・法律判斷，屬律師領域，非本事務所業務。又墓所・墳墓・祭具等祭祀財產屬相續稅之非課稅財產（相續稅法第12條第1項第2號），墓じまい本身通常不生相續稅・所得稅，惟個別稅務判斷屬稅理士領域。本事務所不進行稅務諮詢・稅額計算。

## 書類作成與協商・紛爭應各委託何人？

墓じまい混合行政手續・當事人間協商・親族合意等性質相異之作業。分擔如下。

- 改葬許可申請書及其他書類之作成、必要文件之整理 → 四葉行政書士事務所（行政書士）
- 埋葬證明・收藏證明之發行、改葬許可證之交付 → 現墓地之管理者・市區町村
- 離檀料・墓所撤除或供養條件之協商 → 當事人（申請者）與寺院・墓地・石材店
- 就祭祀承繼或離檀涉權利義務有爭議時之協商・法律判斷 → 律師
- 繼承財產名義變更中之不動產登記 → 司法書士
- 相續稅・所得稅等個別稅務判斷 → 稅理士

四葉行政書士事務所與四葉不動產株式會社為別事業體。本公司僅以獨立的事業體承擔改葬許可申請之書類作成・整理，證明書之發行屬各管理者・市區町村，離檀料等協商屬當事人與寺院，有爭議場面屬律師，登記屬司法書士，稅務屬稅理士，各自個別簽約。本事務所不收取介紹費。行政書士可承辦業務之全貌見[許認可業務](https://luck428.com/legal/services)；受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)。

## 常見問題

**Q. 改葬許可向何處役所提出？**
A. 向焼骨等現所在地（即現有墳墓之市區町村）之市町村長提出（墓地、埋葬等相關法律第5條第2項），而非遷入處之市區町村。申請書之記載事項定於同法施行規則第2條第1項，並附證明埋藏・收藏事實之書面（管理者作成）。書類作成由行政書士以獨立的事業體支援。

**Q. 數十年前之埋葬，不知死亡年月日，可申請嗎？**
A. 死亡年月日・埋葬年月日不詳時，多數自治體允許記載「不詳」，惟樣式・記載方法因市區町村而異。請先向現墓地管理者與該市區町村確認必要文件與記載方法。

**Q. 寺院要求高額離檀料，可委託行政書士交涉嗎？**
A. 離檀料無法律上之定，金額與有無支付義務由與寺院之協商決定。金額或條件無法折衷而生紛爭時之交涉・法律判斷屬律師領域，非行政書士業務。本事務所以別事業體，支援在無爭議前提下之書類作成與手續整理。

**Q. 墓じまい會產生稅金嗎？**
A. 墓所・墳墓・祭具等祭祀財產屬相續稅之非課稅財產（相續稅法第12條第1項第2號），墓じまい本身通常不生相續稅・所得稅。惟個別稅務判斷屬稅理士領域，本事務所不進行稅務諮詢・稅額計算。
