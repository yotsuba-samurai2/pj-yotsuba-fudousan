**結論（先講重點）**：開辦附照護之收費型高齡者住宅，須疊合兩項手續。其一為老人福祉法（昭和38年法律第133號）第29條第1項之收費型高齡者住宅設置屆，向擬設置設施所在地之都道府縣知事（指定都市・中核市為市長）事前屆出。其二為介護保險法（平成9年法律第123號）第8條第11項所定之特定設施入居者生活介護指定，依同法第70條第1項，由都道府縣知事（指定都市・中核市為市長）就各事業所指定。人員・設備・營運基準定於指定居宅服務等之事業人員、設備及營運相關基準（平成11年厚生省令第37號）第174條以下，核心為護理・照護職員須達要照護利用者每3人1人以上（常勤換算＝所謂3對1）。本文整理設置屆與指定之流程、要件、時程，以及各部分應委託何人。是否符合基準與指定可否由指定權者審查決定，本事務所不保證指定。物件・建築・消防・勞務・稅務均以獨立的事業體各自個別簽約。

## 收費型高齡者住宅之設置屆何時向誰提出？

收費型高齡者住宅，指使高齡者入居，並提供入浴・排泄・飲食之照護、飲食供應、洗衣掃除等家事、健康管理之任一服務之設施（老人福祉法第29條第1項）。擬設置者須事前向擬設置設施所在地之都道府縣知事（指定都市・中核市為市長，以下同）屆出。重點在於此為事前屆出，而非開設後之事後屆出。

收費型高齡者住宅依所提供之服務，運用上分為下列類型（厚生勞働省「收費型高齡者住宅設置營運標準指導指針」之區分）。「附照護」指已取得介護保險特定設施入居者生活介護指定者。

| 類型 | 概要 | 照護之定位 |
| --- | --- | --- |
| 附照護收費型高齡者住宅 | 已取得特定設施入居者生活介護指定 | 由設施職員以介護保險服務提供 |
| 住宅型收費型高齡者住宅 | 未取得特定設施指定 | 由入居者個別簽約外部居宅服務 |
| 健康型收費型高齡者住宅 | 需照護時以退居為前提 | 不提供照護 |

設置屆應於事業開始前預留餘裕提出。須於事業開始預定日之幾個月前屆出，因自治體運用而異，部分都道府縣要求事前相談・協議。屆出時期・樣式・附件請於該自治體公式頁面確認。未屆出而營運，可能成為老人福祉法上指導・改善命令等對象。

## 取得特定設施入居者生活介護指定之要件為何？

欲名為「附照護」，須就各事業所取得介護保險法第8條第11項所定之特定設施入居者生活介護指定。指定依同法第70條第1項由都道府縣知事為之，申請者原則須為法人。人員・設備・營運基準定於指定居宅服務等之事業人員、設備及營運相關基準（平成11年厚生省令第37號）第174條以下（人員為第175條），並由各自治體條例具體化。人員配置之基本如下。

| 職種 | 配置思考（常勤換算） |
| --- | --- |
| 護理・照護職員 | 要照護利用者數除以3以上（3對1）。護理職員：利用者30人以下1人以上，31人以上每50人1人以上 |
| 生活相談員 | 利用者每100人1人以上。其中1人以上為常勤 |
| 機能訓練指導員 | 1人以上（部分情形可兼務） |
| 計畫作成擔當者（介護支援專門員） | 以利用者每100人1人為標準，配置1人以上。部分情形可兼務 |
| 管理者 | 專職常勤1人（無妨礙時部分情形可兼務） |

護理・照護職員之「3對1」以常勤換算方法計算。夜勤・宿直如何編排、常勤換算如何落實於排班、工作規則與時間外・休日勞動協定如何整備，屬勞務設計問題，為社會保險勞務士領域。與本公司・本事務所為獨立的事業體，各自個別簽約（設施勞務之詳細亦見姊妹網站社會保險勞務士之專欄）。介護報酬之計算・請求由事業者或請求代行擔當，會計・稅務屬稅理士領域。

## 居室面積・共用部・無障礙等建築側基準看何處？

設備基準定於平成11年厚生省令第37號（第176條等），並由標準指導指針具體化。介護居室原則為個室，每入居者床面積原則13平方公尺以上（不含走廊・共用部之專用部分面積）。共用部依所提供服務，設置食堂、機能訓練室、浴室、便所、醫務室或健康管理室、護理・照護職員室、談話室等。並要求走廊寬度・消除高低差・扶手等無障礙，及確保避難路線。

| 確認處 | 主要要求 |
| --- | --- |
| 介護居室 | 原則個室，每人床面積原則13平方公尺以上 |
| 共用設備 | 食堂・機能訓練室・浴室・便所・醫務室或健康管理室等 |
| 無障礙 | 走廊寬度・消除高低差・扶手・輪椅可用之便所浴室 |
| 用途・防火 | 是否符合建築基準法上用途（老人住宅）、用途變更確認申請之要否 |
| 消防用設備 | 屬消防法施行令別表第一(6)項ロ，自動火災報知設備・撒水設備等 |

轉用既有建物時，可能須建築基準法上用途變更確認申請，其要否・設計由建築士（設計者）判斷。消防用設備（自動火災報知設備・撒水設備・向消防機關通報之火災報知設備等）之要否與消防同意由消防署判斷。物件之用途地域・面積一次確認由不動產公司擔當，本公司僅提供物件資訊，不判斷建築確認或消防可否。

## 自設置屆至指定・開設之時程如何編排？

設置屆（老人福祉法）與特定設施指定（介護保險法）為不同手續，惟實務上並行準備。因順序前後易遭退件，宜及早開始事前協議。一般流程如下。

1. 確定事業計畫・資金計畫，設立法人（於章程事業目的加入收費型高齡者住宅之設置營運・特定設施入居者生活介護）
2. 選定物件，確認居室面積・共用部・建築基準法・消防法之符合
3. 與都道府縣（指定權者）進行事前協議（設置屆・指定兩者）
4. 確保護理・照護職員、生活相談員、機能訓練指導員、計畫作成擔當者、管理者
5. 提出收費型高齡者住宅設置屆
6. 提出特定設施入居者生活介護指定申請書與附件
7. 經書面審查・現地確認，取得指定（多數自治體為每月1日付）並開設

多數自治體以每月1日付指定，指定申請之提出期限一般設於指定希望日之前月或前前月。因截止日・樣式・必要文件依指定權者而異，請務必於該自治體公式頁面確認。代表性必要文件為設置屆樣式全套、指定申請書與附表、法人登記事項證明書・章程、事業所平面圖・照片・租賃契約書等、營運規程、從業者勤務形態一覽表與資格證、管理者・計畫作成擔當者之經歷、收支預算書、各種誓約書等。四葉行政書士事務所於行政書士業務範圍內，支援設置屆・指定申請書・附表・附件之作成、事前協議資料整理、營運規程等文案。是否符合基準之最終判斷與指定可否由指定權者審查。

## 設置屆・指定・建築・消防・勞務・稅務應各委託何人？

附照護收費型高齡者住宅之開設，涉及多個專業領域。分擔如下。

- 設置屆・指定申請書・附表・附件之作成、事前協議之支援 → 四葉行政書士事務所（行政書士）
- 事業用物件之選定・租賃・重要事項說明、用途地域・面積之一次確認 → 四葉不動產株式會社
- 用途變更確認申請・設計、居室面積・無障礙之符合、檢查濟證之確認 → 建築士（設計者）
- 自動火災報知設備・撒水設備等之要否判定・消防同意 → 消防署・消防設備士
- 符合人員基準之僱用契約・工作規則・含夜勤宿直之工時管理・社會保險適用 → 社會保險勞務士
- 法人設立・變更登記 → 司法書士
- 法人會計・稅務・稅額計算、伴隨介護報酬請求之經理 → 稅理士
- 涉及權利義務・紛爭之個別法律判斷 → 律師

## 常見問題

**Q. 設置屆與特定設施指定，只做其一即可嗎？**
A. 欲名為「附照護」，由設施職員以介護保險服務提供照護，須同時具備老人福祉法第29條第1項之設置屆與介護保險法之特定設施入居者生活介護指定。未取得指定則為住宅型，由入居者個別簽約外部居宅服務。因類型不同而人員・設備・手續有異，請於事前協議確認。

**Q. 服務型高齡者住宅（サ高住）也能取得特定設施指定嗎？**
A. 符合一定要件之服務型高齡者住宅可能被納入特定設施，惟登錄處・所管與屆出可能與收費型高齡者住宅不同。以何種架構進行，因事業計畫與物件而異，請以該自治體手引與事前協議確認。制度架構之整理於行政書士業務範圍內支援，惟指定可否由指定權者審查。

**Q. 夜勤體制與職員工時可向行政書士諮詢嗎？**
A. 符合人員基準，與該職員之僱用契約・工作規則・含夜勤宿直之工時管理・社會保險適用，為不同問題。後者屬社會保險勞務士領域，與本公司為獨立的事業體，各自個別簽約。本事務所支援指定申請之書面面。

**Q. 可使用既有建物嗎？**
A. 除居室面積・共用部・無障礙外，可能須建築基準法上用途變更確認申請，或追加消防用設備。用途變更判斷向建築士（設計者）、消防用設備要否向消防署確認。物件屬不動產公司、建築確認屬建築士，各為別事業體，各自個別簽約。
