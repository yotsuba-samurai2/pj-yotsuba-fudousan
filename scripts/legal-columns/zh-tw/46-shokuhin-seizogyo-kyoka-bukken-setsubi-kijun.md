**結論（先講重點）**：要開設製作並販售烘焙點心、蛋糕的菓子工房，或製作並販售便當、熟食的外帶店，除了在店內提供餐點的餐飲店營業外，還需要菓子製造業或熟食（惣菜）製造業的營業許可。這些依食品衛生法施行令第35條屬於須取得許可的業種，菓子製造業為同條第11號、熟食製造業為同條第25號，向都道府縣知事（設有保健所的市與特別區則為市長、區長）申請許可（食品衛生法第55條第1項）。設施應符合的基準，依同法第54條由各自治體的條例訂定，餐飲店營業與製造業所要求的區劃、設備有所不同。在簽訂物件契約前，先向保健所事前諮詢並依條例基準製作圖面十分重要。本文為整理許可條件與流程的一般性資訊提供，能否取得許可由保健所審查決定，本事務所並不保證取得許可。

## 餐飲店營業許可與菓子、熟食製造業許可有何不同？

最大的差別在於「是否讓客人當場飲食」與「是否製作、包裝後販售」。在店內烹調並提供餐點或飲料屬餐飲店營業（施行令第35條第1號）；將製作好的點心或熟食包裝後供外帶、批發販售，一般則屬菓子製造業（同條第11號）或熟食製造業（同條第25號）。即使是同一間廚房，提供形態改變，所需的許可也會改變。

若想同時經營內用與外帶，可能需要餐飲店營業與製造業的多項許可。適用哪一種許可，取決於所處理的食品、加工內容與販售形態，請向開業預定地的管轄保健所確認。餐飲店營業許可本身的取得方式，整理於[取得餐飲店營業許可：保健所的設施基準與食品衛生責任者](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)。

| 業態 | 適用的許可 | 依據 |
| --- | --- | --- |
| 在店內烹調並提供餐點 | 餐飲店營業 | 施行令第35條第1號、食品衛生法第55條第1項 |
| 製作並販售點心、麵包、蛋糕 | 菓子製造業 | 施行令第35條第11號 |
| 製作並販售便當、熟食 | 熟食製造業 | 施行令第35條第25號 |
| 僅販售常溫可保存的包裝食品 | 營業申報 | 食品衛生法第57條第1項 |

## 2021年食品衛生法改正如何重整許可業種？

依2018年公布的改正食品衛生法，自2021年（令和3年）6月1日起，營業許可制度經檢討，須取得許可的業種整理於食品衛生法施行令第35條。同時，對於不在許可對象內但對公眾衛生有影響的營業，新設了營業申報制度（食品衛生法第57條第1項）。

在菓子、熟食方面，餡類製造業併入菓子製造業，並新設了複合型熟食製造業（施行令第35條第26號）與複合型冷凍食品製造業（同條第28號）。複合型熟食製造業，是可與熟食製造業一併製作食肉處理業、菓子製造業、水產製品製造業（魚肉練製品除外）、麵類製造業相關食品的業種，僅在實施以HACCP為基礎的高度衛生管理時，才免除這些許可。自己的營業究竟屬於單一許可、複合型或申報，請向保健所確認。

| 手續種類 | 依據 | 主要例子 |
| --- | --- | --- |
| 營業許可 | 食品衛生法第55條第1項、施行令第35條 | 菓子製造業、熟食製造業等 |
| 營業申報 | 食品衛生法第57條第1項 | 常溫可保存的包裝食品販售等 |

## 製造業許可所需的物件設備基準要到什麼程度？

設施應符合的基準，依食品衛生法第54條，由各自治體的食品衛生法施行條例訂定。國家在施行規則中揭示應參酌的框架，但具體的數值與規格因自治體與業態而異，請以開業預定地的條例與保健所的指引確認。製造業與有客席的餐飲店不同，較重視製造專用的區劃、作業動線與清洗設備。具代表性的檢查項目如下。

| 項目 | 檢查重點 |
| --- | --- |
| 作業區劃 | 將製造室與居住空間、販售空間明確區分的配置 |
| 洗手設備 | 設置從業人員用的洗手處；常要求可防止交叉污染的水龍頭構造 |
| 水槽（清洗設備） | 依用途所需的槽數；許多自治體要求2槽以上 |
| 地板、牆壁、天花板 | 易清潔、具耐水性的材質 |
| 冷藏、冷凍設備 | 設有可確認溫度的溫度計 |
| 換氣、防蟲防鼠、供熱水 | 充分的換氣、防止鼠與昆蟲入侵、必要的熱水 |

即使將自宅的一部分作為菓子工房，製造室通常也須與居住空間區劃。因數值與是否需要區劃會因業態而變，在決定裝潢工程與格局之前先向保健所事前諮詢，並依條例基準製作圖面，可避免工程重做。物件的選定、租賃的評估屬另一事業體四葉不動產股份有限公司的領域。

## 符合HACCP的衛生管理，小規模事業者也需要嗎？

需要。自2021年（令和3年）6月1日起，原則上要求所有食品等事業者實施符合HACCP的衛生管理（食品衛生法第51條第1項）。菓子、熟食的製造業，在一般衛生管理之外，也需製作衛生管理計畫並加以記錄、確認。不過小規模事業者可採「導入HACCP思維的衛生管理」，可參考業界團體製作的手冊。

同時，每個設施須配置1名食品衛生責任者（依食品衛生法第51條第1項的一般衛生管理基準）。具廚師、糕點衛生師等資格的人可直接擔任；若無資格，則可透過修畢由都道府縣知事等辦理（或指定）的養成講習會取得資格。角色分工如下。

- 菓子製造業、熟食製造業的許可申請書、圖面等的製作，以及協助與保健所的事前諮詢 → 四葉行政書士事務所（行政書士）
- 事業用物件的選定、租賃、重要事項說明，以及可否作為製造室的評估 → 四葉不動產股份有限公司
- 製造室的區劃、排氣、防火相關的工程與消防手續 → 建築師、消防設備士、消防機關
- 法人設立的登記 → 司法書士
- 開業後的會計、稅務 → 稅理士
- 員工的雇用契約、工作規則、社會保險 → 社會保險勞務士
- 涉及權利義務、糾紛的個別法律判斷 → 律師

四葉行政書士事務所與四葉不動產股份有限公司為不同事業體。本事務所僅以獨立的事業體承辦菓子製造業、熟食製造業的許可申請協助，物件、工程、消防、登記、稅務、勞務則與各該有資格者、行政窗口分別簽約、諮詢。本事務所不收取介紹費。許認可的整體樣貌請見[許認可、各種申請服務](https://luck428.com/legal/services)，受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)。能否取得許可本身由保健所判斷。

## 常見問題

**Q. 我開咖啡店，也想販售自家製的蛋糕，只要餐飲店營業許可就夠了嗎？**
A. 在店內提供的部分屬餐飲店營業，但若將製作好的蛋糕包裝供外帶或批發販售，可能另需菓子製造業的許可（施行令第35條第11號）。餐飲店營業涵蓋到哪裡、從哪裡開始需要製造業許可，取決於販售形態。請向開業預定地的管轄保健所確認。

**Q. 可以在自宅廚房開菓子工房嗎？**
A. 通常無法直接使用家庭用廚房。製造室須與居住空間區劃，並滿足條例的基準（依食品衛生法第54條的各自治體條例），例如洗手、水槽、冷藏設備等。在施工前先向保健所事前諮詢，並依基準製作圖面，可減少重工。

**Q. 熟食製造業與餐飲店營業，兩者都要取得嗎？**
A. 若在店內提供餐點，同時又製作並包裝熟食販售，可能需要餐飲店營業與熟食製造業（施行令第35條第25號）的多項許可。也有像複合型熟食製造業那樣，以HACCP為基礎的衛生管理為條件、可一併製作多業種食品的機制，請將營業內容告知保健所後確認。

**Q. 小型個人工房也需要因應HACCP嗎？**
A. 是。自2021年6月1日起，原則上要求所有事業者因應。不過小規模事業者可採「導入HACCP思維的衛生管理」，基本上是參考業界團體的手冊，製作衛生管理計畫並加以記錄、確認。具體的格式請向保健所或手冊確認。
