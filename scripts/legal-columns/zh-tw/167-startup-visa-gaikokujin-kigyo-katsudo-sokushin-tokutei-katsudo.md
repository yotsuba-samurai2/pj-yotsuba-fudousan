**結論（先講重點）：**創業簽證是依經濟產業省「外國人創業活動促進事業」的機制。無法即刻滿足在留資格「經營・管理」要件的外國人創業者，經實施團體（獲認定的地方公共團體或民間事業者）對「創業準備活動計畫」的確認，可以在留資格「特定活動」停留日本，進行公司設立等創業準備。創業者向實施團體提出「創業準備活動計畫」，受確認並取得確認證明書，持以向地方出入國在留管理局申請而取得「特定活動」在留資格。在留期間含更新最長2年，惟更新單位（如每6個月）與對象實施團體因實施團體、計畫而異，且制度改動頻繁，請務必以出入國在留管理庁與經濟產業省的最新頁面確認。期滿後若欲續業，須變更為在留資格「經營・管理」。又「經營・管理」的基準已因令和7年（2025年）10月16日施行的修正而提高，創業簽證的見込基準、本人要件亦於同日告示修正中一部調整。創業活動計畫的確認申請與在留資格的申請取次由四葉集團的行政書士（申請取次行政書士）以獨立的事業體承辦；公司設立登記由司法書士辦理；社會保險、勞務由社會保險勞務士負責；稅務由稅理士負責；作為事業所的物件由屬不同事業體的不動產負責，各自分別簽約。彼此不收取介紹費。本文為一般性資訊，不就個別申請能否獲准作出判斷或保證。

由特定活動44號（創業簽證）變更時，若確認證明書於修正告示施行日（2025年10月16日）前交付，適用修正前基準；該日以後交付者適用修正後基準。請核對證明書交付日及入管最新指引，不宜一律認定適用新基準。

變更為「經營・管理」並適用修正後基準時，3,000萬日圓不是年營業額基準。法人指株式會社的已繳資本金或持分公司的出資總額，不能直接把營運費用加到資本金計算。個人事業則指確保事業所、職員1年薪資及設備投資等所投入的總額。資金與至少1名符合範圍的常勤職員兩項要件均須滿足。

僱用要件的常勤職員，須為經營或管理者以外、居住於日本的日本人、特別永住者，或持別表第二在留資格（永住者、日本人の配偶者等、永住者の配偶者等、定住者）者。僅僱用別表第一就業等在留資格者，不能滿足至少1人的僱用要件。常勤性及僱用實態須個別確認，社會保險與僱用保險手續由社會保險勞務士承辦。 日語能力要件所指的常勤職員，與僱用人數要件不同，也包含持別表第一在留資格者。申請者本人或常勤職員任一方符合即可，並非要求所有人均達B2。

此處B2指「日本語教育の参照枠」的B2相當以上。事業計畫須由持日本資格的中小企業診斷士、公認會計師或稅理士確認具體性、合理性與可實現性。

## 創業簽證與經營・管理簽證有何不同？

在留資格「經營・管理」是在日本從事事業經營・管理的正式在留資格。其基準已因令和7年（2025年）10月16日施行的上陸基準省令修正而提高，要求資本金・出資總額3,000萬日圓以上、僱用常勤職員1人以上等（修正的全貌整理於[日本出入國在留管理廳公布的修正內容（日文）](https://www.moj.go.jp/isa/content/001448070.pdf)，新設立流程整理於[中國、台灣的創業者如何取得「經營・管理」在留資格](/zh-tw/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)）。

創業簽證（外國人創業活動促進事業）則是為來日時尚無法滿足此「經營・管理」要件的創業者所設、可謂準備階段的制度。由經濟產業省認定的實施團體（獲認定的地方公共團體或民間事業者）確認創業準備活動計畫，取得確認證明書的創業者以在留資格「特定活動」停留日本，同時推進公司設立、事業所確保、資本金準備等創業準備。無須自始備齊「經營・管理」的形式要件即可開始活動，是與正式簽證的最大差異。本文聚焦於此準備階段的機制與向正式簽證的移轉。

| 項目 | 創業簽證（特定活動） | 經營・管理簽證 |
| --- | --- | --- |
| 定位 | 創業準備階段的在留 | 正式的經營・管理在留 |
| 在留資格 | 特定活動 | 經營・管理 |
| 來日時的資本金・常勤職員 | 無須即刻滿足（以計畫確認即可） | 原則須滿足基準 |
| 審查・確認主體 | 實施團體（獲認定的地方公共團體或民間事業者）確認計畫，入管核予特定活動 | 地方出入國在留管理局 |
| 典型在留期間 | 含更新最長2年 | 1年、3年、5年等 |

## 在哪個實施團體、以何種創業活動計畫能受確認？

可使用創業簽證者，限經濟產業省外國人創業活動促進事業認定的實施團體（獲認定的地方公共團體或民間事業者）。過去國家戰略特區的機制與經濟產業省的機制並立，但已於2025年1月統合至經濟產業省機制、整理為全國推展的形式。對象實施團體有數個，並隨制度改動而增減。可使用的實施團體與窗口，請以經濟產業省的制度頁面與各實施團體的指引確認。

欲受確認，須向各實施團體提出「創業準備活動計畫」。實施團體就事業的具體性、實現可能性、對地區的貢獻等進行審查，認為適當者即交付確認證明書（創業準備活動計畫確認證明書）。審查時亦有實施團體聽取中小企業診斷士、投資家等對創業、經營有見識的第三方意見。計畫內容，以及在留期間內須展示何等整備事業用財產的見込等要件，已於令和7年（2025年）10月16日施行的告示修正中就見込基準、本人要件一部調整。具體基準由各實施團體的實施要綱所定，請於提出前以最新要綱確認。

| 確認流程 | 內容 |
| --- | --- |
| ① 提出創業準備活動計畫 | 向認定實施團體（獲認定的地方公共團體或民間事業者）提出事業計畫 |
| ② 實施團體審查・確認 | 審查具體性、實現可能性等（亦有聽取第三方意見之例） |
| ③ 交付確認證明書 | 交付創業準備活動計畫確認證明書 |
| ④ 在留資格申請 | 附確認證明書向地方出入國在留管理局申請特定活動 |

## 在留期間內須準備什麼、何時移轉至正式簽證？

獲核予在留資格「特定活動」後，於該期間內推進向正式「經營・管理」移轉的準備。具體而言為公司設立、獨立事業所的確保、資本金・出資的準備、計畫的精緻化等。在留期間含更新最長2年，惟亦有要求每半年更新的實施團體，更新單位與上限因實施團體、計畫而異。

期滿後若欲在日本續行事業經營，須申請將在留資格自「特定活動」變更為「經營・管理」。於此變更時點，將審查是否滿足「經營・管理」基準（除上述適用舊基準的例外外，2025年10月16日修正後，除資本金・出資總額3,000萬日圓以上、常勤職員1人以上等形式要件外，尚有日語能力、事業計畫書的專家確認等定性要件）。更新、變更階段所問的事業繼續性・實體之考量，詳見[經營・管理簽證更新所問「事業的繼續性・實體」之舉證](/zh-tw/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)。變更未獲准時須歸國，故準備時程宜保留餘裕。

| 階段 | 應辦事項 | 相關專家 |
| --- | --- | --- |
| 特定活動在留中 | 公司設立・事業所確保・資本金準備・計畫精緻化 | 行政書士・司法書士・稅理士 |
| 期滿前 | 準備「經營・管理」的變更申請 | 行政書士（申請取次） |
| 變更後 | 以「經營・管理」正式營運事業 | 稅理士・社會保險勞務士 等 |

## 公司設立、社會保險、稅務各該向誰委託？

自使用創業簽證至移轉正式簽證，橫跨多位專家的領域。四葉集團的行政書士以獨立的事業體承辦創業準備活動計畫的確認申請文件製作輔助，以及在留資格（特定活動・經營・管理）的申請文件製作輔助與申請取次（文件製作依行政書士法第1條之3；申請取次依入管申請等取次制度）。亦請參閱本所的[承辦業務](/zh-tw/legal/services)、[受任流程](/zh-tw/legal/nagare)、[報酬額表](/zh-tw/legal/ryokin)。與各專家均以獨立的事業體分別簽約，彼此不收取介紹費。

公司設立、役員變更等登記由司法書士辦理；資本金確認前提的稅務、法人稅・消費稅申報由稅理士負責；僱用員工時的社會保險、僱用保險、勞務由社會保險勞務士負責；作為獨立事業所的物件之選定與租賃仲介、重要事項說明由屬不同事業體的四葉不動産株式会社負責。各事業體皆為獨立，雖可於同一窗口受理諮詢，仍請分別簽訂契約。

| 委託對象 | 主要角色 |
| --- | --- |
| 行政書士（本所） | 創業活動計畫的確認申請・在留資格申請文件製作輔助與申請取次（文件製作依行政書士法第1條之3；申請取次依入管申請等取次制度） |
| 司法書士 | 公司設立・役員變更・本店遷移等商業登記 |
| 稅理士 | 資本金確認前提的稅務、法人稅・消費稅・決算申報 |
| 社會保險勞務士 | 員工的健康保險・厚生年金・僱用保險・勞災手續 |
| 不動產業者（屬不同事業體的本公司） | 作為獨立事業所的物件之選定・租賃仲介・重要事項說明 |

找房時如何出示在留資格、保證公司扮演什麼角色，可參閱獨立經營的四葉不動産株式会社所整理的[外國人在日本找房指南](/zh-tw/global)。房屋仲介與在留手續分別簽約。

## 常見問題

**Q. 用創業簽證，即使沒有資本金也能來日本準備創業嗎？**
A. 創業簽證（外國人創業活動促進事業）是一種制度：即使是來日時無法滿足「經營・管理」資本金・常勤職員等要件的創業者，只要受實施團體對創業準備活動計畫的確認，即可以在留資格「特定活動」停留日本進行準備。惟確認會審查計畫的具體性、實現可能性，並設有見込基準。許可本身由地方出入國在留管理局審查決定。

**Q. 任何實施團體都能使用嗎？**
A. 可使用者限經濟產業省外國人創業活動促進事業認定的實施團體（獲認定的地方公共團體或民間事業者）。2025年1月國家戰略特區的機制與經濟產業省的機制已統合為全國推展的形式，惟對象實施團體隨制度改動而增減。可使用的實施團體與窗口，請以經濟產業省的制度頁面與各實施團體的指引確認。

**Q. 在留期間多長、能否延長？**
A. 在留資格「特定活動」的期間含更新最長2年，惟亦有要求每半年更新的實施團體，更新單位與上限因實施團體、計畫而異。期間的運用可能經修訂，請以最新指引確認。期滿後若欲續業，須變更為在留資格「經營・管理」。

**Q. 期間結束後一定能變更為經營・管理簽證嗎？**
A. 並非自動變更。期滿後若欲在日本續行事業經營，須申請自「特定活動」變更為「經營・管理」並受審查。除上述適用舊基準的例外外，2025年10月16日修正後的「經營・管理」要求資本金・出資總額3,000萬日圓以上、常勤職員1人以上等基準。變更能否獲准，由兼顧基準充足與事業實體的入管審查決定。
