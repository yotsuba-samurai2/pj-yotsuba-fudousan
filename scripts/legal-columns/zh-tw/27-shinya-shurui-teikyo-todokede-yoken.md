**結論（先說要點）**：以酒吧、居酒屋等於午前0時至午前6時之深夜以供酒為主要營業者，須依風俗營業等之規制及業務適正化等相關法律（風營法）第33條第1項，就各營業所向管轄其所在地之公安委員會提出「深夜供酒飲食店營業」開始申報書。窗口為管轄之警察署生活安全課，須於開始營業約10日前申報。申報以已取得食品衛生法之飲食店營業許可為前提，於住居系用途地域，可能因都道府縣條例而不得營業。本文為一般資訊提供，整理深夜供酒飲食店營業之申報要件・用途地域・營業所構造設備，以及與飲食店營業許可、租賃之角色分工，不判斷個別申報之可否。

## 深夜供酒，為何須另行申報？

開設飲食店，首先須取得保健所（食品衛生法）之飲食店營業許可。此外，若於午前0時至6時之深夜持續「以供酒為主之營業」，另須風營法第33條第1項之申報。

判斷之分界在於「深夜賣何種商品之店」。風營法第2條第13項第4號將酒吧、酒場及其他向客供酒之營業定為「供酒飲食店營業」。其中，以通常認為主食之餐點為營業常態之店（如拉麵店、牛丼店等以主食為中心者）則被排除。

| 深夜（0～6時）之營業內容 | 第33條之申報 |
| --- | --- |
| 酒吧・小酒館・居酒屋等以供酒為中心 | 須申報 |
| 拉麵店・定食店等以供主食為常態，酒為附隨 | 原則不須 |
| 以接待款待客人（該當酒店等風俗營業） | 申報不足，且原則不得於0時後營業 |

伴隨接待之風俗營業原則禁止深夜營業，與深夜供酒飲食店營業屬不同架構。四葉行政書士事務所於行政書士業務範圍內，支援申報要否之確認、要件之整理、申報書與附件圖面之製作、申報之代理。個別可否由所轄審查。

## 不得申報之用途地域・立地為何？

深夜供酒飲食店營業，依風營法第33條第4項，各都道府縣得以條例「定地域禁止營業」。多數都道府縣將住居聚集之用途地域（住居系用途地域）指定為營業禁止地域。

因此，即使物件良好，若其所在地屬住居系用途地域或條例禁止地域，縱使申報亦不得營業。用途地域由都市計畫所定，即使同一街道，亦因區劃而異。決定物件前，宜確認所在地之用途地域與都道府縣條例之禁止地域。立地之可否，為申報前提之重要確認事項。

## 營業所之平面圖・構造，會審查什麼？

申報書須附營業所平面圖，並依都道府縣條例所定營業所構造・設備之技術上基準審查。代表性基準如下（數值於多數都道府縣共通，細節依條例而異）。

| 項目 | 基準概略 |
| --- | --- |
| 客室之樓地板面積 | 每室9.5㎡以上（僅1客室時不適用） |
| 客室內之視線 | 不設置妨礙視線、概略高逾1公尺之設備 |
| 裝飾等 | 不設置有害善良風俗之虞之照片・裝飾等 |
| 出入口之上鎖 | 客室出入口不設上鎖設備（通往店外之出入口除外） |
| 明亮度 | 營業所內照度不低於20勒克斯 |
| 噪音・振動 | 不超過條例所定數值基準 |

平面圖須繪明客室・調理場・廁所等之配置與樓地板面積、設備高度。若圖面與現況不符，可能於申報後之調查受指摘。若對營業所內裝或隔間施工，宜依此基準設計為妥。

## 與飲食店營業許可、租賃如何分工？

深夜供酒飲食店營業橫跨多項手續與專業領域。分工如下。

- 深夜供酒飲食店營業開始申報之要件確認・平面圖等製作・申報代理 → 四葉行政書士事務所（行政書士）
- 店舖物件之租賃・立地（用途地域）確認・使用條件之調整 → 四葉不動產株式會社（宅地建物交易業者）
- 飲食店營業許可（食品衛生法）之申請 → 保健所（構造基準之確認視需要與設計・內裝業者）

飲食店營業許可為保健所（食品衛生法）之手續，與深夜供酒飲食店營業之申報，根據法律與窗口均不同。取得飲食店營業許可，為第33條申報之前提。

與四葉行政書士事務所別事業體之四葉不動產株式會社，以獨立的事業體、個別契約擔任物件尋找・租賃契約・用途地域之確認。飲食店營業許可屬保健所所管，非本事務所代行事項。各領域均以與各窗口・資格者作為獨立的事業體個別簽約為前提，本事務所不收取介紹費。受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)；取扱業務之全貌見[許認可・各種申請服務](https://luck428.com/legal/services)。其他開業許認可，亦可參考[古物商許可，營業所需要什麼？](https://luck428.com/legal/column/kobutsusho-kyoka-eigyosho-yoken)、[產業廢棄物收集運搬業許可如何取得？](https://luck428.com/legal/column/sanpai-shushu-unpan-kyoka-torikata)。

## 常見問題

**Q. 本店為拉麵店，深夜亦供生啤酒，須申報嗎？**
A. 以通常認為主食之餐點（如拉麵）為營業常態之店，被排除於風營法第2條第13項第4號之「供酒飲食店營業」，縱於深夜附隨供酒，原則亦不須第33條之申報。惟若實態上供酒被判斷為營業之中心，則可能須申報。個別判斷由所轄警察署為之，建議開業前確認。

**Q. 申報應於何時前提出？**
A. 須於開始營業約10日前，向管轄營業所所在地之公安委員會（窗口為所轄警察署生活安全課）提出申報書。因平面圖等附件之製作費時，宜配合內裝工程計畫及早準備。

**Q. 住居系用途地域是否不得深夜營業？**
A. 依風營法第33條第4項，多數都道府縣以條例將住居系用途地域等指定為營業禁止地域。若物件所在地屬禁止地域，縱使申報亦不得於深夜供酒營業。用途地域與條例禁止地域，宜於決定物件前確認。

**Q. 已有飲食店營業許可，是否即不須深夜申報？**
A. 否。飲食店營業許可（食品衛生法・保健所）與深夜供酒飲食店營業之申報（風營法・公安委員會）為不同手續。取得飲食店營業許可雖為申報之前提，但僅此並不得於0時後以供酒為主營業。兩者均須。
