**結論（先講重點）**：沒有法定繼承人（不明有無繼承人）時，遺產成為法人（民法第951條），家庭裁判所依利害關係人或檢察官的請求，選任相續財產清算人（民法第952條第1項）。清算人向債權人、受遺贈人清償，仍有剩餘者，可分與給與被繼承人維持共同生計者、致力於療養看護者等特別緣故者（民法第958條之2），最終剩餘者歸屬國庫（民法第959條）。2023年（令和5年）4月1日施行的修正，將「相續財產管理人」改為「相續財產清算人」，並使公告並行。本文從行政書士的角度，將手續全貌整理為一般性資訊。選任的聲請與審判為家庭裁判所的手續，屬律師、司法書士的領域；不動產登記由司法書士；繼承稅由稅理士，各以獨立的事業體分別簽約為前提分別承接。

## 沒有法定繼承人時，遺產會如何？

沒有配偶、子女、直系尊親屬、兄弟姊妹，或全體皆拋棄繼承——此種「不明有無繼承人」的情形，遺產原本會處於懸空狀態。民法將此財產視為一個法人（相續財產法人，民法第951條），並備有由家庭裁判所選任的相續財產清算人加以管理、清算的機制。清算人向被繼承人的債權人與受遺贈人清償，若有剩餘財產，經對特別緣故者的分與，最後剩餘者歸屬國庫。

| 階段 | 內容 | 依據 |
| --- | --- | --- |
| 相續財產法人的成立 | 不明有無繼承人時，遺產成為法人 | 民法第951條 |
| 清算人的選任與尋找繼承人的公告 | 家庭裁判所選任清算人，並定6個月以上的期間為尋找繼承人的公告 | 民法第952條 |
| 對債權人、受遺贈人的公告 | 清算人定2個月以上的期間為請求申報的公告（於上述6個月期間內屆滿） | 民法第957條第1項 |
| 無人主張權利時 | 期間內無繼承人主張權利者，未知的債權人、受遺贈人不得行使權利 | 民法第958條 |
| 對特別緣故者的分與 | 家庭裁判所依請求，將清算後剩餘財產的全部或一部給與 | 民法第958條之2 |
| 歸屬國庫 | 未經處分的財產歸屬國庫 | 民法第959條 |

「沒有繼承人」的情形，不僅包含自始即無任何親屬的情形，也包含繼承人全體拋棄繼承而結果無人承繼的情形。拋棄繼承的基本，於[拋棄繼承與限定承認](https://luck428.com/legal/column/souzoku-hoki-gentei-shonin)中整理。

## 相續財產清算人由誰、如何選任？

相續財產清算人，由家庭裁判所依利害關係人或檢察官的請求選任（民法第952條第1項）。利害關係人包含曾借款給被繼承人的債權人、受遺贈的受遺贈人、可能成為特別緣故者立場的人，以及對被繼承人有債權、債務的人等。聲請對象為管轄被繼承人最後住所地的家庭裁判所。手續依家事事件手續法別表第一所列的審判事件進行。

| 項目 | 內容 |
| --- | --- |
| 得聲請之人 | 利害關係人（債權人、受遺贈人、可能成為特別緣故者之人等）或檢察官 |
| 聲請對象 | 管轄被繼承人最後住所地的家庭裁判所 |
| 手續性質 | 家事事件手續法（別表第一的審判事件） |
| 預納金 | 可能被要求預納官報公告費用與清算人報酬的預納金 |

清算人多由律師或司法書士擔任。選任後，清算人進行尋找繼承人的公告與對債權人、受遺贈人的請求申報公告，將財產變現以供清償。選任的聲請與審判為向家庭裁判所的手續；代理及具爭議性的對應屬律師，審判聲請書類的製作與登記屬司法書士的領域。行政書士於行政書士業務範圍內，就財產與關係人的整理等前提部分，以資訊方式協助。

## 何種人可作為特別緣故者受財產分與？

經清算後仍有剩餘財產，且無人主張繼承人權利時，家庭裁判所若認為適當，可將清算後剩餘財產的全部或一部給與特別緣故者（民法第958條之2第1項）。條文所列的特別緣故者，為下列三種類型。

| 類型 | 例 |
| --- | --- |
| 與被繼承人維持共同生計者 | 內緣、事實婚配偶，事實上的養子女等 |
| 致力於被繼承人療養看護者 | 長年持續照顧起居或看護之人 |
| 其他與被繼承人有特別緣故者 | 被認定具有相當於上述之密切關係之人 |

請求分與，須於清算人選任公告（民法第952條第2項）所定期間屆滿後3個月內為之（民法第958條之2第2項）。逾此期限即無法受分與，故時期的管理甚為重要。是否分與、範圍為何，由家庭裁判所依與被繼承人關係的深淺與財產狀況判斷。何人屬特別緣故者，最終由家庭裁判所判斷，本文並不斷定其可能性。獨居者於生前預作準備的方法，於[死後事務委任契約](https://luck428.com/legal/column/shigojimu-inin-keiyaku-ohitorisama)與[任意監護契約](https://luck428.com/legal/column/nini-koken-keiyaku-ikogata)中整理。

## 2023年的民法修正，使清算的手續與期間有何改變？

2023年（令和5年）4月1日施行的民法等一部修正之法律（令和3年法律第24號），大幅整理了此一領域。重點在於名稱與公告二者。

| 修正點 | 修正前 | 修正後 |
| --- | --- | --- |
| 名稱 | 相續財產管理人 | 相續財產清算人 |
| 公告的進行方式 | 依序進行選任公告、債權申報公告、尋找繼承人公告 | 尋找繼承人公告（6個月以上）與債權申報公告（2個月以上）並行進行 |
| 手續所需期間的概略 | 因公告依序疊加，合計10個月以上 | 因公告並行，最短約6個月左右 |

修正前須依序疊加三種公告，至清算完成至少需10個月以上。修正後，使對債權人、受遺贈人的請求申報公告（民法第957條第1項）於尋找繼承人的公告（民法第952條第2項）期間內屆滿，並行進行，故期間得以縮短。又，此次修正另設有以繼承開始後遺產的保存為目的之相續財產管理人（民法第897條之2）此一不同制度，因名稱相似，須注意勿混淆。

## 選任聲請、登記、繼承稅該分別向誰諮詢？

繼承人不存在的手續，牽涉家庭裁判所、登記與稅務，橫跨多位有資格者的領域。角色分工如下，各以獨立的事業體分別簽約為前提。

- 手續全貌的整理、財產與關係人資訊的整理 → 四葉行政書士事務所（行政書士業務範圍內）
- 相續財產清算人選任的聲請與審判等家庭裁判所的手續、具爭議性的事案 → 律師（代理、協商）、司法書士（聲請書類的製作）
- 變更為相續財產清算人名義的登記、伴隨歸屬國庫或對特別緣故者分與的不動產登記 → 司法書士
- 繼承稅、讓渡所得等稅務的申報 → 稅理士

行政書士不得代理家庭裁判所的審判聲請，被選任為清算人者通常亦為律師、司法書士。本事務所的角色，僅止於手續的藍圖繪製，以及行政書士業務範圍內的資訊整理。繼承業務的全貌請見[繼承業務的服務](https://luck428.com/legal/services/inheritance)、受任流程請見[受任的流程](https://luck428.com/legal/nagare)、費用請見[報酬額表](https://luck428.com/legal/ryokin)。作為放手土地之選項的國庫歸屬，亦於[繼承土地國庫歸屬制度](https://luck428.com/legal/column/souzoku-tochi-kokko-kizoku)中處理。繼承的不動產出售等不動產諮詢，由另一事業體四葉不動產股份有限公司於[繼承不動產的窗口](https://luck428.com/souzoku)對應。四葉行政書士事務所與四葉不動產股份有限公司為不同的事業體，各領域皆以獨立的事業體分別簽約為前提。本事務所不收取介紹費。

## 常見問題

**Q. 繼承人全體拋棄繼承時也需要相續財產清算人嗎？**
A. 繼承人全體拋棄而無人承繼時，屬於「不明有無繼承人」，遺產成為法人（民法第951條）。有向債權人清償或處分財產之必要時，由利害關係人或檢察官向家庭裁判所聲請選任相續財產清算人（民法第952條第1項）。

**Q. 內緣配偶能取得財產嗎？**
A. 內緣、事實婚配偶並非法定繼承人，惟可作為與被繼承人維持共同生計者等特別緣故者，向家庭裁判所請求財產分與（民法第958條之2第1項）。請求須於清算人選任公告期間屆滿後3個月內為之（同條第2項）。是否准許由家庭裁判所判斷。

**Q. 手續需要多久？**
A. 2023年（令和5年）4月1日施行的修正使公告得並行進行，最短約6個月左右為概略基準。修正前因公告依序疊加需10個月以上。實際期間視財產內容與變現狀況而異。

**Q. 剩餘的財產最終會如何？**
A. 清算後，縱經對特別緣故者的分與仍未處分的財產，歸屬國庫（民法第959條）。有不動產剩餘時的名義變更（變更為相續財產清算人名義的登記或歸屬國庫的登記）由司法書士、繼承稅由稅理士，各以獨立的事業體分別簽約後對應。
