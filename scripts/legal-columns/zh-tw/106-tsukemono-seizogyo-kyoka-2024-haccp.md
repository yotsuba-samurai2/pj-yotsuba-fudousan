**結論（先講重點）：**於直賣所、道之驛或網路販售醬菜（淺漬、泡菜、梅乾、澤庵等）而製造者，原則上須取得「醬菜製造業」的營業許可。此係2018年（平成30年）修正食品衛生法等部分條文的法律（平成30年法律第46號）重新檢討許可業種時新設的業種，定於食品衛生法施行令第35條第29號，許可依食品衛生法第55條由保健所（都道府縣知事等）核發。施行令施行日（2021年〔令和3年〕6月1日）前即已營業者，設有3年的經過措施，惟已於2024年（令和6年）5月31日屆滿，自2024年6月1日起，無許可即不得製造販售用醬菜。許可須符合都道府縣以條例所定的設施基準（食品衛生法第54條）、沿HACCP的衛生管理（食品衛生法第51條），並須設置食品衛生責任者，家庭廚房原樣則不予許可。本文為一般性資訊，不就個別設施是否符合基準作最終判斷。四葉集團的行政書士，以獨立的事業體承辦營業許可申請文件與衛生管理計畫整備的支援。設施的適合審查與許可屬保健所，製造室的施工屬建築士與設備業者，營業稅務屬稅理士，員工的勞務屬社會保險勞務士，物件尋找屬不同事業體的不動產業者，各自分別簽約。

## 賣醬菜何以需要營業許可？

醬菜長期僅屬都道府縣條例下的「申報」對象，多數地區不需食品衛生法上的營業許可。惟因淺漬等所致的食物中毒曾經發生等背景，2018年（平成30年）修正食品衛生法（平成30年法律第46號）整體重新檢討許可業種，將醬菜製造業新定為許可業種。其依據為食品衛生法施行令第35條第29號，於此列為須許可的業種。

| 項目 | 內容（依據） |
| --- | --- |
| 業種的新設 | 依修正食品衛生法等部分條文的法律（平成30年法律第46號）重新檢討許可業種 |
| 定位 | 食品衛生法施行令第35條第29號「醬菜製造業」 |
| 許可的依據 | 食品衛生法第55條（都道府縣知事等的營業許可） |
| 施行令的施行日 | 2021年（令和3年）6月1日 |

醬菜製造業，除梅乾、澤庵、淺漬、泡菜、酸黃瓜等的製造外，亦有不少自治體說明包含以醬菜為主要原料的食品的製造，範圍細節因保健所而異。與其他食品相關許認可的關係，另於[食品製造業的許可與物件、設備基準](https://luck428.com/legal/column/shokuhin-seizogyo-kyoka-bukken-setsubi-kijun)整理。亦請參閱本事務所的[許認可服務案內](https://luck428.com/legal/services)。

## 2024年6月以後，無許可販售醬菜會如何？

施行令施行日（2021年〔令和3年〕6月1日）前即已製造醬菜者，設有3年的經過措施。該期限已於2024年（令和6年）5月31日屆滿，自2024年6月1日起，無許可即不得製造販售用醬菜。

| 時期 | 處理 |
| --- | --- |
| 2021年6月1日前即已營業 | 須於2024年5月31日前取得許可（經過措施） |
| 2024年6月1日以後 | 無許可即不得製造販售用醬菜。新設者須於營業前取得許可 |

未取得許可而營業者（違反食品衛生法第55條第1項），依同法第82條為2年以下拘禁刑或200萬日圓以下罰金的對象，法人亦得依第88條的兩罰規定科以同額罰金。自製自用，或無償往來，通常不屬「以營業為之」的製造、販售，惟既反覆繼續販售，即須許可。是否該當有疑義時，請勿逕為前提，而直接向保健所確認為妥。

## 可獲許可的製造室設施基準（洗手、區劃、給排水）須至何種程度？

許可須於設施符合都道府縣以條例所定的設施基準（食品衛生法第54條；參酌厚生勞動省令的基準而定）後，始予核發。家庭廚房與住居一體的空間原樣，原則上不予許可。代表性的確認點如下，惟具體數值、規格，務必依所管保健所的條例、要綱確認。

| 區分 | 主要確認點（因條例而異） |
| --- | --- |
| 區劃 | 製造室以牆壁等與住居、居室區劃，並區分作業區域 |
| 洗手 | 於製造室、廁所設置可洗淨消毒的洗手設備 |
| 給排水 | 使用水的確保（適於飲用）與適當的排水、洗淨設備 |
| 構造、材質 | 地板、牆壁、天花板易於清掃，器具為不浸透性且易洗淨的材質 |
| 區域、換氣 | 更衣場所、保管設備、換氣、照明、防蟲防鼠對策 |

製造室的施工、內裝屬建築士、設備業者的領域，租賃物件階段的用途與設備可否，為不動產的確認事項。嗣後修改格局、給排水將使費用增加，故於押定物件前，由保健所事前諮詢並審閱圖面為實務作法。食品物件設備的思考方式，亦於[食品製造業的許可與物件、設備基準](https://luck428.com/legal/column/shokuhin-seizogyo-kyoka-bukken-setsubi-kijun)觸及。

## 作為沿HACCP的衛生管理，小規模業者應記錄何事？

自2020年（令和2年）6月1日起（經經過措施後，於2021年6月1日完全施行），原則上對所有食品等業者均要求「沿HACCP的衛生管理」（食品衛生法第51條）。醬菜製造業亦無例外。惟就小規模營業者等，認可因所取扱食品特性而異的「導入HACCP思考的衛生管理」，依厚生勞動省公布的業種別手引書推進。

| 區分 | 所要求的取組（食品衛生法第51條） |
| --- | --- |
| 一般衛生管理 | 施設內外的清潔保持、鼠蟲的驅除、使用水與器具的管理等 |
| 重要工程的管理 | 為防危害發生而管理特別重要工程的取組（洗淨、鹽分或溫度的管理等） |
| 小規模營業者等 | 因食品特性而異的取組（依手引書作成衛生管理計畫並記錄） |

小規模業者「寫什麼」的核心，在於依手引書的範本作成衛生管理計畫，並就原材料的受入、使用水、洗手、溫度管理等的實施每日查核並留存記錄。記錄宜作成嗣後能說明衛生管理的形式。衛生管理計畫的整備與樣式的準備，行政書士得予支援，惟計畫是否符合基準的最終審查由保健所為之。手引書的最新版，請勿逕為前提，而於厚生勞動省的官方網頁確認。

## 申請向何處、委託何人較為確實？

申請對象為管轄製造所所在地的保健所（都道府縣知事、保健所設置市長等的許可）。因相關專業人員分屬不同領域，原則上請與各專業以獨立的事業體分別簽約。四葉集團的行政書士，以獨立的事業體承辦營業許可申請文件的作成、提交代辦，衛生管理計畫整備的支援，以及食品衛生責任者的確認。

| 委託對象 | 主要角色 |
| --- | --- |
| 行政書士（本事務所） | 營業許可申請文件的作成、提交，衛生管理計畫整備的支援 |
| 保健所 | 設施基準的適合審查、現地確認，許可的決定 |
| 建築士、設備業者 | 製造室的施工、給排水、內裝等的施作 |
| 稅理士 | 營業額、進貨的記帳，稅務申報 |
| 社會保險勞務士 | 僱用員工時的勞動保險、社會保險，就業規則 |
| 不動產業者（屬不同事業體的本公司） | 可供製造的物件的介紹、簽約 |

個別設施是否符合基準、應以何業種區分申請等判斷，最終屬保健所的審查領域，行政書士不得代為保證許可。尋找可供製造的物件階段，由不同事業體的不動產業者得予協助。亦請參閱本事務所的[受任流程](https://luck428.com/legal/nagare)與[報酬表](https://luck428.com/legal/ryokin)。與各專業人員均以獨立的事業體簽約，彼此不收取介紹費。

## 常見問題

**Q. 可將於自宅廚房所製的梅乾於道之驛販售嗎？**
A. 若反覆繼續以販售為目的而製造，原則上須取得醬菜製造業的許可。與住居一體的家庭廚房原樣不符設施基準，通常不予許可，須有與住居區劃的製造室等設備。是否該當，請向所管保健所確認。

**Q. 以往即販售醬菜，現在仍須許可嗎？**
A. 須要。施行令施行前即已營業者的3年經過措施，已於2024年（令和6年）5月31日屆滿。自2024年6月1日起，無許可即不得製造販售用醬菜。若無許可而持續者，請速向保健所洽詢。

**Q. 縱為小規模，亦須對應HACCP嗎？**
A. 須要。惟就小規模營業者等，認可因所取扱食品特性而異的「導入HACCP思考的衛生管理」，依厚生勞動省的業種別手引書作成衛生管理計畫，並就每日實施加以記錄即足（食品衛生法第51條）。

**Q. 未取得許可而販售會如何？**
A. 未取得許可而營業的行為，違反食品衛生法第55條第1項，依同法第82條為2年以下拘禁刑或200萬日圓以下罰金的對象。法人亦得依兩罰規定（第88條）科以罰金。個別該當性的判斷，屬保健所、偵查機關的領域。
