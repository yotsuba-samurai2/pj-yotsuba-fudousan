**結論（先說要點）**：生活介護，是身心障礙者綜合支援法第5條第7項所定之身心障礙福祉服務，開業須向都道府縣知事（指定都市・中核市為市長）取得指定身心障礙福祉服務事業者的指定（同法第36條）。人員・設備・營運之基準，依同法第43條，並由國之基準——平成18年厚生勞動省令第171號與各自治體之條例具體定之。物件須於面積・設備・避難齊備後，方成為指定之對象，故須一面製作申請書，一面並行確保物件、招募人員、確認建築與消防。本文整理指定申請之流程與物件應滿足之點，並說明何部分應委託何人。指定可否與是否符合基準，由指定權者審查決定，本事務所不保證取得指定。

## 生活介護之指定基準，由何法令決定？

生活介護，是綜合支援身心障礙者日常生活及社會生活之法律（身心障礙者綜合支援法。平成17年法律第123號）第5條第7項所定之服務。定義為：就需要經常介護之身心障礙者，主要於白天，於身心障礙者支援設施或其他設施，供與入浴・排泄・飲食等介護、創作活動或生產活動之機會，及其他便宜。

欲經營，須取得同法第36條之指定身心障礙福祉服務事業者之指定。指定之人員・設備・營運基準，依同法第43條，並以國之基準（平成18年厚生勞動省令第171號，關於指定身心障礙福祉服務事業等之人員、設備及營運之基準）為據，由都道府縣・指定都市・中核市之條例定之。應確認之法令，遂成「法律→省令→自治體條例」之三層。

| 區分 | 依據 |
| --- | --- |
| 服務之定義 | 身心障礙者綜合支援法第5條第7項 |
| 事業者之指定 | 身心障礙者綜合支援法第36條 |
| 人員・設備・營運基準之委任 | 身心障礙者綜合支援法第43條 |
| 國之基準 | 平成18年厚生勞動省令第171號 |
| 具體基準 | 都道府縣・指定都市・中核市之條例 |

利用者受支援，以障礙支援區分之認定為前提；生活介護之對象原則為區分3以上（伴隨設施入所者為區分4以上），年齡50歲以上者基準放寬。區分之範圍由厚生勞動省令定之，故個別是否該當，以認定與自治體之運用確認。

## 生活介護之人員基準，須幾人？

人員基準規定於平成18年厚生勞動省令第171號，並由自治體條例具體化。基本配置如下。

| 職種 | 配置思考方式 |
| --- | --- |
| 醫師 | 為利用者健康管理・療養指導所需之數（囑託醫即可） |
| 看護職員・理學療法士或作業療法士・生活支援員 | 此3職種之總數，依平均障礙支援區分配置。看護職員1人以上、生活支援員1人以上，其中1人以上常勤 |
| 服務管理責任者 | 利用者60人以下1人以上。61人以上，每40人（含端數）加1人 |
| 管理者 | 原則專任常勤1人（無妨礙時得兼任） |

看護職員・理學療法士或作業療法士・生活支援員之總數，依平均障礙支援區分，下限如下變動。

| 平均障礙支援區分 | 總數之下限 |
| --- | --- |
| 未滿4 | 利用者人數除以6以上 |
| 4以上未滿5 | 利用者人數除以5以上 |
| 5以上 | 利用者人數除以3以上 |

生活介護之指定原則須利用定員20人以上（多機能型等類型思考方式會改變）。符合人員基準之僱用契約・工時設計・工作規則・社會保險適用，屬社會保險勞務士領域，與本公司為獨立的事業體，各自個別簽約。

## 物件之面積・設備，於何處會不合格？

設備基準（平成18年厚生勞動省令第171號）要求訓練・作業室、諮詢室、洗面所、廁所、多目的室及其他營運上必要之設備。物件易不足之點如下。

| 設備 | 主要要求 |
| --- | --- |
| 訓練・作業室 | 不妨礙訓練・作業之寬度；備必要之機械器具。部分自治體以條例訂定每人面積，有以3.3㎡以上為例者 |
| 諮詢室 | 得以隔間等顧及隱私 |
| 洗面所・廁所 | 依利用者特性之數量・規格 |
| 多目的室 | 於不妨礙支援提供時，部分自治體允許與諮詢室兼用 |

輪椅移動、廁所與出入口寬度、消除高低差等無障礙，亦關乎建築基準法及各自治體之福祉城鄉營造條例。設備不僅看「有無」，更看「寬度・規格・動線是否符合基準」，故於看屋階段將圖面與現況對照確認，是減少返工之捷徑。面積或設備未達基準之物件，不成為指定之對象。

## 用途變更之確認申請，自何規模起需要？

將事務所或店舖等既有建物改為生活介護事業所時，可能構成建築基準法上之用途變更。身心障礙福祉服務事業所，被視為建築基準法施行令第19條所稱之「兒童福祉設施等」，並定位為同法之特殊建築物。

向特殊建築物用途變更，且供該用途使用部分之樓地板面積超過200㎡時，依建築基準法第87條第1項，準用同法第6條第1項第一號，須向建築主事或指定確認檢查機關提出確認申請。此樓地板面積基準，自原本之逾100㎡提高為逾200㎡，於2019年（令和元年）6月25日施行。惟即使在200㎡以下，建築基準法・消防法之實體基準（防火・避難・採光等）仍適用，故「無須確認申請」與「符合基準」係屬二事。

是否構成用途變更、是否需要確認申請，係基於圖面與現況之建築專業判斷。設計・確認申請宜委託建築士（設計者），並一併確認既存不合格與有無檢查濟證。本公司僅承擔物件資訊與用途地域・面積之一次確認，不作建築確認之判斷。

## 消防設備於何處產生追加成本？

生活介護事業所，區分於消防法施行令別表第一之(6)項（社會福祉設施等）。即使同為(6)項，主要收容自力避難困難者之設施(6)項ロ，與以通所為主之其他(6)項ハ，所需消防用設備亦異。通所之生活介護一般區分於(6)項ハ，惟依利用者狀態與設施形態，用途判定會不同。

滅火器・自動火災報知設備・引導燈・撒水設備等之要否，由用途區分・總樓地板面積・樓層數・收容人員決定。於既有建物，此追加設置最易造成費用與工期之估算落差。防火對象物之用途判定與消防同意，由消防署判斷，故決定物件前，宜先向管轄消防署諮詢。本公司・本事務所不判斷消防設備之要否。

## 指定申請之文件與事前協議，依何順序進行？

一般流程如下。順序前後顛倒容易被退件，故宜及早開始事前協議。

1. 確定事業計畫與資金計畫，設立法人（於章程事業目的加入身心障礙福祉服務）
2. 選定物件，確認是否符合設備基準・建築基準法・消防法
3. 與指定權者進行事前協議
4. 確保服務管理責任者・生活支援員・看護職員等
5. 製作申請書與附件，於截止日前提出
6. 書面審查・必要時現地確認
7. 指定（多數自治體為每月1日生效）

多數自治體以每月1日生效核發指定，申請書提出期限一般設於希望指定日之前一月或前二月。截止日因指定權者而異，年度更替時亦可能提前，故務必於該自治體公式頁面確認。代表性必要文件如下。

- 指定申請書、指定相關記載事項（附表）
- 法人登記事項證明書、章程
- 事業所平面圖、照片、租賃契約書等
- 營運規程、重要事項說明書
- 從業者勤務體制・勤務形態一覽表、資格證・實務經驗證明、服務管理責任者研修等修了證
- 管理者・服務管理責任者之經歷書
- 收支預算書、處理利用者申訴所採措施之概要、各種誓約書 等

四葉行政書士事務所於行政書士業務範圍內，支援指定申請書・附表・附件之製作、事前協議資料整理、營運規程等文案製作。是否最終符合基準與指定可否，由指定權者審查。

## 物件・建築・勞務・登記・稅務，各應委託何人？

指定申請涉及多個專業領域。分工如下。

- 指定申請書・附表・附件之製作、事前協議支援 → 四葉行政書士事務所（行政書士）
- 事業用物件之選定・租賃・重要事項說明，及用途地域・面積之一次確認 → 四葉不動產株式會社
- 用途變更之確認申請・設計，及既存不合格與檢查濟證之確認 → 建築士（設計者）
- 消防用設備之要否判定・消防同意 → 消防署
- 符合人員基準之僱用契約・工作規則・工時管理・社會保險適用 → 社會保險勞務士
- 法人設立・變更登記 → 司法書士
- 法人會計・稅務・稅額計算 → 稅理士
- 涉及權利義務・紛爭之個別法律判斷 → 律師

## 常見問題

**Q. 生活介護事業所，任何物件都能開嗎？**
A. 除面積・設備・避難外，既有建物尚可能需要用途變更之確認申請或追加消防用設備。用途變更之判斷向建築士（設計者）確認，消防用設備之要否向消防署確認。物件與不動產、建築確認與建築士，各作為別事業體個別簽約。

**Q. 用途變更之確認申請必然需要嗎？**
A. 向特殊建築物用途變更，且供該用途使用部分之樓地板面積超過200㎡時，依建築基準法第87條第1項須提出確認申請。即使在200㎡以下無須確認申請，防火・避難・採光等實體基準仍適用。是否需要，係建築士基於圖面與現況之專業判斷。

**Q. 人員須於開所前全部備齊嗎？**
A. 服務管理責任者及常勤要件等直接關乎指定要件之人員，須於申請時點示明確保狀況。招募、勞動條件設計、社會保險適用屬社會保險勞務士領域，與本公司為獨立的事業體，各自個別簽約。

**Q. 定員自幾人起？**
A. 生活介護之指定原則須利用定員20人以上。因多機能型等類型思考方式會改變，個別定員以該自治體之條例與手引確認。
