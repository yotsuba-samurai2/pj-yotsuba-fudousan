**先講重點：** 要以事業經營寵物店、寵物美容、寵物旅館、訓練教室等，開始營業前須向管轄事業所所在地的都道府縣知事（設有保健所的政令指定都市、中核市等為市長）取得「第一種動物取扱業」的登錄。依據為動物之愛護及管理相關法律（昭和48年10月1日法律第105號）第10條第1項。登錄須就各事業所、各業種選任動物取扱責任者（同法第22條），並使飼養設施符合基準。本文為整理登錄要件與流程的一般性資訊提供，登錄與否由具登錄權的地方政府判斷，本事務所不予保證。

## 第一種動物取扱業是什麼？哪些業種是登錄的對象？

動物之愛護及管理相關法律（下稱「動物愛護管理法」）第10條第1項規定，凡以營利為目的、反覆並持續地經營動物（哺乳類、鳥類、爬蟲類，但不含畜產農業用、試驗研究用、生物製劑製造用者）之取扱者，須取得都道府縣知事等的登錄。這即是第一種動物取扱業。它與無償經營多數動物的「第二種動物取扱業」（申報制）為不同制度，以是否具有反覆持續的營利性作切分。

登錄的對象業種有下列7種。即使同一店舖，也須就各項行為特定業種登錄。例如兼營銷售與美容（保管），則兩業種都須登錄。

| 業種 | 主要例子 |
| --- | --- |
| 銷售 | 寵物店、繁殖業者（含以銷售為目的的繁殖、輸入） |
| 保管 | 寵物旅館、寵物美容（保管顧客動物者）、寵物保姆 |
| 出借 | 為攝影、活動或出租而出借動物之業 |
| 訓練 | 訓練教室、到府訓練、寄養訓練 |
| 展示 | 動物咖啡廳、互動設施、移動動物園 |
| 競賣仲介 | 動物拍賣（競賣）的仲介 |
| 受讓飼養 | 有償受讓動物並飼養，如高齡犬貓之家等 |

美容因在施術期間保管顧客的動物，多半屬於「保管」。僅處理自己飼養的動物，或無償贈與友人，通常不屬反覆持續的營利；但是否該當的最終判斷，須向開業地的地方政府出示欲經營之內容後確認。

## 要成為動物取扱責任者，需要什麼資格或實務經驗？

動物愛護管理法第22條要求第一種動物取扱業者，就各事業所選任為適正實施業務的「動物取扱責任者」。責任者須自專屬該事業所的常勤職員中選任。若開設者本人符合要件，本人亦可兼任責任者。

可擔任責任者的要件，於令和2年（2020年）6月1日施行的修正中趨於嚴格。動物愛護管理法施行規則所定的現行要件，須滿足下列其一。僅有資格，或僅有經驗，皆不足夠；係將「實務經驗」與「資格或學歷」組合要求的形式。

| 途徑 | 應滿足的要件 |
| --- | --- |
| 依資格 | 持有獸醫師免許者 |
| 依資格 | 持有愛玩動物看護師免許者 |
| 經驗＋資格、學歷 | 具欲經營業種相關半年以上的實務經驗（限以常勤職員在職）等，且已通過所定資格考試，或畢業於教學1年以上的學校等教育機關 |

代替實務經驗，就欲處理的動物種類，「認定為同等的1年以上飼養從事經驗」亦被接受；惟不含個人興趣的飼育，何謂「同等」為地方政府的裁量判斷，須事前個別協議。此外，責任者不得該當動物愛護管理法第12條第1項各款的欠格事由（如受拘禁刑以上之刑或違反動物相關法令之罰金刑未經一定期間等）。選任後，負有使責任者每年至少1次接受動物取扱責任者研修的義務（同法第22條）。

## 設施基準（籠子、照明、隔音等）要求到什麼程度？

關於飼養設施的構造、規模，於令和3年（2021年）6月1日施行的修正中，分階段導入了所謂的數值規制。動物愛護管理法施行規則的修正，就籠子等的大小、寢床與運動空間的確保、地板牆壁的材質、採光、換氣、隔音，以及汙物汙水的處理等，訂定了具體基準。

| 項目 | 主要內容 |
| --- | --- |
| 籠子等的大小 | 就犬、貓，以體長、體高為基準的最小面積、高度的數值基準 |
| 運動空間 | 寢床、休息場所與運動空間分開設置或一體設置，基準不同 |
| 每名員工的飼養頭數上限 | 犬每人20頭（其中繁殖犬15頭）、貓每人30頭（其中繁殖貓25頭）為上限 |
| 繁殖的限制 | 用於犬、貓繁殖的年齡與一生分娩次數的上限 |
| 環境的管理 | 溫濕度管理、亮度確保、臭氣與害蟲的防止等 |

每名員工飼養頭數上限等，就修正時已在營業的既有業者設有經過措施，第一種動物取扱業於令和6年（2024年）6月1日完全施行。籠子的具體尺寸與適用細節，依施行規則、告示與地方政府的運用而定，故數值當否請以開業地地方政府的手冊確認。此處不斷定全國一律的尺寸值。

## 從申請到開始營業，依什麼順序進行？

登錄的流程為：備妥申請書與附件向地方政府窗口提出，經飼養設施的現地檢查後，取得登錄證。可開始營業者為取得登錄之後，店頭須揭示標識、從業者須佩戴名牌。登錄的有效期間為5年，須每5年更新（動物愛護管理法第13條）。

| 階段 | 主要內容 |
| --- | --- |
| 事前諮詢 | 攜帶業種、設施圖面，向地方政府諮詢能否符合基準 |
| 提出申請書 | 第一種動物取扱業登錄申請書（各業種、各事業所） |
| 主要附件 | 證明責任者資格、實務經驗的文件、飼養設施平面圖與附近見取圖、事業計畫、法人的登記事項證明書等 |
| 現地檢查 | 確認飼養設施是否符合基準 |
| 登錄、交付 | 登入登錄簿、交付登錄證、揭示標識與名牌 |
| 更新 | 有效期間5年；期間屆滿前申請更新 |

申請手續費、格式與必要文件的細部，因地方政府而異。標準處理期間亦不同，故從開業預定日回推、先從事前諮詢開始較為安全。

## 物件選擇與登錄，由誰、依什麼順序處理？

若先簽訂物件契約，可能日後才發現飼養設施無法符合基準，或用途地域、建物管理規約不允許動物取扱業。安全的順序為：①物件現勘與用途確認 → ②確認設施能否符合基準、向地方政府事前諮詢 → ③簽約 → ④內裝與設備工程 → ⑤登錄申請 → ⑥現地檢查 → ⑦登錄、開始營業。物件方需要哪些條件，於[可供動物取扱業使用的物件條件](https://luck428.com/column/doubutsu-toriatsukai-bukken-youken)（不動產）整理。

- 第一種動物取扱業登錄申請的製作，以及與地方政府事前諮詢的支援 → 四葉行政書士事務所（行政書士）
- 事業用物件的選定、租賃、重要事項說明，及用途地域、管理規約的確認 → 四葉不動產株式會社
- 內裝達大規模用途變更時的確認申請 → 建築士、特定行政廳
- 開業後從業員的勞動條件、社會保險、工作規則 → 四葉社會保險勞務士事務所（社會保險勞務士）
- 會計、稅務 → 稅理士
- 涉及權利義務與紛爭的個別法律判斷 → 律師

四葉行政書士事務所與四葉不動產株式會社為不同的事業體。本事務所僅以獨立的事業體承辦第一種動物取扱業登錄申請的支援，物件、勞務、稅務請與各專業人士、事業體分別簽約、諮詢。本事務所不收取介紹費。許可的整體樣貌請見[行政許可手續](https://luck428.com/legal/services)，受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)。登錄與否本身由地方政府判斷。

## 常見問題

**Q. 我要自己開寵物美容店。需要動物取扱業的登錄嗎？**
A. 施術期間通常會保管顧客的動物，該情形屬於「保管」業種，須取得第一種動物取扱業的登錄（動物愛護管理法第10條第1項）。若兼營銷售，另加「銷售」業種登錄。是否該當的最終判斷，請向開業地的地方政府出示欲經營之內容後確認。

**Q. 只要在寵物店經驗夠久，就能當動物取扱責任者嗎？**
A. 僅有經驗並不足夠。令和2年6月1日施行的修正後，須持有獸醫師、愛玩動物看護師的資格，或將半年以上實務經驗與通過所定資格考試或畢業於1年以上教育機關組合（動物愛護管理法施行規則）。要件如何適用請向地方政府確認。

**Q. 登錄一旦取得，就永久有效嗎？**
A. 不是。登錄的有效期間為5年，須每5年更新（動物愛護管理法第13條）。若未更新而過期，登錄即失效。更新受理的開始時期因地方政府而異，請於有效期間屆滿前及早辦理。

**Q. 先租物件，之後再開始準備登錄可以嗎？**
A. 不建議。若租到飼養設施無法符合基準，或用途地域、管理規約不允許動物取扱業的物件，往往須重做內裝或契約。先進行物件現勘與用途確認、以及設施能否符合基準的確認，於簽約前建立見通，較為安全。
