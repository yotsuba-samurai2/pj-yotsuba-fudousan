**結論（先講重點）**：要將個人經營的診所法人化，首先須取得醫療法人的設立認可。醫療法人非經其主要事務所所在地的都道府縣知事認可，不得設立（醫療法第44條第1項），並且在主要事務所所在地辦理設立登記後始告成立（醫療法第46條）。認可申請的受理往往一年僅數次，且須經都道府縣醫療審議會的諮詢，因此自正式申請至認可大致需2至3個月。認可申請書、章程或捐助章程、事業計畫、財產目錄等文件的製作與提出協助，由本事務所（四葉行政書士事務所）承辦；設立登記由司法書士，法人的稅務、會計由稅理士，社會保險的轉換由社會保險勞務士，各自作為獨立的事業體分別簽約對應。本文為整理制度流程的一般性資訊提供，個別的能否認可與格式，取決於診所所在地都道府縣的審查。

## 法人化後，與個人開業有什麼不同？

醫療法人，是將擬開設醫院、有醫師或牙醫師常時勤務的診所、介護老人保健設施或介護醫療院的社團或財團予以法人化者，稱為「醫療法人」（醫療法第39條）。個人開業時，院長個人是診所的開設者；法人化後開設者變成法人，院長以理事長的身分經營法人。開設分院、拓展至介護事業、以及事業承繼的便利，是考慮法人化的主要動機。

另一方面，醫療法人受到非營利性的框架限制。醫療法人不得為剩餘金的分配（醫療法第54條），無法將利益分配給出資者。依2007年（平成19年）4月1日施行的改正醫療法，新設者原則上限於沒有出資持分規定的醫療法人。無法像股份有限公司那樣設計持分退還或分配的機制，是與個人事業或一般公司的重大差異。

| 項目 | 個人開業 | 醫療法人 |
| --- | --- | --- |
| 開設者 | 醫師個人 | 醫療法人 |
| 設立手續 | 開設申報（醫療法第8條第1項） | 設立認可（醫療法第44條第1項）＋設立登記（醫療法第46條） |
| 剩餘金分配 | ― | 禁止（醫療法第54條） |
| 持分 | ― | 新設原則上為無持分規定的醫療法人 |
| 分院、介護事業 | 以個人為單位受限 | 在章程範圍內較易拓展 |

是否法人化本身，是綜合稅務、資金週轉與承繼計畫的經營判斷。稅額與社會保險費的試算屬稅理士的領域，本事務所不進行稅務諮詢。

## 設立認可的申請何時提出？至認可需要多久？

醫療法人非經其主要事務所所在地的都道府縣知事認可，不得設立（醫療法第44條第1項）。知事在認可設立時，須事先聽取都道府縣醫療審議會的意見，此一諮詢與答覆的時程決定了整體排程。

在許多都道府縣，認可申請的受理或事前說明會一年僅數次（如春、秋）。實務上，一般是先以暫時申請（事前審查）整備文件內容，再進入正式申請，經醫療審議會審議後核發認可書。自正式申請至認可大致需2至3個月，含事前準備則須以數個月為單位往前逆算。

| 階段 | 主要內容 | 概估 |
| --- | --- | --- |
| 事前諮詢、暫時申請 | 章程草案、事業計畫、財產目錄的檢查 | 配合受理時程 |
| 正式申請 | 提出認可申請書全套 | 受理梯次（一年數次） |
| 都道府縣醫療審議會 | 諮詢、答覆 | 正式申請後數週起 |
| 認可書核發 | 設立的認可 | 正式申請後大致2至3個月 |

受理梯次、截止與格式因都道府縣而異。請務必在申請前確認開業預定地都道府縣的指引（本文不對特定都道府縣的時程作斷定）。

## 認可申請的必要文件與出資財產如何備齊？

設立認可的核心是章程或捐助章程（醫療法第44條）。社團醫療法人製作章程，財團醫療法人製作捐助章程，訂定名稱、目的、擬開設的醫療機構、事務所所在地、資產、社員（或評議員）與役員等事項。役員原則上須置理事3人以上、監事1人以上（醫療法第46條之5第1項）。

出資的財產，是用於診所營運的設備、週轉資金等，以財產目錄、出資申請書等佐證。週轉資金要估列多少，各都道府縣的運用指引有所不同，可見以一定期間的週轉資金為概估的指導，但金額基準須向都道府縣確認（本文不對具體金額作斷定）。

| 文件 | 內容 |
| --- | --- |
| 設立認可申請書 | 都道府縣所定格式 |
| 章程或捐助章程 | 社團為章程、財團為捐助章程（醫療法第44條） |
| 設立總會議事錄 | 設立意思決定的記錄 |
| 事業計畫書、預算書 | 開業後2年左右的收支預估 |
| 財產目錄、出資申請書 | 出資財產與週轉資金的佐證 |
| 役員名冊、就任承諾書 | 理事3人以上、監事1人以上（醫療法第46條之5第1項） |

這些認可申請文件的製作與提出協助，可由本事務所（四葉行政書士事務所）作為向官公署提出之文件的製作而承辦。計畫數值的合理性與稅務屬稅理士的領域。

## 認可之後，登記與稅務、勞務由誰接手？

即使核發了認可書，該時點法人尚未成立。醫療法人於主要事務所所在地辦理設立登記後始告成立（醫療法第46條）。設立登記須在認可等設立所需手續完成之日起2週內辦理。登記完成後，才能以法人身分進入診所的開設許可（醫療法第7條）、保險醫療機構的指定等手續。

角色分工如下。

- 醫療法人設立認可申請書、章程或捐助章程、事業計畫、財產目錄等文件的製作與提出協助，以及認可後各項申報的協助 → 四葉行政書士事務所（行政書士）
- 分院、遷移地等事業用物件的選定、租賃、重要事項說明 → 四葉不動產股份有限公司
- 醫療法人的設立登記、不動產登記 → 司法書士
- 法人的稅務、會計，社會保險費的試算，出資財產與事業計畫的數值 → 稅理士
- 役職員的雇用契約、工作規則、社會保險的新規適用或轉換 → 社會保險勞務士
- 涉及權利義務、糾紛的個別法律判斷 → 律師

四葉行政書士事務所與四葉不動產股份有限公司為不同事業體。本事務所僅以獨立的事業體承辦醫療法人設立認可申請的協助，物件、登記、稅務、勞務則與各該有資格者、事務所分別簽約、諮詢。設立登記交由司法書士、稅務交由稅理士，本事務所不代理登記申請、不製作登記申請書、不進行稅務諮詢。本事務所不收取介紹費。個人開業入口的診所開設申報，整理於[診所的開設是申報或許可（醫療法第8條）](https://luck428.com/legal/column/shinryojo-kaisetsu-todokede-iryoho-8jo)。承辦業務的整體樣貌請見[許認可、各種申請服務](https://luck428.com/legal/services)，受任流程請見[受任流程](https://luck428.com/legal/nagare)，費用請見[報酬額表](https://luck428.com/legal/ryokin)。能否認可本身由都道府縣判斷。

## 常見問題

**Q. 可以隨時把個人診所改為醫療法人嗎？**
A. 認可申請的受理與說明會，各都道府縣往往一年僅數次，未必想到就能立刻申請。因為要從暫時申請（事前審查）進到正式申請，再經都道府縣醫療審議會的諮詢與答覆，自正式申請至認可大致需2至3個月。受理梯次與截止請以開業預定地都道府縣的指引確認。

**Q. 醫療法人可以分配利益嗎？**
A. 不可以。醫療法人不得為剩餘金的分配（醫療法第54條）。對役員的貸款、為特定個人保有資產等實質上與分配同視的行為，亦須避免。依2007年（平成19年）4月1日施行的改正醫療法，新設原則上為沒有出資持分規定的醫療法人。

**Q. 認可下來後，可以立刻以法人身分開始診療嗎？**
A. 僅核發認可書並不使法人成立。法人於主要事務所所在地辦理設立登記後始告成立（醫療法第46條），登記須在認可等手續完成之日起2週內辦理。之後尚須以法人身分取得診所開設許可（醫療法第7條）與保險醫療機構的指定。宜逆算安排，使開業與保險診療開始的時點不致錯開。

**Q. 設立認可的申請書可以委託行政書士嗎？**
A. 向官公署提出的認可申請書、章程或捐助章程、事業計畫、財產目錄等文件的製作與提出協助，可由行政書士承辦。惟設立登記為司法書士的業務、法人的稅務與會計為稅理士的業務。本事務所不進行這些登記代理或稅務諮詢，並以各自作為獨立的事業體分別簽約為前提提供說明。
