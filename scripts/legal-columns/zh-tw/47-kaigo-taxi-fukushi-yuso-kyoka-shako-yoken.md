**結論（先講重點）**：開辦照護計程車（有償運送需照護者就醫、外出），須依道路運送法第4條取得國土交通大臣（實務為地方運輸局長）的許可。多數屬一般乘用旅客自動車運送事業中的「福祉輸送事業限定」許可；若使用附輪椅、擔架設備的福祉自動車，車輛一台即可申請。駕駛人須持有為有償運送旅客的第二種駕駛執照（道路交通法第86條）；若以轎車型的一般車輛進行照護運送，駕駛人還須具備照護福祉士、訪問照護員（居家照服員）等資格。本文以行政書士觀點，整理許可種類、營業所與車庫（物件）要件、二種駕照與照護資格、費用與期間概估，以及物件、駕照、勞務該交給誰，屬一般資訊提供。個別許可之可否由運輸支局・地方運輸局審查決定。

## 開辦照護計程車（福祉輸送）需要哪種許可？

照護計程車是回應他人需求、有償以包租乘用車運送需照護者的事業。開辦須依道路運送法第4條取得一般旅客自動車運送事業許可。

道路運送法第3條將旅客自動車運送事業分類，照護計程車屬「一般乘用旅客自動車運送事業」（以一個契約包租乘車定員未滿11人之車輛運送旅客之事業）。實務上，多以將運送對象限於需照護者的「福祉輸送事業限定」許可為主。

許可基準規定於道路運送法第6條，要旨如下。

| 區分 | 內容（要旨） |
| --- | --- |
| 輸送安全（第6條） | 事業計畫為確保輸送安全而適當 |
| 事業計畫適當（第6條） | 營業所・車庫・車輛等計畫不妨害輸送安全及公共福祉 |
| 遂行能力（第6條） | 具備自行適切且持續遂行事業之能力（資金等） |

此外，須不該當道路運送法第7條之欠格事由（如許可被撤銷後未經一定期間者）。四葉行政書士事務所於行政書士業務範圍內，協助確認要件、製作事業計畫與申請文件、代理申請。個別許可之可否由運輸支局・地方運輸局審查決定。

## 一般乘用旅客與「福祉輸送事業限定」有何不同？

同為一般乘用旅客自動車運送事業，一般法人計程車與福祉輸送事業限定，在運送對象與最低車輛數上不同。

| 事項 | 一般乘用旅客（法人計程車） | 福祉輸送事業限定（照護計程車） |
| --- | --- | --- |
| 運送對象 | 不特定之一般旅客 | 限經認定為需照護・需支援者、領有身心障礙者手冊者，及因肢體不便・內部障礙等而單獨移動或利用大眾運輸困難者等 |
| 最低車輛數 | 依營業區域訂定之最低車輛數（多數區域為5台以上） | 車輛1台即可申請 |
| 主要使用車輛 | 一般乘用車 | 福祉自動車（附輪椅・擔架用升降機或斜坡等之車）或一般車輛（轎車型等） |

福祉輸送事業限定可自1台起步，適合個人或小規模開業。惟可運送對象限於需照護者，是與一般計程車的重大差異。因運送對象不同會改變應取得的許可種類，宜在事業計畫階段整理清楚對象。

## 營業所・車庫（物件）與車輛有哪些要件？

營業所・車庫・休息小睡設施與車輛各有要件。

| 設施・車輛 | 主要要件 |
| --- | --- |
| 營業所 | 具使用權原（自有或租賃）。位於不牴觸建築基準法・都市計畫法・農地法等相關法令之場所。市街化調整區域原則不得設置 |
| 車庫 | 原則與營業所併設。無法併設時，須距營業所一定距離內（部分地區為2km，依地方運輸局而異）。可容納所有使用車輛，前面道路符合車輛限制令 |
| 休息・小睡設施 | 與營業所或車庫併設，供駕駛人休息 |
| 車輛 | 福祉自動車（附輪椅・擔架用升降機或斜坡、旋轉座椅等之車），或一般車輛（轎車型）。須具使用權原 |

若先簽物件、事後才發現因用途地域或地目不能用，就得重新尋找。宜在物件選定階段對照要件確認。營業所・車庫物件之尋找與租賃，由別事業體四葉不動產株式會社（宅地建物交易業者）承辦。

## 駕駛人的二種駕照與照護資格、勞務如何處理？

有償運送旅客之駕駛，除道路運送法外，另須道路交通法第86條之第二種駕駛執照。駕照區分規定於道路交通法第84條；為旅客運送而駕駛旅客自動車，須持有第二種駕照。

此外，若非福祉自動車而以轎車型等一般車輛進行照護運送，駕駛人須具備下列之一資格。

| 使用車輛 | 駕駛人須具備 |
| --- | --- |
| 福祉自動車（附升降機・斜坡等） | 對應使用車輛之第二種駕駛執照 |
| 一般車輛（轎車型等） | 第二種駕照，另加照護福祉士・訪問照護員（居家照服員）・居宅照護從業者・照護運送服務從事者研修結業者等之一資格 |

駕駛人之工時・社會保險・工作規則等勞務，屬社會保險勞務士領域。若雇用駕駛人開業，須另行整備勞務設計。

## 至許可為止的流程與費用・期間概估？

自申請至開始運輸之流程與費用概估如下。

| 階段 | 內容・概估 |
| --- | --- |
| 提出申請書 | 經管轄運輸支局向地方運輸局提出 |
| 所需資金 | 須依人事費・車輛費・燃料費・保險費等估算，確保自有資金 |
| 標準處理期間 | 審查約2個月（依地方運輸局而異）。無文件缺漏・補正時之概估 |
| 許可・登錄免許稅 | 許可後繳納登錄免許稅（3萬日圓） |
| 開始運輸 | 事業用自動車登錄（綠牌）、整備營運與整備管理體制、提出開始運輸之申報 |

以法人申請計程車事業時，役員須經法令考試；福祉輸送事業限定則處理方式可能不同。要件細部因地方運輸局・運輸支局而異，請於申請地之最新手引確認。即使取得許可，仍須經事業用自動車登錄（福祉限定綠牌）與開始運輸前之確認，方能實際開始運送。

## 物件・駕照・勞務該交給誰？

照護計程車橫跨許認可・不動產・車輛・勞務。分工如下。

- 許可申請之要件確認・事業計畫與文件製作・代理申請 → 四葉行政書士事務所（行政書士）
- 營業所・車庫物件之尋找、用途地域・地目・前面道路適合確認、租賃契約 → 四葉不動產株式會社（宅地建物交易業者）
- 第二種駕駛執照・照護資格之取得 → 駕駛人本人（指定教習所・研修機構）
- 駕駛人之工時・社會保險・工作規則 → 社會保險勞務士
- 法人設立・役員變更等登記 → 司法書士

四葉行政書士事務所與四葉不動產株式會社為別事業體。各領域均以與各資格者作為獨立的事業體個別簽約為前提，本事務所不收取介紹費。受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)；全貌見[許認可・各種申請服務](https://luck428.com/legal/services)。同屬運送業許可者，亦請參閱整理載貨營業所・車庫要件之[一般貨物自動車運送事業許可與營業所・車庫要件](https://luck428.com/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)。

## 常見問題

**Q. 只有1台車也能開辦照護計程車嗎？**
A. 福祉輸送事業限定之一般乘用旅客自動車運送事業，車輛1台即可申請。一般法人計程車須具依營業區域訂定之最低車輛數（多數區域5台以上），但福祉輸送事業限定放寬此要件。屬何者取決於運送對象與事業計畫。

**Q. 用轎車型的一般轎車也能做照護計程車嗎？**
A. 可能可行，但以轎車型等一般車輛進行照護運送，駕駛人除第二種駕駛執照外，還須具備照護福祉士・訪問照護員（居家照服員）等資格。若使用附輪椅・擔架設備之福祉自動車，具對應車輛之第二種駕照即可。

**Q. 可以把自宅當營業所或車庫嗎？**
A. 若具使用權原且不牴觸建築基準法・都市計畫法・農地法等，可能可行。惟市街化調整區域原則不得設置。車庫原則與營業所併設，無法併設時須距營業所一定距離內（部分地區2km，依地方運輸局而異）。建議於決定物件前對照要件確認。

**Q. 申請後多久會核准？**
A. 審查之標準處理期間約2個月（依地方運輸局而異）。此為無文件缺漏・補正時之概估，並以所需資金之確保與補正事項之解消於期間內完成為前提。個別審查期間由運輸支局・地方運輸局判斷。
