**結論（先說要點）**：為建築一定規模以上之建築物等而變更土地區劃形質之「開發行為」，原則上須經都道府縣知事等之開發許可（都市計畫法第29條第1項）。取得許可，須符合適用於所有區域之技術基準（同法第33條）；於市街化調整區域，尚須符合立地基準（同法第34條）之各號之一。工程完成後受檢查，經工程完成公告後始得建築建築物（同法第36條・第37條）。本文為一般資訊提供，整理開發許可之要件與流程，不作個別許可可否或許可基準之適用等具體法律判斷。

## 開發許可（都市計畫法第29條）於何種情形須申請？

開發許可之對象為「開發行為」。開發行為，指主要為建築建築物或建設特定工作物之目的，而變更土地區劃形質者（都市計畫法第4條第12項）。特定工作物包含混凝土廠等可能致周邊環境惡化之第一種特定工作物，及高爾夫球場、一定規模以上之運動・休閒設施等第二種特定工作物（同條第11項）。單純之建物改建，或不伴隨區劃形質變更之土地利用，非屬開發行為。

是否須許可，依土地所在區域及開發行為之規模而定。各區域之規模目安如下（都市計畫法施行令第19條）。

| 區域 | 須申請開發許可之規模目安 |
| --- | --- |
| 市街化區域 | 1,000平方公尺以上（得以條例下修至最小300平方公尺） |
| 三大都市圈既成市街地・近郊整備地帶等之一定區域 | 500平方公尺以上 |
| 未定區域區分之都市計畫區域（非線引）・準都市計畫區域 | 3,000平方公尺以上 |
| 都市計畫區域・準都市計畫區域外 | 1公頃（10,000平方公尺）以上 |
| 市街化調整區域 | 原則上不論規模均須申請 |

許可權者為都道府縣知事，惟於指定都市・中核市等，由該市之首長掌權。又，供農業・林業・漁業使用之一定建築物、車站・圖書館・變電所等公益上必要建築物之一部、以都市計畫事業・土地區劃整理事業所為之開發行為等，得作為除外事由而不須許可（都市計畫法第29條第1項各號）。屬何規模・區域・除外事由，因自治體運用而異，請於著手前向預定建築之自治體窗口確認。

## 於市街化調整區域可建何種開發（第34條）？

市街化調整區域係應抑制市街化之區域。於此取得開發許可，除技術基準（第33條）外，尚須符合立地基準（都市計畫法第34條）各號之一。主要之號如下。

| 號 | 所涵蓋開發行為之例 |
| --- | --- |
| 第1號 | 供開發區域周邊居住者日常生活所必要物品之販售・加工・修理等店舖等 |
| 第9號 | 為確保道路順暢交通而設於適當位置之休憩所・加油站等 |
| 第10號 | 於地區計畫或集落地區計畫區域內、符合計畫之開發行為 |
| 第11號 | 於以條例指定為鄰接・近接市街化區域且大致連棟50以上建築物之地域內之開發行為 |
| 第12號 | 作為無促進市街化之虞且於市街化區域內施行困難・不適當者，以條例限定區域・目的・用途所定者 |
| 第14號 | 經開發審查會之議，認無促進市街化之虞且於市街化區域內施行困難・不適當者 |

可能符合何號，因條例指定區域之範圍及審查基準而各自治體差異甚大。第11號・第12號因以條例定區域及用途，須事先於自治體之開發許可基準・審查要領確認對象地是否入該區域、預定建物之用途是否獲准。若無可能符合之號，於市街化調整區域亦有無法建築之情形。

## 開發許可之技術基準（第33條）係應符合何事？

技術基準（都市計畫法第33條）不問市街化區域・市街化調整區域，共通適用於所有開發行為。主要項目如下。

- 預定建築物等之用途，符合用途地域・地區計畫等
- 依開發區域之規模・形狀，適當配置道路・公園・廣場等公共空地
- 排水設施以能適當處理污水・雨水等之構造・能力設置
- 自來水等給水設施以無礙需求之構造・能力設置
- 已採防止崩崖・出水等災害之措施
- 已取得開發區域內公共設施管理者之同意，並與將管理新設公共設施者協議（同法第32條）
- 申請者具完成開發行為所需之資力・信用

此等為技術性・定量性之基準，道路寬度或排水計畫等於自治體審查要領有細部規定。設計與圖面之製作，通常有建築士・測量士・土木設計等專家參與。

## 自申請至許可・工程完成公告之流程與期間為何？

開發許可之一般流程如下。

| 階段 | 內容 | 根據・留意點 |
| --- | --- | --- |
| ① 事前相談・事前協議 | 於自治體窗口確認區域區分・規模・立地基準之該當性 | 依自治體運用 |
| ② 公共設施管理者之同意・協議 | 道路・水路等管理者之同意；與新設公共設施管理者協議 | 都市計畫法第32條 |
| ③ 申請 | 附設計圖書及相當數關係權利人之同意等申請 | 都市計畫法第30條 |
| ④ 審查・處分 | 審查技術基準與（調整區域者）立地基準；許可或不許可 | 都市計畫法第35條（遲滯無延處分・通知） |
| ⑤ 工程 | 依許可內容施行造成等工程 | 變更須變更許可等 |
| ⑥ 工程完成屆・檢查 | 屆報工程完成，經檢查交付檢查濟證 | 都市計畫法第36條第1項・第2項 |
| ⑦ 工程完成公告 | 由知事等公告工程完成 | 都市計畫法第36條第3項 |
| ⑧ 建築 | 公告後得建築預定建築物 | 都市計畫法第37條（公告前原則不得建築） |

審查所需之標準期間由各自治體訂定，含事前協議可能達數月，惟此處不示一律日數（請以對象地自治體之標準處理期間確認）。於工程完成公告前，原則上不得建築・改築建築物（都市計畫法第37條）。又，工程完成公告後，建築獲許可之預定建築物等以外之建築物受限制（同法第42條）。

## 登記・測量・稅務・爭訟應委由何人？

開發許可之申請書・附件圖書中，對行政機關之許認可申請書類之製作・提出代理，得於行政書士業務範圍內支援。另方面，伴隨開發之各手續，有由行政書士以外之資格者擔當者。

- 將農地變更為宅地等時之農地轉用許可・屆報，係與開發許可有別之手續（見[農地轉用（農地法第4條・第5條）許可之流程](https://luck428.com/legal/column/nochi-tenyo-4jo-5jo-kyoka-nagare)）。
- 土地之測量・分筆・地目變更等表示相關登記，屬土地家屋調查士業務。
- 所有權移轉、抵押權設定等權利相關登記，屬司法書士業務（涉及相續者，另見[相續登記之流程](https://luck428.com/legal/column/souzoku-touki-nagare)）。
- 事業計畫之收支・稅務判斷，屬稅理士業務。
- 對開發許可之不許可等所為之審查請求・撤銷訴訟等爭訟代理，屬律師業務。

四葉行政書士事務所與四葉不動産株式会社為別事業體。開發許可之申請書類製作由行政書士，測量・分筆・地目變更由土地家屋調查士，權利相關登記由司法書士，事業計畫之稅務由稅理士，都市計畫相關之不服申立・爭訟由律師，各以獨立的事業體個別簽約處理。本事務所不收取介紹費。物件之買賣・活用相談請洽[不動產之相續・賣出窗口](https://luck428.com/souzoku)。受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)；取扱業務見[取扱業務](https://luck428.com/legal/services)。

## 常見問題

**Q. 於市街化調整區域是否無法建築建物？**
A. 雖係應抑制市街化之區域，惟並非完全不得建築。除技術基準（都市計畫法第33條）外，若符合立地基準（同法第34條）之一，得經開發許可而建築。惟是否有可能符合之號，依對象地・預定用途及自治體之條例・審查基準，個別可否請洽自治體窗口與資格者確認。

**Q. 改建是否不須開發許可？**
A. 不伴隨區劃形質變更之單純改建，本即非屬開發行為（都市計畫法第4條第12項），多屬不須開發許可。惟依是否伴隨造成或區劃變更、是否位於市街化調整區域內等而異。判斷自是否構成開發行為起始，請洽自治體確認。

**Q. 開發許可之申請書類可否委由行政書士？**
A. 對行政機關之許認可申請書類之製作・提出代理，得於行政書士業務範圍內支援。惟設計圖書由建築士等，測量・分筆・地目變更由土地家屋調查士，權利登記由司法書士擔當，各以獨立的事業體個別簽約。

**Q. 工程完成後是否即可建築建物？**
A. 否。工程完成屆報後受檢查，經檢查濟證之交付後為工程完成公告（都市計畫法第36條）。預定建築物之建築，原則上於此工程完成公告後為之（同法第37條）。公告前之建築原則上不獲准。
