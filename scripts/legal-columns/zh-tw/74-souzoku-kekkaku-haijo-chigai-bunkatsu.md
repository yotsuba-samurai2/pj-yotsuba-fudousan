**先講重點：** 繼承欠格與廢除，都是使特定人喪失繼承權的制度，但機制不同。繼承欠格是為一定重大行為的相續人，不經手續而依法律當然喪失繼承權的制度（民法第891條）。廢除是具有特留分的推定繼承人有虐待、重大侮辱、顯著不當行為時，經被繼承人請求由家庭裁判所審判、使其喪失繼承權的制度（民法第892條至第895條）。兩者皆為代襲繼承的原因（民法第887條第2項）。本文為一般性資訊提供，具體個案屬於何者、廢除能否獲准，須經向具資格者諮詢及家庭裁判所的判斷。

## 繼承欠格與廢除有何不同？

兩者「將某人排除於繼承之外」的效果相同，但排除的理由與手續根本不同。繼承欠格依法律當然發生，無須手續。廢除基於被繼承人的意思，由家庭裁判所的審判發生。整理如下。

| | 繼承欠格 | 廢除 |
| --- | --- | --- |
| 依據 | 民法第891條 | 民法第892條至第895條 |
| 對象 | 所有繼承人 | 具有特留分的推定繼承人 |
| 事由 | 法定欠格事由（重大不當行為、干涉遺言等） | 虐待、重大侮辱、其他顯著不當行為 |
| 效果發生 | 依法律當然（無須手續） | 家庭裁判所審判確定 |
| 被繼承人的意思 | 無關而發生 | 須被繼承人請求 |
| 取消、撤回 | 不可 | 可（民法第894條） |
| 能否受遺贈 | 不可（民法第965條準用第891條） | 可（廢除未被準用） |
| 是否記入戶籍 | 不記入 | 審判確定後申報並記入 |
| 代襲繼承 | 發生（民法第887條第2項） | 發生（民法第887條第2項） |

對象為具有特留分的推定繼承人一點亦屬重要。兄弟姊妹本無特留分，故不在廢除對象之列；被繼承人以遺言定「不使兄弟姊妹繼承」即足，故無廢除的必要。

## 成為繼承欠格是因為做了什麼行為？

民法第891條規定，凡屬下列五者之一者不得為繼承人（喪失繼承權）。

1. 故意致被繼承人或先順位、同順位繼承人於死，或欲致其於死，因而受刑之處罰者
2. 明知被繼承人被殺害，卻不告發、不告訴者（欠缺是非辨別能力時，或殺害者為自己的配偶、直系血親時除外）
3. 以詐欺或脅迫，妨礙被繼承人為關於繼承的遺言、撤回、取消或變更者
4. 以詐欺或脅迫，使被繼承人為關於繼承的遺言、撤回、取消或變更者
5. 就關於繼承的被繼承人遺言書，予以偽造、變造、破棄或隱匿者

重點在於，欠格不經手續而依法律當然發生。既不需家庭裁判所的審判，也不需被繼承人的意思表示。繼承開始後，某繼承人是否屬於欠格，會在遺產分割或登記的場面成為問題，若有爭執，最終以訴訟確定。又，欠格者不僅不能繼承，亦不能受遺贈。因民法第965條就受遺者準用民法第891條，而此對廢除並未準用。何種行為屬於欠格事由（尤其第5款隱匿、破棄遺言書的故意與目的）的評價屬個別判斷，具紛爭性時的主張與舉證屬律師的領域。

## 廢除向何處聲請？可以用遺言為之嗎？

廢除向家庭裁判所聲請。方式有二。其一，被繼承人於生前自行向家庭裁判所聲請（民法第892條）。於具有特留分的推定繼承人對被繼承人為虐待、或加以重大侮辱，或有其他顯著不當行為時，得為聲請。其二，以遺言廢除（民法第893條）。被繼承人以遺言表示廢除的意思時，遺言執行者於遺言生效後，遲滯地向家庭裁判所聲請廢除。此時，廢除的效力溯及被繼承人死亡之時發生。若考慮以遺言廢除，遺言執行者的指定為關鍵，故遺言書的類型請一併確認[自筆證書遺言與公正證書遺言](https://luck428.com/legal/column/jihitsu-kosei-yuigon)。

廢除可隨時取消（民法第894條）。取消亦可以生前聲請或遺言為之。又，廢除或其取消的聲請後、審判確定前繼承開始時，家庭裁判所得依親族、利害關係人或檢察官的聲請，命就遺產的管理為必要的處分（民法第895條）。在手續面，推定繼承人廢除的審判事件屬家事事件手續法別表第一之86項，廢除審判的取消屬同表之87項所定的審判事件，作為不適於調停的審判事項處理（家事事件手續法）。

| 手續 | 得聲請之人 | 依據 |
| --- | --- | --- |
| 生前的廢除 | 被繼承人 | 民法第892條 |
| 以遺言廢除 | 遺言執行者（基於遺言） | 民法第893條 |
| 廢除的取消 | 被繼承人（生前、遺言） | 民法第894條 |
| 審判確定前的遺產管理 | 親族、利害關係人、檢察官 | 民法第895條 |

## 有欠格、廢除時，法定應繼分與代襲繼承如何變化？

因欠格、廢除而喪失繼承權者，視為自始非繼承人，該部分反映於其他繼承人的法定應繼分。此處重要的是代襲繼承。被繼承人的子於繼承開始前死亡，或屬於繼承欠格、或因廢除而喪失繼承權時，該人之子（孫）代襲而為繼承人（民法第887條第2項）。亦即，即使親因欠格、廢除而被排除，其子仍能以代襲繼承人身分繼承。此為使被排除的本人不因而得利、同時保障其直系卑親屬權利的機制。

易與繼承拋棄混淆。拋棄繼承者視為自始非繼承人，但拋棄並非代襲繼承的原因。故拋棄者之子不代襲。請掌握此差異：欠格、廢除發生代襲，拋棄則不發生。法定應繼分本身的思路，整理於[法定應繼分與代襲繼承的基礎](https://luck428.com/legal/column/houtei-souzoku-bun)。最終應繼分的確定與分割方式，由全體繼承人的遺產分割協議決定。

## 協議書、家裁聲請、登記應委託給誰？

涉及欠格、廢除的繼承，分工依階段而異。

- 為確定繼承人與應繼分的戶籍收集、繼承關係說明圖，以及達成合意時遺產分割協議書的製作支援 → 四葉行政書士事務所（行政書士）
- 廢除、其取消向家庭裁判所的聲請，與對方的交涉、代理，欠格有無的紛爭，涉及權利義務的個別法律判斷 → 律師
- 繼承財產有不動產時的繼承登記 → 司法書士
- 繼承稅的申報、計算 → 稅理士
- 繼承的不動產之出售、活用諮詢 → 四葉不動產株式會社

## 常見問題

**Q. 繼承欠格與廢除，哪一個是較重的制度？**
A. 並非輕重之別，而是機制不同。繼承欠格是為一定重大行為的繼承人不經手續而依法律當然喪失繼承權的制度（民法第891條）。廢除是具有特留分的推定繼承人有虐待、重大侮辱、顯著不當行為時，經被繼承人請求由家庭裁判所審判使其喪失繼承權的制度（民法第892條）。欠格因行為的重大性當然發生，廢除則需被繼承人的意思與家庭裁判所的判斷，此為不同之處。

**Q. 可以用遺言廢除繼承人嗎？**
A. 可以。被繼承人以遺言表示廢除的意思時，遺言執行者於遺言生效後，遲滯地向家庭裁判所聲請廢除（民法第893條）。效力溯及被繼承人死亡之時發生。因指定遺言執行者為關鍵，宜自遺言製作階段即行考量。廢除可隨時取消（民法第894條）。

**Q. 親因欠格、廢除而不能繼承，其子也不能繼承嗎？**
A. 其子能以代襲繼承人身分繼承。被繼承人的子屬於繼承欠格，或因廢除而喪失繼承權時，該人之子代襲而為繼承人（民法第887條第2項）。被排除者僅為為行為的本人，其直系卑親屬的繼承權以代襲受保障。又，繼承拋棄非代襲繼承的原因，故拋棄者之子不代襲。

**Q. 被廢除的人也不能受遺贈嗎？**
A. 廢除是使人喪失繼承權的制度，並不妨礙遺贈。民法第965條就受遺者準用民法第891條（欠格），但未準用廢除，故被廢除的人受遺贈並不受妨礙。另一方面，屬於欠格者則繼承與遺贈皆不能受。個案如何處理，請向具資格者諮詢。
