**先講結論：** 若您不擁有自己的卡車，而是安排其他業者的運送來承攬貨物（利用運送），需要辦理日本《貨物利用運送事業法》上的手續。以卡車進行的利用運送，以及不含集配的海運、空運、鐵路利用運送，辦理向國土交通大臣的「第一種貨物利用運送事業」登錄（第3條第1項）即可。相對地，若將海運、空運、鐵路運送與其前後的集配（卡車收貨、送貨）一貫承攬，則需「第二種貨物利用運送事業」許可（第20條）。本文為一般性資訊，整理第一種與第二種的分界、財產基礎（淨資產300萬日圓以上），以及與一般貨物運送的差異。個別登錄、許可能否核准，取決於運輸局的審查。

## 第一種登錄與第二種許可有何不同？

貨物利用運送事業，是指自己不擁有運送工具（船舶、飛機、鐵路車輛、卡車），而是利用實際運送業者（實運送業者）的運送，對貨主承攬運送的事業。《貨物利用運送事業法》（平成元年法律第82號）將其分為「第一種」與「第二種」。

| 類別 | 手續 | 對象事業（要旨） |
| --- | --- | --- |
| 第一種 | 國土交通大臣的**登錄**（第3條第1項） | 第二種以外的利用運送。卡車利用運送，以及不含集配的海運、空運、鐵路利用運送 |
| 第二種 | 國土交通大臣的**許可**（第20條） | 利用海運、空運、鐵路業者的運送，並將其前後的集配（卡車收送）一貫承攬 |

分界在於「是否連同集配，將海運、空運、鐵路運送一貫承攬」（第2條第7項、第8項的定義）。僅安排港到港的貨櫃運送屬第一種；自貨主倉庫收貨、以船運送、於到達地以卡車配送一貫承攬則屬第二種。本所在行政書士業務範圍內，協助確認屬何種類、製作與提出申請文件。個別能否核准取決於運輸局的審查。

## 第一種登錄需要的財產基礎與營業所要件為何？

第一種登錄，以不落入第6條的登錄拒絕事由為條件。實務上最常出問題的是財產基礎（同條第7款）與設施（同條第6款）。

| 事項 | 內容（要旨） |
| --- | --- |
| 財產基礎 | 依施行規則第8條，以**淨資產300萬日圓以上**為基準。剛成立、尚未結算的法人，資本金300萬日圓以上即視為符合 |
| 營業所 | 須有使用權原，且符合《都市計畫法》《建築基準法》等相關法令 |
| 保管設施 | 若進行保管，須確保適合保管貨物的設施；不進行保管則不需要 |
| 消極資格 | 不得落入第6條第1項各款 |

登錄後，須繳納登錄免許稅（《登錄免許稅法》別表第一；金額請於撰寫時點確認）。營業所與保管設施須先確認用途地區與使用權原，建議在簽約前先對照要件。物件面的要件，另請參考屬別事業體的四葉不動產所整理的[運送業營業所、車庫的物件要件](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

## 第二種許可要做國際運送或集配需要什麼？

第二種許可（第20條）適用於將海運、空運、鐵路運送與卡車集配一貫組合的事業。許多國際海運、國際空運的承攬業者（forwarder）會取得此許可。

| 事項 | 內容（要旨） |
| --- | --- |
| 財產基礎 | 與第一種相同，以**淨資產300萬日圓以上**為基準 |
| 集配體制 | 就集配區域，以及承擔集配的運送（自行的貨物汽車運送，或委託其他運送業者），規劃出可確保運送安全的體制 |
| 營業所、保管設施 | 確保遂行事業所需的設施 |
| 許可、登錄免許稅 | 許可後繳納登錄免許稅（別表第一；金額請於撰寫時點確認） |

國際運送另有利用外國實運送業者時的處理、國際約款的申報等，與純國內案件不同的論點。第二種與第一種的差別在於「一貫承攬集配」，若以自家卡車進行集配，還須一併設計是否需要一般貨物汽車運送事業許可。

## 一般貨物（綠牌）與利用運送如何區分使用？

依「以自家卡車運送」或「安排其他業者運送」，所需手續根本不同。

| 事業形態 | 所需手續 | 依據 |
| --- | --- | --- |
| 以自家卡車（綠牌）有償運送 | 一般貨物汽車運送事業的**許可** | 《貨物汽車運送事業法》第3條 |
| 以輕型卡車（黑牌）有償運送 | 貨物輕汽車運送事業的**申報** | 《貨物汽車運送事業法》 |
| 不擁有車輛而安排其他業者運送（卡車、國內） | 第一種貨物利用運送事業的**登錄** | 《貨物利用運送事業法》第3條第1項 |
| 將海運、空運、鐵路加集配一貫承攬 | 第二種貨物利用運送事業的**許可** | 《貨物利用運送事業法》第20條 |

以自家車輛運送的一般貨物要件（營業所、車庫、最低車輛數等），請見[一般貨物汽車運送事業的許可｜營業所、車庫要件](https://luck428.com/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)；輕貨物（黑牌）的申報請見[貨物輕汽車運送事業的申報](https://luck428.com/legal/column/keikamotsu-kei-jidosha-unso-todokede)。是否僅需利用運送，抑或還需運送業許可，取決於是否自行運送貨物。

## 從申請到開業的流程為何？

第一種（登錄）與第二種（許可）流程相似，但審查輕重不同。

| 階段 | 內容、基準 |
| --- | --- |
| 事前確認 | 確認屬第一種或第二種、是否符合財產基礎（淨資產300萬日圓以上）、能否確保營業所與保管設施 |
| 提出申請 | 向管轄的地方運輸局提出（涉及外國船舶等的部分於本省辦理） |
| 標準處理期間 | 由運輸局公告。基準上第一種約2～3個月、第二種約3～4個月（無文件缺漏時；請向受理機關確認最新資訊） |
| 登錄、許可 | 繳納登錄免許稅 |
| 開業 | 完成運費、費用的設定與申報等開業手續後開始營運 |

## 常見問題

**Q. 一輛卡車都沒有也能開業嗎？**
A. 可以。貨物利用運送事業是不擁有運送工具、利用實運送業者的運送對貨主承攬運送的事業。不含集配的卡車利用運送，可辦第一種登錄（《貨物利用運送事業法》第3條第1項）開業。若以自家車輛運送，另需一般貨物汽車運送事業等許可。

**Q. 該選第一種還是第二種？**
A. 若連同集配（收貨、送貨）將海運、空運、鐵路運送一貫承攬，以第二種許可為基本；否則為第一種登錄。僅以卡車在國內安排的利用運送屬第一種。因取決於事業形態，建議對照事業計畫確認。

**Q. 需要多少資本金？**
A. 第一種、第二種皆以財產基礎淨資產300萬日圓以上為基準（施行規則第8條）。尚未結算的公司，以資本金300萬日圓以上視為符合。淨資產的計算方式與附件請向受理機關確認。

**Q. 想從事國際承攬（forwarder）該怎麼辦？**
A. 若將國際海運、空運與集配（卡車收送）一貫組合，典型上需第二種許可；若僅安排港到港、機場到機場而不含集配，可能屬第一種。因有國際約款申報等與純國內不同的論點，需個別確認。
