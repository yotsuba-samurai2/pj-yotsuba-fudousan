**結論（先講重點）：**應他人請求並收取報酬、以建築物的設計或工程監理為業者，原則上須依《建築士法》第23條，就建築士事務所向都道府縣知事辦理登記。這與承攬建設工程所需的建設業許可（建設業法）是不同制度。登記有效期間自登記之日起算5年，期滿後欲繼續者須辦理更新登記（同條第2項、第3項）。各建築士事務所須配置專任的管理建築士（第24條第1項）；可擔任管理建築士者，須為以建築士身分從事設計或國土交通省令所定其他業務3年以上後、修畢登錄講習機關舉辦的管理建築士講習者（同條第2項）。事務所所屬建築士另須受定期講習（第22條之2）。本文為一般性資訊，不就個別事務所是否符合登記或管理建築士要件作出判斷或保證。登記、變更申報文件的製作與提出支援，由四葉集團的行政書士以獨立的事業體承辦；設計、工程監理、建築確認申請的業務本身屬建築士的獨占業務；事務所物件的租賃與重要事項說明由屬不同事業體的不動產業者負責；公司設立、董監事變更的登記由司法書士辦理；社會保險與勞務由社會保險勞務士負責；稅務由稅理士負責。各自分別簽約。

## 建築士事務所的「登記」與建設業許可有何不同？

出發點在於「以什麼為業」。《建築士法》第23條第1項規定，一級建築士、二級建築士或木造建築士，或僱用此等人員者，欲應他人請求並收取報酬、以設計或工程監理等為業時，須定明建築士事務所並取得都道府縣知事的登記。亦即，這是著眼於「反覆持續、收取報酬從事設計與監理」的登記。另一方面，建設業許可（建設業法第3條）則著眼於「承攬建設工程」，屬不同制度，於承攬單件請負金額達一定金額（建築一式工程為1,500萬日圓，其他工程為500萬日圓，均含稅）以上的工程時才需要。

| 項目 | 建築士事務所登記 | 建設業許可 |
| --- | --- | --- |
| 依據法律 | 建築士法第23條 | 建設業法第3條 |
| 著眼點 | 收取報酬、以設計與工程監理等為業 | 以承攬建設工程為業 |
| 需要的場合 | 應他人請求、收取報酬反覆持續從事設計等時 | 承攬單件請負金額達一定金額（建築一式1,500萬／其他500萬・均含稅）以上的工程時 |
| 登記、許可對象 | 都道府縣知事 | 國土交通大臣或都道府縣知事 |
| 有效期間 | 5年（須辦更新登記） | 5年（須更新） |

僅開設設計事務所並不需要建設業許可，但若自行承攬工程，則兩者可能同時相關。建設業許可本身的要件論點不同，另請參閱[建設業許可的要件（經營業務管理責任者、專任技術者、財產基礎）](https://luck428.com/legal/column/kensetsugyo-kyoka-yoken-keikan-sengi-zaisan)。若涉及電氣工程，[電氣工程業的登記、擬制登記與通知](https://luck428.com/legal/column/denki-koji-gyo-touroku-eigyosho-shunin)又是另一套手續。究屬哪一制度須依事業內容而定，故在計畫早期即向主管的都道府縣（指定事務所登記機關）確認，不可或缺。

## 管理建築士需要哪些要件（專任、修畢講習）？

《建築士法》第24條第1項要求建築士事務所的開設者，就各一級、二級、木造建築士事務所，配置管理該事務所的專任一級、二級或木造建築士（管理建築士）。管理建築士是登記的前提，欠缺者即無法取得登記（第23條之4的登記拒否事由）。

可擔任管理建築士者的要件規定於第24條第2項：須為以建築士身分從事設計或國土交通省令所定其他業務3年以上後，修畢登錄講習機關舉辦的管理建築士講習課程的建築士。

| 項目 | 內容（依據） |
| --- | --- |
| 配置義務 | 各事務所須配置專任的管理建築士（第24條第1項） |
| 資格 | 以建築士身分從事設計或省令所定其他業務3年以上（第24條第2項） |
| 講習 | 於上述之後修畢登錄講習機關的管理建築士講習（第24條第2項） |
| 專任的意涵 | 常駐於該事務所並專責其管理；原則上不允許兼任他事務所或非常勤 |

須留意的是，管理建築士講習是「成為管理建築士的講習」，與後述的定期講習（第22條之2）為不同事物。實務年數與業務內容是否符合要件，屬《建築士法》上的判斷，行政書士不得以獨占業務代為判定。僅出借名義而未實際常駐的「借牌」管理建築士，將成為登記拒否或登記撤銷的對象。

## 登記的有效期間、更新、變更申報，何時提出什麼？

登記的有效期間自登記之日起算為5年（建築士法第23條第2項）。有效期間屆滿後仍欲繼續經營建築士事務所者，須辦理更新登記（同條第3項）。若疏忽更新致有效期間屆滿，登記即失效，不得在無登記狀態下繼續從事設計等業務。

| 手續 | 內容（依據・運用） |
| --- | --- |
| 登記有效期間 | 5年（第23條第2項） |
| 更新登記 | 期滿後欲繼續者須辦理（第23條第3項）；多數都道府縣要求於屆滿約30日前申請 |
| 登記事項變更申報 | 名稱、所在地、管理建築士、所屬建築士等有變更時 |
| 廢業等申報 | 廢止或停業建築士事務所時 |

登記的申請手續規定於第23條之2（申請書記載事項）、第23條之3（登記的實施）。更新的申請時期與變更申報的期限、樣式，因都道府縣（指定事務所登記機關）而運用各異，故管理屆滿日、一旦發生變更即迅速申報，是實務的要點。「在別縣是這種格式」未必能直接適用，也是申請實務常見的問題。

## 事務所的實態（專用性、設備）要求到什麼程度？

登記並非「備齊文件即足」，而以具備事務所的實態為前提。尤其會審視專任的管理建築士是否實際常駐並管理該事務所。未配置管理建築士，或僅具名義而欠缺實態，構成違反《建築士法》第24條第1項，成為登記拒否（第23條之4）或登記撤銷（第26條）的理由。實務上亦有都道府縣以未配置管理建築士為由撤銷登記的處分案例。

| 受審視之點 | 具體例 |
| --- | --- |
| 管理建築士的常駐、專任 | 常駐於該事務所、未兼任他事務所 |
| 事務所的實態 | 從事業務的獨立空間；設計圖書的保存與業務記錄 |
| 非借牌 | 管理建築士與所屬建築士確實存在並實際參與業務 |

關於設備與圖書保存的具體運用（應備文件、保存年限、報告書提出等），由《建築士法》、國土交通省令與各都道府縣手冊所定，品項與樣式的細部由主管窗口判斷。開業前先向管轄的都道府縣（指定事務所登記機關）事前諮詢，較易避免提出前夕的退件。

## 登記（行政書士）與設計監理（建築士）、登記（司法書士）如何劃分？

由於相關專業人員分屬不同領域，原則上請與各方以獨立的事業體分別簽約。四葉集團的行政書士，以獨立的事業體承辦建築士事務所登記、更新、變更申報的申請文件製作輔助，以及向主管都道府縣（指定事務所登記機關）事前諮詢的引導。

| 委託對象 | 主要角色 |
| --- | --- |
| 行政書士（本事務所） | 建築士事務所登記、更新、變更申報的申請支援；建設業許可申請支援（別論點） |
| 建築士 | 設計、工程監理、建築確認申請等建築士獨占業務本身 |
| 司法書士 | 公司設立、董監事變更等商業登記 |
| 不動產業者（屬不同事業體的本公司） | 事務所物件的選定、租賃仲介、重要事項說明 |
| 社會保險勞務士 | 員工的社會保險與勞務手續 |
| 稅理士 | 開業後稅務 |

亦請參閱本事務所的[承辦業務](https://luck428.com/legal/services)、[受任流程](https://luck428.com/legal/nagare)與[報酬額表](https://luck428.com/legal/ryokin)。與各專業人員均以獨立的事業體簽約，彼此不收取介紹費。登記終究只是以設計與監理為業的入口，設計與監理內容本身的判斷由建築士為之。

## 常見問題

**Q. 即使我獨自在家做設計，也需要建築士事務所登記嗎？**
A. 若應他人請求、收取報酬、以設計與工程監理等為業（反覆持續）者，不論規模均須辦理建築士事務所登記（建築士法第23條）。即使僅一人，該人也須符合專任管理建築士的要件（以建築士身分具3年以上實務＋修畢管理建築士講習）。是否具備事務所的實態亦會受審視。

**Q. 只要持有建設業許可，就不需要建築士事務所登記嗎？**
A. 兩者為不同制度，即使持有建設業許可，若以設計與監理為業，仍須另行辦理建築士事務所登記。建設業許可是承攬建設工程（如建築一式1,500萬、其他500萬，均含稅以上等）所需，並不涵蓋以設計與監理為業。應依所從事業務的內容判斷。

**Q. 管理建築士的定期講習與管理建築士講習是同一件事嗎？**
A. 是不同的。管理建築士講習是為成為管理建築士、於實務之後修畢的講習（第24條第2項）。定期講習則是所屬建築士事務所的一級、二級、木造建築士持續受講的講習；依建築士法第22條之2，須每隔國土交通省令所定期間（法律上為3年以上5年以內的範圍，施行規則定為每3年度）受講。

**Q. 忘記更新、有效期間屆滿會怎樣？**
A. 登記有效期間為5年，欲繼續者須辦理更新登記（建築士法第23條第2項、第3項）。若疏忽更新，登記即失效，不得在無登記狀態下繼續從事設計等業務。多數都道府縣要求於屆滿約30日前申請。管理屆滿日並預留時間辦理，至為重要。
