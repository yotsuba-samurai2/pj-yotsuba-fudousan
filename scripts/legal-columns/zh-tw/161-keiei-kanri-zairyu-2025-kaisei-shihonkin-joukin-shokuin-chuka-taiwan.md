**結論（先講重點）：**原依修正前基準持「經營・管理」在留者，即使在至2028年10月16日的過渡期間，也非自動獲准更新。應將目前的經營實績證據與未來達成新基準的計畫分開準備。

本文限於既有在留經營者，如何將2025年10月修法的因應反映於更新資料。公司設立及新申請請見[經營・管理取得總說](/zh-tw/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)；一般更新的經營實態與繼續性請見[更新立證解說](/zh-tw/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)。本文不判斷或保證個別許否、過渡措施適用。

## 既有在留者至2028年10月16日的過渡措施，代表什麼？

對已以「經營・管理」在留者，設有過渡措施。依出入國在留管理廳的指引，自施行日令和7年10月16日起滿3年之日，即至令和10年（2028年）10月16日止，即使尚未達修法後新基準，也須依經營狀況及達成新基準的預期等判斷在留期間更新的許否。此為使修法影響不致驟然到來的緩衝措施。

惟「至2028年前無須作為」的理解並不正確。過渡措施不保證更新，亦須審查達成新基準的預期。此外，從來更新所確認之點——有經營的實體、已履行公租公課（法人稅・消費稅・住民稅等）與社會保險、已確保獨立事業所——仍與過渡措施無關而受審視。更新時事業繼續性的思路，於前揭[經營・管理簽證更新所問的「事業繼續性・實體」之立證](/zh-tw/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)詳述。

| 區分 | 過渡期間中（至令和10年10月16日）的處理 |
| --- | --- |
| 新規申請（認定・變更） | 原則適用新基準；須確認施行前受理及創業簽證例外 |
| 在留者的更新（新基準的形式要件） | 依經營狀況及達成新基準的預期等判斷許否 |
| 經營實體・公租公課・社會保險・事業所 | 與過渡措施無關，仍依從來確認 |

## 過渡期間的更新，如何區分目前實績與新基準達成計畫？

先核對在留期限、上次申請副本及所屬機關類別，再對照入管的更新文件清單。下表是整理範例，不是所有案件一律必備的清單。上次申請後的變更，應對應日期、理由及證據。

| 核對項目 | 目前證據範例 | 新基準的準備事項 |
| --- | --- | --- |
| 經營狀況 | 最近年度決算文件、目前在留期間的經營管理活動說明 | 核對上次申請後變更與計畫數字 |
| 資本金等 | 登記事項證明書、繳資及出資紀錄 | 資金缺口、來源、時程與進度；未完成增資不得寫成已完成 |
| 常勤職員與日語能力 | 僱用及出勤紀錄、在留資格等證據、日語能力證明 | 分別核對僱用與語言要件，區分預定招聘與已僱用 |
| 稅務、保險、許可 | 納稅、保險加入與繳納、事業許可的證據 | 如實整理欠缺資料、未履行事項及處理情形 |
| 學位、經驗、計畫 | 相關學位或經歷證據、事業計畫及專家確認資料 | 區分適用基準、仍在準備的事項與時間 |

提交時程表不等於會獲准。應確認說明與決算、登記、僱用、納稅資料一致；各類別省略或追加資料依入管最新指引處理。

## 準備更新時，如何與新申請基準區分？

新申請原則依修正後基準審查。不可把既有在留者的更新過渡措施，誤作新申請的資金或人員緩期。以下比較只供更新計畫核對差距，不另作新申請總說。

| 項目 | 修法前的目安 | 修法後（令和7年10月16日施行） |
| --- | --- | --- |
| 資本金・出資總額 | 500萬日圓以上（或常勤職員2人以上） | 3,000萬日圓以上 |
| 常勤職員 | 作為替代要件有2人以上的選項 | 要件化僱用1人以上 |
| 日語能力 | 無明文基準 | 申請者或常勤職員任一方達「日本語教育の参照枠」的B2相當以上 |
| 經營經驗・學位 | 從事管理業務時原已有3年以上經驗等要件 | 3年以上經營經驗或經營管理或事業相關領域的博士、碩士或專業職學位 |
| 事業計畫書 | 提出 | 經具日本資格的中小企業診斷士・公認會計師・稅理士確認 |

3,000萬日圓不是年營業額基準。法人指株式會社的已繳資本金或持分公司的出資總額，不能直接把營運費用加到資本金計算。個人事業則指確保事業所、職員1年薪資及設備投資等所投入的總額。資金與至少1名符合範圍的常勤職員兩項要件均須滿足。

僱用要件的常勤職員，須為經營或管理者以外、居住於日本的日本人、特別永住者，或持別表第二在留資格（永住者、日本人の配偶者等、永住者の配偶者等、定住者）者。僅僱用別表第一就業等在留資格者，不能滿足至少1人的僱用要件。常勤性及僱用實態須個別確認，社會保險與僱用保險手續由社會保險勞務士承辦。

日語能力要件所指的常勤職員，與僱用人數要件不同，也包含持別表第一在留資格者。申請者本人或常勤職員任一方符合即可，並非要求所有人均達B2。

確認者須持有日本的中小企業診斷士、公認會計師或稅理士資格，確認計畫的具體性、合理性與可實現性。申請公司的董事或職員不得擔任評價者，但外部顧問公認會計師或稅理士可以。

## 更新文件、登記、稅務與勞務應分別委託誰？

由於相關專業人員分屬不同領域，原則上請與各方以獨立的事業體分別簽約。四葉集團的行政書士，以獨立的事業體承辦在留資格的申請文件製作輔助與申請取次。亦請參閱本事務所的[承辦業務](/zh-tw/legal/services)、[受任流程](/zh-tw/legal/nagare)與[報酬額表](/zh-tw/legal/ryokin)。與各專業人員均以獨立的事業體簽約，彼此不收取介紹費。

| 委託對象 | 主要角色 |
| --- | --- |
| 行政書士（本事務所） | 在留資格（認定・變更・更新）的申請文件製作・申請取次（文件製作依行政書士法第1條之3；申請取次依入管申請等取次制度） |
| 司法書士 | 公司設立・董監事變更・本店遷移等商業登記 |
| 稅理士 | 資本金確認的前提稅務、法人稅・消費稅・決算的申報 |
| 社會保險勞務士 | 常勤職員的健康保險・厚生年金・僱用保險・勞災的適用手續 |
| 不動產業者（屬不同事業體的本公司） | 作為獨立事業所的物件選定・租賃仲介・重要事項說明 |
| 具日本資格的中小企業診斷士・公認會計師・稅理士 | 事業計畫書的專家確認 |

找房時如何出示在留資格、保證公司扮演什麼角色，可參閱獨立經營的四葉不動産株式会社所整理的[外國人在日本找房指南](/zh-tw/global)。房屋仲介與在留手續分別簽約。

## 常見問題

**Q. 可以等到2028年10月才準備資料嗎？**
A. 不可以如此理解。過渡措施不保證更新，也不免除申請。每次更新仍應能說明目前經營狀況與達成新基準的預期。

**Q. 尚未增資或招聘應如何說明？**
A. 將已完成事項與計畫分開，附上時程、資金來源及進度依據；不可把未來計畫寫成已滿足的要件。

**Q. 過渡期間仍須注意納稅及保險嗎？**
A. 過渡措施不免除公法義務。稅務、保險、勞動法令及必要許可仍屬核對事項，具體資料須依類別與最新指引確認。

**Q. 交齊表中資料就能獲准更新嗎？**
A. 不能保證。表中僅為整理例，必備與追加文件依申請及機關類別而異，許否由入管審查判斷。
