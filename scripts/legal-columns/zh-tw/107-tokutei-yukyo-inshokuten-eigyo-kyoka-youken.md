**先講重點：** 深夜讓客人遊興並提供酒類的店家，在不屬其他風俗營業的情況下，須取得特定遊興飲食店營業許可。簽租約前應確認營業區域、時間，以及每間客室33㎡以上等構造設備基準。

**最後更新：2026-10-10**

本文為規劃俱樂部、現場演奏或舞蹈飲食店的人，整理營業區分與物件確認事項。個別適用、設施符合性須與具資格者及所轄警察署確認，許可由都道府縣公安委員會判斷。

## 哪些營業屬於特定遊興飲食店營業？

風俗營業等之規制及業務適正化等相關法律（風營法）第2條第11項，針對設設備讓客人遊興、提供飲食與酒類，並於深夜仍以此方式營業的店家。已屬其他風俗營業者除外。依第31條之22，各營業所須分別取得許可。

| 要素 | 應確認的實際營業 |
|---|---|
| 深夜 | 凌晨0時至6時是否同時有遊興與酒類提供 |
| 遊興 | 店方是否積極引導客人遊玩、享樂 |
| 飲食、酒類 | 是否讓客人飲食並提供酒類 |
| 其他風俗營業 | 是否因接待、低照度等屬於其他類型 |

白天才讓客人遊興，深夜停止遊興而只供酒，不能僅以「深夜也營業」認定為特定遊興。應分別確認遊興、供酒的時段。

警察廳2025年解釋運用基準說明「遊興」的概念，例子包括對不特定客人演出或現場演奏、讓客人跳舞、勸客人唱卡拉OK、遊戲等。單純設置設備由客人自行使用，與店方積極勸誘不同。應依實際引導、設備及運營確認，而非只看「酒吧」名稱或活動標題。

## 接待營業和深夜供酒申報有何不同？

| 實際營業 | 風營法上的主要程序 | 依據 |
|---|---|---|
| 接待客人並提供飲食 | 風俗營業1號許可 | 第2條第1項第1號、第3條第1項 |
| 無接待，深夜同時有遊興與供酒 | 特定遊興飲食店營業許可 | 第2條第11項、第31條之22 |
| 無接待、遊興，深夜以供酒為主 | 深夜酒類提供飲食店營業申報對象 | 第33條第1項；日常提供一般主食的營業等依法排除 |

此表只整理風營法的分類。屬申報對象，也須另查食品衛生法的飲食店營業許可、消防及建築等條件。詳見[接待飲食店1號的物件要件](/zh-tw/legal/column/fuzoku-eigyo-1go-settai-inshoku-kyoka-bukken-kyori)、[深夜酒類提供飲食店申報](/zh-tw/legal/column/shinya-shurui-teikyo-todokede-yoken)。

低照度飲食店屬風營法第2條第1項第2號；第3號是區畫席飲食店，兩者是不同類別。是否屬低照度，須依規定的測量方法及營業方式確認。特定遊興原則上須維持超過10勒克斯，調暗燈光的時段也須向所轄警察確認。

## 營業區域與時間如何確認？

原則上須位於都道府縣條例指定的「營業所設置許容地域」。飯店等內部符合特別條件的營業所可能有例外，但不能只因位於飯店內就適用。

| 項目 | 簽租約前的確認事項 |
|---|---|
| 區域 | 具體地址、街區是否在條例與公告的許容地域內 |
| 保全對象設施 | 依當地規定確認學校、醫院等類別、距離與測量方式 |
| 營業時間 | 查都道府縣條例禁止營業的時段 |
| 飯店等例外 | 確認國家公安委員會規則的具體條件 |

施行令以保全對象設施基地周圍約100公尺為限，由條例設定相關區域。這不代表全國一律要求100m的離隔距離。距離或營業時間不能套用全國一致數值。京都府警2026年9月28日更新說明，列出凌晨5至6時禁止營業，以及相關類別的保全設施距離70m。這是地域差異的例子，不能轉用其他地方。本文尚未驗證目標物件的條例、公告與現況；應向所轄警察署生活安全部門提供具體地址與營業計畫確認。未成年者進入及供酒限制亦須另查。

## 客室33㎡等構造設備基準有哪些？

風營法施行規則第75條的主要確認事項如下。營業所總面積不等於客室面積。

| 項目 | 基本確認事項 |
|---|---|
| 客室面積 | 每一間客室33㎡以上 |
| 照度 | 須有使營業所內照度維持超過10勒克斯的構造或設備 |
| 視線 | 不得設置妨礙客室內視線的設備 |
| 出入口鎖具 | 客室出入口不得設鎖具；直接通往營業所外的出入口為例外 |
| 其他 | 確認有害風俗環境設備的禁止、噪音及振動等基準 |

深夜營業原則上須常態維持超過10勒克斯。警察廳基準也規定：僅在座席讓客人遊興的客室，10勒克斯以下的時段須少於每次深夜營業時間的一半。應區分構造設備基準與營業運用，不可自行套用此項處理。客室範圍、面積計算、照度測量位置、營業時燈光設定與鎖具例外，須查現行規則並向所轄警察署確認。簽租約、裝修前應核對圖面與實際現況；面積、照度符合不等於保證許可。

## 申請文件與取得許可的流程如何？

先就營業方法、立地、構造事前相談，再整備文件，經所轄警察署向公安委員會申請。經文件審查、現場確認等後作出許可判斷。完整附件、審查期間及2025年修法後的具體欠格條件須依所在地、申請人確認，本文尚未逐項驗證。

| 類別 | 文件範例 |
|---|---|
| 營業內容 | 許可申請書、營業方法及遊興方法說明 |
| 營業所 | 平面圖、面積計算圖、照明與音響圖、使用權證明 |
| 申請人等 | 住民票、誓約書；法人定款、登記事項證明等 |

## 應找誰協助，哪些行政程序分別辦理？

| 事項 | 受任者或行政窗口 |
|---|---|
| 許可要件整理、申請文件與申請圖面、申請代理 | 四葉行政書士事務所；申請圖面與建築設計須區分 |
| 店舖尋找、租賃仲介 | 四葉不動産株式会社 |
| 建築設計、構造、裝修工程 | 建築士、工程業者等；法定須建築士辦理的設計由建築士負責 |
| 深夜加給、排班等勞務 | 四葉社会保険労務士事務所 |
| 風營法許可審查 | 都道府縣公安委員會；經所轄警察署相談、申請 |
| 飲食店營業許可 | 於保健所辦理食品衛生法程序；消防、建築另向各主管機關確認 |

四葉行政書士事務所、四葉社会保険労務士事務所、四葉不動産株式会社是獨立的事業體。民間專業人士的委託須分別簽約，各受任者直接請款、收款；本事務所不收介紹費。公安委員會、保健所是審查或許可的行政窗口，不是民間受任契約的簽約對象。詳見[受任流程](/zh-tw/legal/nagare)、[報酬額表](/zh-tw/legal/ryokin)、[許認可服務](/zh-tw/legal/services)。

## 常見問題

**Q. 白天遊興，深夜只供酒，也屬特定遊興嗎？**
A. 不能只因深夜營業就判斷。須確認深夜是否同時有遊興與供酒，以及是否屬其他風俗營業。深夜不進行遊興時，應依實態檢討深夜供酒申報等其他類別。

**Q. 只放卡拉OK機器就屬遊興嗎？**
A. 客人自行使用設備，與店家積極勸誘唱歌不同。須將店方引導、活動運營等實態，依警察廳解釋運用基準與所轄警察署確認。

**Q. 只辦深夜供酒申報就能開業嗎？**
A. 該申報是風營法類別的程序。有接待或深夜遊興時，須檢討其他許可；食品衛生法的飲食店許可、消防及建築等要件亦須分別確認。

**Q. 每間客室33㎡、照度達標就能在任何地方取得許可嗎？**
A. 不能。除每間33㎡以上、原則維持超過10勒克斯外，還須確認當地許容地域、距離與禁止時間、其他設備基準、欠格事由等。單憑面積和照度不保證許可。
