**先講結論：** 來自中國、台灣等地的創業者，在日本設立公司並經營其事業時，目標多為在留資格「經營、管理」（《出入國管理及難民認定法》別表第一之二）。上陸許可基準規定於同法第7條第1項第2款之基準省令，2025年（令和7年）10月16日施行的修法，將資本額或出資總額提高至3,000萬日圓以上，並新增常勤職員1人以上的雇用、申請人本人或常勤職員的一定日語能力、3年以上經營經驗或碩士等學位、事業計畫的專家確認、獨立事業所的確保。本文為一般性資訊，整理要件全貌與代辦申請的行政書士角色。個別能否核准，取決於出入國在留管理廳的審查。

## 「經營、管理」在留資格的主要要件為何？

「經營、管理」是供在日本經營事業、或從事管理的外國人使用的在留資格（《出入國管理及難民認定法》別表第一之二）。上陸許可基準置於同法第7條第1項第2款之基準省令，並於2025年（令和7年）10月16日的修法大幅變更。修法後主要基準如下。

| 事項 | 修法後基準（2025年10月16日施行） |
| --- | --- |
| 資本額或出資總額 | **3,000萬日圓以上**（修法前為500萬日圓以上） |
| 常勤職員 | 雇用**1人以上**。對象為日本人、特別永住者、以別表第二在留資格在留的外國人 |
| 日語能力 | 申請人本人或常勤職員達「日語教育參照框架」的**B2相當以上**（以日語能力試驗N2以上、BJT商務日語能力測驗400分以上等舉證） |
| 經營經驗、學歷 | 就事業的經營、管理有**3年以上經驗**，或博士、碩士、專門職學位 |
| 事業計畫 | 經中小企業診斷士、公認會計士、稅理士等**專家確認** |
| 事業所 | 確保獨立事業所。**與自宅兼用原則上不予認可** |

已以「經營、管理」在留者，設有自施行日起3年（令和10年＝2028年10月16日）的過渡措施，其間更新時預期須逐步符合修法後基準。修法宗旨據稱在於防止無實體的公司設立、確保實質的事業營運。本所在行政書士業務範圍內，協助確認要件、整理舉證資料、製作申請文件與代辦申請。個別能否核准取決於出入國在留管理廳的審查。

## 事業所（辦公室）與資本額需要到什麼程度？

修法後特別加重的是資本額與事業所。

| 事項 | 內容（要旨） |
| --- | --- |
| 資本額、出資總額 | 法人為已繳納的資本額（合名、合資、合同公司為出資總額），個人事業為投入事業的總額，須達**3,000萬日圓以上** |
| 事業所 | 供持續經營事業的獨立設施。**與自宅兼用原則上不予認可**，僅借用地址的形態難以獲准 |
| 使用權原 | 須有租賃契約等使用權原，且用途地區、建物用途須適合事業 |

事業所不僅是「有無可租物件」，還須先確認用途地區與建物使用方式是否適合事業。若先簽約後才發現不能使用便得重找，於物件選定階段先確認較為安全。事業所物件的尋找與租賃，由屬別事業體的四葉不動產（持照不動產業者）以獨立的事業體另行簽約辦理。本所不收取介紹費。

## 公司設立與在留資格申請，哪個先？

居於海外而創業時，實務上一般為「先設立公司，再申請在留資格」。因為審查以公司（法人）存在，且資本、事業所、事業計畫齊備為前提。

| 階段 | 內容 |
| --- | --- |
| ① 事業計畫、資金 | 準備3,000萬日圓以上資本、製作經專家確認的事業計畫、確保事業所 |
| ② 公司設立 | 章程製作、認證，繳納出資，設立登記（登記申請由司法書士辦理） |
| ③ 在留資格申請 | 向出入國在留管理廳提出在留資格認定證明書交付申請等（自海外招聘時）；由行政書士代辦申請 |
| ④ 入境、開業 | 依證明書取得簽證入境，開始事業 |

公司設立登記由司法書士，法人設立申報、稅務由稅理士，事業所物件由不動產業者，雇用員工時的社會保險、勞動保險由社會保險勞務士，各有分工。各事業體以獨立的事業體分別簽約，本所不收取介紹費。

## 設立登記、稅務、社會保險該如何分工委託？

取得「經營、管理」離不開行政書士以外的專家參與。獨占業務的切分如下。

- 在留資格的要件確認、舉證資料整理、申請文件製作與代辦申請 → 四葉行政書士事務所（可代辦申請的行政書士）
- 公司的設立登記、董事變更等登記 → 司法書士
- 法人設立申報、稅務、記帳、稅務諮詢 → 稅理士
- 事業所物件的尋找、租賃契約 → 四葉不動產（持照不動產業者）
- 雇用員工時的社會保險、勞動保險手續 → 社會保險勞務士

四葉行政書士事務所與四葉不動產股份有限公司為不同事業體。各領域以各自有資格者、以獨立的事業體分別簽約為前提，本所不收取介紹費。行政書士不能代理登記，稅務諮詢由稅理士、登記由司法書士承擔。以團體家屋（group home）等特定行業考量「經營、管理」時與指定申請的關係，另見[外國人如何開展團體家屋事業（經營、管理在留資格）](https://luck428.com/legal/column/group-home-gaikokujin-keieikanri-zairyushikaku)。

## 代辦申請的行政書士能做到什麼程度？

向出入國在留管理廳的在留資格申請，原則上由本人親自到場辦理，但完成一定研修並提出申報的行政書士（代辦申請行政書士），可代本人提交（代辦）申請文件，藉此減輕本人到入管窗口的負擔。

| 可以做的事 | 不能做的事 |
| --- | --- |
| 要件確認、舉證資料整理、申請書與理由書製作、代辦申請 | 保證或斷定結果；審查由出入國在留管理廳進行 |
| 事業計畫書的製作協助（數值妥當性以專家確認為前提） | 公司設立登記（司法書士業務）、稅務諮詢、申報（稅理士業務） |
| 以中文（繁體、簡體）、英文說明文件的窗口 | 斷定個案的法律評價；最終判斷由有資格者、入管進行 |

代辦申請僅為手續代辦，並不保證在留資格獲准。須逐一符合資本、事業所、日語能力、事業計畫的專家確認等修法後基準。委任流程請見[委任流程](https://luck428.com/legal/nagare)、費用請見[報酬額表](https://luck428.com/legal/ryokin)、業務全貌請見[許可、各項申請服務](https://luck428.com/legal/services)。

## 常見問題

**Q. 資本額真的需要3,000萬日圓嗎？**
A. 2025年（令和7年）10月16日施行的修法，將資本額或出資總額的下限由500萬日圓以上提高至3,000萬日圓以上。已以「經營、管理」在留者，設有自施行日起3年（2028年10月16日）的過渡措施，但新申請者依修法後基準審查。個別處理請向出入國在留管理廳確認。

**Q. 不會說日語也能取得嗎？**
A. 修法後，申請人本人或常勤職員須具備「日語教育參照框架」B2相當以上（如日語能力試驗N2以上）的日語能力。若申請人本人未達，亦可透過確保達該水準的常勤職員因應。舉證方式與具體水準須依最新基準確認。

**Q. 可以在設立公司前先申請在留資格嗎？**
A. 實務上一般為設立公司、資本、事業所、事業計畫齊備後再申請，因公司存在與事業實體為審查前提。設立登記由司法書士、在留資格代辦申請由行政書士分工，各以獨立的事業體分別簽約。

**Q. 委託行政書士就一定會核准嗎？**
A. 不會。可代辦申請的行政書士能做到的，是要件確認、資料整理、文件製作與代辦申請，能否核准由出入國在留管理廳審查判斷，無法保證或斷定核准。本文為一般性資訊，不保證個別結果。
