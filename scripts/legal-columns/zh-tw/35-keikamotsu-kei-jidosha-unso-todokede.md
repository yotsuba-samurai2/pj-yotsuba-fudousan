**結論（先說要點）**：以一輛輕型廂型車起步之配送・宅配（貨物輕型汽車運送事業，即所謂黑牌），非如一般貨物汽車運送事業之「許可」，而以「申報」即可開始。依據為貨物汽車運送事業法第2條第4項（貨物輕型汽車運送事業之定義）與第36條第1項（經營申報）。向管轄之運輸支局提出貨物輕型汽車運送事業經營申報書與事業用汽車等聯絡書，並持該聯絡書於輕型汽車檢查協會辦理黑牌之車輛登錄。自2025年4月1日起，新增於各營業所選任貨物輕型汽車安全管理者之義務（同法第36條之2，令和6年法律第23號）。本文為一般資訊提供，整理申報制與許可制之差異、必要文件與車庫・營業所條件、2025年施行之安全管理義務，以及物件・勞務應交由何人處理。個別申報之受理與必要文件，由管轄之運輸支局・輕型汽車檢查協會之處理而定。

## 輕貨物（黑牌）非許可而以申報即可開始？

貨物輕型汽車運送事業，於貨物汽車運送事業法第2條第4項定義為「應他人需求、有償以汽車（限於三輪以上之輕型車及二輪車）運送貨物之事業，且為一般貨物汽車運送事業及特定貨物汽車運送事業以外者」。輕型廂型車、輕型卡車及機車快遞屬之。

一般貨物汽車運送事業須依第3條取得「許可」，貨物輕型汽車運送事業則依第36條第1項以「申報」即可開始。該項規定「欲經營貨物輕型汽車運送事業者，須依省令所定手續，將營業所之名稱及位置、事業用汽車之概要及其他事項向國土交通大臣申報」。實務上向管轄之運輸支局申報。

| 項目 | 貨物輕型汽車運送事業（黑牌） |
| --- | --- |
| 手續種類 | 申報（貨物汽車運送事業法第36條第1項） |
| 使用車輛 | 三輪以上之輕型車・二輪車（輕型廂型車、輕型卡車、機車等） |
| 事業用汽車數量 | 1輛起可 |
| 車牌 | 黑底黃字之事業用車牌（即所謂黑牌） |

申報一經受理即足，非如許可般以審查判斷可否之制度。惟提出文件之格式與附件因運輸支局而異，事前於窗口確認可避免文件退回。

## 與一般貨物運送之差異何在？（輛數・運行管理者・車庫）

雖同為「運送貨物之事業」，一般貨物汽車運送事業與貨物輕型汽車運送事業係手續與要件均不同之制度。主要差異如下。

| 事項 | 一般貨物汽車運送事業（綠牌） | 貨物輕型汽車運送事業（黑牌） |
| --- | --- | --- |
| 手續 | 許可（第3條） | 申報（第36條第1項） |
| 事業用汽車數量 | 最低5輛 | 1輛起可 |
| 運行管理者 | 須選任 | 無須選任（另選任安全管理者） |
| 整備管理者 | 達一定輛數時須設 | 原則不需 |
| 車庫 | 位置・大小之基準（車輛相互間50公分以上等） | 具使用權原之停車空間（併設或一定距離內為目安） |
| 開始前期間 | 標準處理期間概略3〜5個月 | 申報一經受理即可進入車輛登錄 |

一般貨物之許可要件（5輛・運行管理者・車庫大小・法令試驗等），於另文[一般貨物汽車運送事業之營業所・車庫要件](https://luck428.com/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)整理。以一輛輕型廂型車起步時，先依事業計畫確認是否屬貨物輕型汽車運送事業。

## 申報所需文件與車庫・營業所之條件為何？

申報之核心文件為貨物輕型汽車運送事業經營申報書與事業用汽車等聯絡書。將經營申報書向運輸支局提出，並持蓋有確認印之事業用汽車等聯絡書至輕型汽車檢查協會，辦理黑牌車輛之登錄（事業用之變更登錄）。

| 文件 | 內容 |
| --- | --- |
| 貨物輕型汽車運送事業經營申報書 | 記載營業所之名稱・位置、事業用汽車數量等，向運輸支局提出 |
| 運價料金設定申報書 | 申報所適用之運價・料金 |
| 運送約款 | 使用標準貨物輕型汽車運送約款時，於申報書載明其旨 |
| 事業用汽車等聯絡書 | 受運輸支局確認，用於輕型汽車檢查協會之車輛登錄 |

營業所・車庫之條件雖無如一般貨物般細之面積基準，惟下列各點為目安。

- 營業所具使用權原（自有或租賃）。亦有可將自宅作為營業所之情形
- 車庫能收容計畫之事業用汽車且具使用權原。原則併設於營業所，分開時以一定距離內（因地區而異）為目安
- 以租賃物件作為車庫・營業所時，須確認契約上是否認可該用途

車庫或營業所之距離・大小之處理因運輸支局而異。於簽約物件前，依用途與使用權原之要件確認，可避免簽約後重做。物件側之要件，向不動產之承辦確認較為確實。

## 2025年施行之貨物輕型汽車安全管理者做什麼？

以貨物輕型汽車運送事業相關事故增加為背景，貨物汽車運送事業法經修正（令和6年法律第23號，2024年5月15日公布），自2025年4月1日起施行貨物輕型汽車安全管理者制度。依據為同法第36條之2。

| 事項 | 內容 |
| --- | --- |
| 選任義務 | 於各營業所選任貨物輕型汽車安全管理者（第36條之2） |
| 施行日 | 2025年4月1日 |
| 對象 | 貨物輕型汽車運送事業者 |
| 講習 | 選任前修畢貨物輕型汽車安全管理者講習。其後每2年須受定期講習 |
| 主要業務 | 點呼、對駕駛人之指導・監督、業務之記錄等確保運行安全之業務 |
| 選任・申報 | 選任時向運輸支局等申報 |
| 經過措施 | 2025年3月31日前已提出經營申報之既有事業者，於2027年3月31日前選任即可 |

違反選任義務或申報義務者，定有罰則（100萬日圓以下罰金）。講習之受講手續費與日程，由受登錄之講習機關之案內而定。新開始之事業者，於修畢講習後選任安全管理者並申報。四葉行政書士事務所於行政書士業務範圍內，支援申報文件與安全管理者選任申報書之製作。個別申報之受理與文件之要否，由管轄之運輸支局之處理而定。

## 僱用人員・租借物件時應向何人諮詢？

貨物輕型汽車運送事業，非僅以申報即告完結，尚涉及物件・勞務・登記・稅務。分工如下。

- 貨物輕型汽車運送事業之經營申報、事業用汽車等聯絡書、安全管理者選任申報書之製作 → 四葉行政書士事務所（行政書士）
- 營業所・車庫物件之尋找、用途與使用權原之確認、租賃契約 → 四葉不動產株式會社（宅地建物交易業者）
- 僱用駕駛人時之勞動保險・社會保險加保、工時（改善基準告示）、就業規則・36協定 → 社會保險勞務士
- 法人設立・役員變更等之登記 → 司法書士
- 所得稅・消費稅等稅務之諮詢・申報 → 稅理士

四葉行政書士事務所與四葉不動產株式會社為別事業體。各領域均以與各資格者作為獨立的事業體個別簽約為前提，本事務所不收取介紹費。受任流程見[受任流程](https://luck428.com/legal/nagare)；費用見[報酬額表](https://luck428.com/legal/ryokin)；全貌見[許認可・各種申請服務](https://luck428.com/legal/services)。營業所・車庫物件側之要件，亦請參閱別事業體四葉不動產株式會社整理之[運送業營業所・車庫物件要件](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

## 常見問題

**Q. 僅一輛輕型廂型車亦能申報嗎？**
A. 貨物輕型汽車運送事業以1輛事業用汽車起即可開始，無如一般貨物汽車運送事業之最低5輛要件。是否屬申報（貨物汽車運送事業法第36條第1項）之事業計畫，視使用車輛與運送內容而定。個別受理之可否由管轄之運輸支局之處理而定。

**Q. 黑牌於何處申辦？**
A. 先向運輸支局提出貨物輕型汽車運送事業經營申報書，再持蓋有確認印之事業用汽車等聯絡書至輕型汽車檢查協會，辦理事業用（黑牌）車輛之登錄。申報與車輛登錄之窗口不同，須確認順序後進行。

**Q. 2025年起之安全管理者必須選任嗎？**
A. 自2025年4月1日起，貨物輕型汽車運送事業者須於各營業所選任貨物輕型汽車安全管理者（貨物汽車運送事業法第36條之2）。新開始之事業者於修畢講習後選任・申報。2025年3月31日前已申報之既有事業者，設有2027年3月31日前選任即可之經過措施。

**Q. 與一般貨物（綠牌）如何區分使用？**
A. 以三輪以上之輕型車或二輪車運送者為貨物輕型汽車運送事業（申報・黑牌）；以普通車或小型卡車等運送者為一般貨物汽車運送事業（許可・綠牌，最低5輛・運行管理者）。屬何者視使用車輛與事業計畫而定。許可制之詳情見[一般貨物汽車運送事業之營業所・車庫要件](https://luck428.com/legal/column/ippan-kamotsu-unso-kyoka-eigyosho-shako-yoken)。
