**結論（先に要点）**：相続した実家（空き家）を売って「空き家の譲渡所得の3,000万円特別控除」（租税特別措置法第35条第3項）を使うには、確定申告に「被相続人居住用家屋等確認書」を添付する必要があります。この確認書は、売った家屋・土地の所在地を管轄する市区町村長が交付します（国税庁・国土交通省の案内・参照日 2026-10-31）。交付の申請には、被相続人の除票住民票、電気・ガス・水道の使用中止（閉栓）日が分かる書類、売買契約書の写しなどを添えます。本記事は官公署に提出する書類の作成という範囲での一般的な情報提供であり、特例が使えるかどうかの税務判断や税額計算・申告は行いません。

## 「被相続人居住用家屋等確認書」はなぜ必要で、どこへ申請しますか？

空き家の譲渡所得の3,000万円特別控除は、相続した被相続人の居住用家屋（またはその敷地）を一定の要件のもとで売ったときに、譲渡所得から最高3,000万円を控除できる特例です（租税特別措置法第35条第3項、同法施行令第20条の3、同法施行規則第18条の2）。この特例を受けるには、確定申告書に「被相続人居住用家屋等確認書」を添付することが求められます（国税庁「No.3306」・参照日 2026-10-31）。

確認書は、税務署ではなく、売った家屋・土地の所在地を管轄する市区町村長が交付します。つまり、税の申告は税務署、特例の前提となる事実を証明する確認書は市区町村、と窓口が分かれます。確認書は、その家屋が「被相続人の居住用家屋」に当たり、相続の時から譲渡の時まで空き家であったことなどを、市区町村が書類で確認したことを示すものです。

| 項目 | 内容 |
| --- | --- |
| 根拠 | 租税特別措置法第35条第3項（施行令第20条の3・施行規則第18条の2） |
| 確認書の交付者 | 売った資産の所在地を管轄する市区町村長 |
| 提出先・用途 | 確定申告書に添付して税務署へ（特例の適用要件の一つ） |
| 控除額 | 最高3,000万円（令和6年1月1日以後の譲渡で、取得した相続人が3人以上のときは2,000万円） |

特例が実際に使えるかどうかの判断と税額計算・申告は税理士の領域です。当事務所（行政書士）は、確認書の交付申請書類の作成・提出という範囲でお手伝いします。

## 確認書が出る家屋の要件（築年・区分所有・空き家）はどう整理されますか？

確認書は、売った家屋が特例の対象となる「被相続人居住用家屋」の事実を満たすことを前提に交付されます。国税庁が示す主な要件は次のとおりです（No.3306・参照日 2026-10-31）。

| 要件 | 内容 |
| --- | --- |
| 建築時期 | 昭和56年5月31日以前に建築されたこと |
| 区分所有でないこと | 区分所有建物登記がされている建物でないこと |
| 相続直前の居住 | 相続開始の直前に被相続人以外に居住していた人がいなかったこと（主として被相続人が居住していた一の建築物に限る） |
| 空き家の継続 | 相続の時から譲渡の時まで、事業・貸付け・居住の用に供されていないこと |
| 適用期間 | 平成28年4月1日から令和9年12月31日までの間の譲渡 |
| 譲渡対価 | 譲渡対価の額が1億円以下であること（他の相続人の譲渡分等と合算して判定） |

被相続人が相続開始直前に老人ホーム等へ入所していた場合でも、要介護認定を受けていたことなど一定の要件を満たせば対象になり得ます。その場合は、入所の事実や要介護認定を示す書類が追加で必要になります。どの要件に当たるかの最終的な当てはめと税務判断は、税理士にご確認ください。

## 申請に添える書類にはどんなものがありますか？

市区町村に確認書の交付を申請するときは、申請書に次のような書類を添えます（各市区町村の交付要綱・参照日 2026-10-31。自治体により名称・部数が異なります）。

| 区分 | 主な書類 |
| --- | --- |
| 相続・居住の確認 | 被相続人の除票住民票、相続人の住民票 |
| 空き家であった確認 | 電気・ガス・水道の使用中止（閉栓）日が確認できる書類、閉栓証明や使用中止の連絡票など。使用中止日は相続開始日以降のものに限られる点に注意 |
| 譲渡の確認 | 売買契約書の写し |
| 老人ホーム入所の場合 | 要介護認定・施設入所の事実を示す書類 |

電気・ガス・水道の使用中止日が相続開始日より前だと、相続の時に空き家であったことを示せず、確認が受けられないことがあります。閉栓日の記録は早めに手元で確認しておくのが安全です。必要書類は自治体ごとに異なり、追加を求められることもあるため、申請前に物件所在地の市区町村の最新の案内で確認してください。

## 取壊して売る場合と、耐震改修して売る場合で書類はどう変わりますか？

この特例は、(1)家屋を耐震改修して（耐震性のある家屋として）売る類型と、(2)家屋を取り壊して土地だけを売る類型に大きく分かれ、確認書の様式も譲渡の態様で分かれます。

- 耐震改修して売る場合：譲渡の時に一定の耐震基準に適合していることが要件です。令和6年1月1日以後の譲渡では、譲渡の日の属する年の翌年2月15日までに基準を満たすこととなった場合も対象になります。耐震基準適合証明書や工事に関する書類が必要になります。
- 取り壊して土地を売る場合：相続の時から取壊し等の時まで、また取壊し等の時から譲渡の時まで、要件を満たす必要があります。建物の取壊しを示す書類（閉鎖事項証明書など）が必要になります。令和6年1月1日以後の譲渡では、譲渡の日の属する年の翌年2月15日までに取壊し等が行われた場合も対象になります。

| 譲渡の態様 | 要件の要点 | 主な追加書類 |
| --- | --- | --- |
| 耐震改修して売る | 譲渡時に耐震基準適合（令和6年以後の譲渡は翌年2月15日までの適合も可） | 耐震基準適合証明書、工事関係書類 |
| 取り壊して土地を売る | 相続時〜取壊し時・取壊し時〜譲渡時の要件（令和6年以後の譲渡は翌年2月15日までの取壊し等も可） | 建物の取壊しを示す書類（閉鎖事項証明書など） |

どちらの様式に当たるか、必要書類の過不足は自治体と税理士で確認します。本記事は制度の枠組みの情報提供にとどめ、個別の当てはめは行いません。

## 控除が使えるかの判断・申告は誰に、滅失登記や売買は誰に振りますか？

空き家の売却は、確認書の取得と並行して税務・登記・売買が動きます。担当は次のとおり分かれ、それぞれ独立した事業体として別々にご契約・お手続きいただきます。

- 被相続人居住用家屋等確認書の交付申請書類の作成・提出 → 四葉行政書士事務所（行政書士）。資料と情報の提供までを行い、具体的な法的判断・税務判断はしません
- 特例が使えるかの判断・税額計算・確定申告 → 税理士。当事務所は税務判断・申告を行いません
- 建物の取壊し後の建物滅失登記（表示に関する登記） → 土地家屋調査士
- 相続登記（所有権移転の登記） → 司法書士
- 空き家の売却の媒介 → 別事業体の四葉不動産株式会社（宅地建物取引業者）。独立した事業体として別契約で対応します

## よくある質問

**Q. 被相続人居住用家屋等確認書はどこでもらえますか？**
A. 売った家屋・土地の所在地を管轄する市区町村長が交付します（国税庁「No.3306」・参照日 2026-10-31）。税務署ではありません。交付を受けた確認書を、確定申告書に添付して特例（租税特別措置法第35条第3項）を受けます。申請の窓口・様式は自治体ごとに異なるため、物件所在地の市区町村の最新の案内で確認してください。

**Q. 電気やガスの閉栓日はなぜ重要なのですか？**
A. 特例は相続の時から譲渡の時まで空き家であったことが前提のため、市区町村は電気・ガス・水道の使用中止（閉栓）日が分かる書類で空き家だった事実を確認します。使用中止日は相続開始日以降のものに限られ、相続開始日より前の閉栓だと確認が受けられないことがあります。閉栓日の記録は早めに手元で確認しておくのが安全です。

**Q. 建物を取り壊してから売るときと、残したまま売るときで書類は違いますか？**
A. 違います。取り壊して土地を売る場合は建物の取壊しを示す書類（閉鎖事項証明書など）、耐震改修して売る場合は耐震基準適合証明書などが必要で、確認書の様式も分かれます。令和6年1月1日以後の譲渡では、譲渡の日の属する年の翌年2月15日までに取壊し等・耐震基準適合がされた場合も対象になります。どちらに当たるかは自治体・税理士に確認してください。

**Q. 行政書士は税金の計算もしてくれますか？**
A. いたしません。特例が使えるかどうかの税務判断と税額計算・確定申告は税理士の領域です。当事務所（行政書士）は、被相続人居住用家屋等確認書の交付申請書類の作成・提出という範囲でお手伝いします。税務は独立した事業体の税理士と別々にご契約いただきます。当事務所は紹介料を受け取りません。
