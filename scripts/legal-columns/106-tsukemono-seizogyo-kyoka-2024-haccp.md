**結論（先に要点）**：直売所・道の駅・ネットなどで販売する漬物（浅漬け・キムチ・梅干し・たくあん等）を製造するには、原則として「漬物製造業」の営業許可が必要です。これは2018年（平成30年）の食品衛生法等の一部を改正する法律（平成30年法律第46号）で営業許可業種が見直された際に新設された業種で、食品衛生法施行令第35条第29号に定められ、許可は食品衛生法第55条に基づき保健所（都道府県知事等）が行います。施行令の施行日（2021年〔令和3年〕6月1日）より前から営んでいた事業者には3年間の経過措置がありましたが、それが2024年（令和6年）5月31日で終了し、2024年6月1日以降は許可なしでは販売用の漬物を製造できなくなりました。許可には都道府県の条例で定める施設基準（食品衛生法第54条）への適合と、HACCPに沿った衛生管理（食品衛生法第51条）、食品衛生責任者の設置が必要で、家庭の台所そのままでは許可は下りません。本記事は一般的な情報提供で、個別の施設が基準に適合するかの最終判断をするものではありません。四葉グループの行政書士は、営業許可の申請書類や衛生管理計画の整備の支援を独立した事業体として担います。施設の適合審査・許可は保健所、製造室の工事は建築士・設備業者、売上の税務は税理士、従業員の労務は社会保険労務士、物件探しは別事業体である不動産業者の領域で、それぞれ別々にご契約いただきます。

## そもそも漬物の販売になぜ営業許可が必要になったのか？

漬物は長く、都道府県の条例に基づく「届出」の対象にとどまり、食品衛生法上の営業許可は不要な地域が多くありました。しかし浅漬けなどを原因とする食中毒が起きたことなどを背景に、2018年（平成30年）の食品衛生法改正（平成30年法律第46号）で営業許可業種が全体的に見直され、漬物製造業が新たに許可業種として位置づけられました。根拠は食品衛生法施行令第35条第29号で、ここに許可を要する業種として列挙されています。

| 項目 | 内容（根拠） |
| --- | --- |
| 業種の新設 | 食品衛生法等の一部を改正する法律（平成30年法律第46号）による営業許可業種の見直し |
| 位置づけ | 食品衛生法施行令第35条第29号「漬物製造業」 |
| 許可の根拠 | 食品衛生法第55条（都道府県知事等の営業許可） |
| 施行令の施行日 | 2021年（令和3年）6月1日 |

漬物製造業には、梅干し・たくあん・浅漬け・キムチ・ピクルスなどの製造のほか、漬物を主たる原材料とする食品の製造も含まれると案内する自治体が多く、範囲は保健所により細部が異なります。食品を扱うほかの許認可との関係は[食品製造業の許可と物件・設備基準](/legal/column/shokuhin-seizogyo-kyoka-bukken-setsubi-kijun)でも整理しています。当事務所の[許認可サービスのご案内](/legal/services)もご覧ください。

## 2024年6月以降、許可なしで漬物を売るとどうなるのか？

施行令の施行日（2021年〔令和3年〕6月1日）より前から漬物を製造していた事業者には、3年間の経過措置が設けられていました。その期限が2024年（令和6年）5月31日で終了し、2024年6月1日以降は、許可を受けずに販売用の漬物を製造することはできません。

| 時期 | 取扱い |
| --- | --- |
| 2021年6月1日より前から営業 | 2024年5月31日までに許可を取得する必要があった（経過措置） |
| 2024年6月1日以降 | 許可なしでは販売用の漬物を製造できない。新規は営業開始前に許可が必要 |

許可を受けずに営業した場合（食品衛生法第55条第1項違反）は、同法第82条により2年以下の拘禁刑又は200万円以下の罰金の対象とされ、法人にも第88条の両罰規定で同額の罰金が科されることがあります。自分で漬けたものを自家消費する場合や、無償でのやり取りは「業として」の製造・販売に当たらないのが通常ですが、反復継続して販売する以上は許可が要ります。該当するか迷う場合は、書く前提にせず保健所に直接確認するのが確実です。

## 許可が下りる製造室の施設基準（手洗い・区画・給排水）はどこまで必要か？

許可は、都道府県が条例で定める施設基準（食品衛生法第54条。厚生労働省令の基準を参酌して定める）に施設が適合してはじめて下ります。家庭の台所と住居が一体の空間のままでは、原則として許可は下りません。代表的な確認点は次のとおりですが、具体的な数値・仕様は所管保健所の条例・要綱で必ず確認します。

| 区分 | 主な確認点（条例により異なる） |
| --- | --- |
| 区画 | 製造室を住居・居室と壁等で区画し、作業区域を分ける |
| 手洗い | 製造室・トイレに洗浄消毒できる手洗い設備を設ける |
| 給排水 | 使用水の確保（飲用適）と適切な排水、洗浄設備 |
| 構造・材質 | 床・壁・天井が清掃しやすく、器具は不浸透性で洗浄しやすい材質 |
| 区域・換気 | 更衣場所、保管設備、換気・照明、防虫防そ対策 |

製造室の工事や内装は建築士・設備業者の領域で、物件を借りる段階での用途や設備の可否は不動産の確認事項です。間取りや給排水を後から直すと費用がかさむため、物件を押さえる前に保健所の事前相談で図面を見てもらうのが実務です。食品を扱う物件の設備の考え方は[食品製造業の許可と物件・設備基準](/legal/column/shokuhin-seizogyo-kyoka-bukken-setsubi-kijun)でも触れています。

## HACCPに沿った衛生管理として小規模事業者は何を記録すればよいのか？

2020年（令和2年）6月1日から（経過措置を経て2021年6月1日に完全施行）、原則としてすべての食品等事業者に「HACCPに沿った衛生管理」が求められています（食品衛生法第51条）。漬物製造業も例外ではありません。もっとも、小規模な営業者等には、取り扱う食品の特性に応じた「HACCPの考え方を取り入れた衛生管理」が認められ、厚生労働省が公表する業種別の手引書に沿って進められます。

| 区分 | 求められる取組（食品衛生法第51条） |
| --- | --- |
| 一般的な衛生管理 | 施設内外の清潔保持、ねずみ・昆虫の駆除、使用水・器具の管理など |
| 重要な工程の管理 | 危害の発生を防ぐため特に重要な工程を管理する取組（洗浄・塩分や温度の管理など） |
| 小規模営業者等 | 食品の特性に応じた取組（手引書に沿った衛生管理計画の作成と記録） |

小規模事業者が「何を書くか」の中心は、手引書のひな形に沿って衛生管理計画を作り、原材料の受入れ・使用水・手洗い・温度管理などの実施を日々チェックして記録に残すことです。記録は後から衛生管理を説明できる形にしておきます。衛生管理計画の整備や様式の準備は行政書士が支援できますが、計画が基準に適合するかの最終的な審査は保健所が行います。手引書の最新版は、書く前提にせず厚生労働省の公式ページで確認します。

## 申請はどこへ・誰に頼むのが確実か？

申請先は、製造所の所在地を所管する保健所（都道府県知事・保健所設置市長等の許可）です。関係する専門家が分かれるため、それぞれ独立した事業体として別々にご契約いただくのが基本です。四葉グループの行政書士は、営業許可の申請書類の作成・提出の代行、衛生管理計画の整備の支援、食品衛生責任者の確認までを、独立した事業体として担います。

| 依頼先 | 主な役割 |
| --- | --- |
| 行政書士（当事務所） | 営業許可の申請書類の作成・提出、衛生管理計画の整備支援 |
| 保健所 | 施設基準への適合審査・現地確認、許可の決定 |
| 建築士・設備業者 | 製造室の工事・給排水・内装などの施工 |

| 社会保険労務士 | 従業員を雇う場合の労働保険・社会保険、就業規則 |
| 不動産業者（別事業体の当社） | 製造に使える物件の紹介・契約 |

個別の施設が基準に適合するか、どの業種区分で申請すべきかといった判断は、最終的には保健所の審査領域で、行政書士が代わりに許可を保証するものではありません。製造に使える物件を探す段階では、別事業体の不動産業者がお手伝いできます。当事務所の[受任の流れ](/legal/nagare)と[報酬額表](/legal/ryokin)もご覧ください。各専門家とは独立した事業体として契約し、相互に紹介料を受け取りません。

## よくある質問

**Q. 自宅の台所で作った梅干しを道の駅で売れますか？**
A. 反復継続して販売用に製造するなら、原則として漬物製造業の許可が必要です。住居と一体の家庭の台所そのままでは施設基準を満たさず許可は下りないのが通常で、住居と区画した製造室などの設備が要ります。該当するかは所管の保健所に確認してください。

**Q. 以前から漬物を売っていました。今も許可は要りますか？**
A. 必要です。施行令の施行前から営んでいた事業者の3年間の経過措置は2024年（令和6年）5月31日で終了しました。2024年6月1日以降は、許可を受けずに販売用の漬物を製造することはできません。許可がないまま続けている場合は速やかに保健所へご相談ください。

**Q. 小規模でもHACCPの対応は必要ですか？**
A. 必要です。ただし小規模な営業者等には、取り扱う食品の特性に応じた「HACCPの考え方を取り入れた衛生管理」が認められ、厚生労働省の業種別手引書に沿って衛生管理計画を作り、日々の実施を記録する形で足ります（食品衛生法第51条）。

**Q. 許可を取らずに売るとどうなりますか？**
A. 許可を受けずに営業する行為は食品衛生法第55条第1項に違反し、同法第82条により2年以下の拘禁刑又は200万円以下の罰金の対象とされています。法人にも両罰規定（第88条）で罰金が科されることがあります。個別の該当性の判断は保健所・捜査機関の領域です。
