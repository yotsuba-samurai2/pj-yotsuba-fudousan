**結論（先に要点）**：公正証書遺言は、証人2人以上の立会いのもとで遺言者が遺言の趣旨を公証人に口授し、公証人が筆記して作成する遺言です（民法第969条）。公証人が関与し原本を公証役場が保管するため方式不備で無効になりにくく、遺言者の死亡後に家庭裁判所の検認を受ける必要がありません。公証人の手数料は公証人手数料令で定められ、財産を受け取る人ごとに目的の価額を当てはめて合算し、目的の価額の合計が1億円以下のときは遺言加算が加わります。証人には欠格事由があり、推定相続人・受遺者やその配偶者・直系血族などはなれません（民法第974条）。本記事は一般的な情報提供で、どの財産を誰に遺すべきかといった法的効果の最終判断をするものではありません。四葉グループの行政書士は、遺言の原案づくりの支援、必要書類の収集、公証役場との日程調整、証人の手配までを独立した事業体として担います。相続人間に争いがある場合の対応や法的効果の最終判断は弁護士、遺言執行後の相続登記・遺贈の登記は司法書士、相続税・納税資金の試算は税理士、相続不動産の売却は別事業体である不動産業者の領域で、それぞれ別々にご契約いただきます。

## 公正証書遺言は、自筆証書遺言と比べて何が確実なのか？

公正証書遺言は、法律の専門家である公証人が関与して作成する点に特色があります。民法第969条は、証人2人以上の立会い、遺言者による遺言の趣旨の口授、公証人による筆記と読み聞かせ（又は閲覧）、遺言者・証人の署名押印、公証人の付記・署名押印という方式を定めています。作成された原本は公証役場が保管するため、紛失・改ざんの心配がなく、方式不備で無効になるおそれが小さいのが利点です。

| 項目 | 公正証書遺言 | 自筆証書遺言 |
| --- | --- | --- |
| 作成 | 公証人が関与（民法第969条） | 遺言者が全文・日付・氏名を自書し押印 |
| 証人 | 2人以上の立会いが必要 | 不要 |
| 保管 | 公証役場が原本を保管 | 自宅保管又は法務局の保管制度 |
| 検認 | 不要 | 原則必要（法務局保管なら不要） |
| 費用 | 公証人手数料がかかる | 作成自体の費用はかからない |

自筆証書遺言は手軽ですが、方式の不備や保管の不安が残ります。両者の違いや法務局の保管制度は[自筆証書遺言と公正証書遺言の違い](/legal/column/jihitsu-kosei-yuigon)で整理しています。どちらが適するかは、財産の内容・相続人の状況・費用への考え方によって変わります。当事務所の[相続・遺言のご案内](/legal/services/inheritance)もご覧ください。

## 公証人の手数料は、財産の額でどう決まるのか？

公証人の手数料は公証人手数料令（第9条別表）で定められた公定料金で、財産を相続・遺贈で受け取る人ごとに、その人が受け取る財産の価額（目的の価額）を表に当てはめて算出し、合計します。2025年（令和7年）10月1日の改定後の金額は次のとおりです。

| 目的の価額 | 手数料 |
| --- | --- |
| 100万円以下 | 5,000円（うち50万円以下は3,000円） |
| 100万円超200万円以下 | 7,000円 |
| 200万円超500万円以下 | 13,000円 |
| 500万円超1,000万円以下 | 20,000円 |
| 1,000万円超3,000万円以下 | 26,000円 |
| 3,000万円超5,000万円以下 | 33,000円 |
| 5,000万円超1億円以下 | 49,000円 |
| 1億円超3億円以下 | 49,000円に超過額5,000万円ごとに15,000円を加算 |
| 3億円超10億円以下 | 109,000円に超過額5,000万円ごとに13,000円を加算 |

このほか、目的の価額の合計が1億円以下のときは遺言加算として13,000円が加わります。正本・謄本は電子データでの交付が1通2,500円、書面での交付が1枚300円（原本が3枚を超える場合は超過1枚につき300円を加算）です。遺言者の病床で作成する場合は手数料の50%加算、公証人が自宅・施設などへ出張する場合は日当（1日2万円、4時間以内は1万円）と交通費がかかります。例えば配偶者に6,000万円・長男に4,000万円を相続させる遺言なら、配偶者分49,000円＋長男分33,000円＝82,000円に遺言加算13,000円を足して95,000円が目安です。実際の金額は財産評価で変わるため、作成前に公証役場で確認します。相続不動産の評価は税理士・不動産の領域で、当事務所の[報酬額表](/legal/ryokin)は別に定めています。

## 証人2人は誰に頼めて、誰は証人になれないのか？

公正証書遺言には証人2人以上の立会いが必要ですが（民法第969条）、誰でも証人になれるわけではありません。民法第974条は、次の人を証人・立会人になれない欠格事由として定めています。

| 号 | 証人になれない人 |
| --- | --- |
| 第1号 | 未成年者 |
| 第2号 | 推定相続人、受遺者、並びにこれらの配偶者及び直系血族 |
| 第3号 | 公証人の配偶者、四親等内の親族、書記及び使用人 |

つまり、財産を受け取る立場の家族や、その配偶者・子などは証人になれません。適任者が身近にいないときは、公証役場が証人を紹介する運用もあります。四葉グループの行政書士は、守秘義務を負う専門家として証人の手配や証人としての立会いをお引き受けできます。誰を証人にできるかの判断は、推定相続人・受遺者の範囲の確認と結びつくため、相続関係の整理とあわせて進めるのが実務です。

## 当日までに集める書類と、公証役場での流れはどうなるのか？

公正証書遺言は、原案を固めてから公証人と事前に打ち合わせ、当日に証人2人の立会いで作成します。あらかじめ次のような書類をそろえます（公証役場により異なります）。

| 区分 | 主な書類 |
| --- | --- |
| 遺言者本人 | 印鑑登録証明書など本人確認資料 |
| 相続人へ遺す場合 | 遺言者と相続人の関係がわかる戸籍（戸籍謄本等） |
| 相続人以外へ遺贈する場合 | 受遺者の住民票など |
| 財産の資料 | 不動産の登記事項証明書・固定資産評価証明書、預貯金等の資料 |

当日は、遺言者が遺言の趣旨を公証人に口授し、公証人が筆記した内容を遺言者・証人に読み聞かせ又は閲覧させ、誤りがなければ全員が署名押印します。2025年（令和7年）10月1日からは公証人法の改正（令和5年法律第53号）で公正証書の作成手続がデジタル化され、指定された公証役場ではウェブ会議（リモート方式）の利用や電子データでの作成・交付が順次可能になりました。利用できるかは公証役場に確認します。四葉グループの行政書士は、原案づくりの支援・必要書類の収集・公証役場との日程調整を担います。

## 作った後に気が変わったら、遺言は書き換えられるのか？

遺言は、作成した後でもいつでも書き換えられます。民法第1022条は、遺言者はいつでも遺言の方式に従ってその遺言の全部又は一部を撤回できると定めています。前の遺言と後の遺言が抵触する部分は、後の遺言で撤回したものとみなされます（民法第1023条）。

| 場面 | 取扱い（根拠） |
| --- | --- |
| 内容を変えたい | いつでも新しい遺言で撤回・変更できる（民法第1022条） |
| 前後の遺言が抵触 | 抵触部分は後の遺言で撤回とみなす（民法第1023条） |
| 公正証書遺言を撤回 | 新たな遺言（公正証書・自筆いずれも可）で撤回できる |

公正証書遺言を撤回するのに、前の公正証書を物理的に破棄する必要はなく、新しい遺言で意思を示します。撤回や複数の遺言が併存するときの優劣は[遺言の撤回・抵触と複数遺言の優劣](/legal/column/yuigon-tekkai-teishoku-fukusu-yuigon-yuretsu)で整理しています。書き換えの要否は、家族構成や財産の変化を踏まえて定期的に見直すのが安心です。

## よくある質問

**Q. 公正証書遺言にすると、死亡後の検認は不要になりますか？**
A. はい。公正証書遺言は公証人が作成し原本を公証役場が保管するため、家庭裁判所の検認は不要です。自筆証書遺言は原則として検認が必要ですが、法務局の自筆証書遺言書保管制度を利用した場合は検認が不要になります。検認の要否は遺言の方式と保管方法によって変わります。

**Q. 手数料は財産の総額に一つの料率をかけて決まるのですか？**
A. いいえ。公証人手数料令では、財産を相続・遺贈で受け取る人ごとに、その人が受け取る価額を別表に当てはめて手数料を出し、合計します。目的の価額の合計が1億円以下のときは遺言加算13,000円が加わり、正本・謄本の交付や出張には別途費用がかかります。正確な額は財産評価をもとに公証役場で確認します。

**Q. 家族に証人を頼めますか？**
A. 財産を受け取る推定相続人・受遺者や、その配偶者・直系血族は証人になれません（民法第974条）。未成年者や公証人の近親者等もなれません。適任者がいないときは公証役場が証人を紹介することがあり、守秘義務を負う行政書士が証人の手配や立会いをお引き受けすることもできます。

**Q. 一度作った公正証書遺言を後から変更できますか？**
A. できます。遺言者はいつでも遺言の方式に従って全部又は一部を撤回・変更できます（民法第1022条）。前の遺言と抵触する新しい遺言を作れば、抵触部分は後の遺言で撤回したものとみなされます（民法第1023条）。前の公正証書を破棄する必要はなく、新しい遺言で意思を示します。
