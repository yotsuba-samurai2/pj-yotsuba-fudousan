**結論（先に要点）**：建設・解体・運送などの事業で生じた「他人の産業廃棄物」を、業として（反復継続して）収集・運搬するには、廃棄物の処理及び清掃に関する法律第14条第1項にもとづく都道府県知事の許可が必要です。許可を受けるには、車両・容器などの施設と申請者の能力が環境省令の基準に適合すること（第14条第5項第1号）、欠格要件（同項第2号が準用する第7条第5項第4号）に該当しないこと、そして事業を行う本人や役員が公益財団法人日本産業廃棄物処理振興センター（JWセンター）の講習会を修了していることが求められます。本記事は、産廃収集運搬業の許可の要件・欠格要件・講習・車庫や積替え保管場所の扱い・都道府県ごとの許可と更新を整理する一般的な情報提供であり、個別の許可の可否は判断しません。

## 産業廃棄物収集運搬業の許可は、どんな事業に必要なのか？

産業廃棄物とは、事業活動に伴って生じた廃棄物のうち、燃え殻・汚泥・廃油・廃プラスチック類・がれき類など、法令で定められた種類のものをいいます。これを他人から委託を受けて、業として（有償で反復継続して）収集・運搬する場合に、この許可が必要になります。

判断の分かれ目は「誰の廃棄物を運ぶか」です。

| 場面 | 許可の要否 |
| --- | --- |
| 他社が排出した産業廃棄物を委託を受けて運搬する | 収集運搬業の許可が必要 |
| 自社の事業で出た産業廃棄物を、自社で処分先へ運ぶ（自社運搬） | 原則として許可は不要（ただし運搬基準・委託基準の遵守は必要） |
| 一般家庭から出たごみ（一般廃棄物）を運ぶ | 産業廃棄物の許可では足りず、市町村の一般廃棄物収集運搬業の許可が別に必要 |

建設・解体・運送から事業を広げる場合、元請や他社の現場で出た廃棄物を運ぶのであれば「他人の産業廃棄物」に当たり、許可が要ります。四葉行政書士事務所では、行政書士業務の範囲で、許可の要否の確認、要件の整理、申請書類の作成、申請の代理を支援します。個別の許可の可否は都道府県の審査によります。

## 許可が下りない『欠格要件』とは具体的に何か？

欠格要件とは、これに一つでも当たると許可を受けられない事由です。産廃収集運搬業では、第14条第5項第2号が第7条第5項第4号を準用しており、主に次のものが定められています。

| 区分 | 内容（要旨） |
| --- | --- |
| 心身の故障 | 心身の故障により業務を適切に行えない者として環境省令で定めるもの |
| 破産 | 破産手続開始の決定を受けて復権を得ない者 |
| 刑罰（拘禁刑以上） | 拘禁刑以上の刑に処せられ、その執行を終わり、又は執行を受けることがなくなった日から5年を経過しない者 |
| 刑罰（罰金） | 廃棄物処理法など環境関連の一定の法令違反で罰金の刑に処せられ、5年を経過しない者 |
| 暴力団関係 | 暴力団員又は暴力団員でなくなった日から5年を経過しない者、暴力団員等がその事業活動を支配する者 |
| 不正・不誠実 | その業務に関し不正又は不誠実な行為をするおそれがあると認めるに足りる相当の理由がある者 |

2022年の刑法改正で懲役・禁錮は「拘禁刑」に一本化され、条文も拘禁刑以上の刑と表記されています。欠格要件は申請者本人だけでなく、法人の役員や一定の使用人などにも及びます。許可を受けた後に欠格要件に該当すると許可は取り消され、該当した場合は届出の義務もあります。過去に刑罰歴がある方は、該当の有無を早めに確認しておくことが大切です。

## 講習会の修了はいつ・誰が受ければよいのか？

許可申請には、公益財団法人日本産業廃棄物処理振興センター（JWセンター）が実施する講習会の修了証が必要です。申請の前に、修了しておく必要があります。

| 項目 | 新規許可の場合 | 更新許可の場合 |
| --- | --- | --- |
| 課程 | 産業廃棄物の収集・運搬課程（新規） | 産業廃棄物の収集・運搬課程（更新） |
| 日数の目安 | 2日間の講義＋修了試験 | 1日程度の講義＋修了試験 |
| 修了証の有効期間 | 原則5年 | 原則2年（自治体により5年とする例もある） |
| 受講する人 | 個人は事業主本人、法人は代表者又は業務を行う役員（政令で定める使用人を含む） | 同左 |

特別管理産業廃棄物（廃酸・廃アルカリ・感染性廃棄物など）を扱う場合は、別に特別管理産業廃棄物の収集・運搬課程を修了する必要があります。修了証の有効期間や更新講習の扱いは自治体の審査基準で差があるため、申請先の都道府県の最新の手引きを確認してください。

## 積替え・保管をする場合、場所の要件はどう変わるのか？

収集運搬には「積替え保管なし」と「積替え保管あり」の区分があります。

- **積替え保管なし**：排出場所から処分・再生の施設まで、途中で降ろさず直行して運ぶ形です。多くの新規許可はこの区分から始めます。
- **積替え保管あり**：途中で別の車両へ積み替えたり、一時的に保管したりする形です。この場合、保管場所について、囲い・掲示板の設置、種類ごとの分別、保管上限（数量）、飛散・流出・悪臭の防止などの基準を満たす土地が必要で、審査もより厳格になります。

なお、運搬車両を置くための車庫（駐車場）は、積替え保管場所とは別に、使用権原（自己所有か賃貸借契約か）を書面で示せることが求められます。車庫用地や積替え保管に使う土地の手配・賃貸借は、宅地建物取引業者の役割です。四葉行政書士事務所とは別事業体の四葉不動産株式会社が、独立した事業体として別契約で物件探しと契約を担当します。当事務所は紹介料を受け取りません。

## 許可はどの都道府県で取り、更新はいつ来るのか？

第14条第1項は、運搬のみを業として行う場合、許可権者を「産業廃棄物の積卸しを行う区域」を管轄する都道府県知事と定めています。つまり、積替え保管を伴わない収集運搬では、積み込む場所と荷を降ろす場所の双方の都道府県で許可が必要で、単に通過するだけの都道府県では許可は要りません。政令で定める市が独自に許可を出す区域もあります。

有効期間は5年ごとで（第14条第2項）、期間の経過で効力を失うため、期限前に更新講習を修了したうえで更新申請をします。優良産廃処理業者認定制度の基準に適合すると認定された場合は、有効期間が7年になります。

事業の広げ方によって関わる専門分野が分かれます。担当は次のとおりです。

- 産廃収集運搬業許可の要件確認・書類作成・申請代理 → 四葉行政書士事務所（行政書士）
- 車庫用地・積替え保管場所となる土地や物件の手配・賃貸借 → 四葉不動産株式会社（宅地建物取引業者）
- 法人設立・役員変更などの登記 → 司法書士
- 許可取得後の労働保険・ドライバーの労務・就業規則 → 社会保険労務士

四葉行政書士事務所と四葉不動産株式会社は別事業体です。各分野は、それぞれの資格者と独立した事業体として別々にご契約いただく前提で、当事務所は紹介料を受け取りません。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務の全体像は[許認可・各種申請サービス](/legal/services)をご覧ください。

## よくある質問

**Q. 自分の会社で出た廃棄物を自社のトラックで運ぶのにも許可は要りますか？**
A. 自社の事業で生じた産業廃棄物を自社で処分先へ運ぶ「自社運搬」は、原則として収集運搬業の許可は不要です。ただし、運搬中の飛散・流出防止など法令上の運搬基準は守る必要があります。他人（他社）の産業廃棄物を委託を受けて運ぶ場合は、業として行うものとして許可が必要です。

**Q. 許可があれば全国どこでも運搬できますか？**
A. いいえ。積替え保管を伴わない収集運搬では、産業廃棄物の積卸しを行う区域を管轄する都道府県ごとに許可が必要です。積み込む都道府県と降ろす都道府県の双方の許可が要り、単に通過するだけの都道府県では許可は要りません。運搬ルートに応じて必要な許可を確認します。

**Q. 講習会は誰が受ければよいですか？**
A. 個人事業なら事業主本人、法人なら代表者又は業務を行う役員（政令で定める使用人を含む）が、JWセンターの収集・運搬課程を修了します。新規は2日間の講義と修了試験があり、修了証には有効期間があります。申請の前に修了しておく必要があります。

**Q. 過去に罰金刑を受けたことがありますが、許可は取れますか？**
A. 欠格要件に当たるかどうかによります。廃棄物処理法など環境関連の一定の法令違反による罰金や、拘禁刑以上の刑については、一定期間（多くは5年）を経過していないと欠格要件に該当し得ます。該当の有無や個別の判断は都道府県が行いますので、申請前に確認することをおすすめします。
