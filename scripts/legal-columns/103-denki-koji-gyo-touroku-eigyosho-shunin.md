**結論（先に要点）**：電気工事を請け負って業として営むには、原則として電気工事業の業務の適正化に関する法律（昭和45年法律第96号）に基づく登録が必要です。一般用電気工作物に係る電気工事（一般用電気工事）を行う場合は登録電気工事業者（同法第3条）、自家用電気工作物に係る電気工事のみを行う場合は事業開始の10日前までに通知する通知電気工事業者（同法第17条の2）になります。建設業法第3条第1項の建設業許可を受けた建設業者が電気工事業を営むときは、登録等の規定が適用除外され、みなし登録電気工事業者（届出）又はみなし通知電気工事業者（通知）として扱われます（同法第34条）。一般用電気工事を行う営業所ごとには、第一種電気工事士、又は第二種電気工事士の免状交付後に電気工事に関し3年以上の実務経験を有する者を、主任電気工事士として置かなければなりません（同法第19条）。本記事は一般的な情報提供で、個別の事業が登録・通知のどちらに当たるか、資格要件を満たすかを判断・保証するものではありません。許認可（登録・みなし登録・通知）の申請支援は四葉グループの行政書士が独立した事業体として担い、会社設立や役員変更の商業登記は司法書士、営業所の不動産（事務所・資機材の保管場所）の確保は別事業体である不動産業者、税務は税理士の領域です。電気工事士法上の作業資格の判断は経済産業省・産業保安監督部の所管で、それぞれ別々にご契約いただきます。

## 電気工事業の「登録」「みなし登録」「通知」は何が違うのか？

出発点は「どの電気工作物を扱うか」です。電気工事業の業務の適正化に関する法律（以下「電気工事業法」）は、一般家庭や小規模店舗などの一般用電気工作物を扱う一般用電気工事を行う事業者には登録を求め（第3条）、高圧受電の工場・ビルなどの自家用電気工作物のみを扱う事業者には通知を求めています（第17条の2）。さらに、建設業許可を受けた建設業者には、登録・通知に代わる特例（みなし登録・みなし通知）が置かれています（第34条）。

| 区分 | 扱う電気工作物 | 手続（根拠） | 主任電気工事士 |
| --- | --- | --- | --- |
| 登録電気工事業者 | 一般用電気工事を行う（自家用も可） | 登録・有効期間5年（第3条） | 必要 |
| 通知電気工事業者 | 自家用電気工事のみ | 事業開始の10日前までに通知（第17条の2） | 不要 |
| みなし登録電気工事業者 | 建設業許可者で一般用電気工事を行う | 届出（第34条第4項） | 必要 |
| みなし通知電気工事業者 | 建設業許可者で自家用電気工事のみ | 通知（第34条第5項） | 不要 |

登録と通知の提出先は、1の都道府県の区域内にのみ営業所を置くなら当該都道府県知事、2以上の都道府県にまたがって営業所を置くなら経済産業大臣（産業保安監督部長）です。どちらに当たるか、どの電気工作物を扱うかで手続が分かれるため、計画の早い段階で営業所の所在地を管轄する窓口に確認することが欠かせません。なお「登録」と「作業をする資格」は別で、現場で作業するには電気工事士法の第一種・第二種電気工事士などの資格が必要です。

## 建設業許可を持っていると、電気工事業の手続はどう変わるのか？

建設業法第3条第1項の許可を受けた建設業者が電気工事業を営む場合は、電気工事業法第34条の特例がかかり、登録に関する規定（第2章）が適用除外になります。許可を受けた建設業者は、一般用電気工事を行うなら登録電気工事業者とみなされ（同条第2項）、自家用電気工事のみなら通知電気工事業者とみなされます（同条第3項）。ただし「みなされる」だけでは足りず、電気工事業を開始・変更・廃止したときは届出（同条第4項）又は通知（同条第5項）が必要です。

| 場面 | 必要な手続 |
| --- | --- |
| 建設業許可者が一般用を含む電気工事業を開始 | みなし登録電気工事業者の届出（第34条第4項） |
| 建設業許可者が自家用のみの電気工事業を開始 | みなし通知電気工事業者の通知（第34条第5項） |
| 建設業許可の更新で許可番号・許可年月日が変わった | 変更の届出 |
| 既に登録電気工事業者だった者が建設業許可を受けた | 従来の登録は効力を失う（第34条第6項）＝みなしへ切替 |

注意したいのは、みなし登録になっても一般用電気工事を行う営業所には主任電気工事士の設置義務がかかる点です。また、建設業許可そのもの（1件の電気工事の請負代金が税込500万円以上になる場合などに要る電気工事業の許可）は、電気工事業法の登録とは別の制度です。これは同じ行政書士が扱う業務ですが論点が異なるため、[建設業許可の要件（経営業務の管理責任者・専任技術者・財産的基礎）](/legal/column/kensetsugyo-kyoka-yoken-keikan-sengi-zaisan)もあわせてご確認ください。解体を伴う場合の[解体工事業の登録と建設業許可の違い](/legal/column/kaitai-koji-gyo-touroku-kensetsu-kyoka-chigai)も別の手続です。

## 営業所ごとに置く主任電気工事士には、どんな資格・実務が要るのか？

電気工事業法第19条第1項は、登録電気工事業者に対し、一般用電気工事の業務を行う営業所（特定営業所）ごとに主任電気工事士を置くことを義務づけています。主任電気工事士になれるのは、第一種電気工事士、又は第二種電気工事士の免状の交付を受けた後に電気工事に関し3年以上の実務経験を有する者です。

| 項目 | 内容（根拠） |
| --- | --- |
| 設置する場所 | 一般用電気工事を行う営業所ごと（第19条第1項） |
| 資格 | 第一種電気工事士／第二種電気工事士の免状交付後3年以上の実務経験 |
| 自ら従事する場合の例外 | 代表者等が主任電気工事士の要件を満たし自ら主として従事する営業所は別扱い（第19条第2項） |
| 欠けたとき | 欠けた日から2週間以内に新たに選任（第19条第3項） |

主任電気工事士は、一般用電気工事の作業を管理する役割を担うため、複数の営業所や他の電気工事業者との兼務は認められないのが原則です。資格の有無・実務経験の算定は電気工事士法に基づく判断で、行政書士が独占業務として代わりに判定するものではありません。免状や実務の裏づけが取れているかは、申請前の確認事項になります。

## 営業所に備える測定器具・保安体制はどこまで求められるのか？

電気工事業法第24条は、電気工事業者に対し、営業所ごとに絶縁抵抗計その他経済産業省令で定める器具を備えることを義務づけています。扱う電気工作物によって必要な器具が変わります。

| 営業所の種類 | 備える器具（経済産業省令） |
| --- | --- |
| 一般用電気工事を行う営業所 | 絶縁抵抗計、接地抵抗計、回路計（抵抗及び交流電圧を測定できるもの） |
| 自家用電気工事を行う営業所 | 上記に加え、低圧検電器、高圧検電器、継電器試験装置、絶縁耐力試験装置 |

このほか、営業所及び電気工事の施工場所ごとに氏名・名称や登録番号等を記載した標識を掲げる義務（第25条）と、営業所ごとに帳簿を備えて保存する義務（第26条）があります。器具の具体的な品目や様式は経済産業省令・各自治体の手引で定められており、品番や台数の最終的な適否は所管の窓口が判断します。「他県ではこうだった」がそのまま通用しない点は、登録申請の実務でよく問題になります。

## 登録の有効期間・更新・変更届を出し忘れるとどうなるのか？

登録電気工事業者の登録の有効期間は5年です（電気工事業法第3条第2項）。有効期間の満了後も引き続き電気工事業を営もうとするときは、更新の登録を受けなければなりません（同条第3項）。更新を失念して有効期間が切れると登録は失効し、無登録のまま営業を続けることはできません。

| 手続 | 期限・内容（根拠） |
| --- | --- |
| 登録の有効期間 | 5年（第3条第2項） |
| 更新の登録 | 有効期間の満了後も続けるなら必要（第3条第3項） |
| 登録事項の変更の届出 | 変更の日から30日以内（第10条） |
| 廃止の届出 | 電気工事業を廃止したとき |

氏名・名称、営業所、主任電気工事士などの登録事項に変更があったときは、変更の日から30日以内に届け出る必要があります（第10条）。無登録での営業や通知を怠った営業、更新切れのままの営業には罰則が定められています。手続の名称・様式・期限の細部は自治体により異なるため、満了日を管理し、変更が生じたら速やかに届け出ることが実務の要になります。

## よくある質問

**Q. 電気工事業の登録と建設業許可は、どちらを取ればよいですか？**
A. 目的が異なります。電気工事業法の登録（又は通知・みなし）は、電気工事を業として行うために必要な手続です。建設業許可は、1件の電気工事の請負代金が税込500万円以上になる場合などに必要な別制度で、建設業許可を受けても電気工事業法上の届出・通知は別途必要です。扱う電気工作物と請負金額の双方を確認して判断します。

**Q. 第二種電気工事士しかいなくても登録できますか？**
A. 一般用電気工事を行う営業所には主任電気工事士が必要で、第二種電気工事士の場合は免状交付後に電気工事に関し3年以上の実務経験が求められます（電気工事業法第19条）。要件を満たす人がいない営業所では主任電気工事士を置けず、登録の前提を欠きます。実務経験の算定は電気工事士法に基づく判断です。

**Q. 高圧のビルや工場の電気工事だけを請けるときも登録が要りますか？**
A. 自家用電気工作物に係る電気工事のみを行う場合は、登録ではなく通知電気工事業者になり、事業開始の10日前までに通知します（電気工事業法第17条の2）。この場合は主任電気工事士の設置義務はありませんが、現場の作業には電気工事士法上の資格（認定電気工事従事者・特種電気工事資格者など）が必要になります。

**Q. 登録の更新を忘れて期間が切れたらどうなりますか？**
A. 登録の有効期間は5年で、満了後も続けるには更新が必要です（電気工事業法第3条）。更新を失念すると登録は失効し、無登録のまま営業を続けることはできません。満了日を管理し、余裕をもって更新手続を行うことが大切です。登録事項に変更があったときは30日以内の届出も必要です（第10条）。
