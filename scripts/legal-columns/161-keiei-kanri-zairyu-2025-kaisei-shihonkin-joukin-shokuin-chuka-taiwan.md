**結論（先に要点）**：改正前から「経営・管理」で在留する方の更新では、2028年10月16日までの経過措置でも自動許可にはなりません。経営状況と新基準への適合見込みを説明するため、現在の証拠と今後の計画を分けて準備します。

本記事は、既に在留している経営者が2025年10月改正への対応を更新資料にどう反映するかに絞ります。新規の会社設立・在留資格取得は[経営・管理の取得総説](/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)、通常の更新での経営実態・継続性の立証は[既存の更新解説](/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)をご覧ください。個別の許否や経過措置の適用を判断・保証するものではありません。

## 既存の在留者は、2028年10月16日まで何が猶予されるのか？

既に「経営・管理」で在留している方には、経過措置があります。出入国在留管理庁の案内によれば、施行日である令和7年10月16日から3年を経過する日、すなわち令和10年（2028年）10月16日までの間は、改正後の新基準（資本金・出資総額3,000万円以上、経営経験・学位、常勤職員の雇用など）を満たさない場合も、経営状況や新基準への適合見込み等を踏まえて許否が判断されます。改正の影響をいきなり受けないための緩衝措置です。

ただし、「2028年まで何もしなくてよい」という理解は正確ではありません。経過措置は更新を保証するものではなく、新基準への適合見込みも審査されます。また、経営の実体があること、公租公課（法人税・消費税・住民税など）や社会保険を履行していること、独立した事業所を確保していることといった、従来から更新で確認される点は、経過措置とは別に引き続き見られます。更新時の事業の継続性の考え方は前掲の[経営・管理ビザの更新で問われる「事業の継続性・実体」の立証](/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)で詳しく扱っています。

| 区分 | 経過措置期間中（令和10年10月16日まで）の扱い |
| --- | --- |
| 新規申請（認定・変更） | 原則は新基準。施行前受付・スタートアップの旧基準適用例外を確認 |
| 在留中の方の更新（新基準の形式要件） | 経営状況・新基準への適合見込み等を踏まえて許否判断 |
| 経営の実体・公租公課・社会保険・事業所 | 経過措置とは別に、従来どおり確認される |

## 経過措置中の更新で、現在の実績と適合見込みをどう資料にするか？

まず在留期限・前回の申請控え・所属機関カテゴリーを確認し、入管庁の更新用提出書類一覧と照合します。以下は整理例であり、全件一律の必須書類一覧ではありません。前回からの変更は、変更日・理由・裏付け資料を対応させます。

| 確認の軸 | 現在の裏付け資料の例 | 新基準への準備として整理すること |
| --- | --- | --- |
| 事業の経営状況 | 直近年度の決算文書、直近在留期間の経営・管理活動の説明 | 前回申請との変更点、現状と計画の数字の整合 |
| 資本金等 | 登記事項証明書、払込み・出資を裏付ける記録 | 不足額、調達方法、実施予定と進捗。未実施の増資を完了済みと書かない |
| 常勤職員・日本語能力 | 雇用契約・勤務記録、在留資格等の確認資料、日本語能力の証明 | 雇用要件と日本語要件を別々に確認し、採用予定と雇用済みを区別 |
| 税・社会保険・許認可 | 納税、保険加入・納付、必要な事業許可を示す資料 | 不足資料や未履行事項を隠さず、事実と対応状況を整理 |
| 学位・経験・事業計画 | 該当する学位・経歴資料、事業計画と専門家確認資料 | 該当する基準と、まだ準備中の点・実施時期を区別 |

新基準への適合見込みは、予定表だけで許可されるという意味ではありません。決算・登記・雇用・納税資料と説明が矛盾しないか確認し、カテゴリー別の省略可否・追加資料は最新の入管案内に従います。

## 更新計画を立てる際、新規申請の基準とは何を区別するか？

新規申請は原則として改正後基準による審査です。既存在留者の更新にある経過措置を新規申請の資金・人員準備の猶予と混同しないでください。以下は更新に向けた差分確認用の比較であり、新規申請の総説ではありません。

| 項目 | 改正前の目安 | 改正後（令和7年10月16日施行） |
| --- | --- | --- |
| 資本金・出資総額 | 500万円以上（または常勤職員2人以上） | 3,000万円以上 |
| 常勤職員 | 代替要件として2人以上の選択肢あり | 1人以上の雇用を要件化 |
| 日本語能力 | 明文の基準なし | 申請者または常勤職員のいずれかが「日本語教育の参照枠」のB2相当以上 |
| 経営経験・学位 | 管理業務に従事する場合は3年以上の経験等 | 経営経験3年以上または経営管理又は事業に関連する分野の博士・修士・専門職の学位 |
| 事業計画書 | 提出 | 日本の中小企業診断士・公認会計士・税理士による確認 |

3,000万円は年商の基準ではありません。法人では株式会社の払込済資本金又は持分会社の出資総額を指し、運転経費を資本金に足して判定するものではありません。個人事業では事業所確保、職員給与1年分、設備投資等への投下総額を指します。資金要件と常勤職員1人以上の雇用要件は、いずれも必要です。

雇用要件の常勤職員は、経営・管理に従事する者以外で日本に居住する日本人、特別永住者、又は別表第二の在留資格（永住者、日本人の配偶者等、永住者の配偶者等、定住者）の方が対象です。別表第一の就労資格等の方だけでは、この1人以上の要件を満たしません。常勤性・雇用実態は個別に確認し、社会保険・雇用保険の適用手続は社会保険労務士が担います。

日本語能力の要件を満たす常勤職員には、雇用人数の要件と異なり、別表第一の在留資格の方も含まれます。申請者本人か常勤職員のいずれかが満たせばよく、両者全員にB2を求める要件ではありません。

確認者は日本の資格を持つ中小企業診断士・公認会計士・税理士です。計画の具体性・合理性・実現可能性を確認します。申請会社の役員・従業員は評価者になれませんが、外部顧問の公認会計士・税理士は対象になります。

## 更新資料の作成・登記・税務・労務は誰に依頼するか？

関係する専門家が分かれるため、それぞれ独立した事業体として別々にご契約いただくのが基本です。四葉グループの行政書士は、在留資格の申請書類の作成補助と申請取次を独立した事業体として担います。当事務所の[取扱業務](/legal/services)・[受任の流れ](/legal/nagare)・[報酬額表](/legal/ryokin)もご覧ください。各専門家とは独立した事業体として契約し、相互に紹介料を受け取りません。

| 依頼先 | 主な役割 |
| --- | --- |
| 行政書士（当事務所） | 在留資格（認定・変更・更新）の申請書類作成・申請取次（書類作成は行政書士法第1条の3。申請取次は入管の申請等取次制度に従う） |
| 司法書士 | 会社設立・役員変更・本店移転などの商業登記 |
| 税理士 | 資本金の確認の前提となる税務、法人税・消費税・決算の申告 |
| 社会保険労務士 | 常勤職員の健康保険・厚生年金・雇用保険・労災の適用手続 |
| 不動産業者（別事業体の当社） | 独立した事業所となる物件の選定・賃貸借の媒介・重要事項説明 |
| 日本の中小企業診断士・公認会計士・税理士 | 事業計画書の専門家確認 |

日本で住まいを探す際の在留資格の示し方・保証会社の利用は、別事業体・四葉不動産株式会社の[外国人の住まい探しガイド](/global)で説明しています。不動産の媒介と在留手続は別々に契約します。

## よくある質問

**Q. 2028年10月まで資料の準備を待ってよいですか？**
A. いいえ。経過措置は更新の保証や手続不要の制度ではありません。現在の経営状況と新基準への適合見込みを、更新ごとに説明できるよう準備します。

**Q. まだ実施していない増資・採用はどう書きますか？**
A. 実施済みの事実と予定を分け、時期・資金源・進捗を裏付けとともに説明します。将来計画を現在達成した要件のように書かないでください。

**Q. 経過措置中も納税・保険の資料は必要ですか？**
A. 経過措置で公的義務が免除されるわけではありません。税・社会保険・労働関係法令や必要な許認可も確認されます。具体的な提出資料はカテゴリーと最新案内により確認します。

**Q. この一覧を全部出せば更新できますか？**
A. いいえ。表は整理例です。必須書類は申請区分・カテゴリー等で異なり、追加資料を求められる場合もあります。許否は入管の審査で判断されます。
