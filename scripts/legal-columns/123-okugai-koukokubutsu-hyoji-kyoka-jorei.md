**結論（先に要点）**：店舗の看板は、その場所と大きさしだいで、屋外広告物の表示の許可が必要になります。屋外広告物の規制は屋外広告物法（昭和24年法律第189号）を枠組みとし、実際の禁止地域・許可地域・大きさや高さの基準・許可の有効期間は、各都道府県・政令市などが定める屋外広告物条例で決まります。同法第3条は都道府県が条例で良好な景観・風致の維持や公衆への危害防止のために表示・設置を禁止できる地域や物件を定められること、第4条は都道府県知事の許可を受けなければならないなどの制限を条例で定められること、第5条は広告物の形状・面積・色彩・意匠その他表示の方法の基準を条例で定められることを規定しています。看板を設置する広告業者の側には、第9条・第10条に基づき条例で設けられる屋外広告業の登録（営業所ごとの業務主任者の選任を含む）が関係します。本記事は一般的な情報提供で、個別の看板が許可対象か・基準に適合するかの最終判断をするものではありません。四葉グループの行政書士は、屋外広告物の表示許可申請と屋外広告業の登録申請の支援を、独立した事業体として担います。一定規模の工作物としての建築確認や構造の安全は建築士、看板の製作・施工は広告施工業者、店舗の物件・テナント探しは別事業体である当社（不動産業者）の領域で、それぞれ別々にご契約いただきます。当事務所は各専門家から紹介料を受け取りません。

## 屋外広告物の許可が要るのは、どんな看板？

屋外広告物とは、常時又は一定の期間継続して屋外で公衆に表示されるもので、看板・立看板・はり紙・はり札、広告塔・広告板、建物その他の工作物等に掲出・表示されたものをいいます（屋外広告物法第2条第1項）。店舗の壁面看板、袖看板（突き出し看板）、自立看板、のぼり、店先の立看板は、いずれもこの屋外広告物に当たり得ます。許可が要るかどうかは、場所（どの地域か）と大きさ・高さで決まり、その具体は管轄の条例によります。

| 看板の例 | 屋外広告物に当たるか | 許可の要否の目安 |
| --- | --- | --- |
| 壁面看板・袖看板 | 当たる | 設置場所と大きさにより許可が必要なことが多い |
| 自立看板・広告塔 | 当たる | 高さ・面積が大きいほど許可の対象になりやすい |
| のぼり・店頭の立看板 | 当たる | 条例で簡易な広告物として扱い・制限がある場合がある |
| 店舗内に向けた室内の表示 | 屋外で公衆に表示されないため当たらないことが多い | 条例で確認 |

自店舗の名称や営業内容を示す「自家用広告物」であっても、規制の対象から当然に外れるわけではありません。条例で一定面積までを許可不要とする扱いを設けている地域もありますが、基準は地域ごとに異なります。開業時の他の店舗系の届出（例として飲食店なら[飲食店の営業許可と施設基準](/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)）とは別の制度なので、看板は看板として確認が必要です。受任の進め方は[受任の流れ](/legal/nagare)をご覧ください。

## 禁止地域・許可地域と、大きさ・高さの基準は？

屋外広告物法は、地域や場所を「禁止」と「許可（制限）」に分けて条例で定める枠組みを置いています。第3条は、良好な景観・風致の維持のために必要があると認めるときに表示・設置を禁止できる地域や場所（第1項）、橋りょう・街路樹・銅像・記念碑などの物件への表示の禁止（第2項）、公衆に対する危害を防止するために必要があるときの禁止（第3項）を、都道府県が条例で定められるとしています。第4条は、禁止地域以外について都道府県知事の許可を受けなければならないなどの制限を、第5条は広告物の形状・面積・色彩・意匠その他表示の方法の基準や掲出物件の形状その他設置の方法の基準を、いずれも条例で定められるとしています。

| 法の条文 | 条例で定められること |
| --- | --- |
| 第3条 | 禁止地域・禁止場所、禁止物件（橋りょう・街路樹等）、危害防止のための禁止 |
| 第4条 | 許可を要する地域・場所、知事等の許可その他の制限 |
| 第5条 | 大きさ（面積）・高さ・形状・色彩・意匠など表示の方法の基準 |
| 第7条 | 違反広告物への表示・設置の停止命令、除却その他必要な措置 |

このため、「何平方メートルまで」「地上何メートルまで」といった具体的な数値基準や、どの用途地域が禁止・許可のどちらに当たるかは、全国一律ではなく、設置場所を管轄する屋外広告物条例を直接確認する必要があります。景観法に基づく景観地区や、文化財・自然公園の周辺では、より厳しい扱いになることがあります。基準に適合するかの判断は条例の読み取りを伴うため、申請支援の範囲で行政書士がお手伝いします。費用の目安は[報酬額表](/legal/ryokin)で別に定めています。

## 許可の申請先・有効期間・更新はどうなる？

許可の申請先は、設置場所を管轄する都道府県・政令指定都市・中核市・景観行政団体などで、申請の窓口・様式・添付書類（位置図・設計図・意匠図・構造や強度に関する書類など）や有効期間・更新の扱いは条例で定められます。許可には有効期間が設けられ、期間満了後も継続して表示するには更新の許可が必要とされるのが一般的ですが、期間の長さは条例によって異なります。

| 確認する項目 | 考え方 |
| --- | --- |
| 申請先 | 設置場所を管轄する都道府県・政令市・中核市・景観行政団体など |
| 添付書類 | 位置図・付近見取図・意匠図・寸法・構造や強度に関する書類など（条例で指定） |
| 有効期間 | 条例で定める期間（地域により異なる）。満了後の継続は更新の許可が必要なことが多い |
| 変更・除却 | 内容を変えるとき・撤去するときの届出や手続も条例で定められる |

具体的な有効期間の年数や手数料の額は条例ごとに異なるため、本記事では一律の数値を示しません。設置予定地の条例・最新の運用を書く直前に確認するのが確実です（未確認の数値は書かない方針です）。屋外広告物の表示許可の申請書類の作成・提出の代行は、官公署に提出する書類の作成・手続として行政書士が支援しますが、個別の許可の可否の最終判断は許可権者（行政庁）が行います。当事務所の[取扱業務のご案内](/legal/services)もあわせてご覧ください。

## 看板を設置する業者に必要な「屋外広告業の登録」とは？

屋外広告業とは、屋外広告物の表示又は掲出物件の設置を行う営業をいいます（屋外広告物法第2条第2項）。都道府県は、条例で、屋外広告業を営もうとする者に都道府県知事の登録を受けなければならないとする登録制度を設けることができます（第9条）。その条例には、登録の有効期間・登録の要件・業務主任者の選任・登録の取消しや営業停止などの事項を定めるものとされ（第10条第1項）、有効期間は5年とすること、営業所ごとに業務主任者を選任することなどの基準が置かれています（第10条第2項）。看板を自分で製作・設置して事業として請け負う広告施工業者は、この登録の対象になります。

| 立場 | 必要になり得る手続 |
| --- | --- |
| 看板を出す店舗・事業者 | 屋外広告物の表示の許可（第4条に基づく条例） |
| 看板を製作・設置する広告業者 | 屋外広告業の登録（第9条・第10条に基づく条例） |
| 登録業者の各営業所 | 業務主任者の選任（講習会修了者・試験合格者等から） |

店舗を出す側の「表示許可」と、設置業者側の「屋外広告業の登録」は別の手続です。看板を外注する場合でも、表示許可は原則として広告物を表示する者（店舗側）が関わるため、どちらの手続が誰に必要かを整理してから進めると行き違いが起きにくくなります。登録申請・業務主任者に関する支援も行政書士が担います。関係する事業者は、それぞれ独立した事業体として別々にご契約いただくのが基本で、当事務所は各専門家から紹介料を受け取りません。

## よくある質問

**Q. 自分の店の名前を出すだけの看板でも、許可は必要ですか？**
A. 場所と大きさによります。自店の名称・営業内容を示す自家用広告物であっても、屋外広告物法第4条に基づく条例の許可地域にあり、条例で定める大きさを超えれば許可が必要になります。条例で一定面積までを許可不要とする地域もありますが、基準は地域ごとに異なるため、設置場所を管轄する屋外広告物条例を確認してください。

**Q. のぼりや店頭の立看板にも規制はありますか？**
A. のぼりや立看板も屋外広告物に当たり得ます（屋外広告物法第2条第1項）。はり紙・はり札・立看板などは、条例で簡易な広告物として表示の方法や場所が制限され、違反物は除却の対象になることがあります（第7条）。歩道や道路上に置く場合は道路占用の可否など別の規律も関わるため、設置場所の条例と管理者の扱いを確認してください。

**Q. 看板の設置を業者に頼めば、許可の手続も業者がやってくれますか？**
A. 必ずしもそうではありません。店舗側が負う「表示の許可」（第4条の条例）と、設置業者が負う「屋外広告業の登録」（第9条・第10条の条例）は別の手続です。表示の許可は広告物を表示する者が関わるため、誰がどの手続を担うかを契約前に整理しておくと安全です。申請書類の作成・提出の支援は行政書士が独立した事業体として行います。

**Q. 許可を受けずに看板を出すと、どうなりますか？**
A. 条例に違反した広告物については、都道府県知事等が表示・設置の停止を命じ、又は相当の期限を定めて除却その他必要な措置を命ずることができます（屋外広告物法第7条）。簡易な違反物は即時に除却される扱いが置かれている場合もあります。過料などの罰則が条例に定められていることもあるため、設置前に許可の要否を確認することをおすすめします。
