**結論（先に要点）**：ペット（犬・猫など）は法律上「物」で権利能力がないため、ペット自身に財産を遺したり、ペットを遺言の受遺者・信託の受益者にしたりはできません。残されるペットの世話を託す仕組みは主に二つです。一つは負担付遺贈で、世話をしてくれる人に財産を遺贈し、その負担として飼育を義務づけます（民法第1002条）。義務が履行されないときは、相続人が催告をし、履行がなければ遺言の取消しを家庭裁判所に請求できます（民法第1027条）。もう一つはペットのための信託で、受託者に財産を託し、飼育費を受け取る受益者（世話をする人など）のために管理・給付させます（信託法第2条・第3条）。受益者を定めない目的信託は契約又は遺言でのみ設定でき、存続期間は20年までです（信託法第258条・第259条）。本記事は一般的な情報提供で、個別の遺言や契約が有効かの最終判断をするものではありません。四葉グループの行政書士は、負担付遺贈の遺言や信託契約の文案づくりの支援を、独立した事業体として担います。遺言・信託契約の公正証書化は公証人、遺留分侵害や受遺者・相続人の紛争は弁護士、信託に不動産を組み入れる場合や死亡後の名義変更の登記は司法書士、相続税・受贈益の課税は税理士、相続不動産の売却・活用は別事業体である不動産業者（当社）の領域で、それぞれ別々にご契約いただきます。当事務所は各専門家から紹介料を受け取りません。

## ペットに直接財産は遺せないのか、どんな仕組みなら世話を託せるのか？

日本の法律では、ペットは「物」として扱われ、権利能力がありません。そのため、ペットに直接お金を遺すことも、ペットを遺言で財産を受け取る受遺者にすることも、信託で利益を受ける受益者にすることもできません。残されるペットのためにできるのは、「世話をしてくれる人」に財産を渡しつつ、飼育という義務や目的を結びつける設計です。

| 仕組み | 誰に財産を渡すか | 根拠 |
| --- | --- | --- |
| 負担付遺贈 | 世話をする人（受遺者）に遺贈し、飼育を負担とする | 民法第1002条 |
| ペットのための信託 | 受託者に託し、受益者（世話をする人等）のために給付 | 信託法第2条・第3条 |
| 目的信託（受益者の定めのない信託） | 受託者に託し、飼育という目的のために管理 | 信託法第258条（存続期間20年・第259条） |

遺言は、遺言者の死亡の時から効力を生じます（民法第985条）。つまり遺言による手当ては亡くなった後に働くため、入院・施設入所など生前の局面には、別の仕組みと組み合わせて備えます。生前の事務を託す選択肢は、おひとりさまの[死後事務委任契約の基本](/legal/column/shigojimu-inin-keiyaku-ohitorisama)や任意後見とあわせて考えると整理しやすくなります。遺言・契約の文案づくりは当事務所の[相続・遺言のご案内](/legal/services/inheritance)でも扱っています。

## 負担付遺贈と『ペット信託』は何がどう違うのか？

どちらも「世話をしてもらう」ことを財産と結びつける点は同じですが、お金の管理のされ方と、約束を守らせる仕組みが異なります。

| 観点 | 負担付遺贈 | ペットのための信託 |
| --- | --- | --- |
| 仕組み | 受遺者に財産を遺贈し、飼育を負担とする | 受託者に財産を託し、飼育費を給付させる |
| 財産の管理 | 受遺者が自分の財産として管理 | 信託財産として受託者が分別管理 |
| 開始時期 | 遺言者の死亡後（遺言） | 契約なら生前から、遺言なら死亡後 |
| 守らせる手段 | 履行しなければ遺言の取消しを家裁に請求（民法第1027条） | 信託の定め・信託監督人・受益者代理人などで監督 |
| 根拠 | 民法第1002条 | 信託法第2条・第3条 |

負担付遺贈を受けた者は、遺贈の目的の価額を超えない限度でのみ飼育の義務を負います（民法第1002条第1項）。受遺者が遺贈を放棄したときは、負担の利益を受けるべき者が自ら受遺者となることができます（同条第2項）。一方、信託は財産を信託財産として切り分けて受託者に管理させるため、飼育費が受託者個人の債務や相続に巻き込まれにくい利点があります。家族を受託者とする設計の全体像は[家族信託の行政書士の役割と組成](/legal/column/kazoku-shintaku-gyosei-yakuwari-kumisei)もご覧ください。

## 世話をしてもらう人（受遺者・受託者）に飼育を守らせるにはどう書けばよいか？

「誰が・どのペットを・どのように世話するか」を具体的に書き、守られなかったときの手当てまで定めておくことが要点です。負担付遺贈では、飼育の内容を負担として明記し、履行しないときの対応を想定します。

| 書いておく事項 | 具体例 |
| --- | --- |
| 対象のペット | 個体を特定（名前・種類・特徴・登録番号など） |
| 飼育の内容 | 居住環境、通院・ワクチン、食餌、看取りの方針 |
| 受遺者・受託者 | 引き受ける人と、引き受けない場合の次順位 |
| 監督の仕組み | 遺言執行者、信託監督人・受益者代理人の指定 |
| 不履行時 | 負担付遺贈は履行の催告と遺言の取消し請求（民法第1027条） |

負担付遺贈で受遺者が飼育義務を果たさないときは、相続人が相当の期間を定めて履行を催告し、それでも履行がないときは、その負担付遺贈に係る遺言の取消しを家庭裁判所に請求できます（民法第1027条）。信託では、受益者が高齢・不在でも監督が働くよう、信託監督人や受益者代理人を定めておくのが実務です。これらの文案づくりは行政書士が支援しますが、個別の有効性の最終判断は資格者が行います。進め方は[受任の流れ](/legal/nagare)をご覧ください。

## 飼育費はいくら・どう渡すのが現実的で、余った財産はどう扱うのか？

飼育費は、ペットの平均余命・医療費・世話の対価を見積もって決めます。渡し方は、負担付遺贈なら一括で遺贈し、信託なら必要なときに分けて給付する設計が選べます。

| 項目 | 考え方 |
| --- | --- |
| 金額の見積り | 平均余命×年間の食餌・医療・世話の費用に予備を加える |
| 渡し方（遺贈） | 受遺者へ一括で遺贈し、飼育を負担とする |
| 渡し方（信託） | 受託者が管理し、必要な時期に飼育費として給付 |
| 余剰の扱い | ペットの死亡後の残余財産の帰属先をあらかじめ定める |
| 対価 | 世話の手間に対する謝礼を別に定めることも可能 |

ペットが亡くなった後に信託財産や遺贈財産が残る場合に備え、残余の帰属先（別の人や団体など）を定めておきます。目的信託（受益者の定めのない信託）を使うときは、存続期間が20年を超えられない制限がある点に注意します（信託法第259条）。金額や渡し方は、相続人の遺留分や課税にも影響するため、税理士・弁護士と役割を分けて検討します。当事務所の費用の目安は[報酬額表](/legal/ryokin)で別に定めています。

## 公正証書にする意味と、遺言執行者・信託監督人の役割は？

遺言や信託契約を公正証書にしておくと、方式の不備で無効になりにくく、原本が公証役場に保管され、紛失・改ざんの心配が小さくなります。負担付遺贈を公正証書遺言にすれば、死亡後の家庭裁判所の検認も不要です。公正証書遺言の作り方や公証人手数料は[公正証書遺言の作り方・証人・手数料](/legal/column/kosei-shosho-yuigon-koshonin-shonin-hiyo)で整理しています。

| 役割 | 内容 |
| --- | --- |
| 公証人 | 遺言・信託契約の公正証書化（作成・原本保管） |
| 遺言執行者 | 遺言の内容を実現する（受遺者への引渡し・飼育の見守り等） |
| 信託監督人 | 受益者のために受託者を監督する（信託法） |
| 受益者代理人 | 受益者に代わって権利を行使する（信託法） |

飼育を続けてもらえるかを見届ける仕組みとして、遺言では遺言執行者、信託では信託監督人や受益者代理人を置くのが安心です。これらの指定や文案づくりは行政書士が支援し、公正証書化は公証人が行います。信託契約・遺言のいずれを選ぶか、両方を組み合わせるかは、生前の備え（任意後見・死後事務委任）とあわせて設計します。

## 遺留分・相続税・登記で、弁護士・司法書士・税理士へ何を振るのか？

ペットのための手当ては、多くの財産を特定の人へ渡す設計になりやすく、他の相続人の遺留分や課税、不動産があれば登記が関係します。関係する専門家は、それぞれ独立した事業体として別々にご契約いただくのが基本です。

| 依頼先 | 主な役割 |
| --- | --- |
| 行政書士（当事務所） | 負担付遺贈の遺言・信託契約の文案づくりの支援 |
| 公証人 | 遺言・信託契約の公正証書化 |
| 弁護士 | 遺留分侵害額の請求（民法第1046条）、受遺者・相続人間の紛争、法的効果の最終判断 |
| 司法書士 | 信託に不動産を組み入れる場合の信託の登記、死亡後の名義変更の登記 |
| 税理士 | 相続税・受贈益の課税の試算 |
| 不動産業者（別事業体の当社） | 相続不動産の売却・活用の相談 |

財産の渡し方が他の相続人の遺留分を侵害する場合は、遺留分侵害額に相当する金銭の支払請求（民法第1046条）が問題になり、これは弁護士の領域です。信託財産に不動産を入れるときは信託の登記が必要で、司法書士が担います。相続不動産の売却が絡む場合は、別事業体の不動産業者による[相続不動産の相談窓口](/souzoku)もご利用いただけます。当事務所は各専門家と独立した事業体として契約し、相互に紹介料を受け取りません。個別の有効性や課税の最終判断は、面談のうえ資格者が行います。

## よくある質問

**Q. ペットに直接お金を遺すことはできますか？**
A. できません。ペットは法律上「物」で権利能力がないため、ペット自身に財産を遺したり、受遺者・受益者にしたりはできません。残されるペットの世話は、世話をする人に財産を渡しつつ飼育を義務づける負担付遺贈（民法第1002条）や、受託者に財産を託すペットのための信託（信託法第2条・第3条）で託します。

**Q. 負担付遺贈とペット信託は、どちらが安心ですか？**
A. 一概には言えません。負担付遺贈は遺言で完結し手軽ですが、お金は受遺者の財産として管理され、守らせる手段は履行の催告と遺言の取消し請求（民法第1027条）になります。信託は財産を信託財産として分別管理でき、信託監督人などで継続的に監督できますが、組成の手間がかかります。家族構成や財産に応じて選びます。

**Q. ペットが亡くなった後に残ったお金はどうなりますか？**
A. あらかじめ残余財産の帰属先を定めておきます。定めがないと相続や信託の清算の規律に従って処理されます。受益者の定めのない目的信託を使う場合は、存続期間が20年を超えられない制限（信託法第259条）にも注意して設計します。

**Q. 遺留分や相続税はどう考えればよいですか？**
A. 特定の人へ多くの財産を渡すと、他の相続人の遺留分侵害額の請求（民法第1046条）が問題になることがあり、これは弁護士の領域です。相続税・受贈益の課税は税理士、不動産を信託に入れる場合の登記は司法書士が担います。行政書士は文案づくりを支援し、各専門家とは独立した事業体として別々にご契約いただきます。
