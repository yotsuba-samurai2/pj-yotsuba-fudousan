**結論（先に要点）**：在留資格「経営・管理」の更新では、新規のときに見た「これから事業を始められるか」ではなく、「実際に事業が継続して行われ、経営の実体があるか」が中心に問われます。判断の資料は、直近の決算、法人税・消費税や住民税など公租公課の納付状況、社会保険の加入、独立した事業所の実在、今後の事業計画です。とくに決算は、出入国在留管理庁が示す事業の継続性の考え方に沿って、直近2期の損益と債務超過の有無で見られます。根拠は出入国管理及び難民認定法の別表第一の二「経営・管理」と、同法第七条第一項第二号の基準を定める省令です。さらに令和7年（2025年）10月16日施行の改正で資本金・出資総額3,000万円以上などの新基準が加わりましたが、既に在留している方の更新には令和10年10月16日までの経過措置があります。本記事は一般的な情報提供で、個別の更新が許可されるかを判断・保証するものではありません。入管への申請取次は四葉グループの行政書士が独立した事業体として担い、法人税・決算の申告は税理士、役員変更などの登記は司法書士、社会保険・雇用保険の手続は社会保険労務士、事業所物件は別事業体の不動産が扱います。それぞれ別々にご契約いただきます。

## 経営・管理ビザの更新は、新規設立のときと何が変わるのか？

在留資格「経営・管理」は、出入国管理及び難民認定法の別表第一の二に掲げる「本邦において貿易その他の事業の経営を行い又は当該事業の管理に従事する活動」に対応します。新規（認定・変更）のときは、会社を作り、事業所を確保し、事業計画が成り立つかという「スタートできるか」が中心でした。更新では、その計画が実際に動いているか——売上が立ち、納税や社会保険が履行され、経営者本人が日常的に経営しているか——という「続いているか」が問われます。見る資料の重心が、計画書から決算書・納税証明書へ移るイメージです。

あわせて、令和7年（2025年）10月16日施行の改正で基準そのものが引き上げられました。新規設立の要件の全体像は[中国・台湾の起業家が「経営・管理」在留資格を取るには](/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)で整理していますが、更新との関係では次の点が重要です。

| 局面 | 主に問われること |
| --- | --- |
| 新規（認定・変更） | 事業所の確保、事業計画の実現可能性、資本金・出資総額などの形式要件 |
| 更新 | 事業の継続性・実体、直近の決算、公租公課・社会保険の履行、経営者本人の関与 |
| 2025年10月16日改正 | 資本金・出資総額3,000万円以上、常勤職員1人以上、申請者または常勤職員の日本語能力（B2相当以上）、経営経験3年以上または学位、事業計画の専門家確認 |
| 経過措置 | 既に在留中の方の更新は令和10年10月16日まで、新基準を満たさないことだけを理由に不許可としない |

## 「事業の継続性・実体」は、どんな資料で立証するのか？

更新で確認されるのは、形式より中身です。出入国在留管理庁の資料では、業務の大半を外部に委託し経営者本人が日常的に経営していない場合は「経営・管理」に当たらないとされ、事業所も原則として自宅との兼用は認められません。公租公課の履行も重視され、雇用保険・労災保険、健康保険・厚生年金保険の加入と保険料の納付、国税・地方税（法人税・消費税・法人住民税・法人事業税など）の納付状況が確認されます。

| 立証したいこと | 代表的な資料 |
| --- | --- |
| 事業が動いていること | 直近の決算書（貸借対照表・損益計算書）、確定申告書の控え |
| 納税を履行していること | 法人税・消費税・住民税などの納税証明書 |
| 社会保険を履行していること | 健康保険・厚生年金、雇用保険・労災の加入・納付の記録 |
| 事業所が実在すること | 賃貸借契約書、所在地の写真、看板・表札、独立性が分かる資料 |
| 今後も続くこと | 今後の事業計画書、予想収益の根拠資料 |

これらは単年度の数字だけでなく、2期分の推移で見られます。許認可が必要な事業なら、その取得状況を示す資料の提出も求められます。正当な理由なく長期間出国していると、経営者としての関与が疑われ消極的な要素になり得ます。

## 赤字決算や事務所の実態不足は、更新にどう響くのか？

赤字だからといって直ちに不許可になるわけではありません。出入国在留管理庁の「外国人経営者の在留資格基準の明確化について」（平成17年8月策定・令和2年8月改定）は、直近2期の決算に応じて事業の継続性の見方を整理しています。要点を表にすると次のとおりです。

| 直近2期の決算状況 | 事業の継続性の扱い |
| --- | --- |
| 売上総利益があり、直近期末に欠損金がない（剰余金がある、または剰余金も欠損金もない） | 継続性ありと認められる。当期純損失でも欠損金が生じなければ可 |
| 売上総利益はあるが、欠損金があり、債務超過ではない | 原則あり。今後1年間の事業計画書・予想収益の資料を提出。必要に応じ第三者の評価書 |
| 直近期末のみ債務超過（その前期末は債務超過でない） | 1年以内に債務超過を解消する見通しを含め、中小企業診断士・公認会計士などの第三者が評価した書面が必要 |
| 直近期末・前期末とも債務超過 | 原則として継続性は認められない |
| 直近2期とも売上総利益がない（売上総損失） | 原則として継続性は認められない |

ポイントは、赤字でも債務超過に至っていないか、至っても1年以内に解消の見通しを第三者評価で示せるか、という点です。事務所については、自宅兼用や名義だけの住所では実体を欠くと見られやすく、独立した事業所の確保が前提になります。業務を丸ごと外部委託し、経営者本人が経営に関与していない形も、更新では不利に働きます。

## 更新・変更の提出書類と申請取次は、誰が担えるのか？

在留期間の更新は、現在の在留期間の満了前に、本人が居住地を管轄する地方出入国在留管理局へ申請するのが原則です。行政書士は、出入国在留管理庁へ届け出た申請取次行政書士として、行政書士法第1条の3に基づき、本人に代わって申請書や資料を提出する申請取次を担えます。これは本人の出頭を一部省くための制度で、許可そのものを保証するものではありません。

| 書類の例 | 内容 |
| --- | --- |
| 在留期間更新許可申請書・写真 | 所定様式。活動内容に応じた区分 |
| 決算文書・確定申告書の控え | 直近期（必要に応じ前期も） |
| 納税証明書・社会保険の資料 | 公租公課・社会保険の履行状況 |
| 登記事項証明書・事業所の資料 | 会社の存在、事業所の実在 |
| 事業計画書・予想収益の資料 | 継続性を補強する場合 |

経過措置の期間中でも、経営の専門家による評価文書の提出を求められることがあります。永住への切り替えを視野に入れるなら、納税・社会保険を継続して履行してきた記録が効いてきます。永住の考え方は[中国・台湾の専門職が日本で永住許可を申請するには](/legal/column/eiju-kyoka-shinsei-chuka-taiwan-senmonshoku)もあわせてご確認ください。

## 入管申請（行政書士）と、税務・登記・労務はどこで線を引くのか？

関係する専門家が分かれるため、それぞれ独立した事業体として別々にご契約いただくのが基本です。四葉グループの行政書士は、在留期間更新・変更の申請書類の作成補助と申請取次を、独立した事業体として担います。

## よくある質問

**Q. 直近の決算が赤字でした。更新はもう無理ですか？**
A. 赤字だけで直ちに不許可になるわけではありません。出入国在留管理庁は直近2期の決算で事業の継続性を見ており、赤字でも債務超過に至っていなければ、今後1年間の事業計画書などで補強できる場合があります。債務超過になった場合も、1年以内に解消する見通しを中小企業診断士・公認会計士などが評価した書面があれば考慮されます。2期連続の債務超過や売上総損失は原則として認められにくくなります。

**Q. 事務所を自宅と兼用しても更新できますか？**
A. 事業所は原則として自宅との兼用は認められないとされています。経営・管理では独立した事業所の実在が前提で、更新でも賃貸借契約書や所在地の写真などで実体が確認されます。住所を借りているだけで実体を欠く場合は、不利に働きます。物件の確保は別事業体の不動産が扱い、契約の内容は宅地建物取引士が重要事項説明を行います。

**Q. 2025年10月の改正で資本金3,000万円が必要になりました。いま在留中でも更新で満たさないとダメですか？**
A. 既に「経営・管理」で在留している方の更新には、令和10年（2028年）10月16日までの経過措置があります。この間は、新基準（資本金・出資総額3,000万円以上など）を満たさないことだけを理由に不許可とはされず、経営状況や今後満たす見込みなどで総合的に判断されます。ただし、経営の実態・納税・社会保険の履行や独立した事業所の確保は、経過措置とは別に従来どおり確認されます。

**Q. 更新の申請は本人が入管へ行かないとできませんか？**
A. 出入国在留管理庁に届け出た申請取次行政書士が、行政書士法第1条の3に基づき、本人に代わって申請書や資料を提出する申請取次を担えます。本人の出頭を一部省けますが、これは手続上の取次であって、許可そのものを保証するものではありません。許否は入管の審査によります。
