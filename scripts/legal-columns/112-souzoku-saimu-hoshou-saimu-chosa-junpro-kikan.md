**結論（先に要点）**：相続する借金・保証債務は、契約書・督促状・通帳・信用情報で調べます。単純承認・限定承認・相続放棄の選択には民法第915条の3か月の熟慮期間があり、間に合わなければ家庭裁判所に伸長を申し立てます。家裁への申述・申立書類の作成は行政書士の業務範囲外です。

**情報確認日：2026年10月12日**。本記事は、プラス財産よりマイナス（借金・連帯保証）が多いかもしれない相続で、何をどう調べ、どの手続を誰に頼むかを整理します。制度の全体像は[相続放棄・限定承認の基本](/legal/column/souzoku-hoki-gentei-shonin)、財産の棚卸しは[相続財産目録の作り方](/legal/column/souzoku-zaisan-mokuroku)をご覧ください。

## 相続する借金や保証債務は、どうやって調べるのか？

被相続人の債務は一か所にまとまっていません。次の資料を突き合わせて洗い出します。

| 調べる先 | 分かること |
| --- | --- |
| 契約書・金銭消費貸借証書・保証契約書 | 借入・保証の相手と金額 |
| 郵便物（請求書・督促状・催告書） | 継続中の債務や滞納 |
| 預貯金通帳・口座の引落し履歴 | 返済・リース・保証料の支払 |
| 信用情報機関への開示請求 | 貸金・クレジット・銀行取引の登録情報 |

信用情報は、CIC・JICC・全国銀行個人信用情報センターに登録されています。法定相続人が亡くなった方の情報の開示を請求できる場合がありますが、必要書類（戸籍など）や可否・方法は各機関で異なります。請求前に各機関の最新案内で確認してください。民法第915条第2項により、相続人は承認・放棄の前に相続財産を調査できます。

## 連帯保証人の地位は相続されるのか？

通常の保証債務・連帯保証債務は金銭債務として相続人に承継され、法定相続分に応じて分かれるのが原則です。一方、限度額や期間を定めない継続的な保証には別の扱いがあります。

| 保証の種類 | 相続の扱い（原則） |
| --- | --- |
| 特定の債務の保証・連帯保証 | 承継される |
| 個人根保証契約 | 主たる債務者または保証人の死亡で元本が確定（民法第465条の4第1項第3号）。死亡時までの確定分を承継 |
| 身元保証 | 一身専属とされ、原則として承継されない（確定済みの具体的賠償は別） |

主たる債務者の委託を受けた保証人は、債権者に残額等の情報提供を請求できます（民法第458条の2。2020年〔令和2年〕4月1日施行）。被相続人が生前に保証していた債務の残高確認の手がかりになります。保証の具体的な効力や範囲の判断は弁護士に相談してください。

## 単純承認・限定承認・相続放棄はどう選ぶのか？

| 選択 | 内容 | 根拠 |
| --- | --- | --- |
| 単純承認 | 権利義務を無限に承継。法定単純承認となる場合がある | 民法第920条・第921条 |
| 限定承認 | 得た財産の限度でのみ債務・遺贈を弁済 | 民法第922条〜第924条 |
| 相続放棄 | 初めから相続人でなかったものとみなす | 民法第938条・第939条 |

限定承認は、共同相続人の全員が共同してのみできます（第923条）。第915条第1項の期間内に相続財産の目録を作成して家庭裁判所に提出し、限定承認する旨を申述します（第924条）。相続放棄は家庭裁判所に申述します（第938条）。財産を処分したり、期間内に手続をしなかったりすると、法定単純承認になることがあります（第921条）。相続放棄をした人が放棄時に財産を現に占有していれば、引渡しまで保存義務を負います（第940条。令和3年改正・2023年〔令和5年〕4月1日施行）。

## 3か月の熟慮期間はいつから数えるのか？間に合わないときは？

熟慮期間は、自己のために相続の開始があったことを知った時から3か月です（第915条第1項）。期間内に判断できないときは、家庭裁判所に期間の伸長を申し立てられます。

起算点には例外があります。最高裁昭和59年4月27日判決は、相続財産が全く存在しないと信じ、そう信じたことに相当な理由がある場合には、相続財産の全部または一部の存在を認識した時または通常認識しうべき時から起算するとしました。ただし適用の可否は事案ごとの評価であり、断定はできません。後から多額の借金が判明したケースの扱いは、司法書士・弁護士に相談してください。

## 誰に何を頼むのか？（家裁への申述・債務整理の振り先）

| 依頼先 | 担当する範囲 |
| --- | --- |
| 四葉行政書士事務所 | 相続財産・債務の調査、相続財産目録の作成支援 |
| 司法書士・弁護士 | 相続放棄・限定承認・熟慮期間伸長の家裁への申述・申立書類の作成 |
| 弁護士 | 債務整理・訴訟、保証債務の効力や範囲の判断 |
| 税理士 | 相続税・みなし譲渡所得の試算 |
| 司法書士 | 相続登記 |

**家庭裁判所に提出する申述書・申立書の作成は、行政書士の業務範囲外です。** 四葉行政書士事務所、四葉社会保険労務士事務所、四葉不動産株式会社はそれぞれ別事業体で、独立した事業体として受任します。各分野の担当者と別々にご契約いただき、各受任者が直接請求・入金を受けます。当事務所は紹介料を受け取りません。

[相続手続サポート](/legal/services/inheritance)、[受任の流れ](/legal/nagare)、[報酬額表](/legal/ryokin)をご確認ください。相続不動産の売却は別契約の[相続不動産相談](/souzoku)で扱います。

## よくある質問

**Q. 借金の有無はどう調べればよいですか？**
A. 契約書・督促状・通帳の引落しを確認し、信用情報機関（CIC・JICC・全国銀行個人信用情報センター）への開示も検討します。法定相続人が亡くなった方の情報を請求できる場合がありますが、必要書類や方法は各機関の最新案内で確認してください。

**Q. 連帯保証も相続されますか？**
A. 通常の保証・連帯保証は原則として承継されます。個人根保証契約は保証人等の死亡で元本が確定し、身元保証は原則承継されません。具体的な効力・範囲は弁護士に相談してください。

**Q. 3か月を過ぎたら必ず単純承認ですか？**
A. 期間徒過は法定単純承認の一事由ですが、起算点には最高裁昭和59年4月27日判決の例外があり、間に合わないときは家庭裁判所への期間伸長の申立てもあります。適用の可否は事案ごとです。

**Q. 相続放棄の書類は行政書士に頼めますか？**
A. 家庭裁判所に提出する申述書・申立書の作成は行政書士の業務範囲外で、司法書士・弁護士が担います。行政書士は相続財産・債務の調査と財産目録の作成支援を行います。
