**結論（先に要点）**：介護付き有料老人ホームを新規に開くには、二つの手続きを重ねて進めます。一つは老人福祉法（昭和38年法律第133号）第29条第1項にもとづく有料老人ホームの設置届で、施設を設置しようとする地の都道府県知事（指定都市・中核市では市長）へ、あらかじめ届け出ます。もう一つは介護保険法（平成9年法律第123号）第8条第11項に定める特定施設入居者生活介護の指定で、同法第70条第1項により都道府県知事（指定都市・中核市では市長）が事業所ごとに指定します。人員・設備・運営の基準は指定居宅サービス等の事業の人員、設備及び運営に関する基準（平成11年厚生省令第37号）第174条以下に定められ、看護・介護職員は要介護の利用者3人につき1人以上（常勤換算＝いわゆる3対1）が中心になります。本記事は、設置届と指定の流れ・要件・スケジュールと、どの部分を誰に頼むかを整理するためのものです。基準への適合や指定の可否は指定権者の審査によるものであり、当事務所が指定を保証するものではありません。物件・建築・消防・労務・税務は、それぞれ独立した事業体として別々にご契約いただきます。

## 有料老人ホームの設置届はいつ誰に出しますか？

有料老人ホームとは、老人を入居させ、入浴・排せつ・食事の介護、食事の提供、洗濯・掃除等の家事、健康管理のいずれかのサービスを行う施設をいいます（老人福祉法第29条第1項）。これを設置しようとする者は、あらかじめ、その施設を設置しようとする地の都道府県知事（指定都市・中核市では市長。以下同じ）へ届け出なければなりません。開設してからの事後届出ではなく、事前の届出である点が要です。

有料老人ホームは、提供するサービスによって次の類型に分けて運用されています（厚生労働省「有料老人ホームの設置運営標準指導指針」の区分）。「介護付」は、介護保険の特定施設入居者生活介護の指定を受けたものを指します。

| 類型 | 概要 | 介護の位置づけ |
| --- | --- | --- |
| 介護付有料老人ホーム | 特定施設入居者生活介護の指定を受けている | 施設の職員が介護保険サービスとして提供 |
| 住宅型有料老人ホーム | 特定施設の指定を受けていない | 入居者が外部の居宅サービスを個別に契約 |
| 健康型有料老人ホーム | 介護が必要になった場合は退去が前提 | 介護は提供しない |

設置届は事業開始前に余裕をもって出します。事業開始予定日の何か月前までに届け出るかは自治体の運用で異なり、都道府県によっては事前の相談・協議を求めます。届出の時期・様式・添付書類は、必ず当該自治体の公式ページで確認します。無届のまま運営すると老人福祉法上の指導・改善命令等の対象になり得ます。

## 特定施設入居者生活介護の指定を受ける要件は何ですか？

「介護付」を名乗るには、介護保険法第8条第11項に定める特定施設入居者生活介護の指定を、事業所ごとに受けます。指定は同法第70条第1項により都道府県知事が行い、申請者は原則として法人であることが求められます。人員・設備・運営の基準は指定居宅サービス等の事業の人員、設備及び運営に関する基準（平成11年厚生省令第37号）第174条以下（人員は第175条）に定められ、各自治体の条例で具体化されます。人員配置の基本は次のとおりです。

| 職種 | 配置の考え方（常勤換算） |
| --- | --- |
| 看護職員・介護職員 | 要介護の利用者の数を3で除した数以上（3対1）。看護職員は利用者30人まで1人以上、31人以上は50人ごとに1人以上 |
| 生活相談員 | 利用者100人につき1人以上。うち1人以上は常勤 |
| 機能訓練指導員 | 1人以上（他職種との兼務ができる場合がある） |
| 計画作成担当者（介護支援専門員） | 利用者100人につき1人を標準とし、1人以上を配置。兼務ができる場合がある |
| 管理者 | 専従の常勤1人（支障がなければ兼務できる場合がある） |

看護・介護職員の「3対1」は、常勤換算方法で数えます。夜勤・宿直をどう組むか、常勤換算をどうシフトに落とすか、就業規則や時間外・休日労働の協定をどう整えるかは労務設計の問題で、社会保険労務士の領域です。当社・当事務所とは独立した事業体として別々にご契約いただきます（施設労務の詳細は姉妹サイトの社会保険労務士のコラムもご覧ください）。介護報酬の算定・請求は事業者または請求代行が担い、会計・税務は税理士の領域です。

## 居室面積・共用部・バリアフリーなど建物側の基準はどこを見ますか？

設備基準は平成11年厚生省令第37号（第176条ほか）に定められ、標準指導指針で具体化されています。介護居室は原則として個室とし、入居者1人当たりの床面積は原則13平方メートル以上とされています（廊下・共用部を除く専用部分の面積）。共用部としては、食堂、機能訓練室、浴室、便所、医務室または健康管理室、看護・介護職員室、談話室などを、提供するサービスに応じて設けます。廊下幅・段差解消・手すり等のバリアフリー、避難経路の確保も求められます。

| 確認する箇所 | 主な求められ方 |
| --- | --- |
| 介護居室 | 原則個室、1人当たり床面積は原則13平方メートル以上 |
| 共用設備 | 食堂・機能訓練室・浴室・便所・医務室または健康管理室など |
| バリアフリー | 廊下幅・段差解消・手すり・車いす対応の便所や浴室 |
| 用途・防火 | 建築基準法上の用途（老人ホーム）への適合、用途変更確認申請の要否 |
| 消防用設備 | 消防法施行令別表第一(6)項ロに該当し、自動火災報知設備・スプリンクラー設備等 |

既存の建物を転用する場合は、建築基準法上の用途変更の確認申請が必要になることがあり、その要否・設計は建築士（設計者）の判断によります。消防用設備（自動火災報知設備・スプリンクラー設備・消防機関へ通報する火災報知設備等）の要否と消防同意は消防署の判断によります。物件の用途地域・面積の一次確認は不動産会社が担い、当社は物件情報の提供までを行い、建築確認や消防の可否は判断しません。

## 設置届から指定・開設までのスケジュールはどう組みますか？

設置届（老人福祉法）と特定施設の指定（介護保険法）は別の手続きですが、実務では並行して準備します。順番が前後すると差し戻しになりやすいため、事前協議を早めに始めます。一般的な流れは次のとおりです。

1. 事業計画・資金計画を固め、法人を設立する（定款の事業目的に有料老人ホームの設置運営・特定施設入居者生活介護を加える）
2. 物件を選び、居室面積・共用部・建築基準法・消防法への適合を確認する
3. 都道府県（指定権者）と事前協議を行う（設置届・指定の両方）
4. 看護・介護職員、生活相談員、機能訓練指導員、計画作成担当者、管理者を確保する
5. 有料老人ホームの設置届を提出する
6. 特定施設入居者生活介護の指定申請書と添付書類を提出する
7. 書類審査・現地確認を経て、指定（多くの自治体で毎月1日付）を受け、開設する

指定は毎月1日付で行う自治体が多く、指定申請の提出期限は指定希望日の前月または前々月に設定されているのが一般的です。締切・様式・必要書類は指定権者ごとに異なるため、必ず当該自治体の公式ページで確認します。代表的な必要書類は、設置届の様式一式、指定申請書と付表、法人の登記事項証明書・定款、事業所の平面図・写真・賃貸借契約書等、運営規程、従業者の勤務形態一覧表と資格証、管理者・計画作成担当者の経歴、収支予算書、各種誓約書などです。四葉行政書士事務所では、行政書士業務の範囲で、設置届・指定申請書・付表・添付書類の作成、事前協議の資料整理、運営規程等の文案づくりを支援します。基準への最終的な適合判断や指定の可否は指定権者の審査によります。

## 設置届・指定・建築・消防・労務・税務は誰に分けて頼めばいいですか？

介護付き有料老人ホームの開設は、複数の専門分野が交わります。担当は次のように分かれます。

- 設置届・指定申請書・付表・添付書類の作成、事前協議の支援 → 四葉行政書士事務所（行政書士）
- 事業用物件の選定・賃貸借・重要事項説明、用途地域・面積の一次確認 → 四葉不動産株式会社
- 用途変更の確認申請・設計、居室面積・バリアフリーの適合、検査済証の確認 → 建築士（設計者）
- 自動火災報知設備・スプリンクラー設備等の要否判定・消防同意 → 消防署・消防設備士

- 法人の会計・税務・税額計算、介護報酬請求に伴う経理 → 税理士
- 権利義務・紛争にわたる個別の法的判断 → 弁護士

## よくある質問

**Q. 設置届と特定施設の指定は、どちらか一方だけでよいですか？**
A. 「介護付」を名乗り、施設の職員が介護保険サービスとして介護を提供するには、老人福祉法第29条第1項の設置届と、介護保険法の特定施設入居者生活介護の指定の両方が必要です。指定を受けない場合は住宅型となり、入居者が外部の居宅サービスを個別に契約します。どちらの類型にするかで人員・設備・手続きが変わるため、事前協議で確認します。

**Q. サービス付き高齢者向け住宅（サ高住）でも特定施設の指定は受けられますか？**
A. 一定の要件を満たすサービス付き高齢者向け住宅は特定施設に含まれ得ますが、登録先・所管や届出が有料老人ホームと異なる場合があります。どの枠組みで進めるかは事業計画と物件により変わるため、当該自治体の手引きと事前協議で確認します。制度の枠組みの整理は行政書士業務の範囲で支援しますが、指定の可否は指定権者の審査によります。

**Q. 夜勤体制や職員の労働時間は行政書士に相談できますか？**
A. 人員基準を満たすことと、その職員の雇用契約・就業規則・夜勤や宿直を含む労働時間管理・社会保険の適用は別の問題です。後者は社会保険労務士の領域で、当社とは独立した事業体として別々にご契約いただきます。当事務所は指定申請の書類面を支援します。

**Q. 既存の建物を使えますか？**
A. 居室面積・共用部・バリアフリーのほか、建築基準法上の用途変更の確認申請や、消防用設備の追加が必要になることがあります。用途変更の判断は建築士（設計者）、消防用設備の要否は消防署に確認します。物件は不動産会社、建築確認は建築士と、それぞれ別事業体として別々にご契約いただきます。
