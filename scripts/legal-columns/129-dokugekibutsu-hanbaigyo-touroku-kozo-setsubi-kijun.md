**結論（先に要点）**：試薬や農薬などの毒物・劇物を売るには、店舗ごとに都道府県知事の販売業の登録が必要です（毒物及び劇物取締法第3条第3項・第4条）。登録には店舗の設備基準（施行規則第4条の4）を満たし、毒物劇物取扱責任者を置くこと（第7条・第8条）が前提になります。

**情報確認日：2026年10月23日**。本記事は、毒物劇物販売業の登録に必要な店舗・設備と人の配置を、物件選びの段階から整理します。条文は[e-Gov法令検索](https://laws.e-gov.go.jp/law/325AC0000000303)で照合しましたが、各法令の最終改正日・全施行履歴、自治体ごとの手数料・標準処理期間は未検証です。個別の登録の可否は所管の都道府県（保健所）と有資格者が判断します。

## 毒物劇物の販売業登録とは何か、どんな区分があるのか

毒物及び劇物取締法第3条第3項は、販売業の登録を受けた者でなければ、毒物・劇物を販売・授与したり、販売・授与の目的で貯蔵・運搬・陳列したりしてはならないと定めます。登録は、毒物及び劇物取締法第4条により、店舗ごとに、その店舗の所在地の都道府県知事が行います。保健所を設置する市・特別区では、市長・区長が窓口になります。

販売業の登録は、毒物及び劇物取締法第4条の2により、扱える品目で3種類に分かれます。扱う品目が広いほど責任者の試験区分も広く求められるため、業態を決める段階で区分を確認します。

| 登録の区分 | 扱える毒物・劇物 | 根拠 |
| --- | --- | --- |
| 一般販売業 | 品目の制限なし | 毒物及び劇物取締法第4条の2 |
| 農業用品目販売業 | 厚生労働省令で定める農業上必要な品目のみ | 第4条の2・第4条の3第1項 |
| 特定品目販売業 | 厚生労働省令で定める品目のみ | 第4条の2・第4条の3第2項 |

農業用品目販売業者は農業用品目以外を、特定品目販売業者は定められた品目以外を、それぞれ販売・授与できません（第4条の3）。どの品目がどの区分に当たるかは厚生労働省令で定められ、所管の最新の手引きで確認します。

## 登録に必要な店舗の構造・設備の基準はどこで決まっているか

登録の要件の一つが設備です。毒物及び劇物取締法第5条は、店舗の設備が厚生労働省令で定める基準に適合しないと認めるときは登録をしないと定めます。その基準が毒物及び劇物取締法施行規則第4条の4です。同条第2項は、販売業の店舗について、同条第1項第2号から第4号まで（貯蔵・陳列・運搬）を準用すると定めています。製造所に求められる第1号（製造作業に伴う構造・処理設備）は、販売業の店舗には準用されません。

| 確認する事項 | 根拠（施行規則第4条の4） |
| --- | --- |
| 毒物・劇物を他の物と区分して貯蔵できる設備 | 第1項第2号イ（販売業に準用） |
| 容器や貯蔵設備から漏れ・しみ出しのおそれがないこと | 第1項第2号ロ・ハ |
| 貯蔵場所に施錠設備（施錠が性質上できない場合は堅固なさく） | 第1項第2号ニ・ホ |
| 陳列する場所に施錠設備 | 第1項第3号 |
| 運搬用具から漏れるおそれがないこと | 第1項第4号 |

面積の数値や区画の取り方は、自治体の審査基準で細部が異なります。賃貸物件では、区分した貯蔵スペースと施錠できる保管・陳列設備をとれるか、申請に添える店舗の設備の概要図を用意できるかが鍵になります。具体的な寸法や様式は、本記事では確定値を示しません（自治体差があり裏取りできていないため未検証です）。物件の適否の最終判断は申請先の行政が行います。

## 毒物劇物取扱責任者には誰がなれるのか

毒物及び劇物取締法第7条は、販売業者は店舗ごとに専任の毒物劇物取扱責任者を置き、毒物・劇物による保健衛生上の危害の防止に当たらせなければならないと定めます。販売業者自身が責任者を兼ねることもできます。責任者を置いたとき・変更したときは、30日以内に都道府県知事へ届け出ます（第7条第3項）。

責任者になれる人は、毒物及び劇物取締法第8条で定められています。

| 資格の区分 | 内容 |
| --- | --- |
| 薬剤師 | 第8条第1項第1号 |
| 応用化学に関する学課を修了した者 | 厚生労働省令で定める学校の卒業者等（第8条第1項第2号） |
| 毒物劇物取扱者試験の合格者 | 第8条第1項第3号 |

ただし、18歳未満の者、心身の障害により業務を適正に行えない者、麻薬等の中毒者、毒物劇物に関する罪等で刑の執行を終えてから3年を経過していない者は、責任者になれません（第8条第2項）。毒物劇物取扱者試験は一般・農業用品目・特定品目の3区分で、農業用品目・特定品目の合格者は、その品目を扱う店舗でしか責任者になれません（第8条第3項・第4項）。扱う区分と責任者の資格は対応している必要があります。

## 登録はどこに、どんな書類で出すのか

申請先は、店舗の所在地の都道府県知事（保健所設置市・特別区では市長・区長）です。申請書には、毒物及び劇物取締法第6条の登録事項（申請者の氏名・住所、店舗の所在地など）を記載し、店舗の設備の概要図や、取扱責任者の資格を証する書類などを添えます。添付書類の様式は自治体で異なるため、所管の手引きで確認してください。

登録は一度受ければ永続するわけではありません。毒物及び劇物取締法第4条第3項は、販売業の登録は6年ごとに更新を受けなければ効力を失うと定めます（製造業・輸入業は5年ごと）。店舗の移転や設備の変更、責任者の変更などは、変更の届出や新たな登録の対象になり得ます。何が届出・変更手続に当たるかは、申請先の最新案内で確認してください。

## 設備・責任者・労務は誰に頼むのか（分離受任の整理）

毒物劇物販売業の開業には、申請・設備・人・物件という性質の違う作業が重なります。それぞれの専門家に分けて頼むのが基本です。

| 依頼先 | 担当する範囲 |
| --- | --- |
| 四葉行政書士事務所 | 販売業の登録申請書類の作成支援（本人申請の補助） |
| 四葉不動産株式会社 | 店舗物件の選定・用途地域や管理規約の下調べ・内見の仲介 |
| 建築士・施工業者 | 貯蔵設備・区画・施錠設備の設計・改修 |
| 薬剤師等の有資格者 | 毒物劇物取扱責任者としての就任や取扱いの判断 |
| 社会保険労務士 | 従業員の雇用・就業規則・社会保険の設計 |

四葉行政書士事務所、四葉社会保険労務士事務所、四葉不動産株式会社はそれぞれ別事業体で、独立した事業体として受任します。各分野の担当者と別々にご契約いただき、各受任者が直接請求・入金を受けます。当事務所は紹介料を受け取りません。毒物劇物取扱責任者には有資格者本人が就任するもので、代行はできません。都道府県・保健所の薬務担当は登録の行政窓口で、受任契約の相手ではありません。

[許認可サポート](/legal/services)、[受任の流れ](/legal/nagare)、[報酬額表](/legal/ryokin)をご確認ください。医薬品を扱うドラッグストアは別制度の[店舗販売業の許可](/legal/column/iyakuhin-tenpo-hanbaigyo-drugstore-kozo-setsubi-touroku-hanbaisha)、調剤を行う薬局は[薬局開設許可の構造設備・管理薬剤師](/legal/column/yakkyoku-kaisetsu-kyoka-kozo-setsubi-kanri-yakuzaishi)に整理しています。毒物劇物の販売業登録はこれらと根拠法も区分も別です。

## よくある質問

**Q. 毒物劇物を少量だけ売るのにも登録は要りますか？**
A. 販売・授与を業として行うなら、量の多少にかかわらず販売業の登録が前提になります（毒物及び劇物取締法第3条第3項）。登録を受けずに販売・陳列等はできません。扱う品目や取引の形で区分や手続が変わるため、所管の薬務担当に確認してください。

**Q. 薬剤師でなくても毒物劇物取扱責任者になれますか？**
A. なれる場合があります。薬剤師のほか、厚生労働省令で定める学校で応用化学の学課を修了した者、毒物劇物取扱者試験の合格者が責任者の資格を持ちます（第8条第1項）。ただし農業用品目・特定品目の試験合格者は、その品目を扱う店舗に限られます（第8条第4項）。

**Q. 登録はどのくらいの期間と費用がかかりますか？**
A. 登録手数料は都道府県の条例等で定められ、金額は自治体で異なります。標準処理期間も各自治体の審査基準に示されます。設備と書類が整っているかで変わります。本記事では確定した金額・日数は示していません（自治体差が大きく裏取りできていないため未検証です）。

**Q. 一度登録すれば更新は不要ですか？**
A. 不要ではありません。販売業の登録は6年ごとに更新を受けなければ効力を失います（第4条第3項）。更新の申請時期や方法は自治体の案内で定められているため、期限に余裕をもって確認してください。
