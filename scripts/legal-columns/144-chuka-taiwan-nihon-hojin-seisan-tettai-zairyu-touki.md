**結論（先に要点）**：中国・台湾企業が日本の子会社をたたむときは、株主総会の解散決議から清算人による清算、債権者への官報公告と各別の催告、残余財産の確定・分配、清算結了までを順に進めます（会社法第471条・第475条・第499条・第507条）。経営・管理の在留資格で来日した経営者は、会社の清算によってその在留資格の基盤が失われるため、別の在留資格への変更か出国準備への切替えを入管が審査します。残余財産の本国送金は税務と外為法の報告が関わります。本記事は撤退の流れと各専門家の分担を整理する一般的な情報提供であり、具体的な法的判断は行いません。

## 中国・台湾企業が日本子会社をたたむとき何から着手しますか？

日本法人（株式会社）をたたむときは、まず会社をどうやって消滅させるか（通常清算か、債務超過なら特別清算・破産か）を見極めるところから始めます。資産が負債を上回り、債務を全額弁済できる見込みがあれば、会社法の通常清算の手続によります。着手前に整理しておく主な項目は次のとおりです。

| 着手前に確認すること | 内容 |
| --- | --- |
| 清算の方式 | 通常清算か、債務超過なら特別清算・破産か（弁済できるかの見極め） |
| 役員・従業員 | 代表者・取締役の退任、従業員の解雇予告・社会保険の資格喪失 |
| 許認可 | 事業に許認可があれば廃止届・返納が必要か |
| 在留資格 | 経営・管理などの在留資格で滞在する役員の扱い |
| 財産 | 不動産・預金・売掛金などの資産、買掛金・借入金などの負債 |

解散・清算は、登記・税務・労務・在留資格・対外送金が同時並行で動くため、着手前に全体の順序を決めておくことが要になります。どの方式によるべきかという最終的な判断は、債務の状況に応じて弁護士・司法書士などの有資格者が行います。

## 解散・清算の登記と官報公告はどんな順序で進みますか？

株式会社の解散事由は会社法第471条が定めており、株主総会の決議（会社法第309条第2項の特別決議）による解散が実務では一般的です。解散すると会社は清算をしなければならず（会社法第475条）、清算人が現務の結了・債権の取立て・債務の弁済・残余財産の分配を行います。順序の骨格は次のとおりです。

1. 株主総会で解散の決議をし、清算人を選任する（会社法第471条）
2. 解散の登記・清算人の登記をする（司法書士）
3. 債権者に対し、一定の期間内に債権を申し出るべき旨を官報に公告し、知れている債権者には各別に催告する。この期間は2箇月を下ることができない（会社法第499条）
4. 債権の申出期間の経過後に債務を弁済し、残った財産（残余財産）を株主に分配する
5. 清算事務が終わったら決算報告を作成し、株主総会の承認を受ける（会社法第507条）。承認で清算は結了し、清算結了の登記をする（司法書士）

会社法第499条の官報公告は、債権者を保護するための手続で、申出期間を2箇月以上とる必要があります。この期間があるため、解散を決めてから清算結了までは、順調でも数か月はかかります。登記（解散・清算人・清算結了）は司法書士の担当です。

## 経営・管理の在留資格で来日した経営者は撤退後に在留資格がどうなりますか？

経営・管理の在留資格は、日本で事業の経営または管理の活動を行うことを前提としています。会社をたたんで事業をやめると、その活動の基盤が失われるため、在留資格をそのまま維持することは原則としてできなくなります。撤退後の選択肢は、入管（出入国在留管理庁）の個別審査によって次のように分かれます。

- 日本で別の事業や就労を続けるなら、それに対応する在留資格への変更を申請する
- 日本を離れるなら、清算手続や帰国の準備が残っている間、出国準備のための在留資格（特定活動）へ切り替えてから出国する

出国準備のための特定活動の在留期間や、変更が認められるかどうかは、清算の進み具合・残務の有無・個々の事情によって入管が判断します。在留期限が迫っているのに清算が終わらない、役員が複数いて扱いが異なる、といった場合は早めの確認が要ります。在留資格の変更・特定活動への切替えの申請書類の作成は行政書士が扱い、許認可事業であれば廃止届の提出も行政書士の担当です。最終的な許否は入管が審査して判断します。

## 残余財産を本国へ送金するときの税務・為替の注意点は何ですか？

清算では、解散の日までの事業年度と、その後の清算中の各事業年度、残余財産が確定した事業年度について、法人税などの確定申告が必要になります（法人税法）。残余財産を株主（本国の親会社など）に分配・送金するときは、源泉徴収（みなし配当の課税など）の要否を含め、税務上の整理が欠かせません。税額の計算と申告は税理士の担当です。

対外送金では、外国為替及び外国貿易法第55条（支払等の報告）に基づき、居住者等が外国へ向けた一定の支払等をしたときは、政令で定める場合を除き、報告が必要とされています。実務上、銀行等を経由する支払等の報告は日本銀行を経由して行い、一定の金額（3,000万円相当額を超える支払等）が報告の対象とされています（参照日 2026-10-30）。金額の基準や提出期限は政令・告示で定められ運用も変わるため、具体的な要否は送金時に金融機関と日本銀行の最新の案内で確認します。

| 項目 | 担当・確認先 |
| --- | --- |
| 清算中の各事業年度・残余財産確定事業年度の確定申告、源泉徴収の要否 | 税理士 |
| 残余財産の対外送金の実行 | 金融機関 |
| 支払等の報告（外国為替及び外国貿易法第55条） | 金融機関・日本銀行の最新案内で要否を確認 |

税務と送金は、金額や源泉徴収の当てはめで結論が変わるため、本記事では制度の枠組みの情報提供にとどめ、具体的な税額・送金可否の判断はしません。

## 清算登記・在留資格・税務・送金は誰に振り分けますか？

日本法人の撤退は、複数の手続が同時に動くため、担当を分けて進めます。

- 在留資格の変更・出国準備（特定活動）への切替えの申請、許認可の廃止届 → 四葉行政書士事務所（行政書士）。資料と情報の提供までを行い、具体的な法的判断はしません
- 解散の登記・清算人の登記・清算結了の登記 → 司法書士
- 清算事業年度・残余財産確定事業年度の確定申告、源泉徴収・みなし配当の税務 → 税理士
- 従業員の解雇予告、社会保険・労働保険の資格喪失手続 → 社会保険労務士
- 残余財産の対外送金・外為法の報告の実行 → 金融機関
- 債務超過での特別清算・破産、債権者との紛争 → 弁護士
- 本社ビルなど会社所有不動産の売却 → 別事業体の四葉不動産株式会社（宅地建物取引業者）

解散の登記・清算人の登記・清算結了の登記は司法書士、清算の確定申告と源泉徴収の税務は税理士、従業員の解雇予告や社会保険の資格喪失は社会保険労務士、債務超過での特別清算・破産や債権者との紛争は弁護士が、いずれも独立した事業体として別々にご契約・お手続きいただきます。会社が所有する不動産の売却は、四葉行政書士事務所とは別事業体の四葉不動産株式会社が、独立した事業体として別契約で対応します。各分野は、それぞれの窓口・資格者と別々にご契約いただく前提で、当事務所は紹介料を受け取りません。撤退は在留期限や申告期限との兼ね合いがあるため、順序を決める段階からご相談ください。受任の流れは[受任の流れ](/legal/nagare)、料金は[報酬額表](/legal/ryokin)、取扱業務は[取扱業務一覧](/legal/services)をご覧ください。進出・設立側の手続は[台湾企業の日本支店・外国会社の登記](/legal/column/taiwan-kigyo-nihon-shiten-gaikoku-kaisha-touki)、[経営・管理の在留資格と会社設立](/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)、更新時の事業継続性は[経営・管理の更新と事業の継続性の立証](/legal/column/keieikanri-koshin-jigyo-keizokusei-rissho-chuka-taiwan)もご覧ください。

## よくある質問

**Q. 日本の子会社をたたむには何から始めますか？**
A. まず債務を全額弁済できるか（通常清算か、債務超過なら特別清算・破産か）を見極めます。通常清算なら、株主総会の解散決議と清算人の選任（会社法第471条）から始め、解散の登記、債権者への官報公告と各別の催告（会社法第499条）、債務弁済と残余財産の分配、決算報告の承認・清算結了（会社法第507条）へと進みます。登記・税務・労務・在留資格・送金が同時に動くので、着手前に順序を決めておくことが大切です。

**Q. 官報公告の期間はどのくらい必要ですか？**
A. 清算株式会社は、債権者に対し一定の期間内に債権を申し出るべき旨を官報に公告し、知れている債権者には各別に催告しなければなりません。この期間は2箇月を下ることができません（会社法第499条）。この期間があるため、解散から清算結了までは順調でも数か月かかります。公告には、期間内に申出をしない債権者は清算から除斥される旨を付記します。

**Q. 経営・管理の在留資格は会社をたたむと失効しますか？**
A. 経営・管理の在留資格は事業の経営・管理の活動が前提なので、会社をたたむとその基盤が失われ、原則としてそのままの維持はできなくなります。日本で別の活動を続けるなら対応する在留資格への変更を、帰国するなら出国準備のための特定活動への切替えを入管が審査します。在留期間や許否は清算の進み具合や個々の事情によるため、早めに行政書士・入管に確認してください。

**Q. 残余財産を本国へ送金するとき何に注意しますか？**
A. 清算中の各事業年度と残余財産確定の事業年度について法人税などの確定申告が必要で、分配には源泉徴収（みなし配当の課税など）の要否があります（法人税法）。税額の計算・申告は税理士の担当です。対外送金は、外国為替及び外国貿易法第55条の支払等の報告の対象になることがあり、一定の金額を超える支払等が対象とされています。具体的な要否は送金時に金融機関と日本銀行の最新案内で確認してください。
