**結論（先に要点）**：相続人に認知症などで判断能力を欠く方がいると、その相続不動産は「すぐには売れない」のが原則です。売却の前提になる遺産分割協議は判断能力（意思能力）がないと有効に成立せず（民法第3条の2）、本人に代わって協議や売却をするには家庭裁判所が選ぶ成年後見人が要ります。さらに、売る不動産が本人の居住用なら、後見人でも家庭裁判所の許可が別に必要です（民法第859条の3）。後見開始の申立てと審判は家庭裁判所で、申立て支援は弁護士・司法書士、相続登記は司法書士、評価・税務は不動産鑑定士・税理士へ分け、売却の媒介は当社が担います。それぞれ独立した事業体として別々にご契約いただきます。

実家などの相続不動産を売りたいのに、相続人である親や兄弟に認知症の方がいる——そんなとき「なぜ売れないのか」「どう段取りすればよいのか」が最初の悩みになります。本人を外して話を進めることはできず、かといって家族だけで代筆するわけにもいきません。手続きの順番を知らないまま動くと、せっかくの契約が後で無効になりかねません。

この記事は、相続人に判断能力を欠く方がいる場面で、不動産の売却が止まる理由と、売れるようになるまでの段取りを、不動産の視点から整理します。後見開始の申立ての可否や個別の法的判断は弁護士・司法書士・家庭裁判所の領域で、本記事はあくまで一般的な情報提供です。

四葉不動産株式会社は、東京都文京区小日向を拠点に、相続不動産の査定と売却の媒介を承っています。認知症の相続人が関わる売却について、売る前に確認できることからご相談いただけます。

## なぜ相続人に認知症の方がいると売却が止まるのか？

相続した不動産を売るには、まず誰のものかを確定させる遺産分割協議を整え、相続登記をしてから売買に進むのが通常の流れです。ところが遺産分割協議は、相続人全員による法律行為であり、各相続人に意思能力（物事を理解し判断する能力）が要ります。

民法第3条の2は、「法律行為の当事者が意思表示をした時に意思能力を有しなかったときは、その法律行為は、無効とする」と定めます（平成29年法律第44号による新設・2020年4月1日施行）。認知症などで判断能力を欠く相続人が加わった遺産分割協議は、本人の意思表示が無効となり、協議全体が成立しません。

| 段階 | 判断能力を欠く相続人がいると |
| --- | --- |
| 遺産分割協議 | 本人の意思表示が無効。家族が代筆・代理することもできない |
| 相続登記 | 分割が整わないと、売却に向けた名義変更が進まない |
| 売買契約 | 本人が当事者なら、意思能力を欠くまま結んだ契約は無効 |

つまり「売れない」のではなく、本人に代わって適法に判断・署名できる人（成年後見人）を立てる手続きが先に要る、ということです。

## 成年後見人がつくと、いつ・どのように売れるのか？

判断能力を欠く本人のために、家庭裁判所が成年後見人を選びます。民法第7条は、精神上の障害により事理を弁識する能力を欠く常況にある者について、家庭裁判所が本人・配偶者・四親等内の親族等の請求により後見開始の審判をすることができると定め、第8条で後見開始の審判を受けた者を成年被後見人とし、成年後見人を付すとしています。

成年後見人が選ばれると、本人に代わって遺産分割協議に加わり、相続登記や売買の当事者になれます。おおまかな順序は次のとおりです。

| 順序 | 内容 | 担うのは誰か |
| --- | --- | --- |
| 1 | 後見開始の申立て（家庭裁判所へ） | 本人・親族等。書類作成の支援は弁護士・司法書士 |
| 2 | 家庭裁判所の審判・成年後見人の選任 | 家庭裁判所 |
| 3 | 成年後見人が遺産分割協議に参加 | 成年後見人（本人の利益を守る立場） |
| 4 | 相続登記 | 司法書士 |
| 5 | 売買契約・決済（居住用なら家裁の許可が前提） | 売主（後見人）＋媒介は当社 |

注意したいのは、後見人は「本人の利益」を守る立場だという点です。相続人の都合で安く売る、本人の取り分を減らすといった分割には、後見人は応じられません。後見人が共同相続人の一人でもある場合は利益が相反するため、別に特別代理人を選ぶ必要が生じます（民法第826条・第860条）。

共有状態の相続不動産を売る考え方は、[共有不動産を売るときの相続人全員の同意の整理](/column/souzoku-kyoyu-fudosan-uru-doui)も参考になります。

## 居住用不動産の売却に家庭裁判所の許可が要るのはなぜか？

成年後見人がついても、それだけで本人名義の不動産を自由に売れるわけではありません。民法第859条の3は、成年後見人が成年被後見人に代わって、その居住の用に供する建物又はその敷地について、売却、賃貸、賃貸借の解除又は抵当権の設定その他これらに準ずる処分をするには、家庭裁判所の許可を得なければならないと定めます。

住む場所を失うことは本人の生活と精神状態に大きく影響するため、本人保護の観点から、居住用不動産の処分には特別に家裁の許可を要求しているのです。許可を得ずにした居住用不動産の売却は無効と解されています（国税庁の文書回答など）。

| 不動産の性格 | 家裁の許可（第859条の3） |
| --- | --- |
| 本人が現に住む・過去に住んだ・将来住む予定の建物とその敷地 | 必要（許可なき売却は無効） |
| 本人の居住用に当たらない相続不動産 | 第859条の3の許可は不要。ただし後見人の善管注意義務・家裁への報告は残る |

「居住の用に供する」は実務で比較的広く解釈される傾向があるとされ、該当するかどうかの判断は家庭裁判所・後見人の領域です。当社が「許可は要る／要らない」を断ずることはできません。配偶者居住権など居住にまつわる権利が絡む売却の考え方は、[配偶者居住権付き建物を売るときの整理](/column/souzoku-haiguusha-kyojuuken-tatemono-baikyaku)も参考になります。

## 遺産分割の前に売る方法はあるのか？

「後見開始まで待てない」「分割の前に売りたい」という相談もありますが、判断能力を欠く相続人がいる以上、本人を外して先に売ることはできません。考えられる筋道は限られます。

| 筋道 | 留意点 |
| --- | --- |
| 後見開始を待ってから売る | 原則の流れ。本人の居住用なら第859条の3の家裁許可も要る |
| 相続放棄で相続人から外れる | 判断能力を欠く本人は単独でできず、後見人の関与が要る。安易な選択は不可 |
| 遺言があった場合 | 本人の協議参加が不要になることがある。ただし遺言の有効性は別途確認 |

いずれも可否は個別の事情と法的判断によります。「分割前に売る近道」をうたう情報もありますが、本人の保護を外れる方法は後で無効になるおそれがあります。急ぐ気持ちはあっても、後見の手続きを飛ばさないことが、結果的に最短になることが多いです。手続きの要否と可否は、弁護士・司法書士・家庭裁判所にご確認ください。

## 後見の申立ては誰に頼み、売却は誰が担当するのか？（分離受任）

認知症の相続人が関わる不動産の売却は、後見・登記・税務・不動産がそれぞれ別の事業体にまたがります。順番を取り違えると、後見人の選任を待たずに契約してしまう、居住用の許可を失念するといった行き違いが起きます。

| 役割 | 誰が担うか |
| --- | --- |
| 査定・媒介・重要事項説明・決済 | 宅地建物取引業（当社） |
| 後見開始の審判・居住用不動産処分許可 | 家庭裁判所 |
| 後見開始の申立て支援・利益相反や紛争の判断 | 弁護士・司法書士 |
| 相続登記・成年後見登記の確認 | 司法書士 |
| 相続税・譲渡所得税の計算と申告 | 税理士 |
| 不動産の評価（鑑定） | 不動産鑑定士 |

後見開始の審判事件や居住用不動産処分許可の申立ては、家事事件手続法の別表第一に掲げられた家庭裁判所の手続きです。申立書類の作成・支援は弁護士・司法書士の業務で、当社は代行しません。

これらは**それぞれ独立した事業体**であり、**別々にご契約**いただく前提です。当社は不動産の売却面を担い、後見の申立て支援や利益相反の判断は弁護士・司法書士、相続登記は司法書士、相続税・譲渡所得税は税理士、鑑定評価は不動産鑑定士へと分けてご案内します。当社は紹介料を受け取りません。

## よくある質問

**Q. 親が認知症です。家族の話し合いで実家を売り、代筆すればよいのでは？**
A. 判断能力を欠く相続人が加わった遺産分割協議や売買契約は、本人の意思表示が無効となり成立しません（民法第3条の2）。家族が代筆・代理することもできず、家庭裁判所が選ぶ成年後見人を立てる手続きが先に要ります。可否と段取りは弁護士・司法書士へご確認ください。

**Q. 成年後見人がつけば、すぐに実家を売れますか？**
A. 後見人は本人に代わって協議や売買の当事者になれますが、売る不動産が本人の居住用なら、別に家庭裁判所の許可が必要です（民法第859条の3）。許可なき居住用不動産の売却は無効と解されています。居住用に当たるかの判断は家庭裁判所・後見人の領域です。

**Q. 後見人は私（子）がなれますか？**
A. 親族が後見人になれる場合もありますが、選ぶのは家庭裁判所です。後見人が共同相続人の一人だと遺産分割で利益が相反するため、別に特別代理人の選任が必要になることがあります（民法第826条・第860条）。選任や利益相反の判断は弁護士・司法書士・家庭裁判所にご相談ください。

**Q. 後見の手続きには時間がかかりますか。先に買主を探せますか？**
A. 後見開始の審判や居住用不動産処分許可には一定の期間がかかります。後見人の選任や許可を待たずに契約すると無効のおそれがあるため、順番を守るのが安全です。当社は、手続きと並行して市場の状況の整理や売却準備のご相談を承り、契約・決済は要件が整ってから進めます。
