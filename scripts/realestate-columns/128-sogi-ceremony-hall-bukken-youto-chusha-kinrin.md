**結論（先に要点）**：火葬を伴わない葬儀式場（セレモニーホール）は、建築基準法上おおむね「集会場」として扱われ、用途地域ごとの建築制限を受けます。火葬炉を併設する火葬場とは根拠法も立地の枠組みも異なります。物件を探す前に、用途地域・接道・駐車場・近隣対応を分けて確認します。

空き倉庫やロードサイドの建物、自己所有地を使って家族葬ホールや貸し式場を開きたい、または葬祭業者へ貸したい、という相談が増えています。ところが「どんな建物でも式場にできる」わけではありません。多くは用途地域の制限、接道、駐車場、近隣への説明という段階で検討が止まります。

最初につまずきやすいのが、葬儀式場と火葬場の混同です。両者は建築や許認可の枠組みが違うため、同じ「葬祭施設」と考えて物件を探すと、後で建てられない・貸せないことが分かります。

四葉不動産株式会社は、東京都文京区を拠点に、事業用物件の調査と賃貸・売買の媒介を承っています。式場を開ける物件か、葬祭業者へ貸せる物件かを、売主・貸主・借主のそれぞれの立場から整理するところからご相談いただけます。

## セレモニーホールは火葬場や墓地と何が違い、どんな許認可の枠組みになるのか？

まず、施設に火葬炉や遺骨の収蔵があるかどうかで枠組みが分かれます。通夜・告別式などの儀式を行うだけで、火葬や埋蔵・収蔵を伴わない葬儀式場は、墓地、埋葬等に関する法律（墓地埋葬法）の経営許可の対象ではないのが一般的です。

| 施設 | 主な根拠 | 立地・許認可の枠組み（概略） |
| --- | --- | --- |
| 葬儀式場（火葬炉なし） | 建築基準法（集会場） | 用途地域の建築制限（法第48条・別表第二）。火葬を伴わなければ墓地埋葬法の経営許可は対象外 |
| 火葬場 | 建築基準法第51条・墓地埋葬法 | 都市計画区域内では都市計画でその敷地の位置が決定されているか、特定行政庁の許可等が必要。墓地埋葬法の経営許可も別に必要 |
| 墓地・納骨堂 | 墓地埋葬法 | 遺骨の埋蔵・収蔵を伴うため経営許可の対象（別記事・行政書士の領域） |

墓地埋葬法は、第2条で埋葬・火葬・墳墓・墓地・納骨堂・火葬場などを定義し、第10条で墓地・納骨堂・火葬場の経営には都道府県知事等の許可が必要と定めています。火葬炉を併設する計画は、この経営許可と建築基準法第51条の両方が関わり、立地のハードルが大きく上がります。

一方、火葬を伴わない式場でも、「集会場」として用途地域の制限や消防の基準は受けます。墓地埋葬法の対象かどうかの最終的な判断や、火葬・収蔵を伴う計画の可否は、自治体の担当課と、許認可を扱う行政書士に確認してください。墓地・納骨堂の経営許可については[墓地・納骨堂の経営許可は行政書士の領域](/legal/column/bochi-noukotsudo-keiei-kyoka)に分けています。

## 用途地域で葬儀式場を開けるのはどこまでで、どんな物件だと建てられないのか？

火葬を伴わない葬儀式場は「集会場」に当たるのが一般的な整理で、用途地域ごとの建築制限を受けます。建築基準法第48条と別表第二は、用途地域ごとに建てられる建築物・建てられない建築物を定めています。都市計画法第8条・第9条が用途地域の種類と趣旨を定め、具体的な建築制限は建築基準法が担う、という関係です。

| 用途地域の例 | 集会場（葬儀式場）の扱い（一般的な傾向） |
| --- | --- |
| 第一種・第二種低層住居専用地域、第一種中高層住居専用地域 | 集会場は原則として建てられない傾向。特定行政庁の許可による例外の余地はあるが保証はない |
| 第二種中高層住居専用地域〜近隣商業・商業・準工業など | 規模や地域により建てられる可能性があるが、面積要件や付帯条件を要確認 |
| 工業・工業専用地域 | 用途の制限が別の観点から掛かるため、計画ごとに要確認 |

ただし、これはあくまで一般的な傾向です。同じ用途地域でも、建物の規模、既存不適格の有無、地区計画などの上乗せ規制で結論は変わります。用途地域の該当性と建築の可否は、特定行政庁（建築指導課）と建築士が判断する事項です。推測で「建てられる」と決めず、計画の規模を示して個別に確認します。

事業用物件の用途地域の読み方は、業種は違っても考え方が共通する部分があります。[介護事業所を開ける物件と用途地域](/column/kaigo-jigyousho-bukken-youto-chiiki)、[旅館業・ホテルの営業と物件要件](/column/ryokangyo-hotel-eigyo-bukken-youken)も、用途地域から物件を絞る流れの参考になります。

## 建築基準法・消防法・駐車場附置義務の面で式場物件に求められる条件は？

用途地域をクリアできても、建物そのものと設備の基準が残ります。集会場は多数の人が集まる用途のため、避難や防火、来場者の車の扱いが論点になります。

| 確認する面 | 主な内容 |
| --- | --- |
| 建築基準法（集会場） | 特殊建築物としての避難・防火の基準、床面積に応じた規定。既存建物なら検査済証や既存不適格の有無 |
| 消防法 | 消防法施行令別表第一の防火対象物の区分（集会場は該当区分あり）に応じた消防用設備・届出。所轄消防署に事前相談 |
| 駐車場 | 会葬者・霊柩車・送迎バスの出入り。自治体の駐車場附置義務条例に該当する規模なら附置義務の確認 |
| 周辺道路 | 霊柩車・バスの進入と転回、建物前の停車スペース、近隣の生活動線との干渉 |

駐車場の附置義務は、建物の用途と延べ面積などに応じて自治体の条例で定められます。基準は自治体ごとに異なるため、物件所在地の条例を参照日とともに確認します。会葬者の車が路上に滞留すると近隣対応の火種になるため、法令上の附置義務とは別に、実際の運用台数も見ておきます。

既存建物を式場に転用する場合は、検査済証や用途変更の要否も確認します。用途変更の扱いは[検査済証のない物件を福祉用途へ変える](/column/kensazumisho-nashi-bukken-fukushi-youto-henko)、消防・騒音の論点は[カラオケボックスの物件と用途地域・消防](/column/karaoke-box-tenpo-bukken-youto-shoubou-soon)が、考え方の参考になります。避難・防火の具体的な基準適合は、建築士と所轄消防署に確認してください。

## 市街化調整区域の既存建物をホールに転用するとき開発許可や用途変更はどう扱うのか？

ロードサイドの建物や郊外の倉庫は、市街化調整区域にあることが珍しくありません。市街化調整区域では、都市計画法により建築や用途変更が制限されます。

都市計画法第29条は開発行為に知事等の許可を要すると定め、第34条は市街化調整区域での開発許可の立地基準を限定列挙しています。第43条は、開発許可を受けた区域以外で建築物を新築・改築したり、用途を変更して別種の建築物にしたりする場合に知事等の許可が必要と定めています。つまり、既存の倉庫を葬儀式場に「用途変更」するだけでも、市街化調整区域では許可の検討が要る場合があります。

既存建物の建替え（改築）として扱えるか、用途変更として新たな許可が要るかは、従前の用途・規模との同一性や、自治体の運用基準によって分かれます。許可の立地基準に当てはまるかどうかの判断と、開発許可・用途変更の許可申請は行政書士の領域です。市街化調整区域の物件の考え方は[市街化調整区域の既存建物を事業用に使う](/column/kensetsugyo-shizaioki-shako-chosei-kuiki-bukken)も参考にしてください。

物件がどの区域区分にあるかは、売買・賃貸の前提として調べます。市街化調整区域だから必ず不可、市街化区域だから必ず可、と決めつけず、区域区分・用途地域・接道をそろえて確認します。

## 近隣説明・自治会対応で物件選定前に確認しておくべきことは？

葬儀式場は、法令の基準を満たしても近隣との関係で計画が進まないことがあります。会葬者の出入り、送迎車、夜間の人の動きなどへの懸念から、反対運動や紛争に発展した例も報じられています。物件を決める前に、次の点を確認します。

- 用途地域・区域区分と、周辺の住宅・施設の立地
- 自治体に葬祭施設に関する独自の条例・指導要綱・事前協議の仕組みがあるか
- 自治会・町内会への事前説明の慣行や、求められる説明の範囲
- 会葬者・車両の動線が、近隣の生活動線や通学路と干渉しないか

一部の自治体は、葬祭場・斎場について距離制限や事前の届出・協議を求める条例や要綱を設けています。物件所在地の条例・要綱を参照日とともに確認し、必要なら事前協議の窓口に相談します。近隣との話し合いが紛争になり、損害賠償や差止めといった法的な争いになった場合は、弁護士に相談する領域です。四葉不動産は物件と法令上の前提を整理しますが、紛争の代理や法的判断は行いません。

## 貸し式場として葬祭業者へ賃貸する場合、賃貸借契約と原状回復はどう整理するのか？

自己所有の建物や土地を、自分で運営せず葬祭業者へ貸すという出口もあります。この場合、貸主は式場の運営者ではなく、建物・土地の賃貸人として関わります。

| 整理する項目 | 確認する内容 |
| --- | --- |
| 用途・許認可の前提 | 借主の用途（集会場としての式場）が用途地域・建築・消防の基準に適合するか。許認可は借主側で取得 |
| 賃貸借の条件 | 用途の限定、内装・設備工事の負担、看板、近隣対応の役割分担、契約期間 |
| 原状回復 | 式場仕様の内装・設備を、契約終了時に誰がどこまで戻すか。特殊な設備の扱い |
| リスクの分担 | 近隣対応・苦情、設備の保守、賃料の滞納時の対応 |

貸主と借主は別の立場なので、契約で用途と工事・原状回復の範囲を明確にします。賃貸借の媒介と条件の整理は宅建業（当社不動産）が担い、賃貸借契約書の内容確認は媒介の範囲で行います。賃貸借契約書の読み方は[賃貸借契約書のどこを読むか](/column/chintaishaku-keiyakusho-doko-wo-yomu)も参考にしてください。借主が取得すべき許認可の要否や、近隣紛争化したときの対応は、それぞれ行政書士・弁護士の領域です。

## よくある質問

**Q. 住宅街の空き家をセレモニーホールにできますか？**
A. 用途地域によります。火葬を伴わない式場は「集会場」として扱われるのが一般的で、第一種・第二種低層住居専用地域や第一種中高層住居専用地域では原則建てられない傾向です。該当性と可否は特定行政庁と建築士が判断するため、計画の規模を示して個別に確認します。

**Q. ロードサイドの倉庫（市街化調整区域）を式場に転用できますか？**
A. 市街化調整区域では、用途変更でも都市計画法に基づく許可の検討が要る場合があります。立地基準に当てはまるかの判断と許可申請は行政書士の領域です。区域区分・用途地域・接道をそろえて確認してから判断します。

**Q. 火葬場も一緒に作りたいのですが、物件探しの進め方は変わりますか？**
A. 変わります。火葬炉を併設すると、墓地埋葬法の経営許可と建築基準法第51条の立地の枠組みが加わり、ハードルが大きく上がります。経営許可は行政書士、立地の可否は特定行政庁の領域で、式場だけの計画とは分けて検討します。

**Q. 自分で運営せず、葬祭業者に貸すだけなら許認可は不要ですか？**
A. 貸主は賃貸人の立場で、式場としての許認可や近隣対応は借主側が担うのが基本です。ただし、用途が用途地域・建築・消防に適合することは賃貸の前提になります。用途の限定や原状回復を賃貸借契約で明確にしておきます。
