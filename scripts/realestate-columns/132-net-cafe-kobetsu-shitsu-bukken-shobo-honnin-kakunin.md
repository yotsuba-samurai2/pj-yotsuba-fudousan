**結論（先に要点）**：複合カフェ（ネットカフェ・漫画喫茶）の物件は、用途地域で店舗用途が認められるかに加え、個室・ブース区画が消防法施行令別表第一(2)項ニの対象として自動火災報知設備などを備えられるかが要点です。東京都では、営業開始の10日前までに公安委員会へインターネット端末利用営業の届出が要ります。物件の適合は不動産側で、届出書類の作成は行政書士へ分けて進めます。

ネットカフェ・漫画喫茶（複合カフェ）を新しく出そうとすると、「この物件で個室を作れるのか」「消防はどこまで求められるのか」「東京都の届出はいつ、誰が出すのか」と迷います。空き店舗や空きフロアを複合カフェ用に貸したいオーナーの側も、どんな物件なら借り手がつくのかを知っておきたいところです。

複合カフェの物件は、用途地域・床面積という建築面、個室区画の防火・避難という消防面、そして東京都のインターネット端末利用営業の届出という許認可面が重なります。物件を先に契約してから「個室の消防設備が足りない」「用途が合わない」と分かると、出店の準備が止まります。先に不動産面と許認可面を分けて確認するのが確実です。

四葉不動産株式会社は、東京都文京区小日向を拠点に、事業用物件の調査と賃貸仲介を承っています。複合カフェの物件について、契約前に確認できることからご相談いただけます。

## ネットカフェの物件は用途地域と床面積でどこまで制限される？

ネットカフェ・漫画喫茶は、建築基準法の用途の扱いとしては一般に「店舗（サービス業を営む店舗）」に準じて考えられます。ただし、個室で遊興の設備を客に利用させる形態は「遊技場」や「興行場」に近いと見られることもあり、どの用途に当たるかは建物の作りと特定行政庁の判断で変わります。「この地域なら必ず出せる」と決めつけず、物件ごとに用途地域と用途分類を確認するのが安全です。

| 確認すること | 物件側で見ておきたい点 |
| --- | --- |
| 用途地域 | 店舗・遊技場系の用途が建てられる地域か。第一種低層住居専用地域など住居専用系では制限が強い |
| 既存用途 | もとの用途（事務所・物販店など）から用途変更の確認申請が要るか（床面積200㎡超の特殊建築物への変更で要否が分かれる） |
| 床面積 | 個室の数と通路、受付・調理スペースが収まる面積か |
| 階・位置 | 地階・無窓階・上階だと避難と消防の条件が重くなる |

用途変更の確認申請が要るかどうかは、建築基準法第87条と、特殊建築物への用途変更に関する規定（床面積200㎡を超える場合など）で決まります。用途地域の判断や建築の可否は建築士・特定行政庁の領域です。当社は賃貸借の媒介と重要事項説明を通じて、物件の用途地域・既存用途・面積を契約前に整理します。

飲食を併設する複合カフェでは、飲食店の排気や区画も論点になります。深夜稼働の店舗で物件選びがどこまで決まるかは、[スケルトン物件で飲食店を開くときの排気・防火の考え方](/column/inshokuten-skeleton-bukken-haiki-grease)も参考になります。

## 個室・ブース区画に消防法令上どんな防火・避難の条件がかかる？

複合カフェの肝は個室・ブース区画です。消防法施行令別表第一(2)項ニは、「カラオケボックスその他遊興のための設備又は物品を個室（これに類する施設を含む。）において、客に利用させる役務を提供する業務を営む店舗」を定めており、インターネットカフェ・漫画喫茶はこの対象として施行規則に位置づけられています。個室で客を滞在させる形態のため、火災時の避難の遅れが重く見られます。

| 確認すること | 内容 |
| --- | --- |
| 自動火災報知設備 | (2)項ニは延べ面積にかかわらず設置が必要（平成20年10月1日施行の改正で面積要件が撤廃された） |
| 誘導灯・避難経路 | 個室の配置で避難通路の幅・出口までの距離が確保できるか |
| 内装制限 | 個室の壁・天井の仕上げが内装制限に適合するか |
| 防火対象物使用開始届 | 使用開始の前に、各自治体の火災予防条例に基づき消防署へ届け出る（東京都は使用開始の7日前まで） |

(2)項ニの施設は、小規模でも自動火災報知設備が要る点が、通常の物販店や事務所と大きく違います。既存の建物に個室を後付けする場合、報知設備・誘導灯・区画をあとから整えられるかが物件選びの分かれ目になります。消防用設備の設計・設置と消防署への届出は、消防設備士・特定行政庁の領域です。当社は物件の現況（既設の報知設備・階・無窓階かどうか）を契約前に確認します。

同じく個室・防音・消防が重なる業態として、[カラオケボックスの物件と用途地域・消防・防音の確認点](/column/karaoke-box-tenpo-bukken-youto-shoubou-soon)の整理も、個室区画の考え方の参考になります。

## 東京都のインターネット端末利用営業（本人確認条例）の届出は誰がいつ出す？

東京都では「インターネット端末利用営業の規制に関する条例」（平成22年7月1日施行）が、個室等を設けて客に通信端末機器でインターネットを利用させる営業を規制しています。個室等を一部でも設ける複合カフェは、この「インターネット端末利用営業」に当たります。

| 項目 | 内容 |
| --- | --- |
| 届出の時期 | 営業開始の10日前までに店舗ごとに届け出る（条例第3条） |
| 届出先 | 店舗所在地を管轄する警察署（生活安全課）を経由して東京都公安委員会へ |
| 本人確認 | 利用者に本人確認書類の提示を求めて本人特定事項を確認する義務（条例第4条） |
| 記録の保存 | 本人確認記録・通信端末機器特定記録の作成・保存義務（最終のサービス提供日から3年間） |
| 変更届 | 届出事項に変更があったときは、変更の日から10日以内 |

本人確認と記録の保存は、匿名利用による犯罪を防ぐための条例の中心的な義務です。届出書（別記様式第1号）には、営業時間や本人確認記録・通信端末機器特定記録の作成・保存の方法を記載し、個人営業なら住民票の写し、法人営業なら定款と登記事項証明書などを添えます。

この届出書類の作成や、添付書類の整え方の支援は行政書士の業務です。当社（宅地建物取引業）は届出を代理しません。物件が条例上の「個室等」を設けられる作りかどうか、届出に必要な平面図のもとになる物件情報を、不動産側で整理します。なお東京都以外では条例の有無や内容が異なるため、出店地の公安委員会・警察署で直接確認してください。

## 深夜営業や個室の仕様が風営法・特定遊興に触れないかの線引きは？

複合カフェは深夜まで営業することが多く、「風営法の許可が要るのではないか」と心配されます。通常のネットカフェ・漫画喫茶は、客に飲食をさせながら遊興をさせる「特定遊興飲食店営業」や、接待を伴う「風俗営業」には当たらないのが一般的で、インターネット端末利用営業の届出で足りることが多いとされます。

ただし、線引きは個室で何を提供するかで変わります。たとえば個室で性的なサービスを提供すれば店舗型性風俗特殊営業などの問題が生じ、酒類を提供して深夜に遊興をさせれば特定遊興飲食店営業（風営法）の許可が論点になります。どの営業類型に当たるかの最終的な法的判断は、弁護士と警察（公安委員会）の領域です。当社も行政書士も、営業類型を確定させることはできません。

物件側でできるのは、想定する営業形態（深夜営業の有無、飲食・酒類の提供、個室の仕様）を先に固め、それが建物の用途・消防・条例と整合するかを確認することです。遊技に関わる業態の物件要件は、[ゲームセンター（風営法5号）の物件と用途・面積の確認点](/column/game-center-fuei-5go-bukken-youto-menseki)の整理も、区画と許認可の関係を考える参考になります。

## 内見から契約・届出まで、物件側が落ちやすいチェックポイントは？（分離受任）

複合カフェの出店では、物件・建築・消防・条例届出がそれぞれ別の事業体にまたがります。順番を取り違えると、契約した物件に個室の消防設備を入れられない、用途変更が通らないといった行き違いが起きます。

| 役割 | 誰が担うか |
| --- | --- |
| 物件の調査・賃貸仲介・重要事項説明 | 宅地建物取引業（当社） |
| 用途地域・用途変更の確認申請・内装設計 | 建築士・特定行政庁 |
| 消防用設備の設計・設置・消防署への届出 | 消防設備士・特定行政庁 |
| インターネット端末利用営業の届出書類の作成 | 行政書士 |
| 営業類型（風営法該当性）の法的判断・紛争 | 弁護士 |

実務では、用途地域と既存用途（用途変更の要否）を不動産側で先に確認し、個室区画に自動火災報知設備・避難経路を入れられるかを消防面で見てから、条例の届出へ進むのが分かりやすい順序です。

これらは**それぞれ独立した事業体**であり、**別々にご契約**いただく前提です。当社は物件の不動産面を担い、用途変更や消防設備の設計は建築士・消防設備士へ、条例の届出書類は行政書士へ、営業類型の判断は弁護士へと分けてご案内します。当社は紹介料を受け取りません。

## よくある質問

**Q. 事務所用の空きフロアを、そのままネットカフェにできますか？**
A. 用途変更の確認申請が要るか（床面積200㎡超の特殊建築物への変更など）、個室区画に自動火災報知設備・避難経路を入れられるか、を先に確認します。事務所のままでは消防や避難の条件を満たさないことがあり、内装と設備の整備が前提になります。用途変更の可否は建築士・特定行政庁、消防設備は消防設備士の領域です。

**Q. 東京都のインターネット端末利用営業の届出は、いつ、誰が出しますか？**
A. 東京都では、営業開始の10日前までに店舗ごとに、所在地を管轄する警察署（生活安全課）を経由して東京都公安委員会へ届け出ます（条例第3条）。届出書類の作成支援は行政書士の業務で、当社は代理しません。物件が条例上の「個室等」を設けられる作りかどうかを不動産側で整理します。

**Q. 個室があると、自動火災報知設備は必ず要りますか？**
A. 消防法施行令別表第一(2)項ニに当たる店舗（カラオケボックスやインターネットカフェ等の個室型）は、延べ面積にかかわらず自動火災報知設備が必要です（平成20年10月1日施行の改正で面積要件が撤廃されました）。既存建物に個室を後付けする場合、設備を入れられるかが物件選びの分かれ目になります。設計・設置は消防設備士の領域です。

**Q. 深夜まで営業すると風営法の許可が要りますか？**
A. 通常のネットカフェ・漫画喫茶は、特定遊興飲食店営業や風俗営業には当たらないのが一般的で、インターネット端末利用営業の届出で足りることが多いとされます。ただし、酒類を提供して深夜に遊興をさせる、個室で性的サービスを提供するなどの場合は別の規制が論点になります。営業類型の最終判断は弁護士・公安委員会の領域です。
