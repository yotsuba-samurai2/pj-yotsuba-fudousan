**結論（先に要点）**：クラフトビール醸造所（酒類製造）を開く物件で先に効くのは、①用途地域（醸造所は建築基準法別表第二の「工場」で、作業場の床面積と危険性・環境影響で置ける区域が絞られる）②建物側の要件（タンクを載せる床荷重・天井高・電気容量・冷蔵/貯蔵区画）③醸造排水（BODが高く、水質汚濁防止法の特定施設＋下水道・浄化槽の規制がかかる）④酒類製造免許の最低製造数量（ビールは年60キロリットル、発泡酒は年6キロリットル）の4点です。免許そのものは所轄税務署（国税庁）の所管で、宅地建物取引業者や行政書士の業務範囲ではありません。物件の調査・媒介・売買/賃貸借契約は当社（四葉不動産株式会社）が、タップルームの飲食店営業許可など保健所提出書類の作成は四葉行政書士事務所が担い、免許は税務署、建築確認・床荷重の設計は建築士、排水設備は設備業者、酒税・法人税は税理士へ振ります。これらは独立した事業体で、それぞれ直接ご契約いただきます。

「前のテナントが飲食店だったから、そのまま醸造タンクを入れて開けます」と言われて借りたのに、いざ仕込みを始める段になって床が抜けそう・排水が下水道に流せない・電気が足りない、と分かる。飲食店やクリニックの物件で起きる手戻りが、醸造所ではより重くのしかかります。本記事は、東京でブルーパブ・小規模醸造所を開こうとしている起業者と、その物件を貸す・探す立場の方に向けて、賃貸借契約や購入を決める前に確認できることを、酒税法・都市計画法・建築基準法・水質汚濁防止法・食品衛生法の条文と公的資料から順に整理したものです。酒類製造免許そのものは税務署の所管なので取得の相談先は分けて示し、本記事は不動産の側から見た物件条件に絞ります。可否の最終確認は所轄税務署・特定行政庁・保健所・消防署・自治体の下水道/環境部局の窓口で行います。

## クラフトビール醸造所はどの用途地域なら開けますか？

醸造所は法律上「物を製造する工場」です。飲食店（店舗）や診療所とは扱いが変わり、**用途地域で置ける場所が絞られます**。ここが最初の関門です。

建築基準法（昭和25年法律第201号）第48条と別表第二は、用途地域ごとに建てられる建築物を定めています。工場については、**作業場の床面積の合計**と、**危険性が大きいか著しく環境を悪化させるおそれがあるか**という2つの物差しで区域が分かれます。酒類製造業（醸造）は、危険物を大量に扱う工場や著しい環境悪化のおそれがある工場の類型には通常当たりませんが、作業場の広さによって置ける用途地域が変わります。おおむね次のとおりです。

| 用途地域 | 工場としての扱い（目安） |
|---|---|
| 第一種・第二種低層住居専用地域／田園住居地域 | 原則不可（小規模な兼用住宅の一部などの例外を除く） |
| 第一種・第二種中高層住居専用地域 | 原則不可（工場は建てられない） |
| 第一種・第二種住居地域・準住居地域 | 作業場の床面積が小さく（おおむね50㎡以下）、原動機出力等の条件を満たす範囲で可 |
| 近隣商業地域・商業地域 | 作業場の床面積がおおむね150㎡以下で可 |
| 準工業地域 | 危険性・環境悪化のおそれが少ない工場は原則可（醸造所は置きやすい） |
| 工業地域・工業専用地域 | 可（ただし工業専用地域には住宅・店舗を併設できない） |

**タップルーム（店内提供）を併設して規模も持ちたいなら、準工業地域・工業地域が現実的な候補になりやすい**一方、工業専用地域は飲食提供の店舗を併設できない点に注意が要ります。作業場の床面積の段階（50㎡・150㎡など）と原動機出力の扱いは特定行政庁（自治体の建築主事）の運用で分かれるため、想定する製造規模と物件の用途地域を早い段階で突き合わせてください。用途地域と容積率が土地の値づけをどう動かすかは[日本の土地値はなぜ「容積率」で変わるのか](/column/yosekiritsu-hosei-tochine)に整理しています。事業用物件全般は[投資用・事業用不動産](/toushi)、会社設立とオフィス選びの論点は[会社設立とオフィス選び](/office)をご覧ください。

## 床荷重・天井高・電気容量など建物側で見落としやすい要件は何ですか？

用途地域の次に効くのが、建物そのものが醸造設備に耐えるかです。飲食店の居抜きでは足りない項目が並びます。

| 契約前に確認 | なぜ効くか |
|---|---|
| 床荷重（積載荷重） | 仕込み後の発酵・貯酒タンクは満水で1基あたり数百キログラム〜数トンになる。事務所仕様（1㎡あたり300kg程度）のままでは持たない床がある |
| 天井高 | 縦型の発酵タンク・煙突・配管の立ち上げに高さが要る |
| 電気容量 | 冷却機（チラー）・ボイラー・ポンプ・冷蔵庫で電力を食う。単相しか来ていない物件では動力（三相）の引き込み可否を確認 |
| 給湯・ボイラー・ガス容量 | 仕込みの加熱（湯煮）に大量の熱源が要る |
| 冷蔵・貯蔵の区画 | 発酵・貯酒・原料（麦芽・ホップ）・製品の温度管理区画を取れるか |
| 搬入経路 | タンク・製品パレットの搬入出、フォークリフトが通れる間口・前面道路の幅員 |

床荷重は特に見落とされがちです。**満水のタンクは局所的に重く、事務所や小売店の床仕様では補強が要ることがあります。** 床の補強・構造の可否は建築士（構造設計）の判断です。既存建物の構造を確認したうえで、必要な補強の範囲と、それが賃貸借契約の原状回復にどう跳ね返るかを、契約前に貸主と詰めておくと手戻りが減ります。中古建物では検査済証の有無も確認しておきます。検査済証がない中古建物は、用途変更の確認申請や融資で支障が出ることがあり、法適合状況調査で建築時の適法性を確かめられる場合があります。この論点は[検査済証のない中古物件を福祉用途に転用できるか](/column/kensazumisho-nashi-bukken-fukushi-youto-henko)に整理しています。設計・施工は建築士と設備業者が、当社（不動産会社）は物件がこれらの条件を満たせるかの下調べと貸主との条件交渉に伴走します。

## 醸造排水（BOD・水量）と下水道・浄化槽の規制はどこを確認しますか？

醸造所は飲食店以上に**水と有機物**を扱います。仕込み・洗浄・酵母・麦芽かす由来の排水はBOD（生物化学的酸素要求量）が高く、量も多いのが特徴です。ここが物件選びに直結します。

まず、醸造所は水質汚濁防止法（昭和45年法律第138号）の**特定施設**を置く事業場になり得ます。同法施行令別表第一は、酒類製造業（ビール・清酒等）の用に供する洗びん施設・原料を湯煮により加熱処理する施設・ろ過施設・蒸留施設などを特定施設として挙げています。特定施設を設置しようとするときは、都道府県知事等への届出が必要です（同法第5条）。公共用水域（河川等）へ排水する場合は、同法第3条に基づく排水基準（BOD・SSなどの許容限度）が適用されます。

次に、多くの都市部の物件は公共下水道に接続します。この場合は下水道法（昭和33年法律第79号）と各自治体の下水道条例が効き、特定施設の設置等の届出（下水道法第12条の3）や、基準を超える排水を薄めずに処理する**除害施設**の設置が求められることがあります。下水道の区域外で浄化槽を使う物件では、浄化槽法に基づく処理と維持管理が別に要ります。

| 排水の確認点 | どこで確認するか |
|---|---|
| 公共下水道か浄化槽か・接続の可否 | 自治体の下水道局・物件の給排水図 |
| 特定施設の届出の要否 | 都道府県・自治体（水質汚濁防止法・下水道法） |
| 除害施設が要るか（BOD等の排除基準） | 自治体の下水道条例。数値は自治体で異なる |
| 排水管の口径・勾配・排水量の余裕 | 設備業者・給排水図 |

**排水の基準値や届出の運用は自治体で異なり、書く時点でも変わり得ます。** 醸造規模（年間何キロリットルを、どれだけの水を使って仕込むか）を伝えたうえで、着手前に自治体の下水道・環境部局へ直接確認してください。排水設備・除害施設の設計施工は設備業者が担い、排水協議には指定工事店が関わります。給排水と換気の物件条件は、飲食店の[スケルトン物件で飲食店を開くとき、排気・グリストラップ・防火で物件選びはどこまで決まるか](/column/inshokuten-skeleton-bukken-haiki-grease)や[クリーニング店の物件と給排水・排水処理](/column/cleaning-jo-bukken-youken-kyusuisui-shori)と共通する論点が多く、参考になります。

## 酒類製造免許の最低製造数量とは何で、誰に相談すればいいですか？

酒類を製造するには、物件の要件とは別に、**酒類製造免許**が要ります。これは物件の話とは所管が違います。

酒税法（昭和28年法律第6号）第7条第1項は、酒類を製造しようとする者は、製造しようとする酒類の品目別に、**製造場ごとに、その製造場の所在地の所轄税務署長の免許を受けなければならない**と定めます。つまり免許の所管は所轄税務署（国税庁）で、**宅地建物取引業者や行政書士の業務範囲ではありません**。

そして、免許には**最低製造数量基準**があります。酒税法第7条第2項は、1年間の見込製造数量が品目ごとに定める数量に達しない場合には免許を受けられないと定めています。クラフトビールに関わる主な数量は次のとおりです。

| 品目 | 年間の最低製造数量 |
|---|---|
| ビール | 60キロリットル |
| 発泡酒 | 6キロリットル |
| 果実酒 | 6キロリットル |
| リキュール | 6キロリットル |
| 清酒 | 60キロリットル |

**ここがクラフトビール開業で最も知られた分かれ目です。** 「ビール」の免許は年60キロリットルの製造見込みが要りますが、果実や香辛料などの副原料を使い「発泡酒」に当たる造りにすると、最低製造数量は年6キロリットルまで下がります。小規模なブルワリーが発泡酒免許で始め、規模の拡大に合わせてビール免許を検討する、という流れが一般的なのはこのためです。なお2018年（平成30年）4月1日の酒税法改正で「ビール」の定義が広がり（麦芽比率が67%以上から50%以上に引き下げられ、果実や香辛料等の副原料が認められた／酒税法第3条第12号）、従来は発泡酒だった商品の一部がビールに含まれるようになりましたが、免許ごとの最低製造数量の区別は残っています。免許を与えないことができる場合（人的要件・場所的要件・経営基礎要件・需給調整要件などの拒否要件）は同法第10条に定められています。

**免許の要否・可否の最終判断は所轄税務署です。** 想定する品目と製造数量を整理したうえで、税務署の酒類指導官（酒類担当）や、酒類の免許に精通した専門家に相談してください。当社・当事務所はこの免許そのものの取得を代行しません。物件が製造・排水・電気の条件を満たすかの確認までを担います。

## 醸造とタップルーム（飲食提供）を併設するなら物件で何が変わりますか？

自社ビールを店内で飲ませるブルーパブ（タップルーム併設）にすると、**製造の免許とは別に、飲食提供の許可**が重なります。物件条件も一段増えます。

店内でビールを提供して飲食させる営業は、食品衛生法（昭和22年法律第233号）第55条の**飲食店営業の許可**（保健所）が必要です。厨房・手洗い・区画など保健所の施設基準を満たせるかを、契約前に確認します。飲食店営業許可の物件条件は[飲食店の営業許可と保健所の施設基準](/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)（行政書士）に整理しています。

さらに、造った酒を店の外へ売る（ボトル・缶で小売する）なら別途**酒類販売業免許**が、深夜0時以降に主として酒類を提供するなら**深夜酒類提供飲食店営業の届出**が要ります。これらは製造とは別の許認可で、店舗の許認可申請書類の作成は行政書士の業務です。酒類の小売免許と店舗の物件要件は[酒類小売免許が取れる店舗物件の条件](/legal/column/shurui-kouri-menkyo-tenpo-bukken-yoken)、深夜提供の届出は[深夜酒類提供飲食店営業の届出の要件](/legal/column/shinya-shurui-teikyo-todokede-yoken)（いずれも行政書士）にまとめています。

| 併設で増える確認 | 所管・担い手 |
|---|---|
| 店内提供の飲食店営業許可 | 保健所／申請書類は行政書士 |
| ボトル・缶の小売（酒類販売業免許） | 所轄税務署 |
| 深夜0時以降の酒類提供の届出 | 警察署／届出書類は行政書士 |
| 消防用設備・避難（客席が増える） | 消防署・消防設備士 |
| 工業専用地域では店舗併設不可 | 特定行政庁（用途地域） |

**製造だけの物件と、飲食提供も行う物件では、用途地域・消防・保健所の見方が変わります。** タップルームを持つなら、工業専用地域を避け、飲食提供の施設基準と消防を満たせる物件を選ぶ、という順で絞り込みます。

## よくある質問

**Q. クラフトビール醸造所は住宅街（第一種低層住居専用地域）に開けますか？**
A. 原則できません。醸造所は建築基準法別表第二の「工場」に当たり、第一種・第二種低層住居専用地域や中高層住居専用地域では建てられません。住居系地域でも作業場の床面積が小さければ置ける余地はありますが、製造規模が上がると近隣商業・商業（作業場おおむね150㎡以下）や準工業・工業地域が現実的です。用途地域上の可否は物件ごとに異なるため、特定行政庁の窓口で確認してください。

**Q. 飲食店の居抜き物件なら、そのまま醸造タンクを入れて始められますか？**
A. 始められるとは限りません。飲食店仕様の床は満水のタンク（1基で数百キロ〜数トン）を想定していないことが多く、床荷重の補強が要る場合があります。電気（動力）容量、給湯・ボイラー、排水の口径と処理も足りないことがあります。床荷重と構造は建築士、排水は設備業者と自治体に、契約前に確認してください。

**Q. 醸造所の排水はそのまま下水道に流せますか？**
A. そのままとは限りません。醸造排水はBOD（有機物）が高く、量も多いため、公共下水道では下水道法と自治体の下水道条例に基づき、特定施設の届出や除害施設の設置が求められることがあります。基準値は自治体で異なるので、想定する醸造規模を伝えて、着手前に自治体の下水道・環境部局へ確認してください。

**Q. ビールの免許は年60キロリットルも造れないと取れないのですか？**
A. 「ビール」の免許は年60キロリットルの製造見込みが要件です（酒税法第7条第2項）。一方、副原料の使い方によって「発泡酒」に当たる造りにすると、最低製造数量は年6キロリットルまで下がります。小規模な醸造所が発泡酒免許で始める例が多いのはこのためです。免許の要否・可否の判断は所轄税務署の所管なので、品目と製造数量を整理して税務署に相談してください。
