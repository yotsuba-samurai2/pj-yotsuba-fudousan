**結論（先に要点）**：「経営・管理」の在留資格で事業所として認められる物件は、住居と明確に区分された独立区画で、法人名義・事業用の使用目的で借りられ、外見上も事業所として確認できる状態にあることが骨格です。令和7年（2025年）10月16日施行の改正で資本金・出資の総額は3,000万円以上、常勤職員1人以上などに引き上げられ、自宅兼事業所は原則として認められなくなりました。当社は物件が事業所として使えるかの情報提供まで、在留資格の申請・事業計画書は行政書士、会社の設立登記は司法書士、資本金・税務は税理士へ、別々にご契約いただく形でご案内します。

日本で会社を設立し「経営・管理」の在留資格を取ろうとする中国本土・台湾の起業家と、その代理をする現地の専門家に向けて、在留資格の審査で事業所として認められる物件の条件を、出入国管理及び難民認定法と上陸許可基準省令、出入国在留管理庁の案内から整理します。当社は物件の独立性・用途・賃貸借契約という不動産側の情報提供を担い、在留資格の可否判断や事業計画の作成は行いません。該当する領域はそれぞれの専門家へ、別々にご契約いただく形でご案内します。

## 在留資格の審査で「事業所」と認められる物件の条件は何か

骨格は3つです。第一に、住居と明確に区分された独立区画であること。第二に、法人名義で、事業用の使用目的で借りられていること。第三に、看板・表札等で外見上も事業所として確認できる状態にあること。加えて改正後は、その事業の規模に見合う事業所であることが求められます。

「経営・管理」は入管法別表第一の二に掲げる在留資格で、本邦で事業の経営・管理に従事する活動が対象です。上陸許可基準（出入国管理及び難民認定法第七条第一項第二号の基準を定める省令。平成2年法務省令第16号）は、事業を営むための事業所が本邦に存在することを求め、事業がまだ開始されていない場合は事業所として使用する施設が本邦に確保されていることを要します。出入国在留管理庁の審査では、その施設が住居や私的空間と区別された、継続的に事業に使える独立の区画かどうかが見られます。

| 確認項目 | 事業所として見られるポイント |
|---|---|
| 独立性 | 住居・私的空間と明確に区分された独立区画か |
| 名義・目的 | 法人名義で、賃貸借契約の使用目的が事業用か |
| 継続性 | 月単位の短期スペースでなく継続的に使えるか |
| 外見 | 看板・表札等で事業所と確認できる状態か（審査の一材料） |
| 規模 | 改正後の事業規模（資本金3,000万円以上等）に見合う広さ・実体か |

事業所要件の最終的な判断は出入国在留管理庁が個別に行うため、物件を押さえる前に、申請を担う行政書士と事業所の実体について擦り合わせておくのが確実です。

## 自宅兼用やバーチャルオフィスでも経営・管理ビザは通るのか

令和7年10月16日の改正後、自宅を事業所と兼ねることは原則として認められなくなりました。バーチャルオフィス（住所だけを借りる形態）や、誰でも使えるコワーキングスペースの共用部分も、独立した事業所の実体を示しにくいため原則として事業所要件を満たしません。

住居と事業所が同じ空間だと、事業所としての独立性・実体を示しにくく、改正後の審査ではここが通りにくくなりました。レンタルオフィスの個室・一区画やインキュベーション施設でも、会社名義で明確に区分され、継続的に事業に使える実体があるかで判断が分かれます。バーチャルオフィスで会社設立まではできても、在留資格の事業所要件で詰まる論点は[バーチャルオフィスで会社設立｜できること・許認可で詰まること](/legal/column/office-virtual-office-kyoninka)に整理されています。物件がどこまで事業所の実体を備えるかは、当社が独立区画・名義・使用目的という現況を情報提供し、在留資格上の可否は行政書士へ振ります。

| 形態 | 事業所要件の見込み |
|---|---|
| 自宅兼事業所 | 改正後は原則認められない |
| バーチャルオフィス（住所のみ） | 原則不可（独立の実体を示しにくい） |
| コワーキング共用部 | 原則不可 |
| レンタルオフィスの個室・専用区画 | 会社名義・明確な区分・継続利用があれば可の余地（個別判断） |
| 独立した事業用テナント | 事業所として認められやすい |

## 賃貸借契約の名義と使用目的はどう書いておくべきか

事業所として認められるには、賃貸借契約を法人名義（設立前なら設立後に名義を切り替える段取り）で結び、使用目的を事業用（事務所）としておくことが前提です。居住用契約のまま事務所として使うと、事業所の実体が否定されるだけでなく、貸主との契約違反にもなり得ます。

契約前に、貸主・管理会社へ事務所利用の可否と使用目的の明記を確認し、重要事項説明で用途地域・用途制限・原状回復・看板設置の可否を押さえます。これらは宅地建物取引業法第35条の重要事項説明と第37条書面で明らかにすべき事項です。当社は物件側の調整と重要事項説明を担い、法人設立のタイミングと契約名義の段取りは、会社の設立登記を担う司法書士、在留資格の申請を担う行政書士と役割を分けて進めます。

| 契約上の論点 | 押さえどころ |
|---|---|
| 名義 | 法人名義（設立前は設立後の名義切替の段取りを貸主と合意） |
| 使用目的 | 事業用（事務所）として明記。居住用契約のままにしない |
| 看板・表札 | 設置可否を契約・管理規約で確認 |
| 重要事項説明 | 用途地域・用途制限・原状回復・費用（宅建業法第35条・第37条書面） |

## 中国・台湾から契約するとき内見・重要事項説明はどう進めるのか

来日前の段階でも、オンライン内見と、宅地建物取引業法が認めるIT重説（テレビ会議等を用いた重要事項説明）で手続きを進められます。重要事項説明は宅地建物取引士が記名した重要事項説明書に基づいて行い、契約内容は第37条書面で確認します。

非居住者・設立前の法人が当事者になる場合は、本人確認書類、署名・サインの取り方、代金送金の経路（海外からの着金）など、国内取引にはない確認が重なります。中国本土からの送金は資本規制や着金の遅延が絡むことがあり、決済スケジュールに余裕を見ておくのが実務上の鍵です。当社は不動産取引の進め方と重要事項説明を担い、資本金の払込みや税務、送金に伴う在留資格・会社設立の段取りは、税理士・司法書士・行政書士へそれぞれ振ります。

| 進め方 | ポイント |
|---|---|
| 内見 | オンライン内見で候補を絞り、可能なら来日時に実地確認 |
| 重要事項説明 | 宅地建物取引士によるIT重説が可能（記名した重説書に基づく） |
| 本人確認 | 非居住者・設立前法人の本人確認、署名・サインの取り方 |
| 決済 | 海外送金の経路・着金時期に余裕を見る |

## よくある質問

**Q. 自宅の一室を事務所にして経営・管理ビザは取れますか？**
A. 令和7年10月16日の改正後、自宅を事業所と兼ねることは原則として認められなくなりました。住居と区別された独立区画で、法人名義・事業用の使用目的で借りた事業所が前提です。個別の可否は在留資格の論点なので、申請を担う行政書士にご確認ください。当社は物件が独立区画として使えるかの情報提供を担います。

**Q. バーチャルオフィスの住所でも事業所として認められますか？**
A. 住所だけを借りるバーチャルオフィスや、誰でも使えるコワーキングの共用部分は、独立した事業所の実体を示しにくいため原則として事業所要件を満たしません。レンタルオフィスの専用個室は、会社名義・明確な区分・継続利用があれば認められる余地がありますが、個別判断です。会社設立と許認可で詰まる論点は行政書士の記事もご参照ください。

**Q. 賃貸借契約は個人名義と法人名義のどちらで結べばよいですか？**
A. 事業所として認められるには法人名義・事業用の使用目的が前提です。設立前は、設立後に法人名義へ切り替える段取りを貸主と合意しておきます。居住用契約のまま事務所として使うと、事業所の実体が否定され、貸主との契約違反にもなり得ます。名義切替のタイミングは設立登記を担う司法書士と合わせてご調整ください。

**Q. 来日前でも物件を決めて契約できますか？**
A. オンライン内見で候補を絞り、宅地建物取引業法が認めるIT重説（テレビ会議等を用いた重要事項説明）で手続きを進められます。非居住者・設立前法人の本人確認や海外からの送金の着金時期など、国内取引にない確認が重なるため、決済スケジュールに余裕を見ておくのが実務上の鍵です。資本金の送金・税務は税理士、会社設立は司法書士へご相談ください。
