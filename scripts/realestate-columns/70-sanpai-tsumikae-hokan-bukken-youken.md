**結論（先に要点）**：産業廃棄物の「積替え・保管」を行う拠点は、倉庫や資材置場をただ借りれば足りるものではありません。物件側で効くのは3点です。①用途地域——上屋などの建築物を設けるなら建築基準法第48条・別表第二の用途制限を受け、実務では準工業・工業・工業専用地域が向きます。②囲いと掲示板——飛散・流出・地下浸透・悪臭を防ぐ囲いと、縦横おおむね60cm以上の掲示板が要ります。③保管の上限量と高さ——積替えのための保管量は1日あたりの平均的な搬出量の7日分が上限で、屋外で容器を使わず積む場合は高さの制限がかかります。物件の選定と用途地域の確認は当社（四葉不動産株式会社）が、積替え・保管を含む産業廃棄物収集運搬業の許可申請は行政書士が、施設基準への適合確認や建築確認は建築士が、それぞれ独立した事業体として別々にご契約いただく形で分担します。

産業廃棄物の収集運搬業で「積替え・保管」の拠点を構えたいが、どんな物件なら基準を満たせるのか——この記事は、そうした拠点物件を探す事業者に向けて、契約前に不動産の側から確認できる点を、廃棄物処理法・建築基準法の条文と自治体の許可申請の手引きから順に整理したものです。物件の調査・選定・媒介は当社が情報提供として担い、許可の可否や施設基準への最終的な適合判断は行政書士・建築士など有資格者が行います。単に運ぶだけの収集運搬（積替え保管なし）と、拠点で一時保管する積替え・保管とでは、物件に求められる条件がはっきり変わります。

## 産廃の積替え・保管ができる物件は、どの用途地域が向くのか？

まず押さえたいのは、「積替え・保管の場所そのもの」と「そこに建てる建築物」を分けて考えることです。屋外に野積みするだけで建築物を伴わない保管場所は、建築基準法の用途地域の建築制限を直接は受けません。一方、上屋・倉庫・事務所などの建築物を設けるなら、その建築物が建築基準法第48条・別表第二の用途制限を受けます。

そのうえで、実務上の立地は自治体の産業廃棄物処理業の許可審査でも見られます。住居系の用途地域は近隣とのトラブルや生活環境上の支障が問題になりやすく、多くの自治体の手引きが工業系（準工業地域・工業地域・工業専用地域）を前提に案内しています。

| 論点 | 物件で確認すること |
|---|---|
| 建築物を建てるか | 上屋・事務所を設けるなら建築基準法第48条・別表第二の用途制限を受ける。住居専用地域は不可・制限が厳しい |
| 屋外の野積みか | 建築物でなければ用途地域の建築制限は直接受けないが、自治体の立地基準（住居系を避ける等）は別途かかりやすい |
| 市街化調整区域 | 建築物を伴う場合は都市計画法の開発許可・建築許可という別の壁がある |
| 近隣環境 | 飛散・悪臭・騒音・車両の出入りで周辺と衝突しないか |

事業用物件の探し方の全体像は[事業用不動産をお探しの方へ](/toushi)、拠点・事務所の構え方は[オフィス・事業所の物件](/office)に整理しています。似た論点の拠点物件としては、[運送業の営業所・車庫の物件](/column/unsou-eigyosho-shako-bukken-yoken)や[自動車の解体・破砕業の物件](/column/chuko-jidosha-kaitai-hasai-bukken-youken)もあわせてご覧ください。

## 囲い・掲示板・飛散流出防止など、物件側に必要な設備は何か？

産業廃棄物を保管するときは、生活環境の保全上の支障が生じないよう、施行令が定める保管基準を満たす必要があります（廃棄物処理法第14条、廃棄物処理法施行令第6条第1項第1号）。積替えのための保管も、この保管基準に沿うことが前提です。物件を選ぶ段階で確認できるのは、次の設備・区画を後から整えられるかどうかです。

| 求められること | 物件で確認する点 |
|---|---|
| 囲い | 保管場所の周囲に囲いを設けられるか。積み上げた廃棄物の荷重が直接かかる場合はその構造にも耐えること |
| 掲示板 | 縦・横それぞれおおむね60cm以上の掲示板を掲げられる場所があるか（保管場所である旨・種類・管理者と連絡先・最大保管高さ等を表示） |
| 飛散・流出防止 | 風による飛散、雨水による流出を防げるか。屋根・シート・区画で対応できる素地があるか |
| 地下浸透・汚水対策 | 油分や汚液が地下へ浸透しないよう、床のコンクリート舗装・排水・油水分離ができるか |
| 悪臭・害虫 | 周辺へ悪臭が及ばないか。腐敗しやすい品目を扱うなら密閉・換気の余地があるか |

これらは物件の「素地」で決まります。土間コンクリートが打たれ、排水と囲いが設けやすい平場の倉庫・工場・資材置場は適合させやすく、逆に土がむき出しで排水経路のない土地は、地下浸透対策の工事負担が大きくなります。

## 保管できる上限量と、面積・高さの制限はどう決まるのか？

積替え・保管には数量の上限があります。積替えのために保管できる産業廃棄物の量は、その積替えの場所における1日あたりの平均的な搬出量に7を乗じた量（＝おおむね7日分）が上限とされています。「運ぶ途中で一時的に置く」ための保管であって、長期の在庫置場ではない、という趣旨です。

高さにも制限があります。屋外で容器を用いずに保管する場合、囲いに接しない部分は勾配がおおむね50%以下、囲いに接する部分は囲いの下端から一定の高さ（囲いに廃棄物の荷重がかからないよう、囲いの内側2mまでは囲いの高さより50cm低く、2mを超える部分は勾配50%以下）に抑える必要があります。数量・高さの具体的な数字は自治体の許可申請の手引きに図解されています。

| 項目 | 目安 |
|---|---|
| 積替えのための保管上限量 | 1日あたりの平均的な搬出量の7日分 |
| 屋外・容器なしの積み上げ高さ | 囲いに接しない部分は勾配50%以下、囲いに接する部分はさらに制限 |
| 必要な面積 | 取扱品目・搬出量・車両の回転から逆算（自治体の手引きの図を参照） |
| 品目ごとの追加基準 | 石綿含有産業廃棄物・特別管理産業廃棄物などは上乗せの基準あり |

つまり物件の広さは「多く積めるほどよい」のではなく、搬出量から逆算した必要量を、囲い・高さの制限を守って置ける平場が取れるか、で判断します。

## 積替え保管なしの収集運搬と、物件要件はどう違うのか？

同じ産業廃棄物収集運搬業でも、「積替え・保管を含まない」場合と「含む」場合とで、物件に求められる条件は大きく変わります。

| | 積替え・保管なし | 積替え・保管あり |
|---|---|---|
| 物件（拠点）の位置づけ | 車両を止める車庫・事務所があれば足りることが多い | 保管基準を満たす保管場所そのものが許可の対象になる |
| 用途地域・立地 | 事務所・車庫の用途制限を見る | 保管場所の立地・囲い・排水まで見る（工業系が向く） |
| 数量・高さの制限 | ——（積み替え・保管をしない） | 平均搬出量の7日分・積み上げ高さの制限がかかる |
| 許可の範囲 | 収集運搬業（積替え保管を除く） | 収集運搬業（積替え保管を含む）——申請区分が別 |

「運ぶだけ」なら車庫と事務所の要件を満たす物件で足りることが多いのに対し、「拠点で一時保管する」なら、その保管場所が保管基準に適合することが許可の前提になります。ここを取り違えて住居系の用途地域や排水のない土地を契約すると、後から施設を整えられず許可に届かない、という事態になりかねません。物件を決める前に、扱う品目・搬出量と、想定する積替え・保管の有無を固めておくのが安全です。

## よくある質問

**Q. 倉庫を借りれば、すぐに産廃の積替え・保管に使えますか？**
A. すぐには使えないことが多いです。積替え・保管の場所は、囲い・掲示板・飛散流出防止・地下浸透対策など保管基準（廃棄物処理法第14条、施行令第6条第1項第1号）を満たす必要があり、住居系の用途地域や排水のない土地では適合させにくいです。物件を決める前に、扱う品目・搬出量と施設の整備可否を確認するのが安全です。

**Q. どのくらいの量まで保管してよいのですか？**
A. 積替えのための保管量は、その場所の1日あたりの平均的な搬出量の7日分が上限とされています。長期の在庫置場ではなく、運搬の途中で一時的に置くための保管、という位置づけです。具体的な数量・高さの図解は自治体の許可申請の手引きに載っています。

**Q. 用途地域はどこでもよいのですか？**
A. 上屋などの建築物を設けるなら建築基準法第48条・別表第二の用途制限を受け、住居専用地域は不可・制限が厳しくなります。屋外の野積みで建築物を伴わない場合でも、多くの自治体は生活環境上の支障を避けるため工業系（準工業・工業・工業専用）を前提に案内しています。

**Q. 許可申請の書類作成もお願いできますか？**
A. 許可申請の書類作成は行政書士（四葉行政書士事務所）が承ります。当社（不動産）は物件の選定・用途地域の確認・媒介を担い、施設基準への適合確認や建築確認は建築士が担います。これらは独立した事業体として別々にご契約いただきます。
