**結論（先に要点）**：リバースモーゲージ（リ・バース60）付きの実家を相続したら、まず金融機関へ連絡し、元金の残高と返済期限、ノンリコース型かリコース型かを確認します。元金は契約者の死亡時に、相続人が一括返済するか担保物件の売却代金で返済する仕組みです。売却して精算する場合は、査定・媒介・決済での残債一括返済・抵当権抹消までを段取りします。残債の法的評価や相続放棄の可否は弁護士、抵当権抹消と相続登記は司法書士へ分けて進めます。

親がリバースモーゲージを利用していた自宅を相続すると、「残っている借金はどうなるのか」「売らないと返せないのか」「相続放棄した方がよいのか」と不安になります。リバースモーゲージは、生前は利息だけを払い、元金は契約者が亡くなったときに一括で返す住宅ローンです。通常の住宅ローンとは返済のタイミングと精算の構造が違います。

住宅金融支援機構の【リ・バース60】は、機構の住宅融資保険を付して民間金融機関が提供する満60歳以上向けの商品です。元金は、借入者が亡くなったときに、相続人が一括返済するか、担保物件（住宅および土地）の売却代金で返済します。まず自分が相続した物件がこの仕組みに当てはまるかを確認することが出発点です。

四葉不動産株式会社は、東京都文京区小日向を拠点に、不動産の売却相談と仲介を承っています。残債精算のための売却について、進め方と確認事項を整理するところからご相談いただけます。

## リバースモーゲージの残債は相続でどう扱われる？

民法第896条は、相続人が相続開始の時から被相続人の財産に属した一切の権利義務を承継すると定めています（一身専属のものを除く）。したがってリバースモーゲージの残債（借入金の返済義務）も、原則として相続人が承継します。相続した時点で、担保物件とともに返済の義務も引き継ぐことになります。

【リ・バース60】は、元金を死亡時に一括返済する商品です。返済の方法は、相続人による一括返済か、担保物件の売却代金による返済のいずれかです。売却で精算するか、手元資金で返済して物件を残すかは、相続人が選べます。

| 確認すること | 内容 |
| --- | --- |
| 残高 | 元金の残高と、精算までに生じる利息 |
| 返済期限 | 死亡後、いつまでに一括返済・売却を求められるか（金融機関・契約による） |
| 返済責任の型 | ノンリコース型かリコース型か |
| 連帯債務 | 配偶者等が連帯債務者か。両方が亡くなったときが一括返済の時期になる場合がある |

まず取扱金融機関へ連絡し、残高・期限・契約の型を書面で確認します。返済方法や期限の細目は金融機関・契約によって異なるため、約款と残高証明で確かめます。残債の計算や税額の確定は、当社の業務ではありません。

## ノンリコース型とリコース型で相続人の負担はどう違う？

【リ・バース60】には、担保物件の売却代金で残債を返しきれなかった場合の扱いが2種類あります。ここが通常の住宅ローンと大きく違う点です。

| 型 | 売却代金で返しきれない残債の扱い |
| --- | --- |
| ノンリコース型 | 相続人は残った債務の返済を求められない |
| リコース型 | 残った債務は相続人が返済する義務を負う |

ノンリコース型であれば、担保物件を売って代金を返済に充てた後、不足が出ても相続人に残債の請求が及びません。リコース型では、売却後の不足分を相続人が返す必要があります。自分が相続した契約がどちらの型かで、売却後に負担が残るかどうかが変わります。

どちらの型かは契約で決まっており、相続人が後から選び直せるものではありません。ノンリコースかリコースかの評価、金融機関との交渉に関わる法律事務は弁護士の領域です。当社は売却の段取りを担い、型の法的評価は弁護士へ、残高の確認は金融機関へとおつなぎします。

通常の住宅ローン残債と抵当権抹消が中心の相続は、[相続した実家に住宅ローンの残債と抵当権が残っているときの売却](/column/souzoku-jikka-juutaku-loan-zansai-teitouken-massho-baikyaku)で扱っています。本記事は、死亡時一括返済・ノンリコース特約というリバースモーゲージ特有の精算構造に限定します。

## 残債精算のために売却する流れと期限は？

売却して残債を精算する場合、通常の売却に「残債の一括返済」と「抵当権の抹消」という段取りが加わります。担保物件には金融機関の抵当権が設定されているため、決済時に売買代金から残債を返済し、同時に抹消するのが基本です。

| 段階 | 確認する内容 |
| --- | --- |
| 連絡・確認 | 金融機関へ連絡し、残高・返済期限・型・抵当権の内容を確認 |
| 査定・媒介 | 担保物件の査定、媒介契約、販売方針の決定 |
| 売買契約 | 買主との契約。残債の一括返済を前提とした決済の組み立て |
| 決済・抹消 | 売買代金から残債を一括返済し、抵当権抹消登記・相続登記を行う |
| 精算 | 残余があれば相続人へ。ノンリコース型で不足が出ても残債請求は及ばない |

死亡後、一括返済・売却までにどれくらいの期間が認められるかは、金融機関・契約によって異なります。据置きや猶予の有無も含め、早めに金融機関へ確認します。抵当権抹消登記と相続登記は司法書士の業務で、当社は登記を代理しません。相続登記は2024年4月1日から義務化されており、期限の確認が必要です。

譲渡所得（取得費・譲渡費用・特例の適用）の計算は税理士の領域です。売却益が出るかどうかは、取得費や特例の適用で変わります。税額の見込みは税理士に確認します。

## 相続放棄と売却精算はどちらを選ぶ？誰に相談する？（分離受任）

「残債があるなら相続放棄すべきか」という相談をよくいただきます。選択は、ノンリコース型かリコース型か、他に負債があるか、物件を残したいかによって変わります。

民法第915条第1項は、相続の承認・放棄を、自己のために相続の開始があったことを知った時から3か月以内にしなければならないと定めています（期間は伸長できる場合があります）。相続放棄をすると、民法第939条により初めから相続人とならなかったものとみなされ、担保物件を含む相続財産を一切受け取れなくなります。

| 選択肢 | 向く場面（一般論） |
| --- | --- |
| 売却して精算 | ノンリコース型で、物件を手放してよい場合。売却後に残債が残らない前提 |
| 返済して物件を残す | 手元資金で一括返済でき、実家を保有し続けたい場合 |
| 相続放棄 | リコース型で残債が大きい、または他に多額の負債がある場合。ただし他の財産も失う |

ノンリコース型で他に負債がなければ、売却して精算すれば残債は残らないのが原則のため、相続放棄をせずに済む場合があります。一方、リコース型や他の負債がある場合は、放棄も含めて検討します。熟慮期間は3か月と短いため、早めの確認が必要です。

| 役割 | 誰が担うか |
| --- | --- |
| 担保物件の査定・売却の媒介 | 宅地建物取引業（当社） |
| 抵当権抹消登記・相続登記 | 司法書士 |
| 相続放棄の可否・ノンリコース/リコースの法的評価・金融機関との交渉 | 弁護士 |
| 譲渡所得・取得費・税額の計算 | 税理士 |
| 残債・返済方法・期限 | 取扱金融機関 |

これらは**それぞれ独立した事業体**であり、**別々にご契約**いただく前提です。当社は売却の段取りを担い、法的評価は弁護士、登記は司法書士、税務は税理士、残債は金融機関へと分けてご案内します。当社は紹介料を受け取りません。

## よくある質問

**Q. リバースモーゲージの残債は、相続すると必ず自分が払うのですか？**
A. 民法第896条により残債の返済義務も原則として相続人が承継します。【リ・バース60】は死亡時に元金を一括返済する商品で、相続人による一括返済か担保物件の売却代金での返済を選べます。ノンリコース型なら、売却代金で返しきれなくても残債の請求は及びません。

**Q. ノンリコース型とリコース型は、相続後に選び直せますか？**
A. 選び直せません。どちらの型かは契約で決まっています。ノンリコース型は売却後に残債が残らず、リコース型は不足分を相続人が返す義務を負います。自分の相続した契約がどちらかを、金融機関で確認します。型の法的評価は弁護士の領域です。

**Q. 相続放棄と売却では、どちらが得ですか？**
A. ノンリコース型で他に負債がなければ、売却して精算すれば残債が残らないため放棄をせずに済む場合があります。リコース型や他の負債がある場合は放棄も検討します。放棄は3か月の熟慮期間内に行い、他の相続財産も失います。可否の判断は弁護士に確認します。

**Q. 売却の決済と抵当権の抹消は、どう進みますか？**
A. 担保物件には金融機関の抵当権が設定されているため、決済時に売買代金から残債を一括返済し、同時に抵当権抹消登記を行うのが基本です。抹消登記と相続登記は司法書士が担います。当社は査定・媒介と、残債を前提とした決済の段取りを整理します。
