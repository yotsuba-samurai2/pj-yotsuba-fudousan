**結論（先に要点）**：定員20名以上の認可保育所の物件で小規模保育と決定的に変わるのは、屋外遊戯場（園庭。付近の公園等で代替可）、乳児室・ほふく室を含む居室面積、そして2階以上に保育室を置くときの2方向避難と耐火の3点です。保育所は用途地域では詰まりません（建築基準法別表第二で第一種低層住居専用地域でも建てられ、工業専用地域でも制限の対象になっていません）。詰まるのは面積・避難・用途変更の確認申請・消防です。当社は物件の用途・面積・避難・消防の現況という情報提供まで、認可申請と設備運営基準の適合審査は行政書士と市区町村、確認申請・採光避難の計算は建築士、人員・労務は社会保険労務士へ、別々にご契約いただく形でご案内します。

文京区・近隣で定員20名以上の認可保育所の本体施設を探す社会福祉法人・学校法人・株式会社の開設担当と、その不動産担当に向けて、小規模保育の物件探しと「何が同じで、何が変わるのか」を児童福祉施設の設備及び運営に関する基準（昭和23年厚生省令第63号）・建築基準法・消防法施行令から整理します。当社は物件の用途・構造・面積・消防の現況という情報提供を担い、認可の可否や採光・避難の計算、人員配置・労務の設計は行いません。該当する領域はそれぞれの専門家へ、別々にご契約いただく形でご案内します。

## 認可保育所と小規模保育では物件に求められる面積・設備はどう違うのか

根拠となる省令が別で、認可保育所（定員20名以上）は屋外遊戯場・乳児室・ほふく室・保育室/遊戯室の面積がそれぞれ定められます。満2歳未満の子を預かるなら乳児室1人1.65㎡以上・ほふく室1人3.3㎡以上、満2歳以上は保育室又は遊戯室1人1.98㎡以上、屋外遊戯場は満2歳以上1人3.3㎡以上です。

定員6〜19名の地域型保育（小規模保育事業）は「家庭的保育事業等の設備及び運営に関する基準」に拠り、本体施設の認可保育所は「児童福祉施設の設備及び運営に関する基準」第32条に拠ります。物件探しの出発点としての用途地域・消防の考え方は[小規模保育事業の物件を貸す・探すとき、用途地域と面積で何を確認するのか](/column/hoiku-shoukibo-bukken-youto-chiiki)と重なりますが、本体施設では屋外遊戯場（園庭）の確保と、乳児を預かる場合の乳児室・ほふく室、そして規模が大きいぶん避難の要件が前面に出ます。

| 居室・設備 | 児童福祉施設設備運営基準 第32条の面積（1人あたり） | 根拠 |
|---|---|---|
| 乳児室（満2歳未満） | 1.65㎡以上 | 第32条第2号 |
| ほふく室（満2歳未満） | 3.3㎡以上 | 第32条第3号 |
| 保育室又は遊戯室（満2歳以上） | 1.98㎡以上 | 第32条第6号 |
| 屋外遊戯場（満2歳以上） | 3.3㎡以上 | 第32条第6号 |
| 医務室・調理室・便所 | 設置（面積の一律基準は条文になし） | 第32条第1号・第5号 |

面積は「定員」ではなく「実際に入所させる年齢区分ごとの人数」で効くため、0〜2歳の受入れを厚くするほど乳児室・ほふく室の面積が要ります。各室の最終的な適否は所管自治体（市区町村）の認可基準・条例と事前協議で決まるため、物件を押さえる前の確認が前提です。

## 屋外遊戯場（園庭）がない物件でも近隣公園で代替できるのか

条文上は代替できる余地があります。第32条第5号は屋外遊戯場について「保育所の付近にある屋外遊戯場に代わるべき場所を含む」と定めており、付近の公園・広場等を代替地にできます。ただし「付近にあること」「安全に日常的に使えること」「必要な面積を満たすこと」を自治体が個別に審査します。

屋外遊戯場（園庭）は満2歳以上の幼児1人につき3.3㎡以上が必要ですが、敷地内に確保できない都市部の物件では、近隣の公園等を「代わるべき場所」として認めてもらう運用が一般的です。何をもって代替地と認めるか（距離、園児だけで安全に移動できる経路か、他施設との共用で必要時に使えるか、面積が足りるか）は、こども家庭庁『保育所等の設備・運営基準』や各自治体の手引きに沿って市区町村が判断します。代替地に頼る前提の物件は、契約前に自治体へ代替地の可否を確認しておかないと、認可の段階で園庭不足として差し戻される恐れがあります。

| 確認項目 | ポイント |
|---|---|
| 代替地の根拠 | 第32条第5号「付近にある屋外遊戯場に代わるべき場所を含む」 |
| 距離・経路 | 園児が安全に日常利用できる付近か（距離の数値基準は自治体運用【未検証】） |
| 面積 | 満2歳以上1人3.3㎡以上を満たすか |
| 使用の確実性 | 公園管理者等の使用承諾、専用でなくても必要時に使えるか |

代替地として認められる距離・条件の数値は自治体ごとに運用が分かれ、全国一律ではないため、ここは断定せず【未検証】とし、所管自治体への確認を前提にします。

## 2階以上・ビルテナントで開設するとき避難・防火でどこを見るのか

保育室等（乳児室・ほふく室・保育室又は遊戯室）を2階以上に設けるときは、第32条第8号が耐火・2方向避難・区画などを細かく求めます。2階以上は原則として耐火建築物または準耐火建築物、3階以上は耐火建築物とされ、階ごとに避難用の屋外階段・傾斜路等を設け、保育室等のどこからでもいずれかの避難施設まで歩行距離30m以下にします。

第32条第8号は、保育室等を2階以上に置く場合に、イ＝建物の構造（2階以上は耐火又は準耐火、3階以上は耐火）、ロ＝階に応じた避難用施設（待避上有効なバルコニー、屋外傾斜路、屋外階段等のうち一以上）、ハ＝避難上有効な位置と歩行距離30m以下、ニ＝調理室の区画（耐火構造の床壁・特定防火設備、ダンパー、自動消火装置）、ホ＝壁・天井の不燃内装、ヘ＝転落防止設備、ト＝非常警報設備と消防機関への通報設備、チ＝カーテン等の防炎、を求めます。ビルの空室を転用する物件では、この耐火区画・2方向避難・調理室の防火区画を既存建物で成立させられるかが、選定の分かれ目になります。

| 確認項目 | 第32条第8号のポイント |
|---|---|
| 構造 | 2階以上は耐火又は準耐火、3階以上は耐火建築物 |
| 2方向避難 | 階に応じた屋外階段・屋外傾斜路・待避バルコニー等を避難上有効な位置に |
| 歩行距離 | 保育室等のどこからでも避難施設まで30m以下 |
| 調理室 | 耐火区画・特定防火設備・ダンパー・自動消火装置 |
| 内装・通報 | 不燃内装、非常警報設備、消防機関への通報設備、防炎物品 |

消防法施行令別表第一では保育所は(6)項ハ(3)に区分され、延べ面積等に応じて自動火災報知設備・消火器・誘導灯等が要ります。必要な消防用設備の具体と工事費は機器構成と建物で変わるため【未検証】とし、採光・避難の計算と確認申請は建築士、消防用設備は消防設備士・所轄消防署の確認を前提にします。

## 用途地域と建築基準法上の用途変更（確認申請）はどこで誰に確認するのか

用途地域は保育所ではほぼ問題になりません。建築基準法別表第二で保育所は第一種低層住居専用地域（(い)項第6号「老人ホーム、保育所、福祉ホームその他これらに類するもの」）でも建てられ、工業専用地域でも建築できない建築物に挙げられていません。詰まるのは用途地域ではなく、既存建物を転用するときの用途変更の確認申請です。

事務所・店舗・共同住宅等を認可保育所（建築基準法上は児童福祉施設）に転用するとき、用途変更部分の延べ床面積が200㎡を超えると、使用前に用途変更の確認申請が要ります（建築基準法第6条第1項・第87条）。福祉用途への用途変更でつまずきやすい点は[福祉用途への用途変更はどこで確認申請が要るか](/legal/column/group-home-kenchikukijunho-youto-henko)に整理しています。用途変更の確認申請・採光や避難の計算は建築士・特定行政庁の領域で、当社は現況用途と面積を物件情報として整理し、計算と申請は建築士へ振ります。

| 確認項目 | 根拠・ポイント |
|---|---|
| 用途地域 | 別表第二(い)項第6号。第一種低層住居専用地域でも可、工業専用地域でも制限対象外 |
| 用途変更の確認申請 | 用途変更部分の延べ床面積200㎡超で必要（第6条第1項・第87条） |
| 採光 | 居室の採光（建築基準法第28条）。計算は建築士 |
| 誰が | 計算・確認申請＝建築士／認可の適合審査＝市区町村と行政書士 |

## よくある質問

**Q. 認可保育所と小規模保育で、物件に求められる基準はどう違いますか？**
A. 根拠となる省令が別です。認可保育所（定員20名以上）は児童福祉施設の設備及び運営に関する基準第32条に拠り、屋外遊戯場（園庭）の確保、乳児室1人1.65㎡以上・ほふく室1人3.3㎡以上・保育室又は遊戯室1人1.98㎡以上などが定められます。小規模保育（6〜19名）は家庭的保育事業等の基準に拠り、屋外遊戯場や規模が小さいぶん避難の要件も変わります。物件の適否は所管自治体にご確認ください。

**Q. 園庭がないビルの物件でも認可保育所にできますか？**
A. 条文上、屋外遊戯場は「保育所の付近にある屋外遊戯場に代わるべき場所を含む」とされ、近隣の公園等を代替地にできる余地があります（第32条第5号）。ただし距離・経路・面積・使用の確実性を市区町村が個別に審査します。代替地として認められる距離の数値は自治体ごとに運用が分かれるため（本記事では【未検証】扱い）、契約前に所管自治体へ代替地の可否をご確認ください。

**Q. 2階に保育室を置きたいのですが、物件側で何が要りますか？**
A. 第32条第8号で、2階以上は原則として耐火建築物又は準耐火建築物、3階以上は耐火建築物とされ、階に応じた屋外階段・屋外傾斜路等の避難施設、保育室等のどこからでも避難施設まで歩行距離30m以下、調理室の耐火区画と自動消火装置、不燃内装、転落防止、消防機関への通報設備などが求められます。該当の判断と採光・避難の計算は建築士の領域です。

**Q. 既存の事務所ビルを認可保育所にする場合、確認申請は要りますか？**
A. 用途変更部分の延べ床面積が200㎡を超えると、使用前に用途変更の確認申請が要ります（建築基準法第6条第1項・第87条）。保育所は用途地域の制限ではほぼ詰まりません（別表第二(い)項第6号で第一種低層住居専用地域でも可、工業専用地域でも制限対象外）。確認申請と採光・避難の計算は建築士へ、認可の適合審査は市区町村と行政書士へご相談ください。
