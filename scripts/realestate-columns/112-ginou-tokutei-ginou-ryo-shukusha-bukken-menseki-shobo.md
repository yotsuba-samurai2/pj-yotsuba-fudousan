## 外国人の寮に使う物件は1人当たり何㎡以上を確保すればよいのか

面積は在留制度側の基準で効きます。技能実習の運用要領は寝室を就寝する者1人当たり4.5㎡以上（床の間・押入を除く）とし、特定技能1号の支援運用要領は居室を1人当たり7.5㎡以上とするのが原則です。労働基準法の寄宿舎（事業附属寄宿舎規程）は別枠で、第一種寄宿舎の寝室1人2.5㎡以上という最低線を定めます。

数字が3つ出てくるのは、根拠が別だからです。技能実習は、適切な宿泊施設の確保として寝室1人4.5㎡以上・個人別の私有物収納設備・室面積の7分の1以上の有効採光面積の窓・採暖設備を求めます。特定技能1号は、義務的支援の「住居の確保」で居室1人7.5㎡以上（ルームシェアは居室面積÷居住人数で7.5㎡以上）を原則とし、技能実習から継続して同じ社宅等に住む場合は寝室1人4.5㎡以上で足りる扱いがあります。これらとは別に、宿泊施設が労働基準法上の「事業の附属寄宿舎」に当たると、事業附属寄宿舎規程の設備基準（第一種は寝室1人2.5㎡以上・一室16人以下・私有物収納は個人別）が重ねてかかります。

| 制度・根拠 | 面積の目安（1人当たり） | 併せて求められるもの |
|---|---|---|
| 技能実習（運用要領） | 寝室4.5㎡以上（床の間・押入を除く） | 個人別の私有物収納、7分の1以上の採光窓、採暖 |
| 特定技能1号（支援運用要領） | 居室7.5㎡以上（継続社宅は寝室4.5㎡以上） | 住居確保は義務的支援 |
| 事業附属寄宿舎規程（第一種） | 寝室2.5㎡以上・一室16人以下 | 私有物収納は個人別、7分の1以上の採光窓 |

実務では、物件を寮として提案するなら、最も広い基準（特定技能の居室7.5㎡）に合わせておくと制度をまたいで使えます。受入れ人数に見合う居室面積・収納・採光がとれるかは、物件側で当社が現況を整理し、在留制度上の適否は行政書士、寄宿舎規則・労務は社会保険労務士へ振ります。

## 一般の賃貸マンションを寮にすると消防法上どんな設備が要るのか

寄宿舎・下宿・共同住宅は消防法施行令別表第一(5)項ロに区分されます。自動火災報知設備・消火器・誘導灯等は、この区分と延べ面積・階数に応じてかかり、区画や入居人数を変えると必要な設備も変わります。一般の分譲・賃貸マンション（共同住宅）をまるごと寮にする場合と、1住戸を複数人で使う場合とで、消防の見方が変わります。

消防法第17条と施行令は、防火対象物の区分（別表第一）ごとに消防用設備等の設置を求めます。(5)項ロの寄宿舎・共同住宅では、延べ面積等の条件に応じて自動火災報知設備、消火器、誘導灯、場合により避難器具等が必要です。既存建物では、これらを後付けできるか、受信機や配線の経路がとれるかが選定の分かれ目になります。建物全体を寮として用途を変える場合は、用途変更に伴う確認申請の要否（用途変更部分200㎡超）も別に検討します。

| 確認項目 | ポイント |
|---|---|
| 消防法上の区分 | 寄宿舎・下宿・共同住宅は別表第一(5)項ロ |
| 消防用設備 | 自動火災報知設備・消火器・誘導灯等（区分・延べ面積・階数で変わる） |
| 2階以上の避難 | 技能実習の運用要領は2階以上の寝室に屋外へ通ずる階段を2箇所以上（収容15人未満は1箇所） |
| 判断主体 | 所管消防（消防署・予防課）が個別に判断。物件確定前に相談 |

必要な消防用設備の具体と工事費は建物と区分で変わるため【未検証】とし、消防用設備の設計は消防設備士、確認は所轄消防署を前提にします。当社は現況（既設の消防用設備、用途区分の見込み）を物件情報として整理します。

## 用途地域や建物の用途（共同住宅・寄宿舎）で借りられる物件は変わるのか

変わります。建築基準法別表第二では、共同住宅・寄宿舎・下宿は(い)項第3号に挙げられ、第一種低層住居専用地域でも建てられますが、工業専用地域（(わ)項第3号）では建てられません。寮に向く物件を工業団地の近くで探すとき、ここでつまずくことがあります。

寄宿舎として使う建物は、建築基準法上の用途が「寄宿舎」または「共同住宅」に当たります。別表第二は用途地域ごとに建てられる建築物を定め（第48条）、共同住宅・寄宿舎・下宿は第一種低層住居専用地域から準工業地域まで幅広く建てられる一方、工業専用地域では住宅・共同住宅・寄宿舎とも建築できない建築物に挙げられています。工場に近い割安な物件が工業専用地域にあると、寮として使えないことがあるため、用途地域の確認が先に要ります。既存の事務所・店舗を寮（寄宿舎）に転用する場合は、用途変更部分の延べ床面積が200㎡を超えると確認申請が要ります（建築基準法第6条第1項・第87条）。

| 確認項目 | 根拠・ポイント |
|---|---|
| 用途地域 | 別表第二(い)項第3号＝共同住宅・寄宿舎・下宿。工業専用地域(わ)項第3号は不可 |
| 建物の用途 | 寄宿舎・共同住宅として使えるか（事務所・店舗からの用途変更の要否） |
| 用途変更の確認申請 | 用途変更部分の延べ床面積200㎡超で必要（第6条第1項・第87条） |
| 採光 | 居室の採光（建築基準法第28条）。計算は建築士 |

## 賃貸借契約で入居人数・又貸し（転貸）の扱いはどう決めておくべきか

受入れ機関が物件を借り上げて実習生・特定技能外国人に住まわせる形は、法的には転貸（又貸し）に当たることが多く、賃貸借契約で入居人数と転貸の可否を明記しておく必要があります。貸主の承諾なく複数人を住まわせたり転貸したりすると、契約違反・解除の火種になります。

借上げ社宅の場合、契約当事者は受入れ機関（借主）と貸主で、実習生・特定技能外国人は転借人の立場になります。契約で「入居人数」「法人による借上げ・従業員寮としての使用」「転貸の承諾」「原状回復」「退去時の精算」を明確にし、重要事項説明（宅地建物取引業法第35条）と第37条書面で確認します。家賃を給与から控除する場合の実費範囲・合理性は、賃金控除や労使協定の論点として社会保険労務士の領域です。寄宿舎規則の作成と労働基準監督署への届出が必要かどうかは[外国人技能実習生や特定技能外国人に寄宿舎を用意するとき、寄宿舎規則の届出は必要ですか？](/labor/column/gaikokujin-kishukusha-kisoku-todokede-roumu)に整理されています。

| 契約上の論点 | 押さえどころ |
|---|---|
| 当事者 | 受入れ機関（借主）と貸主。入居者は転借人 |
| 入居人数・転貸 | 人数と転貸（従業員寮としての使用）の承諾を明記 |
| 家賃控除 | 給与控除の実費範囲・合理性は社会保険労務士の領域 |
| 重要事項説明 | 用途・原状回復・費用（宅建業法第35条・第37条書面） |

## よくある質問

**Q. 外国人の寮は1人当たり何㎡あればよいですか？**
A. 制度で異なります。技能実習の運用要領は寝室を就寝する者1人当たり4.5㎡以上（床の間・押入を除く）とし、特定技能1号の支援運用要領は居室を1人当たり7.5㎡以上（ルームシェアは居室面積÷居住人数）とするのが原則です。労働基準法の事業附属寄宿舎規程（第一種）は寝室1人2.5㎡以上という別枠の最低線です。制度をまたいで使うなら広い基準に合わせるのが実務上安全です。適否は行政書士・社会保険労務士にご確認ください。

**Q. 普通の賃貸マンションを寮にすると消防設備は追加で要りますか？**
A. 寄宿舎・共同住宅は消防法施行令別表第一(5)項ロに区分され、延べ面積・階数に応じて自動火災報知設備・消火器・誘導灯等が要ります。区画や入居人数を変えると必要な設備も変わります。既存建物で後付けできるかが選定の分かれ目です。必要な設備の具体と工事費は建物で変わるため（本記事では【未検証】扱い）、消防用設備の設計は消防設備士、確認は所轄消防署へご相談ください。

**Q. 工業団地の近くの割安な物件を寮にできますか？**
A. 用途地域によります。共同住宅・寄宿舎・下宿は建築基準法別表第二(い)項第3号で第一種低層住居専用地域でも建てられますが、工業専用地域（(わ)項第3号）では建てられません。工場に近い割安な物件が工業専用地域にあると寮に使えないことがあるため、用途地域の確認が先に要ります。事務所・店舗からの用途変更が200㎡を超えると確認申請も要ります。

**Q. 会社で借り上げて実習生に住まわせるとき、契約で何を決めておくべきですか？**
A. 受入れ機関が借り上げて住まわせる形は転貸（又貸し）に当たることが多いので、賃貸借契約で入居人数・従業員寮としての使用・転貸の承諾・原状回復を明記しておきます。貸主の承諾なく複数人を住まわせると契約違反になり得ます。家賃を給与から控除する場合の実費範囲・合理性や寄宿舎規則の届出は社会保険労務士の領域です。
