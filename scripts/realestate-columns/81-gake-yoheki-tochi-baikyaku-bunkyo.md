**結論（先に要点）**：文京区のように坂と高低差の多い地域では、がけや擁壁のある土地を売るとき、「擁壁が安全か」「建て替えのときに造り直しが要るか」が価格と買い手の範囲を左右します。東京都建築安全条例第6条は、高さ2mを超えるがけの下端からの水平距離ががけの高さの2倍以内の場所に建築物を建てる、または敷地を造成する場合に、原則として高さ2mを超える擁壁を設けることを求めています。高さ2mを超える擁壁は建築基準法第88条第1項と同法施行令第138条第1項第5号により工作物として確認の対象で、建築物ががけ崩れ等の被害を受けるおそれがあるときは擁壁の設置その他安全上適当な措置が必要です（同法第19条第4項）。さらに2024年7月31日から文京区全域が宅地造成及び特定盛土等規制法（盛土規制法）の宅地造成等工事規制区域に指定され、一定規模以上の盛土・切土は許可の対象です。擁壁の安全性と建て替え時の要否は建築士（構造）と特定行政庁（文京区）が判断し、当社（四葉不動産株式会社）は判断しません。当社が行うのは、擁壁の検査済証などの書類と役所調査の結果を報告書にし、重要事項として説明し、出口を並べることです。各専門家とはそれぞれ独立した事業体として別々にご契約いただき、当社は紹介料を受け取りません。

小日向・小石川・目白台・本郷など、文京区の住宅地は台地と低地の境に坂が走り、擁壁の上に建つ家、がけの下に建つ家が珍しくありません。相続した実家の裏が高い擁壁だった、造成時の書類が残っていない、というご相談は、売却の前に必ず整理が要ります。本記事は、がけ・擁壁のある土地を売るときに、何を確認し、誰が判断し、どう説明するかを条文と区の公表資料から整理します。出口の全体像は[売りにくい土地・建物の出口相談](/wakeari)、接道や再建築の論点は[再建築不可の土地・家の出口相談](/wakeari/saikenchiku-fuka)にまとめています。

## がけ・擁壁のある土地は、何が問題になりますか？

| 規定 | 内容 | 売却で効いてくる場面 |
|---|---|---|
| 東京都建築安全条例第6条 | 高さ2mを超えるがけの下端からの水平距離ががけの高さの2倍以内の場所に建築物を建築し、または敷地を造成する場合は、原則として高さ2mを超える擁壁を設けなければならない | 建て替え時に擁壁の新設・造り直しが必要になりうる |
| 建築基準法第19条第4項 | 建築物ががけ崩れ等による被害を受けるおそれのある場合は、擁壁の設置その他安全上適当な措置を講じなければならない | がけ下・がけ上の敷地での安全措置 |
| 建築基準法第88条第1項・施行令第138条第1項第5号 | 高さ2mを超える擁壁は工作物として、確認等の規定が準用される | 既存擁壁に確認済証・検査済証があるかどうか |
| 盛土規制法（宅地造成及び特定盛土等規制法） | 宅地造成等工事規制区域内の一定規模以上の盛土・切土・土石の堆積は許可の対象 | 造成をともなう建て替え・売却後の工事 |

つまり、擁壁が古い、書類がない、高さや構造が分からない土地は、買主が建て替えの費用とリスクを読めず、買い手の範囲が狭くなります。逆に、擁壁の書類がそろい、専門家の見立てが得られていれば、説明できる土地になります。

## 売る前に、どの書類を確認しますか？

| 確認事項 | 書類・確認先 | 担う人 |
|---|---|---|
| 擁壁の確認済証・検査済証の有無 | 文京区の建築計画概要書・台帳記載事項証明 | 当社（役所調査） |
| 造成時の図面・工事記録 | 所有者の保管書類、施工会社 | 所有者、当社が整理 |
| がけの高さ・擁壁の高さと敷地との位置関係 | 現地の測量・高低差の分かる図面 | 土地家屋調査士・測量士 |
| 擁壁の構造・劣化の状況 | 現地調査 | 建築士（構造）。当社は判断しない |
| 宅地造成等工事規制区域の指定 | 文京区・東京都の公表資料 | 当社（役所調査） |
| 隣地との境界と擁壁の所有関係 | 境界確定測量、登記簿 | 土地家屋調査士。手順は[境界確定測量と売却](/column/souzoku-fudosan-kyoukai-kakutei-sokuryo-baikyaku) |

擁壁が自分の土地にあるのか隣地にあるのか、共有なのかは、境界の位置とあわせて確認します。擁壁の所有関係が曖昧なままだと、修繕費用の負担をめぐる争いのもとになり、紛争性が出れば弁護士の領域です。

## 盛土規制法で、文京区は何が変わりましたか？

宅地造成及び特定盛土等規制法（昭和36年法律第191号。令和4年法律第55号による改正で題名が変わり、2023年5月26日施行）に基づき、東京都は規制区域を指定し、文京区の公表によれば2024年7月31日から文京区全域が「宅地造成等工事規制区域」に指定されました。文京区が主な対象として挙げる工事は次のとおりです。

| 許可の対象となる主な工事（文京区の公表資料による） |
|---|
| 盛土で高さ1mを超えるがけを生じるもの |
| 切土で高さ2mを超えるがけを生じるもの |
| 盛土で高さ2mを超えるもの |
| 盛土または切土をする土地の面積が500㎡を超えるもの |
| 一時的な土石の堆積で高さ2mを超え、かつ面積300㎡を超えるもの |

これらは、売却後に買主が擁壁を造り直す、敷地を造成するといった場面で関わります。どの工事が許可の対象になるかは、文京区の担当課（都市計画課開発担当）と建築士に確認します。本記事は個別の工事の許可要否を判断しません。

## 売却時の説明と責任は、どうなりますか？

宅地建物取引業法第35条第1項第2号は、建築基準法その他の法令に基づく制限で政令で定めるものの概要を重要事項として説明することを求めています。東京都建築安全条例第6条のがけの規定や、盛土規制法の規制区域は、この説明に関わる事項です。

| 説明する事項 | 内容 |
|---|---|
| がけ・擁壁の存在と高さ、位置関係 | 測量や図面に基づく事実 |
| 擁壁の確認済証・検査済証の有無 | 役所調査の結果。無いなら無いことを説明 |
| 東京都建築安全条例第6条の該当 | 建て替え時に擁壁が必要になりうること |
| 宅地造成等工事規制区域の該当 | 一定規模以上の工事は許可対象であること |
| 建築士の見立て（取得している場合） | 内容と、見立てであって保証ではないこと |

売主が知りながら告げなかった事実については、担保責任を負わない特約をしても責任を免れません（民法第572条）。擁壁のひび割れや過去の崩れ、役所からの指摘は、そのまま買主に伝えます。契約不適合責任の範囲をどう定めるかは、契約ごとに検討します。

## 四葉不動産株式会社は、何を行いますか？

四葉不動産株式会社（宅地建物取引業 東京都知事(1)第113304号）は、東京都文京区小日向を拠点に、がけ・擁壁のある土地、再建築不可・狭小地・共有・借地など売りにくい土地・建物の売却の媒介と、出口の比較を行っています。がけ・擁壁のある土地では、役所調査（確認済証・検査済証の有無、条例の該当、規制区域の指定、用途地域）、書類の整理、建築士への相談材料の作成、報告書と出口の比較、媒介契約（同法第34条の2）、重要事項説明（同法第35条）、売買契約と決済の段取りを担います。報酬は同法第46条に基づく定めの範囲内で、紹介料は受け取りません。

## よくある質問

**Q. 擁壁の検査済証がありません。売れませんか？**
A. 売れないわけではありません。無いことを重要事項として説明し、建築士の見立てを取るか、現状のまま売るか、買取業者を買主とする媒介にするかを比べます。書類が無い擁壁は買主が建て替え費用を読みにくいため、買い手の範囲が狭くなることは一般論として押さえておきます。

**Q. 擁壁が古いのですが、造り直しは必要ですか？**
A. 当社は判断できません。建て替えの計画がある場合、東京都建築安全条例第6条の該当や擁壁の構造・状態をもとに、建築士と特定行政庁（文京区）が判断します。造成をともなう工事は盛土規制法の許可の対象になることがあり、これも区の担当課で確認します。

**Q. 隣の家の擁壁がうちの土地に迫っています。誰の責任ですか？**
A. 擁壁がどちらの土地にあるか、境界がどこかで変わります。境界確定測量は土地家屋調査士が行い、費用負担や修繕をめぐって争いがあるときは弁護士へ直接ご依頼いただく形をご案内します。当社は登記簿・公図と測量結果を整理し、売却時の説明に反映します。

**Q. 盛土規制法の規制区域に入っていると、売却に何か影響しますか？**
A. 売却そのものが制限されるわけではありません。ただし、買主が擁壁の造り直しや造成を行う場合、一定規模以上の盛土・切土は許可の対象になるため、重要事項説明で規制区域の該当を伝えます。文京区の公表によれば、2024年7月31日から文京区全域が宅地造成等工事規制区域です。
