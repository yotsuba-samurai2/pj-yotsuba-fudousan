**結論（先に要点）**：相続土地国庫帰属制度は、2023年（令和5年）4月27日の施行から約3年半で、法務省の統計（令和8年9月30日現在・速報値、公表は令和8年10月19日）によると、申請6,125件に対して国庫帰属が認められたのは3,231件、却下86件、不承認103件、取下げ1,162件です。申請の段階で却下されるのは、建物が建っている土地・担保権などが設定された土地・境界が明らかでない土地などで、法律があらかじめ「申請できない土地」を定めています（相続土地国庫帰属法第2条第3項）。審査の段階で不承認になるのは、管理に過分の費用・労力を要する崖がある土地・地上の工作物や樹木がある土地・地下に有体物がある土地・争訟によらなければ管理処分できない土地などです（第5条第1項）。承認されると、国の管理費用の一部にあたる負担金を納めます。却下・不承認になった土地や、負担金まで払って手放すより売る・貸す方がよい土地は、売却や寄付など別の出口を不動産（当社）が検討します。承認申請の書類作成は行政書士、審査は法務局、境界の確定測量は土地家屋調査士、譲渡所得など税務は税理士の領域で、それぞれ独立した事業体として別々にご契約いただく形でおつなぎします（紹介料のやりとりはありません）。

相続した売れない土地（遠方・原野・山林・管理困難地）の出口を探している相続人に向けて、制度の運用実績（どれだけ使われ、どんな土地が却下・不承認になったか）を法務省の統計で確認し、却下・不承認だった場合の別の出口までを、条文と公的資料の順に整理します。本記事は一般的な情報提供であり、個別の土地が却下・不承認になるかどうか、負担金額、税の適用といった最終判断は、法務局・専門家の領域です。

四葉不動産株式会社は、東京都文京区小日向を拠点に、相続した不動産の調査と査定・売却の媒介を承っています。「国庫帰属を申請すべきか、売った方がよいか」という段階から、契約前に確認できることをご相談いただけます。

## 相続土地国庫帰属制度は、これまでにどれだけ申請・承認されたのか？

法務省は制度の運用状況の統計を定期的に公表しています。最新の公表（令和8年10月19日付・令和8年9月30日現在の速報値）では、次のとおりです。制度の選択を考えるとき、「申請しても一定割合は取下げや却下・不承認になっている」という実績を知っておくと、見通しが立てやすくなります。

| 項目 | 件数（令和8年9月30日現在・速報値） |
|---|---|
| 申請件数 | 6,125件 |
| 帰属件数（国庫帰属が認められた件数） | 3,231件 |
| 却下件数 | 86件 |
| 不承認件数 | 103件 |
| 取下げ件数 | 1,162件 |

申請の地目別では、田・畑が2,372件と最も多く、宅地2,135件、山林928件、その他690件と続きます。取下げ1,162件の理由としては「有効活用の見込みが生じた」595件、「却下・不承認であることが判明した」415件などが挙げられています。つまり、申請してみて別の出口が見つかったり、要件に合わないと分かって取り下げたりする例が相当数あるということです。制度どうしの選び方（国庫帰属・寄付・売却の比較）は既存記事[相続した土地を手放す——国庫帰属・寄付・売却の比較](/column/souzoku-tochi-tehanasu-kokko-kizoku-baikyaku-hikaku)で扱っており、本記事は運用実績（却下・不承認の類型）に主題を絞ります。

## 申請の段階で「却下」されるのはどんな土地か？（法第2条第3項）

却下とは、審査に入る前の段階で「そもそも申請できない土地」として退けられることです。相続土地国庫帰属法第2条第3項は、次のいずれかに当たる土地は承認申請ができないと定めています。

| 却下となる土地（第2条第3項） | 内容 |
|---|---|
| 建物の存する土地 | 建物が建っている土地 |
| 担保権等が設定されている土地 | 抵当権など担保権や、使用収益を目的とする権利が設定されている土地 |
| 他人の使用が予定される土地 | 通路など他人による使用が予定される土地として政令で定めるものを含む土地 |
| 土壌汚染されている土地 | 土壌汚染対策法の特定有害物質により汚染されている土地 |
| 境界が明らかでない土地 | 境界が明らかでない土地、または所有権の存否・帰属・範囲に争いがある土地 |

法務省の統計では、却下86件の理由（1件で複数の理由が認められる場合があるため合計は却下件数と一致しません）として、添付書類の提出がなかった37件、境界が明らかでない土地23件、通路の用に供されている土地22件、申請の権限を有しない者による申請11件、建物の存する土地4件などが挙げられています。境界が明らかでないことや、通路として使われていることが実際の却下理由になっている点は、物件を見ておく段階で確認しておきたいところです。境界の確定は土地家屋調査士の領域で、確定測量をしてから申請する流れになります。

## 審査で「不承認」になるのはどんな土地か？（法第5条第1項）

不承認とは、申請は受理されたものの、審査の結果「国庫に帰属させるのは適当でない」として承認されないことです。相続土地国庫帰属法第5条第1項は、次のいずれかに当たる土地は承認しないと定めています。却下要件（申請できる土地かどうか）とは別に、審査で「通常の管理・処分に過分の費用・労力を要するか」を見る段階です。

| 不承認となる土地（第5条第1項） | 内容 |
|---|---|
| 崖がある土地 | 政令で定める勾配・高さの崖があり、管理に過分の費用・労力を要する土地 |
| 地上に有体物がある土地 | 通常の管理・処分を阻害する工作物・車両・樹木その他の有体物が地上にある土地 |
| 地下に有体物がある土地 | 除去しなければ通常の管理・処分ができない有体物が地下にある土地 |
| 争訟を要する土地 | 隣接地の所有者等との争訟によらなければ通常の管理・処分ができない土地として政令で定めるもの |
| その他過分の費用・労力を要する土地 | 上記のほか、通常の管理・処分に過分の費用・労力を要する土地として政令で定めるもの |

法務省の統計では、不承認103件の理由として、通常の管理・処分を阻害する工作物・車両・樹木等が地上にある土地49件、国による追加の整備が必要な森林37件、国庫帰属後に法令に基づく金銭債務を負担する土地12件、災害の危険による被害防止措置が必要な土地11件、過分の費用・労力を要する崖がある土地7件などが挙げられています（1件で複数の理由が認められる場合があるため合計は不承認件数と一致しません）。放置された工作物や立木、山林の整備不足が実際に不承認の主因になっている点は、山林や原野を手放したい相続人には重要な実績です。山林の出口の考え方は[相続した山林を売る・隣地に買ってもらう](/column/rinchi-baikyaku-kaimashi-nanari-tochi-deguchi)でも整理しています。

## 却下・不承認になった土地は、売却や寄付など別の出口をどう探すのか？

国庫帰属が却下・不承認になっても、土地の出口がなくなるわけではありません。むしろ、負担金まで払って国に引き取ってもらうより、売る・貸す方が手取りが残る土地もあります。出口はおおむね次に分かれます。

| 出口 | 向くケース | 主に関わる担当 |
|---|---|---|
| 売却（市場・隣地・買取り） | 需要が見込める、隣地所有者が買い増しを望む | 当社（宅地建物取引業） |
| 寄付（自治体・法人・個人） | 売却が難しいが引き取り手がいる | 当社・相手方（受贈の可否は相手次第） |
| 賃貸・利用（駐車場・資材置場・ソーラー等） | 建築制限はあるが別用途で使える | 当社・事業者 |
| 要件を整えて再申請 | 境界確定や工作物撤去で要件を満たせる | 土地家屋調査士・解体業者・行政書士 |

売れない前提で国庫帰属に進む前に、まず市場で売れないか、隣地所有者に買ってもらえないか、別用途で貸せないかを確認するのが順序です。隣地の方が買い増しを望む「隣地需要」は、一般の市場より成約しやすいことがあります。管理困難地の手放し方全体は[相続した市街化調整区域の土地は売れる？](/column/chousei-kuiki-souzoku-tochi-baikyaku)、空き家付きの土地は[相続した空き家は解体して更地で売るか古家付き土地で売るか](/column/souzoku-akiya-kaitai-koyatsuki-dochira)でも扱っています。当社は、国庫帰属の要件に照らして却下・不承認になりそうかの見当（最終判断は法務局）と、売却・寄付・賃貸という別の出口の整理をお手伝いします。

## 申請書類の作成から負担金の納付まで、誰に相談すればよいのか？

相続土地国庫帰属制度は、承認申請（行政書士・本人）・審査（法務局）・境界確定（土地家屋調査士）・代替の出口としての売却（不動産）・税務（税理士）が、別々の領域にまたがります。不動産会社が担うのは、代替の出口の検討と調査・査定・媒介までです。

| 困りごと | 振り先 |
|---|---|
| 却下・不承認時の売却・寄付・賃貸など別の出口の検討、調査・査定・媒介 | 当社（宅地建物取引業） |
| 国庫帰属の承認申請書類の作成・提出の代理 | 行政書士 |
| 承認申請の審査・負担金額の通知 | 法務局（管轄の法務局・地方法務局） |
| 境界（筆界）の確定測量、分筆 | 土地家屋調査士 |
| 所有権移転・相続登記 | 司法書士・土地家屋調査士 |
| 譲渡所得など税務 | 税理士 |

これらは**それぞれ独立した事業体**であり、**別々にご契約**いただく前提です。当社は紹介料・送客手数料を受け取ることも支払うこともありません。承認を受けると負担金を納める必要があり、負担金は国有地の種目ごとに10年分の標準的な管理費用を考慮して算定されます。原則として面積にかかわらず定額（20万円）ですが、一部の市街化区域内の宅地・農地や一定の森林などは面積に応じて算定されます（相続土地国庫帰属法第10条・施行令。具体額は法務局の通知と施行令の算定による）。承認申請の可否や書類は行政書士が、審査と負担金額は法務局が、境界確定は土地家屋調査士が、登記は司法書士が、税務は税理士が判断・担当します。なお、相続した土地が被相続人の名義のままなら、申請や売却の前に相続登記（令和6年〈2024年〉4月1日から義務化・不動産登記法第76条の2）が必要になるのが通常で、これは司法書士の領域です。相続不動産の進め方は[相続した不動産の相談窓口](/souzoku)もご覧ください。

**[国庫帰属か売却か迷う相続土地のご相談を四葉不動産へ（相談無料）](/souzoku)**

お問い合わせに「相続土地国庫帰属」と、土地の所在地（自治体）、地目（宅地・田畑・山林・原野など）、建物や工作物・立木の有無、境界が確定しているか、相続登記が済んでいるかをご記入ください。国庫帰属が向くか、売却・寄付・賃貸が向くかを先に決めつけず、却下・不承認になりそうかの見当（最終判断は法務局）と、別の出口の整理からお話しします。

## よくある質問

**Q. 相続土地国庫帰属制度は、これまでにどれくらい使われていますか？**
A. 法務省の統計（令和8年9月30日現在・速報値、公表は令和8年10月19日）では、2023年4月の施行から約3年半で申請6,125件、国庫帰属が認められた帰属件数3,231件、却下86件、不承認103件、取下げ1,162件です。申請してから別の出口が見つかって取り下げる例や、要件に合わず却下・不承認になる例も相当数あります。数値は速報値で、最新は法務省のページで確認してください。

**Q. どんな土地だと「却下」されますか？**
A. 相続土地国庫帰属法第2条第3項は、建物が建っている土地、担保権などが設定された土地、通路など他人の使用が予定される土地、土壌汚染された土地、境界が明らかでない土地などを「申請できない土地」としています。法務省の統計では、添付書類の不足、境界が明らかでない土地、通路の用に供されている土地が実際の却下理由の上位です。境界の確定は土地家屋調査士の領域です。

**Q. どんな土地だと「不承認」になりますか？**
A. 第5条第1項は、管理に過分の費用・労力を要する崖がある土地、工作物・車両・樹木が地上にある土地、地下に有体物がある土地、争訟によらなければ管理処分できない土地などを不承認としています。法務省の統計では、地上の工作物・樹木、追加整備が必要な森林、金銭債務を負担する土地が不承認理由の上位です。放置された立木や工作物のある山林・原野は、撤収や整備をしないと通りにくい傾向があります。

**Q. 却下・不承認だったら、もう手放せないのですか？**
A. そうではありません。負担金を払って国に引き取ってもらうより、売る・貸す方が手取りが残る土地もあります。市場での売却、隣地所有者への売却、自治体や法人への寄付、駐車場・資材置場などの賃貸という別の出口を検討できます。当社は、国庫帰属の見当（最終判断は法務局）と、売却・寄付・賃貸の整理をお手伝いします。売却の媒介は不動産、申請は行政書士、境界確定は土地家屋調査士と、担当は分かれます。
