**結論（先に要点）**：キッチンカーの「仕込み場所（セントラルキッチン）」は、車両とは別に、営業許可を受けた施設が原則として必要です。車両は積める水の量に限りがあり、保健所の基準では給排水タンクの容量で車内でできる調理の範囲が絞られるため、下処理・加工は許可施設で行うのが基本だからです。物件選びの肝は、給排水と手洗いを施設基準どおり備えられるか、作業区画を住居や他用途と分けられるか、用途地域・賃貸借契約でその営業が認められるかの3点。営業許可の区分判断と保健所協議・申請は行政書士／保健所、用途地域や用途変更の最終判断は特定行政庁・建築士へ分け、物件の賃貸借と用途確認は当社が担います。

移動販売・キッチンカーで開業する、あるいは既に車両で売っていて下処理の拠点を借りたい——そんなとき「仕込みはどこでやるのか」「どんな物件なら保健所の許可が下りるのか」が最初の関門になります。車両だけでは完結しないことが多く、物件を決める前に施設基準と用途を押さえておかないと、契約後に許可が下りない事態になりかねません。

## キッチンカーに「仕込み場所」はなぜ必須なのか？

キッチンカー（食品の移動販売）は、車両そのものが食品衛生法第55条第1項の営業許可（飲食店営業など）を受けて営業します。ただし車両に積める水の量には限りがあり、保健所の施設基準では、給水タンク・排水タンクの容量によって車内でできる調理の範囲が区分されるのが一般的です。

埼玉県東松山保健所や茨城県日立保健所の案内では、タンク容量の目安をおおむね次のように説明しています（容量・条件は自治体ごとに異なるため、営業予定地の保健所で図面を示して確認するのが確実です）。

| 給水・排水タンクの容量（目安） | 車内で想定される調理 |
| --- | --- |
| 約40L以上 | 簡易な調理のみ、または単一品目。使い捨て容器が前提 |
| 約80L以上 | 2工程程度までの簡易な調理、複数品目。使い捨て容器が前提 |
| 約200L以上 | 複数工程の調理、または通常の食器を使う営業 |

このため、下処理・カット・下味つけ・加工といった「仕込み」は車内で完結しづらく、茨城県日立保健所は「仕込みが必要な場合は、食品営業許可を取得した施設で行う必要がある」と案内しています。これが、車両とは別に仕込み場所（セントラルキッチン）の物件が要る理由です。

## 仕込み場所の物件に求められる設備要件は何か？（給排水・手洗い・区画）

仕込み場所は、それ自体が営業許可を受ける「施設」です。施設の基準は、食品衛生法第54条に基づき、厚生労働省令（食品衛生法施行規則の別表に定める基準）を参酌して各都道府県等が条例で定めています。2018年改正法の令和3年6月1日施行で、この基準の骨格が全国で平準化されました。物件段階で効くのは、おおむね次の点です。

| 確認項目 | 物件で見るポイント |
| --- | --- |
| 給水・排水 | 必要な給排水設備を引けるか。排水が適切に処理できる系統か |
| 手洗い設備 | 作業区域に専用の手洗いを設けられるか（消毒設備を含む） |
| 作業区画 | 下処理・調理の区域を住居や他用途と明確に区分できるか |
| 床・壁・天井 | 清掃しやすく、不浸透性の素材に仕上げられるか |
| 換気・照明 | 作業場に十分な換気と照明を確保できるか |
| 保管設備 | 原材料・器具の保管、冷蔵・冷凍設備を置けるか |

具体的な数値や細目は条例・保健所の運用で差があります。細部を物件側で断定せず、図面を保健所に示して事前協議するのが確実です。飲食店のスケルトン物件で排気・給排水を見るときの考え方は、[スケルトン物件で飲食店を開くときの排気・グリストラップ・防火の確認点](/column/inshokuten-skeleton-bukken-haiki-grease)も参考になります。

## どんな営業許可が要り、誰が申請するのか？

営業許可を要する業種は、食品衛生法第55条第1項を受けた食品衛生法施行令第35条が定めています。令和3年6月1日施行の改正で、許可業種は従来の34業種から32業種に再編されました。仕込み場所でどの区分に当たるかは、作る食品と工程によって変わります。

| 想定される区分 | どんな場合か（例） |
| --- | --- |
| 飲食店営業 | 調理して提供する食品全般を仕込む場合 |
| そうざい製造業 | 煮物・焼物・揚物などの副食物をまとまった量で製造する場合 |
| 届出業種 | 許可業種に当たらない一部の営業（食品衛生法第57条の届出） |

どの区分に該当するか、車両の許可と仕込み場所の許可を別に取るのか同一施設で扱えるのかは、個別の判断になります。この区分の判断と保健所協議・営業許可申請の書類作成は、行政書士および保健所の領域です。当社は許可申請を代行しません。物件の賃貸借と用途の確認を当社が担い、許可の区分と申請は行政書士・保健所へおつなぎします。

## 用途地域や賃貸借契約で確認すべき点は？

仕込み場所は固定の施設なので、車両と違って用途地域の制限がかかります。建築基準法第48条・別表第二は、用途地域ごとに建てられる建築物の用途を定めています。飲食店営業として仕込むなら「店舗・飲食店」扱い、そうざい製造業としてまとまった量を製造するなら「工場」扱いに近づき、製造の規模によっては住居系地域で制限を受けることがあります。

| 確認項目 | 見るポイント |
| --- | --- |
| 用途地域 | 想定する営業の用途が、その地域で認められるか |
| 用途変更 | 既存建物の用途を変える場合、確認申請の要否（規模による） |
| 賃貸借契約 | 使用目的に「食品の製造・調理」を含められるか。原状回復の範囲 |
| 近隣 | 臭気・排水・搬出入で近隣とぶつからないか |

用途地域への適合や用途変更の確認申請の要否は、最終的には特定行政庁・建築士の判断です。当社は物件の用途地域と賃貸借の使用目的を事前に確認し、確認申請が絡む場合は建築士へおつなぎします。

## 自宅や既存店舗を仕込み場所に使えるのか？

「自宅のキッチンで仕込めないか」という相談は多いのですが、仕込み場所は営業許可を受けた施設である必要があり、住居と作業区域が区分されていないと基準を満たしにくいのが実情です。自宅の一部を使う場合も、作業区画・手洗い・給排水を基準どおりに整え、居住スペースと分けられるかが分かれ目になります。

既存の飲食店舗を仕込み拠点として使う場合は、その店舗の営業許可の区分で仕込みまでカバーできるか、営業時間外に別事業として使うなら許可の名義・区分をどう整理するかを、保健所に確認する必要があります。いずれも可否は個別の施設と運用次第で、資格のない者が「使えます」と断ずることはできません。物件の下見の段階で、当社が用途地域と賃貸借の条件を確認し、許可の可否は行政書士・保健所へおつなぎします。

## よくある質問

**Q. キッチンカーの車両に許可があれば、仕込み場所の許可は要りませんか？**
A. 車両と仕込み場所はそれぞれ別の施設として扱われるのが一般的で、仕込みが必要な場合は営業許可を受けた施設で行う必要があると案内する保健所が多くあります（茨城県日立保健所ほか）。どこまで車内で完結できるかは給排水タンクの容量などで変わるため、営業予定地の保健所に図面を示してご確認ください。

**Q. 仕込み場所はどんな営業許可の区分になりますか？**
A. 作る食品と工程により、飲食店営業やそうざい製造業などに分かれます。許可業種は食品衛生法第55条第1項・施行令第35条が定め、令和3年6月1日施行の改正で34業種から32業種へ再編されました。区分の判断と申請は行政書士・保健所の領域ですので、具体的な区分はそちらでご確認いただきます。

**Q. 自宅のキッチンを仕込み場所にできますか？**
A. 仕込み場所は営業許可を受けた施設である必要があり、住居と作業区域を区分し、手洗い・給排水を基準どおりに整えられるかが分かれ目です。多くの場合、居住スペースと分けた専用の区画が求められます。可否は個別の施設と保健所の運用によるため、断定はできません。

**Q. 物件を借りてから許可が下りないと困ります。順番はどうすればよいですか？**
A. 物件を決める前に、用途地域で想定する営業が認められるか、施設基準を満たせる作りかを確認し、保健所と事前協議してから契約に進むのが安全です。当社は物件の用途確認と賃貸借を担い、許可の区分・協議は行政書士・保健所へおつなぎします。
