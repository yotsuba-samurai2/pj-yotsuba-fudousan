**結論（先に要点）**：遺言執行者がいる相続不動産を売るとき、売買契約の当事者（売主）が誰かは遺言の形で変わります。「相続させる」旨（特定財産承継遺言）なら不動産を取得した相続人が売主で、執行者は相続登記などの対抗要件具備を担います。遺産を売って分ける清算型の遺贈なら、執行者が売却手続を進める形になります。遺言の解釈と権限の範囲は弁護士、登記は司法書士へ分け、不動産の仲介は当社が担います。

公正証書遺言で不動産を取得した、あるいは遺言執行者に指定・選任された——そんな立場で相続した不動産を売ろうとすると、「契約書に署名するのは自分なのか執行者なのか」「決済の場に誰が立つのか」と戸惑います。遺言があるかないか、そして遺言の書き方（「相続させる」か「遺贈する」か）で、売却の当事者も登記の流れも変わります。

この記事は、遺言執行者が関わる相続不動産を売る場面で、媒介契約・売買契約・決済に誰が当事者として立つかを、不動産の視点から整理します。遺言の有効性や執行者の権限範囲そのものの判断は弁護士の領域で、本記事はあくまで一般的な情報提供です。

四葉不動産株式会社は、東京都文京区小日向を拠点に、相続不動産の査定と売却の媒介を承っています。遺言執行者が関わる売却について、売る前に確認できることからご相談いただけます。

## 遺言執行者がいると、売買契約の売主や署名者は誰になる？

まず押さえるのは、遺言執行者の権限です。民法第1012条第1項は、遺言執行者は遺言の内容を実現するため、相続財産の管理その他遺言の執行に必要な一切の行為をする権利義務を有すると定めます。同条第2項は、遺贈の履行は遺言執行者がある場合には遺言執行者のみが行うことができるとします（平成30年法律第72号による改正・2019年7月1日施行）。

誰が売主になるかは、遺言がその不動産をどう承継させているかで分かれます。

| 遺言の形 | 不動産の承継 | 売買契約の売主・署名者 |
| --- | --- | --- |
| 「相続させる」旨（特定財産承継遺言） | 相続開始時に当該相続人へ当然に承継 | 不動産を取得した相続人（受益相続人） |
| 遺贈（特定遺贈） | 受遺者が遺贈を受けて取得 | 取得後は受遺者。遺贈の履行は執行者が行う |
| 清算型の遺贈（売って分ける旨） | 執行者が換価して代金を分配 | 執行者が売却手続を進める |

民法第1015条は、遺言執行者がその権限内において遺言執行者であることを示してした行為は、相続人に対して直接にその効力を生ずると定めます。つまり清算型のように執行者が売却を担う場面では、執行者が「遺言執行者として」契約の当事者に立ちます。一方、「相続させる」旨で特定の相続人が取得した不動産をその相続人の判断で売るなら、売主はその相続人です。

どの類型に当たるか、遺言の文言の解釈は最終的に弁護士の領域です。当社は、遺言の写しと登記の状況を見て、売買の当事者が誰になりそうかを整理し、確定が必要な点は弁護士・司法書士へおつなぎします。執行者の職務や選任の仕組みそのものは、行政書士側の[遺言執行者は誰がなる・どう選任するか](/legal/column/yuigon-shikkosha-shokumu-sennin-dare)で扱っています。

## 特定財産承継遺言（相続させる旨）と遺贈では、売却・登記の流れがどう違う？

売却の前提になる登記の流れも、遺言の形で変わります。2021年の不動産登記法改正（令和3年法律第24号）で、遺贈による所有権移転登記の一部が単独申請できるようになりました（2023年〈令和5年〉4月1日施行）。ただし単独申請できるのは相続人に対する遺贈に限られ、相続人以外への遺贈は従来どおり共同申請です。

| 遺言の形 | 登記の原因 | 申請の形 |
| --- | --- | --- |
| 「相続させる」旨（特定財産承継遺言） | 相続 | 相続人が単独で相続登記。執行者も対抗要件具備の行為ができる（民法第1014条第2項） |
| 相続人への遺贈 | 遺贈 | 受遺者（相続人）が単独で申請できる（不動産登記法第63条第3項・2023年4月1日施行） |
| 相続人以外への遺贈 | 遺贈 | 受遺者と相続人（または執行者）の共同申請 |

民法第1014条第2項は、特定財産承継遺言があったとき、遺言執行者は対抗要件を備えるために必要な行為をすることができると定めます。買主へ所有権を移すには、売る前提として受益相続人・受遺者の名義へ登記を整えておくのが通常です。清算型の遺贈では、相続人名義を経てから売買による移転登記を行うなど、順序が複雑になることがあります。

登記の原因・順序・単独申請の可否の判断と申請の代理は司法書士の業務です。当社は登記を代理しません。売却のスケジュールに合わせて、どの登記を先に整えるかを司法書士と確認しながら進めます。

## 媒介契約・本人確認・決済の場に、執行者と受益相続人はどう関わる？

不動産を売るときは、媒介契約（宅地建物取引業法第34条の2）、重要事項説明（第35条）、売買契約書の交付（第37条）という段取りを踏みます。遺言執行者が関わる売却では、これらの当事者が誰かを最初に確定させておくことが肝心です。

| 場面 | 誰が当事者になるか（類型により異なる） |
| --- | --- |
| 媒介契約 | 売主となる者（受益相続人、または清算型では遺言執行者） |
| 本人確認（犯罪収益移転防止法） | 契約の当事者となる者と、代理する執行者の双方 |
| 重要事項説明 | 買主への説明。売主側は権利関係・遺言・登記の状況を開示 |
| 決済・引渡し | 売主となる者が受領。清算型では執行者が代金を受領し分配 |

本人確認は、宅地建物取引業者が犯罪収益移転防止法に基づいて行います。執行者が売主として契約する場合は、執行者本人の確認に加えて、遺言で執行者に指定・選任されたことを示す資料（遺言書、家庭裁判所の選任審判書など）を確認します。受益相続人が売主の場合は、その相続人の本人確認と、不動産を取得した根拠（遺言・登記）を整えます。

当社は、媒介契約の段階で売主が誰になるかを遺言と登記から整理し、重要事項説明で遺言・執行者の関与・登記の状況を買主へ開示します。遺言の有効性や権限の有無に争いが見込まれる場合は、媒介に入る前に弁護士へご相談いただくようお願いしています。

## 遺言の内容と異なる売却や、相続人が売却に反対したらどうなる？

遺言執行者がいる場合、相続人は勝手に処分できません。民法第1013条第1項は、遺言執行者があるときは相続人が相続財産の処分その他遺言の執行を妨げるべき行為をすることができないと定め、同条第2項は、これに違反した行為は無効とする（ただし善意の第三者には対抗できない）としています。

| 状況 | 整理のしかた |
| --- | --- |
| 相続人が執行者に無断で売ろうとする | 第1013条で妨害行為は制限される。無断の処分は原則無効 |
| 相続人が売却に反対する | 清算型など執行者の権限内なら、執行者が売却を進められる場合がある |
| 遺言と異なる内容で売りたい | 相続人全員の合意で遺産分割をやり直す余地があるかは弁護士の判断 |
| 遺言の有効性に争いがある | 売却の前に弁護士へ。有効性が固まるまで媒介に入れないことがある |

反対する相続人がいる、遺言の有効性が争われている、執行者の権限範囲があいまい——こうした場面での可否は、個別の法的判断そのものです。当社も含め、資格のない者が「売れます」「売れません」と断ずることはできません。相続人間の争いや遺言の解釈は弁護士、登記は司法書士へ振り分けます。

共有持分や分割をめぐる売却の考え方は、[共有者の一人が持分を第三者へ売る場合の整理](/column/souzoku-kyoyu-mochibun-dai3sha-baikyaku-bunkatsu)や、[換価分割で相続不動産を売る流れ](/column/kanka-bunkatsu-fudosan-baikyaku-nagare)も参考になります。

## 売却前に執行者が確認しておくべき書類と、専門職への振り分けは？（分離受任）

遺言執行者が関わる売却は、遺言の解釈・登記・税務・不動産がそれぞれ別の事業体にまたがります。順番を取り違えると、登記が整わないまま契約してしまう、譲渡所得税の負担者を誤解するといった行き違いが起きます。

| 役割 | 誰が担うか |
| --- | --- |
| 査定・媒介・重要事項説明・決済 | 宅地建物取引業（当社） |
| 遺言の有効性・執行者の権限範囲・相続人間の争いの判断 | 弁護士 |
| 相続登記・遺贈による移転登記 | 司法書士 |
| 譲渡所得税・相続税の計算と申告 | 税理士 |
| 遺言執行者の選任申立て | 家庭裁判所 |

売る前に確認しておきたい書類は、遺言書（公正証書遺言なら正本・謄本、自筆証書なら検認済みのもの）、執行者の指定・選任を示す資料、登記事項証明書、固定資産税の課税明細などです。清算型では、債務の弁済や代金分配の順序も先に整理します。

これらは**それぞれ独立した事業体**であり、**別々にご契約**いただく前提です。当社は不動産の売却面を担い、遺言の解釈や権限の判断は弁護士、登記は司法書士、譲渡所得税・相続税は税理士へと分けてご案内します。当社は紹介料を受け取りません。

## よくある質問

**Q. 「相続させる」旨の遺言で不動産を取得しました。売主は私で合っていますか？**
A. 特定財産承継遺言（「相続させる」旨）では、不動産は相続開始時に当然にその相続人へ承継されるため、原則として取得した相続人が売主になります。遺言執行者は対抗要件を備えるための行為（相続登記など）をする権限を持ちます（民法第1014条第2項）。文言の解釈に迷う場合は弁護士へご確認ください。

**Q. 清算型の遺贈で、執行者が売って分けるよう書かれています。契約は誰が結びますか？**
A. 遺産を売却して代金を分配する清算型では、遺言執行者が遺言の内容を実現するために売却手続を進めます（民法第1012条第1項・第1015条）。執行者が「遺言執行者として」契約の当事者に立つ形です。登記の順序や代金分配は司法書士・税理士と確認しながら進めます。

**Q. 相続人の一人が売却に反対しています。売れますか？**
A. 執行者の権限内の売却（清算型など）か、取得した相続人自身の売却か、遺言の有効性に争いがあるかで扱いが変わります。民法第1013条は、執行者がいる場合の相続人による妨害行為を制限します。可否は個別の法的判断にあたるため、弁護士へご相談ください。当社は売却の媒介面を担います。

**Q. 遺贈を受けた不動産の登記は、自分だけで申請できますか？**
A. 2023年4月1日施行の不動産登記法第63条第3項により、相続人に対する遺贈なら受遺者が単独で所有権移転登記を申請できます。相続人以外への遺贈は従来どおり共同申請です。登記の可否と申請の代理は司法書士の業務ですので、具体的な申請はそちらへおつなぎします。
