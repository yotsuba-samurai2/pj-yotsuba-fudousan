**結論（先に要点）**：就労移行支援の事業所にできる物件は、まず建築基準法上の用途が通るか、次に指定基準省令が求める訓練・作業室や相談室をその面積で確保できるか、そして消防法上の区分と設備が足りるかの3点で決まります。就労移行支援は障害者総合支援法の訓練等給付で、標準利用期間が原則2年。働くための訓練と実習のスペースを前提にする点が、就労継続支援A型・B型と設計の出発点が変わるところです。物件の用途地域・用途変更の要否・消防の現況の確認は当社が、指定申請は行政書士、用途変更の確認申請は建築士、職業指導員などの労働条件や社会保険は社会保険労務士へ分けてご案内します。それぞれ独立した事業体として、別々にご契約いただきます。

就労移行支援の事業所を開きたい事業者と、その物件を貸すオーナーに向けて、「どんな物件なら使えるのか」を建築基準法・指定基準省令・消防法の順に整理します。本記事は一般的な情報提供で、指定の可否や設備基準への適合の最終判断は、指定権者（都道府県・政令市等）・建築士・所管消防の領域です。

## 就労移行支援の事業所に求められる物件の基本要件とは何か？

就労移行支援は、一般就労を希望する障害のある方に、就労に必要な知識・能力の向上の訓練や職場実習、求職活動の支援などを行うサービスです。障害者の日常生活及び社会生活を総合的に支援するための法律（障害者総合支援法・平成17年法律第123号）に基づく指定障害福祉サービスの一つで、訓練等給付に位置づけられ、標準利用期間は原則2年とされています（障害者総合支援法施行規則第6条の9。更新が認められる場合でも更新は1回・1年が目安で、あん摩マッサージ指圧師等の養成施設を利用する場合は3年又は5年）。

この「2年で一般就労へ送り出す」前提が、工賃型のB型や雇用契約型のA型（いずれも就労継続支援）と設計の出発点を分けます。就労移行支援では、訓練室や職場を模した実習スペース、求職活動や面談のための相談室が中心になります。物件選びで効くのは、おおむね次の3点です。

| 確認の軸 | 物件で見るポイント | 根拠 |
| --- | --- | --- |
| 建築基準法上の用途 | その用途地域で建てられるか、用途変更の確認申請が要るか | 建築基準法第48条・別表第二、第87条 |
| 指定基準省令の設備 | 訓練・作業室、相談室、洗面所、便所を確保できるか | 平成18年厚生労働省令第171号 第178条・第179条 |
| 消防法上の区分と設備 | 防火対象物の区分と、必要な消防用設備を備えられるか | 消防法施行令別表第一(6)項 |

就労継続支援A型・B型の物件の考え方は[就労継続支援A型の物件は用途地域と消防のどこで確認するか](/column/shuro-keizoku-shien-a-bukken-youto-chiiki)と[就労継続支援B型の物件は用途地域と消防のどこで落ちるか](/column/shuro-keizoku-shien-b-bukken-youto-chiiki-shobo)にまとめています。本記事は、訓練と実習が中心になる就労移行支援に固有の物件要件を扱います。

## 用途地域と建築基準法上の「用途」はどう確認するか？

就労移行支援の事業所は、建築基準法施行令第19条第1項の「児童福祉施設等」に当たります。同項は、児童福祉施設・老人福祉施設・障害者支援施設のほか、生活介護・自立訓練・就労移行支援・就労継続支援などの障害福祉サービス事業の用に供する施設を「児童福祉施設等」と位置づけており、就労移行支援はこの用途として扱われます。

この用途でどの用途地域に建てられるかは、建築基準法第48条・別表第二および施行令第130条の各条で地域ごとに個別に決まります。事務所・店舗・住宅として使われていた既存建物を就労移行支援の事業所に変える場合は、用途変更の確認申請の要否が物件選びの分かれ目になります。

| 確認項目 | 根拠・ポイント |
| --- | --- |
| 用途の該当 | 施行令第19条第1項の「児童福祉施設等」に該当（就労移行支援を明記） |
| 用途地域の可否 | 建築基準法第48条・別表第二、施行令第130条の各条で個別に確認 |
| 用途変更の確認申請 | 用途を変える部分の床面積が200㎡超なら、使用前に確認申請（建築基準法第6条第1項・第87条） |
| 採光・避難 | 児童福祉施設等として採光・避難関係の規定が強めにかかる |

事務所や寄宿舎（社員寮など）からの用途変更は、床面積が200㎡を超えると使用前に確認申請が要ります。200㎡以下でも、採光・避難・消防の各規定への適合は別に問われます。用途地域への適合や確認申請の要否の最終判断は特定行政庁・建築士の領域で、当社は現況用途と面積を整理し、確認申請は建築士へおつなぎします。

## バリアフリー・訓練室・相談室の面積や設備はどこまで必要か？

指定基準省令（指定障害福祉サービスの事業等の人員、設備及び運営に関する基準・平成18年厚生労働省令第171号）は、就労移行支援の設備に関する基準（第178条・第179条）として、訓練・作業室、相談室、洗面所、便所を置くことを求めます。訓練・作業室は「訓練又は作業に支障がない広さ」とされ、相談室は談話の漏えいを防ぐ間仕切り等を設けることとされています。

注意したいのは、訓練・作業室について利用者1人あたりの面積が全国一律の数値では定められていない点です。民間の解説が示す「1人あたり◯㎡」といった数値は運用・推奨の目安で、省令本体の数値ではありません。ここは断定せず【未検証】とし、所管の指定権者の条例・手引きと事前協議で確認する前提にします。

| 設備 | 求められること | 面積・数値の扱い |
| --- | --- | --- |
| 訓練・作業室 | 訓練又は作業に支障がない広さ、必要な機械器具 | 全国一律の㎡/人基準はなし。目安は指定権者の運用【未検証】 |
| 相談室 | 談話が外に漏れない間仕切り等 | ― |
| 洗面所・便所 | 利用者の特性に応じたもの | ― |
| 多目的室等 | 支障がなければ相談室と兼用できる余地 | ― |
| バリアフリー | 段差・通路幅・手すり等は条例で上乗せがあり得る | 条例・手引きで確認 |

バリアフリーの水準は、利用者の障害特性や自治体の条例で上乗せされることがあります。何㎡・どの仕様が要るかの最終的な可否は指定権者・建築士が判断するため、物件を押さえる前に指定権者との事前協議が要ります。指定申請の手続は行政書士が別契約で承ります。

## 消防法令上の設備と防火対象物の区分はどうなるか？

消防法施行令別表第一の(6)項は社会福祉施設等を区分し、身体上・精神上の理由で自ら避難することが困難な者が主として入所・利用するものを(6)項ロ、それ以外を(6)項ハとします。通所で、避難が困難な利用者を主な対象としない就労移行支援は(6)項ハになるのが基本ですが、サービス内容や利用者の避難困難性、受入体制を総合して所管消防が個別に判断します。

| 確認項目 | ポイント |
| --- | --- |
| 防火対象物の区分 | 通所の就労移行支援は(6)項ハが基本。避難困難者を主な対象とすると(6)項ロの可能性 |
| 消防用設備 | 区分・面積・階数で、自動火災報知設備・消火器・誘導灯等。区分で変わる |
| 判断主体 | 所管消防（消防署・予防課）が個別に判断。物件確定前に相談 |
| 既存建物 | 必要な設備を後付けできるか（配線・区画）が選定の分かれ目 |

必要な消防用設備の具体や工事費は、機器の構成と建物で変わるため、ここも断定せず【未検証】とし、消防設備士・建築士・所管消防の確認を前提にします。当社は既設の消防用設備や区分の見込みを物件情報として整理し、設計・工事・確認申請は各専門家へおつなぎします。

## よくある質問

**Q. 就労移行支援は就労継続支援A型・B型と同じ物件で開けますか？**
A. 建築基準法上の用途はいずれも「児童福祉施設等」で共通なので、用途地域・用途変更・採光・避難・消防の枠組みは重なります。ただし就労移行支援は標準利用期間が原則2年で、一般就労に向けた訓練室や実習スペース、相談室が中心になる点が設計の出発点として異なります。設備の該当は指定権者、用途の判断は建築士にご確認ください。

**Q. 事務所や社員寮を就労移行支援の事業所に変えたいのですが、確認申請は要りますか？**
A. 用途を変える部分の床面積が200㎡を超えると、使用前に用途変更の確認申請が要ります（建築基準法第6条第1項・第87条）。200㎡以下でも採光・避難・消防の各規定への適合は別に問われます。該当の判断と設計は建築士・特定行政庁の領域で、当社は現況用途と面積を整理し、建築士へおつなぎします。

**Q. 訓練・作業室は利用者1人あたり何㎡必要ですか？**
A. 指定基準省令（平成18年厚生労働省令第171号第178条）は「訓練又は作業に支障がない広さ」とするだけで、全国一律の1人あたり㎡数は定めていません。民間解説が示す数値は運用・推奨の目安で、省令の数値ではありません（本記事では【未検証】扱い）。必要面積は定員や訓練内容、指定権者の条例で変わるため、物件確定前に事前協議でご確認ください。

**Q. 職員の労働条件や社会保険は不動産会社で相談できますか？**
A. いいえ。職業指導員・就労支援員などスタッフの労働時間・就業規則・社会保険の設計は社会保険労務士の領域で、当社は扱いません。物件・用途の確認は当社、指定申請は行政書士、労務は社会保険労務士へ、それぞれ独立した事業体として別々にご契約いただきます。
