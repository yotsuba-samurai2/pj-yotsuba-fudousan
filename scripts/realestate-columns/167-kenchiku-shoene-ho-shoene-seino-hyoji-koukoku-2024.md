**結論（先に要点）**：2024年（令和6年）4月1日から、建築物の販売・賃貸を行う事業者は、2024年4月以降に新築される建築物の広告などに「省エネ性能ラベル」を表示するよう努めることになりました。根拠は建築物のエネルギー消費性能の向上等に関する法律（建築物省エネ法＝平成27年法律第53号）第27条第1項の努力義務と、国土交通大臣が表示すべき事項・方法を定めた告示（令和5年国土交通省告示第970号、令和5年9月25日公布）です。ラベルには、国の省エネ基準からの削減度合いを示すエネルギー消費性能（星の数）、住宅なら断熱性能、再エネ設備の有無、評価年月日などが載り、住戸向けのラベルでは年間の目安光熱費も任意で表示できます。これは「表示義務」ではなく努力義務ですが、適切に表示しない事業者には国土交通大臣が勧告・公表・命令を行うことができます（第28条）。不動産会社（当社）が担うのは、広告にラベルを載せる媒介の実務と、重要事項説明（宅地建物取引業法第35条）を含む情報提供、そしてオーナーが何を先に手配すべきかの整理まで。ラベルのもとになる省エネ計算やBELSの評価書の発行は建築士・登録住宅性能評価機関、建築確認や完了検査は指定確認検査機関・特定行政庁、省エネ改修の補助金の申請は各制度の窓口（当社では扱いません）が担い、いずれも独立した事業体として別々にご契約いただく形でおつなぎします（紹介料のやりとりはありません）。個別の物件の省エネ性能の算定や適合の最終判断は、各有資格者・評価機関の領域です。

住宅や事業用物件を売買・賃貸の広告に出すオーナーや、媒介を使う売主・貸主に向けて、省エネ性能ラベルや目安光熱費の表示で何が変わったのかを、条文と国土交通省の資料の順に整理します。本記事は一般的な情報提供であり、個別の物件の省エネ性能の算定やラベルの作成の最終判断は、建築士・登録住宅性能評価機関と所管の行政の領域です。

四葉不動産株式会社は、東京都文京区小日向を拠点に、住宅・事業用不動産の調査と媒介を承っています。「この物件を広告に出すとき、何を表示すればよいのか」という段階から、契約前に確認できることをご相談いただけます。

## 省エネ性能表示制度は何を根拠に、いつ始まったのか？

省エネ性能表示制度の根拠は、建築物省エネ法の第27条です。第27条第1項は、建築物の販売又は賃貸を行う事業者（販売事業者等）は、その建築物についてエネルギー消費性能を表示するよう努めなければならないと定めています。第27条第2項は、国土交通大臣がその表示すべき事項と表示の方法その他事業者が遵守すべき事項を定めて告示するとしています。

この第27条第2項を受けて定められたのが、「建築物のエネルギー消費性能に関し販売事業者等が表示すべき事項及び表示の方法その他建築物のエネルギー消費性能の表示に際して販売事業者等が遵守すべき事項」（令和5年国土交通省告示第970号、令和5年9月25日公布）です。この告示に沿った表示の運用が、2024年（令和6年）4月1日から始まりました。従来も平成28年の告示に基づく努力義務はありましたが、国が定める様式のラベルを用いる形に具体化されたのが今回の制度です。

| 項目 | 内容 |
|---|---|
| 根拠法 | 建築物省エネ法（平成27年法律第53号）第27条・第28条 |
| 告示 | 令和5年国土交通省告示第970号（令和5年9月25日公布） |
| 運用開始 | 2024年（令和6年）4月1日 |
| 位置づけ | 努力義務（表示義務ではない。従わなければ勧告・公表・命令の対象） |

## 売買・賃貸の広告で、具体的に何を表示することになったのか？

表示の対象になるのは、2024年4月以降に新築される建築物を販売・賃貸するときの広告などです。新聞・雑誌の広告、チラシ、パンフレット、インターネット広告といった、買主・借主が物件を選ぶために見る媒体が対象になります。表示には、原則として国の告示で定められた様式の「省エネ性能ラベル」を用います。

ラベルに載る主な項目は次のとおりです。住宅（住戸）向けのラベルと、住棟・非住宅向けのラベルで一部の扱いが異なります。

| 表示項目 | 内容 | 備考 |
|---|---|---|
| エネルギー消費性能 | 国の省エネ基準からの削減度合いを星の数で多段階表示（再エネを除く一次エネルギー消費量ベース） | 必須 |
| 断熱性能 | 外皮の断熱性能を多段階表示 | 住宅で必須（非住宅にはない） |
| 再エネ設備の有無 | 太陽光発電などがあれば「再エネ設備あり」と表示 | 設置時に表示 |
| 目安光熱費 | 年間の光熱費の目安（円） | 住戸ラベルで任意・住棟ラベルでは表示されない |
| ネット・ゼロ・エネルギー等 | ZEH水準・ZEB水準の達成の表示 | 第三者評価の場合に表示 |
| 評価年月日・評価の区分 | 評価した年月日、自己評価か第三者評価かの別 | 必須 |

星の数は「エネルギー消費性能」の多段階評価で、再生可能エネルギーを除いた一次エネルギー消費量が国の基準からどれだけ削減されているかを示します。断熱性能は住宅のラベルにだけある項目で、外皮の性能を別の目盛りで多段階に示します。目安光熱費は住戸向けのラベルで任意に表示できる項目で、すべてのラベルに必ず載るものではありません。

## 省エネ性能ラベルの星や目安光熱費は、誰がどう算定するのか？

ラベルの評価には、事業者自身が行う「自己評価」と、評価機関が行う「第三者評価（BELS）」の二通りがあります。

自己評価は、販売・賃貸事業者が、建築物のエネルギー消費性能の計算結果をもとにラベルを作成するものです。計算やラベルの作成を支援する「自己評価ラベル・評価書作成プログラム」が、一般社団法人住宅性能評価・表示協会のサイトで公開されています。第三者評価は、登録住宅性能評価機関などの評価機関がBELS（建築物省エネルギー性能表示制度）として評価・発行するもので、ネット・ゼロ・エネルギー（ZEH・ZEB）の表示は第三者評価の場合にラベルへ載ります。

| 評価の種類 | 誰が行うか | ラベルの位置づけ |
|---|---|---|
| 自己評価 | 販売・賃貸事業者（計算は建築士等の協力が前提） | 自己評価である旨をラベルに表示 |
| 第三者評価（BELS） | 登録住宅性能評価機関などの評価機関 | 第三者評価である旨を表示・ZEH/ZEB表示が可能 |

ここで役割を分けて押さえたいのは、ラベルに載る星の数や断熱性能の目盛り、目安光熱費のもとになる省エネ計算は、建築士や登録住宅性能評価機関の専門領域だという点です。不動産会社（当社）が担うのは、できあがったラベルを広告に正しく載せる媒介の実務と、重要事項説明での情報提供までで、省エネ性能の算定そのものは行いません。省エネ投資やZEHの考え方は、建てる側の省エネと補助金を扱った[木造賃貸・マンションのゼロエミ化と補助金](/column/mokuzo-chintai-mansion-zeroemi-hojokin)の記事も参考になります。本記事はあくまで「広告時の表示（努力義務）」に限った整理で、補助金の申請は各制度の窓口の領域です。

## 表示は義務なのか努力義務なのか、既存物件はどう扱われるのか？

省エネ性能ラベルの表示は、建築物省エネ法第27条第1項の「努力義務」です。表示そのものを強制する「義務」ではありません。ただし、国土交通大臣は、告示に従った表示をしていない事業者に対して表示をすべき旨を勧告でき（第28条第1項）、勧告に従わないときはその旨を公表でき（第2項）、正当な理由なく勧告に係る措置をとらず省エネ性能の向上を著しく害すると認めるときは、社会資本整備審議会の意見を聴いて命令できます（第3項）。努力義務だから何をしてもよい、という制度ではありません。

既存建築物（2024年4月1日より前に建築確認を行った物件など）については、省エネ性能が分かっていれば新築と同様に表示することが推奨されていますが、表示しない場合に勧告などの対象にはなりません。注文住宅も制度上は対象外で、制度に沿った表示が推奨される扱いです。

| 対象 | 表示の扱い |
|---|---|
| 2024年4月以降に新築される建築物の販売・賃貸広告 | 努力義務（従わなければ勧告・公表・命令の対象になり得る） |
| 既存建築物 | 推奨（勧告等の対象にはならない） |
| 注文住宅 | 対象外（推奨） |

## ラベルが無い・低い物件は、売却や募集で不利になるのか？

これは一般的な情報提供の範囲でお伝えすると、ラベルの有無や評価の高低が、ただちに売買・賃貸の可否を左右するわけではありません。努力義務であり、ラベルが無いことを理由に取引ができなくなる制度ではないからです。一方で、同じエリア・同じ価格帯で省エネ性能ラベルを掲げた物件が増えるほど、ラベルの無い物件は買主・借主の比較検討で見劣りする場面が出てきます。年間の目安光熱費は、入居後のランニングコストに直結する情報として関心を持たれやすい項目です。

役割はこう分かれます。これらは一つの契約にまとめられるものではなく、**いずれも独立した事業体として別々にご契約**いただきます。

| 担当 | 役割 |
|---|---|
| 不動産（当社） | 広告へのラベル表示の媒介、重要事項説明を含む情報提供、手配すべきものの整理 |
| 建築士・登録住宅性能評価機関 | 省エネ計算、BELS評価書・ラベルの発行 |
| 指定確認検査機関・特定行政庁 | 建築確認・完了検査 |
| 各制度の窓口 | 省エネ改修の補助金の申請（当社では扱わない） |
| 司法書士 | 建物・法人の登記 |
| 税理士 | 売却・賃貸に伴う税務 |

物件のことと広告は当社、省エネ計算とラベル発行は建築士・評価機関、と窓口を分けたうえで、同じ一つの窓口からスムーズにおつなぎする形です。紹介にあたって紹介料のやりとりはありません。

## 広告を出す前に、オーナーは何を手配しておけばよいのか？

広告を出す前にオーナー側で段取りしておくと滞りがないのは、次の点です。物件側の客観的な情報（竣工時期、建築確認の時期、設計図書や省エネ計算の有無、BELS評価書の有無）は、当社が広告の媒介の前提として確認します。

| 手配すること | 誰に相談するか |
|---|---|
| 自己評価でラベルを作るか、第三者評価（BELS）を取るか | 建築士・登録住宅性能評価機関 |
| 省エネ計算の結果・設計図書の用意 | 建築士（新築時の設計者等） |
| 広告へのラベル表示の媒介・重要事項説明 | 不動産（当社） |
| 省エネ改修を伴う場合の補助金 | 各制度の窓口 |

**[物件の広告・省エネ性能ラベルの相談は四葉不動産へ（相談無料）](/toushi)**

お問い合わせに、物件の種別（住宅か事業用か）、新築か既存か、BELS評価書の有無、売却か賃貸かをご記入ください。広告にラベルを載せる段取りと、省エネ計算・ラベル発行・補助金の振り先の整理からお話しします。

## よくある質問

**Q. 省エネ性能ラベルの表示は義務ですか、努力義務ですか？**
A. 努力義務です。建築物省エネ法第27条第1項は、建築物の販売・賃貸を行う事業者はエネルギー消費性能を表示するよう努めなければならないと定めており、表示そのものを強制する義務ではありません。ただし、告示（令和5年国土交通省告示第970号）に従った表示をしない事業者には、国土交通大臣が表示をすべき旨の勧告を行い、従わなければ公表、さらに命令まで行うことができます（第28条）。努力義務だから表示しなくてよい、という制度ではありません。

**Q. いつから、どの物件が対象になりますか？**
A. 運用は2024年（令和6年）4月1日から始まりました。対象は、2024年4月以降に新築される建築物を販売・賃貸するときの広告など（新聞・雑誌広告、チラシ、パンフレット、インターネット広告）です。既存建築物は、省エネ性能が分かっていれば表示が推奨されますが、表示しなくても勧告等の対象にはなりません。注文住宅も対象外で、制度に沿った表示が推奨される扱いです。

**Q. ラベルの星や目安光熱費は、不動産会社が決めるのですか？**
A. いいえ。星で示すエネルギー消費性能や断熱性能、目安光熱費のもとになる省エネ計算は、建築士や登録住宅性能評価機関の領域です。自己評価は事業者が計算結果をもとに作成し、第三者評価はBELSとして評価機関が発行します。不動産会社（当社）が担うのは、できあがったラベルを広告に正しく載せる媒介と、重要事項説明での情報提供までで、省エネ性能の算定そのものは行いません。

**Q. 年間の目安光熱費はすべてのラベルに載りますか？**
A. いいえ。目安光熱費は住戸向けのラベルで任意に表示できる項目で、住棟向けのラベルには表示されません。エネルギー消費性能（星）や評価年月日、自己評価か第三者評価かの区分は必須項目ですが、目安光熱費や再エネ設備の有無などは物件や評価の種類によって扱いが変わります。表示の様式の細目は告示で定められており、改正されることがあるため、最新の国土交通省の案内と告示本文で参照日を控えて確認してください。
