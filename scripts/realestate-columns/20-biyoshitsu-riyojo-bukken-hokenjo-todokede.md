**結論（先に要点）**：美容室・理容所の物件で保健所が見るのは、①作業場と待合を明確に区分できるか②洗場・消毒・採光照明換気の設備が整うか、の2点です。加えて、飲食店やクリニックと違い、美容院・理髪店は建築基準法の用途地域制限を受けます。開設届は「あらかじめ」出し、構造設備の検査・確認を受けてからでなければ使えません。契約前に用途地域と区画を確かめれば、手戻りは防げます。

「あとは内装だけ」と言われて借りたのに、開設届の段になって保健所から区画のやり直しを求められる。飲食店や介護事業所で起きるのと同じ手戻りが、美容室・理容所でも起きます。本記事は、東京で美容所・理容所を開こうとしている美容師・理容師の方と、その物件を貸す方に向けて、賃貸借契約を結ぶ前に確認できることを、美容師法・理容師法の条文と厚生労働省の要領から順に整理したものです。可否の最終確認は特定行政庁と保健所の窓口で行います。

## 美容室・理容所の物件で、保健所は何を見ているのか？

保健所が見るのは「構造設備」です。美容師法（昭和32年法律第163号）第12条は、こう定めています。「美容所の開設者は、その美容所の構造設備について都道府県知事の検査を受け、その構造設備が第十三条の措置を講ずるに適する旨の確認を受けた後でなければ、当該美容所を使用してはならない」。理容所も同じで、理容師法（昭和22年法律第234号）第11条の2が構造設備の検査・確認を、使用の前提として定めています。

つまり——**内装が終わってから保健所が来て、区画や設備が基準に足りなければ、そのままでは営業できません。** ここが物件選びの起点です。

では何を満たせばよいのか。厚生労働省の「理容所及び美容所における衛生管理要領」（昭和56年6月1日環指第95号）が、構造設備の考え方を示しています（**2026年8月24日参照**）。

| 項目 | 要領が示す考え方 |
|---|---|
| 区画 | 作業場と待合所は**明確に区分**されていること。作業場は居住室・休憩室等と間仕切りで区分 |
| 照明 | 作業中の作業面の照度は**300ルクス以上が望ましい**（下限は各都道府県の条例による） |
| 換気 | 作業場内の炭酸ガス濃度は5,000ppm以下（1,000ppm以下が望ましい） |
| 洗場 | 流水装置とし、給湯設備を設けること |
| 消毒 | 器具・布片・タオル等を消毒する設備または器材を備えること |
| 収納 | 皮膚に接する器具を、消毒済みと未消毒に区別して収納できること |

**注意すべきは、具体的な数値（作業室の床面積、洗い場やシャンプー設備の数など）は、各都道府県が条例で定めるということです。** 美容師法第13条・理容師法第12条は、衛生上必要な措置として「清潔の保持」「消毒設備」「採光・照明・換気の充分な確保」を挙げ、さらに「その他都道府県が条例で定める衛生上必要な措置」を求めています。**数値は自治体で違います。着手時に管轄の保健所に確かめてください。**

## 作業場の面積やシャンプー台の数に、全国一律の決まりはあるのか？

**全国一律の数値はありません。** 面積・シャンプー設備の数・洗い場の位置といった具体的な基準は、上に書いたとおり各都道府県（保健所設置市・特別区ではその市・区）の条例で定められます。だから「隣の県ではこの広さで通った」が、そのまま使えるとは限りません。

物件側で確認しておくとよいのは、条例の数値そのものより、**その数値を満たせる素地があるか**です。

| 契約前に確認 | なぜ効くか |
|---|---|
| 作業場と待合を仕切れる間取りか | 区画は要領・条例の要の一つ。ワンルームでは待合を別に取れないことがある |
| 給排水の位置と口径 | 洗場は流水・給湯が要る。シャンプー台を増やすほど給排水の増設費が動く |
| 換気設備の有無・増設余地 | 炭酸ガス濃度の基準は換気で担保する |
| 電気容量 | シャンプー給湯・ドライヤー・空調で容量が要る。増設は費用と工期に響く |
| 床・壁の防水と清掃性 | 「常に清潔に保つ」ための素地。原状回復の範囲とも絡む |

給排水・換気・電気容量の設計は施工業者（設計者）の領域です。**当社（不動産会社）は、物件がこれらの条件を満たせるかどうかの下調べと、貸主との条件交渉に伴走します。** 設備設計そのものは行いません。同じ構造の手戻りが飲食店の物件で起きる理由は[「介護事業所の物件が見つからない本当の理由」](/column/kaigo-jigyousho-bukken-youto-chiiki)に、契約書のどこを読むかは[「賃貸借契約書、どこを読めばいいか」](/column/chintaishaku-keiyakusho-doko-wo-yomu)に整理しています。

## 居抜きとスケルトンで、確認すべき設備の違いは何か？

大きく違います。前の借主が美容室・理容所だった居抜きなら、洗場・給排水・換気が残っていることがあります。ただし——**「前も美容室だったから大丈夫」は保証になりません。**

理由は2つです。第一に、構造設備の検査・確認は美容所・理容所ごとに受け直すものであり（美容師法第12条／理容師法第11条の2）、前の店の確認が新しい開設者に引き継がれるわけではありません。第二に、条例や運用は改正されることがあり、前の店が開設した時点の基準と、いま求められる基準が違う場合があります。

| | 居抜き（前も美容室・理容所） | スケルトン |
|---|---|---|
| 洗場・給排水 | 残っていることが多い（要点検） | 新設。位置と口径を設計から |
| 換気設備 | 流用できる場合あり | 新設 |
| 区画（作業場・待合） | 前の間取りを踏襲できる場合あり | 一から設計 |
| 検査・確認 | **新たに受け直す** | 新たに受け直す |
| 初期費用の傾向 | 抑えやすい | 増えやすい |

居抜きでも、**引渡し前に設備の状態を点検し、保健所の基準を満たすかを確認**しておくのが安全です。残置設備の所有・修繕・撤去の負担を契約でどう定めるかは、居抜き特有の論点です。

## 用途地域や建築確認が問題になるのは、どんなときか？

ここが、クリニックとの最大の違いです。診療所は建築基準法の用途制限では全用途地域で建てられますが、**美容院・理髪店は「店舗（サービス業を営む店舗）」として扱われ、用途地域の制限を受けます。**

建築基準法（昭和25年法律第201号）施行令（昭和25年政令第338号）第130条の3第3号は、第一種低層住居専用地域で建てられる兼用住宅の一つとして「理髪店、美容院……その他これらに類するサービス業を営む店舗」を挙げます。ただし条件があり、**延べ面積の2分の1以上を住居とし、店舗部分の床面積の合計が50㎡以下**でなければなりません。つまり第一種低層住居専用地域では、単独の店舗としては建てられず、自宅兼用で小規模なものに限られます。

第二種低層住居専用地域では、建築基準法別表第二(ろ)項第二号と施行令第130条の5の2により、政令で定める店舗（理髪店・美容院を含む）で、**床面積の合計150㎡以内・3階以上を当該用途に供しないもの**が建てられます。第一種中高層住居専用地域以上では、面積の制限が緩みます。

| 用途地域 | 美容院・理髪店の扱い |
|---|---|
| 第一種低層住居専用地域 | 兼用住宅のみ（住居が延べ面積の1/2以上・店舗部分50㎡以下） |
| 第二種低層住居専用地域 | 政令で定める店舗として150㎡以内・3階以上に供しないもの |
| 第一種・第二種中高層住居専用地域 | 面積制限が緩和され建てやすい |
| 住居・準住居・近隣商業・商業・準工業地域 | 建てられる |

そして、**事務所や別業種の店舗を美容室に変えるとき、床面積によっては用途変更の確認申請が要ることがあります。** 建築基準法第87条第1項は、用途を変更して同法第6条第1項第1号の特殊建築物（別表第一(い)欄の用途で200㎡超）とする場合に確認申請を準用しますが、美容院はこの別表第一(い)欄の特殊建築物には通常当たりません。もっとも、確認申請の要否とは別に、用途地域の制限（第48条）や採光・換気などの実体規定はかかります。**用途地域上の可否と用途変更の要否は、契約前に特定行政庁で確認できます。** 用途地域と容積率が土地の値づけをどう動かすかは[「日本の土地値はなぜ『容積率』で変わるのか」](/column/yosekiritsu-hosei-tochine)に、消防・自治体の確認が契約より先に要る例は[「民泊を始められる物件の条件」](/column/minpaku-bukken-joken-kakunin)に整理しています。

## 開設届は誰がいつ出す？物件契約とのスケジュールはどう組むか？

美容師法第11条は、「美容所を開設しようとする者は……美容所の位置、構造設備……その他必要な事項を**あらかじめ**都道府県知事に届け出なければならない」と定めます。理容師法第11条も同じです。**「あらかじめ」＝開設前**であり、飲食店の営業許可やクリニックの開設届（開設後10日以内）とは順序が違います。

さらに、構造設備の検査・確認（美容師法第12条／理容師法第11条の2）を受けてからでなければ使用できません。したがって流れはこうなります。

| 順番 | やること | 担い手 |
|---|---|---|
| 1 | 用途地域・用途変更の要否を確認 | 特定行政庁・宅地建物取引業者 |
| 2 | 区画・給排水・換気・電気容量を満たせるか下調べ | 宅地建物取引業者・施工業者 |
| 3 | 賃貸借契約 | 宅地建物取引業者 |
| 4 | 内装工事（区画・洗場・消毒設備・照明・換気） | 施工業者 |
| 5 | 開設届を「あらかじめ」提出 | 開設者（美容師・理容師） |
| 6 | 保健所の立入検査（構造設備）・確認 | 保健所 |
| 7 | 確認後に使用開始（営業） | 開設者 |

**物件の契約は手続の前提です。** 従業者が2人以上になる美容所には管理美容師（美容師法第12条の3）、理容所には管理理容師（理容師法第11条の4）を置く必要があり、これは人の要件なので物件とは別に準備します。開設届など保健所に提出する書類の作成は、四葉行政書士事務所が承ります。**行政の窓口・様式・条例の数値・受付の運用は変わります。着手時点で管轄の保健所のページを直接ご確認ください。** 事業用物件全般は[投資用・事業用不動産](/toushi)、事務所と許認可の関係は[会社設立とオフィス選び](/office)をご覧ください。

## 誰に相談すればよいですか？

物件の調査、媒介、売買・賃貸借の契約は、四葉不動産株式会社（宅地建物取引業 東京都知事(1)第113304号）が承ります。美容所・理容所の開設届など官公署に提出する書類の作成は、四葉行政書士事務所が承ります。用途変更・建築確認が絡む場合の設計は建築士が、内装の給排水・換気設計は施工業者が扱います。

**この2つ（不動産会社・行政書士事務所）はそれぞれ独立した事業体です。それぞれ直接ご契約いただきます。** 当社・当事務所は、紹介料・送客手数料を受け取ることも支払うこともありません。登記は司法書士、税務は税理士、労務は社会保険労務士へ、それぞれ直接ご依頼いただく形をご案内します。相談は無料です。

## よくある質問

**Q. 住宅街（第一種低層住居専用地域）に美容室を開けますか？**
A. 単独の店舗としては原則開けません。建築基準法施行令第130条の3第3号により、理髪店・美容院は「兼用住宅」としてのみ建築でき、延べ面積の2分の1以上を住居とし、店舗部分の床面積の合計が50㎡以下であることが条件です。用途地域上の可否は物件ごとに異なるため、特定行政庁の窓口で確認してください。

**Q. 前も美容室だった居抜き物件なら、そのまま開設届が通りますか？**
A. 通るとは限りません。構造設備の検査・確認は開設者ごとに受け直すもので（美容師法第12条・理容師法第11条の2）、前の店の確認は引き継がれません。条例や運用が改正されていることもあります。残置設備の状態と現行基準への適合を、引渡し前に点検し、保健所に確認してください。

**Q. 作業場の広さやシャンプー台の数には、法律上の数値がありますか？**
A. 全国一律の数値はありません。美容師法第13条・理容師法第12条は「その他都道府県が条例で定める衛生上必要な措置」を求めており、面積・設備の具体的な数値は各都道府県（保健所設置市・特別区ではその市・区）の条例で定められます。管轄の保健所でご確認ください。

**Q. 開設届はいつ出せばよいですか？物件契約より先ですか？**
A. 美容師法第11条・理容師法第11条は「あらかじめ」（開設前に）届け出ると定めています。さらに構造設備の検査・確認を受けてからでなければ使用できません。したがって、物件契約→内装工事→開設届→保健所の検査・確認→営業開始、の順です。物件の契約は手続の前提になります。
