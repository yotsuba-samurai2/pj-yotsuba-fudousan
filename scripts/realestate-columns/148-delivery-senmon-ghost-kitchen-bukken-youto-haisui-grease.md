**結論（先に要点）**：イートインを持たない宅配・テイクアウト専業（ゴーストキッチン）でも、客に出す食品を調理するなら飲食店営業の許可が要り（食品衛生法〔昭和22年法律第233号〕第55条第1項・施行令第35条第1号）、物件選びでは用途地域・排水・保健所の施設基準の3点が先に効きます。用途地域は建築基準法（昭和25年法律第201号）第48条・別表第二で、飲食店は第一種低層住居専用地域では原則建てられず、第二種低層は床面積150㎡以下、第一種中高層は500㎡以下、第二種中高層は1,500㎡以下、第一種住居は3,000㎡以下、工業専用地域では建てられません。排水は下水道法（昭和33年法律第79号）第10条が排水設備の設置を義務づけ、油脂を含む厨房排水にはグリストラップ（油脂分離阻集器）を昭和50年建設省告示第1597号や各自治体の下水道条例・排水設備基準で求めるのが通例です。物件の調査と賃貸の媒介は当社（宅地建物取引業）、飲食店営業許可の申請と保健所協議の書類作成は行政書士、施設基準の事前相談は管轄保健所、用途地域適合・用途変更の確認申請は建築士・特定行政庁へ、それぞれ独立した事業体として別々にご契約いただく形でおつなぎします（紹介料のやりとりはありません）。

イートインを持たず宅配・テイクアウトに絞って低投資で始めたい方、居抜きの小区画やシェアキッチンを探している方に向けて、契約前に物件側で確認できることを、条文と国の資料の順に整理します。本記事は一般的な情報提供であり、個別の物件がどの用途に当たるか、どの許可が要るかの最終判断は、特定行政庁・保健所と有資格者の領域です。

四葉不動産株式会社は、東京都文京区小日向を拠点に、事業用物件の調査と賃貸・売買の媒介を承っています。デリバリー専業の区画について、契約前に確認できることからご相談いただけます。

## デリバリー専門の店舗はどの用途地域なら開けるのか？

デリバリー専業でも、厨房で調理をする以上、建築基準法上は「飲食店」として扱われるのが一般的です。用途地域ごとの可否と規模の上限は、建築基準法第48条と別表第二で決まります。イートインが無いからといって、この面積制限が消えるわけではありません。おおむね次のとおりです（概要であり、階数の計算や特定行政庁の条例・地区計画でさらに絞られることがあります）。

| 用途地域 | 飲食店の可否・規模の目安 |
|---|---|
| 第一種低層住居専用地域 | 原則不可（兼用住宅で店舗部分が床面積50㎡以下などの例外のみ） |
| 第二種低層住居専用地域 | 2階以下かつ床面積150㎡以下 |
| 第一種中高層住居専用地域 | 2階以下かつ床面積500㎡以下 |
| 第二種中高層住居専用地域 | 2階以下かつ床面積1,500㎡以下 |
| 第一種住居地域 | 床面積3,000㎡以下 |
| 第二種住居・準住居・近隣商業・商業・準工業 | 飲食店は可（上限は大きい） |
| 工業地域 | 飲食店は可 |
| 工業専用地域 | 不可 |

住居系の地域で低投資の小区画を探すときは、この床面積の上限が最初の関門です。なお、複数ブランドを一つの厨房で動かす大規模な調理に寄ると、建築基準法上「工場」に近い扱いになりうるケースもあり、用途の当てはめは物件ごとに分かれます。どの用途に当たるか、用途変更の確認申請が要るかは、建築士・特定行政庁にご確認ください。

## イートインがなくても飲食店営業許可は要るのか、保健所は何を見るのか？

要ります。客に提供する食品を調理する営業は、店内で食べさせるかどうかにかかわらず、飲食店営業の許可の対象です（食品衛生法第55条第1項、施行令第35条第1号の「飲食店営業」）。2018年の法改正（令和3年6月1日に全面施行）で、営業許可業種は政令で定める34業種から32業種に再編され、HACCPに沿った衛生管理が制度化されたほか、許可の要らない営業には保健所への届出が新設されました（第57条）。

保健所が施設で見るのは、食品衛生法第54条が条例に委ねる施設基準です。令和3年6月1日施行の施行規則の共通基準に、都道府県・保健所設置市の条例が重なります。宅配専業の区画でも、作業区画の区分、手洗い設備、冷蔵・冷凍設備、二槽シンクや給湯、床・壁の清掃しやすさといった点は変わりません。一つの厨房で複数ブランドを運営しても、許可は施設ごとに取るのが原則です。構造設備が基準を満たせるかは、物件を押さえる前に管轄保健所へ事前相談しておくのが安全です。許可の区分判断と申請書類の作成は行政書士が、施設基準の個別の適合判断は保健所が担います。

## 排水・グリストラップ・給排水はどこまで物件側で用意されているか？

飲食店の厨房排水には油脂や残渣が混じるため、そのまま流すと配管の詰まりや下水道への悪影響を招きます。公共下水道の供用区域では、下水道法第10条が排水設備の設置を義務づけ、油脂を分離・阻集するグリストラップ（油脂分離阻集器）を、昭和50年建設省告示第1597号（排水設備の技術的基準）や各自治体の下水道条例・排水設備の技術上の基準で求めるのが通例です。基準を超える排水を出すおそれがあるときは、除害施設の設置を条例で命じられることもあります（下水道法第12条・第12条の11）。

居抜きの区画では、前のテナントが飲食店だったとしても、グリストラップの容量が自分の業態に見合うか、点検・清掃がされてきたか、給排水・給湯の口径や排気ダクトが使えるかを、契約前に見ておく必要があります。グリストラップが無い、または容量が不足する区画では、後から設置・増設が要り、床下の配管工事が賃貸借契約の原状回復や造作の扱いに絡みます。居抜きで油脂と排気を扱った[スケルトン・居抜きの飲食店物件の確認点](/column/inshokuten-skeleton-bukken-haiki-grease)や、車両では調理が完結しない[キッチンカーの仕込み場所の物件要件](/column/kitchen-car-shikomi-basho-bukken-eigyo-kyoka-youken)も、排水と許可の考え方が参考になります。配管・排気の設計や能力の判断は、建築士・設備業者の領域です。

## 居抜き・シェアキッチンと一棟賃貸では契約・原状回復がどう違うのか？

デリバリー専業の出店形態は、大きく分けて、運営者が許可を取得済みのシェアキッチン（クラウドキッチン）に区画を借りる形と、区画・一棟を自分で賃借して居抜き・スケルトンから仕立てる形があります。契約と原状回復の論点が異なります。

| 形態 | 確認する点 |
|---|---|
| シェアキッチン（区画を時間・月極で利用） | 飲食店営業許可が施設運営者側にあるか、自分の区画で別途取れるか／許可名義と更新／区画の専有・共用の範囲／退去時の原状回復の軽重 |
| 居抜き賃貸（厨房設備が残る区画） | 給排水・グリストラップ・排気ダクトの能力と現況／造作譲渡の有無と費用／原状回復がスケルトン返しか現況返しか／賃貸借の使用目的に飲食店が含まれるか |
| スケルトン賃貸（内装なし） | 給排水・ガス・電気容量を引けるか／グリストラップ新設の可否／用途変更の確認申請／初期投資と退去時の撤去費 |

低投資・短期で始めたいならシェアキッチンが入りやすい一方、許可の名義や区画の専有の扱いで後から縛りが出ることがあります。自分で借りる場合は、賃貸借契約の使用目的に「飲食店営業（デリバリー）」が含まれるか、転貸やブランドの入替えが認められるかを、契約前に確認しておきます。契約条項の有利・不利の最終的な評価は弁護士の領域です。

## 近隣への配慮（におい・配達員の出入り・騒音）で物件選びに響く点は何か？

デリバリー専業は、イートインの客が来ない代わりに、配達員のバイク・自転車の出入りと待機、厨房の排気のにおい、仕込みや深夜営業の音が、近隣との摩擦になりやすい業態です。物件選びの段階で次の点を見ておくと、開業後のトラブルを避けやすくなります。

- 排気のにおい：排気ダクトの位置と向き、近隣の窓・ベランダとの距離。悪臭は悪臭防止法や自治体の生活環境条例の対象になりうる
- 配達員の動線：バイク・自転車の待機・駐輪スペースを敷地内に確保できるか、前面道路での待機が通行の支障にならないか
- 騒音・時間帯：深夜・早朝の調理や車両の音。マンション一階のテナントなら管理規約の用途・時間制限

これらは許可の可否とは別に、賃貸借契約や管理規約で営業そのものが制限される要因になります。物件の立地と近隣の状況を、契約前に当社が現況調査でお渡しします。

## よくある質問

**Q. イートインが無いデリバリー専業でも飲食店営業許可は要りますか？**
A. 客に出す食品を厨房で調理する以上、イートインの有無にかかわらず飲食店営業の許可が要ります（食品衛生法第55条第1項、施行令第35条第1号）。2018年改正（令和3年6月1日全面施行）で許可業種は34から32に再編され、許可の要らない営業は届出制になりました（第57条）。どの区分に当たるかの判断と申請書類の作成は行政書士、施設基準の適合判断は管轄保健所の領域です。

**Q. 住宅街の物件でもデリバリー専門の厨房を開けますか？**
A. 用途地域によります。飲食店は第一種低層住居専用地域では原則建てられず、第二種低層は床面積150㎡以下、第一種中高層は500㎡以下といった規模の上限があります（建築基準法第48条・別表第二）。デリバリー専業も建築基準法上は飲食店として扱われるのが一般的で、イートインが無くてもこの面積制限は外れません。用途の当てはめと用途変更の要否は建築士・特定行政庁にご確認ください。

**Q. 居抜き物件ならグリストラップはそのまま使えますか？**
A. 使えるとは限りません。前のテナントの業態と容量が自分の業態に見合うか、点検・清掃がされてきたかを確認する必要があります。公共下水道の区域では排水設備の設置が義務で（下水道法第10条）、油脂を含む厨房排水にはグリストラップを告示や自治体の条例で求めるのが通例です。容量不足や未設置なら設置・増設が要り、配管工事が原状回復や造作の扱いに絡みます。能力の判断は建築士・設備業者の領域です。

**Q. 一つの厨房で複数のデリバリーブランドを運営できますか？**
A. 運営の形としては行われていますが、飲食店営業の許可は施設ごとに取るのが原則です。シェアキッチンでは運営者側の許可の名義や区画の専有の扱い、自分で借りる場合は賃貸借の使用目的にブランドの入替えや転貸が含まれるかを、契約前に確認しておきます。許可の区分は保健所・行政書士、契約条項の評価は弁護士の領域です。
