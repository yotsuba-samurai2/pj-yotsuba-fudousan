**結論（先に要点）**：相続した不動産に塀・樹木の枝・庇（ひさし）の越境があっても、売ること自体はできます。売却で効くのは、越境の事実を買主に重要事項として説明できるか、将来の是正を約束した「越境の覚書」を隣地と交わして買主に引き継げるか、そして境界（筆界）がはっきりしているかです。2023年4月1日に施行された改正民法第233条で、越境した隣地の枝を自分で切り取れる場合が条件付きで認められましたが、原則はいまも「竹木の所有者に切除させる」です。越境の調査・重要事項説明・媒介は当社（宅地建物取引業）が担い、境界確定測量は土地家屋調査士、越境の覚書の作成は行政書士、相続登記は司法書士、隣地ともめている場合は弁護士、相続税は税理士へ、それぞれ独立した事業体として別々にご契約いただく形でおつなぎします（紹介料のやりとりはありません）。

隣地との越境がある実家・土地を相続し売却したい相続人と、仲介する不動産担当に向けて、「越境があると売れないのか」「何から手を付ければよいのか」を、改正民法と宅地建物取引業法の順に整理します。本記事は一般的な情報提供であり、個別の越境をどう処理するか、枝を切ってよいか、境界がどこかの最終判断は、弁護士・土地家屋調査士・当事者間の合意の領域です。

四葉不動産株式会社は、東京都文京区小日向を拠点に、相続不動産の査定と売却の媒介を承っています。隣地との越境がある土地について、売る前に確認できることからご相談いただけます。

## 相続した不動産に越境があると売却で何が問題になるのか？

越境それ自体が売却を禁じるわけではありません。問題になるのは、買主が「越境を知らずに買った」とならないよう重要事項として説明する必要があること、そして買主や買主の融資先（金融機関）が、将来の是正の見通しを気にすることです。

越境には、こちらの塀や庇・樹木の枝が隣地へ出ている場合と、隣地の塀・枝・庇がこちらへ入っている場合の両方があります。実家の相続では、長年のうちに生け垣が育って枝が越えている、古い塀が境界をまたいでいる、庇が隣地側に出ている、といった形で見つかります。

| 越境の種類 | 売却で効く点 |
|---|---|
| 樹木の枝・根の越境 | 改正民法第233条・第234条の処理。枝は原則「切らせる」、根は切れる |
| 塀・擁壁の越境 | 所有関係と境界の位置。[擁壁のある土地の売却](/column/gake-yoheki-tochi-baikyaku-bunkyo)の論点とも重なる |
| 庇・建物の一部の越境 | 境界線付近の建築（民法第234条）と、建替え時の是正 |
| 境界自体が未確定 | 越境の有無を確定できない。測量と筆界の確認が先 |

宅地建物取引業者が売買を媒介するときは、宅地建物取引業法（昭和27年法律第176号）第35条の重要事項説明で、取引の判断に重要な影響を及ぼす事項を買主に説明します。越境の有無・内容・是正の約束の有無は、買主の土地利用や将来の負担に直結するため、説明するのが実務です。当社は、越境の現況を現地と資料で確かめ、重要事項説明に正確に反映します。

## 改正民法233条で隣地の枝はどこまで切れるのか？

原則はいまも「隣地の竹木の所有者に越境した枝を切除させる」です。2023年4月1日施行の改正で、一定の場合に限り、越境された側が自分で枝を切り取れるようになりました。根は従前どおり自分で切り取れます。

民法第233条（令和3年法律第24号による改正・2023年〔令和5年〕4月1日施行）の骨格は次のとおりです。

| 項 | 内容 |
|---|---|
| 第233条第1項 | 隣地の竹木の枝が境界線を越えるときは、その竹木の所有者に、枝を切除させることができる（原則） |
| 第233条第2項 | 竹木が共有のときは、各共有者が越境した枝を切り取ることができる |
| 第233条第3項 | 次のいずれかのとき、土地の所有者は自ら枝を切り取れる。①所有者に催告したのに相当の期間内に切除しない②竹木の所有者を知ることができず、又はその所在を知ることができない③急迫の事情があるとき |
| 第233条第4項 | 隣地の竹木の根が境界線を越えるときは、その根を切り取ることができる |

改正前は、枝については「切らせる」か、応じないなら訴えを起こして判決を得て強制執行する必要がありました。改正後も原則は変わらず、「催告して相当期間待つ」「所有者不明」「急迫」のいずれかに当たってはじめて自ら切れます（第3項）。相当の期間は事案によりますが、各自治体の解説ではおおむね2週間程度とされる例があります。自分の判断で勝手に切ると、かえって損害賠償を問われることがあるため、どの要件に当たるかの判断は弁護士の領域です。建物の一部（庇など）の越境には、境界線から50センチメートル以上離して建物を築造すべきとする民法第234条が関わり、違反の是正請求には着手後1年・建物完成後は損害賠償のみとなる期間制限があります（第234条第2項）。当社が切除や是正の可否を断ずることはありません。

## 越境の覚書には何を書けばよいのか？

越境をすぐに解消できないときは、隣地所有者との間で「越境の覚書（確認書）」を交わし、現状の確認と、将来の建替え・改修時に是正する約束、そしてその約束を買主（第三者）に引き継がせることを定めておくのが実務です。

覚書に盛り込むのは、おおむね次の内容です（個別の事情で変わります）。

| 項目 | 書く内容 |
|---|---|
| 越境の特定 | どの物（塀・枝・庇など）が、どちらからどの範囲で越えているか。測量図・写真で特定 |
| 現状の相互確認 | 現状では撤去を直ちに求めないこと |
| 将来の是正 | 建替え・改修・樹木の更新などの機会に、越境を解消すること |
| 承継 | 所有者が替わっても（売買・相続でも）本覚書の内容を承継させること |
| 費用負担 | 是正費用を誰が負担するか |

このような覚書は、権利義務に関する書類として行政書士が作成する業務です。隣地と越境の事実や是正の要否をめぐって対立している場合は、交渉・調停・訴訟になり得るため、弁護士の領域です。当社は、覚書を交わす前提となる越境の現況と境界の資料を整え、覚書の作成は行政書士へ、合意ができない紛争は弁護士へと切り分けてご案内します。これらは**それぞれ独立した事業体**であり、**別々にご契約**いただく前提です。当社は紹介料・送客手数料を受け取ることも支払うこともありません。

## 境界が未確定のときは誰に何を頼むのか？

越境の有無や範囲は、境界（筆界）がどこかが分からないと確定できません。境界の測量と筆界の確認は、土地家屋調査士の専管です。売る前に境界確定測量や筆界特定を済ませておくと、越境の説明も覚書も確かなものになります。

土地の筆界（公法上の境界）に関する測量・表示に関する登記や、筆界特定の手続の代理は、土地家屋調査士法（昭和25年法律第228号）が土地家屋調査士の業務と定めています。隣地所有者の立会いのもとで境界を確認し、確定測量図を作る「確定測量」や、筆界が不明なときに法務局（筆界特定登記官）が筆界の位置を明らかにする「筆界特定制度」があります。

| 困りごと | 頼む先 |
|---|---|
| 境界を測って確定測量図を作る、境界標を確認する | 土地家屋調査士 |
| 筆界が不明で筆界特定を申請する | 土地家屋調査士（手続代理） |
| 越境の覚書・合意書を作る | 行政書士 |
| 隣地と境界・越境でもめている（交渉・調停・訴訟） | 弁護士 |
| 相続登記、建物の表題に関する登記 | 司法書士・土地家屋調査士 |

境界が確定していれば、越境部分の面積や位置をもって重要事項説明や覚書に落とし込めます。私道持分や接道が絡む場合は[相続した私道持分のある土地の売却](/column/souzoku-shido-mochibun-ichitei-doro-baikyaku)、境界確定測量から売却までの流れは[相続不動産の境界確定測量から売却までの進め方](/column/souzoku-fudosan-kyoukai-kakutei-sokuryo-baikyaku)も参考になります。当社は、既存の測量図や登記の現況を確認し、確定測量や筆界特定が要るかの見立てと、土地家屋調査士への振り分けをお手伝いします。

## 越境を残したまま売る方法と価格への影響は？

越境を解消してから売る方法と、越境を残したまま覚書を付けて売る方法があります。どちらを選ぶかは、是正の難易度・費用・時間と、買主や融資先の受け止めで決まります。価格には、是正費用の見込みや買主の手間の分だけ影響が出ることがあります。

| 売り方 | 要点 |
|---|---|
| 越境を解消してから売る | 塀の作り直し・枝の切除・庇の改修などで越境をなくす。費用と隣地の協力が要る |
| 越境を残し覚書を付けて売る | 現状のまま、将来の是正を約した覚書を買主に承継。説明と書面が整っていれば売りやすい |
| 境界・越境でもめたまま売る | 価格が下がりやすく、買主・融資が付きにくい。先に紛争の解決を図るのが順番 |

買主が住宅ローンを使う場合、金融機関が越境の是正の見通し（覚書の有無）を確認することがあります。覚書が整っていれば、越境を残したままでも取引が進むことは珍しくありません。価格への影響の程度は、越境の内容・是正費用・立地で変わり、査定のなかで個別に見ます。当社は、越境を解消してから売るか・覚書を付けて現況で売るかの比較と、それぞれで誰に何を頼むかの段取りからご相談をお受けします。相続税評価や譲渡所得税は税理士、相続登記は司法書士、紛争は弁護士の領域で、当社が税額や勝ち負けを断ずることはありません。

**[越境のある相続不動産の売却を四葉不動産に相談する（相談無料）](/souzoku)**

お問い合わせに「越境のある相続不動産の売却」と、越境の状況（塀・枝・庇など）・境界確定の有無・相続登記の状況をご記入ください。売れる・売れないを先に決めつけず、越境と境界の確認、どこを誰に振るかの整理からお話しします。

## よくある質問

**Q. 隣地から伸びてきた枝は、自分で切ってよいのですか？**
A. 原則は、竹木の所有者に越境した枝を切除させる形です（民法第233条第1項）。2023年4月1日施行の改正で、①所有者に催告したのに相当の期間内に切除しないとき②所有者を知ることができず又は所在が不明なとき③急迫の事情があるときは、自ら切り取れるようになりました（第233条第3項）。要件に当たらないのに勝手に切ると損害賠償を問われることがあり、どの要件に当たるかの判断は弁護士の領域です。なお、越境した根は従前どおり自分で切り取れます（第233条第4項）。

**Q. 越境があると、相続した家は売れないのですか？**
A. 売れます。越境それ自体が売却を禁じるものではありません。実務では、越境の有無・内容を重要事項として買主に説明し、すぐ解消できない越境は隣地と「越境の覚書」を交わして将来の是正を約し、買主に承継させます。覚書が整っていれば、越境を残したままでも取引が進むことは珍しくありません。説明と書面の整備は当社が、覚書の作成は行政書士が担います。

**Q. 越境の覚書は誰が作るのですか？**
A. 権利義務に関する書類として、行政書士が作成する業務です。覚書には、越境の特定、現状の相互確認、将来の建替え・改修時に是正する約束、所有者が替わっても承継させること、費用負担などを盛り込みます。隣地と越境の事実や是正をめぐって対立している場合は、交渉・調停・訴訟になり得るため弁護士の領域です。当社は覚書の前提となる現況・境界の資料を整え、行政書士・弁護士へおつなぎします。

**Q. 境界がはっきりしないときは何から始めればよいですか？**
A. 境界（筆界）の測量と確認は、土地家屋調査士の専管です（土地家屋調査士法）。隣地の立会いで境界を確認する確定測量や、筆界が不明なときに法務局が筆界を明らかにする筆界特定制度があります。境界が確定すれば、越境の範囲を数量で示して重要事項説明や覚書に落とし込めます。当社は既存の測量図・登記の現況を確認し、確定測量や筆界特定が要るかの見立てと、土地家屋調査士への振り分けをお手伝いします。
