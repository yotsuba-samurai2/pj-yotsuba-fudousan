**先讲重点**：餐车的"备料场所（中央厨房）"原则上需要一处与车辆分开、另外取得营业许可的设施。车辆能载的水有限，保健所的基准会依给排水水箱的容量，限制车内可进行的调理范围，因此前处理与加工基本上要在许可设施进行。选物件的关键有三：能否依设施基准备妥给排水与洗手设备、能否把作业区与住居及其他用途明确区隔、用途地域与租赁契约是否允许该营业。营业许可的区分判断与向保健所协商、申请，交给行政书士与保健所；用途地域及用途变更的最终判断交给特定行政厅与建筑士；物件的租赁与用途确认由本公司负责。

以流动餐车创业，或已在用车辆贩售、想租一处做前处理的据点——这时候"备料在哪里做""什么物件保健所才会核发许可"是第一道关卡。很多情况下光靠车辆无法完成作业，若在选物件前没有先掌握设施基准与用途，很可能签约后才发现许可下不来。

本文从设备、许可、用途三个角度，整理在挑选餐车备料据点物件的阶段、签约前可以确认的事项。属于哪一种营业许可的区分，以及与保健所的协商，是行政书士与保健所的领域，本文仅为一般性资讯提供。

四叶不动产株式会社以东京都文京区小日向为据点，承接事业用物件的租赁中介，以及用途地域与用途变更的事前确认。关于餐车的备料据点，欢迎在决定物件之前就与我们洽谈。

## 餐车为什么一定要有"备料场所"？

餐车（食品的流动贩售）是车辆本身取得食品卫生法第55条第1项的营业许可（饮食店营业等）来营业。但车辆能载的水量有限，保健所的设施基准一般会依给水水箱、排水水箱的容量，区分车内可进行的调理范围。

埼玉县东松山保健所、茨城县日立保健所的说明，把水箱容量的大致标准说明如下（容量与条件各地不同，最确实的做法是带着图面向营业预定地的保健所确认）。

| 给水・排水水箱容量（大致标准） | 车内可进行的调理 |
| --- | --- |
| 约40L以上 | 仅简易调理，或单一品项；以抛弃式容器为前提 |
| 约80L以上 | 两道工序左右的简易调理、多项品项；以抛弃式容器为前提 |
| 约200L以上 | 多工序调理，或使用一般餐具的营业 |

因此，前处理、切配、调味、加工等"备料"很难在车内完成，茨城县日立保健所说明"需要备料时，须在已取得食品营业许可的设施进行"。这正是餐车之外还需要备料场所（中央厨房）物件的原因。

## 备料场所的物件需要什么设备？（给排水、洗手、区隔）

备料场所本身就是一处要取得营业许可的"设施"。设施基准依食品卫生法第54条，由各都道府县等参酌厚生劳动省令（食品卫生法施行规则别表所定基准）以条例订定。随着2018年修正法于令和3年（2021年）6月1日施行，这套基准的骨架已在全国平准化。在物件阶段，大致有以下重点。

| 确认项目 | 物件要看的重点 |
| --- | --- |
| 给水・排水 | 能否引入必要的给排水设备；排水能否妥善处理 |
| 洗手设备 | 作业区能否设置专用洗手设备（含消毒设备） |
| 作业区隔 | 前处理・调理的区域能否与住居及其他用途明确区隔 |
| 地板・墙・天花板 | 能否以易清洁、不透水的材质收边 |
| 换气・照明 | 作业场能否确保足够的换气与照明 |
| 保管设备 | 能否放置原材料・器具的保管及冷藏冷冻设备 |

具体数值与细项，各地条例与保健所运用会有差异。不要在物件端自行断定细节，带图面向保健所事前协商最确实。关于在毛坯（骨架）餐饮物件确认排气与给排水的思路，[在骨架物件开餐饮店时的排气、油脂截留器与防火确认点（日文）](https://luck428.com/zh/column/inshokuten-skeleton-bukken-haiki-grease)也可参考。

## 需要哪种营业许可？由谁申请？

需要取得许可的营业业种，由食品卫生法第55条第1项所衔接的食品卫生法施行令第35条规定。随着令和3年（2021年）6月1日施行的修正，许可业种由原本的34种重编为32种。备料场所属于哪一种区分，会依制作的食品与工序而变。

| 可能的区分 | 什么情况（例） |
| --- | --- |
| 饮食店营业 | 备料经调理后提供的食品 |
| 熟菜（そうざい）制造业 | 以一定量制造炖煮・烧烤・油炸等副食 |
| 申报业种 | 不属于许可业种的部分营业（食品卫生法第57条的申报） |

属于哪一区分，车辆的许可与备料场所的许可要分开取得还是在同一设施处理，都属个别判断。这个区分判断与向保健所协商、制作营业许可申请文件，属行政书士与保健所的领域。本公司不代办许可申请。物件的租赁与用途确认由本公司负责，许可的区分与申请转介给行政书士与保健所。

## 用途地域与租赁契约要确认什么？

备料场所是固定设施，因此和车辆不同，会受到用途地域的限制。建筑基准法第48条与别表第二，就各用途地域规定可建筑的建筑物用途。若以饮食店营业备料，视为"店铺・饮食店"；若以熟菜制造业大量制造，则接近"工厂"处理，依制造规模，可能在住居系地域受限。

| 确认项目 | 要看的重点 |
| --- | --- |
| 用途地域 | 所设想的营业用途在该地域是否被允许 |
| 用途变更 | 既有建物变更用途时，是否需要确认申请（依规模而定） |
| 租赁契约 | 使用目的能否纳入"食品的制造・调理"；回复原状的范围 |
| 邻里 | 臭气・排水・搬出入是否会与邻里冲突 |

是否符合用途地域、是否需要用途变更的确认申请，最终由特定行政厅与建筑士判断。本公司事前确认物件的用途地域与租赁的使用目的，涉及确认申请时转介建筑士。

## 可以用自宅或既有店铺当备料场所吗？

"能不能在自宅厨房备料"是常见的咨询，但备料场所必须是取得营业许可的设施，若住居与作业区没有区隔，通常难以符合基准。即使使用自宅一部分，分界在于能否依基准备妥作业区、洗手与给排水，并与居住空间分开。

若要把既有餐饮店铺当备料据点，须向保健所确认该店铺的营业许可区分能否涵盖备料，若在营业时间外当作另一事业使用，则许可的名义与区分要如何整理。两者的可行与否都取决于个别设施与运用，无资格者不能断言"可以使用"。在看屋阶段，本公司确认用途地域与租赁条件，许可的可行性转介行政书士与保健所。

## 常见问题

**Q. 车辆有许可，备料场所就不用许可了吗？**
A. 车辆与备料场所一般被视为各自独立的设施，许多保健所说明，需要备料时须在已取得许可的设施进行（茨城县日立保健所等）。车内能完成到什么程度，会依给排水水箱容量而变，请带图面向营业预定地的保健所确认。

**Q. 备料场所会是哪一种营业许可区分？**
A. 依制作的食品与工序，分为饮食店营业、熟菜制造业等。许可业种由食品卫生法第55条第1项与施行令第35条规定，并随令和3年（2021年）6月1日施行的修正由34种重编为32种。区分判断与申请属行政书士与保健所的领域，请向该处确认具体区分。

**Q. 可以把自宅厨房当备料场所吗？**
A. 备料场所必须是取得营业许可的设施，分界在于能否把住居与作业区区隔，并依基准备妥洗手与给排水。多数情况需要与居住空间分开的专用区。可行与否取决于个别设施与保健所的运用，无法一概断言。

**Q. 租了之后许可下不来会很困扰，顺序该怎么安排？**
A. 在决定物件之前，先确认所设想的营业在用途地域是否被允许、格局能否符合设施基准，并向保健所事前协商后再签约，较为安全。本公司负责物件的用途确认与租赁，许可的区分・协商转介行政书士与保健所。
