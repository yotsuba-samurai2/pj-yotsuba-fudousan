**先讲重点**：不附设火化炉的殡葬式场（追思会馆），在建筑基准法上大致被当作“集会场”，受各用途地域的建筑限制。它与另有立地框架的火葬场不同。在找物件之前，先把用途地域、接道、停车场与邻里应对分开确认。

想用空仓库、路边建物或自有土地开设家族葬会馆、出租式场，或出租给殡葬业者的咨询日益增加。然而，并非任何建物都能当作殡葬式场。多数计划会卡在用途地域限制、接道、停车场，或向邻里说明这几个阶段。

最容易一开始就卡住的，是把殡葬式场与火葬场混为一谈。两者的建筑与许可框架不同，若当成同一种“殡葬设施”去找物件，往往事后才发现盖不了、租不了。

四叶不动产株式会社以东京都文京区为据点，承接事业用物件的调查与租赁、买卖中介。我们可以从卖方、出租方、承租方各自的立场出发，先整理“这个物件能否开设式场、能否出租”这个前提。

## 追思会馆与火葬场、墓地有何不同？属于哪种许可框架？

框架首先依“设施是否有火化炉、是否收藏遗骨”而分。只举行守灵、告别式等仪式，而不涉及火化或埋藏、收藏的殡葬式场，一般不属于墓地、埋葬等相关法律（墓地埋葬法）的经营许可对象。

| 设施 | 主要依据 | 立地与许可框架（概略） |
| --- | --- | --- |
| 殡葬式场（无火化炉） | 建筑基准法（集会场） | 受用途地域建筑限制（法第48条、别表第二）。若不涉火化，则非墓地埋葬法经营许可对象 |
| 火葬场 | 建筑基准法第51条、墓地埋葬法 | 在都市计划区域内，须于都市计划中决定其基地位置，或取得特定行政厅许可等。另须取得墓地埋葬法的经营许可 |
| 墓地、纳骨堂 | 墓地埋葬法 | 因涉及遗骨埋藏、收藏，属经营许可对象（另有专文，属行政书士领域） |

墓地埋葬法第2条界定埋葬、火化、坟墓、墓地、纳骨堂与火葬场等，第10条规定经营墓地、纳骨堂或火葬场须取得都道府县知事等的许可。附设火化炉的计划同时牵涉此经营许可与建筑基准法第51条，立地门槛大幅提高。

即使是不涉火化的式场，仍会以“集会场”身分受用途地域限制与消防基准规范。墓地埋葬法是否适用的最终判断，以及涉及火化、收藏之计划是否可行，请向自治体主管课与承办许可的行政书士确认。墓地、纳骨堂的经营许可另见[墓地、纳骨堂的经营许可](https://luck428.com/zh/legal/column/bochi-noukotsudo-keiei-kyoka-youken-nagare)。

## 用途地域下，殡葬式场能开到什么程度？哪种物件盖不了？

不涉火化的殡葬式场，一般被当作“集会场”，受各用途地域建筑限制。建筑基准法第48条与别表第二，就各用途地域规定了可建与不可建的建筑物。都市计划法第8条、第9条界定用途地域的种类与宗旨，具体的建筑限制则由建筑基准法承担。

| 用途地域举例 | 集会场（殡葬式场）之对待（一般倾向） |
| --- | --- |
| 第一种、第二种低层住居专用地域、第一种中高层住居专用地域 | 集会场原则上盖不了。虽有特定行政厅许可的例外空间，但无保证 |
| 第二种中高层住居专用地域至邻近商业、商业、准工业等 | 依规模与地域可能可建，但须确认面积要件与附带条件 |
| 工业、工业专用地域 | 从其他角度另有限制，须逐案确认 |

不过，这终究只是一般倾向。即使同一用途地域，也会因建物规模、是否既存不适格、地区计划等上位规范而结论不同。用途是否适用、能否建筑，是由特定行政厅（建筑指导课）与建筑师判断的事项。别凭推测断定“盖得了”，请提出计划规模逐案确认。

事业用物件的用途地域判读，不同业种之间也有共通的思路。[小规模多功能居家照护的物业与用途地域](https://luck428.com/zh/column/shoukibo-takino-kaigo-bukken-youken)、[旅馆业、酒店的营业与物件要件](https://luck428.com/zh/column/ryokangyo-hotel-eigyo-bukken-youken)，都可作为以用途地域筛选物件的参考。

## 在建筑基准法、消防法、停车场附设义务上，式场物件须具备什么条件？

即使通过用途地域，建物本身与设备的基准仍在。集会场属多人聚集的用途，避难、防火与来场车辆的处理都会成为论点。

| 确认面向 | 主要内容 |
| --- | --- |
| 建筑基准法（集会场） | 作为特殊建筑物的避难、防火基准，以及依楼地板面积而定的规定。既有建物则须看有无竣工检查证、是否既存不适格 |
| 消防法 | 依消防法施行令别表第一的防火对象物分类（集会场有对应区分），备置消防设备与办理申报。须事先洽所辖消防署 |
| 停车场 | 吊唁者、灵柩车、接送巴士的进出。若规模触及自治体停车场附设义务条例，须确认附设义务 |
| 周边道路 | 灵柩车、巴士的进入与回转、建物前的停车空间，以及与邻里生活动线的干扰 |

停车场附设义务依建物用途与总楼地板面积等，由自治体条例规定。各自治体基准不同，请连同参照日确认物件所在地的条例。吊唁者的车辆若滞留路面，容易成为与邻里摩擦的导火线，因此除法定附设义务外，也要预估实际运用车数。

将既有建物改作式场时，也要确认有无竣工检查证与是否需用途变更。用途变更的处理可参考[将无竣工检查证的物件改作福祉用途](https://luck428.com/zh/column/kensazumisho-nashi-bukken-fukushi-youto-henko)，消防与噪音论点可参考[卡拉OK包厢物件与用途地域、消防](https://luck428.com/zh/column/karaoke-box-tenpo-bukken-youto-shoubou-soon)。避难、防火之具体基准是否符合，请向建筑师与所辖消防署确认。

## 将市街化调整区域的既有建物改作会馆时，开发许可与用途变更如何处理？

路边建物与郊区仓库常位于市街化调整区域。在该区域，建筑与用途变更受都市计划法限制。

都市计划法第29条规定开发行为须取得知事等许可；第34条就市街化调整区域的开发许可立地基准采限定列举；第43条规定在开发许可区域以外，新建、改建建筑物，或变更用途为不同种类建筑物时，须取得知事等许可。也就是说，仅把既有仓库“用途变更”为殡葬式场，在市街化调整区域也可能须检讨是否要许可。

能否以既有建物之改建处理，或须以用途变更取得新许可，取决于与原建物在用途、规模上的同一性，以及自治体的运用基准。能否符合许可立地基准的判断，以及开发许可、用途变更许可的申请，属行政书士领域。市街化调整区域物件的思路另见[将市街化调整区域的既有建物作事业用](https://luck428.com/zh/column/kensetsugyo-shizaioki-shako-chosei-kuiki-bukken)。

物件位于哪一区域区分，应作为买卖、租赁的前提先行调查。别断定市街化调整区域必然不可、市街化区域必然可行，请把区域区分、用途地域、接道一并确认。

## 在挑选物件前，邻里说明与社区应对该先确认什么？

即使符合法令基准，殡葬式场仍可能因邻里关系而无法推进。对吊唁者进出、接送车辆、夜间人员动向的疑虑，曾有演变为反对运动与纠纷的报导案例。决定物件前，请确认以下各点。

- 用途地域、区域区分，以及周边住宅、设施的立地
- 自治体是否就殡葬设施设有自订条例、指导纲要或事前协议机制
- 向社区、町内会事前说明的惯例，以及被要求说明的范围
- 吊唁者、车辆动线是否与邻里生活动线或通学路冲突

部分自治体就殡葬场、斋场设有距离限制或事前申报、协议的条例或纲要。请连同参照日确认物件所在地的条例、纲要，必要时洽事前协议窗口。若与邻里的协商演变为纠纷，进而成为损害赔偿或禁止请求等法律争议，则属律师领域。四叶不动产整理物件与法令前提，但不承接纠纷代理，也不作法律判断。

## 以出租式场方式租给殡葬业者时，租赁契约与回复原状如何整理？

把自有建物或土地不自营、改租给殡葬业者，也是一种出场方式。此时出租方并非式场经营者，而是以建物、土地的出租人身分参与。

| 整理项目 | 确认内容 |
| --- | --- |
| 用途与许可前提 | 承租方用途（作为集会场的式场）是否符合用途地域、建筑、消防基准。许可由承租方取得 |
| 租赁条件 | 用途限定、内装与设备工程的负担、招牌、邻里应对的角色分担、契约期间 |
| 回复原状 | 式场规格的内装、设备，于契约终了时由谁、回复至何种程度。特殊设备的处理 |
| 风险分担 | 邻里应对与客诉、设备维护、租金滞纳时的处理 |

出租方与承租方立场不同，请在契约中明确用途与工程、回复原状的范围。租赁中介与条件整理由宅建业（本公司）承担，租赁契约书的内容确认在中介范围内进行。租赁中介与服务范围可参考[服务介绍](https://luck428.com/zh/services)。承租方须取得哪些许可，以及邻里纠纷化时的应对，分别属行政书士与律师领域。

## 常见问题

**Q. 可以把住宅区的空屋改成追思会馆吗？**
A. 视用途地域而定。不涉火化的式场一般被当作“集会场”，在第一种、第二种低层住居专用地域与第一种中高层住居专用地域倾向原则上盖不了。是否适用、能否可行由特定行政厅与建筑师判断，请提出计划规模逐案确认。

**Q. 可以把路边仓库（市街化调整区域）改作式场吗？**
A. 在市街化调整区域，即使是用途变更，也可能须依都市计划法检讨是否要许可。能否符合立地基准的判断与许可申请属行政书士领域。请在把区域区分、用途地域、接道一并确认后再判断。

**Q. 我也想一并兴建火葬场，找物件的做法会改变吗？**
A. 会。附设火化炉会加上墓地埋葬法的经营许可与建筑基准法第51条的立地框架，门槛大幅提高。经营许可属行政书士、立地可否属特定行政厅领域，应与仅设式场的计划分开检讨。

**Q. 若不自营、只租给殡葬业者，是否就不需要许可？**
A. 出租方属出租人立场，式场的许可与邻里应对原则上由承租方负责。不过，用途须符合用途地域、建筑、消防，是租赁的前提。请在租赁契约中先明确用途限定与回复原状。
