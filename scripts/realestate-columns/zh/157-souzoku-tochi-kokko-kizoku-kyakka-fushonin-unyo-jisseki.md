**结论（先讲要点）**：继承土地国库归属制度自2023年（令和5年）4月27日施行约三年半，依法务省统计（令和8年9月30日现在・速报值，公表于令和8年10月19日），相对于申请6,125件，获承认归属国库的为3,231件，驳回86件、不承认103件、撤回1,162件。在申请的阶段被驳回的，是有建物的土地・设有担保权等的土地・界线不明的土地等，法律事先定出了「不能申请的土地」（继承土地国库归属法第2条第3项）。在审查的阶段不承认的，是管理需过分费用・劳力的悬崖的土地・地上有工作物或树木的土地・地下有有体物的土地・不经诉讼即无法管理处分的土地等（第5条第1项）。获承认后，需缴纳相当于国家管理费用一部分的负担金。被驳回・不承认的土地，或与其缴负担金放手、不如出售・出租较有剩余的土地，由不动产（本公司）检讨出售・捐赠等别的出口。承认申请的书类制作为行政书士、审查为法务局、界线的确定测量为土地家屋调查士、让渡所得等税务为税理士的领域，各为独立事业体、以分别签约为前提为您转介（无介绍费的往来）。

## 继承土地国库归属制度，至今被申请・承认了多少？

法务省定期公表制度的运用状况统计。最新公表（令和8年10月19日付・令和8年9月30日现在的速报值）如下。考虑制度的选择时，先知道「申请后仍有一定比例以撤回・驳回・不承认收场」的实绩，较易建立预期。

| 项目 | 件数（令和8年9月30日现在・速报值） |
|---|---|
| 申请件数 | 6,125件 |
| 归属件数（获承认归属国库的件数） | 3,231件 |
| 驳回件数 | 86件 |
| 不承认件数 | 103件 |
| 撤回件数 | 1,162件 |

申请的地目别中，田・旱田最多为2,372件，其次宅地2,135件、山林928件、其他690件。撤回1,162件的理由，包含「产生了有效活用的见込」595件、「判明属驳回・不承认」415件等。亦即，申请后找到别的出口、或发觉不符要件而撤回的例子相当多。制度之间的选法（国库归属・捐赠・出售的比较）在既有文章[放手继承的土地——国库归属・捐赠・出售的比较](https://luck428.com/zh/column/souzoku-tochi-tehanasu-kokko-kizoku-baikyaku-hikaku)处理，本文将主题聚焦于运用实绩（驳回・不承认的类型）。

## 在申请的阶段「被驳回」的是哪种土地？（法第2条第3项）

驳回是指在进入审查之前，以「本来就不能申请的土地」被退回。继承土地国库归属法第2条第3项规定，属于下列任一的土地不能申请。

| 被驳回的土地（第2条第3项） | 内容 |
|---|---|
| 有建物的土地 | 有建物坐落的土地 |
| 设有担保权等的土地 | 设有抵押权等担保权，或以使用收益为目的之权利的土地 |
| 预定他人使用的土地 | 含政令所定、预定供通路等他人使用之土地的土地 |
| 遭土壤污染的土地 | 遭土壤污染对策法的特定有害物质污染的土地 |
| 界线不明的土地 | 界线不明，或所有权的存否・归属・范围有争议的土地 |

法务省统计中，驳回86件的理由（1件可能被认定多个理由，故各理由合计与驳回件数不一致），包含未提出附件37件、界线不明23件、供通路之用22件、由无申请权限者申请11件、有建物坐落4件等。界线不明与作为通路使用成为实际的驳回理由这点，是在看物件的阶段就想确认的。界线的确定属土地家屋调查士的领域，流程是先做确定测量再申请。

## 在审查「不承认」的是哪种土地？（法第5条第1项）

不承认是指申请虽获受理，但审查结果认为「使之归属国库并不适当」而不予承认。继承土地国库归属法第5条第1项规定，属于下列任一的土地不予承认。与驳回要件（是否为可申请的土地）不同，此阶段看的是「通常的管理・处分是否需过分费用・劳力」。

| 不承认的土地（第5条第1项） | 内容 |
|---|---|
| 有悬崖的土地 | 有政令所定坡度・高度之悬崖，管理需过分费用・劳力的土地 |
| 地上有有体物的土地 | 地上有妨碍通常管理・处分之工作物・车辆・树木等有体物的土地 |
| 地下有有体物的土地 | 不除去即无法进行通常管理・处分之有体物在地下的土地 |
| 需经诉讼的土地 | 不经与邻地所有者等的诉讼即无法进行通常管理・处分、政令所定的土地 |
| 其他需过分费用・劳力的土地 | 除上述外，政令所定、通常管理・处分需过分费用・劳力的土地 |

法务省统计中，不承认103件的理由，包含地上有妨碍管理・处分之工作物・车辆・树木等49件、需国家追加整备的森林37件、归属国库后依法令负担金钱债务的土地12件、需采取防灾措施的土地11件、需过分费用・劳力之悬崖7件等（1件可能被认定多个理由，故合计与不承认件数不一致）。放置的工作物或立木、山林的整备不足，实际上成为不承认的主因这点，对想放手山林・原野的继承人是重要实绩。山林出口的思考方式，亦在[出售继承的山林・请邻地买下](https://luck428.com/zh/column/rinchi-baikyaku-kaimashi-nanari-tochi-deguchi)整理。

## 被驳回・不承认的土地，如何寻找出售或捐赠等别的出口？

即使国库归属被驳回・不承认，土地的出口也不会消失。反而，有些土地与其缴负担金请国家收下，不如出售・出租较有剩余。出口大致分为以下。

| 出口 | 适合情形 | 主要相关的负责者 |
|---|---|---|
| 出售（市场・邻地・买取） | 可望有需求，或邻地所有者想买下 | 本公司（宅地建物交易业） |
| 捐赠（自治体・法人・个人） | 难以出售但有收受者 | 本公司・对方（可否受赠视对方而定） |
| 出租・利用（停车场・资材放置场・太阳能等） | 虽有建筑限制但可作别用途 | 本公司・业者 |
| 整备要件后再申请 | 界线确定或工作物撤去后可符合要件 | 土地家屋调查士・拆除业者・行政书士 |

在以「卖不掉」为前提进到国库归属之前，先确认能否在市场售出、能否请邻地所有者买下、能否作别用途出租，是顺序。邻地所有者想买下的「邻地需求」，有时比一般市场更易成交。管理困难地的整体放手方式，亦在[继承的市街化调整区域土地卖得掉吗](https://luck428.com/zh/column/chousei-kuiki-souzoku-tochi-baikyaku)、附空屋的土地在[继承的空屋拆除成空地出售或附旧屋土地出售](https://luck428.com/zh/column/souzoku-akiya-kaitai-koyatsuki-dochira)处理。本公司协助依国库归属要件判断是否可能被驳回・不承认的大致研判（最终判断为法务局），以及出售・捐赠・出租这些别的出口的整理。

## 从申请书类的制作到负担金的缴纳，该向谁咨询？

继承土地国库归属制度，横跨承认申请（行政书士・本人）・审查（法务局）・界线确定（土地家屋调查士）・作为替代出口的出售（不动产）・税务（税理士）等不同领域。不动产公司负责的是替代出口的检讨与调查・估价・中介。

| 困扰 | 转介对象 |
|---|---|
| 驳回・不承认时出售・捐赠・出租等别的出口检讨、调查・估价・中介 | 本公司（宅地建物交易业） |
| 国库归属的承认申请书类制作・提出的代理 | 行政书士 |
| 承认申请的审查・负担金额的通知 | 法务局（管辖的法务局・地方法务局） |
| 界线（笔界）的确定测量、分笔 | 土地家屋调查士 |
| 所有权移转・继承登记 | 司法书士・土地家屋调查士 |
| 让渡所得等税务 | 税理士 |

这些各为**独立事业体**，以**分别签约**为前提。本公司不收取也不支付介绍费・送客手续费。获承认后需缴纳负担金，负担金依国有地的种目别、考量10年份的标准管理费用算定。原则不论面积为定额（20万日元），但部分市街化区域内的宅地・农地或一定的森林等则依面积算定（继承土地国库归属法第10条・施行令。具体金额依法务局的通知与施行令的算定）。承认申请的可否与书类由行政书士、审查与负担金额由法务局、界线确定由土地家屋调查士、登记由司法书士、税务由税理士判断・负责。又，继承的土地若仍为被继承人名义，申请或出售前通常需先办继承登记（令和6年〈2024年〉4月1日起义务化・不动产登记法第76条之2），这属司法书士的领域。继承不动产的进行方式请见[继承不动产的咨询窗口](https://luck428.com/zh/souzoku)。

## 常见问题

**Q. 继承土地国库归属制度至今被用了多少？**
A. 依法务省统计（令和8年9月30日现在・速报值，公表于令和8年10月19日），自2023年4月施行约三年半，申请6,125件、获承认归属的归属件数3,231件、驳回86件、不承认103件、撤回1,162件。申请后找到别的出口而撤回，或因不符要件被驳回・不承认的例子也相当多。数值为速报值，最新请在法务省的页面确认。

**Q. 哪种土地会「被驳回」？**
A. 继承土地国库归属法第2条第3项，将有建物的土地、设有担保权等的土地、预定供通路等他人使用的土地、遭土壤污染的土地、界线不明的土地列为「不能申请的土地」。法务省统计中，附件不足、界线不明、供通路之用为实际驳回理由的前段。界线的确定属土地家屋调查士的领域。

**Q. 哪种土地会「不承认」？**
A. 第5条第1项将管理需过分费用・劳力之悬崖的土地、地上有工作物・车辆・树木的土地、地下有有体物的土地、不经诉讼无法管理处分的土地列为不承认。法务省统计中，地上的工作物・树木、需追加整备的森林、负担金钱债务的土地为不承认理由的前段。放置立木或工作物的山林・原野，不撤收或整备则不易通过。

**Q. 被驳回・不承认的话，就不能放手了吗？**
A. 并非如此。有些土地与其缴负担金请国家收下，不如出售・出租较有剩余。可检讨在市场售出、向邻地所有者出售、向自治体或法人捐赠、作为停车场・资材放置场出租等别的出口。本公司协助国库归属的研判（最终判断为法务局），与出售・捐赠・出租的整理。出售中介为不动产、申请为行政书士、界线确定为土地家屋调查士，负责者是分开的。
