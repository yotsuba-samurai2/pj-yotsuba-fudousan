**先讲重点**：继承人中有因失智等欠缺判断能力的人时，该继承不动产原则上"无法马上出售"。出售的前提——遗产分割协议，若欠缺意思能力便无法有效成立（民法第3条之2）；要代本人参与协议或出售，须有家庭裁判所选任的成年后见人。此外，若要卖的不动产是本人的居住用，即使有后见人，也须另外取得家庭裁判所的许可（民法第859条之3）。后见开始的声请与审判在家庭裁判所，声请支援交给律师・司法书士、相续登记交给司法书士、评价与税务交给不动产鉴定士・税理士，出售中介由本公司负责。各为独立事业体，分别签约。

想卖掉老家等继承不动产，身为继承人的父母或兄弟却有失智——这时候"为什么卖不掉""该怎么安排顺序"就成了第一个烦恼。不能把本人排除在外推进，也不能由家人代签。若不知道手续的顺序就行动，好不容易成立的契约可能事后被认定无效。

本文从不动产的角度，整理继承人中有欠缺判断能力者时，出售为何会卡住，以及到可以出售为止的步骤。后见开始声请能否进行、以及个别的法律判断，属律师・司法书士・家庭裁判所的领域，本文仅为一般性资讯提供。

四叶不动产株式会社以东京都文京区小日向为据点，承接继承不动产的估价与出售中介。关于有失智继承人涉入的出售，欢迎从卖出前可以确认的事项开始与我们洽谈。

## 继承人里有失智的人，出售为什么会卡住？

要卖继承来的不动产，通常要先把确定归属的遗产分割协议谈妥、办好相续登记，再进入买卖。但遗产分割协议是全体继承人的法律行为，各继承人都需要有意思能力（理解事物并做出判断的能力）。

民法第3条之2规定："法律行为的当事人于意思表示时不具意思能力者，该法律行为无效"（平成29年法律第44号新设、2020年4月1日施行）。有因失智等欠缺判断能力的继承人加入的遗产分割协议，其意思表示无效，协议整体即无法成立。

| 阶段 | 若有欠缺判断能力的继承人 |
| --- | --- |
| 遗产分割协议 | 本人的意思表示无效；家人也不能代笔、代理 |
| 相续登记 | 分割未谈妥，朝向出售的名义变更无法推进 |
| 买卖契约 | 本人若为当事人，在欠缺意思能力下所缔结的契约无效 |

也就是说，并非"卖不掉"，而是须先进行一道手续：为本人立一位能合法判断并签名的人（成年后见人）。

## 有了成年后见人，何时、如何能出售？

为欠缺判断能力的本人，由家庭裁判所选任成年后见人。民法第7条规定，对于因精神上障碍而处于欠缺辨识事理能力常况的人，家庭裁判所得依本人、配偶、四亲等内亲属等的声请，为后见开始的审判；第8条则将受后见开始审判者定为成年被后见人，并为其附加成年后见人。

成年后见人选出后，便可代本人加入遗产分割协议，成为相续登记与买卖的当事人。大致顺序如下。

| 顺序 | 内容 | 由谁负责 |
| --- | --- | --- |
| 1 | 后见开始的声请（向家庭裁判所） | 本人・亲属等；文件制作支援由律师・司法书士 |
| 2 | 家庭裁判所的审判・成年后见人的选任 | 家庭裁判所 |
| 3 | 成年后见人参与遗产分割协议 | 成年后见人（保护本人利益的立场） |
| 4 | 相续登记 | 司法书士 |
| 5 | 买卖契约・交割（居住用者以家裁许可为前提） | 卖方（后见人）＋中介由本公司负责 |

要注意的是，后见人是"保护本人利益"的立场。因继承人方便而贱卖、减少本人取分的分割，后见人无法答应。若后见人同时也是共同继承人之一，利益相反，便须另行选任特别代理人（民法第826条・第860条）。

共有状态的继承不动产如何出售，[出售共有不动产时全体继承人同意的整理（日文）](https://luck428.com/zh/column/souzoku-kyoyu-fudosan-uru-doui)也可参考。

## 居住用不动产的出售，为什么需要家庭裁判所的许可？

即使有了成年后见人，也不代表就能自由出售本人名义的不动产。民法第859条之3规定，成年后见人代成年被后见人，就其供居住使用的建物或其基地，进行出售、出租、租赁契约的解除或抵押权的设定等其他与此相当的处分时，须取得家庭裁判所的许可。

因为失去居所会大幅影响本人的生活与精神状态，基于保护本人的观点，居住用不动产的处分特别要求家裁许可。未取得许可而为的居住用不动产出售，被解释为无效（国税厅的文书回答等）。

| 不动产的性质 | 家裁许可（第859条之3） |
| --- | --- |
| 本人现住・曾住・将来预定居住的建物及其基地 | 需要（未经许可的出售无效） |
| 不属于本人居住用的继承不动产 | 第859条之3的许可不需要；但后见人的善良管理注意义务与向家裁报告仍在 |

"供居住使用"在实务上倾向于较宽地解释，是否该当由家庭裁判所・后见人判断。本公司无法断言"需要／不需要许可"。涉及配偶居住权等居住相关权利的出售思路，[出售附配偶居住权建物的整理（日文）](https://luck428.com/zh/column/souzoku-haiguusha-kyojuuken-tatemono-baikyaku)也可参考。

## 遗产分割之前有办法出售吗？

也有"等不到后见开始""想在分割前出售"的咨询，但只要有欠缺判断能力的继承人，就不能把本人排除在外先卖。可想到的途径有限。

| 途径 | 留意点 |
| --- | --- |
| 等后见开始后再卖 | 原则流程。若为本人居住用，还需第859条之3的家裁许可 |
| 以抛弃继承退出继承人之列 | 欠缺判断能力的本人不能单独为之，须后见人涉入；不可轻率选择 |
| 有遗言时 | 本人可能不必参与协议；但遗言的有效性须另行确认 |

两者的可行与否都取决于个别情事与法律判断。有资讯宣称"分割前出售的捷径"，但偏离保护本人的做法，事后可能被认定无效。再怎么着急，不跳过后见手续，结果往往才是最短路。手续的要否与可行，请向律师・司法书士・家庭裁判所确认。

## 后见的声请要找谁？出售由谁负责？（分离受任）

有失智继承人涉入的不动产出售，横跨后见、登记、税务、不动产等不同事业体。顺序取错，可能在后见人选任前就签约，或遗漏居住用的许可。

| 角色 | 由谁负责 |
| --- | --- |
| 估价・中介・重要事项说明・交割 | 宅地建物取引业（本公司） |
| 后见开始的审判・居住用不动产处分许可 | 家庭裁判所 |
| 后见开始声请的支援・利益相反或纷争的判断 | 律师・司法书士 |
| 相续登记・成年后见登记的确认 | 司法书士 |
| 相续税・让渡所得税的计算与申报 | 税理士 |
| 不动产的估价（鉴定） | 不动产鉴定士 |

后见开始的审判事件与居住用不动产处分许可的声请，是家事事件手续法别表第一所列的家庭裁判所手续。声请文件的制作・支援属律师・司法书士的业务，本公司不代办。

这些**各为独立事业体**，以**分别签约**为前提。本公司负责不动产的出售面，后见声请的支援与利益相反的判断交给律师・司法书士，相续登记交给司法书士，相续税・让渡所得税交给税理士，鉴定评价交给不动产鉴定士。本公司不收取介绍费。

## 常见问题

**Q. 父母失智了。由家人商量卖掉老家、代签不就好了吗？**
A. 有欠缺判断能力的继承人加入的遗产分割协议或买卖契约，因本人的意思表示无效而无法成立（民法第3条之2）。家人也不能代笔、代理，须先进行由家庭裁判所选任成年后见人的手续。可行与顺序请向律师・司法书士确认。

**Q. 有了成年后见人，就能马上卖老家吗？**
A. 后见人可代本人成为协议或买卖的当事人，但若要卖的不动产是本人的居住用，须另外取得家庭裁判所的许可（民法第859条之3）。未经许可的居住用不动产出售被解释为无效。是否属居住用，由家庭裁判所・后见人判断。

**Q. 我（子女）可以当后见人吗？**
A. 亲属有时可担任后见人，但选任者是家庭裁判所。若后见人是共同继承人之一，在遗产分割上利益相反，可能须另行选任特别代理人（民法第826条・第860条）。选任与利益相反的判断，请向律师・司法书士・家庭裁判所咨询。

**Q. 后见手续要花时间吗？可以先找买方吗？**
A. 后见开始的审判与居住用不动产处分许可需要一定期间。在后见人选任或取得许可前就签约，有无效之虞，守住顺序较为安全。本公司可在手续进行的同时，承接市场状况的整理与出售准备的咨询，契约・交割则在要件齐备后再推进。
