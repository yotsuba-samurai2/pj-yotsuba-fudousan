**结论（先讲重点）**：「经营・管理」在留资格被认作事业所的物件，骨架是三点：与住居明确区分的独立区划、以法人名义・事业用目的承租、以及以招牌・门牌等在外观上也能确认为事业所的状态。2025年（令和7年）10月16日施行的改正，把资本金・出资总额提高到3,000万日元以上、常勤职员1名以上，自宅兼事务所原则上不再被认可。本公司负责到物件能否作为事业所使用的信息提供为止，在留资格的申请・事业计划书交给行政书士、公司设立登记交给司法书士、资本金・税务交给税理士，分别签约推进。

本文面向将在日本设立公司并申请「经营・管理」在留资格的中国大陆・台湾创业者，以及代理他们的当地专业人士，依出入国管理及难民认定法与上陆许可基准省令、出入国在留管理厅的说明，整理在审查中被认作事业所的物件条件。本公司负责物件的独立性・用途・租赁契约等不动产侧的信息提供，不进行在留资格的可否判断或事业计划的制作。相关领域各自交给专业人士，分别签约推进。

## 审查中被认作「事业所」的物件条件是什么？

骨架有三。第一，与住居明确区分的独立区划。第二，以法人名义、事业用目的承租。第三，以招牌・门牌等在外观上也能确认为事业所的状态。此外改正后还要求与事业规模相称的事业所。

「经营・管理」是入管法别表第一の二所列的在留资格，对象是在日本从事事业经营・管理的活动。上陆许可基准（出入国管理及难民认定法第七条第一项第二号的基准省令。平成2年法务省令第16号）要求经营事业用的事业所存在于日本，若事业尚未开始，则须在日本确保作为事业所使用的设施。出入国在留管理厅的审查，会看该设施是否为与住居或私人空间区分、能持续用于事业的独立区划。

| 确认项目 | 作为事业所被看的重点 |
|---|---|
| 独立性 | 是否为与住居・私人空间明确区分的独立区划 |
| 名义・目的 | 是否以法人名义、租赁契约的使用目的是否为事业用 |
| 持续性 | 是否为可持续使用、而非月租短期空间 |
| 外观 | 是否以招牌・门牌等能确认为事业所（审查的一项材料） |
| 规模 | 是否与改正后的事业规模（资本金3,000万日元以上等）相称的宽度与实体 |

事业所要件的最终判断由出入国在留管理厅个别进行，故押下物件前，宜与负责申请的行政书士就事业所的实体先行对齐。

## 自宅兼用或虚拟办公室能通过经营・管理签证吗？

2025年10月16日改正后，把自宅兼作事业所原则上不再被认可。虚拟办公室（只租地址的形态）、以及任何人都能使用的共享办公共用部分，因难以呈现独立事业所的实体，原则上也不满足事业所要件。

住居与事业所同为一个空间时，难以呈现事业所的独立性・实体，改正后的审查在此容易通不过。租赁办公室的个室・一区划或育成办公室，也要看是否以法人名义明确区分、能持续用于事业的实体而判断。虽以虚拟办公室能完成公司设立，却在在留资格的事业所要件卡关的论点，整理于[以虚拟办公室设立公司｜能做的事・在许认可卡关的事](https://luck428.com/legal/column/office-virtual-office-kyoninka)。物件具备多少事业所实体，由本公司就独立区划・名义・使用目的的现况提供信息，在留资格上的可否交给行政书士。

| 形态 | 事业所要件见込 |
|---|---|
| 自宅兼事业所 | 改正后原则不被认可 |
| 虚拟办公室（只有地址） | 原则不可（难以呈现独立实体） |
| 共享办公共用部 | 原则不可 |
| 租赁办公室的个室・专用区划 | 有法人名义・明确区分・持续使用则有被认可的余地（个别判断） |
| 独立的事业用店面 | 较易被认作事业所 |

## 租赁契约的名义与使用目的该怎么写？

要被认作事业所，前提是以法人名义（设立前则安排设立后切换名义）签租赁契约，并把使用目的定为事业用（事务所）。以居住用契约原样当事务所使用，不仅否定事业所的实体，也可能构成与出租人的契约违反。

契约前，向出租人・管理公司确认事务所利用的可否与使用目的的载明，并在重要事项说明中掌握用途地域・用途限制・原状回复・招牌设置的可否。这些是宅地建物取引业法第35条重要事项说明与第37条书面应厘清的事项。本公司负责物件侧的协调与重要事项说明，法人设立的时点与契约名义的安排，则与负责公司设立登记的司法书士、负责在留资格申请的行政书士分工推进。

| 契约论点 | 把握处 |
|---|---|
| 名义 | 法人名义（设立前与出租人就设立后名义切换达成合意） |
| 使用目的 | 载明为事业用（事务所）。勿维持居住用契约 |
| 招牌・门牌 | 于契约・管理规约确认设置可否 |
| 重要事项说明 | 用途地域・用途限制・原状回复・费用（宅建业法第35条・第37条书面） |

## 从中国・台湾签约时，看房・重要事项说明如何进行？

来日前的阶段，也能以线上看房，以及宅地建物取引业法认可的IT重说（以视讯会议等进行的重要事项说明）推进手续。重要事项说明依宅地建物取引士记名的重要事项说明书进行，契约内容以第37条书面确认。

非居住者・设立前法人为当事人时，会叠加国内交易所没有的确认：本人确认文件、签名的取得方式、代金汇款的路径（海外入账）等。自中国大陆汇款可能涉及资本管制或入账延迟，故在结算排程上预留余裕是实务上的关键。本公司负责不动产交易的进行方式与重要事项说明，资本金的缴纳与税务、汇款相关的在留资格・公司设立安排，则分别交给税理士・司法书士・行政书士。

| 进行方式 | 重点 |
|---|---|
| 看房 | 以线上看房缩小候补，可能时于来日时实地确认 |
| 重要事项说明 | 可由宅地建物取引士进行IT重说（依记名的重说书） |
| 本人确认 | 非居住者・设立前法人的本人确认、签名取得方式 |
| 结算 | 于海外汇款的路径・入账时期预留余裕 |

## 常见问题

**Q. 把自宅的一室当事务所能取得经营・管理签证吗？**
A. 2025年10月16日改正后，把自宅兼作事业所原则上不再被认可。前提是以与住居区分的独立区划、以法人名义・事业用目的承租的事业所。个别可否属在留资格的论点，请向负责申请的行政书士确认。本公司负责物件能否作为独立区划使用的信息提供。

**Q. 虚拟办公室的地址能被认作事业所吗？**
A. 只租地址的虚拟办公室、以及任何人都能使用的共享办公共用部，因难以呈现独立事业所的实体，原则上不满足事业所要件。租赁办公室的专用个室，若有法人名义・明确区分・持续使用，有被认可的余地，但属个别判断。公司设立与许认可卡关的论点，请参考行政书士的文章。

**Q. 租赁契约要以个人名义还是法人名义签？**
A. 要被认作事业所，前提是法人名义・事业用目的。设立前，先与出租人就设立后切换为法人名义达成安排。以居住用契约原样当事务所使用，会否定事业所的实体，也可能构成与出租人的契约违反。名义切换的时点请与负责设立登记的司法书士一并协调。

**Q. 来日前能决定物件并签约吗？**
A. 能以线上看房缩小候补，并以宅地建物取引业法认可的IT重说（以视讯会议等进行的重要事项说明）推进手续。因会叠加国内交易没有的确认（非居住者・设立前法人的本人确认、海外汇款的入账时期等），在结算排程预留余裕是实务上的关键。资本金的汇款・税务请洽税理士，公司设立请洽司法书士。
