**结论（先说重点）**：能做中古车行・旧货商展示场的物件，首先被用途地域筛选。卖物品的店铺受建筑基准法别表第二的用途限制，原则上不能盖在第一种低层住居专用地域与工业专用地域。若伴随整备，汽车修理工场的作业场楼地板面积限制会另外发生作用。用来展示・保管的停车空间，要先确认租赁契约是否许可该用途，以及回复原状的范围到哪里。

「想把没在用的店铺变成中古车展示场」「想把物件租给旧货商」这类咨询越来越多。但空地或店铺能否成为展示场，取决于用途地域・建物的用途・契约这三点。本文写给预定开中古车行或旧货商、正在找展示・保管用租赁物件的事业者，依建筑基准法・旧货营业法（古物营业法）・车库法的条文，逐项整理签约前能确认的事。个别物件的可否，最终由特定行政厅与所辖警察署确认。

## 中古车行・旧货商的店铺・展示场物件，是由用途地域决定吗？

首先被用途地域筛选。因为卖物品的店铺受建筑基准法别表第二的用途限制。

建筑基准法（昭和25年法律第201号）第48条与别表第二，依用途地域订定可盖的建筑物。展示・销售中古车的店铺被当作「经营物品销售业的店铺」，可否随规模与地域而变。大致如下。

| 用途地域 | 物品销售店铺的可否（大致） |
|---|---|
| 第一种低层住居专用地域 | 原则不可（一定的兼用住宅店铺部分除外） |
| 第二种低层住居专用地域 | 楼地板面积150㎡以内・2层以下 |
| 田园住居地域 | 原则不可（农产品直销所等例外） |
| 第一种中高层住居专用地域 | 楼地板面积500㎡以内・2层以下 |
| 第二种中高层住居专用地域 | 楼地板面积1,500㎡以内・2层以下 |
| 第一种住居地域 | 楼地板面积3,000㎡以内 |
| 第二种住居・准住居・近邻商业・商业・准工业 | 可盖 |
| 工业地域 | 可盖（大规模店铺另有限制） |
| 工业专用地域 | 物品销售店铺・餐饮店不可 |

**是「只展示・销售」还是「也做整备・车检」，会使发生作用的限制不同。** 只销售的话依店铺（物品销售业）的上表限制；伴随整备则叠加汽车修理工场的限制。适合与否的最终判断由特定行政厅进行。把没有检查完成证的中古物件转为其他用途时的议题，整理在[没有检查完成证的中古物件能否转作其他用途](https://luck428.com/column/kensazumisho-nashi-bukken-fukushi-youto-henko)。

## 若做整备・车检，汽车修理工场的限制如何发生作用？

依作业场的楼地板面积分阶段限制，住居系只能放小规模的。

建筑基准法别表第二把汽车修理工场依作业场楼地板面积合计（大致为50㎡・150㎡・300㎡的阶段）区分，住居系地域只能放小作业场，从准工业地域起规模才扩大。伴随整备・钣金・车检的中古车店，这项限制会叠在展示场的用途限制之上。

| 业态 | 主要发生作用的限制 | 物件要看的点 |
|---|---|---|
| 只展示・销售 | 物品销售店铺的用途限制 | 用途地域・店铺楼地板面积・接道 |
| 伴随整备・车检 | 汽车修理工场的作业场面积限制 | 用途地域・作业场面积・原动机出力・近邻 |

**会发生「展示场没问题，却在后面的整备空间卡到用途限制」的情况。** 先决定要做到哪种业态再去对物件，可减少反复。作业场楼地板面积与地域的具体对应、原动机出力的处理，请向特定行政厅确认（本文未就地域逐一断定数值）。

## 展示车的保管场所（车库），要到什么程度才需要申报・证明？

以销售为目的作为库存摆放的车，与登录使用的车，处理方式不同。

汽车的保管场所的确保等相关法律（昭和37年法律第145号。以下称「车库法」）第3条，课予汽车保有者在道路以外处所确保保管场所的义务。第4条要求想依道路运送车辆法登录者，提出警察署长交付、证明道路以外处所已确保保管场所的书面（即所谓车库证明）。轻自动车依第5条申报保管场所位置；变更保管场所时依第7条于15日内申报变更。

这里的关键是「登录的场面才需要车库证明」。展示场上陈列的销售用库存车，通常在买主确定、进入登录阶段时由买主取得车库证明，事业者不会为了作为库存摆放而逐台重取。相对地，事业者登录作为公司用车使用的车，作为其保有者仍需确保保管场所并取得车库证明・申报。

| 车的状态 | 车库证明・申报 | 根据・负责 |
|---|---|---|
| 展示场的销售用库存（未登录） | 通常于登录时由买主取得 | 车库法第4条（手续在买主） |
| 事业者登录作为公司用车使用 | 需确保保管场所并取得车库证明 | 车库法第3条・第4条 |
| 新使用轻自动车 | 申报保管场所位置 | 车库法第5条 |
| 变更了保管场所 | 15日内申报变更 | 车库法第7条 |

**库存的摆放场所本身，与车库法的车库证明另属一事，是看物件的用途地域・接道・租赁契约能否安全放下该台数的问题。** 车库证明的申请协助（依买主・事业者委托制作书类）由行政书士承担，证明・申报的窗口是管辖保管场所的警察署。本公司确认物件侧的停车可能性。运送业的营业所・车库物件条件，另整理在[要开运送业，营业所与车库的物件该看哪里选](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

## 旧货商许可的营业所要件，与租赁物件的契约要注意什么？

定下营业所、取得公安委员会的许可，且收购在营业所进行，这几点会影响物件。

古物营业法（昭和24年法律第108号）第3条规定，想经营旧货商者须取得都道府县公安委员会的许可。第5条规定向管辖主营业所所在地的公安委员会提出许可申请书（实务上经由所辖警察署）；第13条要求各营业所选任管理者一人；第14条更规定旧货商不得在营业所或交易相对人的住所・居所以外的场所收受旧货。

落在物件上的议题如下。

| 确认点 | 为何影响选物件 |
|---|---|
| 作为营业所使用的权原 | 租赁时出租人是否同意「作为旧货营业的营业所使用」 |
| 独立营业所的实体 | 是否设管理者、有能适正执行业务的区划 |
| 收购（收受）进行的场所 | 收购在营业所进行（第14条），故要整理展示场与营业所的位置关系 |
| 使用承诺・转租可否 | 租赁契约是否许可该用途・使用形态 |

**把租赁物件作旧货商营业所时，请先读契约书「使用目的」栏是否许可旧货营业。** 限住宅用・事务所用的契约，之后要另行交涉加上用途。租赁契约该读哪里，整理在[租赁契约书，该读哪里](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。旧货商许可营业所要件本身的细节，请见[旧货商许可的营业所要件](https://luck428.com/legal/column/kobutsusho-kyoka-eigyosho-yoken)（行政书士侧）。

## 用青空停车场・资材放置场做展示时，回复原状与契约形态怎么组？

先确认契约是否许可该用途，并以书面固定回复原状的范围，是重点。

把空地的青空停车场或资材放置场当展示空间时，出租人是否同意铺装・招牌・照明・围篱的设置，退租时要回复到哪里（回复原状范围），都要写进契约。土地租赁中，以拥有建物为目的会受借地借家法保护，而作为停车场・资材放置场的暂时使用、或不盖建物的利用，处理方式不同，故契约形态要配合目的选择。

| 议题 | 契约要决定的事 |
|---|---|
| 用途 | 能否把「中古车的展示・保管」写进使用目的 |
| 造作・设置物 | 铺装・招牌・照明・围篱的设置可否与费用负担 |
| 回复原状 | 退租时撤除的范围・还地或现况返还 |
| 契约形态・期间 | 是否为不盖建物的利用；期间・更新・中途解约条件 |

**即使打算「只是摆放」，一旦铺装或装招牌就会产生回复原状的负担。** 先决定要动到哪里，把费用负担与撤除范围落进契约。事业用物件整体请见[投资用・事业用不动产](https://luck428.com/toushi)，事务所与许认可的关系请见[公司设立与办公室选择](https://luck428.com/office)，仓库・保管的物件条件请见[能做营业仓库的物件条件](https://luck428.com/column/eigyo-souko-touroku-bukken-youken)。

## 常见问题

**Q. 中古车展示场能盖在任何用途地域吗？**
A. 不能。展示・销售的店铺受建筑基准法别表第二的用途限制，第一种低层住居专用地域原则不可，工业专用地域连物品销售店铺本身都不能盖。第二种低层住居专用地域为楼地板面积150㎡以内・2层以下等，可否随地域与规模而异。伴随整备则另有汽车修理工场的作业场面积限制。适合与否请向特定行政厅确认。

**Q. 展示中的每一台库存车都要取得车库证明吗？**
A. 通常不用。车库证明（车库法第4条）在汽车登录的场面才需要，销售用库存车一般在买主确定、进入登录阶段时由买主取得。但事业者登录作为公司用车使用的车，作为其保有者仍需确保保管场所并取得车库证明・申报（第3条・第5条・第7条）。手续窗口是管辖保管场所的警察署。

**Q. 租赁店铺能作旧货商的营业所吗？**
A. 有可能。但前提是租赁契约的使用目的许可旧货营业，且设有管理者、有能适正执行业务的区划。因古物营业法第14条要求收购在营业所进行，故也要整理展示场与营业所的位置关系。请先读使用目的栏，必要时交涉加上用途。许可申请由行政书士承担。

**Q. 旧货商许可申请或车库证明能委托不动产公司吗？**
A. 不能。旧货商许可・车库证明等向官公署提出的书类制作・申请协助是行政书士的业务，由四葉行政書士事務所承接。物件的调查・仲介・契约由四葉不動産株式会社承接。用途变更确认申请与汽车修理工场的适合设计由建筑士承担。皆为各自独立的事业体，请分别直接签约。
