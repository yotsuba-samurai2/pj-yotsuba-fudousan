**结论（先说要点）**：能登录为附服务高龄者住宅（Sakoju）的物件骨架有四项——各户原则25㎡以上（共用部分充足则18㎡以上）、各户或共用部分的厨房・厕所・洗面・浴室・收纳、走廊宽度・高低差・扶手的无障碍、至少提供安否确认（状况把握）与生活咨询服务。这是高龄者住まい法的登录基准，建物的设计・改修，加上契约与运营规则也一并被要求。既有建物也能符合，但由楼地板面积与共用设备的作法决定可否。

“能不能把空着的公寓做成Sakoju”的咨询日益增加。但Sakoju并非可自由自称的住宅，而是高龄者住まい法的登录制度。本文写给在东京考虑Sakoju的不动产所有者・事业者：登录的物件・建物条件，依高龄者的居住安定确保相关法律的条文与国土交通省・厚生劳动省的说明顺序整理。可否与数值的最终确认，在授予登录的都道府县・政令市等窗口。

## 能登录为Sakoju的物件最低条件是？

Sakoju是依高龄者的居住安定确保相关法律（平成13年法律第26号）第5条登录的高龄者向租赁住宅等。登录主体为都道府县知事（政令指定都市・中核市则为其首长），登录有有效期间，每5年更新（**2026年8月25日参照**）。

登录基准的骨架，大致分为“住宅本身”“提供的服务”“契约”三块。

| 区分 | 登录基准骨架 |
|---|---|
| 规模 | 各户楼地板面积原则25㎡以上（居间・食堂・厨房等共用部分具充足面积时18㎡以上） |
| 设备 | 各户备厨房・水洗厕所・收纳・洗面・浴室（于共用部分适当备置共同利用者，部分可不设于各户；但厕所・洗面以各户为基本） |
| 构造 | 无障碍构造（确保走廊宽度、消除高低差、设置扶手） |
| 服务 | 至少提供状况把握（安否确认）与生活咨询服务，并有照护专业人员参与 |
| 契约 | 明示居住部分的书面契约。不收取租金・押金・服务对价以外的金钱。预付款有返还规则与保全措施。未经住户同意不变更居住部分・不解除契约 |

**要注意，楼地板面积与设备的数值是住宅基准，须与服务・契约规则一起构成“登录基准”。** 只把建物整好，若服务体制或契约书不达基准，也不会被登录。作为物件的问题，先发生作用的是楼地板面积、无障碍，以及共用设备如何作。

## 各户25㎡・共用设备・无障碍，既有建物能符合吗？

有能符合的情形，但越是既有建物，越由**楼地板面积与共用部分的作法**分出可否。

第一是楼地板面积。原则各户25㎡以上，即使达不到的狭小住户，只要**居间・食堂・厨房等共用部分具充足面积，可缓和至18㎡以上。** 也就是“加大各户”或“加厚共用部分”的设计判断。转用既有单间公寓时，这共用部分设在何处是最初的关卡。

第二是设备。各户备厨房・厕所・洗面・收纳・浴室为基本，但**于共用部分作为共同利用的设备适当备置，部分可不设于各户**（厨房・浴室・收纳）。惟水洗厕所与洗面设备以各户为基本。如何运用此缓和，会大幅改变改修规模。

第三是无障碍。须符合走廊宽度、消除高低差、扶手设置等构造基准。**既有建物中，走廊宽度与有无楼梯・电梯，是改修能否符合的分界。**

| 签约前确认 | 为何有效 |
|---|---|
| 各户楼地板面积与格局 | 能否符合25㎡（缓和18㎡）；可能须合并住户 |
| 共用部分可取得的面积 | 左右楼地板面积・共用设备缓和的可否 |
| 走廊宽度・高低差・电梯 | 左右无障碍改修的规模 |
| 给排水・电力容量 | 影响共用厨房・浴室、状况把握机器的导入 |
| 用途・构造 | 牵涉用途变更确认申请与耐震的要否 |

楼地板面积、无障碍符合、用途变更确认申请的要否，属建筑确认・设计的领域。**本公司（不动产公司）协助调查物件能否符合Sakoju登录基准，并在取得・租赁的条件交涉上伴走。** 设计判断与符合可否本身由建筑士处理。照护事业所物件的卡关方式整理于[“照护事业所物件找不到的真正理由”](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)，租赁契约书该读哪里整理于[“租赁契约书该读哪里”](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 登录申请・建筑确认・照护服务指定由谁承担？

Sakoju牵涉多位专家。角色分开。

| 要做的事 | 承担者 |
|---|---|
| 物件调查・取得，中介与契约 | 宅地建物取引业者（本公司） |
| Sakoju登录申请文件的制作 | 行政书士 |
| 无障碍符合・用途变更等设计、建筑确认 | 建筑士 |
| 照护保险服务（特定设施入居者生活照护等）的指定申请 | 另行手续（向指定权者申请） |

Sakoju是“住宅”的登录，其中是否提供照护服务是另一制度。**若向住户提供照护保险服务，视情形须另行指定或申报。** 混淆住宅登录与照护服务指定，会看错开设的步调。

Sakoju登录申请等向官公署提出的文件之制作，由四叶行政书士事务所承接。**登录主体・样式・登录基准的运用（各自治体以高龄者居住安定确保计划上乘的基准等）会变。着手时请直接确认授予登录的自治体页面。** 事业用物件全般见[投资用・事业用不动产](https://luck428.com/toushi)，事务所与许认可的关系见[公司设立与办公室选择](https://luck428.com/office)。用途地域与容积率如何影响地价整理于[“日本地价为何随‘容积率’而变”](https://luck428.com/column/yosekiritsu-hosei-tochine)。

## 费用与期间的目安大概多少？

费用与期间，随物件状态（新建或既有改修）与自治体运用而大幅变动。**没有全国一致的定价。** 这里不断定金额，作为“项目”整理花钱与花时间之处。

| 项目 | 目安的考量 | 承担者 |
|---|---|---|
| 建筑・改修费 | 随楼地板面积・无障碍・共用设备的作法大幅变动；最大变动要因 | 建筑士・施工业者 |
| 设计・确认申请 | 若需用途变更确认申请则期间延长 | 建筑士 |
| 登录申请 | 依自治体样式制作文件；手续费依自治体 | 行政书士 |
| 登录有效期间 | 5年（须更新） | — |
| 状况把握・生活咨询体制 | 人员配置・机器导入的运营成本 | 事业者 |

**期间随既有建物的改修规模与用途变更要否，以数月为单位变动。** 具体金额・期间・自治体独自基准，本文无法确定，**作为未检证处理，请向登录主体与建筑士个别确认。** 与其硬放数字目安，不如掌握变动要因来规划更为安全。

## 常见问题

**Q. 各户18㎡也能登录为Sakoju吗？**
A. 有能登录的情形。各户楼地板面积原则25㎡以上，但若有供高龄者共同利用的充足面积之居间・食堂・厨房等设备，可缓和至18㎡以上（高龄者的居住安定确保相关法律的登录基准）。共用部分面积的取法会改变可否，请在设计阶段向建筑士与登录主体确认。

**Q. 能把既有公寓转用为Sakoju吗？**
A. 若能符合楼地板面积・无障碍・共用设备基准即可。惟走廊宽度、高低差、共用部分面积、给排水达不到基准时，须改修或用途变更确认申请。既有建物中，先确认各户楼地板面积与共用部分可取得的面积是出发点。

**Q. 是Sakoju就当然能提供照护服务吗？**
A. 不是。Sakoju是“住宅”的登录，提供状况把握（安否确认）与生活咨询是登录的基准。要向住户提供照护保险服务，须视情形另行指定或申报。住宅登录与照护服务指定是不同制度，请分开安排步调。

**Q. Sakoju登录申请可以委托不动产公司吗？**
A. 不行。向官公署提出的登录申请文件之制作属行政书士业务，由四叶行政书士事务所承接。物件的调查・中介・契约由四叶不动产株式会社承接。无障碍符合与用途变更的设计・建筑确认由建筑士承担。皆为各自独立的事业体，请各自直接签约。
