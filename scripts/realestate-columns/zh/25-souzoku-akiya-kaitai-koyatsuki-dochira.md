**结论（先说重点）**：卖继承到的空房时，「拆除后卖素地」或「连同老屋（现况）卖」取决于四点——①拆除费用，与拆为素地后住宅用地特例消失、固定资产税上升；②买方族群（素地适合想盖屋的人，连同老屋适合重视价格、DIY、投资者）；③契约不符责任与拆除费负担；④空房3000万日元特别扣除（租税特别措置法35条3项）的适用方式。特别是该扣除已整理成「先拆为素地再卖／买方于交屋后拆除」两种都能用的形式，因此拆除时点左右手取金额。税额计算交税理士，灭失登记交土地家屋调查士・司法书士。

继承到的老家变成空房，真要卖时必定撞上的，就是「先拆再卖，还是原样卖」。何者较划算因物件与买方而异，没有一律的正解。本文写给想卖继承空房的继承人，整理**素地交付与连同老屋交付这两种卖法本身的差异**（费用、期间、买方族群、契约不符责任、税的特例）。放置不管的风险与扣除的逆算另有专文，此处聚焦于「拆或不拆」的判断。

## 卖素地与连同老屋卖，对买方而言有何不同？

同一块地，作为素地与连同老屋，**买方族群会不同**。

素地适合想马上盖屋的人、建商、建售业者。若界址与地中埋设物清楚，买方能立即规划建筑计划。连同老屋（现况交付），则适合**想压低价格、以DIY或改建为前提、想作投资出租的人**。即使不认老屋的价值，也能成立「拆除费由买方负担、故相应便宜」的定价。

| | 素地交付 | 连同老屋（现况交付） |
|---|---|---|
| 主要买方族群 | 想马上盖屋・建售业者 | 重视价格・DIY・改建・投资 |
| 卖方初期费用 | 拆除费先支出 | 不支出 |
| 至交屋的期间 | 因拆除而延长 | 较快 |
| 是否易于辨识 | 高（看得到地形） | 建物遮挡视线 |

何者卖得较高，取决于区位与建物状态。土地价值如何随容积率变动见[此处](https://luck428.com/column/yosekiritsu-hosei-tochine)，「卖或留」的整体判断见[此处](https://luck428.com/column/souzoku-jikka-uru-nokosu)。

## 拆除费用，与拆为素地后固定资产税上升，各要抓多少？（税额交税理士）

拆为素地前，务必掌握**固定资产税的住宅用地特例**。

地方税法对建有住宅的土地（住宅用地）之固定资产税，减轻其课税标准。**小规模住宅用地（200㎡以下的部分）课税标准减为6分之1**，超过部分之一般住宅用地减为3分之1（都市计划税分别为3分之1、3分之2）。**拆除建物成为素地，此住宅用地特例消失，固定资产税上升。**

常有人说「拆为素地后固定资产税变6倍」，但这并不精确。特例消失后课税标准上升，惟素地有负担调整措施与非住宅用地上限（课税标准为评价额的70%）在运作，故**实际增幅并非恰好6倍**。增幅因自治体、评价额而异。

| 状态 | 小规模住宅用地固定资产税的课税标准 |
|---|---|
| 建有房屋（住宅用地） | 评价额的6分之1 |
| 拆除为素地 | 特例消失（有负担调整・非恰好6倍） |

此外，被放置的空房若被指定为**「特定空家等」或「管理不全空家等」**并收到市町村劝告，其基地会被排除于住宅用地特例之外（空家等对策特别措置法）。不拆除、仅是放置，也可能使特例消失，须留意。**具体税额与增幅的试算交税理士**，放置风险请另行确认。

## 连同老屋卖，契约不符责任与拆除费负担如何？

卖连同老屋土地时的重点是**契约不符责任**（旧称瑕疵担保责任）。

民法规定，所卖之物不符契约内容时，买方可请求追完（修补）・减少价金・损害赔偿・解除契约（民法562条以下）。老旧空房易出现漏水、白蚁、给排水故障，原样出售可能日后被追究此责任。

因此个人间的中古交易，常附上**「以现况有姿交付、不负契约不符责任（免责）」的特约**。民法上，契约不符责任可以特约减轻・免除（惟卖方明知而未告知之事实不及于免责）。

须注意**卖方为宅地建物取引业者、买方为个人（非业者）**的情形。此时依宅地建物取引业法40条，除将契约不符责任的通知期间定为「自交屋日起2年以上」外，其余对买方不利的特约无效。个人卖方与业者卖方，免责特约的效力不同。

| | 个人为卖方 | 业者为卖方・买方为个人 |
|---|---|---|
| 契约不符责任的免责特约 | 原则有效（明知未告知者除外） | 受40条限制（自交屋起2年以上等） |
| 拆除费之处理 | 以「买方负担、故便宜」等织入价格 | 同样以价格・条件调整 |

拆除费要「由卖方负担、拆为素地后交付」或「由买方负担、连同老屋便宜交付」，是价格协商的内容。选哪一种，也会改变下述税的特例的用法。

## 若要用3000万日元特别扣除，拆除时点会改变什么？（适用可否交税理士）

卖继承空房时的一大要素，是**「被继承人的居住用财产（空房）出售时的3000万日元特别扣除」（租税特别措置法35条3项）**。可自让渡所得扣除最多3000万日元（继承人3人以上时每人2000万日元）。

主要要件如下。

| 要件 | 内容 |
|---|---|
| 建筑时期 | 昭和56年5月31日以前建筑 |
| 建物种类 | 非区分所有建物（公寓大厦等） |
| 居住状况 | 继承开始前，被继承人一人居住（有入住安养机构等特例） |
| 用途 | 自继承至出售，未供事业・出租・居住使用 |
| 让渡对价 | 1亿日元以下 |
| 期限 | 至继承开始起满3年之日所属年度的12月31日／特例适用期限至令和9年12月31日 |
| 房屋状态 | 出售时符合耐震基准，或拆除房屋成为素地 |

此处拆除时点会发生作用。以往须「卖方于交屋前耐震改修」或「拆为素地」，惟**自令和6年（2024年）1月1日以后的让渡，买方于让渡翌年2月15日前耐震改修或拆除者，亦纳入适用对象**。也就是说，卖方不必先拆，**由买方于交屋后拆除的安排也能用扣除**。

这大幅改变「拆为素地再卖，或连同老屋卖」的判断。**适用可否、要件之套用与让渡所得的计算，属税理士的所管。** 要件细琐，尚有入住安养机构的特例与共有情形的处理。本公司看卖法（素地／现况）与价格设计，税理士看扣除的适用可否，各自分别进行。

## 常见问题

**Q. 先拆再卖，或连同老屋卖，哪个较划算？**
A. 没有一律的正解。素地适合想马上盖屋的买方、也易于想像，但拆除费先支出，且成为素地期间住宅用地特例消失。连同老屋不需初期费用、能较快挂牌，但须将契约不符责任与拆除费织入价格。3000万日元扣除自2024年起，由买方于交屋后拆除的形式亦可用，宜在向税理士确认适用可否后再决定。

**Q. 拆除空房，固定资产税会变6倍吗？**
A. 不会「恰好6倍」。拆除使住宅用地特例（小规模住宅用地课税标准6分之1）消失、课税标准上升，但素地有负担调整措施与评价额70%的上限在运作，故实际增幅因自治体、评价额而异。具体试算请向税理士确认。又，放置并收到「特定空家等」劝告，即使不拆也可能使特例消失。

**Q. 拆除建物后，登记须做什么吗？**
A. 须办理。依不动产登记法第57条，拆除（灭失）建物后须于1个月内申请建物灭失登记。表题部（现况・测量）属土地家屋调查士的领域，权利部手续属司法书士的领域。名义仍为被继承人时，作为前提尚须继承登记。

**Q. 连同老屋卖，能不负契约不符责任吗？**
A. 个人为卖方时，「现况有姿・不负契约不符责任（免责）」特约原则有效（惟明知未告知之事实不及于免责）。卖方为宅地建物取引业者、买方为个人时，依宅地建物取引业法40条有限制，通知期间须自交屋起2年以上，对买方不利之特约无效。特约如何撰写因当事人与物件而异，于中介中个别确认。
