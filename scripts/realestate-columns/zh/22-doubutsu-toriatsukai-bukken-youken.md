**结论（先说要点）**：宠物美容沙龙・宠物店的物件，最先卡关的是能否符合饲养设施基准（笼子・洗净・消毒・换气・排水）、气味与吠叫会不会与邻居冲突，以及租约是否禁止“饲养动物”三点。第一种动物取扱业的登录是“按事业所”取得，物件能否符合设施基准是前提。签约前确认用途地域・排水・换气与出租人意向，就能避免返工。

因为“是可养宠物的大楼”而承租，到了登录阶段却因饲养设施的换气或排水达不到基准而要重做装修。餐饮店、美容室会发生的返工，动物相关的店同样会发生。本文写给在东京要开宠物美容沙龙・宠物店的人，以及把物件租给他们的人：签租约前能确认的事，依动物的爱护及管理相关法律的条文与环境省・自治体的说明顺序整理。可否的最终确认在授予登录的自治体窗口。

## 动物取扱业的物件，签约前先确认什么？

先确认自己的生意是否属于“需要登录的业”。动物的爱护及管理相关法律（昭和48年法律第105号）第10条规定，以贩售・保管・出借・训练・展示等方式，将动物（哺乳类・鸟类・爬虫类）作为事业经营者，须**按事业所**，向所在地管辖的都道府县知事（指定都市・中核市等则为其首长）取得**第一种动物取扱业的登录**（**2026年8月25日参照**）。

自己的店属于哪个种别：

| 业态 | 对应种别（例） |
|---|---|
| 宠物店（活体贩售） | 贩售 |
| 宠物美容沙龙（收下施作） | 保管 |
| 宠物旅馆 | 保管 |
| 训练教室 | 训练 |
| 猫咪咖啡・互动 | 展示 |

**登录是“按事业所”。** 因此物件一变就要重新登录，物件本身能否符合饲养设施基准是登录的前提。这是物件选择的起点。

登录有有效期间，每5年更新（同法第13条）。此外，涉及暴力团关系者、过去被撤销登录者等一定事由时，登录会被拒绝（同法第12条）。

## 饲养设施的面积・笼子・气味对策，由物件如何决定？

第一种动物取扱业者，须遵守环境省令所定饲养设施的构造・规模及动物管理方法等基准（同法第21条）。具体由同法施行规则（平成18年环境省令第1号）规定，令和3年6月1日施行的修正加入了犬・猫的数值基准（**2026年8月25日参照**）。

在物件端会发生作用的点：

| 项目 | 施行规则的考量 |
|---|---|
| 笼子等 | 依动物种类・数量・体格的大小；犬猫依运动空间分离或一体而基准不同；床材原则禁用铁丝网（肉垫受保护者除外） |
| 给饵・给水设备 | 能随时饮用清洁水的设备 |
| 洗净・消毒设备 | 能洗净并消毒设施・器具的设备 |
| 排水设备 | 能适当排出污物・污水的排水 |
| 换气设备 | 排出气味・湿气・粉尘，并管理温湿度的换气 |
| 遮光・照明设备 | 顾及动物生理的采光・照明 |
| 从业人员数 | 犬・猫的每名从业者饲养头数有上限（犬20头〔其中繁殖用15头〕、猫30头〔其中繁殖用25头〕；从业者数基准经过渡措施分阶段施行） |

**要注意，这些是“为动物”的基准，而建物里什么放在哪，由物件的给排水・换气素地决定。** 事后想在单间店铺装入大型洗净槽或大换气，会牵动给排水增设与电力容量增设的费用与工期。

物件端值得确认的，与其说是数值本身，不如说是**能否具备符合的素地**：

| 签约前确认 | 为何有效 |
|---|---|
| 给排水的位置与口径 | 洗净・消毒・给水必备；宠物美容大量用热水 |
| 换气・排气路径 | 气味是邻居纠纷主因；方向与能力重要 |
| 电力容量 | 给汤・吹风机・空调・洗净机需容量 |
| 防水・易清扫的地墙 | “保持清洁”的素地；与恢复原状范围相关 |
| 隔音余地 | 吠叫对策；木造・轻量钢骨易传声 |

给排水・换气・隔音的设计是施工业者（设计者）的领域。**本公司（不动产公司）协助调查物件能否符合这些条件，并在与出租人的条件交涉上伴走。** 不进行设备设计本身。相同的返工整理于[“美容室・理容所的物件，保健所看什么”](https://luck428.com/column/biyoshitsu-riyojo-bukken-hokenjo-todokede)与[“照护事业所物件找不到的真正理由”](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)。

## 用途地域与对邻居的顾虑，哪种物件容易被拒？

动物相关的店，与餐饮店、诊所不同之处在于，**气味・吠叫・排水这些对邻居的影响，大幅左右物件选择。**

第一是租约。集合住宅・杂居大楼多在契约书中禁止“饲养动物”或携入宠物。即使是可养宠物的住宅，那也是允许住户饲养，未必包含反复收下动物的“业”。**须在申请前先读契约书如何规定动物饲养与作为业的使用。** 契约书该读哪里整理于[“租赁契约书该读哪里”](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

第二是用途地域。宠物店・宠物美容沙龙在建筑基准法上被视为“服务业店铺”，与美容院同样受用途地域限制。第一种低层住居专用地域难以设单独店铺，第二种低层住居专用地域则有楼地板面积合计150㎡以内等限制。可否在特定行政厅窗口确认。用途地域与容积率如何影响地价整理于[“日本地价为何随‘容积率’而变”](https://luck428.com/column/yosekiritsu-hosei-tochine)。

第三是邻居。与登录可否无关，气味・噪音会透过自治体的生活环境条例与邻居投诉影响店的存续。**排气方向、营业时间、隔音的作法，以及出租人与邻居的状况，最好在签约前确认。**

## 常见问题

**Q. 可养宠物的公寓，就能开宠物美容沙龙吗？**
A. 未必。可养宠物是允许住户饲养，未必包含反复收下动物的“业”。许多租约限制“饲养动物”或作为业的使用。请在申请前确认契约条款与出租人意向，并确认换气・排水・消毒设备能否符合施行规则的基准。

**Q. 店铺搬迁后，第一种动物取扱业登录会怎样？**
A. 登录是按事业所取得（动物的爱护及管理相关法律第10条）。搬迁就要就新物件重新登录。因新物件须能符合设施基准，搬迁地的给排水・换气・区划最好在签约前确认。

**Q. 笼子大小或从业人员数有固定数值吗？**
A. 就犬・猫而言，施行规则（令和3年6月1日施行的修正）订有笼子大小、每名从业者饲养头数上限等数值基准（犬每人20头〔其中繁殖用15头〕、猫30头〔其中繁殖用25头〕；从业者数基准分阶段施行）。数值的适用与解释依自治体运用，请向管辖的动物爱护中心等确认。

**Q. 登录申请可以委托不动产公司吗？**
A. 不行。向官公署提出的登录申请文件之制作属行政书士业务，由四叶行政书士事务所承接。物件的调查・中介・租赁契约由四叶不动产株式会社承接。两者为各自独立的事业体，请各自直接签约。动物取扱责任者是否符合要件，由授予登录的自治体审查。
