**结论（先说重点）**：产业废弃物的「转运・保管」据点，不是租个仓库或堆置场就够。物件上起作用的有三点。①用途地域——若设置上屋等建筑物，受建筑基准法第48条・别表第二的用途限制，实务上准工业・工业・工业专用地域较合适。②围栏与告示板——需要防止飞散・泄漏・地下渗透・恶臭的围栏，以及纵横各约60cm以上的告示板。③保管上限量与高度——转运用的保管量以1日平均搬出量的7日份为上限，露天不使用容器堆放时受高度限制。物件的选定・用途地域确认由本公司（四叶不动产株式会社），含转运・保管的产业废弃物收集运搬业许可申请由行政书士，设施基准的适合确认・建筑确认由建筑士，各自作为独立事业体、分别直接签约承担。

想在收集运搬业设一个做「转运・保管」的据点，却不知道哪种物件能符合基准——本文写给寻找此类据点物件的业者：签约前能从不动产一侧确认的点，依废弃物处理法・建筑基准法的条文与自治体的许可申请手册整理。物件的调查・选定由本公司以信息提供承担，许可可否与设施基准的最终适合判断由行政书士・建筑士等有资格者为之。单纯运送（无转运保管）与在据点暂时保管的转运・保管，物件要求的条件明显不同。

## 能做产业废弃物转运・保管的物件，适合哪种用途地域？

首先要把「保管场所本身」与「在其上盖的建筑物」分开想。只在露天堆放、不伴随建筑物的保管场所，不直接受用途地域的建筑限制。反之，若设置上屋・仓库・事务所等建筑物，该建筑物受建筑基准法第48条・别表第二的用途限制。

此外，选址在自治体的产业废弃物处理业许可审查中也会被检视。住居系用途地域易与邻里及生活环境起冲突，多数自治体的手册以工业系（准工业・工业・工业专用地域）为前提说明。

| 论点 | 物件上要确认的事 |
|---|---|
| 是否盖建筑物 | 设上屋・事务所受建筑基准法第48条・别表第二限制；住居专用地域不可或限制严格 |
| 是否露天堆放 | 非建筑物则不直接受用途地域限制，但自治体的选址基准（避开住居系）另有 |
| 市街化调整区域 | 伴随建筑物时，都市计画法的开发许可・建筑许可是另一道墙 |
| 邻里环境 | 飞散・恶臭・噪音・车辆出入是否与周边冲突 |

## 围栏・告示板・防止飞散泄漏等，物件侧需要什么设备？

保管产业废弃物时，须符合施行令所定的保管基准，以免对生活环境造成妨碍（废弃物处理法第14条、施行令第6条第1项第1号）。转运用的保管也以此为前提。物件选定阶段能确认的，是以下设备・区划能否事后整备。

| 要求 | 物件上确认的点 |
|---|---|
| 围栏 | 能否在保管场所周围设围栏；废弃物荷重直接施加时能否承受 |
| 告示板 | 是否有地方挂纵横各约60cm以上的告示板（表示为保管场所・种类・管理者与联络方式・最大高度等） |
| 防止飞散・泄漏 | 能否防止风吹飞散、雨水泄漏；有无屋顶・防尘布・区划的素地 |
| 地下渗透・污水 | 油分与污液能否不渗入地下；地面混凝土铺装・排水・油水分离能否做到 |
| 恶臭・害虫 | 恶臭是否波及周边；若处理易腐品目，有无密闭・换气余地 |

这些取决于物件的「素地」。打好土间混凝土、易设排水与围栏的平地仓库・工厂・堆置场易于符合；土壤裸露、无排水路径的土地，地下渗透对策的工程负担较大。

## 能保管的上限量与面积・高度限制如何决定？

转运・保管有数量上限。转运用能保管的产业废弃物量，以该场所1日平均搬出量乘以7（约7日份）为上限。旨在「运送途中暂时放置」的保管，而非长期库存场。

高度也有限制。露天不使用容器保管时，未接触围栏的部分坡度约50%以下，接触围栏的部分须压低（使荷重不施于围栏：内侧2m以内低于围栏高度50cm，超过2m的部分坡度50%以下）。数量・高度的具体数字，自治体的许可申请手册有图解。

| 项目 | 目安 |
|---|---|
| 转运用保管上限量 | 1日平均搬出量的7日份 |
| 露天・无容器堆积高度 | 未接触围栏部分坡度50%以下，接触围栏部分再受限 |
| 必要面积 | 由品目・搬出量・车辆回转逆算（参手册的图） |
| 品目别附加基准 | 含石棉产业废弃物・特别管理产业废弃物等有上乘基准 |

也就是说，物件的大小不是「能堆越多越好」，而是看能否在守住围栏・高度限制下，取得由搬出量逆算的必要量的平地。

## 无转运保管的收集运搬，物件要件有何不同？

同为产业废弃物收集运搬业，「不含转运・保管」与「含」，物件要求的条件差异很大。

| | 无转运・保管 | 有转运・保管 |
|---|---|---|
| 物件（据点）的定位 | 多半有停车的车库・事务所即可 | 符合保管基准的保管场所本身成为许可对象 |
| 用途地域・选址 | 看事务所・车库的用途限制 | 连保管场所的选址・围栏・排水都看（工业系合适） |
| 数量・高度限制 | ——（不做转运・保管） | 平均搬出量7日份・堆积高度限制生效 |
| 许可范围 | 收集运搬业（除转运保管） | 收集运搬业（含转运保管）——申请区分不同 |

「只运送」多半用符合车库与事务所要件的物件即可；「在据点暂时保管」则以该保管场所符合保管基准为许可前提。若在此搞错而签了住居系用途地域或无排水的土地，恐事后无法整备设施、达不到许可。决定物件前，先确定处理品目・搬出量与是否转运・保管，较为安全。

## 常见问题

**Q. 租了仓库就能马上做产废的转运・保管吗？**
A. 常常不能马上。转运・保管场所须符合围栏・告示板・防止飞散泄漏・地下渗透对策等保管基准（废弃物处理法第14条、施行令第6条第1项第1号），在住居系用途地域或无排水的土地难以符合。决定物件前，先确认处理品目・搬出量与设施能否整备较安全。

**Q. 能保管多少量？**
A. 转运用的保管量以该场所1日平均搬出量的7日份为上限。定位是运送途中暂时放置的保管，而非长期库存场。具体数量・高度的图解载于自治体的许可申请手册。

**Q. 用途地域哪里都行吗？**
A. 若设上屋等建筑物，受建筑基准法第48条・别表第二限制，住居专用地域不可或限制严格。即使露天不伴随建筑物，多数自治体为避免生活环境妨碍，也以工业系（准工业・工业・工业专用）为前提说明。

**Q. 许可申请的文书制作也能拜托吗？**
A. 许可申请文书由行政书士（四叶行政书士事务所）承接。本公司（不动产）负责物件选定・用途地域确认・媒介，设施基准的适合确认与建筑确认由建筑士承担。这些以独立事业体、分别直接签约。
