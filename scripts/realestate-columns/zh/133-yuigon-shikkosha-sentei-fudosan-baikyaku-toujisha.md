**先讲重点**：出售有遗言执行人的继承不动产时，买卖契约的当事人（卖方）是谁会随遗言的形式而变。"使之继承"旨（特定财产承继遗言）者，由取得不动产的继承人当卖方，执行人负责相续登记等对抗要件的具备。把遗产卖掉再分配的清算型遗赠，则由执行人进行出售手续。遗言的解释与权限范围交给律师、登记交给司法书士，不动产的中介由本公司负责。

以公证遗言取得了不动产，或被指定、选任为遗言执行人——以这样的身分想出售继承来的不动产时，常会困惑"在契约上签名的是我还是执行人""交割现场谁出面"。有没有遗言，以及遗言怎么写（"使之继承"还是"遗赠"），会改变出售的当事人与登记的流程。

本文从不动产的视角，整理遗言执行人涉及的继承不动产出售场面中，媒介契约、买卖契约、交割由谁出任当事人。遗言的有效性或执行人权限范围本身的判断是律师的领域，本文仅为一般性的资讯提供。

四叶不动产株式会社以东京都文京区小日向为据点，承接继承不动产的估价与出售中介。关于有遗言执行人涉及的出售，可从出售前能确认的事项开始咨询。

## 有遗言执行人时，买卖契约的卖方与签名者是谁？

首先要掌握的是遗言执行人的权限。民法第1012条第1项规定，遗言执行人为实现遗言的内容，享有管理相续财产及为执行遗言所必要之一切行为的权利义务。同条第2项规定，有遗言执行人时，遗赠的履行仅能由遗言执行人为之（平成30年法律第72号修正、2019年7月1日施行）。

谁成为卖方，取决于遗言如何承继该不动产。

| 遗言的形式 | 不动产的承继 | 买卖契约的卖方、签名者 |
| --- | --- | --- |
| "使之继承"旨（特定财产承继遗言） | 于继承开始时当然承继予该继承人 | 取得不动产的继承人（受益继承人） |
| 遗赠（特定遗赠） | 受遗人因遗赠而取得 | 取得后为受遗人；遗赠的履行由执行人为之 |
| 清算型遗赠（卖掉再分配旨） | 执行人变价后分配代金 | 执行人进行出售手续 |

民法第1015条规定，遗言执行人于其权限内，表明其为遗言执行人所为之行为，对继承人直接生效。因此在清算型等由执行人负责出售的场面，执行人以"遗言执行人"身分出任契约当事人。反之，若某特定继承人依"使之继承"旨取得不动产、由该继承人自行判断出售，卖方就是该继承人。

究竟属于哪种类型、遗言文字的解释，最终是律师的领域。本公司会看遗言的影本与登记状况，整理买卖当事人可能为谁，须确定的部分则转介律师、司法书士。执行人的职务与选任机制本身，由行政书士侧的[遗言执行人由谁担任、如何选任（日文）](https://luck428.com/legal/column/yuigon-shikkosha-shokumu-sennin-dare)处理。

## 特定财产承继遗言（使之继承旨）与遗赠，在出售与登记的流程上有何不同？

作为出售前提的登记流程，也会随遗言的形式而变。2021年的不动产登记法修正（令和3年法律第24号）使遗赠的所有权移转登记之一部分可单独申请（2023年〈令和5年〉4月1日施行）。但可单独申请者限于对继承人的遗赠，对继承人以外之人的遗赠仍依从前的共同申请。

| 遗言的形式 | 登记的原因 | 申请的形式 |
| --- | --- | --- |
| "使之继承"旨（特定财产承继遗言） | 相续 | 继承人单独办相续登记；执行人亦可为对抗要件的具备（民法第1014条第2项） |
| 对继承人的遗赠 | 遗赠 | 受遗人（继承人）可单独申请（不动产登记法第63条第3项、2023年4月1日施行） |
| 对继承人以外的遗赠 | 遗赠 | 由受遗人与继承人（或执行人）共同申请 |

民法第1014条第2项规定，有特定财产承继遗言时，遗言执行人可为具备对抗要件所必要之行为。要把所有权移转予买方，通常以先把登记整理到受益继承人、受遗人的名义为出售前提。清算型遗赠中，可能须经继承人名义再办买卖的移转登记等，顺序会较复杂。

登记的原因、顺序与单独申请可否的判断，以及申请的代理，是司法书士的业务。本公司不代理登记。我们会配合出售时程，与司法书士确认该先整理哪一项登记后再进行。

## 媒介契约、本人确认、交割的现场，执行人与受益继承人如何涉入？

出售不动产要经过媒介契约（宅地建物取引业法第34条之2）、重要事项说明（第35条）、买卖契约书的交付（第37条）等步骤。有遗言执行人涉入的出售，最要紧的是一开始就确定这些的当事人是谁。

| 场面 | 谁出任当事人（依类型而异） |
| --- | --- |
| 媒介契约 | 成为卖方者（受益继承人，或清算型中的遗言执行人） |
| 本人确认（犯罪收益移转防止法） | 成为契约当事人者，与代理的执行人双方 |
| 重要事项说明 | 对买方的说明；卖方侧揭露权利关系、遗言与登记状况 |
| 交割、交付 | 成为卖方者受领；清算型中由执行人受领并分配代金 |

本人确认由宅地建物取引业者依犯罪收益移转防止法进行。执行人以卖方身分签约时，除确认执行人本人外，还要确认显示其被指定、选任为执行人的资料（遗言书、家庭裁判所的选任审判书等）。受益继承人为卖方时，则整理该继承人的本人确认，以及取得不动产的依据（遗言、登记）。

本公司在媒介契约阶段，依遗言与登记整理卖方为谁，并于重要事项说明中向买方揭露遗言、执行人的涉入与登记状况。若预见遗言有效性或权限有无有争议，我们会请您在进入媒介前先向律师咨询。

## 若出售内容与遗言不同，或继承人反对出售，会怎样？

有遗言执行人时，继承人不能擅自处分。民法第1013条第1项规定，有遗言执行人时，继承人不得处分相续财产或为其他妨害遗言执行的行为；同条第2项规定，违反者其行为无效（但不得对抗善意第三人）。

| 状况 | 整理方式 |
| --- | --- |
| 继承人未经执行人同意想出售 | 第1013条限制妨害行为；擅自处分原则无效 |
| 继承人反对出售 | 清算型等属执行人权限内者，执行人可推进出售 |
| 想以与遗言不同的内容出售 | 能否由继承人全体合意重做遗产分割，是律师的判断 |
| 遗言的有效性有争议 | 出售前先找律师；有效性确定前可能无法进入媒介 |

有反对的继承人、遗言有效性受争、执行人权限范围不明——这些场面的可否，本身即属个别的法律判断。包含本公司在内，无资格者都不能断言"卖得掉"或"卖不掉"。继承人间的争执与遗言的解释交给律师，登记交给司法书士。

关于共有持分或分割的出售思考，可参考[共有人之一把持分卖给第三人时的整理（日文）](https://luck428.com/column/souzoku-kyoyu-mochibun-dai3sha-baikyaku-bunkatsu)与[以变价分割出售继承不动产的流程（日文）](https://luck428.com/column/kanka-bunkatsu-fudosan-baikyaku-nagare)。

## 出售前执行人该确认哪些文件、如何分配给各专业？（分离受任）

遗言执行人涉入的出售，遗言的解释、登记、税务、不动产分属不同事业体。顺序一旦弄错，就会发生登记未整理就先签约、误解让渡所得税由谁负担等情形。

| 角色 | 由谁负责 |
| --- | --- |
| 估价、媒介、重要事项说明、交割 | 宅地建物取引业（本公司） |
| 遗言有效性、执行人权限范围、继承人间争执的判断 | 律师 |
| 相续登记、遗赠的移转登记 | 司法书士 |
| 让渡所得税、相续税的计算与申报 | 税理士 |
| 遗言执行人的选任声请 | 家庭裁判所 |

出售前要先确认的文件，有遗言书（公证遗言的正本、誊本，自书遗言则为已检认者）、显示执行人指定、选任的资料、登记事项证明书、固定资产税的课税明细等。清算型中，债务的清偿与代金分配的顺序也要先整理。

这些是**各自独立的事业体**，以**分别签约**为前提。本公司负责不动产的出售面，遗言的解释与权限判断交给律师，登记交给司法书士，让渡所得税、相续税交给税理士。本公司不收取介绍费。

## 常见问题

**Q. 我以"使之继承"旨的遗言取得了不动产，卖方是我没错吧？**
A. 特定财产承继遗言（"使之继承"旨）中，不动产于继承开始时当然承继予该继承人，因此原则上由取得的继承人当卖方。遗言执行人享有为具备对抗要件所必要之行为（如相续登记）的权限（民法第1014条第2项）。若对文字有疑义，请向律师确认。

**Q. 遗言写明由执行人卖掉再分配（清算型），契约由谁缔结？**
A. 把遗产卖掉分配代金的清算型中，遗言执行人为实现遗言内容而推进出售手续（民法第1012条第1项、第1015条），以"遗言执行人"身分出任契约当事人。登记顺序与代金分配会与司法书士、税理士确认后进行。

**Q. 继承人之一反对出售，卖得掉吗？**
A. 处理方式会依是执行人权限内的出售（如清算型）、还是取得的继承人自行出售，以及遗言有效性是否有争议而不同。民法第1013条限制有执行人时继承人的妨害行为。因可否属个别法律判断，请向律师咨询。本公司负责出售的媒介面。

**Q. 受遗赠的不动产登记，我可以自己一个人申请吗？**
A. 依2023年4月1日施行的不动产登记法第63条第3项，对继承人的遗赠，受遗人可单独申请所有权移转登记；对继承人以外的遗赠仍依从前的共同申请。登记可否的判断与申请代理是司法书士的业务，实际申请由其承办。
