**先讲重点**：继承到附以房养老（リ・バース60）的老家，先联络金融机构，确认本金余额、清偿期限，以及属无追索型或有追索型。本金在契约人死亡时一次清偿——由继承人清偿，或以担保物件的售价清偿。以出售结清时，整理估价、中介、交割时的一次清偿与抵押权涂销。余债的法律评价与可否放弃继承交给律师，抵押权涂销与继承登记交给司法书士。

继承到父母曾使用以房养老的自宅时，常会不安："剩下的借款怎么办""不卖就还不了吗""是不是该放弃继承"。以房养老是一种住宅贷款：生前只付利息，本金在契约人死亡时一次清偿。清偿时点与结清结构，都与一般住宅贷款不同。

住宅金融支援机构的【リ・バース60】，是附机构住宅融资保险、由民间金融机构提供的满60岁以上商品。本金在借款人死亡时，由继承人一次清偿，或以担保物件（住宅及土地）的售价清偿。先确认自己继承的物件是否符合这个结构，是出发点。

四叶不动产株式会社以东京都文京区小日向为据点，承接不动产的出售咨询与中介。关于为结清余债而出售，可从整理进行方式与确认事项开始咨询。

## 以房养老的余债在继承时如何处理？

民法第896条规定，继承人自继承开始时起，承继被继承人财产上的一切权利义务（专属一身者除外）。因此以房养老的余债（借款的清偿义务）原则上由继承人承继。继承的当下，就与担保物件一起承接了清偿义务。

【リ・バース60】是本金于死亡时一次清偿的商品。清偿方式为继承人一次清偿，或以担保物件的售价清偿。要以出售结清，或以自备资金清偿而保留物件，由继承人选择。

| 要确认的事 | 内容 |
| --- | --- |
| 余额 | 本金余额，以及至结清为止产生的利息 |
| 清偿期限 | 死亡后多久内须一次清偿・出售（依机构・契约而异） |
| 清偿责任型 | 无追索型或有追索型 |
| 连带债务 | 配偶等是否为连带债务人；一次清偿时点可能为两人皆亡之时 |

先联络承办金融机构，以书面确认余额、期限与契约型。清偿方式与期限细节依机构・契约而异，须以约款与余额证明确认。余债的计算与税额的确定，非本公司业务。

## 无追索型与有追索型，继承人的负担有何不同？

【リ・バース60】对于以担保物件售价仍无法清偿的余债，有两种处理方式。这正是与一般住宅贷款大为不同之处。

| 型 | 售价无法清偿之余债的处理 |
| --- | --- |
| 无追索型 | 不向继承人请求剩余债务的清偿 |
| 有追索型 | 剩余债务由继承人负清偿义务 |

无追索型下，将担保物件售价充作清偿后，即使有不足，也不向继承人请求。有追索型下，继承人须清偿出售后的不足额。自己继承的契约属哪一型，决定出售后是否还有负担。

属哪一型于契约已定，继承人无法事后重新选择。无追索或有追索的评价、与金融机构交涉的法律事务，属律师领域。本公司承担出售的程序，型的法律评价引介律师、余额确认引介金融机构。

## 为结清余债而出售的流程与期限为何？

以出售结清时，一般出售要加上"余债的一次清偿"与"抵押权的涂销"。担保物件上设有金融机构的抵押权，故基本做法是在交割时以售价清偿余债，并同时涂销。

| 阶段 | 要确认的内容 |
| --- | --- |
| 联络・确认 | 联络机构，确认余额、清偿期限、型与抵押权内容 |
| 估价・中介 | 担保物件的估价、媒介契约、贩售方针 |
| 买卖契约 | 与买方的契约；以一次清偿余债为前提安排交割 |
| 交割・涂销 | 以售价一次清偿余债，办理抵押权涂销登记・继承登记 |
| 结清 | 有剩余归继承人；无追索型即使不足也不被请求余债 |

死亡后，到一次清偿・出售为止给予多少期间，依机构・契约而异。含有无宽限或延缓在内，宜及早向机构确认。抵押权涂销登记与继承登记属司法书士业务，本公司不代理登记。继承登记自2024年4月1日起义务化，须确认期限。

让渡所得（取得费、让渡费用、特例适用）的计算属税理士领域。是否有售出获利，依取得费与特例适用而变。税额的估计向税理士确认。

## 放弃继承与出售结清该选哪个？找谁咨询？（分离受任）

常有人问"有余债是不是该放弃继承"。选择依属无追索或有追索、是否另有负债、是否想保留物件而变。

民法第915条第1项规定，继承的承认・放弃，须自知悉为自己而继承开始时起3个月内为之（期间于一定情形可伸长）。放弃继承后，依民法第939条视为自始不为继承人，含担保物件在内的继承财产一概不能取得。

| 选项 | 适合的情形（一般论） |
| --- | --- |
| 出售结清 | 无追索型且可放手物件；以出售后不留余债为前提 |
| 清偿后保留 | 可以自备资金一次清偿，且想持续持有老家 |
| 放弃继承 | 有追索型且余债大，或另有大额负债；惟亦失去其他财产 |

无追索型且无其他负债时，出售结清原则上不留余债，故可能不必放弃继承。有追索型或另有负债时，则一并考虑放弃。熟虑期间短仅3个月，须及早确认。

| 角色 | 由谁承担 |
| --- | --- |
| 担保物件的估价与出售中介 | 宅地建物交易业（本公司） |
| 抵押权涂销登记・继承登记 | 司法书士 |
| 可否放弃继承・无追索/有追索的法律评价・与金融机构交涉 | 律师 |
| 让渡所得・取得费・税额计算 | 税理士 |
| 余债・清偿方式・期限 | 承办金融机构 |

这些是**各自独立的事业体**，须**分别签约**。本公司承担出售程序，法律评价交给律师、登记交给司法书士、税务交给税理士、余债交给金融机构。本公司不收取介绍费。

## 常见问题

**Q. 继承到以房养老的余债，一定要自己还吗？**
A. 依民法第896条，清偿义务原则上由继承人承继。【リ・バース60】是本金于死亡时一次清偿的商品，可选继承人一次清偿，或以担保物件的售价清偿。无追索型下，充作售价后即使不足也不被请求余债。

**Q. 继承后能重新在无追索型与有追索型之间选吗？**
A. 不能。属哪一型于契约已定。无追索型出售后不留余债，有追索型须由继承人清偿不足额。请向机构确认自己继承的契约属哪一型。型的法律评价属律师领域。

**Q. 放弃继承与出售，哪个划算？**
A. 无追索型且无其他负债时，出售结清不留余债，故可能不必放弃。有追索型或另有负债时，则一并考虑放弃。放弃须于3个月熟虑期间内为之，且会失去其他继承财产。可否请向律师确认。

**Q. 出售的交割与抵押权涂销如何进行？**
A. 担保物件上设有金融机构的抵押权，故基本做法是交割时以售价一次清偿余债，并同时办理抵押权涂销登记。涂销登记与继承登记由司法书士承担。本公司整理估价、中介，以及以余债为前提安排的交割。
