**结论（先说重点）**：自立训练（生活训练・机能训练）的事业所物件，先看三点──①用途地域（自立训练事业所在建筑基准法上属「儿童福祉设施等」，工业专用地域以外大致可建）②能否确保训练・作业室・咨询室・盥洗室・厕所・多目的室（指定障害福祉服务基准〈平成18年厚生劳动省令第171号〉第168条，机能训练为第158条准用第81条）③消防法施行令别表第一的用途区分（自立训练原则为(6)项ハ）与自动火灾报警设备的要否。训练室并无「3㎡×定员」之类的数值面积基准，省令只规定「不妨碍训练的宽度」。签约前先确认用途地域・设备・消防・用途变更的要否・出租人可否，可避免返工。

「租下店面之后」才发现咨询室无法隔间、或因追加消防设备而延后开业──餐饮店或诊所会遇到的返工，在自立训练事业所同样会发生。本文写给为开设自立训练事业所（障害者综合支援法的训练等给付）而在找租赁物件的法人・个人事业主，以及出租该物件的业主，依指定障害福祉服务的事业等人员、设备及运营相关基准（平成18年厚生劳动省令第171号）与建筑基准法・消防法的条文，依序整理签约前可确认的事项。人员配置的常勤换算与社会保险的劳务、指定申请文件的制作、报酬的计算不在本文范围。物件能否满足基准的最终确认，在指定权者（都道府县・市町村）与特定行政厅・消防署的窗口进行。

## 自立训练的事业所物件，与其他障害福祉服务有何不同？

首先要掌握的是，自立训练有**机能训练**（维持・恢复身体机能的训练）与**生活训练**（维持・提升生活能力的训练）两类，两者都是障害者综合支援法第5条第12项所定的**训练等给付**服务。它与就劳移行支援・就劳继续支援A/B・生活介护・放课后等日间照顾・儿童发展支援同属「障害福祉服务」，但**设备・人员基准依类型分别以不同条文规定**，影响物件的要件也不同。

就物件选择而言，自立训练有以下三项特征。

| 观点 | 自立训练（生活训练・机能训练）的影响 |
|---|---|
| 用途地域 | 建筑基准法上属「儿童福祉设施等」，工业专用地域以外大致可建 |
| 训练室面积 | **无数值面积基准**。只规定「不妨碍训练或作业的宽度」（并无通所介护「3㎡×定员」之类的基准） |
| 消防区分 | 原则为消防法施行令别表第一(6)项ハ。主要收容避难困难者的设施为(6)项ロ |

**也就是说，若比照通所介护或团体家屋以「由定员逆推面积」来思考，就会误判。** 自立训练的训练・作业室没有数值基准，相对地需自行设计不妨碍训练内容的宽度。介护事业所一般的用途地域观念，另于内部文章整理。此外，生活训练除日间通所型外尚有住宿型（指定住宿型自立训练），住宿型需追加居室・浴室，设备思路不同，本文主要以日间通所型为前提。事业用物件整体请见[投资・事业用不动产](https://luck428.com/zh/toushi)，事务所与许认可的关系请见[公司设立与办公室选择](https://luck428.com/zh/office)。

## 训练室・咨询室・厕所等，面积与设备的最低基准看哪里？

设备基准的核心，机能训练为**第158条准用的第81条**，生活训练为**第168条**（均为平成18年厚生劳动省令第171号。**2026年11月19日参照**）。两者都要求事业所设置以下设备。

| 设备 | 基准上的定位 | 物件要确认的素地 |
|---|---|---|
| 训练・作业室 | 必置。**不妨碍训练或作业的宽度**，并备训练所需机械器具等 | 无数值基准；足以进行训练内容的宽度与放置器具的区划 |
| 咨询室 | 必置。**须设防止室内谈话外泄的隔间等** | 能否隔为个室或以隔间区划 |
| 盥洗室 | 必置。依利用者特性 | 能否对应轮椅・障害特性的盥洗 |
| 厕所 | 必置。依利用者特性 | 能否无障碍化的厕所 |
| 多目的室 | 必置。其他运营所需设备 | 于无妨碍时可与咨询室兼用 |

**要留意的是，训练・作业室没有「○㎡×定员」之类的数值基准。** 通所介护以「3㎡×利用定员以上」用数字绑定食堂兼机能训练室，但自立训练的训练・作业室只规定「不妨碍训练的宽度」。因此需**由定员・训练课程自行估算所需宽度**，内见时确认有效面积（扣除柱・水路的实测）较为安全。

另一个关键是**咨询室与多目的室的兼用**。第168条第4项（机能训练为准用的第81条第3项）规定，于不妨碍利用者支援时可将咨询室与多目的室兼用。以单一楼层节省区划是可行的，但咨询室以防止谈话外泄的隔间为前提。

又，生活训练若办理**住宿型（指定住宿型自立训练）**，依第168条第3项，除上述外尚需**居室（每室定员1人、扣除收纳设备等后7.43平方米以上）与浴室**。居室7.43平方米是本领域少见的数值基准，若考虑住宿型，宜及早确认物件格局。区划・给排水・无障碍的设计，以及用途变更确认申请的要否判断，属建筑士・设计者的领域。**本公司（不动产公司）协助物件能否满足这些条件的事前调查，以及与出租人的条件交涉。** 设备设计与构造适合的判断本身不由本公司进行。

## 哪个用途地域能开设？建筑基准法上需要用途变更吗？

自立训练事业所在建筑基准法上并非「诊疗所」或「店铺」，而是作为**「儿童福祉设施等」**处理。建筑基准法施行令第19条第1项于「儿童福祉设施等」中明列「障害福祉服务事业（限于生活介护、自立训练、就劳移行支援或就劳继续支援之事业）所使用的设施」，自立训练事业所即属此。用途地域的限制准用建筑基准法别表第二中儿童福祉设施等的处理（**2026年11月19日参照**）。

| 用途地域 | 自立训练事业所（儿童福祉设施等）可否的大致判断 |
|---|---|
| 工业专用地域 | 不可建 |
| 第一种・第二种低层住居专用地域 | 原则可（依规模有面积限制） |
| 上述以外的住居系・商业系・工业地域 | 原则可 |

**亦即，单就用途地域卡关的大致只有工业专用地域，住宅区的低层住专也有开设余地。** 但建筑基准法上的用途判断，会因事业所规模・形态与特定行政厅的运用而变动。**可否的最终确认请于特定行政厅（建筑指导课）的窗口进行。**

另一关键是**用途变更的确认申请**。将原为物贩店铺或事务所的建物改为自立训练事业所（儿童福祉设施等）时，该用途部分的楼地板面积超过200平方米即需确认申请（建筑基准法第6条・第87条）。**该当与否及要否的判断属建筑士的领域**，签约前先行评估可避免返工。市街化调整区域内的物件，尚须叠加都市计划法的开发许可・建筑许可，宜先确认区域区分。

## 消防法的用途区分与洒水・自动火灾报警设备如何确认？

因利用者每日往来，**消防设备是物件选择的关卡**。首先是用途区分。消防法施行令别表第一(6)项ハ(5)明列障害者综合支援法第5条第12项的**自立训练之设施**，故通所型的自立训练事业所原则上区分为**(6)项ハ**（**2026年11月19日参照**）。而主要收容避难困难障害者等的障害者支援设施型，或以避难困难者为主的短期入所・共同生活援助设施，则区分为(6)项ロ。

区分确定后，自动火灾报警设备的要否即可自条文读出（施行令第21条第1项）。

| 自立训练事业所形态 | 消防区分 | 自动火灾报警设备 |
|---|---|---|
| 日间通所型（无入居・住宿） | (6)项ハ | **楼地板面积300㎡以上**需设置（第21条第1项第3号ロ） |
| 住宿型（使利用者入居・住宿） | (6)项ハ | **不论面积**均需设置（第21条第1项第1号ロ） |
| 主要收容避难困难者的形态 | (6)项ロ | 不论面积均需设置 |

**洒水设备・向消防机关通报的火灾报警设备・诱导灯等的要否，取决于区分（ロ或ハ）与楼地板面积・收容人员**，仅凭本文条文无法对个别物件下结论。何种设备需到何种程度的判断与设置，属消防署（预防课）与消防设备业者的领域。签约前先确认消防设备现况与可能追加的设备，可避免开业后的意外工程。

角色分工如下。

| 工作 | 承担者 |
|---|---|
| 物件调查・中介・租赁契约 | 宅地建物交易业者（本公司） |
| 用途变更确认申请的要否判断、构造适合、无障碍・给排水设计 | 建筑士・设计者 |
| 消防用设备设置的要否判断・设置 | 消防署（预防课）・消防设备业者 |
| 指定申请等向官公署提出文件的制作 | 行政书士 |
| 依人员配置的常勤换算・就业规则・社会保险 | 社会保险劳务士 |
| 取得时的所有权移转登记 | 司法书士 |
| 报酬计算・税务 | 税理士（请款经国民健康保险团体联合会） |

## 签约前应在物件上先厘清哪些项目？

将以上整理为签约前的检查清单。

| 确认点 | 观察重点 |
|---|---|
| 用途地域 | 是否为工业专用地域；低层住专则向特定行政厅确认规模限制 |
| 用途变更 | 用途部分超过200㎡是否需确认申请（请教建筑士） |
| 训练・作业室 | 足以进行训练内容的宽度与器具放置处；以实测确认有效面积 |
| 咨询室 | 能否隔间・个室化以防止谈话外泄 |
| 盥洗室・厕所 | 能否依利用者特性无障碍化 |
| 多目的室 | 与咨询室兼用，或另行独立取得 |
| 住宿型的情形 | 能否取得居室（每人7.43㎡以上）与浴室 |
| 消防 | 是否为(6)项ハ；楼地板面积300㎡以上需自动火灾报警设备；向消防署确认追加设备的评估 |
| 出租人可否 | 对福祉事业的出租与内装・设备工事可否、恢复原状的范围 |

人员的常勤换算（机能训练须将看护职员・理学疗法士/作业疗法士/言语听觉士・生活支援员的总数定为利用者数÷6以上等〈第156条〉，生活训练须将生活支援员定为通所÷6＋住宿÷10以上等〈第166条〉）属劳务设计，而非物件本身。本公司将物件（不动产）与申报（行政手续）的论点并陈于同一张桌上确认。

## 该向谁咨询？

物件的调查、中介、买卖・租赁契约，由四叶不动产株式会社（宅地建物交易业 东京都知事(1)第113304号）承办。指定申请等向官公署提出文件的制作，由四叶行政书士事务所承办。用途变更确认申请的要否・构造适合・无障碍设计由建筑士・设计者，消防用设备由消防署・设备业者，依人员配置的常勤换算・就业规则・社会保险由社会保险劳务士，取得时的登记由司法书士，报酬・税务由税理士处理。

**这些均为各自独立的事业体，请分别直接签约。** 本公司・本事务所不收取亦不支付介绍费・送客手续费。登记的司法书士、税务的税理士、劳务的社会保险劳务士，亦请各自直接委托。咨询免费。

## 常见问题

**Q. 自立训练的训练室是由定员逆推面积吗？**
A. 不是。通所介护以「3㎡×利用定员以上」绑定食堂兼机能训练室，但自立训练的训练・作业室没有数值面积基准。指定基准（平成18年厚生劳动省令第171号）只规定「不妨碍训练或作业的宽度」。因此需由定员・训练课程自行估算所需宽度，内见时确认有效面积（扣除柱・水路的实测）较安全。少见的数值基准，是住宿型自立训练的居室每人7.43平方米以上（扣除收纳设备等）。

**Q. 自立训练的事业所在住宅区也能开吗？**
A. 有开设余地。自立训练事业所属建筑基准法施行令第19条第1项的「儿童福祉设施等」（障害福祉服务事业中办理自立训练之事业所使用的设施），用途地域的限制准用儿童福祉设施等的处理。工业专用地域以外大致可建，第一种・第二种低层住居专用地域亦在规模限制下可行。惟用途判断会因事业所规模・形态与特定行政厅运用而变动，可否的最终确认请于特定行政厅（建筑指导课）进行。既有建物用途变更时，用途部分超过200平方米即需确认申请。

**Q. 消防法上自立训练属哪个区分？**
A. 消防法施行令别表第一(6)项ハ(5)明列障害者综合支援法第5条第12项的「自立训练之设施」，故通所型事业所原则为(6)项ハ。自动火灾报警设备，通所型（无入居・住宿）于楼地板面积300㎡以上需设置，住宿型（使利用者入居・住宿）则不论面积均需设置（施行令第21条第1项）。洒水设备・诱导灯等的要否依区分与规模而变，请向消防署（预防课）确认。主要收容避难困难障害者等的形态则区分为(6)项ロ。

**Q. 咨询室与多目的室可以兼用吗？**
A. 可以。指定基准规定，于不妨碍利用者支援时，可将咨询室与多目的室兼用（生活训练为第168条，机能训练为准用的第81条）。惟咨询室以设防止室内谈话外泄的隔间等为前提，盥洗室・厕所须依利用者特性。以单一楼层节省区划虽可行，但咨询的秘密保持与无障碍宜于物件选择阶段先行确认。
