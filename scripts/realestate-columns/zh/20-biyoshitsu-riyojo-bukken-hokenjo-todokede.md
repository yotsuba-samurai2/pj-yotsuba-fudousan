**结论（先说重点）**：美容室・理容所的物件，保健所看的是两点——能否明确区分作业场与等候区，以及洗场・消毒・采光照明换气是否达到基准。此外，与餐饮店、诊所不同，美容院・理发店受建筑基准法的用途地域限制。开设申报要「事先」提出，并须通过构造设备的检查・确认后才能使用。签约前确认用途地域与分区，就能避免返工。

被告知「只剩装修」而承租，到了开设申报阶段，却被保健所要求重做分区。餐饮店、护理事业所会发生的返工，美容室・理容所同样会发生。本文写给在东京要开美容所・理容所的美容师・理容师，以及把物件租给他们的人：签租约前能确认的事，依美容师法・理容师法的条文与厚生劳动省的要领顺序整理。可否的最终确认在特定行政厅与保健所窗口。

## 美容室・理容所的物件，保健所在看什么？

保健所看的是「构造设备」。美容师法（昭和32年法律第163号）第12条规定：「美容所的开设者，须就其美容所的构造设备接受都道府县知事的检查，并在取得该构造设备适于采行第13条措施之确认后，方得使用该美容所。」理容所也一样，理容师法（昭和22年法律第234号）第11条之2将构造设备的检查・确认，定为使用的前提。

也就是说，**装修完成后保健所来查，若分区或设备不足基准，就无法照原样营业。** 这是选物件的起点。

那要满足什么？厚生劳动省的「理容所及美容所之卫生管理要领」（昭和56年6月1日环指第95号）示出了构造设备的思路（**2026年8月24日参照**）。

| 项目 | 要领示出的思路 |
|---|---|
| 分区 | 作业场与等候所须**明确区分**；作业场以隔断与居住室・休息室等区分 |
| 照明 | 作业中作业面的照度**300勒克斯以上为佳**（下限依各都道府县条例） |
| 换气 | 作业场内二氧化碳浓度5,000ppm以下（1,000ppm以下为佳） |
| 洗场 | 采流水装置，并设供热水设备 |
| 消毒 | 备有消毒器具・布片・毛巾等的设备或器材 |
| 收纳 | 接触皮肤的器具能以消毒完成与未消毒区别收纳 |

**要注意，具体数值（作业室的建筑面积、洗场或洗发设备的数量等）由各都道府县以条例定之。** 美容师法第13条・理容师法第12条列出「保持清洁」「消毒设备」「充分采光・照明・换气」等卫生措施，并进一步要求「其他都道府县以条例所定的卫生上必要措施」。**数值因自治体而异。着手时请向管辖的保健所确认。**

## 作业场的面积或洗发台的数量，有全国一致的规定吗？

**没有全国一致的数值。** 面积、洗发设备数量、洗场位置等具体基准，如上所述由各都道府县（设置保健所的市・特别区则为该市・区）以条例定之。所以「隔壁县以这个大小过关」未必能直接套用。

在物件端可先确认的，与其说是条例数值本身，不如说是**能否满足该数值的基础条件**。

| 签约前确认 | 为何有效 |
|---|---|
| 能隔出作业场与等候的格局 | 分区是要领・条例的核心之一；单间房可能无法另辟等候区 |
| 给排水的位置与口径 | 洗场需流水・供热水；洗发台愈多，给排水增设费愈动 |
| 换气设备的有无・增设余地 | 二氧化碳浓度基准以换气担保 |
| 电气容量 | 洗发供热水・吹风机・空调耗容量；增设影响费用与工期 |
| 地板・墙壁的防水与清洁性 | 「常保清洁」的基础；也牵涉恢复原状范围 |

给排水・换气・电气容量的设计是施工业者（设计者）的领域。**本公司（不动产公司）陪伴的是物件能否满足这些条件的前置调查，以及与出租人的条件交涉。** 不做设备设计本身。餐饮店物件会发生相同返工的原因，整理在[〈护理事业所的物件为何找不到〉](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)；租约要读哪里，整理在[〈租赁契约书，该读哪里〉](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 带装修（居抜）与毛坯，要确认的设备差别是什么？

差很多。前承租人若是美容室・理容所的带装修物件，洗场・给排水・换气可能留着。但——**「以前也是美容室，所以没问题」不是保证。**

两个理由。第一，构造设备的检查・确认是每家美容所・理容所各自重新接受（美容师法第12条／理容师法第11条之2），前一家的确认不会承接给新的开设者。第二，条例与运用可能已修正，前一家开设时的基准与现在要求的基准可能不同。

| | 带装修（前为美容室・理容所） | 毛坯 |
|---|---|---|
| 洗场・给排水 | 多半留着（需点检） | 新设；位置与口径从设计起 |
| 换气设备 | 可能沿用 | 新设 |
| 分区（作业场・等候） | 可能沿用旧格局 | 从头设计 |
| 检查・确认 | **重新接受** | 重新接受 |
| 初期费用倾向 | 较易压低 | 较易增加 |

即使是带装修，**交房前点检设备状态、确认是否符合保健所基准**较安全。残置设备的所有・修缮・撤除负担如何在契约中约定，是带装修特有的议题。

## 用途地域或建筑确认会成为问题，是在什么时候？

这是与诊所最大的不同。诊所在建筑基准法的用途限制下所有用途地域都能建，但**美容院・理发店被当作「店铺（服务业店铺）」，受用途地域限制。**

建筑基准法（昭和25年法律第201号）施行令（昭和25年政令第338号）第130条之3第3号，把「理发店、美容院……及其他类似的服务业店铺」列为第一种低层住居专用地域可建的兼用住宅之一。但有条件：**须以建筑总面积的2分之1以上供居住，且店铺部分的建筑面积合计在50㎡以下。** 也就是说，在第一种低层住居专用地域不能作为单独店铺，只限自宅兼用且小规模者。

在第二种低层住居专用地域，依建筑基准法别表第二(ろ)项第二号与施行令第130条之5之2，政令所定的店铺（含理发店・美容院），**建筑面积合计150㎡以内、且不以3楼以上供该用途者**可建。第一种中高层住居专用地域以上，面积限制放宽。

| 用途地域 | 美容院・理发店的处理 |
|---|---|
| 第一种低层住居专用地域 | 仅限兼用住宅（居住占总面积1/2以上・店铺部分50㎡以下） |
| 第二种低层住居专用地域 | 政令所定店铺，150㎡以内、不供3楼以上 |
| 第一种・第二种中高层住居专用地域 | 面积限制放宽，较易建 |
| 住居・准住居・近邻商业・商业・准工业地域 | 可建 |

而且，**把事务所或别业种的店铺改为美容室时，依建筑面积可能需要用途变更的确认申请。** 建筑基准法第87条第1项，在用途变更为同法第6条第1项第1号的特殊建筑物（别表第一(い)栏用途且200㎡超）时准用确认申请；美容院通常不属于该别表第一(い)栏的特殊建筑物。不过，与确认申请要否无关，用途地域限制（第48条）与采光・换气等实体规定仍会适用。**用途地域上的可否与用途变更的要否，签约前可向特定行政厅确认。** 用途地域与容积率如何牵动土地价格，整理在[〈日本的土地价格为何会因「容积率」而改变〉](https://luck428.com/column/yosekiritsu-hosei-tochine)；消防・自治体确认须先于契约的例子，整理在[〈能开民宿的物件条件〉](https://luck428.com/column/minpaku-bukken-joken-kakunin)。

## 开设申报由谁、何时提出？与物件契约的时程如何安排？

美容师法第11条规定，「欲开设美容所者……须将美容所的位置、构造设备……及其他必要事项，**事先**向都道府县知事申报」。理容师法第11条亦同。**「事先」＝开设前**，与餐饮店的营业许可、诊所的开设申报（开设后10日内）顺序不同。

再者，须通过构造设备的检查・确认（美容师法第12条／理容师法第11条之2）后才能使用。因此流程如下。

| 顺序 | 要做的事 | 担当者 |
|---|---|---|
| 1 | 确认用途地域・用途变更要否 | 特定行政厅・宅地建物取引业者 |
| 2 | 前置调查能否满足分区・给排水・换气・电气容量 | 宅地建物取引业者・施工业者 |
| 3 | 租赁契约 | 宅地建物取引业者 |
| 4 | 装修工程（分区・洗场・消毒设备・照明・换气） | 施工业者 |
| 5 | 「事先」提出开设申报 | 开设者（美容师・理容师） |
| 6 | 保健所的进场检查（构造设备）・确认 | 保健所 |
| 7 | 确认后开始使用（营业） | 开设者 |

**物件的契约是手续的前提。** 从业者2人以上的美容所须置管理美容师（美容师法第12条之3），理容所须置管理理容师（理容师法第11条之4）；这是人的要件，与物件分开准备。开设申报等向保健所提出的文件之制作，由四叶行政书士事务所承接。**行政的窗口・样式・条例数值・受理运用会变。着手时请直接查阅管辖保健所的页面。** 事业用物件整体在[投资用・事业用不动产](https://luck428.com/toushi)，事务所与许认可的关系在[公司设立与办公室选择](https://luck428.com/office)。

## 常见问题

**Q. 能在住宅区（第一种低层住居专用地域）开美容室吗？**
A. 原则上不能作为单独店铺开。依施行令第130条之3第3号，理发店・美容院只能作为「兼用住宅」建筑，条件是居住占总面积2分之1以上、店铺部分建筑面积合计50㎡以下。可否因物件而异，请向特定行政厅窗口确认。

**Q. 前身也是美容室的带装修物件，开设申报就会直接通过吗？**
A. 未必。构造设备的检查・确认是每位开设者各自重新接受（美容师法第12条・理容师法第11条之2），前一家的确认不会承接。条例或运用也可能已修正。请于交房前点检残置设备的状态与是否符合现行基准，并向保健所确认。

**Q. 作业场的大小或洗发台的数量，法律上有数值吗？**
A. 没有全国一致的数值。美容师法第13条・理容师法第12条要求「其他都道府县以条例所定的卫生上必要措施」，面积・设备的具体数值由各都道府县（设置保健所的市・特别区则为该市・区）以条例定之。请向管辖的保健所确认。

**Q. 开设申报何时提出？在物件契约之前吗？**
A. 美容师法第11条・理容师法第11条规定「事先」（开设前）申报。且须通过构造设备的检查・确认后才能使用。因此顺序是：物件契约→装修工程→开设申报→保健所检查・确认→开始营业。物件的契约是手续的前提。
