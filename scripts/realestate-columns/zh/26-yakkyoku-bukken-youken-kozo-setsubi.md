**结论（先说重点）**：调剂药局的物件，先起作用的是两点——①用途地域（药局视为「店铺」，与诊所不同，受用途地域限制）②药局等构造设备规则要求的面积约19.8㎡以上、调剂室6.6㎡以上、清洁的分区。医疗大楼或诊所併设，还要看处方笺应对与动线。可否的最终判断在保健所与特定行政厅。签约前确认用途地域与分区的素地，就能避免返工。

以为「诊所就在隔壁，药局当然进得来」而承租，到了开设许可阶段，却被要求重做调剂室面积或分区。餐饮店、诊所物件会发生的返工，调剂药局同样会发生。本文写给在东京要新开设・迁移调剂药局的药剂师・医疗系事业者，以及企划医疗大楼的不动产所有人：签租约前能确认的事，依医药品医疗机器等法（药机法）与药局等构造设备规则的条文顺序整理。可否的最终确认在保健所与特定行政厅窗口。

## 调剂药局的物件，什么用途地域才能开？

这是与诊所最大的不同。诊所在建筑基准法的用途限制下全用途地域都能盖，但**药局视为「店铺（贩卖物品的店铺）」，受用途地域限制。**

建筑基准法（昭和25年法律第201号）以别表第二与第48条，定出各用途地域可盖的建筑物。药局在部分住居系地域难以作为单独店铺兴建，在第一种低层住居专用地域原则上只能作为兼用住宅（延べ面积1/2以上为住居，店铺部分50㎡以下）兴建。在近邻商业・商业・准工业地域则较易兴建。

| 用途地域 | 药局（店铺）的处理概略 |
|---|---|
| 第一种低层住居专用地域 | 不可单独店铺；仅限兼用住宅范围（住居占延べ面积1/2以上・店铺50㎡以下） |
| 第二种低层住居专用地域 | 可作为政令规定一定规模的店铺兴建 |
| 第一种・第二种中高层住居专用地域 | 面积限制放宽，较易兴建 |
| 住居・准住居・近邻商业・商业・准工业地域 | 可兴建 |

**「土地上有诊所，药局当然也进得来」并不成立。** 诊所不受用途限制，但即使在其邻接地或同一栋建物，药局作为店铺仍受用途地域限制。此外，把事务所或别业种的店铺改为药局时，依楼地板面积，可能需要用途变更的确认申请。**用途地域上的可否与用途变更的要否，签约前可在特定行政厅确认。** 诊所物件的确认顺序见[「诊所的物件，签约前要确认什么」](https://luck428.com/column/clinic-bukken-youto-chiiki-kaisetsu-todokede)；用途地域与容积率如何牵动土地价格见[「日本地价为何随『容积率』改变」](https://luck428.com/column/yosekiritsu-hosei-tochine)。

## 药局开设许可的构造设备基准（面积・调剂室・清洁室）要满足什么？

开药局，依药机法（关于确保医药品、医疗机器等品质、有效性及安全性等的法律・昭和35年法律第145号）第4条第1项，须取得所在地都道府县知事（设有保健所的市之市长・特别区之区长）的许可。此许可每6年须更新（同条第4项）。第5条规定，**构造设备不符合厚生劳动省令所定基准时**等，得不予许可。

那「厚生劳动省令所定基准」就是药局等构造设备规则（昭和36年2月1日厚生省令第2号）第1条。直接影响选物件的号如下（**2026年8月28日参照**）。

| 号 | 药局的构造设备基准（摘录） |
|---|---|
| 第一号 | 购买・受让者容易出入，且外观明显可知为药局 |
| 第二号 | 换气充分，且清洁 |
| 第三号 | 与其他药局・店铺、常时居住场所、不洁场所**明确区别** |
| 第四号 | 面积**约19.8㎡以上**，能适切进行药局业务 |
| 第五号 | 具备采光・照明以确保照度（陈列60勒克斯以上・调剂台120勒克斯以上） |
| 第七号 | 具备**冷暗贮藏**设备 |
| 第八号 | 具备**可上锁的贮藏设备** |
| 第十号 | **调剂室6.6㎡以上**，天花板与地板为板张・混凝土或准此者，并采行防止购买者进入的措施 |

也就是说，物件端的起点是**能否确保约19.8㎡以上，并在其中将6.6㎡以上的调剂室，与居住场所、不洁场所明确区分地作出。** 常被问到的「清洁室」，是在宅医疗用作无菌制剂处理（混合高热量输液等）时的**无菌调剂室**。这是仅对进行无菌制剂处理的药局要求的另一基准，须有把室内空气清净度常时保持在ISO14644-1 Class 7以上的设备等。仅一般调剂则不需要，但若预定在宅对应，于物件阶段预留设置空间可免返工。

给排水・空调・电气容量的设计属施工业者（设计者）领域。**本公司（不动产公司）协助调查物件能否满足这些条件，并在与出租人的条件交涉中陪跑。** 不进行设备设计本身。相同构造的返工为何发生见[「护理事业所物件难寻的真正理由」](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)；契约书该读哪里见[「租赁契约书该读哪里」](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 医疗大楼或诊所併设的物件，要注意什么？

医疗大楼集客动线整齐、较易开业，但作为物件有其固有论点。

| 论点 | 为何有影响 |
|---|---|
| 构造设备的区分 | 第三号要求「与其他药局・店铺・居住场所・不洁场所的明确区别」；于图面确认共用部与调剂室・待合的间隔 |
| 面积的确保 | 切出分区会减少有效面积；是否低于19.8㎡・调剂室6.6㎡ |
| 独立性 | 药机法上，药局须与特定医疗机构在经营・机能上独立；动线与引导的作法有时受质疑 |
| 租金与处方笺见込 | 併设诊所的诊疗科与处方倾向会改变库存构成；与租金负担取得平衡 |
| 用途地域・用途变更 | 大楼整体用途，与药局部分用途地域上的可否・用途变更要否 |

尤其**药局与医疗机构的独立性**牵涉物件的作法（出入口・动线・分区），签约前于图面阶段确认保健所的想法较安全。数值与运用因自治体而异。事业用物件整体见[投资用・事业用不动产](https://luck428.com/toushi)，事务所与许认可的关系见[公司设立与办公室选择](https://luck428.com/office)，保健所申报先于契约的例子见[「开美容室・理容所的物件要确认什么」](https://luck428.com/column/biyoshitsu-riyojo-bukken-hokenjo-todokede)。

## 签约前，要向保健所与行政书士确认什么？

药局开设许可，是在构造设备备妥后接受保健所检查才下来。因此流程如下。

| 顺序 | 要做的事 | 承担者 |
|---|---|---|
| 1 | 确认用途地域・用途变更要否 | 特定行政厅・宅地建物取引业者 |
| 2 | 调查能否满足面积・调剂室・分区・给排水・电气容量 | 宅地建物取引业者・施工业者 |
| 3 | 租赁契约 | 宅地建物取引业者 |
| 4 | 装修工程（调剂室・分区・贮藏设备・照明・换气） | 施工业者 |
| 5 | 药局开设许可的申请 | 开设者・行政书士 |
| 6 | 保健所的到场检查（构造设备）・审查 | 保健所 |
| 7 | 许可后开设・开始调剂 | 开设者 |

**物件的契约是手续的前提。** 管理药剂师的配置等人的要件，与物件另行准备。药局开设许可等向保健所・药事窗口提出的书类制作，由四叶行政书士事务所承办。**行政的窗口・样式・自治体的数值・受理的运用会变。着手时点请直接确认管辖保健所的网页。**

## 常见问题

**Q. 能盖诊所的土地，药局当然也能开吗？**
A. 未必。诊所在建筑基准法用途限制下全用途地域都能盖，但药局视为「店铺」，受用途地域限制。第一种低层住居专用地域原则上仅限兼用住宅范围。可否因物件而异，请在特定行政厅窗口确认。

**Q. 调剂药局需要的面积，法律有规定吗？**
A. 药局等构造设备规则第1条规定，药局面积「约19.8㎡以上」、调剂室「6.6㎡以上」。这是全国共通的省令基准。惟照度与设备细部的运用、所需宽度的判断因自治体・物件而有幅度，请向管辖保健所确认。

**Q. 预定对应在宅医疗。物件阶段要先看什么？**
A. 若进行无菌制剂处理（混合高热量输液等），需要无菌调剂室。这是仅对进行无菌制剂处理的药局要求的另一基准，须有把空气清净度常时保持在ISO14644-1 Class 7以上的设备等。仅一般调剂则不需要，但若将来对应，于物件阶段预留设置空间可免返工。

**Q. 药局开设许可由谁何时申请？在物件契约之前吗？**
A. 药局开设许可（药机法第4条第1项）是在构造设备备妥并经保健所检查后才下来。因此顺序为：物件契约→装修工程→许可申请→保健所检查・审查→开设。物件的契约是手续的前提。许可申请书等官公署提出书类的制作由行政书士承办。
