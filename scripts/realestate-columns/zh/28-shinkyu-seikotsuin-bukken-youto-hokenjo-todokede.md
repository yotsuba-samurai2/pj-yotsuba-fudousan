**结论（先说重点）**：针灸院・整骨院（あはき・柔整的施术所）的物件，先发生作用的是两点：①用途地域（施术所与诊所不同，一般被当作「服务业店铺」处理，受用途地域限制）②能否满足施术所的构造设备基准（专用施术室6.6㎡以上・等候室3.3㎡以上・换气・消毒设备）。开设申报是「开设后10日内」由施术者本人向保健所提出，申报文件的制作由行政书士承接。签约前确认用途地域与面积・换气，就能避免返工。

被告知「只剩装修」而承租，真要开业时却发现施术室的面积或换气不足基准。餐饮店、美容室会发生的返工，针灸院・整骨院同样会发生。本文写给在东京要开针灸院・接骨院（整骨院）的施术者，以及把物件租给他们的人：签租约前能确认的事，依あはき法（按摩・指压・针・灸师等相关法律）・柔道整复师法的条文与省令顺序整理。疗养费的处理或施术内容当否等医事判断，本文不予涉入。可否的最终确认在特定行政厅与保健所窗口。

## 针灸院・整骨院能在哪些用途地域开？

先整理前提。针灸院是「针・灸」的施术所（あはき法），整骨院・接骨院是「柔道整复」的施术所（柔道整复师法），连同按摩指压，这些**不是医疗法上的诊所，而是「施术所」**。这是用途地域讨论的起点。

诊所在建筑基准法的用途限制下所有用途地域都能建，但**施术所在建筑基准法别表第二没有固有分类，许多特定行政厅把它当作「服务业店铺」（近似理发店・美容院）而施以用途地域限制来运用。** 在此前提下，住宅区最严格的地域无法作为单独店铺开业。

建筑基准法（昭和25年法律第201号）施行令（昭和25年政令第338号）第130条之3列举第一种低层住居专用地域可建的兼用住宅，条件是**居住占延面积2分之1以上、且店铺等部分的建筑面积合计50㎡以下**。把施术所套用到同条第3号的「理发店、美容院……及其他类似的服务业店铺」的运用下，第一种低层住居专用地域仅限自宅兼用且小规模者。第一种住居地域以上，就较易作为3,000㎡以下的店铺建筑。

| 用途地域 | 施术所（作为店铺处理时）的目安 |
|---|---|
| 第一种・第二种低层住居专用地域 | 原则仅限兼用住宅（居住占延面积1/2以上・店铺部分50㎡以下） |
| 第一种・第二种中高层住居专用地域 | 在面积限制下可（依自治体运用） |
| 第一种・第二种住居地域、准住居地域 | 较易作为3,000㎡以下店铺建筑 |
| 近邻商业・商业・准工业地域 | 可建 |

**但需注意。** 也有自治体把依法设立的施术所当作「准诊所」处理，在低层住居专用地域也认可，**处理因特定行政厅而异。** 若是租赁大楼，还须看整栋的用途。**可否因物件而异，请于签约前向特定行政厅窗口确认。** 用途地域与容积率如何牵动土地价格，整理在[〈日本的土地价格为何会因「容积率」而改变〉](https://luck428.com/column/yosekiritsu-hosei-tochine)。

## 作为施术所向保健所申报的构造设备基准是什么？

保健所（都道府县知事等）看的是「构造设备」。あはき法第9条之5第1项规定「施术所的构造设备，须符合厚生劳动省令所定的基准」，同条第2项要求卫生上必要的措施。柔道整复师法第20条也是相同架构。**装修完成后若不足基准，就无法照原样使用。** 这是选物件的起点。

具体数值在省令。あはき法施行规则（平成2年厚生省令第19号）第25条、柔道整复师法施行规则（平成2年厚生省令第20号）第18条，以几乎相同的内容要求下列各点（**2026年8月29日参照**）。

| 项目 | 省令要求的基准 |
|---|---|
| 施术室 | **6.6㎡以上**的专用施术室 |
| 等候室 | **3.3㎡以上**的等候室 |
| 换气 | 施术室须有相当于室面积**7分之1以上**的部分可对外气开放（有可替代的适当换气装置则不在此限） |
| 消毒 | 备有消毒施术所用器具・手指等的设备 |

此外，あはき法施行规则第26条・柔道整复师法施行规则第19条要求的卫生措施为**常保清洁、充分采光・照明・换气**。

在物件端可先确认的，是能否满足这些数值的基础条件。

| 签约前确认 | 为何有效 |
|---|---|
| 能配置6.6㎡以上施术室与3.3㎡以上等候室的面积・格局 | 面积是省令的核心；单间房可能无法分出施术室与等候 |
| 窗户的大小・位置，或换气设备 | 施术室需相当于面积1/7以上的对外开放或换气装置 |
| 给排水的位置 | 手指・器具的消毒需要洗手处 |
| 电气容量 | 物疗机器・空调・供热水耗容量；增设影响费用与工期 |
| 地板・墙壁的清洁性 | 「常保清洁」的基础；也牵涉恢复原状范围 |

换气・给排水・电气容量的设计是施工业者（设计者）的领域。**本公司（不动产公司）伴走的是物件能否满足这些条件的前置调查，以及与出租人的条件交涉。** 不做设备设计本身。相同返工会发生的原因，整理在[〈护理事业所的物件为何找不到〉](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)；租约要读哪里，整理在[〈租赁契约书，该读哪里〉](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 居抜（带装修）与毛坯，申报重做的差别在哪？

差很多。前承租人若是针灸院・整骨院的居抜物件，施术室的分区・洗手处・换气可能留着。但——**「以前也是施术所，所以没问题」不是保证。**

两个理由。第一，施术所的申报是逐一施术所提出（あはき法第9条之2／柔道整复师法第19条），前一家的申报不会承接给新的开设者。第二，あはき（按摩・针・灸）与柔道整复**根据法不同**，两者都做就各需申报。若前一家只做针・灸，而你要并设整骨院，柔整的构造设备・申报就要另外办。

| | 居抜（前为施术所） | 毛坯 |
|---|---|---|
| 施术室・等候的分区 | 可能沿用旧格局 | 从头设计 |
| 洗手处・给排水 | 多半留着（需点检） | 新设；位置从设计起 |
| 换气设备 | 可能沿用 | 新设 |
| 申报 | **重新提出**（あはき・柔整各别） | 重新提出 |
| 初期费用倾向 | 较易压低 | 较易增加 |

即使是居抜，**交房前点检施术室的面积与换气是否符合现行省令基准**较安全。残置设备的所有・修缮・撤除负担如何在契约中约定，是居抜特有的议题。

## 开设申报由谁、何时提出？装修动工前要确认什么？

这里与美容室・理容所相反。美容所・理容所的开设申报是「事先（开设前）」，但**施术所的申报是「开设后10日内」。** あはき法第9条之2规定「开设施术所者，须于开设后10日内，将开设场所、从事业务的施术者姓名及其他省令所定事项，向施术所所在地的都道府县知事申报」，柔道整复师法第19条亦同（设置保健所的市・特别区则向该市长・区长申报）。休止・废止时，自该日起10日内申报。

虽说是「开设后」，构造设备在开设时点须符合省令基准，故实务流程如下。

| 顺序 | 要做的事 | 担当者 |
|---|---|---|
| 1 | 确认用途地域・用途变更要否 | 特定行政厅・宅地建物取引业者 |
| 2 | 前置调查施术室・等候的面积、换气、给排水能否满足 | 宅地建物取引业者・施工业者 |
| 3 | 租赁契约 | 宅地建物取引业者 |
| 4 | 装修工程（分区・施术室・等候・换气・消毒设备） | 施工业者 |
| 5 | 开设 → **10日内**申报施术所 | 开设者（施术者本人） |
| 6 | 保健所的确认・进场检查 | 保健所 |

另外，即使把事务所或别业种店铺改为施术所，**施术所通常不属于建筑基准法别表第一(い)栏的特殊建筑物，故用途变更的确认申请原则上不需要。** 但与确认申请要否无关，用途地域限制（建筑基准法第48条）与采光・换气等实体规定仍会适用。消防方面，针灸院・整骨院一般被当作消防法施行令别表第一的(15)项（非特定用途的防火对象物）处理，所需消防用设备会因整栋的租户构成・楼层数・建筑面积而变。**用途地域・用途变更・消防，签约前可向特定行政厅・消防署确认。**

## 物件契约容易卡关的点在哪？

施术所的申报（开设后10日内）等向保健所提出的文件之制作，由四叶行政书士事务所承接。**申报本身由施术者本人为之**，行政书士不是代为提出，而是协助制作文件的定位。牵涉用途变更・建筑确认时的设计由建筑士处理，装修的给排水・换气设计由施工业者处理。**行政的窗口・样式・条例数值・受理运用会变。着手时请直接查阅管辖保健所与特定行政厅的页面。** 事业用物件整体在[投资用・事业用不动产](https://luck428.com/toushi)，事务所与许认可的关系在[公司设立与办公室选择](https://luck428.com/office)。

物件的调查、中介、买卖・租赁契约，由四叶不动产株式会社（宅地建物取引业 东京都知事(1)第113304号）承接。施术所的申报等向官公署提出的文件之制作，由四叶行政书士事务所承接。

**这两者（不动产公司・行政书士事务所）是各自独立的事业体。请各自直接签约。** 本公司・本事务所既不收取也不支付介绍费・转介费。登记请找司法书士、税务请找税理士、劳务请找社会保险劳务士，各自直接委托。咨询免费。

## 常见问题

**Q. 针灸院或整骨院能在住宅区（第一种低层住居专用地域）开吗？**
A. 在把施术所比照服务业店铺处理的一般运用下，原则上不能作为单独店铺开。依建筑基准法施行令第130条之3，可作为兼用住宅（居住占延面积1/2以上・店铺部分50㎡以下）建筑。另有自治体把依法设立的施术所比照诊所处理，故处理不一。请就个别物件向特定行政厅确认。

**Q. 施术室或等候室的大小，法律上有数值吗？**
A. 有。あはき法施行规则第25条・柔道整复师法施行规则第18条要求6.6㎡以上的专用施术室、3.3㎡以上的等候室、施术室面积7分之1以上可对外气开放（或换气装置）、消毒设备。这是全国共通的省令基准。

**Q. 前身也是整骨院的居抜物件，申报就会直接通过吗？**
A. 不会直接承接。申报是逐一施术所重新提出（あはき法第9条之2・柔道整复师法第19条）。あはき（按摩・针・灸）与柔道整复根据法不同，两者都做就各需申报。请于交房前点检残置设备是否符合现行省令基准，并向保健所确认。

**Q. 开设申报何时提出？在物件契约之前吗？**
A. 施术所的申报是「开设后10日内」（あはき法第9条之2・柔道整复师法第19条），与美容所・理容所的「事先（开设前）」顺序相反。但构造设备在开设时点须符合省令基准，故依物件契约→装修工程→开设→10日内申报的顺序准备。
