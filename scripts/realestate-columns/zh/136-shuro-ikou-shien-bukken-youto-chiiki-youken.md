**先讲重点**：能不能当就业转衔支援事业所的物件，由三点决定：建筑基准法上的用途是否通过、是否能以所需面积确保指定基准省令要求的训练・作业室与相谈室、消防法上的分类与设备是否足够。就业转衔支援（就労移行支援）是"障害者综合支援法"的训练等给付，标准利用期间原则2年。以"为就业而训练与实习的空间"为前提，正是它与就労继续支援A型・B型设计起点不同之处。物件的用途地域・用途变更要否・消防现况的确认由本公司负责，指定申请交给行政书士、用途变更的确认申请交给建筑士、职员的劳动条件与社会保险交给社会保险劳务士。各为独立事业体，分别签约。

写给想开设就业转衔支援事业所的事业者，以及想将物件出租作此用途的业主，依建筑基准法、指定基准省令、消防法的顺序，整理"什么样的物件能用"。本文为一般性资讯提供，指定能否通过、是否符合设备基准的最终判断，属指定权者（都道府县・政令市等）・建筑士・所管消防的领域。

四叶不动产株式会社以东京都文京区小日向为据点，承接事业用物件的租赁中介与用途地域・用途变更的事前确认。关于就业转衔支援的物件，欢迎从决定签约前的阶段与我们洽谈。

## 就业转衔支援事业所要求的物件基本条件是什么？

就业转衔支援，是为希望进入一般就业的身心障碍者，提供就业所需知识与能力的训练、职场实习、求职活动支援等的服务。它是依"障害者综合支援法"（平成17年法律第123号）的指定障害福祉服务之一，定位为训练等给付，标准利用期间原则2年（障害者综合支援法施行规则第6条之9；即使准予更新，也以1次・1年为目安，使用按摩指压・针・灸等养成设施者为3年或5年）。

这个"2年内送往一般就业"的前提，使它与工资型的B型、雇用契约型的A型（皆为就労继续支援）在设计起点上分道。就业转衔支援以训练室、模拟职场的实习空间、求职与面谈用的相谈室为中心。选物件时主要有三点。

| 确认的轴 | 物件要看的重点 | 根据 |
| --- | --- | --- |
| 建筑基准法上的用途 | 该用途地域能否建、是否需用途变更的确认申请 | 建筑基准法第48条・别表第二、第87条 |
| 指定基准省令的设备 | 能否确保训练・作业室、相谈室、洗面所、便所 | 平成18年厚生劳动省令第171号 第178条・第179条 |
| 消防法上的分类与设备 | 防火对象物的分类，以及能否配备所需消防用设备 | 消防法施行令别表第一(6)项 |

就労继续支援A型・B型的物件思路，整理于[就労继续支援A型的物件如何确认用途地域与消防（日文）](https://luck428.com/zh/column/shuro-keizoku-shien-a-bukken-youto-chiiki)与[就労继续支援B型的物件在用途地域与消防哪里会卡（日文）](https://luck428.com/zh/column/shuro-keizoku-shien-b-bukken-youto-chiiki-shobo)。本文处理以训练与实习为中心的就业转衔支援所特有的物件条件。

## 用途地域与建筑基准法上的"用途"如何确认？

就业转衔支援事业所属建筑基准法施行令第19条第1项的"儿童福祉设施等"。该项除儿童福祉设施外，将老人福祉设施、障害者支援设施，以及生活介护・自立训练・就业转衔支援・就労继续支援等障害福祉服务事业所用设施，定位为"儿童福祉设施等"；就业转衔支援即以此用途处理。

此用途能建于哪些用途地域，由建筑基准法第48条・别表第二及施行令第130条各条按地域逐一决定。将原为事务所・店铺・住宅使用的既有建物改为就业转衔支援事业所时，用途变更的确认申请要否，是选物件的分水岭。

| 确认项目 | 根据・重点 |
| --- | --- |
| 用途该当 | 属施行令第19条第1项的"儿童福祉设施等"（明载就业转衔支援） |
| 用途地域能否 | 依建筑基准法第48条・别表第二、施行令第130条各条逐件确认 |
| 用途变更的确认申请 | 变更部分的楼地板面积超过200㎡者，使用前须确认申请（建筑基准法第6条第1项・第87条） |
| 采光・避难 | 作为儿童福祉设施等，采光与避难相关规定较严 |

由事务所或宿舍（员工宿舍等）改用时，楼地板面积超过200㎡者，使用前须确认申请。即使在200㎡以下，采光・避难・消防各规定的符合仍另行被要求。用途地域符合与确认申请要否的最终判断属特定行政厅・建筑士的领域，本公司整理现况用途与面积，确认申请转介建筑士。

## 无障碍、训练室、相谈室的面积与设备要到什么程度？

指定基准省令（指定障害福祉服务事业等的人员、设备及营运相关基准・平成18年厚生劳动省令第171号）就就业转衔支援的设备基准（第178条・第179条），要求设置训练・作业室、相谈室、洗面所、便所。训练・作业室须为"训练或作业不受妨碍的宽度"，相谈室须设间隔等以防谈话外泄。

要注意的是，训练・作业室的每位利用者面积，并未以全国一律的数值订定。民间解说所示的"每人◯㎡"是实务・建议的目安，并非省令本体的数值。此处不作断定，标为【未验证】，以向所管指定权者的条例・手引与事前协议确认为前提。

| 设备 | 要求 | 面积・数值的处理 |
| --- | --- | --- |
| 训练・作业室 | 训练或作业不受妨碍的宽度、必要的机械器具 | 无全国一律的㎡/人基准；目安为指定权者的运用【未验证】 |
| 相谈室 | 以间隔等使谈话不外泄 | ― |
| 洗面所・便所 | 因应利用者的特性 | ― |
| 多目的室等 | 无妨碍时可与相谈室兼用 | ― |
| 无障碍 | 高低差・通道宽度・扶手等可能依条例加码 | 以条例・手引确认 |

无障碍的水准，可能因利用者的障碍特性与当地条例而加码。需要几㎡・何种规格的最终可否由指定权者・建筑士判断，故押下物件前须与指定权者事前协议。指定申请的手续由行政书士以另约承接。

## 消防法上的设备与防火对象物的分类如何？

消防法施行令别表第一(6)项区分社会福祉设施等：因身体上・精神上理由自行避难困难者为主要入所・利用对象者属(6)项ロ，其余属(6)项ハ。采通所、且不以避难困难者为主要对象的就业转衔支援，原则属(6)项ハ；但会综合服务内容、利用者的避难困难性、收受体制，由所管消防逐件判断。

| 确认项目 | 重点 |
| --- | --- |
| 防火对象物分类 | 通所的就业转衔支援原则(6)项ハ；以避难困难者为主要对象则可能(6)项ロ |
| 消防用设备 | 依分类・面积・楼层：自动火灾报知设备・灭火器・引导灯等；因分类而变 |
| 判断主体 | 由所管消防（消防署・预防课）逐件判断；物件确定前先洽询 |
| 既有建物 | 所需设备能否后装（配线・区划）是选定的分水岭 |

所需消防用设备的细节与工程费，因机器构成与建物而异，此处同样不作断定、标为【未验证】，以消防设备士・建筑士・所管消防的确认为前提。本公司将既设消防用设备与分类的见込整理为物件资讯，设计・工程・确认申请转介各专家。

## 常见问题

**Q. 就业转衔支援能与就労继续支援A型・B型用同一物件开设吗？**
A. 建筑基准法上的用途三者皆为"儿童福祉设施等"，故用途地域・用途变更・采光・避难・消防的框架重叠。但就业转衔支援标准利用期间原则2年，以朝向一般就业的训练室・实习空间・相谈室为中心，这是设计起点上的不同。设备该当请向指定权者、用途判断请向建筑士确认。

**Q. 想把事务所或员工宿舍改为就业转衔支援事业所，需要确认申请吗？**
A. 变更部分的楼地板面积超过200㎡者，使用前须用途变更的确认申请（建筑基准法第6条第1项・第87条）。即使在200㎡以下，采光・避难・消防各规定的符合仍另行被要求。该判断与设计属建筑士・特定行政厅的领域，本公司整理现况用途与面积并转介建筑士。

**Q. 训练・作业室每位利用者需要几㎡？**
A. 指定基准省令（平成18年厚生劳动省令第171号第178条）只说"训练或作业不受妨碍的宽度"，未订全国一律的每人㎡数。民间解说所示数值为实务・建议的目安，非省令数值（本文作【未验证】处理）。所需面积因定员、训练内容、指定权者的条例而变，请于物件确定前以事前协议确认。

**Q. 职员的劳动条件与社会保险，能向不动产公司咨询吗？**
A. 不行。职业指导员・就业支援员等职员的工时・就业规则・社会保险设计属社会保险劳务士的领域，本公司不处理。物件与用途的确认由本公司、指定申请交给行政书士、劳务交给社会保险劳务士，各为独立事业体、分别签约。
