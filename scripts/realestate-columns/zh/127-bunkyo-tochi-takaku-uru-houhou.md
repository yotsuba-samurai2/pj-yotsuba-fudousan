**结论（先说重点）**：想让文京区的土地卖得更好，起点是用资料说明建筑条件与土地现况，再选择适合潜在买方的出售方式。除了挂牌价，也要比较扣除费用与税负后的净到手金额、完成交付所需时间，以及卖方承担的条件。

准备出售文京区土地时，屋主往往先想到「附近挂牌价每坪多少」，或「拆成空地是不是能卖得更高」。但即使位于同一町内，临路方式、可建筑的规模、与邻地的高低差不同，买方的评估也可能不同。

小日向、小石川或千石，单凭地名无法决定出售策略。打算使用这笔土地的人，需要确认哪些资料才能做出购买决定？由卖方先准备这些材料，才能为价格协商建立基础。

## 要看哪个金额，才知道这次出售的结果是否合适？

首先要厘清卖方的优先顺序。能花多少时间争取理想价格？换屋或取得资金的日期是否已经确定？能否预先支付拆除、测量等费用？如果这些条件不清楚，即使收到购买申请，也不容易取舍。

| 比较项目 | 出售前先厘清的事情 |
| --- | --- |
| 净到手金额 | 售价扣除卖方负担的费用与税金后，希望保留多少 |
| 时程 | 除了签约日期，最晚何时必须收取价款并完成交付 |
| 卖方负担的条件 | 旧房、现场遗留物、测量等事项，由谁负担到什么范围 |

若仍有房贷或其他借款，还要另外确认清偿后实际留在手上的资金。估价并不保证最终成交价，也不保证净到手金额。

关于估价与实际购买出价的差别，请参阅[估价与实际购买出价](https://luck428.com/zh/column/satei-gaku-to-fuda-chigai)。本文着重于厘清估价前提后，屋主如何选择准备工作与出售条件。

## 文京区的土地，要准备哪些资料才能让买方理解其价值？

只有面积与到车站的距离，买方仍无法规划购买后的用途。应将「已确认的事项」与「还需要进一步调查的事项」分开说明。没有资料的部分，也不宜用推测填补。

| 确认事项 | 可提供给买方的判断材料 |
| --- | --- |
| 可建筑用途与规模 | 用途地域、建蔽率与容积率、高度及防火等指定；依具体计划由建筑师检讨 |
| 道路与出入 | 道路种类、宽度、临路长度、是否须退缩；如属私道，另确认权利、通行与挖掘相关资料 |
| 面积与界址 | 登记面积、测量图、界址确认文件是否存在及其制作时间 |
| 高低差与挡土墙 | 土地与道路、邻地的位置关系；挡土墙图面、施工历程及调查纪录 |
| 居住环境 | 到车站的路线与坡道、周围建物、生活设施，以及核对后的学区资料 |

文京区有台地、谷地与坡道。实际步行查看，往往能发现地图无法呈现的条件。不过，不能因此概括认为高地一定安全、低地一定难卖，仍须分别确认地形与个别基地条件。

不能只依都市计划指定的容积率，就断定「一定能盖出这么大的建物」。道路、基地形状及各种限制也会影响建筑可能性，需要建筑师检讨并向区政府相关窗口确认。详见[容积率与土地价格的关系](https://luck428.com/zh/column/yosekiritsu-hosei-tochine)。

对重视学区的买方，应提供核对到所在地「番、号」的信息，而非只有学校名称。文京区部分学区范围还会依旧町名区分。不能只因学校就在附近就认定指定校，也不能保证入学或较高的出售价格。

界址、道路及高低差的个别调查方式，请分别参阅[界址与确定测量](https://luck428.com/zh/column/souzoku-fudosan-kyoukai-kakutei-sokuryo-baikyaku)、[道路退缩、面积与价格（日文参考）](https://luck428.com/column/setback-42jo-2ko-doro-tochi-baikyaku-menseki)、[文京区的坡地与挡土墙确认事项（日文参考）](https://luck428.com/column/gake-yoheki-tochi-baikyaku-bunkyo)。

## 买方不同，应该着重说明哪些信息？

想自建住宅的个人，与兴建住宅后出售的公司，需要的判断材料不同。除了卖方的希望，也要依买方购买后想实现的用途，整理土地信息。

| 潜在买方 | 主要评估内容 | 卖方可先整理的信息 |
| --- | --- | --- |
| 想自建住宅的个人 | 理想生活方式，以及土地加上建筑费的总预算 | 居住环境、基地与道路资料、建筑评估所需条件、交付时程 |
| 住宅开发或收购业者 | 建筑、施工与转售的计划及成本 | 建筑条件、形状与高低差、旧房及挡土墙资料、买卖双方的费用负担 |
| 邻地所有权人 | 扩大基地后的用途与便利性 | 界址与权利关系、出售范围，以及出售整笔土地时的比较 |

这是规划出售方式时的买方分类，并不表示目前已经有购买意愿者，也不保证一定会出现竞价。

狭小地或不规则土地，有时可考虑与邻地合并使用。但邻地所有权人也有自己的预算与计划，不宜认定「因为是邻居就一定愿意出高价」，而应与对外出售的方式比较。接洽的顺序、能透露多少出售信息，也要与卖方讨论后决定。

各种出口的比较，可参阅[文京区狭小地的出售与活用（日文参考）](https://luck428.com/column/kyosho-tochi-15tsubo-uru-ikasu-bunkyo)及[出售给邻地所有权人与增购邻地（日文参考）](https://luck428.com/column/rinchi-baikyaku-kaimashi-nanari-tochi-deguchi)。

阅读行情资料时，要对照土地条件与时间。附近的挂牌价、公示地价、相续税路线价、实际交易价格，目的与意义各不相同。国土交通省「不动产信息资料库」的土地交易价格资料，也包含以问卷为基础的信息，并非完整涵盖每一笔交易。不能直接将附近案例的每坪单价套用到自己的土地。

## 支付拆除或测量费用前，要先比较什么？

投入准备费用，不代表售价一定会等额增加。应先厘清支出的目的，以及如何反映在出售条件上。

有旧房的土地，可以比较「保留旧房交付」与「由卖方拆除后交付」两种方案。除了预期售价，也要把拆除费、工期、发现地下状况时如何处理，以及税负影响一起纳入。买方也可能希望使用现有建物，因此不必在咨询出售前，就先以拆除为前提。

拆除住宅可能影响土地固定资产税、都市计划税的住宅用地特例。改建等情况也有相关处理方式，税额并非一律相同。决定拆除时间前，请向都税事务所或税理士确认。让渡所得税的特例，也会因自用住宅或继承空屋等情况而有不同的检讨内容。

测量亦同。应依现有图面、界址确认状况、买方计划与买卖条件，向土地家屋调查士确认还需要哪些工作。有旧测量图，不等于这次交易所需的界址确认已经完备。

收到购买申请后，不宜只看出价，还要将以下条件对齐比较。

| 比较项目 | 应确认的内容 |
| --- | --- |
| 费用负担 | 中介费、测量、拆除、现场遗留物清运等；报价单应确认含税金额、工作范围与另计费用 |
| 成交前提 | 买方融资、建筑计划评估等申请附带条件 |
| 交付 | 收取价款的日期、能否保留旧房或物品，以及是否来得及完成准备 |
| 瑕疵等事项的处理 | 土地与建物现况掌握到何种程度、如何说明，以及契约负担如何约定 |

不建议隐瞒已知瑕疵或与邻地之间的悬而未决事项。应整理事实，反映在说明与契约条件中。涉及责任范围等个别法律判断时，请向律师确认。

## 开始出售后，如何检讨价格与销售方式？

开始销售前，先约定挂牌价依据、潜在买方、可公开的信息，以及检视进度的时间，较容易根据询问情形思考下一步。

广泛公开出售信息，与希望不让邻居知道而低调出售，可公开的范围不同。如希望限制公开，应一并理解对接触买方范围与出售时程的影响，再与卖方决定销售方针。

询问较少时，原因不一定只有价格。还应检查资料是否不足、说明是否足以让买方判断，以及交付条件是否符合预想买方的需求。整理询问、现场查看与未继续洽谈的原因后，再检讨价格、资料、销售对象或契约条件应如何调整。

## 常见问题

**Q. 可以比附近土地更高的每坪单价出售吗？**
A. 设定挂牌价时，除了附近的广告价格，也要确认形状、道路、建筑条件与时间等差异。整理希望价格、依据与可投入的出售期间，并先约定如何依询问情形调整方针。

**Q. 不清楚土地界址，也可以咨询吗？**
A. 可以。先确认登记、图面与界址确认文件有哪些，再区分需要向土地家屋调查士请教的事项。不必在咨询前，就由卖方自行发包所有测量工作。

**Q. 先拆掉旧房，会比较容易卖高价吗？**
A. 会依土地及建物现况、买方用途、拆除费用与税务处理而不同。应先比较保留旧房与拆除两种方案的净到手金额及交付时间，再做决定。

**Q. 还没决定出售，可以只估价或咨询吗？**
A. 可以。请先告知已知的所在地、面积、旧房有无及希望时程。四葉不動産会整理出售方式与确认事项，说明后续步骤。咨询与是否正式委托中介，可以分开考虑。
