**结论（先说重点）**：能做营业仓库的物件，首先取决于你是「受他人寄托而保管货物的仓库业」，还是「单纯出租仓库空间的不动产租赁」。经营仓库业需要国土交通大臣的登录（仓库业法第3条），而仓库的设施・设备符合各仓库种类的基准，是登录的要件（第6条第1项第4款、仓库业法施行规则）。物件被看的地方，除了使用权原与相关法令适合之外，还有防水・防湿・遮热・耐火・防火区划・防犯・防鼠等。目标种类（一类～冷藏等）不同，条件也会改变。

「想把没在用的建物变成出租仓库」「想把物件租给仓库用途」这类咨询越来越多。但挂上「仓库」的招牌，并不等于就是营业仓库。营业仓库是仓库业法下的登录制度，建物的构造要达到各种类的基准，才会被登录。本文写给想开展出租仓库・保管业务的事业者，以及想租给仓库用途的物件所有人，依仓库业法・同施行规则的条文与国土交通省的资料，逐项整理签约前能确认的事。数值与可否的最终确认，由登录窗口的地方运输局进行。

## 所谓「营业仓库」与一般出租仓库，到底差在哪？

分歧点在于「是否为受他人寄托而保管货物的营业」。

仓库业法（昭和31年法律第121号）把受寄托而在仓库保管货物的营业定为「仓库业」，并规定想经营者必须取得国土交通大臣的登录（第3条）。这里的关键是「受寄托而保管」。若从货主收受货物、对其保管负责并取得对价，即属仓库业，需要登录。

相对地，若只是把建物这个不动产的空间直接出租，由承租人以自己的管理摆放自己的物品，那是不动产的租赁，并非仓库业。把自家商品由自家保管的自家仓库，同样不是仓库业。

| 情形 | 仓库业的登录 | 主要负责 |
|---|---|---|
| 受货主寄托而保管货物并取得对价 | 需要（仓库业法第3条） | 仓库业者 |
| 出租仓库建物、承租人摆放自己的物品 | 不需要（不动产租赁） | 宅地建物取引业者（本公司） |
| 把自家商品由自家保管（自家仓库） | 不需要 | — |

**「租仓库来自己用」与「作为营业仓库替他人保管货物」，在法律上完全不同。** 目标是哪一种，物件要求的条件与必要的手续都会改变。先确定自己属于哪一种，是出发点。判断有疑问时，请向登录窗口的地方运输局确认。

## 能通过仓库业登录的物件，建物的哪里会被看？

会看设施・设备是否符合各仓库种类、由国土交通省令所定的基准。

仓库业法第6条第1项第4款规定，仓库的设施或设备依仓库种类而未符合国土交通省令所定基准时，即拒绝登录。该基准在仓库业法施行规则（昭和31年运输省令第59号），作为所有仓库共通的基准（第3条之3），要求对该仓库有使用权原，且符合建筑基准法・都市计划法等相关法令。

在此之上，最基本的一类仓库的设施设备基准（施行规则第3条之4），大致由下列项目构成。

| 被看的地方 | 基准的思考 |
|---|---|
| 使用权原・相关法令适合 | 所有或租赁的权原；符合建筑基准法・都市计划法等（用途地域・用途变更・检查完成证的议题） |
| 轴组・外墙・地板强度 | 能承受保管货物与装卸的构造 |
| 防水性能 | 防止雨水从屋顶・外墙・开口部渗入 |
| 防湿性能 | 防止地面来的湿气 |
| 遮热性能 | 屋顶・外墙的隔热 |
| 耐火・防火 | 耐火・准耐火构造、防火区划 |
| 灭火器等 | 灭火器及其他灭火设备 |
| 防犯 | 照明・上锁等防盗 |
| 防鼠 | 防止老鼠等侵入的措施 |

**符合建筑基准法・都市计划法，被放在这套基准的入口。** 用途地域能否盖仓库、既存建物是否需要用途变更的确认申请、有没有检查完成证，都在选物件的阶段先发生作用。把没有检查完成证的中古物件转为其他用途时的议题，整理在[没有检查完成证的中古物件能否转作其他用途](https://luck428.com/column/kensazumisho-nashi-bukken-fukushi-youto-henko)。适合与否本身，由建筑士・特定行政厅判断。

## 从一类到冷藏仓库，种类不同物件条件如何变？

仓库种类不同，所要求的设施设备基准的条文就会改变。

仓库业法施行规则第3条把仓库种类分为一类・二类・三类・野积・水面・贮藏槽・危险品・冷藏等。以保管什么决定种类，各种类都有各自的基准。

| 种类 | 主要保管货物例 | 基准的条 | 物件条件的特征 |
|---|---|---|---|
| 一类仓库 | 一般货物（范围广） | 施行规则第3条之4 | 防水・防湿・遮热・耐火・防火・防犯等最为综合 |
| 二类仓库 | 比一类受限（不易燃物品等） | 第3条之5 | 一类基准去掉耐火性能的构成 |
| 三类仓库 | 不易受湿气・温度影响的物品 | 第3条之6 | 一类基准的一部（不需防湿・遮热等） |
| 野积仓库 | 适合户外保管的物品（原木・矿物等） | 第3条之7 | 周围的防护设施・防犯设备・防止掉落 |
| 贮藏槽仓库 | 散装・液状（谷物・液体等） | 第3条之9 | 筒仓・储槽的密闭构造・强度 |
| 危险品仓库 | 消防法・高压气体等的危险物 | 第3条之10 | 工作物型・土地型的分别基准（其他法令也重叠） |
| 冷藏仓库 | 摄氏10度以下保管的物品 | 第3条之11 | 定温维持・温度计・防热等温度管理 |

**「同一栋建物，也会因为保管什么而使能通过的种类不同」是重点。** 一般货物为一类，摄氏10度以下保管的物品为冷藏仓库，危险物为危险品仓库，目标种类不同，物件要求的性能也不同。危险品仓库还会重叠消防法・高压气体保安法等其他法令的规制，因此从选物件的阶段就要看其适合。先决定要做哪一种，再去对物件，可减少反复。

## 登录前可以先进行物件契约吗？顺序该怎么做？

**先确认登录的可能性，再确定物件比较安全。** 若先押下不符设施设备基准的物件，恐怕改修费暴增，或无法登录而闲置。实务上，下列顺序较稳。

| 顺序 | 要做什么 | 主要负责 |
|---|---|---|
| 1 | 决定目标仓库种类与保管货物 | 事业者 |
| 2 | 下调候选物件的用途地域・用途变更・检查完成证・构造 | 宅地建物取引业者（本公司）・建筑士 |
| 3 | 确认对设施设备基准的适合可能性 | 建筑士・向地方运输局事前咨商 |
| 4 | 租赁・买卖的条件交涉与签约（改修可否特约等） | 宅地建物取引业者（本公司） |
| 5 | 仓库业登录的申请 | 行政书士 |
| 6 | 若有增改建，建物表题・变更登记 | 土地家屋调查士・司法书士 |

若以租赁借仓库，重点是把出租人是否同意改修与设备设置、恢复原状的范围到哪里，写进契约。租赁契约该读哪里，整理在[租赁契约书，该读哪里](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。**本公司（不动产公司）陪跑物件是否可能符合仓库业基准的下调，以及取得・租赁的条件交涉。** 对设施设备基准的适合与否本身，由建筑士・地方运输局判断，登录申请由行政书士承担。事业用物件整体请见[投资用・事业用不动产](https://luck428.com/toushi)，事务所与许认可的关系请见[公司设立与办公室选择](https://luck428.com/office)。运送业的营业所・车库物件条件，另整理在[要开运送业，营业所与车库的物件该看哪里选](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

## 谁该找谁做什么（物件＝不动产／登录＝行政书士／登记＝司法书士）？

角色是分开的。仓库牵涉的专家多，一开始先做好分工就不会迷路。

| 要做的事 | 负责 |
|---|---|
| 物件的调查・取得・租赁仲介与契约 | 四叶不动产株式会社（宅地建物取引业） |
| 仓库业登录的申请书类制作・提出支援 | 行政书士 |
| 设施设备基准的适合设计・用途变更的确认申请 | 建筑士 |
| 建物的表题登记・增改建后的变更登记 | 土地家屋调查士・司法书士 |
| 租金・保证金・折旧等税务 | 税理士 |

物件的调查、取得・租赁的仲介、买卖・租赁的契约，由四叶不动产株式会社（宅地建物取引业 东京都知事(1)第113304号）承接。仓库业登录等向官公署提出的书类制作，由四叶行政书士事务所承接。**这两者（不动产公司・行政书士事务所）是各自独立的事业体。请分别直接与各自签约。** 本公司与本事务所，既不收取也不支付介绍费・转介费。设施设备基准的适合设计与用途变更请找建筑士，建物的表题・变更登记请找土地家屋调查士・司法书士，税务请找税理士，各自直接委托。咨询免费。

## 常见问题

**Q. 只是租仓库摆自己的库存，也需要仓库业的登录吗？**
A. 不需要。把自家货物由自家保管的自家仓库，或出租仓库这个不动产、由承租人摆放自己物品的情形，一般不属仓库业（受他人寄托而保管的营业），故不需仓库业法第3条的登录。反之，若受货主寄托而保管并取得对价，就需要登录。判断有疑问时，请向地方运输局确认。

**Q. 能把中古仓库租来做营业仓库吗？**
A. 有可能。但前提是该仓库除了使用权原・相关法令适合外，还能符合目标种类的设施设备基准（防水・防湿・遮热・耐火・防火区划・防犯・防鼠等）。既存建物中，用途地域・用途变更确认申请的要否・检查完成证・构造会先发生作用。适合与否请向建筑士与地方运输局确认。

**Q. 常温的一般货物与冷冻品，物件条件会不同吗？**
A. 会不同。一般货物是一类仓库（施行规则第3条之4），摄氏10度以下保管的物品是冷藏仓库（第3条之11），冷藏仓库还加上定温维持・温度计・防热等温度管理。以保管什么决定目标种类，物件要求的性能也会改变，因此先决定种类再去对物件较实务。

**Q. 仓库业的登录申请能委托不动产公司吗？**
A. 不能。向官公署提出的登录申请书类制作是行政书士的业务，由四叶行政书士事务所承接。物件的调查・仲介・契约由四叶不动产株式会社承接。设施设备基准的适合设计与用途变更确认申请由建筑士承担。皆为各自独立的事业体，请分别直接签约。
