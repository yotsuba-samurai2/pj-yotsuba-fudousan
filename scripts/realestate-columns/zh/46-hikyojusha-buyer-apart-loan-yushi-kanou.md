**先讲结论：**住在海外的华人圈（中国、台湾）非居住者购买日本收益物件时，日本国内金融机构的套房贷款、Proper Loan，多在借款时要求日本国内的住所（住民登录）、永住资格，或日本国内的连带保证人，海外在住的本人单独能用的很有限。能否贷款、条件如何，是各金融机构依其审查所作的最终判断，本公司无法断定“能贷”或“不能贷”。因此实务上现金交割是主轴，从海外汇款的入账时点反推交割日是要点。融资审查的可否交各金融机构，外汇管理、汇款交往来银行，预扣、确定申报与纳税管理人的申报交税理士、税务署，在留资格交行政书士，登记交司法书士，这些皆以各自独立的事业体、分别签约为前提。本公司（四叶不动产株式会社）只限于物件的调查、居间、买卖合同的信息提供。

本文写给想买日本一栋、区分收益物件的中国大陆、台湾非居住者投资人，以及在当地支援该投资的资产顾问（专业层）。融资的最终判断交各金融机构，汇款、外汇管理与税务交往来银行、税理士，在留与纳税管理人的申报交税理士、税务署，在留资格的申请交行政书士。本公司只限于物件取得实务的信息提供，这些皆以各自独立的事业体、分别签约为前提。

## 非居住者能在日本的金融机构办不动产投资贷款吗？

不能一律说“能”或“不能”。**各金融机构的要件不同，可否是其审查的最终判断。**

一般而言，日本国内金融机构的套房贷款、Proper Loan，多在借款时要求下列之一。海外在住、在日本无住所且无法满足这些的非居住者本人，能单独借到的机构很少。

| 金融机构常要求的要件 | 对海外在住、单独行动的非居住者本人 |
|---|---|
| 日本国内的住所（住民登录）、在留资格 | 无住民登录，难以满足 |
| 永住资格或长期的在留实绩 | 非居住者本人多半没有 |
| 国内的稳定收入、确定申报实绩 | 无国内所得则难以提示 |
| 住在日本的连带保证人 | 能否备妥，决定可否 |

另一方面，也有在日本设立法人（资产管理公司），以该法人与国内董事、保证检讨融资的路径，或使用本国金融机构的日本业务等路径。惟这些同样视各行审查而定，条件也逐年变动。**本公司不断定特定金融机构名称或“能借的商品”。**可否请务必自行向各金融机构确认。法人持有与个人持有的分水岭，整理在[收益物件用法人持有或个人持有](https://luck428.com/column/hikyojusha-shisan-kanri-hojin-shuueki-bukken)。

## 若融资困难，现金交割的步骤如何？

在非居住者的交易中，现金交割（不使用融资的一次付清）是主轴。步骤如下。

1. 签署买付、买卖合同。签约时支付定金（定金的性质，日本与本国不同）
2. 买卖合同时，宅地建物交易业者进行**交易时确认**（本人确认）
3. 交割日，同时进行尾款支付与所有权转移登记（司法书士）
4. 交割同时取得钥匙、文件的交付

现金交割没有融资审查，手续推进较快。惟**自海外汇入购买资金时，入账前的时间左右交割时程**（见下节）。定金、贷款特约、合同不符等合同条款容易误解之处，整理在[买卖合同容易绊倒的条款](https://luck428.com/column/baibai-keiyaku-teppukin-loan-tokuyaku-chugokugo-buyer)。

## 自海外汇入购买资金，交割时程会如何改变？

海外汇款与国内账户间转账不同，**入账前可能需数日以上**。主因如下。

| 汇款耗时的原因 | 对交割的影响 |
|---|---|
| 汇款银行、收款银行的合规确认（资金来源确认等） | 入账延迟则可能赶不上交割日 |
| 外币兑换、汇率确定 | 对日元计价交割额的所需金额会变动 |
| 本国侧的汇款金额、次数管制（各国不同） | 无法一次汇出，可能分批 |
| 中转银行的经由 | 入账日难以预估 |

因此，**从交割日反推、预留余裕地开始汇款**是要点。若入账赶不上交割日，会有交割延迟，甚至合同解除、定金损失的风险。汇款可否、所需日数、上限，属往来银行与本国管制的问题，本公司从交割时程调整这一不动产侧协助。外汇管理、汇款本身的判断属往来银行、税理士的领域。

## 非居住者该备妥的本人确认、在留、纳税管理人文件有哪些？

在非居住者的交易中，须在本国备妥替代日本住民票、印鉴证明的文件。

首先，宅地建物交易业者是犯罪收益转移防止法上的**特定事业者**，于签署买卖合同时，负有**交易时确认**（本人特定事项、交易目的、实际控制人等的确认）的义务（犯罪收益转移防止法第4条）。就非居住者本人，除护照等本人确认文件外，还需证明本国住所的文件。

在登记场面，替代日本印鉴证明，一般使用本国公证机关等核发的**签名（Sign）证明、住所证明**。取得这些需时，因此及早准备是要点。登记申请的代理由司法书士承办。

在税务上，自日本不动产取得租金的非居住者需**确定申报**，在日本无住所、居所者要办理申报等，须指定并申报**纳税管理人**（国税通则法第117条）。纳税管理人是否需要资格、公司能否担任，整理在[纳税管理人需要资格吗](https://luck428.com/column/nozei-kanrinin-shikaku-hojin)。

| 场面 | 常需的文件、手续 | 承办者 |
|---|---|---|
| 买卖合同（交易时确认） | 护照等、本国住所证明、交易目的确认 | 宅地建物交易业者（本公司） |
| 所有权转移登记 | 本国公证的签名证明、住所证明 | 司法书士 |
| 租金的确定申报 | 纳税管理人的申报（国税通则法第117条） | 税理士、税务署 |
| 在日本居住并经营事业 | 在留资格的申请 | 行政书士 |

## 融资审查、汇款、税务，各该找谁咨询？

非居住者购买收益物件，多位专家的领域交叠。角色分工如下。

| 咨询内容 | 承办者 |
|---|---|
| 融资的可否、条件、审查 | 各金融机构 |
| 海外汇款、外币兑换、汇款上限 | 往来银行（本国侧、日本侧） |
| 租金的预扣、确定申报、纳税管理人、外币相关税务 | 税理士、税务署 |
| 外为法上的不动产取得报告 | 本人、居住者的代理人（见下） |
| 在留资格、向政府机关提出的书面 | 行政书士 |
| 所有权转移登记 | 司法书士 |
| 物件的调查、居间、买卖合同 | 宅地建物交易业者（本公司） |

租金收入的税务上，承租人若是法人或事业目的，其支付的租金原则上预扣20.42％（所得税法第212条第1项、第213条第1项；承租人若是为自己、亲属居住而承租的个人，依施行令第328条不预扣）。实务流程请见[非居住者的房租如何被预扣](https://luck428.com/column/hikyojusha-yachin-gensen-2042)。将来，向非居住者买物件的买方，原则上须就转让对价预扣10.21％（所得税法第161条第1项第5号等）。这些税额的判断属税理士领域。

外为法上，非居住者取得日本国内不动产（或其相关权利）时，原则上须于取得后20日内，经日本银行向财务大臣提出“本邦不动产或其相关权利之取得报告书”。依令和8年（2026年）4月1日施行的报告省令改正，取得日在同日以后者，原则上不论取得目的皆为报告对象，并于报告事项新增交易相对人（居住者、非居住者之别）、取得目的、不动产编号。适用除外的最新范围，请以财务省、日本银行的案内确认。外为法报告的全貌，整理在[外为法的不动产取得报告](https://luck428.com/column/hikyojusha-fudosan-shutoku-gaitameho-houkoku)。

**这种分担，不是由某一家全部承接的形式。**各自以独立的事业体、分别签约。本公司、本事务所不收取也不支付介绍费、送客手续费。本公司只承办物件的调查、居间、买卖合同这一不动产侧，融资可否、汇款、税务，一律请向各金融机构、往来银行、税理士确认后推进。事业用、投资用物件整体，整理在[投资用・商用不动产](https://luck428.com/toushi)。

## 常见问题

**Q. 住在海外，能在日本的银行办收益物件贷款吗？**
A. 能办的机构有限。日本国内金融机构的套房贷款、Proper Loan，多要求日本国内的住所（住民登录）、永住资格、国内的连带保证人，海外在住的非居住者本人单独难以满足。可否、条件是各金融机构依其审查的最终判断，本公司无法断定，请务必向各金融机构确认。

**Q. 用现金买时，交割上最该注意的是什么？**
A. 海外汇款的入账时点。自海外汇款因合规确认、中转银行经由而入账耗时，若赶不上交割日，会有交割延迟、合同解除、定金损失的风险。请从交割日反推、预留余裕地开始汇款。汇款可否、上限、所需日数，属往来银行与本国管制的问题。

**Q. 非居住者买物件，需要外为法的报告吗？**
A. 原则上需要。非居住者取得日本不动产等时，须于取得后20日内经日本银行向财务大臣提出报告书。依令和8年（2026年）4月1日施行的报告省令改正，取得日在同日以后者，原则上不论取得目的皆为报告对象。适用除外的最新范围，请以财务省、日本银行的案内确认。另外，是否为“非居住者”，是以住所而非国籍判断。

**Q. 租金与出售会课什么税？**
A. 租金收入作为不动产所得需确定申报，承租人若是法人、事业目的，租金原则上预扣20.42％（所得税法第212条、第213条）。将来，向非居住者买物件的买方，原则上有就转让对价预扣10.21％的义务（所得税法第161条第1项第5号等）。在日本无住所者也需办理纳税管理人的申报（国税通则法第117条）。税额的判断，请向税理士确认。
