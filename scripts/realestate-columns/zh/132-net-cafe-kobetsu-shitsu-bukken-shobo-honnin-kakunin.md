**先讲重点**：复合咖啡（网咖、漫画喫茶）的物件，重点在于用途地域是否允许店舗用途，以及个室区划能否作为消防法施行令别表第一(2)项ニ的设施，装设自动火灾报知设备等。在东京，须于开业的10天前向公安委员会提出网络端末利用营业的申报。物件的适配在不动产面处理，申报文件的制作则分开交给行政书士。

想新开设网咖、漫画喫茶（复合咖啡）时，常会犹豫"这个物件做得出个室吗""消防会要求到什么程度""东京的申报何时、由谁提出"。想把空店面、空楼层租给复合咖啡用途的业主，也会想知道什么样的物件才招得到租客。

复合咖啡的物件，会同时牵涉建筑面（用途地域、楼地板面积）、消防面（个室区划的防火与避难），以及许可面（东京的网络端末利用营业申报）。若先签了物件才发现"个室的消防设备不足""用途不符"，开业准备就会停摆。先把不动产面与许可面分开确认才稳妥。

## 网咖的物件在用途地域与楼地板面积上受到多少限制？

网咖、漫画喫茶在建筑基准法的用途上，一般比照"店舗（经营服务业的店舗）"来看。不过，在个室中让顾客使用游兴设备的形态，有时会被认为接近"游技场"或"兴行场"，究竟属于哪种用途，取决于建物的构造与特定行政厅的判断。不要先认定"这个地域一定能开"，而要逐件确认用途地域与用途分类。

| 要确认的事 | 物件面要看的点 |
| --- | --- |
| 用途地域 | 是否为可兴建店舗、游技场类用途的地域；第一种低层住居专用地域等住居专用系限制较强 |
| 既有用途 | 从原用途（办公、零售等）变更是否需要用途变更的确认申请（变更为200㎡以上的特殊建筑物等会分出要否） |
| 楼地板面积 | 个室的数量与走道、柜台、调理空间是否容纳得下 |
| 楼层与位置 | 地下层、无窗层、上层会让避难与消防条件变重 |

是否需要用途变更的确认申请，取决于建筑基准法第87条与特殊建筑物用途变更的相关规定（如超过200㎡的情形）。用途地域的判断与可否兴建是建筑士、特定行政厅的领域。本公司通过租赁中介与重要事项说明，于签约前整理物件的用途地域、既有用途与面积。

若复合咖啡并设餐饮，餐饮店的排气与区划也会成为论点。深夜营业店舗的物件选择被决定到什么程度，可参考[在毛坯（skeleton）物件开餐饮店时排气与防火的思考（日文）](https://luck428.com/column/inshokuten-skeleton-bukken-haiki-grease)。

## 个室、隔间区划在消防法令上要符合哪些防火与避难条件？

复合咖啡的关键在于个室、隔间区划。消防法施行令别表第一(2)项ニ规定"在个室（含类似设施）中，让顾客使用卡拉OK包厢或其他游兴用设备或物品，提供此役务的营业店舗"，网咖、漫画喫茶依施行规则被归入此一对象。因为是让顾客滞留于个室的形态，火灾时避难延误被看得较重。

| 要确认的事 | 内容 |
| --- | --- |
| 自动火灾报知设备 | (2)项ニ不论总楼地板面积均须设置（平成20年10月1日施行的修正已撤除面积要件） |
| 诱导灯、避难路径 | 个室的配置能否确保避难走道宽度与到出口的距离 |
| 内装限制 | 个室的墙壁、天花板的装修是否符合内装限制 |
| 防火对象物使用开始申报 | 使用开始前，依各自治体的火灾预防条例向消防署申报（东京为使用开始的7天前） |

(2)项ニ的设施，即使规模小也须装设自动火灾报知设备，这点与一般零售店、办公室大不相同。若在既有建物后加个室，能否事后补上报知设备、诱导灯与区划，就成为物件选择的分水岭。消防用设备的设计、设置与向消防署申报是消防设备士、特定行政厅的领域。本公司于签约前确认物件现况（既设报知设备、楼层、是否无窗层）。

同样牵涉个室、隔音、消防的业态，[卡拉OK包厢物件在用途地域、消防、隔音上的确认点（日文）](https://luck428.com/column/karaoke-box-tenpo-bukken-youto-shoubou-soon)的整理，对思考个室区划也有参考价值。

## 东京的网络端末利用营业（身份确认条例）申报由谁、何时提出？

在东京，"网络端末利用营业的规制相关条例"（平成22年7月1日施行）规制设置个室等、让顾客以通信端末机器使用网络的营业。只要设有一部分个室的复合咖啡，即属于此"网络端末利用营业"。

| 项目 | 内容 |
| --- | --- |
| 申报时期 | 于开业的10天前逐店申报（条例第3条） |
| 申报对象 | 经由管辖店舗所在地的警察署（生活安全课），向东京都公安委员会 |
| 身份确认 | 要求顾客出示身份确认文件、确认本人特定事项的义务（条例第4条） |
| 记录保存 | 本人确认记录、通信端末机器特定记录的制作与保存义务（自最后一次提供役务之日起3年） |
| 变更申报 | 申报事项有变更时，自变更日起10天内 |

身份确认与记录保存，是为防止匿名利用犯罪的条例核心义务。申报书（别记样式第1号）要记载营业时间，以及本人确认记录、通信端末机器特定记录的制作与保存方法，个人营业附住民票誊本，法人营业附章程与登记事项证明书等。

这些申报文件的制作、附件的整备支援是行政书士的业务。本公司（宅地建物取引业）不代理申报。在不动产面，整理物件是否为可设置条例所称"个室等"的构造，以及申报所需平面图的物件资讯基础。另外，东京以外之地，条例有无与内容各异，请向开业地的公安委员会、警察署直接确认。

## 深夜营业或个室规格是否触及风营法、特定游兴的界线在哪？

复合咖啡常营业到深夜，因此有人担心"是不是需要风营法的许可"。一般的网咖、漫画喫茶，通常不属于一面让顾客饮食、一面提供游兴的"特定游兴饮食店营业"，也不属于伴随接待的"风俗营业"，多半以网络端末利用营业的申报即足。

不过，界线会随个室中提供什么而变。例如在个室提供性服务，就会产生店舗型性风俗特殊营业的问题；提供酒类并于深夜让人游兴，就会出现特定游兴饮食店营业（风营法）的许可论点。究竟属于哪种营业类型，最终的法律判断是律师与警察（公安委员会）的领域。本公司与行政书士都无法确定营业类型。

物件面能做的，是先把设想的营业形态（有无深夜营业、是否提供餐饮与酒类、个室规格）固定下来，再确认其是否与建物用途、消防、条例相容。牵涉游技业态的物件要件，[游戏中心（风营法5号）物件在用途与面积上的确认点（日文）](https://luck428.com/column/game-center-fuei-5go-bukken-youto-menseki)的整理，对思考区划与许可的关系也有参考价值。

## 从看房到签约、申报，物件面最常卡在哪？（分离受任）

复合咖啡的开业，物件、建筑、消防、条例申报分属不同事业体。顺序一旦弄错，就会发生签了的物件装不下个室消防设备、用途变更过不了等情形。

| 角色 | 由谁负责 |
| --- | --- |
| 物件调查、租赁中介、重要事项说明 | 宅地建物取引业（本公司） |
| 用途地域、用途变更的确认申请、内装设计 | 建筑士、特定行政厅 |
| 消防用设备的设计、设置与向消防署申报 | 消防设备士、特定行政厅 |
| 网络端末利用营业申报文件的制作 | 行政书士 |
| 营业类型（风营法该当性）的法律判断、纠纷 | 律师 |

实务上，较清楚的顺序是：先在不动产面确认用途地域与既有用途（用途变更的要否），再在消防面看能否为个室区划装入自动火灾报知设备与避难路径，然后才进入条例的申报。

这些是**各自独立的事业体**，以**分别签约**为前提。本公司负责物件的不动产面，用途变更与消防设备设计交给建筑士、消防设备士，条例申报文件交给行政书士，营业类型的判断交给律师。本公司不收取介绍费。

## 常见问题

**Q. 办公用的空楼层可以直接改成网咖吗？**
A. 先确认是否需要用途变更的确认申请（如变更为200㎡以上的特殊建筑物），以及能否为个室区划装入自动火灾报知设备与避难路径。办公维持原样往往不符合消防或避难条件，内装与设备的整备是前提。用途变更的可否是建筑士、特定行政厅的领域，消防设备是消防设备士的领域。

**Q. 东京的网络端末利用营业申报，何时、由谁提出？**
A. 在东京，须于开业的10天前逐店，经由管辖所在地的警察署（生活安全课），向东京都公安委员会申报（条例第3条）。申报文件的制作支援是行政书士的业务，本公司不代理。在不动产面，整理物件是否为可设置条例所称"个室等"的构造。

**Q. 有个室，就一定要装自动火灾报知设备吗？**
A. 属于消防法施行令别表第一(2)项ニ的店舗（卡拉OK包厢、网咖等个室型），不论总楼地板面积均须装设自动火灾报知设备（平成20年10月1日施行的修正已撤除面积要件）。若在既有建物后加个室，能否装设设备就成为分水岭。设计与设置是消防设备士的领域。

**Q. 营业到深夜就需要风营法的许可吗？**
A. 一般的网咖、漫画喫茶通常不属于特定游兴饮食店营业或风俗营业，多半以网络端末利用营业的申报即足。但若提供酒类并于深夜让人游兴、或在个室提供性服务等，就会出现其他规制的论点。营业类型的最终判断是律师与公安委员会的领域。
