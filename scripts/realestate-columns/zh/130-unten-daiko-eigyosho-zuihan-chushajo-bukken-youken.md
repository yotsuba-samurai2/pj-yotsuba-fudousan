**先讲重点**：代驾业的"营业所"是认定申请书上所填的"主要营业所"，因此要选办公用途符合用途地域与租约使用目的的物件。随伴用汽车的保管场所（车库），须依车库法在营业本据位置约直线2公里内确保。先在不动产面把物件的用途适配与车库确保妥当，向公安委员会的认定申请再分开交给行政书士。

想开设汽车代驾（运转代行）业时，常会犹豫"是不是任何物件都能当营业所""随伴的车的停车场可以离多远"。代驾是取得都道府县公安委员会认定后经营的工作，申请书要填主要营业所的所在地，也须先确保随伴用汽车的保管场所。

有人先签了物件，后来才发现营业所用途或车库距离不符要件，认定准备因此卡住。物件能否通过认定，分成不动产面（用途地域、租约、车库确保）与许可面（认定要件、申请）来确认，最为稳妥。

四叶不动产株式会社以东京都文京区小日向为据点，承接事业用物件的调查与租赁中介。对于要当营业所与随伴车保管场所的物件，可从签约前能确认的事项开始咨询。

## 代驾的"营业所"能用的物件条件是什么？

代驾业的根据法是"汽车代驾业业务适正化相关法律"（代驾业法／运转代行业法，平成13年法律第57号，最终修正令和2年法律第42号）。该法第2条将代驾业定义为：代替他人驾驶汽车提供劳务的营业，且须同时符合——主要在夜间对受提供酒类的醉客提供劳务、让该人乘车、以常态使用随伴于被代驾汽车（代行运转自动车）的汽车（随伴用自动车）——各款。

该法第4条规定，经营代驾业须取得都道府县公安委员会的认定。申请一般经由管辖主要营业所所在地的警察署（交通课）提出。也就是说，营业所即认定申请书上所填的事业据点。

| 要确认的事 | 物件面要看的点 |
| --- | --- |
| 用途 | 建物能否作为办公室（营业所）使用；仅限住居的物件可能不符使用目的 |
| 使用目的 | 租约的使用目的能否纳入"代驾业的营业所"；出租人同意的范围 |
| 标示 | 能否挂招牌、公司名（建物规约、出租人许可） |
| 联络体制 | 能否设置派车、受理用的电话与设备；深夜运作的业态是否获邻里理解 |

代驾业法并未就营业所订定细致的构造基准。因此物件面先起作用的，是用途地域是否允许办公用途、是否符合租约使用目的这些不动产基本。认定要件与欠格事由本身的判断，属行政书士与公安委员会的领域。

认定要件（第3条欠格事由、损害赔偿措施、安全驾驶管理者等）与申请流程，在行政书士侧的[代驾业认定、营业所与随伴汽车的要件（日文）](https://luck428.com/legal/column/unten-daiko-nintei-eigyosho-zuihan-jidosha-yoken)说明。本文仅限于寻找能通过该认定之物件的不动产面。

## 随伴用汽车的保管场所（车库）可以离多远？

随伴用汽车是随伴于驾驶客人车辆的员工、并载其返回的车。既然是汽车，就受"汽车保管场所确保等相关法律"（车库法，昭和37年法律第145号）规范。

车库法第3条课予保有者于道路以外确保保管场所的义务，要件委由政令定之。施行令要求，保管场所与营业本据位置间的直线距离不得超过约2公里等。对代驾而言，即须在营业所（营业本据）直线2公里内确保随伴车的车库。

| 要确认的事 | 物件面要看的点 |
| --- | --- |
| 距离 | 营业所到车库的直线距离是否在2公里内 |
| 使用承诺 | 承租月租停车场时，能否取得出租人的保管场所使用承诺证明书 |
| 车位数 | 对照随伴车台数，车位是否足够；增车的余地 |
| 夜间运作 | 深夜出入与待命对邻里的音、光影响 |

保管场所若为承租而非自有，须有出租人的保管场所使用承诺证明书。签约前要确认能否取得作为车库出租的承诺。保管场所证明（车库证明）申请书类的制作与代办是行政书士的业务，本公司不代理申请，而是整理确保车库这一不动产面的程序。

此与货运业的营业所、车库物件要件框架不同。寻找货运据点的思路，请参考[货运业营业所与车库物件的要件（日文）](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

## 用途地域与租约上要注意什么？

即使营业所与车库各自符合要件，也可能因物件立地与契约条件而卡住。代驾属深夜运作的业态，连同与邻里的关系一起确认。

| 要确认的事 | 内容 |
| --- | --- |
| 用途地域 | 该地域能否盖办公用途；住居系地域可能对规模或用途有限制 |
| 使用目的 | 租约使用目的是否含营业所、车库；有无禁止目的外使用的条款 |
| 原状回复 | 设置招牌、划设车位时，退租时的处理 |
| 邻里 | 邻里对深夜派车、出入的理解；音、光与路上待命 |

用途地域的判断与建筑可否属建筑师与特定行政厅的领域。别断定"这个地域一定能当办公室"，要逐件确认用途地域与建物状况。若在使用目的不符的情况下签约，可能在认定准备阶段才发现物件不能当营业所。租赁中介与重要事项说明由本公司进行，签约前整理使用目的与出租人同意范围。

一如深夜的餐饮、娱乐系业态，对邻里的影响是从选址阶段就要看的课题。阅读物件、用途地域与邻里应对的思路，也可参考[事业用物件的用途地域读法（日文）](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)。

## 认定申请与物件契约，该先进行哪一个？（分离受任）

开代驾时，物件、车库、保险与申请分属不同事业体。顺序弄错，可能签了的物件不能用，或保险来不及。

| 角色 | 由谁承担 |
| --- | --- |
| 营业所、车库物件的调查与租赁中介 | 宅地建物交易业（本公司） |
| 认定申请、保管场所证明（车库证明）书类制作 | 行政书士 |
| 损害赔偿措施（保险） | 保险公司 |
| 法人设立、登记 | 司法书士 |
| 纠纷、法律评价 | 律师 |

实务上较清楚的顺序，是先在不动产面把营业所的用途适配与随伴车车库（直线2公里内）整理妥当，再把认定申请交给行政书士。损害赔偿措施涉及认定要件（代驾业法第3条），故与保险公司的契约也并行确认。

这些是**各自独立的事业体**，须**分别签约**。本公司承担物件与车库的不动产面，认定与车库证明的申请交给行政书士、保险交给保险公司，分开介绍。本公司不收取介绍费。另外，让客人搭乘随伴用汽车运送，涉及旅客运送许可的课题，须向运输局与行政书士确认。

## 常见问题

**Q. 能把自家一间房当代驾的营业所吗？**
A. 仅限住居的物件，可能因租约使用目的或用途地域限制而不能当办公室。即使自有，也须确认建物规约与用途地域。签约前，我们会整理该物件能否作为认定申请书上所填的主要营业所。

**Q. 随伴用汽车的车库可以离营业所很远吗？**
A. 车库法施行令要求保管场所与营业本据位置的直线距离不得超过约2公里。请在营业所直线2公里内确保车库。承租月租停车场时，要确认能否取得出租人的保管场所使用承诺证明书。

**Q. 担心签了物件后认定下不来。顺序该怎么做？**
A. 较清楚的顺序，是先在不动产面把营业所的用途适配与随伴车车库整理妥当，认定申请再分开交给行政书士。损害赔偿措施（保险）也涉及认定要件，故并行确认。物件、车库、申请、保险都与不同事业体分别签约。

**Q. 车库证明的申请也能委托不动产公司吗？**
A. 保管场所证明（车库证明）申请书类的制作与代办是行政书士的业务，本公司不代理申请。本公司承担要当车库之物件的调查与租赁中介，申请则引介行政书士。向出租人取得保管场所使用承诺证明书，作为租赁条件整理。
