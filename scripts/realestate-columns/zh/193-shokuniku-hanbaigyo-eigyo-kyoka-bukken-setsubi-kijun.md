**先讲结论：** 精肉店或烧肉用食肉批发等食肉销售业，是食品卫生法上需要「许可」的业种（施行令第35条第3款），物件必须符合处理室・冷藏设备・给排水・不渗透性地板与腰墙等设施基准。是否符合最终由管辖保健所判断，并非由不动产中介决定许可与否。

本文写给为开设精肉店・烧肉用食肉批发・清真（halal）食肉店等而寻找店铺或作业场物件的事业者，以便在购买・承租前确认物件是否符合设施基准，依食品卫生法（昭和22年法律第233号）・同法施行令（昭和28年政令第229号）・同法施行规则（昭和23年厚生省令第23号）的条文整理。四叶不动产株式会社（宅地建物交易业）负责物件调查・中介・重要事项说明（由宅地建物交易士进行），以及物件是否可能符合设施基准的初步查看。本公司不处理许可申请或设施基准的最终判断，仅止于整理资讯。从不动产角度检视餐饮店排水的做法请见[餐饮店毛坯（skeleton）物件与排水・油脂截留器](https://luck428.com/zh/column/inshokuten-skeleton-bukken-haiki-grease)，含调理的食品营业许可要件请见[餐车（kitchen car）的备料场所物件与营业许可要件](https://luck428.com/zh/column/kitchen-car-shikomi-basho-bukken-eigyo-kyoka-youken)。事业用物件咨询请见[投资・事业用不动产咨询](https://luck428.com/zh/toushi)。

## 食肉销售业为何需要「许可」而非申报？

2021年（令和3年）6月1日修正后的食品卫生法全面施行，重新整编了营业许可制度与营业申报制度。对公众卫生影响显著、由政令所定的营业，其设施由都道府县以条例订定基准（食品卫生法第54条），欲经营该营业者须取得都道府县知事的许可（同法第55条第1项）。列举这些「政令所定营业」的即是食品卫生法施行令第35条，目前为32种业种属许可制。食肉销售业即明定于其第3款的许可业种。

不过，该款排除「专以容器包装状态进货食肉并原状销售的营业」。若仅进货已包装的食肉、不做分切或分装而原状销售，则以申报（同法第57条）即可，而非许可。像精肉店或烧肉用食肉批发那样，在店头或作业场将块肉分切・切片・分装的业态，因伴随处理而需要许可。许可附有不少于5年的有效期间（同法第55条第3项），若有违反食品卫生法等情事而构成消极资格者，可能无法取得许可（同条第2项）。在寻找物件的阶段先厘清自己的业态属许可或申报，便能看清设施投资的概况。

| 业态例 | 食品卫生法上的定位 | 依据 |
|---|---|---|
| 将块肉分切・分装销售（精肉店・烧肉用批发） | 食肉销售业＝许可 | 施行令第35条第3款 |
| 仅将已包装食肉原状销售 | 申报 | 施行令第35条第3款括号・法第57条 |
| 制造火腿・香肠・培根等 | 食肉制品制造业＝另一许可 | 施行令第35条第15款 |

## 物件所要求的设施基准（区划・冷藏设备・给排水・地板墙面）为何？

设施基准分两层：适用于全业种的共通基准（食品卫生法施行规则别表第十九）与各业种别基准（同别表第二十），都道府县参酌后以条例订定基准。共通基准要求：依作业区分以隔间等作必要区划，并与住居等不处理食品的房间区划（别表第十九第2款）；地板・内墙・天花板以便于清扫・洗净・消毒的材料与构造制成；使用水的设施地板为不渗透性且排水良好，内墙自地板到容易受污染的高度以不渗透性材料腰墙（同第3款ハ・ニ）。另要求供应必要温度・足量水的给水设备、防止逆流并适当排出设施外的排水设备、洗净消毒手指的流水式洗手设备，以及不影响作业场构造的厕所（同第3款ヘ・チ・リ・ヲ）。

作为业种别基准（别表第二十第3款），食肉销售业须设处理室；处理室内备有分割肉・内脏等所需设备；备有可将需冷藏保存的制品管理在摄氏10度以下、需冷冻保存的制品管理在摄氏零下15度以下的冷藏・冷冻设备，其规模与处理量相称；不可食部分・废弃用容器为不渗透性材料且附盖。选择物件时，重点在于是否有能容纳这些的面积・区划・给排水引入・电力容量（冷藏・冷冻设备）。数值与运用细节会因条例与管辖保健所的运用而异，故物件锁定后向保健所事前咨询最为确实。

| 确认项目 | 基准要点 | 依据 |
|---|---|---|
| 区划 | 依作业区分的区划・与住居等的区划 | 施行规则别表第十九第2款 |
| 地板・内墙 | 不渗透性地板・排水良好・腰墙（使用水的设施） | 同别表第十九第3款ニ |
| 冷藏・冷冻 | 冷藏10度以下／冷冻零下15度以下・规模与处理量相称 | 同别表第二十第3款ハ |
| 给排水・洗手 | 足量给水・防逆流排水・流水式洗手 | 同别表第十九第3款ヘ・チ・リ |
| 处理室 | 处理室与分割设备 | 同别表第二十第3款イ・ロ |

## 在哪些用途地域与建物可以开业？

食肉销售业的店铺，在建筑基准法（昭和25年法律第201号）上属「物品销售业店铺」，受各用途地域的建物用途限制（同法第48条・别表第二）。概略而言，第一种低层住居专用地域原则上不得兴建店铺，仅限与住宅并用且非住宅部分达一定规模（占总建筑面积的一定比例且50㎡以下）的店铺等。第二种低层住居专用地域可设建筑面积150㎡以内的一定店铺等；中高层住居专用・住居系・邻近商业・商业・准工业各地域则视规模而可；工业专用地域原则不得设物品销售店铺。具体可否与面积上限会因地域与规模而异，故向建筑士・特定行政厅确认最为确实。

食肉的分切・分装属「销售业」范围，与制造火腿・香肠等（食肉制品制造业）属不同许可、不同处理。若伴随制造，用途地域上将以「工厂」处理，可设置的地域会因所用原动机出力与作业内容而进一步受限。使用既有建物时，从原用途（事务所・住宅等）变更为店铺，可能因建筑面积而需建筑基准法上的用途变更确认申请。物件过去是否已作为餐饮店・物贩店铺使用，是估算用途变更工夫的重要线索。

| 用途地域 | 物品销售店铺的处理（概略） |
|---|---|
| 第一种低层住居专用地域 | 原则不可（仅限与住宅并用的一定规模店铺等） |
| 第二种低层住居专用地域 | 建筑面积150㎡以内的一定店铺等 |
| 住居系・邻近商业・商业・准工业 | 视规模而可 |
| 工业专用地域 | 物品销售店铺原则不可 |

## 许可申请要委托谁，不动产一方要确认物件的什么？

角色依资格而分。食肉销售业营业许可申请的作成・代办属行政书士；取得食品卫生责任者资格的养成讲习会由各都道府县的食品卫生协会举办；厨房・冷藏设备・给排水的设备工程属专业工程业者；开业后税务属税理士。各设施须设食品卫生责任者（食品卫生法施行规则第66条之2第3项），由调理师・制果卫生师・营养士等有资格者，或食品卫生协会等所办养成讲习会的结业者担任。四叶不动产株式会社于物件调查・重要事项说明中整理这些手续的必要性，并以独立的事业体分别签约的方式，将您转介给各专业人士。

不动产一方在签约前可确认的，包括物件的面积与区划能否容纳处理室・冷藏设备・洗手・厕所、给排水与电力容量是否足以支应设备、用途地域与临路・搬运动线是否契合业态、既有建物是否需自原用途变更、承租时出租人是否同意作食肉销售业使用及设备工程等。由于设施基准是否符合最终由管辖保健所判断，故锁定候选后向保健所事前咨询，必要时与行政书士・建筑士一同看物件最为安全。签约前先订定能等待保健所判断的契约条件（如设施基准不符时的解除条款），可降低回头的负担。

| 角色 | 负责 |
|---|---|
| 营业许可申请的作成・代办 | 行政书士 |
| 食品卫生责任者养成讲习会 | 各都道府县的食品卫生协会 |
| 厨房・冷藏・给排水的设备工程 | 设备工程业者 |
| 物件调查・中介・重要事项说明 | 宅地建物交易业者（宅地建物交易士） |
| 开业后税务 | 税理士 |

## 常见问题

**Q. 仅进货已包装的食肉并销售，也需要许可吗？**
A. 专以容器包装状态进货食肉、不做分切或分装而原状销售的营业，排除于食肉销售业许可之外，以营业申报（食品卫生法第57条）即可（施行令第35条第3款括号）。在店头或作业场将块肉分切・切片・分装的业态因伴随处理而需要许可。在找物件前先向管辖保健所确认属哪一种最为确实。

**Q. 冷藏・冷冻设备需要到什么程度？**
A. 食品卫生法施行规则别表第二十第3款要求备有可将需冷藏保存制品管理在摄氏10度以下、需冷冻保存制品管理在摄氏零下15度以下的冷藏・冷冻设备，其规模与处理量相称。所需台数・容量会因取用量而异，确保电力容量是选物件的要点。具体是否符合由条例与管辖保健所的运用判断，故请就候选物件向保健所事前咨询。

**Q. 住宅区的空店铺也能开精肉店吗？**
A. 视用途地域而定。第一种低层住居专用地域原则上不得兴建物品销售店铺，仅限与住宅并用的一定规模店铺等。自第二种低层住居专用地域以上的多数地域视规模而可，但工业专用地域原则不得设物品销售店铺（建筑基准法第48条・别表第二）。具体可否、面积上限与是否需用途变更确认申请，请向建筑士・特定行政厅确认。

**Q. 许可申请或食品卫生责任者的安排可委托不动产公司吗？**
A. 许可申请的作成・代办属行政书士、食品卫生责任者的养成讲习会属各都道府县食品卫生协会的领域，并非不动产公司代为办理之事。四叶不动产株式会社负责物件是否可能符合设施基准的初步查看与重要事项说明，并与行政书士・建筑士・设备工程业者・税理士各以独立的事业体分别签约的方式为您转介。不收取介绍费・送客手续费。
