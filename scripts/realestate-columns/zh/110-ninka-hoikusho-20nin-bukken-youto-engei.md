**结论（先讲重点）**：定员20名以上的认可保育所物件，与小规模保育决定性不同的是三点：屋外游戏场（园庭，可用附近公园等代替）、含乳儿室・爬行室的居室面积、以及把保育室设在2楼以上时的两方向避难与耐火。保育所在用途地域上不会卡（建筑基准法别表第二在第一种低层住居专用地域也能兴建，工业专用地域也不在限制之列）。卡的是面积・避难・用途变更的确认申请・消防。本公司负责到物件的用途・面积・避难・消防现况的信息提供为止，认可申请与设备运营基准的适合审查交给行政书士与市区町村、确认申请与采光避难的计算交给建筑士、人员・劳务交给社会保险劳务士，分别签约推进。

本文面向在文京区及周边寻找定员20名以上认可保育所本体设施的社会福祉法人・学校法人・股份公司的开设承办人与其不动产承办人，依儿童福祉设施设备运营基准（昭和23年厚生省令第63号）・建筑基准法・消防法施行令，整理“与小规模保育的物件寻找哪里相同、哪里改变”。本公司负责物件的用途・构造・面积・消防现况的信息提供，不进行认可的可否或采光・避难的计算、人员配置・劳务的设计。相关领域各自交给专业人士，分别签约推进。

## 认可保育所与小规模保育，对物件要求的面积・设备有何不同？

依据的省令不同。认可保育所（定员20名以上）对屋外游戏场・乳儿室・爬行室・保育室/游戏室各有面积规定。若收托未满2岁的孩子，乳儿室每人1.65㎡以上・爬行室每人3.3㎡以上；满2岁以上者，保育室或游戏室每人1.98㎡以上，屋外游戏场满2岁以上每人3.3㎡以上。

定员6〜19名的地域型保育（小规模保育事业）依“家庭的保育事业等的设备及运营基准”，本体设施的认可保育所依“儿童福祉设施的设备及运营基准”第32条。用途地域・消防的起点思路，与[小规模保育事业的物件出租・寻找时，用途地域与面积要确认什么](https://luck428.com/column/hoiku-shoukibo-bukken-youto-chiiki)相通，但本体设施把屋外游戏场（园庭）的确保、收托乳儿时的乳儿室・爬行室，以及因规模较大而凸显的避难要件推到前面。

| 居室・设备 | 第32条的面积（每人） | 依据 |
|---|---|---|
| 乳儿室（未满2岁） | 1.65㎡以上 | 第32条第2号 |
| 爬行室（未满2岁） | 3.3㎡以上 | 第32条第3号 |
| 保育室或游戏室（满2岁以上） | 1.98㎡以上 | 第32条第6号 |
| 屋外游戏场（满2岁以上） | 3.3㎡以上 | 第32条第6号 |
| 医务室・调理室・厕所 | 设置（条文无一律面积） | 第32条第1号・第5号 |

面积不是依“定员”而是依“实际收托的各年龄区分人数”生效，收托0〜2岁越多，所需乳儿室・爬行室面积越大。各室的最终可否由主管市区町村的认可基准・条例与事前协议决定，故押下物件前的确认是前提。

## 没有屋外游戏场（园庭）的物件，能用附近公园代替吗？

条文上有代替的余地。第32条第5号就屋外游戏场定为“包含保育所附近可代替屋外游戏场的场所”，可用附近的公园・广场等作为代替地。但“是否在附近”“是否能安全日常使用”“是否满足所需面积”由市区町村个别审查。

屋外游戏场需满2岁以上每人3.3㎡以上，但在无法于基地内确保的都市物件中，常以附近公园等被认作“可代替的场所”。何者算代替地（距离、园童是否能安全移动的路线、与其他设施共用时必要时能否使用、面积是否足够），由市区町村依儿童家庭厅《保育所等的设备・运营基准》与各自治体的手册判断。依赖代替地的物件，若未在契约前向自治体确认代替地可否，可能在认可阶段因园庭不足被退回。

| 确认项目 | 重点 |
|---|---|
| 代替地依据 | 第32条第5号“包含附近可代替屋外游戏场的场所” |
| 距离・路线 | 是否为园童能安全日常利用的附近（距离数值为自治体运用【未验证】） |
| 面积 | 是否满足满2岁以上每人3.3㎡以上 |
| 使用确实性 | 公园管理者等的使用承诺，非专用时必要时能否使用 |

代替地被认可的距离・条件数值因自治体而异、并非全国统一，故本文不作断定、列为【未验证】，以主管自治体的确认为前提。

## 在2楼以上・大楼店面开设时，避难・防火要看哪里？

把保育室等（乳儿室・爬行室・保育室或游戏室）设在2楼以上时，第32条第8号对耐火・两方向避难・区划有细致要求。2楼以上原则为耐火建筑物或准耐火建筑物，3楼以上须为耐火建筑物，各楼层设屋外楼梯・斜坡道等避难设施，自保育室等任一处至任一避难设施的步行距离须30m以下。

第32条第8号要求：把保育室等设于2楼以上时，イ＝建物构造（2楼以上为耐火或准耐火、3楼以上为耐火）、ロ＝依楼层的避难设施（待避上有效的阳台、屋外斜坡道、屋外楼梯等之一以上）、ハ＝避难上有效的位置与步行距离30m以下、ニ＝调理室的区划（耐火构造的楼地板墙壁・特定防火设备・风管防火阀・自动灭火装置）、ホ＝墙壁天花板的不燃内装、ヘ＝防坠落设备、ト＝非常警报设备与向消防机关通报火灾的设备、チ＝窗帘等的防焰。转用大楼空室的物件，能否在既有建物中成立此耐火区划・两方向避难・调理室防火区划，成为选定的分水岭。

| 确认项目 | 第32条第8号重点 |
|---|---|
| 构造 | 2楼以上耐火或准耐火、3楼以上耐火建筑物 |
| 两方向避难 | 依楼层的屋外楼梯・屋外斜坡道・待避阳台设于有效位置 |
| 步行距离 | 自保育室等任一处至避难设施30m以下 |
| 调理室 | 耐火区划・特定防火设备・风管防火阀・自动灭火装置 |
| 内装・通报 | 不燃内装、非常警报设备、向消防机关通报的设备、防焰物品 |

消防法施行令别表第一中保育所区分为(6)项ハ(3)，依延べ面积等配置自动火灾报知设备・灭火器・诱导灯等。必要消防用设备的具体与工程费随构成与建物而变，故列为【未验证】，以采光・避难计算与确认申请由建筑士、消防用设备由消防设备士・辖区消防署确认为前提。

## 用途地域与建筑基准法上的用途变更（确认申请），向谁在哪里确认？

用途地域对保育所几乎不成问题。建筑基准法别表第二中，保育所在第一种低层住居专用地域（(い)项第6号“老人院、保育所、福祉之家及类似者”）也能兴建，且未列入工业专用地域不能兴建的建筑物。卡的不是用途地域，而是转用既有建物时的用途变更确认申请。

把事务所・店铺・共同住宅等转为认可保育所（建筑基准法上属儿童福祉设施）时，用途变更部分楼地板面积超过200㎡，使用前就需用途变更确认申请（建筑基准法第6条第1项・第87条）。福祉用途变更容易卡关的点，整理于[福祉用途变更在哪里需要确认申请](https://luck428.com/legal/column/group-home-kenchikukijunho-youto-henko)。用途变更的确认申请与采光・避难计算属建筑士・特定行政厅领域，本公司把现况用途与面积整理为物件信息，计算与申请交给建筑士。

| 确认项目 | 依据・重点 |
|---|---|
| 用途地域 | 别表第二(い)项第6号。第一种低层住居专用地域也可，工业专用地域亦非限制对象 |
| 用途变更确认申请 | 用途变更部分楼地板面积超过200㎡需申请（第6条第1项・第87条） |
| 采光 | 居室的采光（建筑基准法第28条）。计算由建筑士 |
| 由谁 | 计算・确认申请＝建筑士／认可的适合审查＝市区町村与行政书士 |

## 押下物件前，在与自治体的事前协议中该确认什么？

顺序是“锁定物件→面积・屋外游戏场（代替地）・避难・用途变更・消防的可否确认→与市区町村事前协议→认可申请→人员配置・劳务设计”。认可保育所是受市区町村认可的设施，若签约后才在事前协议发现面积・园庭・避难不足，回头的成本很大。

事前协议的论点包括：对各年龄区分定员的居室面积、屋外游戏场（园庭）或代替地的可否、设于2楼以上时的避难・耐火、调理室与供餐方式、以及与职员配置相称的宽度。职员配置基准（保育士人数）与排班・就业规则的设计属社会保险劳务士，认可申请书类与设备运营基准的适合整理属行政书士。

## 常见问题

**Q. 认可保育所与小规模保育，对物件的标准有何不同？**
A. 依据的省令不同。认可保育所（定员20名以上）依儿童福祉设施设备运营基准第32条，规定屋外游戏场（园庭）、乳儿室（每人1.65㎡）・爬行室（每人3.3㎡）・保育室或游戏室（每人1.98㎡）等。小规模保育（6〜19名）依家庭的保育基准，因规模较小，园庭与避难要件也不同。物件可否请向主管市区町村确认。

**Q. 没有园庭的大楼物件能做认可保育所吗？**
A. 条文上屋外游戏场“包含附近可代替的场所”，有用附近公园等作代替的余地（第32条第5号）。但市区町村会个别审查距离・路线・面积・使用确实性。因被认可的距离因自治体而异（本文列为【未验证】），请在契约前向主管市区町村确认代替地可否。

**Q. 想把保育室设在2楼，物件侧需要什么？**
A. 第32条第8号原则要求2楼以上为耐火或准耐火建筑物、3楼以上为耐火建筑物，依楼层的屋外楼梯・斜坡道，自保育室等任一处至避难设施步行距离30m以下，调理室的耐火区划与自动灭火装置，不燃内装，防坠落，向消防机关通报的设备等。该判断与采光・避难计算属建筑士领域。

**Q. 把既有事务所大楼改为认可保育所，需要确认申请吗？**
A. 用途变更部分楼地板面积超过200㎡，使用前需用途变更确认申请（建筑基准法第6条第1项・第87条）。保育所在用途地域上几乎不会卡（别表第二(い)项第6号在第一种低层住居专用地域也可，工业专用地域亦非限制对象）。确认申请与采光・避难计算请洽建筑士，认可的适合审查请洽市区町村与行政书士。
