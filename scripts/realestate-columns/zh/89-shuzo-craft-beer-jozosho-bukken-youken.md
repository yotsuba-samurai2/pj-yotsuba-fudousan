**结论（先说重点）**：开精酿啤酒酿造所（酒类制造）的物业，先发生作用的是四点：①用途地域（酿造所是建筑基准法别表第二的「工厂」，可设置的区域受作业场楼板面积与危险性・环境影响筛选）②建物侧要件（承载酒罐的楼板荷重・天花板高・电力容量・冷藏/贮藏区划）③酿造排水（BOD高，属水质污浊防止法的特定设施，并受下水道・净化槽规制）④酒类制造免许的最低制造数量（啤酒年60千升、发泡酒年6千升）。免许本身由所辖税务署（国税厅）管辖，非宅地建物交易业者或行政书士的业务范围。物业的调查・媒介・买卖/租赁合同由本公司（四叶不动产株式会社）承担，酒吧区（tap room）的饮食店营业许可等保健所提交文书的制作由四叶行政书士事务所承担；免许找税务署、建筑确认・楼板荷重的设计找建筑士、排水设备找设备业者、酒税・法人税找税理士。这些是各自独立的事业体，请分别直接签约。

「前一位租客是餐厅，所以直接放入酿造罐就能开」——你以此为前提租下，却在开始投料酿造时发现楼板快塌、排水无法排入下水道、电力不足。餐厅与诊所物业会发生的返工，在酿造所更沉重。本文写给在东京开啤酒酒吧・小规模酿造所的创业者，以及出租・寻找该物业的立场者：在决定租赁或购买前能确认的事，依酒税法・城市规划法・建筑基准法・水质污浊防止法・食品卫生法的条文与公开资料依序整理。因酒类制造免许本身由税务署管辖，取得的咨询对象另行标示；本文聚焦于从不动产侧看的物业条件。可否的最终确认，在所辖税务署・特定行政厅・保健所・消防署・自治体的下水道/环境部门的窗口进行。

## 精酿啤酒酿造所在哪些用途地域能开？

酿造所在法律上是「制造物品的工厂」。与餐厅（店铺）或诊所处理不同，**可设置的场所受用途地域筛选**。这是第一道关卡。

建筑基准法（昭和25年法律第201号）第48条与别表第二，就各用途地域订定可兴建的建筑物。工厂方面，以**作业场楼板面积的合计**、以及**是否危险性大或会显著恶化环境**两把尺区分区域。酒类制造业（酿造）通常不属于大量处理危险物或会显著恶化环境的工厂类型，但可设置的用途地域随作业场大小而变。大致如下。

| 用途地域 | 作为工厂的处理（大致） |
|---|---|
| 第一种・第二种低层住居专用地域／田园住居地域 | 原则不可（小规模兼用住宅的一部分等例外除外） |
| 第一种・第二种中高层住居专用地域 | 原则不可（不能兴建工厂） |
| 第一种・第二种住居地域・准住居地域 | 作业场楼板面积小（大致50㎡以下）且符合原动机出力等条件的范围内可 |
| 近邻商业地域・商业地域 | 作业场楼板面积大致150㎡以下可 |
| 准工业地域 | 危险性・环境影响少的工厂原则可（酿造所易设置） |
| 工业地域・工业专用地域 | 可（惟工业专用地域不能并设店铺） |

**若想并设酒吧区（店内提供）并保有规模，准工业・工业地域较为现实**；另须注意工业专用地域不能并设饮食提供的店铺。作业场楼板面积的阶段（50㎡・150㎡等）与原动机出力的处理，依特定行政厅（自治体的建筑主事）的运用而分，故请及早把设想的制造规模与物业的用途地域对照。用途地域与容积率如何牵动地价，整理于[日本地价为何随「容积率」而变](https://luck428.com/column/yosekiritsu-hosei-tochine)。事业用物业全般请见[投资用・事业用不动产](https://luck428.com/toushi)，公司设立与办公室选择请见[公司设立与办公室选择](https://luck428.com/office)。

## 楼板荷重・天花板高・电力容量等建物侧要件，哪些易被忽略？

用途地域之后发生作用的，是建物本身能否承受酿造设备。以下项目是餐厅沿用既有装修所不涵盖的。

| 签约前确认 | 为何发生作用 |
|---|---|
| 楼板荷重（积载荷重） | 投料后的发酵・贮酒罐满水时每座数百公斤〜数吨。办公室规格（每㎡约300公斤）的楼板有承受不住者 |
| 天花板高 | 立式发酵罐・烟囱・配管的立起需要高度 |
| 电力容量 | 冷却机（chiller）・锅炉・泵・冷藏库耗电。只有单相的物业，须确认能否引入动力（三相） |
| 供热水・锅炉・燃气容量 | 投料的加热（煮沸）需大量热源 |
| 冷藏・贮藏区划 | 能否取得发酵・贮酒・原料（麦芽・啤酒花）・成品的温度管理区划 |
| 搬运路线 | 酒罐・成品栈板进出的门面・前面道路宽度，叉车能否通行 |

楼板荷重尤其易被忽略。**满水的酒罐局部很重，办公室或零售店规格的楼板可能需要补强。** 楼板能否补强・构造是否允许，是建筑士（构造设计）的判断。确认既有建物的构造后，把所需补强的范围，以及它如何反映到租赁合同的恢复原状，在签约前与出租人谈妥，可减少返工。中古建物也要确认检查完成证的有无。无检查完成证的中古建物，在用途变更确认申请与融资上可能有障碍，有时可通过法适合状况调查确认建筑时的合法性。此论点整理于[无检查完成证的中古物业能否转为福祉用途](https://luck428.com/column/kensazumisho-nashi-bukken-fukushi-youto-henko)。设计・施工由建筑士与设备业者负责，本公司（不动产公司）就物业能否满足这些条件的预先调查与对出租人的条件交涉伴走。

## 酿造排水（BOD・水量）与下水道・净化槽的规制，要在哪里确认？

酿造所比餐厅更甚地处理**水与有机物**。投料・洗净・酵母・麦芽渣所生的排水BOD（生物化学需氧量）高、量也多。这与物业选择直接相关。

首先，酿造所可能成为设置水质污浊防止法（昭和45年法律第138号）**特定设施**的事业场。同法施行令别表第一，把酒类制造业（啤酒・清酒等）用的洗瓶设施・以煮沸加热处理原料的设施・过滤设施・蒸馏设施等列为特定设施。要设置特定设施时，须向都道府县知事等提交申报（同法第5条）。向公共水域（河川等）排水时，适用同法第3条的排水基准（BOD・SS等的容许限度）。

其次，城市地区的多数物业接入公共下水道。此时适用下水道法（昭和33年法律第79号）与各自治体的下水道条例，可能要求特定设施的设置申报（下水道法第12条之3），或设置不稀释而处理超标排水的**除害设施**。在下水道区域外使用净化槽的物业，另须依净化槽法处理与维护管理。

| 排水的确认点 | 在哪里确认 |
|---|---|
| 公共下水道或净化槽・接入的可否 | 自治体的下水道局・物业的给排水图 |
| 特定设施申报的要否 | 都道府县・自治体（水质污浊防止法・下水道法） |
| 是否需要除害设施（BOD等排除基准） | 自治体的下水道条例。数值因自治体而异 |
| 排水管的口径・坡度・排水量的余裕 | 设备业者・给排水图 |

**排水的基准值与申报的运用因自治体而异，写作当下也可能变动。** 传达酿造规模（一年酿多少千升、用多少水投料）后，请在动手前直接向自治体的下水道・环境部门确认。排水・除害设施的设计施工由设备业者负责，排水协商由指定工事店参与。给排水与换气的物业条件，与餐厅的[以毛坯（skeleton）物业开餐厅时，排气・隔油池・防火如何决定物业选择](https://luck428.com/column/inshokuten-skeleton-bukken-haiki-grease)、[洗衣店的物业与给排水・排水处理](https://luck428.com/column/cleaning-jo-bukken-youken-kyusuisui-shori)有许多共通论点，可资参考。

## 酒类制造免许的最低制造数量是什么？该找谁咨询？

要制造酒类，除物业外还需要**酒类制造免许**。这与物业的话题管辖不同。

酒税法（昭和28年法律第6号）第7条第1项规定，欲制造酒类者，须就欲制造的酒类品目别，**按制造场别，取得该制造场所在地所辖税务署长的免许**。也就是说，免许由所辖税务署（国税厅）管辖，**非宅地建物交易业者或行政书士的业务范围**。

而免许有**最低制造数量基准**。酒税法第7条第2项规定，一年的预计制造数量未达各品目所定数量时，不得取得免许。与精酿啤酒相关的主要数量如下。

| 品目 | 年最低制造数量 |
|---|---|
| 啤酒 | 60千升 |
| 发泡酒 | 6千升 |
| 果实酒 | 6千升 |
| 利口酒 | 6千升 |
| 清酒 | 60千升 |

**这是精酿啤酒开业最为人知的分界。** 「啤酒」免许需年60千升的预计制造，但以果实或香辛料等副原料做成属「发泡酒」的酿法，最低制造数量便降到年6千升。小规模酿造所以发泡酒免许起步、随规模扩大再研究啤酒免许，即因此故。又，2018年（平成30年）4月1日的酒税法修正扩大了「啤酒」的定义（麦芽比率由67%以上降到50%以上，并认可果实・香辛料等副原料／酒税法第3条第12号），使部分原属发泡酒的商品被纳入啤酒，但各免许最低制造数量的区别仍存。可不予免许的情形（人的要件・场所要件・经营基础要件・供需调整要件等拒否要件）规定于同法第10条。

**免许的要否・可否最终判断在所辖税务署。** 整理设想的品目与制造数量后，请找税务署的酒类指导官（酒类担当），或精通酒类免许的专家咨询。本公司・本事务所不代办此免许本身，仅承担确认物业能否满足制造・排水・电力条件。

## 若酿造与酒吧区（饮食提供）并设，物业会有何不同？

做成在店内提供自家啤酒的啤酒酒吧（并设酒吧区），会在**制造免许之外，叠上饮食提供的许可**。物业条件也增加一层。

在店内提供啤酒供饮食的营业，须取得食品卫生法（昭和22年法律第233号）第55条的**饮食店营业许可**（保健所）。请在签约前确认厨房・洗手・区划能否满足保健所的设施基准。饮食店营业许可的物业条件，整理于[饮食店营业许可与保健所的设施基准](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)（行政书士）。

此外，把所造的酒卖到店外（以瓶・罐零售）需另取**酒类销售业免许**，深夜0时以后主要提供酒类则需**深夜酒类提供饮食店营业的申报**。这些是与制造分开的许认可，店铺许认可申请文书的制作是行政书士的业务。酒类零售免许与店铺物业要件整理于[能取得酒类零售免许的店铺物业条件](https://luck428.com/legal/column/shurui-kouri-menkyo-tenpo-bukken-yoken)，深夜提供的申报整理于[深夜酒类提供饮食店营业申报的要件](https://luck428.com/legal/column/shinya-shurui-teikyo-todokede-yoken)（皆为行政书士）。

| 并设而增加的确认 | 管辖・承担者 |
|---|---|
| 店内提供的饮食店营业许可 | 保健所／申请文书由行政书士 |
| 瓶・罐零售（酒类销售业免许） | 所辖税务署 |
| 深夜0时以后提供酒类的申报 | 警察署／申报文书由行政书士 |
| 消防用设备・避难（客席增加） | 消防署・消防设备士 |
| 工业专用地域不能并设店铺 | 特定行政厅（用途地域） |

**只做制造的物业，与也做饮食提供的物业，在用途地域・消防・保健所的看法会变。** 若要有酒吧区，就以「避开工业专用地域、选能满足饮食提供的设施基准与消防的物业」的顺序筛选。

## 常见问题

**Q. 精酿啤酒酿造所能开在住宅街（第一种低层住居专用地域）吗？**
A. 原则不能。酿造所属建筑基准法别表第二的「工厂」，在第一种・第二种低层住居专用地域或中高层住居专用地域不能兴建。住居系地域若作业场楼板面积小尚有余地，但制造规模上升后，近邻商业・商业（作业场大致150㎡以下）或准工业・工业地域较现实。用途地域上的可否因物业而异，请于特定行政厅窗口确认。

**Q. 若是餐厅沿用装修的物业，直接放入酿造罐就能开始吗？**
A. 未必。餐厅规格的楼板多未设想满水酒罐（每座数百公斤〜数吨），可能需要楼板荷重补强。电力（动力）容量、供热水・锅炉、排水的口径与处理也可能不足。请在签约前，楼板荷重与构造找建筑士、排水找设备业者与自治体确认。

**Q. 酿造所的排水能直接排入下水道吗？**
A. 未必能照原样。酿造排水BOD（有机物）高、量也多，故在公共下水道，依下水道法与自治体下水道条例，可能要求特定设施申报或设置除害设施。基准值因自治体而异，请传达设想的酿造规模，于动手前向自治体的下水道・环境部门确认。

**Q. 啤酒免许真的要能年产60千升才拿得到吗？**
A. 「啤酒」免许以年60千升的预计制造为要件（酒税法第7条第2项）。相对地，依副原料的用法做成属「发泡酒」的酿法，最低制造数量降到年6千升。小规模酿造所多以发泡酒免许起步即因此。免许的要否・可否判断由所辖税务署管辖，请整理品目与制造数量后找税务署咨询。
