**結論（先に要点）**：自立訓練（生活訓練・機能訓練）の物件で先に効くのは、①用途地域（自立訓練事業所は建築基準法上「児童福祉施設等」に含まれ、工業専用地域を除きおおむね建てられる）②訓練・作業室・相談室・洗面所・便所・多目的室が確保できるか（指定障害福祉サービス基準〈平成18年厚生労働省令第171号〉第168条・第158条→第81条準用）③消防法施行令別表第一の用途区分（自立訓練は原則(6)項ハ）と自動火災報知設備の要否、の3点です。訓練室には「3㎡×定員」のような数値の面積基準はなく「支障がない広さ」とだけ定められています。契約前に用途地域・設備・消防・用途変更の要否・貸主の可否を確かめれば手戻りを防げます。

「テナントを借りてから」相談室を間仕切れない、消防設備の追加で開設が遅れる——飲食店やクリニックで起きる手戻りが、自立訓練事業所でも起きます。本記事は、自立訓練（障害者総合支援法の訓練等給付）の事業所を新規開設するために賃貸物件を探している法人・個人事業主と、その物件を貸すオーナーに向けて、賃貸借契約を結ぶ前に確認できることを、指定障害福祉サービスの事業等の人員、設備及び運営に関する基準（平成18年厚生労働省令第171号）と建築基準法・消防法の条文から順に整理したものです。人員配置の常勤換算や社会保険の労務、指定申請書類の作成、報酬の算定には踏み込みません。物件が基準を満たせるかの最終確認は、指定権者（都道府県・市町村）と特定行政庁・消防署の窓口で行います。

## 自立訓練の事業所物件は、他の障害福祉サービスと何が違いますか？

まず押さえたいのは、自立訓練には**機能訓練**（身体機能の維持・回復の訓練）と**生活訓練**（生活能力の維持・向上の訓練）の2類型があり、どちらも障害者総合支援法第5条第12項に定める**訓練等給付**のサービスだという点です。就労移行支援・就労継続支援A/B・生活介護・放課後等デイサービス・児童発達支援などと同じ「障害福祉サービス」の仲間ですが、**設備・人員の基準は類型ごとに別の条文**で定められており、物件に効く要件も異なります。

物件選びの観点では、自立訓練は次の3点が特徴です。

| 観点 | 自立訓練（生活訓練・機能訓練）での効き方 |
|---|---|
| 用途地域 | 建築基準法上「児童福祉施設等」に含まれ、工業専用地域を除きおおむね可 |
| 訓練室の面積 | **数値の面積基準はない**。「訓練又は作業に支障がない広さ」とだけ定める（通所介護の「3㎡×定員」のような基準はない） |
| 消防区分 | 原則として消防法施行令別表第一(6)項ハ。避難困難者を主として入所させる型は(6)項ロ |

**つまり、通所介護やグループホームと同じ感覚で「面積は定員から逆算」と考えると取り違えます。** 自立訓練の訓練・作業室は数値基準がない代わりに、訓練内容に支障がない広さを自分で設計する必要があります。介護事業所一般の用途地域の考え方は[「介護事業所の物件は用途地域で決まる」](/column/kaigo-jigyousho-bukken-youto-chiiki)に整理しています。なお、生活訓練には日中通所型のほかに宿泊型（指定宿泊型自立訓練）があり、宿泊型は居室・浴室が追加で要るため設備の考え方が変わります。本記事は主に日中通所型を前提に整理します。

## 訓練室・相談室・便所など、面積と設備の最低基準はどこを見ますか？

設備基準の中心は、機能訓練では**第158条が準用する第81条**、生活訓練では**第168条**です（いずれも平成18年厚生労働省令第171号。**2026年11月19日参照**）。両者とも、事業所に次の設備を設けることを求めています。

| 設備 | 基準上の位置づけ | 物件で確認する素地 |
|---|---|---|
| 訓練・作業室 | 必置。**訓練又は作業に支障がない広さ**を有し、必要な機械器具等を備える | 数値基準はない。訓練内容に足る広さと、器具を置ける区画 |
| 相談室 | 必置。**室内の談話の漏えいを防ぐ間仕切り等**を設ける | 個室または間仕切りで区切れるか |
| 洗面所 | 必置。利用者の特性に応じたもの | 車いす・障害特性に対応できる洗面 |
| 便所 | 必置。利用者の特性に応じたもの | バリアフリー化できるトイレ |
| 多目的室 | 必置。その他運営に必要な設備 | 相談室と兼用も可（支障がない場合） |

**押さえておきたいのは、訓練・作業室に「○㎡×定員」のような数値基準がないことです。** 通所介護は食堂兼機能訓練室を「3㎡×利用定員以上」と数で縛りますが、自立訓練の訓練・作業室は「支障がない広さ」とだけ定めます。その分、**定員・訓練プログラムから必要な広さを自分で見立てる**ことになるため、内見では有効面積（柱・水回りを除いた実測）を確認しておくのが安全です。

もう一つ効くのが**相談室と多目的室の兼用**です。第168条第4項（機能訓練は第81条第3項準用）は、利用者の支援に支障がない場合、相談室と多目的室を兼用できると定めています。ワンフロアで区画を節約する設計は可能ですが、相談室は談話の漏えいを防ぐ間仕切りが前提です。

なお、生活訓練で**宿泊型（指定宿泊型自立訓練）**を行う場合は、第168条第3項により、上記のほかに**居室（定員1人・収納設備等を除き7.43㎡以上）と浴室**が追加で要ります。居室の7.43㎡はこの分野では数少ない数値基準なので、宿泊型を検討するなら物件の間取りを早めに確かめます。区画・給排水・バリアフリーの設計や、用途変更の確認申請の要否の判断は建築士・設計者の領域です。**当社（不動産会社）は、物件がこれらの条件を満たせるかの下調べと、貸主との条件交渉に伴走します。** 設備設計や構造適合の判断そのものは行いません。

## どの用途地域なら開設でき、建築基準法上の用途変更は必要ですか？

自立訓練事業所は、建築基準法上は「診療所」でも「店舗」でもなく、**「児童福祉施設等」に含まれる施設**として扱われます。建築基準法施行令第19条第1項は「児童福祉施設等」に「障害福祉サービス事業（生活介護、自立訓練、就労移行支援又は就労継続支援を行う事業に限る。）の用に供する施設」を明記しており、自立訓練事業所はここに含まれます。用途地域の制限は、建築基準法別表第二の児童福祉施設等の扱いに準じます（**2026年11月19日参照**）。

その結果、用途地域では次のように整理できます。

| 用途地域 | 自立訓練事業所（児童福祉施設等）の可否の目安 |
|---|---|
| 工業専用地域 | 建てられない |
| 第一種・第二種低層住居専用地域 | 原則可（規模により面積の制限あり） |
| 上記以外の住居系・商業系・工業地域 | 原則可 |

**つまり用途地域そのもので詰まるのは工業専用地域くらいで、住宅街の低層住専でも開設できる余地があります。** ただし建築基準法上の用途の判断は、事業所の規模・形態や特定行政庁の運用で変わり得ます。**可否の最終確認は特定行政庁（建築指導課）の窓口で行ってください。**

もう一つ効くのが**用途変更の確認申請**です。もとが物販店舗や事務所だった建物を自立訓練事業所（児童福祉施設等）に変えるとき、その用途部分の床面積が200㎡を超えると確認申請が要ります（建築基準法第6条・第87条）。**該当の有無と要否の判断は建築士の領域**で、契約前に見立てておくと手戻りを防げます。市街化調整区域内の物件では、これに加えて都市計画法の開発許可・建築許可の論点が重なるため、区域区分を先に確認します。

## 消防法の用途区分とスプリンクラー・自動火災報知設備はどう確認しますか？

利用者が日々通う施設なので、**消防設備は物件選びの関門**になります。まず効くのが用途区分です。消防法施行令別表第一の(6)項ハ(5)は、障害者総合支援法第5条第12項に規定する**自立訓練を行う施設**を明記しており、通所型の自立訓練事業所は原則として**(6)項ハ**に区分されます（**2026年11月19日参照**）。一方、避難が困難な障害者等を主として入所させる障害者支援施設型や、短期入所・共同生活援助を避難困難者主体で行う施設は(6)項ロに区分されます。

区分が決まると、自動火災報知設備の要否が条文から読めます（消防法施行令第21条第1項）。

| 自立訓練事業所の形態 | 消防区分 | 自動火災報知設備 |
|---|---|---|
| 日中通所型（入居・宿泊なし） | (6)項ハ | **延べ面積300㎡以上**で必要（第21条第1項第3号ロ） |
| 宿泊型（利用者を入居・宿泊させる） | (6)項ハ | **面積に関わらず**必要（第21条第1項第1号ロ） |
| 避難困難者を主として入所させる型 | (6)項ロ | 面積に関わらず必要 |

**スプリンクラー設備・消防機関へ通報する火災報知設備・誘導灯などの要否は、区分（ロかハか）と延べ面積・収容人員で変わり**、本記事の条文だけでは個別の物件の結論は出ません。どの設備がどこまで要るかの判断と設置は、消防署（予防課）と消防設備業者の領域です。契約前に消防設備の現況と、必要になりそうな追加設備の見立てを確認しておくと、開設後の想定外の工事を避けられます。

役割は次のように分かれます。

| やること | 担い手 |
|---|---|
| 物件の調査・媒介・賃貸借契約 | 宅地建物取引業者（当社） |
| 用途変更の確認申請の要否判断、構造適合、バリアフリー・給排水の設計 | 建築士・設計者 |
| 消防用設備の設置の要否判断・設置 | 消防署（予防課）・消防設備業者 |
| 指定申請など官公署に提出する書類の作成 | 行政書士 |
| 人員配置に沿った常勤換算・就業規則・社会保険 | 社会保険労務士 |
| 取得する場合の所有権移転登記 | 司法書士 |
| 報酬の算定・税務 | 税理士（請求は国民健康保険団体連合会） |

## よくある質問

**Q. 自立訓練の訓練室は、定員から面積を逆算するのですか？**
A. いいえ。通所介護の食堂兼機能訓練室は「3㎡×利用定員以上」と数で縛られますが、自立訓練の訓練・作業室には数値の面積基準がありません。指定基準（平成18年厚生労働省令第171号）は「訓練又は作業に支障がない広さ」とだけ定めます。そのため定員・訓練プログラムから必要な広さを自分で見立てることになり、内見で有効面積（柱・水回りを除いた実測）を確認しておくのが安全です。数少ない数値基準は、宿泊型自立訓練の居室が1人あたり7.43㎡以上（収納設備等を除く）という点です。

**Q. 自立訓練の事業所は住宅街でも開けますか？**
A. 開ける余地があります。自立訓練事業所は建築基準法施行令第19条第1項の「児童福祉施設等」に含まれ（障害福祉サービス事業のうち自立訓練を行う事業の用に供する施設）、用途地域の制限は児童福祉施設等の扱いに準じます。工業専用地域を除きおおむね建てられ、第一種・第二種低層住居専用地域でも規模の制限つきで可能です。ただし用途の判断は事業所の規模・形態や特定行政庁の運用で変わり得るため、可否の最終確認は特定行政庁（建築指導課）で行ってください。既存建物を用途変更する場合は、用途部分が200㎡を超えると確認申請が要ります。

**Q. 消防法では、自立訓練はどの区分になりますか？**
A. 消防法施行令別表第一(6)項ハ(5)が障害者総合支援法第5条第12項の「自立訓練を行う施設」を明記しており、通所型の自立訓練事業所は原則として(6)項ハに区分されます。自動火災報知設備は、通所型（入居・宿泊なし）なら延べ面積300㎡以上で、宿泊型（利用者を入居・宿泊させる）なら面積に関わらず必要です（施行令第21条第1項）。スプリンクラー設備・誘導灯等の要否は区分と規模で変わるため、最終的には消防署（予防課）で確認してください。避難が困難な障害者等を主として入所させる型は(6)項ロに区分されます。

**Q. 相談室と多目的室は兼用できますか？**
A. できます。指定基準は、利用者の支援に支障がない場合、相談室と多目的室を兼用できると定めています（生活訓練は第168条、機能訓練は準用する第81条）。ただし相談室は室内の談話の漏えいを防ぐ間仕切り等を設けることが前提で、洗面所・便所は利用者の特性に応じたものが必要です。ワンフロアで区画を節約する設計は可能ですが、相談の秘密保持とバリアフリーは物件選びの段階で確かめておくのが安全です。
