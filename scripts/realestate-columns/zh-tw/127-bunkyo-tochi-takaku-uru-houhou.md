**結論（先說重點）**：想讓文京區的土地賣得更好，起點是用資料說明建築條件與土地現況，再選擇適合潛在買方的出售方式。除了開價，也要比較扣除費用與稅負後的實收金額、完成交付所需時間，以及賣方承擔的條件。

準備出售文京區土地時，屋主往往先想到「附近開價每坪多少」，或「拆成空地是不是能賣得更高」。但即使位於同一町內，臨路方式、可建築的規模、與鄰地的高低差不同，買方的評估也可能不同。

小日向、小石川或千石，單憑地名無法決定出售策略。打算使用這筆土地的人，需要確認哪些資料才能做出購買決定？由賣方先準備這些材料，才能為價格協商建立基礎。

四葉不動産株式会社以文京區小日向為據點，提供土地出售諮詢與仲介服務。即使尚未決定是否出售，也可以先來討論價格與辦理步驟。

## 要看哪個金額，才知道這次出售的結果是否合適？

首先要釐清賣方的優先順序。能花多少時間爭取理想價格？換屋或取得資金的日期是否已經確定？能否預先支付拆除、測量等費用？如果這些條件不清楚，即使收到購買申請，也不容易取捨。

| 比較項目 | 出售前先釐清的事情 |
| --- | --- |
| 實收金額 | 售價扣除賣方負擔的費用與稅金後，希望保留多少 |
| 時程 | 除了簽約日期，最晚何時必須收取價款並完成交付 |
| 賣方負擔的條件 | 老屋、現場遺留物、測量等事項，由誰負擔到什麼範圍 |

若仍有房貸或其他借款，還要另外確認清償後實際留在手上的資金。估價並不保證最終成交價，也不保證實收金額。

關於估價與實際購買出價的差別，請參閱[估價與實際購買出價](https://luck428.com/zh-tw/column/satei-gaku-to-fuda-chigai)。本文著重於釐清估價前提後，屋主如何選擇準備工作與出售條件。

## 文京區的土地，要準備哪些資料才能讓買方理解其價值？

只有面積與到車站的距離，買方仍無法規劃購買後的用途。應將「已確認的事項」與「還需要進一步調查的事項」分開說明。沒有資料的部分，也不宜用推測填補。

| 確認事項 | 可提供給買方的判斷材料 |
| --- | --- |
| 可建築用途與規模 | 用途地域、建蔽率與容積率、高度及防火等指定；依具體計畫由建築師檢討 |
| 道路與出入 | 道路種類、寬度、臨路長度、是否須退縮；如屬私道，另確認權利、通行與挖掘相關資料 |
| 面積與界址 | 登記面積、測量圖、界址確認文件是否存在及其製作時間 |
| 高低差與擋土牆 | 土地與道路、鄰地的位置關係；擋土牆圖面、施工歷程及調查紀錄 |
| 居住環境 | 到車站的路線與坡道、周圍建物、生活設施，以及核對後的學區資料 |

文京區有台地、谷地與坡道。實際步行查看，往往能發現地圖無法呈現的條件。不過，不能因此概括認為高地一定安全、低地一定難賣，仍須分別確認地形與個別基地條件。

不能只依都市計畫指定的容積率，就斷定「一定能蓋出這麼大的建物」。道路、基地形狀及各種限制也會影響建築可能性，需要建築師檢討並向文京區公所相關窗口確認。詳見[容積率與土地價格的關係](https://luck428.com/zh-tw/column/yosekiritsu-hosei-tochine)。

對重視學區的買方，應提供核對到所在地「番、號」的資訊，而非只有學校名稱。文京區部分通學區域還會依舊町名區分。不能只因學校就在附近就認定指定校，也不能保證入學或較高的出售價格。

界址、道路及高低差的個別調查方式，請分別參閱[界址與確定測量](https://luck428.com/zh-tw/column/souzoku-fudosan-kyoukai-kakutei-sokuryo-baikyaku)、[道路退縮、面積與價格](https://luck428.com/zh-tw/column/setback-42jo-2ko-doro-tochi-baikyaku-menseki)、[文京區的坡地與擋土牆確認事項](https://luck428.com/zh-tw/column/gake-yoheki-tochi-baikyaku-bunkyo)。

## 買方不同，應該著重說明哪些資訊？

想自建住宅的個人，與興建住宅後出售的公司，需要的判斷材料不同。除了賣方的希望，也要依買方購買後想實現的用途，整理土地資訊。

| 潛在買方 | 主要評估內容 | 賣方可先整理的資訊 |
| --- | --- | --- |
| 想自建住宅的個人 | 理想生活方式，以及土地加上建築費的總預算 | 居住環境、基地與道路資料、建築評估所需條件、交付時程 |
| 住宅開發或收購業者 | 建築、施工與轉售的計畫及成本 | 建築條件、形狀與高低差、老屋及擋土牆資料、買賣雙方的費用負擔 |
| 鄰地所有權人 | 擴大基地後的用途與便利性 | 界址與權利關係、出售範圍，以及出售整筆土地時的比較 |

這是規劃出售方式時的買方分類，並不表示目前已經有購買意願者，也不保證一定會出現競價。

狹小地或不規則土地，有時可考慮與鄰地合併使用。但鄰地所有權人也有自己的預算與計畫，不宜認定「因為是鄰居就一定願意出高價」，而應與對外出售的方式比較。接洽的順序、能透露多少出售資訊，也要與賣方討論後決定。

各種出口的比較，可參閱[文京區狹小地的出售與活用](https://luck428.com/zh-tw/column/kyosho-tochi-15tsubo-uru-ikasu-bunkyo)及[出售給鄰地所有權人與增購鄰地](https://luck428.com/zh-tw/column/rinchi-baikyaku-kaimashi-nanari-tochi-deguchi)。

閱讀行情資料時，要對照土地條件與時間。附近的開價、公示地價、相續稅路線價、實際交易價格，目的與意義各不相同。國土交通省「不動產資訊資料庫」的土地交易價格資料，也包含以問卷為基礎的資訊，並非完整涵蓋每一筆交易。不能直接將附近案例的每坪價格套用到自己的土地。

## 支付拆除或測量費用前，要先比較什麼？

投入準備費用，不代表售價一定會等額增加。應先釐清支出的目的，以及如何反映在出售條件上。

有老屋的土地，可以比較「保留老屋交付」與「由賣方拆除後交付」兩種方案。除了預期售價，也要把拆除費、工期、發現地下狀況時如何處理，以及稅負影響一起納入。買方也可能希望使用現有建物，因此不必在諮詢出售前，就先以拆除為前提。

拆除住宅可能影響土地固定資產稅、都市計畫稅的住宅用地特例。改建等情況也有相關處理方式，稅額並非一律相同。決定拆除時間前，請向都稅事務所或稅理士確認。讓渡所得稅的特例，也會因自用住宅或繼承空屋等情況而有不同的檢討內容。

測量亦同。應依現有圖面、界址確認狀況、買方計畫與買賣條件，向土地家屋調查士確認還需要哪些工作。有舊測量圖，不等於這次交易所需的界址確認已經完備。

收到購買申請後，不宜只看出價，還要將以下條件對齊比較。

| 比較項目 | 應確認的內容 |
| --- | --- |
| 費用負擔 | 仲介費、測量、拆除、現場遺留物清運等；估價單應確認含稅金額、工作範圍與另計費用 |
| 成交前提 | 買方融資、建築計畫評估等申請附帶條件 |
| 交付 | 收取價款的日期、能否保留老屋或物品，以及是否來得及完成準備 |
| 瑕疵等事項的處理 | 土地與建物現況掌握到何種程度、如何說明，以及契約負擔如何約定 |

不建議隱瞞已知瑕疵或與鄰地之間的懸而未決事項。應整理事實，反映在說明與契約條件中。涉及責任範圍等個別法律判斷時，請向律師確認。

## 開始出售後，如何檢討價格與銷售方式？

開始銷售前，先約定開價依據、潛在買方、可公開的資訊，以及檢視進度的時間，較容易根據詢問情形思考下一步。

廣泛公開出售資訊，與希望不讓鄰居知道而低調出售，可公開的範圍不同。如希望限制公開，應一併理解對接觸買方範圍與出售時程的影響，再與賣方決定銷售方針。

詢問較少時，原因不一定只有價格。還應檢查資料是否不足、說明是否足以讓買方判斷，以及交付條件是否符合預想買方的需求。整理詢問、現場查看與未繼續洽談的原因後，再檢討價格、資料、銷售對象或契約條件應如何調整。

## 常見問題

**Q. 可以比附近土地更高的每坪價格出售嗎？**
A. 設定開價時，除了附近的廣告價格，也要確認形狀、道路、建築條件與時間等差異。整理希望價格、依據與可投入的出售期間，並先約定如何依詢問情形調整方針。

**Q. 不清楚土地界址，也可以諮詢嗎？**
A. 可以。先確認登記、圖面與界址確認文件有哪些，再區分需要向土地家屋調查士請教的事項。不必在諮詢前，就由賣方自行發包所有測量工作。

**Q. 先拆掉老屋，會比較容易賣高價嗎？**
A. 會依土地及建物現況、買方用途、拆除費用與稅務處理而不同。應先比較保留老屋與拆除兩種方案的實收金額及交付時間，再做決定。

**Q. 還沒決定出售，可以只估價或諮詢嗎？**
A. 可以。請先告知已知的所在地、面積、老屋有無及希望時程。四葉不動産會整理出售方式與確認事項，說明後續步驟。諮詢與是否正式委託仲介，可以分開考慮。
