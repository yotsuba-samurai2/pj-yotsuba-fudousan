**結論（先說重點）**：針灸院・整骨院（あはき・柔整的施術所）的物件，先發生作用的是兩點：①用途地域（施術所與診所不同，一般被當作「服務業店舖」處理，受用途地域限制）②能否滿足施術所的構造設備基準（專用施術室6.6㎡以上・待合室3.3㎡以上・換氣・消毒設備）。開設申報是「開設後10日內」由施術者本人向保健所提出，申報文件的製作由行政書士承接。簽約前確認用途地域與面積・換氣，就能避免返工。

被告知「只剩裝潢」而承租，真要開業時卻發現施術室的面積或換氣不足基準。餐飲店、美容室會發生的返工，針灸院・整骨院同樣會發生。本文寫給在東京要開針灸院・接骨院（整骨院）的施術者，以及把物件租給他們的人：簽租約前能確認的事，依あはき法（按摩・指壓・針・灸師等相關法律）・柔道整復師法的條文與省令順序整理。療養費的處理或施術內容當否等醫事判斷，本文不予涉入。可否的最終確認在特定行政廳與保健所窗口。

## 針灸院・整骨院能在哪些用途地域開？

先整理前提。針灸院是「針・灸」的施術所（あはき法），整骨院・接骨院是「柔道整復」的施術所（柔道整復師法），連同按摩指壓，這些**不是醫療法上的診所，而是「施術所」**。這是用途地域討論的起點。

診所在建築基準法的用途限制下所有用途地域都能建，但**施術所在建築基準法別表第二沒有固有分類，許多特定行政廳把它當作「服務業店舖」（近似理髮店・美容院）而施以用途地域限制來運用。** 在此前提下，住宅區最嚴格的地域無法作為單獨店舖開業。

建築基準法（昭和25年法律第201號）施行令（昭和25年政令第338號）第130條之3列舉第一種低層住居專用地域可建的兼用住宅，條件是**居住占延面積2分之1以上、且店舖等部分的樓地板面積合計50㎡以下**。把施術所套用到同條第3號的「理髮店、美容院……及其他類似的服務業店舖」的運用下，第一種低層住居專用地域僅限自宅兼用且小規模者。第一種住居地域以上，就較易作為3,000㎡以下的店舖建築。

| 用途地域 | 施術所（作為店舖處理時）的目安 |
|---|---|
| 第一種・第二種低層住居專用地域 | 原則僅限兼用住宅（居住占延面積1/2以上・店舖部分50㎡以下） |
| 第一種・第二種中高層住居專用地域 | 在面積限制下可（依自治體運用） |
| 第一種・第二種住居地域、準住居地域 | 較易作為3,000㎡以下店舖建築 |
| 近鄰商業・商業・準工業地域 | 可建 |

**但需注意。** 也有自治體把依法設立的施術所當作「準診所」處理，在低層住居專用地域也認可，**處理因特定行政廳而異。** 若是租賃大樓，還須看整棟的用途。**可否因物件而異，請於簽約前向特定行政廳窗口確認。** 用途地域與容積率如何牽動土地價格，整理在[〈日本的土地價格為何會因「容積率」而改變〉](https://luck428.com/column/yosekiritsu-hosei-tochine)。

## 作為施術所向保健所申報的構造設備基準是什麼？

保健所（都道府縣知事等）看的是「構造設備」。あはき法第9條之5第1項規定「施術所的構造設備，須符合厚生勞動省令所定的基準」，同條第2項要求衛生上必要的措施。柔道整復師法第20條也是相同架構。**裝潢完成後若不足基準，就無法照原樣使用。** 這是選物件的起點。

具體數值在省令。あはき法施行規則（平成2年厚生省令第19號）第25條、柔道整復師法施行規則（平成2年厚生省令第20號）第18條，以幾乎相同的內容要求下列各點（**2026年8月29日參照**）。

| 項目 | 省令要求的基準 |
|---|---|
| 施術室 | **6.6㎡以上**的專用施術室 |
| 待合室 | **3.3㎡以上**的待合室 |
| 換氣 | 施術室須有相當於室面積**7分之1以上**的部分可對外氣開放（有可替代的適當換氣裝置則不在此限） |
| 消毒 | 備有消毒施術所用器具・手指等的設備 |

此外，あはき法施行規則第26條・柔道整復師法施行規則第19條要求的衛生措施為**常保清潔、充分採光・照明・換氣**。

在物件端可先確認的，是能否滿足這些數值的基礎條件。

| 簽約前確認 | 為何有效 |
|---|---|
| 能配置6.6㎡以上施術室與3.3㎡以上待合室的面積・格局 | 面積是省令的核心；單間房可能無法分出施術室與待合 |
| 窗戶的大小・位置，或換氣設備 | 施術室需相當於面積1/7以上的對外開放或換氣裝置 |
| 給排水的位置 | 手指・器具的消毒需要洗手處 |
| 電氣容量 | 物療機器・空調・給湯耗容量；增設影響費用與工期 |
| 地板・牆壁的清潔性 | 「常保清潔」的基礎；也牽涉回復原狀範圍 |

換氣・給排水・電氣容量的設計是施工業者（設計者）的領域。**本公司（不動產公司）伴走的是物件能否滿足這些條件的前置調查，以及與出租人的條件交涉。** 不做設備設計本身。相同返工會發生的原因，整理在[〈照護事業所的物件為何找不到〉](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)；租約要讀哪裡，整理在[〈租賃契約書，該讀哪裡〉](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 居抜（帶裝潢）與毛胚，申報重做的差別在哪？

差很多。前承租人若是針灸院・整骨院的居抜物件，施術室的區劃・洗手處・換氣可能留著。但——**「以前也是施術所，所以沒問題」不是保證。**

兩個理由。第一，施術所的申報是逐一施術所提出（あはき法第9條之2／柔道整復師法第19條），前一家的申報不會承接給新的開設者。第二，あはき（按摩・針・灸）與柔道整復**根據法不同**，兩者都做就各需申報。若前一家只做針・灸，而你要併設整骨院，柔整的構造設備・申報就要另外辦。

| | 居抜（前為施術所） | 毛胚 |
|---|---|---|
| 施術室・待合的區劃 | 可能沿用舊格局 | 從頭設計 |
| 洗手處・給排水 | 多半留著（需點檢） | 新設；位置從設計起 |
| 換氣設備 | 可能沿用 | 新設 |
| 申報 | **重新提出**（あはき・柔整各別） | 重新提出 |
| 初期費用傾向 | 較易壓低 | 較易增加 |

即使是居抜，**交屋前點檢施術室的面積與換氣是否符合現行省令基準**較安全。殘置設備的所有・修繕・撤除負擔如何在契約中約定，是居抜特有的議題。

## 開設申報由誰、何時提出？裝潢動工前要確認什麼？

這裡與美容室・理容所相反。美容所・理容所的開設申報是「事先（開設前）」，但**施術所的申報是「開設後10日內」。** あはき法第9條之2規定「開設施術所者，須於開設後10日內，將開設場所、從事業務的施術者姓名及其他省令所定事項，向施術所所在地的都道府縣知事申報」，柔道整復師法第19條亦同（設置保健所的市・特別區則向該市長・區長申報）。休止・廢止時，自該日起10日內申報。

雖說是「開設後」，構造設備在開設時點須符合省令基準，故實務流程如下。

| 順序 | 要做的事 | 擔當者 |
|---|---|---|
| 1 | 確認用途地域・用途變更要否 | 特定行政廳・宅地建物取引業者 |
| 2 | 前置調查施術室・待合的面積、換氣、給排水能否滿足 | 宅地建物取引業者・施工業者 |
| 3 | 租賃契約 | 宅地建物取引業者 |
| 4 | 裝潢工程（區劃・施術室・待合・換氣・消毒設備） | 施工業者 |
| 5 | 開設 → **10日內**申報施術所 | 開設者（施術者本人） |
| 6 | 保健所的確認・進場檢查 | 保健所 |

另外，即使把事務所或別業種店舖改為施術所，**施術所通常不屬於建築基準法別表第一(い)欄的特殊建築物，故用途變更的確認申請原則上不需要。** 但與確認申請要否無關，用途地域限制（建築基準法第48條）與採光・換氣等實體規定仍會適用。消防方面，針灸院・整骨院一般被當作消防法施行令別表第一的(15)項（非特定用途的防火對象物）處理，所需消防用設備會因整棟的租戶構成・樓層數・延床面積而變。**用途地域・用途變更・消防，簽約前可向特定行政廳・消防署確認。**

## 物件契約容易卡關的點在哪？

施術所的申報（開設後10日內）等向保健所提出的文件之製作，由四葉行政書士事務所承接。**申報本身由施術者本人為之**，行政書士不是代為提出，而是協助製作文件的定位。牽涉用途變更・建築確認時的設計由建築士處理，裝潢的給排水・換氣設計由施工業者處理。**行政的窗口・樣式・條例數值・受理運用會變。著手時請直接查閱管轄保健所與特定行政廳的頁面。** 事業用物件整體在[投資用・事業用不動產](https://luck428.com/toushi)，事務所與許認可的關係在[公司設立與辦公室選擇](https://luck428.com/office)。

物件的調查、仲介、買賣・租賃契約，由四葉不動產株式會社（宅地建物取引業 東京都知事(1)第113304號）承接。施術所的申報等向官公署提出的文件之製作，由四葉行政書士事務所承接。

**這兩者（不動產公司・行政書士事務所）是各自獨立的事業體。請各自直接簽約。** 本公司・本事務所既不收取也不支付介紹費・轉介費。登記請找司法書士、稅務請找稅理士、勞務請找社會保險勞務士（2026年9月開業預定），各自直接委託。諮詢免費。

## 常見問題

**Q. 針灸院或整骨院能在住宅區（第一種低層住居專用地域）開嗎？**
A. 在把施術所比照服務業店舖處理的一般運用下，原則上不能作為單獨店舖開。依建築基準法施行令第130條之3，可作為兼用住宅（居住占延面積1/2以上・店舖部分50㎡以下）建築。另有自治體把依法設立的施術所比照診所處理，故處理不一。請就個別物件向特定行政廳確認。

**Q. 施術室或待合室的大小，法律上有數值嗎？**
A. 有。あはき法施行規則第25條・柔道整復師法施行規則第18條要求6.6㎡以上的專用施術室、3.3㎡以上的待合室、施術室面積7分之1以上可對外氣開放（或換氣裝置）、消毒設備。這是全國共通的省令基準。

**Q. 前身也是整骨院的居抜物件，申報就會直接通過嗎？**
A. 不會直接承接。申報是逐一施術所重新提出（あはき法第9條之2・柔道整復師法第19條）。あはき（按摩・針・灸）與柔道整復根據法不同，兩者都做就各需申報。請於交屋前點檢殘置設備是否符合現行省令基準，並向保健所確認。

**Q. 開設申報何時提出？在物件契約之前嗎？**
A. 施術所的申報是「開設後10日內」（あはき法第9條之2・柔道整復師法第19條），與美容所・理容所的「事先（開設前）」順序相反。但構造設備在開設時點須符合省令基準，故依物件契約→裝潢工程→開設→10日內申報的順序準備。
