**結論（先講重點）**：繼承土地國庫歸屬制度自2023年（令和5年）4月27日施行約三年半，依法務省統計（令和8年9月30日現在・速報值，公表於令和8年10月19日），相對於申請6,125件，獲承認歸屬國庫的為3,231件，駁回86件、不承認103件、撤回1,162件。在申請的階段被駁回的，是有建物的土地・設有擔保權等的土地・界線不明的土地等，法律事先定出了「不能申請的土地」（繼承土地國庫歸屬法第2條第3項）。在審查的階段不承認的，是管理需過分費用・勞力的懸崖的土地・地上有工作物或樹木的土地・地下有有體物的土地・不經訴訟即無法管理處分的土地等（第5條第1項）。獲承認後，需繳納相當於國家管理費用一部分的負擔金。被駁回・不承認的土地，或與其繳負擔金放手、不如出售・出租較有剩餘的土地，由不動產（本公司）檢討出售・捐贈等別的出口。承認申請的書類製作為行政書士、審查為法務局、界線的確定測量為土地家屋調查士、讓渡所得等稅務為稅理士的領域，各為獨立事業體、以分別簽約為前提為您轉介（無介紹費的往來）。

本文為正在尋找繼承而難以售出之土地（遠方・原野・山林・管理困難地）出口的繼承人，以法務省統計確認制度的運用實績（被用了多少、哪種土地被駁回・不承認），並整理被駁回・不承認時的別的出口，依條文與公開資料的順序整理。本文為一般性資訊提供，個別土地是否被駁回・不承認、負擔金額、稅的適用等最終判斷屬法務局・專家的領域。

四葉不動產株式會社以東京都文京區小日向為據點，承辦繼承不動產的調查與估價・售出的仲介。歡迎從「該申請國庫歸屬，還是出售較好」的階段開始諮詢。

## 繼承土地國庫歸屬制度，至今被申請・承認了多少？

法務省定期公表制度的運用狀況統計。最新公表（令和8年10月19日付・令和8年9月30日現在的速報值）如下。考慮制度的選擇時，先知道「申請後仍有一定比例以撤回・駁回・不承認收場」的實績，較易建立預期。

| 項目 | 件數（令和8年9月30日現在・速報值） |
|---|---|
| 申請件數 | 6,125件 |
| 歸屬件數（獲承認歸屬國庫的件數） | 3,231件 |
| 駁回件數 | 86件 |
| 不承認件數 | 103件 |
| 撤回件數 | 1,162件 |

申請的地目別中，田・旱田最多為2,372件，其次宅地2,135件、山林928件、其他690件。撤回1,162件的理由，包含「產生了有效活用的見込」595件、「判明屬駁回・不承認」415件等。亦即，申請後找到別的出口、或發覺不符要件而撤回的例子相當多。制度之間的選法（國庫歸屬・捐贈・出售的比較）在既有文章[放手繼承的土地——國庫歸屬・捐贈・出售的比較](https://luck428.com/zh-tw/column/souzoku-tochi-tehanasu-kokko-kizoku-baikyaku-hikaku)處理，本文將主題聚焦於運用實績（駁回・不承認的類型）。

## 在申請的階段「被駁回」的是哪種土地？（法第2條第3項）

駁回是指在進入審查之前，以「本來就不能申請的土地」被退回。繼承土地國庫歸屬法第2條第3項規定，屬於下列任一的土地不能申請。

| 被駁回的土地（第2條第3項） | 內容 |
|---|---|
| 有建物的土地 | 有建物坐落的土地 |
| 設有擔保權等的土地 | 設有抵押權等擔保權，或以使用收益為目的之權利的土地 |
| 預定他人使用的土地 | 含政令所定、預定供通路等他人使用之土地的土地 |
| 遭土壤污染的土地 | 遭土壤污染對策法的特定有害物質污染的土地 |
| 界線不明的土地 | 界線不明，或所有權的存否・歸屬・範圍有爭議的土地 |

法務省統計中，駁回86件的理由（1件可能被認定多個理由，故各理由合計與駁回件數不一致），包含未提出附件37件、界線不明23件、供通路之用22件、由無申請權限者申請11件、有建物坐落4件等。界線不明與作為通路使用成為實際的駁回理由這點，是在看物件的階段就想確認的。界線的確定屬土地家屋調查士的領域，流程是先做確定測量再申請。

## 在審查「不承認」的是哪種土地？（法第5條第1項）

不承認是指申請雖獲受理，但審查結果認為「使之歸屬國庫並不適當」而不予承認。繼承土地國庫歸屬法第5條第1項規定，屬於下列任一的土地不予承認。與駁回要件（是否為可申請的土地）不同，此階段看的是「通常的管理・處分是否需過分費用・勞力」。

| 不承認的土地（第5條第1項） | 內容 |
|---|---|
| 有懸崖的土地 | 有政令所定坡度・高度之懸崖，管理需過分費用・勞力的土地 |
| 地上有有體物的土地 | 地上有妨礙通常管理・處分之工作物・車輛・樹木等有體物的土地 |
| 地下有有體物的土地 | 不除去即無法進行通常管理・處分之有體物在地下的土地 |
| 需經訴訟的土地 | 不經與鄰地所有者等的訴訟即無法進行通常管理・處分、政令所定的土地 |
| 其他需過分費用・勞力的土地 | 除上述外，政令所定、通常管理・處分需過分費用・勞力的土地 |

法務省統計中，不承認103件的理由，包含地上有妨礙管理・處分之工作物・車輛・樹木等49件、需國家追加整備的森林37件、歸屬國庫後依法令負擔金錢債務的土地12件、需採取防災措施的土地11件、需過分費用・勞力之懸崖7件等（1件可能被認定多個理由，故合計與不承認件數不一致）。放置的工作物或立木、山林的整備不足，實際上成為不承認的主因這點，對想放手山林・原野的繼承人是重要實績。山林出口的思考方式，亦在[出售繼承的山林・請鄰地買下](https://luck428.com/zh-tw/column/rinchi-baikyaku-kaimashi-nanari-tochi-deguchi)整理。

## 被駁回・不承認的土地，如何尋找出售或捐贈等別的出口？

即使國庫歸屬被駁回・不承認，土地的出口也不會消失。反而，有些土地與其繳負擔金請國家收下，不如出售・出租較有剩餘。出口大致分為以下。

| 出口 | 適合情形 | 主要相關的負責者 |
|---|---|---|
| 出售（市場・鄰地・買取） | 可望有需求，或鄰地所有者想買下 | 本公司（宅地建物交易業） |
| 捐贈（自治體・法人・個人） | 難以出售但有收受者 | 本公司・對方（可否受贈視對方而定） |
| 出租・利用（停車場・資材放置場・太陽能等） | 雖有建築限制但可作別用途 | 本公司・業者 |
| 整備要件後再申請 | 界線確定或工作物撤去後可符合要件 | 土地家屋調查士・拆除業者・行政書士 |

在以「賣不掉」為前提進到國庫歸屬之前，先確認能否在市場售出、能否請鄰地所有者買下、能否作別用途出租，是順序。鄰地所有者想買下的「鄰地需求」，有時比一般市場更易成交。管理困難地的整體放手方式，亦在[繼承的市街化調整區域土地賣得掉嗎](https://luck428.com/zh-tw/column/chousei-kuiki-souzoku-tochi-baikyaku)、附空屋的土地在[繼承的空屋拆除成空地出售或附舊屋土地出售](https://luck428.com/zh-tw/column/souzoku-akiya-kaitai-koyatsuki-dochira)處理。本公司協助依國庫歸屬要件判斷是否可能被駁回・不承認的大致研判（最終判斷為法務局），以及出售・捐贈・出租這些別的出口的整理。

## 從申請書類的製作到負擔金的繳納，該向誰諮詢？

繼承土地國庫歸屬制度，橫跨承認申請（行政書士・本人）・審查（法務局）・界線確定（土地家屋調查士）・作為替代出口的出售（不動產）・稅務（稅理士）等不同領域。不動產公司負責的是替代出口的檢討與調查・估價・仲介。

| 困擾 | 轉介對象 |
|---|---|
| 駁回・不承認時出售・捐贈・出租等別的出口檢討、調查・估價・仲介 | 本公司（宅地建物交易業） |
| 國庫歸屬的承認申請書類製作・提出的代理 | 行政書士 |
| 承認申請的審查・負擔金額的通知 | 法務局（管轄的法務局・地方法務局） |
| 界線（筆界）的確定測量、分筆 | 土地家屋調查士 |
| 所有權移轉・繼承登記 | 司法書士・土地家屋調查士 |
| 讓渡所得等稅務 | 稅理士 |

這些各為**獨立事業體**，以**分別簽約**為前提。本公司不收取也不支付介紹費・送客手續費。獲承認後需繳納負擔金，負擔金依國有地的種目別、考量10年份的標準管理費用算定。原則不論面積為定額（20萬日圓），但部分市街化區域內的宅地・農地或一定的森林等則依面積算定（繼承土地國庫歸屬法第10條・施行令。具體金額依法務局的通知與施行令的算定）。承認申請的可否與書類由行政書士、審查與負擔金額由法務局、界線確定由土地家屋調查士、登記由司法書士、稅務由稅理士判斷・負責。又，繼承的土地若仍為被繼承人名義，申請或出售前通常需先辦繼承登記（令和6年〈2024年〉4月1日起義務化・不動產登記法第76條之2），這屬司法書士的領域。繼承不動產的進行方式請見[繼承不動產的諮詢窗口](https://luck428.com/zh-tw/souzoku)。

**[在國庫歸屬與出售間猶豫的繼承土地諮詢交給四葉不動產（諮詢免費）](https://luck428.com/zh-tw/souzoku)**

洽詢時請註明「繼承土地國庫歸屬」，並填寫土地的所在地（自治體）、地目（宅地・田旱田・山林・原野等）、有無建物或工作物・立木、界線是否確定、繼承登記是否已辦。不先認定適合國庫歸屬或適合出售・捐贈・出租，先從是否可能被駁回・不承認的研判（最終判斷為法務局），與別的出口的整理談起。

## 常見問題

**Q. 繼承土地國庫歸屬制度至今被用了多少？**
A. 依法務省統計（令和8年9月30日現在・速報值，公表於令和8年10月19日），自2023年4月施行約三年半，申請6,125件、獲承認歸屬的歸屬件數3,231件、駁回86件、不承認103件、撤回1,162件。申請後找到別的出口而撤回，或因不符要件被駁回・不承認的例子也相當多。數值為速報值，最新請在法務省的頁面確認。

**Q. 哪種土地會「被駁回」？**
A. 繼承土地國庫歸屬法第2條第3項，將有建物的土地、設有擔保權等的土地、預定供通路等他人使用的土地、遭土壤污染的土地、界線不明的土地列為「不能申請的土地」。法務省統計中，附件不足、界線不明、供通路之用為實際駁回理由的前段。界線的確定屬土地家屋調查士的領域。

**Q. 哪種土地會「不承認」？**
A. 第5條第1項將管理需過分費用・勞力之懸崖的土地、地上有工作物・車輛・樹木的土地、地下有有體物的土地、不經訴訟無法管理處分的土地列為不承認。法務省統計中，地上的工作物・樹木、需追加整備的森林、負擔金錢債務的土地為不承認理由的前段。放置立木或工作物的山林・原野，不撤收或整備則不易通過。

**Q. 被駁回・不承認的話，就不能放手了嗎？**
A. 並非如此。有些土地與其繳負擔金請國家收下，不如出售・出租較有剩餘。可檢討在市場售出、向鄰地所有者出售、向自治體或法人捐贈、作為停車場・資材放置場出租等別的出口。本公司協助國庫歸屬的研判（最終判斷為法務局），與出售・捐贈・出租的整理。出售仲介為不動產、申請為行政書士、界線確定為土地家屋調查士，負責者是分開的。
