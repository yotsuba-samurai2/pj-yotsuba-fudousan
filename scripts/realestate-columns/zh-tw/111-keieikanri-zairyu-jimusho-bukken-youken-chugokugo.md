**結論（先講重點）**：「經營・管理」在留資格被認作事業所的物件，骨架是三點：與住居明確區分的獨立區劃、以法人名義・事業用目的承租、以及以招牌・門牌等在外觀上也能確認為事業所的狀態。2025年（令和7年）10月16日施行的改正，把資本金・出資總額提高到3,000萬日圓以上、常勤職員1名以上，自宅兼事務所原則上不再被認可。本公司負責到物件能否作為事業所使用的資訊提供為止，在留資格的申請・事業計畫書交給行政書士、公司設立登記交給司法書士、資本金・稅務交給稅理士，分別簽約推進。

本文面向將在日本設立公司並申請「經營・管理」在留資格的中國大陸・台灣創業者，以及代理他們的當地專業人士，依出入國管理及難民認定法與上陸許可基準省令、出入國在留管理廳的說明，整理在審查中被認作事業所的物件條件。本公司負責物件的獨立性・用途・租賃契約等不動產側的資訊提供，不進行在留資格的可否判斷或事業計畫的製作。相關領域各自交給專業人士，分別簽約推進。

## 審查中被認作「事業所」的物件條件是什麼？

骨架有三。第一，與住居明確區分的獨立區劃。第二，以法人名義、事業用目的承租。第三，以招牌・門牌等在外觀上也能確認為事業所的狀態。此外改正後還要求與事業規模相稱的事業所。

「經營・管理」是入管法別表第一の二所列的在留資格，對象是在日本從事事業經營・管理的活動。上陸許可基準（出入國管理及難民認定法第七條第一項第二號的基準省令。平成2年法務省令第16號）要求經營事業用的事業所存在於日本，若事業尚未開始，則須在日本確保作為事業所使用的設施。出入國在留管理廳的審查，會看該設施是否為與住居或私人空間區分、能持續用於事業的獨立區劃。

| 確認項目 | 作為事業所被看的重點 |
|---|---|
| 獨立性 | 是否為與住居・私人空間明確區分的獨立區劃 |
| 名義・目的 | 是否以法人名義、租賃契約的使用目的是否為事業用 |
| 持續性 | 是否為可持續使用、而非月租短期空間 |
| 外觀 | 是否以招牌・門牌等能確認為事業所（審查的一項材料） |
| 規模 | 是否與改正後的事業規模（資本金3,000萬日圓以上等）相稱的寬度與實體 |

事業所要件的最終判斷由出入國在留管理廳個別進行，故押下物件前，宜與負責申請的行政書士就事業所的實體先行對齊。

## 自宅兼用或虛擬辦公室能通過經營・管理簽證嗎？

2025年10月16日改正後，把自宅兼作事業所原則上不再被認可。虛擬辦公室（只租地址的形態）、以及任何人都能使用的共享辦公共用部分，因難以呈現獨立事業所的實體，原則上也不滿足事業所要件。

住居與事業所同為一個空間時，難以呈現事業所的獨立性・實體，改正後的審查在此容易通不過。租賃辦公室的個室・一區劃或育成辦公室，也要看是否以法人名義明確區分、能持續用於事業的實體而判斷。雖以虛擬辦公室能完成公司設立，卻在在留資格的事業所要件卡關的論點，整理於[以虛擬辦公室設立公司｜能做的事・在許認可卡關的事](https://luck428.com/legal/column/office-virtual-office-kyoninka)。物件具備多少事業所實體，由本公司就獨立區劃・名義・使用目的的現況提供資訊，在留資格上的可否交給行政書士。

| 形態 | 事業所要件見込 |
|---|---|
| 自宅兼事業所 | 改正後原則不被認可 |
| 虛擬辦公室（只有地址） | 原則不可（難以呈現獨立實體） |
| 共享辦公共用部 | 原則不可 |
| 租賃辦公室的個室・專用區劃 | 有法人名義・明確區分・持續使用則有被認可的餘地（個別判斷） |
| 獨立的事業用店面 | 較易被認作事業所 |

## 租賃契約的名義與使用目的該怎麼寫？

要被認作事業所，前提是以法人名義（設立前則安排設立後切換名義）簽租賃契約，並把使用目的定為事業用（事務所）。以居住用契約原樣當事務所使用，不僅否定事業所的實體，也可能構成與出租人的契約違反。

契約前，向出租人・管理公司確認事務所利用的可否與使用目的的載明，並在重要事項說明中掌握用途地域・用途限制・原狀回復・招牌設置的可否。這些是宅地建物取引業法第35條重要事項說明與第37條書面應釐清的事項。本公司負責物件側的協調與重要事項說明，法人設立的時點與契約名義的安排，則與負責公司設立登記的司法書士、負責在留資格申請的行政書士分工推進。

| 契約論點 | 把握處 |
|---|---|
| 名義 | 法人名義（設立前與出租人就設立後名義切換達成合意） |
| 使用目的 | 載明為事業用（事務所）。勿維持居住用契約 |
| 招牌・門牌 | 於契約・管理規約確認設置可否 |
| 重要事項說明 | 用途地域・用途限制・原狀回復・費用（宅建業法第35條・第37條書面） |

## 從中國・台灣簽約時，看屋・重要事項說明如何進行？

來日前的階段，也能以線上看屋，以及宅地建物取引業法認可的IT重說（以視訊會議等進行的重要事項說明）推進手續。重要事項說明依宅地建物取引士記名的重要事項說明書進行，契約內容以第37條書面確認。

非居住者・設立前法人為當事人時，會疊加國內交易所沒有的確認：本人確認文件、簽名的取得方式、代金匯款的路徑（海外入帳）等。自中國大陸匯款可能涉及資本管制或入帳延遲，故在結算排程上預留餘裕是實務上的關鍵。本公司負責不動產交易的進行方式與重要事項說明，資本金的繳納與稅務、匯款相關的在留資格・公司設立安排，則分別交給稅理士・司法書士・行政書士。

| 進行方式 | 重點 |
|---|---|
| 看屋 | 以線上看屋縮小候補，可能時於來日時實地確認 |
| 重要事項說明 | 可由宅地建物取引士進行IT重說（依記名的重說書） |
| 本人確認 | 非居住者・設立前法人的本人確認、簽名取得方式 |
| 結算 | 於海外匯款的路徑・入帳時期預留餘裕 |

## 決定物件前，該向行政書士確認什麼？

押下物件前，就「此區劃・此契約條件是否能滿足事業所要件」與負責申請的行政書士對齊，是避免重做的捷徑。資本金3,000萬日圓以上・常勤職員1名以上・日本語B2相當・經營經驗等改正後的基準，關乎整個在留資格，事業所的寬度・實體也以是否與此規模相稱來看。

中國・台灣創業者在改正後取得「經營・管理」的全貌與申請取次，整理於[中國・台灣的創業者如何在日本取得「經營・管理」在留資格？──2025年10月改正後的要件與申請取次](https://luck428.com/legal/column/keieikanri-zairyu-chuka-kigyousha-kaisha-setsuritsu)。既有在留者有施行後3年（令和10年10月16日）的經過措施，但這是在留資格側的論點，屬行政書士領域。

| 階段 | 由誰 | 內容 |

| ② 要件對齊 | 行政書士＋本公司 | 事前確認以此區劃・契約條件能否滿足事業所要件 |

## 常見問題

**Q. 把自宅的一室當事務所能取得經營・管理簽證嗎？**
A. 2025年10月16日改正後，把自宅兼作事業所原則上不再被認可。前提是以與住居區分的獨立區劃、以法人名義・事業用目的承租的事業所。個別可否屬在留資格的論點，請向負責申請的行政書士確認。本公司負責物件能否作為獨立區劃使用的資訊提供。

**Q. 虛擬辦公室的地址能被認作事業所嗎？**
A. 只租地址的虛擬辦公室、以及任何人都能使用的共享辦公共用部，因難以呈現獨立事業所的實體，原則上不滿足事業所要件。租賃辦公室的專用個室，若有法人名義・明確區分・持續使用，有被認可的餘地，但屬個別判斷。公司設立與許認可卡關的論點，請參考行政書士的文章。

**Q. 租賃契約要以個人名義還是法人名義簽？**
A. 要被認作事業所，前提是法人名義・事業用目的。設立前，先與出租人就設立後切換為法人名義達成安排。以居住用契約原樣當事務所使用，會否定事業所的實體，也可能構成與出租人的契約違反。名義切換的時點請與負責設立登記的司法書士一併協調。

**Q. 來日前能決定物件並簽約嗎？**
A. 能以線上看屋縮小候補，並以宅地建物取引業法認可的IT重說（以視訊會議等進行的重要事項說明）推進手續。因會疊加國內交易沒有的確認（非居住者・設立前法人的本人確認、海外匯款的入帳時期等），在結算排程預留餘裕是實務上的關鍵。資本金的匯款・稅務請洽稅理士，公司設立請洽司法書士。
