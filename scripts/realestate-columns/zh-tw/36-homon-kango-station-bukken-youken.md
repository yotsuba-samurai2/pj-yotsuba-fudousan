**結論（先說重點）**：訪問看護站的物件，法令首先要求兩點——①專用事務室，②提供訪問看護所需的設備・備品（指定居宅服務等基準〈平成11年厚生省令第37號〉第62條）。因為服務是到利用者自宅，不需要像介護機構或附服務高齡者住宅那樣的居室。用途地域也相對寬鬆：訪問介護・訪問看護的事務所，依技術性助言（國住街第107號・平成27年11月13日）被視為「老人福祉中心及其類似者」，住居專用地域也有設置餘地。指定的可否由指定權者（都道府縣・地方厚生局）判斷，本公司僅止於提供物件資訊。

要新開一間訪問看護站時，最先煩惱的是「該租什麼物件」。讀介護機構或附服務高齡者住宅（sa-kou-ju）的文章，會看到居室大小・無障礙・面積基準密密麻麻排列，但訪問看護是到利用者家中的服務，物件的思考方式根本不同。本文寫給考慮新開訪問看護站的看護師・醫療法人負責人，以及尋找事業用物件的不動產實務者，把契約前可確認的事項依條文與國家資料順序整理。物件的調查・仲介・租賃仲介由本公司（四葉不動產株式會社）以資訊提供的方式承擔，指定的可否由指定權者判斷。

## 訪問看護站的物件，首先要求什麼？

訪問看護站是看護師等到利用者自宅訪問、提供療養照護與診療輔助的事業所。因為不在所內「留宿・收容」利用者，物件不需要居室、浴室、食堂。法令對物件要求的骨架，收斂為以下3點。

| 論點 | 要求什麼 | 依據 |
|---|---|---|
| 事務室 | 有事業運營所需寬度的**專用事務室** | 指定居宅服務等基準 第62條 |
| 設備・備品 | 提供訪問看護所需的設備・備品等 | 同 第62條 |
| 用途地域 | 訪問介護・看護等事務所視為「老人福祉中心及其類似者」 | 建築基準法別表第2・國住街第107號 |

**物件先起作用的是「能否確保專用事務室」。** 比起面積數值本身，更被問到的是能否與其他事業區分，取得可保管記錄・管理利用者資訊・讓員工待機與交班的寬度。事業用物件的思考見[投資用・事業用不動產](https://luck428.com/toushi)、作為開業據點的找法見[事業用據點・辦公室](https://luck428.com/office)。介護的「機構型」事業所在物件觀點上有何不同，可一併參見[「介護事業所的物件由用途地域決定」](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)。

## 事務室的寬度、感染預防的區劃，需要到什麼程度？

指定居宅服務等基準第62條規定，指定訪問看護站須「設置有事業運營所需寬度的專用事務室，並備置提供指定訪問看護所需的設備及備品等」。**全國一律的面積數值並未寫入條文。** 實務上，都道府縣・指定都市的指定申請手引會示出「所需寬度」的目安（諮詢空間・感染防止觀點等），故起步時要確認開設預定地的手引。

常被誤解為「需要獨立的感染預防區劃」，但法令作為物件構造一律義務化的，並非獨立的感染區劃本身。感染症的蔓延防止，被整理為運營基準側的要求（感染症的預防及蔓延防止對策的委員會・指針・研修・訓練），以及把設備・備品等衛生管理的要求。因此物件階段看的是以下這種「能取得區劃的素地」。

| 物件看的點 | 為何起作用 |
|---|---|
| 手部衛生設備 | 能否在事務室附近確保洗手台・水槽 |
| 器材的洗淨・消毒空間 | 能否有把訪問器材分清潔・不潔處理的作業面 |
| 清潔的保管區劃 | 能否取得可把衛生材料・記錄清潔保管的架子・區劃 |
| 隱私顧慮 | 處理利用者資訊的事務室能否與來客・共用部區分 |

數值基準與所需區劃的運用因自治體而有幅度。**起步時請直接確認開設預定地的都道府縣・指定都市所公布的指定申請手引（各自治體手引隨時改訂）。**

## 用途地域會有問題嗎（建築基準法別表第2）？

事業用物件常以用途地域為最先關卡，但訪問看護站這裡相對寬鬆。過去訪問看護等事務所被解為建築基準法（昭和25年法律第201號）第48條・別表第2的「事務所」，有一段時期被視為住居專用地域不可建。

不過，接受平成27年（2015年）規制改革實施計畫的國土交通省住宅局市街地建築課技術性助言（**國住街第107號・平成27年11月13日**），把為住民提供訪問介護・訪問看護等服務的事務所（病院・診療所・店舗等除外）視為「老人福祉中心及其類似者」，**在包含第一種低層住居專用地域的住居專用地域也能設置**的餘地擴大了。

| 用途地域 | 訪問看護等事務所的扱い目安 |
|---|---|
| 第一種・第二種低層住居專用地域 | 有以「老人福祉中心及其類似者」建造的餘地（留意規模限制） |
| 中高層・住居・準住居地域 | 易建 |
| 近鄰商業・商業・準工業地域 | 易建 |
| 工業專用地域 | 留意用途上的限制（以區域的指定確認） |

惟規模（延べ面積）的限制，以及既存建物用途變更時的確認申請（同法第87條第1項）之要否，因物件與區域而變。**用途地域上的可否與用途變更的要否，可在契約前於特定行政廳窗口確認。**

## 獨棟或租賃公寓的一室也能開設嗎？

有可能。訪問看護站不需居室，故獨棟的一部分或租賃公寓・辦公大樓的一室，只要能確保專用事務室與必要設備・備品，就能成為物件候選。選物件的階段想確認的是以下各點。

| 確認點 | 為何起作用 |
|---|---|
| 租賃契約的使用目的 | 能否作為「事務所」「事業用」使用。居住專用契約有時不可 |
| 區分所有公寓的管理規約 | 專有部分的用途限制（住居專用）是否禁止事業利用 |
| 專用區劃的確保 | 能否取得與其他事業區分的專用事務室（併設時） |
| 感染防止・衛生的素地 | 能否取得洗手・器材洗淨消毒・清潔保管的區劃 |
| 無障礙・出入 | 員工動線、記錄・器材搬出入的方便度 |

**「把作為住居承租的房間直接當事務所用」，是在契約・管理規約上易絆倒之處。** 租賃契約書的使用目的與管理規約的用途限制，在決定物件前確認。租賃契約該讀哪裡，整理於[「租賃契約書該讀哪裡」](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 指定申請・人員・登記，該找誰諮詢（分離受任）？

訪問看護站的開設，不會只靠物件完結。因為跨事業體，把擔い手分開思考。

| 要做的事 | 擔い手 |
|---|---|
| 物件的調查・仲介・租賃仲介 | 宅地建物取引業者（四葉不動產株式會社） |
| 指定申請的書類（人員・設備・運營基準的釋明） | 行政書士（四葉行政書士事務所） |
| 人員配置・常勤換算・待機（on-call）等勞務設計 | 社會保險勞務士（四葉社會保險勞務士事務所） |
| 購買物件時的所有權移轉登記 | 司法書士 |
| 稅務（開業・法人稅務） | 稅理士 |

指定的窗口，介護保險的指定居宅服務事業者（訪問看護）是都道府縣知事（指定都市・中核市是市長）（介護保險法第41條）。受此指定後，也有被視為醫療保險的指定訪問看護事業者（健康保險法第88條・第89條＝地方厚生（支）局長的指定）的機制。**指定的可否本身由指定權者（都道府縣・地方厚生局）判斷，本公司僅止於提供物件資訊。** 人員基準（看護師等常勤換算2.5以上、其中1人常勤、管理者為常勤・專從的保健師或看護師）由第60條・第61條規定，但滿足此的配置與常勤換算・待機（on-call）的工資設計，屬社會保險勞務士領域。

## 該找誰諮詢？

物件的調查、仲介、買賣・租賃契約，由四葉不動產株式會社（宅地建物取引業 東京都知事(1)第113304號）承辦。指定申請等向官公署提出的書類製作，由四葉行政書士事務所承辦。人員配置・常勤換算・待機手當等勞務設計由四葉社會保險勞務士事務所，購買時的所有權移轉登記由司法書士，稅務由稅理士，各自處理其領域。

**這些各為獨立的事業體，須各自直接簽約。** 本公司・本事務所，不收取也不支付介紹費・送客手續費。指定的可否由指定權者（都道府縣・地方厚生局）判斷。諮詢免費。

## 常見問題

**Q. 訪問看護站的物件有規定的最低面積嗎？**
A. 指定居宅服務等基準第62條要求「有事業運營所需寬度的專用事務室」，但全國一律的面積數值未寫入條文。實務上都道府縣・指定都市的指定申請手引會示出目安，故起步時請確認開設預定地的手引。手引隨時改訂。

**Q. 感染預防用的獨立房間（區劃）一定要嗎？**
A. 法令並非把「獨立的感染區劃」作為物件構造一律義務化。感染症的蔓延防止是運營基準（委員會・指針・研修等）與衛生管理的要求，物件階段看的是能否在事務室內取得洗手・器材洗淨消毒・清潔保管的區劃。詳情請於開設預定地的手引確認。

**Q. 住居專用地域也能開訪問看護站嗎？**
A. 有餘地。訪問介護・訪問看護等事務所，依技術性助言（國住街第107號・平成27年11月13日）被視為「老人福祉中心及其類似者」，在包含第一種低層住居專用地域的住居專用地域也被認為可設置。惟規模限制與用途變更之要否因物件與區域而變，請向特定行政廳確認。

**Q. 租賃公寓的一室也能開設嗎？**
A. 若能確保專用事務室與必要設備・備品，且租賃契約的使用目的與管理規約認可事業利用，就是候選。因居住專用契約或管理規約的用途限制可能絆倒，決定物件前請確認契約書與規約。可否的最終判斷由指定權者作出。
