**先講重點**：能不能當就業轉銜支援事業所的物件，由三點決定：建築基準法上的用途是否通過、是否能以所需面積確保指定基準省令要求的訓練・作業室與相談室、消防法上的分類與設備是否足夠。就業轉銜支援（就労移行支援）是「障害者綜合支援法」的訓練等給付，標準利用期間原則2年。以「為就業而訓練與實習的空間」為前提，正是它與就労繼續支援A型・B型設計起點不同之處。物件的用途地域・用途變更要否・消防現況的確認由本公司負責，指定申請交給行政書士、用途變更的確認申請交給建築士、職員的勞動條件與社會保險交給社會保險勞務士。各為獨立事業體，分別簽約。

寫給想開設就業轉銜支援事業所的事業者，以及想將物件出租作此用途的屋主，依建築基準法、指定基準省令、消防法的順序，整理「什麼樣的物件能用」。本文為一般性資訊提供，指定能否通過、是否符合設備基準的最終判斷，屬指定權者（都道府縣・政令市等）・建築士・所管消防的領域。

四葉不動產株式會社以東京都文京區小日向為據點，承接事業用物件的租賃仲介與用途地域・用途變更的事前確認。關於就業轉銜支援的物件，歡迎從決定簽約前的階段與我們洽談。

## 就業轉銜支援事業所要求的物件基本條件是什麼？

就業轉銜支援，是為希望進入一般就業的身心障礙者，提供就業所需知識與能力的訓練、職場實習、求職活動支援等的服務。它是依「障害者綜合支援法」（平成17年法律第123號）的指定障害福祉服務之一，定位為訓練等給付，標準利用期間原則2年（障害者綜合支援法施行規則第6條之9；即使准予更新，也以1次・1年為目安，使用按摩指壓・針・灸等養成設施者為3年或5年）。

這個「2年內送往一般就業」的前提，使它與工資型的B型、僱用契約型的A型（皆為就労繼續支援）在設計起點上分道。就業轉銜支援以訓練室、模擬職場的實習空間、求職與面談用的相談室為中心。選物件時主要有三點。

| 確認的軸 | 物件要看的重點 | 根據 |
| --- | --- | --- |
| 建築基準法上的用途 | 該用途地域能否建、是否需用途變更的確認申請 | 建築基準法第48條・別表第二、第87條 |
| 指定基準省令的設備 | 能否確保訓練・作業室、相談室、洗面所、便所 | 平成18年厚生勞動省令第171號 第178條・第179條 |
| 消防法上的分類與設備 | 防火對象物的分類，以及能否配備所需消防用設備 | 消防法施行令別表第一(6)項 |

就労繼續支援A型・B型的物件思路，整理於[就労繼續支援A型的物件如何確認用途地域與消防（日文）](https://luck428.com/zh-tw/column/shuro-keizoku-shien-a-bukken-youto-chiiki)與[就労繼續支援B型的物件在用途地域與消防哪裡會卡（日文）](https://luck428.com/zh-tw/column/shuro-keizoku-shien-b-bukken-youto-chiiki-shobo)。本文處理以訓練與實習為中心的就業轉銜支援所特有的物件條件。

## 用途地域與建築基準法上的「用途」如何確認？

就業轉銜支援事業所屬建築基準法施行令第19條第1項的「兒童福祉設施等」。該項除兒童福祉設施外，將老人福祉設施、障害者支援設施，以及生活介護・自立訓練・就業轉銜支援・就労繼續支援等障害福祉服務事業所用設施，定位為「兒童福祉設施等」；就業轉銜支援即以此用途處理。

此用途能建於哪些用途地域，由建築基準法第48條・別表第二及施行令第130條各條按地域逐一決定。將原為事務所・店鋪・住宅使用的既有建物改為就業轉銜支援事業所時，用途變更的確認申請要否，是選物件的分水嶺。

| 確認項目 | 根據・重點 |
| --- | --- |
| 用途該當 | 屬施行令第19條第1項的「兒童福祉設施等」（明載就業轉銜支援） |
| 用途地域能否 | 依建築基準法第48條・別表第二、施行令第130條各條逐件確認 |
| 用途變更的確認申請 | 變更部分的樓地板面積超過200㎡者，使用前須確認申請（建築基準法第6條第1項・第87條） |
| 採光・避難 | 作為兒童福祉設施等，採光與避難相關規定較嚴 |

由事務所或宿舍（員工宿舍等）改用時，樓地板面積超過200㎡者，使用前須確認申請。即使在200㎡以下，採光・避難・消防各規定的符合仍另行被要求。用途地域符合與確認申請要否的最終判斷屬特定行政廳・建築士的領域，本公司整理現況用途與面積，確認申請轉介建築士。

## 無障礙、訓練室、相談室的面積與設備要到什麼程度？

指定基準省令（指定障害福祉服務事業等的人員、設備及營運相關基準・平成18年厚生勞動省令第171號）就就業轉銜支援的設備基準（第178條・第179條），要求設置訓練・作業室、相談室、洗面所、便所。訓練・作業室須為「訓練或作業不受妨礙的寬度」，相談室須設間隔等以防談話外洩。

要注意的是，訓練・作業室的每位利用者面積，並未以全國一律的數值訂定。民間解說所示的「每人◯㎡」是實務・建議的目安，並非省令本體的數值。此處不作斷定，標為【未驗證】，以向所管指定權者的條例・手引與事前協議確認為前提。

| 設備 | 要求 | 面積・數值的處理 |
| --- | --- | --- |
| 訓練・作業室 | 訓練或作業不受妨礙的寬度、必要的機械器具 | 無全國一律的㎡/人基準；目安為指定權者的運用【未驗證】 |
| 相談室 | 以間隔等使談話不外洩 | ― |
| 洗面所・便所 | 因應利用者的特性 | ― |
| 多目的室等 | 無妨礙時可與相談室兼用 | ― |
| 無障礙 | 高低差・通道寬度・扶手等可能依條例加碼 | 以條例・手引確認 |

無障礙的水準，可能因利用者的障礙特性與當地條例而加碼。需要幾㎡・何種規格的最終可否由指定權者・建築士判斷，故押下物件前須與指定權者事前協議。指定申請的手續由行政書士以另約承接。

## 消防法上的設備與防火對象物的分類如何？

消防法施行令別表第一(6)項區分社會福祉設施等：因身體上・精神上理由自行避難困難者為主要入所・利用對象者屬(6)項ロ，其餘屬(6)項ハ。採通所、且不以避難困難者為主要對象的就業轉銜支援，原則屬(6)項ハ；但會綜合服務內容、利用者的避難困難性、收受體制，由所管消防逐件判斷。

| 確認項目 | 重點 |
| --- | --- |
| 防火對象物分類 | 通所的就業轉銜支援原則(6)項ハ；以避難困難者為主要對象則可能(6)項ロ |
| 消防用設備 | 依分類・面積・樓層：自動火災報知設備・滅火器・引導燈等；因分類而變 |
| 判斷主體 | 由所管消防（消防署・預防課）逐件判斷；物件確定前先洽詢 |
| 既有建物 | 所需設備能否後裝（配線・區劃）是選定的分水嶺 |

所需消防用設備的細節與工程費，因機器構成與建物而異，此處同樣不作斷定、標為【未驗證】，以消防設備士・建築士・所管消防的確認為前提。本公司將既設消防用設備與分類的見込整理為物件資訊，設計・工程・確認申請轉介各專家。

## 指定申請・用途變更・勞務該找誰？（分離受任）

就業轉銜支援的開設，橫跨不動產・許認可・建築・勞務等不同事業體。順序取錯，可能簽下無法用途變更的物件、在消防分類上走回頭路，或在整備職員勞動條件前就到了開設日。

| 角色 | 由誰負責 |
| --- | --- |
| 物件用途・結構・消防現況調查、重要事項說明、租賃仲介 | 宅地建物取引業（本公司） |
| 障害福祉服務事業者的指定申請、與指定權者的協議 | 行政書士 |
| 用途變更的確認申請、採光・避難・消防設計 | 建築士・特定行政廳 |
| 職業指導員・就業支援員等的勞動條件、就業規則、社會保險手續 | 社會保險勞務士 |
| 用途變更伴隨的表題變更等登記 | 司法書士 |
| 報酬請求・會計・稅務 | 稅理士 |

障害福祉服務事業者的指定申請是行政書士的業務，本公司不代辦。職業指導員・就業支援員等職員的工時・休息・就業規則・社會保險的設計，屬社會保險勞務士的領域。

這些**各為獨立事業體**，以**分別簽約**為前提。本公司負責物件的用途・結構・消防現況確認與租賃仲介，指定申請交給行政書士、用途變更的確認申請與設計交給建築士、勞動條件與社會保險交給社會保險勞務士、登記交給司法書士、會計與稅務交給稅理士。本公司不收取也不支付介紹費・送客手續費。

## 常見問題

**Q. 就業轉銜支援能與就労繼續支援A型・B型用同一物件開設嗎？**
A. 建築基準法上的用途三者皆為「兒童福祉設施等」，故用途地域・用途變更・採光・避難・消防的框架重疊。但就業轉銜支援標準利用期間原則2年，以朝向一般就業的訓練室・實習空間・相談室為中心，這是設計起點上的不同。設備該當請向指定權者、用途判斷請向建築士確認。

**Q. 想把事務所或員工宿舍改為就業轉銜支援事業所，需要確認申請嗎？**
A. 變更部分的樓地板面積超過200㎡者，使用前須用途變更的確認申請（建築基準法第6條第1項・第87條）。即使在200㎡以下，採光・避難・消防各規定的符合仍另行被要求。該判斷與設計屬建築士・特定行政廳的領域，本公司整理現況用途與面積並轉介建築士。

**Q. 訓練・作業室每位利用者需要幾㎡？**
A. 指定基準省令（平成18年厚生勞動省令第171號第178條）只說「訓練或作業不受妨礙的寬度」，未訂全國一律的每人㎡數。民間解說所示數值為實務・建議的目安，非省令數值（本文作【未驗證】處理）。所需面積因定員、訓練內容、指定權者的條例而變，請於物件確定前以事前協議確認。

**Q. 職員的勞動條件與社會保險，能向不動產公司諮詢嗎？**
A. 不行。職業指導員・就業支援員等職員的工時・就業規則・社會保險設計屬社會保險勞務士的領域，本公司不處理。物件與用途的確認由本公司、指定申請交給行政書士、勞務交給社會保險勞務士，各為獨立事業體、分別簽約。
