**結論（先說重點）**：產業廢棄物的「轉運・保管」據點，不是租個倉庫或堆置場就夠。物件上發揮作用的有三點。①用途地域——若設置上屋等建築物，受建築基準法第48條・別表第二的用途限制，實務上準工業・工業・工業專用地域較合適。②圍籬與告示板——需要防止飛散・洩漏・地下滲透・惡臭的圍籬，以及縱橫各約60cm以上的告示板。③保管上限量與高度——轉運用的保管量以1日平均搬出量的7日份為上限，露天不使用容器堆放時受高度限制。物件的選定・用途地域確認由本公司（四葉不動產株式會社），含轉運・保管的產業廢棄物收集運搬業許可申請由行政書士，設施基準的適合確認・建築確認由建築士，各自作為獨立事業體、分別直接簽約承擔。

想在收集運搬業設一個做「轉運・保管」的據點，卻不知道哪種物件能符合基準——本文寫給尋找此類據點物件的業者：簽約前能從不動產一側確認的點，依廢棄物處理法・建築基準法的條文與自治體的許可申請手冊整理。物件的調查・選定由本公司以資訊提供承擔，許可可否與設施基準的最終適合判斷由行政書士・建築士等有資格者為之。單純運送（無轉運保管）與在據點暫時保管的轉運・保管，物件要求的條件明顯不同。

## 能做產業廢棄物轉運・保管的物件，適合哪種用途地域？

首先要把「保管場所本身」與「在其上蓋的建築物」分開想。只在露天堆放、不伴隨建築物的保管場所，不直接受用途地域的建築限制。反之，若設置上屋・倉庫・事務所等建築物，該建築物受建築基準法第48條・別表第二的用途限制。

此外，選址在自治體的產業廢棄物處理業許可審查中也會被檢視。住居系用途地域易與鄰里及生活環境起衝突，多數自治體的手冊以工業系（準工業・工業・工業專用地域）為前提說明。

| 論點 | 物件上要確認的事 |
|---|---|
| 是否蓋建築物 | 設上屋・事務所受建築基準法第48條・別表第二限制；住居專用地域不可或限制嚴格 |
| 是否露天堆放 | 非建築物則不直接受用途地域限制，但自治體的選址基準（避開住居系）另有 |
| 市街化調整區域 | 伴隨建築物時，都市計畫法的開發許可・建築許可是另一道牆 |
| 鄰里環境 | 飛散・惡臭・噪音・車輛出入是否與周邊衝突 |

## 圍籬・告示板・防止飛散洩漏等，物件側需要什麼設備？

保管產業廢棄物時，須符合施行令所定的保管基準，以免對生活環境造成妨礙（廢棄物處理法第14條、施行令第6條第1項第1號）。轉運用的保管也以此為前提。物件選定階段能確認的，是以下設備・區劃能否事後整備。

| 要求 | 物件上確認的點 |
|---|---|
| 圍籬 | 能否在保管場所周圍設圍籬；廢棄物荷重直接施加時能否承受 |
| 告示板 | 是否有地方掛縱橫各約60cm以上的告示板（表示為保管場所・種類・管理者與聯絡方式・最大高度等） |
| 防止飛散・洩漏 | 能否防止風吹飛散、雨水洩漏；有無屋頂・防塵布・區劃的素地 |
| 地下滲透・污水 | 油分與污液能否不滲入地下；地面混凝土鋪裝・排水・油水分離能否做到 |
| 惡臭・害蟲 | 惡臭是否波及周邊；若處理易腐品目，有無密閉・換氣餘地 |

這些取決於物件的「素地」。打好土間混凝土、易設排水與圍籬的平地倉庫・工廠・堆置場易於符合；土壤裸露、無排水路徑的土地，地下滲透對策的工程負擔較大。

## 能保管的上限量與面積・高度限制如何決定？

轉運・保管有數量上限。轉運用能保管的產業廢棄物量，以該場所1日平均搬出量乘以7（約7日份）為上限。旨在「運送途中暫時放置」的保管，而非長期庫存場。

高度也有限制。露天不使用容器保管時，未接觸圍籬的部分坡度約50%以下，接觸圍籬的部分須壓低（使荷重不施於圍籬：內側2m以內低於圍籬高度50cm，超過2m的部分坡度50%以下）。數量・高度的具體數字，自治體的許可申請手冊有圖解。

| 項目 | 目安 |
|---|---|
| 轉運用保管上限量 | 1日平均搬出量的7日份 |
| 露天・無容器堆積高度 | 未接觸圍籬部分坡度50%以下，接觸圍籬部分再受限 |
| 必要面積 | 由品目・搬出量・車輛回轉逆算（參手冊的圖） |
| 品目別附加基準 | 含石綿產業廢棄物・特別管理產業廢棄物等有上乘基準 |

也就是說，物件的大小不是「能堆越多越好」，而是看能否在守住圍籬・高度限制下，取得由搬出量逆算的必要量的平地。

## 無轉運保管的收集運搬，物件要件有何不同？

同為產業廢棄物收集運搬業，「不含轉運・保管」與「含」，物件要求的條件差異很大。

| | 無轉運・保管 | 有轉運・保管 |
|---|---|---|
| 物件（據點）的定位 | 多半有停車的車庫・事務所即可 | 符合保管基準的保管場所本身成為許可對象 |
| 用途地域・選址 | 看事務所・車庫的用途限制 | 連保管場所的選址・圍籬・排水都看（工業系合適） |
| 數量・高度限制 | ——（不做轉運・保管） | 平均搬出量7日份・堆積高度限制生效 |
| 許可範圍 | 收集運搬業（除轉運保管） | 收集運搬業（含轉運保管）——申請區分不同 |

「只運送」多半用符合車庫與事務所要件的物件即可；「在據點暫時保管」則以該保管場所符合保管基準為許可前提。若在此搞錯而簽了住居系用途地域或無排水的土地，恐事後無法整備設施、達不到許可。決定物件前，先確定處理品目・搬出量與是否轉運・保管，較為安全。

## 常見問題

**Q. 租了倉庫就能馬上做產廢的轉運・保管嗎？**
A. 常常不能馬上。轉運・保管場所須符合圍籬・告示板・防止飛散洩漏・地下滲透對策等保管基準（廢棄物處理法第14條、施行令第6條第1項第1號），在住居系用途地域或無排水的土地難以符合。決定物件前，先確認處理品目・搬出量與設施能否整備較安全。

**Q. 能保管多少量？**
A. 轉運用的保管量以該場所1日平均搬出量的7日份為上限。定位是運送途中暫時放置的保管，而非長期庫存場。具體數量・高度的圖解載於自治體的許可申請手冊。

**Q. 用途地域哪裡都行嗎？**
A. 若設上屋等建築物，受建築基準法第48條・別表第二限制，住居專用地域不可或限制嚴格。即使露天不伴隨建築物，多數自治體為避免生活環境妨礙，也以工業系（準工業・工業・工業專用）為前提說明。

**Q. 許可申請的文書製作也能拜託嗎？**
A. 許可申請文書由行政書士（四葉行政書士事務所）承接。本公司（不動產）負責物件選定・用途地域確認・媒介，設施基準的適合確認與建築確認由建築士承擔。這些以獨立事業體、分別直接簽約。
