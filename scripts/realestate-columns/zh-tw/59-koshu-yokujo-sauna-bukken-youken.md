**結論（先說重點）**：三溫暖・錢湯・SPA的物件，最先發生作用的是：①用途地域——公眾浴場除「個室付浴場業」外，可在相當廣的用途地域內興建，這裡不易卡關；②公眾浴場法要求的構造設備基準——由都道府縣條例訂定，各自治體不同；③用途變更的確認申請——公眾浴場屬建築基準法的特殊建築物，該用途超過200㎡原則需要；④給排水・換氣・退伍軍人桿菌對策，共4點。選物件真正的關卡不在用途地域，而在構造設備與用途變更・消防。簽約前確認條例與檢查完成證，就能防止返工。

被告知「上一位承租人的浴室設備還留著，可以馬上開」而承租，卻在營業許可階段被保健所與特定行政廳雙方要求重做。餐飲店或診所物件會發生的返工，三溫暖・錢湯也一樣。本文寫給在東京新開三溫暖・錢湯・SPA的業者，以及出租這類物件者，依公眾浴場法・建築基準法・消防法的條文與厚生勞動省的要領，整理簽約或購買前可確認的事項。營業許可的取得本身屬行政書士領域，另文處理；本文聚焦於不動產側看到的物件條件。可否的最終確認，於特定行政廳・保健所・消防署的窗口進行。

## 三溫暖・錢湯的物件，在用途地域能設在哪裡？

先講結論，**用途地域不易成為關卡**，這是三溫暖・錢湯的特徵，與餐飲店、美容室不同。

建築基準法（昭和25年法律第201號）別表第二，就各用途地域訂定可興建的建築物。公眾浴場，即使在限制最嚴的第一種低層住居專用地域，也以「公眾浴場（**除個室付浴場業所涉者外**）」列為可興建的建築物，往上的用途地域亦可興建。因為錢湯長期被定位為地域生活所需的設施。

| 用途地域 | 公眾浴場（除個室付浴場業）的處理 |
|---|---|
| 第一種・第二種低層住居專用地域／田園住居地域 | 可興建（個室付浴場業所涉者不可） |
| 中高層・住居・準住居地域 | 可興建 |
| 鄰近商業・商業・準工業・工業地域 | 可興建 |
| 工業專用地域 | 須確認自治體的運用 |

需要留意的是「**個室付浴場業所涉之公眾浴場**」。這依風俗營業等的規制及業務適正化等相關法律，用途地域受大幅限制。**一般的三溫暖・錢湯・超級錢湯・岩盤浴不屬個室付浴場業**，但依企劃內容，界線須確認。

因此選物件時該先排除的不是用途地域，而是接下來要談的構造設備・用途變更・消防。用途地域與容積率如何牽動土地估價，整理在[日本的土地值為何隨「容積率」而變](https://luck428.com/column/yosekiritsu-hosei-tochine)；消防與自治體的確認先於契約的例子，整理在[能開民泊的物件條件](https://luck428.com/column/minpaku-bukken-joken-kakunin)。

## 公眾浴場法要求的構造・設備要件是什麼？

以營業方式經營公眾浴場，需要都道府縣知事的許可。公眾浴場法（昭和23年法律第139號・最終修正 平成23年法律第122號）第2條第1項規定「以營業方式經營公眾浴場者，須取得都道府縣知事的許可」。第1條把公眾浴場定義為「使用溫湯、潮湯或溫泉其他，使公眾入浴的設施」，三溫暖・錢湯・SPA均屬之。

而許可的可否，取決於物件的作法。同法第2條第2項規定，知事於認定公眾浴場的設置場所或構造設備在公眾衛生上不適當，或設置場所欠缺配置的適正時，可不予許可；同條第3項則規定，**其配置基準與構造設備基準由都道府縣以條例訂定**。第3條進而要求換氣・採光・照明・保溫・清潔及其他公眾衛生上必要的措施，其基準亦委由條例。

**也就是說，具體的數值（浴室・脫衣室的大小、給湯・洗場、換氣能力等），由各都道府縣〈設有保健所的市・特別區則為該市・區〉的條例訂定，各自治體不同。** 「隔壁縣以這個大小通過」不一定能沿用。

在物件側，比起條例數值本身，該先確認的是**有無能滿足該數值的底子**。

| 簽約前確認 | 為何有效 |
|---|---|
| 能否男女別區隔脫衣室與浴室的格局 | 多數條例要求男女別・明確區隔・遮擋 |
| 給排水的位置與口徑・給湯能力 | 浴槽・淋浴・三溫暖需大量給湯與排水 |
| 換氣設備的有無與增設餘地 | 高溫多濕的排出靠換氣確保 |
| 電氣・瓦斯容量 | 三溫暖加熱器・鍋爐・循環過濾需容量 |
| 地板・牆壁的防水與防濕 | 耐常態濕氣的底子。與復原範圍也相關 |

給排水・換氣・電氣的設計屬施工業者（設計者）領域。**本公司（不動產公司）陪伴進行物件能否滿足這些條件的先期調查，以及與出租人的條件協商。** 設備設計本身不做。

另外，公眾浴場有**一般公眾浴場（即所謂錢湯）**與**其他公眾浴場（三溫暖・超級錢湯・岩盤浴・SPA等）**的區分。一般公眾浴場常以條例設有與既設浴場保持距離的配置基準（距離限制），入浴費也是物價統制令的統制對象。另一方面，其他公眾浴場原則不受距離限制，費用亦自由。**新開三溫暖・SPA通常屬「其他公眾浴場」，較不受配置基準之牆**，但構造設備基準仍由條例另定。屬何者依企劃而變，請於著手時向管轄保健所確認。

## 在給排水・換氣・退伍軍人桿菌對策上，選物件有效的點是？

三溫暖・錢湯的物件，比餐飲店更需處理**水與熱與濕氣**，這直接連到選物件。

第一，給湯與排水的能力。浴槽・淋浴・冷水浴使用大量湯水，排水也相應大。簽約前，與施工業者一起看看前面的給排水管口徑、貯湯・鍋爐的放置處、排水的坡度與接續處，能減少返工。

第二，換氣。能否設置把高溫多濕排到室外的路徑（風管・進氣口・排氣口），出租人是否允許穿越外牆・屋頂，與餐飲店的排氣風管是同一議題。此結構與[在毛胚（skeleton）物件開餐飲店時，排氣・油脂截留器・防火把選物件決定到什麼程度](https://luck428.com/column/inshokuten-skeleton-bukken-haiki-grease)相通。

第三，退伍軍人桿菌（Legionella）對策。循環式浴槽在過濾器與配管易繁殖退伍軍人桿菌，公眾浴場的退伍軍人症集體感染過去曾成問題。厚生勞動省的「公眾浴場衛生等管理要領」示明浴槽水的消毒（氯等）・循環過濾裝置的管理・推薦掛流式・貯湯槽的溫度管理等（**2026年9月16日參照**）。在物件階段，**有無能放置循環設備的機械室空間、以及能把配管做短而簡單的底子**，會左右日後衛生管理的難易。

| 物件要看的點 | 何時發揮作用 |
|---|---|
| 給湯・鍋爐的設置場所與容量 | 浴槽・淋浴・三溫暖同時使用能否承受 |
| 排水的口徑・坡度・接續處 | 大量排水與油分・毛髮的處理 |
| 換氣・排氣的路徑與能否穿越 | 高溫多濕的排出。需出租人許可 |
| 機械室（循環過濾・貯湯）的空間 | 退伍軍人桿菌對策與維護的難易 |

這些設計・施工由施工業者、衛生管理的運用由開設者負責。本公司陪伴進行物件是否具此底子的先期調查。

## 中古物件的用途變更・檢查完成證如何確認？

這裡是三溫暖・錢湯特有的關卡。**公眾浴場屬建築基準法的特殊建築物**（別表第一(い)欄(4)項列有「公眾浴場」）。

因此，把曾是事務所或店舖的中古物件改為三溫暖・錢湯時，**該用途所用部分的樓地板面積超過200㎡，原則就需要用途變更的確認申請**。建築基準法第87條第1項，就變更用途為同法第6條第1項第1號的特殊建築物（別表第一(い)欄用途且超過200㎡）時，準用確認手續。這與美容室、診所不易觸及用途變更確認形成對比，漏看這點，開業就會停住。

同時，確認**檢查完成證（檢查済証）**的有無。沒有檢查完成證的中古建物，可能在用途變更確認申請或金融機構融資上出現障礙。即使沒有，有時可透過法適合狀況調查確認興建時的合法性，並須辨別是既存不適格還是違反建築。此議題整理在[沒有檢查完成證的中古物件能否轉為福祉設施](https://luck428.com/column/kensazumisho-nashi-bukken-fukushi-youto-henko)。

| 中古物件確認 | 在哪裡・誰 | 為何有效 |
|---|---|---|
| 該用途部分是否超過200㎡ | 圖面・特定行政廳 | 超過則需用途變更的確認申請（第87條） |
| 檢查完成證的有無 | 檢查完成證・台帳記載事項證明 | 沒有時法適合調查的要否 |
| 是既存不適格還是違反建築 | 建築士・特定行政廳 | 直接影響改正的可否與費用 |
| 消防用設備的現況 | 消防署・圖面 | (9)項イ・ロ要求的設備會變 |

還有消防。消防法施行令別表第一，把**三溫暖（蒸氣浴場・熱氣浴場其他類此的公眾浴場）列為(9)項イ**，其他公眾浴場列為(9)項ロ。(9)項イ因處理火氣・高溫，消防用設備與避難的基準可能比(9)項ロ更嚴。用途變更・建築確認由建築士（指定確認檢查機關）、消防同意・消防用設備由消防署處理。**用途變更的要否・檢查完成證・消防設備，都能在簽約前於特定行政廳與消防署窗口確認。** 事業用物件全般請見[投資用・事業用不動產](https://luck428.com/toushi)，事務所與許認可的關係請見[公司設立與辦公室選擇](https://luck428.com/office)。照護事業所發生同樣返工的原因，整理在[為何找不到照護事業所的物件](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)；契約書要讀哪裡，整理在[租賃契約書，該讀哪裡](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 許可申請・建築確認・消防各該委託誰？

開三溫暖・錢湯，是牽涉專家多的領域。一開始先做好分工就不會迷路。

| 要做的事 | 負責 |
|---|---|
| 物件的調查・條件確認・仲介・買賣/租賃契約 | 四葉不動產株式會社（宅地建物取引業） |
| 公眾浴場的營業許可申請・向保健所提出的書類製作 | 行政書士 |
| 用途變更・建築確認的設計・申請 | 建築士（指定確認檢查機關） |
| 消防同意・消防用設備・防火對象物的申報 | 消防署・消防設備士 |
| 給排水・換氣・循環過濾的設備設計與施工 | 施工業者 |

物件的調查、仲介、買賣・租賃的契約，由四葉不動產株式會社（宅地建物取引業 東京都知事(1)第113304號）承接。公眾浴場的營業許可申請等向官公署提出的書類製作，由四葉行政書士事務所承接。**這兩者（不動產公司・行政書士事務所）是各自獨立的事業體。請分別直接與各自簽約。** 本公司與本事務所，既不收取也不支付介紹費・轉介費。用途變更・建築確認的設計請找建築士，消防用設備請找消防設備士，登記請找司法書士，稅務請找稅理士，各自直接委託。諮詢免費。**行政的窗口・格式・條例的數值・受理的運用會變。請於著手時直接確認管轄保健所・特定行政廳・消防署的頁面。**

## 常見問題

**Q. 三溫暖・超級錢湯能開在住宅區（第一種低層住居專用地域）嗎？**
A. 建築基準法別表第二，即使在第一種低層住居專用地域，也把「公眾浴場（除個室付浴場業所涉者外）」列為可興建的建築物。單看用途地域有開設的餘地。但公眾浴場法的構造設備基準（都道府縣條例）、用途變更的確認申請、消防、對鄰近的顧慮，會另外發生作用。用途地域上的可否依物件而異，請於特定行政廳窗口確認。

**Q. 上一手也是浴場的居抜（帶裝潢）物件，能否原樣通過營業許可？**
A. 不一定。公眾浴場法的許可是就物件與經營者取得，上一手的許可不會承接，條例或運用也可能已修正。請於交屋前檢查殘留設備（浴槽・循環過濾・鍋爐）的狀態、對現行條例基準的適合、退伍軍人桿菌對策的作法、消防用設備的現況，並向保健所・消防署確認。

**Q. 把辦公大樓的一室改為三溫暖，需要用途變更的確認申請嗎？**
A. 公眾浴場屬建築基準法的特殊建築物，故該用途所用部分的樓地板面積超過200㎡時，原則需要用途變更的確認申請（建築基準法第87條第1項）。即使在200㎡以下，用途地域的限制與採光・換氣・防火等實體規定仍會適用。要否依樓地板面積・構造・區域而變，請於簽約前向特定行政廳確認。

**Q. 三溫暖在消防法上，與普通錢湯的處理不同嗎？**
A. 不同。消防法施行令別表第一，把蒸氣浴場・熱氣浴場其他類此的公眾浴場（三溫暖）列為(9)項イ，其他公眾浴場列為(9)項ロ。(9)項イ因處理火氣・高溫，消防用設備與避難的基準可能比(9)項ロ更嚴。所需設備也隨建物的規模・樓層而變，請向消防署確認。
