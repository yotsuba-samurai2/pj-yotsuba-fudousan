**結論（先說重點）**：賣繼承到的空屋時，「拆除後賣素地」或「連同老屋（現況）賣」取決於四點——①拆除費用，與拆為素地後住宅用地特例消失、固定資產稅上升；②買方族群（素地適合想蓋屋的人，連同老屋適合重視價格、DIY、投資者）；③契約不符責任與拆除費負擔；④空屋3000萬日圓特別扣除（租稅特別措置法35條3項）的適用方式。特別是該扣除已整理成「先拆為素地再賣／買方於交屋後拆除」兩種都能用的形式，因此拆除時點左右手取金額。稅額計算交稅理士，滅失登記交土地家屋調查士・司法書士。

繼承到的老家變成空屋，真要賣時必定撞上的，就是「先拆再賣，還是原樣賣」。何者較划算因物件與買方而異，沒有一律的正解。本文寫給想賣繼承空屋的繼承人，整理**素地交付與連同老屋交付這兩種賣法本身的差異**（費用、期間、買方族群、契約不符責任、稅的特例）。放置不管的風險與扣除的逆算另有專文，此處聚焦於「拆或不拆」的判斷。

## 賣素地與連同老屋賣，對買方而言有何不同？

同一塊地，作為素地與連同老屋，**買方族群會不同**。

素地適合想馬上蓋屋的人、建商、建售業者。若界址與地中埋設物清楚，買方能立即規劃建築計畫。連同老屋（現況交付），則適合**想壓低價格、以DIY或改建為前提、想作投資出租的人**。即使不認老屋的價值，也能成立「拆除費由買方負擔、故相應便宜」的定價。

| | 素地交付 | 連同老屋（現況交付） |
|---|---|---|
| 主要買方族群 | 想馬上蓋屋・建售業者 | 重視價格・DIY・改建・投資 |
| 賣方初期費用 | 拆除費先支出 | 不支出 |
| 至交屋的期間 | 因拆除而延長 | 較快 |
| 是否易於辨識 | 高（看得到地形） | 建物遮擋視線 |

何者賣得較高，取決於區位與建物狀態。土地價值如何隨容積率變動見[此處](https://luck428.com/column/yosekiritsu-hosei-tochine)，「賣或留」的整體判斷見[此處](https://luck428.com/column/souzoku-jikka-uru-nokosu)。

## 拆除費用，與拆為素地後固定資產稅上升，各要抓多少？（稅額交稅理士）

拆為素地前，務必掌握**固定資產稅的住宅用地特例**。

地方稅法對建有住宅的土地（住宅用地）之固定資產稅，減輕其課稅標準。**小規模住宅用地（200㎡以下的部分）課稅標準減為6分之1**，超過部分之一般住宅用地減為3分之1（都市計畫稅分別為3分之1、3分之2）。**拆除建物成為素地，此住宅用地特例消失，固定資產稅上升。**

常有人說「拆為素地後固定資產稅變6倍」，但這並不精確。特例消失後課稅標準上升，惟素地有負擔調整措施與非住宅用地上限（課稅標準為評價額的70%）在運作，故**實際增幅並非恰好6倍**。增幅因自治體、評價額而異。

| 狀態 | 小規模住宅用地固定資產稅的課稅標準 |
|---|---|
| 建有房屋（住宅用地） | 評價額的6分之1 |
| 拆除為素地 | 特例消失（有負擔調整・非恰好6倍） |

此外，被放置的空屋若被指定為**「特定空家等」或「管理不全空家等」**並收到市町村勸告，其基地會被排除於住宅用地特例之外（空家等對策特別措置法）。不拆除、僅是放置，也可能使特例消失，須留意。**具體稅額與增幅的試算交稅理士**，放置風險請另行確認。

## 連同老屋賣，契約不符責任與拆除費負擔如何？

賣連同老屋土地時的重點是**契約不符責任**（舊稱瑕疵擔保責任）。

民法規定，所賣之物不符契約內容時，買方可請求追完（修補）・減少價金・損害賠償・解除契約（民法562條以下）。老舊空屋易出現漏水、白蟻、給排水故障，原樣出售可能日後被追究此責任。

因此個人間的中古交易，常附上**「以現況有姿交付、不負契約不符責任（免責）」的特約**。民法上，契約不符責任可以特約減輕・免除（惟賣方明知而未告知之事實不及於免責）。

須注意**賣方為宅地建物取引業者、買方為個人（非業者）**的情形。此時依宅地建物取引業法40條，除將契約不符責任的通知期間定為「自交屋日起2年以上」外，其餘對買方不利的特約無效。個人賣方與業者賣方，免責特約的效力不同。

| | 個人為賣方 | 業者為賣方・買方為個人 |
|---|---|---|
| 契約不符責任的免責特約 | 原則有效（明知未告知者除外） | 受40條限制（自交屋起2年以上等） |
| 拆除費之處理 | 以「買方負擔、故便宜」等織入價格 | 同樣以價格・條件調整 |

拆除費要「由賣方負擔、拆為素地後交付」或「由買方負擔、連同老屋便宜交付」，是價格協商的內容。選哪一種，也會改變下述稅的特例的用法。

## 若要用3000萬日圓特別扣除，拆除時點會改變什麼？（適用可否交稅理士）

賣繼承空屋時的一大要素，是**「被繼承人的居住用財產（空屋）出售時的3000萬日圓特別扣除」（租稅特別措置法35條3項）**。可自讓渡所得扣除最多3000萬日圓（繼承人3人以上時每人2000萬日圓）。

主要要件如下。

| 要件 | 內容 |
|---|---|
| 建築時期 | 昭和56年5月31日以前建築 |
| 建物種類 | 非區分所有建物（公寓大廈等） |
| 居住狀況 | 繼承開始前，被繼承人一人居住（有入住安養機構等特例） |
| 用途 | 自繼承至出售，未供事業・出租・居住使用 |
| 讓渡對價 | 1億日圓以下 |
| 期限 | 至繼承開始起滿3年之日所屬年度的12月31日／特例適用期限至令和9年12月31日 |
| 房屋狀態 | 出售時符合耐震基準，或拆除房屋成為素地 |

此處拆除時點會發生作用。以往須「賣方於交屋前耐震改修」或「拆為素地」，惟**自令和6年（2024年）1月1日以後的讓渡，買方於讓渡翌年2月15日前耐震改修或拆除者，亦納入適用對象**。也就是說，賣方不必先拆，**由買方於交屋後拆除的安排也能用扣除**。

這大幅改變「拆為素地再賣，或連同老屋賣」的判斷。**適用可否、要件之套用與讓渡所得的計算，屬稅理士的所管。** 要件細瑣，尚有入住安養機構的特例與共有情形的處理。本公司看賣法（素地／現況）與價格設計，稅理士看扣除的適用可否，各自分別進行。

## 常見問題

**Q. 先拆再賣，或連同老屋賣，哪個較划算？**
A. 沒有一律的正解。素地適合想馬上蓋屋的買方、也易於想像，但拆除費先支出，且成為素地期間住宅用地特例消失。連同老屋不需初期費用、能較快掛牌，但須將契約不符責任與拆除費織入價格。3000萬日圓扣除自2024年起，由買方於交屋後拆除的形式亦可用，宜在向稅理士確認適用可否後再決定。

**Q. 拆除空屋，固定資產稅會變6倍嗎？**
A. 不會「恰好6倍」。拆除使住宅用地特例（小規模住宅用地課稅標準6分之1）消失、課稅標準上升，但素地有負擔調整措施與評價額70%的上限在運作，故實際增幅因自治體、評價額而異。具體試算請向稅理士確認。又，放置並收到「特定空家等」勸告，即使不拆也可能使特例消失。

**Q. 拆除建物後，登記須做什麼嗎？**
A. 須辦理。依不動產登記法第57條，拆除（滅失）建物後須於1個月內申請建物滅失登記。表題部（現況・測量）屬土地家屋調查士的領域，權利部手續屬司法書士的領域。名義仍為被繼承人時，作為前提尚須繼承登記。

**Q. 連同老屋賣，能不負契約不符責任嗎？**
A. 個人為賣方時，「現況有姿・不負契約不符責任（免責）」特約原則有效（惟明知未告知之事實不及於免責）。賣方為宅地建物取引業者、買方為個人時，依宅地建物取引業法40條有限制，通知期間須自交屋起2年以上，對買方不利之特約無效。特約如何撰寫因當事人與物件而異，於仲介中個別確認。
