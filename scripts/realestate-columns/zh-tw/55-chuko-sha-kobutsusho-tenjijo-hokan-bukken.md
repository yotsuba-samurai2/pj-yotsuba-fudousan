**結論（先說重點）**：能做中古車行・古物商展示場的物件，首先被用途地域篩選。賣物品的店舖受建築基準法別表第二的用途限制，原則上不能蓋在第一種低層住居專用地域與工業專用地域。若伴隨整備，自動車修理工場的作業場樓地板面積限制會另外發生作用。用來展示・保管的停車空間，要先確認租賃契約是否許可該用途，以及回復原狀的範圍到哪裡。

「想把沒在用的店舖變成中古車展示場」「想把物件租給古物商」這類諮詢越來越多。但空地或店舖能否成為展示場，取決於用途地域・建物的用途・契約這三點。本文寫給預定開中古車行或古物商、正在找展示・保管用租賃物件的事業者，依建築基準法・古物營業法・車庫法的條文，逐項整理簽約前能確認的事。個別物件的可否，最終由特定行政廳與所轄警察署確認。

## 中古車行・古物商的店舖・展示場物件，是由用途地域決定嗎？

首先被用途地域篩選。因為賣物品的店舖受建築基準法別表第二的用途限制。

建築基準法（昭和25年法律第201號）第48條與別表第二，依用途地域訂定可蓋的建築物。展示・販售中古車的店舖被當作「經營物品販售業的店舖」，可否隨規模與地域而變。大致如下。

| 用途地域 | 物品販售店舖的可否（大致） |
|---|---|
| 第一種低層住居專用地域 | 原則不可（一定的兼用住宅店舖部分除外） |
| 第二種低層住居專用地域 | 樓地板面積150㎡以內・2層以下 |
| 田園住居地域 | 原則不可（農產品直售所等例外） |
| 第一種中高層住居專用地域 | 樓地板面積500㎡以內・2層以下 |
| 第二種中高層住居專用地域 | 樓地板面積1,500㎡以內・2層以下 |
| 第一種住居地域 | 樓地板面積3,000㎡以內 |
| 第二種住居・準住居・近鄰商業・商業・準工業 | 可蓋 |
| 工業地域 | 可蓋（大規模店舖另有限制） |
| 工業專用地域 | 物品販售店舖・餐飲店不可 |

**是「只展示・販售」還是「也做整備・車檢」，會使發生作用的限制不同。** 只販售的話依店舖（物品販售業）的上表限制；伴隨整備則疊加自動車修理工場的限制。適合與否的最終判斷由特定行政廳進行。把沒有檢查完成證的中古物件轉為其他用途時的議題，整理在[沒有檢查完成證的中古物件能否轉作其他用途](https://luck428.com/column/kensazumisho-nashi-bukken-fukushi-youto-henko)。

## 若做整備・車檢，自動車修理工場的限制如何發生作用？

依作業場的樓地板面積分階段限制，住居系只能放小規模的。

建築基準法別表第二把自動車修理工場依作業場樓地板面積合計（大致為50㎡・150㎡・300㎡的階段）區分，住居系地域只能放小作業場，從準工業地域起規模才擴大。伴隨整備・鈑金・車檢的中古車店，這項限制會疊在展示場的用途限制之上。

| 業態 | 主要發生作用的限制 | 物件要看的點 |
|---|---|---|
| 只展示・販售 | 物品販售店舖的用途限制 | 用途地域・店舖樓地板面積・接道 |
| 伴隨整備・車檢 | 自動車修理工場的作業場面積限制 | 用途地域・作業場面積・原動機出力・近鄰 |

**會發生「展示場沒問題，卻在後面的整備空間卡到用途限制」的情況。** 先決定要做到哪種業態再去對物件，可減少反覆。作業場樓地板面積與地域的具體對應、原動機出力的處理，請向特定行政廳確認（本文未就地域逐一斷定數值）。

## 展示車的保管場所（車庫），要到什麼程度才需要申報・證明？

以販售為目的作為庫存擺放的車，與登錄使用的車，處理方式不同。

自動車的保管場所的確保等相關法律（昭和37年法律第145號。以下稱「車庫法」）第3條，課予自動車保有者在道路以外處所確保保管場所的義務。第4條要求想依道路運送車輛法登錄者，提出警察署長交付、證明道路以外處所已確保保管場所的書面（即所謂車庫證明）。輕自動車依第5條申報保管場所位置；變更保管場所時依第7條於15日內申報變更。

這裡的關鍵是「登錄的場面才需要車庫證明」。展示場上陳列的販售用庫存車，通常在買主確定、進入登錄階段時由買主取得車庫證明，事業者不會為了作為庫存擺放而逐台重取。相對地，事業者登錄作為公司用車使用的車，作為其保有者仍需確保保管場所並取得車庫證明・申報。

| 車的狀態 | 車庫證明・申報 | 根據・負責 |
|---|---|---|
| 展示場的販售用庫存（未登錄） | 通常於登錄時由買主取得 | 車庫法第4條（手續在買主） |
| 事業者登錄作為公司用車使用 | 需確保保管場所並取得車庫證明 | 車庫法第3條・第4條 |
| 新使用輕自動車 | 申報保管場所位置 | 車庫法第5條 |
| 變更了保管場所 | 15日內申報變更 | 車庫法第7條 |

**庫存的擺放場所本身，與車庫法的車庫證明另屬一事，是看物件的用途地域・接道・租賃契約能否安全放下該台數的問題。** 車庫證明的申請協助（依買主・事業者委託製作書類）由行政書士承擔，證明・申報的窗口是管轄保管場所的警察署。本公司確認物件側的停車可能性。運送業的營業所・車庫物件條件，另整理在[要開運送業，營業所與車庫的物件該看哪裡選](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

## 古物商許可的營業所要件，與租賃物件的契約要注意什麼？

定下營業所、取得公安委員會的許可，且收購在營業所進行，這幾點會影響物件。

古物營業法（昭和24年法律第108號）第3條規定，想經營古物商者須取得都道府縣公安委員會的許可。第5條規定向管轄主營業所所在地的公安委員會提出許可申請書（實務上經由所轄警察署）；第13條要求各營業所選任管理者一人；第14條更規定古物商不得在營業所或交易相對人的住所・居所以外的場所收受古物。

落在物件上的議題如下。

| 確認點 | 為何影響選物件 |
|---|---|
| 作為營業所使用的權原 | 租賃時出租人是否同意「作為古物營業的營業所使用」 |
| 獨立營業所的實體 | 是否設管理者、有能適正執行業務的區劃 |
| 收購（收受）進行的場所 | 收購在營業所進行（第14條），故要整理展示場與營業所的位置關係 |
| 使用承諾・轉租可否 | 租賃契約是否許可該用途・使用形態 |

**把租賃物件作古物商營業所時，請先讀契約書「使用目的」欄是否許可古物營業。** 限住宅用・事務所用的契約，之後要另行交涉加上用途。租賃契約該讀哪裡，整理在[租賃契約書，該讀哪裡](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。古物商許可營業所要件本身的細節，請見[古物商許可的營業所要件](https://luck428.com/legal/column/kobutsusho-kyoka-eigyosho-yoken)（行政書士側）。

## 用青空停車場・資材放置場做展示時，回復原狀與契約形態怎麼組？

先確認契約是否許可該用途，並以書面固定回復原狀的範圍，是重點。

把空地的青空停車場或資材放置場當展示空間時，出租人是否同意鋪裝・招牌・照明・圍籬的設置，退租時要回復到哪裡（回復原狀範圍），都要寫進契約。土地租賃中，以擁有建物為目的會受借地借家法保護，而作為停車場・資材放置場的暫時使用、或不蓋建物的利用，處理方式不同，故契約形態要配合目的選擇。

| 議題 | 契約要決定的事 |
|---|---|
| 用途 | 能否把「中古車的展示・保管」寫進使用目的 |
| 造作・設置物 | 鋪裝・招牌・照明・圍籬的設置可否與費用負擔 |
| 回復原狀 | 退租時撤除的範圍・還地或現況返還 |
| 契約形態・期間 | 是否為不蓋建物的利用；期間・更新・中途解約條件 |

**即使打算「只是擺放」，一旦鋪裝或裝招牌就會產生回復原狀的負擔。** 先決定要動到哪裡，把費用負擔與撤除範圍落進契約。事業用物件整體請見[投資用・事業用不動產](https://luck428.com/toushi)，事務所與許認可的關係請見[公司設立與辦公室選擇](https://luck428.com/office)，倉庫・保管的物件條件請見[能做營業倉庫的物件條件](https://luck428.com/column/eigyo-souko-touroku-bukken-youken)。

角色是分開的。中古車販售・古物商牽涉的窗口多，一開始先做好分工就不會迷路。

| 要做的事 | 負責 |

| 古物商許可的申請書類製作・提出支援 | 行政書士（經公安委員會・所轄警察署） |
| 車庫證明・保管場所申報的申請協助 | 行政書士（窗口為所轄警察署） |
| 用途變更的確認申請・自動車修理工場的適合設計 | 建築士・特定行政廳 |

物件的調查、取得・租賃的仲介、買賣・租賃的契約，由四葉不動産株式会社（宅地建物取引業 東京都知事(1)第113304號）承接。古物商許可・車庫證明等向官公署提出的書類製作・申請協助，由四葉行政書士事務所承接。**這兩者（不動產公司・行政書士事務所）是各自獨立的事業體。請分別直接與各自簽約。** 本公司與本事務所，既不收取也不支付介紹費・轉介費。用途變更的確認申請與適合設計請找建築士・特定行政廳，資金計畫與稅務請找稅理士，各自直接委託。諮詢免費。

## 常見問題

**Q. 中古車展示場能蓋在任何用途地域嗎？**
A. 不能。展示・販售的店舖受建築基準法別表第二的用途限制，第一種低層住居專用地域原則不可，工業專用地域連物品販售店舖本身都不能蓋。第二種低層住居專用地域為樓地板面積150㎡以內・2層以下等，可否隨地域與規模而異。伴隨整備則另有自動車修理工場的作業場面積限制。適合與否請向特定行政廳確認。

**Q. 展示中的每一台庫存車都要取得車庫證明嗎？**
A. 通常不用。車庫證明（車庫法第4條）在自動車登錄的場面才需要，販售用庫存車一般在買主確定、進入登錄階段時由買主取得。但事業者登錄作為公司用車使用的車，作為其保有者仍需確保保管場所並取得車庫證明・申報（第3條・第5條・第7條）。手續窗口是管轄保管場所的警察署。

**Q. 租賃店舖能作古物商的營業所嗎？**
A. 有可能。但前提是租賃契約的使用目的許可古物營業，且設有管理者、有能適正執行業務的區劃。因古物營業法第14條要求收購在營業所進行，故也要整理展示場與營業所的位置關係。請先讀使用目的欄，必要時交涉加上用途。許可申請由行政書士承擔。

**Q. 古物商許可申請或車庫證明能委託不動產公司嗎？**
A. 不能。古物商許可・車庫證明等向官公署提出的書類製作・申請協助是行政書士的業務，由四葉行政書士事務所承接。物件的調查・仲介・契約由四葉不動産株式会社承接。用途變更確認申請與自動車修理工場的適合設計由建築士承擔。皆為各自獨立的事業體，請分別直接簽約。
