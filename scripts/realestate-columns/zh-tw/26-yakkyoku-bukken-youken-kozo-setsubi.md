**結論（先說重點）**：調劑藥局的物件，先起作用的是兩點——①用途地域（藥局視為「店舗」，與診所不同，受用途地域限制）②藥局等構造設備規則要求的面積約19.8㎡以上、調劑室6.6㎡以上、清潔的區劃。醫療大樓或診所併設，還要看處方箋應對與動線。可否的最終判斷在保健所與特定行政廳。簽約前確認用途地域與區劃的素地，就能避免返工。

以為「診所就在隔壁，藥局當然進得來」而承租，到了開設許可階段，卻被要求重做調劑室面積或區劃。餐飲店、診所物件會發生的返工，調劑藥局同樣會發生。本文寫給在東京要新開設・遷移調劑藥局的藥劑師・醫療系事業者，以及企劃醫療大樓的不動產所有人：簽租約前能確認的事，依醫藥品醫療機器等法（藥機法）與藥局等構造設備規則的條文順序整理。可否的最終確認在保健所與特定行政廳窗口。

## 調劑藥局的物件，什麼用途地域才能開？

這是與診所最大的不同。診所在建築基準法的用途限制下全用途地域都能蓋，但**藥局視為「店舗（販賣物品的店舗）」，受用途地域限制。**

建築基準法（昭和25年法律第201號）以別表第二與第48條，定出各用途地域可蓋的建築物。藥局在部分住居系地域難以作為單獨店舗興建，在第一種低層住居專用地域原則上只能作為兼用住宅（延べ面積1/2以上為住居，店舗部分50㎡以下）興建。在近鄰商業・商業・準工業地域則較易興建。

| 用途地域 | 藥局（店舗）的處理概略 |
|---|---|
| 第一種低層住居專用地域 | 不可單獨店舗；僅限兼用住宅範圍（住居占延べ面積1/2以上・店舗50㎡以下） |
| 第二種低層住居專用地域 | 可作為政令規定一定規模的店舗興建 |
| 第一種・第二種中高層住居專用地域 | 面積限制放寬，較易興建 |
| 住居・準住居・近鄰商業・商業・準工業地域 | 可興建 |

**「土地上有診所，藥局當然也進得來」並不成立。** 診所不受用途限制，但即使在其鄰接地或同一棟建物，藥局作為店舗仍受用途地域限制。此外，把事務所或別業種的店舗改為藥局時，依樓地板面積，可能需要用途變更的確認申請。**用途地域上的可否與用途變更的要否，簽約前可在特定行政廳確認。** 診所物件的確認順序見[「診所的物件，簽約前要確認什麼」](https://luck428.com/column/clinic-bukken-youto-chiiki-kaisetsu-todokede)；用途地域與容積率如何牽動土地價格見[「日本地價為何隨『容積率』改變」](https://luck428.com/column/yosekiritsu-hosei-tochine)。

## 藥局開設許可的構造設備基準（面積・調劑室・清潔室）要滿足什麼？

開藥局，依藥機法（關於確保醫藥品、醫療機器等品質、有效性及安全性等的法律・昭和35年法律第145號）第4條第1項，須取得所在地都道府縣知事（設有保健所的市之市長・特別區之區長）的許可。此許可每6年須更新（同條第4項）。第5條規定，**構造設備不符合厚生勞動省令所定基準時**等，得不予許可。

那「厚生勞動省令所定基準」就是藥局等構造設備規則（昭和36年2月1日厚生省令第2號）第1條。直接影響選物件的號如下（**2026年8月28日參照**）。

| 號 | 藥局的構造設備基準（摘錄） |
|---|---|
| 第一號 | 購買・受讓者容易出入，且外觀明顯可知為藥局 |
| 第二號 | 換氣充分，且清潔 |
| 第三號 | 與其他藥局・店舗、常時居住場所、不潔場所**明確區別** |
| 第四號 | 面積**約19.8㎡以上**，能適切進行藥局業務 |
| 第五號 | 具備採光・照明以確保照度（陳列60勒克斯以上・調劑台120勒克斯以上） |
| 第七號 | 具備**冷暗貯藏**設備 |
| 第八號 | 具備**可上鎖的貯藏設備** |
| 第十號 | **調劑室6.6㎡以上**，天花板與地板為板張・混凝土或準此者，並採行防止購買者進入的措施 |

也就是說，物件端的起點是**能否確保約19.8㎡以上，並在其中將6.6㎡以上的調劑室，與居住場所、不潔場所明確區分地作出。** 常被問到的「清潔室」，是在宅醫療用作無菌製劑處理（混合高熱量輸液等）時的**無菌調劑室**。這是僅對進行無菌製劑處理的藥局要求的另一基準，須有把室內空氣清淨度常時保持在ISO14644-1 Class 7以上的設備等。僅一般調劑則不需要，但若預定在宅對應，於物件階段預留設置空間可免返工。

給排水・空調・電氣容量的設計屬施工業者（設計者）領域。**本公司（不動產公司）協助調查物件能否滿足這些條件，並在與出租人的條件交涉中陪跑。** 不進行設備設計本身。相同構造的返工為何發生見[「照護事業所物件難尋的真正理由」](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)；契約書該讀哪裡見[「租賃契約書該讀哪裡」](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 醫療大樓或診所併設的物件，要注意什麼？

醫療大樓集客動線整齊、較易開業，但作為物件有其固有論點。

| 論點 | 為何有影響 |
|---|---|
| 構造設備的區分 | 第三號要求「與其他藥局・店舗・居住場所・不潔場所的明確區別」；於圖面確認共用部與調劑室・待合的間隔 |
| 面積的確保 | 切出區劃會減少有效面積；是否低於19.8㎡・調劑室6.6㎡ |
| 獨立性 | 藥機法上，藥局須與特定醫療機構在經營・機能上獨立；動線與引導的作法有時受質疑 |
| 租金與處方箋見込 | 併設診所的診療科與處方傾向會改變庫存構成；與租金負擔取得平衡 |
| 用途地域・用途變更 | 大樓整體用途，與藥局部分用途地域上的可否・用途變更要否 |

尤其**藥局與醫療機構的獨立性**牽涉物件的作法（出入口・動線・區劃），簽約前於圖面階段確認保健所的想法較安全。數值與運用因自治體而異。事業用物件整體見[投資用・事業用不動產](https://luck428.com/toushi)，事務所與許認可的關係見[公司設立與辦公室選擇](https://luck428.com/office)，保健所申報先於契約的例子見[「開美容室・理容所的物件要確認什麼」](https://luck428.com/column/biyoshitsu-riyojo-bukken-hokenjo-todokede)。

## 簽約前，要向保健所與行政書士確認什麼？

藥局開設許可，是在構造設備備妥後接受保健所檢查才下來。因此流程如下。

| 順序 | 要做的事 | 承擔者 |
|---|---|---|
| 1 | 確認用途地域・用途變更要否 | 特定行政廳・宅地建物取引業者 |
| 2 | 調查能否滿足面積・調劑室・區劃・給排水・電氣容量 | 宅地建物取引業者・施工業者 |
| 3 | 租賃契約 | 宅地建物取引業者 |
| 4 | 裝潢工程（調劑室・區劃・貯藏設備・照明・換氣） | 施工業者 |
| 5 | 藥局開設許可的申請 | 開設者・行政書士 |
| 6 | 保健所的到場檢查（構造設備）・審查 | 保健所 |
| 7 | 許可後開設・開始調劑 | 開設者 |

**物件的契約是手續的前提。** 管理藥劑師的配置等人的要件，與物件另行準備。藥局開設許可等向保健所・藥事窗口提出的書類製作，由四葉行政書士事務所承辦。**行政的窗口・樣式・自治體的數值・受理的運用會變。着手時點請直接確認管轄保健所的網頁。**

## 該找誰諮詢？

物件的調查、仲介、買賣・租賃契約，由四葉不動產株式會社（宅地建物取引業 東京都知事(1)第113304號）承辦。藥局開設許可等向官公署提出的書類製作，由四葉行政書士事務所承辦。建築確認・調劑室的構造設計由建築士，給排水・空調設計由施工業者處理。藥機法上適合與否的最終判斷由保健所（都道府縣・保健所設置市・特別區）作出，稅務轉介稅理士。

## 常見問題

**Q. 能蓋診所的土地，藥局當然也能開嗎？**
A. 未必。診所在建築基準法用途限制下全用途地域都能蓋，但藥局視為「店舗」，受用途地域限制。第一種低層住居專用地域原則上僅限兼用住宅範圍。可否因物件而異，請在特定行政廳窗口確認。

**Q. 調劑藥局需要的面積，法律有規定嗎？**
A. 藥局等構造設備規則第1條規定，藥局面積「約19.8㎡以上」、調劑室「6.6㎡以上」。這是全國共通的省令基準。惟照度與設備細部的運用、所需寬度的判斷因自治體・物件而有幅度，請向管轄保健所確認。

**Q. 預定對應在宅醫療。物件階段要先看什麼？**
A. 若進行無菌製劑處理（混合高熱量輸液等），需要無菌調劑室。這是僅對進行無菌製劑處理的藥局要求的另一基準，須有把空氣清淨度常時保持在ISO14644-1 Class 7以上的設備等。僅一般調劑則不需要，但若將來對應，於物件階段預留設置空間可免返工。

**Q. 藥局開設許可由誰何時申請？在物件契約之前嗎？**
A. 藥局開設許可（藥機法第4條第1項）是在構造設備備妥並經保健所檢查後才下來。因此順序為：物件契約→裝潢工程→許可申請→保健所檢查・審查→開設。物件的契約是手續的前提。許可申請書等官公署提出書類的製作由行政書士承辦。
