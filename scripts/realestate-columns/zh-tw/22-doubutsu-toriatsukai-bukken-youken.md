**結論（先說重點）**：寵物美容沙龍・寵物店的物件，最先卡關的是能否符合飼養設施基準（籠子・洗淨・消毒・換氣・排水）、臭味與吠叫會不會與鄰居衝突，以及租約是否禁止「飼養動物」三點。第一種動物取扱業的登錄是「按事業所」取得，物件能否符合設施基準是前提。簽約前確認用途地域・排水・換氣與出租人意向，就能避免返工。

因為「是可養寵物的大樓」而承租，到了登錄階段卻因飼養設施的換氣或排水達不到基準而要重做裝潢。餐飲店、美容室會發生的返工，動物相關的店同樣會發生。本文寫給在東京要開寵物美容沙龍・寵物店的人，以及把物件租給他們的人：簽租約前能確認的事，依動物的愛護及管理相關法律的條文與環境省・自治體的案內順序整理。可否的最終確認在授予登錄的自治體窗口。

## 動物取扱業的物件，簽約前先確認什麼？

先確認自己的生意是否屬於「需要登錄的業」。動物的愛護及管理相關法律（昭和48年法律第105號）第10條規定，以販售・保管・出借・訓練・展示等方式，將動物（哺乳類・鳥類・爬蟲類）作為事業經營者，須**按事業所**，向所在地管轄的都道府縣知事（指定都市・中核市等則為其首長）取得**第一種動物取扱業的登錄**（**2026年8月25日參照**）。

自己的店屬於哪個種別：

| 業態 | 對應種別（例） |
|---|---|
| 寵物店（活體販售） | 販售 |
| 寵物美容沙龍（收下施作） | 保管 |
| 寵物旅館 | 保管 |
| 訓練教室 | 訓練 |
| 貓咪咖啡・互動 | 展示 |

**登錄是「按事業所」。** 因此物件一變就要重新登錄，物件本身能否符合飼養設施基準是登錄的前提。這是物件選擇的起點。

登錄有有效期間，每5年更新（同法第13條）。此外，涉及暴力團關係者、過去被撤銷登錄者等一定事由時，登錄會被拒絕（同法第12條）。

## 飼養設施的面積・籠子・臭味對策，由物件如何決定？

第一種動物取扱業者，須遵守環境省令所定飼養設施的構造・規模及動物管理方法等基準（同法第21條）。具體由同法施行規則（平成18年環境省令第1號）規定，令和3年6月1日施行的修正加入了犬・貓的數值基準（**2026年8月25日參照**）。

在物件端會發生作用的點：

| 項目 | 施行規則的考量 |
|---|---|
| 籠子等 | 依動物種類・數量・體格的大小；犬貓依運動空間分離或一體而基準不同；床材原則禁用鐵絲網（肉球受保護者除外） |
| 給餌・給水設備 | 能隨時飲用清潔水的設備 |
| 洗淨・消毒設備 | 能洗淨並消毒設施・器具的設備 |
| 排水設備 | 能適當排出污物・污水的排水 |
| 換氣設備 | 排出臭味・濕氣・粉塵，並管理溫濕度的換氣 |
| 遮光・照明設備 | 顧及動物生理的採光・照明 |
| 從業人員數 | 犬・貓的每名從業者飼養頭數有上限（犬20頭〔其中繁殖用15頭〕、貓30頭〔其中繁殖用25頭〕；從業者數基準經過渡措施分階段施行） |

**要注意，這些是「為動物」的基準，而建物裡什麼放在哪，由物件的給排水・換氣素地決定。** 事後想在單間店舖裝入大型洗淨槽或大換氣，會牽動給排水增設與電力容量增設的費用與工期。

物件端值得確認的，與其說是數值本身，不如說是**能否具備符合的素地**：

| 簽約前確認 | 為何有效 |
|---|---|
| 給排水的位置與口徑 | 洗淨・消毒・給水必備；寵物美容大量用熱水 |
| 換氣・排氣路徑 | 臭味是鄰居糾紛主因；方向與能力重要 |
| 電力容量 | 給湯・吹風機・空調・洗淨機需容量 |
| 防水・易清掃的地牆 | 「保持清潔」的素地；與回復原狀範圍相關 |
| 隔音餘地 | 吠叫對策；木造・輕量鐵骨易傳聲 |

給排水・換氣・隔音的設計是施工業者（設計者）的領域。**本公司（不動產公司）協助調查物件能否符合這些條件，並在與出租人的條件交涉上伴走。** 不進行設備設計本身。相同的返工整理於[「美容室・理容所的物件，保健所看什麼」](https://luck428.com/column/biyoshitsu-riyojo-bukken-hokenjo-todokede)與[「照護事業所物件找不到的真正理由」](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)。

## 用途地域與對鄰居的顧慮，哪種物件容易被拒？

動物相關的店，與餐飲店、診所不同之處在於，**臭味・吠叫・排水這些對鄰居的影響，大幅左右物件選擇。**

第一是租約。集合住宅・雜居大樓多在契約書中禁止「飼養動物」或攜入寵物。即使是可養寵物的住宅，那也是允許住戶飼養，未必包含反覆收下動物的「業」。**須在申請前先讀契約書如何規定動物飼養與作為業的使用。** 契約書該讀哪裡整理於[「租賃契約書該讀哪裡」](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

第二是用途地域。寵物店・寵物美容沙龍在建築基準法上被視為「服務業店舖」，與美容院同樣受用途地域限制。第一種低層住居專用地域難以設單獨店舖，第二種低層住居專用地域則有樓地板面積合計150㎡以內等限制。可否在特定行政廳窗口確認。用途地域與容積率如何影響地價整理於[「日本地價為何隨『容積率』而變」](https://luck428.com/column/yosekiritsu-hosei-tochine)。

第三是鄰居。與登錄可否無關，臭味・噪音會透過自治體的生活環境條例與鄰居投訴影響店的存續。**排氣方向、營業時間、隔音的作法，以及出租人與鄰居的狀況，最好在簽約前確認。**

## 常見問題

**Q. 可養寵物的公寓，就能開寵物美容沙龍嗎？**
A. 未必。可養寵物是允許住戶飼養，未必包含反覆收下動物的「業」。許多租約限制「飼養動物」或作為業的使用。請在申請前確認契約條款與出租人意向，並確認換氣・排水・消毒設備能否符合施行規則的基準。

**Q. 店舖搬遷後，第一種動物取扱業登錄會怎樣？**
A. 登錄是按事業所取得（動物的愛護及管理相關法律第10條）。搬遷就要就新物件重新登錄。因新物件須能符合設施基準，搬遷地的給排水・換氣・區劃最好在簽約前確認。

**Q. 籠子大小或從業人員數有固定數值嗎？**
A. 就犬・貓而言，施行規則（令和3年6月1日施行的修正）訂有籠子大小、每名從業者飼養頭數上限等數值基準（犬每人20頭〔其中繁殖用15頭〕、貓30頭〔其中繁殖用25頭〕；從業者數基準分階段施行）。數值的適用與解釋依自治體運用，請向管轄的動物愛護中心等確認。

**Q. 登錄申請可以委託不動產公司嗎？**
A. 不行。向官公署提出的登錄申請文件之製作屬行政書士業務，由四葉行政書士事務所承接。物件的調查・仲介・租賃契約由四葉不動產株式會社承接。兩者為各自獨立的事業體，請各自直接簽約。動物取扱責任者是否符合要件，由授予登錄的自治體審查。
