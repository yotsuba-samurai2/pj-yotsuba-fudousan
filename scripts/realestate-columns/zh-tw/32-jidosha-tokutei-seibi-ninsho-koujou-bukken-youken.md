**結論（先說重點）**：可作為認證工廠（特定整備，道路運送車輛法第78條）的物件，由三點決定——①用途地域是否准許汽車修理工廠②認證基準（第80條）的作業場與點檢作業場能否以足夠的間口與天花板高度容納③地板與前面道路能否承受升降機作業與車輛進出。三者都能在簽訂租賃契約前確認。

進行汽車分解整備・電子控制裝置整備的「認證工廠」，沒有地方運輸局長的認證便無法開業。而認證，是在作業場的大小、設備與人員都滿足要件後才會核發。「先租下物件再申請認證，結果作業場不夠」——照護事業所或診所會發生的返工，在整備工廠也以同樣的形式發生。本文寫給在東京新開汽車特定整備事業（認證工廠）的業者，以及經手整備工廠物件的不動產承辦人，依序排出簽約前能確認的事項。可否的最終確認，在管轄營業所的地方運輸局・運輸支局窗口進行。

## 特定整備的認證工廠，物件的面積與天花板高度需要多少？

依經手的汽車種類而變，但若經手乘用的普通自動車・四輪的小型自動車，就需要能一併容納屋內作業場（車輛整備作業場與點檢作業場）、零件整備作業場與車輛置場的大小。

打算經營汽車特定整備事業者，依道路運送車輛法（昭和26年法律第185號）第78條第1項，須取得地方運輸局長的**認證**。認證的基準訂於同法第80條與道路運送車輛法施行規則，作業場等的規模，在施行規則的別表中依對象汽車的種類逐一定出數值。以乘用的普通自動車・四輪小型自動車為對象時的參考如下。

| 作業場等 | 參考大小（普通自動車・四輪小型自動車＝乘用） |
|---|---|
| 車輛整備作業場 | 間口4m以上×進深8m以上 |
| 點檢作業場 | 間口4m以上×進深8m以上 |
| 零件整備作業場 | 8㎡以上 |
| 車輛置場 | 間口3m以上×進深5.5m以上 |

若經手大型（車輛總重8t以上等），數值會更大，車輛整備作業場約為間口5m以上×進深13m以上。**天花板的高度，須足以對對象汽車進行升降機作業**，地板須平滑鋪裝。若進行電子控制裝置整備（後述），另需電子控制裝置點檢整備作業場，但可與車輛整備作業場・點檢作業場共用。用途地域與容積率如何左右地價，整理在[日本的地價為何隨「容積率」而變](https://luck428.com/column/yosekiritsu-hosei-tochine)。

## 因用途地域或周邊環境，會有汽車整備工廠無法開的地方嗎？

有。汽車修理工廠受建築基準法的用途地域限制，在許多住居系地域無法興建。

診所或托兒所不會卡在用途地域，但汽車修理工廠不同。建築基準法（昭和25年法律第201號）第48條與別表第二，依**作業場的樓地板面積合計**，區分汽車修理工廠可興建的用途地域。依國土交通省的用途限制整理，大致如下。

| 用途地域 | 汽車修理工廠可否（依作業場樓地板面積） |
|---|---|
| 第一種・第二種低層住專與中高層住專、田園住居、第一種・第二種住居 | 不可興建 |
| 準住居地域 | 作業場樓地板面積合計150㎡以下可 |
| 近鄰商業・商業・準工業地域 | 同300㎡以下可 |
| 工業地域・工業專用地域 | 無面積限制 |

要留意的是，**認證基準所稱的「作業場」大小，與用途地域限制所稱的「作業場樓地板面積」是不同的尺**。為取得認證而確保大面積的屋內作業場，其樓地板面積可能超過用途地域上限（準住居為150㎡），以致在該地域無法興建。準工業・工業系地域適合整備工廠正是此故。是否會因噪音・塗裝臭氣・進出的車列與鄰里衝突，也是簽約前的觀察點。用途地域在事業用物件先發生作用的例子，見[診所的物件，簽約前該確認什麼](https://luck428.com/column/clinic-bukken-youto-chiiki-kaisetsu-todokede)；運送業的營業所・車庫，見[要開運送業，營業所與車庫的物件該看哪裡挑](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

## 認證工廠與指定工廠（民間車檢場），物件要件有何不同？

指定工廠在認證工廠的要件之外，還需要「完成檢查場」與檢查用機械器具。物件更大，設備負擔也更重。

認證工廠是把整備過的車開到運輸支局的車檢場受檢。相對地，指定工廠（民間車檢場，道路運送車輛法第94條之2）是認證工廠中兼備檢查設備與自動車檢查員、可核發保安基準適合證的工廠。可省去開車進場，代價是物件側的要件增加。

| 區分 | 物件・設備要件 |
|---|---|
| 認證工廠（第78條） | 作業場・點檢作業場・零件整備作業場・車輛置場、作業機械、從事特定整備的從業員 |
| 指定工廠（第94條之2） | 認證工廠要件之外，加上完成檢查場（能容納檢查線的大小・天花板高度）與測試機等檢查用機械器具、選任自動車檢查員 |

一般順序是先以認證工廠選物件，事業成長後再以指定工廠（民間車檢場）為目標。**若一開始便以指定工廠為前提，所需的基地・天花板高度・投資會大不相同。** 在選物件的階段先決定以何者為目標，可避免返工。

## 以承租物件取得認證時，簽約前該向房東確認什麼？

把「可否作此用途」與「建物能否承受工程與重物」，在簽約前以書面確認。

以承租開認證工廠，就看契約與現況兩面。確認的要點如下。

| 要確認的事項 | 為何在簽約前 |
|---|---|
| 使用目的是否含「汽車整備（特定整備）」 | 用途受限的契約，事後便無法申請認證 |
| 升降機・地坑的設置、地板打鑿、動力（三相200V）引入的可否 | 未先就恢復原狀與裝修範圍達成合意，退租時費用會膨脹 |
| 前面道路的寬度與間口 | 經手的車輛（尤其大型）能否進出。與車輛置場・車輛整備作業場的間口直接相關 |
| 用途地域與檢查完成證・建築確認申請的紀錄 | 該地域能否興建汽車修理工廠、是否需用途變更的確認申請 |
| 消防・排水・塗裝室的排氣 | 若處理塗裝或有機溶劑，會受消防法・水質・大氣的規制 |

這些在看屋階段與簽約前可確認。若簽約後才發現「該用途不可」「地板無法設地坑」，認證的設計就得整個重來。租賃契約書該讀哪裡，見[租賃契約書，該讀哪裡](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)；同樣構造的返工為何在照護事業所發生，見[找不到照護事業所物件的真正原因](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)。事業用物件整體見[投資用・事業用不動產](https://luck428.com/toushi)，事務所與公司設立的關係見[公司設立與辦公室選擇](https://luck428.com/office)。

## 物件的要件確認與認證申請，各自該找誰？

物件（不動產）與認證（行政手續），承辦者分開。

認證工廠的開業，在找物件・簽約的部分，與取得認證的部分，承辦者不同。人（整備主任者・工員）與設備是否滿足要件，是在認證申請中審查的，因此**若先把物件定下來，可能因不符要件而重來**——正因如此才把上述要點在簽約前排出。申請本身的人員要件・書類・運輸支局手續，整理在成對的文章（行政書士側）[汽車的特定整備（分解整備）認證申請，要件為何、如何進行](https://luck428.com/legal/column/jidosha-tokutei-seibi-ninsho-shinsei-nagare-youken)。

| 事項 | 承辦者・窗口 |
|---|---|
| 物件的調查・仲介，作業場的租賃・買賣契約 | 宅地建物取引業者 |
| 特定整備事業的認證申請、作業場・設備的要件判斷、向公家機關提出的書類製作 | 行政書士 |
| 認證・完成檢查場的建築確認・用途變更申請 | 建築士・行政書士 |
| 設立公司時的設立登記 | 司法書士 |
| 會計・稅務 | 稅理士 |
| 租金・恢復原狀・遷讓等紛爭 | 律師 |

## 常見問題

**Q. 特定整備的認證，在做哪種作業時需要？**
A. 在把道路運送車輛法第49條第2項所稱「特定整備」的作業當作事業進行時需要。除傳統的分解整備（伴隨原動機・動力傳達裝置・行走裝置・操縱裝置・制動裝置・緩衝裝置・連結裝置的分解的整備）外，2020年（令和2年）4月1日施行的修正，把拆卸・調整（校準/aiming）自動運行裝置或防撞煞車等的攝影機・雷達的「電子控制裝置整備」也納入特定整備。是否該當依作業內容而異，著手前請向運輸支局確認。

**Q. 取得認證，除作業場外還需幾名整備士？**
A. 含整備主任者在內，從事特定整備的從業員需2名以上。其中須有一定比例的自動車整備士資格者，參考值為從事2〜4名時1名、5〜8名時2名、9〜12名時3名。整備主任者原則從一級或二級自動車整備士（以原動機為對象時除二級自動車底盤整備士）中選任。人員要件的細節請向運輸支局確認。

**Q. 可以租住宅區的空倉庫改成整備工廠嗎？**
A. 依用途地域而定。汽車修理工廠依建築基準法別表第二，可興建的地域有限，在第一種・第二種低層住專或住居專用系地域不可興建。參考值為準住居地域作業場樓地板面積合計150㎡以下、近鄰商業・商業・準工業300㎡以下、工業・工業專用無限制。從倉庫的用途變更有時需建築確認申請。請在簽約前確認地域與建物的紀錄。

**Q. 認證工廠與指定工廠（民間車檢場），物件要如何挑選區分？**
A. 認證工廠是把整備過的車開到運輸支局車檢場。指定工廠（第94條之2）在認證工廠要件之外，還需完成檢查場與檢查用機械器具、自動車檢查員，可在自家完成車檢。指定工廠的基地・天花板高度・投資更大，因此一般順序是先以認證工廠選物件，事業成長後再以指定工廠為目標。在選物件階段先決定以何者為目標，返工會較少。
