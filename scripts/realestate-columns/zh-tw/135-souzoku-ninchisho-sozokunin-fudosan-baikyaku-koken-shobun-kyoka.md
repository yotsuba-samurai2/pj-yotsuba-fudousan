**先講重點**：繼承人中有因失智等欠缺判斷能力的人時，該繼承不動產原則上「無法馬上出售」。出售的前提——遺產分割協議，若欠缺意思能力便無法有效成立（民法第3條之2）；要代本人參與協議或出售，須有家庭裁判所選任的成年後見人。此外，若要賣的不動產是本人的居住用，即使有後見人，也須另外取得家庭裁判所的許可（民法第859條之3）。後見開始的聲請與審判在家庭裁判所，聲請支援交給律師・司法書士、相續登記交給司法書士、評價與稅務交給不動產鑑定士・稅理士，出售仲介由本公司負責。各為獨立事業體，分別簽約。

想賣掉老家等繼承不動產，身為繼承人的父母或兄弟卻有失智——這時候「為什麼賣不掉」「該怎麼安排順序」就成了第一個煩惱。不能把本人排除在外推進，也不能由家人代簽。若不知道手續的順序就行動，好不容易成立的契約可能事後被認定無效。

本文從不動產的角度，整理繼承人中有欠缺判斷能力者時，出售為何會卡住，以及到可以出售為止的步驟。後見開始聲請能否進行、以及個別的法律判斷，屬律師・司法書士・家庭裁判所的領域，本文僅為一般性資訊提供。

四葉不動產株式會社以東京都文京區小日向為據點，承接繼承不動產的估價與出售仲介。關於有失智繼承人涉入的出售，歡迎從賣出前可以確認的事項開始與我們洽談。

## 繼承人裡有失智的人，出售為什麼會卡住？

要賣繼承來的不動產，通常要先把確定歸屬的遺產分割協議談妥、辦好相續登記，再進入買賣。但遺產分割協議是全體繼承人的法律行為，各繼承人都需要有意思能力（理解事物並做出判斷的能力）。

民法第3條之2規定：「法律行為的當事人於意思表示時不具意思能力者，該法律行為無效」（平成29年法律第44號新設、2020年4月1日施行）。有因失智等欠缺判斷能力的繼承人加入的遺產分割協議，其意思表示無效，協議整體即無法成立。

| 階段 | 若有欠缺判斷能力的繼承人 |
| --- | --- |
| 遺產分割協議 | 本人的意思表示無效；家人也不能代筆、代理 |
| 相續登記 | 分割未談妥，朝向出售的名義變更無法推進 |
| 買賣契約 | 本人若為當事人，在欠缺意思能力下所締結的契約無效 |

也就是說，並非「賣不掉」，而是須先進行一道手續：為本人立一位能合法判斷並簽名的人（成年後見人）。

## 有了成年後見人，何時、如何能出售？

為欠缺判斷能力的本人，由家庭裁判所選任成年後見人。民法第7條規定，對於因精神上障礙而處於欠缺辨識事理能力常況的人，家庭裁判所得依本人、配偶、四親等內親屬等的聲請，為後見開始的審判；第8條則將受後見開始審判者定為成年被後見人，並為其附加成年後見人。

成年後見人選出後，便可代本人加入遺產分割協議，成為相續登記與買賣的當事人。大致順序如下。

| 順序 | 內容 | 由誰負責 |
| --- | --- | --- |
| 1 | 後見開始的聲請（向家庭裁判所） | 本人・親屬等；文件製作支援由律師・司法書士 |
| 2 | 家庭裁判所的審判・成年後見人的選任 | 家庭裁判所 |
| 3 | 成年後見人參與遺產分割協議 | 成年後見人（保護本人利益的立場） |
| 4 | 相續登記 | 司法書士 |
| 5 | 買賣契約・交割（居住用者以家裁許可為前提） | 賣方（後見人）＋仲介由本公司負責 |

要注意的是，後見人是「保護本人利益」的立場。因繼承人方便而賤賣、減少本人取分的分割，後見人無法答應。若後見人同時也是共同繼承人之一，利益相反，便須另行選任特別代理人（民法第826條・第860條）。

共有狀態的繼承不動產如何出售，[出售共有不動產時全體繼承人同意的整理（日文）](https://luck428.com/zh-tw/column/souzoku-kyoyu-fudosan-uru-doui)也可參考。

## 居住用不動產的出售，為什麼需要家庭裁判所的許可？

即使有了成年後見人，也不代表就能自由出售本人名義的不動產。民法第859條之3規定，成年後見人代成年被後見人，就其供居住使用的建物或其基地，進行出售、出租、租賃契約的解除或抵押權的設定等其他與此相當的處分時，須取得家庭裁判所的許可。

因為失去居所會大幅影響本人的生活與精神狀態，基於保護本人的觀點，居住用不動產的處分特別要求家裁許可。未取得許可而為的居住用不動產出售，被解釋為無效（國稅廳的文書回答等）。

| 不動產的性質 | 家裁許可（第859條之3） |
| --- | --- |
| 本人現住・曾住・將來預定居住的建物及其基地 | 需要（未經許可的出售無效） |
| 不屬於本人居住用的繼承不動產 | 第859條之3的許可不需要；但後見人的善良管理注意義務與向家裁報告仍在 |

「供居住使用」在實務上傾向於較寬地解釋，是否該當由家庭裁判所・後見人判斷。本公司無法斷言「需要／不需要許可」。涉及配偶居住權等居住相關權利的出售思路，[出售附配偶居住權建物的整理（日文）](https://luck428.com/zh-tw/column/souzoku-haiguusha-kyojuuken-tatemono-baikyaku)也可參考。

## 遺產分割之前有辦法出售嗎？

也有「等不到後見開始」「想在分割前出售」的諮詢，但只要有欠缺判斷能力的繼承人，就不能把本人排除在外先賣。可想到的途徑有限。

| 途徑 | 留意點 |
| --- | --- |
| 等後見開始後再賣 | 原則流程。若為本人居住用，還需第859條之3的家裁許可 |
| 以拋棄繼承退出繼承人之列 | 欠缺判斷能力的本人不能單獨為之，須後見人涉入；不可輕率選擇 |
| 有遺言時 | 本人可能不必參與協議；但遺言的有效性須另行確認 |

兩者的可行與否都取決於個別情事與法律判斷。有資訊宣稱「分割前出售的捷徑」，但偏離保護本人的做法，事後可能被認定無效。再怎麼著急，不跳過後見手續，結果往往才是最短路。手續的要否與可行，請向律師・司法書士・家庭裁判所確認。

## 後見的聲請要找誰？出售由誰負責？（分離受任）

有失智繼承人涉入的不動產出售，橫跨後見、登記、稅務、不動產等不同事業體。順序取錯，可能在後見人選任前就簽約，或遺漏居住用的許可。

| 角色 | 由誰負責 |
| --- | --- |
| 估價・仲介・重要事項說明・交割 | 宅地建物取引業（本公司） |
| 後見開始的審判・居住用不動產處分許可 | 家庭裁判所 |
| 後見開始聲請的支援・利益相反或紛爭的判斷 | 律師・司法書士 |
| 相續登記・成年後見登記的確認 | 司法書士 |
| 相續稅・讓渡所得稅的計算與申報 | 稅理士 |
| 不動產的估價（鑑定） | 不動產鑑定士 |

後見開始的審判事件與居住用不動產處分許可的聲請，是家事事件手續法別表第一所列的家庭裁判所手續。聲請文件的製作・支援屬律師・司法書士的業務，本公司不代辦。

這些**各為獨立事業體**，以**分別簽約**為前提。本公司負責不動產的出售面，後見聲請的支援與利益相反的判斷交給律師・司法書士，相續登記交給司法書士，相續稅・讓渡所得稅交給稅理士，鑑定評價交給不動產鑑定士。本公司不收取介紹費。

## 常見問題

**Q. 父母失智了。由家人商量賣掉老家、代簽不就好了嗎？**
A. 有欠缺判斷能力的繼承人加入的遺產分割協議或買賣契約，因本人的意思表示無效而無法成立（民法第3條之2）。家人也不能代筆、代理，須先進行由家庭裁判所選任成年後見人的手續。可行與順序請向律師・司法書士確認。

**Q. 有了成年後見人，就能馬上賣老家嗎？**
A. 後見人可代本人成為協議或買賣的當事人，但若要賣的不動產是本人的居住用，須另外取得家庭裁判所的許可（民法第859條之3）。未經許可的居住用不動產出售被解釋為無效。是否屬居住用，由家庭裁判所・後見人判斷。

**Q. 我（子女）可以當後見人嗎？**
A. 親屬有時可擔任後見人，但選任者是家庭裁判所。若後見人是共同繼承人之一，在遺產分割上利益相反，可能須另行選任特別代理人（民法第826條・第860條）。選任與利益相反的判斷，請向律師・司法書士・家庭裁判所諮詢。

**Q. 後見手續要花時間嗎？可以先找買方嗎？**
A. 後見開始的審判與居住用不動產處分許可需要一定期間。在後見人選任或取得許可前就簽約，有無效之虞，守住順序較為安全。本公司可在手續進行的同時，承接市場狀況的整理與出售準備的諮詢，契約・交割則在要件齊備後再推進。
