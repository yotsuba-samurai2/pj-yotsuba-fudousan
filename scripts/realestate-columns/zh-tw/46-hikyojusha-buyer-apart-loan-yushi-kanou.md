**先講結論：**住在海外的中華圈（中國、台灣）非居住者購買日本收益物件時，日本國內金融機構的套房貸款、Proper Loan，多在借款時要求日本國內的住所（住民登錄）、永住資格，或日本國內的連帶保證人，海外在住的本人單獨能用的很有限。能否貸款、條件如何，是各金融機構依其審查所作的最終判斷，本公司無法斷定「能貸」或「不能貸」。因此實務上現金交割是主軸，從海外匯款的入帳時點反推交割日是要點。融資審查的可否交各金融機構，外匯管理、匯款交往來銀行，扣繳、確定申報與納稅管理人的申報交稅理士、稅務署，在留資格交行政書士，登記交司法書士，這些皆以各自獨立的事業體、分別簽約為前提。本公司（四葉不動產株式會社）只限於物件的調查、仲介、買賣契約的資訊提供。

本文寫給想買日本一棟、區分收益物件的中國大陸、台灣非居住者投資人，以及在當地支援該投資的資產顧問（專業層）。融資的最終判斷交各金融機構，匯款、外匯管理與稅務交往來銀行、稅理士，在留與納稅管理人的申報交稅理士、稅務署，在留資格的申請交行政書士。本公司只限於物件取得實務的資訊提供，這些皆以各自獨立的事業體、分別簽約為前提。

## 非居住者能在日本的金融機構辦不動產投資貸款嗎？

不能一律說「能」或「不能」。**各金融機構的要件不同，可否是其審查的最終判斷。**

一般而言，日本國內金融機構的套房貸款、Proper Loan，多在借款時要求下列之一。海外在住、在日本無住所且無法滿足這些的非居住者本人，能單獨借到的機構很少。

| 金融機構常要求的要件 | 對海外在住、單獨行動的非居住者本人 |
|---|---|
| 日本國內的住所（住民登錄）、在留資格 | 無住民登錄，難以滿足 |
| 永住資格或長期的在留實績 | 非居住者本人多半沒有 |
| 國內的穩定收入、確定申報實績 | 無國內所得則難以提示 |
| 住在日本的連帶保證人 | 能否備妥，決定可否 |

另一方面，也有在日本設立法人（資產管理公司），以該法人與國內董事、保證檢討融資的路徑，或使用本國金融機構的日本業務等路徑。惟這些同樣視各行審查而定，條件也逐年變動。**本公司不斷定特定金融機構名稱或「能借的商品」。**可否請務必自行向各金融機構確認。法人持有與個人持有的分水嶺，整理在[收益物件用法人持有或個人持有](https://luck428.com/column/hikyojusha-shisan-kanri-hojin-shuueki-bukken)。

## 若融資困難，現金交割的步驟如何？

在非居住者的交易中，現金交割（不使用融資的一次付清）是主軸。步驟如下。

1. 簽署買付、買賣契約。簽約時支付訂金（訂金的性質，日本與本國不同）
2. 買賣契約時，宅地建物取引業者進行**取引時確認**（本人確認）
3. 交割日，同時進行尾款支付與所有權移轉登記（司法書士）
4. 交割同時取得鑰匙、文件的交付

現金交割沒有融資審查，手續推進較快。惟**自海外匯入購買資金時，入帳前的時間左右交割時程**（見下節）。訂金、貸款特約、契約不符等契約條款容易誤解之處，整理在[買賣契約容易絆倒的條款](https://luck428.com/column/baibai-keiyaku-teppukin-loan-tokuyaku-chugokugo-buyer)。

## 自海外匯入購買資金，交割時程會如何改變？

海外匯款與國內帳戶間轉帳不同，**入帳前可能需數日以上**。主因如下。

| 匯款耗時的原因 | 對交割的影響 |
|---|---|
| 匯款銀行、收款銀行的法遵確認（資金來源確認等） | 入帳延遲則可能趕不上交割日 |
| 外幣兌換、匯率確定 | 對日圓計價交割額的所需金額會變動 |
| 本國側的匯款金額、次數規制（各國不同） | 無法一次匯出，可能分批 |
| 中轉銀行的經由 | 入帳日難以預估 |

因此，**從交割日反推、預留餘裕地開始匯款**是要點。若入帳趕不上交割日，會有交割延遲，甚至契約解除、訂金損失的風險。匯款可否、所需日數、上限，屬往來銀行與本國規制的問題，本公司從交割時程調整這一不動產側協助。外匯管理、匯款本身的判斷屬往來銀行、稅理士的領域。

## 非居住者該備妥的本人確認、在留、納稅管理人文件有哪些？

在非居住者的交易中，須在本國備妥替代日本住民票、印鑑證明的文件。

首先，宅地建物取引業者是犯罪收益移轉防止法上的**特定事業者**，於簽署買賣契約時，負有**取引時確認**（本人特定事項、交易目的、實質控制人等的確認）的義務（犯罪收益移轉防止法第4條）。就非居住者本人，除護照等本人確認文件外，還需證明本國住所的文件。

在登記場面，替代日本印鑑證明，一般使用本國公證機關等核發的**簽名（Sign）證明、住所證明**。取得這些需時，因此及早準備是要點。登記申請的代理由司法書士承辦。

在稅務上，自日本不動產取得租金的非居住者需**確定申報**，在日本無住所、居所者要辦理申報等，須指定並申報**納稅管理人**（國稅通則法第117條）。納稅管理人是否需要資格、公司能否擔任，整理在[納稅管理人需要資格嗎](https://luck428.com/column/nozei-kanrinin-shikaku-hojin)。

| 場面 | 常需的文件、手續 | 承辦者 |
|---|---|---|
| 買賣契約（取引時確認） | 護照等、本國住所證明、交易目的確認 | 宅地建物取引業者（本公司） |
| 所有權移轉登記 | 本國公證的簽名證明、住所證明 | 司法書士 |
| 租金的確定申報 | 納稅管理人的申報（國稅通則法第117條） | 稅理士、稅務署 |
| 在日本居住並經營事業 | 在留資格的申請 | 行政書士 |

## 融資審查、匯款、稅務，各該找誰諮詢？

非居住者購買收益物件，多位專家的領域交疊。角色分工如下。

| 諮詢內容 | 承辦者 |
|---|---|
| 融資的可否、條件、審查 | 各金融機構 |
| 海外匯款、外幣兌換、匯款上限 | 往來銀行（本國側、日本側） |
| 租金的扣繳、確定申報、納稅管理人、外幣相關稅務 | 稅理士、稅務署 |
| 外為法上的不動產取得報告 | 本人、居住者的代理人（見下） |
| 在留資格、向公家機關提出的書面 | 行政書士 |
| 所有權移轉登記 | 司法書士 |
| 物件的調查、仲介、買賣契約 | 宅地建物取引業者（本公司） |

租金收入的稅務上，承租人若是法人或事業目的，其支付的租金原則上扣繳20.42％（所得稅法第212條第1項、第213條第1項；承租人若是為自己、親屬居住而承租的個人，依施行令第328條不扣繳）。實務流程請見[非居住者的房租如何被扣繳](https://luck428.com/column/hikyojusha-yachin-gensen-2042)。將來，向非居住者買物件的買方，原則上須就讓渡對價扣繳10.21％（所得稅法第161條第1項第5號等）。這些稅額的判斷屬稅理士領域。

外為法上，非居住者取得日本國內不動產（或其相關權利）時，原則上須於取得後20日內，經日本銀行向財務大臣提出「本邦不動產或其相關權利之取得報告書」。依令和8年（2026年）4月1日施行的報告省令改正，取得日在同日以後者，原則上不論取得目的皆為報告對象，並於報告事項新增交易相對人（居住者、非居住者之別）、取得目的、不動產編號。適用除外的最新範圍，請以財務省、日本銀行的案內確認。外為法報告的全貌，整理在[外為法的不動產取得報告](https://luck428.com/column/hikyojusha-fudosan-shutoku-gaitameho-houkoku)。

**這種分擔，不是由某一家全部承接的形式。**各自以獨立的事業體、分別簽約。本公司、本事務所不收取也不支付介紹費、送客手續費。本公司只承辦物件的調查、仲介、買賣契約這一不動產側，融資可否、匯款、稅務，一律請向各金融機構、往來銀行、稅理士確認後推進。事業用、投資用物件整體，整理在[投資用・事業用不動產](https://luck428.com/toushi)。

## 常見問題

**Q. 住在海外，能在日本的銀行辦收益物件貸款嗎？**
A. 能辦的機構有限。日本國內金融機構的套房貸款、Proper Loan，多要求日本國內的住所（住民登錄）、永住資格、國內的連帶保證人，海外在住的非居住者本人單獨難以滿足。可否、條件是各金融機構依其審查的最終判斷，本公司無法斷定，請務必向各金融機構確認。

**Q. 用現金買時，交割上最該注意的是什麼？**
A. 海外匯款的入帳時點。自海外匯款因法遵確認、中轉銀行經由而入帳耗時，若趕不上交割日，會有交割延遲、契約解除、訂金損失的風險。請從交割日反推、預留餘裕地開始匯款。匯款可否、上限、所需日數，屬往來銀行與本國規制的問題。

**Q. 非居住者買物件，需要外為法的報告嗎？**
A. 原則上需要。非居住者取得日本不動產等時，須於取得後20日內經日本銀行向財務大臣提出報告書。依令和8年（2026年）4月1日施行的報告省令改正，取得日在同日以後者，原則上不論取得目的皆為報告對象。適用除外的最新範圍，請以財務省、日本銀行的案內確認。另外，是否為「非居住者」，是以住所而非國籍判斷。

**Q. 租金與出售會課什麼稅？**
A. 租金收入作為不動產所得需確定申報，承租人若是法人、事業目的，租金原則上扣繳20.42％（所得稅法第212條、第213條）。將來，向非居住者買物件的買方，原則上有就讓渡對價扣繳10.21％的義務（所得稅法第161條第1項第5號等）。在日本無住所者也需辦理納稅管理人的申報（國稅通則法第117條）。稅額的判斷，請向稅理士確認。
