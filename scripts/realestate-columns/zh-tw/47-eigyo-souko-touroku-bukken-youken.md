**結論（先說重點）**：能做營業倉庫的物件，首先取決於你是「受他人寄託而保管貨物的倉庫業」，還是「單純出租倉庫空間的不動產租賃」。經營倉庫業需要國土交通大臣的登錄（倉庫業法第3條），而倉庫的設施・設備符合各倉庫種類的基準，是登錄的要件（第6條第1項第4款、倉庫業法施行規則）。物件被看的地方，除了使用權原與相關法令適合之外，還有防水・防濕・遮熱・耐火・防火區劃・防犯・防鼠等。目標種類（一類～冷藏等）不同，條件也會改變。

「想把沒在用的建物變成出租倉庫」「想把物件租給倉庫用途」這類諮詢越來越多。但掛上「倉庫」的招牌，並不等於就是營業倉庫。營業倉庫是倉庫業法下的登錄制度，建物的構造要達到各種類的基準，才會被登錄。本文寫給想開展出租倉庫・保管業務的事業者，以及想租給倉庫用途的物件所有人，依倉庫業法・同施行規則的條文與國土交通省的資料，逐項整理簽約前能確認的事。數值與可否的最終確認，由登錄窗口的地方運輸局進行。

## 所謂「營業倉庫」與一般出租倉庫，到底差在哪？

分歧點在於「是否為受他人寄託而保管貨物的營業」。

倉庫業法（昭和31年法律第121號）把受寄託而在倉庫保管貨物的營業定為「倉庫業」，並規定想經營者必須取得國土交通大臣的登錄（第3條）。這裡的關鍵是「受寄託而保管」。若從貨主收受貨物、對其保管負責並取得對價，即屬倉庫業，需要登錄。

相對地，若只是把建物這個不動產的空間直接出租，由承租人以自己的管理擺放自己的物品，那是不動產的租賃，並非倉庫業。把自家商品由自家保管的自家倉庫，同樣不是倉庫業。

| 情形 | 倉庫業的登錄 | 主要負責 |
|---|---|---|
| 受貨主寄託而保管貨物並取得對價 | 需要（倉庫業法第3條） | 倉庫業者 |
| 出租倉庫建物、承租人擺放自己的物品 | 不需要（不動產租賃） | 宅地建物取引業者（本公司） |
| 把自家商品由自家保管（自家倉庫） | 不需要 | — |

**「租倉庫來自己用」與「作為營業倉庫替他人保管貨物」，在法律上完全不同。** 目標是哪一種，物件要求的條件與必要的手續都會改變。先確定自己屬於哪一種，是出發點。判斷有疑問時，請向登錄窗口的地方運輸局確認。

## 能通過倉庫業登錄的物件，建物的哪裡會被看？

會看設施・設備是否符合各倉庫種類、由國土交通省令所定的基準。

倉庫業法第6條第1項第4款規定，倉庫的設施或設備依倉庫種類而未符合國土交通省令所定基準時，即拒絕登錄。該基準在倉庫業法施行規則（昭和31年運輸省令第59號），作為所有倉庫共通的基準（第3條之3），要求對該倉庫有使用權原，且符合建築基準法・都市計畫法等相關法令。

在此之上，最基本的一類倉庫的設施設備基準（施行規則第3條之4），大致由下列項目構成。

| 被看的地方 | 基準的思考 |
|---|---|
| 使用權原・相關法令適合 | 所有或租賃的權原；符合建築基準法・都市計畫法等（用途地域・用途變更・檢查完成證的議題） |
| 軸組・外牆・地板強度 | 能承受保管貨物與裝卸的構造 |
| 防水性能 | 防止雨水從屋頂・外牆・開口部滲入 |
| 防濕性能 | 防止地面來的濕氣 |
| 遮熱性能 | 屋頂・外牆的隔熱 |
| 耐火・防火 | 耐火・準耐火構造、防火區劃 |
| 滅火器等 | 滅火器及其他滅火設備 |
| 防犯 | 照明・上鎖等防盜 |
| 防鼠 | 防止老鼠等侵入的措施 |

**符合建築基準法・都市計畫法，被放在這套基準的入口。** 用途地域能否蓋倉庫、既存建物是否需要用途變更的確認申請、有沒有檢查完成證，都在選物件的階段先發生作用。把沒有檢查完成證的中古物件轉為其他用途時的議題，整理在[沒有檢查完成證的中古物件能否轉作其他用途](https://luck428.com/column/kensazumisho-nashi-bukken-fukushi-youto-henko)。適合與否本身，由建築士・特定行政廳判斷。

## 從一類到冷藏倉庫，種類不同物件條件如何變？

倉庫種類不同，所要求的設施設備基準的條文就會改變。

倉庫業法施行規則第3條把倉庫種類分為一類・二類・三類・野積・水面・貯藏槽・危險品・冷藏等。以保管什麼決定種類，各種類都有各自的基準。

| 種類 | 主要保管貨物例 | 基準的條 | 物件條件的特徵 |
|---|---|---|---|
| 一類倉庫 | 一般貨物（範圍廣） | 施行規則第3條之4 | 防水・防濕・遮熱・耐火・防火・防犯等最為綜合 |
| 二類倉庫 | 比一類受限（不易燃物品等） | 第3條之5 | 一類基準去掉耐火性能的構成 |
| 三類倉庫 | 不易受濕氣・溫度影響的物品 | 第3條之6 | 一類基準的一部（不需防濕・遮熱等） |
| 野積倉庫 | 適合戶外保管的物品（原木・礦物等） | 第3條之7 | 周圍的防護設施・防犯設備・防止掉落 |
| 貯藏槽倉庫 | 散裝・液狀（穀物・液體等） | 第3條之9 | 筒倉・儲槽的密閉構造・強度 |
| 危險品倉庫 | 消防法・高壓氣體等的危險物 | 第3條之10 | 工作物型・土地型的分別基準（其他法令也重疊） |
| 冷藏倉庫 | 攝氏10度以下保管的物品 | 第3條之11 | 定溫維持・溫度計・防熱等溫度管理 |

**「同一棟建物，也會因為保管什麼而使能通過的種類不同」是重點。** 一般貨物為一類，攝氏10度以下保管的物品為冷藏倉庫，危險物為危險品倉庫，目標種類不同，物件要求的性能也不同。危險品倉庫還會重疊消防法・高壓氣體保安法等其他法令的規制，因此從選物件的階段就要看其適合。先決定要做哪一種，再去對物件，可減少反覆。

## 登錄前可以先進行物件契約嗎？順序該怎麼做？

**先確認登錄的可能性，再確定物件比較安全。** 若先押下不符設施設備基準的物件，恐怕改修費暴增，或無法登錄而閒置。實務上，下列順序較穩。

| 順序 | 要做什麼 | 主要負責 |
|---|---|---|
| 1 | 決定目標倉庫種類與保管貨物 | 事業者 |
| 2 | 下調候選物件的用途地域・用途變更・檢查完成證・構造 | 宅地建物取引業者（本公司）・建築士 |
| 3 | 確認對設施設備基準的適合可能性 | 建築士・向地方運輸局事前諮商 |
| 4 | 租賃・買賣的條件交涉與簽約（改修可否特約等） | 宅地建物取引業者（本公司） |
| 5 | 倉庫業登錄的申請 | 行政書士 |
| 6 | 若有增改建，建物表題・變更登記 | 土地家屋調查士・司法書士 |

若以租賃借倉庫，重點是把出租人是否同意改修與設備設置、回復原狀的範圍到哪裡，寫進契約。租賃契約該讀哪裡，整理在[租賃契約書，該讀哪裡](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。**本公司（不動產公司）陪跑物件是否可能符合倉庫業基準的下調，以及取得・租賃的條件交涉。** 對設施設備基準的適合與否本身，由建築士・地方運輸局判斷，登錄申請由行政書士承擔。事業用物件整體請見[投資用・事業用不動產](https://luck428.com/toushi)，事務所與許認可的關係請見[公司設立與辦公室選擇](https://luck428.com/office)。運送業的營業所・車庫物件條件，另整理在[要開運送業，營業所與車庫的物件該看哪裡選](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

角色是分開的。倉庫牽涉的專家多，一開始先做好分工就不會迷路。

| 要做的事 | 負責 |

| 物件的調查・取得・租賃仲介與契約 | 四葉不動產株式會社（宅地建物取引業） |
| 倉庫業登錄的申請書類製作・提出支援 | 行政書士 |
| 設施設備基準的適合設計・用途變更的確認申請 | 建築士 |
| 建物的表題登記・增改建後的變更登記 | 土地家屋調查士・司法書士 |

物件的調查、取得・租賃的仲介、買賣・租賃的契約，由四葉不動產株式會社（宅地建物取引業 東京都知事(1)第113304號）承接。倉庫業登錄等向官公署提出的書類製作，由四葉行政書士事務所承接。**這兩者（不動產公司・行政書士事務所）是各自獨立的事業體。請分別直接與各自簽約。** 本公司與本事務所，既不收取也不支付介紹費・轉介費。設施設備基準的適合設計與用途變更請找建築士，建物的表題・變更登記請找土地家屋調查士・司法書士，稅務請找稅理士，各自直接委託。諮詢免費。

## 常見問題

**Q. 只是租倉庫擺自己的庫存，也需要倉庫業的登錄嗎？**
A. 不需要。把自家貨物由自家保管的自家倉庫，或出租倉庫這個不動產、由承租人擺放自己物品的情形，一般不屬倉庫業（受他人寄託而保管的營業），故不需倉庫業法第3條的登錄。反之，若受貨主寄託而保管並取得對價，就需要登錄。判斷有疑問時，請向地方運輸局確認。

**Q. 能把中古倉庫租來做營業倉庫嗎？**
A. 有可能。但前提是該倉庫除了使用權原・相關法令適合外，還能符合目標種類的設施設備基準（防水・防濕・遮熱・耐火・防火區劃・防犯・防鼠等）。既存建物中，用途地域・用途變更確認申請的要否・檢查完成證・構造會先發生作用。適合與否請向建築士與地方運輸局確認。

**Q. 常溫的一般貨物與冷凍品，物件條件會不同嗎？**
A. 會不同。一般貨物是一類倉庫（施行規則第3條之4），攝氏10度以下保管的物品是冷藏倉庫（第3條之11），冷藏倉庫還加上定溫維持・溫度計・防熱等溫度管理。以保管什麼決定目標種類，物件要求的性能也會改變，因此先決定種類再去對物件較實務。

**Q. 倉庫業的登錄申請能委託不動產公司嗎？**
A. 不能。向官公署提出的登錄申請書類製作是行政書士的業務，由四葉行政書士事務所承接。物件的調查・仲介・契約由四葉不動產株式會社承接。設施設備基準的適合設計與用途變更確認申請由建築士承擔。皆為各自獨立的事業體，請分別直接簽約。
