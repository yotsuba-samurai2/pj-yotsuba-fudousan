**先講重點**：繼承到附以房養老（リ・バース60）的老家，先聯絡金融機構，確認本金餘額、清償期限，以及屬無追索型或有追索型。本金在契約人死亡時一次清償——由繼承人清償，或以擔保物件的售價清償。以出售結清時，整理估價、仲介、交割時的一次清償與抵押權塗銷。餘債的法律評價與可否拋棄繼承交給律師，抵押權塗銷與繼承登記交給司法書士。

繼承到父母曾使用以房養老的自宅時，常會不安：「剩下的借款怎麼辦」「不賣就還不了嗎」「是不是該拋棄繼承」。以房養老是一種住宅貸款：生前只付利息，本金在契約人死亡時一次清償。清償時點與結清結構，都與一般住宅貸款不同。

住宅金融支援機構的【リ・バース60】，是附機構住宅融資保險、由民間金融機構提供的滿60歲以上商品。本金在借款人死亡時，由繼承人一次清償，或以擔保物件（住宅及土地）的售價清償。先確認自己繼承的物件是否符合這個結構，是出發點。

四葉不動產株式會社以東京都文京區小日向為據點，承接不動產的出售諮詢與仲介。關於為結清餘債而出售，可從整理進行方式與確認事項開始諮詢。

## 以房養老的餘債在繼承時如何處理？

民法第896條規定，繼承人自繼承開始時起，承繼被繼承人財產上的一切權利義務（專屬一身者除外）。因此以房養老的餘債（借款的清償義務）原則上由繼承人承繼。繼承的當下，就與擔保物件一起承接了清償義務。

【リ・バース60】是本金於死亡時一次清償的商品。清償方式為繼承人一次清償，或以擔保物件的售價清償。要以出售結清，或以自備資金清償而保留物件，由繼承人選擇。

| 要確認的事 | 內容 |
| --- | --- |
| 餘額 | 本金餘額，以及至結清為止產生的利息 |
| 清償期限 | 死亡後多久內須一次清償・出售（依機構・契約而異） |
| 清償責任型 | 無追索型或有追索型 |
| 連帶債務 | 配偶等是否為連帶債務人；一次清償時點可能為兩人皆亡之時 |

先聯絡承辦金融機構，以書面確認餘額、期限與契約型。清償方式與期限細節依機構・契約而異，須以約款與餘額證明確認。餘債的計算與稅額的確定，非本公司業務。

## 無追索型與有追索型，繼承人的負擔有何不同？

【リ・バース60】對於以擔保物件售價仍無法清償的餘債，有兩種處理方式。這正是與一般住宅貸款大為不同之處。

| 型 | 售價無法清償之餘債的處理 |
| --- | --- |
| 無追索型 | 不向繼承人請求剩餘債務的清償 |
| 有追索型 | 剩餘債務由繼承人負清償義務 |

無追索型下，將擔保物件售價充作清償後，即使有不足，也不向繼承人請求。有追索型下，繼承人須清償出售後的不足額。自己繼承的契約屬哪一型，決定出售後是否還有負擔。

屬哪一型於契約已定，繼承人無法事後重新選擇。無追索或有追索的評價、與金融機構交涉的法律事務，屬律師領域。本公司承擔出售的程序，型的法律評價引介律師、餘額確認引介金融機構。

以一般住宅貸款餘債與抵押權塗銷為主的繼承，於[繼承到仍有住宅貸款餘債與抵押權的老家之出售（日文）](https://luck428.com/column/souzoku-jikka-juutaku-loan-zansai-teitouken-massho-baikyaku)說明。本文僅限於以房養老特有的結清結構——死亡時一次清償與無追索特約。

## 為結清餘債而出售的流程與期限為何？

以出售結清時，一般出售要加上「餘債的一次清償」與「抵押權的塗銷」。擔保物件上設有金融機構的抵押權，故基本做法是在交割時以售價清償餘債，並同時塗銷。

| 階段 | 要確認的內容 |
| --- | --- |
| 聯絡・確認 | 聯絡機構，確認餘額、清償期限、型與抵押權內容 |
| 估價・仲介 | 擔保物件的估價、媒介契約、販售方針 |
| 買賣契約 | 與買方的契約；以一次清償餘債為前提安排交割 |
| 交割・塗銷 | 以售價一次清償餘債，辦理抵押權塗銷登記・繼承登記 |
| 結清 | 有剩餘歸繼承人；無追索型即使不足也不被請求餘債 |

死亡後，到一次清償・出售為止給予多少期間，依機構・契約而異。含有無寬限或延緩在內，宜及早向機構確認。抵押權塗銷登記與繼承登記屬司法書士業務，本公司不代理登記。繼承登記自2024年4月1日起義務化，須確認期限。

讓渡所得（取得費、讓渡費用、特例適用）的計算屬稅理士領域。是否有售出獲利，依取得費與特例適用而變。稅額的估計向稅理士確認。

## 拋棄繼承與出售結清該選哪個？找誰諮詢？（分離受任）

常有人問「有餘債是不是該拋棄繼承」。選擇依屬無追索或有追索、是否另有負債、是否想保留物件而變。

民法第915條第1項規定，繼承的承認・拋棄，須自知悉為自己而繼承開始時起3個月內為之（期間於一定情形可伸長）。拋棄繼承後，依民法第939條視為自始不為繼承人，含擔保物件在內的繼承財產一概不能取得。

| 選項 | 適合的情形（一般論） |
| --- | --- |
| 出售結清 | 無追索型且可放手物件；以出售後不留餘債為前提 |
| 清償後保留 | 可以自備資金一次清償，且想持續持有老家 |
| 拋棄繼承 | 有追索型且餘債大，或另有大額負債；惟亦失去其他財產 |

無追索型且無其他負債時，出售結清原則上不留餘債，故可能不必拋棄繼承。有追索型或另有負債時，則一併考慮拋棄。熟慮期間短僅3個月，須及早確認。

| 角色 | 由誰承擔 |
| --- | --- |
| 擔保物件的估價與出售仲介 | 宅地建物交易業（本公司） |
| 抵押權塗銷登記・繼承登記 | 司法書士 |
| 可否拋棄繼承・無追索/有追索的法律評價・與金融機構交涉 | 律師 |
| 讓渡所得・取得費・稅額計算 | 稅理士 |
| 餘債・清償方式・期限 | 承辦金融機構 |

這些是**各自獨立的事業體**，須**分別簽約**。本公司承擔出售程序，法律評價交給律師、登記交給司法書士、稅務交給稅理士、餘債交給金融機構。本公司不收取介紹費。

## 常見問題

**Q. 繼承到以房養老的餘債，一定要自己還嗎？**
A. 依民法第896條，清償義務原則上由繼承人承繼。【リ・バース60】是本金於死亡時一次清償的商品，可選繼承人一次清償，或以擔保物件的售價清償。無追索型下，充作售價後即使不足也不被請求餘債。

**Q. 繼承後能重新在無追索型與有追索型之間選嗎？**
A. 不能。屬哪一型於契約已定。無追索型出售後不留餘債，有追索型須由繼承人清償不足額。請向機構確認自己繼承的契約屬哪一型。型的法律評價屬律師領域。

**Q. 拋棄繼承與出售，哪個划算？**
A. 無追索型且無其他負債時，出售結清不留餘債，故可能不必拋棄。有追索型或另有負債時，則一併考慮拋棄。拋棄須於3個月熟慮期間內為之，且會失去其他繼承財產。可否請向律師確認。

**Q. 出售的交割與抵押權塗銷如何進行？**
A. 擔保物件上設有金融機構的抵押權，故基本做法是交割時以售價一次清償餘債，並同時辦理抵押權塗銷登記。塗銷登記與繼承登記由司法書士承擔。本公司整理估價、仲介，以及以餘債為前提安排的交割。
