**先講重點**：出售有遺言執行人的繼承不動產時，買賣契約的當事人（賣方）是誰會隨遺言的形式而變。「使之繼承」旨（特定財產承繼遺言）者，由取得不動產的繼承人當賣方，執行人負責相續登記等對抗要件的具備。把遺產賣掉再分配的清算型遺贈，則由執行人進行出售手續。遺言的解釋與權限範圍交給律師、登記交給司法書士，不動產的仲介由本公司負責。

以公證遺言取得了不動產，或被指定、選任為遺言執行人——以這樣的身分想出售繼承來的不動產時，常會困惑「在契約上簽名的是我還是執行人」「交割現場誰出面」。有沒有遺言，以及遺言怎麼寫（「使之繼承」還是「遺贈」），會改變出售的當事人與登記的流程。

本文從不動產的視角，整理遺言執行人涉及的繼承不動產出售場面中，媒介契約、買賣契約、交割由誰出任當事人。遺言的有效性或執行人權限範圍本身的判斷是律師的領域，本文僅為一般性的資訊提供。

四葉不動產株式會社以東京都文京區小日向為據點，承接繼承不動產的估價與出售媒介。關於有遺言執行人涉及的出售，可從出售前能確認的事項開始諮詢。

## 有遺言執行人時，買賣契約的賣方與簽名者是誰？

首先要掌握的是遺言執行人的權限。民法第1012條第1項規定，遺言執行人為實現遺言的內容，享有管理相續財產及為執行遺言所必要之一切行為的權利義務。同條第2項規定，有遺言執行人時，遺贈的履行僅能由遺言執行人為之（平成30年法律第72號修正、2019年7月1日施行）。

誰成為賣方，取決於遺言如何承繼該不動產。

| 遺言的形式 | 不動產的承繼 | 買賣契約的賣方、簽名者 |
| --- | --- | --- |
| 「使之繼承」旨（特定財產承繼遺言） | 於繼承開始時當然承繼予該繼承人 | 取得不動產的繼承人（受益繼承人） |
| 遺贈（特定遺贈） | 受遺人因遺贈而取得 | 取得後為受遺人；遺贈的履行由執行人為之 |
| 清算型遺贈（賣掉再分配旨） | 執行人變價後分配代金 | 執行人進行出售手續 |

民法第1015條規定，遺言執行人於其權限內，表明其為遺言執行人所為之行為，對繼承人直接生效。因此在清算型等由執行人負責出售的場面，執行人以「遺言執行人」身分出任契約當事人。反之，若某特定繼承人依「使之繼承」旨取得不動產、由該繼承人自行判斷出售，賣方就是該繼承人。

究竟屬於哪種類型、遺言文字的解釋，最終是律師的領域。本公司會看遺言的影本與登記狀況，整理買賣當事人可能為誰，須確定的部分則轉介律師、司法書士。執行人的職務與選任機制本身，由行政書士側的[遺言執行人由誰擔任、如何選任（日文）](https://luck428.com/legal/column/yuigon-shikkosha-shokumu-sennin-dare)處理。

## 特定財產承繼遺言（使之繼承旨）與遺贈，在出售與登記的流程上有何不同？

作為出售前提的登記流程，也會隨遺言的形式而變。2021年的不動產登記法修正（令和3年法律第24號）使遺贈的所有權移轉登記之一部分可單獨申請（2023年〈令和5年〉4月1日施行）。但可單獨申請者限於對繼承人的遺贈，對繼承人以外之人的遺贈仍依從前的共同申請。

| 遺言的形式 | 登記的原因 | 申請的形式 |
| --- | --- | --- |
| 「使之繼承」旨（特定財產承繼遺言） | 相續 | 繼承人單獨辦相續登記；執行人亦可為對抗要件的具備（民法第1014條第2項） |
| 對繼承人的遺贈 | 遺贈 | 受遺人（繼承人）可單獨申請（不動產登記法第63條第3項、2023年4月1日施行） |
| 對繼承人以外的遺贈 | 遺贈 | 由受遺人與繼承人（或執行人）共同申請 |

民法第1014條第2項規定，有特定財產承繼遺言時，遺言執行人可為具備對抗要件所必要之行為。要把所有權移轉予買方，通常以先把登記整理到受益繼承人、受遺人的名義為出售前提。清算型遺贈中，可能須經繼承人名義再辦買賣的移轉登記等，順序會較複雜。

登記的原因、順序與單獨申請可否的判斷，以及申請的代理，是司法書士的業務。本公司不代理登記。我們會配合出售時程，與司法書士確認該先整理哪一項登記後再進行。

## 媒介契約、本人確認、交割的現場，執行人與受益繼承人如何涉入？

出售不動產要經過媒介契約（宅地建物取引業法第34條之2）、重要事項說明（第35條）、買賣契約書的交付（第37條）等步驟。有遺言執行人涉入的出售，最要緊的是一開始就確定這些的當事人是誰。

| 場面 | 誰出任當事人（依類型而異） |
| --- | --- |
| 媒介契約 | 成為賣方者（受益繼承人，或清算型中的遺言執行人） |
| 本人確認（犯罪收益移轉防止法） | 成為契約當事人者，與代理的執行人雙方 |
| 重要事項說明 | 對買方的說明；賣方側揭露權利關係、遺言與登記狀況 |
| 交割、交付 | 成為賣方者受領；清算型中由執行人受領並分配代金 |

本人確認由宅地建物取引業者依犯罪收益移轉防止法進行。執行人以賣方身分簽約時，除確認執行人本人外，還要確認顯示其被指定、選任為執行人的資料（遺言書、家庭裁判所的選任審判書等）。受益繼承人為賣方時，則整理該繼承人的本人確認，以及取得不動產的依據（遺言、登記）。

本公司在媒介契約階段，依遺言與登記整理賣方為誰，並於重要事項說明中向買方揭露遺言、執行人的涉入與登記狀況。若預見遺言有效性或權限有無有爭議，我們會請您在進入媒介前先向律師諮詢。

## 若出售內容與遺言不同，或繼承人反對出售，會怎樣？

有遺言執行人時，繼承人不能擅自處分。民法第1013條第1項規定，有遺言執行人時，繼承人不得處分相續財產或為其他妨害遺言執行的行為；同條第2項規定，違反者其行為無效（但不得對抗善意第三人）。

| 狀況 | 整理方式 |
| --- | --- |
| 繼承人未經執行人同意想出售 | 第1013條限制妨害行為；擅自處分原則無效 |
| 繼承人反對出售 | 清算型等屬執行人權限內者，執行人可推進出售 |
| 想以與遺言不同的內容出售 | 能否由繼承人全體合意重做遺產分割，是律師的判斷 |
| 遺言的有效性有爭議 | 出售前先找律師；有效性確定前可能無法進入媒介 |

有反對的繼承人、遺言有效性受爭、執行人權限範圍不明——這些場面的可否，本身即屬個別的法律判斷。包含本公司在內，無資格者都不能斷言「賣得掉」或「賣不掉」。繼承人間的爭執與遺言的解釋交給律師，登記交給司法書士。

關於共有持分或分割的出售思考，可參考[共有人之一把持分賣給第三人時的整理（日文）](https://luck428.com/column/souzoku-kyoyu-mochibun-dai3sha-baikyaku-bunkatsu)與[以變價分割出售繼承不動產的流程（日文）](https://luck428.com/column/kanka-bunkatsu-fudosan-baikyaku-nagare)。

## 出售前執行人該確認哪些文件、如何分配給各專業？（分離受任）

遺言執行人涉入的出售，遺言的解釋、登記、稅務、不動產分屬不同事業體。順序一旦弄錯，就會發生登記未整理就先簽約、誤解讓渡所得稅由誰負擔等情形。

| 角色 | 由誰負責 |
| --- | --- |
| 估價、媒介、重要事項說明、交割 | 宅地建物取引業（本公司） |
| 遺言有效性、執行人權限範圍、繼承人間爭執的判斷 | 律師 |
| 相續登記、遺贈的移轉登記 | 司法書士 |
| 讓渡所得稅、相續稅的計算與申報 | 稅理士 |
| 遺言執行人的選任聲請 | 家庭裁判所 |

出售前要先確認的文件，有遺言書（公證遺言的正本、謄本，自書遺言則為已檢認者）、顯示執行人指定、選任的資料、登記事項證明書、固定資產稅的課稅明細等。清算型中，債務的清償與代金分配的順序也要先整理。

這些是**各自獨立的事業體**，以**分別簽約**為前提。本公司負責不動產的出售面，遺言的解釋與權限判斷交給律師，登記交給司法書士，讓渡所得稅、相續稅交給稅理士。本公司不收取介紹費。

## 常見問題

**Q. 我以「使之繼承」旨的遺言取得了不動產，賣方是我沒錯吧？**
A. 特定財產承繼遺言（「使之繼承」旨）中，不動產於繼承開始時當然承繼予該繼承人，因此原則上由取得的繼承人當賣方。遺言執行人享有為具備對抗要件所必要之行為（如相續登記）的權限（民法第1014條第2項）。若對文字有疑義，請向律師確認。

**Q. 遺言寫明由執行人賣掉再分配（清算型），契約由誰締結？**
A. 把遺產賣掉分配代金的清算型中，遺言執行人為實現遺言內容而推進出售手續（民法第1012條第1項、第1015條），以「遺言執行人」身分出任契約當事人。登記順序與代金分配會與司法書士、稅理士確認後進行。

**Q. 繼承人之一反對出售，賣得掉嗎？**
A. 處理方式會依是執行人權限內的出售（如清算型）、還是取得的繼承人自行出售，以及遺言有效性是否有爭議而不同。民法第1013條限制有執行人時繼承人的妨害行為。因可否屬個別法律判斷，請向律師諮詢。本公司負責出售的媒介面。

**Q. 受遺贈的不動產登記，我可以自己一個人申請嗎？**
A. 依2023年4月1日施行的不動產登記法第63條第3項，對繼承人的遺贈，受遺人可單獨申請所有權移轉登記；對繼承人以外的遺贈仍依從前的共同申請。登記可否的判斷與申請代理是司法書士的業務，實際申請由其承辦。
