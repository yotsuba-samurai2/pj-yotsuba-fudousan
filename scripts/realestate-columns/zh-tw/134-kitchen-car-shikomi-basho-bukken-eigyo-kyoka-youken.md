**先講重點**：餐車的「備料場所（中央廚房）」原則上需要一處與車輛分開、另外取得營業許可的設施。車輛能載的水有限，保健所的基準會依給排水水箱的容量，限制車內可進行的調理範圍，因此前處理與加工基本上要在許可設施進行。選物件的關鍵有三：能否依設施基準備妥給排水與洗手設備、能否把作業區與住居及其他用途明確區隔、用途地域與租賃契約是否允許該營業。營業許可的區分判斷與向保健所協商、申請，交給行政書士與保健所；用途地域及用途變更的最終判斷交給特定行政廳與建築士；物件的租賃與用途確認由本公司負責。

以行動餐車創業，或已在用車輛販售、想租一處做前處理的據點——這時候「備料在哪裡做」「什麼物件保健所才會核發許可」是第一道關卡。很多情況下光靠車輛無法完成作業，若在選物件前沒有先掌握設施基準與用途，很可能簽約後才發現許可下不來。

本文從設備、許可、用途三個角度，整理在挑選餐車備料據點物件的階段、簽約前可以確認的事項。屬於哪一種營業許可的區分，以及與保健所的協商，是行政書士與保健所的領域，本文僅為一般性資訊提供。

四葉不動產株式會社以東京都文京區小日向為據點，承接事業用物件的租賃仲介，以及用途地域與用途變更的事前確認。關於餐車的備料據點，歡迎在決定物件之前就與我們洽談。

## 餐車為什麼一定要有「備料場所」？

餐車（食品的行動販售）是車輛本身取得食品衛生法第55條第1項的營業許可（飲食店營業等）來營業。但車輛能載的水量有限，保健所的設施基準一般會依給水水箱、排水水箱的容量，區分車內可進行的調理範圍。

埼玉縣東松山保健所、茨城縣日立保健所的說明，把水箱容量的大致標準說明如下（容量與條件各地不同，最確實的做法是帶著圖面向營業預定地的保健所確認）。

| 給水・排水水箱容量（大致標準） | 車內可進行的調理 |
| --- | --- |
| 約40L以上 | 僅簡易調理，或單一品項；以拋棄式容器為前提 |
| 約80L以上 | 兩道工序左右的簡易調理、多項品項；以拋棄式容器為前提 |
| 約200L以上 | 多工序調理，或使用一般餐具的營業 |

因此，前處理、切配、調味、加工等「備料」很難在車內完成，茨城縣日立保健所說明「需要備料時，須在已取得食品營業許可的設施進行」。這正是餐車之外還需要備料場所（中央廚房）物件的原因。

## 備料場所的物件需要什麼設備？（給排水、洗手、區隔）

備料場所本身就是一處要取得營業許可的「設施」。設施基準依食品衛生法第54條，由各都道府縣等參酌厚生勞動省令（食品衛生法施行規則別表所定基準）以條例訂定。隨著2018年修正法於令和3年（2021年）6月1日施行，這套基準的骨架已在全國平準化。在物件階段，大致有以下重點。

| 確認項目 | 物件要看的重點 |
| --- | --- |
| 給水・排水 | 能否引入必要的給排水設備；排水能否妥善處理 |
| 洗手設備 | 作業區能否設置專用洗手設備（含消毒設備） |
| 作業區隔 | 前處理・調理的區域能否與住居及其他用途明確區隔 |
| 地板・牆・天花板 | 能否以易清潔、不透水的材質收邊 |
| 換氣・照明 | 作業場能否確保足夠的換氣與照明 |
| 保管設備 | 能否放置原材料・器具的保管及冷藏冷凍設備 |

具體數值與細項，各地條例與保健所運用會有差異。不要在物件端自行斷定細節，帶圖面向保健所事前協商最確實。關於在毛胚（骨架）餐飲物件確認排氣與給排水的思路，[在骨架物件開餐飲店時的排氣、油脂截留器與防火確認點（日文）](https://luck428.com/zh-tw/column/inshokuten-skeleton-bukken-haiki-grease)也可參考。

## 需要哪種營業許可？由誰申請？

需要取得許可的營業業種，由食品衛生法第55條第1項所銜接的食品衛生法施行令第35條規定。隨著令和3年（2021年）6月1日施行的修正，許可業種由原本的34種重編為32種。備料場所屬於哪一種區分，會依製作的食品與工序而變。

| 可能的區分 | 什麼情況（例） |
| --- | --- |
| 飲食店營業 | 備料經調理後提供的食品 |
| 熟菜（そうざい）製造業 | 以一定量製造燉煮・燒烤・油炸等副食 |
| 申報業種 | 不屬於許可業種的部分營業（食品衛生法第57條的申報） |

屬於哪一區分，車輛的許可與備料場所的許可要分開取得還是在同一設施處理，都屬個別判斷。這個區分判斷與向保健所協商、製作營業許可申請文件，屬行政書士與保健所的領域。本公司不代辦許可申請。物件的租賃與用途確認由本公司負責，許可的區分與申請轉介給行政書士與保健所。

## 用途地域與租賃契約要確認什麼？

備料場所是固定設施，因此和車輛不同，會受到用途地域的限制。建築基準法第48條與別表第二，就各用途地域規定可建築的建築物用途。若以飲食店營業備料，視為「店舖・飲食店」；若以熟菜製造業大量製造，則接近「工廠」處理，依製造規模，可能在住居系地域受限。

| 確認項目 | 要看的重點 |
| --- | --- |
| 用途地域 | 所設想的營業用途在該地域是否被允許 |
| 用途變更 | 既有建物變更用途時，是否需要確認申請（依規模而定） |
| 租賃契約 | 使用目的能否納入「食品的製造・調理」；回復原狀的範圍 |
| 鄰里 | 臭氣・排水・搬出入是否會與鄰里衝突 |

是否符合用途地域、是否需要用途變更的確認申請，最終由特定行政廳與建築士判斷。本公司事前確認物件的用途地域與租賃的使用目的，涉及確認申請時轉介建築士。

## 可以用自宅或既有店舖當備料場所嗎？

「能不能在自宅廚房備料」是常見的諮詢，但備料場所必須是取得營業許可的設施，若住居與作業區沒有區隔，通常難以符合基準。即使使用自宅一部分，分界在於能否依基準備妥作業區、洗手與給排水，並與居住空間分開。

若要把既有餐飲店舖當備料據點，須向保健所確認該店舖的營業許可區分能否涵蓋備料，若在營業時間外當作另一事業使用，則許可的名義與區分要如何整理。兩者的可行與否都取決於個別設施與運用，無資格者不能斷言「可以使用」。在看屋階段，本公司確認用途地域與租賃條件，許可的可行性轉介行政書士與保健所。

## 常見問題

**Q. 車輛有許可，備料場所就不用許可了嗎？**
A. 車輛與備料場所一般被視為各自獨立的設施，許多保健所說明，需要備料時須在已取得許可的設施進行（茨城縣日立保健所等）。車內能完成到什麼程度，會依給排水水箱容量而變，請帶圖面向營業預定地的保健所確認。

**Q. 備料場所會是哪一種營業許可區分？**
A. 依製作的食品與工序，分為飲食店營業、熟菜製造業等。許可業種由食品衛生法第55條第1項與施行令第35條規定，並隨令和3年（2021年）6月1日施行的修正由34種重編為32種。區分判斷與申請屬行政書士與保健所的領域，請向該處確認具體區分。

**Q. 可以把自宅廚房當備料場所嗎？**
A. 備料場所必須是取得營業許可的設施，分界在於能否把住居與作業區區隔，並依基準備妥洗手與給排水。多數情況需要與居住空間分開的專用區。可行與否取決於個別設施與保健所的運用，無法一概斷言。

**Q. 租了之後許可下不來會很困擾，順序該怎麼安排？**
A. 在決定物件之前，先確認所設想的營業在用途地域是否被允許、格局能否符合設施基準，並向保健所事前協商後再簽約，較為安全。本公司負責物件的用途確認與租賃，許可的區分・協商轉介行政書士與保健所。
