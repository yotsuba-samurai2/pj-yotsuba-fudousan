**先講重點**：不附設火化爐的殯葬式場（追思會館），在建築基準法上大致被當作「集會場」，受各用途地域的建築限制。它與另有立地框架的火葬場不同。在找物件之前，先把用途地域、接道、停車場與鄰里應對分開確認。

想用空倉庫、路邊建物或自有土地開設家族葬會館、出租式場，或出租給殯葬業者的諮詢日益增加。然而，並非任何建物都能當作殯葬式場。多數計畫會卡在用途地域限制、接道、停車場，或向鄰里說明這幾個階段。

最容易一開始就卡住的，是把殯葬式場與火葬場混為一談。兩者的建築與許可框架不同，若當成同一種「殯葬設施」去找物件，往往事後才發現蓋不了、租不了。

四葉不動產株式會社以東京都文京區為據點，承接事業用物件的調查與租賃、買賣仲介。我們可以從賣方、出租方、承租方各自的立場出發，先整理「這個物件能否開設式場、能否出租」這個前提。

## 追思會館與火葬場、墓地有何不同？屬於哪種許可框架？

框架首先依「設施是否有火化爐、是否收藏遺骨」而分。只舉行守靈、告別式等儀式，而不涉及火化或埋藏、收藏的殯葬式場，一般不屬於墓地、埋葬等相關法律（墓地埋葬法）的經營許可對象。

| 設施 | 主要依據 | 立地與許可框架（概略） |
| --- | --- | --- |
| 殯葬式場（無火化爐） | 建築基準法（集會場） | 受用途地域建築限制（法第48條、別表第二）。若不涉火化，則非墓地埋葬法經營許可對象 |
| 火葬場 | 建築基準法第51條、墓地埋葬法 | 在都市計畫區域內，須於都市計畫中決定其基地位置，或取得特定行政廳許可等。另須取得墓地埋葬法的經營許可 |
| 墓地、納骨堂 | 墓地埋葬法 | 因涉及遺骨埋藏、收藏，屬經營許可對象（另有專文，屬行政書士領域） |

墓地埋葬法第2條界定埋葬、火化、墳墓、墓地、納骨堂與火葬場等，第10條規定經營墓地、納骨堂或火葬場須取得都道府縣知事等的許可。附設火化爐的計畫同時牽涉此經營許可與建築基準法第51條，立地門檻大幅提高。

即使是不涉火化的式場，仍會以「集會場」身分受用途地域限制與消防基準規範。墓地埋葬法是否適用的最終判斷，以及涉及火化、收藏之計畫是否可行，請向自治體主管課與承辦許可的行政書士確認。墓地、納骨堂的經營許可另見[墓地、納骨堂的經營許可](https://luck428.com/zh-tw/legal/column/bochi-noukotsudo-keiei-kyoka-youken-nagare)。

## 用途地域下，殯葬式場能開到什麼程度？哪種物件蓋不了？

不涉火化的殯葬式場，一般被當作「集會場」，受各用途地域建築限制。建築基準法第48條與別表第二，就各用途地域規定了可建與不可建的建築物。都市計畫法第8條、第9條界定用途地域的種類與宗旨，具體的建築限制則由建築基準法承擔。

| 用途地域舉例 | 集會場（殯葬式場）之對待（一般傾向） |
| --- | --- |
| 第一種、第二種低層住居專用地域、第一種中高層住居專用地域 | 集會場原則上蓋不了。雖有特定行政廳許可的例外空間，但無保證 |
| 第二種中高層住居專用地域至鄰近商業、商業、準工業等 | 依規模與地域可能可建，但須確認面積要件與附帶條件 |
| 工業、工業專用地域 | 從其他角度另有限制，須逐案確認 |

不過，這終究只是一般傾向。即使同一用途地域，也會因建物規模、是否既存不適格、地區計畫等上位規範而結論不同。用途是否適用、能否建築，是由特定行政廳（建築指導課）與建築師判斷的事項。別憑推測斷定「蓋得了」，請提出計畫規模逐案確認。

事業用物件的用途地域判讀，不同業種之間也有共通的思路。[小規模多機能居家照護的物件與用途地域](https://luck428.com/zh-tw/column/shoukibo-takino-kaigo-bukken-youken)、[旅館業、飯店的營業與物件要件](https://luck428.com/zh-tw/column/ryokangyo-hotel-eigyo-bukken-youken)，都可作為以用途地域篩選物件的參考。

## 在建築基準法、消防法、停車場附設義務上，式場物件須具備什麼條件？

即使通過用途地域，建物本身與設備的基準仍在。集會場屬多人聚集的用途，避難、防火與來場車輛的處理都會成為論點。

| 確認面向 | 主要內容 |
| --- | --- |
| 建築基準法（集會場） | 作為特殊建築物的避難、防火基準，以及依樓地板面積而定的規定。既有建物則須看有無竣工檢查證、是否既存不適格 |
| 消防法 | 依消防法施行令別表第一的防火對象物分類（集會場有對應區分），備置消防設備與辦理申報。須事先洽所轄消防署 |
| 停車場 | 弔唁者、靈柩車、接送巴士的進出。若規模觸及自治體停車場附設義務條例，須確認附設義務 |
| 周邊道路 | 靈柩車、巴士的進入與迴轉、建物前的停車空間，以及與鄰里生活動線的干擾 |

停車場附設義務依建物用途與總樓地板面積等，由自治體條例規定。各自治體基準不同，請連同參照日確認物件所在地的條例。弔唁者的車輛若滯留路面，容易成為與鄰里摩擦的導火線，因此除法定附設義務外，也要預估實際運用車數。

將既有建物改作式場時，也要確認有無竣工檢查證與是否需用途變更。用途變更的處理可參考[將無竣工檢查證的物件改作福祉用途](https://luck428.com/zh-tw/column/kensazumisho-nashi-bukken-fukushi-youto-henko)，消防與噪音論點可參考[卡拉OK包廂物件與用途地域、消防](https://luck428.com/zh-tw/column/karaoke-box-tenpo-bukken-youto-shoubou-soon)。避難、防火之具體基準是否符合，請向建築師與所轄消防署確認。

## 將市街化調整區域的既有建物改作會館時，開發許可與用途變更如何處理？

路邊建物與郊區倉庫常位於市街化調整區域。在該區域，建築與用途變更受都市計畫法限制。

都市計畫法第29條規定開發行為須取得知事等許可；第34條就市街化調整區域的開發許可立地基準採限定列舉；第43條規定在開發許可區域以外，新建、改建建築物，或變更用途為不同種類建築物時，須取得知事等許可。也就是說，僅把既有倉庫「用途變更」為殯葬式場，在市街化調整區域也可能須檢討是否要許可。

能否以既有建物之改建處理，或須以用途變更取得新許可，取決於與原建物在用途、規模上的同一性，以及自治體的運用基準。能否符合許可立地基準的判斷，以及開發許可、用途變更許可的申請，屬行政書士領域。市街化調整區域物件的思路另見[將市街化調整區域的既有建物作事業用](https://luck428.com/zh-tw/column/kensetsugyo-shizaioki-shako-chosei-kuiki-bukken)。

物件位於哪一區域區分，應作為買賣、租賃的前提先行調查。別斷定市街化調整區域必然不可、市街化區域必然可行，請把區域區分、用途地域、接道一併確認。

## 在挑選物件前，鄰里說明與社區應對該先確認什麼？

即使符合法令基準，殯葬式場仍可能因鄰里關係而無法推進。對弔唁者進出、接送車輛、夜間人員動向的疑慮，曾有演變為反對運動與糾紛的報導案例。決定物件前，請確認以下各點。

- 用途地域、區域區分，以及周邊住宅、設施的立地
- 自治體是否就殯葬設施設有自訂條例、指導綱要或事前協議機制
- 向社區、町內會事前說明的慣例，以及被要求說明的範圍
- 弔唁者、車輛動線是否與鄰里生活動線或通學路衝突

部分自治體就殯葬場、齋場設有距離限制或事前申報、協議的條例或綱要。請連同參照日確認物件所在地的條例、綱要，必要時洽事前協議窗口。若與鄰里的協商演變為糾紛，進而成為損害賠償或禁止請求等法律爭議，則屬律師領域。四葉不動產整理物件與法令前提，但不承接糾紛代理，也不作法律判斷。

## 以出租式場方式租給殯葬業者時，租賃契約與回復原狀如何整理？

把自有建物或土地不自營、改租給殯葬業者，也是一種出場方式。此時出租方並非式場經營者，而是以建物、土地的出租人身分參與。

| 整理項目 | 確認內容 |
| --- | --- |
| 用途與許可前提 | 承租方用途（作為集會場的式場）是否符合用途地域、建築、消防基準。許可由承租方取得 |
| 租賃條件 | 用途限定、內裝與設備工程的負擔、招牌、鄰里應對的角色分擔、契約期間 |
| 回復原狀 | 式場規格的內裝、設備，於契約終了時由誰、回復至何種程度。特殊設備的處理 |
| 風險分擔 | 鄰里應對與客訴、設備維護、租金滯納時的處理 |

出租方與承租方立場不同，請在契約中明確用途與工程、回復原狀的範圍。租賃仲介與條件整理由宅建業（本公司）承擔，租賃契約書的內容確認在仲介範圍內進行。租賃仲介與服務範圍可參考[服務介紹](https://luck428.com/zh-tw/services)。承租方須取得哪些許可，以及鄰里糾紛化時的應對，分別屬行政書士與律師領域。

## 常見問題

**Q. 可以把住宅區的空屋改成追思會館嗎？**
A. 視用途地域而定。不涉火化的式場一般被當作「集會場」，在第一種、第二種低層住居專用地域與第一種中高層住居專用地域傾向原則上蓋不了。是否適用、能否可行由特定行政廳與建築師判斷，請提出計畫規模逐案確認。

**Q. 可以把路邊倉庫（市街化調整區域）改作式場嗎？**
A. 在市街化調整區域，即使是用途變更，也可能須依都市計畫法檢討是否要許可。能否符合立地基準的判斷與許可申請屬行政書士領域。請在把區域區分、用途地域、接道一併確認後再判斷。

**Q. 我也想一併興建火葬場，找物件的做法會改變嗎？**
A. 會。附設火化爐會加上墓地埋葬法的經營許可與建築基準法第51條的立地框架，門檻大幅提高。經營許可屬行政書士、立地可否屬特定行政廳領域，應與僅設式場的計畫分開檢討。

**Q. 若不自營、只租給殯葬業者，是否就不需要許可？**
A. 出租方屬出租人立場，式場的許可與鄰里應對原則上由承租方負責。不過，用途須符合用途地域、建築、消防，是租賃的前提。請在租賃契約中先明確用途限定與回復原狀。
