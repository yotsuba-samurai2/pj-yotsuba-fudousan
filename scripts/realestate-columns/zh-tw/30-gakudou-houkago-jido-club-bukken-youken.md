**結論（先講重點）**：可用於學童保育（放課後兒童俱樂部＝放課後兒童健全育成事業）的物件，大致由五點決定——①用途地域（建築基準法別表第二：工業專用地域不得興建兒童福祉設施等，其餘12個地域原則可）；②專用區劃面積（放課後兒童健全育成事業之設備及運營基準〈平成26年厚生勞動省令第63號〉第9條＝每名兒童約1.65平方公尺以上、含靜養區劃）；③避難的難易（若把兒童活動室放在二樓以上，須確認避難路徑與防火）；④消防（消防法施行令別表第一的用途分類）；⑤耐震（新耐震＝昭和56年6月以後）。可否的最終確認，在特定行政廳、市町村與消防署的窗口進行。

「放課後日間照顧的物件要件之前看過了，學童也照那樣就好嗎？」我們常收到這個問題。答案是：這是不同制度，看物件的方式也有一部分不同。本文從條文與省令，整理房東、承租人在**選物件階段**能確認的學童（放課後兒童俱樂部）適合條件。事業的申報本身（放課後兒童健全育成事業的申報），是行政書士或業者本人向市區町村辦理的手續，本公司不代辦。若屬於需要用途變更確認申請的規模，則轉介建築士。

## 放課後兒童俱樂部與放課後日間照顧，物件要件也是兩回事嗎？

是的，是兩回事。名稱相似常被混淆，但**根據法、主管機關、面積基準都不同**。搞錯的話，該找的物件與該諮詢的對象都會改變。

放課後兒童俱樂部（學童保育），是**兒童福祉法第6條之3第2項**所定的「放課後兒童健全育成事業」：對就讀小學、其保護者因工作等白天不在家的兒童，於課後給予適當的遊戲與生活場所，以圖其健全育成。是不分有無障礙的一般「學童」。

放課後日間照顧則是**兒童福祉法第6條之2之2的障礙兒通所支援**之一，對象是有障礙的就學兒。兩者的主管、手續與基準都不同。

| | 放課後兒童俱樂部（學童） | 放課後日間照顧 |
|---|---|---|
| 根據法 | 兒童福祉法6條之3第2項 | 兒童福祉法6條之2之2（障礙兒通所支援） |
| 對象 | 小學生（保護者白天不在家） | 有障礙的就學兒 |
| 手續 | 向市町村長**申報**（34條之8第2項） | 都道府縣、指定都市等的**指定** |
| 設備基準 | 省令第63號＋市町村條例 | 省令第15號＋自治體條例 |
| 面積 | 專用區劃 每名兒童約1.65㎡ | 指導訓練室等（自治體條例） |

放課後日間照顧的物件要件另見[放課後日間照顧的物件由用途地域、一樓、面積與採光決定](https://luck428.com/column/houkago-day-bukken-youto-chiiki-1kai)，托育另見[小規模托育的物件與用途地域](https://luck428.com/column/hoiku-shoukibo-bukken-youto-chiiki)。本文專就學童（放課後兒童俱樂部）。

## 學童的物件，在哪些用途地域可以用？

放課後兒童俱樂部在建築基準法上一般被視為**「兒童福祉設施等」**。能否於某用途地域興建，由建築基準法（昭和25年法律第201號）第48條與**別表第二**決定。

大致而言，**工業專用地域不得興建兒童福祉設施等**，其餘12個用途地域原則上可興建。第一種、第二種低層住居專用地域與田園住居地域也原則可，惟可能因規模而須確認。學童多設於住宅區內，此點在實務上少有卡關。

| 用途地域 | 兒童福祉設施等之興建 |
|---|---|
| 第一・二種低層住居專用、田園住居 | 原則可（可能須確認規模） |
| 中高層、住居系 | 可 |
| 近鄰商業、商業 | 可 |
| 準工業、工業 | 可 |
| 工業專用 | **不可** |

「該地域必定可用」並非保證。**用途地域上的可否最終由特定行政廳確認。**

## 每名兒童的面積、靜養空間與避難的概略標準？

面積的骨架由**放課後兒童健全育成事業之設備及運營基準（平成26年厚生勞動省令第63號）**訂定，核心有三：

- **專用區劃面積**：第9條第2項將兼具遊戲與生活場所機能**及靜養機能之區劃（專用區劃）**的面積，定為**每名兒童約1.65平方公尺以上**。靜養空間不是額外努力，而是此專用區劃的要素。
- **支援的單位**：第10條第4項將**一個支援單位的兒童數定為約40人以下**。
- **職員**：第10條要求**每一支援單位配置放課後兒童支援員2人以上**，支援員須為保育士、社會福祉士等並**修畢都道府縣知事等辦理之研修**（1人可以輔助員代替）。

選物件階段，先看能否取得「**兒童數×1.65㎡**的專用區劃」、能否確保靜養區劃。40人規模時，僅專用區劃約需66㎡以上為概略標準。惟此省令現為**「應參酌之基準」**，**實際適用的數值由市町村條例訂定**。1.65㎡、40人只是國家的概略標準，請以預定開設之市區町村條例、運營要綱確認。

| 看的項目 | 由什麼決定 | 主要確認處 |
|---|---|---|
| 專用區劃面積 | 省令第63號（每人約1.65㎡）＋條例 | 市町村 |
| 靜養空間 | 作為專用區劃的機能（第9條） | 市町村 |
| 支援單位（約40人以下） | 省令第63號第10條＋條例 | 市町村 |
| 避難（放二樓以上時） | 建築基準法避難規定、自治體運用 | 特定行政廳 |

把兒童活動室放在二樓以上時，會依建築基準法避難規定與自治體運用追加確認。一樓單層完結則此點較輕。

## 獨棟或空店面能轉為學童嗎？（需要用途變更的規模）

可以。實務上空店面、獨棟的轉用很多，這裡要看**用途變更確認申請、耐震與消防**。

建築基準法**第87條第1項**規定：將建築物用途變更為**特殊建築物**、且供該用途之樓地板**面積超過200㎡**時，準用確認申請規定。兒童福祉設施等屬此特殊建築物。反過來說，**200㎡以下不需用途變更確認申請**（此提高至200㎡係2019年〈令和元年〉6月25日施行之修正，此前為100㎡）。

但「不需申請＝可原樣使用」並不成立。即使規模不需申請，仍須另行符合避難、防火、消防。耐震以**昭和56年6月1日以後的新耐震基準**為首要分界。

| 項目 | 確認事項 | 確認處 |
|---|---|---|
| 用途變更確認申請 | 該用途部分是否超過200㎡（法87條1項） | 特定行政廳、建築士 |
| 耐震 | 是否昭和56年6月以後新耐震；舊耐震則診斷、補強 | 建築士 |
| 消防 | 用途分類與消防設備之要否 | 所轄消防署 |

**面積是否超過200㎡的判斷、設計與手續屬建築士（設計者）的領域。** 本公司確認物件面積與現況並提供見解，用途變更的可否最終判斷與申請請直接委託建築士。

## 押下物件前，要向市區町村確認什麼？

學童是**由市町村依地方實情擔任實施主體**的事業，補助與運營框架因自治體差異甚大。押下物件前先向預定開設之市區町村確認以下，可減少反覆。

| 確認事項 | 為何 |
|---|---|
| 面積、支援單位的條例基準 | 省令僅「應參酌」，實數由條例定 |
| 申報之要否、格式（34條之8第2項） | 民間辦理時須事先向市町村長申報 |
| 補助、委託之要綱與募集時期 | 自治體運營、補助之地域，物件要件會確定 |
| 消防、建築的事前諮詢 | 轉用時的設備負擔可於簽約前掌握 |

物件間隔是否達基準的見解，以及租售中介，由四葉不動產株式會社（宅地建物取引業 東京都知事(1)第113304號）承辦。角色分工如下：

| 擔當者 | 角色 |
|---|---|
| 宅地建物取引業者（本公司） | 確認用途地域、面積、現況，租售中介 |
| 行政書士 | 放課後兒童健全育成事業申報書類之製作、自治體協議 |
| 建築士 | 用途變更確認申請之要否判斷、設計、手續 |
| 所轄消防署、消防設備士 | 消防設備之要否判斷、設置 |
| 司法書士 | 公司設立、不動產登記 |

**事業申報請找行政書士或業者本人，用途變更確認申請找建築士，消防設備找消防設備士，公司設立與登記找司法書士，各自直接委託。** 上述各為獨立的事業體，與本公司分別簽約。本公司不收取也不支付介紹費、送客手續費。諮詢免費。事業用物件的整體諮詢見[事業用不動產諮詢](https://luck428.com/toushi)，開業所需物件搜尋見[事業所、辦公室諮詢](https://luck428.com/office)。

## 常見問題

**Q. 放課後兒童俱樂部與放課後日間照顧，可以用同一物件基準找嗎？**
A. 不行，是不同制度、基準不同。學童（放課後兒童俱樂部）是6條之3第2項的事業，專用區劃每名兒童約1.65㎡（省令第63號），手續為向市町村長申報。放課後日間照顧是障礙兒通所支援，面積基準與手續（指定制）都不同。找物件前先確定是哪種事業。

**Q. 專用區劃需要幾平方公尺？**
A. 省令第63號第9條將含靜養機能的專用區劃定為每名兒童約1.65㎡以上。40人規模時約需66㎡以上為概略標準。惟此省令為「應參酌之基準」，實際數值請以預定開設之市區町村條例確認。

**Q. 民間辦學童時，申報向哪裡提出？**
A. 國、都道府縣、市町村以外之人辦理放課後兒童健全育成事業時，依兒童福祉法34條之8第2項，事先向市町村長申報。申報書類之製作由行政書士承辦，本公司不代辦申報。物件的中介與申報手續各為獨立事業體、分別簽約。

**Q. 把辦公室改為學童，一定要用途變更確認申請嗎？**
A. 供該用途之樓地板面積超過200㎡時，依建築基準法第87條第1項需要確認申請。200㎡以下不需，但仍須另行符合避難、防火、消防。樓地板面積之判斷與申請請直接委託建築士。
