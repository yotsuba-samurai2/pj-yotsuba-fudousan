**結論（先說重點）**：自立訓練（生活訓練・機能訓練）的事業所物件，先看三點──①用途地域（自立訓練事業所在建築基準法上屬「兒童福祉設施等」，工業專用地域以外大致可建）②能否確保訓練・作業室・諮詢室・盥洗室・廁所・多目的室（指定障害福祉服務基準〈平成18年厚生勞動省令第171號〉第168條，機能訓練為第158條準用第81條）③消防法施行令別表第一的用途區分（自立訓練原則為(6)項ハ）與自動火災警報設備的要否。訓練室並無「3㎡×定員」之類的數值面積基準，省令只規定「不妨礙訓練的寬度」。簽約前先確認用途地域・設備・消防・用途變更的要否・出租人可否，可避免返工。

「租下店面之後」才發現諮詢室無法隔間、或因追加消防設備而延後開業──餐飲店或診所會遇到的返工，在自立訓練事業所同樣會發生。本文寫給為開設自立訓練事業所（障害者總合支援法的訓練等給付）而在找租賃物件的法人・個人事業主，以及出租該物件的屋主，依指定障害福祉服務的事業等人員、設備及營運相關基準（平成18年厚生勞動省令第171號）與建築基準法・消防法的條文，依序整理簽約前可確認的事項。人員配置的常勤換算與社會保險的勞務、指定申請文件的製作、報酬的計算不在本文範圍。物件能否滿足基準的最終確認，在指定權者（都道府縣・市町村）與特定行政廳・消防署的窗口進行。

## 自立訓練的事業所物件，與其他障害福祉服務有何不同？

首先要掌握的是，自立訓練有**機能訓練**（維持・回復身體機能的訓練）與**生活訓練**（維持・提升生活能力的訓練）兩類，兩者都是障害者總合支援法第5條第12項所定的**訓練等給付**服務。它與就勞移行支援・就勞繼續支援A/B・生活介護・放課後等日間照顧・兒童發展支援同屬「障害福祉服務」，但**設備・人員基準依類型分別以不同條文規定**，影響物件的要件也不同。

就物件選擇而言，自立訓練有以下三項特徵。

| 觀點 | 自立訓練（生活訓練・機能訓練）的影響 |
|---|---|
| 用途地域 | 建築基準法上屬「兒童福祉設施等」，工業專用地域以外大致可建 |
| 訓練室面積 | **無數值面積基準**。只規定「不妨礙訓練或作業的寬度」（並無通所介護「3㎡×定員」之類的基準） |
| 消防區分 | 原則為消防法施行令別表第一(6)項ハ。主要收容避難困難者的設施為(6)項ロ |

**也就是說，若比照通所介護或團體家屋以「由定員逆推面積」來思考，就會誤判。** 自立訓練的訓練・作業室沒有數值基準，相對地需自行設計不妨礙訓練內容的寬度。介護事業所一般的用途地域觀念，另於內部文章整理。此外，生活訓練除日間通所型外尚有住宿型（指定住宿型自立訓練），住宿型需追加居室・浴室，設備思路不同，本文主要以日間通所型為前提。事業用物件整體請見[投資・事業用不動產](https://luck428.com/zh-tw/toushi)，事務所與許認可的關係請見[公司設立與辦公室選擇](https://luck428.com/zh-tw/office)。

## 訓練室・諮詢室・廁所等，面積與設備的最低基準看哪裡？

設備基準的核心，機能訓練為**第158條準用的第81條**，生活訓練為**第168條**（均為平成18年厚生勞動省令第171號。**2026年11月19日參照**）。兩者都要求事業所設置以下設備。

| 設備 | 基準上的定位 | 物件要確認的素地 |
|---|---|---|
| 訓練・作業室 | 必置。**不妨礙訓練或作業的寬度**，並備訓練所需機械器具等 | 無數值基準；足以進行訓練內容的寬度與放置器具的區劃 |
| 諮詢室 | 必置。**須設防止室內談話外洩的隔間等** | 能否隔為個室或以隔間區劃 |
| 盥洗室 | 必置。依利用者特性 | 能否對應輪椅・障害特性的盥洗 |
| 廁所 | 必置。依利用者特性 | 能否無障礙化的廁所 |
| 多目的室 | 必置。其他營運所需設備 | 於無妨礙時可與諮詢室兼用 |

**要留意的是，訓練・作業室沒有「○㎡×定員」之類的數值基準。** 通所介護以「3㎡×利用定員以上」用數字綁定食堂兼機能訓練室，但自立訓練的訓練・作業室只規定「不妨礙訓練的寬度」。因此需**由定員・訓練課程自行估算所需寬度**，內見時確認有效面積（扣除柱・水路的實測）較為安全。

另一個關鍵是**諮詢室與多目的室的兼用**。第168條第4項（機能訓練為準用的第81條第3項）規定，於不妨礙利用者支援時可將諮詢室與多目的室兼用。以單一樓層節省區劃是可行的，但諮詢室以防止談話外洩的隔間為前提。

又，生活訓練若辦理**住宿型（指定住宿型自立訓練）**，依第168條第3項，除上述外尚需**居室（每室定員1人、扣除收納設備等後7.43平方公尺以上）與浴室**。居室7.43平方公尺是本領域少見的數值基準，若考慮住宿型，宜及早確認物件格局。區劃・給排水・無障礙的設計，以及用途變更確認申請的要否判斷，屬建築士・設計者的領域。**本公司（不動產公司）協助物件能否滿足這些條件的事前調查，以及與出租人的條件交涉。** 設備設計與構造適合的判斷本身不由本公司進行。

## 哪個用途地域能開設？建築基準法上需要用途變更嗎？

自立訓練事業所在建築基準法上並非「診療所」或「店鋪」，而是作為**「兒童福祉設施等」**處理。建築基準法施行令第19條第1項於「兒童福祉設施等」中明列「障害福祉服務事業（限於生活介護、自立訓練、就勞移行支援或就勞繼續支援之事業）所使用的設施」，自立訓練事業所即屬此。用途地域的限制準用建築基準法別表第二中兒童福祉設施等的處理（**2026年11月19日參照**）。

| 用途地域 | 自立訓練事業所（兒童福祉設施等）可否的大致判斷 |
|---|---|
| 工業專用地域 | 不可建 |
| 第一種・第二種低層住居專用地域 | 原則可（依規模有面積限制） |
| 上述以外的住居系・商業系・工業地域 | 原則可 |

**亦即，單就用途地域卡關的大致只有工業專用地域，住宅區的低層住專也有開設餘地。** 但建築基準法上的用途判斷，會因事業所規模・型態與特定行政廳的運用而變動。**可否的最終確認請於特定行政廳（建築指導課）的窗口進行。**

另一關鍵是**用途變更的確認申請**。將原為物販店鋪或事務所的建物改為自立訓練事業所（兒童福祉設施等）時，該用途部分的樓地板面積超過200平方公尺即需確認申請（建築基準法第6條・第87條）。**該當與否及要否的判斷屬建築士的領域**，簽約前先行評估可避免返工。市街化調整區域內的物件，尚須疊加都市計畫法的開發許可・建築許可，宜先確認區域區分。

## 消防法的用途區分與灑水・自動火災警報設備如何確認？

因利用者每日往來，**消防設備是物件選擇的關卡**。首先是用途區分。消防法施行令別表第一(6)項ハ(5)明列障害者總合支援法第5條第12項的**自立訓練之施設**，故通所型的自立訓練事業所原則上區分為**(6)項ハ**（**2026年11月19日參照**）。而主要收容避難困難障害者等的障害者支援設施型，或以避難困難者為主的短期入所・共同生活援助設施，則區分為(6)項ロ。

區分確定後，自動火災警報設備的要否即可自條文讀出（施行令第21條第1項）。

| 自立訓練事業所型態 | 消防區分 | 自動火災警報設備 |
|---|---|---|
| 日間通所型（無入居・住宿） | (6)項ハ | **樓地板面積300㎡以上**需設置（第21條第1項第3號ロ） |
| 住宿型（使利用者入居・住宿） | (6)項ハ | **不論面積**均需設置（第21條第1項第1號ロ） |
| 主要收容避難困難者的型態 | (6)項ロ | 不論面積均需設置 |

**灑水設備・向消防機關通報的火災警報設備・誘導燈等的要否，取決於區分（ロ或ハ）與樓地板面積・收容人員**，僅憑本文條文無法對個別物件下結論。何種設備需到何種程度的判斷與設置，屬消防署（預防課）與消防設備業者的領域。簽約前先確認消防設備現況與可能追加的設備，可避免開業後的意外工程。

角色分工如下。

| 工作 | 承擔者 |
|---|---|
| 物件調查・仲介・租賃契約 | 宅地建物交易業者（本公司） |
| 用途變更確認申請的要否判斷、構造適合、無障礙・給排水設計 | 建築士・設計者 |
| 消防用設備設置的要否判斷・設置 | 消防署（預防課）・消防設備業者 |
| 指定申請等向官公署提出文件的製作 | 行政書士 |
| 依人員配置的常勤換算・就業規則・社會保險 | 社會保險勞務士 |
| 取得時的所有權移轉登記 | 司法書士 |
| 報酬計算・稅務 | 稅理士（請款經國民健康保險團體聯合會） |

## 簽約前應在物件上先釐清哪些項目？

將以上整理為簽約前的檢查清單。

| 確認點 | 觀察重點 |
|---|---|
| 用途地域 | 是否為工業專用地域；低層住專則向特定行政廳確認規模限制 |
| 用途變更 | 用途部分超過200㎡是否需確認申請（請教建築士） |
| 訓練・作業室 | 足以進行訓練內容的寬度與器具放置處；以實測確認有效面積 |
| 諮詢室 | 能否隔間・個室化以防止談話外洩 |
| 盥洗室・廁所 | 能否依利用者特性無障礙化 |
| 多目的室 | 與諮詢室兼用，或另行獨立取得 |
| 住宿型的情形 | 能否取得居室（每人7.43㎡以上）與浴室 |
| 消防 | 是否為(6)項ハ；樓地板面積300㎡以上需自動火災警報設備；向消防署確認追加設備的評估 |
| 出租人可否 | 對福祉事業的出租與內裝・設備工事可否、原狀回復的範圍 |

人員的常勤換算（機能訓練須將看護職員・理學療法士/作業療法士/言語聽覺士・生活支援員的總數定為利用者數÷6以上等〈第156條〉，生活訓練須將生活支援員定為通所÷6＋住宿÷10以上等〈第166條〉）屬勞務設計，而非物件本身。本公司將物件（不動產）與申報（行政手續）的論點並陳於同一張桌上確認。

## 該向誰諮詢？

物件的調查、仲介、買賣・租賃契約，由四葉不動產株式會社（宅地建物交易業 東京都知事(1)第113304號）承辦。指定申請等向官公署提出文件的製作，由四葉行政書士事務所承辦。用途變更確認申請的要否・構造適合・無障礙設計由建築士・設計者，消防用設備由消防署・設備業者，依人員配置的常勤換算・就業規則・社會保險由社會保險勞務士，取得時的登記由司法書士，報酬・稅務由稅理士處理。

**這些均為各自獨立的事業體，請分別直接簽約。** 本公司・本事務所不收取亦不支付介紹費・送客手續費。登記的司法書士、稅務的稅理士、勞務的社會保險勞務士，亦請各自直接委託。諮詢免費。

## 常見問題

**Q. 自立訓練的訓練室是由定員逆推面積嗎？**
A. 不是。通所介護以「3㎡×利用定員以上」綁定食堂兼機能訓練室，但自立訓練的訓練・作業室沒有數值面積基準。指定基準（平成18年厚生勞動省令第171號）只規定「不妨礙訓練或作業的寬度」。因此需由定員・訓練課程自行估算所需寬度，內見時確認有效面積（扣除柱・水路的實測）較安全。少見的數值基準，是住宿型自立訓練的居室每人7.43平方公尺以上（扣除收納設備等）。

**Q. 自立訓練的事業所在住宅區也能開嗎？**
A. 有開設餘地。自立訓練事業所屬建築基準法施行令第19條第1項的「兒童福祉設施等」（障害福祉服務事業中辦理自立訓練之事業所使用的設施），用途地域的限制準用兒童福祉設施等的處理。工業專用地域以外大致可建，第一種・第二種低層住居專用地域亦在規模限制下可行。惟用途判斷會因事業所規模・型態與特定行政廳運用而變動，可否的最終確認請於特定行政廳（建築指導課）進行。既有建物用途變更時，用途部分超過200平方公尺即需確認申請。

**Q. 消防法上自立訓練屬哪個區分？**
A. 消防法施行令別表第一(6)項ハ(5)明列障害者總合支援法第5條第12項的「自立訓練之施設」，故通所型事業所原則為(6)項ハ。自動火災警報設備，通所型（無入居・住宿）於樓地板面積300㎡以上需設置，住宿型（使利用者入居・住宿）則不論面積均需設置（施行令第21條第1項）。灑水設備・誘導燈等的要否依區分與規模而變，請向消防署（預防課）確認。主要收容避難困難障害者等的型態則區分為(6)項ロ。

**Q. 諮詢室與多目的室可以兼用嗎？**
A. 可以。指定基準規定，於不妨礙利用者支援時，可將諮詢室與多目的室兼用（生活訓練為第168條，機能訓練為準用的第81條）。惟諮詢室以設防止室內談話外洩的隔間等為前提，盥洗室・廁所須依利用者特性。以單一樓層節省區劃雖可行，但諮詢的祕密保持與無障礙宜於物件選擇階段先行確認。
