**結論（先說重點）**：能登錄為附服務高齡者住宅（Sakoju）的物件骨架有四項——各戶原則25㎡以上（共用部分充足則18㎡以上）、各戶或共用部分的廚房・廁所・洗面・浴室・收納、走廊寬度・高低差・扶手的無障礙、至少提供安否確認（狀況把握）與生活諮詢服務。這是高齡者住まい法的登錄基準，建物的設計・改修，加上契約與營運規則也一併被要求。既有建物也能符合，但由樓地板面積與共用設備的作法決定可否。

「能不能把空著的公寓做成Sakoju」的諮詢日益增加。但Sakoju並非可自由自稱的住宅，而是高齡者住まい法的登錄制度。本文寫給在東京考慮Sakoju的不動產所有者・事業者：登錄的物件・建物條件，依高齡者的居住安定確保相關法律的條文與國土交通省・厚生勞動省的案內順序整理。可否與數值的最終確認，在授予登錄的都道府縣・政令市等窗口。

## 能登錄為Sakoju的物件最低條件是？

Sakoju是依高齡者的居住安定確保相關法律（平成13年法律第26號）第5條登錄的高齡者向租賃住宅等。登錄主體為都道府縣知事（政令指定都市・中核市則為其首長），登錄有有效期間，每5年更新（**2026年8月25日參照**）。

登錄基準的骨架，大致分為「住宅本身」「提供的服務」「契約」三塊。

| 區分 | 登錄基準骨架 |
|---|---|
| 規模 | 各戶樓地板面積原則25㎡以上（居間・食堂・廚房等共用部分具充足面積時18㎡以上） |
| 設備 | 各戶備廚房・水洗廁所・收納・洗面・浴室（於共用部分適當備置共同利用者，部分可不設於各戶；但廁所・洗面以各戶為基本） |
| 構造 | 無障礙構造（確保走廊寬度、消除高低差、設置扶手） |
| 服務 | 至少提供狀況把握（安否確認）與生活諮詢服務，並有照護專業人員參與 |
| 契約 | 明示居住部分的書面契約。不收取租金・押金・服務對價以外的金錢。預付款有返還規則與保全措施。未經住戶同意不變更居住部分・不解除契約 |

**要注意，樓地板面積與設備的數值是住宅基準，須與服務・契約規則一起構成「登錄基準」。** 只把建物整好，若服務體制或契約書不達基準，也不會被登錄。作為物件的問題，先發生作用的是樓地板面積、無障礙，以及共用設備如何作。

## 各戶25㎡・共用設備・無障礙，既有建物能符合嗎？

有能符合的情形，但越是既有建物，越由**樓地板面積與共用部分的作法**分出可否。

第一是樓地板面積。原則各戶25㎡以上，即使達不到的狹小住戶，只要**居間・食堂・廚房等共用部分具充足面積，可緩和至18㎡以上。** 也就是「加大各戶」或「加厚共用部分」的設計判斷。轉用既有單間公寓時，這共用部分設在何處是最初的關卡。

第二是設備。各戶備廚房・廁所・洗面・收納・浴室為基本，但**於共用部分作為共同利用的設備適當備置，部分可不設於各戶**（廚房・浴室・收納）。惟水洗廁所與洗面設備以各戶為基本。如何運用此緩和，會大幅改變改修規模。

第三是無障礙。須符合走廊寬度、消除高低差、扶手設置等構造基準。**既有建物中，走廊寬度與有無樓梯・電梯，是改修能否符合的分界。**

| 簽約前確認 | 為何有效 |
|---|---|
| 各戶樓地板面積與格局 | 能否符合25㎡（緩和18㎡）；可能須合併住戶 |
| 共用部分可取得的面積 | 左右樓地板面積・共用設備緩和的可否 |
| 走廊寬度・高低差・電梯 | 左右無障礙改修的規模 |
| 給排水・電力容量 | 影響共用廚房・浴室、狀況把握機器的導入 |
| 用途・構造 | 牽涉用途變更確認申請與耐震的要否 |

樓地板面積、無障礙符合、用途變更確認申請的要否，屬建築確認・設計的領域。**本公司（不動產公司）協助調查物件能否符合Sakoju登錄基準，並在取得・租賃的條件交涉上伴走。** 設計判斷與符合可否本身由建築士處理。照護事業所物件的卡關方式整理於[「照護事業所物件找不到的真正理由」](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)，租賃契約書該讀哪裡整理於[「租賃契約書該讀哪裡」](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 登錄申請・建築確認・照護服務指定由誰承擔？

Sakoju牽涉多位專家。角色分開。

| 要做的事 | 承擔者 |
|---|---|
| 物件調查・取得、仲介與契約 | 宅地建物取引業者（本公司） |
| Sakoju登錄申請文件的製作 | 行政書士 |
| 無障礙符合・用途變更等設計、建築確認 | 建築士 |
| 照護保險服務（特定設施入居者生活照護等）的指定申請 | 另行手續（向指定權者申請） |

Sakoju是「住宅」的登錄，其中是否提供照護服務是另一制度。**若向住戶提供照護保險服務，視情形須另行指定或申報。** 混淆住宅登錄與照護服務指定，會看錯開設的步調。

Sakoju登錄申請等向官公署提出的文件之製作，由四葉行政書士事務所承接。**登錄主體・樣式・登錄基準的運用（各自治體以高齡者居住安定確保計畫上乘的基準等）會變。著手時請直接確認授予登錄的自治體頁面。** 事業用物件全般見[投資用・事業用不動產](https://luck428.com/toushi)，事務所與許認可的關係見[公司設立與辦公室選擇](https://luck428.com/office)。用途地域與容積率如何影響地價整理於[「日本地價為何隨『容積率』而變」](https://luck428.com/column/yosekiritsu-hosei-tochine)。

## 費用與期間的目安大概多少？

費用與期間，隨物件狀態（新建或既有改修）與自治體運用而大幅變動。**沒有全國一致的定價。** 這裡不斷定金額，作為「項目」整理花錢與花時間之處。

| 項目 | 目安的考量 | 承擔者 |
|---|---|---|
| 建築・改修費 | 隨樓地板面積・無障礙・共用設備的作法大幅變動；最大變動要因 | 建築士・施工業者 |
| 設計・確認申請 | 若需用途變更確認申請則期間延長 | 建築士 |
| 登錄申請 | 依自治體樣式製作文件；手續費依自治體 | 行政書士 |
| 登錄有效期間 | 5年（須更新） | — |
| 狀況把握・生活諮詢體制 | 人員配置・機器導入的營運成本 | 事業者 |

**期間隨既有建物的改修規模與用途變更要否，以數月為單位變動。** 具體金額・期間・自治體獨自基準，本文無法確定，**作為未檢證處理，請向登錄主體與建築士個別確認。** 與其硬放數字目安，不如掌握變動要因來規劃更為安全。

## 常見問題

**Q. 各戶18㎡也能登錄為Sakoju嗎？**
A. 有能登錄的情形。各戶樓地板面積原則25㎡以上，但若有供高齡者共同利用的充足面積之居間・食堂・廚房等設備，可緩和至18㎡以上（高齡者的居住安定確保相關法律的登錄基準）。共用部分面積的取法會改變可否，請在設計階段向建築士與登錄主體確認。

**Q. 能把既有公寓轉用為Sakoju嗎？**
A. 若能符合樓地板面積・無障礙・共用設備基準即可。惟走廊寬度、高低差、共用部分面積、給排水達不到基準時，須改修或用途變更確認申請。既有建物中，先確認各戶樓地板面積與共用部分可取得的面積是出發點。

**Q. 是Sakoju就當然能提供照護服務嗎？**
A. 不是。Sakoju是「住宅」的登錄，提供狀況把握（安否確認）與生活諮詢是登錄的基準。要向住戶提供照護保險服務，須視情形另行指定或申報。住宅登錄與照護服務指定是不同制度，請分開安排步調。

**Q. Sakoju登錄申請可以委託不動產公司嗎？**
A. 不行。向官公署提出的登錄申請文件之製作屬行政書士業務，由四葉行政書士事務所承接。物件的調查・仲介・契約由四葉不動產株式會社承接。無障礙符合與用途變更的設計・建築確認由建築士承擔。皆為各自獨立的事業體，請各自直接簽約。
