**先講重點**：複合咖啡（網咖、漫畫喫茶）的物件，重點在於用途地域是否允許店舗用途，以及個室區劃能否作為消防法施行令別表第一(2)項ニ的設施，裝設自動火災報知設備等。在東京，須於開業的10天前向公安委員會提出網路端末利用營業的申報。物件的適配在不動產面處理，申報文件的製作則分開交給行政書士。

想新開設網咖、漫畫喫茶（複合咖啡）時，常會猶豫「這個物件做得出個室嗎」「消防會要求到什麼程度」「東京的申報何時、由誰提出」。想把空店面、空樓層租給複合咖啡用途的屋主，也會想知道什麼樣的物件才招得到租客。

複合咖啡的物件，會同時牽涉建築面（用途地域、樓地板面積）、消防面（個室區劃的防火與避難），以及許可面（東京的網路端末利用營業申報）。若先簽了物件才發現「個室的消防設備不足」「用途不符」，開業準備就會停擺。先把不動產面與許可面分開確認才穩當。

四葉不動產株式會社以東京都文京區小日向為據點，承接事業用物件的調查與租賃仲介。關於複合咖啡的物件，可從簽約前能確認的事項開始諮詢。

## 網咖的物件在用途地域與樓地板面積上受到多少限制？

網咖、漫畫喫茶在建築基準法的用途上，一般比照「店舗（經營服務業的店舗）」來看。不過，在個室中讓顧客使用遊興設備的形態，有時會被認為接近「遊技場」或「興行場」，究竟屬於哪種用途，取決於建物的構造與特定行政廳的判斷。不要先認定「這個地域一定能開」，而要逐件確認用途地域與用途分類。

| 要確認的事 | 物件面要看的點 |
| --- | --- |
| 用途地域 | 是否為可興建店舗、遊技場類用途的地域；第一種低層住居專用地域等住居專用系限制較強 |
| 既有用途 | 從原用途（辦公、零售等）變更是否需要用途變更的確認申請（變更為200㎡以上的特殊建築物等會分出要否） |
| 樓地板面積 | 個室的數量與走道、櫃台、調理空間是否容納得下 |
| 樓層與位置 | 地下層、無窗層、上層會讓避難與消防條件變重 |

是否需要用途變更的確認申請，取決於建築基準法第87條與特殊建築物用途變更的相關規定（如超過200㎡的情形）。用途地域的判斷與可否興建是建築士、特定行政廳的領域。本公司透過租賃仲介與重要事項說明，於簽約前整理物件的用途地域、既有用途與面積。

若複合咖啡併設餐飲，餐飲店的排氣與區劃也會成為論點。深夜營業店舗的物件選擇被決定到什麼程度，可參考[在毛胚（skeleton）物件開餐飲店時排氣與防火的思考（日文）](https://luck428.com/column/inshokuten-skeleton-bukken-haiki-grease)。

## 個室、隔間區劃在消防法令上要符合哪些防火與避難條件？

複合咖啡的關鍵在於個室、隔間區劃。消防法施行令別表第一(2)項ニ規定「在個室（含類似設施）中，讓顧客使用卡拉OK包廂或其他遊興用設備或物品，提供此役務的營業店舗」，網咖、漫畫喫茶依施行規則被歸入此一對象。因為是讓顧客滯留於個室的形態，火災時避難延誤被看得較重。

| 要確認的事 | 內容 |
| --- | --- |
| 自動火災報知設備 | (2)項ニ不論總樓地板面積均須設置（平成20年10月1日施行的修正已撤除面積要件） |
| 誘導燈、避難路徑 | 個室的配置能否確保避難走道寬度與到出口的距離 |
| 內裝限制 | 個室的牆壁、天花板的裝修是否符合內裝限制 |
| 防火對象物使用開始申報 | 使用開始前，依各自治體的火災預防條例向消防署申報（東京為使用開始的7天前） |

(2)項ニ的設施，即使規模小也須裝設自動火災報知設備，這點與一般零售店、辦公室大不相同。若在既有建物後加個室，能否事後補上報知設備、誘導燈與區劃，就成為物件選擇的分水嶺。消防用設備的設計、設置與向消防署申報是消防設備士、特定行政廳的領域。本公司於簽約前確認物件現況（既設報知設備、樓層、是否無窗層）。

同樣牽涉個室、隔音、消防的業態，[卡拉OK包廂物件在用途地域、消防、隔音上的確認點（日文）](https://luck428.com/column/karaoke-box-tenpo-bukken-youto-shoubou-soon)的整理，對思考個室區劃也有參考價值。

## 東京的網路端末利用營業（身分確認條例）申報由誰、何時提出？

在東京，「網路端末利用營業的規制相關條例」（平成22年7月1日施行）規制設置個室等、讓顧客以通信端末機器使用網路的營業。只要設有一部分個室的複合咖啡，即屬於此「網路端末利用營業」。

| 項目 | 內容 |
| --- | --- |
| 申報時期 | 於開業的10天前逐店申報（條例第3條） |
| 申報對象 | 經由管轄店舗所在地的警察署（生活安全課），向東京都公安委員會 |
| 身分確認 | 要求顧客出示身分確認文件、確認本人特定事項的義務（條例第4條） |
| 紀錄保存 | 本人確認紀錄、通信端末機器特定紀錄的製作與保存義務（自最後一次提供役務之日起3年） |
| 變更申報 | 申報事項有變更時，自變更日起10天內 |

身分確認與紀錄保存，是為防止匿名利用犯罪的條例核心義務。申報書（別記樣式第1號）要記載營業時間，以及本人確認紀錄、通信端末機器特定紀錄的製作與保存方法，個人營業附住民票謄本，法人營業附章程與登記事項證明書等。

這些申報文件的製作、附件的整備支援是行政書士的業務。本公司（宅地建物取引業）不代理申報。在不動產面，整理物件是否為可設置條例所稱「個室等」的構造，以及申報所需平面圖的物件資訊基礎。另外，東京以外之地，條例有無與內容各異，請向開業地的公安委員會、警察署直接確認。

## 深夜營業或個室規格是否觸及風營法、特定遊興的界線在哪？

複合咖啡常營業到深夜，因此有人擔心「是不是需要風營法的許可」。一般的網咖、漫畫喫茶，通常不屬於一面讓顧客飲食、一面提供遊興的「特定遊興飲食店營業」，也不屬於伴隨接待的「風俗營業」，多半以網路端末利用營業的申報即足。

不過，界線會隨個室中提供什麼而變。例如在個室提供性服務，就會產生店舗型性風俗特殊營業的問題；提供酒類並於深夜讓人遊興，就會出現特定遊興飲食店營業（風營法）的許可論點。究竟屬於哪種營業類型，最終的法律判斷是律師與警察（公安委員會）的領域。本公司與行政書士都無法確定營業類型。

物件面能做的，是先把設想的營業形態（有無深夜營業、是否提供餐飲與酒類、個室規格）固定下來，再確認其是否與建物用途、消防、條例相容。牽涉遊技業態的物件要件，[遊戲中心（風營法5號）物件在用途與面積上的確認點（日文）](https://luck428.com/column/game-center-fuei-5go-bukken-youto-menseki)的整理，對思考區劃與許可的關係也有參考價值。

## 從看屋到簽約、申報，物件面最常卡在哪？（分離受任）

複合咖啡的開業，物件、建築、消防、條例申報分屬不同事業體。順序一旦弄錯，就會發生簽了的物件裝不下個室消防設備、用途變更過不了等情形。

| 角色 | 由誰負責 |
| --- | --- |
| 物件調查、租賃仲介、重要事項說明 | 宅地建物取引業（本公司） |
| 用途地域、用途變更的確認申請、內裝設計 | 建築士、特定行政廳 |
| 消防用設備的設計、設置與向消防署申報 | 消防設備士、特定行政廳 |
| 網路端末利用營業申報文件的製作 | 行政書士 |
| 營業類型（風營法該當性）的法律判斷、紛爭 | 律師 |

實務上，較清楚的順序是：先在不動產面確認用途地域與既有用途（用途變更的要否），再在消防面看能否為個室區劃裝入自動火災報知設備與避難路徑，然後才進入條例的申報。

這些是**各自獨立的事業體**，以**分別簽約**為前提。本公司負責物件的不動產面，用途變更與消防設備設計交給建築士、消防設備士，條例申報文件交給行政書士，營業類型的判斷交給律師。本公司不收取介紹費。

## 常見問題

**Q. 辦公用的空樓層可以直接改成網咖嗎？**
A. 先確認是否需要用途變更的確認申請（如變更為200㎡以上的特殊建築物），以及能否為個室區劃裝入自動火災報知設備與避難路徑。辦公維持原樣往往不符合消防或避難條件，內裝與設備的整備是前提。用途變更的可否是建築士、特定行政廳的領域，消防設備是消防設備士的領域。

**Q. 東京的網路端末利用營業申報，何時、由誰提出？**
A. 在東京，須於開業的10天前逐店，經由管轄所在地的警察署（生活安全課），向東京都公安委員會申報（條例第3條）。申報文件的製作支援是行政書士的業務，本公司不代理。在不動產面，整理物件是否為可設置條例所稱「個室等」的構造。

**Q. 有個室，就一定要裝自動火災報知設備嗎？**
A. 屬於消防法施行令別表第一(2)項ニ的店舗（卡拉OK包廂、網咖等個室型），不論總樓地板面積均須裝設自動火災報知設備（平成20年10月1日施行的修正已撤除面積要件）。若在既有建物後加個室，能否裝設設備就成為分水嶺。設計與設置是消防設備士的領域。

**Q. 營業到深夜就需要風營法的許可嗎？**
A. 一般的網咖、漫畫喫茶通常不屬於特定遊興飲食店營業或風俗營業，多半以網路端末利用營業的申報即足。但若提供酒類並於深夜讓人遊興、或在個室提供性服務等，就會出現其他規制的論點。營業類型的最終判斷是律師與公安委員會的領域。
