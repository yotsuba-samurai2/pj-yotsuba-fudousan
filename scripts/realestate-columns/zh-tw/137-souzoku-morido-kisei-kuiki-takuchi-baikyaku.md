**先講重點**：繼承的土地即使落在「盛土規制區域」，土地本身仍可出售。盛土規制法所許可規制的，是區域內一定規模以上的填土・切土等「工程」，而非移轉所有權（買賣）。影響價格與好不好賣的，是買方要在該地施工或改建時是否需要許可、既有的填土・擋土牆是否安全。區域該當的調查與重要事項說明・仲介由本公司負責，許可・申報的申請代行交給行政書士、擋土牆・填土的安全性評估與設計交給建築士・土木專家、讓渡所得與相續稅交給稅理士、繼承登記交給司法書士、界線與契約的紛爭交給律師。各為獨立事業體，分別簽約。

寫給繼承了傾斜地或造成地、正考慮出售的繼承人，依「宅地造成及特定盛土等規制法（盛土規制法）」與宅地建物取引業法的順序，整理「落在盛土規制區域就賣不掉嗎」「該從何查起」。本文為一般性資訊提供，既有填土・擋土牆是否安全的判斷、以及許可要否的最終判斷，屬建築士・土木專家與所管都道府縣等的領域。

四葉不動產株式會社以東京都文京區小日向為據點，承接繼承不動產的估價與出售仲介。關於可能落在盛土規制區域的土地，歡迎從賣出前可以確認的事項開始與我們洽談。

## 盛土規制法是什麼，從何時起什麼改變了？

盛土規制法（宅地造成及特定盛土等規制法）由令和4年法律第55號將既往的宅地造成等規制法大幅修改，於令和5年5月26日施行。宗旨是不問土地的用途或目的，以全國一律的基準規制危險的填土等。因此，不只是宅地造成，連對農地或森林的填土、土石的堆積也納入規制。

規制區域有兩種。

| 區域 | 什麼樣的土地 | 工程的許可 |
| --- | --- | --- |
| 宅地造成等工事規制區域 | 市街地或聚落等，一旦填土會對人家等造成危害的區域 | 一定規模以上的工程須都道府縣知事等的許可（法第12條第1項） |
| 特定盛土等規制區域 | 即使遠離市街地等，因地形等條件填土崩塌會對人家等造成危害的區域 | 一定規模以上的工程須都道府縣知事等的許可（法第30條第1項） |

此外，另有將已造成且災害之虞較大的宅地指定為「造成宅地防災區域」的機制（法第45條）。無論何者，指定區域者皆為都道府縣知事等，指定的進度因地而異。重要的是，這些規制是加諸於「工程」，並非禁止土地的買賣本身。

## 自己繼承的土地是否在規制區域，該怎麼查？

是否落在區域內，先在指定區域的都道府縣（或指定都市・中核市等）的公開資訊確認。許多自治體在告示區域指定的同時，也讓人能在網路地圖或窗口閱覽。

| 查法 | 內容 |
| --- | --- |
| 自治體的公開地圖・窗口 | 於都道府縣等的盛土規制法主管課（砂防・宅地防災・開發指導等）確認區域 |
| 告示有無 | 區域指定以告示生效；確認指定日與範圍 |
| 造成宅地防災區域 | 確認是否另行指定（對象為既有造成地） |
| 現地狀況 | 於現地確認過去的填土・切土、擋土牆、崖、湧水等有無 |

區域指定由各都道府縣等逐步進行，即使同一市內，指定有無也會分歧。本公司對受理出售諮詢的土地，會從所在地自治體的公開資訊調查區域該當的見込，接續到朝向重要事項說明的調查。區域的最終該當判斷由所管自治體進行（依2026年10月23日時點的公開資訊確認）。

## 有既有填土・擋土牆的土地賣得掉嗎？由誰判斷安全性？

有既有填土或擋土牆的土地，出售本身仍可。但買方若在該地新做改建或造成，區域內一定規模以上的工程須許可，且既有擋土牆是否符合現行基準成為課題。老舊擋土牆（二段擋土牆、間知塊老化、結構不明等）直接牽動買方的資金計畫與拆除・重做的費用。

| 確認的軸 | 由誰判斷 |
| --- | --- |
| 既有擋土牆的結構・劣化・合法性 | 建築士・土木專家（調查・評估・設計） |
| 區域內工程是否需許可 | 所管都道府縣等（許可審查） |
| 對土地價格的影響 | 宅地建物取引業（本公司。估價・仲介） |

本公司無法斷言「這道擋土牆安全」。安全性的評估與重做的設計屬建築士・土木專家的領域，本公司整理現況（擋土牆有無、過去造成、是否崖地），反映於出售步驟。出售有崖或擋土牆的土地的思路，[出售有崖・擋土牆的土地前要確認的事項（日文）](https://luck428.com/zh-tw/column/gake-yoheki-tochi-baikyaku-bunkyo)、以及牽涉土壤調查的土地出售，[工廠・倉庫跡地等疑有土壤汙染的土地出售（日文）](https://luck428.com/zh-tw/column/souzoku-koujou-souko-dojou-osen-baikyaku)也可參考。

## 重要事項說明中，盛土規制法如何說明？

宅地建物取引業者仲介買賣時，依宅地建物取引業法第35條的重要事項說明，向買方說明法令上的限制。土地是否落在盛土規制法的宅地造成等工事規制區域・特定盛土等規制區域・造成宅地防災區域，作為同法施行令第3條所定的「法令上的限制」成為說明對象。

| 說明的內容 | 重點 |
| --- | --- |
| 區域該當 | 是否落入工事規制區域・特定盛土等規制區域・造成宅地防災區域之一 |
| 區域內的限制 | 一定規模以上的工程須許可之旨（影響買方的改建・造成） |
| 既有填土・擋土牆 | 就現況可掌握的範圍說明；安全性的判斷屬專家領域 |

即使落在區域內，只要正確調查並說明其事實，買賣仍可成立。反之，怠於說明，恐於日後被追究契約不符或說明義務違反。本公司將區域該當的調查結果正確反映於重要事項說明，連同買方改建・造成可能需許可一併說明。許可實際能否取得、哪些工程為許可對象等個別判斷，屬所管自治體與承辦申請的行政書士的領域。

## 許可申請・稅務・登記該找誰？（分離受任）

出售盛土規制區域的繼承土地，橫跨不動產・許認可・建築・稅務・登記・紛爭等不同事業體。順序取錯，可能跳過安全性評估就掛牌、或在繼承登記未竟時就找買方。

| 角色 | 由誰負責 |
| --- | --- |
| 區域該當的調查、估價、重要事項說明、出售仲介・交割 | 宅地建物取引業（本公司） |
| 盛土規制法的許可・申報的申請代行 | 行政書士 |
| 既有擋土牆・填土的安全性評估、重做的設計 | 建築士・土木專家 |
| 繼承登記、建物表題變更等登記 | 司法書士 |
| 讓渡所得稅・相續稅的計算與申報 | 稅理士 |
| 界線或契約的紛爭、繼承人間的爭執 | 律師 |

盛土規制法許可・申報的申請文件製作是行政書士的業務，本公司不代辦。既有擋土牆或填土是否安全的判斷・設計，由建築士・土木專家負責。

## 常見問題

**Q. 繼承的土地落在盛土規制區域，就不能賣了嗎？**
A. 可以賣。盛土規制法所許可規制的是區域內一定規模以上的填土・切土等工程，而非土地的買賣本身（法第12條第1項・第30條第1項）。影響價格與好不好賣的，是買方改建・造成是否需許可、既有擋土牆是否安全。區域該當由本公司調查，並反映於重要事項說明。

**Q. 是否為盛土規制區域，可以在哪裡查？**
A. 指定區域者為都道府縣知事等，一般會連同告示在網路地圖或窗口閱覽。可於盛土規制法主管課（砂防・宅地防災・開發指導等）確認。本公司對受理出售諮詢的土地，也會從所在地自治體的公開資訊調查區域該當的見込。最終的該當判斷由所管自治體進行。

**Q. 土地上有老舊擋土牆。是否安全，不動產公司能判斷嗎？**
A. 不行。擋土牆或填土是否安全的判斷、是否符合現行基準、重做的設計，屬建築士・土木專家的領域。本公司整理現況（擋土牆有無・過去造成・是否崖地）並反映於出售，安全性評估轉介專家。買方施工時許可的要否，屬所管自治體與行政書士的領域。

**Q. 盛土規制區域的土地，在重要事項說明中如何處理？**
A. 土地是否落在盛土規制法區域，作為宅地建物取引業法第35條・同法施行令第3條的「法令上的限制」成為重要事項說明對象。即使落在區域內，只要正確調查並說明仍可成立買賣。因怠於說明恐於日後被追究責任，本公司會將區域該當的調查結果正確反映並說明。
