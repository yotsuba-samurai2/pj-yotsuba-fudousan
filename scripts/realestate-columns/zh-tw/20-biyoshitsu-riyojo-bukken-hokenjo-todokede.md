**結論（先說重點）**：美容室・理容所的物件，保健所看的是兩點——能否明確區分作業場與待合區，以及洗場・消毒・採光照明換氣是否達到基準。此外，與餐飲店、診所不同，美容院・理髮店受建築基準法的用途地域限制。開設申報要「事先」提出，並須通過構造設備的檢查・確認後才能使用。簽約前確認用途地域與區劃，就能避免返工。

被告知「只剩裝潢」而承租，到了開設申報階段，卻被保健所要求重做區劃。餐飲店、照護事業所會發生的返工，美容室・理容所同樣會發生。本文寫給在東京要開美容所・理容所的美容師・理容師，以及把物件租給他們的人：簽租約前能確認的事，依美容師法・理容師法的條文與厚生勞動省的要領順序整理。可否的最終確認在特定行政廳與保健所窗口。

## 美容室・理容所的物件，保健所在看什麼？

保健所看的是「構造設備」。美容師法（昭和32年法律第163號）第12條規定：「美容所的開設者，須就其美容所的構造設備接受都道府縣知事的檢查，並在取得該構造設備適於採行第13條措施之確認後，方得使用該美容所。」理容所也一樣，理容師法（昭和22年法律第234號）第11條之2將構造設備的檢查・確認，定為使用的前提。

也就是說，**裝潢完成後保健所來查，若區劃或設備不足基準，就無法照原樣營業。** 這是選物件的起點。

那要滿足什麼？厚生勞動省的「理容所及美容所之衛生管理要領」（昭和56年6月1日環指第95號）示出了構造設備的思路（**2026年8月24日參照**）。

| 項目 | 要領示出的思路 |
|---|---|
| 區劃 | 作業場與待合所須**明確區分**；作業場以間隔與居住室・休憩室等區分 |
| 照明 | 作業中作業面的照度**300勒克斯以上為佳**（下限依各都道府縣條例） |
| 換氣 | 作業場內二氧化碳濃度5,000ppm以下（1,000ppm以下為佳） |
| 洗場 | 採流水裝置，並設給湯設備 |
| 消毒 | 備有消毒器具・布片・毛巾等的設備或器材 |
| 收納 | 接觸皮膚的器具能以消毒完成與未消毒區別收納 |

**要注意，具體數值（作業室的樓地板面積、洗場或洗髮設備的數量等）由各都道府縣以條例定之。** 美容師法第13條・理容師法第12條列出「保持清潔」「消毒設備」「充分採光・照明・換氣」等衛生措施，並進一步要求「其他都道府縣以條例所定的衛生上必要措施」。**數值因自治體而異。著手時請向管轄的保健所確認。**

## 作業場的面積或洗髮台的數量，有全國一致的規定嗎？

**沒有全國一致的數值。** 面積、洗髮設備數量、洗場位置等具體基準，如上所述由各都道府縣（設置保健所的市・特別區則為該市・區）以條例定之。所以「隔壁縣以這個大小過關」未必能直接套用。

在物件端可先確認的，與其說是條例數值本身，不如說是**能否滿足該數值的基礎條件**。

| 簽約前確認 | 為何有效 |
|---|---|
| 能隔出作業場與待合的格局 | 區劃是要領・條例的核心之一；單間房可能無法另闢待合 |
| 給排水的位置與口徑 | 洗場需流水・給湯；洗髮台愈多，給排水增設費愈動 |
| 換氣設備的有無・增設餘地 | 二氧化碳濃度基準以換氣擔保 |
| 電氣容量 | 洗髮給湯・吹風機・空調耗容量；增設影響費用與工期 |
| 地板・牆壁的防水與清潔性 | 「常保清潔」的基礎；也牽涉回復原狀範圍 |

給排水・換氣・電氣容量的設計是施工業者（設計者）的領域。**本公司（不動產公司）伴走的是物件能否滿足這些條件的前置調查，以及與出租人的條件交涉。** 不做設備設計本身。餐飲店物件會發生相同返工的原因，整理在[〈照護事業所的物件為何找不到〉](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)；租約要讀哪裡，整理在[〈租賃契約書，該讀哪裡〉](https://luck428.com/column/chintaishaku-keiyakusho-doko-wo-yomu)。

## 居抜（帶裝潢）與毛胚，要確認的設備差別是什麼？

差很多。前承租人若是美容室・理容所的居抜物件，洗場・給排水・換氣可能留著。但——**「以前也是美容室，所以沒問題」不是保證。**

兩個理由。第一，構造設備的檢查・確認是每家美容所・理容所各自重新接受（美容師法第12條／理容師法第11條之2），前一家的確認不會承接給新的開設者。第二，條例與運用可能已修正，前一家開設時的基準與現在要求的基準可能不同。

| | 居抜（前為美容室・理容所） | 毛胚 |
|---|---|---|
| 洗場・給排水 | 多半留著（需點檢） | 新設；位置與口徑從設計起 |
| 換氣設備 | 可能沿用 | 新設 |
| 區劃（作業場・待合） | 可能沿用舊格局 | 從頭設計 |
| 檢查・確認 | **重新接受** | 重新接受 |
| 初期費用傾向 | 較易壓低 | 較易增加 |

即使是居抜，**交屋前點檢設備狀態、確認是否符合保健所基準**較安全。殘置設備的所有・修繕・撤除負擔如何在契約中約定，是居抜特有的議題。

## 用途地域或建築確認會成為問題，是在什麼時候？

這是與診所最大的不同。診所在建築基準法的用途限制下所有用途地域都能建，但**美容院・理髮店被當作「店舖（服務業店舖）」，受用途地域限制。**

建築基準法（昭和25年法律第201號）施行令（昭和25年政令第338號）第130條之3第3號，把「理髮店、美容院……及其他類似的服務業店舖」列為第一種低層住居專用地域可建的兼用住宅之一。但有條件：**須以樓地板延面積的2分之1以上供居住，且店舖部分的樓地板面積合計在50㎡以下。** 也就是說，在第一種低層住居專用地域不能作為單獨店舖，只限自宅兼用且小規模者。

在第二種低層住居專用地域，依建築基準法別表第二(ろ)項第二號與施行令第130條之5之2，政令所定的店舖（含理髮店・美容院），**樓地板面積合計150㎡以內、且不以3樓以上供該用途者**可建。第一種中高層住居專用地域以上，面積限制放寬。

| 用途地域 | 美容院・理髮店的處理 |
|---|---|
| 第一種低層住居專用地域 | 僅限兼用住宅（居住占延面積1/2以上・店舖部分50㎡以下） |
| 第二種低層住居專用地域 | 政令所定店舖，150㎡以內、不供3樓以上 |
| 第一種・第二種中高層住居專用地域 | 面積限制放寬，較易建 |
| 住居・準住居・近鄰商業・商業・準工業地域 | 可建 |

而且，**把事務所或別業種的店舖改為美容室時，依樓地板面積可能需要用途變更的確認申請。** 建築基準法第87條第1項，在用途變更為同法第6條第1項第1號的特殊建築物（別表第一(い)欄用途且200㎡超）時準用確認申請；美容院通常不屬於該別表第一(い)欄的特殊建築物。不過，與確認申請要否無關，用途地域限制（第48條）與採光・換氣等實體規定仍會適用。**用途地域上的可否與用途變更的要否，簽約前可向特定行政廳確認。** 用途地域與容積率如何牽動土地價格，整理在[〈日本的土地價格為何會因「容積率」而改變〉](https://luck428.com/column/yosekiritsu-hosei-tochine)；消防・自治體確認須先於契約的例子，整理在[〈能開民宿的物件條件〉](https://luck428.com/column/minpaku-bukken-joken-kakunin)。

## 開設申報由誰、何時提出？與物件契約的時程如何安排？

美容師法第11條規定，「欲開設美容所者……須將美容所的位置、構造設備……及其他必要事項，**事先**向都道府縣知事申報」。理容師法第11條亦同。**「事先」＝開設前**，與餐飲店的營業許可、診所的開設申報（開設後10日內）順序不同。

再者，須通過構造設備的檢查・確認（美容師法第12條／理容師法第11條之2）後才能使用。因此流程如下。

| 順序 | 要做的事 | 擔當者 |
|---|---|---|
| 1 | 確認用途地域・用途變更要否 | 特定行政廳・宅地建物取引業者 |
| 2 | 前置調查能否滿足區劃・給排水・換氣・電氣容量 | 宅地建物取引業者・施工業者 |
| 3 | 租賃契約 | 宅地建物取引業者 |
| 4 | 裝潢工程（區劃・洗場・消毒設備・照明・換氣） | 施工業者 |
| 5 | 「事先」提出開設申報 | 開設者（美容師・理容師） |
| 6 | 保健所的進場檢查（構造設備）・確認 | 保健所 |
| 7 | 確認後開始使用（營業） | 開設者 |

**物件的契約是手續的前提。** 從業者2人以上的美容所須置管理美容師（美容師法第12條之3），理容所須置管理理容師（理容師法第11條之4）；這是人的要件，與物件分開準備。開設申報等向保健所提出的文件之製作，由四葉行政書士事務所承接。**行政的窗口・樣式・條例數值・受理運用會變。著手時請直接查閱管轄保健所的頁面。** 事業用物件整體在[投資用・事業用不動產](https://luck428.com/toushi)，事務所與許認可的關係在[公司設立與辦公室選擇](https://luck428.com/office)。

## 該找誰諮詢？

物件的調查、仲介、買賣・租賃契約，由四葉不動產株式會社（宅地建物取引業 東京都知事(1)第113304號）承接。美容所・理容所的開設申報等向官公署提出的文件之製作，由四葉行政書士事務所承接。牽涉用途變更・建築確認時的設計由建築士處理，裝潢的給排水・換氣設計由施工業者處理。

**這兩者（不動產公司・行政書士事務所）是各自獨立的事業體。請各自直接簽約。** 本公司・本事務所既不收取也不支付介紹費・轉介費。登記請找司法書士、稅務請找稅理士、勞務請找社會保險勞務士（2026年9月開業預定），各自直接委託。諮詢免費。

## 常見問題

**Q. 能在住宅區（第一種低層住居專用地域）開美容室嗎？**
A. 原則上不能作為單獨店舖開。依施行令第130條之3第3號，理髮店・美容院只能作為「兼用住宅」建築，條件是居住占延面積2分之1以上、店舖部分樓地板面積合計50㎡以下。可否因物件而異，請向特定行政廳窗口確認。

**Q. 前身也是美容室的居抜物件，開設申報就會直接通過嗎？**
A. 未必。構造設備的檢查・確認是每位開設者各自重新接受（美容師法第12條・理容師法第11條之2），前一家的確認不會承接。條例或運用也可能已修正。請於交屋前點檢殘置設備的狀態與是否符合現行基準，並向保健所確認。

**Q. 作業場的大小或洗髮台的數量，法律上有數值嗎？**
A. 沒有全國一致的數值。美容師法第13條・理容師法第12條要求「其他都道府縣以條例所定的衛生上必要措施」，面積・設備的具體數值由各都道府縣（設置保健所的市・特別區則為該市・區）以條例定之。請向管轄的保健所確認。

**Q. 開設申報何時提出？在物件契約之前嗎？**
A. 美容師法第11條・理容師法第11條規定「事先」（開設前）申報。且須通過構造設備的檢查・確認後才能使用。因此順序是：物件契約→裝潢工程→開設申報→保健所檢查・確認→開始營業。物件的契約是手續的前提。
