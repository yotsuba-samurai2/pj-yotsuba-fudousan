**結論（先講重點）**：定員20名以上的認可保育所物件，與小規模保育決定性不同的是三點：屋外遊戲場（園庭，可用附近公園等代替）、含乳兒室・爬行室的居室面積、以及把保育室設在2樓以上時的兩方向避難與耐火。保育所在用途地域上不會卡（建築基準法別表第二在第一種低層住居專用地域也能興建，工業專用地域也不在限制之列）。卡的是面積・避難・用途變更的確認申請・消防。本公司負責到物件的用途・面積・避難・消防現況的資訊提供為止，認可申請與設備運營基準的適合審查交給行政書士與市區町村、確認申請與採光避難的計算交給建築士、人員・勞務交給社會保險勞務士，分別簽約推進。

本文面向在文京區及周邊尋找定員20名以上認可保育所本體施設的社會福祉法人・學校法人・股份公司的開設承辦人與其不動產承辦人，依兒童福祉設施設備運營基準（昭和23年厚生省令第63號）・建築基準法・消防法施行令，整理「與小規模保育的物件尋找哪裡相同、哪裡改變」。本公司負責物件的用途・構造・面積・消防現況的資訊提供，不進行認可的可否或採光・避難的計算、人員配置・勞務的設計。相關領域各自交給專業人士，分別簽約推進。

## 認可保育所與小規模保育，對物件要求的面積・設備有何不同？

依據的省令不同。認可保育所（定員20名以上）對屋外遊戲場・乳兒室・爬行室・保育室/遊戲室各有面積規定。若收托未滿2歲的孩子，乳兒室每人1.65㎡以上・爬行室每人3.3㎡以上；滿2歲以上者，保育室或遊戲室每人1.98㎡以上，屋外遊戲場滿2歲以上每人3.3㎡以上。

定員6〜19名的地域型保育（小規模保育事業）依「家庭的保育事業等的設備及運營基準」，本體施設的認可保育所依「兒童福祉設施的設備及運營基準」第32條。用途地域・消防的起點思路，與[小規模保育事業的物件出租・尋找時，用途地域與面積要確認什麼](https://luck428.com/column/hoiku-shoukibo-bukken-youto-chiiki)相通，但本體施設把屋外遊戲場（園庭）的確保、收托乳兒時的乳兒室・爬行室，以及因規模較大而凸顯的避難要件推到前面。

| 居室・設備 | 第32條的面積（每人） | 依據 |
|---|---|---|
| 乳兒室（未滿2歲） | 1.65㎡以上 | 第32條第2號 |
| 爬行室（未滿2歲） | 3.3㎡以上 | 第32條第3號 |
| 保育室或遊戲室（滿2歲以上） | 1.98㎡以上 | 第32條第6號 |
| 屋外遊戲場（滿2歲以上） | 3.3㎡以上 | 第32條第6號 |
| 醫務室・調理室・廁所 | 設置（條文無一律面積） | 第32條第1號・第5號 |

面積不是依「定員」而是依「實際收托的各年齡區分人數」生效，收托0〜2歲越多，所需乳兒室・爬行室面積越大。各室的最終可否由主管市區町村的認可基準・條例與事前協議決定，故押下物件前的確認是前提。

## 沒有屋外遊戲場（園庭）的物件，能用附近公園代替嗎？

條文上有代替的餘地。第32條第5號就屋外遊戲場定為「包含保育所附近可代替屋外遊戲場的場所」，可用附近的公園・廣場等作為代替地。但「是否在附近」「是否能安全日常使用」「是否滿足所需面積」由市區町村個別審查。

屋外遊戲場需滿2歲以上每人3.3㎡以上，但在無法於基地內確保的都市物件中，常以附近公園等被認作「可代替的場所」。何者算代替地（距離、園童是否能安全移動的路線、與他設施共用時必要時能否使用、面積是否足夠），由市區町村依兒童家庭廳『保育所等的設備・運營基準』與各自治體的手冊判斷。依賴代替地的物件，若未在契約前向自治體確認代替地可否，可能在認可階段因園庭不足被退回。

| 確認項目 | 重點 |
|---|---|
| 代替地依據 | 第32條第5號「包含附近可代替屋外遊戲場的場所」 |
| 距離・路線 | 是否為園童能安全日常利用的附近（距離數值為自治體運用【未驗證】） |
| 面積 | 是否滿足滿2歲以上每人3.3㎡以上 |
| 使用確實性 | 公園管理者等的使用承諾，非專用時必要時能否使用 |

代替地被認可的距離・條件數值因自治體而異、並非全國統一，故本文不作斷定、列為【未驗證】，以主管自治體的確認為前提。

## 在2樓以上・大樓店面開設時，避難・防火要看哪裡？

把保育室等（乳兒室・爬行室・保育室或遊戲室）設在2樓以上時，第32條第8號對耐火・兩方向避難・區劃有細緻要求。2樓以上原則為耐火建築物或準耐火建築物，3樓以上須為耐火建築物，各樓層設屋外階梯・傾斜路等避難施設，自保育室等任一處至任一避難施設的步行距離須30m以下。

第32條第8號要求：把保育室等設於2樓以上時，イ＝建物構造（2樓以上為耐火或準耐火、3樓以上為耐火）、ロ＝依樓層的避難施設（待避上有效的陽台、屋外傾斜路、屋外階梯等之一以上）、ハ＝避難上有效的位置與步行距離30m以下、ニ＝調理室的區劃（耐火構造的樓地板牆壁・特定防火設備・風管防火閘・自動滅火裝置）、ホ＝牆壁天花板的不燃內裝、ヘ＝防墜落設備、ト＝非常警報設備與向消防機關通報火災的設備、チ＝窗簾等的防焰。轉用大樓空室的物件，能否在既有建物中成立此耐火區劃・兩方向避難・調理室防火區劃，成為選定的分水嶺。

| 確認項目 | 第32條第8號重點 |
|---|---|
| 構造 | 2樓以上耐火或準耐火、3樓以上耐火建築物 |
| 兩方向避難 | 依樓層的屋外階梯・屋外傾斜路・待避陽台設於有效位置 |
| 步行距離 | 自保育室等任一處至避難施設30m以下 |
| 調理室 | 耐火區劃・特定防火設備・風管防火閘・自動滅火裝置 |
| 內裝・通報 | 不燃內裝、非常警報設備、向消防機關通報的設備、防焰物品 |

消防法施行令別表第一中保育所區分為(6)項ハ(3)，依延べ面積等配置自動火災報知設備・滅火器・誘導燈等。必要消防用設備的具體與工程費隨構成與建物而變，故列為【未驗證】，以採光・避難計算與確認申請由建築士、消防用設備由消防設備士・轄區消防署確認為前提。

## 用途地域與建築基準法上的用途變更（確認申請），向誰在哪裡確認？

用途地域對保育所幾乎不成問題。建築基準法別表第二中，保育所在第一種低層住居專用地域（(い)項第6號「老人院、保育所、福祉之家及類似者」）也能興建，且未列入工業專用地域不能興建的建築物。卡的不是用途地域，而是轉用既有建物時的用途變更確認申請。

把事務所・店舖・共同住宅等轉為認可保育所（建築基準法上屬兒童福祉設施）時，用途變更部分樓地板面積超過200㎡，使用前就需用途變更確認申請（建築基準法第6條第1項・第87條）。福祉用途變更容易卡關的點，整理於[福祉用途變更在哪裡需要確認申請](https://luck428.com/legal/column/group-home-kenchikukijunho-youto-henko)。用途變更的確認申請與採光・避難計算屬建築士・特定行政廳領域，本公司把現況用途與面積整理為物件資訊，計算與申請交給建築士。

| 確認項目 | 依據・重點 |
|---|---|
| 用途地域 | 別表第二(い)項第6號。第一種低層住居專用地域也可，工業專用地域亦非限制對象 |
| 用途變更確認申請 | 用途變更部分樓地板面積超過200㎡需申請（第6條第1項・第87條） |
| 採光 | 居室的採光（建築基準法第28條）。計算由建築士 |
| 由誰 | 計算・確認申請＝建築士／認可的適合審查＝市區町村與行政書士 |

## 押下物件前，在與自治體的事前協議中該確認什麼？

順序是「鎖定物件→面積・屋外遊戲場（代替地）・避難・用途變更・消防的可否確認→與市區町村事前協議→認可申請→人員配置・勞務設計」。認可保育所是受市區町村認可的設施，若簽約後才在事前協議發現面積・園庭・避難不足，回頭的成本很大。

事前協議的論點包括：對各年齡區分定員的居室面積、屋外遊戲場（園庭）或代替地的可否、設於2樓以上時的避難・耐火、調理室與供餐方式、以及與職員配置相稱的寬度。職員配置基準（保育士人數）與排班・就業規則的設計屬社會保險勞務士，認可申請書類與設備運營基準的適合整理屬行政書士。

| 階段 | 由誰 | 內容 |
|---|---|---|
| ① 鎖定物件 | 本公司 | 提供用途地域・現況用途・面積・樓層・消防現況 |
| ② 可否確認 | 本公司＋建築士・消防 | 用途變更（超200㎡）・採光避難計算・消防區分見込 |
| ③ 事前協議 | 業者 | 與市區町村就面積・園庭（代替地）・避難・定員協議 |
| ④ 認可申請 | 行政書士＋市區町村 | 設備運營基準的適合整理與認可申請（另行簽約） |
| ⑤ 人員・勞務 | 社會保險勞務士 | 保育士配置、排班、就業規則（另行簽約） |
| ⑥ 登記・會計 | 司法書士・稅理士 | 建物的表題變更登記、會計・稅務（另行簽約） |

本公司負責物件的用途・構造・面積・消防現況調查、重要事項說明、價格與條件調整、仲介與買賣・租賃契約。**認可申請與設備運營基準的適合審查交給行政書士與市區町村，採光・避難計算與用途變更確認申請交給建築士，保育士的人員配置・排班・就業規則交給社會保險勞務士，建物的表題變更登記交給司法書士，會計・稅務交給稅理士，與本公司各自為獨立的事業體。角色重疊的部分，於契約前明確由誰負責，分別簽約。** 各專業人士請分別直接委託。本公司不收取也不支付介紹費・轉介費。諮詢免費。

## 常見問題

**Q. 認可保育所與小規模保育，對物件的標準有何不同？**
A. 依據的省令不同。認可保育所（定員20名以上）依兒童福祉設施設備運營基準第32條，規定屋外遊戲場（園庭）、乳兒室（每人1.65㎡）・爬行室（每人3.3㎡）・保育室或遊戲室（每人1.98㎡）等。小規模保育（6〜19名）依家庭的保育基準，因規模較小，園庭與避難要件也不同。物件可否請向主管市區町村確認。

**Q. 沒有園庭的大樓物件能做認可保育所嗎？**
A. 條文上屋外遊戲場「包含附近可代替的場所」，有用附近公園等作代替的餘地（第32條第5號）。但市區町村會個別審查距離・路線・面積・使用確實性。因被認可的距離因自治體而異（本文列為【未驗證】），請在契約前向主管市區町村確認代替地可否。

**Q. 想把保育室設在2樓，物件側需要什麼？**
A. 第32條第8號原則要求2樓以上為耐火或準耐火建築物、3樓以上為耐火建築物，依樓層的屋外階梯・傾斜路，自保育室等任一處至避難施設步行距離30m以下，調理室的耐火區劃與自動滅火裝置，不燃內裝，防墜落，向消防機關通報的設備等。該判斷與採光・避難計算屬建築士領域。

**Q. 把既有事務所大樓改為認可保育所，需要確認申請嗎？**
A. 用途變更部分樓地板面積超過200㎡，使用前需用途變更確認申請（建築基準法第6條第1項・第87條）。保育所在用途地域上幾乎不會卡（別表第二(い)項第6號在第一種低層住居專用地域也可，工業專用地域亦非限制對象）。確認申請與採光・避難計算請洽建築士，認可的適合審查請洽市區町村與行政書士。
