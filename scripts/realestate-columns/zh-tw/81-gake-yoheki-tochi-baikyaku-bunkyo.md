**先講結論：** 在文京區這樣坡道與高低差多的地區，出售有懸崖（崖）或擋土牆（擁壁）的土地時，「擋土牆是否安全」「改建時是否需要重做」左右價格與買方的範圍。東京都建築安全條例第6條要求，在自高度超過2m的懸崖下端起的水平距離為懸崖高度2倍以內的場所建築建築物或造成基地時，原則上須設置高度超過2m的擋土牆。高度超過2m的擋土牆，依建築基準法第88條第1項與同法施行令第138條第1項第5號，作為工作物屬確認的對象；建築物有受崖崩等損害之虞時，須設置擋土牆或採取其他安全上適當的措施（同法第19條第4項）。此外，自2024年7月31日起，文京區全域被指定為宅地造成及特定盛土等規制法（盛土規制法）的宅地造成等工事規制區域，一定規模以上的盛土・切土屬許可的對象。擋土牆的安全性與改建時的要否，由建築士（結構）與特定行政廳（文京區）判斷，本公司（四葉不動產株式會社）不作判斷。本公司所做的，是把擋土牆的檢查濟證等文件與公所調查的結果整理成報告書，作為重要事項加以說明，並把出口並列出來。與各專家請各以獨立事業體的形式分別簽約，本公司不收取介紹費。

小日向・小石川・目白台・本鄉等文京區的住宅區，坡道沿著台地與低地的交界延伸，建在擋土牆上的房子、建在懸崖下的房子並不罕見。繼承的老家後方是高聳的擋土牆、造成時的文件沒有留下——這類諮詢，在出售前必須先整理。本文依條文與區的公開資料，整理出售有懸崖・擋土牆的土地時，要確認什麼、由誰判斷、如何說明。出口的全貌整理於[難以出售的土地・建物的出口諮詢](https://luck428.com/wakeari)，接道與重建的論點整理於[再建築不可的土地・房屋的出口諮詢](https://luck428.com/wakeari/saikenchiku-fuka)。

## 有懸崖・擋土牆的土地，會有什麼問題？

| 規定 | 內容 | 在出售時發揮作用的場面 |
|---|---|---|
| 東京都建築安全條例第6條 | 在自高度超過2m的懸崖下端起的水平距離為懸崖高度2倍以內的場所建築建築物或造成基地時，原則上須設置高度超過2m的擋土牆 | 改建時可能需要新設・重做擋土牆 |
| 建築基準法第19條第4項 | 建築物有受崖崩等損害之虞時，須設置擋土牆或採取其他安全上適當的措施 | 崖下・崖上基地的安全措施 |
| 建築基準法第88條第1項・施行令第138條第1項第5號 | 高度超過2m的擋土牆作為工作物，準用確認等的規定 | 既有擋土牆是否有確認濟證・檢查濟證 |
| 盛土規制法（宅地造成及特定盛土等規制法） | 宅地造成等工事規制區域內一定規模以上的盛土・切土・土石堆積屬許可的對象 | 伴隨造成的改建・出售後的工程 |

也就是說，擋土牆老舊、沒有文件、高度或結構不明的土地，買方無法估算改建的費用與風險，買方的範圍就會變窄。反過來，若擋土牆的文件齊備、又取得專家的評估，就會成為說得清楚的土地。

## 出售前，要確認哪些文件？

| 確認事項 | 文件・確認對象 | 承擔者 |
|---|---|---|
| 擋土牆的確認濟證・檢查濟證有無 | 文京區的建築計畫概要書・台帳記載事項證明 | 本公司（公所調查） |
| 造成時的圖面・施工紀錄 | 所有人保管的文件、施工公司 | 所有人，由本公司整理 |
| 懸崖的高度・擋土牆的高度與基地的位置關係 | 現場測量・看得出高低差的圖面 | 土地家屋調查士・測量士 |
| 擋土牆的結構・劣化狀況 | 現場調查 | 建築士（結構）。本公司不作判斷 |
| 宅地造成等工事規制區域的指定 | 文京區・東京都的公開資料 | 本公司（公所調查） |
| 與鄰地的界線及擋土牆的所有關係 | 界線確定測量、登記簿 | 土地家屋調查士。步驟見[界線確定測量與出售](https://luck428.com/column/souzoku-fudosan-kyoukai-kakutei-sokuryo-baikyaku) |

擋土牆是在自己的土地上、在鄰地上，還是共有，與界線的位置一併確認。擋土牆的所有關係若一直曖昧不明，會成為修繕費用負擔之爭的根源，一旦出現紛爭性，就屬律師的領域。

## 因盛土規制法，文京區有了什麼改變？

依據宅地造成及特定盛土等規制法（昭和36年法律第191號。經令和4年法律第55號修正而更改題名，2023年5月26日施行），東京都指定了規制區域；據文京區的公告，自2024年7月31日起，文京區全域被指定為「宅地造成等工事規制區域」。文京區列為主要對象的工程如下。

| 屬許可對象的主要工程（依文京區的公開資料） |
|---|
| 因盛土而產生高度超過1m的懸崖者 |
| 因切土而產生高度超過2m的懸崖者 |
| 盛土高度超過2m者 |
| 進行盛土或切土的土地面積超過500㎡者 |
| 一時性的土石堆積高度超過2m且面積超過300㎡者 |

這些會在出售後買方重做擋土牆、造成基地等場面產生關聯。哪些工程屬許可的對象，向文京區的主管課（都市計畫課開發擔當）與建築士確認。本文不判斷個別工程是否需要許可。

## 由誰判斷擋土牆的安全性？

| 判斷事項 | 判斷者 | 本公司的參與 |
|---|---|---|
| 擋土牆的結構・安全性・耐用的評估 | 建築士（結構設計），必要時為地盤・擋土牆的專業業者 | 整理文件與現場的資訊後交付 |

## 出售時的說明與責任，會是怎樣？

宅地建物取引業法第35條第1項第2號要求，就建築基準法及其他法令所定限制中由政令規定者，說明其概要作為重要事項。東京都建築安全條例第6條的懸崖規定、盛土規制法的規制區域，都是與此說明相關的事項。

| 說明的事項 | 內容 |
|---|---|
| 懸崖・擋土牆的存在與高度、位置關係 | 基於測量與圖面的事實 |
| 擋土牆的確認濟證・檢查濟證有無 | 公所調查的結果。沒有就說明沒有 |
| 東京都建築安全條例第6條的該當 | 改建時可能需要擋土牆 |
| 宅地造成等工事規制區域的該當 | 一定規模以上的工程屬許可對象 |
| 建築士的評估（已取得時） | 內容，以及其為評估而非保證 |

賣方明知而未告知的事實，即使訂有不負擔保責任的特約，亦不能免責（民法第572條）。擋土牆的裂縫、過去的崩塌、公所的指正，都照實傳達給買方。契約不適合責任的範圍如何訂定，逐一契約檢討。

## 常見問題

**Q. 沒有擋土牆的檢查濟證，賣不掉嗎？**
A. 並非賣不掉。把沒有這件事作為重要事項說明，再比較是取得建築士的評估、以現況出售，還是以合作的收購業者為買方的仲介。沒有文件的擋土牆，買方難以估算改建費用，因此買方的範圍會變窄，這點作為一般論先記住。

**Q. 擋土牆很舊，需要重做嗎？**
A. 本公司無法判斷。有改建計畫時，依東京都建築安全條例第6條的該當與擋土牆的結構・狀態，由建築士與特定行政廳（文京區）判斷。伴隨造成的工程可能屬盛土規制法許可的對象，這點也向區的主管課確認。

**Q. 鄰居的擋土牆逼近我家的土地，是誰的責任？**
A. 依擋土牆在哪一方的土地上、界線在哪裡而不同。界線確定測量由土地家屋調查士進行，圍繞費用負擔或修繕有爭執時，請直接委託律師。本公司整理登記簿・公圖與測量結果，反映於出售時的說明。

**Q. 位於盛土規制法的規制區域內，對出售有什麼影響嗎？**
A. 出售本身不受限制。但買方要重做擋土牆或造成時，一定規模以上的盛土・切土屬許可的對象，因此在重要事項說明中傳達規制區域的該當。據文京區的公告，自2024年7月31日起，文京區全域為宅地造成等工事規制區域。
