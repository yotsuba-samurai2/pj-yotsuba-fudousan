**先講重點**：代駕業的「營業所」是認定申請書上所填的「主要營業所」，因此要選辦公用途符合用途地域與租約使用目的的物件。隨伴用汽車的保管場所（車庫），須依車庫法在營業本據位置約直線2公里內確保。先在不動產面把物件的用途適配與車庫確保妥當，向公安委員會的認定申請再分開交給行政書士。

想開設汽車代駕（運轉代行）業時，常會猶豫「是不是任何物件都能當營業所」「隨伴的車的停車場可以離多遠」。代駕是取得都道府縣公安委員會認定後經營的工作，申請書要填主要營業所的所在地，也須先確保隨伴用汽車的保管場所。

有人先簽了物件，後來才發現營業所用途或車庫距離不符要件，認定準備因此卡住。物件能否通過認定，分成不動產面（用途地域、租約、車庫確保）與許可面（認定要件、申請）來確認，最為穩當。

四葉不動產株式會社以東京都文京區小日向為據點，承接事業用物件的調查與租賃仲介。對於要當營業所與隨伴車保管場所的物件，可從簽約前能確認的事項開始諮詢。

## 代駕的「營業所」能用的物件條件是什麼？

代駕業的根據法是「汽車代駕業業務適正化相關法律」（代駕業法／運轉代行業法，平成13年法律第57號，最終修正令和2年法律第42號）。該法第2條將代駕業定義為：代替他人駕駛汽車提供勞務的營業，且須同時符合——主要在夜間對受提供酒類的醉客提供勞務、讓該人乘車、以常態使用隨伴於被代駕汽車（代行運轉自動車）的汽車（隨伴用自動車）——各款。

該法第4條規定，經營代駕業須取得都道府縣公安委員會的認定。申請一般經由管轄主要營業所所在地的警察署（交通課）提出。也就是說，營業所即認定申請書上所填的事業據點。

| 要確認的事 | 物件面要看的點 |
| --- | --- |
| 用途 | 建物能否作為辦公室（營業所）使用；僅限住居的物件可能不符使用目的 |
| 使用目的 | 租約的使用目的能否納入「代駕業的營業所」；出租人同意的範圍 |
| 標示 | 能否掛招牌、公司名（建物規約、出租人許可） |
| 連絡體制 | 能否設置派車、受理用的電話與設備；深夜運作的業態是否獲鄰里理解 |

代駕業法並未就營業所訂定細緻的構造基準。因此物件面先起作用的，是用途地域是否允許辦公用途、是否符合租約使用目的這些不動產基本。認定要件與欠格事由本身的判斷，屬行政書士與公安委員會的領域。

認定要件（第3條欠格事由、損害賠償措施、安全駕駛管理者等）與申請流程，在行政書士側的[代駕業認定、營業所與隨伴汽車的要件（日文）](https://luck428.com/legal/column/unten-daiko-nintei-eigyosho-zuihan-jidosha-yoken)說明。本文僅限於尋找能通過該認定之物件的不動產面。

## 隨伴用汽車的保管場所（車庫）可以離多遠？

隨伴用汽車是隨伴於駕駛客人車輛的員工、並載其返回的車。既然是汽車，就受「汽車保管場所確保等相關法律」（車庫法，昭和37年法律第145號）規範。

車庫法第3條課予保有者於道路以外確保保管場所的義務，要件委由政令定之。施行令要求，保管場所與營業本據位置間的直線距離不得超過約2公里等。對代駕而言，即須在營業所（營業本據）直線2公里內確保隨伴車的車庫。

| 要確認的事 | 物件面要看的點 |
| --- | --- |
| 距離 | 營業所到車庫的直線距離是否在2公里內 |
| 使用承諾 | 承租月租停車場時，能否取得出租人的保管場所使用承諾證明書 |
| 車位數 | 對照隨伴車台數，車位是否足夠；增車的餘地 |
| 夜間運作 | 深夜出入與待命對鄰里的音、光影響 |

保管場所若為承租而非自有，須有出租人的保管場所使用承諾證明書。簽約前要確認能否取得作為車庫出租的承諾。保管場所證明（車庫證明）申請書類的製作與代辦是行政書士的業務，本公司不代理申請，而是整理確保車庫這一不動產面的程序。

此與貨運業的營業所、車庫物件要件框架不同。尋找貨運據點的思路，請參考[貨運業營業所與車庫物件的要件（日文）](https://luck428.com/column/unsou-eigyosho-shako-bukken-yoken)。

## 用途地域與租約上要注意什麼？

即使營業所與車庫各自符合要件，也可能因物件立地與契約條件而卡住。代駕屬深夜運作的業態，連同與鄰里的關係一起確認。

| 要確認的事 | 內容 |
| --- | --- |
| 用途地域 | 該地域能否蓋辦公用途；住居系地域可能對規模或用途有限制 |
| 使用目的 | 租約使用目的是否含營業所、車庫；有無禁止目的外使用的條款 |
| 原狀回復 | 設置招牌、劃設車位時，退租時的處理 |
| 鄰里 | 鄰里對深夜派車、出入的理解；音、光與路上待命 |

用途地域的判斷與建築可否屬建築師與特定行政廳的領域。別斷定「這個地域一定能當辦公室」，要逐件確認用途地域與建物狀況。若在使用目的不符的情況下簽約，可能在認定準備階段才發現物件不能當營業所。租賃仲介與重要事項說明由本公司進行，簽約前整理使用目的與出租人同意範圍。

一如深夜的餐飲、娛樂系業態，對鄰里的影響是從選址階段就要看的課題。閱讀物件、用途地域與鄰里應對的思路，也可參考[事業用物件的用途地域讀法（日文）](https://luck428.com/column/kaigo-jigyousho-bukken-youto-chiiki)。

## 認定申請與物件契約，該先進行哪一個？（分離受任）

開代駕時，物件、車庫、保險與申請分屬不同事業體。順序弄錯，可能簽了的物件不能用，或保險來不及。

| 角色 | 由誰承擔 |
| --- | --- |
| 營業所、車庫物件的調查與租賃仲介 | 宅地建物交易業（本公司） |
| 認定申請、保管場所證明（車庫證明）書類製作 | 行政書士 |
| 損害賠償措施（保險） | 保險公司 |
| 法人設立、登記 | 司法書士 |
| 糾紛、法律評價 | 律師 |

實務上較清楚的順序，是先在不動產面把營業所的用途適配與隨伴車車庫（直線2公里內）整理妥當，再把認定申請交給行政書士。損害賠償措施涉及認定要件（代駕業法第3條），故與保險公司的契約也並行確認。

這些是**各自獨立的事業體**，須**分別簽約**。本公司承擔物件與車庫的不動產面，認定與車庫證明的申請交給行政書士、保險交給保險公司，分開介紹。本公司不收取介紹費。另外，讓客人搭乘隨伴用汽車運送，涉及旅客運送許可的課題，須向運輸局與行政書士確認。

## 常見問題

**Q. 能把自家一間房當代駕的營業所嗎？**
A. 僅限住居的物件，可能因租約使用目的或用途地域限制而不能當辦公室。即使自有，也須確認建物規約與用途地域。簽約前，我們會整理該物件能否作為認定申請書上所填的主要營業所。

**Q. 隨伴用汽車的車庫可以離營業所很遠嗎？**
A. 車庫法施行令要求保管場所與營業本據位置的直線距離不得超過約2公里。請在營業所直線2公里內確保車庫。承租月租停車場時，要確認能否取得出租人的保管場所使用承諾證明書。

**Q. 擔心簽了物件後認定下不來。順序該怎麼做？**
A. 較清楚的順序，是先在不動產面把營業所的用途適配與隨伴車車庫整理妥當，認定申請再分開交給行政書士。損害賠償措施（保險）也涉及認定要件，故並行確認。物件、車庫、申請、保險都與不同事業體分別簽約。

**Q. 車庫證明的申請也能委託不動產公司嗎？**
A. 保管場所證明（車庫證明）申請書類的製作與代辦是行政書士的業務，本公司不代理申請。本公司承擔要當車庫之物件的調查與租賃仲介，申請則引介行政書士。向出租人取得保管場所使用承諾證明書，作為租賃條件整理。
