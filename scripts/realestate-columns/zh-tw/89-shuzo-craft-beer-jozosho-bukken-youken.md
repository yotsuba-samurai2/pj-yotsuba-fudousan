**結論（先說重點）**：開精釀啤酒釀造所（酒類製造）的物件，先發生作用的是四點：①用途地域（釀造所是建築基準法別表第二的「工場」，可設置的區域受作業場樓地板面積與危險性・環境影響篩選）②建物側要件（承載酒槽的樓地板荷重・天花板高・電力容量・冷藏/貯藏區劃）③釀造排水（BOD高，屬水質汚濁防止法的特定施設，並受下水道・淨化槽規制）④酒類製造免許的最低製造數量（啤酒年60公秉、發泡酒年6公秉）。免許本身由所轄稅務署（國稅廳）管轄，非宅地建物取引業者或行政書士的業務範圍。物件的調查・媒介・買賣/租賃契約由本公司（四葉不動產株式會社）承擔，酒吧區（tap room）的飲食店營業許可等保健所提出文書的製作由四葉行政書士事務所承擔；免許找稅務署、建築確認・樓地板荷重的設計找建築士、排水設備找設備業者、酒稅・法人稅找稅理士。這些是各自獨立的事業體，請分別直接簽約。

「前一位租客是餐廳，所以直接放入釀造槽就能開」——你以此為前提租下，卻在開始仕込（投料釀造）時發現樓地板快塌、排水無法排入下水道、電力不足。餐廳與診所物件會發生的返工，在釀造所更沉重。本文寫給在東京開啤酒酒吧・小規模釀造所的創業者，以及出租・尋找該物件的立場者：在決定租賃或購買前能確認的事，依酒稅法・都市計畫法・建築基準法・水質汚濁防止法・食品衛生法的條文與公資料依序整理。因酒類製造免許本身由稅務署管轄，取得的諮詢對象另行標示；本文聚焦於從不動產側看的物件條件。可否的最終確認，在所轄稅務署・特定行政廳・保健所・消防署・自治體的下水道/環境部門的窗口進行。

## 精釀啤酒釀造所在哪些用途地域能開？

釀造所在法律上是「製造物品的工場」。與餐廳（店舖）或診所處理不同，**可設置的場所受用途地域篩選**。這是第一道關卡。

建築基準法（昭和25年法律第201號）第48條與別表第二，就各用途地域訂定可興建的建築物。工場方面，以**作業場樓地板面積的合計**、以及**是否危險性大或會顯著惡化環境**兩把尺區分區域。酒類製造業（釀造）通常不屬於大量處理危險物或會顯著惡化環境的工場類型，但可設置的用途地域隨作業場大小而變。大致如下。

| 用途地域 | 作為工場的處理（目安） |
|---|---|
| 第一種・第二種低層住居專用地域／田園住居地域 | 原則不可（小規模兼用住宅的一部分等例外除外） |
| 第一種・第二種中高層住居專用地域 | 原則不可（不能興建工場） |
| 第一種・第二種住居地域・準住居地域 | 作業場樓地板面積小（大致50㎡以下）且符合原動機出力等條件的範圍內可 |
| 近鄰商業地域・商業地域 | 作業場樓地板面積大致150㎡以下可 |
| 準工業地域 | 危險性・環境影響少的工場原則可（釀造所易設置） |
| 工業地域・工業專用地域 | 可（惟工業專用地域不能併設店舖） |

**若想併設酒吧區（店內提供）並保有規模，準工業・工業地域較為現實**；另須注意工業專用地域不能併設飲食提供的店舖。作業場樓地板面積的階段（50㎡・150㎡等）與原動機出力的處理，依特定行政廳（自治體的建築主事）的運用而分，故請及早把設想的製造規模與物件的用途地域對照。用途地域與容積率如何牽動地價，整理於[日本地價為何隨「容積率」而變](https://luck428.com/column/yosekiritsu-hosei-tochine)。事業用物件全般請見[投資用・事業用不動產](https://luck428.com/toushi)，公司設立與辦公室選擇請見[公司設立與辦公室選擇](https://luck428.com/office)。

## 樓地板荷重・天花板高・電力容量等建物側要件，哪些易被忽略？

用途地域之後發生作用的，是建物本身能否承受釀造設備。以下項目是餐廳居抜（沿用既有裝修）所不涵蓋的。

| 簽約前確認 | 為何發生作用 |
|---|---|
| 樓地板荷重（積載荷重） | 仕込後的發酵・貯酒槽滿水時每座數百公斤〜數噸。辦公室規格（每㎡約300公斤）的樓地板有承受不住者 |
| 天花板高 | 立式發酵槽・煙囪・配管的立起需要高度 |
| 電力容量 | 冷卻機（chiller）・鍋爐・幫浦・冷藏庫耗電。只有單相的物件，須確認能否引入動力（三相） |
| 給湯・鍋爐・瓦斯容量 | 仕込的加熱（湯煮）需大量熱源 |
| 冷藏・貯藏區劃 | 能否取得發酵・貯酒・原料（麥芽・啤酒花）・製品的溫度管理區劃 |
| 搬運路線 | 酒槽・製品棧板進出的間口・前面道路寬度，堆高機能否通行 |

樓地板荷重尤其易被忽略。**滿水的酒槽局部很重，辦公室或零售店規格的樓地板可能需要補強。** 樓地板能否補強・構造是否允許，是建築士（構造設計）的判斷。確認既有建物的構造後，把所需補強的範圍，以及它如何反映到租賃契約的回復原狀，在簽約前與出租人談妥，可減少返工。中古建物也要確認檢查完成證的有無。無檢查完成證的中古建物，在用途變更確認申請與融資上可能有障礙，有時可透過法適合狀況調查確認建築時的合法性。此論點整理於[無檢查完成證的中古物件能否轉為福祉用途](https://luck428.com/column/kensazumisho-nashi-bukken-fukushi-youto-henko)。設計・施工由建築士與設備業者負責，本公司（不動產公司）就物件能否滿足這些條件的預先調查與對出租人的條件交涉伴走。

## 釀造排水（BOD・水量）與下水道・淨化槽的規制，要在哪裡確認？

釀造所比餐廳更甚地處理**水與有機物**。仕込・洗淨・酵母・麥芽渣所生的排水BOD（生物化學需氧量）高、量也多。這與物件選擇直接相關。

首先，釀造所可能成為設置水質汚濁防止法（昭和45年法律第138號）**特定施設**的事業場。同法施行令別表第一，把酒類製造業（啤酒・清酒等）用的洗瓶施設・以湯煮加熱處理原料的施設・過濾施設・蒸餾施設等列為特定施設。要設置特定施設時，須向都道府縣知事等提出屆出（同法第5條）。向公共用水域（河川等）排水時，適用同法第3條的排水基準（BOD・SS等的容許限度）。

其次，都市部的多數物件接入公共下水道。此時適用下水道法（昭和33年法律第79號）與各自治體的下水道條例，可能要求特定施設的設置屆出（下水道法第12條之3），或設置不稀釋而處理超標排水的**除害施設**。在下水道區域外使用淨化槽的物件，另須依淨化槽法處理與維護管理。

| 排水的確認點 | 在哪裡確認 |
|---|---|
| 公共下水道或淨化槽・接續的可否 | 自治體的下水道局・物件的給排水圖 |
| 特定施設屆出的要否 | 都道府縣・自治體（水質汚濁防止法・下水道法） |
| 是否需要除害施設（BOD等排除基準） | 自治體的下水道條例。數值因自治體而異 |
| 排水管的口徑・坡度・排水量的餘裕 | 設備業者・給排水圖 |

**排水的基準值與屆出的運用因自治體而異，寫作當下也可能變動。** 傳達釀造規模（一年釀多少公秉、用多少水仕込）後，請在動手前直接向自治體的下水道・環境部門確認。排水・除害施設的設計施工由設備業者負責，排水協議由指定工事店參與。給排水與換氣的物件條件，與餐廳的[以毛胚（skeleton）物件開餐廳時，排氣・油脂截留器・防火如何決定物件選擇](https://luck428.com/column/inshokuten-skeleton-bukken-haiki-grease)、[洗衣店的物件與給排水・排水處理](https://luck428.com/column/cleaning-jo-bukken-youken-kyusuisui-shori)有許多共通論點，可資參考。

## 酒類製造免許的最低製造數量是什麼？該找誰諮詢？

要製造酒類，除物件外還需要**酒類製造免許**。這與物件的話題管轄不同。

酒稅法（昭和28年法律第6號）第7條第1項規定，欲製造酒類者，須就欲製造的酒類品目別，**按製造場別，取得該製造場所在地所轄稅務署長的免許**。也就是說，免許由所轄稅務署（國稅廳）管轄，**非宅地建物取引業者或行政書士的業務範圍**。

而免許有**最低製造數量基準**。酒稅法第7條第2項規定，一年的見込製造數量未達各品目所定數量時，不得取得免許。與精釀啤酒相關的主要數量如下。

| 品目 | 年最低製造數量 |
|---|---|
| 啤酒 | 60公秉 |
| 發泡酒 | 6公秉 |
| 果實酒 | 6公秉 |
| 利口酒 | 6公秉 |
| 清酒 | 60公秉 |

**這是精釀啤酒開業最為人知的分界。** 「啤酒」免許需年60公秉的製造見込，但以果實或香辛料等副原料做成屬「發泡酒」的釀法，最低製造數量便降到年6公秉。小規模釀造所以發泡酒免許起步、隨規模擴大再檢討啤酒免許，即因此故。又，2018年（平成30年）4月1日的酒稅法修正擴大了「啤酒」的定義（麥芽比率由67%以上降到50%以上，並認可果實・香辛料等副原料／酒稅法第3條第12號），使部分原屬發泡酒的商品被納入啤酒，但各免許最低製造數量的區別仍存。可不予免許的情形（人的要件・場所的要件・經營基礎要件・供需調整要件等拒否要件）規定於同法第10條。

**免許的要否・可否最終判斷在所轄稅務署。** 整理設想的品目與製造數量後，請找稅務署的酒類指導官（酒類擔當），或精通酒類免許的專家諮詢。本公司・本事務所不代辦此免許本身，僅承擔確認物件能否滿足製造・排水・電力條件。

## 若釀造與酒吧區（飲食提供）併設，物件會有何不同？

做成在店內提供自家啤酒的啤酒酒吧（併設酒吧區），會在**製造免許之外，疊上飲食提供的許可**。物件條件也增加一層。

在店內提供啤酒供飲食的營業，須取得食品衛生法（昭和22年法律第233號）第55條的**飲食店營業許可**（保健所）。請在簽約前確認廚房・洗手・區劃能否滿足保健所的施設基準。飲食店營業許可的物件條件，整理於[飲食店營業許可與保健所的施設基準](https://luck428.com/legal/column/inshokuten-eigyo-kyoka-hokenjo-setsubi-kijun-shokuhin-eisei)（行政書士）。

此外，把所造的酒賣到店外（以瓶・罐零售）需另取**酒類販賣業免許**，深夜0時以後主要提供酒類則需**深夜酒類提供飲食店營業的屆出**。這些是與製造分開的許認可，店舖許認可申請文書的製作是行政書士的業務。酒類零售免許與店舖物件要件整理於[能取得酒類零售免許的店舖物件條件](https://luck428.com/legal/column/shurui-kouri-menkyo-tenpo-bukken-yoken)，深夜提供的屆出整理於[深夜酒類提供飲食店營業屆出的要件](https://luck428.com/legal/column/shinya-shurui-teikyo-todokede-yoken)（皆為行政書士）。

| 併設而增加的確認 | 管轄・承擔者 |
|---|---|
| 店內提供的飲食店營業許可 | 保健所／申請文書由行政書士 |
| 瓶・罐零售（酒類販賣業免許） | 所轄稅務署 |
| 深夜0時以後提供酒類的屆出 | 警察署／屆出文書由行政書士 |
| 消防用設備・避難（客席增加） | 消防署・消防設備士 |
| 工業專用地域不能併設店舖 | 特定行政廳（用途地域） |

**只做製造的物件，與也做飲食提供的物件，在用途地域・消防・保健所的看法會變。** 若要有酒吧區，就以「避開工業專用地域、選能滿足飲食提供的施設基準與消防的物件」的順序篩選。

## 常見問題

**Q. 精釀啤酒釀造所能開在住宅街（第一種低層住居專用地域）嗎？**
A. 原則不能。釀造所屬建築基準法別表第二的「工場」，在第一種・第二種低層住居專用地域或中高層住居專用地域不能興建。住居系地域若作業場樓地板面積小尚有餘地，但製造規模上升後，近鄰商業・商業（作業場大致150㎡以下）或準工業・工業地域較現實。用途地域上的可否因物件而異，請於特定行政廳窗口確認。

**Q. 若是餐廳居抜物件，直接放入釀造槽就能開始嗎？**
A. 未必。餐廳規格的樓地板多未設想滿水酒槽（每座數百公斤〜數噸），可能需要樓地板荷重補強。電力（動力）容量、給湯・鍋爐、排水的口徑與處理也可能不足。請在簽約前，樓地板荷重與構造找建築士、排水找設備業者與自治體確認。

**Q. 釀造所的排水能直接排入下水道嗎？**
A. 未必能照原樣。釀造排水BOD（有機物）高、量也多，故在公共下水道，依下水道法與自治體下水道條例，可能要求特定施設屆出或設置除害施設。基準值因自治體而異，請傳達設想的釀造規模，於動手前向自治體的下水道・環境部門確認。

**Q. 啤酒免許真的要能年產60公秉才拿得到嗎？**
A. 「啤酒」免許以年60公秉的製造見込為要件（酒稅法第7條第2項）。相對地，依副原料的用法做成屬「發泡酒」的釀法，最低製造數量降到年6公秉。小規模釀造所多以發泡酒免許起步即因此。免許的要否・可否判斷由所轄稅務署管轄，請整理品目與製造數量後找稅務署諮詢。
