**結論（先に要点）**：運転代行業の営業所は、認定申請書に記す「主たる営業所」として、事務所用途が用途地域・賃貸借契約の使用目的に適合する物件を選びます。随伴用自動車の保管場所（車庫）は車庫法に基づき、使用の本拠の位置からおおむね直線2キロメートル以内に確保します。物件の用途適合と車庫の確保を不動産側で先に整え、公安委員会への認定申請は行政書士へ分けて進めます。

自動車運転代行業（運転代行）を始めようとすると、「営業所にする物件はどんな場所でもよいのか」「随伴する車の駐車場はどこまで離せるのか」と迷います。運転代行は、都道府県公安委員会の認定を受けて営む仕事で、認定の申請書には主たる営業所の所在地を書き、随伴用自動車の保管場所も確保しておく必要があります。

物件を先に契約してから、営業所の用途や車庫の距離が要件に合わず、認定の準備が止まってしまう例があります。認定が通る物件かどうかは、不動産面（用途地域・賃貸借契約・車庫の確保）と、許認可面（認定の要件・申請）に分けて確認するのが確実です。

四葉不動産株式会社は、東京都文京区小日向を拠点に、事業用物件の調査と賃貸仲介を承っています。運転代行の営業所と随伴車の保管場所になる物件について、契約前に確認できることからご相談いただけます。

## 運転代行の「営業所」に使える物件の条件は？

運転代行業の根拠法は「自動車運転代行業の業務の適正化に関する法律」（運転代行業法・平成13年法律第57号、最終改正 令和2年法律第42号）です。同法第2条は運転代行業を、他人に代わって自動車を運転する役務を提供する営業のうち、主として夜間に酒類の提供を受けた酔客に対して役務を提供すること、その者を乗車させること、代行運転する自動車（代行運転自動車）に随伴するための自動車（随伴用自動車）を常態として使用すること、という各号をすべて満たすものと定めています。

同法第4条は、運転代行業を営むには都道府県公安委員会の認定を受けなければならないとしています。認定申請では、主たる営業所の所在地を管轄する警察署（交通課）を経由して申請するのが一般的です。つまり営業所は、認定申請書に記載する事業の拠点にあたります。

| 確認すること | 物件側で見ておきたい点 |
| --- | --- |
| 用途 | 事務所（営業所）として使える建物か。住居専用の物件では使用目的が合わないことがある |
| 使用目的 | 賃貸借契約の使用目的に「運転代行業の営業所」が含められるか。貸主の承諾の範囲 |
| 表示 | 看板・社名表示を掲げられるか（建物規約・貸主の許可） |
| 連絡体制 | 配車・受付の電話や設備を置けるか。深夜に稼働する業態への近隣の理解 |

運転代行業法は営業所の細かな構造基準までは定めていません。したがって物件側で先に効くのは、用途地域の制限で事務所用途が認められるか、賃貸借契約の使用目的に適合するか、という不動産の基本です。認定の要件や欠格事由そのものの判断は、行政書士と公安委員会の領域です。

認定の要件（第3条の欠格事由、損害賠償措置、安全運転管理者など）と申請の流れは、行政書士側の[運転代行業の認定・営業所・随伴自動車の要件](/legal/column/unten-daiko-nintei-eigyosho-zuihan-jidosha-yoken)で扱っています。本記事は、その認定が通る物件を探す不動産面に限定します。

## 随伴用自動車の保管場所（車庫）はどこまで離れてよい？

随伴用自動車は、客の車を運転する従業員に随伴し、戻るための車です。自動車である以上、「自動車の保管場所の確保等に関する法律」（車庫法・昭和37年法律第145号）の対象になります。

車庫法第3条は、自動車の保有者に、道路上の場所以外に保管場所を確保する義務を課し、その要件を政令に委ねています。施行令は、保管場所が使用の本拠の位置との間の距離について直線でおおむね2キロメートルを超えないことなどを求めています。運転代行では、営業所（使用の本拠）から直線2キロメートル以内に随伴車の車庫を確保する、という形になります。

| 確認すること | 物件側で見ておきたい点 |
| --- | --- |
| 距離 | 営業所から車庫までの直線距離が2キロメートル以内か |
| 使用承諾 | 月極駐車場などを借りる場合、貸主から保管場所使用承諾証明書を得られるか |
| 台数 | 随伴車の台数に対して区画数が足りるか。増車時の余地 |
| 夜間稼働 | 深夜の出入りや待機による近隣への音・光の影響 |

保管場所が自己所有地でなく賃借の場合は、貸主の保管場所使用承諾証明書が要ります。契約前に、車庫として貸し出す承諾を得られるかを確認します。保管場所証明（車庫証明）の申請書類の作成・代行は行政書士の業務で、当社は申請を代理しません。車庫の確保という不動産面の段取りを整えます。

運送業の営業所と車庫の物件要件とは枠組みが異なります。貨物運送の拠点を探す場合の考え方は[運送業の営業所・車庫になる物件の要件](/column/unsou-eigyosho-shako-bukken-yoken)を参考にしてください。

## 用途地域や賃貸借契約で気をつける点は？

営業所と車庫がそれぞれ単独で要件に合っても、物件の立地と契約条件で詰まることがあります。運転代行は深夜に稼働する業態のため、近隣との関係も含めて確認します。

| 確認すること | 内容 |
| --- | --- |
| 用途地域 | 事務所用途が建てられる地域か。住居系地域では規模や用途に制限がある場合がある |
| 使用目的 | 賃貸借契約の使用目的に営業所・車庫が含まれるか。目的外使用を禁じる条項の有無 |
| 原状回復 | 看板設置や区画整備を行う場合の退去時の扱い |
| 近隣 | 深夜の配車・出入りに対する近隣の理解。音・光・路上での待機 |

用途地域の判断や建築の可否は、建築士と特定行政庁の領域です。「この地域なら必ず事務所として使える」と決めつけず、物件ごとに用途地域と建物の状況を確認します。賃貸借契約の使用目的が合わないまま契約すると、認定の準備段階で営業所として使えないことが判明する場合があります。賃貸借の媒介と重要事項説明は当社が行い、契約前に使用目的と貸主の承諾範囲を整理します。

深夜稼働の飲食・遊興系と同様に、近隣への影響は立地選びの段階から見ておく論点です。物件・用途地域・近隣対応の読み方は[用途地域と事業用物件の読み方](/column/kaigo-jigyousho-bukken-youto-chiiki)の考え方も参考になります。

## 認定申請と物件契約は、どちらを先に進めればよい？（分離受任）

運転代行の開業では、物件・車庫・保険・申請がそれぞれ別の事業体にまたがります。順番を取り違えると、契約した物件が使えない、保険が間に合わないといった行き違いが起きます。

| 役割 | 誰が担うか |
| --- | --- |
| 営業所・車庫になる物件の調査・賃貸仲介 | 宅地建物取引業（当社） |
| 認定申請・保管場所証明（車庫証明）の書類作成 | 行政書士 |
| 損害賠償措置（保険） | 保険会社 |
| 法人設立・登記 | 司法書士 |
| 紛争・法的な評価 | 弁護士 |

実務では、営業所の用途適合と随伴車の車庫（直線2キロメートル以内）を不動産側で先に整え、そのうえで認定申請を行政書士へ進めるのが分かりやすい順序です。損害賠償措置は認定の要件（運転代行業法第3条）に関わるため、保険会社との契約も並行して確認します。

これらは**それぞれ独立した事業体**であり、**別々にご契約**いただく前提です。当社は物件と車庫の不動産面を担い、認定や車庫証明の申請は行政書士へ、保険は保険会社へと分けてご案内します。当社は紹介料を受け取りません。なお、随伴用自動車に客を乗せて運ぶ行為は旅客運送の許可に関わる論点があり、運輸局や行政書士への確認が必要です。

## よくある質問

**Q. 自宅の一室を運転代行の営業所にできますか？**
A. 住居専用の物件では、賃貸借契約の使用目的や用途地域の制限で事務所として使えない場合があります。自己所有でも、建物の規約や用途地域の確認が必要です。認定申請書に記す主たる営業所として使える物件かを、契約前に整理します。

**Q. 随伴用自動車の車庫は、営業所から離れていてもよいですか？**
A. 車庫法施行令は、保管場所と使用の本拠の位置との距離が直線でおおむね2キロメートルを超えないことを求めています。営業所から直線2キロメートル以内に車庫を確保します。月極駐車場を借りる場合は、貸主の保管場所使用承諾証明書を得られるかを確認します。

**Q. 物件を契約してから認定が下りないと困ります。順番はどうすればよいですか？**
A. 営業所の用途適合と随伴車の車庫を不動産側で先に整え、認定申請は行政書士へ分けて進めるのが分かりやすい順序です。損害賠償措置（保険）も認定の要件に関わるため、並行して確認します。物件・車庫・申請・保険は別々の事業体にご契約いただきます。

**Q. 車庫証明の申請も不動産会社に頼めますか？**
A. 保管場所証明（車庫証明）の申請書類の作成・代行は行政書士の業務です。当社は申請を代理しません。当社は車庫になる物件の調査と賃貸仲介を担い、申請は行政書士へおつなぎします。貸主からの保管場所使用承諾証明書の取得は、賃貸借の条件として整理します。
